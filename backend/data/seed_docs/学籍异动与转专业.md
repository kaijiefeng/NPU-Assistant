# 学籍异动与转专业办理指南（示例）

> 本文为示例知识库文档，用于演示辅导员数字分身的知识问答能力。文中的时间、比例、电话均为示例，实际执行以学校教务处发布的正式规定为准。

## 一、学籍异动的类型

学籍异动是指学生在校期间学籍状态发生的变更，常见类型包括：休学、复学、保留学籍、退学、转专业、转学、延长学习年限、保留入学资格等。各类异动均须通过学籍管理系统提交申请，经学院审核、教务处审批后生效，未经批准擅自离校或不参加教学活动的，按学校规定处理。

## 二、休学与复学

学生因疾病、参军入伍、创业或其他特殊原因需要暂停学业的，可申请休学。因病休学须提供二级甲等以上医院诊断证明，经校医院复核。休学一般以一年为期，累计不得超过两年（参军入伍除外）。休学期间保留学籍，不享受在校生待遇，不得参加课程考核。

复学应在休学期满前提出申请，因病休学的须提交康复证明并经校医院复查合格。复学后原则上编入原专业下一年级学习，已修课程成绩继续有效。参军入伍的学生退役后两年内可申请复学，并按政策享受相关优待。

## 三、退学与保留学籍

退学分为本人申请退学和学校按规处理退学两类。本人申请退学须由学生及家长（或监护人）签字确认，经学院审核后报教务处审批。保留学籍主要适用于应征入伍、国际组织实习等情形，保留期限按国家与学校规定执行。退学学生须办理离校手续，档案与户口按相关规定转出。

## 四、转专业政策

学校一般在大一学年结束后开放转专业申请，示例时间安排为每年 5 月发布通知、6 月组织考核、7 月公示结果。申请条件包括：政治思想表现良好、无违纪记录、已修课程成绩合格；部分专业对高考选考科目、身体条件有额外要求。艺术类、体育类、中外合作办学等特殊类型专业通常不参与转专业。

转专业流程：学生本人提出申请 → 转出学院审核同意 → 转入学院组织考核（笔试、面试或综合面试）→ 教务处审核并公示 → 办理学籍变更与课程认定。各专业接收名额与考核方式在当年通知中公布，示例接收比例为本专业年级人数的 5% 至 10%。

## 五、转专业后的课程认定

转专业学生须按转入专业培养方案修读课程。原专业已修且成绩合格的课程，与转入专业课程名称、学分、教学内容相近的，可申请学分认定；差异较大的课程需补修。转专业学生可能面临补修压力，建议提前了解转入专业培养方案，合理规划学期课程。转专业后原则上不再退回原专业。

## 六、延长学习年限与学业预警

因课程未修满或毕业设计未完成需延长学习年限的，应在毕业学年规定时间内提出申请，经学院审核后报教务处备案。学校实行学业预警制度，累计不及格学分达到一定数量的学生将收到学业预警通知，学院会安排学业帮扶与谈心谈话。收到预警的同学应主动联系辅导员制定修读计划。

## 七、咨询方式

学籍异动与转专业政策性强、时限严格，建议先咨询学院教学秘书与辅导员。咨询方式（示例）：教务处学籍管理科，示例办公地点为长安校区启真楼 4 层，示例电话 029-88XXXXXX，示例受理时间为工作日 9:00—11:30、14:30—17:00。请以教务处当年发布的正式通知为准。
