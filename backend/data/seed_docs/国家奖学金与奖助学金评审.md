# 国家奖学金与奖助学金评审办法（示例）

> 本文为示例知识库文档，用于演示辅导员数字分身的知识问答能力。文中的金额、时间、电话、地点均为示例，实际执行以学校当年发布的正式通知为准。

## 一、学校奖助体系概览

学校本科生奖助体系由“奖、助、贷、勤、补、免”六部分组成，主要包括：国家奖学金、国家励志奖学金、国家助学金、校级优秀学生奖学金、社会奖学金、临时困难补助、勤工助学岗位和学费减免等。各类项目由学生资助管理中心统筹，学院学生工作办公室负责具体组织与初审。家庭经济困难学生入学后可先通过“绿色通道”办理报到，再按规定申请资助项目。

## 二、国家奖学金

国家奖学金用于奖励特别优秀的全日制本科在校生。申请对象原则上为二年级以上（含二年级）学生，奖励标准为每人每年 8000 元（示例标准，以当年上级文件为准）。基本条件包括：热爱祖国，遵守宪法和法律及校纪校规；学习态度端正，成绩优异；社会实践、创新能力、综合素质等方面特别突出。

学业要求方面，一般要求学习成绩排名与综合考评成绩排名均位于同年级同专业前 10%；排名在前 30% 但其他方面表现特别突出的学生，可附证明材料提出申请。同一学年内，国家奖学金与国家励志奖学金不可兼得。

评审流程为：学生本人提出申请并提交材料 → 班级或年级民主评议 → 学院评审工作组初审并在学院范围内公示 3 至 5 个工作日 → 学校评审委员会审定并全校公示 5 个工作日 → 上报上级主管部门。示例时间节点：每年 9 月中旬发布通知，9 月下旬学院截止收材料，10 月中旬完成学校公示。

## 三、国家励志奖学金

国家励志奖学金用于奖励资助品学兼优的家庭经济困难学生，申请者须已通过当学年家庭经济困难认定，奖励标准为每人每年 5000 元（示例标准）。评审时既要看学习成绩，也要看日常表现和自强自立情况。申请材料包括申请表、成绩单、家庭经济困难认定结果和个人事迹材料。

## 四、国家助学金

国家助学金用于资助家庭经济困难学生的生活费用，分为三个等级，示例标准为每人每年 4400 元、3300 元、2200 元，一般按学期发放。申请国家助学金的前提是完成家庭经济困难认定，认定等级与助学金等级相衔接。助学金按学年评审，不要求成绩排名，但出现严重违纪或退学等情况将停止发放。

## 五、申请材料清单

1. 奖学金申请审批表（系统填写后导出，本人签字）；
2. 教务系统打印的正式成绩单；
3. 获奖证书、科研成果、社会实践与志愿服务证明的复印件；
4. 申请国家励志奖学金、国家助学金时，需提供家庭经济困难认定结果；
5. 个人事迹材料，示例要求 800 字左右，突出学业、实践与自强经历。

## 六、注意事项与咨询方式

所有材料必须真实有效，弄虚作假一经查实将取消当年及下一学年评奖评优资格。逾期未提交材料的视为放弃申请。对评审结果有异议的，可在公示期内向学院评审工作组提出书面申诉。

咨询方式（示例）：学院学生工作办公室，办公地点示例为长安校区启真楼 3 层，示例咨询电话 029-88XXXXXX，示例受理时间为工作日 9:00—11:30、14:30—17:00。学校学生资助管理中心负责政策解释与最终答复。请以学校当年发布的评审通知为准。
