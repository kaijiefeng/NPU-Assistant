# NPU 学生手册数据集建设方案（v0.2.0）

## 一、版本安排

- **v0.1.3（当前版本，冻结）**：真实数据清理、TDD 补库、生活服务覆盖、混合检索评测、外部来源审计；
- **v0.2.0（下一个小版本）**：专注构建 **NPU 学生手册数据集**，不再扩散功能。

v0.1.3 后只做 bugfix / 数据修订，不新增功能；v0.2.0 的交付物是“可版本化、可评测、可追溯”的 NPU 学生手册问答数据集。

## 三、数据集目标

### 3.1 范围

以西北工业大学官方学生手册/规章制度为核心：

- 本科生学生手册、研究生手册；
- 学工部、教务部、研究生院、校医院、保卫处、后勤、体育部等公开制度；
- 学院层面的学生管理细则（仅收公开、通用部分）；
- 生活服务指南（宿舍、洗浴、洗衣、餐饮、快递、校车、校园卡、网络等）。

### 3.2 规模目标（v0.2.0）

| 指标 | 目标 |
|---|---:|
| 原始文档 | 80–120 篇 |
| 问答对 | 300–500 条 |
| 类别 | 20+ |
| 可答题 | 70% |
| 多跳/跨章节题 | 15% |
| 不可答/应拒答题 | 15% |
| 每条答案引用 | 100% |
| 人工复核 | P0 100%，整体 ≥30% |

9. 洗浴、洗衣、水电、空调

11. 校园卡、网络、缴费
12. 图书馆、自习、体育场馆
13. 医疗、医保、心理
14. 就业、三方、档案、报到证

## 四、数据格式

每条 QA 采用“问题 + 答案 + 证据 + 版本”的结构：

```json
{
  "id": "npu-handbook-0001",
  "question": "宿舍里怎么洗澡？热水什么时间供应？",
  "answer": "……",
  "category": "宿舍与生活服务/洗浴",
  "answerable": true,
  "source": {
    "document_title": "校园生活向导",
    "source_url": "https://yingxin.nwpu.edu.cn/...",
    "page": 3,
    "section": "星天苑宿舍区",
    "quote": "……",
    "sha256": "...",
    "effective_date": "2026-08-27"
  },
  "review": {
    "status": "approved",
    "reviewer": "human",
    "reviewed_at": "2026-..."
  },
  "version": "2026.1"
}
```

配套文件：

- `documents.jsonl`：原始文档登记（标题、URL、sha256、版本、生效日期）；
- `qa.jsonl`：问答对；
- `eval.jsonl`：冻结评测集（含不可答题）；
- `dataset-card.md`：范围、许可、统计、局限；
- `coverage.csv`：类别 × 覆盖状态。

## 五、构建流水线

```text
官方来源清单
  → 下载/OCR/清洗（去导航、版权、无关内容）
  → 章节切分 + 页码/段落定位
  → 规则模板 + LLM 生成候选 QA
  → 引用校验（答案必须能在 quote 中找到依据）
  → 人工复核（P0 全量）
  → 冻结训练/评测集
  → 导入现有 LLM Wiki（只读本地库）
```

### 质量门禁

- 引用准确率 ≥ 95%；
- 无依据断言 = 0；
- 重复问题 < 2%；
- 不可答题必须明确拒答，不能编造；
- 所有来源 URL 必须属于 `*.nwpu.edu.cn` 或校内官方公众号；
- 每篇文档保留 sha256、抓取时间、生效/失效日期。

## 六、里程碑（v0.2.0）

| 阶段 | 交付 |
|---|---|
| M1 版本冻结 | v0.1.3 tag；本方案 |
| M2 来源盘点 | 80–120 篇官方文档清单 + 缺口 |
| M3 解析/清洗 | PDF/HTML/OCR 统一 Markdown + 章节/页码 |
| M4 QA 试点 | 50 条人工复核 QA，验证 schema/引用 |
| M5 全量构建 | 300–500 条 QA，覆盖 20 类 |
| M6 评测 | 检索/回答/引用/拒答四类指标 |
| M7 发布 | 数据集 v2026.1 + dataset card |

## 七、风险与边界

- **版权/授权**：只收公开资料，保留来源；不复制外校数据集；
- **版本时效**：学生手册会修订，必须记录生效日期和替代关系；
- **OCR 质量**：扫描件需人工抽检；
- **隐私**：不收录学生个人信息、成绩、联系方式；
- **幻觉**：无证据必须拒答；
- **外部数据**：开源数据集只做覆盖清单，不进入本地库；`scripts/audit_sources.py` 持续审计。
