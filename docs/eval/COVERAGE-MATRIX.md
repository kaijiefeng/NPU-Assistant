# 校园问答覆盖矩阵（参考开源数据集/项目）

目标：不再只按“现有文档”出题，而是先按真实校园生活/学习场景建立覆盖矩阵，再补数据、补测试。

## 一、参考的开源数据集/项目

| 来源 | 规模/内容 | 用途 |
|---|---|---|
| [HUST-Student-Handbook2](https://modelscope.cn/datasets/mars1441/HUST-Student-Handbook2) | 华中科技大学 2024 学生手册，700+ 中文问答对，Apache-2.0；覆盖学位、学籍、培养、学术规范、国际交流、奖惩、校园生活 | 学术/学籍类覆盖清单 |
| [CampusIQ](https://github.com/swenidot/CampusIQ) | IIT Jodhpur 34 题评测集：23 可答 + 11 不可答；不可答含体育馆时间、食堂退款、毕业典礼着装、博士补助、停车等 | “未知/不可答”与拒答测试 |
| [university-information](https://github.com/yiyuuuc/university-information) | 社区整理的 25 条大学生活质量 FAQ：宿舍、空调、独立卫浴、澡堂距离、早晚自习、跑步、假期、外卖、地铁、洗衣机、校园网、断电、食堂、热水、电瓶车、限电、通宵自习、电脑、校园卡、银行卡、超市、快递、共享单车、门禁、晚归 | 生活类覆盖清单 |
| [Campus-AI-RAG](https://github.com/liweisi91010/Campus-AI-RAG) | 基于学生手册/教务文件/规章制度的校园 RAG 原型 | 知识库范围与审核流程参考 |

这些数据**不直接整库导入**：学校不同、版权/时效不同，只作为“该问什么”的检查清单；真正入库的仍是西工大官方公开资料。

## 三、当前测试集

`docs/eval/realworld_golden.json` 已扩展到 **42 题**：

- P0：18 题（含宿舍洗澡、洗衣、空调、水电、门禁、自习室等生活类）
- P1：19 题
- P2：5 题

当前结果：**P0 18/18，整体 40/42（95.2%）**；剩余 P1 主要是银行卡发放、校医院就诊引用稳定性、外卖政策（无官方公开规定，按拒答处理）。

运行：

```powershell
.\.venv\Scripts\python.exe scripts\eval_realworld.py
```

## 四、下一步补库优先级

1. **P0 生活类已补齐**：洗澡热水、洗衣、空调、水电费、门禁晚归、自习室；
2. P1 待补：共享单车、外卖政策、体育场馆细则、通宵自习；
3. 学术类继续按 HUST 学生手册目录补：学位授予细则、退学/保留学籍、学术不端处理、国际交流；
4. 参考 CampusIQ 的“不可答”设计，补充**明确未收录**的负样本，训练系统拒答而不是编造；
5. 开源数据集只做覆盖检查，不把外校内容写入本地知识库。
