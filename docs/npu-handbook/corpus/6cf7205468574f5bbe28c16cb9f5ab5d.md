# 校车时刻-网络空间安全学院
一、周一至周五
1.友谊校区至长安校区
北一门发车。时间：7:00和8:00（南苑南门、西苑南门、海关十字公交道向南20米、紫薇壹号公园设有乘车点）、9:00、10:00、11:00、12:00、12:30、14:00、14:30、16:00、17:00、17:30、18:30、21:00。
学生班车: 时间10:00、16:30。
2.长安校区至友谊校区
泰山路（翱翔学生活动中心东侧）发车，紫薇壹号公园、劳动南路人人居设有下车点；若要在唐延路海关大厦下车，上车后请告知驾驶员。时间：6:40（东门设乘车点）、9:00、10:30、11:00、12:30、13:00、14:00、15:00、16:00、17:10（东门设乘车点）、18:00、19:00、21:00、22:30。
学生班车: 时间8:30、19:10。
二、周六、周日及节假日
1.友谊校区至长安校区
北一门发车。时间：8:00（西苑南门、海关十字公交道向南20米、紫薇壹号公园设乘车点）、9:00、12:30、14:00、18:00、20:00。
学生班车：16:00--18:00、20:00。
2.长安校区至友谊校区
泰山路（翱翔学生活动中心东侧）发车，紫薇壹号公园、劳动南路人人居设有下车点；若要在唐延路海关大厦下车，上车后请告知驾驶员。时间：9:00、 11:00、12:30、17:00、18:00、21:00。
学生班车：8:00--9:00。
