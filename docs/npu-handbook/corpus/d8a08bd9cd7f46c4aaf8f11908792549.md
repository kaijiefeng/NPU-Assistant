# 西工大-华为鸿蒙OS菁英班
西工大新闻网9月1日电（樊文迪）8月31日，西工大-华为鸿蒙OS菁英班结班仪式在华为西安研究所举行，党委学生工作部副部长、学生处副处长兼学生职业发展指导服务中心主任管兴华、副主任樊文迪参加结班仪式，仪式由华为西北区域招聘调配&高校生态合作总监鲁月华主持。
华为西安研究所人力资源总监刘宗平致欢迎辞。鲁月华回顾了本次菁英班从招募到结班的全部历程，并邀请优秀学员代表、技术部门负责人分别分享了经验和体会。最后，结合日常表现及理论考试成绩，为表现突出的6位学员颁发了一二三等奖学金，我校软件学院孙思桐同学获得了唯一的一个一等奖。
华为“HarmonyOS菁英班”是华为公司和西北工业大学落实校企合作，不断推进与行业领军企业开展人才交流输送的精准措施之一，通过面向在校信息与软件背景生源招募优秀学生，定制专属培养方案，是全新的HarmonyOS理论与实践的紧密结合的方式，培养出能深刻理解终端操作系统的优秀人才。2020年，华为公司面向西北工业大学开设了全国首个华为终端软件菁英班，在全校范围内招募相关专业在校生前往华为西研所深度参与华为终端软件开发测试工作。2021年，在2020年菁英班成功模式基础上，华为公司再次开设了华为鸿蒙菁英班。
（审稿：管兴华）
