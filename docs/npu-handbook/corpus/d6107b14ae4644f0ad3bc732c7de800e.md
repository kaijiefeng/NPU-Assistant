# 宿舍打印复印
西北工业大学宿舍打印复印
宿舍楼一楼设有自助打印机，可黑白打印、彩印和照片打印；打印数量较多时，可前往星天苑A楼对面大学生综合超市（大超）进门左手边打印。
使用前请确认打印机支持的支付方式，考试周建议错峰打印。
来源：西工大电子信息学院《22级新生攻略》。
