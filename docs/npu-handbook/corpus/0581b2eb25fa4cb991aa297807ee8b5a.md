# 第九届全国大学生集成电路创新创业大赛西北分赛区决赛
7月18—20日，第九届全国大学生集成电路创新创业大赛西北分赛区决赛在西北工业大学友谊校区成功举办，我校获一等奖13项，创历史最好成绩。
本届西北分赛区共设置了23个杯赛，吸引了来自陕西、山西、宁夏、青海、甘肃、新疆、内蒙古等七省区55所高校的878支团队报名，参赛规模较上届增长30%，创历史新高。经过初赛选拔，共有342支团队入围西北分赛区决赛，其中我校入围31支（微电子学院28支）。
比赛日上，各团队凝心聚力，近千名学子激烈角逐，通过现场答辩、实物展示、操作考试等方式，以及评审专家们规范、严格、专业、细致的评审，最终获一等奖队伍73支并晋级全国总决赛，其中我校13支（微电子学院12支），晋级率赛区第一（参赛队伍20支以上高校），创历史最好成绩，同时本科生一等奖数量连年第一。
在候场区举办了“集成电路人才对接会”，华为技术有限公司、北京竞业达数码科技股份有限公司、龙芯中科技术股份有限公司等11家知名企业参加，为参赛学生讲解行业形势，辅导职业规划，对接人才需求，现场气氛热烈。
7月20日西北分赛区颁奖典礼顺利举办，工业和信息化部人才交流中心教育培训处处长林恩雪，西北工业大学团委书记、共青团西安市委副书记佘磊磊，微电子学院党委书记杨妮花，以及企业和参赛师生代表参加典礼。典礼由微电子学院党委副书记余鹏主持。
林恩雪在致辞中指出，大赛通过“企业出题、高校解题”的模式，将行业发展需求融入人才培养，有效提升学生工程素养、实践能力和团队协作精神，为集成电路产业高质量发展注入新动能，为国家高水平科技自立自强提供坚实的人才支撑和创新保障。
杨妮花在致辞中介绍了学校、学院发展情况，肯定了参赛学生的优异表现，同时希望参赛学生通过大赛有所收获和留下宝贵经历，在未来以“芯”力量赋能科技强国，以“创”精神书写时代答卷。
全国大学生集成电路创新创业大赛是全国集成电路领域最大规模、最高档次的高校赛事，由工业和信息化部人才交流中心主办。本届西北分赛区由我校继第七届后第二次承办，微电子学院协办。下一步，微电子学院将持续深化“总师育人文化”，强化学生创新创业教育，为集成电路领域“总师型”人才培养提供“芯” 动力。
