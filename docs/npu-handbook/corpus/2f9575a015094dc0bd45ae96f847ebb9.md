# 西北工业大学集成电路学院2026年暑期校园开放日方案
一、学院概况
西北工业大学集成电路学院(微电子学院)坐落于陕西西安，2015年获批建设“国家示范性微电子学院”（全国首批26所），2019年学院挂牌独立运行。获批建设“国家集成电路人才培养基地”（全国20所）、“集成电路技术国家地方联合工程研究中心”。
学院办学基础雄厚。牵头建设“集成电路科学与工程”一级学科（全国首批18所），参与建设“电子科学与技术”一级学科。设有“微电子科学与工程”（国家级一流专业）、“集成电路设计与集成系统”两个专业。与航天771、772所、中航工业631、618所、中电科58、13所、华为、中兴、华大九天等科研院所和龙头企业深化产教融合，打造高水平人才培养与科研平台。
学院科研特色鲜明。围绕“四个面向”，深化“工科为本、三航当家、信息赋能、融合强校”理念，针对集成电路领域关键核心技术、世界科技前沿，发挥基础研究主力军和重大科技突破策源地作用。在军工宇航专用集成电路、航空航天特种微机电系统、光电集成芯片及微系统等研究领域具有特色优势。学院承担多项国家重大科研攻关项目，深度参与国家重大工程研制任务，为国防科技事业发展和国民经济建设作出了重要贡献。
学院坚持高质量人才培养。落实立德树人根本任务，致力培养集成电路领域“总师”型人才。学生学风优良，基础扎实，本科生深造率70%以上，研究生就业率100%，毕业生深受重点科研院所和国内外龙头企业等好评。与新加坡国立大学、香港城市大学等开展学生联合培养，开阔学生国际视野。学生在全国大学生集成电路创新创业大赛、中国研究生创“芯”大赛等顶级赛事中屡获优异成绩。
学院坚持教育、科技、人才“三位一体”发展思路，育国之栋梁、铸国之重器，努力建设具有三航特色优势的一流学院，为更好地服务强国复兴战略作出更大贡献！
为进一步促进各高校优秀大学生之间的思想和学术交流，吸引优秀学生来集成电路学院（微电子学院）继续深造，特举办2026年暑期校园开放日活动。

二、时间安排与人数规模
1.报名时间：2026年6月25日至7月8日
2.活动时间：2026年7月10日
3.预计人数：70人左右
三、学生申请条件
1.拥护中国共产党的领导，品德良好，遵纪守法，身心健康；
2.有志于从事学术研究，有较强的科研能力，并且有意愿到我院继续深造；
3.“双一流”院校或所学专业在全国学科评估中排名A类的三年级在校本科生；
4.学习成绩优秀，专业排名在40%以前的综合表现优异者（如在校期间获得科技活动、学科竞赛相关奖项或在重要期刊发表学术论文等）；
5.英语6级≥425分，或TOEFL≥72分；或GRE≥960分；或雅思≥5.5分。
四、申请与审核流程
1.网上报名：申请人登录西北工业大学研究生招生信息网（http://yzb.nwpu.edu.cn/）填写报名信息并按照要求上传附件材料。
2.申请人须提供以下材料：
（1）本科前三年成绩单、综合测评成绩单（加盖学校或院系教务部门公章）
（2）其他证明材料（已发表论文、获奖证书或其它考试证书的复印件）
申请人将以上材料扫描（或拍照）后整合为一个PDF文件，上传至报名系统，文件命名为“考生姓名-报考专业”。
3.学院审核：
材料审核工作于2026年7月9日中午12:00前完成，请申请者在报名系统中查询审核结果。
4.学生确认：
1.请申请者在规定的时间内及时确认是否参加。
2.审核通过后请加入暑期校园开放日活动QQ群，群号：790673507，入群时必须回答报名号+姓名+学校。
