# 微电子学院与中科芯集成电路公司合作交流
7月22日，西北工业大学微电子学院院长周德云、副院长王少熙、院长助理阴玥、魏廷存教授、青年教师张浩等一行前往江苏无锡中科芯集成电路股份有限公司参观学习，开展合作交流。
期间，中科芯集成电路股份有限公司微系统中心主任丁涛杰对智能微系统工程实现过程中的微纳加工、3D异构/异质集成等技术及成果进行了精彩的分享；中科芯集成电路股份有限公司西安分公司副总经理钱宏文就本科、硕士研究生联合培养方案进行了详细的介绍；西北工业大学微电子学院院长周德云对学院基本情况与研究方向同中科芯集成电路股份有限公司刘岱董事长等与会领导进行了深入的交流，并希望双方在人才培养、项目申报、实验室共建等方面加强合作并加快建设进程。
最后，中科芯集成电路股份有限公司董事长刘岱对西北工业大学微电子学院院长周德云等一行表示热烈欢迎，并希望双方加快进度、加大力度、快速推进双方在人才培养（本、硕、博课程建设）、实验室共建、项目联合申报、.教材和专著撰写、青年教师培训、首席专家聘任（兼职硕、博导师资发展）、工程博士培养、非全日制工程硕士培养、学生实习实践等方面深入合作,坚持传承“中科芯的信心与能力让用户放心”，“沉下心志，耐住寂寞，保持定力，成就伟业”的集成电路精神，共同致力打造自主可控、高性能、高可靠的国产化智能微系统。
