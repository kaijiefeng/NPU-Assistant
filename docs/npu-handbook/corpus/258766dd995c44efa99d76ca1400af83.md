# 西北工业大学教育实验学院-HarmonyOS菁英班招募宣讲
2022年5月10日，西北工业大学教育实验学院-华为技术有限公司“HarmonyOS菁英班”座谈会暨“HarmonyOS菁英班”招募宣讲会在教西B204举行，教育实验学院学院40余名参加了本次座谈会，会议由教育实验学院副院长蔡力主持。
蔡力表示，华为技术有限公司与教育实验学院是长期的合作伙伴，在人才培养领域推进的联合毕设、实习实践等协同育人项目都取得了良好的人才培养成效，菁英班是学校创新人才培养的新模式，他鼓励学生走出校园，学以致用、以用促学，在与行业领军企业沟通交流中加强自身本领。华为西安研究所校园招聘高级专员孙书宸就HarmonyOS高校人才培养合作整体规划进行了介绍；OpenHarmony高级技术专家龚阿世从HarmonyOS的缘起、现状及未来发展设想等方面为大家详细介绍了华为HarmonyOS；华为终端BG招聘调配部高级专员王鹏介绍了“HarmonyOS菁英班”培养模式、企业资源等方面的情况。
同学们积极发言，与华为公司相关老师就菁英班的选拔、培养等问题展开了深入地交流讨论。
