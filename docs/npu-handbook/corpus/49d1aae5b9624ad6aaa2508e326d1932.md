# 集成电路学院第七次学生代表大会暨第六次研究生代表大会通知
各班级团支部：
西北工业大学集成电路学院（微电子学院）第七次学生代表大会（以下简称“学代会”）暨第六次研究生代表大会（以下简称“研代会”）将于2026年6月召开。根据《中华全国学生联合会章程》《关于巩固高校学生会（研究生会）改革成果的若干措施》（中青联发〔2023〕3号）、《高校学生代表大会工作规则》（中青办联发〔2017〕9号）的有关规定，结合我院具体情况，学生会、研究生会主席团成员不超过3人，不设主席、副主席，设执行主席，执行主席由主席团成员轮值担任。为进一步做好新一届学生会、研究生会主席团候选人的选拔工作，相关事项通知如下：
一、候选人条件
1.候选人应当为共产党员或共青团员，理想信念坚定、热爱和拥护中国共产党，具有强烈的爱国意识和爱国情感。
2.候选人应积极弘扬和践行社会主义核心价值观，品行端正、作风务实、乐于奉献，具有全心全意为广大同学服务的觉悟和能力。
3.候选人应学有余力、学业优良，选拔过程将学习成绩和综合测评纳入考虑，目前无课业不及格情况。
4．候选人要具有代表性，具有广泛的群众基础，应当从学院学生会部门负责人、研究生会工作人员中产生。
二、工作原则
1.明确遴选条件，候选人须严格符合上述条件。
2.严格遴选程序，候选人应由学院团组织、党组织同意，由学院团委审查后，报学院党委确定。
3.选拔过程公开透明、公平竞争，确保广大同学的知情权、参与权，选拔结果进行公示，接受广大同学监督。
三、选举流程
1.5月14日 下发通知
学生会以及研究生会对各班团支部下发推选主席团候选人通知。
2.5月19日前 团支部推荐、材料提交
有意向报名新一届学生会、研究生会主席团候选人的同学填写报名表提交给学生会或者研究生会。
3.5月20日 确定候选人
学生会、研究生会联合对候选人进行资格审查，确定最终主席团候选人，并向学院党委报批。
4.6月初 大会选举
经学代会和研代会选举产生主席团，并在大会上进行公告。
四、材料提交说明
符合条件且有意向的同学请填写《西北工业大学集成电路学院（微电子学院）第八届学生会主席团候选人报名表》（附件1）或《西北工业大学集成电路学院（微电子学院）第六届研究生会主席团候选人报名表》（附件2），2026年5月19日24:00前将电子版发至学生会、研究生会邮箱。
