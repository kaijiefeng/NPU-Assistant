# 电动自行车充电桩使用
西北工业大学电动自行车充电桩使用
长安校区海天苑3号楼东北角自行车棚内设有智能共享充电桩，共有12个插口，24小时可供30-40辆电动自行车日常充电，扫码付款即可使用。
请勿将电动车电池带入宿舍或私拉电线充电，注意消防安全。
