# 学校超市营业信息
西北工业大学学校超市营业信息
长安校区大学生超市：正常营业时间8:30-23:00，地点在星天苑南餐厅1楼；迎新期间会提前至8:00开门。
友谊校区大学生超市：正常营业时间8:30-21:30，迎新期间延长至22:00。
此外，各宿舍区、教学楼附近还有便利店和小卖部。
