# 本科生补考、缓考与重修规定
西北工业大学本科生补考、缓考与重修规定
一、缓考
学生因病或其他特殊原因不能参加期末考试，可以申请下一学期初的缓考，具体按照《西北工业大学本科生考试管理办法》执行。
二、补考
学生考核成绩不合格的课程，可以参加下一学期开学初安排的同一课程补考，成绩记录标注“补”；补考仍不合格的，须重修。课程大纲规定无补缓考的课程，学生须重修。
三、重修
补考仍不合格的须重修；有考试违纪、取消资格或缺考情形的，该课程总成绩以0分计，不得补考，必须重修。重修课程成绩记录标注“重”。
依据：《西北工业大学本科生学籍管理办法》（2024年修订）第十七至十九条。
