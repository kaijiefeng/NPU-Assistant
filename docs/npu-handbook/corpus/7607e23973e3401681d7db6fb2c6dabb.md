# 宿舍楼自习室使用
西北工业大学宿舍楼自习室使用
学校宿舍楼每层设有一间自习室（云天苑的自习室在2楼），供学生复习、看书和安静学习使用。自习室属于公共空间，请保持安静、爱护桌椅设备，离开时带走个人物品。
考试周等高峰时段建议错峰使用；具体开放安排以各公寓楼通知为准。
来源：航天学院《迎新：校园日常攻略》。
