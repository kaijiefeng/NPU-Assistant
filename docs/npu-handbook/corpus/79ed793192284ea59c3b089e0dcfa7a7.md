# 校园生活向导：宿舍、洗浴、洗衣、空调、网络、餐厅
一、长安校区餐厅
海天苑餐厅建筑面积为7906㎡，餐厅分为三层，一楼为学生餐厅、每一天鲜食店（24小时供应），二楼为自选餐厅（智能化结算）和风味餐厅，三楼为民族餐厅和教工餐厅。
云天苑餐厅建筑面积约为10000㎡，一楼为学生五餐厅，二楼为学生六餐厅。
星天苑南餐厅建筑面积为7853㎡，一楼为学府餐厅，二楼为正禾星苑美食一餐厅和学子餐厅，三楼为正禾星苑美食二餐厅。
星天苑北餐厅与南餐厅遥相呼应，建筑面积为7480㎡，一楼为学生二餐厅，二楼为家乡美食城和民族餐厅，三楼为学生四餐厅和西餐厅，可以满足不同师生的就餐需求。
二、友谊校区餐厅
友谊校区学生一餐厅、学生二餐厅、风味小吃城、美食广场位于爱生楼内，提供平价餐品、各类风味小吃、品牌餐品等食品；教工餐厅位于健翔楼南面一楼，提供线上点餐服务，为师生提供便捷的就餐服务；西工大包子师生供应点在学校西门口处，使校园内外的师生都能够品尝到“西工大包子”的美味。
三、星天苑宿舍区
星天苑C、D、E、F、G五座为男生公寓。每幢楼由南北楼和中间连接单元三部分组成。宿舍为大走廊结构，一层设有公共洗衣房，每层各单元均设有各自卫生间，盥洗室和淋浴间，并有公共活动室。南、北楼分别采用错层设计，分为长短两个单元。宿舍内有地热水，暖气，校园无线WIFI覆盖，空调（需学生自行租赁）。
星天苑A、B座为四室一厅套房结构，每栋楼由南北楼和中间连接单元三部分组成，一层设有公共洗衣房，每个套间内均设有卫生间、淋浴间、客厅和盥洗室。宿舍内有地热水，暖气，校园无线WIFI覆盖，空调（需学生自行租赁）。
星天苑H座为一室带卫生间结构，楼宇设计为H型，由南北楼和中间连接单元三部分组成。一层设有公共洗衣房，每个房间设有卫生间、淋浴间。宿舍内有地热水，暖气，校园无线WIFI覆盖，空调（需学生自行租赁）。
四、云天苑宿舍区
云天苑公寓A、B、C、D座为大走廊结构，每栋楼由南北楼和中间连接单元三部分组成，一层设有公共洗衣房，每层楼均设有公共卫生间，盥洗室和淋浴间，并有公共活动室。南、北楼分别采用错层设计，分为长短两个单元。宿舍内有地热水，暖气，校园无线WIFI覆盖，空调（需学生自行租赁）。
云天苑E、F座为两室一厅套房结构，每栋楼由南北楼和中间连接单元三部分组成，一层设有公共洗衣房，每个套间内均设有卫生间、淋浴间、客厅和盥洗室。南、北楼未采用错层设计。宿舍内有地热水，暖气，校园无线WIFI覆盖，空调（需学生自行租赁）。
五、海天苑宿舍区
海天苑一号楼：
A座、C座为L型公寓楼，宿舍类型为3人间（上床下桌），内设电梯一部，一层设有公共洗衣房和无障碍卫生间，每层楼均设有公共卫生间，盥洗室和淋浴间，并有公共活动区域。宿舍内有地热水和太阳能供热水，暖气，校园无线WIFI覆盖，空调（需学生自行租赁）。
B座为M型公寓楼，宿舍类型为双人间（上下铺），内设电梯两部，每间公寓内均设有独立卫生间，一层设有公共洗衣房和无障碍卫生间，每层楼均设有公共卫生间和淋浴间。宿舍内有地热水和太阳能供热水，暖气，校园无线WIFI覆盖，空调（需学生自行租赁）。
海天苑二号楼：
宿舍为大走廊结构，宿舍内有地热水和太阳能供热水，暖气，校园无线WIFI覆盖，空调（需学生自行租赁）。
A座、B座、C座为U型公寓楼，内设电梯两部，一层设有公共洗衣房，每层楼均设有公共卫生间，盥洗室、淋浴间和无障碍卫生间，并有公共活动区域。
