# 两校区体育场馆个人预约平台使用方法
为提升体育场地使用效率，更好地满足全体师生体育锻炼需求，方便实时了解场地使用情况，体育场馆个人预约平台于2023年4月10日开始试运行。平台试运行具体事项如下：
一、体育场馆个人预约平台试运行场地：
体育场馆个人预约平台试运行仅限于羽毛球、乒乓球及网球场地的预约。可预约场馆：

二、体育场馆个人预约平台试运行可使用人员：可正常进入西北工业大学翱翔门户APP的教职工及学生。
三、体育场馆个人预约平台试运行预约方式：登录西北工业大学翱翔门户APP后进入体育场馆个人预约平台进行场地预约。
四、体育场馆个人预约平台试运行具体操作流程（见附件）
五、体育场馆个人预约平台试运行相关事项：
1、预约时间：可预约三天内场地
2、预约人数：每场每次不少于二人
3、为保证场地资源充分利用，未按约定时间到达场地超过15分钟，体育场馆个人预约平台将自动取消本次预约，并默认爽约一次，系统对30天内累计爽约三次的预约者有禁用30天的设置。
4、因故不能到场，请提前取消，避免进入黑名单，影响后期使用。
5、为避免现场入馆出现场地已被预约,请各位师生提前进入体育场馆个人预约平台进行预约或查看场地使用情况。
6、未进行场地预约入馆的人员不保证有场地可使用。
7、试运行期间，如有问题或建议请进入体育场馆个人预约平台沟通QQ群进行沟通。（QQ群号码：729051109 ）
