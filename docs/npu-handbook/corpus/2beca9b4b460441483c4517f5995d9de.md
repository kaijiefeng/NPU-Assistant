# 集成电路学院三航杯创新大赛答辩演练会
3月24日晚，集成电路学院（微电子学院）在长安校区学院楼111会议室举办第24届“三航杯”创新大赛答辩演练会，帮助参赛团队熟悉答辩流程、突出项目特色、优化呈现方式，打磨参赛项目。集成电路学院（微电子学院）秦鹏副教授、学工主管李媛婷、研究生辅导员王淼、本科生辅导员刘昊旻、玛丽女王学院国金项目负责人张开禹，以及各项目参赛学生代表参加本次会议。
路演环节，六组学生团队按照校级决赛的规范流程，聚焦芯片设计、AI视觉处理、北斗高精度定位等前沿技术领域，依次进行了系统汇报。各团队围绕技术攻关背景、核心创新突破、应用场景验证及落地成效等关键维度展开阐述。项目选题与内容设计紧密对接国家重大战略需求，突出关键技术自主可控的导向，充分展现了参赛学生扎实的专业功底、活跃的创新思维以及解决复杂工程实际问题的综合能力。
参会老师认真听取了各项目汇报，在肯定项目创新性与应用价值的同时，结合“三航杯”评审标准与相应赛道特点，逐一对项目逻辑架构、技术细节、团队协作、财务规划等关键环节，逐一进行了细致点评，并提出了具体、可操作的优化建议，为各团队后续的深入打磨与提升明确了方向。答辩演练现场互动频繁，交流深入。
本次答辩演练会不仅帮助各参赛团队在实战模拟中发现问题、找准短板，更通过参会老师精准指导实现了项目逻辑与展示效果的同步优化。以赛促学、以赛促教、以赛促创、以赛育人，集成电路学院（微电子学院）将持续深化“总师型”人才培养模式，紧密对接“三大赛”要求，推动产学研协同育人，力争在系列高水平竞赛中取得新的突破。
