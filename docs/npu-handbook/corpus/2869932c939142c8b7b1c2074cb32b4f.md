# 宿舍空调办理与租赁
西北工业大学宿舍空调办理与租赁
星天苑、云天苑、海天苑等学生宿舍配有空调，但需学生自行租赁。办理时按学校后勤/宿管通知缴纳押金并办理租赁手续，支持微信、支付宝等方式付款。空调使用产生的电费由宿舍成员按学校规定承担。
具体租赁点、押金标准和办理时间以学生公寓管理中心或后勤集团最新通知为准。
