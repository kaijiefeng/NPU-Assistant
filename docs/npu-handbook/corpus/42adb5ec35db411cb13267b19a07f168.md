# 本科生转专业条件与办理
西北工业大学本科生转专业条件与办理
学生在校学习期间对其他专业有兴趣和专长的，可以申请转专业；休学创业或退役后复学的学生，可根据自身需要申请转专业。
以特殊招生形式录取的学生，国家有相关规定或者录取前与学校有明确约定的，不得转专业。
学生在学期间只能转专业或调整专业一次。转专业学生必须完成转入专业培养方案规定的课程及各教学环节，达到转入专业毕业要求方能毕业。
本科生转专业的具体条件及办理流程，按照《西北工业大学本科生转专业（大类）实施办法》执行。
依据：《西北工业大学本科生学籍管理办法》（2024年修订）第二十四条。
