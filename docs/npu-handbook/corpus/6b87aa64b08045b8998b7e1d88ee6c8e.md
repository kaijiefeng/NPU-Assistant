# 校园网连接与认证
西北工业大学校园网连接与认证
校园网用户可使用无线网络：友谊校区选择 NWPU-YOUYI，长安校区选择 NWPU-CHANGAN。连接后，在弹出认证框中输入深澜用户名和密码完成认证；认证一次后一个月内无需再次登录，即连即用。
尚未激活深澜认证账号的校园网用户，请通过 http://zizhu.nwpu.edu.cn 自行激活。遇到问题可拨打服务热线 88491717，或通过翱翔门户微信企业号报修。
来源：信息化管理处《关于两校区无线网启用无感知认证的通知》（https://it.nwpu.edu.cn/info/2051/20881.htm）。
