# 西北工业大学集成电路学院研究生学科概况
集成电路学院（微电子学院）始终秉承西北工业大学“低调务实、兼收并蓄，厚积薄发、为国铸剑”的总师型人才培养理念，以“立德树人”为根本，聚焦集成电路领域国际学术前沿与国家重大战略需求，紧扣“卡脖子”技术突破与产业高质量发展需求，构建“基础扎实、专业精深、系统协同、实践导向”的拔尖创新人才培养体系。
（一）主建一级学科：集成电路科学与工程
基本介绍：集成电路科学与工程一级学科包含“集成电路设计与设计自动化”、“智能微传感器与集成电路”、“微纳电子材料与器件”、“智能集成系统”四个研究方向，致力于培养具备“专业精、系统强、重实践、敢担当”核心素养的集成电路领域领军人才与复合人才，为我国航空、航天、航海及国防科技工业领域核心芯片与系统自主可控提供人才支撑。

（二）参建一级学科：电子科学与技术
基本介绍：电子科学与技术一级学科包含“电路与系统”、“电磁场与微波技术”、“微电子学与固体电子学”、“物理电子学”、“航空电子综合技术”五个二级学科，立足服务国家与国防重大需求，坚持多学科交叉和宽口径专业教育，持续推动我国空天地海电 子科学与技术领域国防装备跨越式发展。
