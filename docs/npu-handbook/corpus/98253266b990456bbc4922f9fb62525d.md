# 关于2026年大学生医保报销的通知
接西安市医保中心通知，即日起2026年参保学生可正常享受医保待遇。现将报销相关事宜通知如下:
一、门诊就医：
我院已实施大学生门诊直报系统，正常参保学生在我院两校区门诊就医时，持医保电子凭证至收费窗口缴费可直接医保报销。因特殊原因未能直报的，请携带以下资料到校医院医保办审核报销：
（一）在校医院就医：
1.医保电子凭证；
2.门诊医疗费用发票（发票联）。
（二）转诊就医（经校医院医生转诊后在外院就医产生的费用）
1.医保电子凭证；
2.门诊医疗费用发票（发票联）；
3.门诊费用清单；
4.门诊病历；
5.每张化验、检查费发票对应的报告单（复印件）；
6.转诊申请单(寒暑假异地就医无需提供)。
（三）注意事项（报销截止日期）：
连续参保老生2025年1月1日至12月31日期间未报销的门诊费用，报销时间为即日起至2026年3月25日。2025级新生及上一年度断保学生待遇期内的费用，报销时间为即日起至2026年12月31日。逾期医保中心将不予受理。
二、住院就医：
正常参保学生持医保电子凭证，在我市医保定点医院办理医保入院手续，出院结算时可直接医保报销。
在待遇期内未使用医保报销的住院费用，可将报销资料（请关注“西北工业大学医院”微信公众号，输入关键词“未使用医保住院”查看）提交至校医院医保办，按医保中心相关规定审核报销。
请提前在支付宝、微信搜索“医保码”，激活领取“医保电子凭证，并设置六位数密码”。
