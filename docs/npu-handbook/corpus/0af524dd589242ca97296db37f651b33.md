# 集成电路学院毕业生就业常见问题
1．《报到证》是什么？有什么重要性？
《报到证》（以前称《派遣证》），由教育部印制，省级高校毕业生就业管理部门签发，是毕业生在规定时间内办理工作报到、个人户口迁移、人事部门转接档案等手续的凭证。如无《报到证》，则会出现以下情况：(1)异地或原籍均无法办理落户；（2）人事局或人才中心将不予接收毕业生的档案；（3）国有企事业单位无法将其作为正式工作人员等。
2．《报到证》丢了怎么办？
毕业生毕业后两年内《报到证》丢失可以补办，办理时带毕业证复印件、身份证复印件、《就业通知书》（《报到证》下半联，简称“白联”，存在学生档案中）的复印件及本人提交的书面报到证丢失补办申请，到就业中心领取《西北工业大学毕业生报到证丢失补办申请表》填写后到相关部门盖章，经陕西省教育厅批准后进行补办。《报到证》在毕业两年后遗失的不予补发，就业中心可开具《报到证遗失证明》。
3．毕业生如何办理改派手续？
毕业生毕业后两年内（毕业后第二年的6月30日前）可向学校就业中心提出改派申请，超过两年的不予受理，可按其它人员流动手续办理。学校办理改派原则上每2周一次，一般是周五上午到省教育厅办理，改派所需材料须在改派前一天交至就业中心。改派需要提交以下材料：原单位退函（离职或解约证明）、《报到证》原件、新签约的协议书或单位接收函及《西北工业大学毕业生就业调整申请表》（就业信息网下载）；若改派回原籍，则需要原就业单位退函或者无法落户证明、《报到证》原件、《改派回原籍申请表》（就业网下载）及父母户口本首页复印件。
4．改派后户口和档案怎么办？
改派后凭新《报到证》和《就业通知书》（“白联”）办理自己的户口与档案。《报到证》是办理户口的凭证，未在原单位落户的毕业生持原户口迁移证与新《报到证》到校公安处户籍室(友谊校区综合服务楼四楼88494447)办理相关手续；已在原单位落户的毕业生持新《报到证》到原落户派出所办理相关手续。学生凭《就业通知书》（“白联”）办理档案转移手续，到原档案所在单位提档，与其协商后将档案寄发或自带到改派后的新单位。
5．博士毕业生怎样办理派遣、离校相关手续?
（1）已向研究生院学籍科上报过当年预毕业的统分统招博士毕业生，持本人学生证到就业中心领取就业协议书及就业推荐表；（2）博士毕业生答辩后到所在学院领取《离校手续单》与《毕业研究生登记表》；（3）非定向博士毕业生毕业后持毕业证书复印件、一份已签约协议书及办理完毕的《离校手续单》到就业中心申请办理《报到证》；（4）定向、委培博士毕业生将《离校手续单》交学院保存；（5）《毕业研究生登记表》中的“学校意见”需先到就业中心开具介绍信，之后到学校党政办（长安校区数字化大楼105室）盖章；（6）“党组织关系介绍信”在学院党委办理；（7）持《报到证》到学校公安处户籍科(友谊校区综合服务楼四楼88494447)办理户口迁移手续。（8）离校前，本人到学校档案馆（友谊校区老图书馆南侧88492473）将“成绩单”及“毕业研究生登记表”归档。统分统招博士凭《就业通知书》（“白联”）提取档案；定向、委培博士凭单位调档函（单位介绍信）提取本人档案。
6．定向生、委培生是否可以解除定向或委培,并进行改派？
根据陕教生【2010】7号文件精神，对定向生、委培生一律派回原定向、委培单位就业，并对要求改派的毕业生坚决不予办理改派手续。
7．如何查询档案去向？
毕业生可致电学校档案馆（88492473）查询本人档案的去向。我校毕业生档案均通过机要方式寄送，如查询档案机要需先到就业中心开具“介绍信”，凭“介绍信”到学校机要室（长安校区数字化大楼302室88430097）领取“机要交寄单”复印件；持“介绍信”及“机要交寄单”复印件到西安市机要局（钟楼邮局后院87438870）查询机要去向；市机要局会将查询结果以挂号信的方式寄回学校（大概周期15天左右），学生可致电就业中心查询。
