# 校园里的110：保卫处24小时报警值班
西工大新闻网12月5日电（王晙)疫情防控期间，校园求助量激增，保卫处高度重视这一情况，将解决师生困难作为“我为群众办实事”的具体抓手，结合实际推行多种便民举措，为师生提供暖心服务，24小时报警值班电话承载了师生各方面求助。
校卫队员帮助师生运送各类物品，护送伤病学生去医院，为行动不便的老人送菜送药，探望独居老人并检查室内安全，开学季、毕业季为学生转运行李，为师生解决燃眉之急，为困难群众雪中送炭，通过各种暖心服务，践行工大保卫人的初心使命。部分队员放弃正常公休，坚守岗位、以校为家，加班加点顶下人手缺口，接待求助、配发物资、统计信息、沟通协调，每天奔忙于各种“烦难杂”的琐碎事务中，但是面对群众的各种求助，大家总是争着上、抢着上，把困难留给自己，把便利留给师生。
摆渡车送学生就医
摆渡车为学生运送物品
开学季、毕业季为学生转运行李
配合离退休处看望独居老人，并送去学校福利
为90岁独居老人检查天然气、打扫卫生、送饭
哪里有求助，哪里就有保卫人的身影，他们以忠诚诠释着责任与担当，以奉献传递着关爱与信心。
（审核：薛康）
