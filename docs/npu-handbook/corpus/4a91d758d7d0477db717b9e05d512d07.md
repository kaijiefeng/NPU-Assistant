# 2026级新生校园生活适应访谈工作全面启动
为助力2026级新生快速融入校园生活，我校学生心理健康教育中心全面启动新生校园生活适应访谈工作，邀请校内外专业心理咨询师与陕西师范大学心理学院研究生共32人组成访谈咨询师团队，联动各培养单位建立对接机制，畅通咨询师与学生的沟通渠道。
10月8日上午9:00，心理中心召开访谈咨询师培训会，心理中心主任刘欣主讲。刘欣对受邀咨询师长期以来的支持表达感谢，会议强调新生校园生活适应访谈是新生测评工作的核心环节，要求咨询师坚守以生为本，严格遵守专业规范与伦理准则，细致访谈、严谨评估，确保工作质效。随后，刘欣围绕访谈工作的核心原则、规范操作流程和注意事项进行细致讲解，为咨询师团队提供清晰的操作指南。
当日下午14:00，心理中心面向各培养单位开展线上新生校园生活适应访谈说明会。会议强调，新生适应访谈是精准把握新生心理状态、提供个性化成长支持的重要举措，对助力新生平稳度过适应期至关重要，呼吁新生辅导员高度重视、主动配合、认真落实。心理中心专职教师胡纯就访谈工作具体实施细则进行逐项说明，并细致解答辅导员的疑问。
2026级新生校园生活适应访谈工作将于10月12日至11月8日在各培养单位陆续开展，以深入了解新生校园生活适应状况，帮助新生缩短适应周期、顺利融入校园生活。
