# 图书文献-迎新网：图书馆开馆时间与使用
图书馆微信公众号
1、图书馆有多大？
西北工业大学图书馆是一个藏、借、阅、研四位一体的综合性研究型现代大学图书馆。图书馆现有馆舍总面积约4.6万平方米，由友谊校区毗邻的东、西两馆（合计1.4万平方米）和长安校区图书馆（合计3.2万平方米）组成。
2、图书馆有多少书？
截止2018年12月底，图书馆累计纸质馆藏量达365万册，特藏有姜长英航空史料约5000册，历届学位论文约3.9万册。2018年西北工业大学图书馆可使用数据库140种，408个子库。其中，中文数据库58种，221个子库；外文数据库82种，187个子库。共包括中外文电子图书近175万种，中外文电子期刊约4.8万种，国内外学位论文897万余篇，国内外会议论文754万余篇，科技报告499万余篇，技术标准19万篇。
