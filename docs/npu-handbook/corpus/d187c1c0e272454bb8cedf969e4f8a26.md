# 集成电路学院学子签约中兴蓝剑计划
近日，我院先进化合物器件芯片团队硕士研究生李昊东，凭借在人工智能与射频功放设计交叉领域的突出成果，顺利签约中兴通讯“蓝剑计划”。这一成绩既是学子个人奋进的成果，更彰显了学院及课题组在AI+战略布局下的精准育人成效。
图：中兴通讯人力资源总经理李浩为李昊东颁发签约礼
个人简介
李昊东，男，中共党员，师从关赫副教授和张浩副教授，2023年保研至我院新一代电子信息技术专业深造。在读期间，该同学在科研与创新方面表现突出，以第一作者身份发表了4篇期刊及国际会议论文，并已获授权或公开3项国家发明专利。同时，其在全国及省部级高水平学科竞赛中屡获佳绩，多次荣获国家级一等奖及省部级特等奖，展现出扎实的科研功底与卓越的实践能力。
图：李昊东在IMWS-AMP会议上发表报告
科研项目与成果
李昊东在“AI+射频”交叉领域的持续探索中，取得了一系列兼具创新性与实用性的研究成果，积极发挥引领作用带动团队共同成长。他创新性地将AI技术与各类射频器件设计深度融合，成功研发出AI驱动的超宽带功放、Doherty架构功放及高效整流器三类核心技术方案：基于AI模型结合B/J连续类功放阻抗解空间技术，以1/4的面积实现1-3GHz超宽带功放设计；通过AI算法实现后匹配Doherty架构功放一键生成，可覆盖1-3GHz范围内任意300MHz带宽需求；AI优化后的整流器方案更是凭借突出的技术创新性，助力张浩老师斩获日本PIERS会议青年科学家奖，成为该领域对其研究实力的高度认可。此外，他充分发挥传帮带作用，将自身积累的“AI+射频”设计经验无私分享，指导学弟运用AI技术优化滤波器设计，最终助力团队斩获全国大学生集成电路创新创业大赛一等奖，展现了科研成果的辐射价值与团队引领能力。
图：从左到右依次：AI+Doherty功放、AI+整流器、AI+宽带功放
李昊东不仅专注技术突破，更兼具鲜明的产业化思维，致力于让科研成果走出实验室、服务实际需求。他敏锐洞察行业设计效率低、流程复杂的痛点，独立开发出一款可实现从参数优化到版图生成“一键式”设计闭环的APP工具，该工具能显著缩短研发周期、降低设计门槛，在某平台分享后获得超50万次浏览，并吸引了多家科研单位与企业的合作意向，展现出强劲的产业化应用潜力。这些兼具技术深度与产业化价值的成果，与中兴通讯 “ALL in AI，AI for ALL” 的战略布局高度契合，成为其成功入选 “蓝剑计划” 的核心竞争力，也体现了学院与课题组在 “科研与产业双驱动” 培养模式的显著成效。
图：从左到右依次：功放设计APP、APP设计的实物、整流器设计APP
感悟与未来规划
谈及成长，李昊东坦言：“学院的AI+战略布局为我指明了方向，关赫老师和张浩老师的悉心指导让我少走了很多弯路，团队开放的科研氛围和充足的资源支持，让我能够放心大胆地探索未知领域。”未来入职中兴通讯后，他将延续在课题组的研究方向，聚焦功放AI设计底层算法开发，助力产业技术突破。
未来展望
此次李昊东入选中兴“蓝剑计划”，是我院“AI+”战略引导、先进化合物器件芯片团队精准育人的生动体现。未来，学院将继续聚焦前沿科技领域，深化校企协同育人，依托优秀导师团队与科研平台，为国家培养更多兼具扎实专业功底与创新思维的高素质人才，为我国通信技术高质量发展注入西工大力量！
