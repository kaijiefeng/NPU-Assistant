# 西北工业大学与华为深化鸿蒙PC产学研合作
3月2日下午，华为—西北工业大学鸿蒙PC实验局2026春季交流座谈会在长安校区计算机学院105会议室举行。华为终端全球生态发展部副总裁李剑南、陕西、宁夏、湖北省鸿蒙发展代表韦兴君、陕西省终端政企业务部长覃钰珩、政企经理张雪芳一行来访我校，计算机学院副院长郭斌、航空学院副院长万方义、信息化管理处副处长张文生、计算机学院基础教学与实验中心主任姜学锋及计算机学院、自动化学院骨干教师，大学生程序设计创新实践基地鸿蒙开发团队学生代表共同参会。双方围绕鸿蒙实验局建设、鸿蒙人才培养及产学研合作展开深度交流。
鸿蒙PC实验局作为华为与西北工业大学2024年共同签约成立的合作项目，是西工大发挥国防特色学科优势、探索国产化计算机教学与工业软件研发的关键平台。会上，姜学锋详细介绍了实验局前期建设成果，双方共建了鸿蒙PC教学平台，不仅将鸿蒙技术融入计算机基础、程序设计、软件技术等22门核心课程，还组建了跨航空、自动化、计算机等多学院的鸿蒙PC开发者队伍，从大一阶段开始定向培养鸿蒙人才，打造了从课程教学到实践应用的人才培养闭环。在技术研发与产品落地方面，西工大展现出亮眼的创新成果。
交流讨论环节，双方就鸿蒙生态建设、人才培养、工业软件研发等核心议题展开热烈探讨。华为方面表示，鸿蒙生态已顺利跨过用户数关键门槛，目前手机端用户达4100万左右，含PC、平板等在内的全终端用户近7000万，且鸿蒙PC已正式纳入国策，国产化替代进程全面提速。但当前鸿蒙PC生态仍面临工业软件开发工具缺失、跨系统应用迁移成本高等问题，高校作为人才培养和技术创新的核心阵地，成为鸿蒙PC生态建设的关键支撑。
西工大结合自身学科优势，提出多项深化合作的具体建议：一是申请成立工业软件虚拟教研室，联合国内相关高校打造工业软件领域的产学研共同体，精准对接国产化工业软件研发需求；二是细化鸿蒙班人才培养方案，联合华为开发专属教材、课程体系，打造拔尖鸿蒙人才培养阵地；三是拓展鸿蒙PC的应用场景，从高校教学延伸至航空、自动化等行业领域，开展工业软件国产化适配与研发。同时，西工大教师代表也提出了师资培训、教学资源建设、算力支持等实际需求，希望与华为携手完善鸿蒙教学体系。
华为对西工大的建设成果和合作建议给予高度认可，并回应将全力支持双方合作落地：一方面，将为西工大提供师资培训、技术支持，联合开发鸿蒙教学教材与课程，助力西工大打造鸿蒙人才培养标杆；另一方面，将吸纳西工大鸿蒙开发团队学生进入华为实习实践，深化校企人才双向培养；同时，华为将积极对接西工大工业软件研发需求，推动双方在航空工业软件、嵌入式开发等领域的联合攻关，加快鸿蒙PC在行业场景的适配与落地。此外，双方还探讨了在创新创业竞赛中开设鸿蒙应用赛道，扩大鸿蒙生态在高校学生中的覆盖面，培育更多鸿蒙开发者。
此次座谈会进一步夯实了华为与西北工业大学的产学研合作基础，双方将以鸿蒙PC实验局为核心，充分发挥华为的技术与生态优势和西工大的学科、人才优势，在课程共建、人才培养、工业软件研发等方面持续深化合作，打造“百千万”鸿蒙人才培养工程。未来，双方将携手打造鸿蒙PC领域的产学研融合标杆，既为鸿蒙生态输送高素质的专业开发人才，也加速国产化工业软件的研发与落地，推动鸿蒙PC生态在高校教学、航空航天等关键领域的应用，为我国信息技术产业国产化自主创新注入新动能。
（审稿：郭斌）
