# 海天苑电动自行车充电桩
为了完善长安校区海天苑配套设施，满足海天苑园区内学生电动平衡车和电动自行车的充电需求，后勤产业集团动力服务中心积极行动、成功联系安装了智能共享充电桩。
经过前期充分的市场调研，动力服务中心邀请专业公司对海天苑园区进行实地考察，根据现场情况编制充电桩的建设方案及资费标准。经过方案比较，最终选定陕西天天出行科技有限公司以最优惠的资费标准为同学们提供智能电动车充电服务。
充电桩位于海天苑3号楼东北角自行车棚内，2020年12月11日起已进入试运行阶段。充电桩共有12个插口，24小时可供30-40辆电动自行车日常充电，同学们可直接扫码付款使用。今后根据使用情况，会继续安装充电桩，以满足师生的需求。
长期以来，校园内缺乏自行车充电桩，师生员工无法正常充电，导致电动车进楼、公寓内拉线、飞线充电等现象时有发生，存在一定的安全隐患。海天苑园区率先引入电动自行车智能共享充电桩，在消除电动自行车充电安全隐患的同时，体现了后勤产业集团对海天苑“新、特、优”的定位要求，显示了后勤人“乐在人后，勤在人先”的工作理念和“以问题为导向，以需求为牵引”的工作思路。（动力服务中心 撰稿人：孙钊 樊凯 审核人：张应祥）
