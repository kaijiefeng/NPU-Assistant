# 关于两校区无线网启用无感知认证的通知
各校园网用户：
信息中心已于2018年5月19日启用两校区无线网无感知认证。启用后，访问无线网不会再反复弹出认证页面,实现无线联网，即连即用。
具体使用方法为：利用移动终端设备搜索NWPU-YOUYI（友谊校区）或NWPU-CHANGAN（长安校区），在弹出认证框中输入深澜用户名和密码即可，认证一次，一个月内无需再次登录。
无线无感知认证需要使用深澜用户名和密码，请还没激活深澜认证账号的校园网用户尽快通过 http://zizhu.nwpu.edu.cn，自行激活。
系统正在试运行，遇到任何问题，欢迎大家通过服务热线88491717反馈，也可通过翱翔门户微信企业号报修。
特此告知！
