# 毕业生就业三方协议签约说明
西北工业大学毕业生就业三方协议签约说明
三方协议即《毕业生就业协议书》，是毕业生、用人单位和学校三方确认就业关系的书面协议。签约流程如下：
1. 毕业生登录就业签约平台激活账号，填写并打印推荐表，交学院填写推荐意见并盖章，学院收齐后统一到就业中心盖章。
2. 参加招聘会或双向选择，与用人单位达成一致后，在签约平台提交电子协议书。
3. 用人单位填写协议书并签字盖章；无用人自主权的单位须由其上级主管部门或人事代理机构签字确认盖章。
4. 毕业生和用人单位均可打印纸质协议书，学院核对纸质协议与电子协议内容，确认无误后签章留存。
5. 学院定期将留存纸质协议书提交就业中心，就业中心汇总编制就业计划并上报派遣。
来源：电子信息学院《毕业生就业签约派遣办理程序》（https://dianzi.nwpu.edu.cn/info/1503/11568.htm）。
