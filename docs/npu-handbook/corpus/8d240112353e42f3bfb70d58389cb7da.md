# 教育实验学院赴华为西安研究所调研鸿蒙菁英班
9月4日，教育实验学院王掩刚院长、张文涛书记以及学院办公室主任于鸣鹭、2018级辅导员别晓峰等一行4人前往华为公司西安研究所开展拔尖人才校企联合培养调研交流活动。
华为公司西安研究所是华为公司除深圳总部外第一大研究所，是唯一覆盖全部九条产品线的研究所。在华为公司西安研究所招聘总监鲁月华、招聘专员孙书宸的陪同下，王掩刚院长一行先后参观了华为开放实验室、全球技术支持中心、员工办公区域等地。华为公司“对外以客户为中心，对内以奋斗者为本”的工作理念让人印象深刻。
随后，华为公司西安研究所所长龙季平、人力资源部部长杨宝东、招聘总监鲁月华、招聘专员孙书宸等四人和教育实验学院一行四人就探索拔尖人才校企联合培养新模式进行了会议研讨交流。
王掩刚院长以“点燃未来灯塔、引领社会前进，做新时代的领跑者”为题，从发展现状、培养成效、特色举措、教学资源、合作空间等五个方面介绍了教育实验学院培养拔尖创新人才的基本情况，以及开展校企联合培养拔尖创新人才的构想思路。王掩刚院长特别提到了2020年暑假我院四名优秀学生参加华为鸿蒙生态菁英班（全校共选拔包括硕士博士在内的32名学生）的情况，我院本科大三学生闫晓鹏获得唯一的一等奖，我院本科大二学生丁磊磊获得三等奖。
龙季平所长对学院“协同育人、交叉创新、中西融汇、追求卓越“的拔尖人才培养理念表达了高度赞同。他表示，华为的发展深耕于高新技术产业，而高新技术的发展离不开高精尖人才，西北工业大学十多年来为华为公司提供了大量优秀毕业生，为华为公司的发展壮大做出了很大贡献。所以，华为西安研究所非常愿意与西工大进一步共同探索拔尖人才校企联合培养的新模式，共同助力拔尖人才培养。
针对具体合作事宜，双方积极交换意见建议。探讨了聘请华为科学家担任学院学生的校外导师、在大学工程训练实践中心设立华为科研创新平台、探索有规模的华为长期实习工作、探索本硕博衔接的校企联合培养新模式等合作事宜。并共同商定了9月9日华为西安研究所的科学家来学院和优秀学生开展前沿科技交流学术沙龙的具体事宜。
最后，双方参加研讨交流人员合影留念。
