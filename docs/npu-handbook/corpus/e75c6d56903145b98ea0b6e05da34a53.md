# 西工大荣获华为鸿蒙行业共创灯塔奖
2025年12月11日，在华为公司于武汉举办的鸿蒙办公产业峰会上，西北工业大学凭借在鸿蒙生态产教融合与创新人才培养方面的突出贡献，荣获行业共创“灯塔奖”。该奖项旨在表彰为推动鸿蒙生态发展树立标杆、发挥引领作用的先锋单位，标志着西工大在国产操作系统根技术教育推广与工业软件人才培养模式创新方面取得了重要突破。
峰会期间，西工大“鸿蒙产教融合实验室”负责人、计算机学院计算机基础教学与实验中心主任姜学锋老师作了题为“鸿蒙操作系统：引领工业软件教育的变革”的主旨报告，系统阐述了我校计算机学院以鸿蒙技术为牵引，构建“优系、优质、适用”人才培养体系的实践路径。通过建设具有示范意义的“鸿蒙产教融合实验室”，学院围绕全过程、全要素、全周期的根技术人才培养目标，将鸿蒙技术深度融入教育教学体系，不仅实现了“知识传授、能力培养”方式的系统性革新，更将“价值塑造”贯穿育人全过程，为软件人才自主培养探索出一条独具特色的创新之路。
自2025年9月“鸿蒙产教融合实验室”正式启用以来，我校计算机学院持续推进课程教学改革、科研创新、师资队伍建设与生态应用拓展，构建了系统化、高效的全链条协同机制。计算机基础教学与实验中心教师团队成功研发了鸿蒙系统下C/C++开发工具软件、智能机考系统等一系列关键教学支撑平台，形成了“课堂教学—实训平台—科研创新—生态共建”四维一体的闭环育人模式。相关成果为鸿蒙生态在高等教育领域的深度落地提供了可复制、可推广的“西工大方案”，受到行业广泛认可。
作为陕西省最早系统布局鸿蒙生态教育体系的高校，我校积极发挥示范引领作用，主动承担区域辐射责任。计算机学院多次举办“鸿蒙产教融合交流会”，有效推动了“高校—中小学—企业”三位一体协同联动，逐步构建起覆盖多层级教育体系的鸿蒙教学生态系统，为区域教育数字化转型升级和“人工智能+教育”深入发展提供了有力支撑。
此次荣获“灯塔奖”，是对我校特别是计算机学院前一阶段工作的充分肯定，更是对未来持续深化探索的有力激励。学校将以此为契机，进一步深化产教融合、拓展合作生态，持续完善鸿蒙特色人才培养体系，为发展自主可控的信息技术产业、培养国家急需的高水平创新型软件人才贡献西工大智慧与力量。
（审稿：郭斌）
