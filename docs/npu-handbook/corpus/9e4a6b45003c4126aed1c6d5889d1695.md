# 西北工业大学集成电路学院先进集成与可靠性团队
一、团队介绍
先进集成与可靠性团队依托于集成电路学院（微电子学院），长期聚焦于芯片与微系统的高集成、高性能、高可靠与智能化发展开展多学科交叉研究，形成了从芯片设计到系统集成、封装及可靠性验证的完整研究体系。现有博导2人，硕导5人，在校硕博研究生60余人。近年来，团队承担国家级、省部级科研课题30余项，理论成果在国内外相关领域主流期刊和会议上发表论文200余篇，其中ESI热点论文11篇、高被引论文23篇，教材/专著4部，授权发明专利40余项。多项研究成果应用于我国高端装备与信息电子领域，实现了关键芯片与微系统高可靠设计及验证方面的重要突破，获省部级和一级学会科技奖一等奖2项、二等奖7项。指导研究生获国家奖学金、各类专项奖学金等20余人次，毕业生在科研院所、高校及高新技术企业中表现突出。

负责人介绍
王少熙：教授，博导，西北工业大学集成电路学院（微电子学院）副院长，主要从事先进集成、可靠性与生物微电子相关领域研究。陕西省三秦特支创新领军人才，西安市地方领军人才，江苏姑苏创新创业领军人才，浙江宁波甬江人才工程创业团队，陕西省数字经济协会专家，IEEE BioCAS技术委员会委员，IEEE EMBS技术委员会委员，中国微纳米协会高级会员。全国一级赛事工业和信息化技术技能大赛集成电路EDA开发应用赛项专家、总决赛裁判长。
三、主要研究方向
研究方向一：先进集成微系统
面向高性能、高集成、低功耗电子系统发展需求，围绕专用集成电路芯片、射频微系统集成和先进封装等关键技术开展研究。突破面向航空航天、电子信息装备等应用场景的专用芯片设计、射频功能模块与微系统集成，以及高密度封装与异质集成等核心问题，构建从芯片到系统的先进集成技术体系，服务于复杂环境下高性能电子装备的发展需求。
团队研制的伺服控制专用ASIC芯片和建立的超薄悬空MEMS阵列与CMOS三维集成技术
超大规模高密度金属互连技术与混合键合技术
研究方向二：芯片与微系统可靠性
面向芯片与微系统在复杂工况和高可靠应用场景下的稳定运行需求，重点开展芯片与微系统散热、芯片与微系统失效分析、电子元器件与制造工艺可靠性评价等研究，形成涵盖芯片热管理设计及故障诊断分析、元器件及微系统可靠性测试评价与寿命预测的研究体系，为高可靠芯片与电子系统研制提供理论基础和技术支撑。
无人机通信系统核心元器件高功率微波损伤效应及高精度失效检测
研究方向三：生物微电子
面向智能医疗与新型电子器件交叉前沿，团队围绕新一代心电图机、基于人工智能医学分析、新型神经形态器件及芯片等方向开展研究。推动微电子技术与医学、人工智能、类脑计算深度融合，在智能医学检测设备、医学信号智能分析以及新型器件与芯片实现方面形成特色研究，为生物医学工程和新一代智能电子技术发展提供创新方案。
