# 教务部-课程思政精品课程推荐通知
各教学单位：
根据《陕西省教育厅办公室关于开展2026年课程思政精品课程认定的通知》要求，学校现组织开展2026年陕西省课程思政精品课程和教学团队（本科）校内遴选推荐工作。现将有关事项通知如下。
一、指导思想
深入贯彻习近平总书记关于教育的重要论述，按照中共中央办公厅、国务院办公厅《关于深化新时代学校思想政治理论课改革创新的若干意见》，教育部《高等学校课程思政建设指导纲要》，全面落实立德树人根本任务，坚持以“总师育人文化”引领人才培养，发挥教师队伍“主力军”、课程建设“主阵地”、课堂教学“主渠道”作用，强化示范引领，全面推进课程思政建设理论研究和教学实践，着力构建全面覆盖、类型丰富、层次递进、相互支撑的课程思政体系。
二、申报条件
1. 课程已纳入本科人才培养方案，实施学分管理，并至少经过两个学期或两个教学周期的建设和完善。校级课程思政示范课程、校级及以上“课程思政大练兵”获奖课程和各类课程思政优秀案例获奖课程优先推荐。
2. 课程准确把握“坚定学生理想信念，教育学生爱党、爱国、爱社会主义、爱人民、爱集体”主线，结合所在学科专业、所属课程类型的育人要求和特点，深入挖掘蕴含的思政教育资源，优化课程思政内容供给。
3. 课程注重体现学校办学定位和学科专业特色，注重价值塑造、知识传授与能力培养相统一，科学设计课程目标和教案课件，将思政教育有机融入课程教学，达到润物无声的育人效果。
4. 课程以落实立德树人根本任务为核心，注重课程思政建设模式创新，教学内容体现思想性、前沿性与时代性，教学方法体现先进性、互动性与针对性，形成可供同类课程借鉴共享的经验、成果和模式。
5. 课程可由一名教师讲授，也可由教学团队共同讲授。入选精品课程相应团队自动认定为课程思政教学团队，教学团队无需单独申报。
6. 课程授课教师政治立场坚定，师德师风良好。课程负责人具有高级职称，能够准确把握本课程开展课程思政建设的方向和重点，并融入课程教学全过程。课程教学团队人员结构合理，任务分工明确，集体教研制度完善且有效实施，经常性开展课程思政建设教学研究和交流，课程思政建设整体水平高。
7. 课程考核方式和评价办法完善，育人效果显著，学生评教结果优秀，校内外同行专家评价良好，形成较高水平的课程思政展示成果，具有良好的示范辐射作用。
8. 已获普通本科教育、研究生教育或继续教育的国家级、省级课程思政精品课程（示范课程），该课程不得重复申报，课程负责人在本科或研究生同一学段内不得以负责人再次申报课程。
9. 分领域思想精品课程申报范围为2025年秋季学期、2026年春季学期已向陕西省教育厅申报过的“分领域思想专题教学讲义推广使用课程”试点课程。
三、申报要求
请各教学单位高度重视课程思政精品课程申报工作，结合办学定位、专业特色和课程特点，广泛动员、积极组织。对符合申报条件的课程和团队，组织专家认真开展院级遴选评审和材料指导凝练工作，各教学单位推荐申报不超过5个课程并在汇总表中对申报课程明确推荐顺序，分领域思想精品课程不做限额要求。
申报材料包括：
1. 课程思政/分领域思想精品课程和团队申报汇总表（见附件1-1、1-2）：汇总表word电子版一份（无需签字盖章），纸质版一份（含签字盖章），内容须保持一致。
2.课程思政/分领域思想精品课程和团队申报书及其附件材料（见附件2）：申报书PDF电子版一份（含课程负责人签字），附件材料PDF电子版一份（按申报书中“附件材料清单”顺序汇总并含相应签字盖章）。
要求所有报送材料均能上网公开，申报教师和教学单位须严格审查，确保不违反有关法律及保密规定。请各教学单位于2026年11月10日（周二）前统一将汇总表word、申报书PDF、附件材料PDF电子版发送至指定邮箱，汇总表纸质版提交至指定地点。
教务部将结合课程教学评价情况，组织专家遴选评审，按限额择优推荐17项（本科）思政精品课程、教学团队，以及分领域思想精品课程。
