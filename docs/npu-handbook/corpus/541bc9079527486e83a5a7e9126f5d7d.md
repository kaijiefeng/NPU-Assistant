# 全国首家鸿蒙系统教学适配应用落地西工大
11月12日华为终端公司中国区副总裁徐虎率核心团队访问西北工业大学计算机学院，双方就鸿蒙系统教学适配应用开展交流研讨。副院长郭斌、基础教学与实验中心主任姜学锋及相关教师参加了本次研讨，姜学锋主持座谈交流。
徐虎副总裁携团队人员首先参观了位于实验大楼的“鸿蒙系统实验室”，深入了解了全国首家鸿蒙系统教学适配应用的落地情况，并与正在开展鸿蒙应用开发的师生团队亲切交流。在听取实验室建设情况后，徐虎副总裁指出要持续深化产教融合，将实验室打造成为国产操作系统人才培养的高地和行业应用创新的策源地。
座谈会上，郭斌对徐虎一行表示欢迎和感谢，他说：与华为鸿蒙的合作已超越传统校企合作范畴，我们正共同探索自主基础软件人才培养的新路径，和鸿蒙的合作将让我们的学生在国产系统崛起过程中获得先发优势。接着双方就鸿蒙系统教学适配应用、鸿蒙人才培养及“鸿蒙支持领域应用灯塔计划”等关键议题展开深度研讨。双方均表示，西工大在科技领域的深厚积淀与华为鸿蒙在基础软件领域的创新实践形成完美互补，此次合作不仅是技术对接，更是构建自主可控技术生态的重要实践。
此次交流研讨为未来双方进行深层次的合作奠定了良好的基础，不仅是校企合作模式的创新突破，更是响应国家关于加强基础软件人才培养号召的具体实践，为构建自主可控的国产软件生态系统提供了“高校－企业”协同的新范式。
（审稿：郭斌）
