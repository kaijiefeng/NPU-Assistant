# 西北工业大学集成电路学院（微电子学院）学院简介
凝芯铸魂,飞天巡洋
西北工业大学集成电路学院(微电子学院)坐落于陕西西安，2015年获批建设“国家示范性微电子学院”（全国首批26所），2019年学院挂牌独立运行。获批建设“国家集成电路人才培养基地”（全国20所）、“集成电路技术国家地方联合工程研究中心”。
学院办学基础雄厚。牵头建设“集成电路科学与工程”一级学科（全国首批18所），参与建设“电子科学与技术”一级学科。设有“微电子科学与工程”（国家级一流专业）、“集成电路设计与集成系统”两个专业。与航天771、772所、中航工业631、618所、中电科58、13所、华为、中兴、华大九天等科研院所和龙头企业深化产教融合，打造高水平人才培养与科研平台。
