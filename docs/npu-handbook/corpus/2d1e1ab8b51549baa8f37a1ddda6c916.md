# 集成电路学院2026级本科新生见面会暨军训动员大会
8月22日下午，集成电路学院2026级本科新生见面会暨军训动员大会在教学东楼B1-102举办。学院党委书记杨妮花、副院长阴玥、班主任代表郑然出席，2026级全体本科新生参会，会议由2026级本科生辅导员王淼主持。
杨妮花书记代表学院对新生表示热烈欢迎。她回顾学校发展历程，讲述学校自1938年建校以来与国家命运紧密相连的办学底色，介绍学校在集成电路领域的办学积淀与杰出校友事迹。勉励新生牢记为国铸剑使命，将个人发展融入国家战略需求，以优秀校友为榜样，树立求真务实的优良学风。
阴玥副院长围绕专业学习开展讲解，厘清微电子与集成电路的学科关系，解读本科阶段学业任务，寄语新生进入大学仍要保持奋斗姿态，切勿松懈。他结合行业数据介绍集成电路产业发展现状，分析国内行业面临的机遇与挑战，引导新生认清专业价值，扛起时代赋予的责任。
班主任代表郑然副教授对新生寄予殷切期望。他结合行业技术瓶颈，对同学们大学学习生活提出要求，指出大学阶段要做到理论学习与实践锻炼相结合，积极参与实践活动，并向新生介绍学院各类科研育人平台资源。
2026级新生代表苗欣悦感谢学院的关怀保障，号召全体同学谨记“三实一新”校风、“公诚勇毅”校训，传承总师育人文化，脚踏实地，努力成长为总师型后备人才。
会后，辅导员王淼老师开展军训动员，介绍军训相关安排，祝愿新生开启充实的大学生活。
愿2026级新生厚植报国情怀，锤炼专业本领，把个人理想融入集成电路事业发展，勤学善思、笃行实干，书写青年一代的青春答卷。
