# 西北工业大学集成电路学院科研概况
集成电路学院（微电子学院）紧密围绕“四个面向”，深入践行“0到1”“1到0”科研理念，精准对接航空航天航海等国家重大需求，聚焦集成电路核心关键问题和“卡脖子”技术瓶颈，自觉发挥基础研究主力军和重大科技突破策源地作用。学院兼顾“0到1”原创性自由探索与“1到0”回溯性基础研究，一方面鼓励科研人员开展“原创性”的底层技术创新，深耕基础原理与核心算法；另一方面立足西工大系统、整机、型号研究优势，从航宇装备应用场景中梳理关键科学问题，开展“有中寻根”反向攻关，实现“从工程中来、回工程中去”的科研闭环，在航宇专用集成电路设计、空天微纳机电系统、先进集成及可靠性等领域形成鲜明特色优势，推动“0到1”原创突破与“1到0”技术溯源双向发力，助力关键技术从跟跑、并跑向领跑跨越。学院主持承担国家科技重大专项、国家重点研发计划、武器装备重点型号、国防基础科研、国防预先研究、国家重大计划、国家自然科学基金重点项目等重要项目，深度参与了多型卫星、飞机等国家重大工程的研制任务，为国家集成电路产业自主可控、国防科技事业发展和国民经济建设做出重要贡献。
