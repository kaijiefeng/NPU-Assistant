# 中兴通讯蓝剑计划集成电路学院座谈会
2025年9月2日上午，中兴通讯“蓝剑计划”优秀人才招募座谈会在我校长安校区启真楼110会议室成功举办。本次活动由微电子学院与中兴通讯联合主办，旨在为微电子及相关专业学生搭建与企业面对面交流的高端平台，助力同学们深入了解行业前沿人才需求。
中兴通讯TQE（技术质量鉴定）部长王一行、TQC（全面质量管理）总监张放、技术专家级总监任菀舒及合作企业代表出席座谈会。我院副院长阴玥、副教授马彦昭、计算机学院副教授安建峰及研究生代表共同参会。
座谈会上，中兴通讯TQE部长王一行首先介绍了公司的发展战略与布局，指出作为全球领先的通信解决方案提供商，中兴正持续深耕5G、芯片及云计算领域，并积极拓展政企与算力新赛道。他特别强调，西工大在集成电路领域特色鲜明，培养学生专业基础扎实，与中兴的人才需求高度契合。
随后，王一行详细介绍了芯片技术管理类岗位的职责，涵盖半导体器件技术评估、供应商管理与质量管控等，欢迎微电子、电子科学与技术等专业同学加入，并强调企业重视沟通协作和快速学习能力。
“蓝剑计划”作为公司顶尖人才项目，为入选者提供导师制、系统培训和快速晋升通道。王一行表示，西工大校友在中兴表现优异，期待更多同学加入。
交流环节中，同学们就专业发展、实习就业等问题与企业代表深入交流。大家表示，通过此次座谈对行业趋势与个人规划有了更清晰的认识。
本次座谈会为我院学生与行业龙头企业搭建了高效交流平台，学院今后将继续拓展优质企业资源，助力学生实现更高质量就业。
