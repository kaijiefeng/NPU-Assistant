# 国有资产管理处调研微电子学院共享实验平台
4月25日下午，国有资产管理处副处长史建强来微电子学院调研座谈，微电子学院党委书记甘雪涛、副书记余鹏、办公室主任景省利参加了座谈会。会议由甘雪涛主持。
会议开始，甘雪涛简要介绍了学院在人才培养、科研成果、实验教学平台建设等方面的基本情况，重点讲述了学院目前公用房资源配置的现状以及存在的主要问题，以期通过共享实验平台的建设进一步优化现有资源配置，为学院科技工作高质量发展以及人才培养质量稳步提升做好服务和保障。接下来，史建强从资产管理机制、公用房管理办法等方面详细介绍了学校在深化公用房改革、优化公用房资源配置工作中的理念、做法和经验，并对我院共享实验平台的建设提供了宝贵的意见建议。
此次调研座谈，使学院对学校公用房资源管理及改革办法有了更深入的了解，对于学院下一步建设共享实验平台、优化公用房资源配置具有重要的指导意义。
