# 西北工业大学集成电路学院混合信号ASIC设计团队
一、团队名称：“混合信号ASIC设计”科研团队
二、团队负责人：魏廷存教授
三、团队成员：
魏廷存：博士、教授、博士生导师，E-mail: weitc@nwpu.edu.cn
陈 楠：博士、副研究员，E-mail: nc@nwpu.edu.cn
魏廷存：（日本）東北大学工学博士，在日本留学和工作近十年。现任西北工业大学集成电路学院教授、博士生导师。入选西安市“5211”人才引进计划。主要从事模拟与混合信号专用集成电路设计方面的研究与人才培养。担任项目负责人，主持研发成功国内首款TFT-LCD驱动控制芯片以及数字电源SoC控制芯片，以第一完成人获得陕西省科学技术一等奖1项、二等奖2项，相关科研成果得到中央电视台《新闻联播》等媒体的报道。完成和承担国家或省部级科研项目20余项，已发表研究论文200余篇、获授权发明专利30余项、完成科技成果转化6项。
陈楠：博士，副研究员。主持国家自然科学基金面上项目、青年项目、陕西省自然科学基金面上项目、以与及华为、航天771所，中电58所等科研院所合作项目8项，并参与4项国家重大科研项目的研发工作。发表学术论文30篇余篇，获授权发明专利8项。入选陕西省三秦特支青年拔尖人才、陕西省高校优秀青年人才支持计划，获华为“火花奖”等。获得全国教师授课竞赛国家级奖2项，指导学生获得国家级学科竞赛奖13项，包括中国国际“互联网+”大学生创新创业大赛金奖和银奖等。
四、团队研究方向：
模拟与混合信号专用芯片设计，具体研究方向包括：
1）数字电源及智能电源控制芯片与系统；
2）微弱环境能量采集自供电芯片与系统；
3）空间探测专用芯片与系统；
4）神经网络硬件加速芯片与微系统；
5）平板显示驱动控制芯片。
1. 数字电源及智能电源控制芯片与系统
随着集成电路与人工智能（AI）技术的快速发展，电子系统的功能日益强大、电路规模持续增长，导致消耗电流急剧增加、且负载频繁变化，这对供电电源的性能提出了更高的要求。目前，电子系统的供电需求已进入“多电压轨、高转压比、大功率、高精度、高能效、高可靠、高功率密度以及复杂工况自适应”的新时代。在此背景下，开关电源必须向着数字化和智能化的方向发展。我们团队长期从事数字电源和智能电源的控制算法、以及数字电源SoC控制芯片设计方面的研究。（见图1）。
图1 团队研发的数字电源SoC控制芯片
2. 微弱环境能量采集自供电芯片与系统
随着物联网（IoT）和移动互联网的迅速普及和发展，超低功耗的智能无线传感节点数量急剧增加、其布设环境更加复杂，传感器的供电问题已经成为制约其普及应用的瓶颈问题。采集自然环境中的微弱环境能量并将其高效地转换为电能，可为无线传感节点提供长期稳定的供电电源，具有自供电、免维护、低成本、小巧轻便、易安装的特点。我们团队主要面向宇航和空间探测等应用场景，研究机械能和太阳能的高效能量采集-电源管理技术，研制成功多款能量采集管理芯片（见图2）。
图2 团队研发的能量采集管理芯片
3. 空间探测专用芯片与系统
我们团队长期致力于空间探测专用芯片与系统的研发，包括抗辐照模拟前端读出芯片（图3）、宇宙射线μ子探测芯片（图4）、抗辐照ADC芯片（图5）和抗辐照LDO芯片（图6）等，重点研究微弱信号的低噪声高精度读出技术和芯片的抗辐照加固技术。

4. 神经网络硬件加速芯片与微系统
随着人工智能技术的快速发展，硬件加速芯片与微系统在语言与图像信号处理、雷达信号实时处理等领域发挥着非常重要的作用，尤其在计算资源受限的嵌入式终端设备中更加重要。我们团队目前致力于神经网路的硬件加速算法（基于FPGA）、加速芯片和微系统的研究。研究成果包括：基于FPGA的时空稀疏LSTM语音识别加速器、基于FPGA的YOLO实时目标检测网络加速器等。
5. 平板显示驱动控制芯片
我们团队分别于2006年和2009年，在国内率先研制成功具有完全自主知识产权的彩屏手机和高清液晶电视用TFT-LCD驱动控制系列芯片（图7），并实现了产业化，为我国平板显示驱动芯片产业发展做出了突出贡献。相关研究成果获得中央电视台《新闻联播》节目的报道，并获得陕西省科学技术奖一、二等奖各1项以及陕西省专利奖1项。
