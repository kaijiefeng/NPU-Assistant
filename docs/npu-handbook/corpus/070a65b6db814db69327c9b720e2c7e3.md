# 校园卡挂失、补办与充值
西北工业大学校园卡挂失、补办与充值
一、挂失
校园卡意外丢失后，可从“西北工业大学”APP上自行挂失，及时避免财产损失。
二、补办
前往启真楼补办校园卡；启真楼一楼设有学生一站式事务服务大厅，可办理一卡通补办等日常事务。补办需携带本人有效身份证件，补办工本费按学校规定执行（新生攻略中为20元）。
三、充值
通过手机应用市场下载“西北工业大学”APP，登录后点击“充值”即可在线上充值校园卡；也可通过校园卡服务窗口、自助设备办理充值。
来源：西工大电子信息学院《22级新生攻略》；《西北工业大学校园卡管理办法》。
