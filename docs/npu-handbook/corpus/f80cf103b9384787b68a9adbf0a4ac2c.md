# 本科生请假与销假办理
西北工业大学本科生请假与销假办理
一、请假
学生因病或其他原因不能按时参加培养方案规定的教学活动，必须事先办理请假手续。未经请假、请假未获批准或请假逾期者，视情节轻重，分别给予批评教育、取消考试资格或纪律处分。
学生请假应事先向学籍所在学院提交书面申请，并附有关证明。请假在30天以内（含30天）的，由各学院批准，报教务部、党委学生工作部备案；请假时间超过1个月的，应当申请休学。
二、销假
请假结束后，学生应按学院要求按时返校并办理销假；具体销假方式、审批人和材料以学院通知为准。返校后应及时向辅导员报到，确认请假状态已闭环。
依据：《西北工业大学本科生学籍管理办法》（2024年修订）。
