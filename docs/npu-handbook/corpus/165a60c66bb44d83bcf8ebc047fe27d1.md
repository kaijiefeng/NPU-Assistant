# 集成电路学院2026级本科新生破冰活动
金秋九月，为帮助2026级本科生新生打破陌生、融入集体，集成电路学院各新生班级于9月下旬至10月上旬陆续开展破冰活动。
脑力全开破隔阂，DL062638班聚力破冰启新程
9月27日晚，DL062638班在学院楼活动室开展破冰活动。“你是谁”、看图猜成语等游戏轮番进行，同学们在欢笑互动中迅速熟络，班集体初显温度。

团结协作拼游戏，DL062639班携手破冰共成长
10月8日，DL062639班在学院111会议室开展破冰活动。在学生会张科想、石少星学长协助下，同学们通过“五句描述一假”自我介绍推理、词语竞猜等环节展开互动，班委分组带队、全员参与，现场气氛热烈，班级凝聚力显著提升。

专业知识拓视野，DL062640班破冰凝志启新航
10月11日，DL062640班开展破冰活动。团队游戏与自我介绍让同学们放下拘谨、彼此熟悉；受邀学长结合自身经历，分享课程学习、科研竞赛与班级生活经验，并介绍专业方向，帮助大家初步建立专业认知与学习目标。

趣味活动聚人心，DL062641班融心聚力开新章
10月10日，DL062641班在玻璃房开展破冰活动。logo竞猜、你画我猜、听歌识曲等趣味环节轮番上演，同学们踊跃互动，在轻松融洽的氛围中拉近距离、凝聚班心。

本次活动搭建起新生沟通相知的桥梁，为班级建设打下坚实基础。2026级本科新生将传承“公诚勇毅”校训，怀揣芯片报国理想，在求学路上同心相伴、笃学精进，以青春之力勇担时代使命，书写属于“芯”青年的奋斗篇章。
