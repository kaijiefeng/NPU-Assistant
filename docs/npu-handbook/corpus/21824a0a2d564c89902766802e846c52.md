# 计算机学院鸿蒙产教融合交流会
2025年10月19日至20日，西北工业大学计算学院联合华为公司在长安校区和友谊校区成功举办了2025“鸿蒙产教融合交流会”及2025中小学“人工智能+教育解决方案”交流会。两场活动由陕西省计算机教育学会主办，西北工业大学计算机学院与华为终端公司共同承办。会议汇聚了来自全省高校与中小学的主管教学领导、骨干教师及教育信息化专家，共同探讨产教融合、人工智能赋能教育的新模式。
深化产教融合，共建鸿蒙生态育人新格局
10月19日，2025“鸿蒙产教融合交流会”在西北工业大学长安校区教学西楼A100举行。本次会议聚焦鸿蒙电脑与教育场景的深度融合，围绕“自主操作系统创新”“产教融合示范应用”“鸿蒙生态人才培养”等主题展开深入研讨。
陕西省计算机教育学会理事长耿国华、西北工业大学教务部副部长张学良、计算机学院及华为终端相关负责人分别致辞。嘉宾们对鸿蒙生态在高等教育领域的推广表示高度肯定，并强调了高校在推动国产操作系统应用、培养自主可控信息技术人才方面的重要责任。
在专题报告环节，华为专家详细介绍了HarmonyOS 5鸿蒙电脑的核心特性、全场景互联体验及教育适配方案。西北工业大学计算机学院展示了在建设“鸿蒙实验室”、推动鸿蒙课程教学改革方面的探索实践。与会专家还就“教育场景下的鸿蒙电脑需求与课程生态构建”“高校鸿蒙生态人才培养模式”“联合实训基地建设”展开了交流讨论。
会议期间，代表们参观了计算机学院与华为共建的全国首个鸿蒙电脑教学实验室，对设备体验区进行了现场互动与交流，进一步加深了对鸿蒙生态在教育领域应用潜力的理解。
赋能基础教育，共筑人工智能教育新生态
10月20日，2025中小学“人工智能+教育解决方案”交流会在西北工业大学友谊校区东会议室举办。活动以“AI赋能教育，创新引领未来”为主题，面向全省中小学教育主管部门、学校管理者及信息技术教师，聚焦人工智能教育的落地实施与生态建设。
陕西省计算机教育学会、西北工业大学计算机学院及华为终端相关负责人在致辞中指出，人工智能教育的推广是教育数字化转型的重要方向，西北工业大学将依托自身在计算机教育与人工智能研究方面的优势，携手华为共同推动“人工智能+教育”的系统落地。会议现场举行了西安（中小学）鸿蒙实训实践基地揭幕仪式，标志着我省中小学鸿蒙教育生态建设迈出实质性步伐。
来自华为的技术专家展示了鸿蒙电脑及操作系统在基础教育中的最新应用场景，并介绍了面向中小学的信息技术与人工智能课程解决方案。基础教育代表西北工业大学附中，西安铁一中学先后分享了人工智能课程建设与学科融合的典型案例，探讨了AI课程教学、评价及创新实践的新路径。
携手创新生态，打造教育数字化典范
西工大计算机学院与华为公司的深度合作，是全国高校中较早系统推进鸿蒙生态产教融合的典范。在此次交流活动中，学院不仅展示了鸿蒙电脑教学实验室的成果与应用场景，更通过技术研讨、案例分享和示范推广，系统呈现了学校在操作系统教学体系建设、人才培养模式创新、产教融合机制完善等方面的前沿实践。自双方共建“鸿蒙产教融合实验室”以来，学院持续在课程教学、科研创新、师资培养、生态应用等领域形成了全链条的协同机制，探索出以“课堂教学—实训平台—科研创新—生态共建”为核心的合作模式，为鸿蒙生态在高等教育落地提供了可复制、可推广的“西工大样本”。
作为陕西省最早引入鸿蒙生态教育体系的高校，西工大主动承担起全省乃至全国高校的示范引领角色。学校积极推动“高校—中小学—企业”协同发展，建设了覆盖高教与基础教育的鸿蒙生态教学体系，为区域教育数字化转型提供了有力支撑，成为陕西省“人工智能+教育”行动计划的关键引领单位。
未来，西工大计算机学院将继续依托自身在人工智能、大模型、嵌入式系统及操作系统方向的科研优势，与华为携手共建更加开放、可持续的教育创新生态，在全国范围内持续发挥鸿蒙产教融合的标杆作用，为建设教育强国和数字中国贡献“西工大力量”。
