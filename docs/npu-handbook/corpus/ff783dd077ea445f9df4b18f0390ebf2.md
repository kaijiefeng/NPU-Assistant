# 毕业生档案、报到证与改派办理
西北工业大学毕业生档案、报到证与改派办理
一、档案
毕业生档案包含学籍卡、成绩单、评语、获奖证明、党团材料等原始材料。毕业未就业学生的档案一般可转至生源地人事部门，或按规定在学校保留两年。
二、报到证
报到证是毕业生就业报到的重要凭证，也是干部身份证明材料之一。报到证有效期一般为两个月；遗失可在规定年限内申请补办，需提供单位证明或个人申请、补办申请表、毕业证和身份证复印件等材料。
三、改派
毕业生毕业后两年内可向学校学生职业发展指导服务中心提出改派申请，超过两年的按其他人员流动手续办理。改派通常需要原单位退函或解约证明、报到证原件、新签约三方协议书原件或单位接收函、改派（补办）报到证申请表等材料。
四、户口与档案转递
改派后凭新报到证和就业通知书（白联）办理户口与档案；档案仍在学校的，将白联交学校档案馆，由档案馆发出档案。
