# 迎新：校园日常攻略（住宿、洗浴、洗衣、自习、网络）
初来乍到，想必各位萌新们都迫不及待地想要了解大学校园生活了吧！那么航小天这就送给大家一份校园日常生活的必读攻略。
一、关于居住
1、宿舍
女生宿舍楼：云天苑A、B座，星天苑A、B座，海天苑1期B座
男生宿舍楼：云天苑C、D、E、F座，星天苑C、D、E、F、G座，海天苑2期A、B、C座
宿舍楼均呈U形，宿舍全部按照单双号分开布局。除星天苑A、B、H之外，其余宿舍楼均为四人间，上床下桌，带有独立阳台，每一层楼均有独立的厕所、浴室。星天苑B座的格局较为特殊，其内部是四室一厅两卫的格局，在一个大的套间内有A、B、C、D四个房间，每个房间住四人，上下铺对面桌，床的尺寸为200*90cm。
宿舍全天不断水不断电不断网，宿舍配备暖气（供暖时段为11月中旬至次年3月中旬）和吊顶电扇（部分宿舍楼），空调需交押金办理（支持微信、支付宝付款）,宿舍钥匙每人一把，报道后在宿管阿姨处领取钥匙。若出门忘带钥匙，可在宿管阿姨处借取钥匙并及时归还。若钥匙不慎丢失，需及时重新配备。
2、洗浴
宿舍楼热水供应时间为19：00-00:30，部分节假日会根据情况调整。洗浴时将校园卡插入浴室的读卡器，然后打开热水开关，就可以开始洗浴了。每次插入一卡通默认扣掉两分钱，插入后无论是否开启花洒都会扣钱。部分宿舍楼改装升级了浴室，需下载“云达人”app激活账户才能使用，具体使用方法在app内有详细说明。相较而言，改装后的浴室开放时间更宽裕，花费更合理，体验更好。
3、洗衣
每栋宿舍楼的一楼都设有一间洗衣房，并且配备多台全自动洗衣机，使用时只需打开支付宝扫描洗衣机上二维码并选择清洗模式即可。航小天提醒您，周末一般是洗衣高峰时段，可以合理安排时间错峰洗衣，避免不必要的时间浪费。
4、自习室
宿舍楼每层都有一间自习室（云天苑的自习室在2楼），如果你还在为教学楼的教室座无虚席而苦恼，或是因为图书馆的距离太遥远而悲伤，这时自习室便体现出它独一无二的价值。无论你是复习考试，还是寻觅安静的地方看书学习，自习室都是一个好去处。
5、校园网
宿舍楼全方位覆盖深澜校园网，但和教学楼以及校园内其他区域不同的是，宿舍网络属于付费网络，无论是wifi还是网线连接电脑，两者同走深澜流量计费（具体价格参考西北工业大学统一支付平台）。航小天建议一个宿舍舍友合资购买每月的“50元不限流量套餐”，以及一个路由器，路由器登录购买该套餐的账号，这样就可以非常合算的上网啦。
6、生活缴费
公寓网费电费均支持线上缴纳，用户可登录手机“西北工业大学”app或电脑“西北工业大学翱翔门户”网页寻找公寓网费电费的缴纳入口。
二、关于餐饮
长安校区餐厅共四个，分为云天苑餐厅、星天苑南餐厅、星天苑北餐厅和海天苑餐厅。
云天苑餐厅分两层。一楼主要经营早餐、主食类、瓦罐汤、冒菜等。二楼设有清真窗口，晚上云餐夜市提供炸串、炒饭、炒面。
星天苑南餐厅分三层。一楼是学府餐厅经营快餐，二楼经营多种早餐和正餐，三楼晚上提供烧烤。
星天苑北餐厅分三层。一楼提供早餐和正餐，二楼设有清真食堂，三楼为各种小餐厅，星天苑北餐三楼开设火锅店和瑞幸咖啡。
海天苑餐厅分三层。一楼为学生餐厅、每一天鲜食店(24小时供座),二楼为自选餐厅(智能化结算)和风味餐厅，三楼为民族餐厅和教工餐厅。一楼、二楼可提供各种早餐，二楼晚上提供烧烤，二楼和三楼均设有自选菜。各位同学可根据自身喜好随心挑选美味的饭菜。
此外，众多教学楼之间也藏匿着一些美食。云天苑宿舍楼下的翱翔小食和水果店，教西D楼下的翱翔连锁便利店，图书馆斜对面的工大文创馆，隐藏在计算机学院楼旁边的蜜雪冰城等，校园内的种种美食正等待同学们去发现。
附一卡通充值方式：下载“西北工业大学”APP，登录后点击“充值”即可线上为自己的校园卡充值。

四、小tips
平时渴了/饿了，不想去餐厅？
在教学楼和公寓楼中有许多自动售货机以及自助咖啡机，渴了饿了就扫码支付，方便快捷。
跳蚤群——出手入手高性价比商品
可以加入西工大的二手货品交易跳蚤群，在群内出手物品或者求购，满足你的各种需求（大家要擦亮眼睛谨慎购买哟），每年的毕业季也会有线下的跳蚤交易市场。
强身健体，自律每一天！
宿舍楼下的健身设施和羽毛球场地，云天苑操场（田径场）、星天苑操场（田径场、羽毛球、网球、排球、足球和篮球）、翱翔体育馆（羽毛球、排球和篮球）、翱翔游泳馆（分为室内和室外）、室内健身房、乒乓球馆等多种运动场地供你选择！
想游玩市区，不知道出行方式？
①坐校车前往市内的友谊校区（位于碑林区），坐校车有线下候车室排队和线上排队两种方式，微信“西工大班车”小程序既可查询校车发车时间又可预约线上排队。
②公交：小东门外有公交站，可乘坐333路和734路。
校园很大，走路很累……
没关系，校园内各处分布着哈喽单车，下载“哈喽单车”app扫码出行，开通月卡优惠更多。
这些就是航小天带给大家的校园日常攻略啦。当然，以上内容仅是略见一斑，校园生活中还有许多未知的有趣事物等待着大家亲自去探索。关注航小天，让你更加了解校园生活。
