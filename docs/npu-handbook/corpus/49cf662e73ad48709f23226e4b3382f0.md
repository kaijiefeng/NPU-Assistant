# 微电子学院与贵州航天测试研究所联合研究实验室
12月13日，微电子学院与贵州航天测试研究所联合共建攻防装备电子元器件联合研究实验室正式签约揭牌。航天测试党委副书记、常务副所长李晓强出席。航天测试科技发展处、科技委办、人力资源处、三室等有关负责同志、微电子学院副院长王少熙、学院办公室主任景省利及相关老师参加本次会议。会议由航天测试科技发展处处长聂祥松主持。
会上，李晓强对微电子学院参会教师表示欢迎，他指出：航天测试将与微电子双方以联合实验室为契机，共同引领科技创新。
李晓强与王少熙共同签订联合研究实验室合作协议并揭牌。
李晓强分别为王少熙、李伟颁发航天测试外聘专家证书。
王少熙分别为李晓强员、孙逊颁发西工大微电子学院校外兼职导师聘任证书。
航天测试与西工大微电子学院将秉持“优势互补、资源共享、共同发展”的原则，聚焦元器件可靠性与保障技术、新型复杂电子元器件检测与分析技术等专业技术方向，成立攻防装备电子元器件联合研究实验室。未来，联合实验室双方将围绕科技创新、人才培养、项目研究、标准制定、设备设施共享等领域开展多维度、深层次、系列化战略合作，共同推动电子元器件可靠性保障等技术的发展。
