# 软件学院华为HarmonyOS菁英班招募宣讲会
5月10日晚上18:00，华为公司HarmonyOS菁英班招募宣讲会在启翔楼401顺利举行。华为公司技术与招聘人员代表龚阿世、王鹏、赵蓉和孙书宸出席，软件学院党委副书记张龙，学生工作助理茹丽媛、孙慧敏参加此次活动。
软件学院党委副书记张龙致辞
首先，张龙对华为菁英班进行简要的介绍，并对同学们积极报名加入华为菁英班给予鼓励。随后负责华为终端调配工作的王鹏对西工大软件学院与华为菁英班的合作表达了肯定，并浅谈华为菁英班能够为同学们带来的收获。接下来，华为技术专家龚阿世为同学们做技术分享，向同学们讲述了华为做鸿蒙系统的初心，并以华为已投入商用的产品所构建出的智慧出行、家居智能化、超级通话终端支撑的社交通讯等多个场景为例展现了鸿蒙系统的跨设备业务无缝连续与流转，真切地让同学们感受到软件定义出新产品形态。而后负责招聘的赵蓉老师为同学们介绍了华为菁英班的运营方案，并展示往届图片、学员感想等让大家更加了解菁英班的氛围。
华为终端BG招聘调配部王鹏介绍华为菁英班
华为终端技术专家龚阿世技术分享
会议最后同学们积极提问，展现出了西工大软件学子的风采，各位老师们也耐心地依次解答了同学们的问题，并祝同学们笔试、面试顺利。
