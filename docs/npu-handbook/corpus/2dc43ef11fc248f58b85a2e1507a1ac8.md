# 集成电路学院2026届研究生优秀毕业生风采录
秦岭巍峨，无言地见证着实验室里不灭的星光；方寸流片，厚重地承载着新时代青年的“中国芯”报国志。2026届集成电路学院（微电子学院）的硕士研究生，将三载炽热青春，悉数熔铸于硅基之上。从EDA工具中的每一次精准推演，到显微镜下纳米级工艺的极限探索；从算法调度的创新突破，到射频器件的跨界攻坚——他们以实干为笔，将科研论文扎扎实实地写在祖国集成电路与微电子产业崛起的大地上。
今天，让我们共同翻开这份属于他们的风采录，走近这群“芯”青年，聆听那硬核青春中绽放的铮铮回响。
孔庆羽
中共党员，师从周世钢教授、陆喜龙副教授，研究方向为射频滤波器设计。作为核心成员参与国家自然科学青年基金项目及军工项目共3项，主持西北工业大学研究生创新基金项目1项并顺利结题。以学生第一作者身份发表SCI一区期刊论文2篇、SCI四区期刊论文1篇、EI会议论文2篇，申请国家发明专利4项（其中授权2项、公开2项）。获评研究生优秀毕业生，获研究生国家奖学金、科研价值奖学金、三星企业专项奖学金、一等学业奖学金、校级“优秀研究生”等荣誉。毕业后，他将入职中科曙光信息产业股份有限公司。
毕业寄语：不必焦虑前路，不必盲从他人。每个人的花期不同，静心沉淀、做好自己，终将如期绽放！
张睿
师从陆喜龙副教授，研究方向为有源相控阵雷达设计与滤波器设计。以学生第一作者身份发表SCI一区论文1篇、国际会议论文2篇，以学生第一发明人身份授权国家发明专利2项、公开发明专利1项。获评研究生优秀毕业生，获研究生国家奖学金、一等学业奖学金、校级“优秀研究生”等荣誉。毕业后，他将选择在本校继续深造，攻读博士学位。
毕业寄语：千淘万漉虽辛苦，吹尽狂沙始到金。
李昊东
中共党员，师从关赫教授、张浩副教授，研究方向为射频前端芯片设计。深度参与国家重点研发计划项目，并赴中电科十三所开展联合攻关。以第一作者身份发表期刊及国际会议论文4篇，以学生第一作者身份授权或公开国家发明专利3项。获评研究生优秀毕业生，获国家级竞赛一等奖3项、省级竞赛特等奖2项等荣誉。毕业后，他将入职西安中兴通讯有限公司。
毕业寄语：在AI时代，技术迭代的速度远超以往，但“公诚勇毅”的校训永不过时。愿你既保持对前沿技术的敏锐嗅觉，又坚守工程师的匠心与家国情怀。AI只是工具，而你才是定义未来的主人！
晁勇
师从黄佛保副教授，研究方向为压电器件。以学生第一作者身份发表SCI一区TOP论文2篇，公开国家发明专利1项。获评研究生优秀毕业生，获研究生国家奖学金、一等学业奖学金、校级“优秀研究生”等荣誉。
毕业寄语：岁月匆匆，惟愿总相逢。感谢西工大三年的悉心培养，一朝毕业，奔赴山海，愿此去前程似锦，不负韶华，不负初心，再相逢时，依旧如故，眉眼如初，情谊不变。
毕安童
中共党员，师从汪钰成副教授，研究方向为高热流密度热源液金散热系统。以学生第一作者身份发表SCI一区论文1篇、中科院二区论文1篇、EI会议论文1篇。获评研究生优秀毕业生，获校级“优秀研究生”、全国大学生集成电路创新创业大赛全国决赛三等奖等荣誉。毕业后，她将入职西安中兴新软件有限责任公司（未来领军人才）。
毕业寄语：愿大家永远带着热爱与勇气，奔赴下一场山海，前路浩荡，未来可期！
夏毅豪
师从陆喜龙副教授，研究方向为微波滤波器。参与国防科工局稳定支持项目等多项重点科研项目和校级创新基金。以第一作者身份发表3篇EI学术论文。获评研究生优秀毕业生，获校级“优秀研究生”、卓越专项就业奖学金等荣誉。毕业后，他将入职中航工业集团空空导弹研究院子公司。
毕业寄语：保持热爱，奔赴山海
张诗妍
师从李伟副教授，研究方向为二维材料与新型存算器件。主持研究生创新基金项目1项。发表SCI期刊论文3篇，并申请国家发明专利1项。获评研究生优秀毕业生，获校级“优秀研究生”、全国大学生集成电路创新创业大赛国家三等奖、校“三航杯”科技发明制作三等奖等荣誉。毕业后，她将入职海光信息技术股份有限公司。
毕业寄语：承蒙母校悉心栽培，感念师长谆谆教诲。值此毕业之际，衷心祝愿母校蒸蒸日上，桃李盈庭，宏图更展，再谱新篇。
赵熠
中共党员，师从刘畅副教授，研究方向为宽带高效率功率放大器。主持西北工业大学硕士研究生实践创新能力培育基金项目1项。以学生第一作者发表SCI一区论文1篇、会议论文1篇，公开国家发明专利4项。获评研究生优秀毕业生，获校级“优秀研究生”、“小米”优秀专项奖学金、一等学业奖学金等荣誉。毕业后，他将入职华为技术有限公司。
毕业寄语：在西工大的求学岁月里，我们学会在探索中求真，在实践中寻找答案。那些点滴的努力与积累，终将汇聚成开拓未来的力量。愿我们怀揣初心、步履坚定，向更高目标稳步前行。
一纸风采录，道不尽三年日夜兼程。他们的故事，远不止于简历上那些顶尖的论文与沉甸甸的荣誉奖项，更在于面对关键领域核心技术挑战时，那一份挺身而出的锐气与担当。属于新一代集成电路与微电子人的长征，此刻真正开始。无论前路是扎根学术、攀登科研高峰，还是奔赴领军企业与国防一线，他们都注定成为支撑未来的坚实脊梁。
愿此行：能如电路布图，精心规划，步步为营，不惧现实“寄生”；亦如芯片抗扰，在风雨中自适应成长，追寻人生“最优解”；更盼突破“摩尔”之限，以“芯”为舟，驶向无限可能的星辰大海。
聚，是一团灼灼之火；散，作满天熠熠之星。带着母校的烙印与期许，去吧，乘风破浪，光芒万丈。前进吧，骄傲的集成电路人！
