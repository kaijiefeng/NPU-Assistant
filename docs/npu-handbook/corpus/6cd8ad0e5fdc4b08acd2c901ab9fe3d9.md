# 央视专题视频聚焦西工大与华为鸿蒙教研实践
近日，央视发布主题视频《一起鸿蒙 绘空天蓝图》，聚焦西北工业大学与华为擎云的创新实践。
作为全国率先开展鸿蒙系统教学并完成与华为擎云产品深度适配的高校，西工大正基于自主根技术，深度重构“教、学、研”核心链条，为国家空天领域建设筑牢安全防线。
筑牢自主创新底座：从办公到工业软件底层深度重构
当前，国内在基础办公、数据库等领域已部分实现了国产化替代。为了补齐操作系统这一关键拼图、打通自主可控生态的闭环，西工大携手华为擎云，将教学与科研的核心扎根于国产底座之上。
自2024年双方合作创建“鸿蒙系统实验局”以来，西工大不仅着手建设了国产根技术适配实验室，更自主研发了一系列教学软件，实现计算机课程在鸿蒙终端设备上稳定运行。
目前，校内多项模型设计工作，已使用国产工业软件开发。这种从操作系统底层向上延伸的替换，不仅保障了教学与尖端科研的连续性，更打破了以往教学核心环节受制于海外技术的被动局面。
深度融入教研：让未来人才在校园驾驭国产根技术
通过与华为擎云的深度适配，基于鸿蒙的软硬件生态正在西工大的各个尖端场景中落地生根。
在人才培养端，“黄玉珊班”、“康继昌”系统拔尖班等班级已率先在校内开展了鸿蒙实训课。通过引入智能基座新课程与鸿蒙适配新教材，计算机教育正加速向服务国家重大战略使命转变。
数据显示，一年来已有超过2000名学生在真实的鸿蒙应用环境中进行学习与实践。
西工大计算机基础教学与实验中心主任姜学锋说，鸿蒙系统带来的最大改变是“安心”——它让师生能够用心学习，让学校能够专心于人才自主培养。
在科研端，搭载鸿蒙系统的华为擎云电脑已进入西工大航空、航海、光电等尖端实验室。
各学院正依托这一全新底座，深度协同：计算机学院与航空学院强强联合，基于鸿蒙系统统筹开展航空软件的研发和应用；光电与智能研究院将鸿蒙分布式理念融入课程体系，推进基于鸿蒙生态的科研底座。
西工大与华为擎云的深度合作，不仅打造了高校筑牢自主教研底座的先锋样板，更构建了教育链、产业链、工业链深度融合的新范式。
自主技术真正服务国家重大科研任务，学子在校园接触最前沿的国产根技术。
未来，随着国产操作系统的普及与软硬件生态的加速繁荣，基于自主根技术的教研体系将孕育更澎湃的创新动能。
华为擎云将持续深耕教育与科研核心场景，携手更多高校与生态伙伴——一起鸿蒙，共建自主创新教育底座，共谱科技自强与人才培育新篇章。
（文字：姜学锋、周果清；审核：尚学群、李春科、付怡）
