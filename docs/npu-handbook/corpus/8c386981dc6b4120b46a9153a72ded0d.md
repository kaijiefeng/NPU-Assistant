# 西北工业大学集成电路学院本科专业概况
一、专业设置
（一）电子信息类（集成电路）：微电子科学与工程
基本介绍：微电子科学与工程为国家级一流本科专业建设点。该专业主要研究半导体器件物理、芯片设计制造等。坚持以微纳电子、集成电路、智能微系统培养为主线，结合学校“三航”特色，培养具有创新能力和国际竞争能力，在微电子科学与工程领域内掌握坚实的理论基础和系统专业知识的人才，满足国家战略及区域经济对微电子人才的需求。本专业属于“电子信息类（集成电路）”，由微电子学院办学，每年普通一批次全国招生。
核心课程：固体物理学、微电子概论、半导体物理、半导体器件基础、模拟集成电路设计、数字集成电路设计、微电子制造工艺、硬件描述语言与FPGA技术、微电子器件封装与测试、光电子技术。
（二）电子信息类（集成电路）：集成电路设计与集成系统
基本介绍：集成电路是现代信息电子产业基石。该学科以物理、数学等为基础，多学科深度交叉融合，兼具深厚理论与鲜明工程特性。经专业学习，学生可胜任集成电路及其应用系统设计、制造、研发、管理等工作，特别是数字、模拟等各类集成电路及微系统设计、验证与测试，具备持续发展和创新能力。本专业属于“电子信息类（集成电路）”，由微电子学院办学，每年普通一批次全国招生。
核心课程：半导体物理、半导体器件基础、模拟集成电路设计、数字集成电路设计、微电子制造工艺概论、硬件描述语言与FPGA技术、集成电路EDA、集成电路芯片测试技术、微系统设计与系统集成。
二、深造与就业
本科毕业生可继续攻读相关学科硕士研究生，本科毕业生深造率保持在71%以上，研究生就业率100%。就业渠道为科研院所、高校、知名微电子与集成电路企业等，如中国航天科技集团公司第九研究院第771、772研究所，中国航空工业第618、631研究所，中国电子科技集团公司第58研究所，海思半导体有限公司，中兴通讯股份有限公司等。就业地点包括京津冀、长三角、珠三角，以及西安、成都等地。学院毕业生就业质量好，平均起薪高，发展空间大。众多优秀校友更是在集成电路、微电子等关键领域成为领军人才，作出卓越贡献。
