# 关于在线办理本科生在读证明的通知
各相关单位、各位同学：
为进一步践行学校服务育人要求，更好地满足两校区本科生在读证明办理需求，使学生不跑路或者少跑路，学校积极优化本科生在读证明的办理流程，提高办事效率。自2024年10月1日起，本科生在读证明全面推行线上办理服务。具体操作流程如下：
一、登录翱翔门户。
二、点击翱翔门户首页“翱翔教务”。
三、进入翱翔教务后，点击左上角“菜单”。
四、选择“学籍管理”菜单栏中的“学籍信息”。
五、进入本人学籍详情页面后，点击右上角“在读证明下载”即可。
