# 学校食堂（餐厅）分布与营业时间
西北工业大学学校食堂（餐厅）分布与营业时间
长安校区餐厅包括：正禾星苑美食一餐厅（星天苑南餐厅二楼）、正禾星苑美食二餐厅（星天苑南餐厅三楼）、学子快餐（星天苑南餐厅二楼）、学府快餐（星天苑南餐厅一楼）、学生二餐厅（星天苑北餐厅一楼）、学生三餐厅（星天苑北餐厅二楼）等。
友谊校区餐厅包括学生一餐厅、学生二餐厅、风味小吃城、民族餐厅、教工餐厅等。
各餐厅供应早餐、午餐、晚餐，部分餐厅有夜市；具体营业时间以餐厅现场公告为准。
来源：西工大微后勤《返校最新生活指南》。
