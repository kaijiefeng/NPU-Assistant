# 学生助学贷款办理（摘要）
西北工业大学学生助学贷款办理（摘要）
一、生源地助学贷款
学生在生源地申请国家开发银行或其他银行助学贷款；到校后将助学贷款回执交至党委学生工作部学生资助服务中心，学校按批次汇总并冲抵学杂费。
二、校园地助学贷款
学生通过中国银行手机银行申请当年国家助学贷款并签订电子合同；学杂费由银行分批次转入学校助学贷款专用账户，生活费发放到学生中国银行卡。
具体申请时间、材料和到账处理以学生资助服务中心、计划财务部最新通知为准。
来源：计划财务部《学生助学贷款办理流程》。
