# 2026级新生班级团队建设活动朋辈志愿者培训会顺利开展
为切实提升2026级新生班级团队建设活动（破冰活动）的实施效果，增强朋辈志愿者的专业带领能力，学生心理健康教育中心于9月10日至11日连续举办了三场专题培训会，吸引来自各学院的49名同学积极参与。
本次培训由心理中心教师郭鹤阳主讲。培训围绕“成为温暖的引导者”这一主题，系统讲解新生班级团队建设活动的意义、流程与带领技巧。郭老师从新生的心理需求出发，指出“联结、信任、期待、归属”是破冰活动的核心目标，强调朋辈志愿者作为同龄人中的支持者在新生适应过程中的重要作用。
在介绍具体活动环节，郭老师带领同学们进行了现场体验，通过亲身参与“善意传递圈”“松鼠搬家”“心有千千结”等活动，使大家在体验中深度体会活动目的，感受破冰活动如何促进互动、拉近距离、增强凝聚力。
此外，培训还特别强调了活动中的伦理原则，包括自愿参与、保密尊重、身心安全等，确保活动在温馨、安全、包容的氛围中进行。
本次培训内容系统全面、注重实效，既有理念引领，又有实操演练，切实提升了志愿者的活动设计与带领能力，更增强了他们作为朋辈支持者的责任感和使命感，为后续新生班级破冰活动的顺利开展打下良好基础，同时也为新生心理适应教育注入朋辈互助的温暖力量。
我校将于9月下旬至10月面向2026级新生班级陆续开展破冰活动，帮助新生在入学初期建立积极的人际联结，增强对班级和学校的归属感，推动我校心理健康教育工作走深走实。
