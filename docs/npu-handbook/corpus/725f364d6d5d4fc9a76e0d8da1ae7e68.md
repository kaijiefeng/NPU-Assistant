# 心理咨询预约方式与来访须知
西北工业大学学生心理健康教育中心：心理咨询预约方式与来访须知
学生心理健康教育中心为西北工业大学全日制本硕博在校学生优先提供心理咨询服务，咨询费用由学校承担。
心理中心实行预约制度，需提前一周预约。预约后，来访者应按时到达；不能如期来访应提前电话说明。如遇特别紧急的情况，请向接待人员说明，及时安排咨询。
心理咨询师会对来访者的心理状态进行评估；评估为需要前往医院进行诊断的来访者，继续咨询时需提供医嘱证明。
来源：学生心理健康教育中心“来访者须知”（https://xl.nwpu.edu.cn/gzdt/rcgz/2.htm）。
