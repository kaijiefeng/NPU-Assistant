# 父母的自我关照——从护航者到守望者”家长心理讲座顺利举行
为进一步深化家校协同育人实效，5月25日晚19:00学生心理健康教育中心面向全体学生家长举办线上专题讲座。讲座以《父母的自我关照——从“护航者”到“守望者”》为主题，邀请上海交通大学心理健康教育与咨询中心主任张洪英副教授担任主讲，我校学生心理健康教育中心主任刘欣主持，吸引众多家长和老师在线参与。
讲座围绕“看见孩子”、“遇见自己”、“自我照料”三方面内容展开。张洪英老师首先结合大学生心理发展规律与脑科学研究，分析了成年早期阶段的核心发展任务，帮助家长理解孩子情绪丰富而理性控制力尚在发展中的特点，指出人际关系、家庭关系与学业压力是学生心理困扰的主要诱因，呼吁家长以理解代替焦虑，以信任取代管控。针对孩子离家后家庭进入空巢期的现实，张洪英老师引导家长正视自身失落与自由并存的复杂心态，倡导从“良师陪练”向“益友顾问”转型，并提出“少指导、多鼓励、常信任、托住底”的沟通原则，鼓励家长通过正念冥想、规律运动、拓展社交等方式实现自我关照。在家校协同方面，她强调家长是孩子的第一监护人，必须坚持生命至上原则，发现异常应及时与学校联动，双方共同筑牢安全屏障。
整场讲座内容丰富、案例生动，既有科学的理论依据，又有切实可行的行动建议。主持人刘欣老师总结表示，父母先学会自我关照，孩子才会真正学会爱护自己。会后家长反响热烈，纷纷表示深受启发。
本次讲座是我校“阳光护航”心理育人宣传教育系列实践活动之一，也是学校推进家校协同育人的重要举措。未来，学校将持续搭建家校沟通平台，助力家长与孩子共同成长，为大学生心理健康保驾护航。
