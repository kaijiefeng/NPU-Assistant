# 集成电路学院铸剑8班第二期招生通知
为深入贯彻落实习近平总书记关于教育的重要论述，统筹推进教育科技人才体制机制一体改革，同时坚持以“总师育人文化”引领培养“低调务实、兼收并蓄，厚积薄发、为国铸剑”的“总师型”人才，根据学校“铸剑班”相关要求，结合集成电路学院（微电子学院）实际情况，现招收西北工业大学"集成电路学院铸剑班"（铸剑8班）第二期学员，具体事项通知如下：
一、班级介绍
西北工业大学“集成电路学院铸剑班”是集成电路学院（微电子学院）“总师型”人才培养的特色项目，旨在选拔并培养具有深厚专业基础、卓越领导力和创新精神的优秀学生。该班级在党委学生工作部的指导下，由集成电路学院（微电子学院）牵头组建并实施。通过汇聚优质教育资源，结合集成电路领域前沿技术和产业发展趋势，为学生搭建一个集理论学习、实践创新、国际交流为一体的综合性成长平台，奠定其未来成为集成电路领域“总师型”人才的能力基础。
二、招生对象
集成电路学院（微电子学院）2024级、2025级本科生，学制为一年。
三、培养内容
1. 芯魂筑基，思政铸魂
坚持以思想政治教育引领人才培养，将理想信念教育、家国情怀培育和专业使命教育有机融入班级建设全过程。依托校内外红色文化资源和学科专业特色，适时开展主题教育、实践研学、专题交流等活动，引导学生在理论学习、历史感悟和专业认知中坚定科技报国志向，增强服务国家战略需求的责任感和使命感。
2. 智启芯程，导师引航
围绕集成电路学科发展和学生成长需求，探索建立多元化导师支持机制。通过邀请校内外专家学者、行业导师和优秀校友等开展学术交流、成长指导和职业分享，帮助学生拓宽专业视野、了解行业趋势、明晰发展方向。
3. 实践磨砺，创新赋能
坚持以实践育人推动学生能力提升，鼓励学生结合专业学习参与科研训练、学科竞赛、创新创业等实践活动。在团队协作和项目训练中提升专业能力、创新能力和解决复杂问题的能力，逐步形成勤学善思、敢于探索、勇于实践的成长氛围。
四、选拔方式
材料提交：请于5月31日18:00前，将"附件：西北工业大学集成电路学院（微电子学院）铸剑班报名表.docx"（电子版）备注"铸剑班第二期+学号+姓名"，发送至邮箱liuhaomin@mail.nwpu.edu.cn。
后续流程：学院将组织资格审查、简历筛选、实地面试，综合评估确定最终录取学员。
西北工业大学集成电路学院（微电子学院）"铸剑8班"期待怀揣"为国造芯"梦想、勇于挑战自我的你加入！
