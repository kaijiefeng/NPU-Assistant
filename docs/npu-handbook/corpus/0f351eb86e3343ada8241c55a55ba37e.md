# 西北工业大学校历、校车时刻表-迎新网
西北工业大学校历2025-2026
关于2025年暑假校车运行安排的通知
各单位、全校师生
按照学校2025年暑假相关安排，现将校车运行安排如下：
一、暑假(7月14日—8月27日)时刻表：
1.友谊校区-长安校区：
七号学生公寓西侧发车，班次 8:00（西苑、高新、紫薇设乘车点）、11:00 、15:00。
2.长安校区-友谊校区：
校车候车厅发车，班次 9:30 、12:30 、17：00。
二、暑假学生返校安排：
（一）友谊校区至长安校区转运校车
1.时间安排：2025年8月24日、30日、31日，8:00—19:00。
2.乘车地点：友谊校区校车乘车点（东门里“七号学生公寓西侧”）。
3.乘车方式：有序排队刷卡乘车，坐满发车。
（二）学生返校专线“一站一场”直通车
1.时间安排：2025年8月23日—24日。
2.西安北站-长安校区：西安北站南广场大巴停车场发车，班次14:00、18:00。
3.咸阳机场—长安校区：咸阳机场T2/T3大巴专用停车场发车（T5航站楼到达学生可通过彩虹摆渡车、地铁14号线或公共交通前往），班次12:00、16:00。
三、注意事项：
请乘坐校车的师生，持本人“一卡通”有序刷卡乘车。2025年7月12日—8月31日暂停通勤校车预约，有乘车需求的同学请线下排队乘车。2025年9月1日恢复校车预约。
