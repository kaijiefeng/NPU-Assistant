# 公开文档分类法（采集与标注口径）

> 适用：`docs/npu-handbook/collect/` 下由 `scripts/handbook_collect.py` 与采集子智能体抓取的公开文档。
> 目的：在「文档数量」之外保证**覆盖广度**——主题、文档类型、受众、发布单位、时效五个维度都可统计、可核对。

## 1. 参考了哪些相似项目的分类法

| 来源 | 分类思路 | 本项目如何借鉴 |
|---|---|---|
| 教育部《普通高等学校学生管理规定》 | 按「学籍 → 教学 → 奖励处分 → 校园秩序 → 课外活动」的制度章节组织 | 作为主题类目主干（学籍与注册、考试与成绩、学位与毕业、纪律与申诉、奖助与资助） |
| 高校学生手册目录（各校公开版） | 「入学与注册 / 学籍管理 / 课程与考试 / 奖助贷 / 公寓与生活 / 就业 / 纪律」 | 补齐校园生活、医疗医保、就业档案、心理健康等学生高频主题 |
| 《瓜兵速成指南》（NWPU 学生自编新生指南，见 `../OPEN-SOURCE-SOURCES.md`） | 六部分：录取入学、学习生活、学生社团、日常生活、学科竞赛、日常出行 | 提供「学生旅程」视角： pilgrimage 从入学到毕业，补上军训、校历出行、社团文体 |
| USC Wiki（南华大学学生校园知识库，<https://uscwiki.com/>） | 五章：初来乍到（新生入门）、认真学习（学习指南）、好好生活（校园生活）、办好事情（事务办理）、走得更远（竞赛与资源） | 用于校验主题类目能否映射成面向学生的「章节」，并发现「事务办理」「竞赛资源」等易漏主题 |
| 校园文档 RAG 项目（如 <https://github.com/rnng1710/spring-ai-rag-knowledgebase>） | 把校园文档按「教务 / 学工 / 后勤 / 信息服务」等来源部门分类，并区分制度与通知 | 引入「发布单位（站点）」与「文档类型」两个正交维度，避免只按主题切分导致通知类文档淹没制度类文档 |

> 只借鉴分类法与字段设计，不导入外部学校的内容；正文全部来自西北工业大学官方公开页面。

## 2. 五维分类模型

### 2.1 主题（L1，单选题，24 + 其他）

| 主题 | 典型内容 | 对应学生旅程章节 |

| 心理健康 | 心理咨询、危机干预、朋辈活动 | 好好生活 |

| 其他 | 无法归入以上主题 | — |

### 2.2 文档类型（单选题）

| 类型 | 判定 | 对问答的价值 |
|---|---|---|
| 制度规章 | 办法、规定、细则、条例、章程、规范、标准、实施方案 | 高：可直接作为权威依据 |
| 办事指南 | 指南、流程、办理、须知、操作说明、FAQ、常见问题 | 高：步骤/材料类问答的主体 |
| 通知公告 | 通知、公告、公示、通报、报名安排 | 中：时效性强，需带发布日期 |
| 数据名录 | 名单、目录、汇总、统计、一览表 | 中：名单/目录类问答 |
| 新闻动态 | 新闻、活动、会议、获奖报道 | 低：主要用于覆盖广度与背景 |
| 其他 | 无法判定 | — |

### 2.3 受众（单选题）

本科新生、本科生、研究生、毕业生、国际学生、教职工、全体。

### 2.4 发布单位（站点）

取详情页域名的二级域（如 `gs.nwpu.edu.cn` → 研究生院；`xgb.nwpu.edu.cn` → 学生工作部）。用于统计「机关部处 / 学院 / 科研与支撑机构」的覆盖比例。

### 2.5 时效

`publish_date`（能解析则填 `YYYY-MM-DD`）+ 采集时间 `collected_at`。统计时按年份分布，避免采集结果全是陈年通知或全是近期新闻。

## 3. 覆盖性验收标准（v2026-11-12 实测）

多轮补采（1921 篇，含 xxgk 信息公开网整站 195 篇）对照验收项：

| 验收项 | 标准 | 实测 | 结论 |
|---|---|---:|---|
| 总量 | ≥1000 篇 | **1921** | ✅ |
| 站点广度 | ≥35 个二级站点，机关/学院/支撑机构都有 | **66 个** | ✅ |
| 主题广度 | ≥18 个类目有文档 | **24 个** | ✅ |
| 高频主题深度 | 学籍/教学/奖助/就业/医疗/公寓/图书馆 各 ≥10 篇 | 均 ≥10 篇（明细见 COMPLETENESS-AUDIT.md） | ✅ |
| 类型广度 | ≥4 种类型，制度规章 + 办事指南 ≥10% | 6 种；218+101=319（16.6%） | ✅ |
| 受众广度 | 至少 4 类被标注 | 7 类全覆盖 | ✅ |
| 时效 | 跨 ≥3 个年份 | 2013–2026（跨 13 年） | ✅ |
| 分类确定性 | 「其他」主题占比 ≤35% | 600/1921 ≈ 31.2% | ✅ |

未达标/偏薄的类目与原因见 [README · 已知缺口](README.md#已知缺口下一轮优先补)：
`纪律与申诉`(1)、`军训与国防`(3)、`生活服务`(4)、`校历与出行`(7)、`校园概况与机构`(7) 内容多集中在 PDF 附件、
微信公众号或被 WAF 拦截的站点（`job`/`zsb`/`tushuguan`），下一轮应走 OCR 或浏览器抓取补齐。

验收指标由 `scripts/handbook_collect.py --report` 自动生成到 `COLLECTION-REPORT.md` / `coverage.csv`。
