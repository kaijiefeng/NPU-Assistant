# 南京理工大学来校调研交流

5月13日上午，南京理工大学财务处副处长梁爽等一行9人来校调研财务管理工作。计划财务部相关人员参加了调研座谈会，会议由李春林部长主持。
座谈会伊始，李春林对南京理工大学一行的到来表示热烈欢迎。梁爽表示，本次调研旨在学习借鉴我校在预算管理、财会监督、信息化建设等方面的先进经验，推动双方财务管理工作提质增效，共同探索新时代高校财务高质量发展的新路径。
随后，双方共同观看了西北工业大学宣传片。综合科科长郭敏雯从基本情况、预算管理、信息化建设等五个方面，介绍了我校开展的相关工作及取得的成效。双方围绕预算绩效管理、财会监督机制、财务信息化建设等议题展开深入交流。双方一致认为，本次交流搭建了两校财务部门沟通互鉴的平台，既拓宽了工作视野、启发了管理思路，也为后续两校在财务数字化转型、预算绩效管理等领域开展深度协作奠定了坚实基础。双方将以本次交流为契机，建立常态化交流机制，共享改革经验，共解管理难题，协同提升财务治理能力与服务保障水平。
计划财务部将认真吸收借鉴兄弟院校先进管理经验，持续完善财务管理机制，依托数智化重构管理流程，凭借专业化赋能战略决策，构建“战略财务、价值财务、智慧财务”三维体系，以高质量财务工作支撑学校各项事业实现高质量发展。
