# 传承师道 尊师重教——公共政策与管理学院召开教师节座谈会暨荣休仪式

感念师恩，岁岁如期。为落实第42个教师节“大力弘扬教育家精神，共筑尊师重教风尚”主题要求，深入学习贯彻习近平总书记关于大力弘扬教育家精神的重要指示。9月10日下午，公共政策与管理学院组织召开教师节座谈会暨荣休仪式。学院领导班子、教师代表及本年度退休教师参会，活动由学院党委书记管兴华主持。
桃李满天下，何用更种花。34载岁月虽使青丝染霜，四季耕耘却让满庭芬芳。在热烈掌声中，管兴华代表学院向赵明华老师颁发荣誉证书及纪念奖杯。青年教师代表向赵老师献花，在赵老师的叮嘱中完成了师道精神的接力。
一语启蔽塞，胜却十年苦。为进一步发挥榜样“传帮带”作用，在座谈会环节，学院“立德树人”奖获得者周炯、新晋长聘副教授杨卓尔及教育部科学研究优秀成果奖获得者郑烨分别围绕学生培养、自身成长及成果产出等方面进行了经验分享。
在自由交流环节，与会教师围绕学院学科建设、人才培养、科学研究、教育教学等方面畅谈思考与建议。学院分管领导就教师提出的意见与建议进行现场回应与沟通。
管兴华做总结发言。他指出，学院处于实现高质量发展的关键阶段，要以师资队伍建设和博士点建设为突破点，克服学院发展的瓶颈问题。要以精品课程建设为抓手，强化育人文科作用发挥。他强调，学院上下要筑牢思想根基，自觉加强党的创新理论武装。要涵养师德风范，坚持严谨治学、严谨管理。要坚持同心同向，增强团结协作自觉，形成奋进实干生态。他要求，学院每一位教职工都要将“精益求精，追求卓越，甘于奉献”刻在心中、融于日常，凝心聚力推动学院事业高质量发展，奋力跑出“十五五”开局加速度。
