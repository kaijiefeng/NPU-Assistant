# 学校召开2026年职称申报工作启动会暨政策宣讲会-人力资源部

9月7日，学校在友谊校区研究生东馆C205报告厅召开2026年职称申报工作启动会暨政策宣讲会。人力资源部主要负责人、相关工作负责人，各学院、研究院及相关职能部门人事秘书、教职工代表共150余人参会。
会上，人力资源部部长唐玉生回顾了学校职称评审办法迭代完善情况，结合国家人才评价改革要求与学校高质量发展需求，解读了2026版职称评审办法修订的政策导向与总体考量。本次修订坚持以创新能力、质量、实效、贡献为评价导向，持续深化分类评价改革，更加突出“干什么评什么”。他要求各单位要压实工作责任，精准解读政策，耐心答疑解惑，严格规范审核，保障本年度职称评审工作平稳有序推进。
会议就2026版职称评审办法核心变化、重点修订条款及申报工作规范要求进行了宣讲，明确了本年度职称评审工作安排部署，同时就申报条件、成果认定、审核流程以及职称申报系统填报操作进行了说明解释，为参会人员提供指导。
