# 【声像档案】归档范围及要求

一、声像档案归档范围
1．党政活动类
党政工作各类会议，社会知名人士来校视察、访问等重要活动。
2．教学类
开学和毕业典礼，毕业生合影，知名教授，学生军训、实习等各类教学活动。
3．科研学术活动类
科研课题评审、鉴定会场面、学术活动开幕式、闭幕式、报告会，科研成果展览等各类科研活动。
4．外事活动类
外宾来校访问，国际合作，外籍学生、教师在校活动，国际学术会议等各类外事活动。
5．产品、仪器设备类
产品定型，批量生产，精、贵、稀设备仪器样照，安装调试运行场面，重点试验室评估等活动。
6．体育类
运动会开幕式、闭幕式、领导讲话等场面，学生课余活动、比赛等。
7．艺术类
艺术创作，演出剧照，艺术交流等活动。
8．校园建设类
校园建筑物，基建工程开工、奠基、落成纪念，学校建设规划模型等。
9．获奖类
党政管理、教学、科研、基建、产品等各项活动获得的奖状及奖品的照片（如被评为省市级以上先进集体、文明单位奖状、劳动模范奖章、先进个人证书等）；在校学生参加各种比赛、竞赛的获奖证书、奖品及获奖者的照片； 毕业生反馈信息中毕业生在工作岗位上取得突出成绩的学生照片、获奖证书和成果照片。
10．人物类
学校历任党委书记、校长、院士、学部委员、长江学者、博士生导师等专家、学者、全国劳模、校内名人，国内外知名校友返校活动、捐赠仪式等。
二、声像档案归档要求
1．声像档案整理前应对归档的声像材料进行筛选和鉴别，对反映同一内容的若干数码照片，应选择其中具有代表性和典型性的，能体现主题内容、主要人物、场景特色等主要因素的声像材料归档。反映同一场景的照片一般只收集一张；
2.毕业生合影照片，电子和纸质版各归一份，原件附带班级姓名、排座说明。
（1）纸质照片：不封塑，照片正上方照片说明应该有西北工业大学、届、学院、专业、班级、摄制时间等字样。
（2）电子版照片：电子版照片为jpg或TIFF格式；原文件不得进行任何修改，文件名以“西北工业大学XX学院XX(届)XX专业XX班毕业合影”方式命名；电子版照片以光盘或发送邮件的形式移交档案馆。
3．数码照片的说明要充分体现时间、地点、人物、事由、背景、摄影者等六要素，准确地反映照片的内容。
4．归档的声像档案材料应在相应设备上演示或检测，做到画面完整、端正，图像清晰、声音清楚，载体材料不磨损、划伤，内容完整准确，载体质量优良；
5．归档的声像档案材料应是直接拍摄形成的原始图像文件，不能进行技术修改和处理。归档保存选用只读光盘作为载体；
6．归档的数码照片格式应为TIFF、JPEG格式。对于采用非通用文件格式的数码照片，收集时应将其在分辨率不变的前提下，转换成TIFF、JPEG格式，并在备注栏中记载。
7．归档的录音、录像应转换成统一的格式刻录在一张或几张光盘上。音频文件一般采用MP3或WAV格式，视频文件采用AVI、MP4格式，数据量大时应采用DVD光盘。
8.声像材料在完成制作后，由各部门兼职档案员采用集中归档和实时归档相结合的方式进行归档。重大活动或重大事件形成的声像档案，一般是在次年6月底前，集中归档。本、硕、博毕业合影留念在工作结束后一个月内收集归档。
9.移交清单一式两份，须同时提交电子版和纸质版。
