# 陕西西工大科技园有限公司-西北工业大学资产经营管理有限公司

陕西西工大科技园有限公司成立于2011年10月，是西北工业大学资产经营管理有限公司的独资企业，注册资本2000万元人民币。
公司经营范围:科技园的开发和管理;科技园区内基地建设和高新技术项目投资(投资限以公司自有资金)与管理;高新技术项目开发、转让、推广、应用、咨询服务及相关产品的销售;公司内部职工培训;试验与办公场地房屋租赁;实验仪器与设备租赁;物业管理。
西北工业大学国家大学科技园(以下简称“西工大科技园”)，始建于1999年，是西北工业大学为响应国家“科教兴国”战略，促进西工大科研成果转化而建立的中国最早的大学科技园之一。是西北工业大学建设“国际知名、国内一流的高水平研究型大学”的高等教育体系的有机外延，2001年5月被教育部、科技部正式批准认定为首批国家大学科技园。西工大科技园依托西工大航空、航天、航海工程教育等优势学科和雄厚的产业基础，致力发展原创科技、推动科技成果转化，促进中小科技企业孵化，提供一流的创业、创新、技术转移、人才培训服务，是西工大对外进行科技、文化、教育、培训以及开展国际、国内交流合作的重要平台。
西工大科技园由陕西西工大科技园有限公司负责运营与管理，以其服务大学、服务社会的理念和追求，已建成“四园三基地”的辐射型科技企业孵化平台。形成围绕高端装备制造、新兴信息产业、新材料、新能源等四大战略性新兴产业发展为重点的军民结合产业聚集区(集群)，成为“特色鲜明、专业突出、管理规范、形象优良”的一流国家大学科技园。目前已有入孵企业50余家，一批业界瞩目的高科技企业和创新创业精英在园区迅速成长。
