# 后勤办公室党支部组织党员理论学习会议

根据学校机关党委5月党支部理论学习指导意见，5月27日下午，后勤办公室党支部在会议室召开了全体党员理论学习会，会议由党支部副书记韩争胜同志主持。
会上，集中学习了《中共西北工业大学委员会贯彻落实中国共产党重大事项请示报告条例措施》、《西北工业大学突发公共卫生事件总体应急预案》、《西北工业大学2020年精神文明建设工作要点》和学校《关于开展保密宣传月活动的通知》等文件主要内容。党员们结合本职工作实际，开展了专题讨论。
党支部书记张文刚同志结合理论学习，安排了后勤办公室近期重点工作。一是贯彻落实学校规章制度规范化建设工作方案精神，在制度建设上，要进一步梳理内部管理制度，查漏补缺，修订完善，规范业务管理工作流程。二是将制度建设覆盖到业务职责范围的每个环节，用制度规范业务管理行为，形成用制度管人、管事的工作局面，为后勤管理提供制度保障。
