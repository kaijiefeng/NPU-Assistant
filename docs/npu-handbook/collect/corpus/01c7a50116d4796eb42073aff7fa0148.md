# 教育实验学院/未来技术学院/学科交叉中心关于开展荣誉导师双选确认工作的通知

为落实立德树人根本任务，强化人才培养核心地位，汇聚校内优质教育教学资源，发挥本科生荣誉导师科研育人作用，提高拔尖创新人才培养质量，根据《教育实验学院/未来技术学院/学科交叉中心荣誉导师管理办法》（教实字〔2025〕8号），现开展教育实验学院/未来技术学院/学科交叉中心2026级全体在籍在校本科生荣誉导师双选确认工作。
一、工作流程
（一）学生意向征集。学生根据荣誉导师最新课题信息，结合学校教师主页（网址：https://teacher.nwpu.edu.cn/）荣誉导师详细信息查询，综合考虑自身专业兴趣和学术发展规划，于10月15日前完成意向荣誉导师登记。
（二）师生双选确认。荣誉导师根据学生申报意愿、学业规划、综合评价等情况，确定指导学生，于10月25日前完成《教育实验学院/未来技术学院/学科交叉中心荣誉导师确认志愿申请表》签字确认工作。
（三）学院审核公示。学院对师生双向选择结果进行审核确认，并公示荣誉导师及其指导学生名单。
二、注意事项
1.每位荣誉导师指导同年级的学生原则上不超过2人，团队（包括国家级、省部级科技创新团队，以及学校翱翔创新团队）协同指导同年级的学生原则上不超过4人。
2.学生应积极参与荣誉导师指定、建议的各类学习与实践活动，及时完成《荣誉导师指导记录手册》填写。
