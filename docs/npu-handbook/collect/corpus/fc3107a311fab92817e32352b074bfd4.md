# 北京研究院党支部召开2024年度组织生活会-西北工业大学

按照资产公司党委关于2024年度党支部组织生活会和开展民主评议党员工作安排，2月24日下午，北京研究院党支部召开2024年度组织生活会。资产公司党委副书记、国家大学科技园副主任田建昌同志到会指导工作。北研院全体党员参会，会议由党支部书记方文杰主持。
会上，方文杰代表党支部委员会向党员大会进行了述职，支部党员结合此次组织生活会主题和查摆突出问题的4个方面，通过自评、互评的方式开展批评与自我批评并开展民主评议党员。
方文杰在总结时指出，2024年学校隆重召开了第十四次党代会，确立了“天下工大、世界三航”远景目标，明确新了“三步走”战略构想。要实现这一宏伟蓝图，需要我们每一名党员同志将党的纪律建设放在首位，以严格的党性修养推动全面从严治党向纵深发展，不断增强党的创造力凝聚力战斗力，确保党的路线方针政策在基层落地生根。她要求全体党员以此次组织生活会为起点，持续深化学习、思考与实践的结合，确保知识、信念与行动的一致性，将学校第十四次党代会精神落到实处，以党的建设新的伟大工程引领教育事业发展，为学校建设成为中国特色世界一流大学的宏伟目标贡献力量。
