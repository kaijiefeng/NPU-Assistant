# 【科研项目档案】归档范围及要求

科研档案归档是指在项目结题或通过验收后，由项目组将项目立项论证、研究实施及过程管理、结题验收及绩效评价、成果管理等过程中形成的具有保存价值的文件材料移交给档案馆。科研项目按照经费来源分为纵向科研项目（含外协）和横向科研项目。

二、归档要求
（一）总体要求
1.实行由项目负责人主持立卷归档的责任制，项目负责人对归档科研文件材料的完整性、准确性、系统性负责。
2.项目组应当明确专人负责科研文件材料的收集、整理、审核，结题验收后按照要求及时归档。
3.项目组根据科研项目的性质、规模、创新性等确定保管期限，保管期限分为永久和定期，定期一般分为30年、10年。
4.科研项目完成或中止后，项目组根据科研内容和科研管理程序，结合科研项目特点将所形成的科研文件材料加以系统整理，履行审查手续后及时归档。研究周期长的项目,可分阶段归档。
5.分工完成的科研项目，应当以任务书、合同或协议等书面形式明确科研档案的归属，由牵头承担单位保存一套完整档案。参加单位保存本单位承担任务所形成的档案。
6.外协科研项目若无合同、定密审批表、保密协议等材料原件，请到科学技术研究院合同办领取。
7.归档材料应为原件，内容必须真实、准确、与实际相符，
若无法提供原件，需填写归档材料未提交原件的情况说明（点击下载），由项目负责人签字。
（二）整理要求
1.归档材料应字迹清楚，图表整洁，签字盖章齐全，书写使用黑色碳素笔。
2.材料规格应为A4纸(小于A4纸的材料，均要粘贴于A4纸上)。
3.归档材料依照“归档范围”顺序依次排列。
4.材料需按“件”编写页码。
5.装订前需去除材料中的塑料制品，右下角对齐左侧双针装订。
6.日期填写格式为8位阿拉伯数字（例20220227）。
三、归档流程及表格
（一）非密科研项目
1.按照归档范围准备材料，并按顺序装订、整理。
2.填写电子表格科研档案案卷目录、科研档案卷内目录，[已脱敏:邮箱] 。
3.填写、打印科研项目文件材料归档审查表、科研档案移交目录、卷内备考表。
4.携带归档范围要求材料到档案馆238室办理移交手续。
（二）涉密科研项目
1.按照归档范围准备材料，并按顺序装订、整理。
2.填写科研项目文件材料归档审查表、卷内目录（科研档案移交目录）、卷内备考表。
3.携带归档范围要求材料到档案馆238办理移交手续。
