# 关于第七届西北工业大学大学生数学竞赛获奖结果的公示

各学院：
第七届西北工业大学大学生数学竞赛已圆满结束。本次竞赛共有2372名学生报名参赛。经评审，最终遴选结果如下：
数学专业类：特等奖10人，一等奖44人，二等奖43人，三等奖57人，共计154人；
非数学专业类：特等奖70人，一等奖436人，二等奖513人，三等奖394人，共计1413人。
现将获奖名单予以公示（见附件）。如有异议，请于公示发布之日起5日内以书面形式反映至联系邮箱。
