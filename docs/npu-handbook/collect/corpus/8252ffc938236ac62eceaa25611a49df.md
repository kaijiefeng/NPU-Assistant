# 关于西北工业大学2026年强基计划校测安排的通知-

特殊类型招生
首页-特殊类型招生>强基计划>
关于西北工业大学2026年强基计划校测安排的通知
发布日期：2026-06-25
点击数：25564
为做好学校2026年强基计划考核工作，根据教育部、工业和信息化部相关文件精神和《西北工业大学2026年强基计划招生简章》，现将校测具体安排通知如下：
一、入围成绩公布
我校将根据各省高考分数公布时间，在西北工业大学本科招生信息网（http://zsb.nwpu.edu.cn/）和强基计划报名平台公布我校强基计划各省入围校测分数线。凡签署校测承诺书并入围校测的考生须按照要求来校进行测试。
二、现场确认及体质测试
现场确认及体测时间:2026年6月30日9:30-16:00
现场确认及体测地点:西北工业大学友谊校区翱翔训练馆
现场确认程序：考生在规定时间内到达翱翔训练馆进行现场确认，核验材料无误后发放体质测试成绩单，即刻进行体质测试，建议考生穿着合适的运动服和运动鞋。体质测试成绩合格考生须在现场确认处换取准考证，方可参加后续面试考核。体质测试未通过考生也须将体质测试成绩单交回现场确认处。
现场确认须携带以下材料：
（1）《西北工业大学2026年强基计划志愿表》原件；
（2）本人身份证原件；
（3）人身意外保险购买单据，确保6月30日至7月1日有效。
现场确认所需材料缺一不可，经检查材料齐全符合参加考核要求者允许参加校测。
三、面试考核
面试考核时间：2026年7月1日上午8:30开始，开考后考生禁止入场。考生根据准考证号在候考室就座，未面试考生不得离开候考室，学校中午提供午餐。
考生面试考核当天仅可携带身份证、准考证（无需考生下载，现场确认时发放）进入候考室及考场。禁止携带手机、智能手表（手环）、智能眼镜等，一经发现按违纪论处。
面试考核地点：友谊校区西馆，候考室及考场安排以准考证和面试当天考场外公布为准。
面试考核成绩低于60分的考生原则上不予录取。
注：具体测试安排如受不可抗拒因素影响有所调整，学校会第一时间通过本科招生信息网公布，请考生注意留意公布信息，同时保证手机联络畅通。
