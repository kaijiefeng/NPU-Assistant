# 电子信息学院举行科创文化节开幕式暨第二期铸剑班开班仪式

10月18日，电子信息学院举行科创文化节开幕式暨第二期铸剑班开班仪式，中国航空工业集团公司洛阳光电设备研究所副所长毛鑫、中航工业光电所人力资源部副部长徐贺、中航工业光电所人力资源部招聘主管郑春艳，电子信息学院副院长姚如贵、学工主管程姣姣、团委书记史越及铸剑班全体学员、各年级学生代表参加活动，会议由党委副书记高敏主持。
会议伊始，史越介绍了电子信息科创文化节的整体安排，活动融合科创启蒙与校园文化建设，弘扬科学家精神，厚植总师育人文化，引导学生树立科技报国志向；以低门槛、高体验的展赛玩讲系列活动，帮助同学们走近前沿科技、动手实操器件、明晰科创方向，同时为科创社团搭建集中展示窗口，营造崇尚科学、乐于实践的育人氛围，让同学们近距离感受电子信息技术的创新魅力。
姚如贵致辞并宣布文化节开幕，希望同学们在本次活动中涵养科学与人文素养，在多元体验中拓宽视野、陶冶情操；勇于创新实践，锤炼过硬本领，努力将理论知识转化为创新成果。
高敏宣读了电子信息学院第二期铸剑班成员名单，勉励同学们在铸剑班的淬炼中锚定发展方向，向着“总师型”人才目标砥砺前行。
姚如贵为毛鑫校友颁发了校外班级导师聘书，师生们共同见证了这一重要时刻。
第一期铸剑班成员胡珂上台分享加入铸剑班的经历及收获，第二期铸剑班成员张贺程分享了自己加入铸剑班的初心与期待，并号召同学们在优秀榜样的引领下不断提升自身能力，成为勇立时代潮头、担当强国强军大任的青年先锋，为祖国的电子信息技术发展和国防科技事业贡献青春智慧与力量。
本次科创文化节与铸剑班开班活动，既是学院深耕总师育人文化、推进国防科创人才培养的生动实践，也是为青年学子搭建起理论学习、科研实践与思想淬炼的融合平台。下一步，电子信息学院将持续联动国防院所等行业单位，依托铸剑班等特色育人载体，不断丰富科创实践场景，引导青年学子传承报国薪火、把论文写在祖国大地上，努力成长为建设科技强国、实现高水平科技自立自强的新时代拔尖创新人才。
