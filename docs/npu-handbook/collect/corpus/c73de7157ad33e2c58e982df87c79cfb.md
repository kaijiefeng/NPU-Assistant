# 保卫处召开预备党员转正大会暨第四季度党课

12月11日，保卫处党支部召开预备党员转正大会暨第四季度党课，会议由保卫处党支部书记朱建军主持，全体党员参加会议。
首先，党员大会讨论刘佳同志由预备党员转为正式党员相关事宜。朱建军说明了会议目的，介绍了预备党员刘佳的基本情况。刘佳同志宣读转正申请书，向大会介绍自己预备期各方面表现及今后努力方向，提出转正要求。入党介绍人对刘佳能否入党表明意见。支委会介绍对刘佳的审查情况，提出同意按期转正的建议。与会党员进行充分讨论并以无记名投票的方式通过刘佳同志转为正式党员。
随后，党支部开展第四季度党课。党支部副书记薛康做了题为“数字时代高校保卫工作”的调研报告。四川大学推出党建品牌化、管理信息化、政保联动化、应急多能化等特色工作举措，校园环境治理取得显著成效；南京航空航天大学警务室推出的“精准服务、定制服务、流动服务”惠民窗口，为师生提供更便捷、更人性化的服务；浙江大学5校区联动式一体化管理，办事流程简便，处处展示出精细管理的成果；作为“枫桥经验”发源地的诸暨市枫桥镇，在基层治理实践中不断赋予新时代“枫桥经验”新内涵。各具特色的创新举措为调研组开拓了视野，增长了见识，为我校保卫信息化建设和基层治理工作提供了借鉴典范。
今年，保卫处严格落实大兴调研之风的工作要求，坚持目标导向和问题导向，精心挑选具有代表性的兄弟院校、研究机构、高科技企业、基层治理示范乡镇等单位，先后组织31人次外出开展工作调研。未来，保卫处将进一步开拓思路，破解影响制约保卫工作发展的障碍；着眼长远规划，以钉钉子精神落实学校的工作部署，肩负起为学校各项事业保驾护航的光荣使命，全力以赴助力学校实现“127”目标。
