# 胡军良教授应邀为陕西省青年发展规划中心作学术报告-西北工业大学

2026年9月23日，西北大学胡军良教授应邀来到西北工业大学马克思主义学院，为陕西省青年发展规划研究中心全员带来题为《马克思主义理论硕博士学术成长的三个阶段及注意事项》的精彩学术报告。报告会由陕西省青年发展规划研究中心主任宫淑燕副教授主持。
胡军良教授把马理论专业硕博士的学术成长过程分成三个阶段：打好基础、研读经典的入门阶段；找准问题、搭建研究框架的突破阶段；自主开展研究、建立学者身份认同的成熟阶段。他结合每个阶段的特点，梳理了对应的核心任务，给出了可以落地的学习建议。
在入门夯实基础阶段，他建议大家沉下心精读经典原著，梳理清楚学科脉络，分清教材表述、宣传话语和学术话语这三类语言，同时学会追溯核心概念的由来与演变过程。到了问题突破阶段，要学会从现实矛盾和现有理论的薄弱之处发掘真正值得研究的问题，摆脱模板化的写作习惯，反复打磨文稿，增强论文本身的理论深度。进入独立研究阶段，他鼓励青年研究者锚定一条持续的研究主线，全方位锻炼科研能力，守住学术底线，保持创新意识。
报告现场，师生们还和胡军良教授围绕AI时代的学术写作展开了热烈探讨。胡教授谈到，AI确实能帮我们搜集材料、构思选题、搭建行文框架、润色文字，是很好的辅助工具，但它终究只是高级帮手，不能直接代替研究者本身。他提醒在场同学，AI产出的内容很容易千篇一律，不要贪图工具带来的便捷，最后写出缺乏思考的平庸文字。做研究，还是要回到原著里深度研读，保持对现实问题的敏感度，只有这样，我们才能从被动接收知识的读者，转变为创造学术成果的研究者。
整场报告会氛围轻松，互动充分。胡教授结合自己科研路上的亲身经历和实例娓娓道来，通俗易懂，在场师生都收获良多。这场报告为马理论硕博士的学术成长指明了清晰方向，也有助于青年科研人员进一步提升科研水平，树立良好的学术规范意识。
