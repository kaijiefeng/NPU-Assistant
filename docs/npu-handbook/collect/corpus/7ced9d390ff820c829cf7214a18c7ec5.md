# 后勤部办公室党支部开展专题党课学习活动

为深入学习贯彻党的二十届四中全会精神，4月8日上午，后勤部办公室党支部组织全体党员开展专题党课学习活动。本次党课由后勤部办公室副主任袁源讲授，党支部书记张文刚主持。
袁源以《夯实基础持续发力——乘势而上、接续推进中国式现代化》为主题，围绕党的二十届四中全会召开的基本情况与重大意义、“十四五”时期发展成就、“十五五”规划战略要点等三大核心内容展开系统讲解。同时，结合学校学习贯彻党的二十届四中全会精神相关工作部署，带领党员们回顾学校“十四五”时期的发展成就与经验，并对学校提出的“十五五”期间核心发展指标“一十百千”进行了详细讲解，引导党员们精准把握政策精神，对标对表落实各项工作要求。袁源指出，后勤保障工作是学校高质量发展的重要基石，我们要以“一十百千”为工作目标和抓手，聚焦师生急难愁盼问题，切实把党的二十届四中全会精神转化为服务学校“十五五”发展的实际成效。
通过此次党课学习，党员们全面了解了学校“十四五”时期的丰硕成果，进一步增强了干事创业的自豪感与使命感。大家纷纷表示，要把学习成果转化为为师生办实事的工作动力，以更加饱满的热情、更加务实的作风，投身后勤管理与服务保障工作，为学校“一十百千”发展目标的实现贡献力量。（撰稿人：毛淑兰；审稿人：韩争胜）
