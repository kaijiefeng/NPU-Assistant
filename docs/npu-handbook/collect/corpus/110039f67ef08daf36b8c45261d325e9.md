# 深入学习革命精神 激发爱国情怀——校工会党支部组织观影活动-校工会（帮扶办）/ 妇女联合会

为深入贯彻落实学校第十四次党代会精神，进一步增强校工会党员的政治信仰与爱国情怀，11月6日下午，工会党支部组织党员同志集体观影《志愿军：存亡之战》。通过生动的历史教育和深刻的思想洗礼，支部成员在观影中缅怀先烈、坚定信念，以扎实的学习和实践推动支部建设再上新台阶。
铭记历史 不忘初心
影片《志愿军：存亡之战》生动再现了抗美援朝战争的峥嵘岁月，讲述了中国人民志愿军为国家存亡英勇奋战、捍卫和平的感人事迹。工会党支部党员同志在观看过程中多次被影片中的悲壮场景深深打动，切身体会到革命先烈们在战火中无畏牺牲、舍生忘死的伟大精神。支部书记陈建军表示，“历史是最好的教科书，党支部将通过丰富的学习形式，引导党员铭记历史、不忘初心，在思想和信仰上不断锤炼自己。”
爱国爱校 砥砺奋进
观影结束后，支部党员们结合影片内容展开热烈讨论，大家纷纷表示，在新时代的工作岗位上，要坚定理想信念，立足本职工作，凝聚起为学校“双一流”建设奋斗的磅礴力量。校工会党支部一直致力于通过主题鲜明、内容丰富的党组织活动，激发党员的爱党爱国之情和爱校爱家之心，未来，校工会党支部将继续以红色教育为抓手，不断深化党员思想政治建设，在实践中担当作为、奋发图强，以实际行动为“天下工大，世界三航”远景目标贡献工会力量。
