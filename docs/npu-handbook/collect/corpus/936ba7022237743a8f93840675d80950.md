# 共建共学忆校史 同心同向担使命——档案馆党支部开展校史教育主题党日暨支部共建活动

为传承学校红色基因、厚植爱校荣校情怀，11月3日，档案馆党支部、后勤集团工程服务中心党支部、材料学院碳材料博士生党支部、碳材料师生融合党支部，共同开展校史教育主题党日暨支部共建活动，组织教工党员、学生党员追寻校史足迹、缅怀先贤。
活动首站，全体党员走进学校档案馆，参观档案文化长廊。档案馆刘老师立足学校“脉源三支、强强融合”的办学根基，从古路坝“教育圣地”烽火办学、“七星灯火”弦歌岁月，讲到“华航西迁”壮怀抉择；从哈军工风洞群建设的攻坚史实、钱学森同西工大的深厚情缘，讲到总师宋文骢、唐长红、韩克岑等一批从西工大走出、挺起国之重器脊梁的优秀校友代表。一段段校史掌故、一个个育人故事，在史料实物与展板长廊间生动呈现，深刻诠释着学校“总师育人文化”的精神内核。
随后，全体党员前往友谊校区桃李园，在寿松涛、刘海滨、季文美三位先生的铜像前驻足瞻仰，聆听档案馆李老师声情并茂的讲述，回顾三位先生的人生历程。三座铜像静静伫立，诉说着先贤们将人生最宝贵的年华留在西北热土的动人故事。
雕像无言，精神有声。蒙蒙细雨中，教工党员和学生党员们有序开展擦拭先贤铜像志愿服务。大家手持抹布，轻轻拭去雕塑表面的浮尘，以简朴庄重的方式追思先贤、致敬前辈。一次擦拭，一份敬意，这既是饱含深情的缅怀，更是一堂浸润人心的现场思政课。
此次支部共建活动，将校史教育、先贤事迹学习与劳动教育有机结合，为各支部互学共进搭建了交流平台。大家表示，将铭记先辈奋斗历程，传承弘扬总师育人文化，把学习所得转化为干事创业的动力，立足本职岗位、勤学实干、笃行不怠，以实际行动践行共产党人的初心使命，为学校高质量发展贡献力量。
