# 人工智能联合实验室共建签约仪式在西工大重庆科创中心顺利举行

6月25日上午，由西北工业大学自动化学院、重庆科创中心与重庆邮电大学人工智能学院共建的“人工智能联合实验室”签约仪式顺利举行。重庆邮电大学副校长韩军伟、科技处副处长（主持工作）肖斌、人工智能学院党委书记邓学平等领导和专家，西北工业大学自动化学院院长/党委书记李伟林、党委副书记易正阳，重庆科创中心副主任杨舜、刘川及骨干研究人员、教师代表共同参会。签约仪式由李伟林主持。
会上，西北工业大学自动化学院院长助理程塨首先立足国家战略和地区发展需求等背景，系统介绍了人工智能联合实验室的建设目标、建设内容、保障措施、预期建设成果等内容，重点阐述了建设一个研究中心和四个研究平台，以及强化人才队伍建设的系列举措与工作思路。
重庆邮电大学先进技术研究院常务副院长路永乐汇报了重庆邮电大学在无人飞行器、无人平台的成果，基于参会三方的技术成果和重庆市军工企业的行业优势，展望了在低空经济方面未来交叉融合的发展方向。
签约环节，邓学平、易正阳、刘川共同在联合实验室共建协议上签字，韩军伟、李伟林和杨舜等领导共同见证。
随后，聚焦联合实验室的建设发展，与会人员围绕人工智能领域未来布局与方向依次交流研讨，并共同为联合实验室后续发展出谋划策。
杨舜在发言中说，作为2月19日校地战略框架协议的具体落实举措，通过联合共建人工智能实验室将进一步推动西工大重庆科创中心在人工智能领域从核心技术的突破到场景应用的拓展，有力赋能国创中心人才、技术和平台站位提高和筹建能力的擢升，重庆科创中心将全力做好支撑，和大家一起推动联合共建工作行稳致远。
李伟林说，筹建联合实验室是西北工业大学与重庆邮电大学深入合作的重要载体，期待各方围绕共建协议内容，整合优势资源，在人工智能、低空经济等方面深入合作，加强基础研究，加快推进相关领域科技成果转化，力争在科学研究、师资队伍建设、人才培养等各方面取得实实在在的成果。
韩军伟在总结发言中指出，本次共建人工智能联合实验室，符合国家战略和成渝地区发展需求，通过资源共融、优势互补，将持续推进各方在人工智能技术创新、科技成果转化及人才培养等方面的交流合作，为实现高水平协同发展贡献力量。
会议当天，与会人员一同参观了重庆两航金属材料有限公司，西工大重庆科创中心展厅、计算集群、超高周疲劳检测平台，并前往重庆邮电大学进行了深入调研交流。
