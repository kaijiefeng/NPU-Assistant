# 务实谋科研 同心强团队——航天学院召开科研发展与团队建设研讨会

为深入贯彻学校“双一流”建设部署与“十五五”发展规划要求，锚定高水平科技自立自强目标，4月20日，航天学院组织召开科研发展与团队建设专题研讨会。学院领导班子、学术委员会委员、各研究所及创新团队负责人、骨干教师代表齐聚一堂，聚焦科研创新提质、团队协同赋能、人才梯队培育、标志性成果产出等核心议题，共商科学研究高质量发展路径，凝聚攻坚奋进合力。
黄攀峰主持会议并作主旨发言。他立足学院发展实际，系统分析科研创新、学科建设、团队协同面临的机遇与挑战，强调要坚持差异化定位、特色化发展，以有组织科研破解分散作战瓶颈，整合优势资源，推动各研究方向深耕细作、提质增效，着力打造国内领先、特色鲜明的学科高峰，助力学校从国内一流向国际一流迈进。他指出，新方向拓展需前瞻布局，AI为学科交叉融合提供重要契机，要打破专业边界，深化校企协同与跨学科科研合作，着力培育高端人才、冲击重大奖项与顶刊成果，筑牢学院核心竞争力。
秦飞作《航天学院科研发展及团队建设研讨》专题汇报，系统梳理学院当前科研工作成效、团队建设现状，客观剖析科研创新、人才培育、资源整合等方面存在的短板不足，同时围绕科研方向聚焦、团队协同赋能、成果转化提升等方面，提出针对性优化思路与实施路径，为后续科研工作开展提供了清晰指引。
与会人员围绕科研方向凝练、团队结构优化、青年科研人才培养、科研考核机制完善、学术生态营造等关键问题深入交流、踊跃建言。大家一致认为，要坚守航天特色科研优势，推动传统科研方向提质升级、新兴科研方向精准突破；完善科研分类评价与资源支持体系，为青年教师科研自由探索提供充足空间；强化团队科研协同与资源整合，避免同质化科研竞争，形成“各擅所长、协同攻坚”的良好科研格局；深化校企科研合作与外部资源拓展，以重大科研项目牵引带动整体科研能力跃升。
本次研讨会凝聚了科研发展共识、明晰了实干路径、压实了工作责任，为学院科研与团队建设提质增效奠定了坚实基础。会议明确了重点科研方向梳理、高水平学术会议承办、科研人才队伍建设、科研管理模式优化及科研成果培育等下一阶段重点工作部署，全院将以此次会议为契机，凝心聚力、真抓实干，聚焦科研创新、人才培育与成果产出，持续强化科研核心竞争力，提升行业影响力，为学校建设中国特色世界一流大学、服务航天强国建设作出新的更大贡献。
