# 翱翔四海|电子信息学院“2026年哈萨克斯坦分校人工智能与丝路文旅冬令营”圆满结束

为有效拓展学生国际视野、提升全球胜任力，2026年2月22日至28日，电子信息学院组织40名学子，在学院国际化秘书郭媛老师的带队下，赴哈萨克斯坦阿里·法拉比哈萨克国立大学（以下简称“哈国大”），开展了为期7天的“人工智能与丝路文旅”冬令营研学之旅。研学期间，学生们聆听了多场高水平学术讲座，参访了超级计算机实验中心、Robotic HUB等科研平台，并与哈国立师生进行了深入交流。依托西北工业大学哈萨克斯坦分校（以下简称“哈分校”）这一重要交流平台，本次活动聚焦“高性能计算与智能科学计算”前沿主题，通过沉浸式学术体验与文化考察，深化学生对相关领域的专业认知，拓展国际视野。
学习交流
本次冬令营围绕“高性能计算与智能科学计算”这一学术主题，同学们在哈国立信息技术与人工智能学院进行了为期七天的系统化学术研修，受益匪浅。通过核心课程学习、学术研讨与科研平台参访的深度融合，同学们在理论与实践的交替中深化了专业认知，拓展了国际视野。
Yerzhan Kenzhebek博士讲解了偏微分方程求解的传统范式。结合Buckley-Leverett两相流模型，课程生动展示了如何训练网络拟合流体动力学方程，让同学们对科学计算与人工智能的融合有了全新认识。Irina Ualiyeva教授主讲的AI驱动的低资源语言处理课程则介绍了基于多语言BERT的文本简化框架，通过语义保留与结构优化，让复杂文本更易被大众理解。这门课程让同学们看到了人工智能技术在促进语言互通、文明互鉴方面的广阔应用前景。
在高性能计算（HPC）专题课程中，主讲专家Yerlan Makhmut以油气开采模型开发为应用背景，系统讲解了OpenMP、MPI与CUDA三大并行计算技术，让同学们对并行计算的基本原理与工程应用有了更清晰的认识。自适应数值网格课程由Olzhas Turar博士主讲，展示了网格生成与优化的核心算法及其在流体力学、电磁场模拟等领域的应用，帮助同学们理解了网格技术在科学计算中的基础性作用。先进计算技术课程则由Baragul Matkerim副教授主讲，系统介绍了异构计算、量子计算等前沿趋势，使同学们对计算技术的未来发展方向有了更全面的把握。
实验室参访
在课程之余，同学们还实地参观了哈分校。在哈方老师的热情接待与详细介绍下，同学们了解了哈分校从动议到揭牌，再到快速发展的建设历程，明白了哈分校作为中国高水平大学在哈萨克斯坦设立的第一所分校，不仅是优质教育资源的海外延伸，更为中哈永久全面战略伙伴关系提供智力支撑。
同学们还走进哈国立的多个科研平台，近距离感受中亚顶尖高校的科研氛围与创新活力。在阿里·法拉比超算中心，当了解到这座峰值计算能力达到数千万亿次每秒的超算中心，不仅支撑着量子化学、基因测序等前沿研究，并与中国科研机构在“一带一路”科技创新行动计划框架下保持着密切合作时，同学们深切感受到科技创新无国界的魅力，也对我国算力技术走出去的战略意义有了更直观的认识。走进Farabi Hub孵化中心，开放式的办公区域和年轻的创业团队让同学们眼前一亮。看到学校为初创团队免费提供办公场地、创业导师服务并协助对接投资机构，同学们真切体会到高校在推动科技创新与成果转化中的积极作为。在机器人实验室，同学们先后参访了两个各具特色的科研空间。库卡机器人实验室内，工业机器人模型与控制系统芯片整齐陈列，技术图谱展示着机器人在汽车制造、航空航天等领域的应用场景。了解到库卡是中国美的集团旗下品牌、是中国制造布局全球的重要成果时，同学们心中涌起浓浓的自豪感。而在汇博机器人实验室，老师现场演示的智能分拣任务令人印象深刻——机械臂凭借自主研发的视觉识别系统，精准抓取传送带上的不同物品并分类放置，整个过程流畅高效。同学们纷纷举起手机记录这精彩瞬间，为中国智造的硬实力由衷赞叹。
文化体验
在本次冬令营活动中，同学们不光在哈国大的课堂里学习前沿知识，更在阿拉木图的大街小巷感受城市的温度与脉动。漫步于潘菲洛夫-28勇士纪念公园，积雪覆盖的松柏与肃穆的光荣纪念碑交相辉映，和平鸽盘旋其间，让同学们感受到历史的厚重与和平的珍贵。从山脚乘坐缆车登上琼布拉克雪山，天山的雪脊在阳光下熠熠生辉，同学们在山顶凝望远方的连绵雪峰，沉浸于天地间的纯净与壮美。最后走进当代艺术馆，一张明信片将这段旅程定格为永恒的纪念。
从实验室的算力脉搏到琼布拉克的皑皑雪山，这七天的跨国研学不仅是一次专业知识的“万里长征”，更是一场深度的文化共振。学子们在哈国大的课堂上拓宽学术边界，在阿拉木图的街头巷尾感知丝路温度，在专业认知与国际视野的交融中收获了难忘的成长体验。此次冬令营的圆满落幕，不仅为中哈青年科技交流画下了精彩的一笔，更在每一位学子心中种下了科技报国、连接世界的种子。
学员感悟
