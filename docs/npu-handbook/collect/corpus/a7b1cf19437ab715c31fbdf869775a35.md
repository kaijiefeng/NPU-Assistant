# 深圳西工大科技园有限公司-西北工业大学资产经营管理有限公司

深圳西工大科技园有限公司成立于2009年，是西北工业大学资产经营管理有限公司的控股子公司，注册资金3000万元。核心业务聚焦于西北工业大学三航科技大厦的运营管理，致力于将其打造为粤港澳大湾区具有影响力的高端商务与产学研一体化平台。
西北工业大学三航科技大厦地处深圳市高新技术产业园核心区，占地4917.41平方米，总建筑面积约4万平方米（地上25层、地下3层），是一座荣获“国家优质工程奖”的超A级写字楼。作为西北工业大学深圳产学研基地，大厦深度融合学校在航空、航天、航海（三航）及材料、力学、机械、计算机、控制、通信（3M、3C）等领域的学科优势，为入驻企业提供技术研发、成果转化、人才培育等一站式服务，于2023年被正式认定为“深圳市军民融合产业集聚区（南山学府）”，已成为汇聚七十余家优秀企业的产业聚集地，其核心优势在于独特的功能定位与资源链接能力。它不仅是军民融合产业的“聚集地”和依托西工大“总师育人文化”及国家级科研平台的人才、科技成果“孵化园”与“高产区”，更是链接西安与大湾区资源的“中转场”。
未来，公司将持续推动大厦智能化升级，强化其作为科技研发、产业孵化与国际交流一体化平台的功能，力争建设成为大湾区的标杆性科技园区。
