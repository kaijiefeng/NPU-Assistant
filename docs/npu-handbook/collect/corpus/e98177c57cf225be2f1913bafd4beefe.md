# 关于邀请参加“2025年中亚青年科学家对话活动”的通知-西北工业大学

各单位：
联合国2030年可持续发展目标是全人类发展的重要议程，中亚是“一带一路”的核心地区，面临着资源需求增加、生态环境恶化、水资源分布不均衡等一系列挑战。新疆位于丝绸之路经济带的核心区，与中亚、南亚等多个国家接壤，资源丰富，是向西开放的重要窗口，有其独特的区位优势和人文优势。为更好落实习近平总书记在新疆考察时的重要指示精神，特别是发挥青年人才建设新疆，服务中亚的关键作用，世界青年科学家联合会拟于8月联合有关单位，在新疆乌鲁木齐举办“2025年中亚青年科学家对话活动”（以下简称活动），旨在提升乌鲁木齐作为“一带一路”重要节点城市的国际影响力，推动搭建中亚地区青年科学家合作网络、建立长期合作机制，鼓励中外青年科学家服务新疆经济社会高质量发展，为中亚地区可持续发展的关键问题提出解决方案。现将活动具体通知如下：
一、活动主题
汇聚丝路英才，共创美好未来
二、主办单位
世界青年科学家联合会
新疆维吾尔自治区科协
中国科学院新疆生态与地理研究所
三、主要议题
1.绿洲守护者：人工智能与游牧智慧的生态对话
2.丝路水脉：从咸海到黄河的可持续发展艺术
3.未来矿藏：绿色勘探中的社区叙事
4.生命绿洲：生物多样性保护的文化解码
四、活动安排
时间： 2025年8月下旬（会期3天，具体行程安排会前另行通知）
地点：新疆维吾尔自治区乌鲁木齐市
请有意向参加此次活动的人员联系北京研究院进行咨询和报名。
联系人：魏羽 17792358075
北京研究院
