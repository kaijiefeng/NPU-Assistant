# 思政实践课教研室开展学习《中国共产党思想政治工作条例》集体备课会-西北工业大学

为深入学习贯彻习近平总书记关于思想政治工作的重要论述，积极探索新时代思想课教学创新方式方法，更好提升思政实践课针对性和实效性，11月26日，思政实践课教研室开展学习《中国共产党思想政治工作条例》集体备课会。会议由教研室主任高红波主持。
会上，高红波首先传达了校院关于组织学习《中国共产党思想政治工作条例》相关工作精神，表示思想政治工作是党的优良传统、鲜明特色和突出政治优势。思政实践课作为学校思想政治理论教育与实践教育的重要手段和载体，必须从政治上、全局上更加深刻认识到思想政治工作的极端重要性，以高度的思想自觉和强烈的责任担当，认真上好思政实践课，更好充分发挥思想政治工作的引领作用。
与会人员就如何更有效开展思政实践课展开了讨论。大家一致认为，思政实践课应结合实际增加实践案例、带领学生接触实践前沿并联动相关学院活动，强化理论与实践融合以提升教学实效。同时，还需创新激励机制，妥善处理理论与实践教学、课堂激励与最终考核的关系。
备课会还学习了《关于禁止在秦岭（西安段）核心保护区开展违规穿越探险等活动的通告》，并强调在课堂教学中进一步宣传加强保护秦岭（西安段）核心保护区生态环境和自然资源完整性、原真性，减少人为活动对核心保护区生态环境的影响。
