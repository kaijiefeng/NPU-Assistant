# 车辆通行证办理（线下）

一、流程图
二、所需提交材料
1.事业编、校聘非事业编：一卡通、车辆行驶证、机动车登记证（车辆所属人为配偶的需提供结婚证或户口本等）
2.单位自聘：需本单位开具证明、领导签字盖章并携带本人劳动合同复印件及近三个月工资流水，于人事处劳资办公室审核通过后，携带人事处审核单和一卡通、车辆行驶证、机动车登记证（车辆所属人为配偶的需提供结婚证或户口本等）
三、注意事项
1.首次办证需线下办理，携带齐全所需材料。
2.线下办理支持微信、支付宝、现金缴费。
四、办公地点：友谊校区北一门便民服务点，联系电话88493716。
