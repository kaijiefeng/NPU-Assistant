# 人工智能学院/无人系统技术研究院召开自然科学基金申报动员会暨撰写技巧讲座

12月24日上午，人工智能学院/无人系统技术研究院组织召开了国家自然科学基金申报书撰写解析暨申报动员会议。会议邀请电子信息学院戴玉超教授为主讲嘉宾，由无人系统技术研究院副院长符文星主持，20余名学院教师参加了此次讲座。
符文星详细介绍了戴玉超教授的个人履历，重点突出了他在学术研究领域取得的成就，并表示本次培训讲座为青年教师提供了及其难得的学习契机。
戴玉超教授在讲解申报书撰写技巧时，针对项目名称、摘要、立项依据等关键环节，详细阐述了撰写要点与优化策略，着重强调申报书需具备科学性、创新性与规范性。在分析申报失败原因时，结合具体案例剖析了常见问题，提出了相应的建议。
参会教师认为讲座内容丰富且具有较强的针对性，通过此次讲座，他们掌握了撰写技巧，明确了注意事项，梳理了申报思路。为青年教师搭建了有效的学习交流平台。下一步，我们将持续聚焦科研人才培育，开展更多有助于提升科研能力的活动，以推动科研事业发展。
