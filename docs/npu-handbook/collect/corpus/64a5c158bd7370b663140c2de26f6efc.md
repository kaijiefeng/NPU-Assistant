# 校内调动申请流程办理

办理指南
一、申请路径：
翱翔门户—网上办事大厅—人事服务—校内人员调动申请
二、注意事项
1.本流程适用于我校事业编制职工校内调动手续办理。
2.申办人员请认真阅读办理指南、注意事项并据实填写。
3.人员类型选择时，辅导员的选择辅导员（不论是否有科级）；科级干部的选择科级干部；非辅导员和科级干部的选择教职工。
4.辅导员调出学工队伍，请先办理学生工作干部宿办合一用房的退宿手续（学生处学生事务管理中心出具退宿证明）；最后请将审批通过的调动申请表各1份交组织部和党委学生工作部。
5.科级干部调动需在组织部领取《科级干部交流表》。
