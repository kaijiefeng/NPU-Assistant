# 急诊科-西北工业大学医院

西北工业大学医院急诊科位于医院一楼大厅东侧，属全年无假日科室，365天24小时应诊。目前接诊急诊、发热门诊、内科常见病、多发病的诊治，3高血压病、2型糖尿病及并发症、高血压急症、冠心病、急性心肌梗死、各种原因休克、心肺复苏术、酒精中毒等各种急诊急救的抢救，可进行的治疗包括：院前急救、家庭出诊、留置胃管、尿管、换药、静脉输液、心电图、洗胃等。承担学校各项活动保健工作及校园突发事件的相关工作。急诊科现有科主任1人，护士长（康复骨外科护士长兼）1人。现有医生5人，副主任医师1名，主治医师4名，其中研究生3名。护理人员7名，其中主管护师3人、护师4人。急诊科获得“青年文明岗”、“医院先进集体”、“先进女教职工集体”称号。全体医护人员遵从“厚德仁爱”的精神，以精湛的急救技术、便捷的就医流程，为我校师生提供优质的急救医疗服务。
设有抢救室1间、全自动抢救床1张、发热留观门诊2间、输液留观室2间、留观座椅14张，留观病床10张，科室拥有全球最先进的ZOLL M系列除颤起搏监护仪、简易呼吸机、十二通道心电图机、SC-I型全自动洗胃机、BD-6000型输液泵、制氧机、高流量湿化治疗仪等设备，可以开展紧急呼救、院前急救等业务，对于一些活动不便或急重症患者可以提供医护出诊上门服务。
