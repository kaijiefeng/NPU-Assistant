# 签证所需材料模板（同时含签证、出境证明、领取单等各类因公出国(境)手续所需模板）

签证所需材料模板
1.中文照会
2.英文照会
3.在职费用证明 (除韩国签证外，其他均用此模板填写后由国际合作处套蓝头信纸后签字盖章）
4.各国名单表
5.各国名单预约表
6.德国声明书（2023.2.15）
7.保险要求
8.签证领取单模板
9.出境证明模板
10.在职费用证明（中文） 仅限韩国使用（韩国签证使用，请用对应模板填写后由人力资源部套红头信纸后签字盖章）
11.部分签证资料自查表帮助老师们在准备材料时对照检查常见易错点，建议各位申请人准备签证材料时逐项对照避免常见易错问题。
其他说明：
签证材料中如涉及外方营业执照等材料请联系邀请方索取；如涉及中方营业执照、组织机构代码证复印件，对我校教职工来说均使用事业单位法人证明复印件即可，负责单位为档案馆，电话：029-88493280。线上申请途径：翱翔门户--办事大厅--事业单位法人证书利用申请
