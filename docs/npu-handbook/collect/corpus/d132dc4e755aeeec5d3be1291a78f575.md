# 化学与化工学院举办优秀研究生毕业生分享交流会

为充分发挥朋辈榜样示范引领作用，帮助在校研究生更好地明确学习目标，做好职业规划，4月2日下午，化学与化工学院在理苑会议室组织开展优秀研究生毕业生分享交流会。六位优秀研究生毕业生代表受邀作经验分享，学院硕士生辅导员高昭老师出席，2023级和2022级部分研究生参加活动。

本次活动邀请了邹俊辉、于猛、樊婉晴、李宇丹、昝姝聿、徐焰等六位2024届优秀研究生毕业生作为分享嘉宾，他们结合自身实际，分别从求学心路历程、就业准备、经验收获等方面进行了详细分享，并就现场同学的提问进行了耐心的回答。

高昭老师对本次活动给予充分肯定，对六位嘉宾的精心准备和精彩分享表示感谢。他希望低年级同学们树立明确目标，向身边榜样学习，不断提升自己，在学业和职业发展取得圆满的结果。

邹俊辉毕业后在本校继续攻读博士学位，他结合自己获得的多个offer的丰富经历，指出在求职过程中要保持良好的心态，不要放弃每一次机会，并建议同学们在认真学习科研的同时，要积累一定的社团和学生工作经历。

于猛同学主要从考公经历展开分享。他结合自己考公务员的经验，分享考公过程中的注意事项与心路历程。他指出，每个省公务员考试每年只有一次，同一时间只能选择一场备考，所以一定要提前规划优先顺序，同时积极的心态是必不可少的，积极的心态会帮助我们反应敏锐、记忆力增强，这在备考过程中十分重要。

樊婉婷毕业后在本校继续攻读博士学位。她结合自身经历，告诫同学们提早做好未来职业规划，不能到人生的岔路才做出决定，准确定位、主动应对在求职过程中是很关键的。

李宇丹毕业去向为中国航天科工集团第六研究院四十六所，她着重分享了就业信息获取途径、简历投递注意事项、选调生和军队岗位报考准备等，强调要有针对性的展示自己的经验和技能，她建议同学们在求职过程中应尽早规划，及时关注招聘信息，打开思路，多投递简历，积极应对面试。

昝姝聿毕业后去向为杭州智元研究院有限公司。她建议大家注重学术与实践之间的联系，多积累与自身研究方向相关的文献，合理安排实验时间，注重写作细节。她强调求职过程中要自信大方、从容应对，将自身最好的一面展示给面试官。

徐焰毕业后去向为长鑫存储技术有限公司。她在求职经验分享中重点介绍了求职准备、简历制作以及注意事项等。她强调要确保简历上的每一个内容都清楚明了，对不同的求职岗位，简历要更加有针对性。她建议同学们及时梳理投递单位信息，始终做到心中有数。
