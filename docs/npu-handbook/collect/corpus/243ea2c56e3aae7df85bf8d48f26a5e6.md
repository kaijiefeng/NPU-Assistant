# 外国语学院开展2026届本科毕业党员专题廉洁教育

6月22日，外国语学院面向2026届本科生毕业党员开展题为“译路清风伴我行”的廉洁专题教育。学院党委副书记张桑桑主讲，全体2026届本科毕业党员参会学习。
讲座紧扣外语专业特色，解读“译路”与“清风”内涵，结合语言行业特点讲明廉洁从业重要意义。张桑桑强调，外语学子涉外接触多、言行关乎党员形象，要严守纪律规矩，精进专业本领的同时坚守清廉本心。
此次讲座通过警示案例、交流研讨，帮助毕业党员明晰纪律红线，筑牢拒腐防变思想防线，树立正确职业操守。
文：徐小慧
