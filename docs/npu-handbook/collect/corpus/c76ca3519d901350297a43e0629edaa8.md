# 机电学院关于本科生外出进行生产实习的规定

随着教学改革以及实际教学情况需要，学生有自行外出生产实习的需求，为保障实习质量以及该项工作积极、稳妥开展，特作以下规定：
1.申请外出实习的学生应有良好的平时成绩和在校表现，原则上必须三人以上组成实习小队。
2.要制定详细的实习大纲及实习计划、实习时间安排。
3.要有拟前往实习单位（拟前往单位不能在家庭所在地）的接收函及负责人姓名和电话，学生要留下联系方式；拟前往实习单位要指定相关技术人员负责指导，并在接收函上注明指导教师及联系方式。
4.自行外出参加生产实习的学生，安全责任自负（提供书面保证书并注明实习期间的住宿安排），本人必须办理保险，同时要有家长知晓书。
5.外出实习的学生要由本人提出书面申请，班主任、辅导员签署意见，由各专业研究审批，自行外出参加生产实习的学生数量，各专业要严格掌握，各专业要同时指定外出实习学生的校内指导老师，对外出实习成员通过电话、邮件等形式进行定期检查，若实习质量和进度无法按计划进行，有权终止实习。
6.外出实习的学生回校后将实习报告、实习单位鉴定意见交至本专业，参加本专业的统一答辩考核。
7.自行外出参加生产实习的学生，经费自付。
8.特殊问题须经主管院长批准。
请各专业严格审批手续，以上条件落实后，才能批准学生自行外出参加生产实习，并将有关材料上报学院本科教学管理办公室备案。
机电学院
2026年6月
