# 中国共产党西北工业大学生命科学与技术学院第一次代表大会顺利召开

2026年5月21日下午，中国共产党西北工业大学生命科学与技术学院第一次代表大会顺利召开。本次大会是在学院全面学习贯彻党的二十大和二十届历次全会精神，深入开展树立和践行正确政绩观学习教育，推动落实学校第十四次党代会部署，奋进“十五五”新征程的关键时期召开的一次重要会议。学校党委常委、副校长张富利，党委组织部副部长宣建林出席会议，生命科学与技术学院师生党员代表参会，大会由学院副院长于兆良主持。
大会在庄严的国歌声中正式开幕。
段利兵同志代表学院党委向大会作题为“凝心聚力 笃行实干 奋力谱写生命科学与技术学院高质量发展新篇章”的工作报告。报告全面回顾、系统总结了过去五年学院的各项工作成绩和经验，精准剖析了学院发展面临的机遇挑战，科学谋划了学院高质量发展的宏伟蓝图，为未来发展指明了前进方向。
张敏乔同志代表学院党委向大会作学院党委党费收缴、使用和管理情况报告。
大会审议并通过了上述两个报告和大会选举办法，通过监票人名单，宣读计票人名单。
宣建林宣读学校党委关于生命科学与技术学院委员会委员候选人预备人选的批复。
总监票人尹大川同志主持大会选举环节，在监票人监督下，与会代表以无记名投票方式，选举产生中国共产党西北工业大学生命科学与技术学院第一届委员会委员。
张富利代表学校向大会的顺利召开表示热烈祝贺，并对未来工作提出三点要求：一是强化政治引领，全面加强党的领导；二是坚守育人初心，落实立德树人根本任务；三是凝聚奋进合力，实现学科高峰新突破。
在《国际歌》中，大会圆满完成了各项议程，胜利闭幕。
会后，新当选委员召开了中国共产党西北工业大学生命科学与技术学院第一届委员会第一次全体会议。会议选举产生了党委书记、副书记，并讨论了委员们的分工，为学院党委的后续工作奠定了坚实基础。
蓝图绘就正当时，笃行致远启新程。学院全体师生将坚持以习近平新时代中国特色社会主义思想为指导，更加紧密地团结在以习近平同志为核心的党中央周围，立足学院基础研究特色优势，凝心聚力担使命，守正创新谋突破，努力打造具有全球影响力的生命科学人才培养和科学研究高地，为服务健康中国、美丽中国建设贡献生科人更大力量！
