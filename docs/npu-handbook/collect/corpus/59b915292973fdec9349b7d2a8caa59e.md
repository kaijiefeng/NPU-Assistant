# 航空学院关于加强端午节期间安全保密工作的通知

端午假期即将来临，为了做好假期期间学院安全保密工作，严防各类事故发生，维护学院安全稳定, 现将学院端午节期间安全保密工作通知如下：
安全方面:
一、 各系、实验室、课题组、机房要在放假前对全体师生在进行一次安全警示教育，增强安全防范意识，同时开展一次深入细致的安全自查，确保不留死角，消除隐患。
二、加强组织领导，落实安全工作责任制 ，按照“谁主管、谁负责”的工作原则，各系、实验室、课题组负责人安排部署好安全工作，明确具体任务和责任人，导师要掌握学生（包括留学生）放假期间的情况。
三、各系、实验室（含机房）办公室、教研室要特别注意以下几点：
（1）假期各机房、办公室、实验室等人员离开时必须关闭水源、电源、锁好门、关好窗。
（2）假期进入实验室人员必须遵守实验室的各项规定，严格执行相关的操作规程。
（3）禁止堵塞实验室消防通道，保持消防通道畅通。
（4）假期里对易燃、易爆、化学品等危险品，要严格按有关制度领用、贮存和使用，严防危化品流出实验室，同时要加强实验废弃物处置的管理。
（5）各实验室门钥匙必须专人专管，不得擅自外借他人使用，以备应急之需。任何人不得在实验室从事烹煮食物、聚餐饮酒、吸烟、使用明火等，严禁在教研室、实验室留宿，不得从事与实验无关的事情。
（6）对于压力容器、气瓶、起重机、行吊等特种设备，假期里应妥善归位放置，如需使用须报实验室负责人批准，实验室安全员同时做好安全提醒等工作。
（7）使用临时工和进行施工的单位要对其相关人员进行安全教育，坚决制止违规使用大功率电器，规范操作施工，防止发生电器火灾和其它安全事故。
四、假期外出游玩的老师要特别注意自身安全。
五、值班人员在值班期间要注意检查本单位及周边情况，发现问题及时报告值班领导，并上报学院以及学校保卫处。
保密方面:
一、放假离校前，涉密人员必须将涉密文件、资料和所有涉密介质（涉密移动硬盘、U盘等存储介质）及笔记本电脑检查后放入密码文件柜中，检查并锁好办公室门窗。
二、严禁在家属区、私人住宅、境外或其他有上网条件的非涉密场所处理涉密科研业务。严禁将涉密笔记本和工作用笔记本带回家中使用。
三、严禁将私人电脑及其他带有视频、录像功能的电子产品带入涉密场所。
四、严格遵守“涉密机不上网、上网机不涉密”的保密规定。
五、严格按照保密要求，做好假期期间涉密载体的制作、产生、移交、传递、保管等各环节的保密工作。确保涉密载体账物相符、流向可控、去向可查。假期中，未经审批禁止将涉密载体带出工作区域。
六、假期外出的教师（特别是涉密人员）不得将工作、科研中知悉的国家秘密泄露给无关人员，禁止将无关人员带入科研工作场所及保密要害部门部位。
祝各位老师节日愉快！
