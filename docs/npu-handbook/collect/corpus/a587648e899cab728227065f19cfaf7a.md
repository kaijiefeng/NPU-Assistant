# 人工智能学院对接教务部、科学技术研究院召开AI赋能教学科研专题研讨会

为深入落实教育数字化战略部署，推动人工智能技术与人才培养、科学研究深度融合，4月13-14日，人工智能学院先后对接教务部部长王海鹏、科学技术研究院院长常洪龙，分阶段召开人工智能赋能教学与科研专题研讨会。院长白俊强、书记毛昭勇等领导班子成员共同参会研讨相关工作。
教学专题研讨阶段，白俊强介绍学院人工智能赋能教学的初步实践、成果经验与发展规划。王海鹏结合学校“总师育人文化”建设要求，强调人工智能赋能本科人才培养的重要意义。双方围绕优化培养方案、打造AI示范课程、建设实践平台三大核心议题深入交流：聚焦“人工智能+X”复合型人才培养路径，推动智能技术与各专业深度融合；遴选优质课程开展智能化升级，形成可复制、可推广的教学模式；深化校企合作、强化实验室建设，全面提升学生人工智能应用实践能力。
科研专题研讨阶段，白俊强从多维度阐释人工智能对科研创新的支撑作用与赋能路径。毛昭勇就学院人工智能算力分配与保障工作作补充说明。常洪龙指出，人工智能已成为科研工作核心工具，在数据分析、模型构建、问题求解等环节显著提升科研效率与成果质量，下一步需强化师生技术应用能力，以AI驱动学校科研水平整体跃升。
本次研讨会先后对接教务、科研两大部门，厘清了人工智能赋能教学与科研的重点方向，搭建起校院协同、部门联动的高效沟通机制，为学校构建“人工智能+”人才培养新范式、推动教学科研双轮驱动、协同提升奠定坚实基础。
