# 红色基因 蓝色情怀”力学与交通运载学院学生党员暑期社会实践纪实（四）

为高质量实施新时代立德树人工程，深入开展西北工业大学实践育人“三个一”暑期专项工作，引导青年学子立大志向、上大舞台、入主战场、干大事业，力学与交通运载工程学院在学工主管王涵晶老师、辅导员高晨光老师的带领下，组建“红色基因蓝色情怀”主题实践队，开启了一场“触摸红色根脉、追寻领袖足迹、传承军工薪火”大学生暑期社会实践，教育引导青年学生党员在实践育人大课堂中，争做又红又专的“总师型”人才。
2026年7月9日，实践队来到照金、南泥湾开展追寻红色印记，传承革命精神研学，实地感悟延安精神的时代内涵，接受革命传统教育。
上午，队员们先抵达照金革命纪念馆，场馆翔实的历史资料、图片、文物，再现了创建以照金为中心的陕甘边革命根据地的艰难历程，以及刘志丹、谢子长、习仲勋等百余位老一辈无产阶级革命家的在照金武装斗争中浴血奋战的峥嵘故事。场馆中“纪念红军长征胜利九十周年专题展”也让实践队一行深受鼓舞，现场大家重温入党誓词。
在陈家坡会议旧址，照金干部学院特聘教师、铜川市青年讲师团李园为师生现场开启了一堂生动的专题党课。她分享的照金革命根据地建设及英烈事迹让大家不禁潸然泪下，队员们了解到革命母亲为解放事业痛失三子的感人故事，也深切体会到革命胜利背后的牺牲与坚守，接受了一次深刻的党性洗礼。
“来到了南泥湾，南泥湾好地方，好呀地方……”实践队一路高歌，下午来到南泥湾，在田间唱响红色经典《南泥湾》，随后在当地农民爷爷的带领下投入到火热的大生产体验活动中，参与垦荒、垅田、耕地，亲身感受当年军民自力更生、开荒垦田的艰苦历程，深刻领悟艰苦奋斗、开拓进取的南泥湾精神。同时，为南泥湾国家示范性综合实践教育挂牌西工大实践育人“三个一”工程实践基地，建立劳动教育合作平台，为后续培养工大青年热爱劳动、尊重劳动者、珍惜劳动成果的优良品德打下基础，实现红色精神传承与劳动实践教育的深度融合。
实践队步伐不停歇还在一路前进，大家在行走中感悟初心、汲取力量，纷纷表示要将红色精神融入青春血脉，在新时代的征程上砥砺前行，用实际行动书写无愧于历史、无愧于时代的青春华章。
