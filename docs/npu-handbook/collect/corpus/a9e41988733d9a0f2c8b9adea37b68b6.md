# 党委保卫部开展高温天气用电安全专项检查

夏季高温炎热，学校教学生活用电量大幅度增加。为进一步加强高温天气消防安全管理，做好火灾预防工作，近日党委保卫部组织对两校区教学区办公楼、实验室、学生餐厅、学生公寓、快递点等重点部位开展了全面细致的用电安全专项检查。
此次检查重点关注三个方面。一是关注电气火灾防范，检查组对电气设备是否超负荷使用、电气线路是否私拉乱接、是否违规使用大功率电器、空调外机电气线路和插头是否裸漏、空调外机周边是否堆放杂物等问题进行了全面排查。二是关注电动自行车安全管理，检查组对电动自行车是否私拉乱接、是否飞线充电、充电设施是否符合规范、停放及充电区域是否进行有效防火分隔以及是否占用消防通道等问题进行了细致检查。三是关注消防知识普及，采取边检查边宣传的方式，在检查中同步就夏季高温用电安全、火灾预防、疏散逃离等消防知识面向师生开展宣传，提醒师生注意日常用电安全，提高警惕性，做到人走断电。本次检查中还发现隐患问题17项，检查组要求相关单位和责任人迅速落实整改，目前均已完成。
后续，党委保卫部将继续切实排查消防安全风险隐患，通过强力整治和广泛宣教，扎实推进校园用电防火工作，助力平安校园建设。
