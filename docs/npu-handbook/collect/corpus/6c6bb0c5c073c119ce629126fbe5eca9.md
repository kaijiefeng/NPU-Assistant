# 筑牢安全根基 聚力教研赋能——体育部有序开展新学期教学检查、教研备课工作

为扎实做好新学期体育教学开局工作，严格落实立德树人根本任务，进一步规范教学秩序、深化教学改革、夯实育人质量，近日，体育部以教学检查为抓手、集体备课为基础、教研部署为引领，统筹推进重点工作，层层压实教学责任，全力保障新学期体育教学工作平稳有序、提质增效。
新学期伊始，体育部第一时间启动开学教学专项检查，由领导班子组成检查小组，全面核验教学运行质量及安全生产工作。本次检查聚焦教师到岗履职、课堂组织规范、学生出勤情况、场馆设施运行及安全保障等关键环节，检查小组深入教学一线随堂听课、现场巡查，对排查发现的问题现场反馈、即时整改，从严从细抓实教学规范、课堂质量与安全管控，为新学期体育教学有序开展筑牢第一道防线。
此前，体育部已先期召开教研室主任专题工作会议，系统谋划新学期体育教学总体方向与重点任务。会议紧扣学校办学定位与育人目标，明确深化体育数智化教学改革要求，依托人工智能技术赋能课堂教学，立足学科实践性本质推进教学数字化建设，坚决杜绝形式化、同质化无效建设；要求持续创新课堂模式，激发学生运动积极性，聚焦精品课程建设，积极培育申报省级、国家级精品课程，打造特色体育教学品牌。针对教学场地资源紧缺现状，会议明确持续推动场馆设施优化升级，细化室外课堂管理细则，常态化排查极端天气授课安全隐患，牢牢守住教学安全底线。
为夯实课堂教学根基，在教研室主任专题会议后，各教研室迅速组织开展新学期首轮集体备课与教研交流活动。各教研室紧扣课程大纲、教学重难点、课堂创新设计、课程思政融入、分层教学实施等核心内容开展集中研讨，协同打磨教学方案、优化授课流程、统一教学标准、细化教学环节，全方位夯实新学期课堂教学的教研基础，确保教学准备精准到位。
本次工作严格遵循“教学检查保运行、集体备课夯基础、会议部署定方向”的工作思路，环环相扣、落地务实，有效规范了教学秩序、凝聚了教研合力、压实了育人责任。下一步，体育部将持续深化体育教育教学改革，常态化开展教研交流与教学督查，强化师资建设、优化场地保障、培育特色项目，不断提升体育育人质量，助力学生强健体魄、锤炼意志，为学校卓越“总师型”本科人才培养工作持续赋能。
