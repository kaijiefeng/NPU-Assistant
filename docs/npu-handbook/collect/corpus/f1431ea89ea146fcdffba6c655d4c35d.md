# 资信证明业务办理指南

一、办理银行资信证明，需携带以下材料至财务处填写《单位资信证明业务委托书》：
（一）科研项目投标提供:纸质版《西北工业大学科研项目投标用印审批单》（“科研系统-投标申请”流程中下载）；
（二）其他业务提供：办理申请（所在学院审批并加盖学院公章），申请中需列明资信证明用途。
二、财务处线上申请用印，审批通过后教职工到学校办公室印信室加盖学校公章；
三、携带现金或工商银行卡到工商银行西工大支行（友谊校区角楼）办理资信证明。（备注：存款类资信证明：300元/份；结算记录良好类资信证明：500元/份。）
