# 公共政策与管理学院组织教师赴甘肃庆阳开展实践研修活动

为持续提升教师思想政治素养、育人履职本领与科研服务社会的能力，9月4日至5日，公共政策与管理学院依托学校 “教师发展支持计划”“研究生导师能力提升项目”，由学院党委书记管兴华带队，组织教师赴甘肃庆阳开展专题实践研修。
教师团队深入庆阳市 “东数西算” 产业园区实地研学。作为国家算力枢纽核心节点，园区现有在建数据中心13个、落地数字企业500余户，智算集群规模突破10万P。教师们近距离了解算力产业赋能区域转型升级的实践路径，观摩“智慧庆阳”人工智能应用成果，深入把握数字治理发展前沿，为科学研究和人才培养积累了宝贵基层实践经验。
在凤凰塬舍、毛寺村，教师团队聚焦乡村振兴与基层治理开展调研，学习当地立足特色资源、深耕产业融合、创新基层治理、推进乡村可持续发展的优秀经验，有效推动理论研究与基层治理实践深度融合。
本次研修同步开展沉浸式理想信念教育。教师团队先后走进军民大生产纪念馆、南梁革命历史纪念馆，重温革命峥嵘岁月，感悟自力更生、攻坚克难的奋斗精神。作为土地革命战争后期全国硕果仅存的完整革命根据地，南梁根据地具有重要历史地位。大家驻足珍贵史料，深切缅怀刘志丹、谢子长、习仲勋等老一辈革命家的不朽功绩，接受深刻的党性淬炼与思想洗礼。
全体教师聆听《南梁精神是校准正确政绩观的四维坐标》专题党课。党课深度解读“面向群众、坚守信念、顾全大局、求实开拓”的南梁精神内核，从立场、价值、格局、方法四个维度明晰正确政绩观内涵，引导教师坚守育人初心、涵养为民情怀、担当育人使命。
活动最后，教师们参观了马锡五审判方式陈列馆，系统学习红色法治理念与基层司法工作方法，深刻领会“为民、利民、便民”的法治精髓。大家表示，将传承红色法治基因，以专业所长服务基层法治建设。
此次研修集产业调研、乡村实践、红色淬炼、法治研学于一体，内容扎实、成效显著。参训教师纷纷表示，将把此次研学所思、所学、所悟转化为教书育人、科研创新的强大动力，进一步坚定理想信念，厚植家国情怀。
公共政策与管理学院将持续抓实教师队伍素养提升，常态化组织国情调研与实践研修，引导教师扎根中国大地做真研究、出真成果，立足学科优势服务国家战略与地方发展，持续贡献西工大智慧与力量。
