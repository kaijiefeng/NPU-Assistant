# 《中国舰船研究》杂志社来院开展“校园行”专题活动

为了落实期刊主办单位与院校学术交流、合作共赢，促进期刊更好更快发展，6月16日上午，《中国舰船研究》杂志社常务副主编易基圣一行莅临航海学院交流座谈。航海学院院长潘光、副院长崔荣鑫及青年教师代表参加了会议，会议由崔荣鑫主持。
潘光代表学院对《中国舰船研究》杂志社一行的来访表示热烈欢迎。他说到，航海学院作为西北工业大学“三航”特色学院之一，主要从事水中兵器、水声工程、水下航行器、海洋工程等领域的科学研究和人才培养，并与《中国舰船研究》杂志社一直保持良好的合作和交流，希望后续双方加强合作，共同在舰船研究领域谋大事、干大事。
易基圣从办刊宗旨、办刊特色、期刊质量、重大活动、行业影响力等方面作了专题汇报。他谈到，西北工业大学作为《中国舰船研究》期刊编委副主任委员单位，在期刊快速发展方面做出了重要贡献，希望更多的资深教授、青年教师能加入到特约专题主编、青年编委的队伍里来，围绕学术前沿提出创新性的选题和组稿。
在交流过程中，双方围绕期刊选题与组稿、审稿专家推荐、青年编委增补、论文水平提升、影响力扩大等主题展开了深入探讨。担任青年编委的杜鹏副教授指出，《中国舰船研究》期刊在行业里知名度高、录用率高、审稿时间段、编委权益完善，为青年学者们提供了广阔的学术交流平台。赵瑞琴副教授表示，期刊专业性很强，选题与组稿很有针对性，希望双方后续能加强交流与合作。
崔荣鑫在总结发言中说到，《中国舰船研究》杂志作为行业里知名度较高的期刊，应多元化发展，加强与各单位之间合作交流，持续扩大期刊影响力；担任期刊编委的教师要认真履行自己的职责，把好审稿关。他鼓励广大师生积极投稿，不断向期刊输送高质量稿件。
此次交流活动取得了圆满成功，为我院与《中国舰船研究》杂志社之间的合作奠定了良好的基础。双方一致表示，将以此次交流为契机，持续深化合作，携手共进，为我国舰船事业的发展创造更多成果。
(审核：刘朝亚，王银涛）
