# 网络空间安全学院召开研究生导师培训会议

为进一步加强研究生导师队伍建设，夯实研究生培养过程管理，2026年10月27日下午，网络空间安全学院召开研究生导师培训会议。学院党委书记张文涛、院长王震、党委副书记杜瑶及全体研究生导师参会，会议由副院长刘志强主持。
会议围绕研究生培养关键环节开展专题培训。会议强调，导师是研究生培养的“第一责任人”，要主动构建健康和谐的导学关系，加强思想政治引领和学术发展指导，关注学生学业进展与成长需求，尊重学生、关爱学生，重视研究生心理健康状态，提升常见问题识别和沟通疏导意识。会议重申“学术规范、为人师表、正向激励”的师德师风工作主线，要求导师带头严守学术诚信底线，做到为人师表、以身作则，营造风清气正的育人环境。会议通过高校安全典型案例，对实验室安全工作提出要求，导师要切实扛起实验室安全管理责任，强化日常自查和学生安全宣传教育，同时针对学院学科特点，强调研究生培养过程中的保密意识与保密责任，把安全要求融入研究生培养全过程。会议还对研究生课程教学规范、学位论文质量把关及过程管理要点作了提醒，并结合学院数智化课程改造和面向教学靶场的课程改造工作，提醒导师主动对接前沿技术与实战需求，提升课程教学和研究生指导的实战化水平。
本次培训紧扣导师履职中的关键环节和常态要求，进一步明确了导师的岗位责任与工作重点。学院将持续完善导师培训机制，推动导师队伍建设和研究生培养质量稳步提升。
