# 【翱翔学生百家讲坛】学生党员“信仰的力量”系列微党课线上宣讲圆满结束

4月3日晚，翱翔学生百家讲坛“信仰的力量”系列微党课第四期“工大故事”以瞩目视频的形式成功举行，为本次系列微党课线上宣讲划上了圆满的句号。
在最后一期的线上微党课中，来自教育实验学院的本科生党员张晓东、外国语学院的硕士生党员吕慧玲、动力与能源学院的博士生党员李冰然分别以《西工大科大师的赤子之心》、《正初心 负使命》、《芳华筑梦 星辰引航》为题。围绕主题“工大故事”带来了精彩的微党课分享，通过讲述老一辈西工大人的故事、回忆华航西迁的历史，品读他们艰苦奋斗、不忘初心的责任与担当，激励新一代西工大人传承工大精神，做中华民族伟大复兴的践行者。
学生党员“信仰的力量”系列微党课共线上举办“爱国力行”、“峥嵘历史”、“时代传承”“工大故事”四期共十二堂课。在为期一个月的时间里，每周五晚，十二名学生党员讲师结合学习工作实际，用具有吸引力和感染力的语言和方式，讲理论、讲观点、讲故事，为大家带来有深度、有态度、有温度的微党课宣讲。参与人员累计超过1000人次。以其新颖的形式，丰富的内容受到了同学们的热烈欢迎。在防疫期间确保了思想教育不断线、不断档，满足了同学们“在家上党课”的需要。
接下来，翱翔学生百家讲坛将继续为同学们提供成长成才的“复合维生素”，欢迎同学们继续关注翱翔学生百家讲坛的其他精彩内容。
