# 迎端午 庆六一”——档案馆工会小组活动报道

初夏时节，微风轻拂。为进一步丰富单位职工的文体生活，提升全体馆员的凝聚力，增进机关部门工会小组间的交流，在端午节来临之际，档案馆工会小组联合财务处工会小组、招标与设备采购中心举办“迎端午 庆六一”亲子趣味运动会工会小组活动，大家欢聚一堂。
运动会设置了抢水瓶、旱地龙舟、你拿我放、送小青蛙回家、拔河等项目，集运动型和趣味性于一体。比赛过程中，场上洋溢着孩子的笑声、欢乐的掌声和呐喊声，热闹非凡。
运动会后，老师们即兴表演呼啦圈比赛，选手们精彩的表现，在老师和孩子们的欢声笑语，阵阵喝彩中圆满结束。
本次活动，既弘扬了中华民族的传统文化，又营造了温馨、欢乐、祥和的节日氛围，进一步丰富和活跃了职工的文化生活，同时也增强了奋战在各部门同志们之间的友谊。
