# 老新交流强能力 课堂提质育新人——体育部组织开展2025-2026学年春季学期青年教师教学能力专家评教活动

文： 霍泽图： 程丽娟、霍泽审核： 聂东风
为深入贯彻《教育强国建设规划纲要（2024—2035年）》及教育部等五部门《关于实施学生体质强健计划的意见》，全面落实《陕西省提升学生体质健康水平三年行动计划》要求，体育部于2026年5月11日至5月15日组织开展了青年教师教学能力专家评教活动。这是继去年青年教师教学观摩活动之后，体育部在教师专业成长方面的又一重要举措，旨在通过资深教师的言传身教，以提高青年教师的教育教学能力，全面提升体育育人实效。
本次评教活动面向2021年及以后入职的青年教师，覆盖篮球、排球等11类专项课程，由校级教学名师、最满意教师及教研室主任等16名资深教师组成指导小组，深入教学一线“把脉问诊”。他们围绕教学设计、课堂组织、运动密度与强度的科学设计、思政元素融入、学生参与度与体验感的提升、“总师育人文化”的落地实践等关键维度，对青年教师进行了系统的观察与诊断。课后，指导小组与青年教师面对面交流，既肯定教学亮点，也直指薄弱环节，并提出针对性改进建议，帮助青年教师明确方向；参与活动的青年教师纷纷表示评教小组的精准点拨让他们受益匪浅，不仅发现了自身在教学组织和教法运用上的盲点，更激发了创新教学形式的动力。大家表示，将认真汲取宝贵意见，持续优化课堂教学，切实提升课程育人质量。
此次评教活动是体育部提升教学质量的关键举措，也是落实“健康第一”理念、弘扬中华体育精神、践行“总师育人文化”的生动实践。体育部将继续坚持“观摩+评教”双轮驱动的教师发展模式，构建常态化的教学质量保障体系，为培养具有“总师型”人才特质的新时代高素质人才注入源源不断的体育力量。
