# 后勤部办公室完成长安校区部分给水主管道改造

为推进学校2025年“改基”专项任务落实，后勤部办公室利用暑假时间，对长安校区部分给水主管道进行了更换改造。
给水管道改造范围
本次改造的给水主管道位于长安校区巡航北路及昆仑路，承担着云天苑E座、F座，星天苑D座、G座、北餐厅等周边13栋楼宇的供水任务。近年来，该趟主管道漏水频发，每年均需进行多次抢修，严重影响供水稳定性，造成大量水资源浪费，大大增加了维护成本。
施工现场情况
为提升供水可靠性、减少水资源浪费、节省运维成本，后勤部办公室组织实施了长安校区部分给水管道改造项目。此次改造工程量大、工期紧，需在开学前完成管道更换并正常供水。施工期间，后勤部办公室严控施工质量，强化安全文明施工监管，加快推进工程进度，最终赶在8月19日完成全部管道更换并正常供水。此次改造共更换给水管道约1公里，新建阀门井61座，改造后将显著提升该区域供水可靠性，为师生创造更加安心的工作学习生活环境。
改造后路面恢复情况
后续，后勤部办公室将持续推动学校老旧水电暖基础设施改造，着力提升校园基础设施运行性能，为加快实现“127”近期目标和“天下工大、世界三航”远景目标贡献后勤力量。（撰稿人：李堃、姚冲；审稿人：韩争胜）
