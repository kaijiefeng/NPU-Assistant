# 西工大在2025(第十届)全国高等院校项目管理大赛中斩获佳绩

2025（第十届）高等院校项目管理大赛暨国际项目管理锦标赛中国赛区总决赛于5月25日在河北工业大学（线下）顺利举办。大赛前期选拔赛历时1个半月，并于5月10日由南京大学和北方工业大学（线上）顺利举行了南北区域赛选拔赛。
本赛事由中国优选法统筹法与经济数学研究会和国际项目管理协会（IPMA）联合主办，中国优选法统筹法与经济数学研究会项目管理专业委员会（PMPC）、河北工业大学（总决赛）、南京大学（南方赛区），北方工业大学（北方赛区）承办。吸引了来自北京大学、中国科学院大学、复旦大学、南京大学、北京航空航天大学、西安交通大学、北京理工大学、天津大学、厦门大学、吉林大学、西北工业大学、北京邮电大学、华东师范大学、华东理工大学、长安大学、河北工业大学、北方工业大学等200余支队伍1000余名高校师生参加，得到了各院校的高度认可和重视。
全国共58支团队成功入围全国总决赛。管理学院选派了2支本科生队和2支研究生队共16名选手参与了大赛角逐，全部进入全国总决赛，最终荣获本科生团体奖一等奖1项、二等奖1项，研究生团队奖二等奖2项，16名参赛选手荣获个人特等奖4项，一等奖3项，二等奖7项，三等奖2项，其中杨沐雨、水瑞晗同学荣获大赛本科生组个人特等奖；李进、辛旭同学荣获大赛研究生组个人特等奖；刘欣雨同学荣获大赛本科生组个人一等奖；庞继元、韩妙爽同学荣获大赛研究生组个人一等奖。黄柯鑫副教授、舒湘沅副教授等4位老师获得优秀指导教师。
大赛同期，指导教师参加了“（第五届）高等院校项目管理课程研讨会”，学院欧立雄教授为研讨会开幕致辞。
学校、学院一直高度重视该项赛事，该赛事是由挂靠学校的PMPC负责组织的全国性赛事，学校在此项赛事上已连续十届取得优异成绩，为工程管理国家一流本科专业建设提供助力。办赛以来，在学校教务部的大力支持下，管理学院积极组织开展校内选拔、组队、培训、模拟练习等比赛筹备工作，四支参赛队伍在比赛中表现出了卓越的团队协作能力和个人水平，充分展现了学院项目管理专业教育理论与实践相结合的优异成果。
