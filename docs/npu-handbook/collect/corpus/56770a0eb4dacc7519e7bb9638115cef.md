# 校医院传达学习贯彻党的二十届五中全会精神-西北工业大学医院

11月4日下午，校医院召开党总支（扩大）会议，传达学习党的二十届五中全会精神，党总支委员、各党支部书记参加会议，会议由党总支书记乔辉主持。
会议学习了《中国共产党第二十届中央委员会第五次全体会议公报》和《中共中央关于持之以恒推进全面从严治党若干重大问题的决定》，传达了学校党委理论学习中心组扩大会议关于学习贯彻党的二十届五中全会精神的部署要求。
与会人员一致认为，党的二十届五中全会是在中国共产党成立105周年、“十五五”开局起步的关键节点召开的一次十分重要的会议。全会审议通过的《决定》，深入贯彻习近平党建思想，对持之以恒推进全面从严治党作出战略部署，是推进新时代党的建设新的伟大工程的纲领性文件。全会提出的“增强党性是全面从严治党的根本性任务”，为基层党组织加强党员教育管理提供了根本遵循。
会议指出，全会专题研究部署持之以恒推进全面从严治党，彰显了党中央坚持严的基调不动摇的坚定决心。医院党组织直接面向师生和患者，作风实不实、纪律严不严，师生感受最直接，学习贯彻全会精神不能止步于会议传达、文件学习，要落到门诊窗口和诊疗服务各环节，体现在师生看病就医的体验上。
会议强调，要把党性锤炼落到日常、把严的基调落到支部、把作风建设落到服务、把管党治党责任压到人。
会议要求，以习近平党建思想引领支部建设、党员教育、作风纪律和廉洁建设，对照全会要求查摆党建短板，压实党建工作责任，推动党建与业务深度融合，守牢廉洁、安全、保密、质量四条底线，持续提升师生就医服务质效。
会议还研究了发展党员等事项。
责编 石丛艳
审核 乔辉
