# 后勤集团机关党支部与饮食服务中心党支部赴西安国家版本馆开展实践学习-后勤集团

为深入学习贯彻习近平文化思想，增强文化自觉、坚定文化自信，扎实推进树立和践行正确政绩观学习教育，5月25日，后勤集团机关党支部与饮食服务中心党支部联合组织党员赴西安国家版本馆开展实践研学活动。
西安国家版本馆是中国国家版本馆“一总三分”的重要组成部分，承担着赓续中华文脉、守护文化根脉、坚定文化自信的重要使命。在讲解员的引导下，党员们依次参观“中华文化经典版本展”“丝绸之路版本展”等展区，认真聆听讲解、驻足品读文献，从甲骨简牍、历代珍本到红色经典、时代文献，全方位感受中华文脉绵延赓续的厚重历史，深刻领略丝路文明交流互鉴的独特魅力。
通过此次实践学习，全体党员接受了一次深刻的文化熏陶和思想淬炼。党员们纷纷表示，将以此次学习为新起点，持续深学细悟习近平新时代中国特色社会主义思想，把文化自信传化为履职动力，把正确政绩观落到服务实处，以更饱满的热情、更务实的作风做好后勤保障与饮食服务工作，为学校高质量发展贡献后勤力量。（图：李昶龙文：王瑾瑶，审核：杜俊业邱若娟）
