# 关于管理类2024级学生专业确认录取结果的公示

各位同学：
根据《西北工业大学专业确认工作实施办法（2020版）》《关于2025年本科生专业确认工作安排的通知》要求，学院组织开展了2024级学生专业确认工作。按照“遵循志愿、成绩优先、计划控制”的原则，由学生自主在翱翔教务系统填报志愿，学校教务部依据学生志愿顺序、学业成绩和学院各专业接收指标，在系统进行录取，确定了录取名单，现将结果予以公示（见附件），公示期为即日起三个工作日。公示期间，若有异议，请以书面形式向专业确认工作小组反映。
