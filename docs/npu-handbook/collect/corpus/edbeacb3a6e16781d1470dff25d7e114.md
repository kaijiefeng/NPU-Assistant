# 校工会慰问动力保障中心一线职工

11月18日和20日，校工会常务副主席陈建军带队，分别在友谊校区和长安校区慰问动力保障中心一线职工。校长助理兼后勤部党工委书记、后勤部部长王宇波，以及后勤部办公室相关领导一同参加慰问。
陈建军对动力保障中心一线职工不畏严寒、恪尽职守的精神给予肯定与赞赏，对他们长期以来为学校教学、科研及师生工作学习生活所提供的基础性、关键性服务保障表示衷心感谢。他叮嘱大家，供暖工作事关全校师生切身利益，任务艰巨、责任重大，希望大家继续发扬优良作风，以饱满的精神状态投入到冬季供暖保障工作中，全力保障供暖质量，让广大师生温暖、舒心地度过寒冬季节。
此次慰问活动充分体现了校工会对一线后勤保障职工的亲切关怀，极大鼓舞了动力保障中心职工的工作热情。后续，动力保障中心将进一步细化运行管理，及时响应师生诉求，全力保障校内供暖系统安全、稳定、高效运行，同时持续协调热力公司提升热源供应，努力为全校师生提供温暖舒适的工作学习生活环境。（撰稿人：李堃；审稿人：韩争胜）
