# 学生工作

10月29日下午，计算机学院组织师生赴中国航空工业集团公司第一飞机设计研究院（简称“一飞院”）参观学习。学院党委副书记、辅导员和40余名博士研究生参加活动。

师生参观了一飞院的展览馆。一幅幅历史图片、一件件展品和一项项重大成果，生动展现了一飞院不断发展壮大的奋斗历程。尤其是飞豹飞机和大运飞机的研制故事，使同学们深切了解“飞豹精神”和“大运精神”的丰富内涵，充分感受到从“航空报国”到“航空强国”的伟大历程。

座谈会上，一飞院人力资源部人员介绍了招聘岗位、任职要求和未来发展等情况，鼓励同学们投身航空事业。同学们围绕学业发展、职业规划等方面踊跃提问。一飞院人力资源部人员一一进行解答，为同学们未来的发展提供了宝贵的建议与指导。

此次活动让同学们对航空事业有了更直观的认识。同学们纷纷表示，个人的成长只有与国家需求同频共振，才能实现真正的价值。今后，要在科研和实践中锤炼本领，为航空事业发展贡献力量。
