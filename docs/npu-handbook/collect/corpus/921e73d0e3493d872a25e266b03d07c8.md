# 后勤部办公室开展2025年全国节能宣传周和低碳日活动

6月23日至29日是全国节能宣传周，活动主题是“节能增效，焕‘新’引领”。6月25日是全国低碳日，活动主题是“碳路先锋、绿动未来”。为深入贯彻落实国家“双碳”战略目标，增强师生节能环保意识，建设节能低碳、绿色环保的校园，后勤部办公室于6月26日上午在长安校区开展了废旧物品兑换绿植活动。
活动现场，师生携带报纸、纸箱、空瓶子等可回收利用的废旧物品积极兑换绿植，广大师生踊跃参与，纷纷在签名墙上签字署名，争当节能低碳的宣传者和践行者。
此次宣传活动有效提升了广大师生的节能低碳意识。后续，后勤部办公室将结合上级部门有关要求，持续深入开展节能宣传工作，为建设低碳校园、降低校园能耗贡献力量。（撰稿人：张偲偲；审稿人：韩争胜）
