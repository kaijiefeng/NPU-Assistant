# 西工大召开2026年本科招生工作总结暨表彰大会-

9月30日，我校召开2026年本科招生工作总结暨表彰大会。校长宋保维出席并讲话，常务副校长张艳宁参加。招生委员会成员单位、相关职能部门负责人，各学院领导及分管招生工作的负责人、招生组长、骨干教师，2026年度本科招生工作先进集体和先进个人代表，校友代表等共计200余人参加大会。大会由副校长岳晓奎主持。
宋保维向受表彰的先进集体和个人表示热烈的祝贺，向奋斗在招生工作一线的全体师生以及长期以来关心支持学校招生工作的广大家长、校友表示衷心的感谢，并对2026年本科招生工作取得的成绩给予充分肯定。他指出，习近平总书记强调：“建设一流大学，关键是要不断提高人才培养质量”，学校党委高度重视招生工作，第十四次党代会明确提出大力推进“总师型”人才培养，将招生工作作为人才培养的首要环节。立足学校国防军工办学使命，招生工作面临的形势更加复杂、任务更加艰巨。从职责使命看，战略需求导向更加鲜明，作为“国防七子”高校，必须深耕国防领域特殊阵地，坚守“为党育人、为国育才”初心使命，把招生工作放在强国强军大局中谋划，源源不断为国家输送“总师型”人才。从人才培养看，价值塑造导向更加突出，要引导广大优秀学子把个人理想、职业规划主动融入强国建设大局，在实践中实现人生价值。从机遇挑战看，动态调整导向更加紧迫，以人工智能为代表的新一轮科技革命深刻改变着选才育才的逻辑，要深化学科专业内涵建设，持续优化学科专业设置、招生政策设计、宣传方式方法等，全方位提升人才培养与选拔质量。
宋保维就进一步推动本科招生工作提出三点要求：一是深化学科专业调整优化，以专业结构升级促进生源质量提升。要围绕国家战略与新兴赛道，超前布局符合学校发展定位的新专业，推动招生专业目录与产业升级、考生需求同频迭代；要健全低效专业退出机制，以“毕业率、深造率、调剂率、转专业率”4项核心指标为关键判断依据，健全“新增—预警—停招—复招/撤销”本科专业动态调整机制，持续推动本科专业布局动态优化。二是建强招生队伍、创新宣传方式，以精准赋能提升宣传转化效能。各学院院长、书记要持续带头深入招生一线，充分调动优秀师生的示范带动作用；要创新宣传方式方法，进一步发挥新时代下网络新媒体的宣传作用，讲深讲透专业特色；要积极发挥杰出校友、热心家长、学生大使等队伍力量，推动宣传从“单向输出”向“双向奔赴”转变。三是优化招生考核评价体系，以制度激励激发全员招生活力。各部门要强化政策协同联动，健全量化考核机制，把招生成效作为重要参考纳入岗位评价和职称评聘考核范围；要动态调整招生队伍，把最能讲、最懂行、最有热情的同志派到招生一线，真正提高招生质量；要持续关注优秀生源入校后的成长发展，做到招进来、培养好、发展好，以人才培养质量反哺招生工作，形成“招生—培养—就业—发展”良性循环。
教务部部长王海鹏宣读了2026年本科招生工作先进集体和先进个人获奖名单。招生办公室主任王克勤作2026年本科招生工作总结汇报。
获奖代表电子信息学院党委书记侯俊、化学与化工学院副院长田威、航天学院辽宁招生组组长张研分别结合本单位工作实际，分享了招生工作体会和经验。大家一致表示，将继续立足“三航”特色学科优势，发扬“六皮作风”把本科招生工作做实做细，让更多优秀学子在西工大成才圆梦，为学校“总师型”人才培养筑牢优质生源根基。
宋保维为获得“先进集体一等奖”的集体代表颁奖。
张艳宁为获得“招生领航人”的代表颁奖。
岳晓奎为获得“先进集体二等奖”“先进集体优秀奖”“招生先锋奖”和“优秀招生大使”的集体和个人代表颁奖。
