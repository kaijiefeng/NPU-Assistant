# 后勤办公室召开学校各业主单位代表座谈会

后勤办公室在组织2017年校园物业服务契约化考核工作中，依据考核工作方案，在友谊校区和长安校区分别召开了各业主单位代表交流座谈会，拓宽渠道，广泛听取业主单位代表对校园后勤物业服务工作状况的意见和建议，以此促进后勤服务保障工作的开展。11月27日至29日后勤办公室在友谊校区学校办公楼A座327会议室和长安校区数字化大楼第一会议室分别召开了后勤服务工作沟通交流座谈会。参加座谈会的领导有：后勤办公室主任赵刚、副主任霍国元、李晗；后勤办科室负责人、管理人员以及来自于党委组织部、宣传部、人事处、发展规划处、航空学院、动力与能源学院等党群部门、学院和职能部门代表共53人参加本次座谈会。
座谈会由后勤办公室主任赵刚主持。赵主任首先介绍了后勤办公室承担着后勤综合改革方案规划论证、校园物业服务工作监管、考核、校园零星维修和自然灾害防治等项工作职能；其次，霍国元副主任介绍了开展校园物业服务监督考核工作总体情况；李晗副主任介绍了校园零星维修工作总体情况。最后，各业主单位代表们踊跃发言，大家对后勤办公室一年来开展工作给予充分肯定，分别将本单位收集整理的师生员工意见和建议进行了交流。就校园后勤物业服务标准、校园环境卫生、水电设备报修维修、校内维修界面确定等方面提出了许多意见和建议。后勤办公室领导与代表们进行了相互沟通、解释和交流。后勤办公室对于各单位提出的意见和建议，下一步要认真梳理，分类，提出整改措施，通过不懈的努力尽快解决，共创和谐美好的校园环境。
随后，后勤办公室向各业主单位代表发放了《2017年校园物业服务契约化考核打分表》，要求各单位代表在充分征求本单位师生员工意见和建议的基础上，填好打分表，并在考核大会上提交。
