# 白俄罗斯政府科技代表团一行来校访问

10月26日，白俄罗斯政府科技代表团一行来校访问。校党委书记张云明，白俄罗斯国家科学技术委员会（以下简称“白科委”）主席科尔日茨基、白俄罗斯国家科学院（以下简称“白科院”）主席团主席卡拉尼克出席会议并讲话。白俄罗斯驻华大使切尔维亚科夫参加活动。副校长岳晓奎主持座谈会。
张云明代表学校向与会嘉宾表示热烈欢迎，向白科委对白俄罗斯国家科学院中国分院（以下简称“白科院中国分院”）建设的支持表示感谢。他指出，今年6月，习近平总书记在会见白俄罗斯总统卢卡申科时，就新形势下发展中白关系作出重要论述，两国元首就深化各领域务实合作达成重要共识。在两国元首战略引领下，中白政治互信持续深化，高质量共建“一带一路”成果丰硕，重点合作项目扎实推进，多边协作富有成效，白科院中国分院迎来了新的历史性发展机遇。此次座谈既是落实两国元首重要共识、深化双边科技合作的务实对话，也是中白老友重逢、共商白科院中国分院高质量发展的重要契机。
张云明强调，西工大在先进材料、智能制造、无人系统、海洋工程等方向拥有雄厚科研实力，为工程科技和国民经济建设输送了大批优秀人才。白科委是双边合作发展的重要支撑，白科院在基础科学、空天、光电与先进材料等领域优势显著。双方团队高效协同，搭建中白专家常态化交流机制，拓展一系列科研合作项目，巩固白科院中国分院实体化运行，开启科研成果转化新篇章，正以实际行动为中白全天候全面战略伙伴关系注入科技新动能。
为更高标准更高质量建好白科院中国分院，张云明提出三点建议：一是服务中白全天候全面战略伙伴关系大局，在合作模式创新、卓越人才培养和人文交流深化上展现更大作为。二是整合西工大和白科院科研平台、骨干团队优势资源，以高水平科技开放合作催生高质量科研成果，推动中白政府间科技合作走深走实。三是畅通产学研协同创新链条，积极推动前沿技术成果落地转化，持续打造中白合作新亮点，为高质量共建“一带一路”、推动构建人类命运共同体作出新的更大贡献。
科尔日茨基表示，白科院中国分院是白科院在境外创建的唯一分院，是中白深化务实合作的里程碑，对落实两国元首重要共识，推动双方教育科技人才合作向更深层次、更宽领域迈进具有重要意义。白科委将进一步加大支持力度，深化项目合作，推动白科院中国分院建设不断取得新成果，助力双方合作迈上新台阶，推动中白关系在高水平上持续向前发展。
卡拉尼克向西工大和白科委对推动白科院中国分院落地所付出的努力表示感谢。他说，白科院中国分院的建设受到两国政府的高度关注与大力支持，各项工作稳步推进，已取得积极进展和显著成效。白科院和西工大合作基础扎实、势头良好，希望双方持续完善项目推进和责任落实机制，在科技、教育等领域开展更多实质性合作，推动产学研用协同创新，取得更多标志性、示范性成果。
双方围绕科研平台共建、科技成果转化和企业项目合作等议题深入交流研讨。
张云明向科尔日茨基、卡拉尼克和切尔维亚科夫赠送纪念品。
座谈会前，白俄罗斯政府科技代表团一行参观了科技成果转化展厅和白科院中国分院。
白俄罗斯政府科技代表团成员，学校相关职能部门、学院主要负责人等参加座谈会。
