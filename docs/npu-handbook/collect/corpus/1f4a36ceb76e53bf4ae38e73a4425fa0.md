# 强科研规范，守安全保密——航海学院召开2026年度科研工作警示教育大会

为进一步规范科研行为，强化学术道德建设，压实实验室安全管理责任，严守招投标工作底线，筑牢科研保密防线，切实防范科研领域各类风险，9月6日，我院组织召开2026年度科研工作警示教育大会，学院100余名教师和科研管理人员参加了会议。会议由崔荣鑫副院长主持。
崔荣鑫带领与会人员集中学习了学校科研项目投标管理办法、科研诚信管理相关规定，深入解读学术不端行为界定、调查处理等政策要求，通报了学术不端典型案例，以案示警、以案明纪，引导全体科研人员筑牢法律红线，坚守学术底线，恪守科研道德，自觉抵制各类学术失范行为，树立求真务实的科研作风。
针对实验室日常管理中的重点风险隐患，崔荣鑫对实验操作规范、危化品存储使用、设备运维、应急处置等工作进行再部署再强调，要求各团队落实安全主体责任，常态化开展隐患自查，把安全要求贯穿科研实验全过程。
崔荣鑫传达了科研保密相关工作要求，重点围绕涉密项目管理、设备操作、信息传输、载体移交与销毁等关键环节开展警示教育，明确科研保密纪律，提醒科研人员绷紧保密之弦，严防失泄密事件发生。
他指出，科研诚信、实验室安全、保密工作是科研工作的底线和生命线，三者相辅相成、缺一不可。全体科研人员要提高思想认识，强化责任担当，做到知规矩、守底线、明责任。各团队要切实履行“第一责任人”职责，将学术规范、安全管理、保密要求融入日常科研管理，做到警钟长鸣、常抓不懈。
下一步，学院将持续健全长效管理机制，常态化开展科研诚信宣教、实验室安全检查和保密自查工作，多措并举夯实科研管理基础，营造风清气正、安全有序的科研环境，保障学院各项科研工作高质量开展。
