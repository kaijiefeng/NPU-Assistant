# 关于开展2020年校级教育教学改革研究项目结题验收工作的通知

各相关单位：
为进一步做好学校教育教学改革研究项目的管理工作，不断培育优秀教育教学成果，持续提高教育教学质量，根据《西北工业大学教育教学改革研究项目管理办法》（教字〔2020〕56号）、《关于公布2020年度校级教育教学改革研究项目立项名单的通知》（教字〔2020〕58号）文件要求，学校对2020年立项的校级教育教学改革研究项目进行了中期检查，组织专家对项目中期材料进行评审，各项目均通过中期检查。同时，学校将评审意见反馈给学院和项目负责人，督促各项目按时完成相关研究。学校现决定对2020年立项的校级教育教学改革研究项目进行结题验收，现将有关事宜通知如下：
一、验收范围
2020年立项的80个校级教育教学改革研究项目，其中，重点项目20项、一般项目60项（见附件1）。
二、验收材料要求
1．请各项目负责人认真填写《西北工业大学教育教学改革研究项目结题验收报告》（见附件2），并将研究成果、项目总结报告、实践效果评议材料及其它有关材料附后，所提交材料不能涉及保密内容。
2．提交结题报告的同时请提交项目申请书和中期检查报告。
三、项目延期申请
不能按期完成的研究项目，需由项目负责人以书面形式提交延期申请，详细说明延期原因，由所在单位教学负责人审核并签署意见，经学校研究同意后方可延期，延期期限不得超过1年。
请各项目负责人按照项目申请书要求，做好结题验收工作，并于2021年3月26日前将结题验收材料纸质版（一式一份）及电子版提交至教务处教学规划与管理办公室。
