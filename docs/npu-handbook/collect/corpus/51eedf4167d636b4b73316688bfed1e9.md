# 陕闽光学学会来院开展光电领域产学研合作暨联合党建交流活动

2026年10月19日，陕西省光学学会、福建省光学学会联合赴物理科学与技术学院，开展光电领域产学研合作暨联合党建交流活动。福建省光学学会会长谭小地、陕西省光学学会秘书长佘江波带队，我院教师、陕西省光学学会副理事长杨德兴教授及相关团队成员陪同，来自两个单位的专家、教授及企业代表共32人参加，先后实地参观了我院光电平台、重点实验室及学校军工素质教育基地。
交流会上，陕西省光信息技术重点实验室主任毛东教授介绍了光电学科发展概况，重点汇报了实验室在科学研究、平台建设和人才培养等方面取得的成果。谭小地对实验室建设成效予以充分肯定，并就深化产学研合作表达了积极意向。
在学校军工素质教育基地，与会人员通过实物重器沉浸式学习，深刻感悟军工报国精神，全面了解学校“三航”科研与平台资源优势，进一步拓宽产学研协同创新思路，借鉴重大装备研制的系统方法与协同机制赋能科研创新，增强了服务高水平科技自立自强的使命感。
此次交流活动搭建起陕闽两地光电领域沟通合作的桥梁，以党建引领产学研深度融合，为后续跨区域联合攻关、成果转化与人才交流合作奠定了良好基础。下一步，学院将持续用好本次交流成果，坚持党建与科研业务同谋划、同推进，常态化推进陕闽两地光电领域互访对接；围绕光电前沿方向共建联合研究载体，梳理关键技术清单，组织跨区域联合攻关；打通成果转化协同渠道，推动实验室技术落地应用；深化人才双向交流，开展联合培养、学术研讨与青年骨干互访；积极探索党建联建新机制，以党建聚合力、促创新，持续放大跨区域协同创新效能，助力学院高质量发展。
