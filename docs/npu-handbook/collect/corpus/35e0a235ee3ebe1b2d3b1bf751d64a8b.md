# 力学与土木建筑学院举办青年教师发展论坛—学术沙龙第六讲

2022年12月7日下午，力学与土木建筑学院青年教师发展论坛——学术沙龙第六讲，在学院楼206会议室和线上腾讯会议室召开。本次青年教师发展中心邀请上海交通大学航空航天学院副院长、“中国高被引学者”、教育部学术新人奖及John H.S. Lee青年学者奖（国内唯一）获得者张博教授，做题为“爆轰波起爆诱导机制及传播激励方法的研究”的讲座。本次报告同时在人事处“筑梦三航”青年教师沙龙平台发布，线上和线下共180余名师生参加了此次学术研讨活动。
张博教授从激波聚焦和横向射流诱导爆轰起爆两个方面介绍了其团队最新的研究成果，并对气相爆轰未来研究方向给出了重要建议。讲座后青年教师及同学针对张博教授讲座内容进行研讨交流，张博教授对相关问题给与细心的解答。
学院青年教师发展中心致力于通过定期的学术沙龙活动为广大研究学者搭建科研学术交流平台，积极营造交叉、创新、融合、互鉴的学术氛围，为高层次人才培养和高水平科研成果产出提供有力支撑。
