# 西北工业大学莫航学院关于征集院徽设计方案的通知

为更好地彰显学院文化底蕴、办学特色和治学精神，进一步增强我院师生荣誉感、使命感和自豪感，现开启活动主题为“莫问前程·航启新章”莫航学院院徽设计征集大赛，具体事宜如下。
一、征集内容
西北工业大学莫航学院院徽
二、征集对象
西北工业大学莫航学院全体师生。可选择个人或团队（宿舍或自组队，不超过四人，鼓励跨班级组队）形式参赛。
三、征集时间即日起至2025年9月15日止
四、作品要求
（一）整体设计能够彰显学院专业特色及中外合作办学特色，展现学院师生“天下工大 世界三航”的精神风貌和价值追求；
（二）设计要主题鲜明，寓意深刻、简洁精巧、色彩明快、易于识别与传播；
（三）院徽是图形标志加学院中文名称和俄文简称的组合。
五、相关说明
（一）学院中文名称：西北工业大学莫航学院
（二）学院俄文名称：Совместный институт Северо-западного политехнического университета и Московского авиационного института
（三）学院俄文简称：Совместный институт СЗПУ-МАИ
（四）可结合西北工业大学、莫斯科航空学院校徽元素，可融入具有学院象征意义的图形、符号或抽象元素（如：天空、航空航天学科符号等）。
（五）色彩不超过2种，可以校徽蓝作为参考颜色（https://news.nwpu.edu.cn/xcb/index/xxsbxt.htm）。
六、投稿须知
（一）作品格式
设计作品请以jpg或png格式提交（分辨率不低于600 dpi，画布尺寸应为15 cm*15 cm），请设计者保留高精度的设计原图（如.ai,.cdr,.psd等），包括各种矢量图形、源文件和所用到的字体。
（二）投稿时间
投稿人请于2025年9月15日17:00前将设计稿及《莫航学院院徽设计征集表》（附件1）发送至x_wensi@nwpu.edu.cn，投稿作品邮件名格式：“院徽设计+设计者姓名/团队名称”，逾期视为无效。
（三）版权协定
1.作品必须为参赛者原创，严禁抄袭、剽窃他人作品，如涉及侵权，责任自负，并取消参赛资格；
2. 学院拥有所有获奖作品的著作权、修改权和使用权，可根据需要进行修改、深化设计、宣传展示和使用。
3.在作品公示后，学院将根据投稿人联系方式与投稿人取得联系并完成后续事宜。未录用作品学院不再通知。
七、评审与表彰
（一）评审方式
由学院组织成立评审小组，对应征作品进行评审。结果将在学院官网予以公布。
（二）奖项设置
1. 设置最佳设计奖1名、杰出入围奖3名、优秀设计奖5名、最佳人气奖1名、优秀组织班级奖3个。
2. 最佳设计奖作品将被重点推荐作为学院官方院徽候选方案，并有机会被实际采用（采用后学院享有完全知识产权），其他参赛作品的设计元素将有机会被实际参考采用（采用后学院享有完全知识产权）。
3. 最佳设计奖奖励2000元，杰出入围奖奖励1500元、优秀设计奖奖励500元、最佳人气奖奖励1500元；所有奖项均颁发荣誉证书。
4. 优秀组织班级奖奖励2000元并颁发奖杯，表彰在宣传动员、作品数量与质量方面表现突出的新生班级。
联系人：邢老师
