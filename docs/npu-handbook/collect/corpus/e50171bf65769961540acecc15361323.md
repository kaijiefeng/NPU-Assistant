# 中国共产党西北工业大学化学与化工学院第二次代表大会胜利召开

2026年11月5日下午，中国共产党西北工业大学化学与化工学院第二次代表大会在学院报告厅隆重召开。本次大会是在深入学习贯彻党的二十大和二十届历次全会精神、习近平总书记关于教育科技人才一体化发展、加强基础研究的重要论述和对国防军工高校重要指示批示精神，全面落实学校第十四次党代会部署要求，奋力开启“十五五”事业发展新征程的关键时期，召开的一次重要会议。学校党委副书记杨晓，党委组织部副部长、党校副校长林欢欢出席会议，化学与化工学院师生党员代表参加会议，学院党外人士代表列席会议。大会由院长顾军渭主持。
大会在庄严雄壮的国歌声中开幕。
傅茂森同志代表学院第一届党委向大会作题为《同心笃行担使命，聚力攻坚创一流—奋力谱写化学与化工学院发展新篇章》的工作报告。报告全面回顾了学院在学校党委的坚强领导和上届学院党委领导班子团结协作、狠抓落实，以及全院师生合力奋进、攻坚克难下在党的建设、人才培养、学科建设、科学研究等方面取得的丰硕成果，深刻剖析了制约学院发展的短板弱项，擘画了学院未来发展的宏伟蓝图，规划了2030年和2035年的发展目标，并明确了重点任务和具体落实举措。
姚东东同志作化学与化工学院第一届党委党费收缴、使用和管理情况报告。
大会审议并通过学院党委工作报告，党费收缴、使用和管理情况报告，表决通过大会选举办法，推选并通过监票人，宣布计票人名单。
林欢欢宣读了学校党委《关于同意中共西北工业大学化学与化工学院第二届委员会委员候选人预备人选的批复》。
总监票人郑亚萍同志主持大会选举环节，在监票人、计票人的监督下，全体党员代表以无记名投票方式，选举产生了中共西北工业大学化学与化工学院第二届委员会委员。
杨晓代表学校党委向大会的顺利召开表示热烈祝贺，对学院团结进取开拓的良好发展局面给予充分肯定，并对学院未来工作提出要求。他指出：一是把牢政治方向，筑牢办学治院根基。要持续深学细悟习近平新时代中国特色社会主义思想和党的二十届五中全会精神，压紧管党治党责任，抓实领导班子自身建设，健全党组织工作体系，切实把党的领导贯穿办学治院全过程，以高质量党建引领学院事业发展。二是胸怀国之大者，践行军工报国使命。要立足国防军工重大需求，聚焦先进新材料等领域攻坚关键科学难题，营造鼓励探索、宽容失败的科研生态，力争产出更多“从0到1”的原创突破，助力国家高水平科技自立自强。三是聚力交叉赋能，重塑科研育人范式。要紧扣“人工智能+教育”部署，推动人工智能赋能基础研究，深耕学科真实应用场景，探索契合学院发展实际的数智化基础研究与育人路径。
在《国际歌》中，大会圆满完成各项议程，胜利闭幕。
会后，新当选委员召开了中国共产党西北工业大学化学与化工学院第二届委员会第一次全体会议。会议选举产生了党委书记、副书记，明确了委员工作分工。
踔厉奋发启新程，笃行实干担大任。化学与化工学院将坚持以习近平新时代中国特色社会主义思想为指导，在学校党委坚强领导下，立足国防军工重大需求和学院基础研究特色优势，凝心聚力担使命，守正创新谋突破，奋力推进学院高质量内涵式发展，为学校建设中国特色世界一流大学，为强国建设、民族复兴伟业贡献更大力量！
