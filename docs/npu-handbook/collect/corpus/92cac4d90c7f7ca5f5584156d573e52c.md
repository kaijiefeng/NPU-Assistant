# 西北工业大学网络空间安全学院开题答辩（李彤）

西北工业大学网络空间安全学院开题答辩（李彤）
一、开题答辩题目：基于强化学习的多智能体协作行为研究
二、开题答辩人：李彤
三、开题答辩时间：2025年1月20日上午10：00
四、开题答辩地点：毅字楼606
五、开题内容简介：
本研究聚焦于多智能体强化学习（MARL）中的协作行为优化，旨在解决智能体协作中的关键技术问题，如行为多样性、策略泛化与复杂任务的解耦优化。研究将从理论模型和实验验证两个角度出发，探索如何平衡个体策略与整体协作目标，提高智能体在多变环境中的适应性和协作效率。核心研究内容包括：一是通过技能学习和无监督方法提升智能体行为的多样性，二是通过深度学习等方法增强智能体策略的泛化能力，三是通过分层强化学习框架优化复杂多阶段任务中的协作与决策。此外，将采用深度学习、博弈论及优化理论等多学科理论方法，通过仿真模拟与实验验证，不断优化多智能体系统中的协作机制，以期为智能交通、智能制造等实际应用提供理论支持和技术指导。
六、开题答辩人简介
李彤，学号2022100378，1997年1月生，网络空间安全专业，师从杨黎斌教授，主要从事于多智能体强化学习方面的研究。
