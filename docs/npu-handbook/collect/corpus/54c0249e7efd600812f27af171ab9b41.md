# 学院举办2026年第一期入党积极分子培训班

为严把党员发展“入口关”，强化入党积极分子理论素养与党性教育，近日，教育实验学院/未来技术学院2026年第一期入党积极分子培训班顺利举行，学院94名入党积极分子全员参训。
本期培训延续“金色课堂、红色课堂、蓝色课堂”三大模块，采取“专题授课+线上党课+交流研讨”模式，推动理论学习入脑入心、实践体悟走深走实。
专题授课环节，学院党委书记牟蕾以《树立和践行正确政绩观，争做为国铸剑、挺膺担当的时代新人》为题，结合学校“总师育人文化”特质与学院拔尖人才培养实践，引导学员筑牢思想根基、践行正确价值导向，在学习科研一线发挥先锋模范作用；贺苗教授围绕《以正确政绩观书写中国式现代化新答卷》，从政绩观的内涵要义切入，阐释青年党员如何在基层与实践中学思践悟；蒲瑶教授以《新时代中国青年的精神特质与使命担当》为题，立足中华文明历史根基与当代青年成长语境，引导学员校准人生坐标、勇担时代使命；高旭红教授作《深入学习贯彻“十五五”规划》专题讲座，系统梳理“十五五”时期发展主线与战略部署，帮助学员从宏观视野理解党和国家事业前进方向。
线上党课环节，组织集中观看学校原创话剧《大国之蓝》，在深海守望、为国铸剑的故事中厚植家国情怀。交流研讨环节，围绕“如何将正确政绩观融入青春奋斗中”展开分组讨论，学员们结合课程体会积极发言、交流提升。后续，全体学员还将赴延安等地实践研学，传承红色基因，强化使命担当。
学院将持续优化入党积极分子课程安排，以“好课程、强实践、多研讨”做实党员发展源头培养，助力同学们在思想上先入党、在行动上作表率。
