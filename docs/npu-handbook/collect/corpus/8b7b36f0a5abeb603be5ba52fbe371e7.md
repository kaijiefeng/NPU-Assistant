# 聚成长| 学院2026级新生开展校史校情知识竞赛

为做实做深校史校情教育，教育实验学院/未来技术学院/学科交叉中心于10月15日，在校史校情专题讲座结束后组织开展校史校情知识竞赛，本次活动由胡茗涵同学主持，以“以赛促学、悟史砺行”的学习实践形式，引导2026级参会新生深学细悟校史内涵。
活动分为热身导学与校史知识竞答两个环节。开场设置互动导学环节，分批次邀请现场同学参与问答互动，在双向交流的氛围中调动同学们的学习积极性。
随后正式开展校史知识竞答，竞赛题目围绕本次校史校情内容设置。现场秩序井然，同学们踊跃作答，学习氛围浓厚。
本次校史校情知识竞赛是专题校史教育的重要延伸，以赛促学的实践载体，帮助新生夯实校史知识基础、深化文化认同，进一步丰富了新生入学教育的开展形式，为学院传承红色办学基因、做好青年思想引领工作积蓄力量。
