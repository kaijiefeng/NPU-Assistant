# 航空学院-西北工业大学医院

责任医师：王利（副主任医师）
简介：
副主任医师，硕士研究生，专业:呼吸内科，毕业于山东第一医科大学，西安市医学会呼吸结核病学分会委员，于三甲医院工作10余年，在华中科技大学同济医学院附属同济医院呼吸内科进修学习，多次在陕西省人民医院进修学习，擅长呼吸内科常见病、多发病的诊治及各项检查操作。在核心期刊发表论文数篇，获科学技术奖2项。
（备注：学院责任医师是医院与学院之间的桥梁，可为我校师生提供健康咨询、健康宣教、体检结果释疑、急救知识技能培训等服务。有需求者，可通过扫描学院责任医师二维码联系。）
