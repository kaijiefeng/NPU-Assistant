# 航天学院研究生会热议两会：聚力“十五五”，逐梦航天强国

2026年3月4日至5日，全国两会在北京召开。值此盛会之际，航天学院研究生会于3月26日在航天学院370会议室开展了两会要点解读学习会，会议围绕国家科技战略创新、新时代高质量发展、就业政策和与研究生生活等议题展开热烈讨论。航天学院研究生会全体成员参加本次活动，会议由院研究生会主席团成员耿浩华主持。
2024级硕士研究生吕行：
站在“十五五”开局之年的新起点上，更加深刻地感受到国家发展进入关键跃升阶段。新一轮科技革命与产业变革加速演进，人工智能等前沿技术正重塑科研范式与产业格局。在这一背景下，青年科研工作者应强化问题导向与前瞻布局，将基础研究与国家重大战略需求紧密结合，在关键核心技术领域持续突破，以高水平创新成果支撑高质量发展。在今后的学习科研中，我将聚焦前沿方向深化理论积累，强化交叉融合研究能力，力求在关键问题上实现实质性创新突破。
2025级硕士研究生王锘祎：
“十五五”时期是我国加快实现高水平科技自立自强的重要阶段，航空航天与绿色能源等领域迎来新的发展机遇。面对更加复杂的国际竞争环境，青年一代既要夯实理论基础，又要提升工程实践能力，在关键系统研发与技术攻关中实现从“跟跑”向“并跑、领跑”的转变，以实际行动服务国家重大战略需求。下一阶段，我将以工程需求为牵引深化专业研究，强化实践训练与系统思维，提升解决复杂工程问题的综合能力。
2025级硕士研究生林天宇：
“十五五”开局为航天事业发展指明了新的方向，也对青年学子提出了更高要求。围绕航天强国建设，应加快推动智能化、体系化发展路径，将先进信息技术与航天工程深度融合，不断拓展航天技术服务经济社会发展的能力边界。未来将以更加坚定的责任意识投身科研实践，在服务国家战略中实现个人价值，与时代同频共振。在具体行动上，我将立足航天智能化方向，持续推进理论与工程应用结合，提升科研成果的实际转化能力。
研途漫漫，使命在肩。通过本次“两会精神”专题学习，航天学院研究生对国家发展战略与时代使命的理解进一步深化，并逐步将其内化为指导学习科研的重要遵循。学院研究生会将以此次学习活动为契机，持续强化思想引领与价值塑造，发挥示范带动作用，引导广大同学夯实理论根基、提升创新能力，自觉将个人发展融入国家重大战略需求之中，在关键领域与前沿方向主动作为，以扎实学识与创新实践回应时代召唤，在推进高水平科技自立自强的进程中贡献青春力量。
