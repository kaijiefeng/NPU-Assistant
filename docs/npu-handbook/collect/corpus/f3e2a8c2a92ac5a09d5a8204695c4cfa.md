# 全院教职工大会顺利召开

9月18日上午，西工大宁波研究院教职工大会在研究院展厅召开。
大会伊始，大家共同观看《习近平的教师情》，深刻感悟习近平总书记对教师队伍的殷切关怀和期望，进一步牢固树立“立德树人、教书育人”的初心使命。
在专题学习环节，大家一起共同学习了正确政绩观、保密教育、安全生产、意识形态等相关专题，引导教职工牢固树立和践行正确政绩观，严守纪律规矩、强化责任担当，把精力投入到教学科研和研究院高质量发展中去；同时，提醒全体教职工时刻绷紧保密之弦，严格遵守保密纪律，做到知密于心、守密于行。在安全生产方面，要始终把安全放在首位，压实安全责任，防范各类安全事故发生。在意识形态方面，强调了守好阵地，不断增强政治敏锐性和政治鉴别力。
进入导师聘任环节，研究院智能芯片团队严宇超副研究员、赵建村副研究员被聘任为西北工业大学机械工程学科硕士生导师。赵建村作为导师代表分享了受聘感受与今后工作展望。
最后，徐伟侠副院长围绕研究院发展、教职工关怀等方面与大家进行了交流，并就师德师风、意识形态、安全生产、保密教育、安全出行、为民办实事等工作进行了部署。希望全体教职工提高认识、协同落实，以“做好了才算做”的标准推进研究院高质量发展。
