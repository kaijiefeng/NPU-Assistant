# 关于友谊校区西村5号楼南侧求实路井盖更换施工的通知

友谊校区师生、住户：
为解决求实路部分污水井盖塌陷问题，保障井盖正常使用，后勤部办公室计划于9月25日（周五）10时至16时对西村5号楼南侧求实路3个污水井盖进行更换施工。
施工期间不封闭道路，仅单侧局部占道，将在施工点位设置防撞锥桶、警示标志等安全防护设施，确保作业区域安全。请过往车辆及行人经过施工路段时注意观察、减速慢行，避让施工点位警示设施，确保交通安全。
因此次施工带来的不便，敬请理解与配合！
特此通知。
后勤部办公室
2026年9月24日
