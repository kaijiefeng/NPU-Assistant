# 【关工委工作】“龙舟传文脉，童心向深蓝”海洋国防启蒙活动在校举办

6月18日下午，由校关工委、幼儿园主办，航海学院关工委、团委承办的“龙舟传文脉，童心向深蓝”海洋国防启蒙主题活动在幼儿园举行。航海学院关工委副主任、原航海学院院长黄建国教授，“筑梦深蓝”航海知识科普队大学生志愿者及幼儿园小朋友共同参与。
活动现场，科普队队员以一场“海洋大冒险”带领小朋友们走进奇妙的航海世界。从端午龙舟文化到远洋大船，从潜水艇到仿生机器魔鬼鱼，队员们通俗易懂地讲述了船舶与海洋装备的发展历程，并巧妙引入西北工业大学的科研故事，鼓励孩子们从小立志做勇敢的海洋探索者。
黄建国教授结合实物，用游泳体验作比讲解浮力原理，将深奥知识化为童言妙语；又生动讲述福建舰、驱逐舰的保家卫国使命，在孩子们心中悄然播下向海图强的种子。
大手牵小手，深蓝启童智。黄建国教授与大学生志愿者带领孩子们拼装小帆船模型，孩子们兴致勃勃地在水中试航，大学生志愿者展示的潜水器、明轮船、蒸汽船等实物模型，更让孩子们目不转睛，尽情领略航海科技的奇妙与魅力。
此次活动将端午节传统文化与海洋国防教育有机融合，以寓教于乐的方式在幼小心灵中点亮科技强国之光，是校关工委落实立德树人根本任务、发挥“五老”育人作用的生动实践。未来，校关工委将继续发挥学校学科专业优势，持续开展面向青少年儿童的科普教育活动，让爱国情怀与强国梦想在孩子们心中生根发芽。
