# 关于2026-2027学年秋季学期2026届本科结业生申请毕业工作的通知

各学院：
根据学校本科结业生申请毕业工作安排，现启动2026-2027学年秋季学期2026届本科结业生申请毕业工作，具体事项通知如下：
一、工作要求
请各学院认真审查本学院所有结业生的不合格课程（包括毕业设计/论文等），如有已考未录入成绩的课程，请尽快督促完成成绩录入，以免影响此次工作的顺利开展。
二、时间安排
本次结业申请毕业材料报送截止时间为11月13日（星期五）中午12:00。
三、材料提交
请各学院一对一通知此次符合毕业要求的学生及时填写《西北工业大学毕业生领取证书申请表》（附件1），并对学生提交的表格进行审核，无误后将本学院《2026-2027学年秋季学期2026届本科结业生申请毕业名单》（附件2，签字盖章纸质版和电子版）及所有符合毕业要求的结业生提交的《西北工业大学毕业生领取证书申请表》（附件1，签字盖章纸质版和电子版扫描件）、成绩单（荧光笔或红笔标记出此次通过课程）和2张小二寸照片（此照片需与学信网照片保持一致），按时提交至教务部学籍学位办公室。
请各学院务必做到此次审核不漏一人、按照时间节点精准报送相关材料，并请各学院教学负责人做好复查、督查，以免造成漏报、错报等情况出现！
