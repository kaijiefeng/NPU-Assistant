# 西北工业大学材料学院特种功能材料团队非事业编招聘启事

西北工业大学材料学院特种功能材料团队因工作需要，现面向社会公开招聘非事业编制人员2名，具体要求如下：
一、岗位名称
科研助理
二、岗位职责
1.参与科研项目的申请、立项、审计，验收等管理工作；
2.撰写相关技术文档，参与项目阶段性汇报与成果总结；
3完成团队其他工作内容。
三、应聘条件
1.坚决拥护党和国家的路线、方针、政策，遵守国家的法律法规；
2.品行端正，具有良好的道德修养和思想品质；
3.本科及以上学历；
4.工作细致，责任心强，积极主动，身心健康。
四、招聘程序
1.符合条件者请将个人简历、学历、学位证明及其他证明材料电子版于2026年11月25日24:[已脱敏:邮箱]（邮件主题：岗位名称+姓名+学校+专业，不接受压缩文件）；
2.学院对符合条件的应聘者进行初筛，入围者通知笔试和面试，择优录用。
五、考核及待遇
1.考核及待遇参照西北工业大学非事业编制人员有关规定执行；
2.薪资待遇：面议；
3.工作地点为西北工业大学友谊校区；
4.试用期3个月，首次聘期3年。
