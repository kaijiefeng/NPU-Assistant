# 关于举办西北工业大学2026年秋季帮扶地区农产品展销会的通知-校工会（帮扶办）/ 妇女联合会

全体师生员工、各位校友及家属：
金秋送爽，硕果飘香。又是一年丰收季，对口帮扶地区的山野田间满载秋收喜悦，孕育出天然优质、风味纯正的特色农产。为深入落实乡村振兴帮扶工作部署，持续深化我校消费帮扶成果，搭建帮扶地区农产品直通校园的暖心桥梁，让藏在深山的原生态好物走出乡土、走进西工大校园、走进广大师生生活，学校决定举办2026年秋季帮扶地区农产品展销会。
消费有温度，帮扶有力量，购买即助力。每一份农产品的选购，都不仅是一次对天然美味的邂逅，更是我校师生以实际行动践行社会责任、助力乡村振兴的暖心善举。我们以买代帮，用一份份真诚的消费，搭建校地同心帮扶的纽带，切实帮助帮扶地区拓宽农产品销售渠道、稳固农户增收渠道，为乡村产业发展、乡村振兴赋能添力。为方便大家择优选购、暖心助农，现将本次展销会相关事宜通知如下：
一、展销时间
2026年10月19日（星期一）至10月23日（星期五），每日9:00—19:00。
二、展销地点
友谊校区三航路。
三、展销内容
广西融水、陕西镇巴、城固、蒲城、白水五地农特产品齐聚校园，百余种秋日风物自山野田畴而来。经当地政府推荐把关，产地直供，绿色安全。往年口碑好物与乡土新品同台亮相，现场设品鉴区，可先尝后买。
四、温馨提示
部分生鲜产品数量有限，售完即止。请按需选购，有序参与，共同维护校园环境。
一袋一篮，盛着秋日丰饶，也连着远方乡亲的期盼。欢迎广大师生员工及家属前往，把乡土好物带回家，把西工大温情递向田野，为乡村振兴贡献力量。
活动期间，学校帮扶办主任陈建军将在“陈建军”抖音号（CCTWJackson）进行专场助农直播，欢迎广大师生、校友及社会公众持续关注与支持。
校工会
2026年10月16日
