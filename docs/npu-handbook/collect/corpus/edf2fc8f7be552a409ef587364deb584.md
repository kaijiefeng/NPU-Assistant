# 北京研究院党支部召开调查研究成果交流会-西北工业大学

按照《中共西北工业大学委员会关于开展调查研究的实施方案》和《资产公司党委深入开展学习贯彻习近平新时代中国特色社会主义思想主题教育工作方案》要求，7月24日下午，北京研究院党支部召开主题教育调查研究成果交流会，北京研究院全体党员及部门负责同志参会。
会上，党支部书记方文杰作了题为《以支部建设为核心的北京研究院组织能力提升研究》的专题党课。她从主题教育理论学习情况、选题背景介绍、调研方案及实施情况、存在的问题及整改措施以、调研工作小结等五个方面详细阐述了调查研究全过程。在调查研究实施中，通过实践研学、单位走访和谈心谈话等多种途径，发现了北京研究院在组织能力中存在的相关问题，并逐一给出了具体的解决提升方案。
随后，北京研究院副院长李捷作了题为《大飞机发展及航空产业链的需求调研》的专题党课。从运-7、运-10、ARJ21到C919大型客机，以科普的形式介绍了我国飞机制造业发展的艰难、坎坷、曲折路程。分析了国有航空产业供应链现状并介绍了西安、天津、扬州在航空产业供应链建设方面的成就。最后，从航空标准件制造、数控零件制造、材料、装配、模具、线缆、电子元器件、设备等8条支链，深入分析了航空产业链中未来市场和价值区间。
方文杰在总结时表示，党员干部要深刻理解“调查研究是我们党的传家宝”这句话的内涵，要做到以习近平新时代中国特色社会主义思想为指引，以党的二十大精神为指导，统一思想认识，坚持知行合一，强化调研成果运用，将主题教育与北京研究院建设工作有机融合，加快推进北京研究院高质量发展。
