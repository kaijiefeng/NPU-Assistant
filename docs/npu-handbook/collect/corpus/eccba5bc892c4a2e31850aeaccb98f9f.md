# 内科-西北工业大学医院

一、科室概况
西北工业大学内科住院部现共开设病床44张，其中重症监护病房病床（简称ICU）2张，配有独立的专业护理单元及较先进的抢救设备。拥有多参数心电心脏监护仪、心脏除颤仪、心电图机、24小时动态心电图监测仪、24小时血压监测仪、血糖仪、肺功能测定、呼出气一氧化氮测定和经颅多普勒超声仪、胃幽门螺杆菌监测等各种诊断检测仪，科室还配备有增强型体外反搏治疗仪、重复经颅磁刺激治疗仪、机械排痰治疗仪、微波治疗仪、磁治疗仪、预防下肢血栓形成气压治疗以及气垫床等先进治疗设备。诊疗工作主要针对内科疾病的筛查、诊疗及慢性病日常健教指导。具体涵盖：（1）心血管病单元（2）脑血管病治疗及康复单元（3）糖尿病管理单元（4）急慢性呼吸道疾病诊治单元（5）消化道疾病诊治单元 （6）头晕、头痛诊治单元（7）.认知障碍及痴呆诊治单元。
二、医务人员及专业范围
科室共有中高级职称医师6人，其中副主任医师4名，主治医师1名，住院医师1名。亚专业涵盖神经内科、呼吸内科、消化内科、风湿免疫等多科目，并多次派遣人员前往第四军医大学附属西京医院、西安交通大学第二附属医院、陕西省人民医院等三甲医院进修学习。对内科各系统常见疾病诊断和治疗以及急危重疑难疾病的识别积累了丰富的临床经验，尤其针对缺血性脑血管疾病功能恢复、各种原因引起的认知功能障碍、冠心病、高血压、各种原因引起的心衰、慢阻肺、支气管哮喘、糖尿病及糖尿病急慢性并发症、风湿性骨关节病等的治疗具有较高水平。
三、护理人员及专业范围
科室共有护理人员13名，包含主管护7名，护师5名，护士1名，其中9名均有十年以上三级医院工作经验。本科学历6人，3人获得学士学位，5人拥有健康管理师资格证书，1人获得陕西省康复护理专科护士证书、2人获得消毒员上岗证书及特种设备管理证书，5人由省级颁发的认知功能评定培训证书。秉承着“专业、温馨、尊重、成长”的护理理念，为了更好的为患者服务，科室曾多次派送人员前往西京医院、陕西省人民医院等综合性三甲医院学习先进的护理技术及技能，针对不同疾病特点的患者进行专业、精准的护理工作。团队对内科常见疾病的护理常规，如心衰常规护理、心脏康复护理、病毒性心肌炎护理、糖尿病护理、高血压病护理指导、各种肺炎常规护理、脑梗后遗症护理、压疮护理、PICC护理、吸痰护理、各种管路维护及临终关怀、等均有丰富的操作。另外，结合我科病源主要以中老年患者为主的特点，采取“护理-健教一体化”的管理方式，将健康教育渗透到日常护理工作中，真正把“做患者健康卫士”践行到底。
四、特色医疗
1.增强型体外反搏增强型体外反搏(enhanced external counter pulsation ,EECP)，为一种无创性辅助循环装置。主要作用包括：（1）通过与心脏舒缩功能相配合的对肢体进行序惯加压，从而提高心、脑、肾等重要脏器血流灌注，改善重要脏器的血液循环。（2）增加血液中生长因子及CD34+细胞的水平，刺激侧支循环生成。（3）增加患者体内一氧化氮浓度及降低内皮素水平，抑制血管收缩，改善了血压并减少心绞痛发生。
我院2020年医院引进了体外反搏治疗仪，年平均接待5000余人次，疗效确实可靠，显著改善了病人的临床症状和体征，极大满足广大教职工慢病治疗需求，填补了我院心脑肾及糖尿病并发症等缺血性疾病的治疗空缺，在陕西省乃至全国高校医院处于领先行列。
2.肺通气功能检测，是评价呼吸生理功能所必须的实验室检测之一。肺功能对人体无损伤，敏感性高、重复监测方便、配合简单易行，对肺部功能性病变的检查有重要的意义。可用于：早期检出肺、呼吸道病变；鉴别呼吸困难的原因，判断气道阻塞的部位；评估外科手术耐受力及术后发生并发症的可能性；健康体检、劳动强度耐受力的评估；危重病人的病情监测等。
3.呼出气一氧化氮检测，可检测人体呼出气中的NO的浓度，从而鉴别气道炎症的类型。例如对于哮喘、慢性咳嗽、慢阻肺、过敏性鼻炎与原发性纤毛运动障碍等呼吸道疾病的病因鉴别，指导抗炎药物的使用，并可在治疗过程中监测疗效以便及时调整治疗方案，对疾病的预后进行科学的管理。
4.24小时动态心电图及中央心电监护系统可长时程同步监测心率及心律变化。无创伤，安全性好。
5.24小时动态血压，用于测定患者24小时内，每间隔一定时间内的血压值及全天平均血压值。
6.尿素14C呼气试验，是幽门螺杆菌检测的重要手段。操作简单、无创伤，有助于及早诊断并指导根除HP感染。
7.认知功能测评，对于痴呆及痴呆前期，早发现、早诊断、早治疗，从而减少发病，延缓、控制病情进展，有效提高老年患者生活质量。
8.肌电图诱发电位仪，用于确定周围神经肌肉系统和中枢神经系统的功能状态及可疑病变，检出亚临床病灶，对病损精确定位。对周围神经疾病、颈腰椎疾病、糖尿病、各类神经损伤、康复治疗评价、感觉及运动功能评价等的诊察确定。
9.振动排痰仪，是一种通过振动气道痰液松动而利于咳出的机器，并促进肺部血液循环。可使痰液易于咳出，利于呼吸系统感染的控制，减少气管插管的风险。
10.微波治疗仪是利用电磁场热效应促进肺部炎症消散吸收，改善局部循环，缩短肺部炎症病程，提高生活治疗。
11.吞咽神经肌肉电刺激治疗仪（主要用于非机械性咽损伤引起的吞咽困难和构音障碍的评估、治疗和实践。
五、服务特色
1. “一站式”服务：内科系统疾病均可在一个病房得到综合治疗；出院后继续进行健康咨询和健康促进活动，从而使患者获得最佳疗效保障。
2. 倡导“五声服务”：入院迎接声、入病房问候声、操作不顺有道歉声、病人配合有道谢声、出院有送别声。
3. 开展延伸服务：病人出院时送上科室联系卡，让病人随时与医护人员保持联系，开展电话随访。
4. 对患者住院全过程实施医疗、生活全程护理指导，解除老人来院的陌生、焦虑。解除家属担心学生不适应的后顾之忧。用爱心、细心、耐心、暖心关爱呵护每一位患者。
