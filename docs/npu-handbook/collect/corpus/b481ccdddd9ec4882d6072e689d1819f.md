# 《ACS Nano》封面报道我院肖发俊、赵建林教授团队局域激子共振调谐重要研究成果

近日，我院肖发俊、赵建林教授团队联合北京大学刘开辉教授、中国科学院物理研究所马超杰副研究员，在纳米科技领域顶级期刊《ACS Nano》上发表了题为“Resonance Tuning of Localized Excitons via a Plasmonic Nanocavity”的研究论文，并入选当期的期刊封面（Supplementary Cover）。
西北工业大学物理科学与技术学院博士生王其发、北京大学物理学院博士生薛国栋为论文共同第一作者，肖发俊教授、马超杰副研究员、刘开辉教授为论文共同通讯作者，赵建林教授对本工作给予了重要指导，西北工业大学物理科学与技术学院为论文第一署名单位。
二维过渡金属硫族化合物（TMDs）中的激子及多体束缚态在光与物质相互作用中发挥着重要作用，并在光电子与量子光学器件领域展现出广阔的应用前景。其中，由缺陷、无序或应变诱导形成的局域激子因其较长的辐射寿命、稳健的自旋-能谷耦合特性以及较高的光子提取效率，被认为是构建片上单光子源的理想候选。然而，现有局域激子的激发与调控多依赖低温条件或复杂器件结构，难以满足高密度片上集成的需求。近年来，研究者通过金属或介质纳米结构在单层TMDs中引入稳定应变，实现了局域激子的有效激发。然而，为抑制热涨落影响，确保器件在室温下稳定运行，仍亟需进一步实现激子发射能量的红移调控。其核心挑战在于如何协同匹配应变诱导势阱深度与等离激元共振能量，否则局域激子发射易被自由激子背景淹没或因强度过低而难以探测。因此，在实现宽波段可调的同时保持高发光亮度，仍是当前亟待解决的关键问题。
针对上述挑战，该团队设计并制备了一种纳腔-WSe2复合结构，提出了一种单层WSe2中局域激子的室温激发与共振调控策略。通过结合纳米尺度应变工程与Purcell效应，利用强局域等离激元模式与局域激子发射峰的精准匹配，实现了局域激子发射强度约22倍的提升。此外，通过纳腔模式的共振可调谐性，实现了247 meV的局域激子能量调控范围。该研究构建了一种稳健的局域激子发光调谐的策略，为实现具备高亮度、可扩展及波长可定制的非经典光源提供了新的技术路径。相关成果有望推动可调谐单光子源、片上量子光子回路等的发展，为量子信息处理与量子通信应用奠定基础。
