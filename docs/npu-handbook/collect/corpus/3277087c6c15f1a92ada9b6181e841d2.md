# 党委学生工作部传达学习树立和践行正确政绩观专题党课精神

7月7日上午，党委学生工作部在友谊校区召开全体工作人员专题学习会议，集中传达学习学校树立和践行正确政绩观专题党课精神。会议由党委学生工作部部长于辉主持，学工部全体人员参会学习。
会议传达并学习了张云明书记在树立和践行正确政绩观专题党课完整内容，深刻领会习近平总书记关于树立和践行正确政绩观系列重要论述的核心要义。
会议指出，全体学工人员要牢牢把握树立和践行正确政绩观的七个方面重要内涵，不断强化践行正确政绩观的政治自觉、思想自觉、行动自觉。
会议强调，要恪守“公诚勇毅”校训，弘扬“三实一新”校风，以服务学生成长成才为学工队伍践行正确政绩观的价值准则，始终坚持问需、问计、问效于学生，把服务学生全面发展作为学生工作最大政绩；不断完善“1+4+N”学生工作体系，沉下心、卯足劲、踏实干，探索更多行之有效的育人特色实践路径，对照校领导调研指导学生工作、2026年度辅导员代表座谈会等各项部署要求，精益求精提升文字写作与思政研究水平，用心用情用力护航学生成长发展。
会议要求，要以案为鉴、警钟长鸣，对照党课中通报的各类反面典型案例深入自查自省，及时防范、纠治工作中存在的政绩观偏差问题。
党委学生工作部将以此次专题学习为契机，进一步树立和践行正确政绩观，筑牢政治忠诚、强化担当实干，引领学生工作改革创新，立足国防军工高校育人使命，培育更多堪当强国强军重任的青年人才，为学校加快建设中国特色世界一流大学贡献学工力量。
