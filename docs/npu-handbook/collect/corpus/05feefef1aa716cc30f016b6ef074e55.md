# 后勤办公室党支部开展劳动实践主题党日活动

为进一步强化劳动育人成效，增强党员干部爱校护校意识，12月1日下午，后勤办公室党支部联合后勤产业集团物业服务中心党支部、航空学院硕士研究生第一党支部，在友谊校区桃李园开展“树木刷白穿新衣 温暖过冬增颜值”劳动实践主题党日活动。
活动开始前，首先由物业绿化师傅为大家科普树木刷白的相关知识以及实际操作中的注意事项。接着，大家提着桶、拿着刷，摇身变成一个个“粉刷匠”，热情高涨地投入到为树木换新颜的劳动实践之中。活动现场热火朝天，大家分工明确、配合默契，按照止口平整、均匀统一的要求，认真细致反复涂刷，为一排排大树穿上了御寒的白色“新衣”。
据专业绿化师傅讲解，树木涂白不止是为了美观，还能够为树木安全过冬做好准备，一是杀菌防虫，杀灭和驱除对树木产生危害的病、虫等；二是预防冻伤，白色涂白剂能够使50%以上的阳光被反射掉，避免因昼夜温差过大造成树干冻裂。
活动结束后，大家纷纷表示，这次劳动实践活动很有意义，因为在大家的共同努力下，涂白后的树木整齐划一，成为冬季校园里独特靓丽的风景线。同时作为“后勤人”，也希望以自己的实际行动提升校园颜值，与广大师生一起，共同维护美好的校园环境。（撰稿人：毛淑兰；审稿人：韩争胜）
