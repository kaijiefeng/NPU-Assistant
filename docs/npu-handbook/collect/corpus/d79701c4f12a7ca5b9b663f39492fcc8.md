# 学院组织师生赴关中革命纪念馆开展红色教育实践活动

11月27日下午，教育实验学院/未来技术学院铸剑班学员、学生党员代表及学生骨干，共计30余人，赴陕西富平关中革命纪念馆开展红色教育实践。
关中革命纪念馆承载着关中地区厚重的革命记忆，是传承红色基因、赓续红色血脉的重要阵地，详细记录了中国共产党领导下关中人民的奋斗足迹。在讲解员的引导下，同学们依次参观了“关中新民主主义革命历史展”“习仲勋同志生平陈列展”和“传承红色基因 赓续红色血脉”三个主题展馆。通过珍贵的历史文物、照片和场景复原，同学们深入了解了关中地区在中国共产党领导下的革命历程，以及习仲勋同志等老一辈无产阶级革命家坚守信仰、砥砺前行的奋斗事迹，切身感受了革命先辈的崇高精神风范。
同学们纷纷表示，要以更加饱满的热情投入到学习和生活中，肩负时代使命，将革命精神转化为奋进的动力。教育实验学院/未来技术学院将持续开展红色实践教育，引导学生传承革命精神，成长为担当民族复兴大任的时代新人。
