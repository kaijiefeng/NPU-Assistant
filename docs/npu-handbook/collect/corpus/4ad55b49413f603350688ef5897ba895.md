# 后勤办公室党支部组织党员理论学习会议

根据学校机关党委9月党支部理论学习指导意见，9月23日下午，后勤办公室党支部在会议室召开了全体党员理论学习会，会议由党支部书记张文刚同志主持。
首先，由张文刚同志带领全体党员集中学习了《习近平：不断开拓当代中国马克思主义政治经济学新境界》《习近平在经济社会领域专家座谈会上的讲话》《习近平：思政课是落实立德树人根本任务的关键课程》《习近平在中央第七次西藏工作座谈会上强调全面贯彻新时代党的治藏方略建设团结富裕文明和谐美丽的社会主义现代化新西藏》《习近平：推动更深层次改革实行更高水平开放为构建新发展格局提供强大动力》《习近平作出重要指示强调坚决制止餐饮浪费行为切实培养节约习惯在全社会营造浪费可耻节约为荣的氛围》等6篇理论指导性文章。
接着，就学习内容和党员自学的《中国制度面对面》《习近平谈治国理政》等相关内容结合后勤办公室目前开展的制度建设、校园综合治理、节能工作等进行了专题研讨和交流。张文刚同志指出，各项工作有效持续地开展离不开制度的保障，以制度固化我们的职责，各司其职，做好我们每个人的手头工作，将力量拧成一股绳，将劲儿往一处使，共同推动后勤综合改革行稳致远。
最后，张文刚同志对全体党员提出了几点要求。第一、要善于学习，勤于思考；学而不思则罔、思而不学则殆。尤其是年轻党员更要不断学习提升自己，以新的理论知识武装自己、充实自己。第二、要善于发现问题，解决问题，积极跟进，做到工作到位而不越位。第三、要注重实践，真抓实干，理论学习不是形式，理论知识不但要刻于心中，更要用于实际工作当中。讲实话、干实事，切实为后勤综合改革工作稳步推进助力。
