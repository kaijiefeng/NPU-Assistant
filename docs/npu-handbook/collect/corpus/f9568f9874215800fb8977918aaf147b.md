# 我校开展2026级新生心理适应讲座主讲教师培训

为扎实做好2026级新生心理健康教育及心理测评工作，进一步提升新生心理适应专题讲座的专业性、针对性与实效性，8月31日上午10点，学生心理健康教育中心开展2026级新生心理适应讲座主讲教师培训会。本次培训由心理中心主任刘欣主讲，30余名教师参加培训。
培训中，刘欣对全体参训教师积极投身心理育人工作予以肯定。她指出，新生入学适应期是心理健康教育的关键阶段，关乎学生成长成才。她希望全体参训教师深耕专业、打磨讲授能力，以饱满的热情和科学的方法开展讲座，精准回应新生心理困惑，扎实做好新生心理适应引导工作。
随后，刘欣围绕讲座核心内容、讲座重点及工作规范开展专项培训。培训系统讲解了新生心理测评的意义、测评流程及报告解读方法，结合本科生、研究生不同成长与心理特点，精准梳理两类新生适应难题，并配套讲授实用的心理调适与疏导方法。
本次培训有效提升了参训教师的心理专业知识储备和科普实操能力，进一步完善了新生心理健康教育工作体系，为后续全校新生心理适应讲座高质量、标准化开展筑牢专业保障。
我校2026级新生心理适应讲座将于9月1日至14日在全校范围内开展。讲座将通过系统普及心理健康知识、科学传授心理调适技巧，助力本、研新生顺利完成身份转变，快速适应校园学习生活，为学校人才培养夯实心理根基。
