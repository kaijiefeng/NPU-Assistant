# 第二课堂丨学生科协举办第九期“领航者说”主题活动

10月15日，西北工业大学学生科学技术协会“领航者说”系列活动第九期开讲。本期继续围绕“SolidWorks从零起航”主题，邀请学校WMJ战队成员颜子渊担任主讲，面向学校首届3D打印设计大赛参赛选手，系统梳理从数字模型到实物成型的完整链路。活动还设置了实操演示环节，带领大家上手体验把创意变成实物的全过程。
培训中，颜子渊同学从SolidWorks的草图绘制讲起，逐步展开旋转、拉伸等基础建模操作，随后转入Bambu Studio，讲解打印质量设置与打印方式的选择要点。在实操环节，他以一座拱桥为例，完整演示了从建模、切片到打印输出的全过程。借此，同学们既掌握了草图完全定义的方法，厘清了旋转与扫描各自的适用场景，也直观理解了层高、支撑、填充密度与首层附着等参数对成品质量的影响，真正走通“设计—切片—打印—验证”的完整链路。
随后，活动进入赛前辅导环节。学生科协余俊初同学介绍了首届3D打印设计大赛的赛制规则：大赛设理工科创、文艺创意两个赛道，分别以承重桥梁设计与三航主题文创作品为比拼内容，并对参赛作品的规格要求与提交方式作了详细说明。
现场互动气氛热烈，同学们接连抛出“可不可以打印多个配件进行拼装”“多个配件怎么一起打印”等疑问，主讲人逐一作了解答。
本次培训聚焦SolidWorks建模与3D打印两项实用技能，通过朋辈讲师的实战经验分享与现场实操演示，帮助零基础同学快速上手软件操作，走通从图纸到实物的完整流程，也为同学们备战首届3D打印设计大赛、参与后续科创项目打下基础。
