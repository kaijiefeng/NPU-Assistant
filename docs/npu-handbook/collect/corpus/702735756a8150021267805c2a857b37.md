# 总师摇篮，为国铸剑——数学与统计学院全力做好2025年本科招生宣传工作

为进一步增强考生、家长及社会对我校的了解，持续提升学校生源质量，院长聂玉峰、党委书记王莉统筹部署、亲临现场，副院长郭千桥、院长助理刘晓刚、林伟老师、王振海老师组织协调，副院长都琳、副书记张莹、全院52位教师和6名重庆籍本科生积极参与，在重庆和西安两地通过线上线下相结合的方式开展形式多样的宣传活动，全力做好2025年本科招生宣传工作。
精心备战：数学与统计学院招生宣传培训会强势启航
为全面做好2025年本科招生工作，切实增强招生宣传工作的组织性、纪律性，进一步提升招生宣传实效，数学与统计学院于6月10日晚20:00在友谊校区西馆XA105教室组织召开了招生宣传工作专题培训会。培训会上，学校招生办公室副主任马婷婷首先致辞。她强调了招生工作对于学校发展的重要性，并对学院招生宣传队伍提出了明确要求与殷切期望。随后，院长助理刘晓刚对2025年我校重庆市招生政策、志愿指导、宣传方案、相关注意事项等方面作出了详细解读。学院副院长郭千桥对招生工作须知和必读资料目录进行着重强调。最后，学院党委书记王莉作总结发言。她指出，2025年招生工作使命艰巨、责任重大，全院参与招生宣传的同志必须进一步提高认识、明确责任、规范宣传、严守纪律，以高度的责任感和饱满的热情投入到招生宣传工作中，全力以赴提升生源质量。
（图1 2025年招生宣传工作培训会）
重磅启幕：重庆招生政策发布会反响热烈
为深入解读招生政策、精准对接重庆考生需求，全面展示学校办学特色与育人优势，数学与统计学院联合招办及各院系，于6月中下旬在重庆市沙坪坝区、江北区、渝中区连续举办四场招生政策发布会，累计吸引800余名考生及家长参与，现场气氛热烈，互动积极。
活动聚焦2025年招生政策、优势学科及特色培养项目。宣讲专家团队对学校报考指南和重庆市招生计划、拔尖创新人才培养模式（黄玉珊航空班、陈士橹飞天班、黄震中海洋班、智慧三航拔尖班、数学与交叉科学拔尖班等）以及中外合作办学项目等进行了全面细致的解读，并就志愿填报策略、专业发展前景等家长考生关切的问题提供了权威指导。
6月14日-15日，在重庆连续组织两场西工大招生政策宣讲会和一场家长见面会，航天学院校金友，航海学院闫永胜，伦敦玛丽女王大学工程学院副院长程茵，教育实验学院/未来技术学院南云，数学与统计学院党委副书记张莹、副院长郭千桥、院长助理刘晓刚和林伟老师分别汇报特色班培养模式。王睿璇和李彦吉在现场为考生及家长提供了专业、热情的咨询服务。
（图2第一场、第二场政策发布会活动现场）
6月21日-22日，继续连续组织两场西工大招生政策宣讲会，发布会聚焦学校2025年在渝招生政策及拔尖人才培养体系。招办副主任马婷婷，航空学院李霓，航海学院雷开卓，数学与统计学院党委书记王莉、副院长都琳、院长助理刘晓刚和林伟老师依次介绍特色班培养模式。李彦吉和常昕烨在现场为考生及家长提供了专业、热情的咨询服务。
（图3第三场、第四场政策发布会活动现场）
深入一线：中学宣讲与咨询巡展全覆盖
志愿填报关键期，老师们分别深入重庆市第一中学校、南开中学校、第八中学校、巴蜀中学校及重庆市各区县40余所知名中学开展线下招生咨询活动50余场，累计服务广大考生和家长万余人次，实现精准触达与深度交流。同时，学院也选派老师参加西安铁一中滨河学校和西工大校园开放日招生咨询活动。老师们不仅系统介绍西工大办学历史、学科实力、育人环境、近年录取情况及特色专业，更针对考生个性化的志愿填报与专业选择困惑，提供一对一权威指导。

（图5西安招生咨询活动现场部分照片）
（图6西北工业大学校园开放日活动现场部分照片）
多维保障：线上线下，服务不断线
驻点咨询：在重庆大酒店设立长期咨询站，教师团队以专业热忱提供精准志愿指导。
热线畅通：面向重庆考生开通30余部招生专线，确保咨询即时响应。
云端答疑：依托微信群、QQ群等平台，全天候为考生及家长解疑释惑，构建高效便捷的线上服务体系。
（图7招生咨询QQ群截图）
成效初显：口碑载道，砥砺前行
招生团队的专业素养与真诚付出赢得了广大考生和家长的高度赞誉。家长们纷纷表示，通过深入接触，对西工大的学科优势与育人特色有了更清晰的认知，报考信心倍增。咨询现场更吸引了众多高一、高二学子前来交流，他们以考入西工大为志，感谢老师们的指导。
数学与统计学院通过系统化、立体化的招生宣传矩阵，成功将西工大的总师育人文化、学科实力与育人环境全方位呈现。未来，学院将继续以重庆、西安等重点区域为支点，创新宣传模式，深化校地合作，持续吸引心怀报国理想的优秀学子汇聚西工大，为学校高质量生源的规模性突破贡献力量。
