# 广电计量检测（西安）有限公司赴我校集成电路学院座谈交流-集成电路学院（微电子学院）

11月4日下午，广电计量检测（西安）有限公司总经理付喆、副总经理贺伟林等一行7人赴我校集成电路学院调研交流。集成电路学院院长马炳和、副院长王少熙、阴玥及相关教师代表参加会议。会议由集成电路学院院长马炳和主持。
马炳和代表学院对付喆一行的到访表示热烈欢迎，并从发展历史、学科与科研、人才培养、开放协同等方面全面介绍了集成电路学院的发展情况。马炳和表示，近年来学院坚持面向国家集成电路产业重大需求，不断深化产教融合，广电计量作为国有第三方计量检测机构，与学院学科方向契合度高，双方合作前景广阔。
付喆对学院的热情接待表示感谢，并介绍了广电计量检测集团股份有限公司及西安公司的基本情况。他指出，广电计量对集成电路等学科方向的人才需求迫切，希望双方在人才培养、师资培训等方面加强合作。随后，双方就校企合作内容进行了深入友好交流。
此次座谈交流为双方深化合作奠定了良好基础。双方将建立常态化沟通机制，开展务实合作，共同为国家集成电路产业发展贡献力量。
