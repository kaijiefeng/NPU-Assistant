# 新生入学教育|集成电路学院（微电子学院）举办2026级本研新生心理适应讲座-集成电路学院（微电子学院）

9月7日晚20:00，集成电路学院（微电子学院）在教学西楼D-104举行本研新生心理适应讲座。本次讲座旨在引导新生正视入学适应期的心理波动，掌握基本的自我调适方法，为后续学习生活筑牢心理根基。
本次讲座由刘昊旻老师主讲。刘昊旻结合日常工作观察，梳理了新生在生活节奏调整、宿舍关系磨合、学业目标重建等方面的常见适应困难，引导同学们认识到入学初期出现的迷茫焦虑属于正常过渡反应。刘昊旻老师提醒同学们，心理测评是了解自身心理状态的重要参考，并非对心理状态的定性“贴标签”。他介绍了调整认知偏差、建立规律作息、主动寻求朋辈与师长支持等可操作的调适方法，鼓励新生将心理调适融入日常生活，避免问题累积。
本次讲座结合心理适应教育与辅导员一线工作视角，帮助新生在校园生活语境中理解心理健康含义。集成电路学院后续将依托“一站式”学生社区和心理育人阵地，把心理健康教育嵌入日常管理、文化活动与学业指导，帮助2026级新生成长的同时，实现心理韧性与人格同步提升。
