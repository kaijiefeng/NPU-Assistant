# 喜报｜新突破！航天学院获批首个国家自然科学基金创新研究群体项目

近日，国家自然科学基金2026年度评审结果公布，航天学院代洪华教授牵头的“空间在轨操控”项目获批创新研究群体项目（B类）。该项目为学院首项创新群体项目，同时也是我校首次获批创新群体B类项目。
创新研究群体项目直接经费1000万元，竞争激烈、评审门槛严苛。“空间在轨操控”创新研究群体（B类）由代洪华牵头，袁源、党朝辉、杜崇瑞为骨干成员，岳晓奎教授任顾问教授。团队紧扣航天强国重大战略需求，依托航天学院学科平台，汇聚多学科中青年骨干力量，在航天器智能操控和高性能计算等方向积累了扎实的研究基础，面向国家“十五五”时期航天强国建设战略需求，聚焦国家航天器在轨安全与空间态势感知领域重大需求，围绕厘米级空间碎片天基感知、聚类预报与碰撞规避基础理论和关键方法开展研究，推动基础理论创新与航天安全防护应用深度融合，努力为我国航天器长期安全稳定在轨运行提供理论基础与技术支撑。
学院坚持强化基础研究，推动“从1到0”工程驱动与“从0到1”原始探索双向发力。深化有组织科研，完善基金全链条培育，资源配置与评价激励向基础研究倾斜；依托飞天学术论坛、院士专家研讨，从航天重大工程凝练科学问题，加强与航天院所协同，打通理论攻关与工程验证链条。本次项目获批是航宇学科“双一流”建设标志性成果，学院将持续支持团队开展前沿攻关，产出高水平原创成果，服务航天强国建设与高水平科技自立自强。
