# 本科和硕士毕业生户口迁移须知

一、办事流程
二、所需材料
学生处提供的毕业生户口去向。
三、注意事项
1.每年3月、6月毕业生离校前一周，保卫处户籍室统一办理户口迁出，并提前将户口发放至各学院，毕业生集中离校前到学院辅导员处领取户口。
2.领取户口后，办理户口迁移的尽快到接收方办理落户手续；暂留的等确定户口去向后尽快办理户口迁出手续，办理流程可参考博士毕业生户口迁出流程。
3.本校升学的毕业生在入学报到时将集体户口登记卡交给户籍办理点保卫处工作人员，或于报到后一个月内交保卫处户籍室。
4.保卫处户籍室地址：友谊校区综合楼400室，电话88494447；长安校区启真楼一楼学生一站式服务大厅，电话88430735。
