# 资产公司党委委员杨安庆同志为北研院党支部讲授党课-西北工业大学

11月15日，资产公司党委委员杨安庆同志为北京研究院党支部讲授党课。党课由支部书记方文杰同志主持，党支部全体党员及入党积极分子参加学习。
为促进研究院科技成果转化，杨安庆同志讲授了《总结校企改革经验 促进成果转化——西工大校办企业概况》党课。杨安庆同志首先带领大家学习了习近平总书记二十大报告中关于科教兴国部分重要论述。接着深入浅出地讲解了学校校办企业基本情况、校企改革背景、历程、内控体系制度和成果转化的模式、成效。杨安庆同志强调科技成果转化未来与研究院创新孵化以及企业服务是密切相关的，需要好好研究，做好经济成果安全管理。
