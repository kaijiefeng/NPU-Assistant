# 学校联合检查组对我院进行安全生产检查

根据西北工业大学安全生产委员会办公室《关于开展第三季度全校安全生产检查的通知》文件精神。为切实加强“中秋”“国庆”两节前后的安全生产工作。9月25日，安全生产管理办公室、科学技术研究院、保卫处、教务处、后勤产业集团在安管办姜文军副主任带领下，到我院翼型叶栅空气动力学国家级重点实验室开展安全生产检查，实验室相关负责同志陪同检查。
检查组按照安全责任制落实、教育培训、开学前现场检查后实验室整改落实情况等方面，具体对实验场所用电规范、特种设备的使用、消防设施设备、安全通道以及安全警示标志等方面进行了检查。对检查中存在的问题要求立即整改，希望学院进一步落实实验室安全管理责任制，加强安全教育和培训提高师生员工安全意识，完善实验室安全操作规程并严格执行，加强安全检查排查力度，发现隐患及时治理，确保学院的安全稳定。
