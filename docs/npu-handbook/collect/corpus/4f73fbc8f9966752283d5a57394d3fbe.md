# 党委组织部、机关党委党支部赴汉中开展主题党日活动

7月16日至17日，党委组织部、机关党委党支部赴中航工业陕飞和国立西北工学院古路坝旧址开展“弘扬爱国奋斗精神、建功立业新时代”主题党日活动。
7月16日下午，党支部成员首先来到中航工业陕飞，先后参观陕飞展厅、数字化部装生产线、总装脉动生产线、试飞厂，近距离感受“大国重器”的生产过程及其风采，整个参观过程贯穿“航空报国 航空强国”主线，陕飞人的爱国主义情怀与使命担当精神让大家感慨不已，“祖国终将选择那些忠诚于祖国的人 祖国终将记住那些奉献于祖国的人”，通过参观，大家纷纷表示，陕飞人真正的将爱国主义情怀植于心践于行，此次参观之行为大家带来了爱国主义精神的新洗礼。参观结束后，党支部成员还与陕飞杨根军副总工程师一行开展了座谈研讨，会上观看了陕飞宣传片，并就航空报国精神和党建工作进行了专题研讨。
7月16日晚，党支部开展支部学习，会上，大家围绕白天参观学习内容，结合学校党支部学习参考内容开展研讨交流，就“新时代下的居安思危、新时代我们能够做些什么”等内容纷纷展开发言，整个学习过程气氛热烈，学习内容结合实际。此次学习，使大家对新时代爱国奋斗精神加深了理解，同时为大家在新时代下如何立足岗位建功立业提供了思路。
7月17日上午，党支部部分成员赴国立西北工学院古路坝旧址进行爱国爱校教育活动，党支部副书记王彦革首先从古路坝的历史、坝上的学习故事等方面对旧址进行了介绍，随后党支部成员面向校友师昌绪先生撰文的“国立西北工学院旧址”纪念碑，同唱校歌，回顾老一辈西工大人的爱国之情、强国之志和报国之行。此行，大家还对纪念碑进行无化学试剂清洗，通过党支部成员1小时的共同努力，碑体焕然一新，碑刻重现光彩。
7月17日上午，党支部书记李小聪带领支部部分成员赴镇巴县宝山村看望我校扶贫挂职干部并进行慰问。
此次党支部活动，紧密围绕“弘扬爱国奋斗精神、建功立业新时代”主题，大家在实践中学习，在实践中思考，取得了较好的活动效果。党委组织部、机关党委党支部将继续丰富创新党支部活动，将学习与实践相结合，提升党日活动实效。（文：宋辉 石寒 图：王一宁 审核：李小聪）
