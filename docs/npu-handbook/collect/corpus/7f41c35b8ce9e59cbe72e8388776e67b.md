# 莫航学院成功举办2025级本科生班级风采大赛

为深入贯彻落实《关于在2025级本科生中开展优良班风学风创建活动的通知》精神，充分展示学院各班级的青春风采与精神面貌，进一步推进班级文化建设。11月15日下午，莫航学院在启真楼四楼大厅举行2025级本科生班级风采大赛。学院党委副书记程茵、团委书记邢文思、相关办公室教师代表和学生代表对各班级的建设成果与现场展示进行评审。
各班风采介绍
本次大赛分为班级文化展示和风采展演两个环节。在班级文化展示环节，各参赛班级通过PPT、视频等多种形式，系统展示了独具特色的班级管理机制、班规公约、班服班徽设计理念以及丰富多彩的班级活动。
MA022502班微电影《青春集结号：我们的班级拾光》
在风采展演环节，同学们以合唱、乐器演奏、诗歌朗诵、舞蹈表演等多种艺术形式，生动诠释了班级文化内涵，展现了团结向上的精神风貌。其中，探测制导与控制技术二班的《歌唱动荡的青春》，将现场气氛推向高潮，既传递了对红色岁月的敬仰，更彰显了青年接续红色薪火、勇毅前行的信念。
MA032502班合唱《歌唱动荡的青春》
MA012502班合唱《你从未离去》
各班级通过创新活动形式，将思想引领、学风建设与美育教育有机融合，打造出“有组织、有文化、有情谊、有学风、有作为”的班集体。评委们从班级文化建设、成员参与度、精神风貌等多个维度进行综合评定，最终遴选出优秀班级代表学院参加校级风采大赛，并评定出院级一、二、三等奖。
MA032501班朗诵《我的未来式由我做主》
此次活动是学院落实立德树人根本任务的重要举措，通过搭建班级展示平台，有效增强了新生集体荣誉感和归属感，为培育“低调务实、兼收并蓄”的“总师型”人才奠定了坚实基础。学院将持续深化班风学风建设，以文化人、以文育人，助力学生成长成才。
