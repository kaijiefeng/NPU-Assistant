# 自动化学院江苏招生组赴淮阴中学开展招生宣传活动

为进一步深化高校与中学教育衔接，吸引更多优质生源报考西北工业大学，4月10日，西北工业大学校务委员会副主任、原校党委副书记陈建有，马克思主义学院副院长贺苗，江苏招生组组长马戎，管理学院研究员李晶一行赴淮阴中学开展招生宣传活动。通过赠送“运-20”模型、举办专题报告等形式，向中学师生展现了我校办学特色与人才培养成果。
陈建有研究员代表学校向淮阴中学国防园赠送“运-20”飞机模型，并为学生作了《大国三航与强国之梦》的专题报告，鼓励学生们积极报考西北工业大学。报告从中国成就的政治根基、国防利器与国家战略实力、西工大精神与“总师育人文化”等三个方面展开。他结合西工大校史中“华航西迁”的壮举，阐释了国家战略需求与高等教育紧密结合的历史逻辑。此外，他以校友张金鹏（中国空空导弹研究院首席专家）等“总师型”人才的成长故事，向师生诠释了我校“隐姓埋名，为国铸剑”的精神传承。报告结束后，学生们踊跃提问，现场气氛活跃。本次报告以西工大“总师育人文化”为纽带，将国家战略、科技前沿与青年使命紧密相连，为淮中学子种下了“科技报国”的种子。
淮阴中学是首批国家级示范性高中，近年来为我校输送了大量优秀学子。本次招生宣传活动的成功举办，有效提升了学校在中学的知名度，为持续提高生源质量奠定坚实基础。未来，学院将继续以“走出去”与“请进来”相结合的方式，创新宣传形式，吸引更多优秀学子加入，助力人才培养高质量发展。
