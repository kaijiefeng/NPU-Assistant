# 便民义诊暖校园 健康服务护师生-西北工业大学医院

为严格落实高新区社会事业服务局健康服务工作要求，进一步优化校园医疗服务、保障师生身心健康，10月8日，西北工业大学长安校区医院在校内开展公益义诊活动。
本次义诊紧贴师生日常健康需求，内科、外科、眼科、心理科、皮肤科、理疗科、妇科等多个科室参加，覆盖常见疾病诊疗、眼部筛查、皮肤护理、劳损理疗、女性健康咨询及心理疏导等多项服务。现场医护人员一对一问诊答疑，针对学生常见的身体不适、皮肤问题、用眼疲劳、肩颈劳损、情绪压力等健康难题，现场给出专业诊疗建议和调理方案，高效解决师生各类健康困扰。
本次活动将优质、便捷的医疗服务送至师生身边，切实缩短就医距离、提升健康保障水平，获得师生广泛好评。下一步，长安校区医院将持续落实属地工作要求，常态化开展便民健康服务，持续夯实健康校园建设，全力守护师生身心健康。
责编 石丛艳
