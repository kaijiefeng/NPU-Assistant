# 学在HC|郝保权教授主讲长征胜利90周年专题讲座

弘扬长征精神，砥砺初心使命。长征是中国共产党和红军谱写的壮丽史诗。值长征胜利90周年之际，教育实验学院/未来技术学院/学科交叉中心于10月8日下午，特邀图书馆副馆长郝保权教授，作题为“长征精神永放光芒，走好新时代长征路”的专题讲座。2026级本科生及辅导员代表参与活动，学院副书记、副院长范翔主持本次讲座。
郝保权教授从红一方面军的长征历程讲起，回望了三大主力胜利会师、长驱二万五千里的壮阔征程。他指出，长征是一次有计划的战略转移，而非仓促撤退；红军在几十万敌军围追堵截中八次调整落脚点，恰恰体现了中国共产党人实事求是、一切从实际出发的思想方法。在讲授伟大长征精神时，他从坚定理想信念、不怕牺牲、实事求是、顾全大局、依靠人民群众五个方面，系统阐释了长征精神的深刻内涵。
谈及青年一代如何传承长征精神，郝保权教授勉励同学们：长征不是尘封的历史，而是一座取之不尽的精神富矿。大家既要从一个个长征故事中感悟信仰的力量，也要把这份感动落到日常，在学业上肯啃硬骨头，在困难面前不退缩，把长征精神转化为脚踏实地、攻坚克难的实际行动。
此次讲座以纪念长征胜利 90 周年为旨，引导同学们加深了对长征精神和青年使命担当的理解。九十年过去，长征的硝烟早已散尽，但长征精神从未过时。学院以此次讲座为契机，引导广大师生在铭记历史中汲取力量，把长征精神转化为立德树人的实际行动，在新时代的长征路上砥砺前行。
