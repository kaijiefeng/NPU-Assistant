# 民航学院姜洪开教授入选2024年度“全球高被引科学家”

2024年11月19日，科睿唯安发布了2024年度“全球高被引科学家”（2024 Highly Cited Researchers）名单，我院姜洪开教授上榜，这已是姜洪开教授连续三年入榜。
2024年度科睿唯安“全球高被引科学家”名单根据2013至2023年期间所发表的高被引论文数量遴选得出，旨在彰显“高被引科学家”在同行之中的重要学术影响力。本年度西北工业大学共有24人次入选，包含跨学科、材料科学、地球科学、化学、工程学、物理学6个学科领域，其中姜洪开教授入选跨学科领域。
姜洪开教授担任中国振动工程学会故障诊断分会常务理事及中国振动工程学会转子动力学分会常务理事；获工业和信息化部国防科技进步二等奖和教育部科研进步二等奖各1项；入选2023年、2022年和2021年度爱思唯尔航空宇航科学与技术领域高被引学者，且论文入选2022年度“领跑者5000—中国精品科技期刊顶尖学术论文”。主要研究方向为飞行器故障诊断与健康管理、新一代人工智能与大数据分析等，团队研究工作属新兴交叉学科；该榜单的发布，不仅是对姜洪开教授专业学术水平的肯定，也是对学院科学研究成果的展示。
