# 西北工业大学医院召开中层干部扩大会议-西北工业大学医院

9月12日，校医院召开中层干部扩大会议。会议由院长郑莉莉主持，医院领导班子成员、科主任、副主任、护士长、支部书记及专科专业组组长参加会议。
院长助理田博领学了医务人员道德准则（2025年版）、违规使用医保基金警示案例，传达了全省二级以上医院开展“六个多”服务的通知，明确医院服务规范。
副院长何凯亮传达中央层面和工信部《关于做好医疗卫生机构集中整治医德医风有关问题的通知》，做了关于医疗行业腐败问题和廉政教育的提醒，并简要通报科室工作量阶段性完成情况和下半年工作的一些想法，为后续工作推进提供参考。
副院长孙伟光通报了2025年诊疗设备购置资金使用情况和医院固定资产清查工作情况，助力医院规范资产管理流程。
办公室主任石丛艳领学了学校印发的《西北工业大学师德考核实施办法》《西北工业大学教师行为规范》《西北工业大学师德失范行为处理办法》，要求医院职工身在学校这一教育环境，要注意敬业修身，遵守师德规范。
六级职员郑琪传达了学校2025年秋季学期安全教育第一课暨安全教育主题党课内容，为大家开展安全教育培训，着重讲解了高校安全教育要点，强调 “安全生产首位意识”，要求全体干部以“预防在前”为原则，切实提升安全防范意识与能力。
院长郑莉莉传达学习宋保维校长《优化学科专业布局 推动“总师型”人才培养》专题报告，并通报了医院2025年收支情况。她表示，医疗行业正处在发展的“阵痛期”，中层干部需注意约束自身，要强化服务意识，要开发潜在市场，深入思考科室在健康领域的发展空间，持续做好师生与患者服务工作。
党总支书记乔辉传达学习李言荣书记《关于我校“十五五”规划中的几个问题》专题报告。他要求，医院要立足服务保障单位定位，紧跟学校发展步伐，继续在日常诊疗及急救培训、家庭签约医师等服务方面发力；聚焦核心竞争力提升，找准医院发展突破口；梳理完善医院工作的制度、机制和流程，为师生提供一流医疗服务保障；不断学习医疗行业政策与行业规范，及时调整工作方向。
会议精准传达学校暑期务虚会与新学期中层干部会的核心精神，梳理了过往工作成效与不足，明确了医院新学期工作重点和发力方向。接下来，医院将以此次会议为契机，凝聚全院力量，扎实推进各项工作，为学校实现“天下工大，世界三航”的宏伟愿景贡献健康力量。
