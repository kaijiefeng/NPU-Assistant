# 学院第四党支部赴高新区第二十一小学开展主题党日活动

为弘扬探索精神、点燃青少年科学求知热情，11月27日下午，教育实验学院第四党支部协航天科普志愿者服务队，走进西安高新区第二十一小学，开展“航天科普进校园，童心逐梦向星辰”主题党日活动。
活动现场，科普志愿者们化身“科学向导”，用通俗易懂的语言搭配精彩的航天影像资料，生动讲解我国前沿科技领域的发展成果与辉煌成就，科学探索的种子在孩子们心中悄然扎根。
最受孩子们欢迎的当属水火箭的制作与发射环节。在志愿者们的耐心指导下，孩子们分组协作、动手实践，一步步变成造型各异的水火箭。随着水火箭直冲蓝天，孩子们欢呼雀跃，尽情感受科技实践的独特魅力。
此次主题党日活动，是一次知识的传递更是一次精神的传承。未来，教育实验学院将持续开展形式多样的科普活动，助力青少年点燃科学梦想，为培养担当民族复兴大任的时代新人添砖加瓦。
