# 重”聚数统，“渝”快成长——2023级重庆籍本科新生见面会召开

为进一步促进新生融入大学学习生活，提升个人生涯规划能力和潜力，完善重庆招生宣传工作，12月5日晚上18:40-21:20，2023级重庆籍本科新生见面会在长安校区启翔楼357会议室顺利召开。数学与统计学院党委书记王莉、副院长郭千桥、微积分课程负责人武海波、重庆招生组组长林伟和王振海、招生秘书李彦吉、重庆籍学生代表张颢瀚以及二十余位重庆籍新生参加，见面会由副院长郭千桥主持。
首先，郭千桥副院长对重庆籍新生们的到来表示热烈欢迎。他表示同学们可以在座谈会上畅所欲言，表达自己来校学习与生活的真实感受。鼓励同学们尽快完成从高中到大学的角色转变，积极主动、奋发图强，充分利用西工大的优质资源和平台，努力探索自己的多样可能性。
微积分课程负责人武海波老师作了《高等数学》学业指导讲座。武老师首先解释了“为什么要学习微积分”和“微积分学什么”两个问题，而后从“正-反”“学-问”“做-想”几个不同的视角给出微积分课程的学习建议。最后她希望同学们做到：以感恩的心努力学习，以好奇的心探索学习，以快乐的心愉快学习，以谦虚的心认真学习，以宁静的心安静学习，以永恒的心持续学习。
重庆籍学长代表张颢瀚同学结合个人发展经历向新生们分享了在西工大日常学习、学生工作与社会实践等方面的成长经验；他以“过来人”的身份强调了自律学习的重要性，告诫大家在大学也不要放松。
学院党委书记王莉作了题为《以终为始，职业规划筑梦前行》讲座。她结合点燃理想、追逐梦想、实现梦想三个部分，联系学生案例，重点介绍了生涯规划、能力培养、价值观塑造等内容，勉励同学们在未来努力到竭尽全力，拼搏到感动自己，度过一个值得骄傲的大学四年生活。
招生组组长林伟老师和王振海老师也对重庆学子殷殷嘱托，大学的学习方式相比高中发生了很大变化，需要同学们提高自学能力、发挥主观能动性，建议同学们要经常与任课教师交流沟通，有困难要第一时间寻求帮助。勉励新同学们在进入大学以后要更加自律，更加合理地安排自己的时间，根据自身学业情况及时调整业余时间，尽快找到大学生活的重心。
交流互动环节，新生们畅所欲言，分享了自己进入西工大后的学习生活以及遇到过的困难，老师们贴心予以解答。在轻松愉快的氛围中，见面会落下帷幕。
会后，徐周全同学说：“参加本次重庆籍新生见面会使我在临近期末的紧张复习中松了一口气，在学习和心理上都有收获。武海波老师讲授了关于微积分学习的顶层逻辑，这让我重新审视自己微积分的学习过程，看到了不足之处。通过与会上老师交流，才了解到西工大为我们重庆籍学生提供的平台，这使我心中多了一份归属感，感到一种背后一直有人支持的踏实感。”李佳颖同学说：“见面会的老师学长分享的经验，让我感受到学校对新生的关爱与热情，为我适应新环境提供了许多帮助。在陌生的城市遇见一群家乡的同学，倍感亲切，希望在今后的生活中互帮互助，共同度过美好的大学生活。”。欧阳驰骋同学说：“这次参加见面会，我得到了很多宝贵的建议，老师们和学长都提到新生应该参加学生组织、加入一个感兴趣的社团，还特意强调了学习数学的重要性，数学是理工科的基础，同时也要学好英语，以便抓住未来的机会。总之，这是一次很有意义的见面会，我受益良多。”
本次见面会不仅增进了新生同学之间的相互了解，也提供了一个新生和老师们交流与沟通的平台，对于他们能更好地融入大学生活、养成良好的生活和学习习惯以及人生的长远发展，都具有重大的现实意义。线下见面增进了招生组老师和新生们的感情，不仅要招进来，更要培养好，进一步诠释了我校以学生为根的人才培养理念。
