# 国家卓越工程师学院2026届研究生毕业典礼暨学位授予仪式圆满举行

3月26日，西北工业大学国家卓越工程师学院2026届研究生毕业典礼暨学位授予仪式在毅字楼436报告厅隆重举行。中国科学院院士、国家卓越工程师学院院长张卫红，学院党委书记、常务副院长蒋建军，学院教职工，2026届全体研究生毕业生及家长代表出席典礼。典礼由学院党委副书记、副院长王谦主持，现场气氛热烈而温馨，饱含着对毕业生的美好期许与深切祝福。
张卫红院士首先代表学院向顺利完成学业的全体研究生表示诚挚祝贺，向辛勤培育学生的校内外导师及默默支持的家长们致以衷心感谢，他结合学院作为全国首批国家卓越工程师学院试点建设单位的使命，对毕业生提出三点殷切希望：一是勇担使命，做强国筑梦的先行者，继续扎根国家重点行业一线，攻克“卡脖子”技术难题；二是赓续情怀，做初心如磐的奋斗者，传承西工大“公诚勇毅”的校训与“科技报国”的精神血脉；三是敢为人先，做引领变革的开拓者，在新一轮科技革命与产业变革中，勇闯创新“无人区”，成为工程科技领域的领跑者。他寄语毕业生，母校永远是大家最坚实的后盾，愿大家带着卓越精神奔赴四海。
毕业生代表于镇源同学登台发言，他分享了在西安航天动力研究所联培经历，谈及航天六院院魂带来的精神感召，分享了参与国家级重点科研项目的实践体会，在理论与实际结合中，深刻认识到解决工程实践问题的能力对卓越工程师的重要性。同时表达了对母校、老师的感恩之情，以及对同窗挚友的不舍之意，也抒发了毕业生们即将投身社会、建功立业的坚定决心。
典礼上，学院对获评“2026年研究生优秀毕业生”的白云飞、李腾飞、任洪凯、王浩宇、王燕婷、于亮、于镇源、朱鑫宇8名同学进行表彰。张卫红院士、蒋建军院长为优秀毕业生们颁奖，肯定了他们在学习和实践中的优异表现，他们积极投身国家国防科技事业的主战场，生动诠释了学院“爱党报国、敬业奉献，具有突出技术创新能力，善于解决复杂工程问题”的卓越工程师培养目标。
同时，学院为优秀毕业生代表李腾飞颁发校友联络员证书，希望全体毕业生以校友联络为纽带，凝聚毕业生力量，持续助力学院与学校的建设发展。
随后，典礼迎来最激动人心的学位授予仪式。蒋建军院长为全体毕业生拨穗并颁发学位证书，毕业生们依次上台，接受这一庄严的荣誉，定格下人生中极具意义的时刻，标志着他们正式完成学业，开启人生新的篇章。
学位授予仪式结束后，蒋建军院长以《铸卓越匠心育工程栋梁赴时代新程》为题，为全体毕业生讲授毕业“最后一课”，送上三点临别嘱托与期望。一是铸牢忠诚之魂，把“国之大者”刻进心中，希望大家始终心怀家国，将个人理想融入民族复兴伟业，把技术用在国家最需要的地方，做党和国家信得过、靠得住、用得上的卓越工程师；二是砥砺实干之行，把“卓越标准”融入日常，秉持西工大“三实一新”校风，以精益求精的工匠精神沉心钻研，让卓越成为一种习惯、一种追求；三是涵养格局胸襟，把“责任担当”扛在肩上，以大格局、大情怀直面科技竞争与时代挑战，敢于担当、勇闯敢试，展现中国工程师的志气、骨气、底气。他寄语同学们，青春逢盛世，奋斗正当时，希望大家带着西工大人与国卓院人的双重印记，怀揽月豪情，守报国丹心，在强国建设、民族复兴的伟大征程中创一流业绩，成时代栋梁，并祝愿大家始终铭记“让卓越成为一种习惯”的学院座右铭，一生卓越。
学院2026届研究生毕业典礼暨学位授予仪式圆满落幕。愿全体2026届毕业生牢记卓越工程师的使命与担当，在强国建设、民族复兴的壮阔征程中勇毅前行，以实干笃行书写青春答卷，在国家关键领域攻坚克难、建功立业，不负母校“为党育英才、为国铸重剑”的殷切期许，争做新时代堪当大任的“总师型”卓越人才，为实现高水平科技自立自强、助力国家高质量发展贡献智慧与力量。
