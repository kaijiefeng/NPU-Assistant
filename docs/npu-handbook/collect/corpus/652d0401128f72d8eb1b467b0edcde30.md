# 关于启动两校区供暖系统冷水循环的通知

全体师生员工、校内住户：
为确保2026-2027供暖季两校区供暖系统正常运行，动力保障中心在完成供暖系统加压试水的基础上，计划于2026年11月1日8时起，同时对两校区供暖系统正式启动冷水循环，冷水循环将持续至正式供暖。为避免因跑冒滴漏造成不必要的损失，确保广大师生住户的财产安全，温馨提示以下师生住户在冷水循环期间注意相关事项：
1.正在装修的住户：请务必提醒施工人员注意保护供暖管道及设施，切勿私自拆改、碰撞暖气片及管线。若近期对供暖系统进行过改动，请务必仔细检查接口、阀门是否连接紧密，并在冷水循环初期重点观察是否有渗漏。
2.暖气管道老旧及长期空置的住户：冷水循环期间管道压力会发生变化，老旧管网可能发生爆管或接口漏水。请此类住户（特别是长期不在家的住户）务必安排人员定期回家查看，注意观察管道接口、阀门处是否有渗水现象。若长期无人居住，或委托邻居、亲友协助留意。
在此期间，如发现供暖设施漏水现象，请通过统一报修平台、或拨打029-88493979（友谊校区）、029-88430945（长安校区）进行报修。各单位如有涉及供暖系统的维修改造施工计划，请务必提前向动力保障中心报备。
特此通知。
后勤部办公室
2026年10月27日
