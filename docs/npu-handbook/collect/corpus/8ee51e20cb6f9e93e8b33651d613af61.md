# 学在HC｜张凯教授与学院2026级学生代表座谈交流

9月29日，教育实验学院/未来技术学院/学科交叉中心在学研空间开展“学在HC”系列活动。受HC002610班主任王书恒邀请，力学与交通运载工程学院副院长、飞行器结构动力学与智能控制工业和信息化部重点实验室主任张凯教授，以“超大型空间结构波传播特性与行为调控”为题作专题讲座。
讲座中，张凯从国家重大战略需求出发，结合高分三号、北斗三号、天宫二号等我国航天领域具有代表性的空间结构，介绍了超大型空间结构面临的工程技术与力学问题。他围绕“张拉整体结构”，讲解了受压构件与受拉单元的结构特性，并结合一维组装结构的波传播响应图表，分析不同组装方式对结构动力学行为的影响，帮助同学们初步了解力学研究在航天工程中的应用。在交流环节，张凯围绕同学们提出的力学与航天交叉领域相关问题进行解答，并结合自身科研经历，鼓励大家重视数理基础，保持对未知领域的好奇，在学习和实践中逐步培养科研思维与创新能力。
此次活动不仅让同学们深入了解超大型空间结构、结构动力学等领域的前沿研究成果，也帮助大家进一步认识到基础理论学习与国家重大工程需求之间的紧密联系。学院始终坚持以学科前沿引领专业教育、以重大工程实践涵养家国情怀，引导同学们重视数理基础、主动关注科技前沿，在学习与实践中培养科研思维与创新能力，为今后的专业学习与发展奠定坚实基础。
