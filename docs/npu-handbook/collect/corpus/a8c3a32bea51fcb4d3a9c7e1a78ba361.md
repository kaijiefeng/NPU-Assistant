# 锚定高端学术目标 聚力人才成果双升——航天学院召开高被引科学家培育暨高被引论文分析研讨会

为深入落实我校“十五五”规划部署，锚定“双一流”建设与高水平科技自立自强要求，进一步提升航天学院学术产出质量、加快高层次学术人才培育进程，4月16日上午，航天学院特邀学校图书馆联合举办高被引科学家培育研讨暨航天学院高被引论文分析研讨会。会议特邀科睿唯安高级顾问马亚鹏、学校图书馆知识服务中心孟芮莅临作专题报告，航天学院各研究所、各团队师生代表参会，会议由图书馆党总支书记高大力主持。
马亚鹏作《2025 年“全球高被引科学家”榜单及方法论解读》报告，围绕引文分析体系与高影响力科研人才数据洞察、“全球高被引科学家” 遴选机制与标准解析两大核心板块，系统阐释了高被引论文的数据源遴选、评价维度与判定规则，全面解读了高被引科学家的入选逻辑、指标构成及年度动态变化，结合当前学术评价体系要求，重点强调科研诚信建设的重要性，明确论文自引率管控等关键注意事项，为师生精准把握高端学术成果培育路径提供了权威指引。
孟芮作《航天学院论文产出分析与对策》专题报告，围绕高被引论文数据来源、学院论文产出、学科前沿研判及优化建议四大板块系统展开。报告明确高被引论文数据的权威来源与筛选标准，依托多维度学术数据系统梳理我院论文产出特征，从研究方向凝练、学术团队构建、成果转化推广、学术交流合作等多个维度，为师生提供了可借鉴、可落地的实践路径，助力师生明晰努力方向、提升学术研究的针对性，为我院学术高质量发展提供精准的数据支撑与科学的路径指引。
参会师生认真聆听、积极交流，围绕报告核心内容及自身科研困惑深入研讨，就高被引论文写作、学术成果引用效能等关键问题与主讲嘉宾互动咨询。大家纷纷表示，此次研讨会内容详实、靶向性强，明晰了高被引论文与高被引科学家培育核心要点，为自身学术研究明确了方向、理清了思路，收获颇丰。
本次研讨会圆满落幕，为航天学院高被引科学家孵化、高水平论文产出筑牢了基础、指明了方向。后续，航天学院将持续强化高层次学术人才培育与高水平学术成果产出，聚焦航天学科前沿领域、关键核心科研方向，不断优化科研布局、提升学术产出质量与国际影响力，以坚定的决心、务实的举措，全力推进高被引科学家培育工作，努力产出更多具有国际影响力的高水平学术成果，为学校“双一流”建设稳步推进注入航天力量。
