# 民航航空器冲击防护与安全评估重点实验室举行第三届学术委员会会议

2024年12月6日上午，民航学院在江苏省太仓市太仓途易蓝酒店成功举办了民航航空器冲击防护与安全评估重点实验室第三次学术委员会会议。重点实验室主任李玉龙教授、副主任崔浩教授及学术委员会委员、实验室研究骨干等20余人以现场及线上形式参加了会议。会议由实验室学术委员会副主任徐建新教授主持。
首先，李玉龙教授代表重点实验室对各位委员对重点实验室的关怀和帮助表示感谢，对重点实验室团队成员的辛勤努力表示感谢。崔浩教授代表重点实验室向学术委员会汇报了实验室在科技创新、师资队伍、人才培养、国际合作、成果转化等方面取得的成果，并介绍了后续规划，明确提出了下一年度工作目标与工作重点。学术委员会委员围绕重点实验室发展建设开展研讨交流，充分肯定了实验室的发展规划和未来前景对实验室下一步工作提出建议和要求，并表示学术委员会将全力支持实验室建设与发展。
随后，来自华南理工大学的张龙辉教授、西北工业大学民航学院的严寅中教授、曹博副教授分别就各自的研究领域最新研究成果进行了精彩的学术报告。
此次会议不仅是对实验室过去一年工作的总结，更是对未来发展方向的深入探讨和规划。实验室将会把大家的建议记在心上、扛在肩上，以引领相关学科实现重大突破，支撑相关产业蓬勃持续发展为己任，为国家的民航事业贡献更多的智慧和力量。
会后，学术委员会成员们合影留念，在与会人员的支持下，会议取得圆满成功。
