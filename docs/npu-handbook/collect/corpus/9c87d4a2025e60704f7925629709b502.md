# 莫航学院开展2026级新生入学教育系列活动（二）

为扎实做好2026级新生入学教育，引导新生锚定成长目标，启航大学新征程，近日，莫航学院围绕党团教育、心理测评解读及学生管理规章制度等内容开展新生入学教育系列活动。2026级辅导员邹昊燃及相关工作负责人担任主讲人。2026级全体新生参加学习。
筑牢思想入党根基，涵养青年报国初心
学院党委组织员高贝围绕申请入党的基本条件、党员发展规范流程及遴选标准等核心内容展开详细讲解。她鼓励同学们要在日常学习生活中锤炼品德修为、提升思想觉悟，以实际行动践行对党的赤诚初心。
传承团史红色基因 凝聚青年奋进力量
学院团委副书记邢文思围绕共青团工作进行专题介绍，带领新生回顾了中国共青团的光辉发展历程，解读了新时代团员青年的使命与责任，解读了新时代团员青年的使命担当，并结合学院团务工作实际，详细介绍了团员发展流程、创新创业、实践服务等重点工作。她鼓励全体新生在理论学习与实践历练中做到知行合一，努力成长为堪当时代重任的青年学子。
厚植心理防护根基 护航青春逐梦新程
学院心理工作专员赵苑、辅导员邹昊燃聚焦校园环境适应、人际交往沟通、学业节奏把控、情绪调节管理等重点内容展开细致讲解，向新生传授科学实用的自我心理调适方法。同时，详细介绍了学校心理健康教育与咨询服务的预约渠道和服务形式，鼓励同学们正确看待心理咨询，遇到困惑时主动求助、及时疏导情绪，以乐观平和的心态融入集体，开启崭新的大学生活。
严守校园行为准则 织密安全防护屏障
主题班会上，辅导员邹昊燃重点开展了学生行为规范教育，围绕防范电信网络诈骗、校园交通安全等方面进行讲解，针对校园骑行、日常人身安全等重点事项加强提醒，引导同学们树牢安全防范意识，携手共建安全有序的校园环境。
本次新生入学教育系统帮助2026级新生在入学伊始树立规矩意识、责任意识与担当意识，助力新生快速适应校园生活、转变身份角色、稳步开启崭新大学生涯。下一步，学院将持续深耕立德树人根本任务，引导全体新生在实干中积淀学识本领、勇担时代使命，以青春之姿逐梦前行、笃行致远，书写属于新时代青年的精彩答卷。
