# 公管学院2027年国家基金申报动员会暨青年教师学术交流会（第七期）顺利举办

2026年10月29日下午，西北工业大学公共政策与管理学院2027年国家基金申报动员会暨“青年教师学术交流研讨会（第七期）”在友谊校区学舟楼102会议室成功举办。学院院长刘晨光，院长助理席建成及学院青年教师参加会议。本期研讨会邀请李冬冬老师和张晓敏老师分别作学术报告，分享论文撰写经验，由张琳老师主持。
会上，刘晨光对近几年学院教师国家级科研项目的申报、获批情况作了介绍。阐述了学院当前面临的发展机遇，强调了学院对青年教师队伍建设的高度重视，并表示学院将全力为各位老师的科研教学与职业发展提供支持。刘晨光对青年教师寄予厚望，希望通过系列研讨会这一平台，有效促进教师间的深入交流与合作，助力大家在申报国家级科研项目、发表高水平学术论文等方面取得突破性进展。
李冬冬以《国家社科基金申请的几点体会》为题作报告，围绕国家社科基金申报全流程，从热点研判、选题打磨、申报书撰写到心得体会四方面分享。结合2026年管理学立项数据，梳理人工智能与人机协同、乡村振兴、绿色低碳等热点，阐释选题应是政策热词、现实痛点与理论缺口的交汇。在申报书写作部分，针对课题论证活页各模块，对选题说明、选题依据、研究内容、创新之处、预期成果、参考文献等的撰写要点、字数把控、常见误区逐一拆解，结合正反案例讲解题目打磨，区分重点、一般、青年、西部项目的选题侧重。最后总结申报经验，提醒规避选题陈旧、框架松散、论证浅薄等问题，建议尽早打磨初稿、多方征求意见，做到“大问题、小切口”，强化问题意识，提升论证逻辑性与严谨性。
张晓敏以《从陪跑到立项:国自科申请的复盘与建议》为题作报告，通过对比2025年与2026年的申报题目，从选题、变量、理论及申报细节等方面展开分享。结合自身从“陪跑”到“立项”的真实申报经历，系统复盘了不同年份申报书修改打磨的全过程，针对申报书中常见的逻辑不连贯、核心变量界定模糊、研究问题聚焦不足等痛点，逐一分享优化思路与调整方法，提醒青年教师在申报过程中避免盲目堆砌文献、脱离实际问题设计研究框架，建议大家在申报前充分研读指南要求，找准自身研究方向与资助导向的契合点，在反复打磨中夯实研究设计的可行性与创新性。
本次研讨会作为学院青年教师发展支持体系的系列举措之一，有效促进了跨学科观点碰撞与学术交流，既为青年教师提供了展示与分享的平台，也为研究生同学的学术成长提供了切实的指导和启发。未来，学院将继续定期举办该系列研讨会，进一步拓宽师生学术交流的渠道，不断激发科研创新动力，营造互促共进的学术生态，持续助力青年教师与研究生的共同成长与发展。
