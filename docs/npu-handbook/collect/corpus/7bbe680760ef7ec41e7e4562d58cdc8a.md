# 宁波市高新区代表团来西工大调研校地合作

7月13-14日，宁波市高新区党工委书记、管委会主任黄利琴带队来校调研校地合作等情况。学校党委书记张炜，中国科学院院士、常务副校长黄维，副校长何国强等分别参加相关活动。
张炜代表学校对黄利琴一行的到来表示欢迎。他指出，西北工业大学高度重视在甬的校地合作发展，希望双方共同加快推进宁波研究院的建设和发展，为服务国家战略发展作出更大贡献。黄利琴介绍了宁波市高新区的发展规划及本次调研的目的，希望双方进一步加强联系，拓展合作，在更多领域实现共赢发展。黄 维指出，西北工业大学科研攻关力量优势明显，特色鲜明，学科建设发展与宁波市“四区一中心”的发展战略具有很强的互补性；同时，学校宁波研究院将在产业孵化、成果转化中进一步发挥关键作用。
代表团参加了与柔性电子前沿科学中心（柔性电子研究院）座谈会，听取了前沿科学中心建设情况的汇报以及项目专题报告，与会人员就柔性电子产业发展、新材料领域产业孵化等方面进行了深入探索。代表团还参观调研了碳/碳复合材料实验室及西安铂力特增材技术股份有限公司、西安鑫垚陶瓷复合材料有限公司等单位。
学校科学技术研究院、材料学院、资产经营管理有限公司、柔性电子前沿科学中心等单位相关负责人及教师代表参加了有关活动。
