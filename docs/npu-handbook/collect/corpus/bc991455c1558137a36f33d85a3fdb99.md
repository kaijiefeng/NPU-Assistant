# 省委教育工委评估验收学校党建“双创”工作

按照省委教育工委的工作安排，6月15日上午，省委教育工委党建示范创建和质量创优工作第一评估验收组组长、西安交通大学党委常委、党委组织部部长柴渭一行5人莅临我校对党建“双创”工作进行评估验收。
学校党委副书记万小朋，校党委常委、党委组织部部长詹浩，学校办公室、党委组织部、党委宣传部等相关职能部门负责人，入选全国和全省党建标杆院系和样板支部的培育创建单位负责人参加了会议。会议由万小朋主持。
会上，詹浩从“建设好党建工作机制、发挥好党建引领作用、推进好党建示范高校建设和培育好党建典型工作成果”等四个方面汇报了学校党建“双创”工作总体情况以及党建工作示范高校建设推进情况。学校入选教育部、陕西省首批党建“双创”工作培育创建单位负责人：航空学院航空结构工程系党支部书记郑锡涛、计算机学院基础教学与实验中心党支部（原计算机学院基础教学部党支部）书记魏英、材料学院党委书记付前刚、航天学院飞行控制技术研究所党支部书记张凯以及动力与能源学院研究生第九党支部书记李冰然先后围绕创建工作成效、存在问题、下一步打算，以及所形成的“四个一”创建成果等方面进行了汇报。航天学院党委副书记王强代表学校入选教育部、陕西省第二批党建“双创”培育创建单位汇报了创建工作进展。
在交流环节，评估验收组查阅了学校党建“双创”成果汇编，并与参会人员围绕学院党委作用发挥、党建促学科发展、党风廉政建设、党建特色工作、党建与业务融合等内容进行了深入交流与探讨。
柴渭代表评估验收组对学校党建“双创”工作给予充分肯定和高度评价。他指出，学校党建“双创”工作扎实有效，形成了特色鲜明的经验做法，引领和推动学校党建工作高质量发展。他同时就下一步做好党建“双创”工作提出了意见和建议，一是要把握“双创”培育创建工作的初心，紧扣学习贯彻习近平新时代中国特色社会主义思想这条主线，进一步夯实学校各级党组织建设；二是要立足质量建党、制度治党，树立重在建设、重在规范、重在引领的培育创建导向，全面提升基层党组织凝聚力、组织力、战斗力；三是要持续发挥好示范引领作用，加强党建工作与业务工作融合，以立标杆、定标准、促后进为抓手，推动学校党建工作再上台阶。
万小朋在主持会议时强调，各培育创建单位要按照评估验收组的要求，进一步提高思想认识，对党建“双创”工作进行再总结、再梳理、再谋划，优化工作思路、创新方法举措、严格对标看齐。同时，要加大对创建经验的宣传推广，充分发挥示范引领和辐射带动作用，不断促进党建和业务双向深度融合，全面提升党建“双创”工作成效。
会后，评估验收组赴航空学院实地查看了航空结构工程系党支部党员活动室和有关成果展示。（党委组织部 王一宁 机关党委 胡亚杰 摄影：郭友军 审核：张永福）
