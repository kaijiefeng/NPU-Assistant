# 物理科学与技术学院强基班香港中文大学暑期实践项目顺利结束

为提升学生全球胜任力，开拓国际视野，2024年7月，物理科学与技术学院本科2021级强基班全体学生在带队老师的带领下赴香港中文大学开展了为期两周的暑期实践项目。本次实践项目包含物理领域讲座交流、地球与环境科学领域讲座交流、文化艺术参观等一系列内容。
香港中文大学物理系和地球与环境科学系分别从天文学物理、凝聚态物理、计算生物物理、生物物理学和定量生物学及地震、大气测量学、近地表地球物理学、雷达遥感等方面安排了多场讲座和交流研讨内容。
除学习交流外，香港中文大学还安排了图书馆、赛马会气候变化博物馆、东涌古炮台、渔民文化村等参观游览活动，加深同学们对中国香港近代历史、文化、艺术、人文景观及自然风情等多个维度的了解。
在香港回归祖国27周年之际，组织同学们参观了香港故宫文化博物馆。
此次暑期实践活动，为学生们提供了国际交流的宝贵机会。同学们纷纷表示此次活动不仅锻炼了科学思维，开拓了科学视野，也有效激发了思维的火花，为他们的学术研究提供了新的思考方向。
