# 生命科学与技术学院顺利举办第十二期“Life生涯讲堂”——学院师生赴迈瑞西安研究院进行访企拓岗暨支部共建活动

为进一步深化校企协同育人，拓展学生实习实践与就业渠道，推进学生高质量就业，10月27日下午，生命科学与技术学院医工交叉创新中心党支部书记李乐教授带队，带领学院师生一行10余人赴迈瑞西安研究院开展访企拓岗暨校企党支部共建交流活动。
在迈瑞相关负责人吴老师的讲解下，师生一行依次参观了企业成果展厅和研发实验室，系统了解迈瑞西安研究院在生命信息与支持、体外诊断、医学影像等领域的技术布局、研发流程与产业化成果。同学们近距离感受医疗器械行业前沿技术，直观认识到学科专业在临床装备研发中的应用场景。
在座谈环节，吴老师详细介绍了迈瑞西安研究院的发展历程、招聘岗位及实习生培养政策，重点围绕生物医学工程、生物技术等专业方向的人才标准进行说明。李乐介绍了生命科学与技术学院的学科特色、生源情况及就业现状，期望双方以本次走访为起点，持续拓展实习实训、科研联合攻关、专场招聘等合作空间，助力生科院学子在生物医学工程领域实现高质量就业。同学们围绕专业方向、岗位发展等积极与企业代表进行深切交流，进一步明晰行业发展趋势。
此次支部共建活动是生命科学与技术学院深入推进访企拓岗促就业专项的重要举措，也是学院与迈瑞西安研究院携手搭建协同育人平台的具体实践。本次走访以支部共建为纽带，让生科学子近距离接触生物医学工程产业前沿，切身感受到行业发展与个人职业规划的紧密联结。未来，学院将持续深化与企业的互联互通，共同探索党建引领下的校企协同育人新模式，共同为培养担当民族复兴大任的时代新人贡献力量。
【迈瑞西安研究院简介】
迈瑞西安研究院是迈瑞医疗全球重要研发中心之一，位于西安高新区，重点深耕生命信息与支持、超声影像相关软件与算法研发，是医工交叉创新的核心平台。依托迈瑞医疗在生命信息与支持、体外诊断、医学影像三大赛道的技术积淀，研究院聚焦临床真实需求，持续开展监护、超声等高端医疗装备的技术攻关、算法迭代与产品验证，汇聚大量软硬件、信号处理、生物医学工程方向研发人才。迈瑞医疗产品服务全球190余个国家和地区，研究院持续面向高校开放实习、校招通道，为医工相关专业学子提供产业实践、科研转化的优质平台，助力高端医疗器械国产化创新。
