# 铸剑班“青年领导力胜任计划训练营”项目圆满收官

2026年8月19日至28日，由中国国际青年交流中心与联合国可持续发展目标与领导力发展中心共同开展的“青年领导力胜任计划训练营”项目正式实施，39名西北工业大学铸剑班学员汇聚日内瓦湖畔，在这座多边外交的摇篮之城，完成了一场为期十天的高规格全球治理研学之旅。项目聚焦全球治理前沿议题与青年领导力系统提升，通过联合国官员大师课程、六大国际组织实地参访、专题学术研讨及成果汇报等核心模块，锻造着眼未来、面向世界的复合型全球治理青年人才。
大师亲授，洞见多边治理前沿
项目开班仪式在日内瓦安全政策中心（GCSP）举行。联合国前副秘书长Fabrizio Hochschild亲自为学员带来首场大师课《联合国与多边主义》。他结合自身在联合国系统数十年的高层经验，系统阐释了联合国在和平安全、人道主义、人权与发展中的运作逻辑，并直面AI时代多边治理面临的规则重构与伦理挑战。课程中，他多次以亲身参与的重大外交事件为例，让学员深刻体悟大国博弈下国际协调的复杂性与使命感。随后，学员们走进国际电信联盟（ITU）总部，聆听官员详解ITU从电报时代到人工智能标准制定的治理演进，并参访联合国日内瓦办事处万国宫，穿行于历史性会议厅与各成员国旗帜之间，直观感受国际规则如何在协商与妥协中诞生。
前沿探索，感知科技与精神之力
在欧洲核子研究中心（CERN），学员分组参观反质子减速器等大型装置，了解人工智能如何实时筛选粒子对撞的海量数据，领略基础科学与智能技术深度融合的突破力量。在专题授课上，联合国大学巴黎办公室高级研究员Serge Stinckwich带来人工智能发展脉络主题课程，警示AI作为工具不能替代人的判断。“两弹一星”元勋钱三强之子钱思进教授应邀作专题报告，他以粒子物理史与CERN运行机制为主线，讲述数千名科学家数十年如一日接力攻关的故事，讲到基础物理奖获奖名单长达数页时，他动情落泪。这场跨越代际的精神对话，让学员们深切体悟到科学探索中纯粹坚守与协同奉献的崇高品格。
职业赋能，对话国际组织选拔实况
Fabrizio Hochschild再次开讲，围绕“国际组织实习与人才选拔”开设实战课程，以Integrity、Professionalism、Respect for Diversity三大核心价值切入，结合真实招聘数据，详解联合国系统面试流程、薪资体系与胜任力标准，将原本模糊的国际化职业规划转化为可量化的行动坐标。此后，铸剑班学员依次参访国际劳工组织（ILO）、国际贸易中心（ITC）和世界卫生组织（WHO）。在ILO，学员们模拟政府、雇主、工人三方议事机制，热议AI对劳动市场的治理影响；在ITC，官员剖析多元学科背景与AI工具在国际贸易中的差异化优势；在WHO，工作人员深入阐释全球卫生应急协调机制。每场交流均由国际组织资深官员亲自接待讲解，学员直面治理实务，收获远超书本认知。
学术淬炼，青年之声赢得专家赞誉
研学期间，坚持每晚集中开展90分钟分组专题研讨，学员们围绕“AI时代国际组织职能重塑”“数字鸿沟下的全球公平”“青年参与全球治理路径”等议题展开激烈交锋，研究框架在每天的反复推敲中趋于完善。
8月26日，本次训练营的学术成果展示环节在GCSP会议室正式举行。此前的研学过程中，五个学术小组分别围绕国际电信联盟（ITU）、国际劳工组织（ILO）、国际贸易中心（ITC）、世界卫生组织（WHO）以及欧洲核子研究组织（CERN）的实地参访与文献调研，形成了五份专题研究报告。各报告聚焦AI时代下的职能重塑、数字公平、全球卫生协调、科技伦理与青年参与等前沿议题，结合一手访谈笔记、公开数据库及多边治理理论，提出具有批判性视角的分析框架与可操作的政策建议。展示当日，各组采用全英文PPT汇报与现场答辩相结合的形式，逐一登台呈现研究成果。授课专家前副秘书长Fabrizio Hochschild、高级研究员Serge Stinckwich等作为评委现场展开深入质询，提问角度犀利且具有学术导向。答辩结束后，随即举行结业仪式。专家评审团首先对学术报告质量给予高度评价，并逐一为学员颁发结业证书。全场掌声热烈，为这场集学术淬炼、视野拓展与使命担当于一体的海外研学画上圆满句号。从实地观察到深夜研讨，从报告撰写到直面答辩，整个闭环不仅让知识内化为能力，更让铸剑班学员们真切体会到中国青年在全球治理议题上发声、建言、贡献智慧的可能与责任。
从万国宫的多边谈判厅到CERN的大型科研装置，从国际组织的职业讲堂到深夜的学术辩论室，学员们不仅收获了全球治理的前沿知识、国际组织的一手经验，更在联合国高官亲自指导下重构了职业愿景与使命担当。学员们纷纷表示，通过本次训练营真切感受到中国青年在全球治理舞台上的责任与机遇。未来，铸剑班学子将以此为起点，以“铸剑”精神融入世界治理实践，在构建人类命运共同体的进程中，发出更加响亮、更加自信的西工大青年声音。
学生感言：
在本次联合国青年领导力胜任计划训练营项目中，我先后参访ITC、WHO、ILO等国际组织，近距离了解国际组织的运行机制，并与机构官员开展交流对话，收获颇丰。前联合国副秘书长法布里齐奥的分享令我深受启发，使我认识到世界各国文化存在显著差异，应当尊重多元文明，秉持和而不同的理念，增进跨文化理解。此行令我印象尤为深刻的是对CERN的走访。我们实地参观全球顶尖的物理实验设施，与科研人员面对面交流。钱思进教授讲述自身科研经历，谈及科研团队为拓展人类科学边界不懈奋斗时的赤诚动容，让我真切体会到科研工作者对知识纯粹的热爱与追求。此次研学开拓了我的国际视野，也进一步明晰了今后的奋斗方向。
——航空学院2025级本科生 卓子涵
日内瓦研学之旅转瞬即逝，却让我收获了长久而深刻的成长。走进联合国及其专门机构ITU、ILO、WHO，以及CERN等国际组织，我不再局限于课本上的抽象定义，而是真切感受到全球治理体系的庞大、精细与多元，也读懂了国际组织“有所为、有所不为”的运行智慧。研学实践中，我学习了前沿课程，聆听了科研讲座与学者分享。尤其在钱思进教授题为“向光而行”的生涯分享课上，老一辈科学家纯粹的科学初心与治学精神深深打动了我，让我更加坚定了以纯粹之心对待学术的信念。这次远行不仅拓宽了我的视野，也让我更加坚定、踏实地深耕专业、追求卓越，未来以专业能力走向更广阔的世界。
——机电学院2025级本科生 陈婉青
本次参与铸剑班赴日内瓦联合国机构研修营，是一次极具价值的全球胜任力实践历练。项目围绕AI FOR SCIENCE与国际人工智能治理主题，让我们近距离走进ITU、CERN、WHO等国际组织，直面多边治理真实场景，系统理解技术创新与全球规则构建的内在逻辑。通过专题课程、机构调研、小组学术研究与成果答辩，我们运用四维分析框架开展研究，在跨文化交流中拓宽国际视野，切实体会多边主义的现实内涵，也对中国参与全球科技治理形成更为立体的认知。感谢学校铸剑班搭建高水平国际化平台，为我们创造对接国际前沿的宝贵机会。此次经历将激励我立足专业所学，持续锤炼综合能力，努力成长为具备全球视野的青年科技人才。
——伦敦玛丽女王工程学院2025级本科生 李卓远
从粒子加速器的数据洪流到公共卫生的数字健康战略，从ITU的频谱分配到ILO的劳工权利，我和同学们在并肩探索中重新认识了世界的经纬。在WHO与官员对话时，我说：“技术的发展应该是服务于人的。”她点头微笑，对我说：“中国在这一点上做得很好，生命永远是第一位。”那一刻，技术的冰冷逻辑被温柔地解构，我看见远方的人们有着和我们一样的想法，看见那些看似遥远的多边谈判如何真切地落在每一个普通人的命运之上。在万国宫廊柱投下的阴影里，我们第一次真正理解了“世界是平的”这句话背后的重量。我意识到，这场训练营带给我的，远不止于AI如何赋能科学、治理如何协调多边，更是在技术的机理中感受人类脉搏的共振。各国教授们的倾囊相授、钱思进教授的精神启迪、组员们夜以继日的争论与碰撞都让西工大一直倡导的“国际视野、家国情怀”与“团队协作、创新引领”，在这一刻有了具体可感的温度。此刻，我们见他人，见天地，而后见自己。

从CERN的加速器到WHO的会议室，从万国宫的谈判厅到ITU的标准讨论桌，鲁迅那句“无穷的远方，无数的人们，都和我有关”忽然有了具体的形状。二战后联合国成立的初衷，正是试图打破地缘政治的牢笼，让远方的人们不再遥不可及。联合国从来不完美，和平与平等的理想也从未完全实现，但这些机构的存在本身就是一种承诺：技术可以为人类所用，远方可以被关照，那些暂时无法为自己发声的人，在谈判桌上有一个位置。抛开地缘政治或许仍是奢望，但在这里，有人持续地为这个目标付出努力。
