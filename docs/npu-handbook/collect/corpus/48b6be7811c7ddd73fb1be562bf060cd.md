# 校招生办公室领导莅临学院指导本科招生工作

为深化本科招生工作成效，持续提升生源质量，2024年10月22日下午，校招生办公室副主任马婷婷、副主任龚思怡莅临数学与统计学院指导本科招生工作。学院副院长郭千桥、院长助理刘晓刚、重庆招生组组长林伟和王振海、招生秘书李彦吉参加了此次会议。
郭院长对马婷婷副主任和龚思怡副主任的到来表示欢迎，对校招办一直以来对学院招生宣传工作的支持表示感谢。
龚思怡副主任对2024年的招生录取工作进行了全面反馈。她从生源质量、学院负责省份录取情况及学院所在大类录取情况等多个维度，详细解读了我校2024年的整体生源质量与招生情况，对学院在重庆地区招生工作中做出的努力和取得的成绩给予了充分肯定。
马婷婷副主任就2025年招生工作给予具体指导，与会人员就工作细节进行了交流和探讨。
本次会议进一步明晰了学院招生工作目标和工作重点，学院将在学校招生办公室的指导下，凝聚全院教师力量，努力做好下年度招生工作，助力学校“总师型”人才培养。
（图文：李彦吉/审核：郭千桥）
