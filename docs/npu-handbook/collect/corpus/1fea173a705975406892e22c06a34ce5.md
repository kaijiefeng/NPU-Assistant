# 督导促规范 营养护成长 ——校医院开展幼儿园月度健康督导暨膳食营养专题交流工作-西北工业大学医院

为进一步规范幼儿园卫生保健管理，夯实校园健康防护体系，切实落实健康副校长月度入校履职职责，校医院依据《陕西省健康副校长工作手册（试行）》相关要求，在幼儿园组织开展学龄前儿童膳食营养专题交流培训及专项卫生督导检查，全园保教老师、保健医、食堂工作人员共计50余人参加本次活动。
儿科医生王儒结合幼儿园保教工作实际，系统讲解学龄前儿童生长发育规律、科学膳食搭配、营养均衡摄入、四季饮食调理及良好饮食习惯培育等重点内容，详细梳理日常膳食照料、饮食行为引导、营养健康宣教等常态化保育要点，内容贴合保教、食堂岗位实际，帮助参训人员掌握幼儿营养照料相关知识，更好地把营养健康知识运用到日常工作当中，守护幼儿身体健康。
培训结束后，健康副校长张毅对照卫生保健标准开展逐项督导检查。现场查阅全园消毒工作登记台账，核对记录填写的规范性与完整性；二是实地检查消毒柜设备运行状态与日常使用落实情况；三是细致排查幼儿毛巾清洗、消毒及规范存放情况；四是巡查幼儿休息区域，核查紫外线灯使用频次及规范操作情况，着重强调常态化开窗通风对校园疾病预防的重要意义；五是对幼儿园食堂环境卫生、日常保洁及食品安全管控情况开展全面督导，细化工作标准、压实岗位责任，推动园内卫生保健工作规范化、细节化落地。
本次培训与现场督导相结合，既提升了教职工营养保健能力，也进一步规范了园内消毒、食堂卫生等保健工作。下一步，校医院将持续落实健康副校长入校督导机制，常态化开展健康指导，不断提升幼儿园卫生保健工作质量，为幼儿健康成长保驾护航。
