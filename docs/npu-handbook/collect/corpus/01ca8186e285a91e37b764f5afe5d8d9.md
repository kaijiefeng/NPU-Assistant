# 民航学院开展“数字赋能课程建设”专题培训

为深入贯彻落实国家教育数字化战略部署，扎实推进数字技术与教育教学深度融合，着力提升教师队伍数字化教学能力水平，4月27日下午，学院在毅字楼218组织开展“数字赋能课程建设”专题培训。本次培训特邀智慧树平台资深讲师担任主讲，学院全体教师通过线上线下相结合的方式同步参加，共同研讨数字时代课程建设的新方法与新路径。
培训过程中，主讲老师围绕高校数智化课程建设的发展现状、人工智能技术赋能课程创新的实践探索、数智化课程建设的具体实施路径以及优秀典型案例等重点内容，进行了系统阐述与深入讲解。培训内容充实全面，实践指导性强，有效契合了当前教育教学改革的工作需求。
培训现场交流互动积极。参训教师普遍反映，此次培训针对性强、实效性显著，有效解决了工作中的疑惑与困难，切实提升了运用数字化手段开展教学的能力素养，为后续课程建设与教学实践奠定了坚实基础。
此次专题培训进一步巩固了学院数字化教学改革的工作基础。下一步，学院将持续常态化开展此类专项培训活动，不断深化数字技术与教育教学全过程的融合创新，为持续推动学院教育教学高质量发展注入新的动力与活力。
