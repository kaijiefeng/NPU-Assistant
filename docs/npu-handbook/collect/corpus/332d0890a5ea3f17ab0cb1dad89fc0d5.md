# 党委保卫部党支部开展理论学习及党课学习教育

6月29日上午，党委保卫部党支部组织开展6月份理论学习研讨及专题党课学习教育。会议由党支部书记朱建军主持，支部党员参加。
朱建军同志领学了《习近平关于树立和践行正确政绩观论述摘编》部分篇目，以及“警示案例与师德规范”“党员干部‘八小时外’100条纪律红线”等重要内容，随后，支部党员围绕学习内容，结合实际工作交流学习心得体会。
王坤庆同志作了题为《树立和践行正确政绩观，以高水平安全保障学校高质量发展》的专题党课。他结合当前保卫工作的重点任务和难点问题，从“政绩为谁而树”“树什么样的政绩”“靠什么树政绩”三个层面展开讲解。他指出，树立和践行正确政绩观是一项长期性、常态化的工程，要求全体党员秉持“功成不必在我，功成必定有我”的胸怀，将所学所悟内化于心、外化于行，努力创造无愧于时代、无愧于学校重托、无愧于师生信任的新业绩。
朱建军总结强调，全体党员要始将正确政绩观融入日常管理服务，把守护师生安全和校园稳定作为第一要务，强化底线思维和极限思维，坚持预防为主、标本兼治，全方位筑牢校园安全防线；要持续加强作风建设，以高标准严要求规范自身言行，锻造素质过硬、作风优良的保卫队伍，以高水平安全保障学校高质量发展。
