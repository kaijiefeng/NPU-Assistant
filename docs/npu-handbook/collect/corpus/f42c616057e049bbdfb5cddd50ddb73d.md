# 夯实科研基础 提升学术素养——软件学院举办《科研及论文写作》专题培训

为不断提升研究生科研素养与学术创新能力，夯实科研基础，10月22日下午，软件学院在启翔楼401举办《科研及论文写作》专题培训。学院干红平副教授参与答疑交流，全体博士一年级研究生和部分硕士研究生集中参加培训。培训聚焦计算机科学和软件工程领域科研选题、学术研究能力提升，旨在服务国家特色化示范性软件学院建设，培养大型工业软件等领域高质量研究人才。
培训围绕科研选题、文献检索与阅读、研究方法、实验设计、学术论文结构、写作规范及投稿流程等内容展开系统讲解，引导博士研究生聚焦关键核心软件的自主创新和自主可控问题开展研究。干红平从科研选题与文献阅读策略入手，提出“先广后精”的阅读方法：泛读阶段快速把握领域核心关注点，精读阶段以批判性思维深入剖析实验设计与评价指标设定；同时，介绍了研究问题的分类思路，并分享了寻找研究方法的路径。在学术论文写作方面，重点讲解如何通过细化通用问题形成独特研究问题切入点，并推荐了首先完成研究问题的定义，以及接下来的写作顺序：“方法—实验—结论-引言—摘要”，以及每部分的写作要点，以确保全文逻辑闭环。在投稿策略方面，主讲嘉宾比较了期刊、会议与杂志等发表载体的差异化定位，分享了选刊技巧与投稿建议。
在自由交流答疑环节，与会师生围绕论文中问题论述的篇幅把握、引言中“背景—问题”的过渡写法、小领域研究的可行性、对比实验的复现与处理、工程问题向学术论文的转化等热点难点问题展开深入交流，干红平逐一作针对性解答。培训中强调，研究生应掌握规范的科研方法，提升学术论文撰写与发表能力，注重问题定义的准确性、逻辑的严密性和贡献表述的清晰性，并综合考虑期刊定位与自身工作的匹配度。
软件学院始终把研究生科研能力与学术水平提升作为高层次人才培养的重要抓手，深耕研究生培养内涵，以高质量科研训练和学术实践赋能人才培养质量提升。本次培训全面夯实研究生科研训练基础，明晰科研选题、论文写作与成果产出的实践路径，为支持博士研究生围绕工业软件关键核心问题开展深入研究、持续提升研究生科研素养与学术创新能力、服务国家特色化示范性软件学院建设提供有力保障，助力取得高水平创新成果，为教育强国、科技强国、人才强国建设贡献软件力量。
