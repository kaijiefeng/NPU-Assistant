# 西工大举办第四届集成电路文化节 游园会上玩转“芯”知识-集成电路学院（微电子学院）

10月17日至18日，第四届集成电路文化节游园会在翱翔学生中心门口举行。活动由共青团西北工业大学委员会主办，共青团西北工业大学集成电路学院委员会承办。
不设专业门槛，无需提前报名。四张桌子依次排开，四道关卡各有趣味。原本藏身在课本和实验室中的芯片知识，在一场场趣味挑战中变得生动鲜活。
游园会现场，同学们围坐桌前，踊跃参与闯关。集成电路学院供图
第一关「芯片图鉴·现场快答」考验观察力与知识储备。同学们随机抽取芯片实物卡，辨认类型、判别功能，并说出相应的应用场景。题目由浅入深，大家也在观察与作答中，逐渐了解不同芯片的特点与用途。
第二关「二进制」比拼思维敏捷度与运算速度。同学们运用2的幂次关系完成进制换算，在一轮轮闯关答题中巩固基础知识，加深对二进制的理解。
同学在摊位上辨认芯片实物卡。集成电路学院供图
第三关「芯片找茬」中，同学们化身质检工程师，在60秒内从芯片阵列中找出5处缺陷。这场限时挑战考验观察力与专注力，也让大家对自动化光学检测（AOI）和芯片良率背后的质量要求有了初步了解。
第四关「‘引脚’对齐大作战」考验手感与耐心。蒙眼转圈后，同学们要在三次机会内，将模拟“引脚”插入对应位置。看似简单，上手才知不易。一次次的尝试下来，大家体会到了精准对位的难度，也更能理解芯片封装对精度的要求。
两天里，摊位前人头攒动。蒙眼挑战时的笑声、闯关成功后的欢呼、兑奖台前的长队，汇成游园会最鲜活的注脚。同学们在游戏中学习，在动手尝试中探索，也在轻松的互动中感受到集成电路的乐趣。纸面上的知识，也在亲身体验中变得可感可知。
同学正在摊位前参与闯关挑战。集成电路学院供图
让知识走出课本，让兴趣连接专业。此次游园会将集成电路知识融入校园生活，为同学们打开了一扇了解专业的窗口。愿同学们带着这份好奇与热情，在今后的学习与实践中，收获更多“芯”知识。
