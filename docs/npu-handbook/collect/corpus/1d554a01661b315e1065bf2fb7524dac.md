# 西安南山苑宾馆有限责任公司-西北工业大学资产经营管理有限公司

西安南山苑宾馆有限责任公司成立于2018年7月9日，注册资本200万元人民币，是西安翱翔工大后勤产业集团有限公司的独资子公司。
南山苑宾馆于2018年8月18日开业运行，位于西北工业大学长安校区，秦岭脚下沣峪口往西5公里，紧邻关中环线，交通便利，占地30余亩，建筑面积约15000平方米。功能设施齐全，内设各种类型客房、学术报告厅、中西餐厅、大宴会厅、不同规格的包间等。其中，客房132间；多功能厅1个、报告厅1个、会议室6间；大宴会厅1个，西餐厅1个，大小各异的宴会包间10个。宾馆大堂设有大堂吧、茶吧、休息区、商务中心、商品区等各类服务区，为宾客提供多样化的服务。此外，宾馆还有健身房、乒乓球室、台球室、多功能室等健身休闲文娱区。
2019年，南山苑宾馆依托自身资源建立了校内大学生劳动实践基地，充分发挥大学生劳动教育等育人作用。开展《劳动教育理论与技能实践》等劳动教育课程，2021—2025年，累计授课64课时，上课学生累计1400余人次。
2023年，宾馆在长安校区校园内打造、运营“云上南山”咖啡馆，并于2024年在咖啡馆内增设“航空书店”，满足师生的多元化需求。
