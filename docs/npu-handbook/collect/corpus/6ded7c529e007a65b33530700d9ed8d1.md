# 党委保卫部举办2025迎新环启翔湖接力赛

12月3日，党委保卫部在长安校区启翔湖畔举办“2025迎新环启翔湖接力赛”，旨在激励校卫队员积极参与业务训练，提升体能素质，培育团队协作精神。50余名校卫队员踊跃参与，党委保卫部部长朱建军及相关科室人员出席并全程观看了比赛。
比赛设置了体能竞赛和业务知识比拼两个单元内容。随着发令员一声枪响，参赛选手如离弦的箭飞驰而出，在迅速完成接力跑和途中各环节答题后，向着终点奋力冲刺。选手们斗志昂扬，配合默契，展现了出了拼搏精神和强大的团队凝聚力，现场气氛时而紧张，时而欢快，场外观众助威呐喊声不绝于耳，欢声笑语一片。经过激烈的角逐，最终杨航东等同志组建的队伍斩获第一名。
2025迎新环启翔湖接力赛不仅丰富了校卫队的业余生活，同时也为校卫队搭建了切磋业务、检验体能的平台，通过以赛促学、以赛促训，提升了校卫队的专业水平和能力，展现了校卫队拼搏向上的精神风貌。
