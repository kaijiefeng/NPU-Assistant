# 聚成长｜学院开展大学生生涯规划专题讲座

为引导2026级新生科学认识专业选择，做好大学阶段生涯发展规划，教育实验学院/未来技术学院/学科交叉中心于10月22日下午举办“知己知彼，规划未来——大学生生涯规划指南”专题讲座。本次讲座特邀学生职业发展指导中心朱莉老师担任主讲，2026级本科生及辅导员代表到场聆听。
讲座上，朱莉老师结合学校毕业生升学、就业整体数据，梳理同学们在专业选择中普遍存在的认知误区。她结合各行业发展现状，细致剖析不同专业对应的能力要求、发展路径与就业去向，帮助同学们对各专业发展前景建立全面客观的认知。
围绕专业选择的实操方法，朱莉老师从自我认知与方向匹配切入，结合大学不同阶段成长特点，为同学们提供系统的规划思路。她鼓励同学们立足自身实际，在实践探索中找准发展方向，理性看待专业选择，以更加从容的心态应对学业发展，为大学学习与长远发展筑牢基础。
本次讲座是学院新生生涯启蒙系列活动之一，帮助新生破除专业选择的认知迷雾，树立科学的专业观与发展观。下一步，学院将持续做实做细新生生涯教育工作，引导学生在探索实践中科学规划学业与发展路径，助力学生高质量成长成才。
