# 【π·归来】海外访学报告第12期——王璇：在英国格拉斯哥大学研究多尺度心肌灌注问题的建模与计算

报告时间：2026年9月8日（周二）上午10:00
报告地点：长安校区海天苑大楼E-101
报告人简介：
王璇，西北工业大学数学与统计学院2022级博士研究生，师从蔡力教授，主要从事心肌灌注的建模与计算的研究。
项目概况及报告内容：
受学校国际化领军人才培养项目资助，王璇同学于2026年3月至8月赴英国格拉斯哥大学数学与统计学院，开展为期6个月的访问交流，合作导师为Hao Gao教授。
访学期间，王璇同学参加了“Modern Optimisation Techniques and Deep Learning”国际学术会议，在Hao Gao教授指导下开展心脏多尺度心肌灌注问题的建模与计算研究，投稿学术论文一篇。本次报告将介绍该生在英国格拉斯哥大学学习期间的收获和体会，以及在心肌灌注建模与计算方面取得的研究成果。
