# 教务部（工程实践训练中心）召开全体教职工大会传达学习学校2026年寒假务虚会、春季学期中层干部会会议精神

3月5日，教务部（工程实践训练中心）召开全体教职工大会，传达学习学校2026年寒假务虚会、春季学期中层干部会会议精神，安排部署中心本年度重点工作，中心全体教职工在VR教室参加会议。
会上，康鹏军副主任带领与会人员共同学习了李言荣书记、宋保维校长在寒假务虚会和新学期中层干部会上的讲话精神，全面传达了学校“十五五”规划核心指标和2026年重点工作安排。他详细解读了李言荣书记关于人才培养、基础研究、干部执行力提升的重要要求，以及宋保维校长部署的2026年九大重点工作，尤其强调了与实践教学工作紧密相关的“总师型”人才培养、教育教学改革、教学质量提升等核心任务，帮助全体教职工精准把握学校发展定位和年度工作导向，深刻领会会议精神实质，切实把思想和行动统一到学校的决策部署上来。
结合学校会议精神和中心职能，康鹏军副主任对本年度重点工作进行了系统部署。他强调，本年度中心要持续紧扣学校“总师型”人才培养目标，聚焦“总师育人文化”在工程实践教学中的落地生根、见行见效，着力推进课程模式革新与实践课程提质，始终以课程建设、教材建设、教育教学研究、平台建设“四位一体”为核心抓手，不断深化工程实践教育内涵建设，推动实践教育高质量发展。同时，要顺应智能产业发展趋势，大力推进人工智能与工程实践教育深度融合，为学校人才培养工作注入新动能。
会议强调，2026年是学校“十五五”规划开局之年，也是中心改革发展的关键一年。全体教职工要提高政治站位，强化责任担当，始终坚持以立德树人为根本任务，牢牢把握工作核心，以“高质量、高水平、高标准”为工作基调，凝心聚力、真抓实干，不断提升实践教学质量，助力“总师型”人才培养，为学校实现“天下工大、世界三航”远景目标，走好高质量内涵式发展道路贡献工训力量。
