# 关于组织开展2022中国正能量“五个一百”网络精品征集遴选工作的通知

各单位：
按照《工业和信息化部办公厅关于组织开展2022中国正能量“五个一百”网络精品征集遴选工作的通知》安排，为进一步做好2022年我校“五个一百”网络精品征集工作，现就有关工作安排如下：
一、相关要求
（一）2021年8月1日至2022年12月31日期间，在网络上原创发布的文字、图片、
音视频、专题专栏、主题活动等五类作品。每个单位最多推荐5件作品，单类作品最多3件。
（二）鼓励报送国际传播作品，是指在境外网络平台发布或落地传播，以及在境内发布、在境外网络平台引起广泛影响的作品。
（三）报送作品应据实申报作者或主创人员，与作品首发时署名和排序等信息一致。刊播时未署名，或作者、主创人员数量超出6名的，需按“集体”名义进行报送。
（四）报送作品不得对原版刊播作品进行重新录制、编辑。音频作品格式为WAV或MP3;视频作品格式为AVI或MP4。图片作品应制作成像素为1422x800至3558x2490之间，不小于1MB的RGB模式JPEG文件。
（五）由多篇作品集合而成的专题或专栏内容，应在整组的开头、中间和结尾3个阶段各择1篇代表作，并进行报送。
具体要求详见附件。
二、作品申报
请于2023年2月3日（周五）前填写报送《工业和信息化系统2022中国正能量“五个一百”网络精品报送作品汇总表》，[已脱敏:邮箱]。
