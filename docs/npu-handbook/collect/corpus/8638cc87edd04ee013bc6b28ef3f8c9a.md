# 西北工业大学材料学院材料微观组织计算及合金设计团队招聘公告

西北工业大学材料学院材料微观组织计算及合金设计团队因工作需要，现面向社会公开招聘非事业编制人员1名，具体要求如下：
一、岗位名称
岗位：科研助理（1名）
二、岗位职责
1.协助完成科研任务，包括但不限于材料微观组织计算、合金成分与工艺设计、实验、采购、调研等工作；
2.负责科研项目数据统计、整理、分析、总结等工作；
3.合金成分设计与熔炼制备、样品加工与热处理、金相制样及SEM/EBSD、XRD 等微观组织表征实验。
三、应聘条件
1.遵纪守法，热爱本职工作，身体健康；
2.熟练掌握各种办公软件，有较好的写作和沟通能力；
3.责任心、服务意识强，有较强的团队协作精神和组织协调能力；
4.本科及以上学历，专业不限，材料科学与工程、物理学、力学等相关专业优先。
四、招聘程序
1.符合条件者请将个人简历、学历、学位证明及其他证明材料电子版于2026年11月17日12:[已脱敏:邮箱]（邮件主题：岗位名称+姓名+学校+专业，不接受压缩文件）；
2.学院对符合条件的应聘者进行初筛，入围者通知笔试和面试，择优录用。
五、考核及待遇
1.考核及待遇参照西北工业大学非事业编制人员有关规定执行；
2.工作地点为西北工业大学友谊校区；
3.试用期6个月，首次聘期3年。
