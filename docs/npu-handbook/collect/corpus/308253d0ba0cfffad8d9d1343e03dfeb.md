# 化学与化工学院分年级召开本科生学情分析会

为持续推进“总师育人文化”走深走实，深化学风建设，提高本科人才培养质量，4月21日，化学与化工学院在学院楼392会议室分年级召开了本科生学情分析会。副院长田威、党委副书记姚东东、本科生各年级辅导员和班主任、教学秘书、学工秘书参加会议。会议由姚东东主持。
各年级辅导员围绕本年级学生日常管理及学情整体情况作详细汇报，结合课程成绩、绩点分布、毕业深造等核心数据，全面梳理不同年级本科生在学业中存在的共性问题与个性化短板，清晰总结各阶段学业发展重点，为后续精准开展学业指导提供数据支撑。各班班主任结合自身经验与班级学生实际，逐一交流班级学生学习状态、课程学习难点，针对个别学生存在的学业薄弱环节、学习动力不足等问题展开深入探讨，分享班级管理与学业引导经验，提出针对性改进建议。
姚东东结合学生思想政治教育与日常管理工作，对思想引领、学风建设、专项帮扶、家校联动等重点工作提出具体要求。他强调，全体学工干部要始终坚持以学生为中心，聚焦学生成长核心需求和教育管理关键节点，充分用好第二课堂、“一站式”学生社区两大育人阵地，强化思想价值引领与综合能力提升。同时，开展常态化学业预警与精准帮扶机制，通过一对一学业辅导、优秀学生学习经验分享、朋辈结对互助共进等多元暖心育人举措，助推学生精进学业水平，夯实专业知识根基。
田威针对本次研讨交流情况总结讲话并指出，本科生学情分析是提升人才培养质量、优化育人举措的重要抓手。学院高度重视本科教学工作与学生全面发展，教学学工要双线密切协同，班主任辅导员要双向紧密联动，全面梳理学情问题，优化教学管理与学业指导服务，做好分类施策与精准对接，切实解决学生实际困难，持续营造优良学风，推动学院本科教学质量与育人水平稳步提升。
本次学情分析会进一步厘清了学院本科生学业进展情况，凝聚了学院育人合力，夯实了学工与教学协同联动的工作平台。下一步，化学与化工学院将建立长效学情研判机制，细化各项学业提升举措，精准发力、持续推进，全力护航本科生成长成才，推动学院人才培养工作高质量发展，为学校总师型人才培养和“一十百千”发展目标的实现贡献化学力量。
