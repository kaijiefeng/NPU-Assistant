# 笑谈健康，多病共防”——校医院成功举办预防疾病脱口秀大赛-西北工业大学医院

10月31日下午，校医院医技公卫党支部联合机电学院、学生MED志愿者协会，在长安校区医院学术厅成功举办“笑谈健康——预防疾病脱口秀大赛”。
比赛现场，来自各学院的9名选手化身“健康段子手”，围绕艾滋病、HPV感染、肺结核、流感等校园常见传染病，结合恋爱社交、宿舍夜话等日常场景，用幽默风趣的语言将晦涩的医学知识转化为接地气的“爆梗”。没有了传统的说教，现场笑声不断、掌声连连，同学们在轻松的氛围中消除了对疾病的恐惧与误区。
为坚守医学科普科学性底线，活动特别邀请预防保健科医师徐欣雨与机电学院责任医师梁乐乐担任专业咨询，对脱口秀涉及的知识点进行严格把关，对互动问题进行现场解析。在选手讲演间隙，现场穿插了有奖问答环节，题目紧扣段子中的核心知识点，观众们踊跃抢答，在轻松互动中加深了对“多病共防”及阻断药、疫苗等知识的了解。
本次活动充分发挥了医技公卫党支部的党建引领与专业优势，打破了传统科普壁垒。未来，校医院将继续以党建为引领，创新健康教育模式，让健康知识更接地气、更有温度，为构建“多病共防”的健康校园贡献力量。
