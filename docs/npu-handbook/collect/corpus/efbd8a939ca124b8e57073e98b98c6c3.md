# 体育部举办运动损伤防治与康复治疗专题培训

10月29日下午，体育部举办运动损伤防治与康复治疗专题培训，特邀运动康复物理治疗师、康复培训师王婷及其团队围绕教师体育运动过程常见的疼痛防治与康复治疗等问题展开专项实践培训。体育部党总支委员徐耀铎主持活动，体育部教师参加培训。
在理论培训环节，王婷围绕身体“力线”展开讲解。她从“鞋是脚的枷锁”讲起，说明尖头收窄鞋挤压脚趾、足底肌肉发力受限、足弓无力，力线异常随之出现，X型腿、O型腿和扁平足往往由此埋下隐患；结合图示分析了O型腿（膝内翻）、X型腿（膝外翻）、圆肩驼背头前引、脊柱侧弯四类常见体态问题的形成机理和易发疼痛点；进而指出“力线偏移不是局部问题，而是上下连锁代偿”，足、膝、髋、脊柱、肩颈是一条完整的链条，一处偏移，疼痛常常出现在远离病因的位置。她结合教师长期站立授课、伏案备课、低头批改作业的职业特点分析，久站久坐、姿势单一，容易出现身体其他部位代偿 （使用过多的部位出现劳损，使用不到的部位闲损），从而形成了身体的肌肉张力失衡、力线传导错误，进而在足踝、膝、髋、腰、颈、肩等身体代偿较多的关节、肌肉、筋膜出现活动受限，弹性变差，粘连变多，身体循环变慢等积累问题，她反复提醒大家，早发现、早干预，比事后治疗更重要。
在康复治疗演示环节，王婷邀请有不适症状的老师走上治疗工作台，逐一进行体态评估，现场判断引起疼痛的来源与诱发病因，随后施以手法治疗，她边操作边讲解力度、方向和注意要点。台下教师对照自身情况和指导学生开展体育运动及竞技比赛中遇到的问题不时提问交流、深入探讨，王婷逐一进行了解答，现场气氛热烈。
参加培训的老师表示，这次培训内容聚焦、重点突出、实用性强，不仅让我们进一步了解到运动损伤带来的身体疼痛防治与康复治疗的专业知识 ，更对教师开展学生健康教育、体育运动指导和带好竞技队伍帮助很大。过去，我们遇到膝痛、腰痛，多以为是局部劳损，这次才更加清晰的弄懂了还要从足、膝、髋、脊柱的力线关系上找原因的道理，也知道了个人身体健康日常需要注意的有关事项，很有收获。
此次专题培训依托教师发展支持培训计划开展。下一步，体育部将继续针对广大教师业务深耕、技能提升、职业发展和身体健康等需求安排培训内容，以务实举措助力教师成长成才、健康工作、积极奉献。
