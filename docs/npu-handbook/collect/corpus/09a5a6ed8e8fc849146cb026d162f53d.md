# 2025级新生安全温馨提示来了！

亲爱的新生同学们：
金色的九月奏响青春的乐章，欢迎你正式成为“西工大人”！从今天起，这里将是你逐梦的新起点，而安全，则是这段旅程最温暖的底色。为帮助大家平安、从容地开启大学生活，党委保卫部（保卫处）结合校园实际，整理了一份“新生安全锦囊”，愿每一位新伙伴都能将安全意识融入日常，让成长之路畅通无忧。
安全锦囊一：警惕诈骗陷阱，守护财产安全
1.刷单诈骗
常见诈骗手法： 以“高薪兼职”“日赚千元”为诱饵，小额返利后诱导大额投入。
防范技巧： 所有网络刷单均为诈骗，坚决拒绝任何形式的垫资要求。
2.注销校园贷诈骗
常见诈骗手法： 冒充客服、平台工作人员，声称账户异常、影响征信，威胁诱导转账或要求共享屏幕。
防范技巧： 个人征信由中国人民银行统一管理。凡以注销账户、消除不良记录等为由要求转账或共享屏幕的，均为诈骗。
3.低价购物诈骗
常见诈骗手法： 在网络平台发布远低于市场价的商品信息，诱导私下交易或点击不明链接支付。
防范技巧： 务必在正规平台交易，坚决拒绝脱离平台支付的要求。
4.冒充熟人诈骗
常见诈骗手法： 盗用QQ、微信等社交账号，冒充亲友、老师等，以紧急用钱为由要求转账。
防范技巧： 涉及转账汇款，必须通过电话或当面核实对方身份，切勿轻信文字信息。
5.网络交友诈骗
常见诈骗手法：伪装成网友建立信任关系后，诱导在虚假投资理财或赌博平台投入资金。
防范技巧： 凡网友推荐投资理财或赌博平台的，均为诈骗。切勿轻信“稳赚不赔”“内幕消息”。
6.防骗应急指引
“国家反诈中心APP”是公安部推出的权威反诈工具，能有效识别和预警诈骗电话、短信、APP，请务必下载安装并开启预警功能。
切勿随意泄露身份证号、银行卡号、手机验证码、家庭住址等重要信息。涉及钱财问题，务必通过官方渠道或直接联系当事人确认。
一旦怀疑被骗或已转账，立即保留好聊天记录、转账凭证等证据，并第一时间拨打党委保卫部电话或110报警。
安全锦囊二：严守消防规定，共建平安校园
1.入校时严禁携带易燃易爆物品。
2.在宿舍严禁私拉乱接电线，不得使用热得快、电暖器、电炉等大功率违规电器，以防电路过载引发火灾；离开宿舍时，务必关闭所有电器电源，拔掉插头。
3.要主动熟悉教室、图书馆等公共场所的疏散通道和安全出口位置，确保紧急情况下能迅速、有序撤离。
4.严禁损坏消防设施和器材，严禁使用明火，切勿乱扔烟头；
5.严禁将电动自行车、电动滑板车等使用蓄电池的交通工具在室内、楼梯间、公共走道、门厅等区域停放或充电；不得将蓄电池带入室内存放或充电；严禁从室内私拉电线到室外充电。
6.如遇到火情，立即拨打党委保卫部24小时值班电话及119火警电话，并迅速撤离至安全区域。
安全锦囊三：遵守交通规则，保障出行安全
1.校园内有共享自行车、电动自行车等供使用，建议大家不购买电动自行车。对于已购置的电动自行车，应自觉遵守《西安市电动自行车管理规定（试行）》的相关要求，为电动自行车登记上牌；不使用无牌车辆。
2. 骑乘电动自行车、摩托车必须佩戴符合标准的安全头盔。严禁私自非法改装车辆或购买、使用超标车辆。
3.坚决不乘坐校门口及地铁站周边的“黑车”，保障自身安全及事故后的合法权益。
4.电动自行车、机动车等必须停放在指定区域，服从管理人员安排。
