# 南京大学胡大平教授来学院作学术报告-西北工业大学

5月22日，南京大学胡大平教授为西北工业大学马克思主义学院全院师生带来题为《“我”在超级现代性中的流失》的学术报告。本次讲座由学院副院长张云龙教授主持。
在科技飞速迭代与全球化深度交织的今天，胡大平教授指出“我是谁”这一古老追问正面临前所未有的挑战。随着基因编辑、人工智能、合成生物学等技术的突破，传统关于生命与自我的理解框架已发生动摇，我们正步入一个“超级现代性”时代，个体不仅在生理层面成为可被加工的对象，更在消费社会与数字媒介中被碎片化、商品化与虚拟化。
从“永生的海拉”细胞到转基因作物的普及，从AlphaFold精准预测蛋白质结构到“生命3.0”概念的提出，技术已将生命视为可编程、可优化的系统。与此同时，消费主义与社交媒体催生出身份多变、情感流动、人格分裂等现代问题，不仅广告与时尚主导着欲望，而且虚拟社区取代了邻里温情，个体在追求自由与个性的过程中，反而沦为商品逻辑的载体，内心空虚与过度曝光并存。
最后，面对“我”的流失，胡大平教授指出在现代技术社会、智能社会中，只有重新定位人的本质，才能摆脱人的孤立原子状态而融入相互依存的社会关系，从被动接受技术的客体转变为承担责任、追求希望的主体。正如卡西尔所言，人应不断审视自身生存状况，在符号与文化中重建理想世界，唯有寻回共同体、呵护心灵、树立崇高镜像，方能在流动的时代中锚定自我，重获尊严与意义。
