# 校领导为后勤部办公室党支部讲授专题党课

为深入学习贯彻学校第十四次党代会精神，增强党员干部职工的责任感、使命感，12月25日下午，校长助理兼后勤部党工委书记、后勤部部长王宇波为后勤部办公室党支部讲授专题党课，主题为《从影视作品中的西工大元素看我校为党育人、为国育才的人才培养历程》。支部全体党员30余人参加了此次学习。
王宇波主要从“怀救国之心，成国之栋梁——老一代校友救国之路”“铸大国重器，挺民族脊梁——中生代校友报国之路”“凝大国剑锋，圆强国之梦——新生代校友强国之路”“为党育英才，为国铸重剑——西工大现象”四个方面充分阐释我校人才培养的初心与使命。他结合“古路坝灯火”“寻找师昌绪”等影视话剧，以及一个个生动的故事、一幕幕感人的视频，形象生动地阐述了三代校友拼搏奋斗的精神和科技报国的决心。
党课的最后，王宇波强调，作为西工大的后勤党员，也必须肩负起为党育人、为国育才的重任，加快推进一流后勤建设，助力续写新时代人才培养“西工大现象”新篇章。
这堂生动的党课，使在场的党员们深受鼓舞。大家纷纷表示，要把不怕苦、不怕累，有韧劲、不畏难，耐得住寂寞，经得住诱惑的优良传统和扎实作风贯穿后勤工作的方方面面，强化责任担当、主动履职作为，持续为学校“127”近期目标和“天下工大、世界三航”远景目标的实现贡献后勤人的力量。（撰稿人：毛淑兰；审稿人：韩争胜）
