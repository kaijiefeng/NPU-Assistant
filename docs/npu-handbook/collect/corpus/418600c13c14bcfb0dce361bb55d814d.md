# 我校成功举办第十四届CICC青年科学家论坛暨机器人与具身智能论坛

4月18日至19日，第十四届CICC青年科学家论坛暨机器人与具身智能论坛在西安建国饭店成功举办。中国工程院戴浩院士、唐立新院士，中国科学院于登云院士，以及南京航空航天大学校长姜斌教授、西北工业大学党委副书记杨晓、中南大学阳春华教授、北京空间飞行器总体设计部王大轶研究员、中国科学院自动化研究所侯增广研究员、重庆大学罗均教授、北京师范大学李小俚教授等专家学者齐聚一堂。来自清华大学、国防科技大学、上海交通大学、浙江大学、西安交通大学、哈尔滨工业大学、北京师范大学、北京航空航天大学、北京理工大学、天津大学、东南大学、东北大学、中南大学、湖南大学、重庆大学、电子科技大学、南京航空航天大学、南京理工大学、上海大学、西北工业大学等高校的专家学者，来自中国航天科技集团、北京空间飞行器总体设计部、中国科学院自动化研究所、中国科学院空天信息创新研究院、中国科学院沈阳自动化研究所、中科院深圳先进技术研究院等科研院所和行业单位的专家代表，以及师生代表共计400余人参加论坛，围绕机器人、具身智能、智能控制与航天应用等前沿方向开展深入交流。本次论坛由中国指挥与控制学会主办，CICC青年工作委员会、西北工业大学航天学院、陕西省自动化学会智能机器人专业委员会承办。
开幕式由航天学院院长黄攀峰教授主持。
中国指挥与控制学会名誉理事长、中国工程院戴浩院士，西北工业大学党委副书记杨晓分别致开幕词。
戴浩院士致辞
杨晓副书记致辞
开幕式期间，举行了2025年度CICC青年人才托举工程启动仪式。
主论坛上，唐立新院士作题为《基于DAO的制造循环工业系统机器人技术》的报告。
于登云院士作题为《智能航天助力两创发展》的报告。
南京航空航天大学姜斌教授作题为《先进飞行器导航控制与健康管理》的报告。
阳春华教授、王大轶研究员、侯增广研究员、罗均教授、李小俚教授以及黄攀峰教授分别作主论坛报告，围绕先进飞行器导航控制与健康管理、工业具身智控大模型、空间飞行器自诊断重构、医疗机器人的人机交互与闭环控制、高性能复杂结构多机器人协同制造、脑电与无创神经调控、航天器超精超稳控制等主题分享了最新研究进展。
4月19日，论坛开设具身智能分论坛、机器人控制分论坛、机器人学习分论坛、CICC青托分论坛和CICC博士生分论坛。30余位来自不同研究领域的专家学者和青年学者聚焦具身世界模型、机器人操作、智能制造、边缘智能、数据驱动控制等主题，带来了精彩纷呈的学术报告。
具身智能分论坛由中国科学院深圳先进技术研究院程俊研究员、西北工业大学刘正雄教授主持，刘洪海教授、薛建儒教授、刘敏教授、赵春晖教授、齐俊桐教授、王钢教授等业内知名专家作分论坛报告。
机器人控制分论坛由西北工业大学张夷斋教授、张帆教授主持，徐昕教授、吴新宇研究员、张立宪教授、蒲华燕教授、边桂彬教授、叶茂娇教授等业内知名专家作报告。
机器人学习分论坛由西北工业大学马志强教授、刘星教授主持，兰旭光教授、徐静教授、刘浩教授、刘安安教授、尤著宏教授、刘行健教授等业内知名专家作报告。
CICC青托分论坛由白成超主持，卢宛萱、李一辰、杨松岩、牛伟纳、韩煜祺、王宇航等作报告。CICC博士生分论坛由化永朝主持，钟山、袁泽安、于铭瑞、杨月婷、徐正怿、王琛、马永胜、康倩、李晓林、吴桢、曾丹平等作报告。
CICC青年科学家论坛暨机器人与具身智能论坛为控制、机器人与具身智能领域的专家学者和青年科技工作者搭建了高水平交流平台。论坛聚焦学术前沿和国家需求，促进了不同研究方向之间的深度交流，为青年人才成长和相关领域创新发展注入了新动能。
