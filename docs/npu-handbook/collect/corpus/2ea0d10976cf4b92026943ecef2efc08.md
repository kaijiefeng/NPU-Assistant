# 生命科学与技术学院召开庆祝建党105周年暨“七一”表彰大会

6月30日，生命科学与技术学院召开“聚合力，守初心，迎‘七一’”—庆祝中国共产党成立105周年暨生命科学与技术学院“七一”表彰大会。学院党委书记段利兵、副书记张敏乔、受表彰的个人和先进学生党支部负责同志，各党支部党员代表等参加会议。会议由张敏乔主持。
大会在庄严的国歌中拉开帷幕。
段利兵宣读学院表彰决定。
辅导员乔雪琪、张敏乔、段利兵分别为获得“优秀学生共产党员”“优秀学生党务工作者”“先进学生党支部”荣誉称号的先进个人和集体颁发证书。
随后，优秀学生共产党员代表研究生第二党支部叶永懿、优秀学生党务工作者代表修复生态学师生融合党支部丁森旭、先进学生党支部代表秦岭生态监测与保护师生融合党支部郝鑫怡依次作交流发言。他们结合自身情况和支部建设的实际，分享了践行初心使命、勇于担当作为的深刻体会和宝贵经验，表达了在今后的学习工作中将继续笃行实干、奋勇争先。
大会特别设置了“共过政治生日”环节，段利兵向近1年接收为预备党员的党员代表赠送了学院精心准备的政治生日贺卡，勉励各位党员时刻铭记党员身份，永葆政治本色。
政治生日贺卡颁发完毕后，大会进行了入党宣誓环节。近一年来新接收的预备党员面向党旗庄严宣誓，全体与会正式党员一同重温入党誓词，进一步强化了新党员的入党认同感与归属感，深化了老党员的组织观念与纪律意识。
宣誓礼毕，张敏乔带领全体与会党员共同学习《中国共产党章程》部分章节，通过原原本本学、逐字逐句悟，大家更加深刻地理解了党员的权利义务和党的纪律规矩，进一步增强了学习党章、遵守党章、贯彻党章、维护党章的思想自觉和行动自觉。
最后，段利兵以“树立和践行正确政绩观，谱写高质量发展新篇章”为题，讲授了专题党课。他围绕习近平总书记关于树立和践行正确政绩观的重要论述、开展树立和践行正确政绩观学习的重要意义，准确把握正确政绩观的核心要义和实践标准以及树立和践行正确政绩观的实践路径进行了深刻阐述。鼓励全体师生树立和坚持正确的政绩观，在服务“健康中国”“美丽中国”建设中建功立业，在教书育人和成长成才中书写无愧于时代的答卷。
