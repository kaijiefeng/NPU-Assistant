# 电子信息学院党委书记侯俊讲授树立和践行正确政绩观学习教育专题党课

6月5日下午，电子信息学院党委书记侯俊以“‘实’字当头 ‘干’字为要”为题，面向全院党支部书记、党支部委员、发展对象共130余人讲授树立和践行正确政绩观学习教育专题党课。党课由学院党委副书记高敏主持。
党课上，侯俊立足习近平总书记关于树立和践行正确政绩观的重要论述，从树立和践行正确政绩观的重大意义、核心要义、正反典型案例剖析、师生如何笃行实干四个维度系统展开讲授。他围绕“政绩为谁而树、树什么样的政绩、靠什么树政绩”三个重大问题层层深入，通过焦裕禄、黄文秀、谷文昌等先进榜样的实干事迹，对照高校学术不端、秦岭违建别墅等反面警示案例，清晰阐明了正确政绩观的核心要义与实践要求。侯俊结合学院工作实际，指出教师群体的正确政绩观，就是坚守为党育人、为国育才的初心使命，要将立德树人作为检验一切工作的根本标准；青年学生要自觉摒弃功利化、短视化的成长误区，把个人“小我”融入国家发展“大我”。
最后，侯俊强调，树立和践行正确政绩观，起决定性作用的是党性。他勉励全体师生自觉加强党性锻炼，切实把正确政绩观内化于心、外化于行，将学习教育的成效转化为推动高质量发展的实效。
