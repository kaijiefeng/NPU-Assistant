# 学生助学贷款办理流程

一、生源地助学贷款
1.国家开发银行生源地助学贷款
学生申请后，需将助学贷款回执交至党委学生工作部学生资助服务中心，贷款放款至代办机构（支付宝、招行银行、平安银行等）学生个人账户后，由当地学生资助服务中心从代办机构学生个人账户划转学杂费金额注1至学校账户。学校学生资助服务中心汇总后按批提交学生名单和到款明细至财务处，财务处批量处理冲抵学杂费欠费，冲抵后余额转入财务系统所维护工行卡中；未足额缴纳的部分，由学生后续自行缴纳。
注1：学杂费金额并非贷款金额，贷款金额中包含的生活费在代办机构（支付宝、招行银行、平安银行等）账户暂存，学生自行取用。
2.其他银行生源地助学贷款
学生在其他金融机构（农商行、农信社等）申请后，按照金融机构填写学校账户信息注2及备注信息（学号及姓名），待金融机构放款后，财务处收款并按备注信息手动入账。入账后冲抵学杂费欠费，冲抵后余额转入财务系统所维护工行卡中；未足额缴纳的部分，由学生后续自行缴纳。
如转账时未备注信息，在放款一个工作日后，持转账银行回单和身份证明至财务处办公点现场入账。

二、校园地助学贷款
校园地助学贷款（中国银行），学生通过中国银行手机银行申请当年的国家助学贷款并签订电子贷款合同后，学杂费金额注3于当年10-12月银行分批次转入学校国家助学贷款专用账户，生活费发放到学生的中国银行卡里。学校学生资助服务中心收到银行发放名单汇总后按批提交学生名单和到款明细至财务处，财务处批量处理冲抵学杂费欠费，冲抵后余额转入学生中国银行卡中，未足额缴纳的部分，由学生后续自行缴纳。
注3：学杂费金额并非贷款金额，贷款金额中包含的生活费在中国银行账户暂存，学生自行取用。
