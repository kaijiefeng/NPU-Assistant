# 西北工业大学机电学院本科人才培养反馈意见调查办法（2012年版）

为了充分掌握我院本科生人才培养效果及其毕业后的发展情况,有依据地适时修订专业培养方案、改进教育教学模式和方法等，本着长效、客观、可行的基本原则，特制定本调查办法。
第一条在本科应届毕业生中，作为毕业教育内容之一，就本科生人才培养内容进行全体毕业学生问卷调查，主要考查应届毕业生对于培养目标、毕业要求、课程体系等的意见和建议，具体调查问卷内容由系主任和专业负责人根据各专业情况组织出具。该调查工作由本科生辅导员负责安排调查、回收问卷。
第二条在学院本科生各专业中，每年随机确定1到2个毕业班作为样本班，该班毕业生均为本科生人才培养效果征询意见和建议的主要调研对象。在每个样本班中，确定一名责任心和组织力强的同学为班级组织联络员，负责联络和组织本班所有同学积极参与并配合母校本学院完成有关调研工作。
第三条针对毕业后约第5年和约第10年的调研对象，每年4月份进行一次调研，调研对象如实填写“毕业生对本科人才培养的反馈意见表”，同时在毕业生协助及学院及专业系的联系沟通下，主要针对培养目标、毕业要求、课程体系以及毕业生发展情况等获得3-5家典型用人单位及企业专家的评价意见和建议。调查结果材料由该班组织联络员转交学院教学办。具体调查问卷内容由系主任和专业负责人根据各专业情况组织出具。
第四条本科生教学办负责组织保存并合理使用调查问卷。根据需要，调查结果可由教学办反馈给主要院领导、系主任、专业负责人、课程负责人、教学办、学生口、班主任及相关教师等，用于改进教育教学工作。
第五条针对往届毕业生的调查，学院校友分会和班级组织联络员保持联系，收集调研材料，撰写调研报告等。
西北工业大学机电学院
2012年8月20日
