# 关于开展西北工业大学2025-2026学年春季学期学生社团活动立项申报工作的通知-青春驿站-共青团西北工业大学委员会

各学生社团指导单位：
为深入学习宣传贯彻习近平总书记关于青年工作的重要思想，持续弘扬“总师育人文化”，进一步发挥学生社团在校园文化建设中的重要作用，打造一批具有示范性和影响力的优质学生社团活动，现就2025-2026学年春季学期学生社团活动立项申报工作通知如下：
一、申报时间
即日起至3月13日
二、活动类型
（一）德育活动
培养学生具有正确的世界观、人生观和价值观，引导学生具有正确的政治观念和良好的道德品质，践行社会主义核心价值观的德育活动。
（二）智育活动
关注学生的能力发展和知识积累，帮助学生掌握系统的科学文化知识、技能，培养解决问题的能力和创新思维的智育活动。
（三）体育活动
坚持健康第一的教育理念，推动文化学习和体育锻炼协调发展，增强学生的体质，培养学生健康的生活方式和体育精神，开展团队协作的体育活动。
（四）美育活动
通过艺术教育和审美教育，使学生具有正确的、健康的审美观，培养学生发现美、鉴赏美和创造美的能力，培养学生高尚情操和文明素质的美育活动。
（五）劳育活动
培养学生具有正确的劳动观念和熟练的劳动技能，引导学生理解劳动的价值，注重培育学生的劳动素养，激发学生劳动热情的劳育活动。
三、申报安排
（一）申报阶段
1.项目申报
各学生社团指导单位填写《西北工业大学2025-2026学年春季学期学生社团活动申报表》（附件1）和《西北工业大学2025-2026学年春季学期学生社团校级活动意识形态审核意见表》（附件2），有相关成果的活动可随申报表提交支撑材料。
2.
活动评审 团委学生社团指导中心对各学生社团指导单位提交的材料进行初审，对申报项目组织评审，结合现场答辩、推送投票、校园文化活动督察员反馈等情况综合打分，评选出立项活动。
（二）实施阶段
1.管理活动经费。各学生社团指导单位要做好活动预算规划，据实填写经费预算，活动过程中需合理分配资金，避免浪费。
2.做好工作记录。各学生社团指导单位要做好活动过程的记录，包含留存活动宣传素材、活动现场照片、活动改进措施等。
3.规范组织实施。各学生社团指导单位要根据相关要求，至少提前一周在“翱翔门户—办事大厅—西北工业大学学生活动审批备案”提交活动审批，至少提前3个工作日在“团团小文体”小程序提交宣传物料，及时更新活动信息，组织活动参与成员签到签退。
（三）结项阶段
1.做好信息录入。活动现场阶段结束后的3个工作日内，各学生社团指导单位须确定并公布参与人员名单与获奖名单，获奖人数不得超过参与人数的15%，并录入“团团小文体”小程序。
2.提交活动材料。活动现场阶段结束后的3个工作日内，各学生社团指导单位需配合活动督察员完成材料撰写，提供活动目标达成情况、宣传素材、现场照片等，并整理活动报销材料。
3.参与活动评估。学校团委将结合活动成效及意义对活动进行验收，按照活动验收效果在学生社团评星定级时酌情赋分及进行相应比例的报销。
四、活动要求
（一）强化意识形态审核把关，保障活动质量
各学生社团指导单位应依据青年学生成长成才的需求，以习近平新时代中国特色社会主义思想为引领，遵循思想性、知识性、艺术性、趣味性相结合的原则，支持跨社团（至多四个）融合特色资源，举办方向准确、内涵充实、品位高雅、形式丰富的高质量社团活动，推动青年学生德智体美劳全面发展。
（二）规范活动开展，确保工作实效 各学生社团要在活动开始前两周向主办单位做好报备，严格按照申报书内容规范开展活动，不可随意变换活动内容，以高度的责任感配合学校团委做好立项活动的督查考核工作。要提前做好活动应急预案，注重加强学生社团指导单位的过程性指导。
（三）注重活动宣传，做好工作总结 各社团要做好活动宣传，利用好新媒体平台展示活动风采，扩大活动影响辐射面。活动结束后，应及时进行成果总结，评奖评优工作需遵循公正、公平和公开的原则，并广泛听取师生的意见和建议，汲取经验，及时反馈。
五、提交要求
各学生社团指导单位于3月13日17:00前将由单位主管领导签字、单位盖章的纸质版申报表报送至长安校区星天苑综合服务大楼“青春驿站”203学生社团指导中心，[已脱敏:邮箱]，邮件主题及压缩包命名为“学生社团指导单位名称—活动类型（德/智/体/美/劳育活动）—学生社团名称”。
