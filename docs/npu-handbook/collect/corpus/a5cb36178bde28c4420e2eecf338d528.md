# 电子信息学院召开党委理论学习中心组（扩大）会议 传达学习贯彻党的二十届五中全会精神

11月2日下午，电子信息学院召开党委理论学习中心组（扩大）会议，传达学习贯彻党的二十届五中全会精神。学院党委理论学习中心组成员、教职工党支部书记参加学习，会议由党委书记侯俊主持。
会议传达学习了党的二十届五中全会精神、《中共中央关于持之以恒推进全面从严治党若干重大问题的决定》、教育部党组扩大会议精神以及学校党委书记张云明在校党委理论学习中心组扩大会议上的讲话精神。会上，参会人员对标学校党委提出的学习贯彻工作要求，结合学院办学实际开展学习研讨，深刻领会和把握持之以恒推进全面从严治党的重点任务和实践要求。
会议强调，要把深入学习贯彻全会精神作为当前和今后一个时期的重大政治任务，与学习贯彻习近平党建思想结合起来，以高度的政治自觉、思想自觉、行动自觉抓好全会精神学习贯彻工作。要认真落实张云明书记在学校党委理论学习中心组扩大会议上提出的工作要求，深刻认识持之以恒推进全面从严治党的极端重要性和现实紧迫性，坚持党建工作与中心工作深度融合、同频共振，把全面从严治党要求贯穿办学治院全过程，切实把学习成效转化为攻坚克难、干事创业的实际动力，推动学校党委部署的各项重点任务在学院落实落细、走深走实。
会议要求，各党支部要在一周内通过“三会一课”、主题党日等形式将全会精神传达到每一名党员，重点围绕《决定》原文和学校党委工作部署开展学习研讨。要对标学校党委学习贯彻要求，立足电子信息学科特色，把学习贯彻全会精神与学院发展痛点、育人堵点、科研难点、治理卡点结合起来，带着问题学、联系实际悟、立足岗位干，把学习成果体现在人才培养、有组织科研、师资队伍建设和学科建设实际成效上，以全面从严治党新成效保障学院各项事业高质量发展，助力学校加快建设中国特色、世界一流大学。
会议还通报了关于做好中央巡视期间有关工作事宜。
