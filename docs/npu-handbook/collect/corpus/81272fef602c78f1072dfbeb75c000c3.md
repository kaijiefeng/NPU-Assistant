# 计划财务部赴航空学院开展财务专题宣讲会

为进一步提升财务服务质量，强化制度执行规范，7月2日下午，计划财务部走进航空学院开展财务专题宣讲会。学院科研副院长李斌、新进教师、各科研团队人员参加宣讲会。
本次宣讲紧扣科研一线师生实际需求，内容覆盖科研经费全生命周期管理、报销实务操作、信息系统应用，以及招标采购与合同管理全流程。计划财务部结合学校最新财务管理制度，通过政策解读、系统演示、风险点梳理等方式，明确经费使用红线，针对性解答了科研项目预决算编制、经费报销、合同签订及财务系统使用过程中的常见问题。
参会人员纷纷表示，此次宣讲会内容充实、务实高效，帮助大家准确把握制度要求、熟练掌握操作规范，强化了科研经费合规使用的思想自觉和行动自觉。
下一步，计划财务部将持续巩固“走出去、送服务”工作机制，常态化深入学院开展财务宣讲，打通财务服务“最后一公里”，不断提升财务管理和服务水平，为学校高质量发展提供坚实财务保障。
