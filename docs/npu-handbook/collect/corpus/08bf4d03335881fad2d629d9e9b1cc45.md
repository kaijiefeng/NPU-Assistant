# 科研到款立项入账业务流程

业务流程描述：
①项目负责人请先与对方单位核实到款情况，确保该笔到款已汇抵学校账户。
②项目负责人登录翱翔们门户科研系统，点击“经费到款认领”，进入搜索界面，输入对方单位名称和来款金额（单位：万元），点击查询即可搜到对应到款，点击“认领”，进入认领界面，填写相关项目认领信息，提交即可。
注：2014年之前立项的项目，科研经费到款认领仍走线下方式办理。
