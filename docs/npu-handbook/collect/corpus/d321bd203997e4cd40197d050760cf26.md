# 关于举办“2024西北工业大学校园马拉松”的通知

全校师生及校友：
学校定于5月19日，在西北工业大学长安校区举办“2024西北工业大学校园马拉松”。现将赛事的相关内容与注意事项通知给大家，请所有参赛人员按时参加，安全比赛。
一、时间地点
（一）比赛时间
2024年5月19日9:00
（二）比赛地点
西北工业大学长安校区
（三）比赛线路
本站赛事全程6.8公里。
起终点：西北工业大学长安校区北门东风广场。
比赛路线沿途经过东风广场、巡航北路、东大路、三航大道、华山路、巡航西路等（详见下图）。
（四）检录
1.检录时间：8:00--8:45；
2.检录地点及方式：所有选手须在赛前15分钟到达西北工业大学长安校区北门东风广场，凭参赛号码布进行检录，请选手合理安排出行时间，提早到达起点检录，比赛风雨无阻。
（五）竞赛规程
见附件1.2024西北工业大学校园马拉松竞赛规程。
二、物资领取
1.本次活动报名时间已于5月3日结束，报名成功的师生、校友短信已发送，没有收到短信的师生、校友可以在报名平台上查询，如若查询不到，则报名未成功；
2.组委会为所有参赛选手提供参赛服、号码布（带芯片）。获得参赛资格的运动员，请于赛前持有效身份证件（原件、复印件均可）和赛事领物短信（支持代为领物），于2024年5月18日10:00—20:00，在西北工业大学长安校区云天苑田径场西侧跑廊领取比赛物资。比赛当日无法领取参赛物品，请选手合理安排领物时间。
三、车辆道路安排
1.校车安排由后勤部统一负责，请各位师生、校友合理安排时间乘坐校车前往长安校区参加比赛(校友出示校友证乘车)；
2.开车前往参赛的教职工、校友请将车辆停在家属区或云天苑篮球场。赛事期间，比赛沿途路线严禁停放各种车辆，请老师们合理安排停车，如收到移车通知，请于5月18号下午18:00之前尽快驶离赛道，以免给第二天的比赛活动带来不便；
3.道路封闭时间：2024年5月19日上午8:50—上午10:30分（重点路口如东北门等采取集中出入管理措施执行）。
四、注意事项
（一）本次赛事不提供存取衣物服务。
（二）参赛选手应身体健康，有长期参加跑步锻炼的基础。有以下身体状况者不宜参加比赛：
参赛者应在有资质的正规医疗机构进行体检，并结合体检报告评估自己的身体状况，确认是否可以参加相关运动比赛。有以下疾病或状况者不宜参加比赛：
1.先天性心脏病和风湿性心脏病患者；
2.高血压和脑血管疾病患者；
3.心肌炎和其他心脏病患者；
4.冠状动脉性心脏病患者和严重心律不齐者；
5.如果在做轻微活动时感到胸部中等程度疼痛；
6.血糖过高或过低的糖尿病患者；
7.比赛日前两周以内患过感冒者；
8.赛前一晚大量饮酒或睡眠不足者；
9.孕妇；
10.其他不适合运动的疾病患者。
在比赛中，如有身体不适，请随时停止跑步，改步行，症状明显的立即退出比赛，向道旁志愿者求助。因个人身体及其他个人原因导致的人身损害和财产损失，由参赛选手个人承担责任。
