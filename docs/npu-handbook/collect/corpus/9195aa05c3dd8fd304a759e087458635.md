# 我要当总师”学生宣讲团第五期｜立报国强国大志向，做挺膺担当奋斗者

为深入贯彻落实党的二十大和二十届三中、四中全会精神，认真学习贯彻习近平总书记关于教育、科技、人才的重要论述，大力弘扬总师育人文化，2025年12月4日，教育实验学院党委“我要当总师”学生宣讲团面向西安高级中学百余人研学团队开展“立报国强国大志向，做挺膺担当奋斗者”主题宣讲活动。
宣讲团成员王梦雨、张瑞分别聚焦我国空空导弹、“澳门科学一号”卫星B星总设计师，深情讲述了科研工作者们的爱国热忱与拼搏征程。王梦雨以“铸剑长空征程”为脉络，生动勾勒出怀揣航空梦想的少年成长为共和国空空导弹事业领军人物的奋斗轨迹，既让同学们清晰见证我国空空导弹技术从“仿制起步”到“自主创新跨越”的飞跃式发展，更被科研团队“精益求精攻难关、集思广益铸利刃”的拼搏精神深深感召。张瑞以“星海逐梦的坚守”为主题，通过攻克微小卫星技术难关的鲜活细节、饱含家国情怀的奋斗篇章，让同学们既深刻体悟“澳门科学一号”卫星B星从构思设计到成功发射的艰辛与荣耀，更真切感受科研工作者“扫清缺陷勇奋斗、星辰大海谱新篇”的责任担当与赤子情怀。
“我要当总师”学生宣讲团将持续围绕弘扬总师育人文化开展系列活动，打造校际青少年成长交流优质平台，让更多青少年走近总师、读懂总师。以榜样之光点亮青春理想，为成长注入“为国铸剑”的精神动能，播撒矢志报国的火种，引导广大青少年立大志、明大德、成大才、担大任，奋力成长为堪当民族复兴重任的时代新人。
