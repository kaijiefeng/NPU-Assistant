# 陕西省学位与研究生教育研究中心赴广西融水开展爱心助学捐赠活动-西北工业大学研究生院

10月29日，陕西省学位与研究生教育研究中心组织学位与研究生教育领域专家团队和西北工业大学研究生院师生代表，赴广西融水苗族自治县香粉乡中心小学开展爱心文具捐赠活动，延续西北工业大学十一年定点帮扶传统，以教育助学助力民族团结进步和乡村振兴。
陕西省学位与研究生教育研究中心由陕西省教育厅批准设立、依托西北工业大学建设，是从事学位与研究生教育研究的专门学术机构。香粉乡中心小学坐落于苗山深处，是西北工业大学定点帮扶片区内的乡镇中心小学。长期以来，西北工业大学坚持党建领航，构建教育提升、科技筑梦、产业增收、消费帮扶、健康医疗等“六位一体”帮扶模式，持续在该校落地三航科普、AI梦想课堂、物资捐助等教育帮扶项目。一批山区孩子在趣味科技启蒙中走近航天与人工智能，在心底种下科学梦想的种子。本次捐赠，是研究中心立足自身职能，依托西工大帮扶基础、联动科教资源、深化陕桂教育协作、落实科教助学的务实行动。
捐赠仪式上，专家代表向学校移交笔记本、彩笔等爱心文具，把来自陕西的关怀送到孩子们手中。专家勉励同学们珍惜学习机会、勤学善思、心怀理想，铸牢中华民族共同体意识，厚植家国情怀，把社会各界的关爱转化为逐梦前行的动力。
活动现场交流期间，专家团队详细了解学校办学条件、少数民族学生培养、三航科普进校园、思政教育实施等情况。立足研究生教育研究视角，同学校负责人、驻村工作队、支教教师围绕山区基础教育质量提升、青少年科学素养培育、民族团结教育载体创新等议题深入交流，共同探索后续科教资源共享、研学联动等合作路径。
香粉乡中心小学校长梁意仁对研究中心一行表示感谢。他谈到，此次爱心捐赠充实了学生学习物资，进一步打通校地沟通渠道，为学校用好西北工业大学帮扶资源、常态化开展科普启蒙、建设书香校园提供有力支撑。现场孩子们拿到崭新文具，脸上洋溢着喜悦。
下一步，陕西省学位与研究生教育研究中心将持续依托西北工业大学定点帮扶融水的良好基础，充分发挥学术平台优势，扎实开展民族地区教育帮扶，推动优质教育理念和科教资源向苗山腹地延伸，以教育牵线赋能民族地区乡村教育提质增效。
