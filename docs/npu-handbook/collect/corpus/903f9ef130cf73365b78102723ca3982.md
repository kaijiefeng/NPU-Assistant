# 自动化学院举办2022年度第二期研究生导师培训会

为全面贯彻党的教育方针，提升研究生培养质量，推进一流研究生人才培养行动计划落实落地，11月24日下午，自动化学院成功举办2022年度第二期研究生导师培训会。我校物理科学与技术学院赵建林教授应邀作主题讲座。院长韩军伟出席会议并致辞，学院全体研究生导师通过线上和线下相结合的方式参加会议。会议由副院长王小旭主持。
韩军伟教授在致辞中强调，导师是研究生培养的第一责任人，要始终牢记“为党育人，为国育才”使命，坚持立德树人的根本任务，做研究生成长成才的指导者和引路人，加强师德修养，以德立身、以德立学、以德施教、以德育德，为党和国家培养出一批德才兼备的高层次优秀人才。
赵建林教授以《立德树人，严谨治学——做一个尽职尽责的研究生导师》为主题，他结合自身长期从事一线教学、科研、学科建设及人才培养工作的丰富经历，分别从导师的作用与素质要求、导师与学科的关系、导师与学生的关系、研究生培养过程的关键环节、培养和提高学生能力等方面做了生动精彩的经验分享，提出了很多指导研究生的宝贵建议，并就研究生日常培养中遇到实际困难的处理经验和与会老师进行了深入交流。
王小旭教授就研究生招生、培养、授予学位等关键环节的校院两级相关文件制度进行了详细解读，着重介绍了导师在研究生培养各个环节应如何落实第一责任人职责，如何把好培养质量关，如何增进导学关系。同时，以学院一流研究生人才培养行动计划为落脚点，强调了研究生导师要在落实一流行动计划中发挥关键作用，为学院培养一流人才添砖加瓦。
本次研究生导师培训旨在进一步夯实导师第一责任人职责，帮助新导师全面及时了解研究生教育教学最新动态，尽快熟悉导师职责，促进导师指导能力和指导水平的提升，切实增强导师对研究生人才培养工作的责任感、使命感和认同感。
