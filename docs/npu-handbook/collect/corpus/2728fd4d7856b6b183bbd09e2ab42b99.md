# 《人民日报》刊发我校无人系统发展战略研究中心黄汉桥教授的专家点评文章

5月4日，习近平总书记给中国青年五四奖章暨新时代青年先锋奖获奖者代表回信，向全国各族青年致以节日祝贺并提出殷切期望。《人民日报》要闻版报道我校无人系统发展战略研究中心主任黄汉桥关于青春力量托举国产无人机的专家点评文章。
报道全文如下：
“九天苍穹”无人航空通用平台腾空而起，“新舟鸿鹄”HH—200航空商用无人运输系统首飞成功……我国无人机产业连续突破。观察其背后的研发团队，许多80后、90后航空青年勇挑重担，托举国产无人机飞得更好。
年轻思维是产业革新的活水。青年工程师敢突破固有思维，跳出传统研发定式；敢在参数博弈中反复试错，在复杂工况中打磨技术。这股“初生牛犊不怕虎”的闯劲，源自跨学科视野、创新活力与钻研韧劲，适配无人机产业多元攻坚需求。但也要看到，除了热血理想与大胆突破，理性敬畏与长期沉淀更为难得。从“追求单点最优”到“追求系统最优”——这是工程思维成熟的标志，也是年轻人从“会造飞机”到“会造好飞机”的转变。
“十五五”规划纲要为低空经济健康有序发展划定清晰方向，无人机产业正从技术探索迈向产业化落地，政策赋能、赛道扩容，时代已为青年铺开追梦画卷。这里不缺前沿技术、不缺发展机遇，缺的是敢于直面航空领域研发门槛高、周期长、压力大等挑战，善钻研、肯深耕、沉下心的新生力量。而产业参与各方也应搭建培育平台，完善成长通道，破除发展壁垒，给年轻人容错试错的空间；畅通晋升路径，让才华不被埋没，让付出能有回响。
无人机的苍穹没有边界，青年的潜力亦无上限。持续给机会、搭舞台、强支撑，让更多专业精、重实践、能担当的青年扎根低空赛道，助推我国低空产业奔赴更远征程。

据悉，我国自主研制的高空长航时多用途重型“九天”无人机于2025年12月在陕西蒲城成功首飞，标志着我国大型无人机技术实现新突破。该机型由智能无人系统高端智库（无人系统发展战略研究中心）、人工智能学院/无人系统技术研究院、无人飞行器全国重点实验室联合航空工业一飞院共同论证。平均年龄仅约34岁的青年攻关团队在徐德民院士的带领下，面向国家重大战略需求，从确立研制定位与技术构型，到飞控测试与仿真搭建，青年人勇挑大梁，发挥重要支撑作用，为项目落地奠定了坚实基础。“九天”的成功，是我国无人系统蓬勃发展的缩影，更是青年人在我国无人机行业逐步占据创新主力军的重要体现。
当前，青年科技人才发展已经上升为国家战略，从“教育强国、科技强国、人才强国”的一体部署，到各类青年人才支持计划的出台和落地，政策暖意正持续转化为创新动力。学校大力弘扬“低调务实、兼收并蓄、厚积薄发、为国铸剑”的总师育人理念，以“九天”等重大项目为牵引，持续为青年搭建创新赛道，托举越来越多优秀青年在无人系统发展大潮中脱颖而出，让青春在蓝天翱翔中闪光，中华民族伟大复兴的中国梦必将在一代代青年的接力奋斗中变为现实。
智能无人系统高端智库（无人系统发展战略研究中心）是学校为推动无人系统学科创新发展、服务国防科技事业而重点打造的新型高校科技智库，于2025年入选首批国家级高端智库试点建设机构（高校仅2所），面向国家重大战略需求，聚焦无人系统领域的新质能力生成、科技发展、产业布局、学科建设与人才培养等重大问题，采用“小核心+大协作”运行模式，开展前瞻性、针对性、储备性的战略研究、战略咨询及战略评估，为国防建设提供坚实智力支撑。
人工智能学院/无人系统技术研究院作为学校在智能领域重点布局的新兴交叉学院与科研机构，于2023年获批建设无人飞行器技术全国重点实验室，聚焦世界科技前沿，引入多元化社会资源开放办学理念和产学研用协同模式，重点开展融合空/天/地/海/电多维空间、具备智能感知与认知/智能决策/自主协同控制及人机共融能力的无人化系统体系及相关科学技术研究。
（文：智能无人系统高端智库 审核：徐晓峰）
