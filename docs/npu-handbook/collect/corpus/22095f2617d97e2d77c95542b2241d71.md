# 【大赛通知】关于举办2023年中国大学生工程实践与创新能力大赛全国总决赛的预通知

为深化高等工程教育改革，加强卓越工程人才培养，2023年中国大学生工程实践与创新能力大赛新能源车赛道太阳能电动车赛项和虚拟仿真赛道工程场景数字化赛项将于11月24-26日在西北工业大学长安校区举行国赛总决赛。
中国大学生工程实践与创新能力大赛是教育部高校工程训练教指委组织，全国工程创新实践类规模最大的竞赛，是持续推动高等学校本科教学质量提升、加强新工科建设、深化教学改革的重要载体。
届时，将有来自全国198所高校的275支学生队伍进行两个赛项的角逐。欢迎广大老师和同学们前来观摩、学习，共同见证青年创新力量的崛起。
中国大学生工程实践与创新能力大赛组委会
西北工业大学工程实践训练中心
2023年11月21日
