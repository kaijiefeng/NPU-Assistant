# 北京研究院党支部召开主题教育专题民主生活会-西北工业大学

按照学校《关于开好学习贯彻习近平新时代中国特色社会主义思想主题教育专题民主生活会的通知》要求，8月28日上午，北京研究院党支部召开学习贯彻习近平新时代中国特色社会主义思想主题教育专题民主生活会，北京研究院党支部全体党员及学校第六督导组宋强同志出席会议。
首先，党支部书记方文杰代表领导班子进行了深入对照检查，向大会详细汇报了2022年度民主生活会整改措施落实情况和本次民主生活会准备情况，从6个方面突出问题和12条具体要求出发，深入检视问题并制定整改措施。随后，班子成员方文杰、李捷依次进行了个人对照检查发言。
宋强在点评时表示，北京研究院主题教育专题民主生活会会前准备充分、领导班子和班子成员对照检查聚焦问题、剖析检视全面深刻、整改举措方向明确，达到了以学铸魂、以学增智、以学正风、以学促干的实践要求。希望北京研究院领导班子和班子成员坚持当下改和长久立相结合，进一步完善各项工作体制机制。
方文杰在总结时表示，开展主题教育是今年党的建设的重大任务。全体党员干部，要以此次民主生活会为契机，坚持学思用贯通、知信行统一，把习近平新时代中国特色社会主义思想运用到贯彻落实党的二十大提出的重大战略部署中去，转化为坚定理想、锤炼党性和指导实践、推动北京研究院工作的强大力量。
