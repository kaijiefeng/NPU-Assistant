# 【蓝色情怀】生命科学与技术学院组织学生赴西安卫星测控中心参观学习

为深入推进“三个一”实践育人，助力“总师型”拔尖创新人才培养，2026年10月29日下午，西北工业大学生命科学与技术学院组织学院铸剑班（第二期）学员、学生党员代表20余人赴西安卫星测控中心开展“第二课堂”参观学习活动，实地了解我国航天卫星测控事业发展历程，感悟深厚航天精神，厚植科技报国情怀。此次活动由学院学工主管马倩老师带队。
首先，同学们观看了我国航天卫星测控事业发展宣传片，系统了解卫星测控技术在航天工程中的重要作用、发展历程与主要任务。接着，中心老师围绕我国航天事业发展历程，重点介绍了从东方红一号、二号到载人航天工程、北斗卫星导航系统等重大任务的发展经过，生动讲述了我国航天事业从无到有、由弱到强的不凡历程。最后，同学们围绕卫星测控技术、航天工程应用及未来发展趋势等话题踊跃提问，中心老师逐一耐心解答，现场气氛热烈。
此次参观学习是学院深化实践育人、拓展学生视野的重要举措。参观学生纷纷表示，本次学习打破了书本认知的局限，近距离领略大国重器风采，感悟实干精神，既开阔了眼界，也激发了科研报国的热情，后续会扎实学好专业知识，锤炼过硬本领。
未来，学院将继续依托校内外实践育人平台，引导学生走进国家重点单位、重大工程一线，在真实场景中受教育、长才干、作贡献，不断提升人才培养质量。
【学生感想】
铸剑班 2026级本科生 黄永冰：今天，我们有幸参观西安卫星测控中心，进一步体会到国家航天航空事业的逐步壮大！ 正是先辈们矢志报国、协同攻坚的伟大精神，推动中国航天航空事业的不断进步！作为新时代青年，我们应该以先辈们为榜样，树立远大理想，努力学习，争取为国家航天事业做贡献！
铸剑班 2026级本科生 张广耀：今天，我来到西安卫星测控中心研学，学习我国卫星事业发展历程，了解到测控中心承担着卫星在轨监测、轨道控制等关键任务。这里的航天测控人有一个浪漫的名字 ——牧星人，他们以电波为鞭，在地面守护遨游太空的航天器。一代代牧星人隐姓埋名、精测妙控，默默坚守岗位。我由衷敬佩航天人甘于奉献、勇攀高峰的担当。今后我会努力学好本领，传承航天精神，立志为祖国航天事业贡献力量。
