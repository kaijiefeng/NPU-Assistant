# 大赛通知-关于举办第三届全国大学生职业规划大赛校级选拔赛暨西北工业大学第十届 “飞鲨杯”大学生职业生涯规划大赛的通知

关于举办第三届全国大学生职业规划大赛校级选拔赛暨西北工业大学第十届 “飞鲨杯”大学生职业生涯规划大赛的通知
日期：2025-10-22 16:52 浏览次数：256
各培养单位：
为了激发和培养学生的职业规划意识，引导学生树立“立大志向、上大舞台、入主战场、干大事业”的职业发展观，合理规划大学学习与生活，进一步促进毕业生高质量充分就业，按照《教育部关于举办第三届全国大学生职业规划大赛的通知》（教学函〔2025〕2号），特举办第三届全国大学生职业规划大赛校级选拔赛暨第十届“飞鲨杯”大学生职业生涯规划大赛。现将有关事项通知如下：
一、大赛主题
筑梦青春志在四方，规划启航职引未来。
二、赛事介绍
本次大赛分为成长赛道和就业赛道。
（一）成长赛道
面向本科非毕业年级学生，考察其树立生涯发展理念并合理设定职业目标、围绕实现目标持续行动并不断调整的成长过程，通过学习实践提升综合素质和专业能力，体现正确的择业就业观念。
（二）就业赛道
面向本科高年级计划求职学生（不含已通过推免等确定升学的毕业年级学生）及研究生。考察其求职实战能力，对标目标职业及岗位要求，个人综合素质和专业能力等方面的契合度，个人发展路径与就业市场需求的适应度。
三、赛程设置
（一）赛事时间安排
院赛时间：10月23日至11月30日
校赛时间：12月1日至12月31日
（二）比赛流程
1.院级选拔与推荐工作
各培养单位须统筹部署本院赛组织工作，明确1名专职教师作为院赛负责人，组织院赛安排事宜。院赛结束后，各赛道须择优推荐3名优秀选手晋级校赛复赛，并同步组织所有选手通过全国大学生职业规划大赛平台（网址：zgs.chsi.com.cn）报名，使用学信网账号登录，系统开放权限后提交电子版报名材料，报名截止时间不晚于2025年12月31日。
2.校赛筹备与选拔
学生职业发展指导服务中心将在校赛启动前，统筹组织晋级选手开展赛前集训，内容包括参赛技巧指导、作品优化建议、模拟答辩等，助力选手提升竞赛水平。
集训结束后，由学生职业发展指导服务中心牵头组织校赛评审工作，具体时间及安排另行通知。
四、校赛奖励设置
成长赛道与就业赛道（本科生组、研究生组）皆按以下标准设置奖励：
一等奖1名：奖金 8000 元，荣誉证书一份。
二等奖2名：奖金 5000 元，荣誉证书一份。
三等奖3名：奖金 2000 元，荣誉证书一份。
优胜奖6名：蓝牙耳机（除一、二、三等奖以外的决赛选手），进入决赛学生将择优推荐至省赛、国赛。
五、组织机构
本次大赛由西北工业大学党委学生工作部主办，陕西省教育厅指导，沈阳飞机设计研究所提供赞助。
