# 力学与土木建筑学院举办青年教师发展论坛—学术沙龙第五讲

2022年11月30日下午，力学与土木建筑学院青年教师发展论坛——学术沙龙第五讲，在学院延安精神活动中心召开。本次青年教师发展中心邀请网络空间安全学院党委书记、科技探索奖、中国青年五四奖章及国家杰出青年基金获得者王震教授，做题为“学科交叉背景下的青年教师成长与发展”的讲座。20余名师生参加了此次学术研讨活动。
王震教授结合自身情况及自己深入的对青年教师发展的理解对我院青年教师做基础科研及工程应用工作给予全方位讲述与指导，讲座后青年教师及同学针对王震教授讲座内容、自身发展路径进行研讨交流，王震教授结合自己课题组及长期以来对青年教师发展的细致思考给与细心的解答。
学院青年教师发展中心致力于通过定期的学术沙龙活动为广大研究学者搭建科研学术交流平台，积极营造交叉、创新、融合、互鉴的学术氛围，为高层次人才培养和高水平科研成果产出提供有力支撑。
