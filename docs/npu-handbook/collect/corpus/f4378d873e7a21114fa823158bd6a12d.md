# 西北工业大学医院圆满完成迎新生系列工作-西北工业大学医院

8月21日至9月6日，在校医院全体职工的共同努力下，2026级新生入学体检、出血热疫苗接种及军训医疗保障等迎新生系列工作圆满完成。校医院在保证两校区正常诊疗的同时，以充分的准备、高效的组织和温暖的服务，为新生顺利入学保驾护航。据统计，本次共完成新生入学体检11404人，为新生接种出血热疫苗7105剂次。
为确保各项工作顺利开展，校医院于8月20日召开工作会议，对体检时间安排、场地设置、人员配备、设备管理、军训保障点设置、急救药品配备及突发情况应急预案等进行全面研讨与细致部署。从体检流程优化、功能区规划到医疗设备调试、应急物资储备，每一个环节都力求周密，为迎新生系列工作奠定了坚实基础。
新生体检：高效有序，圆满完成
8月21日，本科新生入学体检在长安校区正式启动；8月30日，研究生新生入学体检在两校区同步开展。在学生志愿者和现场医务人员的共同引导下，各项检查有条不紊地进行，现场秩序井然，流程衔接顺畅。体检期间，医院在两校区抽血处贴心准备了含糖饮料和面包，防止学生因空腹抽血出现低血糖反应。
疾病防控：筑牢防线，步步扎实
根据长安校区所在高新区的防疫要求，校医院积极落实疾病预防措施，为新生接种出血热疫苗7105剂次，并优化结核病筛查，由血液检测（IGRA）替代结核菌素试验，切实筑牢校园公共卫生安全防线，为学校疾病预防和卫生保障工作打下坚实基础。
军训保障：全程守护，保驾护航
8月24日起，2026级本科生军训正式拉开帷幕。校医院统筹调配医疗资源，在两校区设置多个军训医疗保障点，共派出294人次医疗保障人员，为4400余名参训新生的健康安全保驾护航。针对军训期间常见的中暑、低血糖、运动损伤、皮肤晒伤等情况，各保障点配备了充足的藿香正气水、创可贴、碘伏、冰袋等常用药品和急救物资。
医疗保障人员冒着酷暑坚守训练场，早、中、晚三班轮换，密切关注参训学生身体状况，做到早发现、早处置、早转运；对症状较重的学生，迅速启动应急预案，通过绿色通道及时转运至校医院进行救治。同时，医务人员还利用训练间隙向新生普及高温防护、科学补水、运动损伤预防等健康知识。
此次迎新生系列工作的圆满完成，充分体现了校医院全心全意为师生服务的宗旨和扎实高效的工作作风。校医院将继续以优质的医疗服务守护校园健康，为学校人才培养和中国特色世界一流大学建设提供坚实的医疗保障。
