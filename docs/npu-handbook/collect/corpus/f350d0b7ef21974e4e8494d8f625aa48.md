# 航海学院举行校内外研究生导师代表座谈交流会

2025年5月26日，航海学院校内外研究生导师代表座谈交流会在武汉成功举行。会议由航海学院副院长曾向阳教授主持。
曾向阳对各位校外导师百忙之中来参加座谈会表示欢迎，并就我院的师资队伍建设、研究生培养及学院发展思路向与会的校内外导师代表作了简要介绍。
校外导师强调了自身在学生培养过程中的角色与责任，提出应不断改进与学生沟通的方式，提升学生的实务能力。同时，校内导师也分享了研究生培养的要求和学生需求，强调专业实习对专业型研究生完成毕业论文的重要性以及校外导师扮演的重要作用。
最后，曾向阳代表航海学院对各位校内外导师表达了感谢，并希望今后多开展此类活动，不断加强导师与导师之间、导师与学生之间的交流，进一步提升航海学院研究生培养质量。
此次交流会不仅加深了校内外导师之间的了解与合作，还为研究生培养工作提供了新的思路和方法。未来，航海学院将继续通过交流会、专题工作坊等形式加强校内外导师的沟通与协作，共同推动研究生培养质量的不断提升。
（审核：刘朝亚，王银涛)
