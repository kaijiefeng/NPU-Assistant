# 智绘芯乡村・豫鲁谱新篇 | 寻访红色足迹 溯源农耕文脉 青春助农步履不停-集成电路学院（微电子学院）

7月27日，西北工业大学集成电路学院“智绘芯乡村・豫鲁谱新章”暑期三下乡社会实践队在指导教师刘昊旻带领下，在河南省新乡市开展多维度实践。团队围绕红色研学、民情走访、文脉探寻、科普志愿四大主题开展实践，汲取奋进力量，把握发展方向，践行青年担当，扎实推进科技助农实践。
团队首先前往新乡县七里营镇刘庄村史来贺同志纪念馆开展红色思政学习。馆内史料还原了史来贺带领村民钻研技术、发展集体经济、实现共同富裕的奋斗历程。
参观结束后，队员们深入田间地头与农户家中，围绕农业智能化普及现状开展走访调研。通过与农户面对面交流，团队详细了解了当地大田种植中智能灌溉、植保农机等设备的普及情况，也真切捕捉到小农户面临的设备采购成本高、操作门槛高、后期运维不便等现实痛点。
随后，团队先后走进新乡市平原博物馆与市科技馆深化实践认知。在平原博物馆，队员们在农耕文明展区系统梳理了华北平原农耕智慧的传承与迭代脉络，理解了农业技术进步对乡村发展的核心价值，对中原粮食主产区的农业根基形成了具象认知。
在科技馆内，队员们化身科普志愿者，为参观的中小学生讲解展品科学原理，结合实践主题讲解芯片、传感器在智慧农业中的应用，将专业知识转化为趣味科普，种下科技兴农的种子。互动现场氛围热烈，队员们也深化了对自身专业价值的理解。
此次实践行程丰富，队员们对“科技助农”形成了更立体的认知。后续团队将继续深耕实践，把所学转化为实干动力，以集成电路专业技术为乡村振兴注入青春动能。
