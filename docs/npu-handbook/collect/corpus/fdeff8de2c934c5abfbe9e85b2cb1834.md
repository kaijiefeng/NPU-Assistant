# 无人系统技术研究院开展科研经费管理专题培训

5月19日，为聚焦科研经费的全流程管理及风险防控，提升团队在预算编制、执行监控、绩效评估等环节的专业能力，无人系统技术研究院邀请前国防科工局经济发展中心审计二处副处长朱伟，就科研经费管理进行专题培训。研究院各团队教师代表及财务助理等参加培训，党委书记毛昭勇主持培训。
朱伟强调了科研管理规范化的重要性，通过科研项目审计案例，系统梳理并详细讲解了科研财务管理制度的框架及其常见问题，为提升资金使用效率提供了具体而有效的建议。
毛昭勇总结指出，此次培训对于加强研究院内部控制和提升科研合规性具有至关重要的作用。未来，研究院将针对无人系统研发的特点，进一步明确经费管理操作规则，确保通过制度创新保障科研项目的高效执行。
