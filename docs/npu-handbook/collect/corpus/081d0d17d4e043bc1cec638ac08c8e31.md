# 中国商飞-西工大大飞机研究院学术委员会第一次会议顺利召开

9月2日，中国商飞-西工大大飞机研究院学术委员会第一次会议在西北工业大学太仓智汇港召开。学术委员会主任、中国商用飞机有限责任公司（以下简称中国商飞）专家工作组组长赵越让，学术委员会主任、中国科学院院士张卫红，中国商飞专家组副组长郭博智，C919型号首席专家韩克岑、中国商飞制造总师姜丽萍、中国商飞二级专家杨志刚、C919型号首席专家周贵荣，校务委员会副主任万小朋参加会议。会议由张卫红院士主持。
万小朋代表学校对中国商飞-西工大大飞机研究院学术委员会第一次会议的召开表示祝贺，他指出，学术委员会是大飞机研究院的最高学术机构，要发挥专业优势和行业优势，把准研究方向，找准实际需求，为双方开展联合攻关提供战略咨询和学术指导，共同推动大飞机研究院工作实现高质量发展。
会议主要针对大飞机研究院首批研究基金项目指南进行评审。会上，大飞机研究院执行院长、北研中心科技管理部部长冯荣欣介绍了研究院建设进展及指南策划情况。评审组依次听取了项目指南汇报，查阅了相关材料，对项目研究的必要性、研究目标与技术指标、研究内容、预期成果等方面进行了质询和评议。
此次评审的指南是在大飞机研究院第一次理事会形成的第一批意向项目基础上，双方多次对接交流，特别是从中国商飞的研制需求出发、发挥西工大科研特色优势形成的。
会前，双方共同参观了太仓智汇港实验室。
大飞机研究院学术委员会委员，中国商飞科技管理部及北研中心，学校科学技术研究院、太仓智汇港管委会相关负责人参加会议。
