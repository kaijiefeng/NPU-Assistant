# 党委书记张云明、校长宋保维检查指导本科招生录取工作

7月24日上午，校党委书记张云明、校长宋保维检查指导2026年本科招生录取工作。副校长岳晓奎参加。
张云明、宋保维详细了解了学校招生工作总体进展、各省录取情况，对现阶段录取工作予以肯定，对全体招生工作人员表示慰问。张云明、宋保维强调，当前正值招生录取的关键阶段，要严守工作纪律、规范录取流程，强化全过程监督管理，确保招生录取公平公正、平稳有序。要系统梳理招录工作经验做法，持续优化改进招生策略，源源不断地吸收符合学校“总师型”人才培养目标的优质生源。要进一步优化招生服务，以信息化手段提升招生服务的普惠性、可及性、便捷性，及时做好政策解读、信息发布、答疑解惑等工作，营造暖心舒心良好氛围。
宋保维还为部分新生录取通知书签名。
（文字：李佩、姚远；图片：司哲；审核：马婷婷、付怡）
