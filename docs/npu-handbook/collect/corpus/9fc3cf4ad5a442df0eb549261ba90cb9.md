# 后勤办公室党支部开展观影主题党日活动

为纪念抗美援朝战争胜利70周年，弘扬爱国主义精神，加强党员党性修养，10月18日下午，后勤办公室党支部联合基建处党支部共建开展“弘扬爱国主义精神厚植爱党爱国情怀”主题党日活动，集体观看爱国主义影片《志愿军：雄兵出击》。
电影取材于历史真实事件，详细讲述了新中国抗美援朝战争缘起。剧情跌宕起伏、催人泪下，英雄先烈们用自己的血肉之躯坚定不移地阻挡住了敌人的钢铁洪流，描绘了抗美援朝战争的恢宏史诗，展现了中国人民志愿军不怕牺牲、誓死保卫国家的爱国主义精神。
观影结束后，大家感触良多，纷纷表示被英雄先烈们坚定理想信念、保卫国家、守护和平、英勇无畏的爱国主义精神所打动。此次共建观影活动，是对党员干部们的一次深刻的思想淬炼和精神洗礼，在今后的工作和生活中将时刻牢记和平年代的来之不易，铭记历史感恩奋进，以更加昂扬的精神状态和饱满的工作热情，扎实推动工作再上新台阶。（撰稿人：毛淑兰；审稿人：韩争胜）
