# 【莫航启航，逐梦翱翔】莫航学院在学校第60届运动会暨第23届体育文化节中首展风采

4月24日，西北工业大学第60届运动会暨第23届体育文化节于长安校区云天苑田径场顺利开幕。莫航学院师生们首次亮相校运动会赛场，以饱满热情与昂扬风貌积极参与各项赛事，充分展现了莫航学子团结协作、奋勇争先的体育精神，用汗水书写了学院首份校运动会答卷。
开幕式上，伴随着激昂的旋律，莫航学院方阵迈着整齐有力的步伐入场。队伍精神饱满、意气风发，步履铿锵尽显青春朝气，独具学院特色的风采展示成为开幕式中亮眼的风景线。
赛场上，运动健儿们奋勇争先，捷报频传，用速度与力量、坚持与协作，斩获多项优异成绩：
径赛赛场上，佟昕蔚发挥稳定，获得女子400米第五名、女子200米第七名；吴莺莺挑战耐力长跑，在女子3000米项目中坚韧前行，取得第八名；刘振全速冲刺，拿下男子200
米第五名。由吴莺莺、蔡昕雅、王馨童、佟昕蔚组成的女子4×100米接力小队，配合默契、衔接流畅，凭借高效协作荣获团体第七名。
田赛赛场中，徐郅轩沉着应战、蓄力迸发，在三级跳远项目中发挥出色，斩获第六名，跳出了属于自己的最佳成绩。
除了获奖项目，我院学子还积极参与了铅球、跳高、游泳、篮球、乒乓球等多个项目的角逐。无论是投掷赛场的奋力一掷、跳高横杆前的纵身一跃，泳池中的破浪前行，还是篮球场上的攻防转换、乒乓球台边的精彩对拉，每一位参赛同学都全力以赴、不留遗憾。他们以拼搏诠释初心，全力驰骋赛场为学院争光添彩。
首次出征校运会，每一次起跑、每一次冲刺、每一次坚持，都是莫航学子的成长印记，每一份成绩都意义非凡、弥足珍贵。此次校运会不仅是体育竞技的舞台，更是学院凝聚力、向心力的集中展现，充分锤炼了学子坚韧意志与协作意识。
青春逢盛世，奋斗正当时。本次运动会圆满落幕，莫航学院全体师生将把赛场之上的拼搏劲头、奋进姿态融入日常学习与成长之中，永葆热血朝气、砥砺笃行奋进。立足崭新起点，怀揣航空理想，以青春之力逐梦远航，凝心聚力、携手同行，持续书写莫航学院高质量发展的崭新篇章。
