# 我校第九届感恩中国近现代科学家奖助学金评选工作圆满结束

为深化大学生爱国主义教育和科学家精神教育，进一步培养西工大学子的社会责任感和创新意识，2026年10月，学校开展了第九届感恩中国近现代科学家奖助学金评选工作，经过学生申请、院系初评、学校组织笔试、面试，最终25名学生脱颖而出获评感恩中国近现代科学家奖助学金。
10月23日，学校组织笔试考核。各培养单位初评推荐的47名奖助学金候选人进入笔试环节，着重考察学生对中国近现代科学家的光辉事迹、科研成果、精神内核的认识了解，以及对学校校史校情和著名校友科学家事迹的学习理解，以考促学引导学生铭记科学先辈足迹。
10月28日，学校组织面试评审。候选人结合自身对科学家精神的理解，阐述了各自学科领域内科学家事迹对自己学习生活的启发，对个人成长的激励，充分展现了新时代青年志向远大、胸怀祖国，将个人成长融入国家需求的精神风貌。
学校按候选学生综合成绩（即基础分、笔试分、面试分总和）排序，最终确定王星辉等10名同学为第九届感恩中国近现代科学家奖学金拟推荐人选，安昱等15名同学为第九届感恩中国近现代科学家助学金拟推荐人选。本次奖助学金的评选，不仅为我校学子搭建了一个深入理解科学家精神的重要平台，更进一步引导广大学子以科学家为榜样，在追求学术进步的同时涵养社会责任感，努力成长为兼具家国情怀与专业素养的拔尖创新人才。
据悉，感恩中国近现代科学家奖助学金由西南交通大学与坚永公司于2018年共同设立，面向西部地区及湖北武汉共34所“双一流”高校开展。该奖助学金旨在加强学生理想信念教育，引导广大学子弘扬爱国奋斗精神，学习科学家、崇敬科学家、感恩科学家，培养有社会责任感、创新精神、实践能力的新时代青年。
