# 【机关风采】机关先进党支部篇：人力资源部党支部-机关党委

坚持党建引领 推动人事人才工作高质量发展
人力资源部党支部坚持以习近平新时代中国特色社会主义思想为指导，深入学习贯彻党的二十大精神和习近平总书记关于人事人才工作的重要论述，紧紧围绕学校“双一流”建设，全面加强教师思想政治和师德师风建设，持续深化人事人才制度改革，着力打造高素质创新型教师队伍，为学校事业高质量发展提供坚强人才支撑。
2026年度机关先进党支部
人力资源部党支部
筑牢理论根基，强化政治引领
党支部始终把政治建设摆在首位，认真落实“第一议题”制度，及时跟进学习习近平总书记重要讲话和重要指示批示精神，特别是关于教育、科技、人才和教师队伍建设工作的重要论述，通过专家“导学”、干部“领学”、党员“勤学”，推动理论学习走深走实。深入开展主题教育和党纪学习教育，牢固树立和践行正确政绩观，引导党员干部深刻领悟“两个确立”的决定性意义，增强“四个意识”、坚定“四个自信”、做到“两个维护”。创新开展特色支部活动，组织赴陕西考古博物院等地开展实践研学，赴镇巴开展“党建引领，教育赋能，助力乡村振兴”主题党日活动，不断提升支部的凝聚力和向心力，切实把学习成果转化为推动人事人才工作、服务学校发展的实际成效。
突出政治功能，深化党建融合
以高质量党建引领高水平师资队伍建设，坚持党管人才原则，把党的领导贯穿人事人才工作全过程各方面。师资队伍结构持续优化、整体水平显著提升，国家级人才入选数连续三年破百，提前完成人才占比20%的目标。出台《西北工业大学翱翔团队建设管理办法》《西北工业大学理科学院、文科学院人才队伍建设专项实施计划》《西北工业大学教职工校内兼聘管理办法》及“百人总师培养工程”等政策举措，不断完善人才引育用留全链条机制。深化人才发展体制机制改革，创新人才评价方式，破除“五唯”倾向，激发人才创新创造活力。坚持党建与业务同谋划、同部署、同推进、同考核，以党建工作新成效推动师资队伍建设新突破，促进学校事业高质量发展。
聚焦铸魂强师，涵养师德师风
围绕“铸魂强师”一个核心，聚焦“思想政治、师德师风”两条主线，优化构建“教育培训、师德涵养、荣誉表彰、考核评价、监督惩处、责任落实、制度规范”工作体系。坚持把政治标准摆在首位，将师德师风作为教师评价第一标准，健全师德师风建设长效机制。持续深化教师理论武装，分层分类开展思想政治教育培训，引导广大教师坚定理想信念、陶冶道德情操、涵养扎实学识、勤修仁爱之心。完善师德荣誉表彰体系，选树宣传师德先进典型，营造尊师重教浓厚氛围；严格师德考核与监督惩处，实行师德“一票否决”，压实各级党组织主体责任，不断提高教师思想政治教育科学化水平，持续推进学校教师思想政治工作质量提升。
深化改革创新，服务发展大局
勇于改革创新、担当作为，作为牵头单位，平稳推进学校机构改革、评价改革工作。牵头制定机构改革方案，完成“三定一聘”及“三减”工作，修订配套政策，优化机构职能配置，理顺管理体制机制，提升治理效能。建立二级单位评价体系，完善分类考核评价机制，结合考核结果做好全校岗位聘任工作，树立正确用人导向。坚持系统观念，加强统筹协调，注重改革的系统性、整体性、协同性，确保各项改革平稳有序推进，以改革促发展、以改革增活力，为学校治理体系和治理能力现代化贡献力量。
弘扬务实作风，提升服务效能
对外赴兄弟高校、科研院所深入开展调研，学习借鉴先进经验做法；对内实现二级单位需求调研、政策宣讲全覆盖，深入一线了解教职工所思所盼，形成高质量调研报告20余份，推动调研成果转化为政策举措和工作实效。以广大教职工切身利益为出发点，强化人事信息化建设，推进职称线上评审系统，优化办事流程，不断提升服务质量和效率。党支部书记抓党建述职评议考核连续6年“好”，单位年度考核连续6年“A等级”，以过硬作风和优异成绩展现人事干部队伍良好形象。
站在新的历史起点上，人力资源部党支部将继续牢记为党育人、为国育才初心使命，以更加昂扬的斗志、更加务实的作风、更加有力的举措，持续深化人事人才制度改革，全面加强教师队伍建设，奋力开创学校人事人才工作新局面，为建设中国特色世界一流大学作出新的更大贡献！
