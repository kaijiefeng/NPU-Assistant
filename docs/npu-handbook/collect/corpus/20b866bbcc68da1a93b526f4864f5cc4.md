# 西北工业大学医院非事业编制自聘人员公开招聘启事

西北工业大学医院始建于1972年，是集医疗、科研、预防保健、健康教育和社区服务为一体的综合性二级乙等医院。医院始终坚持“善医精术 唯实求新”的院训，秉持“小（校）医院孕育大医生，小（校）医院做好大保障，小（校）医院承载大担当”的服务理念服务师生和社区居民。
现有职工202人，其中高级职称49人、中级职称72人、初级职称54人；博士研究生3人、硕士58人；设有12个临床科室、5个医技科室；开放病床100张。医院因业务发展需要，拟面向社会公开招聘护士1人，现将招聘信息公告如下：
一、招聘计划
护士1人（岗位类别：其他专技）
二、招聘条件
1.具有中华人民共和国国籍，拥护中国共产党的领导，具有爱国奉献精神，自觉遵守国家的法律法规和各项规章制度，廉洁自律，无违法犯罪情况；
2.具有良好的思想道德品质、强烈的事业心和责任感，具有较强的服务意识和团队协作精神；
3.热爱高等教育事业，具有良好的职业道德，恪守高校教师师德、学术道德等职业道德规范；
4.具备所聘岗位必备的业务知识、工作能力；
5.具备正常履行岗位职责的身体条件；
6.专业要求：护理学；
7.学历学位：本科及以上；
8.招聘范围：往届生；
9.其他要求：年龄30周岁及以下；具有护师及以上卫生专业技术任职资格；有二级甲等及以上医院护理工作经验者优先考虑。
三、岗位职责
1.严格遵照医嘱落实各项临床护理操作，密切监测患者病情变化，发现异常及时上报，积极配合急危重症患者抢救工作。熟练掌握临床基础护理操作，熟知各项护理核心制度，具备常见急症初步应急处置能力；
2.规范书写护理文书，落实各类护理评估，做好患者健康宣教与出院指导；
3.严格执行院感防控、三查八对等护理核心制度，保障患者诊疗安全；
4.做好病区急救器械、抢救药品及医用耗材的日常管理；
5.维护病区诊疗秩序，积极参与科室护理质量持续改进工作；
6.参与医疗保障、慢病管理、健康科普及其他各项指令性工作任务。
三、招聘程序
本次招聘按照个人报名、资格审核、笔试、面试、综合考察、体检（含心理测评）、公示、录用等程序组织实施。即日起至11月15日17:00止，应聘人员填写《西北工业大学医院应聘人员信息登记表》（附件），[已脱敏:邮箱]。附件中须上传以下材料扫描件：1.毕业证、学位证；2.职称证；3.资格证；4.执业证；5.身份证。医院对符合条件的应聘者进行资格审核，符合条件者组织笔试和面试，择优录用。
四、相关说明
1.应聘人员报名时，须认真阅读招聘要求，按要求如实填写相关信息，对所提交报名材料的真实性、准确性负责。凡弄虚作假或不符合我校招聘要求的，无论何时，一经查实，医院有权取消其考试或录用资格，相关责任由应聘人员承担；
2.应聘人员须在规定的时间内参加医院安排的各项招聘程序，未能按时参加者，均视为本人自动放弃；
3.医院同意聘用的人员，应按规定时间及时办理后续相关手续，逾期视为自动放弃；
4.对逾期不能报到的，或不能提供档案的，或发现有不符合报考资格和录用条件的，或提供信息不真实的，取消录用资格。
五、有关政策和待遇
1.本次招聘岗位为非事业编制自聘岗位。按照医院非事业编制教职工聘用管理相关办法确定薪酬标准，为其缴纳社会保险；
2.除固定工资外各岗位享受绩效等待遇。
六、考核及联系方式
1.考核及待遇参照西北工业大学医院非事业编制人员有关规定执行；
2. 工作地点为西北工业大学友谊校区医院或长安校区医院；
3.试用期6个月，首次聘期3年。
