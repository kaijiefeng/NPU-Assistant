# 关于材料学院2026年暑假工作安排的通知

各课题组、各位老师：
根据学校《关于2026年暑假安排的通知》要求，为更好地服务全院师生，材料学院相关工作安排如下：
一、暑假放假时间及安排
1.学生：7月20日—8月30日。8月31日正式上课。
2.教职工：7月20日—8月27日期间实行轮休，8月28日正式上班。
3.2026级本科新生报到时间为8月22日，地点为长安校区；2026级研究生新生报到时间为8月30日，在友谊校区和长安校区同时进行。2026级本科生于8月24日—9月6日开展军训，军训相关安排由党委学生工作部另行通知。
二、相关注意事项
1.各系、实验室、教学中心、学院办公室要认真做好暑假期间的安全稳定、安全生产、保密及应急管理等工作，主要负责同志、值班人员要保持24小时通讯畅通。如遇突发情况，应妥善处置并及时上报。
2.做好暑假在校学生的关心管理和服务保障工作。放假前要以课题组为单位组织安全检查，排除隐患，放假离校要关闭电源、锁好门窗、确保安全。
3.暑假期间使用会议室、报告厅的师生请务必在使用完后关闭空调、投影仪等电源，锁好门窗、确保安全。
4.暑假期间如有相关业务办理请直接与业务负责人联系，各业务负责人员在暑假轮休期内保持通话顺畅。
三、值班工作安排
1.值班时间
法定工作日：上午8:30~11:30,15:00~18:00
2.值班地点
友谊校区公字楼（详情见附件）
特此通知！
材料学院
2025年7月15日
