# 精准赋能备申报，蓄力冲刺启新篇——航海学院举办2026年国家自然科学基金项目申报冲刺辅导会

为抢抓国家自然科学基金项目申报关键窗口期，进一步提高项目申报质量与立项成功率，3月5日下午14:30，航海学院在友谊校区共享中心会议室组织开展2026年青年、面上、人才类、联合基金项目冲刺辅导会。本次会议邀请了航天学院张夷斋教授、袁源教授、代洪华教授，航海学院陈克安教授，机电学院万敏教授，电子信息学院戴玉超教授，计算机学院张伟伟教授、郭斌教授，物理科学与技术学院王建元教授担任辅导专家，航海学院副院长崔荣鑫主持，30余位教师参会。
会议伊始，崔荣鑫表示，当前申报工作已进入到最后的冲刺阶段，感谢校内兄弟单位专家一直以来对学院基金项目申报工作的大力支持，恳请大家结合最新申报政策与评审标准为各位申报人做好最后的建言献策和把关工作。
由于本次辅导报名人数较多，为了提高辅导的精准度和高效率，学院事先将申报书与专家研究方向进行一对一匹配，现场辅导分为申报书评阅和意见反馈两个环节。在申报书评阅环节，专家从选题创新型、科学问题凝练、研究方法设计、预期成果凝练、经费预算规划等方面全面对申报书进行详细评阅，逐页标记逻辑漏洞、表述短板、格式问题等。在意见反馈环节，专家就申请书中出现的上述问题又逐一与申报人进行面对面诊断，并提出了清晰的修改方向与提升路径。
历时两个多小时，学院顺利完成了30余份申请书的精准辅导，确保每位老师收获两份专家评审意见。此次辅导形式新颖、效率高、针对性强、干活满满，得到了现场专家和申报人的一致好评。
下一步，学院将持续做好跟踪服务和精准支持，全力做好2026年国家自然科学基金项目申报保障工作，力争事先立项数量与质量双突破，努力推动学院科研工作再上新台阶。
