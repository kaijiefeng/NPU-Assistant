# 力学与土木建筑学院举办青年教师发展论坛—学术沙龙第四讲

2022年11月30日上午，力学与土木建筑学院青年教师发展论坛——学术沙龙第四讲，在学院206会议室召开。本次青年教师发展中心邀请中科院上海应用物理研究所黄鹤飞研究员，做题为“熔盐堆用材料辐照研究进展及研发工作的一点思考”的线上讲座。30余名师生通过线上线下的方式参加了此次学术研讨活动。
黄鹤飞研究员针对熔盐堆用材料后续的研发工作，从材料制备、服役性能评估、标准及规范、数据库等方面进行了探讨与展望。李晓强教授针对报告内容进行了点评，并与相关研究方向的师生纷纷进行研讨交流。
学院青年教师发展中心致力于通过定期的学术沙龙活动为广大研究学者搭建科研学术交流平台，积极营造交叉、创新、融合、互鉴的学术氛围，为高层次人才培养和高水平科研成果产出提供有力支撑。
