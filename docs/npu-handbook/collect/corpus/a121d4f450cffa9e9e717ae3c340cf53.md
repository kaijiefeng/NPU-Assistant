# 【求职故事】一场特殊的“面试”

下午4时22分，龚长虎终于停下手中已经有些打颤的笔。他长舒一口气，试图站起身来，才发现腿脚早就麻了。
——他已经在这张画桌上一动不动地伏案画了4个多小时，没吃午饭，甚至连一趟厕所都没来得及去。
“我太开心了——平时都是拿A4纸画，画满整张纸就算，难得有这么大一张画布。”事后，龚长虎有些腼腆地比划。他刚进北京印刷学院设计系读研一，听说第十二届世界漫画大会在北京开，就和朋友一起来玩。到向游人开放的绘画厅，龚长虎走不动了：“我之前去过上海、杭州的好多漫展，都是人挤人，挤得你连看画都没心情;这儿空间挺开阔的，氛围也好，竟然还有免费的画桌。我跟朋友说，你们去玩吧，我画一下——突然就有了画画的欲望。”
“别人坐下来最多画20分钟，他一画就是4个多小时，头都不抬。”一直在这个展厅执勤的工作人员，一边小声啧啧赞叹，一边也和很多旁观者一样，掏出相机来照。
围观的人里还有鱼工坊设计工作室的负责人杨小姐。龚长虎停笔时，她坐在桌对面，也已经一动不动地观察了对方半个多小时。几乎在龚长虎起身的一刹那，她连珠炮般开始发问：
“你能这样画多久?”
“这幅画是在你心中早有腹稿，或是以前画过，还是第一次创作?”
“这幅画你想表达什么?”
“你画过最大尺寸的画是多少?画2米乘5米的有问题么?”
“我就是想看看，他是不是我们在找的那种人才。”之后，杨小姐坦言机缘难得，所以现场来了一次特殊的“面试”。她说自己是在溜达时无意发现龚长虎的创作：“非常意外，画面很有想象力，更令人惊讶的是他思路非常流畅，一气呵成，下笔很少修改。”
龚长虎笔下流出的，是一幅《未来城市》图：一栋栋摩天大楼、盘根错节的道路桥梁、流着口水的大脑袋人类、像宇宙飞船一样的交通工具，密密麻麻填满了半米见方的画布，复杂而不失精巧。
“我没有草稿，想到哪里画到哪里;我也不知道我能画多久，只要画纸够大，我觉得我能一直画下去。”面对这场猝不及防的“面试”，龚长虎从容应对，非常淡定。
显然，杨小姐对“面试”结果很满意：“直接现场构思能画出这样的作品，真的很有才气。”她表示自己的工作室正需要这样能长时间、高效率绘制大幅作品的人才，同时详细询问了龚长虎每周的时间安排，并留下联系方式。
这样的大型漫展，已经成为杨小姐寻找人才的一种特殊方式。她形容自己“像猎头一样”，在展会上捕捉才华横溢的创作者。
“能通过这种方式碰到赏识的人，我也很意外，如果最后能合作，也算是意外的收获吧。”参加完“面试”的龚长虎默默掏出相机，对着自己的画作一通“咔嚓”，“我还没画完，照下来，回去继续画。”
