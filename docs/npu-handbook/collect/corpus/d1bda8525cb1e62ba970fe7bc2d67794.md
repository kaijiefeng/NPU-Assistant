# 【学位项目】爱尔兰都柏林大学学位项目及学分交换项目报名通知

一、学校简介
爱尔兰都柏林大学（University College Dublin，简称UCD）于1854年建立，以高质量的教育标准与一流的研究成果闻名于世，是爱尔兰乃至欧洲最顶尖的研究型大学之一。2026年QS世界排名跃升至全球第118位，位居全球高校前1%之列。
二、项目介绍
（一）本硕联合培养项目
1.学习方式
（1）3+1+1项目：3年（西北工业大学）、1年硕士衔接课程（UCD)、1年硕士课程（UCD）
大三申请，大四赴UCD学习：在UCD完成第一年相关学业，将获得西北工业大学学士学位证书和毕业证书;在UCD完成第二年学业，将获得UCD硕士学位证书。
（2）3.5+0.5+1项目：3.5年（西北工业大学）、0.5年硕士衔接课程（UCD)、1年硕士课程（UCD）
大四第二学期赴UCD学习：在UCD完成一学期相关学业，将获得西北工业大学学士学位证书和毕业证书；在UCD完成第二年学业，将获得UCD硕士学位证书。
2.项目对象
我校大三、大四在籍在校学生
3.专业范围
详见UCD官网：https://www.ucd.ie/alc/programmes/pathways/ge%20pmp/
4.申请截止时间
如计划2026年9月入学，申请截止时间为2026年6月30日
（考虑签证办理周期约20天，请尽早完成申请）
5.申请要求
（1）学业成绩要求
学分绩78分及以上
（2）语言要求
3+1+1项目：雅思5.5 (单科不低于5.0)或托福60 (阅读不低于8,听力不低于7, 口语不低于15, 写作不低于17 )
3.5+0.5+1项目：雅思6.0 (单科不低于5.5 )或托福70 (阅读不低12, 听力不低于11, 口语不低于17, 写作不低于20)
6.项目费用
1年硕士衔接课程学费约13,650欧元(约9万人民币 )
0.5年硕士衔接课程学费约9,100欧元(约6万人民币 )
硕士课程学费约为22,600－29,100欧元（约16-25万人民币／年）
生活及住宿费约10万元人民币/年
*每年学费可能因政策有所调整，以入学当年学费为准。
7.奖学金及学校资助政策
UCD奖学金：通过硕士衔接课程进入UCD 硕士课程学习，可获得10%硕士课程学费减免。
学校资助：根据当年项目申请情况及学校年度经费情况，可提供每人5000-8000元/月的生活费资助（最多资助12个月）及一次性旅费不超过8000元/生。
（二）硕士联合培养项目
1.学习方式
4+1项目：4年（西北工业大学）、1年硕士课程（UCD）
大四完成本科学业后前往UCD进行硕士阶段学习，完成后获得UCD硕士学位证书。
2.项目对象
我校大四在籍在校学生
3.专业范围
请见附件1
4.申请截止时间
如计划2026年9月入学，申请截止时间为2026年6月30日
（考虑签证办理周期约20天，请尽早完成申请）
5.申请要求
（1）学业成绩要求
学分绩78分及以上
（2）语言要求
雅思6.5(单科不低于6.0)
6.项目费用
硕士课程学费约22,600－29,100欧元（约16-25万人民币／年）
生活及住宿费约10万元人民币／年
*每年学费可能因政策有所调整，以入学当年学费为准。
7.奖学金及学校资助政策
UCD提供硕士阶段7000欧元奖学金。
（三）Study Abroad学分交换项目
1.学习方式
赴UCD完成一年或一学期短期留学项目。
2.课程修读
每学期选择5-6门课程；可选择4个本专业必修课，以及2个非本专业选修课程；学生需提前注册所选择的课程，学期开始两个星期内可更换学习模块；所有选课需要与我校老师确定，以满足我校学位授予要求。
3.项目对象
我校大二、大三、大四（仅限第一学期）在籍在校学生
4.申请截止时间
如计划2026年秋季入学，申请截止时间为2026年5月1日
如计划2027年春季入学，申请截止时间为2026年10月25日
5.申请要求
（1）学业成绩要求
学分绩78分及以上
（2）语言要求
雅思成绩6.5，单科不低于6（个别雅思6.0单科不低于5.5）
6.项目费用
1学期约9,300欧元（约7万-8万元人民币）
1年约17,800欧元（约15万元人民币）
生活及住宿费约10万元人民币／年
*每年学费可能因政策有所调整，以入学年学费为准。
7.奖学金及学校资助政策
UCD奖学金：在UCD完成一学期或一年Study Abroad项目，并成功从西北工业大学毕业后申请UCD硕士课程，可有机会获得硕士阶段2000-5000欧元学费减免（商学院除外）。
学校资助：根据当年项目申请情况及学校年度经费情况，可提供每人5000-8000元/月的生活费资助（最多资助12个月）及一次性旅费不超过8000元/生。
三、项目申请材料
1.本科成绩单（中英文版）
2.本科在读证明（中英文版）
3.学分绩证明（加权/算数平均均可）
4.两位导师的学术推荐信（英文）
5.雅思/托福成绩（可派出前提供）
6.个人陈述或者简历（英文）
四、申请方式
学生自主报名，将申请材料交至长安校区教学西楼C座南侧101办公室魏老师处，学校审核通过后，登陆UCD官方申请网站（www.ucd.ie/apply）进行在线申请，并上传全部电子版材料，经UCD招生处审核成功后发放录取通知书。
