# 学校举办2024年新晋长聘副教授培训

为落实立德树人根本任务，建强高素质专业化教师队伍，党委教师工作部以强化教师专业素养为关键，着力构建贯穿教师职业生涯的培训体系，重点策划实施聚焦青年教师成长发展需求的新晋升教师培训，助力青年教师全方位成长成才。近日，学校圆满完成2024年新晋长聘副教授培训。此次培训涵盖立德树人、总师育人、科学研究、职业发展四个必修模块。2023年新晋升的长聘副教授50余人参加培训。
青年骨干教师是学校落实立德树人根本任务的核心力量，10月25日上午，“立德树人奖”获奖教师先进事迹报告会在国一会议室举行，特邀学校“立德树人奖”获奖教师潘光教授、李勇教授做报告。潘光教授结合自身工作经历，从团队发展、科学研究、教书育人三个方面分享了个人感悟和体会，李勇教授结合自身教书育人四十载的经历，从教书和育人两方面诠释了“如何做一名好教师”。
本次培训设立了职业发展经验分享与交流环节，10月25日至29日，学校根据学科划分人文专场、理工专场，邀请不同领域资深学者与青年教师共话职业发展。高层次人才办公室副主任杨妍分别面向人文社科和理工科青年骨干教师，详细介绍了不同领域青年人才发展路径及保障机制，重点讲解了相关人才项目的申报政策和评审方式，以及学校对青年人才发展的支持举措。在人文专场，国家级青年人才王阳教授、国家社科基金重大项目首席专家孙绍勇教授分别从青年人才项目申报、社科重大项目组织等视角分享了个人经验和心得体会。在理工专场，国家级青年人才昌敏研究员、张鼎文教授分别结合各自申报人才项目经历，就前期工作积累、申请书撰写、答辩技巧等进行了细致分享，为参训教师申报人才项目提供了重要帮助和指导。
在总师育人环节，学校特邀航空工业集团沈阳飞机设计研究所首席专家王永庆以“从需求视角看战斗机发展”为题，系统回顾各代战斗机的核心特征与关键技术，并对未来需求牵引与技术驱动的耦合发展趋势做出展望，勉励教师大力弘扬“忠诚奉献、自力更生、艰苦奋斗、勇攀高峰”的航空报国精神，坚持需求牵引和技术创新相结合，为建设航空强国积极贡献力量。同时，学校还组织新晋长聘副教授集体聆听了“时代楷模”杨士莪先进事迹报告会，深入学习杨士莪院士报效祖国、甘为人梯、大爱无私的家国情怀和崇高境界，激励参训教师将个人发展和国家需要紧密结合起来，为国防科技事业不懈拼搏奋斗、为民族复兴伟业贡献西工大人的力量。
新晋长聘副教授培训是学校加强高素质教师队伍建设、完善教师全职业生涯培养体系的重要举措。党委教师工作部围绕青年骨干教师发展需求，从立德树人、总师育人、科学研究、职业发展等多角度丰富培训内容，邀请校内外大师总师、高层次人才、资深专家学者进行指导交流和经验分享，旨在通过培训助力青年骨干教师提升教书育人与学术发展能力，引导新晋长聘副教授立足新起点，以更加强烈的责任担当和奋发有为的精神状态，为党育英才、为国铸重剑，为“天下工大、世界三航”的远景目标做出更大贡献。
