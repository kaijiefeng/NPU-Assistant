# 电子信息学院师生赴中航光电科技股份有限公司开展调研交流

5月21日，电子信息学院党委书记侯俊、副院长高永胜及师生代表一行10余人前往中航光电科技股份有限公司（以下简称中航光电）开展调研交流活动。座谈会由中航光电人力资源部副部长卢允主持，党委委员、副总经理郭建忠、科技发展部副部长孙海洋及相关部门代表出席。
座谈会上，高永胜从过去、现状与未来三个维度，系统介绍了电子信息学院的发展沿革、人才培养、学科发展及科研合作情况。侯俊在交流中表示，希望以此次活动为契机，推动青年教师与企业的技术对接，深化学院人才培养与行业需求紧密衔接，并邀请企业专家走进校园、课堂，讲述设计和生产一线的故事，分享宝贵经验，赋能人才培养。
交流环节中，双方围绕技术痛点、项目落地、人才联合培养等话题展开深入讨论。学院教师代表介绍了各自研究方向的最新进展，并结合参观感受，分享了智能产线带来的启发，认为课堂教学应与产业前沿紧密呼应。企业代表则结合具体业务需求，表达了在通信、光电互连等方向加强技术合作的强烈意愿。郭建忠回顾了双方长期合作的基础，表示将进一步加强产学研项目合作，探索校企党建共建新路径。同时，从岗位需求角度，表达了企业对高素质电子信息人才的迫切期待。
会前，在专业人员的引导下，师生一行先后参观中航光电智能生产车间与企业规划馆。作为国内连接器领域龙头企业，中航光电深耕数字化转型，车间自动化设备高效运作，依托智能排产体系把控生产全流程，讲解员细致讲解精密部件加工工艺，尽显制造业向智能制造转型升级的强劲势能。在规划馆内，通过实物陈列与场景演示，展现企业在航天、医疗、新能源、电子信息等多领域的产业布局与技术成果，前沿互联技术方案尽显硬核科创实力，也让同学们真切感知到专业广阔的应用前景。
本次调研活动，不仅让师生近距离感受了高端制造企业的智能化转型与多领域创新，也为后续在党建共建、科研合作、人才输送等方面的持续合作奠定了坚实基础。同学们纷纷表示，通过走进企业一线，更加明确了专业学习与产业需求之间的连接点，坚定了投身国防科技事业的信心与决心。
