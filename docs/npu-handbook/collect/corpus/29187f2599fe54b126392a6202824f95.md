# 【档案信息服务中心】常见问题答疑

一、法人证书

1. 我们要申请科研项目，需要事业单位法人证书，请问怎么办理？

答：法人证书的办理线上线下均可。选择线上办理，请在网上办事大厅申请，所在二级单位负责人审核通过后流转至档案馆，档案馆管理员审核通过后系统将发送短信到您的手机。如果办理网站、微博、微信注册、认证等新媒体业务时，需要党委宣传部审核。审核通过后，请您来档案馆信息服务中心（113室）领取即可；如果选择线下办理，请在档案馆网站首页“下载专区”，下载“事业单位法人证书利用审批表”，按照表格内容填写，请单位负责人审核签字，携带审批表至档案馆信息服务中心（113室）当场即可领取。

2. 请问组织机构代码证是在档案馆办理吗？

答：组织机构代码证、营业执照和税务登记证已于2015年10月“三证合一”了，您只需按照流程办理事业单位法人证书即可使用。

二、补档事宜

1. 我是2018届的本科毕业生，我要办理入职手续／考研复试／我的单位在审核档案的时候发现我的学籍档案缺失，需要本科成绩单，请问档案馆可以办理吗？

答：补办毕业生学籍档案材料，携带本人身份证即可现场办理，立等可取。如果委托他人代办，请填写委托代办书后由被委托人现场办理。不能来到现场的情况，身份审核后，根据您的需求，发送电子版或邮寄纸质版均可。

2. 我是2016届本科毕业生，需要学位授予证明，请问档案馆有吗？

答：针对本科毕业生，学校统一没有设置学位授予证明，但是可以用毕业生名单（领取学位证签字表）替代，证明已经毕业并且取得学位。

三、英文成绩单

1. 我是在校生，申请了短期出国交流的项目，需要办理英文成绩单，想了解一下办理流程。

答：在档案馆官网首页档案办事大厅“出国材料预约办理”平台预约下单，预约成功后，工作人员会及时受理，当订单状态显示“已办结”时，即可按照系统消息提示的内容办理。在校生需要出具纸质版学籍成绩单（翱翔教务下载打印即可）。如果人在外地不能线下办理，档案馆可以提供邮寄服务。

2. 我申请的学校需要显示GPA，请问怎么办理？

答：2019级、2020级本科生翱翔教务下载的成绩单右下角自带GPA，只需在出国成绩单平均绩点那一栏输入即可。2019级以前的本科生，由于中文成绩单GPA那一项没有数据，需要在学院本科教学秘书老师那里开具中英文对照的GPA证明，方可作为申请材料以备使用。

3. 原计划开学后立即打印英文成绩单以申请出国交换，但临时家中有事不能按时返校，请问打印英文成绩单的业务应该与谁联系？可否让在校同学代领然后将原件邮寄给我？

答：办理中英文成绩单事项，请联系档案馆信息服务中心，联系电话029-88493280。可以先在网上预约，然后请已经返校的同学前来档案馆113办公室直接领取。也可委托已经返校的同学代为办理。由于在校生的中文成绩单尚未归档，请务必携带学院开具的中文成绩单。

4. 申请出国，我需要开具中英文成绩单，成绩单上面是所有科目的成绩都会显示还是只显示专业必修课的成绩，选修课的成绩会显示出来吗？

答：档案馆翻译的英文成绩单和翱翔教务系统里的中文成绩单保持一致。显示所有科目的成绩，选修课的成绩也会如实体现出来。如有问题，欢迎来电咨询029-88493280。

5. 我是今年毕业的本科生，七月三号拿到毕业证与学位证之后我需要办理一下双证的英文版，请问预约系统中的查询公函应该怎么开具呢？

答：出国材料制作预约系统个人办理只需上传个人的身份证和毕业证书电子版，无需填写预约公函。2016届以后的学位证书已经是双语对照件，无需再做翻译，彩色复印即可使用。

6. 请问办理英文成绩单的话，在网上预约过后是否需要自己把中文成绩单提交到档案馆办公室才能开具呢？

答：在校生中文成绩单尚未归档，在线预约后，系统提示办理完毕，须携带中文成绩单来档案馆113室办理。如果是毕业生，携带有效证件，预约完毕，直接办理即可。

7. 我在预约系统申请的时候，一直提示无法上传。请问我该怎么操作？

答：出现这种情况的原因一般是图片格式或者图片大小。请您上传jpg格式的图片，并且不大于500K。

8. 由于联合培养，我需要申请英文成绩单。我选修的三门课程，由于疫情，用另外三门课程替代了。请问能不能只显示最终83门课程的成绩？

答：档案馆出具的出国成绩单需要和翱翔教务系统下载的中文成绩单保持一致。如遇特殊情况，请到学院开具课程变更的情况说明，签字盖章后，附在中文成绩单后，一并交给档案馆方可办理。
