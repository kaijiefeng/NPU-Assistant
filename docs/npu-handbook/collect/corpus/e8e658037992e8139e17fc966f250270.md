# 计算机学院-西北工业大学医院

责任医师：折胜利（副主任医师）
简介：
骨科副主任医师，硕士，毕业于新疆医科大学，外科学，从事骨科临床工作10余年，擅长人工关节置换术、关节镜微创手术、严重肢体创伤与复杂骨折、骨不连、骨髓炎等疾病的治疗。膝关节退变的保膝治疗，颈腰椎疾患的诊断与治疗。现任中国医药教育学会陕西省骨科分会青年常务委员，西安市运动医学分会委员，西安市显微外科分会常务委员，发表论文数十篇。
（备注：学院责任医师是医院与学院之间的桥梁，可为我校师生提供健康咨询、健康宣教、体检结果释疑、急救知识技能培训等服务。有需求者，可通过扫描学院责任医师二维码联系。）
