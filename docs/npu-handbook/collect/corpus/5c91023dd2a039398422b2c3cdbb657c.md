# 【机关风采】戴晓洁：立足岗位守初心 做可靠的保密干部-机关党委

戴晓洁同志在学校保密处从事保密管理工作十余年，从保密战线新兵逐步成长为专业技术人员，主要负责学校保密技防建设、保密监督检查、失泄密事件核查等保密技术相关工作，工作态度认真负责，业务技能熟练专业，工作效果显著。近三年来，带领科室2人次获省级先进个人奖励，1人次获校级荣誉表彰，3人次获部门荣誉表彰。
2026年度机关优秀共产党员
保密处党支部 戴晓洁
做好本职业务工作，护航科研做保障。保密工作政策性强，该同志不断加强政治学习和业务学习，努力提升专业知识和能力，能够准确把握上级文件精神。日常接待师生办事实行首问负责制，不拖沓推诿，依纪依规开展保密监督检查和技术服务工作，制定、修订保密相关制度4项，参与修订制度15项，不断完善学校保密管理制度体系。分类细化上级要求，制定涉密人员和二级单位评分标准及操作方法手册，便于其快速准确掌握相关要求。以案促教，开展警示教育，面向全校发放多期警示教育案例，增强师生保密意识。总结检查中发现的常见问题，制作《涉密项目保密检查内容和要求》课程，面向保密员、涉密人员开展保密送教服务。多次完成迎接上级单位、项目甲方单位来校检查工作，护航学校涉密科研顺利开展。
创立“五法问诊”督导，强基固本改作风。强基固本改作风，根据学校工作模式变化，保密检查开展模式从保密处检查到联合归口部门检查再到邀请上级专家入校开展项目检查，从集中查到分散查到预约保密检查服务，不断创新监督检查形式和方法。将保密检查向保密服务转变，创立“五法问诊”督导检查法，“望”真面目识大局，“闻”真声音寻漏洞，“问”真问题准定位，“切”真难题开药方，“访”真整改求实效，形成检查-整改-回访复核的闭环管理，切实做到以服务之暖化检查之冰，以检查促服务、以服务促发展。
深入钻研保密技术，提升能力多研究。该同志负责学校门户网站保密检查，定期开展网络巡检，及时调整网络检索关键词，发现问题及时处理，将网络传播隐患消灭在萌芽阶段。购置防窃听窃照设备，对学校保密要害部位进行安全检查，提升保密防护能力。部署互联网计算机检查工具，利用网络版检查工具不定期开展校内互联网计算机检查，近两年，共提供保密检查服务6次，检查计算机2302台，命中关键词文件482万余份。部署互联网网站检查工具，对学校主页、二级单位门户网站、官方微信公众号等定期开展检查，利用工具力量增加检查覆盖面。
