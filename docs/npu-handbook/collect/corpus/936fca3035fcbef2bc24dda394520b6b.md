# 党委保卫部组织职工积极参加学校第59届运动会

4月25日—26日，西北工业大学第59届运动会顺利举办，党委保卫部组织职工踊跃参与，在比赛与协作中进一步增进了职工之间的团结和友谊，展现了保卫队伍齐心协力的团队精神。
在竞技项目中，选手们斗志昂扬，他们一个个挥汗如雨，全力以赴。有的遥遥领先，以绝对优势问鼎冠军；有的身处劣势后背水一战，实现绝地反击；有的勇于突破自我，较往年成绩取得了长足进步。无论名次与成绩，都展现了西工大保卫人锲而不舍、永不言弃的精神。在“夹球跑”、“夹乒乓球”团体趣味项目中，选手们配合默契，展现了良好的协同作战能力。积极参加教职工三人篮球赛，与其他教职工们在竞技与合作中诠释了“友谊第一，比赛第二”的体育精神。
党委保卫部职工在参与的10个项目中取得了3枚金牌、3枚银牌、4枚铜牌的好成绩。今后，党委保卫部将进一步发挥体育精神的引领作用，将赛场上坚韧不拔的拼搏精神融入日常工作，把齐心协力的团队精神转化为工作动力，上下齐心，全力护航学校事业发展。
