# 锚定国防砺初心 军工报国担使命｜电子信息学院博士生第五党支部开展主题党日活动

为深入学习贯彻党的二十届五中全会精神，贯彻落实就业优先战略和学校党委高质量就业的工作要求，推动党建工作与就业育人同频共振，11月5日，电子信息学院博士生第五党支部在电子信息学院275会议室开展“锚定国防砺初心 军工报国担使命”主题党日活动。活动设置理论领学、院所介绍、交流研讨和心得分享等环节，全体党员参加。
深学细悟，把稳择业航向
支部党员集体学习了党的二十届五中全会精神，重点学习了习近平总书记在中共中央政治局第二十七次集体学习时的重要讲话，并展开交流研讨。大家表示，博士研究生的职业选择从来不是个人小事，越是关键时刻，越要站稳政治立场、校准价值坐标。
院所画像，明晰奋斗坐标
支部党员骨干以中国电子科技集团有限公司为例作重点解读。沿着京津冀及东北、江浙沪、西安及周边、川渝、安徽等线路，党员们逐一了解四十余家研究所的主要研究方向、岗位需求和引才政策。把“能不能去、如何去、去了怎么发展”的疑问逐个解答。
交流互鉴，共话使命担当
研讨环节，党员们结合科研方向和择业意向谈认识、讲打算。有党员谈到，自己设计的每一个器件、每一行代码，都可能出现在型号装备上，科研的小切口连着国防的大命题；有党员表示，要把学位论文的选题对准院所的真问题，把实验室的成果带到工程一线去检验；还有党员分享了整理院所招聘信息、打磨简历、准备面试的经验。支部同步建立“就业信息共享清单”，由党员分工跟踪重点院所招聘动态，把“一人择业”变成“全支部助力”。
本次主题党日活动既是一次理论学习的深化，也是一次择业观的重塑。从“国家需要什么样的人”到“我能为国家做什么”，党员们在学思践悟中进一步坚定了把个人理想融入强国强军事业的价值选择。下一步，电子信息学院博士生第五党支部将持续深化“党建+就业”融合模式，常态化开展院所介绍、校友分享、简历问诊等活动，引导青年党员主动走进军工央企、重点科研院所和国防一线岗位，在服务国家战略需求中书写无愧于时代的青春答卷。
心得体会
本次活动让我深受触动。支部书记领学让我进一步明晰了电子信息博士投身国防军工的方向与前景；八位同志对各区域中电科研究所的宣讲，让我深切感受到大国重器背后的硬核平台与求才诚意。军工报国不是口号，是我们博士党员的使命。未来，我将持续提升解决复杂工程问题的能力，把论文写在祖国大地上，带动身边同志主动走向国防一线和重点院所，为强军强国贡献青春力量。
支部副书记 裘天成
参加本次主题党日活动，我深受触动。党和国家高度重视科技、人才与国防建设，军工事业的发展离不开一代代科研工作者的接续奋斗。中电科各研究所深耕军工电子关键领域，在雷达、集成电路、网络安全等方面担起国家战略科技力量重任，让我真切体会到新时代青年肩上的责任。今后我会扎实钻研专业知识，锤炼科研本领，树立服务国家重大战略的就业导向，主动向军工一线看齐，努力攻克技术难题，将所学所长转化为报国之力，在强国强军的征程中实现自身价值。
预备党员 温佳祺
通过本次主题党日活动，我在介绍中电科研究所的过程中，加深了对科技自立自强的理解。科研前辈接续攻关的精神，也让我更加明确了自身的责任。作为博士研究生，我将扎实提升科研能力，主动关注国家需求，把科技报国的志向落实到日常研究和实际问题的解决中。
