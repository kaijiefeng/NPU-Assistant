# 技术经济学

一、课程信息
课程名称：技术经济学
获奖等级：陕西省一流本科课程
二、教学团队
王莉芳教授（课程负责人） 谢言副教授
三、课程概况
技术经济学是根据现代工程技术和社会经济发展的需要，在自然科学和社会科学的发展过程中，互相渗透、互相促进，逐渐形成和快速发展起来的交叉学科。《技术经济学》课程旨在从经济角度对工程项目、技术方案进行分析评价，避免投资风险，提高技术、经济、社会效益，为投资决策提供科学依据。课程团队基于学校“总师型”人才培养要求，面向国家重大复杂项目需求，通过科教融合、产教融合不断优化课程内容，持续进行教学方法的改革与探索，将西工大现象、大国重器、科学家精神、国家重大工程技术成就等引入课程，着力培养学生具有工程技术项目系统分析论证的专业知识结构、开展项目全过程分析评价的实践能力，激发学生投身技术创新活动的使命感和价值感。
