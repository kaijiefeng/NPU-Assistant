# 关于组织开展2025年度西北工业大学本科微专业设置工作的通知

各学院：
为更好地适应新技术、新产业、新业态、新模式发展需要，满足学生个性化、多元化发展需求，提升学生社会竞争力，完善“总师型”人才培养体系，现开展学校2025年度微专业设置工作，有关事项通知如下：
一、建设目标
微专业建设以学生发展为中心，充分考虑经济社会发展对人才的需求，交叉融合多个学科专业的前沿知识和技术，科学设置相关课程体系，形成适应度高、支撑性强的微专业培养方案，推动课程内涵的整合和跨学科课程的融合，探索复合型人才培养模式。
二、建设要求
（一）基于现有专业或围绕某个特定行业、研究方向或者核心素养，构建一组核心课程，充分发挥“小学分、精课程、高聚焦、跨学科、灵活性”的特点设置微专业，微专业名称可根据技术特点、应用领域等自行设定。
（二）充分发挥学院专业特色与优势，围绕国家战略、经济社会发展、立足学科专业交叉和发展趋势，开设富有特色的微专业。
（三）有明确的微专业建设方向，有必需的专职教师队伍、教学辅助人员以及教学资源，鼓励微专业建设学院联合科研院所、行业企业组建跨学院教学团队开发建设微专业。
（四）原则上，每个微专业设置5-8门课程，总学分控制在10-16学分。
三、材料报送
请有意向申请增设微专业的学院认真填写《西北工业大学微专业申请表》（附件），并于5月26日（星期一）前将电子材料（盖章版PDF文件）提交至教务部规划办公室。
特此通知。
