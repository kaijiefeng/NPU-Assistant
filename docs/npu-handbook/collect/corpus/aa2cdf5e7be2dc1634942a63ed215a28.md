# 机关工会关于举办“月圆家国梦 华彩映双节”主题活动的通知-机关党委

机关各工会小组：
为弘扬中华优秀传统文化，丰富职工精神文化生活，营造喜庆祥和的节日氛围，机关分工会将举办“月圆家国梦 华彩映双节”主题活动。现将有关事项通知如下：
一、活动时间
9月30日（星期二） 19:00-20:30
二、活动地点
友谊校区健翔楼五楼多功能厅
三、活动内容
1.欢歌迎国庆：外国歌剧选段——Giunse alfin il momento（美妙的时刻即将来临）；歌颂家国情——我爱你中国。
2.巧手寄双节
宋锦珍珠扇DIY：以非遗技艺镌刻团圆，赠予家人共庆佳节。
中秋肌理画创作：用色彩描绘“月圆人圆·国泰民安”的美好愿景。
（两个项目同步开展，请扫描下方二维码选择一个活动报名）
3.灯谜话团圆
现场悬挂80条灯谜，涵盖传统文化与爱国知识，猜中者可领取“双节纪念品”。
四、参与范围与报名方式
1.本次活动面向未自行组织活动的机关工会小组开放，因场地限制，每个手工活动各单位限报2组家庭，每组家庭最多2人（限1名儿童、1名家长）。
2.即日起-9月26日分别进行报名，两个活动各限报40组家庭，报满为止。
机关分工会
2025年9月24日
