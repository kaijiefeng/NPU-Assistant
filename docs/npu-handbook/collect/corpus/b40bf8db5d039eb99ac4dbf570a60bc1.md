# 工大青年宣讲团与离退休工作处银发宣讲团联学联讲交流会顺利举办-青春驿站-共青团西北工业大学委员会

为深入学习贯彻“十五五”规划纲要精神，推动校内理论宣讲骨干队伍共建交流，3月27日下午，工大青年宣讲团与“五老”宣讲团在长安校区启真楼414会议室共同举办了“十五五”规划纲要联学联讲交流会，学校“五老”宣讲团团长黄迪民、银发宣讲员梁三星，离退休工作处、团委相关老师，以及来自机电学院、动力与能源学院、公共政策与管理学院、马克思主义学院、网络空间安全学院的30余名学生宣讲团代表参加活动。
黄迪民老师以“‘十五五’规划纲要宣讲要点”为题展开宣讲，深入解读了“十五五”规划的历史逻辑与现实方位，详细介绍了国家战略规划与学校相关工作开展情况。随后，工大青年宣讲团讲师、柔性电子研究院2024级硕士研究生方宇杰，青马先锋宣讲团讲师、马克思主义学院2025级博士研究生韩藤阁分别以“向‘绿’而‘新’，向‘新’而‘行’”“‘十五五’绘制社会主义法治国家建设新蓝图”为题展开宣讲，以鲜活的案例和生动的语言展现新时代青年的理论思考与使命担当。梁三星老师结合多年扎根西工大的奋斗经历讲述了“十五五”规划的精神要义，以质朴的语言传递真挚情感，引发在场师生的强烈共鸣。交流讨论环节，两位银发宣讲员鼓励各位青年讲师要持续做好党的创新理论青年化阐释，以“总师育人文化”为引领，用心用情讲好“干惊天动地事，做隐姓埋名人”的奋斗故事，在砥砺奋进中汇聚青春力量。
本次活动是学校团委探索共建“大思政”体系、构建协同联动宣讲矩阵的生动实践，为青年讲师提供了宝贵的学习交流平台，在代际对话中实现了理论接力与精神传承。下一步，团委将持续推进与离退休工作处等校内职能部门及学院的常态化联建机制，依托理论备课会、座谈研讨等形式，推动“五老”智慧与青年活力深度融合，共同讲好工大故事、中国故事、时代故事，为促进学校内涵式高质量发展凝聚思想共识、汇聚精神力量。
