# 航海学院2023级研究生开展新生心理适应讲座

为帮助23级新生尽快适应研究生阶段的学习生活，提高心理健康认知，促进身心健康发展，10月19日，航海学院于教学西楼C座212教室举办了《2023级新生心理适应讲座》。本次讲座邀请心理中心唐婧老师担任主讲人，航海学院2023级全体研究生参与此次讲座，讲座由2023级研究生辅导员靳蒲航老师主持。
在这次心理适应讲座中，唐婧老师首先分析了青年人群心理健康问题现状，然后介绍了学生心理健康教育中心以及预约心理咨询服务的方式。接着，唐婧老师针对心理测评报告进行了详细解读，以便于同学们更正确的理解测评结果。同时唐老师指出应认真做心理测验并正确看待测评结果，测评结果仅仅是当前一段时间心理状态的参考，不是衡量自己心理健康的唯一标准，切不可随便给自己“扣帽子”“贴标签”。最后，唐老师介绍了心理健康的自我调适方法。
本次心理适应性讲座为研究生新生们提供了深入了解和探讨心理健康的机会，相信同学们会将从这次讲座中获取的知识和经验融入自己今后的生活当中，以积极向上、健康乐观的心态去探索生活中隐藏的幸福，并更自信地面对未来的挑战。
