# 航投集团党委书记詹向东莅临中心宣讲市第六次党代会精神

6月15日上午，两江航投集团党委书记、董事长詹向东一行莅临中心宣讲市第六次党代会精神。中心及孵化企业重庆两航金属材料有限公司、重庆三航新材料技术研究院有限公司的党员及40岁以下青年参会。
会上，中心党支部书记、副主任张铁邦对詹向东一行的来访表示热烈欢迎。詹向东解读了陈敏尔在中国共产党重庆市第六次代表大会上所作的报告。对重庆市过去五年工作的回顾总结、今后五年发展的思路目标、重点举措、全面从严治党的主要任务进行了详细阐述。
随后，詹向东对两江新区稳住经济大盘20条政策举措进行了解读。他指出，该系列举措聚焦强投资稳增长、优服务稳主体、降成本保就业、促消费稳市场、强调度稳运行等5个方面，能够全力稳经济增长、稳市场主体、稳项目投资、稳消费市场、保民生就业。
接下来，詹向东向全体在场人员宣读了两江新区航空航天产业“十四五”规划。他表示两江新区将瞄准“1+5+1”航空航天细分产业集群布局，加强两江新区航空航天产业培育。他希望重庆科创中心及孵化企业能发挥各自优势，加快航空航天领域科技成果转化，助力两江新区加速航空航天产业发展。
张铁邦表示，重庆科创中心及孵化企业的各位同志要深入学习贯彻重庆第六次党代会精神，围绕中心发展定位，加快高水平科技成果产出，推动科技成果就地转化，为重庆产业优化升级和全国有影响力的科创中心建设贡献自己的力量。
