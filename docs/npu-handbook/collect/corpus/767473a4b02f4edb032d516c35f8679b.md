# 化学与化工学院开展“安全教育第一课 走进体验新课堂”体验馆实训参观活动

为进一步强化学院师生安全意识，提高安全教育的针对性和可操作性，落实上级部门及学校关于开展安全教育第一课的文件精神要求，9月8日上午，化学与化工学院组织2025级新生前往学校安全教育体验馆，开展题为“安全教育第一课 走进体验新课堂”的实训参观活动。本次活动分成4组共110余名师生参与。
学校安全教育体验馆以总体国家安全观为指引，融合“三航”领域科研特色精心打造，用“理论+实操+沉浸式体验”三维教学体系，为师生筑牢生命安全防线。现场师生人员依次参观了安全教育体验馆五个分区板块，在自然灾害区通过中国地震带分布、地震波原理教学及沉浸式地震体验，从“感受灾害威力”到“实操逃生技能”全方位提升了防震减灾意识。在校园安全区通过AI虚拟穿戴设备、危化品标识互动及安全隐患排查系统等媒介辨识学习高校实验室常见风险场景及应对措施，有效提升了师生应急处置能力。
本次安全教育体验馆参观活动通过丰富的情景模拟与实操训练，不仅有效强化了师生的安全防范意识和应急处理能力，更以生动直观的方式将“安全第一、生命至上”的理念深入人心。今后，学院将持续创新安全教育形式，推动安全意识内化于心、外化于行，切实筑牢校园安全屏障，为构建平安和谐的校园环境奠定坚实基础。
