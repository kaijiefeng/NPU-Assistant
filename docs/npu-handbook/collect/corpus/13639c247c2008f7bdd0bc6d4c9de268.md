# 【学术报告】研究生出国（境）交流项目系列报告——张彦华：在意大利都灵理工大学探索深度学习在医学影像分割任务中的应用

报告时间：2026年1月9日（周五）17:00
报告地点：长安校区海天苑大楼一楼会议室
报告人简介：
张彦华，航天学院2020级博士研究生，师从张科教授，主要从事基于深度学习的图像分割算法的研究，已发表学术论文2篇。
项目概况及报告内容：
受国家建设高水平大学公派研究生项目（CSC）资助，张彦华同学于2022年12月至2024年12月期间，赴意大利都灵理工大学进行了为期25个月的学习，外方导师为Gabriella Balestra教授。学习期间，该生在Gabriella Balestra教授的指导下进行了医学影像分割及前列腺癌症检测的相关研究，在基于深度学习的医学影像分割模型的研究上取得了一定进展，发表SCI论文一篇。本次报告将介绍该生在意大利都灵理工大学学习期间的收获和体会，以及在医学影像分割和前列腺癌症检测等研究方面取得的成果。
