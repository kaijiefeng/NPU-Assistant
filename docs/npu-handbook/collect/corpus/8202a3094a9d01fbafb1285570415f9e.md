# 重庆科创中心党支部赴渣滓洞、白公馆红色教育基地开展主题党日活动

为致敬革命英雄，缅怀革命先烈，8月11日下午，中心党支部组织全体在渝党员和青年代表赴重庆市渣滓洞、白公馆红色教育基地进行参观学习，开展主题党日活动。
在支部书记张铁邦的带领下，支部党员和青年代表首先赴渣滓洞纪念馆进行参观，在渣滓洞监狱旧址，同志们认真观看了革命烈士的英勇事迹，感受了当年国民党反动派关押与审问江竹筠、龙光章、许建业、何雪松等革命烈士的牢房与审讯室，了解各革命烈士的光荣事迹与当年艰苦的生活状况，尤其是江竹筠烈士留给孩子和家人的最后一封家书，表达了先烈不屈不挠、不怕牺牲、英勇斗争的大无畏精神，打动了每一位在场的同志。
随后来到白公馆纪念基地，支部党员和青年代表深刻缅怀爱国将领杨虎城将军和新中国最小烈士“小萝卜头”宋振中烈士一家，学习革命先烈的先进事迹。在当时极端艰苦斗争恶劣的复杂环境下，先烈们以自己的方式与国民党反动派进行着顽强的斗争，这可歌可泣的一幕给全体参观党员同志留下了深刻的印象，先辈们甘抛头颅、洒热血的革命精神让人肃然起敬。
结束参观后，全体党员与青年代表纷纷表示被革命先烈面对敌人威逼利诱与严刑拷打，仍坚持内心理想坚韧不屈的革命精神所打动，对革命先辈们即使身处狱中，仍不忘信仰且坚持学习的乐观精神致以崇高的敬意，大家纷纷表示，在工作上要以革命先烈为榜样，坚定理想信念，将爱国主义情怀融入当前工作，凝心聚力、团聚一致，为中心发展贡献力量。
