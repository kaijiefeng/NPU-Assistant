# 公共政策与管理学院在第十届中国研究生公共管理案例大赛中斩获多项奖项和荣誉

在刚刚落下帷幕的第十届中国研究生公共管理案例大赛中，我校公共政策与管理学院喜获丰收，共斩获18项奖项和荣誉，取得历史性突破。中国研究生公共管理案例大赛是公共管理专业最高水平的国家级赛事，第十届大赛共有来自全国284所院校的3156支队伍报名，参赛师生达1.6万人，竞争异常激烈。自2025年11月赛事启动以来，我院高度重视，积极认真组织和精心准备，历时9个月，提交参赛案例22项，经过初赛、决赛及多轮次严格评审，我院8项案例入围全国前20%，创历史新高。其中，进入百强案例1项，并获得百强案例展示资格和案例三等奖，其余入围的7项案例获得优质案例荣誉证书。同时，我院参赛案例还获得了调研报告二等奖1项并进入调研报告全国百强、三等奖8项。由于我院在组织参赛和大赛中取得的突出成绩，为学校获得了优秀组织单位荣誉证书。
本届大赛首次在决赛现场设立了“百强风采展”环节，从进入百强的案例中评选15支队伍登台展示案例风采与创新成果。我院黄清子副教授指导的参赛案例《从“灰地”到“绿核”：深圳甘泉路近零碳社区公园的合作生产实践》入选“百强风采展”，该团队成员的现场展示充分展现了新时代公共管理研究生扎实的理论素养、敏锐的问题研判能力与求真务实的基层实践能力，体现了学院深耕实践育人、着力培养高素质复合型公共管理人才的办学定位。
本届案例大赛启动后，在学校研究生院的大力支持下，学院开展全覆盖赛事动员宣讲，邀约教师骨干、高校案例教学专家开展多场专项辅导，定期组织MPA导师开展案例指导和经验交流，本次共计组建22支队伍参赛。根据专业学位人才培养目标，学院着力将公共管理案例大赛视作MPA高质量人才培养和实践创新能力的关键平台，实现“以赛促教、以赛促学、以赛促研、以赛促创”。依托MPA专业实践必修环节，构建“理论课堂+实地调研+案例开发”一体化教学模式，引导学生紧扣基层治理等命题，运用公共管理理论工具化解一线治理痛、难点的综合能力，培育适配现代化治理需求的复合型公共管理人才。
