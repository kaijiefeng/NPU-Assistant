# 化学与化工学院传达学习2026年暑期务虚会和新学期中层干部会精神

8月31日下午，化学与化工学院召开党委（扩大）会，传达学习学校暑期务虚会、新学期中层干部会及学生工作会会议精神，并安排部署新学期重点工作。学院领导班子成员、党委委员、院长助理、各系（中心）主任、副主任、教工党支部书记及学院办公室全体人员参会。会议由党委书记傅茂森主持。
院长顾军渭带领大家学习了宋保维校长在暑期务虚会和新学期中层干部会上的讲话精神，并就学院本学期重点工作进行安排部署。他强调，全院教职工要牢固树立和践行正确政绩观，立足“十五五”规划目标，将规划中的重点任务细化分解为年度可落地、可考评的具体举措，常态化研判梳理各项指标进展，层层压实工作责任链条，推动各项部署不折不扣落地见效。
傅茂森传达学习了张云明书记在暑期务虚会、新学期中层干部会和学生工作会上的讲话精神，并就落实好学院下一步工作提出三点要求：一是坚持高站位谋划，聚力抓战略落地。全院各单位要第一时间组织传达学习，切实把思想与行动统一到学校“十五五”规划的开局部署上来，不折不扣贯彻落实学校各项工作要求，确保各项任务落地见效。二是坚持新路径破局，聚力抓统筹推进。面对人工智能等技术变革带来的机遇与挑战，要主动谋划、抢抓机遇，以改革思维和创新方法破解发展难题，确保人才培养、师资队伍建设、科学研究等重点工作高质量实施。三是坚持严作风攻坚，聚力抓实效提质。要牢固树立和践行正确政绩观，进一步增强忧患意识与责任意识，迎难而上、攻坚克难，以过硬作风确保各项工作落到实处、取得实效，为学院内涵式发展提供坚强保障。
与会人员纷纷表示，将以昂扬向上的精神风貌、挺膺担当的奋斗姿态、求真务实的工作作风，把“十五五”规划转化为施工图、任务书，踔厉奋发、真抓实干，确保“十五五”开好局、起好步，为学校事业高质量发展贡献化院更大力量。
【班子成员学习心得】
院长顾军渭：学校2026年暑期务虚会、新学期中层干部会锚定学校“十五五”事业发展的核心目标，把树立和践行正确政绩观以及学校高质量发展的要求贯穿到学科建设、人才培养、科技创新的全链条，明晰了发展路径与重点任务。化学与化工学院将对标会议部署，把本次学习研讨的成果转化为实际行动，在原始创新上深耕、在协同攻关上聚力、在人才培养上做实，真正把具有国防特色化学学科的优势转化为学校高质量发展的核心胜势。
党委书记傅茂森：暑期务虚会正值“十五五”开局关键节点。宋保维校长围绕提升过硬本领、勇于担当作为，系统指导将规划转化为实干；张云明书记以“三问”启发我们知责担责履责。两位领导的报告站位高远、把脉精准，既指明战略方向又教给方法路径，为基层学院提供了清晰遵循。学院全体师生要深入贯彻务虚会精神，以正确政绩观校准航向，勇当基础研究和人才培养“头雁”，筑牢党建根基，以有组织科研推动化学与三航深度交叉融合，优化人才引育和资源配置，激发创新内生动力，确保“十五五”规划落地生根，走好国防军工高校基础学科学院高质量发展新路。
副院长田威：作为分管本科教学的副院长，通过深入学习暑期务虚会和新学期干部会精神，我更加深刻认识到，面对人工智能快速发展的新形势，高等教育必须主动求变、加快转型。学院将立足学科特色和人才培养实际，积极探索人工智能赋能课程建设、教学模式改革和科研训练的新路径，推动人工智能与专业教育深度融合。同时，进一步厚植“总师型”育人文化，将系统思维、工程素养、创新能力和家国情怀贯穿人才培养全过程，强化科教融汇、产教融合和交叉培养。今后，我将主动谋划、积极实践，以教育教学改革提升人才培养质量，为学校培养更多具有卓越创新能力和系统集成能力的“总师型”人才贡献力量。
副院长陈凯杰：通过对学校新学期中层干部会精神的学习，深有感触且感责任重大。张云明书记和宋保维校长的发言内容，为下一步学校工作指明了方向，明确了路线。唯有俯下身去，扎实推进各项工作，才能向全校师生交出一份满意的答卷。作为学院主管科研工作的副院长，我将进一步全面深入学习此次会议的核心要义，同全院教师一起继续深耕国防特色需求下的前沿化学领域，努力健全各类激励保障机制夯实基础研究根基，进一步完善团队建设推进有组织科研能级，扎实推进创新学术生态构建催生产学研融合，更好地为学校双一流建设贡献化学力量。
党委副书记姚东东：通过认真学习学校2026年暑假务虚会、新学期中层干部会及学生工作会精神，深刻领会学校“十五五”开局阶段的使命任务，进一步明晰了学生工作在立德树人、总师型人才培养中的职责定位。作为化学与化工学院分管学生工作的党委副书记，我将立足学院基础学科实际，把会议部署转化为育人实干举措。坚持铸魂育人，传承总师育人文化，把价值引领贯穿学生成长全过程，紧扣化学学科服务国家战略的特色，强化国防就业引导，引导学生把个人理想融入强国建设大局。夯实学工队伍建设，抓好辅导员选育管用，提升队伍专业化育人能力。聚焦学生急难愁盼，做实学业帮扶、心理健康教育，守牢校园安全稳定底线。坚持党建与学生工作深度融合，坚持问题导向，补齐工作短板，主动回应学生现实诉求。以严实作风履职尽责，推动思政教育、成长服务提质增效，聚力培养化学领域拔尖创新人才，为学校建设中国特色世界一流大学贡献化院学工力量。
副院长张宝亮：学校2026年暑假务虚会与新学期中层干部会，为研究生教育改革指明方向。会议提出抢抓人工智能发展机遇，推进教育科技人才一体化发展，着力培育“总师型”拔尖创新人才，令人深受启发。结合学院研究生培养实际，我将对标学校“十五五”规划部署，立足国防战略需求，以问题导向破解培养堵点，推动AI赋能研究生教育，优化研究生培养范式，压实导师育人责任，完善质量闭环管理，持续提升研究生培养质量，为学校建设中国特色世界一流大学贡献力量。
