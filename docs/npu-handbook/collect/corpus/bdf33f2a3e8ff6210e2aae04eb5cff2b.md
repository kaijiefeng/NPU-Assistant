# 北京研究院党支部召开党纪学习教育动员会-西北工业大学

为深入学习贯彻习近平总书记关于党纪学习教育的重要讲话和指示精神，落实学校党委和资产公司党委有关党纪学习教育的部署要求，4月15日下午，北京研究院党支部召开党纪学习教育动员会议，全体党员参会。
会议首先组织学习了中央党的建设工作领导小组会议精神，传达了学校党建（全面从严治党）工作领导小组（扩大）会议关于研究部署党纪学习教育工作的重要精神。随后，全体党员认真学习了《中共西北工业大学委员会关于开展党纪学习教育的实施方案》。
会议指出，开展党纪学习教育，是以习近平同志为核心的党中央为加强党的纪律建设、推动全面从严治党向纵深发展作出的重大决策部署，是党的政治生活中的一件大事。全体党员干部要提高政治站位，深刻领会开展党纪学习教育的重要意义，把思想和行动统一到党中央决策部署上来。
下一步，北京研究院要严格按照实施方案要求和资产公司党委的学习安排，踏踏实实、原原本本将党纪学习教育组织好、实施好，确保支部全体党员在思想上受洗礼，在行动上有锤炼，以“干在实处、走在前列、勇立潮头”的精气神儿做好北研院建设，为学校建设中国特色世界一流大学和“127”发展目标不懈奋斗。
