# 软件学院联合百度及青软公司举办第二十八届中国机器人及人工智能大赛—百度智能云智能服务机器人专项赛技术培训

为促进人工智能教育融合发展，积极响应软件学院“软件*AI+X”人才培养理念的落实，4月23日，西北工业大学软件学院联合百度及青软公司在启翔楼举办第二十八届中国机器人及人工智能大赛（CRAIC）—百度智能云智能服务机器人专项赛技术培训。培训采用“专题讲座+理论教学+实操演示”相结合的形式，吸引校内外众多师生踊跃参与。
培训伊始，百度一见视觉大模型产品资深架构师王浩作题为《百度一见视觉大模型创新应用及实践》的专题讲座，结合产业实际案例，系统阐释视觉大模型的创新应用路径，有效拓宽参训师生在智能感知、机器人应用等前沿技术领域的认知视野。
随后，百度研发伙伴高级研发工程师马忠臣围绕赛题规则解析、赛具介绍、商服机器人使用教学、软硬件架构及AI模型分析等内容，为参训同学进行了系统辅导，并通过经验分享和答疑，帮助同学们深入理解赛项要求、明晰备赛方向。
本次培训面向全校师生开放，同时吸引西北大学、西安理工大学、西安科技大学、榆林大学4所高校师生来校参训，活动进一步搭建起校际交流学习平台，营造了浓厚的备赛氛围。
软件学院将持续依托高水平学科平台与竞赛育人体系，深化以赛促学、以赛促练、以赛促创，着力提升学生创新意识、工程实践能力和团队协作水平，为培养“软件*AI+X”“总师型”软件人才提供有力支撑。
审核：马春燕
