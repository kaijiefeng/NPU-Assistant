# 党政办公室部门简介

西北工业大学党政办公室是学校党委和行政的综合办事机构，是领导的参谋和助手，也是承上启下、联系左右、沟通内外的中枢。党政办公室职能包括统筹协调、文秘政研、校务工作、信息机要、督办信访、对外合作、法律事务、服务保障等方面。

## 工作职责

1.负责学校党政工作的统筹协调；
2.负责学校政策研究工作；
3.负责学校重要文件的组织起草工作；
4.负责规章制度建设工作；
5.负责重大事项请示报告工作；
6.负责学校重大校务活动的组织协调工作；
7.负责对外合作工作；
8.负责学校重大决策、重要任务的督办工作；
9.负责学校稳定安全工作；
10.负责学校信访工作；
11.负责学校法律事务工作；
12.负责长安校区日常运行的协调、稳定安全工作；
13.负责学校信息公开和重大信息报送工作；
14.负责学校公文流转，机要文件和印信管理工作；
15.负责校领导公务活动协调及日常服务保障工作；
16.负责学校议事机构的日常管理工作；
17.负责校务委员会办公室的日常工作；
18.负责《西北工业大学年鉴》的编辑工作。
