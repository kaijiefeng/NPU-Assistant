# 明晰成长规划 勇立时代潮头——人工智能学院开展学生成长专题辅导

10月29日，我院面向全体本科学生开展成长成才专题辅导讲座，帮助同学们明确大学发展目标、端正学风态度、科学规划成长道路。本次讲座由夏勇副院长主讲，辅导员李莹玥和学院全体学生参加。
结合当下人工智能快速发展的时代背景，夏勇指出，新时代科技变革日新月异，青年学子身处机遇充沛的黄金时代。他鼓励全体同学树立远大理想、找准人生方向，主动拥抱时代浪潮，把握人工智能领域的发展机遇，在不断学习与实践中积累沉淀、稳步成长。
夏勇强调，大学生发展路径丰富多元，同学们要打破单一思维，多渠道、多路径提升综合能力。他结合学院良好的保研升学成果，鼓励大家以优秀学子为榜样，尽早确立清晰的学习目标与未来规划，脚踏实地夯实学业基础，主动提升专业素养与科创能力。
针对现阶段学习生活，夏勇希望同学们快速完成大学生身份转变，端正学习态度，深耕专业知识。同时着重强调团队合作的重要性，倡导同学们互帮互助、协作共进，在集体氛围中共同提升。
针对即将到来的期中考试，夏院长开展诚信考试专题教育。他勉励同学们常怀感恩之心，珍惜学院学习资源，正确看待考试的检验作用，自觉严守学术底线与考场纪律，杜绝作弊行为，摒弃侥幸心理，诚信应考、踏实治学，携手维护公平公正的考试环境，共建优良学风。
本次辅导立意深刻、指导性强，有效帮助同学们理清了发展思路、明确了努力方向。同学们纷纷表示，将牢记院长期许，立足当下、着眼未来，以坚定的理想信念、扎实的专业能力迎接新时代挑战。
