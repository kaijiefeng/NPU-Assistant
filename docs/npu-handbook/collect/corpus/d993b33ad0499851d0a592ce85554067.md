# 工会党支部召开理论学习会议-校工会（帮扶办）/ 妇女联合会

2月26日下午，工会党支部在友谊校区健翔楼301会议室召开理论学习会议，工会党支部全体党员参加，会议由支部书记陈建军同志主持。
根据机关党委下发的2月份党支部理论学习指导意见，工会党支部支委会提前细化分解学习任务到每一位党员，学习会上8位党员领学有关学习任务并进行了重点发言。
大家集中学习了习近平总书记在“国家工程师奖”首次评选表彰之际作出的重要指示、学习贯彻习近平新时代中国特色社会主义思想主题教育总结会议精神、《习近平总书记关于制造强国的重要论述学习读本》、习近平复信北京交通大学肯尼亚留学生及校友代表等内容，党员根据学习内容，结合自身具体工作进行重点发言。大家纷纷表示，工会党支部要深入学习贯彻党的二十大精神，提高政治站位，强化思想引领，坚持党对工会工作的全面领导，面对新时代、新形势、新要求，要创新支部党建活动形式，紧紧围绕学校“127”发展目标和新学期中层干部会和2024年寒假务虚会会议精神，围绕学校重点工作科学规划布局工会工作，通过高质量党建引领工会工作走深走实，为学校“天下工大、世界三航”发展目标做出更大的贡献。（文：钱娅群 审核：陈建军）
