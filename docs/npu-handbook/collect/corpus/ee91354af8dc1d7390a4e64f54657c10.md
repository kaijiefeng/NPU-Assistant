# 中国共产党西北工业大学离退休第六次代表大会顺利召开

2026年5月15日上午，中国共产党西北工业大学离退休第六次代表大会顺利召开。本次大会是在全面学习贯彻党的二十大和二十届历次全会精神，深入开展树立和践行正确政绩观学习教育，扎实推动学校第十四次党代会部署落地见效，奋进“十五五”新征程的关键时期，召开的一次重要会议。党委常委、副校长孔杰，党委组织部副部长宣建林出席会议，离退休党委全体党员代表参会，大会由陈仲昌主持。
赵洪章代表离退休党委向大会作题为“凝心铸魂 守正创新 情暖桑榆 银发增辉 奋力谱写离退休工作高质量发展新篇章”的工作报告。马俊作党费收缴、使用和管理情况报告。大会审议并通过了上述两个报告和大会选举办法，通过监票人，宣读计票人名单。
宣建林宣读学校党委关于同意中共西北工业大学离退休委员会委员候选人预备人选的批复。
在总监票人和监票人的监督下，与会党员代表以无记名投票方式，选举产生了中国共产党西北工业大学离退休第六届委员会委员。
孔杰代表学校党委向大会的胜利召开表示热烈祝贺，向长期以来关心和支持学校建设发展的全体离退休老领导、老党员、老同志致以崇高敬意和诚挚问候，对新一届离退休党委提出四点希望：一是要强化党建领航，把牢正确政治方向；二是要坚持从严治党，涵养清朗政治生态；三是要深化理论武装，厚植为老服务情怀；四是要锚定学校中心大局，助力学校事业发展。
在《国际歌》中，大会圆满完成各项议程，胜利闭幕。
会后，新当选的中国共产党西北工业大学离退休第六届委员会委员召开第一次全体会议。会议严格按照程序，选举产生了新一届党委书记、副书记，研究明确了委员工作分工。
初心如磐担使命，银发奋进启新篇。离退休党委将始终在学校党委的坚强领导下，以更加坚定的信念、更加务实的作风、更加有力的举措，凝心铸魂强根基，银龄奋进新征程，奋力谱写离退休工作高质量发展新篇章，为实现学校“一十百千”发展目标和“天下工大，世界三航”远景目标贡献银发力量！
