# 西北工业大学出版社有限公司-西北工业大学资产经营管理有限公司

西北工业大学出版社有限公司（以下简称“西工大出版社”）创建于1985年2月，是西北工业大学资产经营管理有限公司的独资公司，是工业和信息化部主管、西北工业大学主办的中央级出版社。西工大出版社迄今已出版图书、新形态出版物逾万种。多个系列入选国家出版基金、国家重点出版物出版规划，并承担50余种工信部规划教材与专著建设任务。建社以来，累计获得各类出版物奖400余项，6次荣膺“中国图书奖”。在中国知网年度评选中，西工大出版社先后被评为航空航天领域、制造业与材料领域“最具学术影响力出版社”。
西工大出版社坚持守正创新，主动对接国家战略，始终秉持为高等教育的教学科研服务，为学科建设和人才培养服务，为国防科技工业科研生产服务的办社宗旨。基于航空、航天、航海等学科优势，形成无人机、空天推进、制导武器等国防特色出版高地。围绕高校立德树人根本任务，充分挖掘总师育人文化，做好新时代校园文化主题出版工作，以图书、光盘等载体形式讲好科学研究和人才培养的西工大故事。
西工大出版社积极履行社会责任，加强阅读引领，涵育阅读风尚，通过建设流动的图书馆——“书香号”校车、24小时共享阅读书柜等形式，持续推动书香社会、书香校园建设。
