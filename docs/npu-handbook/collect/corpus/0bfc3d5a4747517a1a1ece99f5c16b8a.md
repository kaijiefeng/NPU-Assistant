# 一站式”学生社区｜学院举办“院长午餐会”活动

9月29日中午，教育实验学院/未来技术学院/学科交叉中心在“智慧三航”学研空间顺利举办“院长午餐会”。学院院长、本博翱翔总师班执行班主任林鑫，学院党委副书记、副院长范翔，2025级辅导员王杰与2025级本博翱翔总师班（HC002514班）20余名同学围坐一堂，共进午餐，聊成长、话未来。
活动中，全班同学依次发言，汇报入班以来的学业生活情况。大家普遍表示，目前生活学习一切平稳，正逐步与导师建立联系，慢慢融入课题组，同时也坦诚提出了在培养方案、课程安排等方面存在的困惑。面对同学们的提问，林鑫院长耐心倾听、一一回应。针对课程冲突等问题，他叮嘱同学们要扎实打好数理、力学、材料等基础，注重培养自学能力；主动了解团队主要研究方向，建立知识脉络，多与导师、师兄师姐沟通交流，找准定位，培养科研思维。他鼓励大家珍惜本科阶段的黄金时期，循序渐进成长，学会与同伴互助协作，平衡好学业与科研竞赛，依托学院本博贯通、学科交叉的优质平台，把个人理想融入国家发展，沉下心、扎下根，成长为服务国家重大战略的拔尖创新领军人才。
一顿午餐，一段暖心话。本次午餐会既是一次阶段性的总结交流，更是一场生动的本科生科研入门指导课，为同学们指明了本博贯通阶段的成长路径。未来，学院将继续倾听学子心声，优化育人环境，陪伴每一位总师班学子阳光成长、勇敢追梦。
