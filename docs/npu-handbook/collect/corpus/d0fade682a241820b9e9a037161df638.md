# 关于陕西省科技成果转化“三项改革” 政策巡回驿站来校开展政策精准服务活动的通知-西北工业大学资产经营管理有限公司

各单位：
按照《关于开展科技成果转化“三项改革”典型案例交流暨政策精准服务活动的通知》（陕科政函〔2026〕207号）安排，陕西省科技成果转化“三项改革”政策巡回驿站将于10月27日入驻学校，开展科技成果转化“三项改革”政策解读和咨询服务。现将具体事项通知如下：
一、时间地点
1. 活动时间：2026年10月27日（星期二）全天
上午9:00—12:00，下午2:00—5:30
2. 活动地点：创新大厦B座四楼麒麟厅。
二、服务对象
有科技成果转化需求，拟开展或正在开展科技成果转化的科研人员及管理人员等。
三、服务内容
“三项改革”政策巡回驿站政策宣讲团由政策专家、技术经理人、创业人员代表、创投机构等组成，采取“一对一”咨询的形式，向相关科研（管理）人员详细释义“三项改革”相关政策，分享解读典型案例，靶向解决科技成果转化实际遇到的瓶颈问题，提供专业化的技术转移服务。
有意向参加的老师可提前梳理在成果转化过程中遇到的具体问题，在活动时间内前往活动地点，积极配合政策宣讲团工作，确保活动取得实效。
