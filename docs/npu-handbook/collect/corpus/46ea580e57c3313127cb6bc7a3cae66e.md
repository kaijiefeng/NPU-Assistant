# 党委保卫部选派骨干面向新生开展安全专题教育

新学期伊始，为切实强化新生安全防范意识，筑牢平安校园建设根基，9月1日至8日，党委保卫部联合党委学生工作部及各学院相继举办了多场新生安全宣传教育活动。党委保卫部选派业务骨干担任主讲，并充分发挥警校联动机制优势，协调邀请西安市公安局刑事侦查支队、碑林分局国保大队及交警碑林大队民警，分别在两校区开展宣讲。活动覆盖新入学的本科生及研究生5900余名。
党委保卫部张大鹏围绕安全意识培养、校园日常安全及消防安全和火场逃生三大板块展开授课。他结合真实校园案例，系统讲解了财物防盗、防范电信诈骗、日常安全防范及火场逃生等实用技能，引导新生切实提升安全防范意识、练就自我保护硬功夫。在此基础上，他进一步从懂法守法、文明修身、突发应急、国家安全、心理调节等维度，强调六种核心安全意识的养成。整场讲座内容翔实、贴近实际，为新生顺利开启大学生活、筑牢平安校园根基提供了有力指导。
“动动手指赚零花，背后可能就是犯罪陷阱。”西安市公安局刑事侦查支队吴大庆、碑林分局国保大队吕欣分别就电信网络诈骗作专题宣讲。他们结合发生在大学生身边的真实案例，逐类剖析了刷单返利、虚假游戏交易、冒充客服、冒充“公检法”、虚假征信等几类高发骗局的作案手法。讲座还引导新生牢记“不轻信、不透露、不转账、多核实”的防范要点，配合反诈视频和现场答疑，帮助新生看清骗局套路，提高对新型诈骗的辨识与防范能力。
来自交警碑林大队的刘潇泽则聚焦新生出行安全，围绕“一盔一带”、电动车骑行规范、车辆盲区、酒驾危害等内容展开讲解。她结合典型事故案例和警示视频，并组织新生现场佩戴“酒驾眼镜”开展互动体验，让大家直观感受酒后视觉失真、判断失准等带来的危险，在“看、听、体验”中加深对交通法规的理解与记忆，引导同学们自觉遵守交规，做到安全出行、文明出行。
校园安全是学生成长成才的基本保障，更是学校事业发展的底线。在此次新生入学教育系列活动中，党委保卫部进一步强化与各学院、各部门的协同联动，畅通了安全教育联动渠道。党委保卫部将以此次活动为契机，持续做好反诈、消防、交通安全等日常宣传教育及应急演练工作，共同为师生营造安全、稳定、和谐的校园环境。
