# 新时代人文经济学自主知识体系构建学术论坛在西北工业大学举办-西北工业大学

2026年9月12日，由陕西（高校）哲学社会科学重点研究基地“马克思主义创新发展研究中心”，世界政治经济学学会创新马克思主义研究分会，西北工业大学人力资源部、长三角研究院、马克思主义学院，《政治经济学研究》《世界马克思主义研究》联合主办的新时代人文经济学自主知识体系构建学术论坛在西北工业大学（友谊校区）学术交流中心顺利举办。来自北京大学、清华大学、复旦大学、南京大学、西安交通大学、中国社会科学院、华中科技大学、山东大学、兰州大学等全国60余所高校、科研机构的专家学者、高校师生130参加了本次论坛。开幕式上，西北工业大学党委常委、校务委员会秘书长王宇波代表主办方致辞，并对各位专家学者的到来表示热烈欢迎。随后，中国社会科学院学部委员、世界政治经济学学会会长程恩富致辞并做大会报告。开幕式由西北工业大学马克思主义学院党委书记王彦革主持。
论坛聚焦“新时代人文经济学自主知识体系构建”这一主题，共设立四个分论坛，分别围绕马克思主义关于文化与经济的基本思想，人文经济学与中国式现代化建设，人文经济学的理论建构与实践探索，人文经济学与多学科交叉融合进行了深入探讨。
在大会报告环节，中国文化软实力研究中心主任、中宣部理论局原副局长张国祚，中国社会科学院近代史研究所原党委书记、《中国社会科学》原副总编周溯源，兰州大学马克思主义学院院长、国家万人计划哲学社会科学领军人才蔡文成，上海社会科学院资深研究员、上海外国语大学国际金融贸易学院特聘教授李正图，华中科技大学马克思主义学院教授、教育部青年长江学者董慧，陕西省社会科学院研究员、《人文杂志》主编秦开凤，山东大学马克思主义学院教授吴文新，长安大学马克思主义学院院长、教授陈怀平，国家级青年人才、西北工业大学马克思主义学院教授孙绍勇，湖北师范大学党委常委、马克思主义学院院长肖六亿，西北工业大学马克思主义学院教授宁殿霞，东北财经大学人文经济研究院院长、教授朱成全，东华大学马克思主义学院教授陈健，中国民航大学马克思主义学院教授王勇，分别作了《谈谈人文经济研究之维》《关于我国传统文化的继承、创新与发展》《“两个结合”方法论对人文经济学的启示》《习近平文化思想的知识源泉》《人文经济学的三重维度与中国自主知识体系建构》《学术期刊在构建中国自主知识体系中的责任担当》《“第二个结合”视域下构建人文经济学自主知识体系的方法论》《以数智文旅场景为牵引加快发展文化新质生产力》《文化数据的“圈地运动”——数据要素确权与文化产业发展的政治经济学分析》《投资跃升赋能新质生产力发展》《人文经济：探寻高质量发展的文化力量》《新时代人文经济学的标识性概念及其概念体系》《习近平总书记关于人文经济学重要论述的核心要义、理论贡献与实践价值》《人文经济学视域下的民航高质量发展》大会主题报告。
西北大学期刊中心主任、教授卫玲，西北工业大学马克思主义学院院长、教授杨云霞，《管理学刊》执行主编郭志伟分别主持各阶段大会主题报告。
大会闭幕式由《山东社会科学》编审、原主编周文升主持。省级哲社重点研究基地主任、西北工业大学马克思主义学院教授孙绍勇作大会总结发言，不仅对整个论坛的开展情况进行了全面介绍，还对会议发言专家的内容进行了精彩点评。他提出：在推进中国式现代化建设进程中，构建新时代人文经济学自主知识体系，必须坚持以马克思主义为根本指导，牢牢把握“两个结合”根本要求，扎根中国发展实践，挖掘人文要素与经济发展的内在逻辑关系；要强化多学科交叉协同研究，提炼人文经济学标识性概念与理论命题，推动理论研究成果转化，为建设哲学社会科学自主知识体系提供坚实学理支撑。
本次论坛的顺利召开，为参会专家、学者及青年师生搭建起高质量的人文经济学研究的学术对话平台。与会人员在思想碰撞中启迪研究思路、凝聚学术共识，产出一批立足本土实践、富有时代意蕴的研究成果，有效推动了人文经济学领域的学术互通与思想互鉴。
