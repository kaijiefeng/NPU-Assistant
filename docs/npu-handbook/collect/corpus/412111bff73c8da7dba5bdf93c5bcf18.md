# 聚智云端 拥抱变革：AI背景下软件工程人才培养改革研讨会顺利召开

为主动对接国家软件产业与人工智能战略发展，适应AI时代软件工程领域的技术变革与人才需求，全面优化本科教育教学体系，夯实专业办学根基，彰显西工大“总师育人文化”特色育人优势，2026年5月24日20:00，软件学院线上召开软件工程专业本科人才培养方案专题研讨会。会议邀请国内知名高校/企业专家齐聚云端，共议AI时代下软件工程人才培养改革新路径，助力“总师型”拔尖创新软件人才高质量培养。
本次研讨会特邀西北工业大学教务部部长王海鹏教授、北京交通大学软件学院院长卢苇教授等15位来自全国高校和产教融合龙头企业的专家开展专项指导，软件学院领导班子及学院全体教师参加会议。
会议伊始，软件学院党委书记李晗对各位专家莅临指导表示热烈欢迎与衷心感谢，并逐一介绍了与会专家。随后，学校教务部部长王海鹏致欢迎辞，感谢各位专家长期以来对学校教学与人才培养工作的支持。他指出，西工大深耕航空、航天、航海三航特色，始终坚守人才培养中心地位，深入推进“总师育人文化”建设，注重“红透专深”底蕴培塑、“系统整机”观念培养及工程实践能力提升。面向“未来总师”培养，学校正加快构建“人工智能+”高质量课程体系。他强调，软件学院紧扣人工智能发展与软件工程前沿，聚焦“软件*AI+X领域”人才培养目标，持续推进课程体系与实践教学改革。此次研讨会是凝聚共识、推动专业提质增效的重要契机，他恳请各位专家围绕培养目标、课程体系、实践环节和特色凝练多提宝贵意见，助力推动专业高质量内涵式发展。
研讨汇报环节由北京交通大学软件学院院长、示范性软件学院联盟理事长卢苇教授主持。首先，软件学院院长郑江滨就AI时代软件工程3.0版本的内涵作了全面解读。他指出，软件工程3.0是以计算机科学、人工智能和数理自然科学为基础，贯通软件开发全流程、面向领域需求，并将前沿技术转化为现实生产力的新型软件工程范式。围绕这一理念，他进一步阐述了AI时代下软件工程内涵变革、“软件*AI+X”培养方案重塑、课程体系深度重构等重点内容，并以20门课程为例，详细介绍了将人工智能技术深度融入专业教学的改革思路，旨在打通“软件-AI-多学科”交叉培养通道，打造具有西工大独特辨识度的人才培养特色，全力培育具备系统思维、创新能力和深厚家国情怀的“总师型”软件拔尖创新人才。
交流研讨阶段，与会专家结合行业发展趋势、高校办学经验与产业人才需求，对培养方案的科学性、前瞻性、实用性进行全面审议。专家们聚焦课程设置优化、实践教学与产业需求对接、AI与专业深度融合、行业特色强化等关键问题深入研讨，从学科建设、产业适配、长远发展等多角度提出针对性修改意见和优化建议，为方案后续修订完善提供了专业权威支撑。其中，骆斌教授评价新版培养方案立意新颖、思路革新，令人耳目一新；范菁教授充分肯定学院前期筹备扎实细致，为兄弟院校提供了可借鉴的优秀样板；卢苇教授重点从三航特色融入、国产化软件教学落地两大维度提出具体优化建议。与会专家一致认为，本次修订的软件工程人才培养方案改革思路超前、体系架构完善，极具引领示范价值。
研讨尾声，郑江滨代表学院作表态发言，将认真梳理、充分吸纳专家们的宝贵意见，明晰修订重点、细化工作举措，高标准推进培养方案迭代完善。李晗作总结致谢，对各位专家的专业赋能与悉心指导致以诚挚谢意，并强调，学院将以此次研讨会为契机，坚守育人初心、坚持改革决心，以高标准高质量完成培养方案修订工作，持续优化“软件*AI+X”复合型人才培养体系。
本次研讨会的圆满召开，充分彰显了软件学院勇立AI 时代潮头、积极推进教育改革的责任担当。会议既是学院纵深推进本科教育教学改革的重要实践，也是践行“总师型”人才培养理念、发挥示范引领和辐射带动作用的重要举措。下一步，学院将充分吸纳专家意见，逐项完善课程体系与实践育人链条，全力构建适配国家战略、彰显西工大特色的软件工程人才培养体系，为国家软件产业、人工智能及三航事业输送更多高素质、创新型、复合型软件人才。
审核：马春燕
