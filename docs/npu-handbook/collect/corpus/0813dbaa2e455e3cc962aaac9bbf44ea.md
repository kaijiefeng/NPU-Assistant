# 校企携手凝合力 协同创新启新程——东方空间技术（山东）有限公司到访航天学院深化交流合作

为精准对接商业航天与可重复使用运载器发展需求，强化产学研深度融合，推动关键核心技术突破与成果转化，2026年4月22日上午，东方空间技术（山东）有限公司总裁助理、引力二号总师兼总指挥黄帅率核心技术团队一行莅临航天学院，围绕可重复使用火箭总体、气动力 / 热、结构、飞控、动力、发射支持等关键技术领域开展深度对接交流。航天学院副院长秦飞、院长助理李阳，空天飞行技术、空天动力技术、航天结构技术等相关研究所负责人及科研团队骨干参加会议，会议由秦飞主持。
黄帅一行详细介绍了公司发展定位、型号研制进展及核心技术需求，重点围绕可重复使用火箭构型优化、回收总体方案、气动力 / 热研究、轻质化结构设计、智能飞控、发动机及发射回收等关键方向，阐明发展现状与攻关目标。他高度认可航天学院在空天领域的科研实力与人才优势，认为双方技术方向高度契合、合作空间广阔，期待建立常态化对接机制，以项目为牵引，加速前沿技术与工程实践深度融合，携手打造商业航天校企合作典范。
秦飞对东方空间技术（山东）有限公司一行表示热烈欢迎，并结合学院研究方向系统介绍了各主要科研团队在商业航天、可重复使用技术、空天飞行器设计等领域的研究积淀与技术成果。他指出，商业航天高质量发展为校企协同创新提供广阔舞台，学院将以此次交流为契机，聚焦企业工程化需求，整合优势科研力量，在联合技术攻关、重大项目申报、试验平台共享、复合型人才培养等方面精准发力，构建高效务实的合作机制。
交流环节，双方围绕相关领域关键技术展开深入研讨，梳理合作路径与实施模式，就联合攻关、资源互补、成果转化等达成高度共识。与会科研团队结合自身研究方向，针对性展示技术储备与解决方案，为后续合作落地奠定坚实基础。
此次交流洽谈，进一步畅通了校企协同创新通道，明晰了合作方向与重点任务。未来，双方将立足国家商业航天战略需求，以技术协同、项目共研、人才共育为纽带，充分发挥高校基础研究优势与企业工程实践优势，以高水平产学研合作助力我国商业航天高质量发展，共筑空天领域创新发展新生态。
