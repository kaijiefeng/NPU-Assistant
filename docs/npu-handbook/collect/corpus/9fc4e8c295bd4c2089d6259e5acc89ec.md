# 《重庆市促进实数融合推动“人工智能+制造”实施方案》出台

为促进实体经济和数字经济深度融合，推动人工智能赋能新型工业化，加速培育新质生产力，市经济信息委印发了，《重庆市促进实数融合推动“人工智能+制造”实施方案》
主要目标
以人工智能创新与制造业应用“双向赋能”为主线，促进“智能产业化”，加快“产业智能化”，推动人工智能赋能“33618”现代制造业集群高质量发展，打造产业智能化、绿色化、融合化发展新优势。到2027年，规上企业数字化研发设计工具普及率达90%、关键工序数控化率达75%，打造一批AI典型应用场景，建设细分行业产业大脑30个、未来工厂40个、国家领航级和卓越级智能工厂40个。
强化基础支撑能力
加强智能算力供给：强化超大规模智算集群技术突破和工程落地，推广自主国产网络通信协议（V2V）应用。有序推进高水平智算中心建设，推动大模型一体机、边缘计算服务器、工业云算力部署，提升智算资源供给能力。
加快汇聚高质量数据资源：提升工业数据管理及合成能力，开发标准化数据工具链，推动多源数据融合与仿真验证。建设多模态工业语料公共服务平台，集成高质量行业语料资源，推动数据开放与协同应用。推动有条件的企业建设智能网联新能源汽车、低空经济、高端摩托车等重点领域行业、企业可信数据空间，整合可信数据资源。深化数据要素市场化配置改革，强化数据供需对接，推动数据资源开发利用。
加强行业大模型研发：加快研发多模态工业算法、物理仿真与时序数据理解等关键技术，搭建适配制造场景的低代码开发平台，开发语料加工、模型训练、模型管理等一体化工具，实现模型快速部署与迭代。支持企业围绕制造业全流程优化，开发部署可推广应用的行业大模型。鼓励企业面向工业细分场景，发展推广轻量、高效、易部署的中小型模型。
聚焦"33618"现代制造业集群拓展赋能新场景
加速赋能重点产业：深入开展人工智能赋能“33618”现代制造业集群区县行活动，组织专家、服务机构深入区县、企业、园区开展赋能服务。支持企业建设人工智能公共服务平台，提供大模型与智能体开发测评、AI赋能诊断、应用场景打造等服务，促进供需精准匹配。支持企业围绕行业智能化转型打造应用场景，加快AI在工业场景中落地应用。
推动制造业全流程数智化升级：打造数字化转型促进中心，提供诊断评估、供需对接、金融赋能、人才培训等全链条服务。推动“AI+研发设计”，加强AI技术在辅助设计、代码编写、药物研发等方面应用，打造新型研发设计模式。推动“AI+中试验证”，加快机器学习、机器视觉等技术在中试环节的应用，提升中试效率。推动“AI+生产制造”，深化智能工厂梯度培育，推动AI技术深度嵌入流程控制、参数调优、排产调度等核心环节，促进生产过程分析、决策、执行智能化。推动“AI+营销服务”，运用智能体提升获客、营销、定价、渠道时机分析等能力。推动“AI+运营管理”，运用AI技术加速订单处理、销量预测、库存预警等供应链管理智能升级，提升战略、人力资源、财务、风险等管理能力。
推广“产业大脑+未来工厂”新模式：以“产业大脑+未来工厂”新模式牵引“四侧”协同促进“四链”融合。推动供给、需求、服务“三端”发力，按照“共性+特色”模式谋划AI赋能综合应用场景，深化制造业领域“12+N”行业产业大脑赋能。支持企业聚焦生产数智化和全要素协同打造未来工厂，推动未来工厂与产业大脑耦合共生，互联算法、模型、数据等，打造一批综合性重大场景、行业领域集成式场景、高价值小切口场景，加快产业模式和企业组织形态变革。
以人工智能促进工业技术改造升级：推动智能数控机床、智能工业控制装备、绿色节能装备等设备更新，加快智能检测与识别设备、原材料无人运输车辆、智能成套生产线等新型智能装备部署，探索人形机器人在工业领域应用。推进5G-A、万兆光网、增值电信业务扩大对外开放试点部署，推动人工智能与工业互联网、低空智联网融合应用，建设网智一体新型基础设施。推广工业软件、多机协同、人机协作系统和大模型、智能体创新应用，提升企业新型技术改造质效。
加速智能产品装备迭代创新
加速高性能智能体开发：建设智能体开发测试平台，集成多模态模型库、工业场景基准数据集、低代码工具链，降低开发门槛。鼓励软信企业联合制造企业基于模型即服务（MaaS）进行二次开发，研发通用、行业智能体，推进产品与服务标准化、模块化发展。开展工业智能体培育专项行动，推动智能体规模化推广应用。
推动工业产品和装备迭代：推动智能网联新能源汽车、低空装备、新材料、工业机器人、智能绿色能源装备、智慧医疗装备等工业产品和装备融合应用AI技术，实现智能化升级与功能迭代。用好首台（套）、首批次、首版次等应用政策，支持企业迭代产品谱系，打造智能产品矩阵。
加快智能终端产品升级：加快轻量级行业模型在端侧设备规模化部署，推动智能终端企业大力发展AI PC、AI手机、AI家电等高价值、高关联性产品，围绕新消费热点培育发展AI眼镜、AI潮玩、智能可穿戴设备等新型人工智能终端。加快建设具身智能开源社区，加强人形机器人整机、零部件和操作系统研发应用，壮大具身智能产业规模。
打造良好赋能生态
培育人工智能优势企业：大力引育细分领域生态主导型企业和人工智能专精特新“小巨人”企业、高新技术企业、制造业单项冠军企业，持续推动“AI+企业码上服务”，壮大人工智能发展和赋能应用主力军。打造人工智能孵化平台，挖掘和培育高潜力、高成长创业团队。着力引育AI赋能方案设计、装备成套、系统集成、数据服务等优质专业服务商，推动开发“小快轻准”解决方案和产品。
打造创新平台体系：建设重庆人工智能湾区、人工智能产业创新综合体，集聚AI企业、高校院所、行业用户开展产学研用协同创新。打造高能级创新平台，建设一批人工智能领域企业技术中心、制造业创新中心、技术创新中心、中试验证、重点实验室等创新平台，引导平台发挥技术创新和成果转化功能，加快形成人工智能创新合作生态圈。发挥人工智能联盟及相关行业协会作用，分级分类推动重点标准研制。
加强专业人才引育：依托高层次引才计划和“满天星”行动，引进一批AI领军人才，汇聚一批青年创新团队，引进算法工程师、数据标注师、智能驾驶系统工程师等领域专业人才。建好用好重庆通用人工智能研究院、重庆人工智能学院，大力引育全球AI顶尖人才及团队，培养“AI+制造”复合型、实战型人才。
深化产融对接服务：持续深化“产业大脑”和“金融大脑”双向赋能，引导金融机构开发企业智改数转金融产品。优化企业技术改造贷款政策，扩大贴息支持范围。探索将制造业企业高质量生产数据作为银行贷款增信项，提供差异化、全周期金融服务。推动国有投资基金、社会资本为行业语料库建设、智能体与大模型开发、可信数据空间建设等提供资金支持。引导融资租赁公司拓展AI业务，对AI设备和产品提供融资租赁服务。
为保障《实施方案》的顺利落地实施，重庆还将建立部门、区县协同推进工作机制，市经济信息委会同有关部门推动落实重点任务，鼓励各区县结合实际制定政策措施；建立完善“AI+制造”政策体系，加大人工智能创新、应用和赋能等方面的支持力度。
此外，重庆将建立常态化人工智能场景清单征集、遴选、发布机制，以场景带动赋能应用；依托世界智能产业博览会、中国西部国际投资贸易洽谈会等平台，推动跨行业、跨区域的AI赋能技术和应用经验交流及合作共享。
专栏1 重点产业“AI+制造”应用
智能网联新能源汽车：研发汽车领域大模型，推动AI赋能车身设计、硬件配置、参数调优、质量控制与预测性维护等环节，推进整车智能研发、在线检测与全生命周期质量追溯。强化AI技术在辅助驾驶、智能交互、仿真分析等领域应用，打造智慧出行、智慧物流等应用场景。
新一代电子信息制造业：以生成式人工智能与数字孪生技术、先进计算与多模态大模型，提升电子元器件虚拟仿真调试、快速迭代验证、高精度仿真预测等能力。推动企业部署产线动态重构、工艺参数优化模型，构建自适应的电子信息柔性生产系统，开发模块化、智能化制造装备和产线。
先进材料：加快打造新材料研发预测、分子设计、合成制备、关键工序优化等垂类模型，提升新材料研发设计、高通量自动化实验和制备能力。建设新材料大数据中心，构建材料行业高质量数据集。推动企业部署大模型智能体，赋能在线监控调控、工艺改进等，提高生产效率和安全水平。
智能制造及装备：以工业视觉与多模态大模型、数字孪生与强化学习技术，提升检验检测装备智能识别与分析能力。推动AI技术赋能工业机器人、智能绿色能源、自适应通机农机、高端传动、轨道交通等装备的研发设计、性能优化、预测性维护、智能运维等环节。研发无源物联网技术，依托模块化生产单元与智能决策服务，推动制造系统柔性化智能化跃升。
食品及农产品加工：加快运用数据分析决策、生成式AI配方设计、工艺参数自调节等技术，推动产品需求预测和个性化定制。推动开发原料和食品生产“区块链+AI”追溯、食品园区“5G+工业互联网”、供应链风险预测与应急响应等智能化解决方案，保障食品生产安全和供应稳定性。
软件信息服务：构建覆盖软件需求设计、开发、测试、运维的智能化开发工具链产品体系，推动AI技术与基础软件、工业软件及制造业行业应用软件融合，提升软件动态感知、自由化与自演进能力，实现软件功能模块的动态重组与性能优化，赋能软件智能决策能力。研发高性能智能通信中间件，实现软件与大模型的高效协同及多源数据统一分析。
特色优势及“新星”产业：结合各行业特点，充分运用AI技术赋能产业发展壮大，加快发展纺织服装智能化个性化设计与高效生产、生物医药及智慧医疗装备智能研发与供应管理、“AI+低空”等新场景新模式。
专栏2 打造“AI+”智能产品装备
软件和智能体：推动研发设计、生产控制等工业软件向具备感知、决策与执行能力的智能体转型。发展AI驱动的智能体、数字内容、工业软件、汽车软件、开源鸿蒙软件等产品研发与应用。加快研发智能车载、工业控制等智能操作系统，强化实时调度与边云协同能力，提升与工业设备兼容性。
智能网联新能源汽车：加速发展智能座舱、智能车控、智能驾驶、车载传感、车载光、车规级芯片等智能网联关键系统与部件，推动商用车加速智能化转型，培育壮大智联电动车产业。推动整车企业与软硬件供应商协同开发，构建覆盖“车路云网图”的智能产品生态。
低空装备：加强高端低空航空器、反制设备、关键零部件等低空装备研发制造，丰富低空制造产品谱系，推动飞控系统、感知避障模块、轻量化动力系统等关键部件智能化升级。
新材料：加快AI驱动的先进基础材料、合金材料、高性能纤维及复合材料、合成材料研发，推动超材料、智能材料、新型能源材料、微结构材料等前沿新材料研发。
生物医药：强化AI在药物智能筛选、分子结构预测、临床试验设计与智能分析、药物合成工艺优化等领域应用，发展高价值特色原料药、创新小分子药、抗体药物、细胞与基因药物、新型疫苗、长效多肽药物等产品，加快创新药研发。
智慧医疗装备：强化多模态医疗数据融合分析、小样本学习等技术及肿瘤、病理诊断等垂类大模型研发应用，发展AI辅助诊疗、智能病理分析、血液透析和手术动力装置、脑机接口、可穿戴器械等智慧医疗装备。
具身智能机器人：重点开发面向工业制造的焊接、喷涂、装配机器人，面向商业服务的接待、配送、清洁机器人，以及面向特种场景的检测、作业机器人。培育发展具身智能机器人操作系统和一体化关节、末端执行器等零部件，提升机器人智能化与自主化水平。
新一代智能终端：加强高性能、低功耗的设备端和边缘计算推理芯片等产品研发生产，加快智能传感器开发和规模化生产。推动轻量化模型在终端部署，发展AI PC、AI手机、AI家居家电等消费电子与家电产品，打造AI眼镜、AI音箱、AI潮玩、AI教育终端等个人消费终端新爆品。
