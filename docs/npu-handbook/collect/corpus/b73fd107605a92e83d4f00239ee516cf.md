# 一金两铜！我校在第三届全国博士后创新创业大赛中取得佳绩

10月28日，第三届全国博士后创新创业大赛总决赛在福建省泉州市落下帷幕。我校共有4个项目团队入围总决赛，经过激烈角逐比拼，杨德雨、孙延栋和陆宏湜为代表的3个项目团队脱颖而出，获得1个金奖、2个铜奖，这也是我校首次在该项全国性高水平赛事中斩获金奖。
本届全国博士后创新创业大赛是我国规模最大、层次最高、覆盖面最广的博士后赛事，由人力资源社会保障部、福建省人民政府共同主办。本届大赛以“博创引领四十载 智汇赋能向未来”为主题，设置创新赛、创业赛、海外境外（“一带一路”）赛、揭榜领题赛等4个组别，包含新一代信息技术与人工智能、高端装备制造与机器人、新能源与节能环保等7大赛道，参赛项目聚焦国家重大战略、科学技术前沿、产业发展需求，共吸引8006个项目、3.6万人参赛，共有1700余个项目入围全国总决赛，产生了63个金奖、133个银奖和198个铜奖。
学校高度重视本次赛事，自大赛3月份启动以来，人力资源部协同各学院、相关部门周密部署、精心组织，从项目申报、项目遴选到“一对一”专家辅导、路演答辩指导等，充分挖掘项目内涵和特色，不断打磨完善参赛作品。
杨德雨，材料学院博士后，碳/碳复合材料团队成员，参赛项目是《冰与火-面向极端服役环境的碳基复合材料研发及产业化》，获得本次大赛“海外境外赛”的“新材料与石油化工”赛道金奖。该项目研发了系列高性能碳基复合新材料，解决了传统材料无法在极低温、超高温等极端环境下稳定服役的痛点，并成功实现了基础科研成果的落地转化。
孙延栋，电子信息学院博士后，空天电磁认知与利用实验室成员，参赛项目是《基于分布式数学阵列的无人机精准侦扰系统》，获得本次大赛“海外境外赛”的“新一代信息技术与人工智能”赛道铜奖。该项目提出了分布式数学阵列无人机精准侦扰技术，实现了对无人机的“检测-识别-干扰”的技术突破，显著提升了对无人机反制能力，为维护国家低空安全提供有力的技术支撑。
陆宏湜，自动化学院博士后、准聘副教授，空间系绳与飞行器控制团队成员，参赛项目是《太空清道夫-基于柔性系绳的空间不受控威胁物体清理平台》，获得本次大赛“海外境外赛”的“其他行业”赛道铜奖。该项目研发了基于旋转系绳系统的空间碎片清理平台，解决了传统机械臂等硬接触清理方式在安全性和经济性方面的缺陷，将大型空间碎片清理成本降至传统技术约十分之一，精准符合我国及“一带一路”沿线国家航天院所、企业对空间环境治理的需求。
我校将以此次获奖为契机，深入学习贯彻党的二十届四中全会精神，继续加大博士后人才培养与支持力度，进一步营造青年科技人才成长发展的良好生态，不断完善博士后选拔、培养、考察长效机制，推动博士后队伍高质量发展。
