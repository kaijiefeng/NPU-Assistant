# 莫航学院组织2025级本科生开展认识实习

2026年7月，西北工业大学莫航学院组织2025级本科生，赴西安飞机工业（集团）有限责任公司、新海航旗下海航技术西北维修基地等单位开展认识实习。
在安全培训、观摩学习、现场讲解与交流互动过程中，同学们将课堂所学与工程实际相对照，直观了解了行业运行情况及专业应用场景。实习将专业知识学习与行业认知相结合，讲解人员结合航空制造发展历程和民航安全运行要求进行介绍，同学们在了解行业的同时，树立起服务国家航空事业的信念。
本次认识实习将知识传授、能力培养、素养提升与价值塑造贯穿实习全过程，是莫航学院推进产教融合、落实实践育人的重要举措。学院将持续深化产教融合，着力培养兼具家国情怀和工程实践能力的高素质人才。
