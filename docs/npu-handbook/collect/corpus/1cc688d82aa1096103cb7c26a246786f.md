# 后勤部办公室党支部召开专题学习会

为深入贯彻落实党中央关于开展党纪学习教育的要求，高标准、高质量开展党纪学习教育，5月7日上午，后勤部办公室党支部组织全体党员召开专题学习会。会议由党支部书记张文刚主持。
首先，张文刚向全体人员传达了《中共西北工业大学委员会关于开展党纪学习教育的实施方案》文件精神。接着，全体人员集中观看了《中国共产党纪律处分条例》（以下简称《条例》）讲解视频，并就《条例》的制定背景、修订内容、执行要求等方面展开专题学习研讨，重在逐条逐章学习党规党纪知识，培养党规党纪素养。
最后，张文刚对下一步学习提出了具体要求。他强调，《条例》是规范我们工作行为的重要依据，是我们履行职责、服务群众的重要准则。全体党员必须深入学习、全面掌握。他要求党员干部把遵规守纪刻印在心，内化为日用而不觉的言行准则，进一步强化纪律意识，始终做到忠诚干净担当，确保在工作中能够严格遵守、有效执行。（撰稿人：毛淑兰；审稿人：韩争胜）
