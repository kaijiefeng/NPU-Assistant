# 图书馆组织收看党的二十大开幕会

2022年10月16日上午10点，中国共产党第二十次全国代表大会隆重开幕。图书馆组织领导班子成员、党总支委员、党总支理论学习中心组成员及全体党员分别在友谊校区图书馆会议室和图书馆党员活动室集中观看了党的二十大开幕会，认真聆听习近平总书记向大会所作的报告，共同亲历这一庄严的时刻，第一时间学习领会了大会精神。
图书馆全体党员在聆听大会报告后纷纷表示，党的二十大报告高瞻远瞩、立意深远，内涵丰富、博大精深，反映了广大人民群众的心声，映照出强国富民的动人画卷，昭示着中华民族伟大复兴的光明前景，鼓舞人心，催人奋进。同时，在中国共产党第二十次全国代表大会召开之际，图书馆加强宣传氛围的营造，深入挖掘红色资源，以“赓续红色血脉 庆祝党的二十大”为主题开展党史光辉历程照片展、红色报刊展和红色影片欣赏活动。并通过主题书展、官网、瀑布屏、横幅等方式加大宣传力度，全面营造浓厚的文化氛围。
图书馆将继续坚持立德树人根本任务，不断增强“资源育人”、“图情育人”、“知识育人”、“信息育人”、“文化育人”、“管理育人”、“服务育人”功能，为全校教学、科研、学科建设、人才培养和双一流建设提供强有力的保障和支撑，为全面建成“特色鲜明、水平先进、服务一流”的研究型、专业化、智慧型图书馆而努力奋斗。
