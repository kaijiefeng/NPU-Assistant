# 西北工业大学长安校区电力增容改造项目设计采购公告（代资格预审公告）

一、采购内容
1.项目名称：西北工业大学长安校区电力增容改造项目设计
2.项目地点：西北工业大学长安校区
3.项目概况：计划为长安校区新增10kV进线电缆，并更换部分老旧10kV进线电缆等，增加供电容量3万kVA，解决长安校区市政供电容量不足的问题。目前该项目增容方案已获供电部门正式批复。
二、报名资料
1.企业营业执照；
2.法人授权委托书、被授权人身份证（留法人或法人授权委托人联系方式及有效电子邮箱）；
3.具备【工程设计综合资质甲级】,或【电力行业设计乙级】及以上资质,或【电力行业（变电工程/送电工程）专业设计乙级】及以上资质。
4.项目负责人需具备相关专业高级技术职称或相关执业资格证书，且在本单位就职。
5.拟派项目负责人2023年1月1日（以合同签订时间为准）以来承担的合同额不低于30万元的业绩合同一份（合同或其它项目资料中须明确体现项目负责人姓名）。
三、采购人对报名单位进行资格预审，经审核合格的单位才能参与后续报价。
四、报名时间
2026年10月21日至10月23日（工作日：上午8:00-12:00，下午14:00-16:00）。
五、报名方式
本次报名采取线下报名，不接受任何线上报名、不接受联合体投标、不接受关联单位同时投标。响应单位报名时必须携带采购公告第二条所有报名资料的原件（以备报名现场查验，原件查验后及时返还）及加盖公章的复印件（复印件须按照采购公告第二条的报名资料顺序装订，复印件不返还）。未按要求报名或提供资料，或在截止时间后收到的报名资料，一律视为无效。
六、其他要求及注意事项
（一）本次公开采购以各响应单位报名资料中的邮箱为准发送采购文件等相关资料，各响应单位务必保持邮箱可正常接收邮件，凡因响应单位对公告阅读不深、疏漏、或因邮箱问题造成的后果和风险，均由响应单位自负。
