# 青春聚力践初心，志愿同行担使命｜电子信息学院信愿志愿者服务队召开全体成员大会

为进一步凝聚队伍向心力，引导新成员快速熟悉组织架构、明晰各部门岗位职责，厚植志愿服务奉献精神，锚定后续志愿服务工作目标，10月9日，西北工业大学电子信息学院信愿志愿者服务队全体成员大会暨十月主题团日学习活动于学院楼119会议室顺利召开。本次会议由服务队队长王可馨主持，服务队核心骨干与 2026 级新成员悉数参会。
大会伊始，服务队队长王可馨、团支书景亦菲、副队长丁奕晨、各部门负责人及新成员依次进行自我介绍，分享个人经历与兴趣特长，在轻松融洽的氛围中增进彼此了解、拉近成员距离，为后续团队协作与志愿服务活动的开展奠定良好基础。
随后，丁奕晨向全体成员介绍了服务队的基本情况，并带领大家共同学习服务队章程，进一步明确组织宗旨与工作规范。各部门负责人围绕组织部、宣传部、外联部及办公室的职能分工、日常工作和具体职责依次进行介绍，帮助新成员全面了解服务队组织架构与运行机制，为今后有序开展志愿服务工作打下坚实基础。
随后，景亦菲主持开展以“弘扬志愿精神，勇担青年使命”为主题的团日学习活动，围绕“奉献、友爱、互助、进步”的志愿精神，阐释志愿服务的时代内涵与社会价值，并介绍志愿服务专业化、项目化、组织化的发展趋势，引导成员进一步增强服务意识与责任担当，在志愿实践中践行青年使命。
会议最后，王可馨对服务队近期重点工作进行了介绍，重点讲述了即将开展的重阳节敬老志愿服务活动。围绕活动内容与组织形式，成员们积极交流、建言献策，提出联动校内其他学生社团，融入养生操教学、魔方体验、血压测量等服务项目，进一步丰富活动内容、提升服务质量，努力为老年群体带来更加贴心、暖心的志愿服务体验。
本次大会增进了新老成员之间的交流，明确了服务队工作职责与近期任务，进一步凝聚了志愿服务共识。下一步，电子信息学院信愿志愿者服务队将持续弘扬志愿精神，丰富活动形式，提升服务实效，引导青年志愿者在服务社会的实践中彰显青春担当。
