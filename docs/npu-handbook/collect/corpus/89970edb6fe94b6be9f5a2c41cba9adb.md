# 后勤部办公室党支部召开党课暨第一次集中大课交流研讨会

根据学校深入贯彻中央八项规定精神学习教育工作要求，进一步强化党员干部厉行节约、反对浪费的责任意识，6月25日上午，后勤部办公室党支部组织召开支部党课学习暨第一次集中大课交流研讨会。会议由党支部书记张文刚主持，全体党员参加会议。
首先，由后勤部办公室副主任郝东兴为全体党员讲授《<党政机关厉行节约反对浪费条例>学习》专题党课。他从《条例》修订的重要意义切入，重点解读了经费管理、公务接待、公务用车、办公用房等方面新增和修订的条款内容。随后结合4个典型案例深入剖析问题根源，阐述警示教育关键点，提出全体党员要切实增强“过紧日子”意识，把《条例》落实到后勤日常工作的各个环节。
接着，张文刚带领全体党员回顾了6月18日学校第一次集中大课《把教育强国的宏伟蓝图变为美好现实》的要点内容。与会党员结合各自工作实际，围绕“以习近平总书记重要讲话精神为指引，做教育强国建设的奋斗者、践行者”这一主题进行了深入交流研讨。
最后，张文刚强调，全体党员要积极发挥模范带头作用，从日常工作做起，从一言一行做起，在厉行勤俭节约、反对铺张浪费上走在前、作表率。同时，他向与会党员提出更高的要求，希望大家充分认识新时代新征程加快建设教育强国的重大意义，聚焦学校中心工作，提高后勤管理与服务水平，助力学校高质量、高水平、高速度发展。（撰稿人：毛淑兰；审稿人：韩争胜）
