# 关于2023年“五一”劳动节放假安排的通知-西北工业大学

各单位和全校师生：
根据《国务院办公厅关于2023年部分节假日安排的通知》（国办发明电〔2022〕16号），结合我校实际，现将2023年“五一”劳动节放假事宜通知如下：
1.放假时间：2023年4月29日-5月3日，共5天。4月23日（星期日）、5月6日（星期六）正常上班，4月23日、5月6日按当日课表正常上课，具体要求以教务处、研究生院通知为准。
2.“五一”劳动节后友谊校区作息时间调整为：上午8:00—12:00，下午14:30—18:00。长安校区作息时间不变。
3.请各单位做好放假期间的安全稳定、保密及应急管理工作，主要负责同志手机要保持24小时畅通。
4.学校值班电话：
友谊校区：88493361、88492261（传真）
长安校区：88430088
保卫处24小时值班电话：88494110（友谊校区）
88430110（长安校区）
特此通知。
学校办公室
2023年04月17日
