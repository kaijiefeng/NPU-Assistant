# 【科技成果】国际顶尖运动员盛赞深圳技术：无人机创新引领全球运动科技潮流

在本月举办的“滑翔伞世界杯（中国站）”上，西北工业大学深圳研究院展示了新型无人机牵引滑翔伞技术，吸引了众多国际滑翔伞运动员与爱好者的关注。活动现场，中国国家队元朝林教练，两项国记录创造者彭跃，法国、新加坡、澳大利亚、俄罗斯、斯洛文尼亚等10余国世界顶级滑翔伞运动员先后进行了牵引飞行体验，并给予极高评价。
（无人机牵引下平地起飞的滑翔伞）
无人机牵引滑翔伞技术：重新定义滑翔伞升空体验
传统滑翔伞升空通常依赖地面绞盘（winching）或山坡起飞，西北工业大学深圳研究院研发的无人机牵引技术通过高精度控制与稳定动力输出，为滑翔伞运动员提供了前所未有的平稳、高效升空体验。参与体验的运动员纷纷表示，这一技术不仅大幅提升了升空过程的流畅性，更为滑翔伞运动开辟了全新的可能性。一位国际滑翔伞运动员在体验后兴奋地表示：
It is absolutely amazing!!! I have never had such a smooth pull to altitude. This is so much better than winching and opens so many new possibilities! You guys are doing an absolutely amazing job!”
“太不可思议了！我从未体验过如此平稳的升空牵引。这比传统绞盘牵引好太多了，而且为滑翔伞运动带来了更多可能性！你们的工作简直太棒了！”）
（法国顶尖滑翔伞运动员转发翱翔蔚蓝科技牵引起飞视频）
科技赋能体育，翱翔蔚蓝科技引领行业创新
为了推动技术应用和发展，西北工业大学深圳研究院孵化成立了深圳翱翔蔚蓝科技有限责任公司（以下简称“翱翔蔚蓝科技”），作为一家专注于低空运动装备研发的科技型企业，翱翔蔚蓝科技始终致力于通过技术创新推动低空运动与航空产业的发展。此次在滑翔伞世界杯上的成功展示，不仅彰显了技术实力，也为全球滑翔伞运动的发展提供了新的思路。公司负责人表示：我们希望通过无人机牵引技术，解决传统滑翔伞升空中存在的效率与安全性问题，同时为运动员和爱好者创造更极致的飞行体验。未来，我们将继续深化技术研发，推动低空运动的智能化升级”。
（右三为翱翔蔚蓝科技总经理、技术负责人，西工大深研院无人系统实验室负责人王强）
展望未来：无人机牵引或成滑翔伞运动新标准
随着无人机技术的不断成熟，其在航空运动领域的应用潜力正被不断挖掘。翱翔蔚蓝科技的此次突破，不仅获得了顶尖运动员的认可，也引发了行业对“智能化、自动化牵引技术”的广泛讨论。未来，这项技术有望成为滑翔伞训练、比赛乃至休闲飞行的全新解决方案。
深圳翱翔蔚蓝科技有限责任公司简介
深圳翱翔蔚蓝科技有限责任公司成立于 2024 年，凭借全球首创的滑翔伞牵引无人机系统，重新定义了低空运动装备的技术标准。滑翔伞牵引无人机系统凭借全球独家技术和核心专利，在快速增长的全球滑翔伞牵引设备市场中占据技术制高点。其专利设计的双旋翼自适应牵引平台突破传统绞盘地形限制，实现全地形、高精度的智能化牵引，提升运营效率。该解决方案精准服务于商业俱乐部、专业运动员及特种训练场景更引领航空运动进入智能牵引时代。
