# 分析测试中心开展实验室安全全覆盖自查核查工作

分析测试中心于10月19日-20日组织开展实验室安全自查与核查工作，进一步压实安全主体责任，排查整治风险隐患。
各实验室负责人于10月19日对照自查表，逐项核查档案资料与现场安全。10月20日，中心副主任刘平带队，对中心各实验室、样品制备区、气瓶间等重点区域开展全覆盖核查，检查聚焦气瓶管理、危化品存储使用、仪器运行及安全监测设施等关键环节。
刘平在检查中强调：要推动安全监管向全时间段覆盖，杜绝非工作时段、节假日和夜间实验中的监管空白；持续规范气瓶固定、状态标识及危化品领用回收闭环管理，巩固前期整改成果，形成长效监控机制。
此次自查核查进一步强化了中心全员安全意识，确保各时段实验测试活动安全、规范、有序开展，为教学科研提供坚实保障。（文：袁雨晴 审：刘平）
