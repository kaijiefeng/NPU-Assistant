# 名师总师倾力授课，《三航整机工程实训》金课圆满结课

近日，由我校教务部（工程实践训练中心）牵头建设的校级金课《三航整机工程实训》顺利完成全部教学任务，圆满结课。该课程立足学校总师育人特色，聚焦“三航”国家战略需求，汇聚专业名师与行业总师，发挥师资优势赋能实践教学，紧扣整机能力明晰培养定位，为西工大学子打造沉浸式整机工程实践课堂。
教学团队汇聚航空、航天、航海、动力、控制、制造、材料七大领域名师与总师，赵美英、魏祥庚、代洪华、潘光、范玮、齐乐华、李恒、崔万照8位专家分领域开展专题教学。课堂依托飞机、火箭、水下航行器等实物教具，结合C919、运-20等国产装备研制实例，授课专家立足多年科研与工程积淀，从整机架构、零部件工艺到系统集成逐层拆解重难点，现场分步示范、俯身答疑，精准解答学生工程疑问，把前沿工程理念与实战经验融入教学，充分彰显总师工程视野与名师育人初心。
航空学院赵美英教授讲授航空——军机、民机
航天学院魏祥庚教授讲授航天——火箭
航天学院代洪华教授讲授航天——空间站
航海学院潘光教授讲授水下航行器
机电学院齐乐华教授讲授制造体系
动力与能源学院范玮教授讲授动力体系
材料学院李恒教授讲授材料体系
电子信息学院崔万照教授讲授控制体系
下一步，教务部（工程实践训练中心）将继续打磨《三航整机工程实训》精品课程，提炼本次教学经验，优化教学设计方案，持续探索“三航”特色实践育人之路，着力强化师生系统整机观念，为学校培养高素质“三航”工程人才筑牢实训保障。
