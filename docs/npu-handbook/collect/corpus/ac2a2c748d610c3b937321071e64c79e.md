# 国家卓越工程师学院开展安全保密专题教育暨高质量就业座谈交流会

10月15日下午，国家卓越工程师学院在友谊、长安两校区同步开展安全保密专题教育和高质量就业座谈交流会。友谊校区由学院党委书记、常务副院长蒋建军作安全保密专题教育，辅导员戴久淳作高质量就业座谈交流讲解；长安校区由学院党委副书记、副院长王谦围绕两个专题分别宣讲。学院各年级学生分校区参加座谈会。
安全保密专题教育环节，蒋建军、王谦深入阐释总体国家安全观，要求卓越工程师严守科研数据保密底线，提醒同学们严守“涉密不上网、上网不涉密”保密红线，筑牢网络安全防线；并结合警惕钓鱼邮件、终端安全防护、规范信息发布、规范使用AI工具等网络安全重点事项作了具体强调。
高质量就业专题座谈交流会上，王谦、戴久淳结合学校高质量就业动员会议精神，深入研判当前就业总体形势，围绕简历打磨、网签流程及相关注意事项开展细致讲解。座谈现场互动环节，针对同学们提出的问题逐一解答，引导学生进一步做好职业生涯规划，自觉将个人理想追求融入强国建设、民族复兴伟大事业之中。
此次安全保密专题教育暨高质量就业座谈交流会，进一步筑牢了学生安全保密思想防线，明晰了职业发展方向。学院将继续把安全保密教育与就业引导融入人才培养全过程，为培养堪当民族复兴大任的卓越工程技术人才不懈努力。
