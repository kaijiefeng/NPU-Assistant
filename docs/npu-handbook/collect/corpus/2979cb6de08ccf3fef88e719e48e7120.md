# 北京研究院党支部召开主题教育专题组织生活会-西北工业大学

按照学校《关于召开学习贯彻习近平新时代中国特色社会主义思想主题教育专题组织生活会的通知》要求，9月4日上午，北京研究院党支部召开学习贯彻习近平新时代中国特色社会主义思想主题教育专题组织生活会，北京研究院党支部全体党员及资产公司党委委员、副总经理杨安庆同志出席会议。
会上，党支部书记方文杰代表支部向党员大会报告了开展学习贯彻习近平新时代中国特色社会主义思想主题教育的有关情况，并通报了支部检视问题情况。随后，全体党员逐一发言，从6个方面突出问题和12条具体要求出发，深入开展自我批评和批评。
杨安庆在点评时表示，北京研究院主题教育专题组织生活会会前准备充分、会上态度真诚，起到了总结提升、增进团结的预期目的。他希望北京研究院党支部要坚持习近平新时代中国特色社会主义思想学习，深刻把握新习近平新时代中国特色社会主义思想的世界观和方法论。北京研究院发展要在深入开展调查研究的基础上，谋定而后动，锚定学校“127”发展目标开展各项工作。此外，他还对北京研究院的党风廉政建设、意识形态建设和保密工作提出了具体要求。
方文杰在总结时表示，北京研究院党支部要坚决贯彻落实校党委和资产公司党委关于学习贯彻习近平新时代中国特色社会主义思想主题教育的各项工作部署，牢牢把握“学思想、强党性、重实践、建新功”的总要求，推动主题教育取得实实在在的成效，为奋进新征程凝心聚力，为北京研究院高质量发展筑牢根基。
