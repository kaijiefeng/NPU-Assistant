# 校长宋保维调研指导高招咨询相关工作-

连日来，校长宋保维赴高招咨询会现场及湖南长沙、衡阳、耒阳等地调研指导高招咨询相关工作，并为考生与家长讲解学校各项招生政策。
6月26日，我校2025年校园开放日暨一流大学高招咨询会在友谊校区三航路举行，各学院（研究院）及90余所国内一流大学招生老师齐聚西工大，为前来咨询的考生与家长提供面对面指导。校长宋保维赴活动现场调研指导工作。副校长杨益新陪同调研。
本次高招咨询会吸引了陕西省及周边省份大量考生，各学院（研究院）主要领导、招生老师以及招生办公室工作人员与考生、家长面对面，耐心细致地解答学校人才培养、专业设置、招生政策、志愿填报、录取分数等问题，为广大考生提供一线指导和服务，现场气氛热烈、交流深入。
宋保维来到各学院（研究院）招生咨询展位前，对前来参加咨询会的广大考生与家长表示欢迎。他详细询问:“从哪里过来的？意向学院和专业是什么？未来有没有深造计划？”为考生及家长介绍学校学科特色、培养模式、就业前景等，鼓励考生积极报考。
宋保维说，校园开放日既是向社会综合展示学校办学特色、师资底蕴、教学环境的有效方式，也为广大考生搭建了一个与心仪学校面对面沟通交流的平台，各单位要利用好这个时间窗口，以干净优美的校园环境、饱满热情的精神面貌迎接考生和家长，为他们提供更全面、更专业、更个性化的指导与服务，为学校“总师型”人才培养争取更多优质生源。
6月27日，宋保维来到湖南“四大名校”之一的湖南师大附中招生一线参与本科招生宣传工作，参加湖南师范大学附属中学2025届高考考生志愿填报咨询暨高校面对面交流活动，现场为考生答疑解惑。期间，宋保维一行参观了湖南师大附中校史馆，并与湖南师大附中书记谢永红进行座谈交流，深入探讨大学与中学的贯通培养举措。
6月28日，宋保维还来到有百年校史的耒阳市第二中学，分别与该中学曹飞跃书记和学生代表座谈交流，为同学们签名留念。他介绍了学校在“三航”等国防科技领域的重要贡献以及学科特色、招生政策等相关信息，鼓励同学们积极报考西工大，勉励大家坚定理想信念，心怀“国之大者”，努力提高自身本领，肩负起报效祖国的光荣使命。
宋保维对今年招生宣传的组织保障工作表示肯定，对各招生组的辛勤付出表示感谢。他指出，本科生源质量是学校发展和社会评价的关键核心指标，是我校“总师型”人才培养的“毛坯”和“原材料”。当前，正是本科招生工作的攻坚时期，希望大家发扬“四千”精神、保持“六皮”作风，继续做好招生宣传以及后续招生录取工作，为学校“总师型”人才培养吸纳更多优质生源。
