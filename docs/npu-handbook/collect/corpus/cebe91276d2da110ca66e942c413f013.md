# 2025年保密宣传月┃图说保密违法行为（电子挂图）

图说保密违法行为（电子挂图）
一套6张
保密法第五十七条列举的保密违法行为是导致保密措施失效、国家秘密失控、保密技术防护体系受到破坏、国家秘密安全遭受严重威胁的最常见、最典型的行为。
本套挂图基于新修订保密法第五十七条列举的常见保密违法行为，列举典型案例，辅以生动漫画，作出保密提醒，旨在提示机关、单位工作人员切实增强保密意识，规范自身行为，守住守牢国家秘密。
有电子屏的单位可以选择下载使用，电子挂图仅限于在校内单位内部电子屏播放，各单位在下载以及使用电子挂图资料时应注意版权保护，不进行以下任何一项或多项活动：
1、复制、改编或出售电子挂图资料，或创建与电子挂图资料相关的派生作品；
2、将电子挂图资料用于商业目的，包括但不限于广告、营销或在公共媒体传播推广活动；
