# 全校首个阅读专区“铸剑书苑”落地网络空间安全学院

为深化图书馆与各培养单位资源协同共建，推动优质文献资源下沉教学科研一线，打通书香育人“最后一公里”，赋能学科建设与学风培育，9月24日上午，图书馆联合网络空间安全学院在长安校区举行“铸剑书苑”揭牌仪式。学校图书馆党总支书记高大力、副馆长郭永建，网络空间安全学院党委书记张文涛、党委副书记杜瑶，图书馆读者服务中心教师代表，网安学院辅导员及铸剑班学生代表共同参与活动见证书苑落成。

本次“铸剑书苑”由学校图书馆与网络空间安全学院联合打造，是学校书香校园建设、精准服务师生的重要创新举措。书苑书籍由图书馆统筹甄选、专项供给，聚焦网络空间安全学科特色，覆盖专业核心著作、前沿科研文献、通识素养读物等各类资源，在学院设立专属阅读阵地，让师生足不出院即可便捷借阅优质图书资源，切实将文献服务、阅读服务、育人服务送到师生身边。

高大力在致辞中指出，图书馆作为学校文化育人与文献资源保障的核心阵地，承担着保存知识、服务科研、浸润心灵的重要使命。长期以来，图书馆坚持立足全校师生实际需求，积极探索馆院共建新模式，推动馆藏资源走出馆舍、走进院系。此次共建“铸剑书苑”，正是图书馆资源下沉、服务前移的一次生动实践。围绕网络空间安全学科发展方向，图书馆精心遴选专业著作、前沿论著与人文读物，把图书角建在师生身边，降低阅读门槛，营造随处可阅读、随时能研学的良好环境。未来图书馆也将根据师生反馈动态更新馆藏书目，不断丰富书苑资源供给。

张文涛在致辞中指出，网络空间安全学院肩负守护“第五疆域”的时代使命，学院始终践行“铸剑育人”的培养理念，既要锤炼学生过硬的技术本领，也要厚植学生的人文底蕴与家国情怀。学院将用好这一全新阵地，后续依托书苑开展读书分享、主题沙龙、学术共读等系列活动。

“铸剑书苑”作为学校第五届网络安全文化节笃学固本板块的重要组成部分，将同步启动“书香网安·悦读启航”和“网小安”悦读“春泽、夏荫、秋实、冬藏”四季系列主题。下一步，图书馆与网络空间安全学院将持续深化共建合作，常态化更新书苑馆藏、丰富阅读活动、完善运维机制。
