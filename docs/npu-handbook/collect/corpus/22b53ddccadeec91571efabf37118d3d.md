# 【机关风采】土红莉：扎根档案一线 守史赋能践初心-机关党委

土红莉同志23年扎根档案一线，恪守“为党管档、为校守史、为师生服务”初心使命，严守档案工作保密红线，以敬畏之心守护学校历史，以严谨作风服务师生员工，在平凡岗位上发挥档案支撑服务效能，助力学校事业发展。
2026年度机关优秀共产党员
档案馆党支部 土红莉
存史固本，精耕细作夯实学校档案根基
聚焦档案规范化建设，牵头制修订制度6项，将档案工作纳入科研、基建、资产管理工作流程，实现闭环管理，并以“职能”为导向，制定61家单位一对一归档范围，打破原来按照档案类别制定的笼统范围，用制度保障“应归尽归”。聚焦学校中心工作，高质量完成中央巡视、主题教育、乡村振兴等12项重要工作档案归档，累计3939件，为巡视巡察、绩效评价、内控建设提供材料支撑。开展以人为主线档案征集工作，在校友资料征集基础上，创新开展国奖获得者材料征集活动，年征集档案资料1600余件，系统记录、永久留存学校人才培养的鲜活实践成果。作为保密要害部位负责人，制定保密制度2项、规范流程5项，年均组织开展检查10余次，并负责涉密档案管理，每年深入机要室开展文件鉴定4000余件，无论节假日都能第一时间提供各种利用服务。
资政赋能，提质增效支撑各部门业务
全力推进档案数字化升级，制定《馆藏数字化方案》，建立数字化加工项目全流程管理模式，形成9项管控表单，“十四五”期间完成1024.46万页馆藏档案数字化加工，将馆藏档案数字化率从10%提升至85%，实现档案资源电子化存储、利用，大幅提升工作效率。充分发挥档案资政辅治作用，为中央巡视、人才培养、实验室评估、各类项目验收等关键工作提供档案保障，2023年以来，牵头完成工信部、科工局条保项目、固投项目档案专项验收11项，助力学校重大项目顺利推进。
育人服务，创新方式用心满足师生需求
深耕档案思政育人，策划拍摄《档案如光、照亮三航之路》微电影，荣获国家档案局微视频征集二类作品，为全国高校唯一获奖单位，在学习强国展播；以哈分校建设为背景，牵头拍摄《丝路竹简，从阿拉木图到西安的青春印记》微纪录片，生动呈现学校服务对外开放、培养丝路人才的教育贡献；创新开展档案劳动实践活动，将校史教育、劳动实践与思政育人有机融合。同时，把“我为群众办实事”落到实处，切实提升师生满意度。梳理26项服务事项，优化流程，推行不见面办公、一次办结，非涉密档案利用线上申请办理率100%；建立归档问题反馈单制度，推动归档业务提质增效；录制档案服务面对面业务视频14项，提供直观、易懂、实用的业务指导。
