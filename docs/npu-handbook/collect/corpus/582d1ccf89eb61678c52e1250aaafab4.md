# 筑牢保密防线 提升履职能力——计划财务部举办2025年度财务专题培训班第九期培训

为进一步提升财务队伍专业化水平与综合履职能力，根据财务年度重点工作安排，11月12日下午，计划财务部组织开展综合素质能力提升专题培训，特邀保密处综合管理科于竹君和党政办公室政策研究室陈从军分别作保密工作及公文写作的专题培训。计划财务部全体人员参加了培训，培训由张鹏副部长主持。
于竹君以“筑牢保密防线 护航事业高质量发展”为题，围绕当前保密工作面临的严峻形势、涉密信息管理要求、保密法律法规等进行深入讲解，通过结合学校实际案例和财务工作，引导大家深刻认识到保密工作的极端重要性，牢固树立“保密无小事”的责任意识，增强大家在日常工作中自觉维护信息安全的意识和能力。
陈从军围绕“公文审核与公文写作”系统梳理了常用公文文种的格式规范、行文规则与语言特点，结合具体文种实例，解析公文写作中常见的误区与改进方法，强调了公文严谨性、准确性对保障政令畅通、提升管理效能的重要性，着力提升财务人员的逻辑思维、文字表达与规范化办公能力。
张鹏总结强调，保密工作和公文规范是财务管理工作的重要基石，关系到学校事业发展和治理效能。要将保密纪律和规范写作内化于心、外化于行，常态化加强履职能力提升和业务知识更新；将培训所学运用于业务工作，提升文稿质量和工作效率，立足本职，追求卓越。
此次培训内容充实、针对性强。大家纷纷表示，通过此次培训，进一步筑牢了保密思想防线，掌握了公文写作的要领，今后将把学习成果切实转化为推动工作的强大动力，不断提升自身综合素质。
此次专题培训，是计划财务部加强内部建设、提升队伍履职能力的重要举措，也体现了部门主动适应新形势、新要求，从严从实抓好管理的决心。未来，将继续秉持精益求精的态度，持续加强队伍建设与业务培训，不断提升管理服务水平，以更高标准、更严要求、更实举措，为实现学校“一十百千”发展目标和高质量发展提供坚实有力的财务保障。
