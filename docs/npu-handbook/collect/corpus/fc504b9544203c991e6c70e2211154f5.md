# 西北工业大学网络空间安全学院开题答辩（滕敏）

西北工业大学网络空间安全学院开题答辩（滕敏）
一、开题答辩题目：动态多维网络结构挖掘及其应用研究
二、开题答辩人：滕敏
三、开题答辩时间：2025年1月20日上午9：00
四、开题答辩地点：友谊校区毅字楼6楼606会议室
五、开题内容简介：随着大数据技术的快速发展，现实世界中的连接关系逐渐呈现出动态性和多维性。因此，如何精准捕捉复杂网络在不同时间尺度和多维度下的变化特征，实现动态多层网络社团结构的精准挖掘，已成为亟待解决的关键问题。基于上述分析，本研究聚焦于动态多层网络社团结构与关键节点精准挖掘，结合复杂网络分析与机器学习技术，旨在将动态多维网络结构的挖掘及其应用研究扩展到交通、无人机、脑神经科学等多种应用领域。
六、开题答辩人简介
滕敏，女，学号2023100435，网络空间安全专业，导师王震教授，主要从事于网络图结构挖掘研究。
