# 中心科研团队在形状记忆合金领域取得重要进展

NiTi形状记忆合金是一种在适当加热或卸载后能够恢复原始形状的功能材料，最典型的特征包括形状记忆效应和超弹性，这主要源于合金内部的热弹性马氏体相变。优异的功能特性使得NiTi形状记忆合金在航空航天工程、微电子学、机械制造和生物医学等领域具有广泛的应用前景。
在实际循环变形过程中，NiTi形状记忆合金器件常常会发生功能疲劳现象，表现为残余应变增大和相变应力降低，如何获得具有高应变恢复能力与高伪弹性稳定性的NiTi形状记忆合金是当前的研究热点问题。
为了提高NiTi形状记忆合金的应变恢复能力与伪弹性稳定性，进而推动先进制造领域与微机电系统向更精密、更可靠、更高端的方向发展，基于前期的研究工作，中心科研团队“新型金属材料与近净成型技术团队”罗皎教授通过伪弹性测试与微纳观组织表征，从原子尺度提出了NiTi形状记忆合金应力诱发马氏体相变的三步切变模型，揭示了引起NiTi形状记忆合金伪弹性不稳定的原因是B19’→B2相变诱导层错的产生。目前，相关研究成果已于近期发表在金属材料领域顶刊Scripta Materialia。
