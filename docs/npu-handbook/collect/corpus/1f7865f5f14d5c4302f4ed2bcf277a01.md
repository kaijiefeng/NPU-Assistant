# 马克思主义基本原理系召开学习《中国共产党思想政治工作条例》集体备课会-西北工业大学

为深入贯彻落实立德树人根本任务，推动思想政治工作与马克思主义基本原理教学深度融合，11月25日，马克思主义基本原理系组织全体教师开展集体备课会，会议围绕“学条例、悟要义、融教学”主题展开。
会议伊始，教学主任杨永强带领全体教师集中学习《中国共产党思想政治工作条例》（以下简称《条例》）。杨老师系统梳理了《条例》的出台背景、核心框架与实践要求，重点分享了“坚持党的领导”“强化思想引领”“聚焦立德树人”等关键内容，并结合马原理学科特质，分析了《条例》与课程教学的契合点。
交流研讨环节，老师们结合教学科研实际分享学习心得。张云龙认为，学习贯彻落实《条例》内容及精神，是我们的本职工作，要有崇高的责任感，要学好吃透。贺苗认为，应立足唯物史观，在“社会基本矛盾”章节教学中融入《条例》对思政工作时代定位的论述，引导学生理解思政工作的历史必然性；杨冰郁认为，要创新教学方法，将《条例》精神转化为案例素材、课堂研讨议题，在“实践与认识”相关内容讲授中强化价值引领；聂阳认为，可依托《条例》要求深化学科研究，打造“思政教学+马原理阐释”特色研究方向；陈千千认为，需结合学生思想实际，在实践教学中落实《条例》“贴近师生”要求，通过社会调研、主题宣讲等形式推动理论入脑入心。
此次专题备课会凝聚了育人共识，明确了《条例》精神与马克思主义基本原理教学融合的具体路径，为进一步推动习近平新时代中国特色社会主义思想“进教材、进课堂、进头脑”提供了实践遵循，助力原理系教学质量提升与思政工作提质增效。
