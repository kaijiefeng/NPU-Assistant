# 数智时代的公共管理学科建设论坛成功举办

9月27日至29日，由西北工业大学主办，公共政策与管理学院承办的“数智时代的公共管理学科建设论坛”在西安顺利召开。来自浙江大学、西安交通大学、哈尔滨工业大学、上海交通大学、武汉大学、中山大学、山东大学、中国科学技术大学、南开大学、重庆大学、华中科技大学、香港科技大学（广州）等知名高校的50余位专家学者受邀参会。
开幕式上，校党委常务副书记吕卫东代表学校向与会嘉宾表示诚挚欢迎，并向长期以来关心、支持我校公共管理学科发展的各界朋友表示衷心的感谢。他指出，人工智能正在深刻重塑公共治理的组织形态、运行机制和价值秩序。近年来，西北工业大学系统推进“人工智能+”行动，在深耕“三航”特色的同时，高度重视数字化、智能化赋能高质量发展，提升智能时代人才培养能力和水平，为公共部门数字化转型提供了鲜活的实践样本与人才支撑。他表示，本次大会搭建了数字治理领域前沿成果交流平台，期待与会专家学者畅所欲言、深入交流，为进一步深化数字治理理论研究、促进智能技术与治理实践深度融合、服务数字中国建设和国家治理现代化开辟新的空间。
第一阶段主旨报告环节由公共政策与管理学院院长刘晨光教授主持。
浙江大学公共管理学院郁建兴教授作题为《数字公共治理的无尽前沿》的报告，分析了智能时代政府从技术使用者、流程优化者向“元治理者”转变的角色定位，并从知识基础、方法论、主体关系与运行逻辑四个方面阐释数字公共治理的新转向。
西安交通大学公共政策与管理学院李树茁教授作题为《老龄社会风险与韧性治理》的报告围绕老龄社会中的健康风险，探讨了脆弱性、风险与韧性之间的动态关系，介绍了老年人健康风险发展轨迹的分析思路。
华中科技大学公共管理学院张毅教授作题为《人机关系的演变及重构》的报告，围绕能力结构、互动结构与价值结构分析人机共生关系的形态特征。
第二阶段主旨报告环节由公共政策与管理学院副院长李娜教授主持。重庆大学公共管理学院汪涛教授、中山大学政治与公共事务管理学院陈娜副教授、西北工业大学公共政策与管理学院孙斐教授分别作题为《公共数据要素分层价值释放机理与模式比较研究》《从行政单元到时空情境：大数据时代公共服务均等化的空间治理逻辑》和《从“能做”到“愿共创”：政府智能聊天机器人何以激发公众价值共创？》的主旨报告，聚焦公共数据价值、公共服务均等化及人机价值共创等问题进行具体阐释。
会议设置“第十三届数字治理工作坊”及“卓越大学公共管理专业联盟第十届高峰论坛”两个分论坛。
“第十三届数字治理工作坊”由中山大学政治与公共事务管理学院、中山大学中国公共管理研究中心、西北工业大学公共政策与管理学院共同主办，以“智能时代公共治理的发展：理论创新、技术应用与制度回应”为主题，邀请了多所知名高校学者，共同探讨数字治理领域的前沿议题。论坛设置“论文报告”、“圆桌论坛”及“数字治理前沿方法讲座”三个环节，分别由西北工业大学公共政策与管理学院朱楠教授、中山大学政治与公共事务管理学院郑跃平副教授，中共浙江省委党校教授、《治理研究》主编严国萍教授及西北工业大学公共政策与管理学院张琳副教授主持。山东大学政治学与公共管理学院黄晴教授在数字治理前沿方法讲座中作题为《制度之中，脑身之间：神经公共管理的探索与实践》的报告。8位入选论文作者分别进行论文报告，点评专家与汇报人充分讨论，并经投票评选推选出三篇优秀论文。
“卓越大学公共管理专业联盟第十届高峰论坛”由公共政策与管理学院副院长李娜教授主持。会上，同济大学经济与管理学院党委书记施骞教授、重庆大学公共管理学院院长汪涛教授及李娜教授分别作主题报告。各联盟成员单位围绕MPA研究生招生与培养、论文质量、实践成果作为毕业设计的探索等方面进行了深入交流，并确定了第十一届联盟论坛的主办单位。
9月29日下午，与会人员前往西安市长安区综治中心调研参观。
本次会议得到西北工业大学人力资源部“文科学院人才队伍建设专项实施计划”、发展规划处“学科论坛”的大力支持。
