# 支部联建聚合力 劳动实践促育人--后勤集团交流服务中心与机电学院学生党支部开展劳动实践主题党日联建活动-后勤集团

为深入践行“三全育人”理念，推动党建与育人工作深度融合，6月15日上午，后勤集团交流服务中心第一党支部联合机电学院智能制造第一、第二学生党支部，在南山苑宾馆开展“支部联建聚合力，劳动实践促育人”主题党日活动，以劳动实践为纽带深化支部交流，传承中华优秀传统文化。
活动现场，主持人介绍了到场嘉宾、参与支部及活动整体安排。机电学院党委副书记高俊作致辞，他对支部联建协同育人模式给予充分肯定，勉励青年学生在劳动实践中砥砺品格、锤炼本领、增长才干。
在实践互动环节，宾馆专业厨师现场示范包粽子手法，细致讲解粽叶折叠、馅料装填、棉线捆扎等技巧，并手把手指导同学们动手操作。随后，大家一同体验端午香包制作，在穿针引线间感受传统民俗魅力，传递美好祝福。现场氛围轻松热烈，同学们踊跃参与，在亲身体验中感悟劳动价值，领略传统节日文化内涵。
活动最后，大家共同品尝亲手制作的粽子，分享劳动喜悦，体会团队协作的乐趣。后勤集团副总经理王慧兵表示，此次联建活动创新了育人形式、丰富了实践载体，希望以此为契机，持续拓展劳动实践平台，推动服务育人工作落地见效。
此次主题党日活动，将支部共建、劳动实践与传统文化传承有机结合，有效拉近了师生距离，实现了党建引领、服务育人与文化浸润的深度融合。下一步，后勤集团将持续探索“支部联建+服务育人”工作新模式，不断丰富活动载体，促进党建与育人工作同频共振、双向赋能。（文/图：交流服务中心 审稿人：王慧兵、邱若娟）
