# 雷锋月传书香 志愿行暖研途｜学院研学中心邀您捐闲置书籍，让书香漂流！

春风沐三月，雷锋精神暖人心；书香润研途，志愿分享传温情。
恰逢全国第63个学雷锋纪念日、第27个中国青年志愿者服务日，学院学雷锋志愿服务月系列活动温情启幕。为丰富学院新建研学中心藏书资源，打造有温度、有底蕴的学术阅读空间，让闲置书籍焕发新价值，我们特发起研学中心图书漂流志愿活动，现面向全院同学公开征集闲置书籍，以志愿之举传书香之暖，让知识在分享中漂流，让雷锋精神在互助中传承！期待你的一份分享，让研学中心的书香更浓，让同窗相伴的研途更暖！
征集书籍类型
内容积极向上即可，重点贴合学习科研与日常阅读需求，欢迎各类优质书籍：
✅专业学术类：三航领域、工程技术、专业教材、学术专著、行业前沿译著/期刊等
✅工具方法类：科研写作、文献检索、数据分析、软件操作、职业规划等实用书籍
✅人文素养类：经典文学、人物传记、历史哲学、心理成长、科普读物等
✅休闲拓展类：优质散文、社科新知、经典合集、优质期刊合订本等
征集对象
国家卓越工程师学院全院同学
征集时间
即日起至2026年3月20日
捐赠地点
学院新建研学中心【图书漂流角】专属捐赠书架（毅字楼441）
志愿漂流专属印记
1.定制捐赠印章留名：所有捐赠书籍的同学，可现场为书籍加盖定制捐赠纪念章，印章标注「XX级XX捐赠」，让你的善意与姓名，随书籍永久留存、持续漂流；
2.永久馆藏漂流：捐赠书籍将纳入研学中心图书漂流角永久馆藏，作为专属志愿成果，供全院同学免费借阅，让知识在分享中延续价值，让志愿精神在校园中传递。
志愿寄语
研途有书，不负韶华；漂流传暖，同心同行。
一本书的漂流，是一次知识的传递，更是一次志愿精神的践行。此次图书漂流，让我们以书为媒，以志愿为纽带，将雷锋精神融入日常，用点滴分享为研学中心添彩，让闲置书籍成为研途相伴的良师益友，让互助分享成为学院最美的志愿风景。
期待每一位同学的暖心参与，让书香飘满研学中心，让志愿精神在三月绽放！
