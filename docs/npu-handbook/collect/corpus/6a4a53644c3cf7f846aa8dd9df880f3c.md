# 关于开展教职工八段锦健身培训的通知-校工会（帮扶办）/ 妇女联合会

全体教职工：
为更好地推动全民健身活动持续开展，进一步提高教职工身体素质，针对教职工长期伏案等引发的系列亚健康问题，由校工会牵头，联合党委教师工作部、体育部、离退休工作处开展2026年西北工业大学教职工健康同行行动，将于近期举办八段锦科学健身培训活动。现将有关事项通知如下：
一、活动目的
推广传统养生功法，改善颈肩腰腿痛等健康问题，帮助教职工掌握科学运动方法，营造全民健身氛围。
二、活动安排
时间：9月7日- 9月15日（每周一、二）19:00-20:00
地点：友谊校区大操场
主讲人：杨默衍（体育部讲师）
三、培训内容
精选国家体育总局推广版八段锦：
第一式：双手托天理三焦（改善肩颈）
第二式：左右开弓似射雕（强化心肺）
第三式：调理脾胃须单举（促进消化）
第四式：五劳七伤往后瞧（缓解腰背）
第五式：摇头摆尾去心火（调节神经）
第六式：两手攀足固肾腰（疏通肾经）
第七式：攒拳怒目增气力（增强肌肉）
第八式：背后七颠百病消（调节气血）
四、参与对象
全校教职工、家属、学生、社区居民均可参与
五、注意事
请穿着宽松运动服及防滑运动鞋
六、其他
此次培训活动免费，无需报名。如遇雨天、节假日等特殊情况，该活动暂停。
校工会党委教师工作部体育部离退休工作处
2026年9月2日
