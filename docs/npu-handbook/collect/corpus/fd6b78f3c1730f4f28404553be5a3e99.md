# 青海理工学院赴民航学院调研交流

12月5日上午，青海理工学院工学院院长严军一行三人莅临我院开展调研交流。学院在毅字楼205会议室组织召开座谈会，党委书记闫伟、副院长张晓化出席会议。会议由张晓化主持。
闫伟首先代表学院对严军院长一行的到来表示热烈欢迎，并围绕“127”目标，从师资队伍建设、人才培养等方面宏观上介绍了学院基本情况。严军就工学院的专业建设、学生规模、师资力量及实验室建设等办学运行情况作了详细介绍。张晓化阐述了学院的历史沿革、专业建设进展以及低空专业申报相关经验。
最后，双方围绕师资培养、低空应用场景开发、课程设置等方面进行了深入交流和研讨。此次交流对促进两校合作与发展具有重要意义。
