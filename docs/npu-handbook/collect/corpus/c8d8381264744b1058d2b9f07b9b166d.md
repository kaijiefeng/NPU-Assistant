# 【学术报告】研究生出国（境）交流项目系列报告——马霞：在新加坡国立大学探索宽带吸透一体频率选择表面的设计

报告时间：2025年12月16日（周二）上午9:30
报告地点：长安校区电子信息学院343办公室
报告人简介：
马霞，电子信息学院2022级博士研究生，师从郭陈江教授，主要从事宽带吸透一体频率选择表面及角度选择表面设计研究，已发表学术论文3篇。
项目概况及报告内容：
受国家建设高水平大学公派研究生项目资助，马霞同学于2024年10月至2025年11月期间，赴新加坡国立大学电气与计算机工程系进行了为期13个月的学习与研究，外方导师为新加坡工程院院士、IEEE Fellow陈志宁教授。研究期间，在陈志宁教授的指导下，围绕“宽带吸透一体频率选择表面及角度选择表面”课题开展了系统深入的电磁建模与优化工作，该生积极参与课题组学术讨论与国际交流。本次报告将介绍该生在新加坡国立大学学习期间的科研进展与收获，重点围绕“宽带吸透一体频率选择表面及角度选择表面”的研究成果展开，主要内容包括：
1.电磁机理分析与等效电路建模；
2.基于仿真工具的结构优化与性能验证；
3.相关学术论文成果与国际会议交流体会。
电子信息学院 研究生院
2025年12月5日
