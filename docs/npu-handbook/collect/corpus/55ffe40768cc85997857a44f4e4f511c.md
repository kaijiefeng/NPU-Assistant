# 国际合作处召开2027年学生出国（境）工作推进会

10月28日，国际合作处召开2027年学生出国（境）工作推进会，通报年度工作进展，部署下一年度重点任务。各学院代表及国际合作处相关负责科室人员参加会议，会议由国际合作处副处长陈俊主持。
会上，国际合作处通报了2026年国家公派和学校公派项目申报及学生派出情况，并对2027年各类学生出国（境）项目进行了政策解读和工作安排。会议介绍了国际化领军人才培养项目重点派出人员类别和资助标准，梳理了不同培养层次学生的申报流程，要求各学院加强政策宣讲，拓展国际合作资源。会议指出，国家公派项目要在总结2026年成效的基础上，保持现有派出规模，积极申报创新型人才国际合作培养项目。“翱翔四海”短期项目2026年派出任务圆满完成，广受学生好评。会议同时介绍了2027年项目执行的总体安排，并提醒各学院继续做好出国（境）审批、行前教育、经费报销等工作，保障项目有序开展。
此次会议明确了学校2027年学生出国（境）工作的重点任务和实施要求。下一步，国际合作处将加强与各学院的沟通对接，做好项目通知、政策解答和申报指导，协同推进学生选拔、派出及后续管理，确保各项工作落到实处。
