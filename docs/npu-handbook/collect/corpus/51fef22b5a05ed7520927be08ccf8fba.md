# 后勤办公室召开人才培养目标专题研讨会

根据学校总体部署，6月14日，后勤办公室在后勤产业集团大楼二楼会议室围绕学校人才培养大讨论（二）人才培养目标召开了专题研讨会。后勤办公室副主任朱建军、张卫红、郝东兴以及全体管理人员参加。会议由后勤办公室副主任朱建军主持。
在专题研讨会上，朱建军传达了学校有关文件精神，组织全体干部职工集中学习了学校关于《明晰人才培养目标 统筹推进大类培养》工作报告。与会同志结合工作实际，重点围绕工作报告提出新时期人才培养目标要求，开展了专题研讨。通过学习研讨，大家一致认为：学校关于《明晰人才培养目标 统筹推进大类培养》工作报告。在分析借鉴国内外世界一流大学人才培养目标定位模式的基础上，论述了学校人才培养目标定位内涵和历史沿革，提出了学校新时期“三位一体”人才培养目标体系和大类培养具体举措。工作报告主题思想明确，内容完整，定位准确。
联系学校后勤工作:一是要以学校人才培养目标为根本任务，进一步树立“大后勤”管理理念，积极稳妥推进学校后勤综合改革，建立起适应学校人才培养目标和发展的一流后勤管理服务体系，进一步优化后勤服务运行机制，激发后勤运行实体活力，为学校教学、科研和师生员工工作、学习和生活提供好服务保障。二是贯彻落实全国教育大会、全国高校思想政治工作大会精神，突出“服务育人”的教育和育人功能，搭建服务育人平台，提供劳动岗位，培养学生德智体美劳全面发展的国防人才。三是要建立起与学校人才培养目标相适应的服务质量标准体系及服务工作规范，提高后勤服务工作规范化、精细化水平。四是进一步加强校园基础设施维修工程管理，改善校园基础设施环境，为学校“双一流”建设和人才培养提供好校园环境条件保障。（撰稿：王朝阳，审稿：朱建军）
