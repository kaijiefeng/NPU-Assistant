# 教务部召开传达、贯彻2026年寒假务虚会和春季新学期中层干部会精神暨2026年本科教学重点工作部署会

为深入学习领会学校2026年寒假务虚会、春季新学期中层干部会精神，持续推进“总师育人文化”走深走实，高质量、高水平、高标准做好2026年本科教学工作，3月5日下午，教务部在诚字楼218室召开专题会议。副校长王伶，名师、本科教学督导代表，各教学单位本科教学负责人及教务部相关人员参加了会议。会议由招生办公室主任兼教务部副部长王克勤主持。
教务部部长王海鹏传达了寒假务虚会、春季新学期中层干部会精神，并以《总师育人文化引领 人工智能全面赋能 本科人才培养“十五五”开局重点任务举措》为题作主旨报告。他表示，2026年，学校将深入推进“千人千校优秀生源萃取计划”，以生源质量的持续领跑夯实人才根基；深入挖掘“1→0”重大工程基础问题研究，以“高峰领航计划”引导学生早进实验室、早进课题组；深入构建“人工智能+”高质量课程体系，以一流资源推动人工智能赋能人才培养模式全面升级。
教务部副部长张学良、孙中奎、孟中杰分别汇报了本科生毕业及深造、培养方案修订及教材建设、课程建设等相关工作。
最后，王伶在总结发言中指出，2026年，是“十五五”开局之年，是狠抓“一十百千”发展目标落实的关键一年。各教学单位要聚焦立德树人根本任务，把正确的政绩观转化为推动“总师育人文化”走深走实的思想自觉和行动自觉。要落实“习惯过紧日子”的要求，严控铺张浪费，共同推动开源节流。他强调，2026年，各教学单位要保持“时时放心不下，事事心中有底”的工作状态，继续推进“总师型”人才培养，一是要持续开展深挖到“0”的课程体系全链条设计，各学院要充分发挥主体作用，推动全部专业，至少是工科类专业，完成从“1”到“0”的课程体系重构。二是要推进国家教学成果奖的组织申报，做好统筹，讲好成果故事，强化教学成果的示范引领作用，带动学校人才培养工作整体上台阶出水平。三是要持续提升招生深造竞争力，提升招生质量，优化专业配置，强化宣传队伍，加大本研贯通培养，拓展深造渠道。
学校将紧扣“一十百千”发展目标，坚持以“总师育人文化”为引领，更加注重对同学们的“红透专深”底蕴培塑、“系统整机”观念培养、“动手实践”能力提升。本科教学战线将对照提高“总师型”人才自主培养能力的重点任务，把正确政绩观转化为“十五五”教学一线的生动实践，为“天下工大、世界三航”远景目标贡献教务力量。
