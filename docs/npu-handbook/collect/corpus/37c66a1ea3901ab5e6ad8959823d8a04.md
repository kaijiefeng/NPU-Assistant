# 计算机学院部署2027年河南招生宣传工作

11月10日下午，计算机学院召开河南招生宣传总结暨工作部署会。学院副院长郭斌主持会议，各支部书记（片区负责人）及招生宣传组负责人参加会议。

会上，郭斌解读了2027年河南招生宣传工作总体思路、目标任务和重点方向；姚烨分析了2026年河南生源质量基本情况；秦晓红、张静两位副组长和各片区负责人总结了上一年度招生宣传工作，并就2027年工作计划提出建议。郭斌在总结时对片区负责人的辛勤付出表示感谢，要求扎实做好新年度招生宣传工作。
