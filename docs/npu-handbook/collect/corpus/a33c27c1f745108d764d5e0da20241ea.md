# 关于举办“第七届西北工业大学研究生智慧城市技术与创意设计大赛”暨“第九届中国研究生智慧城市技术与创意设计大赛”校内选拔赛的通知-西北工业大学研究生院

各培养单位及各位同学：
中国研究生智慧城市技术与创意设计大赛（以下简称“大赛”）是“中国研究生创新实践系列大赛”的主题赛事之一，也是我校研究生院认定并组织开展的重点赛事。大赛由教育部学位管理与研究生教育司指导，中国学位与研究生教育学会、中国科协青少年科技中心主办，中关村智慧城市产业技术创新战略联盟联合主办。为了推动创新实践教育深入开展，并为我校选拔优秀作品参赛，现决定举办“第七届西北工业大学研究生智慧城市技术与创意设计大赛”暨“第九届中国研究生智慧城市技术与创意设计大赛”校内选拔赛。现将有关事项通知如下：
一、参赛对象
凡正式注册的在读研究生以及已确定攻读研究生资格的本科生均可参赛。
每道赛题每人仅能参与一支团队（1-4人），可同时选择多道赛题进行研究，支持跨院校、跨专业、跨单位自由组队。组队参赛时作品第一作者（队长）所在培养单位为该队伍的参赛单位。
二、赛制与作品内容
竞赛具体要求详见大赛官网https://cpipc.acge.org.cn/cw/hp/1，赛制与作品内容、参赛作品模版见附件1-4。
三、校内选拔赛事宜
校内选拔赛由研究生院主办，自动化学院承办。竞赛组委会专门在自动化学院教学实验中心成立智慧城市创新实践基地，提供场地、设备仪器、人员、经费等方面的支持，邀请资深专家对参赛队伍进行专业培训和指导。竞赛组委会将聘请校内外专家组成评审委员会对作品进行评选，并推选优秀的团队及其作品代表我校参加在杭州举办的全国决赛。
1.宣讲培训会时间：6月下旬（具体时间地点另行通知，请务必加入QQ群）
2.报名对接会时间：7月下旬
3.校内选拔赛时间：9月上旬
