# 关于暑假期间防范电信网络诈骗的安全提醒

全体师生员工：
暑假将至，电信网络诈骗案件进入易发期，为切实维护广大师生财产安全和合法权益，党委保卫部结合本校实际，就暑期防范电信网络诈骗事项提示如下：
一、高度关注高发诈骗类型
（一）刷单返利类。不法分子以“零门槛、高回报”为诱饵，通过前期小额返利建立信任，后以“连续任务”“账户冻结”为由，诱导受害人持续投入资金，最终无法提现。
（二）虚假招聘与实习类。利用学生暑期求职需求，发布“高薪兼职”“内推实习”等虚假信息，以押金、培训费、服装费等名义收取费用，收款后失联；或诱导办理“培训贷”，造成债务风险。
（三）网络游戏交易类。在游戏平台、社交群组中发布“高价收购账号”“低价出售装备”“免费领取皮肤”等信息，引导脱离官方交易平台，通过钓鱼链接或虚假支付页面实施诈骗。
（四）冒充类诈骗。包括冒充电商物流客服以“退款理赔”“取消会员”为由，或盗用社交账号冒充亲友、老师以“突发急事”为由，要求转账汇款；部分案件还诱导受害人开启屏幕共享功能，窃取银行账户信息。
（五）虚假购物与服务类。在二手交易平台或社交渠道发布演唱会门票、电子产品等虚假售卖信息，要求私下转账，收款后失联或以“卡单”“系统故障”为由重复索款。
（六）涉“两卡”及账号租借类。以“租号赚钱”为名，诱导学生出租、出借本人银行卡、手机卡、微信或QQ账号。此类行为不仅导致个人信用受损，更可能被用于电信网络犯罪，出租出借人将依法承担相应法律责任。
二、严格落实个人防护措施
（一）拒绝任何形式的垫资要求。凡要求先行支付资金或完成刷单、点赞等任务后方可获利的，均属诈骗行为。
（二）坚持官方平台交易。网络购物、票务、游戏交易等，务必通过具备合法资质的官方渠道完成，严禁绕开平台进行私下转账。
（三）严格核实身份信息。接到自称客服、熟人、老师等要求转账的电话或信息，须通过原有联系方式或当面方式进行二次确认，切勿仅凭对方指令操作。
（四）谨慎对待陌生链接与二维码。不点击来源不明的网页链接，不扫描非正规渠道提供的二维码，不下载非应用商店上架的应用程序。
（五）禁止开启屏幕共享。切勿应陌生人要求开启手机或电脑的屏幕共享功能，防止个人隐私及账户信息外泄。
（六）严禁出租出借个人账户。本人身份证、银行卡、手机卡、网络社交账号，仅限本人使用，不得以任何形式提供给他人。
全体师生应主动安装“国家反诈中心”APP并启用预警功能，增强技术防护能力。
祝大家度过一个安全、充实的假期。
党委保卫部
