# 西北工业大学公共政策与管理学院2026年暑期校园开放日暨研究生招生宣传日活动方案

一、学院概况
公共政策与管理学院具有较长的办学历史，其渊源可追溯至1983年设立的社会科学部，1985年改为社会科学系。2003年，在原社会科学系、外语系基础上组建人文与经法学院。2021年，人文与经法学院更名为公共政策与管理学院。学院现有专任教师61人，其中教授18人、副教授39人、助理教授（讲师）4人，博士生导师17人、硕士生导师50人。学院现设公共管理学系、经济学系、法学系和MPA教育中心（挂靠），设有国际经济与贸易、法学、行政管理三个本科专业，有公共管理学一级学科博（硕）士学位授予权和应用经济学、法学一级学科硕士学位授予权，建有公共管理硕士（MPA）专业学位授权点。学院先后获批成立了教育部“985工程”哲学社会科学创新基地、中国科协“科普中国”共建基地等国家级平台，获批成立三航发展战略与政策研究中心、碳达峰碳中和技术与政策研究中心、全球治理国际研究中心、国家治理协同创新研究中心等校级研究中心，为学生培养提供了多样化的教学科研平台。
二、时间安排与人数规模
1.报名时间：2026年6月25日16:00——7月6日23:00
2.活动时间：2026年7月10日——7月12日
3.预计人数：90人
4.参加专业：公共管理学、法学、应用经济学、教育学、文物
三、学生申请条件
1. 主要面向综合表现优异的2027届本科生。
2. 遵纪守法，品行优良，无任何违法违纪受处分记录。
3. 身心健康，学风端正，具有较强的科研创新能力和学术实践能力，具有继续深造攻读研究生的愿望与潜质，对所报专业有浓厚的兴趣。
4. 一流大学建设高校或一流学科建设高校应届本科生，本科三年平均学分积成绩位于所在专业的前30%，英语6级≥450分，或具有相当的其它英语考试成绩（如托福≥70分、雅思≥6.0分等）（2027届本科毕业生）。
四、申请与审核流程
1.网上报名：申请人登录西北工业大学研究生招生信息网（http://yzb.nwpu.edu.cn/）填写报名信息并按照要求上传附件材料。
2.申请人须提供以下材料：
（1）《西北工业大学2026年暑期校园开放日申请表》（提交报名后系统生成）
（2）个人简历（按A4排版不超过一页，应涵盖下述4-6内容简况）
（3）本科前五学期成绩单、综合测评成绩单（加盖学校或院系教务部门公章）
（4）英语水平证明
（5）本科在校期间获奖证书或其它考试证书 (含校级及校级以上)
（6）本科在校期间发表论文、参与科研等研究成果情况证明材料
（7）身份证（正反）和学生证首页、个人信息页和注册页扫描件
申请人将以上材料按顺序整合为一个PDF文件，上传至报名系统，文件命名为“报名编号-考生姓名-报考专业”，材料力求精简，突出重点，总页数最多不超过6页。
2.学院审核：
材料审核工作于2026年7月8日9:00前完成，请申请者在报名系统中查询审核结果，并点击确认是否参加。（不再电话通知，审核通过参加暑期校园开放日的学生以“申请专业+实名”入群，QQ群号：158499119）
3.学生确认：
请申请者在学院规定的时间内（7月8日午15:00前）及时确认是否参加。
