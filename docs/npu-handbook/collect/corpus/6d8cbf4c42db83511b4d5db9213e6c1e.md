# 七秩院史话沧桑，银发丹心启新航——航海学院党委原书记王育才教授讲授《漫话院史》课程

5月18日，由西北工业大学关工委主办，航海学院党委、航海学院团委、航海学院关工委主办，学生会、研会承办的“关心下一代银发宣讲”课程在长安校区教学西楼D205顺利举行。西北工业大学航海学院党委原书记王育才教授受邀主讲，为师生们生动讲述航海学院近七十载的峥嵘岁月与辉煌成就。
以史为鉴知兴替，继往开来谱新篇。读懂院史，方能明晰肩头使命。此次宣讲中，王育才教授从学院的起源讲起，回顾了学院服务国家战略的奋进历程。多年来，学院精心打造优势学科，建设了多个国家级教学平台，以雄厚的教学实力为学子们搭建起成长成才的广阔舞台。无数优秀人才从这里走出，在各自领域发光发热，成为了行业栋梁与时代先锋。他特别提到，学院首创的“全国海洋航行器设计与制作大赛”已发展成为国内高校科创品牌，不断激励着青年学子勇攀科技高峰。
长风破浪会有时，直挂云帆济沧海。课程尾声，王育才教授以“传承与创新”寄语青年学子，学院发展的每一步都镌刻着服务国家的初心，希望大家坚持发扬“敢为人先、攻坚克难、团结协作、无私奉献”的航海精神，在海洋强国战略中书写新的篇章。同学们深受鼓舞，纷纷表示将接续奋斗，要为祖国海洋事业贡献青春力量。
本次课程不仅是一场岁月长河回溯，更是一堂浸润心灵的沉浸式思政课堂。以亲身经历为笔，以院史脉络为纸，在亲历者的叙事中勾勒出航海学院“与国家同频、与海洋共振”的精神图谱，让航海精神的深邃内涵与七十年积淀的文化根系深植师生心田，为学院在“双一流”建设新征程中锚定航向，汇聚起向深蓝领域勇毅进发的磅礴动能。
授课专家简介
王育才，西北工业大学航海学院党委原书记，中共党员，长期从事动力系统自动控制、液压技术与控制方面的教学和科研工作，主持完成和主要参加国防科技重点预研、船舶基金及横向国防科研等课题10余项，获部级科技进步奖4项，陕西省高等学校科技进步奖3项。
西北工业大学“银发宣讲团”是由学校关心下一代工作委员会（关工委）牵头组建的特色思政教育团队，以离退休老同志、杰出校友等“五老”（老干部、老战士、老专家、老教师、老模范）为主体，通过讲述党的历史、学校发展历程及个人奋斗故事，引导青年师生传承红色基因、厚植家国情怀。
