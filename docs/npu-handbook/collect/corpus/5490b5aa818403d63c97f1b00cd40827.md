# 启航新程逐智未来——人工智能学院全面推进2026年首轮本科招生工作

2026年是西北工业大学人工智能学院独立开展本科招生的首年，对完善学院人才培养体系、夯实学科建设基础有着重要作用。学院统筹部署招生宣传工作，形成两项核心举措：一是以6月26日校园开放日为核心线下阵地，校、院两级领导到场接待咨询；二是组建多支宣讲队伍赴全国八省份开展线下招生宣传，由院领导牵头、全体骨干教师参与，扎实完成本年度首轮本科招生宣传，广泛吸纳优质生源。
为提前做好招生筹备、扩大学院对外知晓度，学院依托官方公众号开展前期预热。分批次推送各招生专项团队介绍推文，每周推出1至2支团队，介绍团队师资、各省招生服务安排等内容，向考生和家长介绍学院专业、培养相关情况，为后续线下宣讲、校园开放日咨询做好前期宣传铺垫。
一、校园开放日咨询现场热度较高，校院领导现场接待考生咨询
6月26日，学校2026年校园开放日暨高考招生咨询会如期举办。作为首次独立招收本科生的学院，人工智能学院A20展位咨询人数较多，不少考生、家长前来咨询报考相关问题。
学院执行院长白俊强、党委书记毛昭勇、副院长夏勇、副院长陈捷等班子成员全程在岗，针对招生计划、专业培养、师资科研、升学就业等考生关心的问题逐一解答。现场教师结合人工智能行业发展现状与学校三航办学特色，为考生提供针对性报考建议，直观介绍学院办学条件、人才培养体系与学科发展情况。
期间，校领导前往人工智能学院展位视察招生工作，现场了解咨询开展情况，对学院本年度独立招生筹备、线下咨询服务工作提出指导意见。
校内开放日现场实拍：
校领导视察招生咨询会现场
学院领导班子带队骨干教师坐镇高考招生咨询会现场
二、省外线下宣传全面开展，多省招生团队定点对接生源
在校内开放日同步推进、线上预热宣传落地的基础上，学院先期启动八省份线下招生宣传。结合各省生源情况与当地招生政策，学院划分属地宣讲小组，前往各地中学、市级招生会场开展现场宣讲，一对一解读报考政策，介绍学院办学、科研平台、人才培养相关内容；各宣讲组保持线上沟通，同步分享工作信息、交流宣讲经验，保障各地宣传工作有序开展。
2026年，学院面向全国八省份投放本科招生计划，生源布局科学合理、覆盖范围广泛。各省招生指标及师资对接安排如下：陕西省、江苏省各10个，河南省7个，湖南省、湖北省各6个，吉林省5个，安徽省4个，新疆2个。学院派出资深教师团队，专项开展属地招生宣讲咨询工作。

谢辛舟、王典在 湖北省武汉中学、武汉国际会展中心、湖北省武汉华师一附中开展招生宣传
吉博文在江苏省沭阳如东高级中学开展招生宣传
张欣在江苏省徐州新沂一中开展招生宣传
徐晓峰、王伟在吉林省长春市开展招生宣传
陈汉在吉林省松原市实验高级中学、吉林油田高级中学开展招生宣传
赵政桥等在湖南雅礼中学开展招生宣传
三、多渠道宣传形成合力，为首届本科招生打下基础
本次宣传工作采用“公众号团队介绍预热+校内开放日集中咨询+八省份线下巡回宣讲”相结合的模式，也是学院首次独立开展大规模本科招生集中宣传。学院围绕国家人工智能发展需求，依托学校航空、航天、航海特色完善学科建设，学院办学与培养优势得到考生、家长普遍认可。
系列宣传工作围绕考生实际需求开展，线上提前介绍学院与招生团队情况，线下通过实地宣讲、现场一对一咨询直观展示学院办学情况，有效提升学院社会影响力，为今年首届本科招生夯实生源基础。下一步，学院将持续优化招生咨询服务，依托人工智能特色学科吸纳优质生源，保质完成本年度本科招生任务，为人工智能行业输送专业人才，助力学校“双一流”建设稳步推进。
