# 澳门城市大学王忠教授做客我校翱翔灵犀学术殿堂-西北工业大学

2026年6月4日上午，澳门城市大学人文社会科学学院副院长王忠教授做客西北工业大学马克思主义学院，为学院师生带来一场题为《人工智能时代的文化批判》的学术讲座。本次讲座由马克思主义学院院长助理赵海霞教授主持。
王忠教授长期从事文化哲学、文化产业、非物质文化遗产科技与社会等领域的研究，在相关领域拥有深厚的学术积淀与独到见解。讲座围绕尤尔根·哈贝马斯的学术思想展开，梳理了其学术经历与理论脉络。作为法兰克福学派第二代核心人物，哈贝马斯跳出学派早期对工具理性的批判局限，提出交往行为理论，将现代性视作“尚未完成之工程”，并阐释了“系统对生活世界的殖民”等核心观点。
结合当下人工智能发展现状，王忠教授抛出六大文化论题，深入剖析算法、AI对文化交往、公共领域、语言表达与文化认同带来的冲击。他指出，AI可作为高效工具，却无法成为真正的交往主体；算法逻辑不断加剧系统对生活世界的入侵，让文化学习、人际沟通逐渐异化。
讲座最后，王忠教授总结到，工具领域可依托AI发展，但教育、公共讨论、意义协商等交往领域，仍离不开人与人的真诚对话。在算法盛行的当下，坚守交往理性，才能守护人的自主、尊严与文化活力。整场讲座立意深刻，引发在场师生深度思考。
本次讲座紧扣人工智能时代的文化发展现状，直面技术迭代背后的文化变革与现实问题，为在场师生带来了兼具深度与前沿性的学术启迪，不仅拓宽了大家对智能技术与当代文化关系的认知视野，也引导青年学子树立理性的技术观与人文观。整场活动在浓厚的学术氛围中圆满落幕。
