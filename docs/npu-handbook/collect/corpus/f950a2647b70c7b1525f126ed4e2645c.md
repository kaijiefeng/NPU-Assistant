# 【学术报告】研究生出国（境）交流项目系列报告——王鹏：在新加坡南洋理工大学探索海洋防护涂层

报告时间：2025年11月29日（周六）下午14：00
报告地点：友谊校区东馆A411会议室
报告人简介：
王鹏，材料学院2021级博士研究生，师从刘维民院士和叶谦副教授，主要从事海洋防污涂层的研究，曾获校优秀研究生等多项荣誉，已发表学术论文7篇。
项目概况及报告内容：
受学校研究生短期出国（境）访学项目资助，王鹏同学于2024年12月至2025年12月期间，到新加坡南洋理工大学材料科学与工程学院进行了为期12个月的学习，外方导师为材料科学与工程学院陈忠教授。陈忠教授予1997年获英国雷丁大学博士学位，先后在新加坡材料研究与工程研究所（IMRE）及南洋理工大学从事教学科研工作，在材料表面工程、力学性能等研究领域具有深厚学术影响力，并长期担任多家国际期刊编辑及审稿人。
学习期间，该生在陈忠教授的指导下，围绕材料表面工程与力学性能开展深入研究，重点探索了薄膜-基底界面力学行为，并对机械耐久涂层的设计与性能进行了系统评估。本次报告将介绍该生在新加坡南洋理工大学学习期间的收获和体会，以及在表面工程与薄膜力学性能方面取得的研究进展，主要包括：柔性基底对薄膜分层行为的影响机制、高机械耐久性多功能涂层的设计策略与应用前景评估。
材料学院 研究生院
