# 人事处党支部开展主题党日活动

为进一步加强教职工知识拓展，提高教职工培训实效性，促进党建活动与业务工作相融合。11月23日下午，人事处党支部开展主题党日活动，邀请无人系统技术研究院邵典副教授做大语言模型知识讲座。
邵典以《AI 模型：岂止于大》为题从大语言模型发展沿革、大语言模型技术细节、大模型不止语言、大模型发展基础、大模型岂止于大五个方面，给人事处教职工带来了一堂知识丰富、趣味盎然的“辅导课”。同时她将大语言模型与人事处业务工作相结合，从人员数据分析、活动统筹安排等进行了演示，体现出人工智能在不同领域广泛的应用性。参会人员与邵典老师展开热烈的交流。
此次主题党日活动深化了支部党员对人工智能赋能教育数字化信息化的认识。下一步，人事处将持续完善与优化教职工培训课程体系，以高质量党建引领业务高质量发展。
