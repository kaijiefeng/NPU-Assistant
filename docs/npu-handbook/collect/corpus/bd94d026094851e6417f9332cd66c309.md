# 关于举办西北工业大学第四届大学生工程实践与创新能力大赛的通知

各学院：
中国大学生工程实践与创新能力大赛是列入《教育部评审评估和竞赛清单》的重要赛事，该竞赛每两年举办一届。根据《陕西省教育厅办公室关于举办2027年中国大学生工程实践与创新能力大赛陕西赛区竞赛暨第六届陕西省本科高校教师工程创客教学能力大赛的通知》（陕教高办〔2026〕20号）精神，2027年中国大学生工程实践与创新能力大赛陕西赛区竞赛暂定于2027年4月23日至25日在西北农林科技大学举行。为选拔优秀参赛队伍代表我校参加该项赛事，学校决定举办西北工业大学第四届大学生工程实践与创新能力大赛（以下简称“校赛”），现将有关事项通知如下：
一、赛事主题
交叉融合工程创新求卓越，守德崇劳制造强国勇担当。
二、赛项设置
本届校赛设置4个赛道11个赛项：
1.工程实践赛道，包括太阳能电动车、生物质能电动车2个赛项；
2.“智能+”工程创新赛道，包括智能搬运、智能分拣、智能救援3个赛项；
3.虚拟仿真赛道，包括飞行器设计仿真、智能网联汽车设计、工程场景数字化、企业运营仿真4个赛项；
4.陕西省专项赛道，包括智能无人机、中华传统文化艺术设计与工程制作2个赛项。
三、参赛条件
1.参赛选手：我校正式注册的全日制在校本科生。
2.组队规则：每支参赛队由3-4名学生和1-2名指导教师组成，每人限参加一支队伍。
四、竞赛规则
校赛重点考查学生利用跨学科基本理论知识，解决实际问题的设计、制造与创新能力，强调工程思维、工程创新、工程伦理与团队合作等综合素质，重视挑战性和综合性。
本届校赛各赛道赛项规则与2027年中国大学生工程实践与创新能力大赛陕西赛区竞赛规则保持一致：工程实践赛道见附件1；“智能+”工程创新赛道见附件2；虚拟仿真赛道见附件3；陕西省专项赛道见附件4、附件5。
五、报名与赛程安排
1.竞赛（校赛、省赛、国赛）报名通过全国竞赛组委会指定的信息化系统（网址：http://www.gcxl.edu.cn）完成，点击“竞赛报名”按钮完成参赛注册，并按要求提交报名及相关参赛材料（后续统一组织参赛队在该系统报名）。陕西省专项赛道报名方式见附件4、附件5。
2.校赛报名表将同步上传至校赛官方QQ群文件中，请各参赛队于2026年11月14日24:00前提交至联系邮箱（逾期不再接收）。
3.校赛拟定组织两次。第一次拟于2027年1月15日、16日举办，第二次拟定于2027年3月13日、14日举办，择优推荐我校代表队参加陕西省省赛（视参赛队成绩可缺额推荐），具体赛程安排另行通知。
4.校赛实施安排若有改动，将在校赛QQ群中及时通知，其他未尽事宜也将在校赛QQ群内通知，如有疑问可联系群管理员，请各参赛队务必加入该群。
六、竞赛奖项与省赛推荐
校赛设立一等奖、二等奖、优秀奖等奖项，具体奖项数量根据实际报名队伍参赛情况确定，并在第二次校赛后公示公布（按第一次校赛成绩占比30%，第二次校赛成绩占比70%）。第一次校赛仅为每个赛项筛选出优秀队伍作为种子队伍，加入省赛备战阶段的集训营中培育。
根据省赛通知要求，我校将于2027年3月26日前完成校赛报名与选拔工作。工程实践赛道、“智能+”工程创新赛道每个赛项推荐不超过4支队伍进入省赛；虚拟仿真赛道、陕西省专项赛道每个赛项推荐不超过5支队伍进入省赛。
