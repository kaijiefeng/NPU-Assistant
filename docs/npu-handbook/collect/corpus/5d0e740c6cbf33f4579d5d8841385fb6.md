# 离退休党委第三届健步走活动顺利举办

秋意安然，步履向暖。10月9日，离退休党委“银发生辉展风采 步履铿锵向未来”第三届健步走活动如期举行。近千名离退休党员在各家属区踊跃参与本次活动。
活动当天，党员们早早来到现场集结，个个精神饱满、神采奕奕。在起点集体合影留念后，伴着秋日清风，健步走活动正式拉开帷幕。
健步走活动掠影
大家向阳而行、步履稳健，党员们热议国家发展变化，感悟新时代伟大成就，重温入党初心，追忆奋斗岁月，切身感受党组织的关心关怀，充分展现出离退休党员离岗不离党、退休不褪色的政治本色和积极向上的精神风貌。
本次健步走活动已连续举办三届。党员们纷纷表示，活动鼓励大家走出家门、强健体魄，增进党员沟通交流，进一步增强党组织凝聚力和向心力。下一步，离退休党委将持续创新活动形式，不断提升组织生活质效，引导离退休党员永葆党员本色、发挥银发余热。
