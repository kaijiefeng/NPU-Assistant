# 后勤办公室组织开展师德师风专题学习暨主题教育专题党课活动

为落实学习贯彻习近平新时代中国特色社会主义思想主题教育要求，结合《关于印发<西北工业大学师德集中学习教育实施方案>的通知》精神，7月18日上午，后勤办公室组织全体人员开展师德师风专题学习暨主题教育专题党课活动。后勤办公室主任张文刚主持会议。
会上，张文刚首先向全体人员传达了学校关于师德师风集中学习的文件精神，以及《西北工业大学师德集中学习教育实施方案》中的相关内容。随后，全体人员共同学习了《习近平总书记关于师德师风的重要论述（摘编）》《师德规范及警示案例》等重点内容，并结合个人工作情况，进行了交流研讨。
接着，由郝东兴副主任为全体人员讲授《汲取精神力量，助推工作提升》主题教育专题党课。党课内容围绕党员干部应“深刻理解二十大的主题，准确把握大会的核心精神”、“深刻理解理论创新方法，坚持守正创新的超越精神”、“深刻理解中国式现代化，彰显踔厉奋发的进取精神”、“深刻理解各项重点任务，践行埋头苦干的奋斗精神”展开，要求党员干部应持续在务实调查研究、坚持真抓实干、聚力助推发展上下功夫、出真招，把主题教育作为推动后勤管理工作发展的“助力器、动力源”，以推动工作提升的实际成效奏响主题教育的“最强音”。
专题学习活动结束后，张文刚强调，希望全体人员通过此次学习，进一步重视师德师风的重要性。要求大家利用暑假时间加强自我学习和自我提升，在今后的工作中继续坚持底线思维、严格遵守师德规范；同时牢牢把握主题教育总要求，持续以实际行动深化推进主题教育成果见行、见实、落地、落细。
