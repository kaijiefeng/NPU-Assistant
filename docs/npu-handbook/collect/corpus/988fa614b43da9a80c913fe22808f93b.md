# 学院师生赴成都开展国防军工单位实践调研

为扎实推进实践育人“三个一”，引导拔尖学子了解行业发展前沿，树立科研报国志向，更好推进访企拓岗，10月30日至31日，在本博翱翔总师班班主任张卫红院士空天装备设计制造学科突破先导项目支持下，教育实验学院/未来技术学院2024级本博翱翔总师班全体同学赴成都开展国防军工单位实践调研。同学们先后走进中国航发成都发动机有限公司、成飞航空主题教育基地和国家级创新平台，实地感悟军工力量，厚植报国情怀。学院辅导员玛哈，学工主管王蓉带队参加活动。
10月30日，师生一行前往中国航发成都发动机有限公司。在企业工作人员带领下，参观机匣分厂、叶片分厂，近距离观摩航空发动机零部件展品与自动化生产线，切身感受航空精密制造的硬核实力，深刻体会“严慎细实、精益求精”的军工生产理念。
参访后，企业组织师生与优秀校友座谈交流。校友介绍企业发展概况，并结合自身岗位经历分享成长感悟，勉励同学们立足国家需求，夯实专业根基，树立系统工程思维，勇担新时代航空人的使命担当。
同学们围绕企业人才选拔标准、工程实践能力培养、行业发展前景等问题积极提问交流。
10月31日，师生来到成飞航空主题教育基地。跟随讲解员依次参观威龙广场、云中魅影、航空史迹、铁翼风华等展区，重温航空工业艰苦创业、自主创新的奋斗征程。同学们驻足战机展台前仔细观摩学习，深切感悟大国重器背后一代代航空人矢志坚守、接续奉献的精神力量。
此次实践调研让同学们在实地研学中深化了对“公诚勇毅”校训、“三实一新”校风的理解，坚定投身国家重大战略需求的信念。大家纷纷表示，将勤学精进、锤炼过硬本领，立志为国铸剑，把青春奋斗融入强国强军建设。
