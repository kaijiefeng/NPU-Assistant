# 后勤部办公室传达学习2026年暑假务虚会和秋季学期中层干部会精神

9月1日上午，后勤部办公室召开全体会议，传达学习学校2026年暑假务虚会和秋季学期中层干部会精神。会议由后勤部办公室主任张文刚主持，全体人员参加会议。
会上，大家集中深入学习了张云明书记、宋保维校长在暑假务虚会、秋季学期中层干部会上的讲话。会议指出，书记、校长的讲话站位高远、内涵丰富，科学研判了当前办学发展面临的形势与挑战，清晰擘画了新学期发展蓝图，令人备受鼓舞。与会人员一致表示，将深刻领悟会议精神实质，切实把思想、行动和工作重心统一到学校党委决策部署上来，以饱满的工作热情、务实的工作作风、过硬的履职能力扎实推进新学期各项工作再上新台阶。
会议要求，全体人员要持续深入学习书记校长讲话精神，切实做好新学期后勤管理与服务保障工作。会议提出了三点要求：一是提高政治站位，深学细悟会议精神，强化履职尽责的责任感和使命感；二是对标发展大局，扛牢使命重任，聚力攻坚电力增容、热力扩容等重难点工作；三是聚焦主责主业，紧盯师生急难愁盼问题，办实事、优服务、提质效，以坚实的后勤履职成效为学校高质量发展保驾护航。（撰写人：毛淑兰；审稿人：韩争胜）
