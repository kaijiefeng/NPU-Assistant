# 重庆科创中心党支部开展《第二十条》主题党日观影活动

为深入学习贯彻习近平法治思想，深化重庆科创中心党员的法治观念，增强知法、懂法、用法能力，3月13日晚，重庆科创中心党支部开展主题党日观影活动，组织在渝党员及青年理论学习小组成员集中观看法治题材电影《第二十条》。
影片《第二十条》诠释了《中华人民共和国刑法》第二十条关于“正当防卫”法条背后的精神内核——“法，不能向不法让步”。在观看影片的过程中，同志们聚精会神，感慨万千，放映结束后同志们纷纷表示在今后的工作和生活中，要严守法律底线，弘扬“法不能向不法让步”的法治精神，积极引导家人增强法治观念和法律意识，真正做到尊法、学法、守法、用法，守住公平正义的底线。
