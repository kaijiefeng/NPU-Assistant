# 北研院党支部召开2022年度民主生活会-西北工业大学

按照学校《关于开好2022年度二级单位领导班子民主生活会的通知》（组字〔2022〕38号）要求，3月15日上午，北京研究院党支部以“全面贯彻习近平新时代中国特色社会主义思想，贯彻落实党的二十大作出的重大决策部署”为主题，召开了2022年度民主生活会。
首先，党支部书记方文杰代表领导班子进行了深入对照检查，向大会详细汇报了党的二十大精神学习情况以及2022年专题民主生活会的整改落实情况，并对领导班子接下来的努力方向和工作重点进行了明确。随后，班子成员依次进行了个人发言和互评。
资产公司党委委员杨安庆在点评时表示，北研院党支部领导班子对照检查发言和个人发言深入翔实，前期准备扎实、主题明确、态度认真，希望北研院全体同志能够深入学习党的二十大精神，贯彻落实立德树人根本任务，把思想凝聚到北京研究院的建设和发展上去，做好学校在京的排头兵。
