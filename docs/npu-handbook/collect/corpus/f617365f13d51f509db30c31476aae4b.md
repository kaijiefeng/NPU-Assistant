# 航海学院召开2025年新认定研究生导师岗前谈话会暨研究生导师培训会

按照研究生院的总体工作安排，航海学院于2025年9月18日召开新认定研究生导师岗前谈话会暨研究生导师培训会。航海学院院长潘光、党委书记刘朝亚、副院长曾向阳以及2025年新认定的14位博士生导师、13位硕士生导师参加了会议。会议由曾向阳主持。
会议伊始，刘朝亚就导师在政治素质、师德师风、业务素质等方面提出要求，并领学《新时代高校教师职业行为十项准则》。他要求导师要坚守立德树人根本任务，严格遵守研究生教育的规章制度，不断加强自身能力提升，用自己的一言一行去教育学生、影响学生，帮助他们走好科研之路、成长之路。
接着，曾向阳围绕导师岗位要求、导师基本素质要求、导师立德树人职责、导师权利、导师“十不得”、导师激励与退出机制等内容，传达并解读国家、学校及学院相关政策和管理规定。
随后，潘光作了题为《立德树人，行为世范是导师的第一要务》的培训。潘光从导师责任与使命、导师的个人修养、导师与学生关系以及如何培养学生等方面与新认定研究生导师畅谈。他说，导师是学生品格的塑造着，也是科学精神的示范者。只有具备过硬的政治素质、高尚的师德师风、精湛的业务素质才能影响学生的人生观、价值观、世界观。潘光还强调，导师要不断增强自身学术水平和育人能力，面向国家海洋无人装备重大战略需求，培养情怀深、专业精、系统强、重实践、能担当的领军型人才。
与会新认定研究生导师纷纷表示，将牢记立德树人根本任务，躬身践行教育家精神，引领研究生立强国之志、学强国之能、建强国之功，做中国式现代化的推动者，用自己的智慧和担当，培养出具有创新精神和社会责任感的高层次人才。
会议最后，潘光与新认定研究生导师签署岗位责任书，并向所有新认定研究生导师颁发聘书。
学院全体研究生导师将始终牢记习近平总书记的殷殷嘱托，牢记为党育人、为国育才使命，积极探索新时代教育教学方法，不断提升教书育人本领，为培养更多“总师型”人才作出新的贡献，为学校、学院的“双一流”建设贡献智慧和力量。
通过此次岗前谈话培训会，强化了导师作为研究生培养“第一责任人”的意识，提升了导师队伍的能力水平，为学院高质量研究生教育奠定了基础。
（审核：刘朝亚，王银涛)
