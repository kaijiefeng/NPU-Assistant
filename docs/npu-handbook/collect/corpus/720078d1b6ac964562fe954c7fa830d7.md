# 第二届离退休党委健步走活动顺利举行

10月31日，离退休党委分别在友谊校区、南苑、西苑和长安校区家属苑举办“党员展风采 迈步悦心怀”健步走活动。
正值深秋，虽有丝丝凉意，却挡不住我校离退休教职工党员的饱满热情。以党支部为单位，大家在健步走起点整齐列队、整装待发、笑意盈盈，内心的喜悦定格成现场动人的画面。随着指令发出，老党员们结伴前行，步伐铿锵，彼此交流中重温峥嵘岁月，用昂扬姿态书写着退休不褪色、离岗不离党的责任与担当。
健步走活动既展现了我校离退休教职工党员积极乐观、热爱生活的阳光心态，更凝聚着他们初心不改、薪火相传的信仰力量。老党员们纷纷表示，未来要以更加阳光的心态过好退休生活，积极发挥余热，为学校的发展贡献更多银发力量。
（撰稿：李晓珊；摄影：离退休工作处；审核：马俊）
