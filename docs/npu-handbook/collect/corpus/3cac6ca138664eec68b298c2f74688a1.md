# 校党委书记张云明会见李金山教授等2025年度国家科技奖获奖代表

7月10日，校党委书记张云明会见2025年度国家科技奖获奖代表。重庆科创中心负责人、首席科学家李金山教授参加会见。
张云明代表学校党委向获奖团队表示热烈祝贺，向全体参研人员致以崇高敬意。
张云明指出，党的十八大以来，以习近平同志为核心的党中央把科技创新摆在现代化建设突出位置，系统擘画科技强国建设蓝图，推动科技事业取得历史性成就、发生历史性变革。此次5项成果获奖，包括国家技术发明一等奖1项、自然科学二等奖1项、科技进步二等奖2项，国际科学技术合作奖1项，标志着学校推动实施创新驱动发展战略、服务高水平科技自立自强取得新突破；得益于各团队心怀“国之大者”，坚持服务国家重大战略需求，坚持深耕科技创新发展前沿，坚持发挥团队协同创新优势。
张云明强调，要深入学习贯彻习近平总书记重要讲话精神，切实把思想和行动统一到党中央决策部署上来，把习近平总书记和党中央的关心关怀关爱转换成坚守科技报国初心、传承优良作风、勇攀科技高峰的信心、决心和恒心，加强系统观念，推动教育提质、科技赋能、人才赋能深度耦合，筑牢一体推进教育科技人才发展的压舱石；加强基础研究，深化跨学科、跨领域协同创新，着力产出一批具有战略性、引领性、标志性的重大原创成果，争当国家重大战略科技突破的生力军；加强需求牵引，深入产业需求、社会发展和现实痛点，让科研攻关对准实际应用、服务发展大局，争做科技创新和产业创新融合发展的排头兵，为以中国式现代化全面推进强国建设、民族复兴伟业作出新的更大贡献。
副校长孔杰，各获奖团队代表及相关职能部门负责人参加会见。
