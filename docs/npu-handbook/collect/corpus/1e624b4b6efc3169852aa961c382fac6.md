# 自动化学院召开学术型研究生培养方案修订工作推进会

自动化学院召开学术型研究生培养方案修订工作推进会
为深入贯彻学校研究生培养机制改革要求，进一步提高研究生培养质量，6月21日上午，由自动化学院牵头，联合航天学院、电子信息学院、动力与能源学院等召开学术型研究生培养方案修订工作推进会。学院副院长王小旭、学科带头人、各系主任/副主任、教授代表，以及航天学院教师代表、动能学院教师代表、电子信息学院教师代表等参加了研讨与交流。
针对学院负责的三个学科培养方案修订工作，王小旭从组织管理、人员分工等方面进行了具体部署，并强调要特别重视深入调研、学习与借鉴国内外一流高校培养方案，在广泛调研征求意见并充分论证的基础上，对研究生培养方案进行认真修订和完善。参会老师就研究生培养方案的修订展开深入研讨，特别是在硕士研究生基础理论类（数学类）课程优化及调整方面，各学科教师进行了深入探讨和交流。后续学院将邀请数学与统计学院相关教授作关于数学发展的交流报告，为各学科制定符合自身发展的数学类基础课程打好基础。
