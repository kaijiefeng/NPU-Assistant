# 化学与化工学院2026年暑期实践研学出征仪式暨行前安全教育大会顺利举行

7月2日晚，化学与化工学院2026年暑期实践研学出征仪式暨行前安全教育大会在学院楼报告厅举行。学院党委书记傅茂森、党委副书记姚东东、团委书记张莹予、教育实验学院分享嘉宾易子锋及各实践队代表90余人参加。会议由张莹予主持。
安全先行，筑牢底线
大会伊始，姚东东作动员讲话。他强调，暑期实践研学是落实立德树人、践行校训校风与总师精神的重要载体。他鼓励同学们走出校园、深耕一线，立足化学化工专业优势对接国家战略需求，在产业调研、红色研学、基层服务中坚定报国志向、锤炼实践本领。同时要求全体学生严守规章制度、压实安全责任，规范实践宣传与日常报备工作，以严谨务实的作风高质量完成实践任务，在知行合一中彰显化院学子的青春担当。
院学生会社会实践部部长吉扬介绍了2026年暑期实践总体情况。本年度学院共组建5支实践队，涵盖红色教育、乡村振兴、生态环保、科普宣传等多个领域，其中“千年瑶韵·当世风华”实践队、“第十七届西工大绿色营”实践队、“窑洞星火·青春传灯”科普实践队为“三下乡”定向实践队，另有延安红色实践队和线上集中实践队同步推进。
榜样引领，薪火相传
教育实验学院2024级本科生易子锋分享实践经验。他牵头组建并带领“振兴行”实践团队赴广西、甘肃、贵州等地开展助力乡村振兴实践研学，荣获全国优秀实践队等多项荣誉。易子锋从选题策划、实地调研、成果转化等方面分享了宝贵经验，鼓励同学们在实践中锤炼本领、服务社会。
“千年瑶韵·当世风华”实践队负责人尹太鹏代表本年度出征实践队发言。他表示，全体队员已做好充分准备，将以最饱满的热情投身实践，严格遵守纪律，确保安全顺利完成各项任务。
授旗宣誓，正式出征
傅茂森依次为延安红色实践队、“千年瑶韵·当世风华”实践队、“第十七届西工大绿色营”实践队授旗，各队代表郑重接旗。
随后全体实践队员在吉扬带领下肃立宣誓：“坚持运用专业知识，传播先进文化、展现青年风采……奋力书写为中国式现代化挺膺担当的青春篇章！”以铿锵誓言彰显化院青年学子的担当与风采。
傅茂森作总结讲话。他向为本次实践研学付出辛勤努力的师生表示感谢，并提出三点希望：一要做“知行合一”的践行者。跳出课本公式，扎根基层一线，将实验室的知识转化为服务国防的“真招实策”。二要做“底线第一”的守护者。绷紧安全之弦，守好保密之门，明辨是非、站稳立场，将一言一行置于纪律规矩的“铜墙铁壁”之中。三要做“学校形象”的代言人。擦亮“西工大现象”名片，走向祖国最需要的地方，以化学专长回应时代召唤，用过硬本领书写为国担当。
同时，郑重宣布：“化学与化工学院2026年暑期实践研学队伍，正式出征！”
本次暑期社会实践将按照“安全第一、按需设项”原则，采取线上线下并行方式开展。各实践队将于7月上旬至8月下旬奔赴全国各地，在实践中受教育、长才干、作贡献。学院将持续做好安全保障和跟踪指导，确保实践活动安全有序、取得实效。
