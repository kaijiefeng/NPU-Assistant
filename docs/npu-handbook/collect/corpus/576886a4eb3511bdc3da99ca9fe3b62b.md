# 【学术报告】研究生出国（境）交流项目系列报告——在莫斯科航空学院研究航空电子系统技术

报告时间：2025年12月4日（周四）上午9：00
报告地点：长安校区电子信息学院236会议室
报告人简介：
1.孙孝通，电子信息学院2023级硕士研究生，师从樊晔副教授，主要从事卫星通信和物理层安全的研究。
2.孔赵伟，电子信息学院2023级硕士研究生，师从冯晓毅教授，主要从事面向低慢小目标的航迹关联和融合算法研究。
3.赵浩，电子信息学院2023级硕士研究生，师从符小卫教授，主要从事无人智能决策与量子优化算法相关研究。
4.马珍，电子信息学院2023级硕士研究生，师从李彬副教授，主要从事RIS辅助物理层安全的研究。
5.王思腾，电子信息学院2023级硕士研究生，师从胡晓宇副教授，主要从事多涡卷隐藏吸引子混沌系统的研究。
6.马吉福，电子信息学院2023级研究生，师从张耀中副教授，主要从事多无人系统任务规划研究。
7.余泰铮，电子信息学院2023级硕士研究生，师从唐成凯研究员，主要从事多源导航协同定位算法研究。
8.康永翔，电子信息学院2023级硕士研究生，师从马云红副教授，主要从事人工智能优化算法及多无人机编队控制的研究。
9.卿颖，电子信息学院2023级硕士研究生，师从陈楠副研究员，主要从开关电源控制系统研究。
10.毕杨智欣，电子信息学院2023级硕士研究生，师从齐敏副教授，主要从事缺陷检测算法的研究。
11.闫李林，电子信息学院2023级硕士研究生，师从赵宏伟教授，主要从事卫星通信与可信导航研究。
项目概况及报告内容：
受国家留学基金管理委员会的资助，孙孝通等11名同学于2024年9月至2025年7月期间，到莫斯科航空学院进行了为期10个月的学习，外方导师为莫斯科航空学院EvgenyNeretin等教授。学习期间，学生充分学习了Neretin等教授开设的《航空电子系统》《航空电子软件开发》《传感器技术》等课程，在Neretin等教授与国内导师的指导下进行了“航空电子系统智能优化与安全保障”的研究，将航空电子系统开发规范（DO-178C/ARP 4754A）、传感器精准感知技术与人工智能等技术深度融合，针对航空电子软件复杂性高、系统决策融合不足等问题，采用了基于智能推理的航空电子系统优化方案，整合传感器精准数据采集与DO-178C合规性验证流程，有效解决了航空电子系统开发中验证流程繁琐、多源数据融合决策滞后等问题。本次报告将介绍学生在莫斯科航空学院学习期间的收获和体会，主要包括：航空电子系统开发规范研究、传感器技术的应用优化、项目实践中的经验总结等。
