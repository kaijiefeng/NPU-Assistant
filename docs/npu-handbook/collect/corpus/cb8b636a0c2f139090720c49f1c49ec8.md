# 以跑砺志强体魄，体育育人再扩容——我院27名师生参加2026西北工业大学校园马拉松

10月24日上午，比亚迪·中国青年跑西北工业大学站暨2026西北工业大学校园马拉松在西北工业大学长安校区开赛。本次校园马拉松是我院常态化开展的体育育人实践活动，相较往年今年参与队伍进一步壮大，人工智能学院/无人系统技术研究院共有27名师生报名参赛，学院/研究院党委副书记徐晓峰、辅导员韩凯与同学们一同站上赛道，全程参与比赛。
整装待发，师生同场竞技
开赛前，参赛师生在翱翔体育馆东广场完成集结，身着统一参赛服、佩戴号码布，精神饱满、秩序井然。发令后，27名师生从东广场出发，沿巡航东路、三航大道、图书馆环岛、飞机广场、长安大道等校园道路一路奔跑，最终奔赴终点冲线。
赛前，参赛师生合影留念
坚持到底，展现良好风貌
比赛中，我院参赛师生根据自身情况合理分配体力，全程相互鼓励、彼此照应。赛道沿途，师生们的身影成为秋日校园的一道风景，充分展现出学院/研究院师生良好的身体素质与昂扬向上的精神状态。
赛道上的参赛师生
完赛收官，凝聚奋进力量
冲过终点后，参赛师生在终点区域领取完赛奖牌与完赛补给。27名师生全部顺利完赛，大家手持奖牌合影留念，脸上满是完赛后的喜悦与自豪，为本次校园马拉松之行画上圆满句号。
完赛后合影
此次校园马拉松是学校推进体育育人的一次生动实践。参赛师生在奔跑中强健体魄、锤炼意志，也在集体参与中增进了师生之间、同学之间的交流，进一步增强了学院/研究院的凝聚力与集体归属感。
学院/研究院将继续引导广大师生积极参与体育锻炼，在运动中增强体质、健全人格、锤炼意志；鼓励师生把赛场上坚持不懈、奋勇争先的劲头带入日常学习与科研攻关之中，在人工智能与无人系统领域脚踏实地、久久为功，勇攀科技高峰，努力成长为堪当民族复兴重任的“总师型”人才。
