# 电子信息学院2026年第1期发展对象集中培训顺利开展

5月19日至6月5日，电子信息学院党委举办了2026年第1期发展对象培训班。本次培训紧扣学校发展党员工作要求，系统设置课堂教学、实践研学、研讨交流、个人自学四大模块，并在研讨环节创新引入辩论赛式研讨机制，引导学员在观点交锋中深化认识、在思辨互鉴中提升觉悟，培训取得扎实成效。
铸魂・课堂教学 筑牢思想根基
5月19日，马克思主义学院高旭红教授作《深入学习“十五五”规划纲要》专题授课。课程结合时间轴、历史脉络图及党的二十届四中全会等相关材料，系统解读“十五五”规划纲要的编制过程、历史定位、核心内容与未来五年国家发展战略布局，帮助学员深入学习领会“十五五”规划纲要的重大意义与目标任务。
5月21日，学院党务秘书王心怡开展《党员发展材料规范》专项培训。逐一介绍思想汇报、入党志愿书个人信息部分等材料的撰写要求与注意事项，重点梳理入党材料的填写规范，时间逻辑及常见问题，指导学员规范完善个人入党材料。
5月25日，电子信息学院崔万照教授带来《了不起的中国航天》专题讲座。讲座回顾了中国航天从“东方红一号”划破苍穹到中国空间站全面建成、从嫦娥探月到北斗组网的辉煌历程，生动诠释伟大载人航天精神、新时代北斗精神、探月精神的丰富内涵。崔万照结合自身一线科研经历，分享航天人自主创新、攻坚克难的奋斗故事，激励学员立足电子信息专业优势，积极投身高水平科技自立自强伟大事业。
5月26日，马克思主义学院赵海霞教授讲授《党中央在延安的十三年》专题党课。课程系统回顾党中央在延安时期的奋斗历程，深入阐释延安精神的核心要义与时代价值，号召全体学员从党史中汲取奋进力量，传承红色基因、筑牢理想信念，将革命精神内化于心、外化于行。
5月29日，马克思主义学院胡建发副教授主讲《正确政绩观引领下的高校治理现代化》。课程立足以坚强党性筑牢正确政绩观坚实根基，结合高校发展与青年学生成长实际，剖析树立和践行正确政绩观的现实意义，引导学员在专业学习和学生工作中涵养务实作风、树立长远眼光、锤炼过硬本领。
6月5日，电子信息学院党委书记侯俊以《“实”字当头“干”字为要》为题，讲授树立和践行正确政绩观专题党课。课程围绕习近平总书记关于树立和践行正确政绩观的重要论述展开，紧扣 “政绩为谁而树、树什么样的政绩、靠什么树政绩” 三个核心问题，结合焦裕禄、黄文秀等先进典型事迹，引导学员坚决摒弃形式主义、官僚主义，坚守为人民服务的初心使命，以实干担当践行青年使命。
明理・辩论研讨 淬炼党性认知
5月28日，学院创新开展“以辩促学、以学促行”专题辩论研讨活动。活动设置开篇立论、攻辩交锋、自由辩论、总结陈词等环节，围绕理想信念、青年成长、使命担当等七大核心议题展开激烈辩论。学员们引经据典，在观点碰撞中深化理论认知，在思想交锋中端正入党动机，进一步明确了个人成长与国家发展同频共振的实践方向。
践悟・实地研学 厚植文化自信
5月31日，学院组织学员赴西安博物院开展实践研学。在专业讲解员的带领下，学员们依次参观西安博物院基本陈列展厅、唐荐福寺遗址及小雁塔景区，沿着“古都西安”历史展线，近距离观赏周、秦、汉、唐历代珍贵文物及唐代古塔建筑，聆听文物背后的历史故事。通过沉浸式研学，学员们深刻感悟中华文明的源远流长与博大精深，增强了文化自信与历史使命感，进一步坚定了传承中华优秀传统文化、勇担时代使命的决心。
笃学・自主研习 深化理论素养
培训期间，全体学员严格落实个人自学要求，坚持读原著、学原文、悟原理，系统研读《习近平文化思想学习纲要》《习近平法治文选》第一卷、《中国共产党章程》以及《关于新形势下党内政治生活的若干准则》等指定学习材料。大家结合课堂教学、辩论研讨与实地研学的所学所思，认真撰写学习笔记与心得体会。学员们纷纷表示，常态化的自主学习进一步夯实了自身理论根基，深化了对党的性质、宗旨、奋斗使命的理解把握，思想觉悟得到持续提升，为早日成为一名政治坚定、作风过硬的合格共产党员筑牢了思想根基。
本期学习展区
本次培训坚持理论与实践相结合、灌输与启发相统一，构建了“教、学、辩、行”四位一体的培养体系，全面提升了发展对象的政治理论素养、思想觉悟和综合能力。电子信息学院党委将始终把党员发展质量放在首位，持续优化入党积极分子和发展对象培养模式，不断创新培养方式方法，引导广大青年学子坚定不移听党话、跟党走，成长为信念坚定、本领过硬、作风扎实的合格共产党员，为强国建设、民族复兴伟业贡献青春力量。
