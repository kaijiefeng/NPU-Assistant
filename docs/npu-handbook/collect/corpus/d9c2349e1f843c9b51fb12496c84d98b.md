# 电子信息学院-西北工业大学医院

责任医师：袁惠（副主任医师）
简介：
副主任医师，从事消化内科工作10余年，擅长本专业常见病、多发病、疑难病的诊断及治疗，熟练掌握胃镜，及内镜下诊断及治疗。任北京亚太肝病诊疗技术联盟理事，陕西省中西医结合学会会员，陕西省国际医学交流促进会会员，陕西省协会肝病专委会会员。
（备注：学院责任医师是医院与学院之间的桥梁，可为我校师生提供健康咨询、健康宣教、体检结果释疑、急救知识技能培训等服务。有需求者，可通过扫描学院责任医师二维码联系。）
