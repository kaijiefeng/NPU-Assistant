# 档案馆工会小组组织部分职工参加2019年教职工趣味运动会

为了提倡全民健身运动，丰富教职工的业余文化活动，4月24日上午，档案馆工会小组组织部分职工参加2019年教职工趣味运动会。大家相互配合，齐心协力，场外加油鼓劲的号声此起彼伏响彻整个大操场，显得十分活跃热闹。此次趣味运动会的成功举办不仅促进了档案馆职工之间的感情交流，同时也使大家在比赛角逐中增强了团队意识和荣誉意识，展现了大家敢于拼搏、勇争第一的良好精神风貌。
