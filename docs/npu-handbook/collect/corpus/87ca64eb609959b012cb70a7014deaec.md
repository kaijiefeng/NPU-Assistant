# 冰岛

使馆签证处地址：亮马桥北小街1号(女人街美国使馆往北100米路边)和爱沙尼亚使馆签证处在一起办公。
开馆时间：每周1/3/4下午2-4点
使馆电话：85316961
共用一份的申请材料按照本手册序号顺序依次夹在团长护照内，个人单独的申请材料按本手册序号顺序夹在个人护照内。
照片：3.5*4.5白底2张，半年内近照；签证表格：1份
1.留指纹那次签证页的复印件（指纹有效期59个月，超出则无需提供，需再次前往使馆留取指纹）
2.签证表
3.邀请信原件
邀请方还需提前发送邀请函（有签名）[已脱敏:邮箱]
4.英文日程
5.中文照会
6.照会译文
7.欧洲名单表（三人及以上）
8.在职费用证明（英文、签字盖章）
9.机票订单
10.酒店订单
11.保险及复印件
12.签字卡复印件（由中心提供）
