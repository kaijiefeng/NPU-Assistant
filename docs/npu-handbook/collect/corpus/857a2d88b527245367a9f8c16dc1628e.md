# 外国语学院-西北工业大学医院

责任医师：王治荣（副主任医师）
简介：
王治荣，副主任医师，毕业于西安交通大学医学院，妇产科硕士研究生。曾任中华医学会西安分会委员。获西安市妇幼健康技能竞赛三等奖及优秀选手称号。发表国内核心期刊数篇，参与省级科研1项。从事妇产科专业二十余年，曾在交大第二附属医院、陕西省人民医院进修。擅长生殖系统炎症；盆底相关疾患的康复治疗等。在多囊卵巢综合征、异常子宫出血、围绝经期综合征等妇科内分泌疾病方面积累了丰富临床经验；熟练操作无痛可视人工流产术、取环术、LEEP电切术、阴道镜检查、盆底治疗相关疾患的康复治疗等。
（备注：学院责任医师是医院与学院之间的桥梁，可为我校师生提供健康咨询、健康宣教、体检结果释疑、急救知识技能培训等服务。有需求者，可通过扫描学院责任医师二维码联系。）
