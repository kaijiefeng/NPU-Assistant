# 2026年中秋节、国庆节安全提示

全体师生、社区居民：
2026年中秋节、国庆节即将来临，为了您度过一个安全有序、平安祥和的假期，党委保卫部特别提醒您注意以下安全事项：
1.各单位要强化责任意识，放假前做好本单位师生假期安全宣传教育、安全隐患排查及整改。各施工管理单位需加强巡查检查，动火作业前务必向保卫处备案。
2.居家期间注意用火、用电、用气安全。明火必须远离可燃物，开火时切勿离开，养成“三清三关”良好习惯。电动车不进楼入户，不飞线充电。不在室内以及楼梯间公共区域等处堆积杂物，不占用、堵塞安全出口及消防、疏散通道。
3.定期检查电器设备、线路及燃气设备、管道，如有老化、破损等应及时维修更换。严禁在宿舍、教学楼、图书馆等人员密集场所内吸烟。吸烟后及时熄灭烟头，不随意丢弃。
4.假期留校学生要严格遵守学校安全管理制度。严禁在学生宿舍等场所使用电磁炉、电饭锅等违禁电器，严禁私拉乱接电线。做实验时要严格遵守相关管理规定和操作流程，切勿随意丢弃化学品。
5.使用锂电池应从正规厂家选购符合国家标准、通过3C认证、来源正规的产品。储存时避免机械冲击和重压，要定期检查长时间不用的电池。充电时应在特定区域进行，应使用正规厂家生产的合格充电器进行充电。严禁在学生公寓、实验室、住宅楼等建筑内对航模电池、无人机电池、电动车电池、平衡车电池等高危锂电池进行充电。废弃电池应交由专业机构回收处理，不随意丢弃或混入普通垃圾。
6.校园内外均请注意遵守交通规则，文明安全出行。外出时留意天气变化，未成年学生外出应与家长结伴而行。禁止非法穿越，不乘坐非法营运车辆，不到危险区域游玩逗留，注意避免溺水。要提高自我防范意识，防范各类诈骗，确保人身及财产安全。
