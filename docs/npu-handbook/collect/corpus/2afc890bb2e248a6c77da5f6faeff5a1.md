# 就业引航 青春建功｜化学与化工学院举办2025届研究生就业政策宣讲会

6月18日，化学与化工学院在学院楼报告厅举办2025届研究生就业政策宣讲会。学院邀请了西北工业大学学生职业发展指导服务中心副主任李慧做就业专题讲座，共有120余位学生参加学习，学院党委副书记姚东东参会。宣讲会由辅导员马忠雷主持。

姚东东对李慧老师表示热烈欢迎并对学院学生就业工作长期以来的指导和支持表示感谢。接着从国家社会需求、当前就业形势、职业生涯发展等方面对2025届研究生毕业生进行了就业动员，极大地鼓舞了同学们的就业信心。

李慧老师以“在哪里存在 就在哪里绽放”为主题，从化学与化工学院毕业生去向、简历与面试准备、数字化签约平台使用三个方面做了细致的讲解。李老师对学院近几年毕业生的就业去向情况进行了全面分析，重点讲解了简历制作、面试技巧及常见问题应对，以及学校数字化签约平台使用流程。并就学生提出的就业政策、求职技巧、简历和面试准备等方面的问题进行了交流，现场互动气氛热烈。

通过此次活动，使同学们详细了解了研究生就业政策和求职技巧，也对未来职业规划有了更加明确的认知。希望同学们进一步做好职业规划和自我定位，提前了解意向单位情况，做好求职简历和面试准备，以积极的心态迎接即将来临的招聘季，做到胸有成竹，早日实现高质量就业。
