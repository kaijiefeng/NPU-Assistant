# 数字生万象，画笔绘生灵——生命科学与技术学院成功举办美育点单式课堂

为推动生命美育理念与学院美育教育工作深度融合，引导同学们在观察与创作中感受生命科学的魅力，11月5日下午，生命科学与技术学院成功举办美育点单式课堂。活动特别邀请到艺术教育中心刘韬、庞宇阳两位老师先后授课，80余位学生到场听讲。
刘韬老师为同学们带来“轻创中国风：AIGC影视快闪实验室——30分钟玩转国潮视效与微叙事”课程，课堂围绕AI影像的起源与不同平台的操作流程展开，帮助同学们快速了解AIGC影像创作的基本方法。课堂最后播放了学生运用全AI流程制作的中华传统文化短视频，展示了技术赋能下青年学子对传统文化的创新表达。
庞宇阳老师的“校园印象——油画棒写生工作坊”课程从油画的起源讲起，介绍了不同介质在绘画表现中的差异，并讲解了绘画工具与基本技巧。他鼓励同学们放下“画得像不像”的包袱，在动手实践中体会绘画作为表达方式的意义。
从屏幕上的AI生成到画纸上的手工描摹，两堂课看似手段迥异，实则殊途同归：当工具越发强大，那份源自内心的真实表达便愈发珍贵。正如刘韬老师所强调的，技术让影像生产变得高效，但创作的内核始终在于人的表达；而庞宇阳老师所说的“被触动之后想要表达的方式”，恰恰印证了手工绘画在随手可拍的时代依然不可替代。这正是本次美育点单式课堂要传递的理念。
未来，学院将继续以美育为纽带，整合艺术教育与生命科学的交叉资源，把更多优质课程送进同学们的日常，让大家在读懂生命、敬畏生命、热爱生命的过程中有所收获。
