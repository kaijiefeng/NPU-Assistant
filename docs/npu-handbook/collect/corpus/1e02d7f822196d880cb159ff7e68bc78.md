# 工会党支部召开4月理论学习会议-校工会（帮扶办）/ 妇女联合会

为加强工会党支部建设，落实党支部“三会一课”，强化思想引领，4月22日上午，工会党支部组织全体党员召开4月理论学习会议，会议由支部书记陈建军同志主持。
会上，支部书记陈建军同志传达了《机关党委党纪学习教育实施方案》通知精神，他指出，工会党支部全体党员要深刻认识开展党纪学习教育的重要性，通过学习教育坚定理想信念，保持和增强工会工作的政治性、先进性、群众性，不断完善教职工服务体系，团结带领全体教职工推动学校内涵式高质量发展。接着大家集中学习了习近平总书记在湖南考察时的重要讲话精神、中共中央印发的《党史学习教育工作条例》、学校2024年全面从严治党工作会议精神、《求是》杂志发表的习近平总书记重要文章《坚持人民至上》、中国共产党党员网络行为规定等内容，9位党员根据党支部细化分解的学习任务，结合工作实际作进行交流发言，陈建军同志做了党纪学习教育专题对照发言。
最后，按照机关党委的工作安排，会议推选出工会党支部出席机关党委代表大会的代表候选人预备人选，从机关党委委员候选人初步人选名单中推选出机关党委委员候选人预备人选。（文、图/钱娅群 审核/陈建军）
