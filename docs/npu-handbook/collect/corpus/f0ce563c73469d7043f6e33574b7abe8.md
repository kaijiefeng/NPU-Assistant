# 国家卓越工程师学院关工委联合邀请 “五老”银发宣讲员开展专题党课

为扎实推进入党积极分子和发展对象培养教育工作，深化新时代大学生思政引领实效，10月27日下午，国家卓越工程师学院关工委联合民航学院关工委，特邀学校关工委“五老”银发宣讲员高宝营老师讲授专题党课。线上线下50余名入党积极分子和发展对象参加培训学习。
高宝营老师以“正确理解和把握习近平党建思想”为主题，从时代背景与发展脉络切入，系统梳理了习近平党建思想的形成过程，细致阐释了其丰富内涵、核心要义、立场观点和实践要求，为同学们理解习近平党建思想提供了清晰的学理框架。
本次专题党课让同学们深刻理解习近平党建思想的理论逻辑、历史逻辑与实践逻辑，更加完整、准确地把握“新时代党的建设新的伟大工程”的深远意义。下一步，学院将持续依托学校关工委“五老”育人资源，把思想政治教育融入人才培养全过程。
