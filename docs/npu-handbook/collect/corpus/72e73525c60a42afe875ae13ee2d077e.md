# 我院召开保密教育培训会

10月15日下午，人工智能学院/无人系统技术研究院邀请学校保密处副处长王革明开展保密教育主题培训会。本次培训覆盖两院全体学生，357名学生及6位教师代表分三个会场同步参会。培训会由学院执行院长/研究院院长白俊强主持，学院/研究院党委书记毛昭勇、党委副书记徐晓峰、保密员王君瑞，辅导员韩凯、李莹玥参加本次培训。
本次培训围绕保密法律法规、工作纪律、风险防范等内容展开，旨在引导师生充分认清保密工作极端重要性，树牢保密红线意识，掌握日常保密风险识别和防范方法，筑牢科研学习中的保密思想防线。
王革明为全院学生开展保密培训会
培训会上，王革明从国际环境复杂变化、科技竞争和信息竞争日趋激烈讲起，结合国内发展与安全任务相互交织的新形势，分析了信息化、数字化背景下保密工作面临的新情况。王革明结合我校近期发生的真实案例，强调高校学生保密工作要从日常抓起，在日常教学、学术交流、会议活动、材料报送、文件传输以及社交媒体等场景中，一些看似习以为常的操作，如果安全意识不足、信息边界把握不准，就可能留下风险隐患。针对这些常犯易犯问题，全体师生应共同规范信息处理行为，增强风险辨识能力，主动防范失泄密隐患。同时，要不断提高责任意识，自觉维护良好的科研秩序。
此次培训会深化了同学们对保密法规和日常防护要求的理解，为营造安全、规范、严谨的科研学习氛围提供了有力保障。
