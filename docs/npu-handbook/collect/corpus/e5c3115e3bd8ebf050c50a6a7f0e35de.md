# 西北工业大学后勤办公室请销假管理规定

西北工业大学后勤办公室请销假管理规定
后勤办字〔2020〕2号
为了加强内部考勤、考核、岗位管理，严肃劳动纪律，提高工作效率，根据《西北工业大学教职工请假及休假的有关规定》要求，制定本规定。
第一条按时上下班，不迟到，不早退，不脱岗；每天迟到、早退的要严格登记；1个月迟到、早退累计达7小时的当作旷工1天处理，超出部分以此为标准进行计算；每天请假超过半天的要严格登记。
第二条上班时间因公外出，应实行报告制度。科员应向科室负责人说明外出事由、目的地、预计外出时间等，并保持通讯通畅，便于工作联系。若因私离开工作岗位需按审批权限请假，凡未办理请假手续擅自离开工作岗位的按旷工处理。
第三条因病、因公（外出学习、参加会议等）、因事不能上班的，应提前半天请假，并安排好工作。请假实行逐级审批制度。
（一）请假1天以内须科室负责人审批；2-3天(含) 经科室负责人签署意见后报分管副主任审批；3天以上的，经科室负责人签署意见后报主任审批。科室负责人请假由分管副主任批准，副主任请假由主任批准。主任请假由分管校领导批准。
（二）病假要出具医院证明，事假需书面申请理由，经审批后的请假条交运行保障科备案。
（三）如特殊紧急情况无法提前办理请假手续的，须在事后及时完善补办手续。
（四）病假、事假超过30天以上，经主任签署意见后，报人事处审批。
（五）续假：续假应在原批准假期之内书面申请，按规定的审批权限批准后生效；未经审批的按旷工处理。
（六）销假：假满正式上班，应到运行保障科进行销假。
第四条职工年度考勤与考核、奖励绩效挂钩。全年累计请病、事假超过15个工作日，年度考核原则上不能评为优秀，并在奖励绩效中视情况予以扣除。
第五条病假、事假、婚假、产假、节育假、哺乳假、探亲家、丧假按《西北工业大学教职工请假及休假的有关规定》执行，各类请假及旷工期间待遇按学校规定执行。
第六条本规定未涉及的，按国家和学校有关规定执行。本规定若与国家有关规定不一致时，按国家有关规定执行。
第七条本规定由后勤办公室负责解释。
第八条本规定自2020年11月6日起施行。
