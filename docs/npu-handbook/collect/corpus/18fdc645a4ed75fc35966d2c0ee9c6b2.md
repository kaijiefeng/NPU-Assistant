# 学校召开2026—2027学年秋季学期本科教学工作会议

9月7日上午，学校在友谊校区组织召开了2026—2027学年秋季学期本科教学工作会议。副校长岳晓奎出席会议，本科教学名师、督导代表，各教学单位本科教学负责人及教务部相关人员参加了会议。会议由教务部部长王海鹏主持。
会上，招生办公室主任兼教务部副部长王克勤传达了2026年暑假务虚会、秋季学期中层干部会精神。教务部副部长张学良、孙中奎、孟中杰分别汇报了本科生毕业及深造、专业调整优化及教材建设、课程建设等相关工作。教师代表张娟、吕焰结合自身教学实践，交流了深耕教学一线的心得体会。
王海鹏表示，教务部将深刻学习、精准把握“我们是干什么的、我们的处境是什么、我们应该怎么干”3个核心问题，扎实推进学校部署安排，坚守“为党育英才，为国铸重剑”初心使命，继续协同相关部门和各教学单位，聚焦“总师型”人才培养体系完善，以专业调整为抓手，以AI赋能为主线，以机制创新为牵引，扎实工作、锐意进取，不断优化“招生—培养—深造”联动机制，全力推动人才培养“十五五”规划任务落地。
最后，岳晓奎在总结讲话中指出，今年是“十五五”开局之年，学校正处在加快建设中国特色世界一流大学的关键时期，各教学单位要聚焦立德树人根本任务，扎实工作、锐意进取，以更大决心、更实举措持续推进“总师型”人才自主培养。一是要持续优化本科专业布局，推动专业布局与国家战略需求同频共振，聚焦国防军工急需和人工智能等重点领域，主动布局新兴交叉专业，做好专业自评估，强化结果刚性运用，以评促建促改促优。二是要加快推动人工智能赋能教育教学，大力推进AI赋能课程体系建设，加大新形态、数字化教材开发力度，推进AI赋能实践教学体系改革，提升教师人工智能素养。三是要加强人才选拔与深造托举，继续提升招生精准性与实效性，创新开展招生宣传，加大本研贯通培养，拓展深造渠道，持续提升招生深造竞争力。
