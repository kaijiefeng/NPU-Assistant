# 数学与统计学院-西北工业大学医院

责任医师：周杨（主治医师）
简介：
主治医师。硕士，毕业于西安交通大学医学部，曾就职于西安交通大学第一附属医院妇产科。业务范围包括妇产科常见病、多发病诊治及妇科常见手术操作，特别对常见妇科内分泌疾病如多囊卵巢综合征、闭经、更年期综合征等的诊治积累了丰富临床经验，现任陕西省预防医学会生殖健康专业委员会委员，工作至今于核心期刊发表论文6篇，SCI 1篇，参与编写妇产科相关著作6部。
（备注：学院责任医师是医院与学院之间的桥梁，可为我校师生提供健康咨询、健康宣教、体检结果释疑、急救知识技能培训等服务。有需求者，可通过扫描学院责任医师二维码联系。）
