# 重庆科创中心党支部参加两江协同创新区联合党委植树活动

3月15日，重庆科创中心党支部参加了两江协同创新区联合党委开展的两江协同创新区联合党建林2021年义务植树活动。百余株美人梅、红梅等观赏树种在日月同辉创新馆一侧山坡“安家”，为两江协同创新区产城景融合的生态美景添绿增彩。
龙兴镇党委班子，两江协同创新区公司党员干部代表，重庆科创中心、北京理工大学重庆创新中心、哈尔滨工业大学重庆研究院等30家入驻高校、科研院所党员代表等100余人参加活动。
各单位同志们携裹着春泥，三五结队，协同配合，挥锹铲土、扶树填坑、踏土夯苗、提桶浇水……默契协作、干劲十足，每道工序都一丝不苟，现场一片热火朝天的劳动景象。
科创中心党员群众表示通过参加此次两江协同创新区联合党委植树活动，增进了与兄弟高校、科研院所的了解，展现了大家团结协作、吃苦耐劳的精神，增强了大家的生态意识和环保意识，同时把大家都凝聚在了党组织的周围，相信在联合党委的创新模式下，一定会以高质量党建引领高质量发展，干出成绩、形成特色，努力向建党一百周年献礼。
