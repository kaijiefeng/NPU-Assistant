# 保卫处开展新学期安全教育系列讲座

新学期伊始，为提高师生员工的安全意识，9月20日-9月26日，保卫处面向在校学生及校卫队员开展新学期安全教育系列讲座活动，讲座分为防范电信诈骗、反恐宣传教育、和网络安全教育三个主题，进一步提高师生的自我防范意识和应变能力。
在《看清金融陷阱：电信网络诈骗的识别与预防》专题讲座中，友谊校区警务室吕欣警官针对当下电信网络诈骗隐蔽性强、诈骗手法多样的特点，结合真实案例详细讲解了甄别和防范电信诈骗的技巧，配上朗朗上口的“安全七字警示歌”，进一步提升了学生的学习兴趣和安全意识；公安碑林分局网安大队杨光警官，以“网络安全与隐私保护”这一社会热门话题为切入点，用通俗易懂的语言介绍了计算机信息网络国际互联网安全保护管理办法，增强了师生和校卫队员的网络安全法律意识。
此外，针对校园保卫工作的新形势新变化，吕欣警官为校卫队开设了《浅谈反恐应急防范，确保单位内部安全》专题讲座，从社会治安形势分析、反恐基本常识、反恐防范技能和反恐机制四个方面介绍了单位反恐应急工作要求，旨在提高了校卫队的反恐防暴和应急处突能力。
通过开展新学期安全宣传教育系列讲座，提高了在校师生的安全防范意识，营造“全民反诈、全民参与、全民宣传”的校园氛围，同时也提升了安保人员的综合素质和业务水平，为下半年更好的开展安保工作奠定了良好基础。
