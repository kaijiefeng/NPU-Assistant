# 民航学院召开2025年科研工作推进会议

2025年6月5日，西北工业大学民航学院科研工作会在太仓智汇港召开，民航学院院长李玉龙、民航研究院常务副院长李晨、民航学院副院长张超及学院教师等30余人参加了本次会议。此次会议旨在分析总结学院科研发展的成绩与挑战，研究部署下一阶段学院科研领域的各项重点工作，助力学院高质量发展。
会议伊始，张超副院长汇报了学院近期科研工作进展与成效，从国家自然科学基金申报、重大重点项目策划、校企协作、成果培育等方面，深入分析了科研工作面临的形势任务和发展机遇。他指出未来要瞄准国家重大需求，凝练特色科研方向，统筹产学研创新资源，多渠道培育各类项目，提早部署下一阶段科研任务，确保科研工作高效推进。李晨常务副院长介绍了学院近期立项的低空技术项目的相关情况，并鼓励学院青年教师围绕相关关键技术开展协作攻关和预先研究，积极服务低空产业发展需求。随后，为切实做好科研保密工作，提升科研人员保密意识，学院科研秘书、保密员林钰详细介绍了科研保密工作要求，梳理出常见保密问题，提出了针对性防范措施，为科研工作筑牢安全防线。
李玉龙院长在总结讲话中充分肯定了学院科研工作成效，围绕当前科研工作面临的形势与挑战，他期望大家把握战略机遇、保持战略定力、持续整合科研资源。聚焦学院的长远发展做好谋划布局，确保目标责任制高质量完成。
与会教师围绕国家政策要求和学校全局发展，结合学院科研各方面具体工作，深入展开分析与讨论。下一步，民航学院将细化落实会议成果，以扎实行动实现学院科研工作新突破。
