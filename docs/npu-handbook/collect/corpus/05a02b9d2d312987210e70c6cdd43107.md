# 寻迹百年路 共筑青春志——西北工业大学力学与交通运载工程学院赴延安开展“总师型”人才实践育人第二批红色教育活动

2025年10月11日上午，火车缓缓驶离西安站，西北工业大学力学与交通运载学院2025级40余名师生共同启程，奔赴陕西延安红色革命圣地，开展第二期“总师型”人才实践教育活动。此次活动将思政课堂融入红色旅程，引导工大学子在行走中赓续红色血脉，厚植爱国情怀，强化使命担当。
抵达延安后，师生一行首先来到延安革命纪念馆。馆前毛泽东雕像巍然屹立，庄严肃穆。在讲解员的引导下，师生共同回顾了延安从贫瘠之地发展为革命圣地，再到如今“三山两河、绿满城乡”的沧桑巨变，深刻体悟历久弥新的延安精神。
随后，大家走进鲁迅艺术学院旧址。古朴的建筑与青翠的菜园相映成趣，抗战时期诞生于此的经典旋律依旧回响。这些艺术作品曾激励无数革命先驱，如今依然拨动着新时代青年的心弦。
在鲁艺旧址，延安大学张金星老师为师生带来了一堂生动的主题党课。通过延安民歌的变迁，大家感受到中国共产党为这片土地带来的深刻变革。全体师生齐声高唱《黄河大合唱》，激昂的歌声回荡在历史现场，连接起跨越时空的精神共鸣。
夜幕降临，大型红色沉浸剧《再回延安》缓缓上演，随着剧情推进与场景转换，叙述了红军长征过雪山草地到北上延安的革命历史，其间的感人故事和沉浸式艺术表现让不少同学为之动容落泪。
10月12日清晨，同学们在张思德纪念广场集体诵读《为人民服务》，感悟共产党人的初心使命。随后前往延安学习书院，系统学习从党的十八大到二十大以来习近平总书记系列重要讲话精神，深入了解了国家及陕西省的发展成就，在行走中共上一堂“立体思政课”。
实践活动的最后两站分别是杨家岭革命旧址与延安北京知青博物馆。老一辈革命家艰苦朴素的生活作风、北京知青勇战困境的奋斗精神，深深触动着每一位学子，让大家更加珍惜当今来之不易的盛世。
两天的延安之行，同学们触摸的不仅是历史文物，更是闪耀其中的精神光芒。大家怀揣敬畏之心观察、思考、学习，在红色热土上汲取奋进力量。
此次在学院党委组织领导下的第二期延安红色实践，是夯实学校“总师型”人才思想根基的重要举措，进一步坚定了学院青年学子传承革命精神、践行“公诚勇毅”校训，弘扬“三实一新”校风的决心。大家纷纷表示，将把所学所悟转化为强国担当的青春实践，在未来的人生道路上书写无愧于时代的崭新篇章。
