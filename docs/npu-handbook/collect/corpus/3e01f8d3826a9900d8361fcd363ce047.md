# 【国家公派】2026年创新型人才国际合作培养项目第三批拟推荐人员名单公示

各单位：
根据我校2026年创新型人才国际合作培养项目工作安排，经校内评审，拟推荐武博文等6人为2026年创新型人才国际合作培养项目第三批申请人，人员名单参见附件《西北工业大学2026年创新型人才国际合作培养项目第三批拟推荐人员名单》。
公示期为2026年9月11日-17日，如有异议，请于9月17日前将书面意见反馈至国际合作处。
联系电话：88492839。
