# 学院杨云霞教授在权威期刊《马克思主义研究》发表学术论文-西北工业大学

我院杨云霞教授在权威期刊《马克思主义研究》2026年第9期发表题为《百年未有之大变局中的人类文明新形态》的学术论文，深入研究、阐释在百年未有之大变局中人类文明的演进以及中国式现代化所创造的人类文明新形态，产生广泛学术影响。
当今世界正经历百年未有之大变局，其最突出的特点就是“东升西降”。世界格局“东升西降”的演进态势，超越了传统的国力升降与霸权更替范畴，表征了西方中心主义文明范式的衰退和人类文明新形态的兴起。依托哲学根基、经济模式、治理逻辑、世界秩序观和价值观念构成的分析框架，可清晰呈现西方中心主义文明范式的深层结构性困境，揭示其衰落的历史必然性。中国式现代化创造的人类文明新形态，展现出区别于西方文明的全新实践特征，具有重要的时代价值与世界意义。尽管文明范式的新旧更迭具有长期性与复杂性，新型文明范式的全球认同仍面临诸多现实阻碍，但多元共生是人类文明发展的必然走向，以中国式现代化为典型样本的新型文明范式能够有效回应全球治理难题，为化解人类共同发展危机提供解决方案。
《马克思主义研究》由中国社会科学院马克思主义研究院主办，是以专门研究和宣传马克思主义整体理论为宗旨的大型学术理论刊物。是国家社会科学基金资助期刊、全国百强学术期刊、数字影响力100强期刊，是马克思主义理论学科顶级期刊，连续入选CSSCI来源期刊、AMI权威期刊、全国中文核心期刊，RCCSE 中国权威学术期刊，在马克思主义研究领域具有崇高学术声誉和广泛学术影响。
杨云霞教授在《马克思主义研究》先后发表学术论文3篇，体现了扎实的学问功底和良好的学术素养。学院将进一步加强对高质量学术成果的培育和支持，不断推进学院高质量内涵式发展，为实现我校“天下工大、世界三航”远景目标贡献更多的智慧和力量。
作者简介
杨云霞，马克思主义学院院长、教授、博导，国家哲学社会科学领军人才，全国文化名家暨“四个一批”人才，宝钢优秀教师奖获得者，陕西省教学名师，陕西省“六个一批”人才，西安市决策咨询委员会委员。长期从事马克思主义理论研究，主持国家社科基金、国家社科基金重大项目子课题、最高人民法院司法研究重大课题、陕西省社科基金重大项目等50余项；出版专著4部，在《马克思主义研究》《马克思主义与现实》等发表论文110余篇，被人大复印报刊资料全文转载9篇；荣获陕西省哲学社会科学优秀成果一等奖3项。始终坚守教师工作岗位，主持国家级一流课程1门、陕西省教改项目3项，荣获国家教学成果奖、陕西省教学成果奖5项，作为西部地区唯一思政课教师代表参加“全国新时代学校思政课建设推进会”，参与国家教材委员会教材审核工作。兼任中国高等教育学会马克思主义分会副理事长，曾担任国家社科基金等各类项目评审专家、各类人才项目评审专家等。
