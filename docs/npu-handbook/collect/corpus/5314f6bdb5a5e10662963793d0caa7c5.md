# 西工大软件学院与华为联合授课：AI技术与软件深度融合的实践课重塑

2026年4月11日下午，由西北工业大学软件学院西安教师党支部承办的“底层技术与AI融合实践教学”专题课程顺利举办。本次课程特邀华为昇腾生态编译技术专家郭依蓬、毕昇编译器技术专家曾庆宇，与西安教师党支部党员、学院博士生导师徐韬教授共同为学生们授课，标志着新一轮产教融合协同育人项目正式落地课堂。
课堂上，华为专家展示了基于Triton的教学级技术方案。Triton作为一种第三方跨平台编程语言，非常适合高校实践教学：学生可以在较低起点下快速实现算子原型，并在短期内获得优秀的性能表现。
徐韬在授课中指出，底层技术开发能力正成为AI人才的核心竞争力之一。通过与华为共建实践教学环节，学生不再停留于理论推导，而是在产业真实场景中完成“案例学习—项目实践—创新应用”的能力进阶。
课程最后，双方表示下一阶段将把AI辅助编程、自动化性能分析等工具深度融入教学，让学生更早接触产业级工程范式。徐韬说：“我们的目标不是培养只会调用接口的学生，而是能够驾驭底层计算与上层模型的双栖人才。”
此次联合课程的成功开展，为AI时代底层技术人才培养探索出一条可复用的产教融合新路径。
