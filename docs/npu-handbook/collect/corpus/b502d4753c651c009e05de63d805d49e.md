# 数学与统计学院2026年暑期国际学堂《极值集合论》全英文课程顺利结课

2026年7月12日至19日，匈牙利科学院院士Péter Frankl教授为我校师生讲授了暑期国际学堂课程《极值集合论》（Extremal Set Theory），吸引了20余名本科生、研究生选修或旁听。
课程共16学时，主要讲授有限集族在包含、相交、禁图等约束条件下的最大规模与结构刻画问题，包括Sperner定理、Erdős–Ko–Rado定理等经典结论，移位方法、链分解、概率方法等研究工具，以及相关前沿进展与开放问题。
本课程得到了我校国际合作处、教务部和数学与统计学院的支持。
学生感悟：数学与统计学院2024级硕士研究生顾同学在课程结束后表示，通过本次课程，对Sperner定理和Erdős–Ko–Rado定理的证明逻辑和构造方法有了更具体的理解。Frankl教授全程用中文授课，降低了学生语言理解上的障碍。课间Frankl教授仍在教室为同学解答问题，并分享了自己与导师、合作者之间的学术往来经历，提到数学研究中的合作交流，这些分析对同学们后续开展研究工作提供了非常有益的指导和启发。
主讲教师简介：Péter Frankl，匈牙利科学院院士，国际著名数学家，国际数学奥林匹克金牌得主，国际数学家大会邀请报告人。在数学综合类四大顶级期刊Ann. Math.、J. Amer. Math. Soc.，综合类著名期刊J. London Math. Soc.、Trans. Amer. Math. Soc.、Israel J. Math.等发表论文300余篇。
