# 工会党支部走进照金开展特色主题党日活动-校工会（帮扶办）/ 妇女联合会

为扎实推进学习贯彻习近平新时代中国特色社会主义思想主题教育，加强党性修养，推动理论武装走深走实走心，进一步增强党支部的凝聚力和战斗力，5月26日，工会党支部走进照金开展特色主题党日活动，教工艺术团46名老师共同参与活动。
在照金1933广场，西工大教工艺术团、教授合唱团倾情演绎《唱支山歌给党听》《我的祖国》《我和我的祖国》三支革命歌曲，唱出对祖国最真挚的祝福，唱出奋进新征程的磅礴力量，现场气氛热烈，歌声吸引了众多到红色基地的践学者，大家驻足观看，连声称赞。
工会党支部党员与教工艺术团的老师们还共同参观了照金革命纪念馆，讲解员以陕甘边革命历史为主线，为大家讲述了刘志丹、谢子长、习仲勋等老一辈无产阶级革命家的英雄事迹，大家在一张张历史照片、一件件珍贵实物前驻足观看，用心聆听，追忆党的峥嵘岁月和革命先辈，深切感悟照金精神等红色文化。
本次特色主题党日活动通过吸引力和感染力极强的红歌表演以及沉浸式参观学习体验，让支部党员对照金精神有了更加深刻的理解与感悟，加强了党性修养、坚定了理想信念，有效提升党支部的凝聚力和战斗力。大家一致表示，要在学校高质量发展中发挥党员先锋模范作用，做好本职工作，争创一流业绩。
