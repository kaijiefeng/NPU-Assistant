# 学院举办2026年暑期“实践归来话成长”分享交流会

近日，莫航学院举办2026年“实践归来话成长”暑期社会实践交流分享会，学院团委书记杨粉萍、副书记邢文思、各实践队指导教师及实践队员代表参加会议。
交流会上，学院3个实践队代表依次发言，围绕实践筹备过程、实地开展内容、特色创新举措、实践成果收获与个人成长感悟等方面，全方位、多角度地分享展示了走出校园、扎根一线，开展暑期社会实践的所学所获、所思所想。各团队汇报内容充实、感悟深刻，充分展现了工大学子朝气蓬勃、求真务实的青春风貌，现场交流氛围热烈浓厚。
交流现场，各位老师充分肯定了各实践队取得的阶段性成果，围绕项目长效化推进、实践成果深入转化、团队协作能力提升等方面提出针对性指导建议，并鼓励同学们珍惜实践育人的宝贵契机，把社会实践中的所思所得转化为勤学笃行、奋勇争先的内生动力，持续深耕实践沃土、勇担时代使命，让青春在服务社会、奉献基层的新征程中绽放绚丽光彩。
