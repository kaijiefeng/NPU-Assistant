# 刘郑国院长做客“翱翔名家讲堂”

10月16日下午，应学院邀请，中国舰船研究院原院长刘郑国做客“翱翔名家讲堂”，作《锚定强国建设目标 锤炼系统工程素养》主题报告。活动由党委学生工作部主办、莫航学院承办，学院30余名师生代表参加学习报告会。学院党委书记向丹主持活动。
报告会上，刘郑国老师从“认清大势、勇担使命、回应呼唤、笃行实干”四个维度展开。报告深刻剖析了百年未有之大变局下，实现高水平科技自立自强的时代紧迫性，系统回顾了我国船舶工业从跟跑、并跑、迈向并道超车的发展历程。报告中，他生动讲述了大国重器背后的科研攻关历程和一代代造船人向海图强的奋斗故事，让在场同学真切体悟到“爱国、创新、求实、奉献、协同、育人”的科学家精神内涵。他勉励青年学子立足当下，持续锤炼辩证通透的科学思维，培育协同共赢的团队协作能力，涵养勇于突破的创新发展意识，构建知行合一的过硬综合素养，努力成长为可堪大用的系统型工程人才。
互动交流环节，氛围热烈。同学们围绕专业学习、创新实践、职业规划、科技前沿等内容踊跃提问，刘郑国老师逐一解答、悉心点拨。
报告会后，同学们纷纷上前与老师深入交流，畅谈学习体会与理想追求。刘郑国老师认真倾听同学们的所思所想，勉励大家坚定科技报国信念，将个人成长融入国家发展大局，矢志为强国建设贡献新时代青年力量。
同学们备受鼓舞、感触良多，积极分享所学所思。
张垚卿同学表示，“聆听刘郑国老师的专题报告，我深受教育与触动。海上工程试航阶段，先辈挺身而出、随艇下潜，这份无畏担当，是千万次演算推演积淀而成的底气。当前智能技术蓬勃发展，为工程创新带来新机遇，我将紧跟时代浪潮，立志以所学所长报效祖国，扛起青年一代的使命担当。”
李彦成同学谈到，“刘郑国老师结合舰船工程一线实践经历，引导我们跳出单一专业视角，生动阐释了新时代工程人才必备的系统工程思维能力与综合素养。作为新时代青年，我将在专业学习与科创实践中培育系统思维，锤炼过硬本领，以实际行动助力强国建设。”
赵南斐同学说道，“刘郑国老师的分享令我深受启迪。老师结合建立创新研究所的亲身经历，鼓励我们打破惯性思维，运用工程系统观念驱动原始创新。作为西工大学子，我将夯实基础、厚积薄发，将青春理想锚定国家战略需求，在青春实践中践行老师传递的精神力量。”
组织好总师报告会是学院党委深入落实立德树人根本任务、推进“总师型”人才培养的重要举措。这场总师报告会既是一次拓宽视野、启迪思维的专业领航，更是一场赓续奋斗、凝聚力量的精神传承，为青年学子践行报国担当、锤炼系统工程素养注入源源不断的精神动力。
