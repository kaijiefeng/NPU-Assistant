# 学校开展首批校级示范性党员活动室评选活动

5月28日至29日，学校首批校级示范性党员活动室评选活动在长安校区、友谊校区展开。申请单位党委、党总支的负责同志组成评委团，党委常委、党委组织部部长詹浩主持评选活动，学校副总会计师张建新、党委组织部负责党建工作的同志参加此次活动。
为促进工作交流，切实提升评选质量，同时减轻基层工作负担，此次评选采用实地参观+现场交流的形式。评选过程中，26个党员活动室所在基层党委、党总支的负责同志既是主讲人又是评价人，通过对每一个党员活动室现场实地的参观和未来建设方案的聆听，大家在提出问题建议的同时学习到了宝贵经验。整个评选活动始终在有学、有思、有感、有趣的氛围中进行，行走中的工作研讨不绝于耳。此次评选活动受到现场多位基层党委、党总支书记的肯定，表示此次活动为工作学习探索了新模式，为优评优选踏出了新路子。评选最后，詹浩对此次评选情况进行了总结，同时对各基层党委、党总支的党员活动室创建工作给予充分肯定。
示范性党员活动室评选活动是党委组织部认真落实学校第十三次党代会精神，推进党建“双创”工作开展的重要组成部分。下一步，党委组织部将以此为契机，积极打造多功能党支部活动阵地，不断筑牢支部堡垒，继续以高质量党建推动学校高质量发展。（撰稿：宋辉 王一宁；审稿：张永福）
