# 化学与化工学院开展“五一”假期前实验室安全检查

为保障“五一”假期期间实验室安全稳定运行，落实学院安全生产部署，4月30日上午，化学与化工学院组织开展假期前实验室安全专项检查，并对第一季度学校安全生产检查发现的隐患进行“回头看”复查。
本次检查由副院长陈凯杰带队，院长助理郭威、学院安全员郭思敏及学院实验室督查组全体成员参加。检查组对照《高等学校实验室安全检查项目表》及各实验室假期危险性实验备案情况，逐项核查风险点，并与实验室人员交流，提出具体整改意见，要求立行立改；无法当场整改的，须明确方案与临时防护措施，确保风险可控。
此外，检查组对第一季度发现的隐患逐条核实整改情况，确保闭环管理，并提醒各实验室要高度重视假期值班值守和风险防范，严格落实水电气源管理，规范实验操作，坚决杜绝安全事故发生。
此次检查是学院落实全年安全检查不断线、筑牢常态化安全屏障的重要举措，有效强化了师生的安全责任意识，规范了实验室安全管理体系，为学院安全稳定和教学科研工作的有序开展提供了坚实保障。
