# 我校教师在陕西高校思政课教师“大练兵”省级展示活动中再获佳绩-西北工业大学

近日，由陕西省委教育工委、省教育厅组织的2025年度陕西高校思政课教师“大练兵”省级现场展示活动圆满落下帷幕。经高校推荐、网络初评、现场展示、专家评审等环节，我校许斯诺、王竹君两位老师荣获特等奖，王鑫老师荣获一等奖。
来自全省80所高校的166名教师，历经校级思政课教师“大练兵”、网络展示初评等选拔环节，成功晋级省级现场展示，同台竞技。我校三名教师通过前期精研课件打磨、专家集中点评“会诊”、院内模拟实战演练等多轮系统备赛，历经层层遴选顺利晋级并取得优异成绩，充分彰显了我校思政课教师扎实过硬的专业素养和昂扬向上的精神风貌。
许斯诺 课程名称：《习近平新时代中国特色社会主义思想概论》
王竹君 课程名称：《马克思主义基本原理》
王鑫 课程名称：《形势与政策》
学院高度重视青年教师思政课教学能力，多措并举锤炼青年教师队伍，统筹开展教学观摩、听课全覆盖、教学展示等多项教学质量提升举措。下一步，学院将不断完善“院赛－校赛－省赛－国赛”的梯队培育模式，以赛育师、以赛促教，充分发挥辐射带动作用，进一步提升思政课程和课程思政育人效果，推动“总师育人文化”引领思政课改革创新向纵深发展。
