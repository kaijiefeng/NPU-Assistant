# 航海学院召开研究生导师培训会

为加强研究生指导教师队伍建设，提升研究生导师的指导能力和业务水平，2023年9月15日，航海学院在学院201会议室举办了2023年研究生导师培训会，20余名新聘硕博导老师参加了会议。
曾向阳副院长在会上强调了导师是研究生培养的第一责任人，承担着对研究生进行思想政治教育、学科前沿引领、科研方法指导和学术规范教导的责任。他指出，由于招生政策、学生情况、管理规定和论文要求等都在不断发生变化，研究生导师也应与时俱进，不断学习和成长，并要求老师们认真学习学校制订的《研究生培养事故分类与级别》等相关文件。他希望青年导师们能够秉承航海学院在研究生培养方面的优良传统，努力培养出更多更优秀的硕士和博士毕业生。
随后，研究生秘书席杰、罗钰、李淼详细从招生、课程学习、论文开题、中期考核、学位申请等研究生培养环节的一些关键事项展开培训。
本次培训旨在帮助研究生导师们进一步明确导师第一责任人制度，熟悉研究生培养过程的各个环节，明晰研究生培养的相关规定、要求和流程，促进研究生导师指导能力和育人成效的持续提升，为加强航海学院优秀导师队伍建设提供坚实保障。
