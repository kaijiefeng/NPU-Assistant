# 校际交流促发展，互学互鉴共提升——电子科技大学国家卓越工程师学院来院调研交流

2026年10月12日下午，电子科技大学国家卓越工程师学院英才、卓工联合党总支副书记贾龙飞一行来院调研交流。国家卓越工程师学院党委书记、常务副院长蒋建军，党委副书记、副院长王谦及相关科室工作人员参加座谈交流。
座谈会上，蒋建军对贾龙飞一行的到访表示欢迎。双方围绕学生管理培养模式创新、学生党建与思政工作、校企协同育人机制完善、双导师队伍建设等核心议题展开深入研讨，针对人才培养过程中面临的重点难点问题交换了具体意见，分享了各自在解决相关问题时的思路与成效。调研团一行还实地参观了我院的建设情况，直观了解了学院的教学环境与育人氛围。
此次调研交流搭建了两校在卓越工程师培养领域的沟通桥梁，双方一致表示，将以此次交流为契机，共同探索卓越工程师培养的新路径、新方法，携手为国家培养更多爱党报国、敬业奉献、具有突出技术创新能力、善于解决复杂工程问题的工程技术人才，为我国关键领域科技发展与产业升级贡献高校力量。
