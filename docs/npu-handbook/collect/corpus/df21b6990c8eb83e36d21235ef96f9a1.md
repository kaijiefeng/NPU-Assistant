# 共筑保密防线，公民人人有责——航天学院开展师生保密教育专题培训

为深入贯彻总体国家安全观，扎实推进保密宣传月活动走深走实，切实提升全院师生保密意识和安全防范能力，2026年4月17日下午，航天学院组织开展非密师生保密教育专题培训。本次培训紧扣“共筑保密防线，公民人人有责”保密宣传月主题，全院约250名师生参加培训。
培训紧密结合航天领域工作特点和学院教学科研实际，重点围绕《中华人民共和国保守国家秘密法》及国家保密相关法规、学校和学院保密管理制度进行系统讲解，内容清晰、要求明确、贴近日常，让全体参训师生准确把握保密工作基本规范和责任要求。
培训通过解读典型保密警示案例开展警示教育，以案释法、以案明纪，用真实事例警示师生认清失泄密风险与严重危害，进一步强化底线思维，时刻绷紧保密安全这根弦。
为检验学习成效，确保教育培训入脑入心，培训现场组织了保密知识当场测试，以考促学、以学促行，切实巩固学习成果，强化保密责任意识。
此次培训进一步普及了保密法律法规和制度要求，有效提升了全院非密师生的保密意识、法治观念和防范技能，营造了“人人讲保密、处处重保密”的良好氛围。下一步，航天学院将以保密宣传月为契机，持续深化保密宣传教育，把保密工作要求融入教学科研、管理服务全过程，不断筑牢保密安全防线，为学院高质量发展提供坚实安全保障。
