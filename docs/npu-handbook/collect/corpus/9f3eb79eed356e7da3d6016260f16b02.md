# 保卫处联合交警碑林大队开展校园交通秩序整顿活动

3月12日，受保卫处邀约，交警碑林大队副大队长刘勇带队，来我校调研校园交通秩序情况。保卫处朱建军处长、后勤集团副总经理霍国元、友谊校区安全保卫办主任王晓军参加会谈。
会上，保卫处介绍了校园交通秩序特别是校门附近道路交通秩序情况、校园消防通道停放车辆治理的情况，以及两轮非机动车危险行驶等问题，特别邀请碑林交警对校园交通秩序治理给予帮助和指导。刘勇表达了互相配合搞好校园内外交通秩序的良好愿望，双方商定自3月15日开始，积极开展校园及周边交通秩序整治活动，重点整治占用消防通道停车、校内道路超速行驶、非机动车驾乘人员不戴头盔等违法违规行为。
为进一步推进“一盔一带”安全守护行动，提升摩托车、电动车骑乘人员和汽车驾乘人员安全防护水平，3月15日早上，保卫处联合交警碑林大队在友谊校区开展“一盔一带”交通安全宣传活动。
保卫处工作人员和交警主要在友谊校区东门、西门、南门、中小幼门口等处开展教育宣传，通过悬挂宣传横幅、发放宣传资料、面对面讲解等方式，向师生和学生家长们讲解了驾乘摩托车、电动车佩戴安全头盔以及驾乘车系好安全带的重要性，倡导大家提高交通安全意识、法律意识、文明意识，摒弃交通陋习，做到文明、安全出行。
此次活动，增强了摩托车和电动车驾乘人员佩戴安全头盔、汽车驾乘人员使用安全带的意识，同时也提升了校园周边整体交通环境，营造了安全有序、文明和谐的校园交通环境。
