# 校园开放日｜首席科学家黄维院士现场答疑服务广大考生家长

6月26日，西北工业大学校园开放日暨一流大学高招咨询会顺利举办，柔性电子研究院携柔性电子学专业精彩亮相，为广大考生及家长提供精准志愿填报指导与专业解读服务。首席科学家黄维院士亲临现场，与考生、家长面对面交流答疑；研究院领导班子全体成员值守一线，联合优秀青年教师组成专业答疑团队，通过学科宣讲、一对一现场咨询等形式，全方位展示柔性电子学专业办学特色与人才培养成果，为考生科学填报志愿提供权威参考。

咨询会现场人气高涨、交流热烈。针对考生及家长普遍关注的专业优势、培养方案、师资力量、科创平台、升学就业等核心问题，研究院骨干教师开展专题宣讲，深入解读柔性电子学专业发展前景、应用领域及人才培养特色，清晰展现这一前沿交叉专业的独特优势与发展机遇，帮助到场人员全面认识专业价值与报考前景。

黄维院士紧扣行业发展趋势，用通俗易懂的语言，详细解读柔性电子学专业定位、培养模式，耐心回应志愿填报策略、专业选择逻辑、在校发展路径等热点问题。院领导与青年教师同步开展分组答疑，精准解答招生政策、专业学习、实践实训、深造渠道等具体疑问，并结合考生分数、兴趣特长、职业规划等实际情况，量身定制个性化报考建议与学业规划方案。

此次校级高招咨询活动，搭建起学校、专业与考生家庭的高效沟通桥梁，充分彰显了柔性电子研究院的办学实力与育人初心。未来，研究院将持续深耕柔性电子学专业建设，不断完善交叉学科人才培养体系，稳步提升人才培养质量。
