# 【关工委工作】“五老”宣讲团开展集体备课会

4月30日上午，“五老”宣讲团集体备课会在健翔楼五楼多功能厅举办。校关工委主任陈建有，委员黄迪民、王友明，党委宣传部副部长王丽，党委教师工作部副部长林楠，党委学生工作部副部长管峻，马克思主义学院副院长贺苗，团委副书记刘辰一，校关工委秘书长赵洪章、副秘书长马俊以及30余位银发宣讲员参加会议。会议由马俊主持。
备课会上，“银发宣讲员”代表分别作了精彩分享。李华星结合自身宣讲实践，生动阐述了宣讲艺术与方法，强调以真情实感打动听众，提升宣讲的感染力。支希哲围绕课程思政融入主题，分享了如何在专业教学中自然渗透价值引领，实现润物无声的育人效果。王友明从语言表达、案例选取、互动设计等方面入手，就提升宣讲吸引力的路径分享了宝贵经验。鲁卫平以陈士橹院士精神为主线，系统展示了如何围绕典型人物展开宣讲的思路与方法，为人物故事的生动呈现提供了有益借鉴。黄迪民则聚焦西工大几位具有典型代表性的老前辈，深情讲述了他们的奋斗事迹，为宣讲注入了感人至深的精神力量。
贺苗谈到，大中小学思政一体化建设工作，需要各位老前辈在教学衔接、内容贯通等方面给予支持与指导，共同落实好思政育人的新要求。王丽提出，学校统筹推进理论宣讲工作，建强理论宣讲骨干队伍，鼓励老同志将生动故事转化为短视频等新媒体形式，扩大传播影响力。林楠介绍了当前新进青年教师成长发展的培育路径，希望老同志在加强青年教师对校史校情了解、提升教学科研能力等方面发挥传帮带作用，助力青年教师成长。管峻介绍了“总师型”人才培养的实践育人体系，表示将做好桥梁纽带，邀请“五老”走进学生课堂和社区，推动宣讲覆盖更广、效果更实。刘辰一谈到，校团委将持续推进与“五老”的合作，通过团学联建、集体备课等多种形式，推动老青传承，为团学工作注入新的活力。
陈建有向长期奉献在宣讲一线的银发宣讲员们致以敬意，并对各职能部门的支持表示感谢。他分享了自己宣讲的心得，围绕校史校情、三航成就、总师育人文化等主题，介绍了宣讲内容与框架，强调在宣讲过程中要把握“三力”，即注重吸引力、感染力和说服力；通过提问、研讨等方式激发学生思考；通过言传身教实现对学生的价值塑造。
此次集体备课会既展现了老同志们深耕育人的情怀与智慧，也促进了各部门之间的协同联动，为提升学校思政育人实效注入了新的动力。
