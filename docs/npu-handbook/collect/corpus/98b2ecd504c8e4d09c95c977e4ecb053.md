# 网络空间安全学院举办教师教学能力提升暨集体备课培训交流会

为切实提升青年教师教学能力与实战化人才培养水平，2026年4月27日，网络空间安全学院在友谊校区国二会议室成功举办教师教学能力提升暨集体备课活动。本次活动特邀教育部网络空间安全教指委秘书长、北京电子科技学院原副校长封化民教授作专题报告。学院教师齐聚一堂，共同探讨新形势下的网安人才培养改革与教学创新路径。
学院副院长刘志强回顾了学院自2019年正式启动以来的发展历程，并对封化民教授长期以来对学院在人才培养各关键节点给予的支持表示衷心感谢。作为学院面向青年教师开展的系列活动的重要一环，本次活动旨在搭建高端交流平台，为青年教师备战全国高校教学创新大赛及日常教学注入新动能。
封化民教授结合当前复杂的国际网络空间态势，深入剖析了网安人才培养面临的新挑战。他系统性地阐述了中央网信办与教育部强调的育人理念，强调要坚持政治引领与能力导向，厚植国防基因与法治思维；要构建能力导向的认证体系，从知识图谱向能力画像转变，强化实践与攻防兼备；要推进产教融合，将教学延伸至企业及实网环境，引入真实流量开展教学；要注重兴趣教学，通过先实践后理论的翻转模式及AI协同式教材，激发学生内生动力。同时，他鼓励教师们增强课堂的互动性，利用大模型实现个性化教案生成；提升教学的灵活性，打破章节依赖，让学生在项目中反推理论知识；紧扣技术的动态性，结合开源资源与行业标准实时更新教材；强化知识的适应性，以项目驱动贴合岗位需求，防止网安人才培养与职场脱节，真正培养出网络强国的建设者和守护者。
针对现场青年教师提出的困惑，封教授与参会教师展开了深度互动。面对认知域安全无现成教材的难题，封教授建议设立新技术讲座留白空间，将科研解决方案转化为教学资源，重在培养学生安全融合的思维。关于教材编写滞后于技术迭代的问题，他介绍了目前出版界正在探索的AI赋能新形态教材模式，鼓励教师输入讲义，利用AI自动对齐更新，同时注重版权保护。在网安一流课程建设方面，除了打磨教案技巧，更应看重教学实效，尤其是学生在竞赛、项目中解决实际问题的能力。此外，封教授特别强调，在人才培养上不要盲目追逐社会热点，应充分发挥本校三航与自动化等特色学科优势，重点关注无人机系统安全、卫星互联网安全、太空算力安全等高价值领域，实现“安全+行业”的特色发展。
本次培训不仅帮助与会教师看清了AI赋能教育的必然趋势，更缓解了对新技术的焦虑感，明确了从单纯写代码转向综合攻防创新的教学改革路径。下一步，学院将继续深化教育评价改革，将培训成果转化为日常教学质量，在提升学生政治素质与技术能力的基础上，持续提高网安人才培养质量。
