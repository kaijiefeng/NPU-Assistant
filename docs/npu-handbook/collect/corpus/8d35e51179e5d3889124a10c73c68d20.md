# 关于拟授予赵罡等183人博士学位的公示-西北工业大学研究生院

经西北工业大学第十届校学位评定委员会第十六次会议审议并投票表决同意授予赵罡等183人博士学位，现将名单予以公示，公示期为2023年4月4日至2023年5月3日。如对拟授予博士学位人员有异议者，请在公示期限内将有关书面材料扫描后交西北工业大学研究生院学位办公室邮箱（xwb@nwpu.edu.cn）。公示期满无异议者可获得博士学位。
另外，已公示名单中的所有人员，即日起均可在自助打印机上打印其博士学位公示证明。
