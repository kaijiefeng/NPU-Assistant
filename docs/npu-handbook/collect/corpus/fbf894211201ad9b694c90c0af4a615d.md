# 化学与化工学院开展2026届研究生毕业生“工大最后一课”毕业教育

为深化毕业生思想引领，厚植家国情怀与爱校荣校精神，引导毕业生明晰人生方向、勇担时代使命，以昂扬姿态开启人生新征程，3月30日上午，化学与化工学院党委书记傅茂森在学院报告厅为2026届研究生毕业生讲授了“工大最后一课”。学院党委副书记姚东东、辅导员潘富平及2026届研究生毕业生参加。
傅茂森以“怀报国之心、守学科使命、赴时代征程”为主题，紧扣时代发展与学科特色，从三个维度展开讲授。他立足国家战略需求，深刻阐释基础学科人才培养导向，勉励同学们把握时代脉搏，践行基础学科使命担当，扎根专业领域深耕不辍；着眼多元发展路径，引导毕业生精准定位、精进专业素养，锤炼干事创业的硬核实力；传承“公诚勇毅”校训和“三实一新”校风，弘扬总师育人文化，汲取前辈学者的治学智慧与报国情怀，以初心赴使命，向着星辰大海的壮阔征程奋勇前行。
本次课程为即将踏上新征程的全体研究生毕业生送上了临别之际的思想引领与温暖嘱托，既有思想深度，又富有情感温度，为同学们在工大的求学岁月画上一个圆满而厚重的句号。衷心祝愿每一位毕业生前程似锦、逐梦远航，以青春之姿勇担时代使命，以实干之力奔赴未来之约！
