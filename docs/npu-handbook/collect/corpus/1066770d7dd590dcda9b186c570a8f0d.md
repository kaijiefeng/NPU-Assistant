# 党委保卫部组织开展全校第三季度消防及管制类危化品安全专项检查

为深入落实上级及学校有关安全管理要求，进一步强化师生安全意识，压实安全责任，9月14日至15日，党委保卫部对两校区开展了第三季度消防及管制类危化品安全专项检查。
检查人员分消防安全检查组和管制类危化品安全检查组同步开展工作。消防安全检查组采用实地检查、业务指导的方式，深入两校区教学实验楼，对各场所消防安全责任制度落实情况、消防安全疏散通道畅通情况、消防设施设备器材配备及完好有效情况、用电安全管理情况开展检查，并就火灾隐患自查、初期火灾扑救等内容向相关人员进行业务指导。管制类危化品安全检查组采取实地查看、台账核查、现场问询交流相结合的方式，对全校涉管制类危化品管制的16个二级单位开展检查。重点关注管制类危化品出入库使用登记台账填写情况、管制类危化品分类存放落实情况、长久未使用的管制类危化品清理情况。针对检查中发现的隐患问题，检查人员现场指导并提出整改意见，对能够现场整改的问题立行立改，无法现场整改的隐患问题下发整改通知书，要求各二级单位采取有效措施限期整改，形成整改报告。
后续，党委保卫部将夯实工作责任，推进校园消防及管制类危化品安全排查整治工作，全方位织密校园安全防护网，为学校高质量发展保驾护航。
