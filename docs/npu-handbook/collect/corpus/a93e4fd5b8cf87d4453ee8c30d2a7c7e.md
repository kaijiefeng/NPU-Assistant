# 力学与土木建筑学院举办青年教师发展论坛 ——学术沙龙第三讲

2022年11月25日上午，力学与土木建筑学院青年教师发展中心组织了学术沙龙第三讲，本次特别邀请了国家杰出青年基金获得者、上海交通大学张文明教授，作题为“智能微纳表面结构动力学”的线上讲座，近60名师生通过线上或线下的方式参加了此次学术研讨活动，本次学术沙龙由青年教师发展中心主任路宽主持。
张文明教授介绍了微纳褶皱结构动力学的研究概况和最新进展，并分享了其在新型微纳米结构制造技术中的研究成果，包括：（1）微纳褶皱结构的研究背景，动态失稳基础科学问题；（2）褶皱结构形成机理与动态演化；（3）理论模型建立与试验验证；（4）表面结构形貌智能调控；（5）薄膜力学自组装技术及智能表面器件应用。参会师生纷纷围绕报告内容和相关研究方法进行了热烈地交流讨论，张文明教授就在场师生提出的问题进行了详细耐心解答。
青年教师发展中心致力于通过定期的学术沙龙活动为广大研究学者搭建科研学术交流平台，积极营造交叉、创新、融合、互鉴的学术氛围，为高层次人才培养和高水平科研成果产出提供有力支撑。
（文：余滨杉，审核：温世峰）
