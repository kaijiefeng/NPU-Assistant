# 校党委书记张云明赴广西融水调研督导定点帮扶工作并看望研支团-青春驿站-共青团西北工业大学委员会

9月23日至24日，校党委书记张云明带队赴广西柳州市融水苗族自治县调研督导定点帮扶工作。他强调，要持续扛牢中央定点帮扶政治责任，不断健全常态化精准帮扶机制，与融水勠力同心、携手共进，合力书写校地协同推进乡村全面振兴新篇章。柳州市委副书记邓婉玲，融水县委书记周峰、县长叶海峰，副校长王伶等参加相关活动。
张云明先后来到中坪村村委会、三航云栖民宿、航空航天科普基地、易地搬迁安置地等，实地察看乡村发展规划、集体经济运营、科普赋能文旅发展等情况，并深入村民家中入户走访。他强调，要立足中坪村发展实际，充分发挥西工大“三航”特色优势，推动科普研学和乡村文旅深度融合，持续壮大村集体经济，用心做好易地搬迁后续扶持工作，不断拓宽群众增收渠道，带动更多群众在家门口稳定增收致富。
在桂北中药材仓储物流中心、幸福制药公司，张云明详细了解林下经济和中药材产业发展情况。他强调，产业振兴是乡村振兴的重中之重，要立足融水优良生态资源，发挥仓储物流平台集散优势，不断强化科技赋能，依托制药企业推进精深加工，促进药材资源转化增值，做强中药材全产业链，推动林下经济提质增效。
走进融水民族高级中学，张云明听取学校办学基本情况和西工大帮扶工作情况汇报，重点询问西工大捐赠、捐建项目进展，并出席翱翔奖学金、奖教金颁奖仪式，看望第28届研究生支教团融水分队成员。他强调，要发挥学校教育科技人才优势，深化校地教育帮扶合作，持续推动优质教育资源下沉，充分发挥各类捐赠捐建项目作用，助力融水教育质量稳步提升。他勉励支教团成员珍惜一年支教时光，守初心，厚植情怀、扎根基层；精业务，潜心教学、立德树人；肯吃苦，脚踏实地、担当奉献；守底线，严守纪律、注意安全；当纽带，牵线搭桥、双向赋能，在教育帮扶和乡村振兴实践中贡献青春力量。
座谈会上，张云明代表学校向柳州市委市政府、融水县委县政府一直以来对西工大定点帮扶工作的关心、指导和支持表示感谢。他指出，定点帮扶融水是党中央赋予西工大的光荣政治任务，是践行“两个维护”的具体行动，是推进乡村全面振兴的关键抓手。要胸怀“国之大者”，深入学习贯彻习近平总书记关于“三农”工作的重要论述和对广西作出的重要指示批示精神，紧扣铸牢中华民族共同体意识这条主线，进一步找准定点帮扶主攻方向，充分发挥教育科技人才优势，以更大力度、更实举措推动融水乡村振兴工作走深走实、提质增效。要持续推动教育帮扶再提质，深化“组团式”教育帮扶，推动附属中小幼和融水各学校在课程建设、教学研究、教师培训上深度对接协同，进一步提升融水教育教学质量；发挥好翱翔奖教金、奖学金作用，激励教师潜心育人、激励学生奋勇追梦；选派更多优秀研究生支教团成员，深耕课堂教学、拓展科普阵地，把航空航天航海等科教资源带进苗山校园，激发苗乡学子科学兴趣、厚植报国志向。要持续推动产业发展再赋能，牢牢把握高质量发展首要任务，立足融水生态、中药材、民族文旅资源禀赋，持续发挥高校专家智库和校友资源优势，精准开展技术咨询、产品研发升级，助力补齐产业链短板、提升产业质效；做实做深消费帮扶，培育本土电商人才、壮大线上销售矩阵，构建可持续的产销帮扶体系，带动群众稳定增收；围绕融水文旅资源，推动景区品质提升、精品线路串联和特色品牌塑造，以点串线、以线带面，进一步推动融水文旅产业融合发展、提档升级。要持续推动人才振兴再蓄力，发挥西工大优势，精准对接融水人才发展需求，助力融水实现人才振兴；聚焦融水人才培育，常态化搭建校地研修实训平台，分层分类开展基层干部、技术人才、乡村振兴带头人专项培训，充盈乡村人才蓄水池；坚持选派骨干力量扎根一线，深度参与基层治理、产业发展、民生服务，以实干担当做实定点帮扶、赋能苗山振兴。挂职干部要珍惜在融水锻炼的难得机会，牢固树立、深入践行正确政绩观，知责于心、担责于身、履责于行，真正沉下心、扑下身，多进农家门、多坐农家院、多聊家常话，把工作做细做实，让农民群众切实感受党的温暖。
座谈会上还举行了翱翔奖学金、奖教金暨支持融水县教育教学质量提升行动捐赠仪式。
学校党政办公室、工会、团委等相关单位负责人参加调研。
