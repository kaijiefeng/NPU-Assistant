# 【简历指导】网络应聘 简历要有针对性

金三月银四月，高校毕业生求职的黄金季节即将到来。2013年全国高校毕业生春季网络招聘月将于3月1日开启，专家提醒毕业生网上求职时要准确理解各用人单位的招聘信息，有针对性地“打磨”简历，切忌一份简历用到底。
记者今日从有关部门获悉，本次网络招聘月活动由人力资源社会保障部主办，活动期间，我省各大高校毕业生可登录全国招聘信息公共服务网、中国就业网、中国国家人才网共等网站了解详细的招聘信息，进行网络应聘。
海南师范大学就业指导中心负责人陶海生表示，网络应聘由于其经济、快捷、不受地域限制，已成为当代大学生选择较为普遍的一种求职方式。与实地应聘还可口头补充表达不同，网络应聘完全依靠文字表达，所以，包含求职者全部应聘信息的简历显得格外重要。“但实际情况是，不少大学生在求职时就只做了一份电子简历，无论什么招聘单位都是投这一份简历，信息模糊、缺乏针对性，效果并不好。”陶海生说。
陶海生建议，要提高网络应聘的成功率，首先就得要准确理解招聘单位发布的信息，分析其岗位、能力要求等与自己的职业方向和现有条件是否相吻合。一旦确定要应聘某个单位，一定要仔细打磨自己的电子简历，更多突出应聘者与岗位的匹配性，做到“投其所好”。
“很多大学生在简历中对自己的能力习惯用概括性的句子，比如沟通能力强、专业能力强，但缺乏事例和实践的支撑，显得又大有空，反而容易使招聘者反感。”陶海生建议，大学生写简历时最好多用事实性的陈述。比如，说明自己沟通能力强，就举出自己在什么时候参加了哪些相关活动，取得效果怎样，让招聘者在实践活动中看到应聘者的能力。“在众多竞争者中，要使自己的简历脱颖而出，你才有走到下一环节的机会。”陶海生这样对求职的毕业生说。
