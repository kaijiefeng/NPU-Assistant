# 学校收到教育部学位与研究生教育发展中心感谢信

近日，教育部学位与研究生教育发展中心向学校发来感谢信，对我校在“卓越工程师培养改革五年实践成果申请学位展示”中的工作表示衷心感谢。
9月28日至29日，“卓越工程师培养改革五年实践成果申请学位展示”在京举办，系统呈现了实践成果改革制度的创新突破与落地成效。感谢信指出，我校推荐的实践成果精彩亮相，既是卓越工程师培养改革的生动缩影，也为全国层面推进实践成果申请学位改革提供了鲜活的实践样本，彰显了学校深化改革的实践成效与先行示范价值。
备展期间，学院高度重视，高标准完成申请学位实践成果推荐、参展素材报送与打磨工作；在展品优化、内容校核、展示落地等关键环节选派专人全程对接。我校推荐的6项学生专业实践成果参展，其中2026届工程博士孟德君的实践成果“基于几何偏差的航空压气机气动性能不确定性量化及鲁棒性设计研究”入选全国优秀实践成果。
西北工业大学是全国首批牵头建设国家卓越工程师学院的10所高校之一，以“总师育人文化”为引领，在全国率先出台以实践成果申请学位的制度文件，35名毕业生依托重大工程实践成果获授学位；6个校企协同育人基地获评国家级重大案例基地，2项实践成果入选全国优秀实践成果，1个导师组获评全国卓越工程师培养优秀校企导师组。
下一步，学院将持续深化以实践成果申请学位改革实践，巩固改革成效，凝练更多育人经验和标志性成果，为培养造就大批卓越工程师作出更大贡献。
