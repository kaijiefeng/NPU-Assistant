# 牢记“国之大者” 当好秦岭卫士 ——西北工业大学电子信息学院教职工代表赴牛背梁开展实践研学

11月7日，西北工业大学电子信息学院组织教职工代表赴牛背梁国家级自然保护区、柞水县金米村，开展“牢记‘国之大者’，当好秦岭卫士”实践研学。活动循着习近平总书记来陕考察足迹，把学习课堂搬到秦岭生态保护一线，引导教职工在重温殷殷嘱托中强化使命担当、凝聚干事创业力量。
在月亮垭观景台现场教学点，大家重温习近平总书记来陕考察重要讲话重要指示精神，深刻领悟“国之大者”的丰富内涵和实践要求，进一步认识秦岭作为我国重要生态安全屏障和“中央水塔”的战略地位，并结合秦岭违建“大教训”开展警示教育。大家表示，“国之大者”关乎国家富强、民族振兴、人民幸福，必须始终胸怀大局、把握大势、着眼大事，把服务国家战略和人民需求作为根本价值追求。要自觉讲政治，把严明政治纪律和政治规矩摆在更加突出位置，听党话、感党恩、跟党走，始终在思想上政治上行动上同党中央保持高度一致，立足岗位履职尽责、担当作为。
在羚牛谷现场教学点，大家实地感悟牛背梁生态保护与绿色发展融合的实践成果，加深对“绿水青山就是金山银山”理念的理解，进一步认识到必须完整、准确、全面贯彻新发展理念，多做打基础、利长远、惠民生的实事，坚决反对脱离实际的“形象工程”“政绩工程”。
下午，教职工代表来到柞水县金米村，了解当地因地制宜发展木耳产业、完善联农带农机制、促进群众持续稳定增收的实践。结合“小木耳、大产业”的生动案例，大家深刻体会到，推动发展必须尊重规律、久久为功，让发展成果实实在在惠及群众。对高校教育科技工作者而言，就是要坚持立德树人根本任务，面向国家战略需求开展有组织科研，甘坐冷板凳、敢啃硬骨头，把论文写在祖国的大地上，把科研成果应用在全面建设社会主义现代化国家的伟大事业中。
电子信息学院将以此次活动为契机，牢记“国之大者”，自觉把学习教育成效转化为实际行动，巩固拓展树立和践行正确政绩观学习教育成果，把正确政绩观落实到人才培养、有组织科研、师资队伍建设和学科建设各环节，力戒急功近利，强化实干担当，为奋力谱写中国特色世界一流大学建设新篇章贡献电子信息学院力量。
