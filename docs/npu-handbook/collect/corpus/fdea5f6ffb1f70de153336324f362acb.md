# 计划财务部赴力学与交通运载工程学院开展专题宣讲活动

为切实提升科研经费使用效益与管理水平，根据学校年度财务重点工作安排，11月6日下午，计划财务部副部长张鹏带队，一行6人赴力学与交通运载工程学院进行财务政策专题宣讲。学院书记巨维博出席并主持会议，学院教师代表及科研助理等30余人参加交流。
巨维博强调，科研经费管理必须严格遵循“合规性、合理性、相关性、真实性”原则，号召全体教师科学规划、规范使用科研经费，严守中央八项规定精神，持续强化经费监管意识。同时，对计划财务部长期以来对学院财务工作的支持与指导表示感谢。
宣讲环节，张鹏紧密结合国家财经法规与学校规章制度，重点强调了坚守财经纪律底线的重要性，宣读了十项基本财经纪律要求，引导教师们增强规矩意识，筑牢风险防范思想堤坝。随后，招标与设备采购中心王小宁就合同线上签订流程、招投标注意事项及风险点展开细致讲解。科研管理科杜仙怡结合最新政策，深入解析科研项目预算编制要点、项目决算流程与结题注意事项等教师关注的热点内容。会计核算中心付娆则系统梳理了日常报销中的常见问题，并现场演示了无纸化报销操作流程。整场宣讲内容翔实、案例生动，有效增强了教师的财务规范意识与风险防控能力。
与会师生围绕科研合同审批、经费报销流程、发票审核规范等问题踊跃提问，现场交流热烈、氛围融洽。参会教师普遍表示，本次宣讲贴近实际、指导性强，切实解决了科研经费使用过程中的诸多困惑。
下一步，计划财务部将继续深入开展政策宣贯，构建“线上+线下”宣讲、“财务联系人咨询”的多维服务体系，完善“制度-服务-监管”三位一体的现代财务治理体系，持续创新服务模式，优化服务流程，提升服务质量，努力为学校各项事业的蓬勃发展提供更加坚实的财务保障。
