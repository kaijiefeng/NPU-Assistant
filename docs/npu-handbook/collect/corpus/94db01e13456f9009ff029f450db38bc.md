# 材料锻造成形数字孪生关键技术与集成应用”国家级重大项目启动筹备会圆满召开

2月23日，“材料锻造成形数字孪生关键技术与集成应用”国家级重大项目启动筹备会暨重庆企业考察会议在重庆三航新材料技术研究院有限公司（以下简称“三航”）召开，项目负责人、产责单位负责人、各子课题负责人及项目骨干参会，项目首席科学家付华栋教授主持会议。
首先，付华栋教授简要介绍了本次会议的背景并重点强调了会议讨论的核心议题。西北工业大学重庆科创中心副主任、三航总经理唐斌表示，三航对本项目的参研单位保持开放，将积极参与项目的实施工作，共同推进项目开展和关键技术突破。
随后，子课题负责人针对各自的课题研究目标、研究内容和规划、考核指标及前期工作进展进行了介绍。参会成员就汇报内容进行了热烈讨论，形成了重要会议结论，为项目后续实施提供了科学指导。
会后，项目组成员参观了630t等温压机设备与重庆两航金属材料有限公司生产线。
