# 因公短期赴港澳办理流程

为保证申请人顺利办理手续，请至少提前1个半月提出申请。请各位教师在收到邀请信后，尽快到校港澳台办公室办理相关手续。

## 一、校内审批

翱翔门户—外事系统—我的外事—教职工因公临时出国（境）填写审批表—短信通知批件办理完成。

注意事项：

1. 邀请信及中文翻译件：邀请信需明确出访人姓名、出访时间、出访地点、出访事由、工作内容和目的、费用来源；需有邀请单位抬头并有邀请人亲笔签名；邀请信必须从香港或澳门本土发出；可先用正式邀请信扫描件办理审批手续，原件或传真件随后邮寄用于签证申请。

2. 严格按照已批准方案执行任务，严禁擅自延长在港澳停留时间，严禁私自更改路线。

3. 线下办理步骤（2024年起全部转为线上办理）：填写《出国（境）安全保密承诺书》（在保密处网站下载），本人签字并提交所在单位；填写《西北工业大学因公临时出国（境）公示》并发送至国际合作处 jiaoshichuguo@nwpu.edu.cn；填写《西北工业大学因公临时出国（境）任务和预算审批表》，本人签字后由所在单位主要负责人审批并加盖公章，连同附件材料（日程表、邀请信原件、邀请信翻译件）交港澳台办公室审核。审批完成后办理任务批件和政审批件，接到电话通知办理护签手续。

## 二、办理因公港澳通行证及签注（30—40个工作日）

1. 收到短信通知批件办理完成后，按相关说明准备材料即可；根据2024年最新要求，不再需要提交纸质材料。
2. 收到邮件通知办理完毕后到工信部外事服务中心业务二室领取因公赴港澳通行证。

注意事项：按照团组办理港澳通行证，材料齐全后方可寄送。

## 三、返校总结

1. 外事系统提交回国总结，进入出访总结待办事项下载并填写附件1—3：附件1《西北工业大学出国（境）项目总结表》直接上传，附件2—3《实际日程安排》《因公临时出国（境）团组执行中央八项规定及其实施细则精神报告表》打印签字后上传电子版，纸质版提交国际合作处。

2. 持以下材料至毅字楼723交还护照：行后回访回执；任务批件原件；实际出访日程（全部出访人签字）；《因公临时出国（境）团组执行中央八项规定及其实施细则精神报告表》。

注意事项：如因故未能出访也应及时归还因公赴港澳通行证；请自行留存通行证首页、签注页和出入境记录页复印件或扫描件以便报销；持任务批件原件、证照交还证明、通行证首页复印件、签注页复印件、出入境记录页复印件及相关票据到财务处报销；出国（境）费用报销不能分次办理。
