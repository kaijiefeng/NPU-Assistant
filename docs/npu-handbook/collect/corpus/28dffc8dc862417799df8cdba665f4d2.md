# 基础科研能力培训｜“卓越表达力”（第一期）预告

活动简介：
“卓越表达力”是国家卓越工程师学院重点打造的学术赋能品牌活动之一，是“卓越大讲堂”品牌在实践育人环节的重要深化。该活动旨在系统性地强化学生的科研表达与学术沟通能力，为卓越工程师创新能力的展现与价值转化提供关键支撑。
当前，学生在学术论文撰写、项目汇报展示、专利申请表达等关键环节中，普遍存在逻辑结构不清、视觉呈现薄弱、语言组织不够精准等问题，制约了科研成果的有效传播与专业影响力。为此，活动聚焦科研绘图、PPT演示、学术写作等核心表达能力，开设系列化、模块化专题课程，引导学生将复杂研究成果转化为条理清晰、逻辑严谨、具有专业说服力的视觉呈现与书面表达，从而在学术交流、项目申报、成果展示等实际场景中更加精准、高效地传递专业价值。
本活动由多部门协同组织、联合推动，整合优质教学资源与行业专家力量，致力于通过专业化训练，全面提升学生在未来科研道路与职业发展中的核心竞争力。
