# “与君初相识，犹如故人归”—

为创新学科服务模式，支持各单位科研教学工作，帮助学生更好地了解和运用图书馆各项服务和功能，5月10日16:00，西北工业大学图书馆信息咨询与发展研究部刘钊来到伦敦玛丽女王大学工程学院，为2017级同学们带来了一场内容丰富的讲座。本次讲座由图书馆和玛丽女王工程学院共同举办，在学院410报告厅举行。

刘钊以“图书馆与QMES的初相识”为主题，为同学们简要说明了图书馆的各服务部门，全面介绍了图书馆的数字资源类型、特点及其功能，并详细讲解了如何利用图书馆提供的信息，例如如何借阅下载中外文纸质、电子资源，如何荐购所需书籍，以及如何预约研修室等。

在讲座结尾，刘钊宣读了学院借阅书籍累计排名前十位的学生名单，为前五位的同学颁发了奖品，并鼓励同学们更多更好地运用图书馆提供的资源，提升学习能力、树立科研意识，为今后的学术研究奠定基础。

本次讲座是图书馆走进玛丽女王工程学院“创新学科服务，共建一流学院”系列讲座的第一期，学院今后会加强与图书馆等教学支撑单位的合作交流，帮助学院师生更好地利用学校资源，提升办学水平。
