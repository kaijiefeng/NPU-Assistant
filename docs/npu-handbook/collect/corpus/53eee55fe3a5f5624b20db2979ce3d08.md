# 党委保卫部开展2026年全民国家安全教育日培训活动

为深入贯彻落实总体国家安全观，严格落实学校党委关于加强校园国家安全教育、筑牢意识形态安全防线的工作部署，引导广大师生切实增强国家安全意识，在第11个全民国家安全教育日来临之际，党委保卫部组织开展2026年全民国家安全教育日培训活动。
本次培训活动精准聚焦校园安全需求，分为政治安全教育培训和安保反恐防暴应急处置技能培训两大板块，针对性解决不同群体的安全能力提升痛点，确保培训内容务实、形式高效、成效显著。
4月9日，党委保卫部联合党委统战部、材料学院、机电学院，特别邀请原西安市公安局警察训练支队三级警监、二级高级警长高振国在友谊校区开展政治安全教育专题讲座。
讲座中，高振国以《树立政治安全意识，建设平安校园，无悔大学时代》为题，从意识形态安全防范、校园社团规范发展、宗教与邪教渗透抵御、校园网络安全防护等多个维度，结合典型真实案例，全面深入剖析当前我国国家安全面临的新形势、新挑战，生动解读维护国家安全的重大意义，明确大学生在维护国家安全中的责任与义务。整场讲座内容详实、案例鲜活，使在场学生深刻认识到国家安全与自身学习生活的紧密联系，有效提升了学生的安全防范意识和责任担当。
讲座尾声，师生们以热烈的掌声感谢高振国同志的精彩授课，大家纷纷表示，将以此次讲座为契机，把国家安全意识内化于心、外化于行，转化为日常学习科研过程中的行动自觉，主动担当起维护国家安全的青年责任。
为进一步强化校园安全保障能力，提升校卫队员应急处置实战水平，4月7日至8日，党委保卫部分别在两校区同步开展反恐防暴应急处置技能培训。本次技能培训由碑林分局巡特警大队民警宣博文、卢昆仑担任授课教官，两位教官紧密结合校园安全工作实际，采取“理论讲解+实战演示+现场实操”的方式，向参训校卫队员系统传授反恐防暴相关知识和应急处置技能。
参训队员严格遵守培训要求，在教官的专业指导下认真学习、积极参与演练，切实提升了自身应急处突能力。
此次全民国家安全教育日培训活动，既强化了青年学生的国家安全意识和政治素养，又提升了校卫队员的应急处置实战能力，进一步夯实了“师生共学、全员共建、全域共防”的校园安全防护格局。
近年来，党委保卫部始终坚持将安全教育融入校园日常管理，通过技能培训、主题宣传、案例警示等多种形式，持续提升师生安全意识和防范能力。下一步，党委保卫部将常态化开展安全宣传教育和应急技能培训，不断筑牢校园安全工作基础，健全校园安全防控体系，切实守护师生生命财产安全，为学校高质量发展营造安全稳定的良好环境。
