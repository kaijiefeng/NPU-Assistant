# 自动化学院-西北工业大学医院

责任医师：程飞（副主任医师）
简介：
医学硕士，外科副主任医师，1997年毕业于西安交通大学医学院临床医学系，长期从事外科门急诊及临床工作24年，期间在西安交通大学医学院攻读肿瘤学并获医学硕士学位，擅长普通外科常见病及急症的诊治，尤其对于常见肿瘤进行包括手术为主的规范化治疗，曾在《中国普通外科杂志》《陕西肿瘤医学》等发表论文10余篇，现为中华医学会外科会员，陕西省保健协会消化道疾病微创外科会员。
（备注：学院责任医师是医院与学院之间的桥梁，可为我校师生提供健康咨询、健康宣教、体检结果释疑、急救知识技能培训等服务。有需求者，可通过扫描学院责任医师二维码联系。）
