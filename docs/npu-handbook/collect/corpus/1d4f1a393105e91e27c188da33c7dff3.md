# 公共政策与管理学院召开教职工大会

7月13日上午，公共政策与管理学院教职工大会在长安校区学院楼104报告厅举行。学院领导班子、全体教职工参会，会议由学院分工会主席毛加强主持。
会上，学院副院长李娜、原嫄，党委副书记谢丹及院长助理席建成分别围绕本学期研究生培养、本科生培养、学生工作及科学研究工作开展情况进行总结，并结合学院发展目标安排部署下一步重点工作。
院长刘晨光结合学院发展面临的新形势、新任务、新考验，紧扣“树立和践行正确政绩观 推动公管院高质量发展”的主题，全面总结了学院在“十四五”奋进征程上取得的成果，重点剖析了当前学院发展存在的短板与不足，深入解读了学院“十五五”发展规划核心指标体系。要求全院教职工要聚焦学科建设与师资队伍建设两个关键问题，以实干实绩推动学院实现高质量发展。同时，他还通报了近期学院工作出现的若干风险点，要求完善相应风险应对举措，落实举一反三，确保各项工作平稳开展。
学院党委书记管兴华开展了师德师风及学术不端警示教育，要求全体教职工始终牢记为党育人、为国育才的初心使命，持续弘扬教育家精神，坚守学术诚信。随后，管兴华通报了教职工借调、挂职管理规范，并部署了暑期安全稳定各项工作。
