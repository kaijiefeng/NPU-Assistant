# 西北工业大学与德国品牌应用科学大学合作举办工业设计专业硕士研究生教育项目2024年度报告公示

根据教育部《中华人民共和国中外合作办学条例》及《关于提交2024年度中外合作办学报告的通知》的要求，现将西北工业大学与德国品牌应用科学大学合作举办工业设计专业硕士研究生教育项目2024年度报告进行网上公示。
公示期为2026年5月6日至2026年5月12日。公示期间若有异议，请与西北工业大学与德国品牌应用科学大学合作举办工业设计专业硕士研究生教育项目联系。
联系电话：029-89287963
