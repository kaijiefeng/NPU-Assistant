# 民航学院举办2025-2026学年春季学期主讲教师资格认定试讲

为夯实师资队伍建设根基，优化教师队伍结构，提升新进青年教师授课与育人水平，保障教学质量，学院于6月17日上午在毅字楼205会议室开展2025-2026学年春季学期主讲教师资格认证试讲，邀请学院教学督导邓琼、殷之平、宋东三位老师担任评委，对新进教师试讲进行评审与指导。
本次参与认定的新进教师围绕授课内容，结合课程培养目标，从教学目标设定、教学内容梳理等多个环节展开试讲，授课过程中思路清晰、节奏得当，灵活运用多种方式展现教学设计与个人风采，体现了青年教师积极进取的面貌。试讲结束后，三位评委对每位新进教师的表现逐一点评，他们结合课堂实际与学生视角，针对教学设计、授课表达等多个方面指出不足，并给出针对性的改进建议，帮助青年教师理清思路，补齐短板。
此次试讲活动为新进青年教师搭建了专业学习交流提升的平台，有效帮助新进教师夯实教学基础，掌握核心教学技能，强化育人责任意识。下一步，学院将常态化开展教师教学能力提升活动，多措并举打磨优质课堂，持续筑牢教学根基，打造高素质专业化师资队伍，推动学院教育教学高质量发展。
