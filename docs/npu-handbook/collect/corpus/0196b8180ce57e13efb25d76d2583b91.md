# 市级重大专项将获超1000万元资金支持 重庆发布支持软信产业创新三项举措

科技创新如何为重庆软件和信息服务业高质量发展提供核心支撑？在12月30日举行的《重庆市进一步推进软件和信息服务业“满天星”行动计划实施方案》政策例行吹风会上，市科技局党委委员、副局长王伟介绍了重庆以高水平科技创新赋能产业发展的具体路径。
▲市科技局党委委员、副局长王伟答记者问。 记者 罗斌 摄/视觉重庆
近年来，我市聚焦“416”科技创新布局与“33618”现代制造业集群体系建设，持续强化软信领域科技攻关，累计布局实施核心软件重大科技专项20余项，在汽车智驾软件、工业软件、低空飞行软件等关键领域取得积极进展，涌现出“天枢智能”“魔方平台”等一批标志性成果。
面向新一轮行动计划，市科技局将从关键技术攻关、创新平台搭建、创新生态营造等方面系统发力，重点抓好以下三方面工作，全面支撑“满天星”行动高质量发展。
我市将抓好重大（重点）科技专项实施，着力突破一批产业关键技术。尤其是聚焦智能体、工业软件、汽车软件等领域关键技术，构建“原始创新+前沿颠覆性技术研究+关键核心技术攻坚”的研发创新体系，支持我市企业、高校和科研院所等各类创新主体申报国家重点研发计划项目和市级科技项目。比如市级重大专项，每个项目给予财政支持资金超过1000万元，加大软件和信息服务业技术研发投入和攻关力度，推动科技创新和产业创新深度融合。
在平台建设方面，重庆将着力打造高能级产业创新平台，全面提升科技创新能力。其中，支持建设软件和信息服务业研发创新力量，布局打造服务软件和信息服务业科技攻关、成果转化的重庆市重点实验室、川渝共建实验室、高水平科技型企业孵化器等创新平台，加快建设重庆通用人工智能研究院、嘉陵江实验室等一批高端研发机构，汇聚“产、学、研、用”多方要素，形成软件和信息服务业高能级产业创新体系。
我市将持续抓好创新生态营造，促进创新链、产业链、资金链、人才链深度融合。比如，深入实施高新技术企业和科技型企业“双倍增”行动，重点培育科技领军企业，打造软件和信息服务业优质创新主体，推动形成软件和信息服务业协同创新格局；支持优秀科技人才担当重任，鼓励尽职免责担当作为，完善研发创新、成果转化、创业孵化等全周期人才服务机制等。
（来源：重庆日报）
