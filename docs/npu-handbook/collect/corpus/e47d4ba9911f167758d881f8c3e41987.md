# 习近平新时代中国特色社会主义思想概论”教研室召开学习《中国共产党思想政治工作条例》集体备课会-西北工业大学

为深入学习贯彻习近平总书记关于思想政治工作的重要论述，推动思想政治教育要求精准融入课堂教学，全面提升《习近平新时代中国特色社会主义思想概论》（以下简称《概论》）课程教学质量，马克思主义学院《概论》课程教学团队于11月24日晚召开集体备课会。会议由“习近平新时代中国特色社会主义思想概论”教研室主任宁殿霞主持。
会上，全体教师集中研读学习《中国共产党思想政治工作条例》，并围绕条例精神如何落实到课程教学全过程展开讨论。与会老师一致认为，条例的颁布为新时代学校思想政治工作的方向、原则与方法提供了根本遵循，对思政课教师提高政治站位、强化价值引领、深化课程育人具有重要指导意义。
随后，会议就本科教学档案及期末考试相关工作作出安排，全体教师应规范完成教学档案整理归档，并按期落实期末考试命题、监考与阅卷等工作，确保教学运行规范有序、考风考纪严明。
此次备课会主题突出、内容务实，既强化了政治理论学习，也明确了近期教学重点与工作要求。马克思主义学院将以本次备课会为契机，持续推进课程建设与教学改革，为培养堪当民族复兴大任的“总师型”人才持续发力。
