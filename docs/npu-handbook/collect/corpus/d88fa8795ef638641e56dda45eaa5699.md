# 后勤办公室党支部组织开展主题党日观影活动

在学校组织开展“不忘初心、牢记使命”主题教育期间，为了深入学习贯彻习近平新时代中国特色社会主义思想，教育引导党员增强爱党爱国意识，不断提升政治素质，发挥党支部政治核心和党员模范带头作用，认真做好后勤管理工作。
10月13日下午，在中影国际影城大西市店，组织全体党员集中观看了《我和我的祖国》爱国主义教育影片。该影片讲述了新中国成立70年间普通百姓与共和国息息相关的故事，故事情节感人。
通过党支部组织开展主题党日观影活动，全体党员受到了一次深刻的爱国主义教育，思想政治受到了一次深刻的洗礼。纷纷表示作为一名党员要在学校组织开展“不忘初心、牢记使命”主题教育中，坚持理想信念，以担负的使命任务为重，以服务师生为本，以良好的精神状态，勤勤恳恳干事业，扎扎实实做好本职工作。
