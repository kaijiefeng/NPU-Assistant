# 山河万里·卓越同行

为深入贯彻工程硕博士培养改革部署，持续深化产教融合、科教融汇，将立德树人根本任务贯穿卓越工程师培养全过程，立足学校 “为党育人、为国育才、为军铸才”的使命担当，国家卓越工程师学院启动“山河万里・卓越同行”访企问学系列活动，北京片区作为系列走访首站。学院党委副书记、副院长王谦，辅导员孙康瑶赴京，实地调研2025级联培学生实践成长情况，结合中秋节点走访慰问一线实践学子，传递组织关怀，引导青年学子厚植科技报国、军工报国的理想信念。
一线实践是淬炼卓越工程师的重要课堂。本次走访先后走进北京航天控制仪器研究所、中国舰船研究院、航天时代飞鸿技术有限公司，与各单位部门负责人、企业导师共同召开专题座谈。企业导师结合学生在岗实际，充分肯定同学们务实严谨的科研作风与适应重大工程任务的学习能力，同时客观指出学生在工程思维、复杂问题处置、工程化落地方面的能力短板，直面研讨双导师联动、课题动态迭代、实践过程管控等培养机制痛点，为迭代完善卓越工程师全链条培养体系提供了一线实践依据。
座谈期间，学院与学生开展面对面谈心谈话，全面掌握学生思想动态、科研进展与生活保障，调研职业发展意向，收集联合培养相关意见建议。时值中秋佳节，学院为学子送上节日祝福，勉励大家珍惜实践平台，将个人成长发展融入国防现代化建设伟大事业。同学们纷纷表达对学院牵挂关怀的感谢，结合自身科研任务汇报阶段性实践收获，表示将立足岗位潜心钻研，练就过硬本领。
访企深耕合作，协同赋能育人。校企双方围绕卓越工程师培养、人才输送、产学研协同等议题开展深入交流，达成多项共识。一是扩容联合培养合作格局，持续向各军工合作单位输送优质生源，拓展联合培养覆盖面；二是完善双导师协同育人机制，统筹校内导师与企业导师力量，健全双向定期沟通联动制度，紧扣产业重大工程需求动态优化课题设置；三是畅通人才供需渠道，对接合作单位年度人才招聘规划，搭建学生与军工单位双向交流桥梁，推动人才培养供给与行业岗位需求精准适配；四是建立常态化互访交流机制，推进科研协同攻关与产学研联动，实现资源共享、互利共赢。
以红色铸魂凝心，以文化润心育人。活动期间，孙康瑶带领部分在京实践学生走进中国共产党历史展览馆，在珍贵史料与实物展陈中回望百年峥嵘岁月，感悟初心使命、汲取精神力量。随后一行人参观中国非物质文化遗产馆，沉浸式感受中华优秀传统文化的深厚底蕴与时代活力，让学生在历史回望与文化浸润中明晰新时代青年的责任担当，进一步坚定矢志报国、笃行实干的理想信念。
作为“山河万里・卓越同行”访企问学系列活动的开篇首站，本次北京走访既是对在外联培学生的实地调研、思想摸排与暖心慰问，也是深化学院层面校企协同育人的重要实践。下一步，学院将持续推进访企问学系列活动，做实做细全院在外实践学生教育管理、思想引领与人文关怀，转化运用企业反馈与学生诉求，持续优化卓越工程师培养机制，为国防科技领域输送更多高素质人才。
