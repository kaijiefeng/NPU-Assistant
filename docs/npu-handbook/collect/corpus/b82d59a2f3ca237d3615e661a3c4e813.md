# 西北工业大学与德国品牌应用科学大学合作举办工业设计专业硕士研究生教育项目2022与2023年度报告公示

根据教育部《关于进一步加强中外合作办学监管工作的通知》〔教外司办学(2015)1588号〕、《关于进一步做好2016年中外合作办学有关工作的通知》〔教外司办学(2016)283号〕等文件要求，所有中外合作办学机构和项目须每年进行本科以上层次中外合作办学机构和项目信息年度报告。
现根据教育部要求对年度报告中的“自评报告”内容面向社会进行公示，西北工业大学与德国品牌应用科学大学合作举办工业设计专业硕士研究生教育项目2022年度和2023年度报告现公示如下，公示期为一周（2024年4月1日至2024年4月7日），公示期间若有异议，请与西北工业大学与德国品牌应用科学大学合作举办工业设计专业硕士研究生教育项目联系。
