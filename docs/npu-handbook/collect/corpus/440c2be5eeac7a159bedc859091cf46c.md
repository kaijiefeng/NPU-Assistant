# 山河万里·卓越同行 ——国家卓越工程师学院访企问学沈阳站顺利开展

为持续提升工程硕博士入企实践培养质量，推动校企协同育人走深走实，扎实推进访企拓岗促就业工作，11月2日-4日，西北工业大学国家卓越工程师学院党委副书记、副院长王谦带队，学院综合办主任戴月玲、校企合作办主任吴文宁、校企合作秘书苏比、团委书记兼辅导员孙康瑶一同参与，组织相关学生代表赴沈阳开展“山河万里・卓越同行”访企问学研学活动。团队走进国防一线重点单位，慰问已在企实践学生，同步开展红色思政研学，引导青年学子扎根产业现场、触摸国防脉搏，厚植家国情怀，坚定科技报国志向。
团队先后走访中航工业沈阳飞机工业（集团）有限公司、中国航发沈阳发动机研究所等联培单位，开展校企协同育人专题座谈，围绕课题精准对接匹配、实践过程考核评价、以及毕业生就业发展等内容深入研讨交流。联培单位介绍了相关人才引进政策、联培学生培养模式等，结合人才培养实际提出建议，鼓励更多优秀学生投身一线、留企发展，成长为担当重任的工程技术骨干。校企一致表示，将持续健全校企常态化沟通机制，畅通人才供需渠道，依托企业工程实践平台夯实卓越人才培养根基。座谈会进一步厘清了联培单位培养需求，为优化工程硕博士联合培养方案、精细设计入企实践环节提供了重要依据。
座谈会上，学院还与在沈联培学生、拟入企实践学生开展交流，细致了解同学们在岗科研学习、工程实践近况，广泛征集大家对联合培养工作的体会与意见。同学们围绕课题研究、科研培训、日常学习生活、个人成长规划逐一交流，如实反馈实践过程中遇到的难点问题。带队老师们认真倾听诉求、掌握一线实情，勉励同学们在工程实践中勤于观察思考，持续锤炼工程素养、提升解决复杂工程问题的能力。学院将持续做实做细在外实践学生的教育管理与服务保障，常态化对接学生动态，打通培养堵点，提升学生实践获得感与培养成色，推动专业知识与工程实践深度融合。
研学期间，师生一行走进沈飞航空博览园参观学习。展厅系统展现我国航空工业从无到有、由弱到强的奋进历程，集中展示多型国产战机发展成果，生动讲述罗阳同志矢志航空报国、攻坚克难的感人事迹。师生驻足观摩史料图文、装备模型，重温一代代航空人自立自强、拼搏奉献的奋斗历程，沉浸式感悟航空报国精神，对大国重器背后的使命担当有了更为深刻的领悟。
赓续红色血脉，砥砺强国初心。团队前往沈阳“九・一八”历史博物馆开展现场思政教学。翔实的文物史料全景再现东北人民奋起抗争、夺取抗战胜利的壮阔历史，带领师生回望山河蒙难的悲壮岁月，感悟中华民族不屈不挠、矢志争取民族独立与人民解放的伟大精神。同学们纷纷表示，将从先辈抗争精神中汲取奋进力量，筑牢理想信念根基，把家国情怀融入科研学习与工程实践，面向国家重大需求勇挑重担、聚力攻坚，以实干担当助力强国建设。
从武汉、贵阳、北京、上海，再到沈阳，“山河万里·卓越同行”的足迹沿着共和国航空航天事业的脉络不断延伸。本次活动融合企业走访调研、联培学生访谈、红色思政研学多重内容，为进一步密切学院与行业重点单位联动，精准把握工程实践场景、产业人才需求和学生成长痛点，持续优化校企协同育人积累了宝贵经验。
下一步，学院将做好走访成果转化，持续建强入企实践、校企双导师指导、毕业生职业发展全链条培养体系，推动卓越工程师培养与行业需求紧密衔接，为培育信念坚定、工程能力过硬、勇担强国使命的卓越工程人才贡献西工大力量。
