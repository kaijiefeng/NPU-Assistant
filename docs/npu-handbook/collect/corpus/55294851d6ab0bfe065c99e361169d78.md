# 西北工业大学博物馆藏品征集公告

西工大新闻网3月21日电（滕迪）各位校友，老师，同学，社会爱心人士：
“千仞之墙，百炼之钢；镂木铄金，飞天巡洋”。作为全国唯一一所以发展航空、航天、航海领域人才培养和科学研究为特色的研究型大学——西北工业大学，为展示“三航”学科成就，提升文化育人功能，传承弘扬“三航”科学精神，将建设一座以“三航” 为特色，科技与艺术交相辉映的高水平博物馆。
“世界眼光、中国成就、工大贡献”。博物馆将以“航空”“航天”“航海”为主题，设置“三航体验”和“未来展望”空间，集教育性、科技性、思想性、知识性、艺术性、体验性于一体，展现世界“三航”发展历程，突显我国“三航”科技成就，展示“三航人”铸大国重器的家国情怀。
“巍哉学府，辈出栋梁”。西工大人心系三航事业，胸怀报国之志，熔铸三航精神。西工大校友献身三航、科技强国的风采定是博物馆的重要组成。
“大成若缺，其用不弊；大盈若冲，其用不穷。”藏品是博物馆的生命，藏品是历史信息的载体，西工大博物馆建设需要反映三航科技与学科发展历程的展品，展品征集需要您积极参与和大力支持。
藏品征集类别包括但不限于：
一、“三航”科技产品：包括国内、外“三航”产品实物，含整机、原理性样机、实验模型，能够反映某一时期科技发展水平的“三航”产品部件、备件、试验件，具有历史意义的残件、残骸等，尤其是西工大人参与研发、设计、制造的“三航”类科技产品，以及飞行员、航天员、潜水员相关装备等。
二、“三航”科技相关资料：包括“三航”历史产品的图纸、档案资料以及研制、试验中的影像资料、照片、记录等。
三、“三航”教研类展品：如“三航”相关教材、教具、模型、动画、照片、文献资料等，以及“三航”相关实验典型设施、设备等。
四、“三航”竞赛用物品：如参加“三航”相关赛事（含科技类、体育类等）所设计制造的实物、模型、影像资料、照片、文史资料，获得的相关荣誉、获奖证书等。
五、“三航”专家的著作手稿（原稿），工作中使用过的教学、科研相关物品如工具、资料等；工作中形成的有纪念意义的教材、图纸、笔记、照片等；被题词或有重要意义的各类资料等。有关“三航”著名专家的人物故事等。
六、“三航”文宣产品：公开发行的有关于我国“三航”及西工大重大科技成果、优秀人才的文化宣传产品，如报刊、杂志、邮票、首日封、贺年卡、明信片、照片、绘画作品、纪念章等。
七、其他与“三航”有关并具有历史意义的实物、史料。
另外，为了更好地提升学校文化品位，涵养师生人文情怀，博物馆特设历史与文化展厅、艺术与设计展厅。主要从中国古代技术史出发，展现技术遗产所蕴含的科技原理和古人智慧，以及以绘画、书法、雕塑等艺术品和现代工业设计产品来呈现人类对美、艺术与生活的价值追求。以上两大主题藏品亦在征集之列。
学校将通过“收、捐、买、造、拨、借”等多种方式征集藏品。具体操作及流程按《西北工业大学博物馆藏品征集管理办法（试行）》执行。符合馆藏标准的捐赠物将成为西工大博物馆永久收藏，进入藏品目录且展出，并得到长期维护保管。
学校将为捐赠藏品的个人或单位，颁发捐赠证书、举行捐赠仪式并进行报道宣传。所有为博物馆建设做出贡献的人将成为西工大博物馆荣誉馆员。
“公诚勇毅，永矢毋忘；中华灿烂，工大无疆”。愿各位校友、师生、社会爱心人士积极参与，为母校博物馆建设贡献力量！
同时，衷心期待社会各界朋友，特别是三航企事业单位的朋友们大力支持。
