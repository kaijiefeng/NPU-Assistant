# 校内用户注册预约流程

文案：陈建源 编辑：王嘉玮 审核：刘平
大型仪器共享平台（校内版）
1.普通测试流程：
校内用户送样测试用户 校内用户自主操作用户
2.系统登录
2.1 门户登录页面暂无图片（稍后补充）
2.2. 后台登录地址：https://fcdy.nwpu.edu.cn/cf/main/
2.3. 点击统一身份认证登录
2.4 扫码或者选择其他登陆方式登录
2.5 点击仪器管理--搜索使用的设备---点击送样
2.6 点击添加
2.7 填写送样相关信息---点击保存
2.8 填写完成后状态为申请中----状态变成已批准将样品送到指定地方
2.9 样品状态变成已测试----代表样品测试完成
2.10 测试老师可将测试结果上传至辅助股中文件系统---学生可通过文件系统下载测试结果
3.预约测试
3.1 点击资源管理----仪器管理---根据条件搜索使用的仪器---点击预约
3.2 在工作时间内，下拉选择所要使用的时间
3.3 填写预约相关信息
3.4 预约成功
3.5 在预约时间段内在仪器操作电脑登录自己的账号以及客户端登陆密码
（注：新用户注册时会填写客户端密码；旧系统迁移至新系统的用户可根据《客户端密码修 改设置.docx》设置客户端密码。客户端密码可以与翱翔门户密码一致，也可以自行设置）
3.6 使用完成后点击退出
3.7 选择相应的值班老师----星级评价----点击保存
4.App 使用预约教程
4.1 app 下载
苹果手机：可在 APP Store 中搜索仪器控畅享版下载
安卓手机：部分机型可在应用商城中搜索仪器控畅享版下载（如果应用商城没有可下载应用宝程序，在应用宝中下载）
4.2 账号绑定登录---进入大型仪器共享平台
4.3 点击姓名
4.4 点击绑定 app
4.5 点击绑定 app 会出现一个二维码（如下图）
4.6 手机下载安装仪器畅享版 app 后打开
4.7 点击我已阅读并同意---然后点击网页端扫码登录
4.8 搜索查询所要使用仪器
4.9 点击预约---填写预约/送样信息
4.10. 仪器列表右上角为消息中心，可以展示仪器的预约/送样状态变更通知以及新增审批信息， 点击进入可以快速查看预约详情。
