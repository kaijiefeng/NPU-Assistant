# 校医院召开领导班子成员新学期工作研讨会-西北工业大学医院

9月5日，校医院召开领导班子成员新学期工作研讨会，会议传达学习学校2025年暑期务虚会及新学期中层干部会精神，安排部署医院新学期重点工作。会议由乔辉书记主持，领导班子成员参加会议。
会议学习了宋保维校长《优化学科专业布局推动“总师型”人才培养》、李言荣书记《关于我校“十五五”规划中的几个问题》两个专题报告，传达了学校暑期务虚会、新学期中层干部会精神，对报告中深入分析的学校发展面临的新形势和新机遇进行了探讨，进一步统一了思想、形成共识，全院上下同心协力促进医院和学校高质量发展。
医院领导班子成员乔辉、郑莉莉、何凯亮、孙伟光、郑琪、田博、石丛艳分别就上半年分管工作作总结汇报，内容包括医疗业务开展、医保新政策、医疗规范、设备引进、信息化建设、人事管理和考核、健康教育等多个方面，并在总结中对不足之处进行了反思，对新学期相关工作开展进行部署。
会议强调，医院要以学校暑期务虚会和新学期干部会为指导，结合医院工作实际，从医疗服务保障单位定位出发，在医疗服务、人才建设、信息化建设、健康教育服务及AI在医疗行业的应用等多个方面进行深度思考和研讨，将会议精神转化为具体实践，开创医院发展新格局，为学校实现“天下工大，世界三航”的宏伟愿景贡献健康力量。
责编 石丛艳
审核 乔辉
