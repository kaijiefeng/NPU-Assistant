# 党委保卫部对附中、附小、幼儿园开展消防安全专项检查

为切实做好暑期消防安全风险防控工作，有效预防和减少校园火灾事故发生。按照上级工作要求，7月6日，党委保卫部对附中、附小、幼儿园开展了消防安全专项检查。
检查组深入教学楼、餐厅、消防控制室等重点区域，对消防设施设备的配备和运行情况进行了仔细检查，重点查看了灭火器是否在有效期内、压力是否正常，消火栓的水枪、水带是否老化破损和启闭出水功能是否正常，防火卷帘是否正常升降，疏散指示标志和应急照明灯是否能正常亮起，消防设施日常维护保养是否到位。同时，检查组还就消防安全责任制度落实、日常防火巡查检查、初起火灾扑救等事项对相关管理人员进行了业务指导。
此次专项检查旨在进一步夯实相关单位消防安全管理责任，协同联动消除潜在风险隐患。暑期是消防安全防范关键时期，党委保卫部将时刻坚守安全底线，以“零容忍”态度持续强化巡查排查，为平安校园保驾护航。
