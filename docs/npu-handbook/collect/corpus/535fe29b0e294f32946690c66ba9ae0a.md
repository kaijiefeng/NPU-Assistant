# 后勤部办公室党支部传达学习习近平总书记关于西北工业大学哈萨克斯坦分校的重要指示精神

7月4日上午，后勤部办公室党支部召开党员大会，传达学习习近平总书记关于西北工业大学哈萨克斯坦分校的重要指示精神。会议由党支部副书记韩争胜主持，支部全体党员参加了会议。
会上，大家集中深入学习了习近平总书记在哈萨克斯坦媒体发表的署名文章《同心笃行续写中哈关系新篇章》和关于西北工业大学哈萨克斯坦分校的重要指示精神，传达学习了学校党委常委会（扩大）会议有关要求，并开展了交流研讨。会议认为，习近平总书记的重要指示是对中哈两国教育交流与合作的高度肯定，同时也是对西北工业大学建设与发展的殷切期望。会议要求全体党员要深刻认识到这一重要指示的重大意义，必须加强学习、深入领会，准确把握其精神实质。
接着，大家集中回顾了西北工业大学哈萨克斯坦分校的建校背景、建校过程，以及当前取得的成果等，深刻认识到，建设好哈萨克斯坦分校具有重大而深远的政治意义。全体党员深感鼓舞，对未来充满了信心和期待。同时，也进一步激发了大家爱党爱国爱校的情怀和干事创业的热情。
会议强调，全体党员要提高政治站位，以习近平总书记重要指示精神为行动指南，在新征程上，时刻以斗志昂扬的热情和踏实肯干的态度投入到后勤工作中去，为积极推动哈萨克斯坦分校建设取得新成效、开创新局面，为实现学校“127”发展目标和“天下工大、世界三航”远景目标贡献后勤力量。（撰稿人：毛淑兰；审稿人：韩争胜）
