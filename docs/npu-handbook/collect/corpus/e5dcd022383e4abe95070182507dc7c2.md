# 我中心党支部开展“不忘初心、牢记使命”主题教育调研活动

10月29日到10月31日，为贯彻落实“不忘初心、牢记使命”主题教育，支部书记李春科带领我中心党支部党员及员工，调研了中心入驻团队、北理工重庆创新中心及零壹空间。李春科书记在调研中周密部署，认真筹划，针对调研对象的具体情况、存在问题、解决措施、潜在合作等方向开展调研，按照 “深、实、细、准、效”五字要求，有序有力的推进了主题教育的调查研究工作。
10月29日，中心支部成员和员工对中心入驻的科研及产业化团队进行了调研，通过座谈交流的形式，了解了团队的发展情况和存在的问题，听取了各团队对中心各项工作的建议和意见，并提出了改进措施。30日，对北京理工大学重庆创新中心进行了调研，通过实地考察和座谈交流的形式，探讨建设思路，学习了发展经验，促进了交流合作，为重庆科创中心的发展开阔了思路。31日，实地察看了零壹空间总装厂房，了解了商业航天在重庆的发展情况，并就零壹空间的发展建设、研发投入、人才建设、资质获取、潜在合作方向等方面进行了座谈交流。
此次调研践行了习近平总书记的“求真务实”要求，李春科书记强调，要把调研成果转化为解决问题的具体行动，更好的促进科创中心的科技成果转化工作，切实助力学校“双一流”建设。
