# 多轴数控加工刀轨生成与仿真联合技术中心二期项目外协关联关系公示公告-西北工业大学

为规范科研项目管理，保障科研经费使用合规性，根据《西北工业大学科研项目外协管理办法》相关规定，现将“多轴数控加工刀轨生成与仿真联合技术中心二期项目”的外协关联关系情况公示如下：
一、项目基本信息
1. 项目负责人：方文杰
2. 所属二级单位：北京研究院
3. 项目名称：多轴数控加工刀轨生成与仿真联合技术中心二期项目
4. 外协金额：300万元
5. 外协单位：柔胜刚智能科技（苏州）有限公司、北京三航产融科技研究院有限公司、苏州舒博特智能科技有限公司
二、关联关系情况说明
经项目负责人主动申报，上述三家外协单位与学校及项目团队存在以下关联关系：
1. 柔胜刚智能科技（苏州）有限公司为项目团队主要成员持股公司；
2. 北京三航产融科技研究院有限公司是西北工业大学资产公司二级参股公司。
3. 苏州舒博特智能科技有限公司是西北工业大学太仓长三角研究院间接参股单位。
三、承诺声明情况
项目负责人已出具关联关系承诺声明，确认与外协单位存在投资控股类利益关联，并郑重承诺：
1. 知悉国家、省市及学校科研项目及经费管理相关制度，严格履行项目负责人负责制；
2. 不存在违规使用资金、套取资金及利益输送等舞弊、违法行为；
3. 若声明内容不实，愿承担相应责任。
四、公示要求
1. 公示期为2026年4月30日至2026年5月6日（共7天）；
2. 公示期间，任何单位或个人如对上述关联关系及相关情况有异议，可通过书面形式、电话等方式向北京研究院反映；
3. 反映情况需实事求是，提供具体线索和相关证明材料，署实名并留下联系方式，以便核实处理。
