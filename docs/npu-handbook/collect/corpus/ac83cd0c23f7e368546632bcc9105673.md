# 人事处党支部专题研讨主题教育工作方案

为进一步推动主题教育落实落细，4月26日上午，人事处党支部召开支委（扩大）会议，集体学习学校主题教育近期相关通知要求，并研讨支部主题教育工作方案，人事处全体处领导和支委参加会议，会议由支部书记唐玉生主持。
会上，首先传达了机关党委主题教育工作推进会暨支部书记例会相关要求，对处级干部近期理论学习和调查研究工作进行了详细安排部署。参会人员对支部主题教育实施工作方案进行了研讨，在理论学习方面，将通过举办读书班，成立学习小组，处领导讲授专题党课，“三会一课”，实践研学等形式开展学习研讨；在调查研究方面，每位处领导将结合职责任务确定调研选题，制定调研方案，带领党员干部深入开展调研，形成高质量调研报告；此外，在推动发展、检视整改、建章立制方面，也将按照学校统筹安排，扎实落实，稳步推进。
人事处将在工作方案的基础上，突出“实”的导向，进一步加强科学谋划，迅速开展行动，以“五个清单”方式推进主题教育各项工作落实落细，切实将习近平新时代中国特色社会主义思想转化为坚定理想、锤炼党性和指导实践、推动工作的强大力量。
（文/张慧杰 郭昕 审核/唐玉生）
