# 云端引航，锚定未来——软件学院举办2023级本科生专业方向宣讲会 助力“总师型”人才培养

为深入贯彻“总师型”人才培养战略，助力学生科学规划学业与职业发展，切实提升人才培养质量，2025年8月15日上午10点，软件学院在线召开面向2023级本科生的专业方向宣讲会。会议聚焦软件工程专业的四个方向——互联网系统开发、数据科学与智能服务、智能媒体计算及大型工业软件展开深入讲解。专业方向负责人李伟刚、张仕进、高利鹏出席并作专题讲解，190余名本科生参会。会议由本科教学秘书郭艳静主持。
会议伊始，郭艳静强调了专业方向选择对职业发展的重要性。她指出，专业方向选择是学生步入职业发展赛道的重要决策,软件工程专业四个方向经过精心规划，深度契合国家战略需求与行业发展前沿，课程体系明晰、就业指向精准，希望同学们借助此次宣讲科学规划学业路径。
宣讲环节，李伟刚对互联网系统开发方向进行介绍。他深入阐释了互联网软件定义、与传统软件的差异、云计算技术及核心课程体系，并运用科研实例助力同学们理解该方向的应用场景。针对同学们关心的考研、推免、加入科研团队等问题，他逐一耐心解答，给出了极具针对性和可操作性的建议，并鼓励同学们通过参与学科竞赛、大创项目及导师的科研课题不断深化实践能力。
张仕进聚焦大型工业软件方向，系统介绍了工业软件仿真与优化、开发应用、核心课程、师资队伍及竞赛科研资源，并着重强调大型工业软件作为关键“卡脖子”技术的重要性和紧迫性，结合典型案例展示该方向服务智能制造领域的战略价值，鼓励感兴趣的同学立足工业场景，运用算法优势解决实际工业问题。
高利鹏针对数据科学与智能服务、智能媒体计算两大方向展开介绍，从方向内涵、应用场景、核心课程、学习方法建议、就业方向等方面进行详细阐述，并重点介绍了相关科研平台与团队。通过展示团队在跨领域应用中的成功案例，深入解析了数据建模、智能算法与媒体计算技术的广阔发展前景，让同学们对这两个方向的未来发展趋势有了更清晰的认识和更深入的了解。
会议最后，郭艳静对老师们的精彩、详实、富有洞见的专业方向宣讲表示衷心感谢。她指出，三位老师的宣讲内容全面系统、深入浅出，为同学们拨开了专业选择的迷雾，指明了未来发展方向。同时，她再次强调了课程修读的规范性要求，提醒学生需严格按照培养方案完成学分，并建议同学们结合个人发展目标科学制定选课计划，确保学业发展的有序性和针对性。
本次宣讲通过专家引导与典型案例剖析，为急需了解专业内涵、规划学业路径的同学们提供了至关重要的信息和极具价值的指引，深化了其对前沿技术领域的认知，更为个人发展方向的选择注入了信心与动力。软件学院将持续优化人才培养生态，为国家软件产业高质量发展输送更多拔尖创新人才。
（撰稿：曹尹娣 郭艳静 审核：马春燕）
