# 西北工业大学网络空间安全学院开题答辩（张宇光）

一、开题答辩题目：网络空间实体探测与识别技术研究
二、开题答辩人：张宇光
三、开题答辩时间：2024年4月26日19：00
四、开题答辩地点：爱生楼401室（友谊校区）
五、开题内容简介：
本研究面向网络空间实体探测与识别技术领域关键技术，聚焦解决网络资产探测成功识别率低、扫描消耗大；拓扑测量成本高、网络负担重；流量关联特征输入单一、面对新型匿名化策略关联能力弱的实际问题，凝练海量特征条件下的网络资产大范围高效探测、大规模高完整性探测条件下的网络拓扑测量成本控制、多变混淆机制条件下的网络实体通信关系识别三个科学问题，针对性的研究基于实体指纹特殊构造的网络资产优化探测方法、多探测源网络拓扑测量的协同优化探测方法、基于非关联白噪音反向识别的匿名网络流量关联方法，研制网络实体属性探测识别系统，实现实体资产、拓扑、通信属性结合的网络实体信息侦察方法和工具。这些技术将整合实体资产、拓扑和通信属性，为网络空间的主动防御策略提供数据支撑。
六、开题答辩人简介
张宇光，学号2021161078，1985年3月2日生人，网络空间安全学院电子信息专业，导师饶志宏。
