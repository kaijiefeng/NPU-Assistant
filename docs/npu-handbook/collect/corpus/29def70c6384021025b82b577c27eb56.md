# 管理学院-西北工业大学医院

责任医师：关小荣（副主任医师）
简介：
毕业于第四军医大学，眼科副主任医师，硕士。擅长：青光眼，白内障，常见眼底病，青少年近视防控，干眼，眼整形手术。曾于北京同仁医院及天津眼科医院进修学习。陕西省卫生产业监督协会眼健康及儿童青少年近视防控专业委员会常务委员，西安市医学会医学整形与美容学会委员。发表论文十余篇。
（备注：学院责任医师是医院与学院之间的桥梁，可为我校师生提供健康咨询、健康宣教、体检结果释疑、急救知识技能培训等服务。有需求者，可通过扫描学院责任医师二维码联系。）
