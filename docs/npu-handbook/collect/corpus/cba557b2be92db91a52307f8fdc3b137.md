# 第24届“三航杯”创新大赛决赛顺利举办-青春驿站-共青团西北工业大学委员会

3月28日，我校第24届“三航杯”创新大赛决赛顺利落下帷幕。来自全校各人才培养单位的千余个创新项目经网络评审、终评答辩等环节激烈角逐，最终共产生108个金奖、162个银奖、195个铜奖。副校长张富利来到赛事现场观摩比赛，与同学们交流科学问题，鼓励参赛学生勇攀科技创新高峰，成长为科技创新和产业创新的先锋力量。
赛前，学校组织召开“三航杯”决赛评审工作会议。校团委书记佘磊磊详细解读本届大赛评审规则并作工作说明。校长助理王宇波代表学校对参与评审的专家表示欢迎和感谢，从“总师型”人才培养再结硕果、高水平创新人才队伍持续壮大、国家战略科技力量更加彰显等方面介绍了学校近期事业发展情况。他指出，学校始终将创新创业教育作为“总师型”人才培养的重要一环，注重将学校科研优势转化为人才培养的实际成效。今年是“十五五”开局之年和学校发展承前启后的关键节点，要以大赛为牵引，推动创新教育融入教育活动全过程，以赛促教、以赛促学、以赛促创，进一步发挥大赛的育人属性，不断提高创新拔尖人才培养质量。
本届大赛以“科创青春，敢闯会创”为主题，在创新创业教育领导小组各成员单位和各学院、研究院的协同配合下，共同发掘潜力项目，烘托双创氛围，助力“总师型”人才培养。自2026年1月大赛启动以来，全校共挖掘作品一千余个，参赛学生达8370人次。决赛现场，决赛以分组答辩的形式开展，邀请校内外专家评委参与答辩评审，465个项目负责人围绕“主赛道”“青年筑梦红色之旅”“产教融合”3大赛道进行了现场答辩。
我校“三航杯”大赛已累计举办二十四届，积极服务学校“总师型”人才培养，是我校最大规模，最具影响力的学生创新竞赛，致力于培养学生科技创新能力、激发学生科技创新热情，引导广大青年在科技创新领域争当排头兵和生力军。
下一步，团委将持续以“三大赛”为牵引，把创新创业赛事打造为学生知识转化和创新创造能力培养的重要载体，以实干实绩助力“一十百千”发展目标和“天下工大、世界三航”远景目标早日实现，以青春之我绘就学校“十五五”发展新篇。
