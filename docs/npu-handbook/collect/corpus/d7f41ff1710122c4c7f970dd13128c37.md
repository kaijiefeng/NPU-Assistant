# 【安全知识竞赛】关于开展2025年西北工业大学“11.9”消防安全宣传知识竞赛的通知

全体师生：
2025年11月9日是第34个全国消防日，国务院安委会办公室、国家消防救援局定于11月份在全国开展消防宣传月活动，主题是“全民消防、生命至上——安全用火用电”。为进一步提升广大师生消防安全意识，提高应急处置能力，特开展2025年西北工业大学“11.9”消防安全宣传知识竞赛，现将相关事项通知如下:
一、参赛对象
西北工业大学全体师生。
二、竞赛方式
微信扫描下方小程序二维码即可参与：
三、答题时间
11月6日8时至11月20日20时。
四、注意事项与奖项设置
1.答题时从题库中随机抽取20道题目，每题5分，满分100分，每人有2次答题机会。
2.答题时务必填写姓名，工号或学号，二级单位名称，个人联系方式。
3.竞赛设置个人奖项，获奖者需答题满分，并按照答题时长排序确定排名。获奖名单及奖品后续将通知各单位安全员或本人领取并发放。
五、活动联系人
党委保卫部：潘丁，联系电话：88492280。
党委保卫部
2025年11月05日
