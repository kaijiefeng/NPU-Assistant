# 学习先辈伟绩 砥砺初心使命

6月23日，在校党委教师工作部“教师发展支持计划”的支持下，为扎实开展教师培训，体育部组织教师党员、教职工代表50余人赴富平爱国主义教育基地开展“学习先辈伟绩 砥砺初心使命”实践研学，深入推进树立和践行正确政绩观学习教育走实走深。
在庄严肃穆的习仲勋陵园内，参加实践研学的全体教工怀着无比崇敬的心情追思老一辈无产阶级革命家习仲勋同志，深切缅怀先辈的丰功伟绩，表达对先辈无尽的崇敬。大家认真聆听讲解，深入了解习仲勋同志为中国革命、建设和改革事业奋斗终身的光辉历程，深刻感悟老一辈革命家坚定的理想信念、深厚的人民情怀和无私的奉献精神。
随后，大家走进关中革命纪念馆。一件件珍贵文物、一幅幅历史图片、一段段革命故事，生动再现了中国共产党领导关中人民艰苦奋斗、浴血奋战的革命历史。大家通过现场教学，进一步认识到中国革命胜利的来之不易，更加坚定了听党话、跟党走的政治自觉和行动自觉。
在习仲勋故居，大家系统了解了习仲勋同志光辉而伟大的一生。从投身革命到主政地方，从坚持实事求是到心系百姓民生，他始终坚守共产党人的初心本色。一件件朴实无华的生活用品，无声诉说着他艰苦奋斗的过往，大家深刻感悟“党的利益在第一位”的政治品格和“把屁股端端地坐在老百姓这一面”的为民情怀。
大家一致表示，要从老一辈革命家的崇高风范中汲取精神养分，深刻领会习近平总书记关于“政绩为谁而树、树什么样的政绩、靠什么树政绩”的重要论述，把树立和践行正确政绩观的要求内化于心、外化于行，把师生满意不满意作为衡量工作的根本标准，以更加务实的作风、更加昂扬的姿态投身学校体育事业高质量发展，在新征程上展现新担当、实现新作为。（文 杨梦晨 图 李梦帆 审核 傅莉）
