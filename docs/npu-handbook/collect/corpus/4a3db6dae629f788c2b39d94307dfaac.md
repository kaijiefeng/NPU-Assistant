# 我校举行2026年西北工业大学“翱翔四海”暑期项目“平安留学”行前培训

2026年6月25日下午，在教育部国际合作与交流司、教育部留学服务中心大力指导下，2026年西北工业大学“翱翔四海”暑期项目“平安留学”行前培训在长安校区翱翔学生活动中心举行。国际合作处陈思危主持会议，近1800名即将赴国（境）外参加交流项目学生参训。
本次行前培训紧密围绕学生海外学习生活实际需求与风险防控重点，邀请多领域专家开展系统化、实用性专题培训，内容涵盖保密纪律、涉外礼仪、安全防范与应急救护等多个方面。
学校保密处副处长王革明围绕出国（境）期间保密管理要求，结合工作实际，强调在涉外交流与科研活动中必须严守国家安全底线，切实增强保密意识与纪律观念。
陕西省外事办公室礼宾处黄浩围绕涉外礼宾礼仪规范，从纪律要求、出行礼仪、着装规范及用餐礼仪等方面进行了详细讲授，强调在国际交流场景中应遵循基本外交礼节与文化尊重原则，做到言行得体、形象端正，展现中国青年学子的良好风貌与文明素养。
西安市公安局警察训练支队仲强警官结合海外真实案例，重点围绕留学生可能面临的各类安全风险开展专题培训，包括财物盗窃、人身侵害、突发冲突等情形的识别与防范方法，系统讲解不同场景下的应对策略与自我保护技巧，增强学生风险预判能力与应急处置能力，提升在复杂环境中的安全意识与应变能力。
西安市红十字会刘丽老师围绕紧急救护知识开展实操性培训，重点讲授心肺复苏（CPR）标准操作流程、自动体外除颤器（AED）使用方法以及气道异物梗阻的紧急处理措施，通过要点讲解与步骤示范相结合的方式，帮助学生掌握基础急救技能。
教育实验学院本博翱翔总师班2025级学生岳越作为学生代表发言，以“感恩、期待、责任”为主题，倡议同学们珍惜宝贵机会看见世界、对话世界、融入世界，在实践中增长才干、提升本领，学成报国。
国际合作处副处长陈俊在总结中指出，“翱翔四海”项目是学校深入推进本科生“三个一”工程的重要实践载体，是培养具有全球胜任力人才的重要途径。他对所有参加项目的学生提出了四点要求：一是严守纪律底线，严格遵守行程安排与外事安全规定，强化风险防范意识；二是珍惜交流机会，积极参与学习实践，注重成果总结与多元记录；三是展现中国青年形象，遵守文明礼仪，讲好中国故事；四是严守国家政策法规及校纪校规，增强防范意识，确保平安留学。
近年来，学校大力实施本科生“三个一”工程，持续推进“翱翔四海”计划深度实施，为本科生在校期间提供一次出国（境）短期交流机会。2026年已立项近百个暑期项目，涵盖学术提升、国际竞赛、文化交流等七大主题，涉及英国、澳大利亚、德国、新加坡等23个国家和地区。随着项目体系不断完善，越来越多学生走出国门，在国（境）外深化专业认知、增强跨文化沟通能力，在真实场景中提升科研创新与复杂问题解决能力，为培养具有家国情怀与全球视野的高素质人才奠定坚实基础。
