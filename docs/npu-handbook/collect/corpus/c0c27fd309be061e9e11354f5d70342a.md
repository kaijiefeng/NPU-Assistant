# 计算机学院召开研究生培养工作研讨会

为进一步提升研究生培养质量，推动学院研究生教育工作高质量发展，11月10日，学院组织召开研究生培养工作研讨会，全面梳理研究生培养工作现状，深入分析存在的问题，研究部署下一阶段重点工作。会议由尚学群院长主持，学院学术委员会、学位评定分委员会委员代表、研究生教学秘书及学工主管参加会议。

会上，研究生教学秘书刘璐首先围绕学院研究生招生与生源质量、课程体系建设、培养过程管理与质量监控、导师队伍建设等方面，系统介绍了近年来相关工作开展情况，结合数据分析了当前研究生培养工作中存在的短板与不足，并提出针对性优化举措。学工主管刘百芳围绕近五年学院毕业生就业情况进行汇报，通过数据分析梳理就业工作中的差距，并提出相应改进思路。

随后，与会教师围绕研究生教育培养的重点环节和关键问题展开深入交流，并提出意见建议。在招生工作方面，要严把生源质量关，持续加强招生宣传，积极搭建师生交流平台，拓展优质生源渠道。在课程建设方面，建议统筹推进课程群建设，结合不同学科方向和培养层次优化课程供给。在学生培养方面，要抓实优秀博士苗子的早期发掘与全过程培育，对照培育目标和评价标准细化培养举措，夯实“荣誉博士”支持计划实施基础。在就业工作方面，要提前做好毕业生就业意向摸底，强化分类指导与精准服务，多措并举拓宽就业渠道，促进毕业生更加充分、更高质量就业。

尚学群院长在总结讲话中强调，研究生培养质量提升是一项系统性工作，要坚持问题导向和目标导向：一是做好课程体系的整体谋划与布局优化，积极动员优质师资参与研究生核心课、前沿课建设，持续打造高水平研究生课程；二是立足学院办学特色，探索分赛道、分类别的差异化培养路径，切实推进学院“荣誉博士”支持计划落地见效；三是加强毕业生发展跟踪，完善硕博士毕业生数据追踪机制，持续关注毕业生发展情况，为优化人才培养方案、提升研究生培养质量提供有力支撑。

本次研讨会进一步梳理了学院研究生培养工作的重点与难点，明确了下一阶段工作方向。学院将以此次会议为契机，持续完善研究生培养体系，强化全过程质量管理，推动研究生教育培养质量稳步提升。
