# 动力与能源学院-西北工业大学医院

责任医师：赵强（副主任医师）
简介：
骨科副主任医师，中共党员，毕业于西安交通大学医学院临床医学专业。曾在北京积水潭医院、宁波市第六医院、西京医院、兵器工业521医院进修学习。擅长四肢骨折的创伤修复、断指（肢）再植、皮瓣修复、烧伤瘢痕整形、畸形矫正、手外伤术后功能重建及复杂骨科疾病的诊治。多次参加卫计委的“百万医院下乡支医” 、国际马拉松赛事保障等公益 活动。现任中国医药教育协会骨科分会青年委员、陕西保健学会手外科与显微外科分会委员、陕西省医师协会骨质疏松与骨矿盐分会委员等。在核心期刊发表论文2篇，国家级专业杂志发表论文5篇，省部级专业杂志发表论文10余篇等。
（备注：学院责任医师是医院与学院之间的桥梁，可为我校师生提供健康咨询、健康宣教、体检结果释疑、急救知识技能培训等服务。有需求者，可通过扫描学院责任医师二维码联系。）
