# 2026年数学与统计学院第二批国际化领军人才（含本硕博）培养项目申报通知

为深入贯彻国家人才强国战略，培养更多创新型、紧缺型、复合型国际化人才，学校持续实施国际化领军人才培养项目，重点支持博士研究生赴英国、德国、意大利、澳大利亚、法国、西班牙、瑞典等高等教育发达国家的一流高校和科研机构开展联合培养。
一、选派类别及留学期限
本项目重点支持理工农医、新兴学科以及交叉学科等国家重点急需人才培养学科领域的博士研究生赴外交流学习：
1. 本科插班生：留学期限3-8个月，年满18周岁，留学期限不低于3个月；
2. 联合培养硕士研究生：留学期限3-6个月，年龄不超过30岁，留学期限不低于3个月；
3. 联合培养博士研究生：留学期限6-12个月，年龄不超过35周岁，留学期限不低于6个月。
二、申请条件
申请人须为我院全日制在读学生，拥护中国共产党的领导，品德良好，具有扎实的专业基础和发展潜力。
三、项目申请流程
（一）联合培养硕士/博士研究生申请流程
1. 学生申请：填写附件1《国际化领军人才培养项目申请表》（导师签字版本），连同拟留学单位邀请信/入学通知及其他纸质版申请材料，提交至学院海天苑大楼E206-3李老师；
2. 学院审核：学院审核后，将申请材料汇总后提交至国际合作处（港澳台办公室）；
3. 组织评审：国际合作处（港澳台办公室）遵循“公开、公平、公正”的原则进行选拔并公示结果。
（二）本科插班生申请流程
项目类型包括本科生赴国（境）外毕业设计项目及学分学位交换项目等，各类项目“随时发布、随时申请、集中资助”，项目信息及申请材料请关注国际合作处（港澳台办公室）和各培养单位微信公众号报名通知。
四、资助申请及发放流程
（一）联合培养硕士/博士研究生
已录取同学按要求完成研究生出国（境）审批手续即可向国际合作处（港澳台办公室）申请首次资助，剩余资助分批次发放，最后一个月资助将于完成线上返校申请后发放。
（二）本科插班生
获得学校各类长期出国（境）项目录取的本科生需在派出前完成资助申请，具体流程如下：
1. 学生申请：填写附件3《西北工业大学本科生长期（三个月及以上）出国（境）交流项目资助申请表》，将纸质版提交至学院海天苑大楼E206-3李老师；
2. 学院审核：学院审核后连同附件4《西北工业大学本科生长期（三个月及以上）出国（境）交流项目资助汇总表》提交至国际合作处（港澳台办公室）；
3. 组织评审：国际合作处（港澳台办公室）遵循“公开、公平、公正”的原则进行评审并公示结果。
4. 按要求完成线上出国（境）审批手续，国际合作处将分批次进行资助发放。
五、资助内容与标准
本项目为学生提供一次往返国际旅费和资助期限内的生活费资助，具体资助标准如下：
（一）生活费
（二）一次性定额国际旅费
欧美、大洋洲地区不超过10000元/生；亚洲地区不超过5000元/生。
六、重要说明
1. 重点支持博士研究生依托国内外导师间已有的科研合作项目/协议赴国外学习；
2. 优先支持赴QS、THE、U.S.News、ARWU四大排行榜认定的全球前100名高校或所申请学科前50名高校进行交流学习；
3. 学生须在派出前完成项目申请流程并获得资助资格。实际资助期限及资助标准以录取结果为准，且资助期限不得延长；
4. 本批次录取的博/硕研究生须在2026年12月30日前派出，特殊情况可申请延期派出，但最晚应于2027年6月30日前派出，此后资助资格作废；本批次录取的本科插班生资助资格一经批准，仅对所申请项目当次有效，不可转用于其他项目或延至其他时间使用；
5. 学生返校后严格按照出入境记录核实在外留学时间，在外时间低于最低留学期限的，资助不予发放，已发放部分须全额退回学校相应账户。

（二）本科插班生（2027年春季学期拟派出，含毕业设计和学分学位交换项目）
将学院签字盖章后的资助申请表（附件3）PDF扫描件于2026年11月4日（周三）中午12点前发送至邮箱zhuorong.li@nwpu.edu.cn（仅接收邮箱报名）。
