# 校领导到图书馆开展专题工作调研

2022年9月6日上午，副校长张卫红到图书馆进行专题工作调研，图书馆领导班子成员、各部室主任、主任助理及重点岗位人员参加了调研工作。
张卫红在图书馆领导班子的陪同下，查看了图书馆阅览自修区、借还服务区、大学生智慧音乐空间等区域，深入了解图书馆学科服务、特色文献资源、疫情防控等情况，随后听取了图书馆2022年工作情况和新学期干部大会贯彻落实情况的专题汇报。
张卫红对图书馆下一步工作提出了要求。一是进一步落实四个“行动计划”，以追求卓越的工作精神，全面加强图书馆文献资源保障、学科信息服务等工作，助力学校人才工作和学科建设；二是要继续挖掘我校图书馆特色文献资源，特别是西工大历史传承的特色资源，形成我校特色品牌和标签，为学校的文化传承提供支撑；三是加强建设研究型图书馆，时刻关注国内行业动态，找准差距和不足，持续发力，有针对性的开展工作，全面提升图书馆的管理和研究水平。
会议最后，图书馆党总支书记侯沛勇代表图书馆表态，图书馆下一步要深入学习学校新学期干部大会精神，加强辩证思维和创新思维，凝心聚力，狠抓四个“行动计划”落实落地，为学校教学科研提供高质量的文献信息服务，以实际行动迎接党的二十大胜利召开。
