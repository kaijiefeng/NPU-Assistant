# 西北工业大学伦敦玛丽女王大学工程学院中外合作办学机构2022、2023年度报告公示

根据教育部《中外合作办学条例》《中外合作办学条例实施办法》相关规定，以及陕西省教育厅《关于开展中外合作办学机构和项目年度办学报告工作的通知》等文件要求，所有本科以上层次中外合作办学机构和项目须认真开展2022、2023年度办学报告工作。
现根据教育部要求面向社会公示年度报告的“自评报告”信息，西北工业大学伦敦玛丽女王大学工程学院中外合作办学机构2022、2023年度报告现公示如下，公示期为一周（2024年4月1日至2024年4月7日），公示期间若有异议，请与玛丽女王工程学院联系。
