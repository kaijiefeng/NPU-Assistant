# 西北工业大学后勤办公室公文收发管理办法

西北工业大学后勤办公室公文收发管理办法
后勤办字〔2020〕3号
为加强和规范内部公文管理，提高工作效率，特制定本办法。
第一条收文管理
（一）OA翱翔办公平台收到的文件，直接通过平台转呈;纸质版来文，应在收文登记簿进行登记。
（二）转呈应依据文件的性质、内容、重要程度、时限要求，结合办公室内职责及分工进行。
（三）运行保障科负责向承办科室或人员催办工作进展情况。
（四）对于需要留存备查的文件资料，运行保障科进行归档保存。
第二条发文管理
（一）发文一般通过OA翱翔办公流转平台进行。
（二）发文由各科室根据实际需要，经主任认可后发起，发起科室作为拟稿人负责该文件的拟稿承办。
（三）发文按照文件种类分别进行编号。
（四）发文流程
1.起草。拟稿人负责发文起草并上传OA翱翔办公流转平台。
2.初核。拟稿科室科长负责对文字、内容及附件进行核对。
3.核转。运行保障科统一编号，按照规范进行排版，转呈拟稿科室分管领导。
4.复核。拟稿科室分管领导对文稿及附件进行审查、修改、补充。
5.签发。发文由主任统一审批签发。
6.呈送。运行保障科根据文件类型呈送校领导或会签单位。
第三条本办法由后勤办公室负责解释。
第四条本办法自2020年11月6日起施行。
