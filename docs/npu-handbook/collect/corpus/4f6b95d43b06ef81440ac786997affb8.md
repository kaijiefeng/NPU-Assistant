# 【关工委工作】校关工委联合幼儿园开展“薪火相传 篮动未来”体育交流活动

6月10日上午，学校关工委联合幼儿园、体育部和自动化学院举办“薪火相传、篮动未来”体育交流活动。陕西省篮协主席王立彬教授及其团队，学校体育部党总支书记傅莉，幼儿园园长王莉、副园长陈小庆，校关工委副秘书长、离退休工作处副处长马俊，以及幼儿园大班200余名小朋友和大学生代表20余人参加活动。活动由幼儿园教师董乐、贾靖主持。
活动在幼儿园大班小朋友精彩的篮球操表演中拉开帷幕。伴随着动感的节奏，孩子们拍球、转球、运球，动作灵巧娴熟，小小的篮球在他们手中仿佛有了生命，充分展现了西工大幼儿园“以体育人、快乐成长”的蓬勃风采。
傅莉首先介绍了王立彬教授的专业成就与体育情怀。随后，马俊为王立彬教授颁发西北工业大学“银发宣讲员”聘书，标志着这位篮球名将正式加入学校“银发人才”育人队伍。
王立彬教授以“小篮球·大梦想”为题，生动阐释了体育精神与体育强国建设的深刻内涵。他谈到，幼儿园是播撒篮球火种的第一块土壤。我们要牢牢树立‘健康第一’的教育理念，让每个孩子在奔跑、跳跃、协作中感受体育精神的魅力。
紧接着，幼儿园大班带来一场动感十足的跑酷表演，孩子们跨越障碍、灵活攀爬，引来阵阵掌声。表演结束后，王立彬教授代表陕西省篮球协会向幼儿园捐赠定制小篮球，王莉回赠学校“为国铸剑”文创纪念品，寓意“大手牵小手，文化共传承”。
在教学互动环节，王立彬团队为大学生和小朋友们示范了运球、传球、投篮的标准动作。他们弯下腰，用孩子们听得懂的游戏化语言耐心指导。大学生志愿者也主动当起“陪练”，手把手带小朋友感受篮球的触感。
一场别开生面的篮球赛将活动推向高潮。大学生与小朋友展开3V3友谊赛。大学生们放慢脚步、轻柔防守，把投篮机会“漏”给孩子；而小朋友们也毫不怯场，奋力拼抢、认真突破。王立彬教授在场边大声指挥：“别怕，上去抢他！”话音刚落，一个小朋友“唰”地空心入网！三分球！霎时间，欢呼声掀翻了球场。这一刻，没有“让”出来的温情，只有拼出来的光芒。
此次交流活动是校关工委落实“健康第一”育人理念的生动实践。从银发王教授，到朝气蓬勃的大学生，再到稚气未脱的幼儿园萌娃——三代人因篮球而相聚，因热爱而传承。“银发宣讲员”点燃火种，大学生传递接力，小朋友怀抱梦想。小小篮球，滚动的不仅是快乐，更是体育强国的未来希望。
