# 西北工业大学网络空间安全学院开题答辩（吴颖）

一、开题答辩题目：面向物联网应用场景的安全防护关键技术研究
二、开题答辩人：吴颖
三、开题答辩时间：2024年6月21日下午14：30
四、开题答辩地点：爱生楼401室（友谊校区）
五、开题内容简介：针对复杂异构物联网系统所面临的安全问题和防御需求，结合物联网联接的各类应用系统业务高流动性、信息相对封闭、部署规模时变、网络攻击各异等特征，以物流调度、仓储管理、环境监测等典型研究对象，提出安全防护解决方案，深入开展安全防护体系框架构建工作，聚焦研究物联网复杂融合网络的攻击阻断能力、系统协同防御能力，从而适应互联网和物联网技术快速发展背景下信息系统安全防护能力持续增强的需求，最终提升物联网系统安全防护的自动化和智能化水平。
六、开题答辩人简介
吴颖，学号2021161077，1984年7月30日生人，网络空间安全学院电子信息专业，导师饶志宏。
