# 潜心育人 以研促教 知行合一

李亚梦，中共党员，西北工业大学体育部教师，副教授，硕士生导师，北京师范大学体育人文社会学专业博士，生物医学工程博士后。
李亚梦参加工作以来，认真履行教师职责，始终坚持立德树人教育理念，自觉把教书育人放在首位，注重把学科前沿和科研思维融入体育教学，推动科研成果向课程内容和育人实践转化，在教育教学、学生培养、科学研究、社会服务中持续探索，努力做一名有坚定信念、有扎实学识、有仁爱之心、有创新精神的新时代体育教师。
潜心育人，以专注温情助力学生成长
传道启智，授法育人，是学校对每一位老师的职业要求。从入职的第一天起，李亚梦就把上好每一堂课当做自己的努力目标，她积极承担本科教学任务，主要负责公共体育课武术初级、中级和高级的教学工作。课堂上，她既重视基本动作和运动技能的规范传授，也关注学生的课堂参与和运动体验，引导学生在锻炼中感受运动乐趣、掌握科学锻炼方法，逐步增强健康意识、养成终身体育锻炼的习惯。她坚持学习改进教学方法，积极参与课程建设与教学改革，作为核心成员参与《匹克球》《舞龙中级》两门课程建设，并承担《舞龙中级》课程教学改革研究，在课程建设和教学研究中不断积累经验。学生的成长与进步，是李亚梦从事教育工作的重要动力，用心陪伴，当好学生成长的引路人，是她职业生涯的重要追求。担任2026级运动训练专业本科生班主任以来，她坚持以党的创新理论为指导，自觉把为党育人、为国育才、培根铸魂、启智润心要求融入教育实践之中，她关注学生入学后的学习适应、专业认识和发展需求，重视与学生的日常交流，及时了解他们在学习和成长中遇到的问题。指导学生时，她尊重学生个体差异，注重引导学生尽早树立目标意识和规划意识，鼓励大家充分利用大学平台，在学习、训练和实践中认识自己、提升能力，逐步找到适合自身的发展方向。
笃实深耕，以科研探索解决现实需求
李亚梦坚持以解决现实问题为己任开展科研探索，她长期关注儿童健康促进和慢性病运动干预领域的现实问题，先后主持国家自然科学基金青年项目（C类）、陕西省“十四五”教育科学规划项目、陕西省体育局科研项目等多项课题，在国内外学术期刊发表论文20余篇。在慢性病运动干预方向，她重点研究太极拳等传统体育项目对慢性病人群运动功能和健康状况的影响及作用机制；在儿童健康促进方向，她关注社交困境儿童的体育参与、身体活动行为与身心健康，探索有针对性的学校体育支持路径。相关研究为运动促进健康和学校体育实践提供了新的研究视角，也为课程建设和人才培养提供了科研支撑。
乐于奉献，以个人所长回报服务社会
李亚梦始终认为，体育教师的职责不仅体现在课堂和科研中，也应落实到体育实践与社会服务里。她始终不忘体育强国建设赋予自己这一代体育工作者的神圣使命，积极参与体育赛事服务和裁判工作，多次参加学校各类大型体育活动和竞赛的组织工作，曾担任第十二届中国大学生英式七人制橄榄球锦标赛裁判员，并获评“优秀裁判员”荣誉，以认真严谨的态度在赛事一线展现了高校体育教师的专业素养和责任担当。
以体育人、以研求真、服务社会，是李亚梦始终坚持的教育追求。随着运动训练专业课程陆续开设，她将承担《体育测量与评价》《运动损伤与康复》两门专业核心课程的教学任务。目前，她正围绕专业人才培养目标开展课程设计与教学准备，注重把体育测量、运动评价、损伤防护和运动康复等内容与运动训练实践相衔接，为新课开出打好基础。未来，她将继续立足教学岗位、扎实开展科学研究、积极服务社会，在一项项具体工作中认真履行教师职责，为学校体育教育事业和体育人才培养贡献力量。
