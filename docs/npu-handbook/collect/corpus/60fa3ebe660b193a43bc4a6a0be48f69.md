# 聚焦研代会|第一届研究生会主席团候选人简介

主席团候选人介绍
西北工业大学国家卓越工程师学院第一届研究生代表大会即将召开。今天，就让我们来了解一下西北工业大学国家卓越工程师学院第一届研究生代表大会主席团成员候选人，他们分别是张业祺、张钰博、徐嘉悦、黄萌（按姓氏笔画排序）。
张业祺
张业祺，女，汉族，22岁，山东淄博人，中共党员，国家卓越工程师学院2024级博士研究生。
现任班级团支书。学术方面，曾获光电设计大赛全国一等奖、挑战杯国家级三等奖，月球旅店设计大赛全国三等奖，互联网+校级金奖等校级奖项四项，曾获华萌奖学金、校级一等奖学金等；学术工作方面，曾任校学生会干事、小班班长，作为“坐下来能写、站起来能说、走出去能做”的新时代西工大学子，累计组织策划学院活动、班级主题团日等10余场，疫情期间参加线上支教和核酸检测志愿者等志愿活动，累计志愿服务350余小时，获评优秀志愿者多次，践行青年使命担当。我的优势在于有扎实的学术背景，理解研究生的实际需求；丰富的学生工作经验，对活动的策划和执行流程较为熟悉；善于倾听和沟通，始终保持服务同学的初心。
张钰博
张钰博，男，汉族，23岁，陕西西安人，中共党员，国家卓越工程师学院2024级博士研究生。
现任陕西省第十六期青马工程大学生骨干培训班班长、擎动先锋共育党支部宣传委员。曾任西北工业大学首届黄玉珊航空班班长，校团委培训中心负责人等。先后获校“十佳班长”、优秀共青团员、创新创业先进个人等荣誉及“宁波未来之星”奖学金等校级与专项奖学金。先后带队获数模竞赛国赛二等奖、中国国际创新大赛国家级铜奖等国家级、省部级奖项30余项。组建团队“云弈科技”成功入孵西工大国家大学科技园，先后两轮获得投资，目前与南京市江北新区顶山街道招商办签订意向落地合同。先后发表EI论文5篇，在AAME（学校研究生高水平Ⅰ类学术会议）中获唯一“Best Presentation Award”，授权发明专利1项，实用新型专利1项。参与发起组织“大飞机、大梦想”中外大学生实践队，先后获团中央全国优秀实践队，省级标兵团队，两获校特等奖。
徐嘉悦
徐嘉悦，女，汉族，22岁，四川绵阳人，中共党员，国家卓越工程师学院2024级硕士研究生。
现任校研究生会文体部负责人。曾任校、院学生会部门负责人、校团委组织部团务中心主任、第十八次学代会常代会主任、启真社区党员工作站负责人、创客班班长等。入选我校第十五期“青马工程”大骨班并优秀结业。曾带领团队入孵国家大学科技园、飞天创客空间、香港科技园，并获校“模范团队”（全校仅十个），受陕西电视台采访。参加学科竞赛累计获国家级及以上奖励9项，省部级奖励11项，校级奖励三十余项。获评“宁波未来之星”奖学金、校二等奖学金、优秀共青团员、五四红旗团支部、创新创业先进个人等荣誉称号十余项。学生工作期间组织策划“新星杯”校园歌手大赛、工大球王、“缤纷百年绘”百米长卷等校级大型活动40余项，担任学院跨年晚会总导演。积极投身抗击疫情、返乡、迎新、学生大使等志愿服务工作，相关事迹受中国乡村振兴网、中华全国学联、中国青年网、西工大招办等媒体报道。
黄萌
黄萌，女，汉族，23岁，江苏南京人，中共党员，国家卓越工程师学院2024级硕士研究生。
现任国家卓越工程师学院242106班团支部书记，卓越锋帆党支部委员会组织委员。组织过新时代志愿精神学习、国家安全青春挺膺等十余次团日活动。曾获西北工业大学优秀本科生毕业生、校级一等学业奖学金、校级双创之星、吴亚军二等学业奖学金、优秀共青团员、校级优秀大学生等荣誉称号。先后获得中国国际互联网+大学生创新创业大赛陕西省金奖一项、银奖一项，人工智能挑战赛校级一等奖。作为第一作者公开发明专利一项、授权实用新型专利一项、软件著作权三项。累计获得省部级及以上荣誉4项，校级及以上荣誉10余项。曾参加“新时代双创转化成效研究”思政教育社会实践，积极参与“心筑烛梦”线上支教、新冠期间疫情防控等志愿服务。
2025年5月18日，让我们相聚在长安校区教东A410报告厅，一起见证西北工业大学国家卓越工程师学院第一届研究生代表大会的召开！
