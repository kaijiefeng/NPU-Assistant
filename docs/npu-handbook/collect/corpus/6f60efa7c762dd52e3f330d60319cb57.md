# 【勤工助学】国有资产管理处学生助管招聘启事（截止日期2022年9月23日）

岗位名称：
国有资产管理处助管员
岗位需求：
8人
工作地点：
友谊校区勇字楼806、808、811室
工作内容：
1.协助完成电话接听、资料整理、信息系统资料录入等相关工作。
2.完成老师交办的其他临时性事项。
工作要求:
1.具有良好的思想政治素质和高度的责任感，甘于奉献，团队意识强；
2.按时到岗，工作认真踏实，具有责任意识；
3.积极主动配合并且保质保量完成老师布置的工作和任务；
4.熟悉常用办公软件，会CAD制图者优先。
报名方式:
有意者请9月23日之前联系乔老师
