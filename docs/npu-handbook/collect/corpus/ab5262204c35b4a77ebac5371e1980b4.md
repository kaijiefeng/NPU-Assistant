# 笃行致远，化育无声——公共政策与管理学院优秀教职工风采展示

为弘扬教育家精神，展现优秀教职工立德树人、潜心育人、锐意创新的精神风貌，公共政策与管理学院推出“优秀教职工风采展示”专题。本次专题展示汇集学院部分优秀教职工代表，他们紧紧围绕立德树人根本任务，牢记为党育人、为国育才的初心使命，深耕课堂、潜心育人，勇攀科研高峰、服务国家战略，并在管理服务工作中默默奉献、笃行不怠。让我们一同走近身边榜样，感受榜样力量，凝聚奋进动能，在接续奋斗中扛起西工大教师的时代担当，为学校高质量发展做出新的更大贡献。
公共政策与管理学院 郑烨 第十届教育部科学研究优秀成果奖（人文社会科学）青年成果奖、西北工业大学2026年度“本科卓越教学新秀奖”和“本科卓越课堂”、先进工作者
热爱科研，沉下心研究现实中的“真问题”。坚持问题导向，围绕特定方向持续深耕，主持国家级及省部级课题10余项，以第一或通讯作者发表论文100余篇，多篇被《新华文摘》《人大报刊复印资料》等全文收录或转载。注重科研与育人融合，坚持在科研一线培养人才。他常带领研究生深入调研与学术研讨，在言传身教中引导学生锤炼思维，进入学术前沿。近年来，他指导学生在高水平期刊发表多篇论文，将科研过程转化为育人过程，实现教研相长。其著作《政府支持行为对中小企业创新绩效的影响研究》获第十届教育部科学研究优秀成果奖（人文社会科学）青年成果奖，实现学院零的突破。
主讲《行政管理学》等三门本科课程，善于将复杂的理论知识转化为鲜活的课堂体验，用饱满的情绪感染学生。他坚信，老师全情投入，才能换来学生的真心回应。他乐于毫无保留地分享知识、案例与思考，也愿意俯身倾听学生的声音。这种真诚的互动，让他在教学中深刻体会到“教学相长”的快乐。正是这份热爱、严谨、激情与真诚，让他的课堂既有深度又有温度。
公共政策与管理学院 张琳 《组织行为学》课程获批第三批国家级一流本科课程
坚持育人新理念，引导学生从被动听课转向主动探索，面向本科生、硕士生及留学生开设《组织行为学》等核心课程。针对传统课堂“重理论、轻实践”的局限，她创新提出“教与学自组织”的教学模式，推进教学场景、内容、资源、方法与评价的系统改革，开发以“班级组织”为教学实践域的新型教学机制，打造教与学深度融合的授课模式，引导学生在“班级组织”内对所学知识进行循环优化，并推动由“班级组织”向“其他组织”的学习迁移。同时，她构建了涵盖慕课、微课、AI课程、小程序的立体化资源体系，为新文科背景下管理学课程创新提供了有益借鉴。
公共政策与管理学院 刘敏获第十七届陕西省哲社奖二等奖
长期从事产业经济学、国防科技工业治理、科技创新与产业创新研究。在《管理世界》等期刊发表论文20余篇，出版学术专著2部、参编6部，主持国家社科、国家自科等各级各类项目30余项，斩获国防科技进步二等奖、陕西省哲社优秀成果二等奖等5项，获评第八届“国防经济学年度人物”，多项成果被政府、企事业单位采纳。从教治学多年，始终秉持研教相融、经世致用理念，坚守党员初心，深耕学术、潜心育人。坚信科研既要扎根理论、深耕细研，也要贴合实际、服务社会发展，坚持以科研反哺教学，用心培育兼具理论素养与实践能力的经济管理人才。
公共政策与管理学院 李黎明 获第十七届陕西省哲社奖二等奖
深耕专业细分领域，坐热科研“冷板凳”！聚焦知识产权领域，追踪前沿文献，时常温习经典文献，掌握创新经济学、行为经济学和社会心理学的理论发展脉络，开展跨学科研究，精准定位自身科研方向。亲身投入科研数据收集、整理和分析工作，透过社会现象敏锐捕捉真科学问题，及时学习前沿实证研究方法，借助新工具和新方法拓宽科学问题研究的新视角，产出积累代表性论文。统筹规划论文的研究主题，分阶段、有逻辑地推进科学研究，夯实国家级科研项目申报的研究基础；加强学术交流，分享代表性论文的核心观点，积极参与政府的咨政建言，扩大代表性论文的学术影响力和社会影响力，申报高水平的科研奖励。
公共政策与管理学院 李慧 获第十七届陕西省哲社奖二等奖
高校工作20多年来，积极对接国家和地方发展战略，紧密结合学校办学特色和学科发展需求，聚焦科技政策与管理、创新发展政策与管理、技术创新管理等领域，深耕科学研究。主持国家社科基金项目、教育部人文社科研究项目及省、市级课题近20项，发表学术论文40余篇，荣获陕西省哲学社会科学研究优秀成果奖、陕西高校人文社会科学研究优秀成果奖。同时，聚焦育人初心，坚持立德树人，推动思政育人、科研育人、研教深度融合，获评陕西省课程思政示范课程和教学团队、校级教学成果一等奖，荣获学校“最满意教师”、“十育人先进个人”、“三育人先进个人”等荣誉称号，荣获学校优秀硕士学位论文指导教师2次、“百篇优秀本科毕业论文”指导教师2次。
公共政策与管理学院 周炯 西北工业大学2026年度立德树人奖
常怀爱校、爱院、爱生、爱教之心，多年来，坚持把价值引领融入专业课堂，不只传授理论知识，对人才培养还注重引导学生独立思考，厚植家国担当，塑造综合能力与素养。长期深耕经济、金融、公共管理及其交叉领域教学与科研探索，将个人工作与学院、学科发展紧密结合。秉持教学相长理念，在教学中推进教改创新、优化课程模式；科研探索立足专业理论，聚焦现实问题，不断提升科研水平。依托导学导研、学科竞赛、案例研究、论文指导等方式用心育人，尊重学生个体差异，关爱学生，做好学生成长路上的引路人。
