# 【关工委工作】“银发育心员”集体备课会顺利召开

9月11日，“银发育心员”集体备课会在我校召开。此次备课会是学校关工委“银发育心员”队伍第四次参与大学生心理健康课，每学期约15位老教授通过座谈交流、主题分享、草坪沙龙等多种形式深入青年学生，开展实践互动与思想引领，惠及学生近千名。党委学生工作部五级职员张翠仙，离退休工作处副处长、学校关工委副秘书长马俊，离退休工作处五级职员王静，大学生心理健康中心主任刘欣，大学生心理健康课全体专职教师以及关工委“银发育心员”参加会议。
会议伊始，大学生心理健康课教师周晨琛围绕《大学生心理健康教育》实践教学环节作系统介绍，从学校人才培养目标与心理学专业视角出发，进一步明确了“银发育心员”的职责定位、策略方法与工作要求。
“银发育心员”高宝营老师结合此前课程实践探索，以《让“焦虑”助我一臂之力》的课程为例，为老同志们做了现场教学示范与经验分享。
在交流环节，吴祖明、党进宝、陈猛龙、李言俊等老师踊跃发言，他们表示退休后还能以“银发育心员”的身份走近学生，继续做育人育心的工作，是一件很有意义、很幸福的事。大家围绕学生的现实困惑、工作技巧、实践主题等内容，分享了各自的心得与体会，现场气氛温暖而热烈。
马俊在总结中对各位老教授的坚守与奉献表达深深的敬意和感谢。她谈到，老同志们发挥自身的政治优势、经验优势、威望优势，以包容之心倾听学生情绪困惑，循循善诱传递岁月智慧，用温情陪伴疏解青年迷茫，为学校“总师型”人才培养贡献独特而深沉的银发力量。下一步，学校关工委将持续搭建老青互助、代际育人的桥梁，完善常态化工作机制，丰富活动形式，为青年学子健康成长保驾护航。
