# 后勤部办公室开展防灾减灾宣传活动

2026年5月12日是第18个全国防灾减灾日，今年的主题为：“人人讲安全、个个会应急——提高防灾减灾救灾能力”，5月11日至17日为防灾减灾宣传周。为了进一步做好防灾减灾救灾知识宣传，增强全校师生的防灾减灾安全意识，提高广大师生的逃生自救、互救能力和抵御、应对紧急突发灾害事件的能力，保障广大师生的生命安全，后勤部办公室结合学校实际开展了防灾减灾主题宣传教育活动。
5月12日，后勤部办公室于友谊校区三航路东北侧和长安校区翱翔学生中心广场设立专题宣传展板，内容涵盖了地震、泥石流、滑坡、雷电等常见自然灾害的防范知识与应急避险技巧要点，展板既有翔实的文字详解，也有图文并茂生动直观的科普板块，帮助大家更好地学习防灾减灾知识，提升应急避险能力，让安全理念深入人心。
通过本次宣传活动，进一步加强了对师生们的防灾减灾教育，提高了师生实际应对和处置突发安全事件的能力，更进一步增强了师生防灾减灾的安全意识，有助于掌握在危险中迅速逃生、自救、互救的基本方法，提高抵御和应对紧急突发事情的能力。
生命是美好的，生活是多姿多彩的，而要拥有这一切的前提是安全，努力增强自我防范能力，识别灾害风险，提高应对能力！（撰稿人：王磊；审稿人：袁源）
