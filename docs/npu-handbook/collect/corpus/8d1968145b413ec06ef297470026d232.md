# 守护权益、温暖同行——航天学院2026春季学期权益座谈会顺利召开

为深化研究生权益服务，3月17日，航天学院研究生会于学院345学生活动中心举办了2026年春季学期以“守护权益、温暖同行”为主题的权益座谈会。本次活动由研究生会主席团成员耿浩华同学主持，学院团委书记高戈出席，学院研究生会工作人员、各年级研究生学生代表出席参加会议。
一、聚焦权益成果，畅通反馈渠道
会上，研究生会权益部门对本学期工作进展进行了系统梳理，围绕“需求收集—分类处理—跟踪反馈”的闭环机制，持续优化权益问题响应流程，推动形成高效、规范的服务体系。针对同学们在学习、科研与生活中的实际需求，重点介绍了“权益信箱”及“航小天”公众号线上反馈通道，进一步提升问题反馈的便捷性与可达性。同时，研究生会通过定期研判与过程跟踪，确保问题处理公开透明、落实有序。
二、师生共话，凝聚共识
在交流环节，与会学生代表围绕学习环境优化、科研条件保障等方面积极建言。研究生会成员现场记录并逐项回应，表示将协同相关部门推进问题落实。高戈老师对研究生会权益工作给予充分肯定，并指出应在“及时回应”的基础上，进一步强化主动调研与前瞻服务，不断提升权益工作的系统性与实效性。
三、守护启航，未来可期
会议最后，对下一阶段权益工作重点进行了展望，包括优化反馈渠道建设、推动科研资源共享等方向。与会同学表示，通过本次座谈进一步加深了对权益服务体系的理解，对后续服务优化充满期待。
作为联系服务研究生的重要平台，航天学院研究生会将持续坚持以需求为导向，完善“收集—反馈—跟踪—优化”的动态机制，不断提升服务精准度与响应效率，切实将同学诉求转化为推动校园建设与服务提升的实际举措，为研究生学习科研提供更加坚实的保障。
