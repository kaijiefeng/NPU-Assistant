# 岳晓奎

岳晓奎
职务：JAC主任/现任西北工业大学党委常委、副校长
邮箱：xkyue@nwpu.edu.cn
个人简介链接：https://teacher.nwpu.edu.cn/yuexiaokui.html
岳晓奎，男，工学博士，现任西北工业大学副校长。入选国家级人才计划，荣获“十一五”科技攻关奖、“十一五”先进个人等荣誉称号。主持完成国家自然科学基金、国家973、国家863等国家级重点科研项目30余项。在本领域权威期刊及重要国际会议上发表论文百余篇，其中SCI收录30余篇，ESI高被引2篇。出版学术专著4部，获授权发明专利30项。先后获得陕西省科学技术一等奖、陕西省科学技术二等奖等多项省部级科技奖励。
