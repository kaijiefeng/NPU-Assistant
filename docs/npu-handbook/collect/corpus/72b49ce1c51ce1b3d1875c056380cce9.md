# 9院优博风采|2022年陕西省优秀博士学位论文获奖者：余自权

为进一步提高自动化学院研究生培养质量，提升研究生创新能力，促进研究生教育内涵发展，学院特邀请优秀博士学位论文获得者分享自身科研历程与学术体会等，旨在激励在校研究生秉承“公诚勇毅”校训，弘扬“三实一新”校风，潜心研究、锐意创新、成长成才。
本期人物：控制科学与工程学科博士毕业生 余自权
所获奖励：2022年陕西省优秀博士学位论文
余自权，自动化学院2015级博士研究生，师从张友民教授，主要研究方向为集群无人机容错协同控制理论及应用。读博期间受国家留学基金委“国家建设高水平大学公派研究生项目”的资助，赴加拿大康考迪亚大学机械、工业与航空工程系交流学习；截止目前，以第一作者身份在《IEEE Transactions on Neural Networks and Learning Systems》《IEEE Transactions on Systems, Man, and Cybernetics: Systems》等国内外高水平学术期刊/会议上发表论文30余篇。博士毕业后加入南京航空航天大学自动化学院故障诊断与容错控制团队，团队带头人为南京航空航天大学副校长姜斌教授。在校期间荣获2022年陕西省优秀博士学位论文奖，2021年中国航空学会优秀博士学位论文奖，2022年西北工业大学优秀博士学位论文奖，2020年西北工业大学优秀毕业生等多项荣誉奖励。
成长经历
良师益友，谆谆教导。读博期间导师张友民教授经常与学生研讨论文中的前后逻辑和语言写作等方面问题，对他的学术论文要求十分严格，逐字逐句认真修改。硕士期间，导师屈耀红教授不仅向他传授了宝贵的知识，在生活中也给予了他亲切的关心和帮助，使得他坚定了继续读博深造的信心和决心。赴加拿大留学期间，合作导师苏春翌教授在学术上给予了他很多指导和点拨，让他深入了解了相关领域学术前沿。承蒙研途路上三位恩师的悉心指导、教诲和鼓励，一直激励着他在学术科研的道路上不断开拓创新，规划自己的科研方向，为今后的科研事业奠定基础。
求索路途，勇毅前行。博士期间，聚焦集群无人机容错协同控制领域中的关键技术难题，他勤于思考，善于创新。在科研道路上，灵感迸发瞬间的背后，是长时间的积累与思考，遇到科研难题他毫不畏惧，坚定信念，敢于向未知领域的前沿技术发起挑战。在一次又一次的磨练中，他始终秉承母校西北工业大学“公诚勇毅”校训，不断践行科创使命，最终取得了较为丰硕的研究成果，荣获多项奖励表彰。
科研漫道真如铁，而今迈步从头越。心怀对科研事业的热爱，在科研之路上他从未止步，一路前行，虽然他深知前方道阻且长，但也相信只要坚持不懈，就一定会有收获。未来，他将继续以扎实有力的脚步，弘扬母校西北工业大学“三实一新”校风，探索攻克集群无人系统安全自主控制领域中的一项项研究难题。
经验浅享
及时了解和认真阅读相关研究领域的高水平学术期刊和重要学术会议上发表的学术论文，了解前沿方向的最新进展。根据导师的指导要求，制定自己切实可行且难易适中的科研计划，严格执行。厘清急缓，多向导师，及师兄师姐请教，主动接触行业专家，不断攀登科研高峰。
学长寄语
科研是一场持久战，是孤独与寂寞的坚守，是无数个日夜的厚积薄发，“古之立大事者，不惟有超世之才，亦必有坚忍不拔之志”，当经历时间的洗礼和沉淀后，必然厚积而薄发，水到渠成。各位学弟学妹们一定要多和导师沟通，多和师兄师姐们交流，奋力打好每一场科研攻坚战。坚定自己的信念，要相信你们的每一次付出，都是未来收获的果实，只有奋力前行，才能遇见黎明！成功的背后是汗水与坚持，前路漫漫亦灿灿。希望每一位自动化学子都能拥有一个充实而无悔的科研生活，带着科研理想走好每一步，志存高远，争做“国之利器”！
