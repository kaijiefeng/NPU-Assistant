# 化学与化工学院组织开展第四季度安全保密检查

为深入贯彻落实习近平总书记关于总体国家安全观的重要论述，牢牢把握科技安全在国家安全体系中的重要地位，持续筑牢安全保密防线，11月9日下午，化学与化工学院组织开展第四季度安全保密检查。此次检查是学院“督查组-安全员-主管领导-党政负责人”四级安全检查体系的重要一环。
本次检查由学院党委书记傅茂森带队，副院长陈凯杰、院长助理郭威、保密员郑聪、安全员郭思敏及实验室督查组成员参加。检查组首先对学院保密室及承担涉密项目老师的涉密档案资料和相关设备进行检查，对照管理要求，重点核查涉密载体保管、计算机使用、环境安全等情况，确保保密责任落到实处，严防失泄密风险。
随后，检查组深入各实验室，重点查看实验室人员个体防护、危化品规范存放、设备安全操作规程、通风橱及实验台清洁等情况，并对前期发现的问题进行再检查、再督促，推动安全管理要求落实落细。
安全保密是一切工作的底线，必须常抓不懈、警钟长鸣。此次检查是学院落实安全保密主体责任的具体行动，有效强化了师生的安全保密意识，为学院教学科研工作的安全有序开展提供了有力保障。
