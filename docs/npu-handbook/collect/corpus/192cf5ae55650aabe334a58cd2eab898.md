# 电子信息学院传达学习学校树立和践行正确政绩观学习教育警示教育会暨专题党课精神

7月7日上午，电子信息学院召开党委理论学习中心组学习会议，传达学习学校树立和践行正确政绩观学习教育警示教育会暨专题党课精神。学院党委理论学习中心组成员参加学习，会议由党委书记侯俊主持。
会议传达学习了张云明书记在学校树立和践行正确政绩观专题党课上的讲话精神，通报了树立和践行正确政绩观正反面典型案例和科研诚信警示教育案例。
会议指出，要深刻领会习近平总书记关于树立和践行正确政绩观的重要论述，增强贯彻落实的政治自觉、思想自觉和行动自觉。要深刻把握校训校风时代要求，明晰西工大人树立和践行正确政绩观的价值准则。要运用好反面典型案例，以案为镜、举一反三，防范和纠治政绩观偏差。要牢固树立、深入践行正确政绩观，恪守校训、弘扬校风，谱写学校事业高质量发展新篇章。
会议强调，与会同志要以开展树立和践行正确政绩观学习教育为契机，对照反面典型案例检身正己，推动正确政绩观内化于心、外化于行，恪守“公诚勇毅”校训，弘扬“三实一新”校风，沉下心、铆足劲、踏实干，以实干实绩为推动学校事业高质量发展贡献电子信息学院的智慧与力量。
