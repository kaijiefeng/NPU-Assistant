# 党建引领促对外合作 |“科技外交视野下的中俄合作与西工大使命”联学联建主题党日活动顺利举办

9月24日，由国际合作处党支部牵头，联合动力与能源学院、自动化学院共4个师生支部共同举办的“科技外交视野下的中俄合作与西工大使命”专题线上座谈会顺利召开。活动以支部联学联建主题党日暨双周青年讲堂为载体，科技外交专家委员会中俄专委会主任委员、驻俄罗斯使馆原公使衔科技参赞郑世民应邀作主旨报告，校党委常委、副校长孔杰出席并致辞，国际合作处党支部副书记李自伟主持会议。
孔杰在致辞中指出，当前世界百年未有之大变局加速演进，中俄新时代全面战略协作伙伴关系保持高位运行，科技教育合作始终是两国务实合作的核心支柱，两国元首高频会晤，为中俄科技教育合作搭建了顶层平台、指明了发展方向。西工大深耕中俄科技教育合作多年，始终将对俄合作作为对外开放核心战略方向，目前已建成覆盖人才培养、科研攻关、平台建设、人文交流的全方位合作体系，产出一批具有标志性意义的合作成果，希望参会各方以本次联学共建为契机，切实把学习收获转化为推进工作的实际成效，共同推动学校对俄合作提质升级、走深走实，更好地服务国家战略全局。
郑世民结合多年驻外工作经历作主旨报告。他系统梳理俄罗斯科技创新体系、研发投入情况，客观分析俄科技领域的优势短板，介绍其基础研究扎实、人才储备雄厚的突出特点。报告复盘中俄科技合作发展历程，梳理双边、多边合作机制，既总结了大科学工程、人才交流、地方协同等方面丰硕成果，也点出双方在理念差异、成果转化等方面的现实挑战。郑世民提出，新形势下中俄科技合作要把握时代机遇，打造中俄科技命运共同体，创新人才交流模式，推动科技外交提质升级。同时对高校对俄合作给出三点实操建议：一是做实人员交流，保持合作的持续性；二是深耕联合基础研究，依托俄方优势补齐科研短板；三是对接俄国家技术创新计划能力中心，开展端到端技术合作，促进创新链产业链融合。
在互动环节，师生围绕俄方部门对接、国际会议平台建设、青年科研人员如何转化留学资源等实际问题提问。郑世民就对口单位选择、项目申报渠道、合作模式创新等一一答疑解惑，鼓励青年学者发挥桥梁纽带作用。自动化学院导航制导与控制系党支部李广文作总结发言，他表示本次联学兼具战略高度与实践指导性，后续学院将立足导航制导、飞行控制等学科优势，把学习成果落实到联合科研与人才培养工作当中。
本次活动是党建业务深度融合的生动实践。参会师生表示，报告指导性强，后续将立足岗位履职尽责，助力学校国际合作高质量发展。
