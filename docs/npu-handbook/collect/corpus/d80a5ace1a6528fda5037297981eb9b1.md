# 工学交替，筑梦宁波 ——2026秋季学期研究生入驻座谈会顺利召开

9月4日下午，西北工业大学宁波研究院新学期迎新大会在我院报告厅举行。2025级硕士、博士研究生在学校本部完成一年学业后来甬开展科研实践，院领导、导师代表与同学们齐聚一堂，共同开启卓越工程师“工学交替，驻厂1年”实践培养的序幕。
会前，同学们集体参观了研究院展厅和柔性电子、智能芯片、无人航行、卫星大数据等技术中心，深入了解了各科研平台与创新成果，并合影留念。
首先，徐伟侠副院长致欢迎辞，希望同学们尽快适应新环境，在研究院平台和宁波合作企业找准定位、明确方向，迈好第一步。
在优秀学生代表交流环节。2021级直博生石颖超分享了自己的科研心得：博士第一年沉心读文献、学软件、搭框架，看似“慢功夫”，却为后续研究打下根基，要主动与导师沟通、善用企业平台资源，同时保持良好身心状态。2023级博士生王嘉礼围绕科研中的挫折分享体会：实验失利并非从零开始，而是在积累基础上的重新出发，唯有厚积薄发，方能稳步前行。
在新学生代表交流环节。新生代表陈震、陈润欣、王文卓、郭煜昊在发言中表示，将珍惜在宁波的时光。尽快融入集体，脚踏实地、勤学善思、踏实做事，在科研实践中增长才干。
导师代表发言环节。赵建村副研究员勉励新生：把个人志向融入时代浪潮，面向国家战略需求和企业技术难题勇于挑战真问题；珍惜研究院与企业打造的“产教融合”平台，主动走进实验室和企业一线，在解决实际问题中打磨本领；守住“板凳甘坐十年冷”的定力，在挫折中坚韧，在合作中开放，在学术中守信。
院长寄语环节。盛其杰院长回顾了研究院发展历程，他表示，从平台建设到人才集聚，从科研攻关到产业孵化，研究院始终在向上生长。他分享了2024级硕士研究生廖洪彦、郑书慧两位同学扎驻宁波赛福制动工厂，助力企业解决ABS刹车系统关键技术的故事，而宁波赛福制动正是张雪机车ABS刹车系统供应商。他鼓励大家，要把个人成长融入国家需要、创新浙江、宁波国家新型工业化示范区的建设中，入企找需求、回院搞创新，在场景实践中长才干、出成果，与研究院共成长。
自由交流环节。同学们就住宿安排、餐饮服务、文体活动等实际关切的问题进行了提问，院领导逐一回应，既讲安排，也讲解决方案。一问一答间，同学们对在甬做好科研和生活有了更真切的期待。
新学期伊始，大家将以饱满的热情到生产一线开展科研实践活动，锚定方向、笃行实干，在甬城写下属于自己的精彩篇章！
