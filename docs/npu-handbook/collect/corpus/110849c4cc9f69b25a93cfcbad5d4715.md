# 物理科学与技术学院党委召开理论学习中心组（扩大）会议专题学习党的二十届四中全会精神

10月28日上午，物理科学与技术学院党委在学院楼454会议室召开理论学习中心组（扩大）会议，专题学习党的二十届四中全会精神。会议由学院党委书记晁小荣主持，学院党委理论学习中心组成员、师生融合党支部书记、院办教职工等参加会议。
会上，晁小荣领学了《中国共产党第二十届中央委员会第四次全体会议公报》，并对全院开展党的二十届四中全会精神学习宣传作出安排部署。随后，集体研读《习近平谈治国理政》第五卷重点篇目，深刻领会习近平总书记关于全面深化教育改革、推进中国式现代化的新思想新论断新要求。接着，与会人员结合自身岗位，围绕党组织建设、人才培养、科学研究等方面进行深入研讨。
会议强调：一是坚持深学一层，原原本本学、逐字逐句悟，用好“三会一课”、主题党日等载体开展专题研讨学习，在深化理论武装上先行一步，确保真学真懂、学有所获。二是坚持宣传赋能，创新工作方式和传播手段，加大宣传力度，做到理论学习全覆盖，在营造浓厚氛围上走在前、作表率，迅速掀起学习贯彻党的二十届四中全会精神的热潮。三是坚持学用结合，将理论学习融入学科建设、育人管理、科研创新等具体工作中，切实推动理论学习与实际工作同频共振、互促共进。
今后，学院将深入学习贯彻党的二十届四中全会精神，全面落实立德树人根本任务，紧紧围绕学校“127”近期发展目标、“天下工大、世界三航”远景目标以及“一十百千”战略目标，聚焦高质量发展主线，系统推进人才培养、学科建设、科研创新等重点工作，不断提升办学水平和核心竞争力，为学院各项事业高质量发展打下坚实基础。
