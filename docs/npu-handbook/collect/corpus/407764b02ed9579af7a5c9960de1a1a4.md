# 自动化学院赴航空工业618研究所开展“总师型”人才培养座谈会

为完善人才培养体系，以“总师育人文化”引领导师队伍建设、卓越工程师计划、校企课程和教材建设等产教融合培养改革，10月20日，自动化学院副院长许斌、教师代表及研究生教学秘书李焱一行赴航空工业618研究所，与所人力资源部/党委干部部部长李玮奇、导航系统部部长杨国梁、飞行控制系统部飞控系统技术室主任马钊、创新中心管理办公室副主任张闻乾及人力资源部/党委干部部业务主管李永安进行了深入交流。
许斌作题为《“总师型”人才培养》的报告，首先对“西工大现象”、“总师型”人才培养特质的内涵进行解读，结合学院71年办学历程中在航空机载飞控、导航等关键领域培养的型号总师、副总师资源，凝练复合型人才发展特质，就“总师型”人才的培养路径提出思考；就自动化学院航工业618所开展的战略合作、协同育人基地、客座教授、专家互访、专业合作等方面进行了总结。针对以下方面进行了深入恳切的交流，具体包括：如何进行总师型人才培育、如何完善专业学位导师队伍建设、如何共建研究生校企课程建设、如何进行研究生专业教材编著、如何结合企业需求推进研究生实践。
李玮奇分享了“大国三航”系列课程建设情况，表示将大力支持618所和自动化学院相互借力，促进人才培养高质量发展。杨国梁结合自身求学和工作经历，指出校企联合应选拔优秀潜力对象，双向发力、共同推动科技创新和学科发展。马钊结合专业具体方向进行了相关前沿技术的分享，建议从多角度共同推进人才培养。张闻乾提出尝试面向研究生开展揭榜挂帅等机制，加强学院与所里的各方面技术力量联系，建立良好的研究与合作氛围。李永安针对具体的工程博士培育双向发力，促进共同成长等方面进行了分析。与会的学院教师任建新、贾科、韩渭辛、李焱也针对性联合人才培养、工程博士培养、专业融合等方面畅所欲言、充分交流。
双方一致认为，学校在人才培养领域形成了独有的“总师文化”育人氛围，“总师型”人才培养是我校人才培养的核心竞争力。双方将合力完善“总师型”人才的培养路径，以有组织科研推动总师型人才培养，助力学校双一流建设。
此次交流讨论后双方将共同制定“总师型”人才培养行动计划，落实导师队伍、联合课程、研究生教材等事宜，携手前行，为国防科技事业、为教育强国建设作出更大的贡献。
