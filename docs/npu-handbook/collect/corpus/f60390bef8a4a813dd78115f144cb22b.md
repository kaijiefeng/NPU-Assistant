# 放射科-西北工业大学医院

西工大医院放射科自成立以来队伍不断壮大，技术优良、设备先进，是协助临床各科对许多疾病诊断与治疗的重要辅助检查科室。科室现拥有副主任医师 2名、主治医师1名、专业技师2名，已形成一支结构合理、技术力量完善的人才梯队。
为方便我校师生及周边居民就医，放射科近年来陆续引进佳能64排螺旋CT、东软16排螺旋CT以及西门子、赛德科DR等先进设备。
我院螺旋CT具有扫描速度快、图像清晰度高、辐射计量低、信息量大、临床应用领域广泛、后处理软件齐全及三维立体成像等特点，可以完成呼吸系统、消化系统等各部位的三维重建。
1.低剂量胸部CT检查：胸部低剂量螺旋CT扫描辐射剂量仅为常规CT的26％甚至更低，大大降低了对受检者的伤害；尤其适用于肺癌早期筛查、肺内结节的定期追踪，以及未成年人的诊疗中。
2.颅脑CT检查：是一种检查方便，迅速安全，无痛苦，无创伤的新的检查方法，它能清楚的显示颅脑不同横断面的解剖关系和具体的脑组织结构。因而大大提高了病变的检出率和诊断的准确性。
3.内耳CT成像：耳部ct可以显示外耳道的前、后壁，鼓膜，鼓室，听小骨组成的听骨链，前庭窗，耳蜗，半规管和前庭，前庭水管，内耳道。面神经管的迷路段和鼓室段以及咽鼓管骨性段等结构。通过耳部ct可以判断是否有先天性的外耳、中耳、内耳畸形。特别是前庭水管扩大，是内耳畸形中最常见的一种。
4、腹部高清成像：了解腹腔脏器有无感染性疾病：炎症、结核、脓肿等；有无占位，如良、恶性肿瘤，转移性肿瘤等；有无畸形、结石、梗阻、穿孔、积液。
5、四肢关节CT成像：对于隐匿性及细微骨折，可通过多平面重建和骨三维重建（3 D）可清晰显示，减少漏诊风险，并对手术治疗有指导性作用。
这些大型设备的投入使用，大大提高了我院临床疾病的检出率以及病变定位、定性、定量诊断水平，带来新的检查领域，为临床提供了更广泛而确切的诊治信息，从而更好的服务广大师生。
