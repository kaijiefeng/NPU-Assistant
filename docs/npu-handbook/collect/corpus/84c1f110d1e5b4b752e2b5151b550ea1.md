# 夯实财务治理根基，筑牢内控合规防线——计划财务部举办财务专题培训

为深入贯彻落实国家关于“过紧日子”要求，进一步推进无纸化报销工作落地见效，提升合同签订管理水平，规范财务报销流程，计划财务部于9月23日下午面向全校举办财务专题培训，各单位负责财务工作的人员共200余人参加本次培训，培训由计划财务部副部长姚健主持。
姚健结合当前国家财经政策要求与学校发展实际，强调要将厉行节约、提质增效落到实处。本次培训旨在推动无纸化报销、合同管理和差旅平台使用等重点工作落地见效，帮助参训人员熟悉政策要求、掌握业务流程、防范财务风险，保障学校各项财务工作依法依规、高效有序开展。
核算中心付娆结合无纸化报销实施背景与现阶段校内应用情况，围绕无纸化报销展开了系统讲解。她结合具体业务场景，详细演示了无纸化报销全流程操作步骤，帮助参训人员准确掌握业务流程及审核要点。合同管理办公室侯媛媛以“合同管理实务讲解”为题，讲解了合同发起、审核、签署、归档的全链条签订流程，并结合典型业务案例，梳理了合同管理常见风险点与规范要求。信息技术科高福贵介绍了差旅打车平台的上线情况，展示了平台对接主流出行服务商的技术架构，深入剖析了差旅出行报销中的痛点难点。
此次培训是计划财务部提升财务治理效能、服务学校高质量发展的重要举措，也是推进财务工作规范化、智能化、精细化建设的具体实践。计划财务部将以本次培训为契机，牢固树立“管理育人、服务育人”理念，持续聚焦师生关切，以更高标准、更严要求、更实举措，全面提升财务服务保障能力与风险防控水平，为学校提升财务治理能力奠定坚实基础。
