# 西北工业大学定期存款银行竞争性选择公告

根据《中央预算单位资金存放管理实施办法》（财库〔2017〕176 号）相关规定及学校内部管理实施办法，学校拟通过竞争性方式选择开户银行以外的定期存款存放银行。欢迎符合条件的银行参与竞争。
一、项目概况
1.项目编号：西北工业大学定存-2025-001号
2.项目名称：西北工业大学定期存款银行竞争性选择项目
3.定期存款资金规模：不少于人民币1亿元
4.定期存款期限：1年以内（含1年）
5.入围银行：1家
二、资格要求
1.在中国境内依法成立的商业银行、农村信用合作社等银行业金融机构，在西安市设立分支机构。每家银行只允许一个营业网点报名，不接受联合体报名。
2.持有中国银行保险监督管理委员会核发的《金融许可证》和工商行政管理部门办理的营业执照。
3.财务稳健，资本充足率、不良贷款率、流动性比例等指标达到监管标准。
4.内部管理机制健全，具有较强的风险控制能力，近3年无重大违法违规记录，未发生重大违约事件。
三、报名时间及地点
1.报名截止时间：即日起至2025年2月15日10时。
2.报名地点：西北工业大学友谊校区勇字楼120室。不接受电话、信函、网络等其他方式报名。
四、报名时应提供的材料
1.参与者须提供《意向书》（具体格式请参照模板）一式五份，其中正本一份，副本四份，分别装订（正规胶装）成册，每套资料封面须清楚地标明“正本”“副本”。
2.参与者应将《意向书》的正本和副本装袋密封。
3.封袋均应：
（1）加封条密封，在封线处加盖公章，封面必须注明“西北工业大学定期存款存放项目报名材料”字样，并注明银行全称和联系方式等内容。
（2）《意向书》密封袋中，除《意向书》（正本、副本）外，不能夹带其他任何纸质文件资料。
请符合资格要求的银行在规定时间、地点提交参与本项目所需资料。资料不符合规定的，视为自动放弃参与竞争的资格。
五、评选委员会评选，公布结果
1.评选委员会按照综合评分法对符合基本要求的参与银行进行评分。
2.按照得分排名，排名第一的银行入围，结果将在西北工业大学官网“校园公告”发布。
