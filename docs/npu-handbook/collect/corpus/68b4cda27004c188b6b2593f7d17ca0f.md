# 【机关风采】周冬：初心如磐担使命 锐意创新助发展-机关党委

筑牢信仰根基，做政治过硬的“明白人”。周冬同志始终坚持以习近平新时代中国特色社会主义思想武装头脑，深入学习贯彻党的二十大及二十届历次全会精神，积极参加学校第十四次党代会精神学习、教职工党支部书记示范培训班等理论培训活动，不断强化党性修养，改进工作作风，提升履职能力，以实际行动践行“两个维护”，在科研平台建设管理岗位上，始终以优秀共产党员的标准严格要求自己，将政治热情转化为推动学校科技事业高质量发展的强大动力。
2026年度机关优秀共产党员
科学技术研究院 周冬
勇担战略使命，做平台突破的“实干家”。深耕科研平台建设与管理，以“钉钉子”精神推动学校科研平台体系实现阶段性突破和跨越。国家实验室建设取得标志性进展。主动融入国家战略科技力量体系，深化学校与汉江、太行等国家实验室的实质性合作，成功推动成立“汉江实验室西安研究中心”，助力学校加入国家海洋科技创新联合体、水下探测与隐身技术创新联盟。全国重点实验室争取成绩显著。聚焦国家重大战略需求，深度谋划、精准培育，挖掘校内优势团队，成立国家级平台论证专班8个，常态化论证推进；密切对接上级机关，近三年年均出差50余次，单次出差最长7天，掌握重点平台布局思路、重点和计划，保障重大评审答辩。“十四五”以来，推动学校获批翱翔、无人飞行器技术、飞行器基础布局等全国重点实验室17个，实现了优势工科学科国家级平台全覆盖，为学校强化国家战略科技力量、助力高水平科技自立自强提供了坚实支撑。
创新管理机制，做改革攻坚的“排头兵”。面对平台建设运行中的复杂问题，敢于突破、勇于创新，推动构建了高效协同的管理机制模式。强化组织架构，推动实体化运行。编制实施《国家级重点实验室实体化建设实施方案》，协调积极协调组织部、人力资源部、研究生院等部门召开协调会、推进会20余次，推动翱翔、无人飞行器技术等5个国家级平台成为校内二级独立机构，财务账号单列、博士研究生招生指标单列等落地实施，高质量推进平台实体化建设，大幅提升了平台自主运行能力。多元争取投入，强化资源保障。积极争取科技部、科工局及陕西省、西安市等各方支持经费逾亿元。同时，探索建立“平台-任务”一体化运行新机制，制定并实施《西北工业大学重点实验室考核实施细则》《理工类校设科研机构管理办法》等制度，构建“校—院—所”三级科研管理模式，有力推进了有组织的科研，提升了科研机构创新效能。
坚持科研反哺，做立德树人的“践行者”。始终牢记“为党育人、为国育才”的初心使命，连续5年担任《军事理论》课程任课教师及班主任，累计授课120余学时，为5000余名学生开展专题教学；创新教学模式，将学校科研特色优势融入课程内容，推动课程思政与科研反哺教学深度融合。同时，主持教改项目1项，发表教改论文1篇，致力于构建高水平协同育人格局，为培养“总师型”拔尖创新人才提供了有力支撑。
