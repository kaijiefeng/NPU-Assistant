# 西北工业大学精品研讨型智慧教室家具项目采购公告

招标编号：西工大招采（货）-2022-086号
温馨提示：本项目采用资格后审方式进行资格审查，报名成功后即可下载招标文件。
1．招标条件
本项目已由上级部门批准建设，资金来源中央高校改善基本办学条件专项资金，概预算35.1万元，招标人为西北工业大学。本项目已具备招标条件，现进行有限招标，诚邀符合条件的投标人前来报名。
2．项目概况与招标范围
项目概况: 智慧教室课桌椅与传统的课桌椅有着极大的不同，外观、颜色更加的多样化，让整个教室充满活力。可以组合设计，方便小组协作讨论，能给学生带来新鲜感，同时提升教室课堂质量。
工期/供货期：自中标通知书发出之日起30日历天
3．投标人资格要求
3.1投标人应具有独立法人资格，具备有效的企业法人营业执照（具有统一社会信用代码）。
3.2投标人业绩要求：投标人提供近三年（2019年1月1日以来，以合同签订日期为准）同类项目业绩合同一份且合同金额不低于20万元。
3.3投标人出具有效的法定代表人身份证明书、法定代表人授权委托书。
3.4法定代表人身份证（正反面）和被授权人身份证（正反面）。
3.5本项目不接受联合体投标。
3.6投标人无不良行为记录且当前招投标资格状态有效，相关信息查询以政府诚信平台和学校不良行为记录为准，其中政府诚信平台是指信用中国、国家企业信用信息公示系统。
4．资格审查方法
本项目采用资格后审。
5．报名
各报名单位先登录西北工业大学招标与设备采购中心（以下简称西工大招采中心）网站“供应商管理系统”进行网上报名，经西工大招采中心网上确认通过后，视为报名成功。
5.1网上报名
5.1.1报名时间：2022年09月15日至2022年09月21日，每天0:00至24:00（北京时间，下同）。
5.1.2报名网址：西工大招采中心网站“供应商管理系统”栏目。
5.1.3报名程序：
第一步：登录西工大招采中心网站“供应商管理系统”。
第二步：点击“供应商报名”，再点击“公开招标项目报名”，选择报名项目，填写供应商信息，按要求上传材料，核对无误后点击“提交”。
5.2网上确认
5.2.1确认时间：2022年09月15日至2022年09月22日。原则上每日17:00以前的报名信息于当日审核完毕，每日17:00以后的报名信息于下一日17:00以前审核完毕。
5.2.2确认方式：西工大招采中心网上审核报名单位报名信息，报名单位不需要派人来现场。审核以网上报名填写信息和上传的资料为准，填写信息和上传资料应当真实有效。否则，视为报名不成功。
5.2.3审核通过后，短信告知报名单位“用户名”和“登录密码”（请牢记），即为报名成功。
6．获取招标文件
时间：2022年09月15日至2022年09月21日，每天0:00至24:00。
方式：报名成功后，各单位凭“用户名”和“登录密码”登录西工大招采中心网站“供应商管理系统”，下载招标文件、获取相关通知和文件资料。
售价：300元，本公告包含的招标文件售价总和。
7．提交投标文件截止时间、开标时间和地点
提交投标文件截止时间：2022年10月12日09时00分（北京时间）
开标时间：2022年10月12日09时00分（北京时间）
地点：陕西省西安市西北工业大学友谊校区勇字楼125室

10．其他
10.1投标人如有围标、串标、借取他人资质或以其他方式弄虚作假等违法违规行为，一经查实，列入我校不良行为名单。
10.2本项目招标资料（包括：招标文件、答疑纪要、工程量清单、最高限价和有关通知等）自动发送至报名成功单位的系统账户中，请各单位登录西工大招采中心网站的“供应商管理系统”下载，不再另行发放。
10.3法定代表人身份证明书、法定代表人授权委托书的模板请在西工大招采中心网站“下载专区-常用表单”栏目中下载。
10.4“有限招标”是我校为加强普通货物及服务采购管理、提高采购效率，在参照公开招标程序及有关规定的基础上，结合学校实际情况自定的一种采购方式，适用于预算金额达到我校采购额度但未达到公开招标额度的普通货物及服务类项目。
