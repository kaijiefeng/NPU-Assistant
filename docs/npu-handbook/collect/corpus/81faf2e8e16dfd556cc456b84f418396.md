# 外国语学院组织师生赴富平开展红色教育实践活动

为纪念中国人民抗日战争暨世界反法西斯战争胜利80周年，9月6日，外国语学院组织处科级干部，新入职青年教师，各师生党支部书记、支委、党员、入党积极分子等60余名师生赴富平关中革命纪念馆、八路军120师抗日誓师大会旧址开展红色教育实践活动。
关中革命纪念馆通过历史照片、革命实物、场景复原等，系统呈现了渭华起义、陕甘边革命根据地建设、抗日战争时期关中军民的斗争等重大事件，生动还原了革命先辈的奋斗历程，凸显了关中地区在近代革命中的重要作用。师生不断驻足观看，相互交流想法，既了解了那段红色的历史，又从故事中汲取了不断奋进的力量。
在八路军120师誓师纪念地，巍峨的纪念碑与厚重的纪念馆再现了红军进驻富平到浴血抗战的壮阔征程。大家沿着“红军进驻富平”“军民鱼水情深”“庄里镇抗日誓师”“浴血抗战照丹青”“解放西北建功勋”五个篇章深入了解了120师的铁军史诗。随后，在纪念馆的宣誓广场上，预备党员面对鲜红的党旗，庄严地重温入党誓词。“我志愿加入中国共产党，拥护党的纲领，遵守党的章程……”铿锵有力的誓词声在空中回荡，每一位党员的内心都受到一次深刻的洗礼。
此次红色教育实践活动，既是一堂重温革命历史、砥砺初心使命的生动党课，也是一次感受时代脉搏、聚焦主责主业的实践教学。师生们纷纷表示，要以九三阅兵为新的起点，弘扬伟大的抗战精神，缅怀先烈、珍爱和平，紧紧围绕立德树人根本任务，不断从党的光辉历史和科技强军的伟大成就中汲取智慧和力量，以“凡事尽到努力、凡事坚持到底、凡事追求完美、凡事争取第一”的精气神，为学院高质量发展加力赋能，为学校“一十百千”目标贡献文科力量！（文/王开薇；审稿/王高祖）
