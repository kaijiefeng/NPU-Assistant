# 以廉润心守初心 以学促行担使命——电子信息学院本科生第二党支部开展廉洁文化教育专题活动

6月16日，电子信息学院本科生第二党支部组织开展廉洁文化教育专题活动。本次活动由支部书记马琳雅同志主持，支部党员参加学习。
活动伊始，全体同志集中观看《中华传统廉洁文化》高校党组织示范微党课视频。视频中，中国人民大学师生围绕“传统文化”“制度规范”“行为实践”三个维度，对中华传统廉洁文化的思想内涵和实践要求进行了深入阐释。微党课通过张伯行却赠檄文、康熙拒收灵芝等历史故事为切入点，系统梳理了“廉”与“洁”的文化源流，展现了中华优秀传统文化中崇廉尚洁、修身律己的价值追求。通过观看学习，与会党员一致认为，青年党员应从历史典范中汲取精神力量，树立“以廉为荣、以贪为耻”的价值观，将廉洁要求融入日常学习与生活。
随后，范轶凡同志以《筑牢思想防线，严守廉洁纪律》为题进行专题分享。她结合中央纪委五次全会精神与学生党员实际，重点剖析了“小微权力”背后的纪律风险。她谈到，学生党员虽不掌握公共权力，但在学生干部工作、评奖评优、组织活动和服务同学等日常事务中，同样须坚持公平公正原则，自觉接受监督，做到不越纪律红线、不碰制度底线。
在廉洁故事分享环节，三位同志结合不同历史时期的典型事例展开交流。王必洲同志讲述了红军长征途中“三枚铜板”的故事，展现了红军严明的纪律和为民初心；仵一凡同志分享了焦裕禄教育子女补买戏票的事例，体现了共产党人清正廉洁、严于律己的家风传承；刘腾岳同志讲述了明代官员钱如京彻查莲花池税案、为百姓减免税负的故事，展现了古代廉吏心系百姓、坚守正义的担当。鲜活的事例引导支部成员在历史与榜样的对照中感悟廉洁力量，进一步增强了纪律意识和责任意识。
活动最后，马琳雅同志表示，本次廉洁文化教育专题活动主题鲜明、内容充实，既有理论阐释，也有案例剖析，进一步深化了支部成员对廉洁纪律和作风建设的认识。全体党员应以此次学习为契机，将廉洁教育成果内化于心、外化于行，在学习科研、学生工作和服务同学中坚持公道正派、严谨务实，以实际行动发挥党员先锋模范作用，在新时代新征程中书写无愧于党和人民的青春答卷。
