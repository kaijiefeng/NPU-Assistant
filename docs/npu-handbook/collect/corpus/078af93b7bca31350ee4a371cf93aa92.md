# 物理科学与技术学院党委联合管理学院党委开展师德师风专题报告会

为深入学习贯彻习近平总书记关于师德师风建设的重要论述，大力弘扬教育家精神，10月28日下午，物理科学与技术学院党委联合管理学院党委在理学院353会议室开展师德师风专题报告会，数学与统计学院国家级教学名师孙浩教授应邀作专题报告。物理科学与技术学院党委书记晁小荣、管理学院党委副书记王海啸、管理学院院长助理李乘龙，两院党支部书记、青年教师及院办教职工参加了本次报告。报告由学院党委书记晁小荣主持。
会上，晁小荣首先简要介绍了孙浩教授的有关情况，随后孙教授以《坚守教师职业初心，从乡村教师到国家级教学名师》为主题，围绕“弘扬教育家精神，服务教育强国建设”“争做新时代‘大先生’”“以德立身、以德立学、以德施教”“课程育人、科研育人和实践育人”等维度作系统阐述。他结合自身经历，深刻剖析了部分典型案例，生动阐释了教育家精神，刻画了“心系家国、敢为人先、深耕课堂、科研育人”的教师形象，同时激励广大教师以德立身、潜心教学，践行新时代“大先生”的光荣使命。
在互动环节，青年教师围绕教学科研如何协同育人、课程思政融入路径等话题踊跃提问，孙教授逐一耐心解答，现场交流热烈、掌声不断，学习氛围浓厚。
与会教师一致表示，通过此次报告会，进一步明确了在教育强国、科技强国、人才强国新征程中的使命担当，大家深刻认识到师德师风建设的重要意义，更加明晰了做好教书育人、投身教育实践的基本路径。下一步，学院将持续深化师德师风建设，通过选树先进典型、开展思想动态调研等活动，引导教师将师德规范融入教学科研日常，以优良师风带动学院高质量发展。
（文：杨文琪，图：谭皓天，审核：晁小荣）
