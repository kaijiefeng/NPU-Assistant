# 离退休党委组织离退休干部骨干赴蒲城开展实地研学

9月26日，离退休党委组织120余名老党员前往陕西渭南市蒲城县博物馆和时间博物馆，开展“银发续燃星火志，初心铸魂新征途”干部骨干培训。离退休党委机关党支部党员一同参加培训。
在蒲城县博物馆，大家驻足门前六龙壁，聆听其建造背景与雕刻工艺讲解；在碑刻馆了解廉政故事 ——《诫石碑》的警示语、清代“清官碑”记载的知县蔡信芳断案清廉、离任“不带秦中一寸棉”的事迹，让大家印象深刻。
在时间博物馆，沉浸式的参观学习让大家不仅系统地了解了时间科学知识和新中国时频科技事业的发展脉络，也展示了国家授时中心老一辈科学家为我国第一代长短波授时系统建设和“两弹一星”事业做出的重要贡献，以及在他们攻坚克难历程中体现的“淡泊名利、甘于清贫、无私奉献、科技报国”的“326”精神。
参观尾声，大家纷纷表示，这不仅是一次培训学习，更是一场精神洗礼。虽已退休，但初心未改，今后将继续发挥余热，贡献银发力量。
