# 西工大2026年本科招生工作圆满完成-

近日，西北工业大学2026年本科招生录取工作圆满收官。全校聚焦服务国家重大战略需求，在学校党委的坚强领导下，在各学院、各招生组、全校师生、广大校友和职能部门的共同努力下，以“总师育人文化”为引领，构建以家国情怀、总师潜质为核心的政策革新、宣传赋能、精准选拔循环架构，走出一条“先浸润、再选拔”的“总师型”人才特色选才之路，实现了本科生源质量持续保持高位！
【生源质量保持高位】
在全国投放招生计划的31个省份中，我校物理类（理工类）录取最低分位次、平均分位次及最高分位次全部保持优质高位区间。历史类、中外合作办学生源质量整体保持平稳。
2026年物理类（理工类）专业录取分数统计表
【深耕制度创新，升级招生政策体系】
围绕生源选拔需求配套落地“四个更高质量”（更高质量新增、更高质量志愿、更高质量培养、更高质量就业）的招生政策，细化生源筛选、专业调配、宣传引导、跟踪培育全流程标准规范。创新出台100%专业类内任选改革举措，打破传统专业划分与分流限制，赋予学生自主匹配发展赛道的空间。优化招生计划分配规则，加大国防战略硬核工科专业资源倾斜力度，打通招生选拔与中长期专业培养衔接通道，建成导向清晰、灵活可调的招生政策体系。
【优化育人循环架构，打造生源培育新链路】
锚定家国情怀、总师潜质核心选拔标准，树立“报国为先、素养为本”选才导向。坚持顶层牵引，校党委书记张云明、校长宋保维先后赴北京、四川重点生源中学走访。全体校领导33人次带队赴各省教育考试院、重点生源中学，开展调研对接、科普讲座、科技共建等招生宣传活动。
突破“招生仅为选拔”传统认知，前置中学国防科普启蒙，邀请空警-500总设计师欧阳绍修、空警-600总设计师段卓毅、“翼龙”总设计师唐勇、长征二号丁运载火箭总设计师马佳等总师校友，以及李贺军、杨坤德等院士专家走进中学，开展300余场“三航”特色科普讲座及科技活动。开展国防特色研学活动，年均接待2.6万名中学生来校开展科技研学，依托国防重点实验室让高中生近距离感悟大国重器，厚植三航报国理想信念。
全年在各省份开展招生政策宣讲1000余场，5800余名“学生大使”寒假重返中学母校，充分展示学校办学实力和培养特色，精准匹配学生志向与国防专业赛道。集中宣传志愿填报期间，学校1758名师生奔赴全国1800余所主要生源中学，联合各地校友分会共同开展线下招生咨询活动，为考生和家长开展面对面志愿填报指导工作。建立“潜质识别—精准选拔—结构优化—培养反哺”的招生工作循环链路，筑牢“总师型”人才培养源头根基。
公诚勇毅，三实一新，巍哉学府，辈出栋梁。“走遍千山万水、想尽千方百计、说尽千言万语、不辞千辛万苦”，皆为“总师型”人才之源。
感谢全校师生、广大校友、社会各界对西工大本科招生工作的关心、参与、支持。
