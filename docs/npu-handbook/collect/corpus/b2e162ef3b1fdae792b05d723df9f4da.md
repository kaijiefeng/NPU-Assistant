# 西工大获批28个省级案例

近日，陕西省教育厅公布了2025年陕西省本科教学案例评选结果，我校共28个案例成功入选，其中获评课程思政类4个、科教融汇10个、课赛融合3个、项目式教学3个、人工智能+4个、产教融合4个，凸显了学校在创新科教协同育人、以高水平科研支撑高质量人才培养的引领性成效。
学校不断推进“总师育人文化”走深走实，持续加强教学案例的培育与示范引领，多措并举鼓励教师投入教育教学改革研究与创新，将科研优势有效转化为人才培养胜势。学校将锚定“127”发展目标，进一步加强优秀教学案例的推广应用，推动先进的教育教学理念、创新的模式方法应用于教学实际，为“总师型”人才培养质量提升赋能增效！
（文字：薛小婷、刘昕；审核：张学良）
