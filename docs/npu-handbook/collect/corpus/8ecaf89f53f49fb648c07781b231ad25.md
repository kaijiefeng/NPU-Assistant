# 人事处党支部召开学习贯彻习近平新时代中国特色社会主义思想主题教育动员部署会

按照学校和机关党委关于学习贯彻习近平新时代中国特色社会主义思想主题教育实施方案的相关要求，4月20日下午，人事处党支部召开动员部署会，专题学习习近平总书记在主题教育工作会议上的重要讲话精神、学校主题教育动员大会精神以及学校实施方案等内容。
支部组织委员郭昕、宣传委员张慧杰领学了主题教育相关学习材料。支部书记唐玉生传达了学校主题教育动员大会精神和实施方案相关要求，要求全体党员要深刻领会开展主题教育的重大意义，并就支部下一步如何落实各项工作要求进行了安排和部署。
与会党员结合学习感悟和岗位职责进行了交流发言，大家纷纷表示要深刻学习领会主题教育相关文件精神，在工作中要深入基层、深入一线开展调查研究，把一个个“问题清单”变为“成果清单”，不断提升工作能力和服务水平，为人才强校战略贡献自己的力量，为学校人事人才工作添砖加瓦。
（文/张慧杰 图/王凡 审核/唐玉生）
