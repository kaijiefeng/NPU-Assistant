# 无人系统技术研究院/人工智能学院成功举办青年教师教学技能提升活动

11月7日，在校党委教师工作部“教师发展支持计划”的支持下，由无人系统技术研究院分工会牵头，无人系统技术研究院/人工智能学院成功举办青年教师教学技能提升暨年度导师培训活动，研究院院长白俊强出席并做动员讲话。原校党委副书记、副校长王润孝教授，国家级教学名师段哲民教授，国家级教学名师孙浩教授，陕西省教学名师颜红侠教授，校工会常务副主席陈建军老师应邀担任活动评委。活动由研究院党委副书记徐晓峰主持。
经过前期认真准备，来自无人系统技术研究院/人工智能学院的8位青年教师，现场逐一进行了精彩的教学展示。他们立足专业特色，将前沿动态、工程实践与理论教学巧妙结合，讲课内容精炼，教学环节衔接自然，表达条理清晰，自信大方，充分展示了良好的精神风貌和专业功底。现场5位评委结合自身长期从事教育教学的宝贵经验进行了点评，他们充分肯定了青年教师讲课的优点，同时在教学设计的创新优化、课程思政的有效融入、课堂教学的仪表仪态等方面提出了切实可行的指导意见和建议。
陈建军对本次活动给予高度评价，他表示，研究院始终把青年教师成长成才放在师资队伍建设的重要位置，多措并举、搭台铺路，展现出越来越强的活力和实力。希望通过本次活动，充分发挥引领示范作用，带动更多的优秀青年教师参与进来，为我校参加全国高校青年教师教学竞赛储备更多的力量。
经过现场综合考评，邵典荣获一等奖，张永健、李阳、陈汉荣获二等奖，王伟、张豪、王铉彬、王璇荣获三等奖。
本次活动的成功举办是无人系统技术研究院/人工智能学院提升教学质量、促进教师专业成长的一次生动实践。我们将以此次活动为契机，持续搭建教育教学交流平台，夯实“总师型”人才培养教学根基，培养造就新时代高水平专业化教师队伍，为实现我校“天下工大、世界三航”远景目标贡献力量。
