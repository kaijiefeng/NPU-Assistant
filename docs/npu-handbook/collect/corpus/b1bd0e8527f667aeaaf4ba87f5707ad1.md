# 航海学院召开研究生导师培训会

9月10日，航海学院召开研究生导师专题培训会，党委书记刘朝亚做了题为《坚持“高线”，守住“底线”，不越“红线”》主题报告，学院2024年新任研究生导师全体参会。本次会议由副院长曾向阳主持。
曾向阳强调，研究生导师是研究生培养的关键力量，承担着对研究生进行思想政治教育、学科前沿引领、科研方法指导和学术规范教导的责任。举办新任研究生导师培训，既是加强导师第一责任人建设的重要内容，也是促进新任研究生导师更好履职尽责的重要举措。
随后，刘朝亚就坚定政治方向、严守师德师风、遵守学术道德和落实导师第一责任人等十个方面内容进行报告。刘朝亚强调，作为新晋导师，只有充分认识到“以德立身、以德立学、以德施教”的重要作用，才能更好地用自己的一言一行去教育学生、影响学生，帮助他们走好科研之路、成长之路。
最后，刘朝亚要求：要坚持底线思维，做到慎微、慎独、慎初；要保持政治定力，做到在平凡的岗位上守好初心；要勇于担当、不断学习，充分发挥学院优势和学科培养特色，全面提升学院研究生教育质量，成为学生成长成材的引路人。
此次研究生导师培训会使得学院新任研究生导师强化了担当意识，以更加强烈的主动精神践行科教兴国的时代担当。
（撰稿：李淼 审核：曾向阳 刘朝亚）
