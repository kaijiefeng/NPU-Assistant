# 党委保卫部开展应急处置突发事件培训演练

为进一步提升安保人员的专业技能和应急处突能力，12月5日，党委保卫部特聘培训教官碑林分局巡特警大队宣博文、卢昆仑为长安校区安保人员及应急分队成员开展校园群体性突发事件处置培训，并组织反恐防暴应急处突实战演练。
培训分为上午和下午两个阶段开展，教官主要针对盾棍叉等常见防暴器材的使用技巧和注意事项、突发事件处置应对阵型、分场景暴恐袭击实战等内容进行讲解示范和模拟演练。
经过两位教官的耐心指导、示范和纠错，全体安保人员基本掌握了常见防暴器材的使用要领，大家的应急反应意识、群体性突发事件的处置技能等得到了进一步规范和提升。
演练结束后，大家纷纷表示，通过应急处突培训及演练，有效地提升了相互之间协调配合、快速应对和有效处置群体性突发事件的能力及方法。
后续，党委保卫部将不断加大训练力度，强化安全防范意识，增强安保专业技能，为维护和谐稳定的校园环境不懈努力。
