# 化学与化工学院开展寒假前安全保密专项检查

为切实保障寒假期间学院安全稳定，筑牢保密防线，1月22日上午，学院组织开展了寒假前安全保密专项检查。本次检查分两组同步进行，对实验室安全与科研保密工作进行了全面细致的排查。
第一组由院长顾军渭带队，副院长陈凯杰、党政办公室主任郑虹、安全员郭思敏及实验室督查组成员参加，重点对实验室进行安全检查。检查组深入各实验室，对照近期各级检查中发现的问题开展“回头看”，核实隐患整改情况，并对实验室环境卫生、化学品标签、危化品存放、设备操作规程、通风橱及实验台清洁等关键环节进行了逐一检查。顾军渭院长强调要紧盯各类重点危险源，建立健全长效管理机制，系统提升安全管理水平。
第二组由学院党委书记傅茂森带队，院长助理郭威、党政办公室副主任薛佳佳、保密员郑聪参加，主要开展保密工作检查。检查组重点走访学院保密室及承担涉密项目教师的办公场所，严格对照管理规定，对涉密载体保管、计算机使用、环境安全等方面进行了细致核查。傅茂森书记强调保密责任一定落实到实处，牢固树立危机意识，坚决防范失泄密风险。
此次检查是学院在寒假这一重要节点落实安全保密主体责任的具体行动，进一步强化了师生的责任意识，为全院师生平安度过寒假、顺利迎接新学期工作奠定了坚实基础。学院将持续夯实安全保密工作基础，严格落实各项制度要求，切实保障教学科研秩序平稳有序，为学校“天下工大，世界三航”的宏伟愿景与“一十百千”战略目标的实现，营造安全稳定、规范有序的发展环境。
