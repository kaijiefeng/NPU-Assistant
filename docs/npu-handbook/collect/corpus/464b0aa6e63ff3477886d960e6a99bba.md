# 【暑假项目】2026年教育实验学院/未来技术学院/学科交叉中心英国牛津大学STEM跨学科学术前沿暑期项目报名通知

为培养具有家国情怀，追求卓越、堪当大任、引领未来的“总师型”科技创新领军人才，强化学院的国际化氛围，丰富全球胜任力教育教学资源，全方位提升学生的全球胜任力，教育实验学院/未来技术学院/学科交叉中心将于2026年暑假组织开展英国牛津大学STEM跨学科学术前沿暑期项目。
一、学校简介
牛津大学是英语国家中最古老的大学，2026年QS世界大学排名第4。牛津大学拥有雄厚的师资力量，其教职队伍中有83位皇家学会会员和125位英国科学院院士。
二、项目时间
2026年7月26日至2026年8月8日
三、项目内容及亮点
本项目核心课程由牛津大学教授、美国宇航局（NASA）前哈勃学者Martin Bureau领衔。项目主要包括跨学科学术课程、实践工作坊、行业特邀嘉宾讲座、英国企业参访、英式社交拓展及英伦文化体验六部分组成。具体如下：
跨学科学术课程涵盖5大模块，涉及多个领域、几十种议题；
围绕公众演讲、职业规划、影视制作、英国文化礼仪等开展实践工作坊，提高综合素养；
邀请重量级行业嘉宾开展讲座，分享行业概况，探索行业前瞻（往期特邀嘉宾有唐顿庄园总制片人、英格兰央行高管首席数据官、英国知名摄影师、世界银行副行长、联合国委员等）；
实地参访英国知名企业，助力未来职业发展（往期参访企业有英国特许公认会计师公会总部、英格兰央行等）；
探访牛津、温莎城堡、莎士比亚故居、伦敦等，开展特色文化交流活动；
举办英国传统社交晚会、英式下午茶、传统高桌晚宴，沉浸式体验英国社交文化。
项目手册请见附件。
四、项目费用
学费：2100英镑/人
其他费用：1850英镑/人，其中包含：牛津大学学院住宿（单人间）、餐食（周一至周六提供早、中、晚三餐，周日仅早餐）、结业晚宴、参访、接送机等费用。
以上费用不包含：国际机票、签证及保险等其他个人消费。
五、项目资助标准
学校国际合作处将对顺利参加项目并按学校要求顺利完成访学的同学进行资助，具体资助管理办法请见：https://guoji.nwpu.edu.cn/info/1025/5073.htm。
注：每位同学一个自然年内仅可获得一次寒暑假项目资助（一个自然年一次，如超出资助名额限制，优先第一次参加翱翔四海的低年级本科生）。各学院资助配套政策可咨询所在学院外事秘书。
