# 深耕跨域装备研制，传承铸剑初心——石亚军总师讲授“感悟深蓝”课程

近日，西北工业大学航海学院校企协同特色课程“感悟深蓝”第六轮第五讲在长安校区开讲。中船集团702所跨域平台技术发展中心主任、地效翼船系列重点项目总师石亚军应邀授课，200余名本科生到场聆听主题为《地效翼船——在天空与海洋的边界开拓未来航海》的讲座。本次校企联动授课打通校企学科、技术壁垒，立足一线工程研制实践，以西工大“三实一新”校风、总师育人文化为底色，带领青年学子走近海空跨介质装备真实研发赛道，读懂大国海洋装备背后的报国初心。
一、以工程实践为引：褪去科幻滤镜，还原地效翼船真实研制之路
讲座开篇，石总师结合单位多年试飞实测影像，对照大众熟知的科幻影视作品中的掠海载具，客观区分艺术想象与工程落地的现实差距，抛出贴合产业实际的思考命题：如何打造一款适配现代海洋开发、海上民生保障需求，可超低空掠海机动的跨介质装备？
石总师对比现有海洋、航空装备体系厘清定位：潜器侧重深海作业，飞机定位高空巡航；地效翼船依托地面效应形成独有的超低空掠海航行模式，是现代海洋装备体系中差异化补充装备。相关装备并非凭空构想，而是中船 702 所研发团队数十年持续攻关、反复试验迭代形成的工程成果，每一项性能指标、每一套系统方案，都来源于海量的计算、分析、模型试验、样机海试积累，是集体协作打磨出的实用化装备。
二、拆解地效翼船核心技术：集体攻关造就跨介质工程成果
讲座核心环节，石总师从地面效应基础原理、结构材料选型、全域环境适配、多场景应用价值四大维度，完整讲解地效翼船研发体系，全程立足团队协同攻关视角，客观介绍装备核心技术逻辑。
三、传承总师育人精神：扎根实干，在反复试验中锤炼科研底色
交流互动环节，石总师结合自身求学、从业经历，分享中船 702 所研发团队几代科研人深耕地效翼船领域的奋斗历程，结合西工大 “三实一新” 校风与校内总师育人文化，为在场青年学子指明成长路径。
石总师 2002 年毕业于西北工业大学飞机系飞行器设计与工程专业，作为西工大培养的学子，在校期间 “基础扎实、工作踏实、作风朴实、开拓创新” 的校风深刻影响其职业道路。从在校钻研基础理论的学生，到入职后跟随团队奔赴海上试飞场，在海风大浪中记录数据总结规律的青年科研人员，再到牵头重大型号、带领跨专业团队破解跨介质航行控制难题的总师，这条成长道路，也是无数三航科研人的共同轨迹。
四、立足全球产业现状，共绘青年参与海洋装备发展的实干蓝图
讲座尾声，他结合全球地效装备行业发展现状，客观梳理各国研发脉络，并寄语广大学子：海洋发展边界不止于深海与极地，未来地效平台大型化、无人化、技术跨界复合等方向，还有大量工程难题等待攻克。蓝图不是凭空设想，需要青年学子传承“为国铸剑” 初心，把理论知识转化为实实在在的海洋工程装备，助力海洋经济与海洋综合保障体系建设。
五、校企携手传递报国薪火，以协同育人夯实海洋强国根基
讲座收尾，航海学院学生代表接收地效翼船模型、主题文创笔记本等纪念礼品。本次馈赠承载着军工一线科研团队与高校学子之间的精神传承，也是校企协同育人的生动缩影。
“感悟深蓝” 系列课程核心目标是搭建校企交流平台，打破单一学科局限，让在校学生接触真实海洋工程研发场景。本次授课立足一线单位真实研发经验，传递西工大 “三实一新” 校风、总师实干育人理念与 “为国铸剑” 精神，引导青年学子认清校企分工定位、理解团队协同攻关的重要意义。在场学子接过纪念礼品，也接过海洋装备研发的报国接力棒，未来将持续深耕跨介质航行装备相关基础学科，以青春实干投身海洋强国建设，贡献西工大青年力量。
授课专家简介：
石亚军，2002年毕业于西北工业大学飞机系飞行器设计与工程专业，2022级航海学院工程博士研究生，中船集团702所跨域平台技术发展中心主任，研究员，地效翼船系列重点项目总师，江苏省产业教授，某重大任务专家组成员，某领域委员会委员，先后主持多型地效翼船研制，主导地效翼船标准体系构建，发表论文30余篇，获省部级科技奖励6次，获专利授权30项。
