# 重庆科创中心党支部传达学习学校第十四次党代会精神

10月10日下午，中心支部召开会议，传达学习学校第十四次党代会精神，研究部署贯彻落实措施。会议由党支部书记杨舜主持，中心全体党员参加了此次会议。
会议指出，第十四次党代会是在学校全面学习贯彻党的二十大和二十届二中、三中全会精神，深入学习贯彻全国教育大会精神，加快推进“双一流”建设、服务支撑强国复兴伟业的关键时期，召开的一次十分重要的会议。李言荣书记在党代会上所作题为《为党育英才 为国铸重剑 奋力谱写中国特色世界一流大学建设新篇章》的工作报告，全面总结了过去五年学校取得的突出成绩，深刻剖析了学校发展面临的新机遇，提出了“天下工大，世界三航”的远景目标，并具体解释了其核心内涵，系统提出发展举措，为加快建设中国特色世界一流大学指明了前进方向。
会议强调，中心全体党员要深入学习党代会精神，准确把握报告提出的新目标、新任务、新要求，强化党建引领，凝聚发展共识，开创发展新局面。一是积极推进国家级制造业创新中心筹建，培育国家重大科技基础设施，打造高水平国家战略科技力量；二是以概念验证中心、产业中试平台和产业创新综合体为切入点，加快中心内涵式发展，以航空航天特种轻质高强材料与加工的新质生产力赋能“416”科技创新战略布局和“33618”现代制造业集群发展。
