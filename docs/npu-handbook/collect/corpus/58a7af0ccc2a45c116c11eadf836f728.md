# 后勤部办公室党支部组织开展专题党课

为深入学习贯彻学校第十四次党代会精神，进一步提升党员政治素质，11月1日上午，后勤部办公室党支部组织全体党员开展学习贯彻学校第十四次党代会精神专题党课。此次党课由后勤部办公室党支部书记张文刚主持、后勤部办公室副主任郝东兴主讲，支部30余名党员参加了党课学习。
郝东兴首先对学校第十四次党代会的召开背景和大会主题进行了介绍。随后，他从学习贯彻学校第十四次党代会精神内涵和扎实落实学校第十四次党代会重点任务举措两个方面展开详细阐述，对学校近五年来的工作成效、高质量发展规律性的认识以及今后五年的主要任务等进行了全面回顾和学习，并结合后勤工作实际，指出下一步工作思路和举措。他强调，作为学校后勤系统的党员，要以“功成不必在我，功成必定有我”的使命感和责任感，为中国特色世界一流大学建设贡献后勤力量。
通过党课学习，大家纷纷表示，将深入学习贯彻党代会精神，强化责任担当，主动履职作为，以“永远在一线、永远在状态、永远在前列”的精神面貌和更加充足的干劲，在自己的本职岗位上，为学校“127”发展目标和“天下工大、世界三航”远景目标的实现添砖加瓦。（撰稿人：毛淑兰；审稿人：韩争胜）
