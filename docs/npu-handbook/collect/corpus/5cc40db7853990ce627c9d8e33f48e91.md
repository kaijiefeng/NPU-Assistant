# 2026年教职工太极拳24式培训活动通知-校工会（帮扶办）/ 妇女联合会

全体教职工：
为更好地推动全民健身活动持续开展，进一步提高教职工身体素质，丰富教职工文体生活、舒缓工作压力，由校工会牵头，联合党委教师工作部、体育部、离退休工作处开展2026年西北工业大学教职工健康同行活动，将于近期举办太极拳24式科学健身培训。现将有关事项通知如下：
一、活动目的
推广普及传统太极养生文化，传授标准规范的太极拳24式基础动作，帮助教职工舒缓筋骨、放松身心、改善体态，掌握科学、温和的日常健身方法，培养常态化运动习惯，营造积极健康的全民健身氛围。
二、活动安排
时间：2026年10月13日-10月27日，每周二18:30—19:30
地点：友谊校区大操场
主讲人：杨默衍（体育部教师）
三、培训内容
本次培训采用国家体育总局标准化推广的简化太极拳24式，动作简单易学、舒缓柔和，适配教职工日常健身锻炼，系统讲解全套动作要领、呼吸配合、发力技巧及养生功效，循序渐进开展教学，零基础亦可快速入门，具体教学内容涵盖全套24式基础招式。通过整套练习，可有效疏通经络、放松肩颈腰背、调节气血、平复心绪、改善久坐带来的身体僵硬、疲劳乏力等问题。
四、参与对象
全校教职工、家属、学生、社区居民均可参与
五、注意事项
1.请参与者穿着宽松透气的运动服、防滑软底运动鞋，便于肢体舒展，保障运动安全。
2.太极拳动作舒缓，运动前可简单热身，避免肌肉拉伤，运动过程中量力而行。
六、其他
此次培训活动免费，无需提前报名，可直接到场参与。如遇雨天、节假日、极端天气等特殊情况，当期活动自动暂停，不再另行通知。
校工会 党委教师工作部 体育部 离退休工作处
2026年10月8日
