# 后勤集团“服务育人”实践成果亮相杭州展会-后勤集团

近日，第十一届中国教育后勤展会在杭州隆重举办。在这场全国教育后勤系统的盛会上，后勤集团报送的《赓续四十年“服务育人”薪火 深耕劳动教育打造育人新格局》实践成果，经层层遴选，成功入选“党建引领后勤事业高质量发展”优秀实践成果，并在展会专题展区精彩亮相。这不仅是对我校后勤党建工作的高度认可，更是对后勤集团四十余年坚守“服务育人”初心的生动诠释。
党建引领，筑牢服务育人“主阵地”
此次展会的“党建引领服务育人实践”展区吸引了众多兄弟高校同仁驻足交流。展板背后，是后勤集团始终坚持以党的建设引领服务保障全链条的生动实践。作为一所具有深厚国防军工底蕴的高校，学校后勤早在1985年就在全国率先提出并坚持践行“服务育人”理念，并在1986年全国高校思想政治工作座谈会上作经验交流。虽然之后后勤改革不断深化，但后勤部门一直高举“服务育人”旗帜。尤其是近年来，后勤集团党委进一步将服务育人纳入党建工作体系，通过设立党员先锋岗，划定党员责任区，从宿管阿姨帮学生们缝补衣物、餐厅病号餐送餐上门，到校车预约系统的信息化升级，党员骨干带头示范，形成了“党委统筹、支部抓实、党员示范”的工作格局，让后勤日常服务保障充分传递育人温度。
劳动赋能，打造沉浸式育人“新课堂”
在展区现场，后勤集团从劳动教育视角强化服务育人实践的宣传视频备受关注。经过几年探索，后勤集团构建了劳动教育“进课程、进生活、进一线、进双创”工作体系。以党员骨干为核心组建师资队伍，开设的《大学生烹饪》《劳动教育理论与技能实践》等课程正式纳入学校教学体系，课程开放选课时受学生们“秒抢”，年覆盖学生230余人次；把主题党日设在食堂、公寓、绿地等一线，围绕传统节气开展美食制作、家居收纳、植物养护等实践活动，全年开设30余场覆盖4000余人次；连续5年举办校园文创设计大赛，吸引超800名学生参与，80余件优秀作品成功孵化落地，真正实现了“以赛促创、以创育人”。
成效显著，以暖心服务铸就“全国标杆”
近年来，后勤集团获评中国教育后勤协会“后勤服务育人劳动教育示范基地”，后勤文创团队获评全国教育后勤系统“最美后勤人（团队奖）”，校车预约系统获评全国教育后勤信息化建设典型案例。《大学生烹饪》课程获中央电视台专题报道，著名主持人白岩松评价该课程为“让大学生也能成为有品质的生活家”。在软科中国大学生满意度调查中，我校宿舍管理人员待人亲切、校园环境优美等指标位居全国高校前5%，师生满意度与认可度持续提升。
此次入选参展，既是一份荣誉，更是一份责任。后勤集团将以此为契机，继续传承和弘扬“服务育人”优良传统，不断激活后勤育人内生动力，为培养德智体美劳全面发展的时代新人贡献西工大后勤力量。（图：集团各单位 文：崔友婷 审核：邱若娟）
