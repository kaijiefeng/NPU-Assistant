# 管理学院2025级数据科学与智能管理拔尖班动态准入拟录取名单示公示

根据《西北工业大学管理学院数据科学与智能管理拔尖班动态进出管理办法》，学院开展了2025级数据科学与智能管理拔尖班动态准入工作，经过审核及复试，确定了拟录取名单，现将名单予以公示，公示期为2026年8月17日至2026年8月19日。
如有异议，请于公示期内以书面形式反映至联系邮箱。
