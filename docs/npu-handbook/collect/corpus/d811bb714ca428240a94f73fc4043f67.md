# 华南理工大学吴国林教授在我校讲授《量子科学的哲学问题》公开课-西北工业大学

5月23日下午，广东省社科基地华南理工大学哲学与科技高等研究所所长、科学技术哲学研究中心主任，国家“万人计划”哲社领军人才，中宣部文化名家暨“四个一批”人才(理论界)吴国林教授应邀来到西北工业大学，为我校师生带来一场主题为《量子科学的哲学问题》的公开课，我校约两百名学生参与了本次公开课。
吴国林教授本次讲授的主要内容分为量子力学的基本性质、量子信息的基本性质、量子计算、当代量子理论的真理问题以及当代量子理论的检验标准五大板块。量子科学蕴含了很多哲学问题，如量子物质的实在问题、量子力学中存在的因果问题、量子理论的真理问题等。量子力学的因果关系是通过由态函数所表示的量子系统的状态演化所体现出来的，由波函数或概率幅的演化来保证的。量子计算具有整体性的特征，量子计算器的优势在于对数据进行平行处理，某些量子算法具有加速能力，肖尔（Shor）算法能将指数复杂转变为多项式复杂。吴教授通过“原子重新排列为IBM字样”的例子说明这一量子文本的真理属于量子文本诠释学的真理，实践形态的真理就是实践本体论的真理，认识形态的真理就是实践认识论的真理，两种真理统一为实践真理。
吴教授通过清晰的物理学公式将量子纠缠态、量子隐形传态、开放目的隐形传态等复杂的物理学问题讲得深入且透彻。如何掌握作为前沿科学的量子力学？量子信息传递超光速是否破坏了因果律？量子信息实在是何种实在？量子纠缠是物理实在还是信息实在？如何检验当代量子理论的真伪？这些问题都能在吴老师的课堂上得到解答。现场学生专心听课，认真记录，本次公开课在全场热烈的掌声中圆满结束。
