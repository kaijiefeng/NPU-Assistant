# 奋进“十四五”，喜迎“二十大”——国际合作处党支部开展2022年度第三期双周青年论坛

6月22日下午，国际合作处党支部2022年度第三期双周青年论坛在友谊校区毅字楼732会议室顺利开展。国际合作处（国际教育学院）全体人员参加，论坛由国际合作处党支部副书记李自伟主持。
本期共有7位青年管理干部从自身业务出发，分别以“讲好中国故事 传递中国力量、构建可持续发展的国际化模式的思考-来华留学角度、打造“留学工大”品牌，提升学校国际声誉—“学在工大—全球暑期开放课程”项目为例、汉语教师应具备的素质能力探析、说服行为、加拿大高等教育体系简介&我校与加拿大高校的合作、中俄工科高校交流合作中的思考”为题进行了交流分享。每位青年干部立足本职工作，从对外宣传、留学生招生、留学生教育、校际交流合作拓展等角度深入研究，有方向性、针对性地思考，做到发现问题、探索解决问题的方法。
本期双周青年论坛的开展，通过研究分享，促进了青年党员对不同科室间的业务了解，激发了对自身业务的探索和思考，提升了国际合作处党支部的创造力和战斗力。善思则善行，善谋则善为。面对新形势、新环境、新任务和新目标，国际合作处青年党员将以创新实干、务实担当去破局求新，用初心使命来解师生之需。
