# 网络空间安全学院召开2023年招生宣传动员与政策培训会

为高效开展2023年招生宣传工作，扎实推进提高生源质量目标，确保招生工作顺利进行，2023年6月23日，我院召开招生宣传动员与政策培训会。党总支书记王震、常务副院长张盛兵、教学副院长刘志强、副书记禹亮，各招生组组长、招生老师以及学生以线上线下相结合的形式参加了会议。
会上，张盛兵副院长首先强调了招生宣传工作的重要性。他指出，招生宣传是提高生源质量的重要途径之一，对于提升学校知名度至关重要。渭南地区作为我校重要的生源基地，更要把招生宣传工作落实到位。学院领导班子要发挥带头作用，亲自深入到招生工作中去。要从物资、内容、行程等多方面做好充分的招生准备，重点宣传招生政策，推广学校推出的各项特色“王牌班”，吸引优秀学生报考。
招生组长王智江从2023年学校招生政策的变化、宣传方案、志愿填报细节以及其他相关注意事项等方面进行了详细解读，同时向与会人员发放了招生宣传材料。
本次招生宣传动员与培训会的内容详实充实，与会人员对学校招生政策和注意事项有了更深入的了解，学院各招生宣传小组将以更充分的信心和决心将本次招生宣传工作做好。
