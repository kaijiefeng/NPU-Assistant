# 离退休党委召开2026年秋季学期干部骨干大会

9月22日上午，离退休党委2026年秋季学期干部骨干大会于健翔楼五楼多功能厅召开。离退休党委领导班子、党委委员，离退休党支部、行政组长、文体活动队（组）、关工委骨干及离退休工作处全体工作人员参会。会议由离退休党委副书记、离退休工作处副处长陈仲昌主持。
会上，离退休党委书记、离退休工作处处长赵洪章传达学校暑假务虚会、新学期中层干部大会精神。离退休党委副书记、离退休工作处副处长马俊部署2026年下半年离退休党委重点工作，对离退休党员因私出国（境）、吴亚军“老年之星”评选、困难帮扶资助申报等事项的相关要求做了重点强调。
陈仲昌结合离退休工作实际，围绕意识形态、安全稳定等工作作专题宣讲。
下一步，离退休党委将严格落实学校党委各项工作部署，坚持党建引领，建强基层党组织，用心用情做好离退休服务保障，守牢安全稳定底线，凝聚桑榆力量，持续推动学校离退休工作高质量发展。
（撰稿：李晓珊；摄影：赵盛楠；审核：马俊）
