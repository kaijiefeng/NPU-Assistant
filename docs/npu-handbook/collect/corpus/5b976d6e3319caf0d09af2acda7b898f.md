# 西工大航海学院—中安智能海洋无人平台工程化联合实验室正式揭牌

9月10日，“开创深蓝，智领无人——UUV海上应用技术研讨会”暨西工大航海学院-中安智能海洋无人平台工程化联合实验室揭牌仪式在崖州湾科技城举行。来自地方政府、行业院所、兄弟高校的领导、专家、学者出席仪式。
中安智能董事长陆桦在致辞中表示，联合实验室的顺利揭牌，凝聚了校企合力与各方支持。双方将抢抓海洋装备产业机遇，打通水下无人平台技术攻关、工程研制到实际应用的创新链路，深化产学研协同合作。他表示，要以共建联合实验室为全新合作起点，优化合作机制，推动创新链、产业链、人才链深度融合，通过人才联培、实习实践、专家互聘等模式，打造优质校企创新平台，助力海洋强国建设与科技自立自强。
汉江国家实验室副主任刘文帅表示，期待以本次联合实验室建设为契机，充分发挥各方资源优势，聚焦水下无人装备领域，协同开展技术攻关与海上试验，加快推动科研成果向实际应用转化，共同助力海洋装备产业高质量发展。
航海学院院长潘光表示，联合实验室在科研条件保障、成果转化、产业空间供给、人才服务等方面的建设，离不开各方的鼎力支持，期待更多创新资源汇聚崖州湾，推动海洋科技成果落地生根。他希望，各方依托该平台在科研设施共享、关键技术攻关、海上试验验证等领域深化合作，稳步打通工程化落地关键路径。他表示，航海学院水下无人平台技术历经十余年迭代，自研产品可满足各类水下任务，但成果转化成效不足。今后，要抢抓人工智能机遇，融合西工大科研与中安智能软硬件研发优势，补齐短板，合力促进成果落地。他期待各方携手聚力，为我国海洋和国防事业贡献更多力量。
参会嘉宾实地参观联合实验室，并参加了“开创深蓝，智领无人——UUV海上应用技术研讨会”。会上，水下无人系统领域专家们，围绕UUV技术发展及海上应用作专题报告，并结合无人系统智能化、体系化发展深入交流研讨，共同探讨UUV海上应用的新方向、新场景与新机遇。
