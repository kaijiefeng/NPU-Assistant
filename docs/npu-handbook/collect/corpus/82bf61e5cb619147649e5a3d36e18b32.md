# 关于“翱翔学堂”教育平台上线运行的通知

全校师生：

为深入贯彻落实党的二十大精神，落实国家互联网+、教育数字化等重大战略部署，推进《西北工业大学互联网+教育实施方案》，以总师育人文化引领人才培养，更好支持数字教育背景下的教育教学改革，信息化管理处联合教务部、研究生院、国际教育学院建设了翱翔学堂智慧教育平台（以下称翱翔学堂），于2024年2月27日上线试运行。

翱翔学堂以高质量、多元化教育资源供给为核心，首创资源中心、知识图谱中心和教学数据中心的资源支撑框架，以AI智能能力开放平台为驱动，实现教育资源统一管理、知识图谱多元化应用、个性化知识推荐和以数据驱动的智慧教学评价等功能。本次上线版本可支撑教师开设线上课程、管理个人教学资源及录播资源、课程组共建课程公共资源，为同学提供多种形式的学习资源。

平台使用中遇到技术问题或意见建议，请联系信息化管理处信息系统管理办公室，咨询电话88493092；本科生课程相关问题请联系教务部课程办公室，电话88430588；研究生课程相关问题请联系研究生院学术学位培养办公室，电话88492192。

平台使用说明见附件《翱翔学堂操作手册-学生版》《翱翔学堂操作手册-教师版》。
