# 离退休党委召开春季学期离退休干部骨干大会

3月20日上午，离退休党委在友谊校区健翔楼五楼多功能厅召开2026年度春季学期离退休干部骨干大会。离退休党委班子成员、离退休党支部书记及支部委员、行政组长、活动队（组）负责人、关工委骨干、在职教职工等150余人参加了会议。会议由离退休党委副书记、离退休工作处副处长陈仲昌主持。
会上，离退休党委书记赵洪章传达了学校关于树立和践行正确政绩观学习教育相关精神；离退休党委副书记马俊传达了学校寒假务虚会、新学期中层干部会议精神，并就新学期离退休工作重点任务进行安排部署。
随后，陈仲昌围绕党的二十届四中全会、二十届中央纪委五次全会、2026年全国“两会”精神及“十五五”规划相关内容作专题宣讲，引导全体干部骨干深刻领会上级决策部署与学校工作要求，切实把思想和行动统一到各项工作安排上来，为实现学校“一十百千”发展目标和“天下工大，世界三航”远景目标贡献银发力量。
会议还就新学期意识形态、安全稳定等工作进行了部署，强调要进一步压实工作责任，筑牢安全防线，为新学期离退休各项工作平稳有序开展奠定坚实基础。
（撰稿：李晓珊 摄影：赵盛楠 审核：陈仲昌）
