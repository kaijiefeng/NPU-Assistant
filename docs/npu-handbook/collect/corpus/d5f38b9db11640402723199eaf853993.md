# 关于开通长安校区东大门、东篱菊苑西门和友谊校区东门的通知

全体师生员工：
随着疫情的有效控制，疫情防控工作的常态化，学校工作的日常化，出入车辆和人员数量逐渐增加。尤其在上下班高峰时段，经常出现人员、车辆排队检测进校，导致等待车辆占用校门外城市道路，造成长安校区东北门外和友谊校区西门外交通拥堵，存在一定的交通安全隐患。为减轻长安校区东北门和友谊校区西门的交通压力，方便教职工出入，减少人员聚集，经研究决定：
1.从10月22日起，友谊校区东门在已开通人行通道的基础上，准予教职工车辆通行。
2.从10月23日起，长安校区开通东大门、东篱菊苑西门作为教职工专用通道，凭学校有效证件出入，其余人员均由东北门、东篱菊苑西北门出入。
特此通知。
保 卫 处
2020年10月22日
