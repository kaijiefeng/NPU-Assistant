# 机关分工会关于开展2025年“粮心童行 耕读传家”亲子体验活动的通知-机关党委

机关各工会小组：
粮食，国计民生之基，农耕文明之脉。为传承粮食文化，厚植爱粮惜粮情怀，进一步助力机关教职工子女了解粮食知识、培养珍惜意识，学习粮食安全与食品安全要点，同时增进亲子情感交流，机关分工会将开展2025年“粮心童行 耕读传家”粮食文化亲子体验活动。现将有关事宜通知如下：
一、活动时间
6月7日（星期六） 12:30-17:30
二、活动地点
爱菊健康文化体验馆（灞桥区秦汉大道爱菊粮油集团）
三、活动内容
1.探秘智慧生产：参观米面油智能加工车间，探密大国粮仓与放心粮食加工的奥秘。
2.学习爱粮知识：参观“爱粮节粮”科普馆，学习爱粮节粮知识。
3.亲子烘焙时光：亲子动手DIY蛋挞、披萨。
4.科学试验站：淀粉密信
四、交通方式
集体乘大巴往返，11:10在友谊校区角楼集合出发。亦可自行前往，请在报名时注明。
五、参与范围与报名方式
1.本次活动面向未参加过爱菊体验馆活动的教职工开放，每个单位限报2个家庭，每个家庭最多3人（限1名儿童、最多2名家长），参与活动的孩子限3-18周岁。
2.即日起-6月5日12：00前扫描下方二维码报名，活动限报40组家庭，报满为止。
六、注意事项
1.活动期间务必遵守活动纪律，遵循工作人员指引，注意活动安全。
2.乘坐大巴往返的教职工请提前10分钟（11:00）至角楼乘车，自行前往者请于12:10前到达活动地点。
机关分工会
2025年6月4日
