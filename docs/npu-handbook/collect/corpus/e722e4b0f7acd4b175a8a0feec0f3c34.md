# 后勤部办公室开展充电桩安全专项检查

为切实加强校园安全生产管理，有效防范充电设施安全风险，杜绝电气火灾、设备故障等安全事故发生。3月23日至26日，后勤部办公室联合充电桩相关运营单位对校园内213台汽车充电桩及215组电动车充电桩开展安全专项检查，筑牢校园用电安全。
此次安全检查立足“预防为主、全面排查、立行立改”的工作原则，做到每一台充电桩、每一条供电线路、每一处配套设施都逐一核查、不留盲区。重点围绕充电桩硬件设备运行状态、供电线路与电路安全等方面进行排查，专业运维人员逐一检查充电桩机身是否完好、有无破损变形，充电枪头是否完好无损、连接是否牢固，设备散热系统、漏电保护装置、过载保护装置是否灵敏有效，杜绝设备带病运行。全面排查充电桩电源线路有无老化、破损等问题。此次全覆盖安全检查，全面摸清了校园充电桩的运行现状，彻底排查整改了一批潜在的安全隐患配件。
下一步，后勤部办公室将以此次专项检查为契机，建立充电桩常态化安全巡检机制，定期开展全面排查与局部抽检，持续完善设备维护、隐患整改、应急处置全流程管理机制，切实把安全生产责任落到实处，为全体师生打造安全、便捷的校园出行与生活环境。（撰稿人：张偲偲；审稿人：韩争胜）
