# 后勤部办公室党支部组织开展《我们的七月》观影活动

为深入学习贯彻习近平新时代中国特色社会主义思想和党的二十大精神，进一步推进党史学习教育常态化，3月22日下午，后勤部办公室党支部联合后勤集团机关党支部，组织全体党员在大唐西市中影国际影城观看党史题材纪录电影《我们的七月》。
电影以扶眉战役为背景，通过口述历史的方式，真实再现了中国人民解放军第一野战军二兵团第4军11师33团副团长高增岳和他的战友们英勇奋战、不畏牺牲的壮丽画卷。影片中，革命先辈们以满怀保家卫国的青春热血奔赴战场，他们的英雄气概和感人至深的战友情谊，他们的满腔热血和铮铮铁骨，深深触动了在场的每一位观众。
观影过程中，大家沉浸在紧张凝重的战争氛围中，深刻感受到了革命先辈们为了民族解放事业所付出的巨大牺牲。观影结束后，大家纷纷表示，如今的幸福生活来之不易，是无数革命先烈用鲜血和生命换来的。此次观影主题活动不仅是一次生动的党史学习教育，更是一次深刻的精神传承。它让我们更加坚定了理想信念，明确了前进方向。在以后的工作中，我们将继续发扬革命先烈的优良传统，以更加饱满的热情，为推动学校建设与发展贡献自己的力量。（撰稿人：毛淑兰；审稿人：韩争胜）
