# 【关工委工作】非遗扎染传文化，三代同心敬重阳——重阳节孝亲敬老文化活动顺利开展

10月13日下午，由校关工委主办，航空学院关工委、幼儿园承办，学生非遗研究协会协办的“非遗扎染传文化，三代同心敬重阳”重阳节孝亲敬老文化活动在香蜜园举行。航空学院“五老”代表薛璞、郭伟国、竹朝霞老师，航空学院大学生志愿者，幼儿园老师及小朋友等近百人参加活动，共同迎接重阳佳节的到来。
活动伊始，幼儿园林雅静老师向老教授们致以节日的问候和崇高的敬意，并介绍了重阳节的文化内涵，希望小朋友们在动手体验中感受中华优秀传统文化的魅力，在老少互动中涵养尊老敬老的品德。随后，非遗指导老师王幸围绕扎染历史、基础手法和安全操作规范进行讲解，并示范围巾、方巾创作技巧，帮助大家快速掌握扎染要领。
随后，三代人围坐一堂：老教授、大学生与小朋友携手合作，共同完成重阳感恩围巾的捆扎与浸染创作；小朋友们则在大学生志愿者“一对一”的协助下，自主设计花纹，亲手创作属于自己的扎染方巾。扎结、浸染、拆线、晾晒……一块块白布在指尖流转间幻化出千变万化的纹样，晾晒绳上方巾迎风舒展，现场欢声笑语不断。
献礼环节，大学生和小朋友共同将亲手参与制作的扎染围巾敬献给老教授，并送上重阳祝福。老同志们接过围巾，也接过了孩子们浓浓的敬老情意，脸上洋溢着幸福温暖的笑容。最后，全体人员合影留念，共同送上给爷爷奶奶的重阳节祝福。
此次活动以非遗扎染为纽带，深入践行“五老”助“五育”理念，将传统文化传承与孝亲敬老教育有机融合，让尊老敬老、感恩向善的优良品德在代际互动中薪火相传。未来，航空学院将持续深化关工委工作品牌建设，引导青年学子在文化传承中厚植家国情怀，在志愿服务中彰显青春担当。
