# 关于2026年创新型人才国际合作培养项目第一批人员选拔的通知

关于2026年创新型人才国际合作培养项目
第一批人员选拔的通知
各学院：
为持续加快“双一流”建设，推动国内外合作培养创新型国际化人才，国家留学基金管理委员会设立并实施创新型人才国际合作培养项目（以下简称“创新项目”）。我校现有9个执行中项目，覆盖11个国家的33所大学及科研机构。创新项目人员申报每年度分三次开展：2026 年人员申请网上报名及申请受理时间：第一批为3 月1 日-10 日；第二批为6 月1 日-10 日；第三批为9 月1 日-10 日。现启动2026年创新项目第一批人员选拔，欢迎老师和同学们积极申报。
一、申报时间节点
1. 2026年1-3月，联系外方导师确认接受意向，并向相关项目负责学院提交报名材料；
2. 2026年3月1日前，各学院开展人员选拔（涉及学费资助人员须进行面试），确定各项目候选人并公示；
3. 2026年3月1-5日，学院公示的候选人登录国家公派留学管理信息平台进行网上报名，并按要求准备上传的电子版材料，请务必在要求的时间内完成网上填报（需给候选人预留退回和修改，以及国际合作处进行人员公示的时间）；
4. 2026年3月8日前准备好电子材料发送至项目负责人，由项目负责人汇总后发送至国际合作处；
5. 2026年3月10-20日前，国际合作处将候选人的申请材料在线提交至国家留学基金委，包含单位公函、推荐人员名单等材料；
6. 2026年3月20日-4月，国家留学基金委组织对各单位推荐候选人进行材料审核，确定拟录取人员名单；
7. 2026年5月底前，国家留学基金委公布录取名单，留学人员可登录国家公派留学管理信息平台查询录取结果，下载打印录取文件；
8. 2026年6月起，被录取人员办理签证、预订机票等派出手续。
二、申报材料及材料提交方式
学生及项目学院无需再向国际合作处提交纸质版书面申请材料，均提交电子版材料，要求如下：
1. 申请材料列表（以博士、联培博士、硕士、联培硕士为例）：
（1）《国家留学基金管理委员会出国留学申请表》（研究生类）
（2）《单位推荐意见表》（表头不填，其余部分由学院填写并签字盖章）
（3）邀请信/入学通知书
（4）国外导师简历
（5）外语水平证明
（6）学习计划（外文）
（7）成绩单（自本科阶段起）
（8）学费明细（仅涉及学费资助人员需提供）
（9）最高学历/学位证书
（10）有效的《中华人民共和国居民身份证》
申请材料具体说明请点击：https://www.csc.edu.cn/article/3801 （一定要看）
2. 申请材料列表及说明（高级研究学者、访问学者、博士后）请点击：https://www.csc.edu.cn/article/3800 （一定要看）
注：如申请身份为访问学者、博士后或高级研究学者，请先向人事处提交纸质版情况说明，若符合人事处派出标准即可申请项目，并将盖章后的电子版情况说明附于材料中。
3. 以上材料须按照列表顺序向国际合作处提交填写完成的电子版，命名要求如下：
（1）所有材料应按顺序放在一个文件夹内。文件夹命名格式为：
“项目名称_留学身份_姓名，例：XX创新项目_联培博士_姓名”。
（2）所有材料须提交PDF格式，文件命名格式为：“学生姓名_材料序号_材料名称，例：张三_1_出国留学申请表”；
（3）文件夹打包发送至项目负责老师邮箱，项目负责老师整理后以“XX项目_2026年第一批”[已脱敏:邮箱]
注：材料（1）学生请务必签字；
材料（2）请务必填写所有信息，表头不填，学院领导签字并盖院章；推荐意见需要另外提供word版，便于上传；
材料（10）除提供学院盖章PDF版，需要另外提供Word版；
