# 航海学院赴重庆、武汉等地调研并举行同等学力研究生见面会

为持续加强调查研究和校企协同育人工作，聚焦国家战略急需，为“总师型”人才培养奠定坚实基础，10月18日至20日，航海学院副院长曾向阳、研究生教学秘书罗钰、李淼、席杰一行赴重庆（中国船舶重庆公司）、宜昌（中国船舶第七一〇研究所）、武汉（中国船舶第七一九研究所）开展调研和交流，同时与2022级、2023级鄂渝班同等学力研究生进行座谈。
1、中国船舶重庆公司
10月18日，曾向阳带队到中国船舶重庆公司进行座谈交流。重庆公司党委书记、董事长、我院校友徐猛，重庆公司、中船海装相关部门负责人参加会议。
会上，徐猛详细介绍了重庆公司的发展历程，在技术研发、生产经营、人才队伍建设等方面的进展及成效，以及学校毕业生在公司的工作情况和重庆公司职工在职攻读同等学力研究生的情况。徐猛表示，希望双方在人才培养、科技创新等方面进一步深化交流合作，充分发挥各自优势，进一步推动重庆公司高质量发展。
曾向阳表示，重庆公司在产业发展、人才培养需求等方面与西北工业大学高度匹配，航海学院作为学校“三航”特色学院之一，在船舶与海洋工程、水中兵器等领域拥有丰富的科研资源和优势师资，双方可在科研项目、人才培养等方面进一步加强交流互鉴，促进共同发展。会后，学院与重庆地区同等学力研究生进行座谈交流。
2、中国船舶第七一〇研究所
10月19日，曾向阳带队赴中国船舶集团有限公司第七一〇研究所，参观了中国船舶七一〇所展览室，全面了解中国船舶七一〇所发展历程以及为国防现代化建设作出的突出贡献。
中国船舶七一〇所副总工程师郑晗、人力资源部主任钟磊、科技部副主任贾宏春、人力资源部副主任丁颉以及相关工作人员参加座谈交流，双方深入探讨了研究生培养过程的关键问题。会后，学院与中国船舶七一〇所同等学力研究生进行座谈，双方表示提升卓越人才培养质量，培养更多“总师型”人才雏形，为强国建设、民族复兴贡献更大力量。
3、中国船舶第七一九研究所
10月20日，曾向阳带队赴中国船舶集团有限公司第七一九研究所进行调研座谈，探讨同等学力研究生招生培养细节。第七一九研究所人力资源部主任艾昶宏，研究室主任左亮周，副主任王益元，副主任张文金参加座谈。
艾昶宏详细介绍所技术和人才需求，表示希望双方进一步加强全方位、多领域合作，共同培养高层次人才。曾向阳强调，从建设国家战略人才力量、推进中国式现代化全局高度出发，期待双方携手并进，在科研、人才培养等方面挖掘新的合作方向，拓展新的合作渠道；在共同培养高层次人才方面，发挥各自特色优势，方能握指成拳、形成合力，构筑人才高地，铸造大国重器。随后，学院与中国船舶七一九所同等学力研究生进行交流。
航海学院持续落实“走出去，请进来”的工作模式，以同等学力硕博士研究生和工程博士培养工作为契机，加强与行业内单位的沟通协作，共同致力于高层次人才培养和高水平科研合作，以钉钉子精神落实“127”举措。抓铁有痕、踏石留印，加强校企联合，深化产教融合培养改革，着力培养更多“总师型”人才雏形，加快推进中国特色世界一流大学和一流学院建设。
