# 材料学院科教实践与材料分析创新中心2026年秋季学期扫描电镜平台设备培训通知

为进一步优化大型仪器共享服务，缓解热门设备预约压力，提高运行效率与服务水平，支撑“总师型”人才培养与高水平科研成果产出，助力“一十百千”发展目标和“天下工大、世界三航”远景目标的实现，促进高质量、高水平、高标准“三高”发展，材料学院科教实践与材料分析创新中心（以下简称“中心”）计划开展2026年秋季学期扫描电镜平台设备培训，现面向校内师生开放报名，具体培训计划见下表。培训报名要求和注意事项安排如下：
1、报名参加培训的人员须为全日制在校学生（包括本科生、硕士生和博士生）。为保证培训效果，本期培训每台设备每个课题组报名人数不超过2人。
2、报名参加培训学生请如实填写报名申请表（见附件），学生报名参加培训须获得课题组负责人或导师的签字确认。
3、本次培训采用线上报名方式，培训申请表签字版发送至邮箱smarc@nwpu.edu.cn，中心将按照提交申请表的时间顺序确定参加培训学生名单。
4、参加培训后能够熟练操作设备的学生可以预约中心大型仪器设备折扣机时。中心将从参加培训的学生中择优选拔热心公共服务事业、有责任心且愿意成为设备助管的学生作为中心相关仪器设备的助管。助管学生可优先预约所管设备7×24h机时，同时，中心将根据服务情况给予助管学生一定的7×24h机时奖励，具体奖励可详细咨询中心办公室。
5、本次所有设备培训报名截止时间为2026年9月21日16:00。
6、其它未尽事宜请联系中心办公室029-88493450（曹老师）。
