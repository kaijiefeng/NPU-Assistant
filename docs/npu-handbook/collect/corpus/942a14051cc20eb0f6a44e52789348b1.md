# 党建引领聚合力 医教协同护健康 ——医技公卫党支部与国际合作处党支部开展共建主题党日活动-西北工业大学医院

12月18日下午，校医院医技公卫党支部与国际合作处党支部在友谊校区阶三会议室联合开展“党建引领聚合力，医教协同护健康”共建主题党日活动。校医院党总支书记乔辉、副院长孙伟光，国际合作处党支部书记孔杰、副处长向丹、陈俊及双方支部党员同志参加活动。活动由国际合作处党支部副书记李自伟主持。
活动伊始，双方党支部书记分别介绍了支部建设情况。医技公卫党支部书记盛秋简要介绍了近几年支部及所辖科室党建与业务融合的相关举措以及取得的些许荣誉。国际合作处党支部书记孔杰简要回顾了“十四五”以来在中外合作办学、国际交流、合作与引才方面取得的成效，并对校医院在医疗保健、服务育人等方面的工作给予了充分肯定。
乔辉对双方共建提出了期待，希望与国际合作处加强常态化交流学习，围绕留学生健康管理服务、涉外健康保障机制建设等方面深化协作，共同探索医教协同的新路径。医院将以此为契机，持续优化服务流程、升级医疗设施、细化保障举措，为全校师生及国际留学生群体提供更精准、更贴心、更专业的优质医疗保障。全体医务人员将始终秉承“小（校）医院孕育大医生，小（校）医院做好大保障，小（校）医院承载大担当”的理念，努力为学校实现“一十百千”发展目标和“天下工大，世界三航”远景目标贡献健康力量。
在与会党员的见证下，医技公卫党支部书记盛秋与国际合作处党支部书记孔杰共同签订了支部共建协议，标志着双方在组织共建、资源共享、服务联动方面迈出坚实一步。
随后，医院中医理疗科副主任医师袁平开展了题为“中医健康养生”的专题讲座，结合秋冬常见健康问题，深入浅出地讲解了中医防病保健知识。中医理疗师朱雅带领大家练习颈椎保健操，现场气氛积极活跃。
此次共建活动以党建为纽带，促进了医疗健康与国际交流工作的深度融合，为今后进一步发挥各自优势、服务师生健康与国际合作奠定了良好基础。
