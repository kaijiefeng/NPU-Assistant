# 人工智能学院/无人系统技术研究院开展青年教师发展支持培训

为深入贯彻落实上级关于加强教师队伍建设的重要精神，进一步强化教师队伍职业素养培育与思想政治建设，6月2日，学院/研究院邀请学校科学技术研究院军工科研与成果处副处长段元欣，学校人力资源部副部长、党委教师工作部副部长林楠，围绕有组织科研、师德师风建设等开展青年教师发展支持培训。学院/研究院领导班子全体成员，各科研团队代表，近三年新入职青年教师、新遴选导师，办公室相关人员等参加，培训由学院/研究院党委书记毛昭勇主持。
段元欣以《拓展项目申报渠道 夯实科研发展根基》为题，全面介绍科研渠道拓展及项目申报工作。通过分享渠道拓展中如何挖掘整合资源、搭建协同网络、打通转化路径等策略思路，详解项目申报中如何凝练选题、规范材料撰写、对标优化方案等核心要点，切实帮助青年教师提升了科研资源统筹与立项申报实操能力。
林楠以《大力弘扬教育家精神 全面加强师德师风建设》为题，带领大家系统学习习近平总书记关于师德师风的重要论述、国家及学校师德师风建设系列规章制度等，并通过剖析真实反面典型案例，深刻揭示了违规违纪行为的危害与后果，精准敲响了遵守师德规范的纪律警钟，有效引导全体教师知敬畏、存戒惧、守底线。随后，学院/研究院领导班子成员带领青年教师围绕培训内容开展交流研讨和经验分享。
本次培训聚焦科研能力提升、师德师风涵养等关键环节，为青年教师成长提供了有力支撑。参训教师纷纷表示，将把学习成果转化为科研动力与育人实效，勇担使命、奋发作为，为学院/研究院高质量发展，为学校“双一流”建设贡献更大力量。
