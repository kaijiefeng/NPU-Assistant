# 赴白俄罗斯国家科学院开展合作交流

近日，莫航学院党委书记向丹应邀赴白俄罗斯国家科学院开展合作交流。访问期间，向丹与白俄罗斯国家科学院主席团副主席阿列克谢・特鲁汉诺夫举行会谈，并同白俄罗斯国家科学院大学副校长德米特・玛扎查克开展专题座谈，就深化双方务实合作等事宜进行深入沟通，持续推进学院与白俄罗斯国家科学院的务实合作。
会谈中，阿列克谢·特鲁汉诺夫对向丹的到访表示热烈欢迎。他回顾，过去两年，在双方通力协作下，白俄罗斯国家科学院中国分院协议正式签署并揭牌落地。他期待以西北工业大学莫航学院为全新合作支点，共同拓展多层次、多领域交流，一体推进双方教育科技人才协同发展。白俄罗斯国家科学院国际合作局局长塔尼亚·布兰尼克等参加会谈。
座谈中，德米特·玛扎查克介绍了白俄罗斯国家科学院大学的学科设置和人才培养体系，并对西北工业大学莫航学院的办学模式、学科特色和办学成效给予高度赞许，期待双方在推进高层次专家互访、人才培养等方面拓展新的合作增长点，推动双方合作迈上新台阶。
在白期间，白俄罗斯国家科学院第一副主席维塔利·扎列斯基、前第一副主席奇日克·谢尔盖等与向丹亲切会面，就相关合作议题进行交流。
下一步，学院将紧抓合作机遇，持续巩固拓展交流成果，推动各项共识落地见效。
