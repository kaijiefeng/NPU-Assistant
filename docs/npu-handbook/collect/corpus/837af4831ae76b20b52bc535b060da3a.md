# 校友领航｜我院2023届校友覃军受邀做香港高校申博及读博经验交流分享

为发挥优秀校友榜样作用，助力研究生科学规划升学发展路径，10月28日晚，“蒲公英职航计划”辅导员工作室联合院研究生会推出“校友领航”第7期线上分享会。本次活动特邀我院2023届校友、香港城市大学翻译及语言学系博士研究生覃军，围绕香港高校申博与读博相关经验作线上分享。辅导员赵青、三十余名硕博研究生参会，活动由院研究生会学术科研部陈嘉怡主持。
分享中，覃军结合自身申请历程，系统梳理香港高校博士申请时间线与材料规范。他建议同学提前一年半启动规划，对照自身研究方向、导师在研课题与成果情况精准择校选导师；并重点讲解研究计划、个人陈述、英文简历、语言证明、套磁邮件等核心材料准备要点。随后，围绕在读培养与科研成长，覃军介绍了港校入学办理、学分修习、助教工作、资格考核、年度进展报告、学位答辩等培养环节。结合自己从口译转向认知语言学的跨学科研究经历，他建议主动补齐编程、统计等跨学科技能，鼓励大家及时凝练阶段性成果，积极参与国际学术会议交流。会后，同学们就各自关心的问题与覃军进行了交流互动。
本次分享内容务实、指导性强，清晰解答了赴港申博、在读科研中的诸多疑问，为有境外深造意向的研究生提供了参考，有效发挥校友朋辈引领效能，引导同学们提前谋划、笃学深耕，走好科研求学之路。（文字：何臻；图片：何臻 卢思宁；审核：张桑桑）
