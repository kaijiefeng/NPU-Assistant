# 同济大学保卫处赴我校调研安全保卫工作

5月8日，同济大学保卫处赵佳敏副部长、刘胜乾副部长一行赴我校保卫处调研座谈。保卫处朱建军处长、薛康副处长及相关工作人员参加了调研座谈会，会议由朱建军主持。
朱建军对同济大学保卫处的到访表示热烈欢迎，双方互相介绍了参会人员，并观看了我校宣传片。薛康介绍了我校保卫处机构设置和人员编制，并从校园治安综合治理、队伍建设、安全宣传教育等方面介绍了保卫工作开展情况。随后，与会人员围绕人事管理机制、校园治安管理、交通管理等重点难点问题展开交流讨论，赵佳敏对我校安全保卫工作取得的成效表示赞赏，并邀请朱建军处长带队赴同济大学调研交流。
下午，赵佳敏副部长、刘胜乾副部长一行赴长安校区实地考察校卫队宿舍、综合训练场等，并参观了校史馆。王坤庆陪同调研，并详细介绍了长安校区保卫工作开展情况，分享了保卫处与其他部门协调联动开展长安校区安全保卫工作的经验体会，双方进一步开展工作交流。
双方表示将以主题教育为契机，加强调查研究，进一步深化两校保卫工作交流合作，相互取长补短，增进本领，提升校园治安管理水平和服务质量。（文：王晙；图：李文博、王晙；审核：薛康）
