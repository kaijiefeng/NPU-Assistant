# 西北工业大学网络空间安全学院开题答辩（秦郡蔓）

一、开题答辩题目：面向自动驾驶的智能汽车安全防护方法
二、开题答辩人：秦郡蔓
三、开题答辩时间：2025年4月27日上午10:00
四、开题答辩地点：西北工业大学友谊校区爱生楼401会议室
五、开题内容简介：目前学术界及工业界致力于打造“聪明的车、智慧的路、灵活的网”，即具有自动驾驶功能的智能汽车。自动驾驶智能汽车有三大重要板块，即感知环境信息的车载传感器、传输电子控制单元数据的车内网络、与车外道路基础设施/车辆/行人/云服务器等交换信息的通信技术。虽然智能汽车带来了更好的出行体验，但同时也带来了更多的威胁，因此关注自动驾驶智能汽车的安全问题刻不容缓。本文从环境感知、车内网和车际通信三个方面对自动驾驶智能汽车的安全防护进行阐述。
六、开题答辩人简介
秦郡蔓，学号为2022100767，出生于1996年12月，安徽人，就读于西北工业大学研读网络空间安全专业，导师为刘家佳教授。
