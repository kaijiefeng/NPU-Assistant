# 外国语学院组织教师开展研学实践活动

为扎实开展树立和践行正确政绩观学习教育，深入推进师德师风建设。7月2日，外国语学院党委书记王高祖带队，组织学院教师赴汉中南郑区川陕革命根据地纪念馆、城固县古路坝国立西北工学院办学旧址开展研学实践活动。
川陕革命根据地纪念馆是全国爱国主义教育示范基地，也是陕西省廉政教育基地。纪念馆由展陈馆、爱国主义教育广场、纪念碑、何挺颖烈士纪念广场组成，主展馆以“陕南红了半边天”为主题，分7个单元展示川陕革命根据地陕南苏区的革命活动。大家深入了解川陕革命根据地陕南苏区的革命历史，深切缅怀革命先烈。
在古路坝国立西北工学院办学旧址，城固博物馆前馆长苟保平生动讲解了1938年多所高校辗转西迁、扎根城固办学的历史。他介绍，汉中古路坝与重庆沙坪坝、成都华西坝并称抗战“三坝办学”。古路坝的师生在物资极度匮乏、环境闭塞的条件下艰苦求学，先后走出了一千多位毕业生，其中包括师昌绪等十余名两院院士。在场教师无不动容，纷纷表示将传承先辈教育救国的赤诚初心，把古路坝精神融入教书育人全过程。
此次活动依托校党委教师工作部“教师发展支持计划”，将革命传统教育、爱国主义教育与廉洁文化教育有机融合，让教师在实地研学中触摸红色历史、感悟校史底蕴。大家一致表示，将传承红色基因，赓续古路坝薪火，牢固树立和践行正确政绩观，坚守为党育人、为国育才初心使命，以奋进姿态为学校“双一流”建设和学院高质量发展贡献力量。（文/王开薇；审稿/王高祖）
