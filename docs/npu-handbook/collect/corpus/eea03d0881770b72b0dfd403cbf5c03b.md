# 学院召开AI时代数学专业分层次教学与人才培养改革务虚会

为全面落实立德树人根本任务、加快推进人工智能赋能教育教学综合改革，9月3日下午，学院在海天苑E102会议室召开AI时代数学专业分层次教学与人才培养改革务虚会。数学分析、高等代数、抽象代数、概率论、复变函数论、实变函数、数值分析、偏微分方程、数学建模等课专业核心课教师参加会议。会议由本科教学副院长郭千桥主持，聚焦AI时代数学专业分层次教学、核心课程建设与人才培养改革展开深入研讨。
在分层次培养方面，与会教师围绕强基班、拔尖班与普通班的培养定位、核心课程设置、课程高阶性建设、学分绩点规范化等问题展开交流，提出要坚持分类培养、因材施教，构建梯度清晰、各有侧重的培养方案，切实提升拔尖创新人才自主培养质效。在考核评价方面，要积极探索多样化的考核方式，推进过程性考核、开放性作业、项目制课程等改革，适当提高平时成绩占比，使考核真正反映学生对数学的深刻理解与独立思维能力。
与会教师一致认为，AI时代正在深刻重塑数学教学的形态与范式，教师应从传统的“知识传授者”转变为“问题设计师”，善于运用启发式、追问式教学，引导学生聚焦问题本质、深挖内涵、构建假设、提出方案，实现由“解题”向“提出问题、凝练问题”的能力跃升。
会议提出了下一阶段重点工作：一是根据讨论意见，进一步完善形成数学专业核心课程分层次教学方案；二是举办AI赋能数学教学系列论坛，邀请院内骨干教师和国内相关领域专家分享经验，推动互学互鉴、共同提升；三是鼓励各课程组结合课程特点，积极探索AI融入教学的具体路径，推动各项改革举措落地见效。
此次务虚会统一了思想、凝聚了共识。学院教师将以此次会议为契机，坚持立德树人根本任务，以教育家精神引导教师潜心教书育人，以科学家精神激发学生投身基础研究的坚定信念，持续提升拔尖创新人才自主培养质效，推动AI时代学院数学专业人才培养高质量发展。
