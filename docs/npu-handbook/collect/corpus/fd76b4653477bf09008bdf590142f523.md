# 跨省相聚谋提升 互学互鉴共发展——哈尔滨工程大学、太原理工大学、山西师范大学档案同仁莅临学校档案馆调研交流

11月4日、11月9日，哈尔滨工程大学、太原理工大学、山西师范大学档案同仁莅临档案馆开展专题调研交流。
座谈会前，档案同仁先行参观了档案馆文化长廊。在沉浸式体验中深入领略西工大深厚的历史积淀、代代传承的红色基因与“航空报国”的精神内核，直观感受学校在不同历史时期勇担国防使命、坚守育人初心的精神传承。
座谈会上，馆长戚红梅对档案同仁表示热烈欢迎，围绕档案馆基本情况、重点工作和档案数智化建设分享了学校档案馆的实践经验。
哈尔滨工程大学档案馆馆长李凯、太原理工大学档案馆馆长王正强、山西师范大学档案馆馆长张宏业分别介绍了本馆档案工作开展现状，并围绕档案馆管理体制与制度体系建设、一校多区档案运行模式、档案管理模式、数字化加工规范、安全保密管理、档案资源利用等业务内容分享经验，展开深入交流。
此次系列调研交流，搭建起馆际沟通协作的桥梁，大家互学互鉴、取长补短，表示将把学习成果转化为务实举措，共同推动高校档案工作提质增效。
