# 后勤集团开展廉洁纪律专题培训-后勤集团

4月28日下午，后勤集团“翱翔大讲堂”第32期专题培训开讲。集团特邀学校关工委“银发宣讲员”、原后勤集团纪委书记孙明亮同志，以《树立和践行正确的政绩观，做遵规守纪守法的模范》为题作廉洁纪律专题培训，集团各单位业务主管及以上人员、关键岗位员工等100余人通过线上线下相结合方式参加。
培训中，孙明亮围绕树立和践行正确政绩观、严守党的纪律、恪守国家法律、严守制度规矩四大模块展开系统讲解。他深入阐释“立党为公、为民造福，科学决策、真抓实干”十六字方针，解读正确政绩观“高质量发展、出实招求实效、打基础利长远”三条实践标尺，引导参训人员坚决纠治政绩观偏差，以实绩经得起实践、人民、历史检验。
在纪律与法治教育环节，孙明亮详细解读2023年新修订的《中国共产党纪律处分条例》，系统阐释政治、组织、廉洁、群众、工作、生活“六大纪律”红线底线；对《中华人民共和国公职人员政务处分法》进行要点拆解，明确政务处分种类、适用情形与权利救济途径；结合典型案例剖析形式主义、形象工程、特权行为等突出问题，用身边事教育身边人。
针对后勤工作实际，他重点解读《事业单位人事管理回避规定》，明晰岗位回避、履职回避的适用情形、操作流程与责任追究，强化关键岗位风险防控意识，推动依规依纪依法履职。
此次培训主题鲜明、内容务实，进一步强化了后勤干部职工的宗旨意识、纪律意识与规矩意识。参训人员纷纷表示，将以此次培训为契机，牢固树立和践行正确政绩观，把廉洁自律要求融入服务保障全过程，以实干实绩推动后勤事业高质量发展，为学校“一十百千”发展目标提供坚强支撑。
