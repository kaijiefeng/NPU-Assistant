# 康复骨外科-西北工业大学医院

随着社会文明程度的不断提高及现代生活方式的演变，人们对健康的关注度越来越高。为了适应人们对康复理疗的需求，我院适时开设康复骨外科病区。病区现有专业技术人员，其中副主任医师8名，住院医师1名，康复治疗师5名，主管护师4名，护师3名，护士2名。人员均持证上岗，具有丰富的临床经验。
具体业务范围如下：
一．康复理疗专业组： “陕西省康复联盟”会员单位。长期聘请陕西省人民医院专家定期坐诊、业务指导。全科医护人员服务热情周到，具有扎实的理论知识及丰富的临床经验，技术精湛，竭诚为广大患者服务。
【诊疗范围】
拥有专业的医师和康复治疗师。主要设备有：手功能智能治疗仪、电动起立床、减重步态训练、足踝矫形器、多功能康复训练器、综合性作业训练、神经肌肉电刺激治疗仪、冲击波治疗仪、干扰电治疗仪、磁振热治疗仪、超短波短波治疗仪、微波治疗仪、电脑中频治疗仪、中药熏蒸治疗仪、骨质疏松治疗仪（脉冲磁场治疗仪）、红外线治疗仪、电针治疗仪、牵引治疗仪等。
门诊（国医馆）常年有副主任医师坐诊，擅长治疗康复科、骨科及中医科常见病、多发病及疑难疾病的诊治。长期聘请陕西省人民医院中医科曹晓菊主任医师来国医馆坐诊。主要开展项目：中医药辨证施治；中医养生、保健；针灸、推拿、拔罐、刮痧、艾灸、蜡疗、耳穴等；理疗；康复治疗；三伏贴、三九贴治疗等。
住院部开展脑卒中、颅脑损伤、脊髓损伤等导致的肢体偏瘫、吞咽障碍、言语障碍、大小便失禁等。
二．外科专业组：我科是“西北中医肛肠联盟成员单位”，拥有现代化的手术室和治疗设备，具有多年临床经验的副主任医师坐诊，开展诊疗范围如下：
1.头部肿瘤，颈部包块切除术，甲状腺包块切除术。
2.浅表良性肿瘤切除术，乳腺包块切除术，高频电离子腋臭治疗术，副乳切除，微创胸腔闭式引流术。
3.胆囊结石，胆总管结石，胆囊炎，胆管炎，胰腺炎，沁尿系感染等疾病的保守治疗。胃十二指肠溃疡及穿孔，腹膜炎，肠梗阻，阑尾炎等病症治疗。腹股沟疝手术治疗。
4.痔疮，肛瘘，肛裂，肛周脓肿，骶尾部藏毛囊肿等肛肠疾病的治疗（痔疮PPH手术），在肛肠治疗仪的加持下，相得益彰，形成独特的专科特色。
5.包皮环切吻合术，鸡眼，跖疣穴位注射治疗术，烧伤治疗等。
6.精索静脉曲张，大隐静脉曲张，睾丸扭转等疾病的手术治疗。脉管炎等周围血管性疾病的保守治疗。
三．骨科专业组：拥有先进治疗设备，具有多年临床经验的副主任医师坐诊，开展诊疗范围如下：
1.各种骨科常见病、多发病，如骨质疏松症，中老年性骨关节病，颈椎病，腰椎间盘突出，滑膜炎，痛风等保守治疗，采用中西医结合治疗，缓解临床症状，延缓进一步发展。
四肢骨折脱位（锁骨骨折、桡骨小头骨折、尺桡骨骨折、掌指骨骨折、肩锁关节脱位、肩关节脱位、桡骨小头半脱位、掌指关节脱位）、周围神经卡压、骨及软组织肿瘤（骨软骨瘤、内生软骨瘤、血管瘤、血管球瘤）、包块（脂肪瘤、腱鞘囊肿、神经鞘瘤）、狭窄性腱鞘炎、开放性外伤、手部创面的修复、四肢软组织感染（甲沟炎）等。
2. 可开展的手术:上肢及足部骨折切开复位内固定术、内固定取出术、关节脱位手法复位、周围神经卡压（肘管综合征、腕管综合征）松解、狭窄性腱鞘炎腱鞘部分切除术、包块切除术、开放性外伤清创探查修复术、手部创面皮瓣修复术、甲沟炎甲根部分切除术等。
3.特色治疗项目：腰椎电动牵引、颈椎电动牵引、智能中药熏蒸治疗床、骨质疏松治疗仪、穴位贴药、关节腔注射及各种疼痛治疗等。
