# 第30期“逐梦三航”教师沙龙——剑桥大学、墨尔本大学国际化研修项目分享会顺利举办-西北工业大学

为深入推进教师国际化能力提升，促进思政课教学改革创新，4月30日，由党委教师工作部主办、马克思主义学院承办的第30期“逐梦三航”教师沙龙——剑桥大学、墨尔本大学国际化研修项目分享会暨思政课教师集体备课会成功举办。会议由马克思主义学院副院长贺苗主持。30余位教师参与交流。
本次沙龙邀请参与剑桥大学研修的薛金慧副教授、吕天择副教授，以及参与墨尔本大学研修的杨一凡助理教授、陈千千助理教授、吕焰助理教授、王驰助理教授依次进行了分享。
薛金慧介绍了“EMI”以英语为媒介、以学科知识为核心的教学模式，重点分享了ICQ、CCQ提问技巧、互动式课堂组织、形成性评价、学术讲座语言等实用教学方法，并结合沉浸式校园体验与跨文化交流实践，阐述了从“能讲”到“善教”的教学理念转变，提出将EMI教学法融入思政课堂，提升课堂参与度与培养批判性思维。
吕天择为大家分享了剑桥大学格顿学院、圣约翰学院、国王学院等知名学院的办学传统与育人特色，介绍了剑桥技术博物馆、格顿学院博物馆等场所的文化底蕴与教育价值，并结合海外高校教学理念、教学方法等畅谈现行教学模式在网络资源与AI时代背景下的未来发展路径思考。
杨一凡围绕课程内容设置、知识与技能、思维与能力、视野与心态几方面向大家进行了分享，主要立足教师专业成长与课堂教学视角，展示了人工智能赋能教育的先进理念、实操模式与课堂应用路径。
陈千千分享了在墨尔本大学的见闻感受，以及课堂教学方面的思考体会。聚焦“评估与反馈”教学技能，介绍了从终结性评估向持续性形成性评估转变的多元化评价模式，以及如何通过具体、及时、可落地的反馈指导，精准助力学生成长，提出了分层分组教学、跨背景学生能力评估等可借鉴的教学思路。
吕焰带来了关于互动式教学、分布式领导力、批判性思维培养等前沿教学方法的介绍，并结合布鲁姆教育目标分类法，分享了将AI技术合理应用于课程设计、学情分析、教学评价等环节的实践路径，提出了从课堂认知到实践落地的转化思路，为推进思政课教学创新提供了可借鉴的经验与方向。
王驰从墨尔本大学教育特色与研修价值、典型教学方法与经验、教学方法的创新与评价体系的建构，以及对教学实践的启示四个方面入手，结合本土教学实际，分享了研修成果对课堂教学改革的启示和感受。
与会教师表示，本次分享会内容充实、针对性强，既开阔了学术视野，又为思政课集体备课提供了鲜活素材与实践方向。
未来，学校与学院将持续搭建交流平台，推动海外研修成果落地转化，不断提升教师教学科研能力与国际化素养。
