# 工会党支部开展《我们的七月》观影活动-校工会（帮扶办）/ 妇女联合会

为丰富党支部“三会一课”形式，强化党史学习教育，4月26日下午，工会党支部在大唐西市中影国际举行主题党日观影活动——观看党史题材纪录电影《我们的七月》。
该片以扶眉战役为背景，以中国人民解放军第一野战军2兵团4军11师33团副团长高增岳和他的战友们为原型，展现了解放军战士们不畏牺牲、感人至深的战斗细节和战友情谊。
饮水思源，缘木思本。本次观影活动不但为党员们提供了一堂生动深刻的党史党课，也是一场追寻初心使命的革命教育，通过观影活动，使支部全体党员以更加昂扬的斗志、坚定的决心投身工会工作中，锚定学校“127”发展目标和“天下工大、世界三航”远景目标，紧紧围绕学校中心工作，凝聚全校教职工为学校高质量发展做贡献。（文/钱娅群 图/韩关亮 审核/陈建军）
