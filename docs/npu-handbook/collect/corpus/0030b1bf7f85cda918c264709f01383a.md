# 西北工业大学后勤办公室校园维修与应急抢修工程施工管理办法

西北工业大学后勤办公室校园维修
与应急抢修工程施工管理办法
后勤办字〔2019〕6号
第一章总则
第一条为加强校园维修工程和应急抢修工程施工管理，确保工程质量，有效控制施工进度和工程造价，保证施工过程安全、规范、文明，根据相关法律法规，结合学校实际，制定本办法。
第二条本办法适用于后勤办公室负责管理的各类维修、抢修工程。
第二章施工管理目标及管理体系
第三条施工管理目标：工程质量合格，安全零事故，按合同工期完工，施工过程规范文明。
第四条科室负责人为维修工程项目负责人，负责维修工程总体管理，科室负责人对分管副主任负责。甲方代表为现场负责人，同时为执行本办法的第一责任人，负责在施工现场做好项目质量、进度、造价、安全文明施工管理，甲方代表对科室负责人负责。现场监理依据监理合同对维修工程履行监理责任，监理对甲方代表负责。
第三章施工管理
第五条施工开始前，甲方代表应组织监理、施工单位召开现场会议，明确施工各方面要求，协调做好施工前准备工作。（应急抢修工程，后勤产业集团应第一时间告知甲方代表，甲方代表查看现场并做好记录。）
第六条施工管理过程中，甲方代表应及时掌握现场施工情况，收集施工影像资料，并认真做好施工日志。
第七条甲方代表应坚决贯彻国家、行业、地方相关标准与规范，以及招标（采购）文件、施工合同中的相关条款要求；督促施工单位及监理对已完工部分尤其是隐蔽工程及时做好自检及局部验收，并参与抽查，留存检验资料。
第八条甲方代表应督促监理及时做好主要材料的抽检工作，未经监理抽检的材料、不符合合同要求的材料、不合格材料均不得使用，否则，追究相关人员责任。
第九条对施工中发现的质量问题，甲方代表应立即督促施工单位整改，同时追究监理、施工单位责任；发现严重质量问题必须上报，并督促监理、施工单位限期返工处理，同时追究监理、施工单位责任。
第十条甲方代表应理清各施工环节之间的制约关系，抓好关键节点，确保按合同工期完工；因第三方或其它原因导致的工期延误，应做好相关记录并及时上报。
第十一条甲方代表应按照《维修工程签证审批流程》及时办理签证，并对签证的真实性、准确性、及时性负责。
第十二条甲方代表应牢固树立“安全第一、预防为主”的意识，监督监理对施工单位的安全生产许可证、现场安全防护措施、特种机械设备及作业人员的资格证书做好审查，发现不能满足施工安全要求的，立即责令施工单位限期整改。
第十三条甲方代表应严格要求施工单位及时做好施工围挡，施工围挡应干净、整洁，围挡醒目处张贴统一格式的《工程公示牌》；如需在马路或楼宇出入口处设置围挡，应及时同保卫处及楼宇使用单位沟通妥当，尽量减小对车辆及人员通行的影响。
第十四条甲方代表应严格要求施工单位控制施工噪音、粉尘等污染，并保护好周边环境，尽量减小对学校正常教学、科研和生活的影响；施工材料及器具应堆放整齐，施工垃圾应及时清运。
第十五条工程完工后，甲方代表应按照《维修工程竣工验收流程》及时组织验收，验收时现场必须干净整洁，因施工破坏的区域必须恢复原状。
第四章保障措施
第十六条在施工管理过程中，若发现严重质量问题、重大安全隐患、违章指挥或违章作业，或施工单位、监理单位不积极落实甲方代表依据本办法提出的管理要求，甲方代表应及时上报并做好记录，并视情节严重程度下发罚款通知单，罚款金额在工程结算审核或监理费审批中予以扣除。
第十七条针对甲方代表上报的问题，根据问题严重程度，由科室负责人、分管副主任、主任逐级处理，直至提请主任办公会讨论解决。
第十八条在施工管理过程中，后勤办公室项目相关人员应严格遵守廉政相关规定，不得与施工单位、监理单位有工作之外的私人往来，不得接受对方的礼品或宴请。
第五章附则
第十九条本办法由后勤办公室负责解释。
第二十条本办法经2020年10月27日后勤办公室主任办公会讨论通过，自发布之日起施行。
