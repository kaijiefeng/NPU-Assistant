# 工会党支部召开党支部理论学习会并开展民主评议党员-校工会（帮扶办）/ 妇女联合会

1月16日上午，工会党支部在健翔楼301会议室召开党支部理论学习会并开展民主评议党员，工会党支部全体党员参加，会议由支部书记陈建军同志主持。
首先，党员集中学习了习近平总书记在纪念毛泽东同志诞辰130周年座谈会上的讲话、习近平总书记在中央外事工作会议上的重要讲话精神，以及新修订的《中国共产党纪律处分条例》等内容，六名党员结合前期自学情况和个人思想、工作实际进行重点发言。大家一致认为,要进一步坚定理想信念，加强道德修养，通过学习习近平总书记系列重要讲话精神，补足精神之钙，保持和增强工会的政治性、先进性、群众性，持续提高引领力、组织力、服务力，凝心聚力推进学校发展。
随后，支部书记陈建军同志以《聚焦工会主责主业 推动学校高质量发展》为题讲授专题党课，他从强化党建引领、聚焦工会主责、狠抓贯彻落实三个方面解读工会如何围绕学校“127”发展目标，坚决贯彻学校党委决策部署，发挥民主管理、凝心聚力、桥梁纽带作用，多做排忧解难、雪中送炭之事，弘扬劳动精神，开展技能竞赛，团结带领广大教职工、工会会员为学校高质量发展加油鼓劲、摇旗呐喊、奋力拼搏、履职尽责。
最后，工会党支部组织开展了2023年度民主评议党员工作。
