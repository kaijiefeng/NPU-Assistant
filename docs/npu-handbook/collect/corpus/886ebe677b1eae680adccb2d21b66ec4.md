# 西北工业大学2026年第二学士学位招生拟录取名单-

特殊类型招生

西北工业大学2026年第二学士学位招生拟录取名单
发布日期：2026-07-03
点击数：5590
根据《西北工业大学2026年第二学士学位招生简章》有关要求及考生考核成绩，经学校招生委员会审议确定拟录取名单，现予以公示（见附件）。
公示期为5个工作日，公示结束后将按照相关文件要求予以录取并发放录取通知书。
