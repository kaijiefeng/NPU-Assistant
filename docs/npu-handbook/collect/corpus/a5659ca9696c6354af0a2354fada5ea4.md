# 教务部（工程实践训练中心）开设《三航整机工程实训》课

3月20日，《三航整机工程实训》首次课在教务部（工程实践训练中心）创新社区顺利开讲。国家级教学名师、航空学院赵美英教授率先授课，围绕军机、民机等飞行器结构设计原理、核心技术特点与应用场景展开系统讲解，以扎实的学术积淀与鲜活工程案例，带领同学们走进“整机认知”殿堂，直观感受航空大国重器的工程魅力与战略价值。
本课程是“总师育人文化”引领人才培养的重要实践，课程紧扣“三航”领域国家战略需求，以“典型整机深度认知－关键技术维度横向贯通－整机构思创新实践”为进阶路径，打破学科壁垒，引导学生超越局部技术视角，建立从整体使命、架构协同到分系统联动的顶层认知框架。课程设置32学时，理论与实践部分分别为16学时，2026春季学期率先在教育实验学院本博翱翔总师班、数学与统计学院数学强基班开设教学，后续将逐步面向全校本科生开放。
教具模型（飞机、空间站、火箭、水下航行器、发动机等）
课程师资阵容尽显西工大“三航”学科优势，特邀我校在航空、航天、航海、动力、控制、制造、材料等七大领域的国家级教学名师及“三航”产品总师深度参与授课与指导。教学内容覆盖航空军机/民机、航天火箭/空间站、航海水下航行器等“三航”领域典型整机，以及动力、控制、制造、材料四大关键支撑分系统，让学子全方位、多角度领略大国重器的工程内涵，深刻理解“整机观念”在工程实践中的核心价值。
名师+总师的主讲教师团队
金课干货满满，课堂精彩暂告一段落，同学们的思考仍在继续，快来看看TA们怎么说！
教育实验学院本博翱翔总师班李奇峰：赵美英老师的专业讲解，让我对民机设计与行业发展形成了真切且系统的认知。课程围绕整机系统思维、民机发展历程及C919研制过程展开，让我跳出单一专业视角，深刻认识到飞机设计背后是多系统的协同配合，真正理解了系统工程思维的内涵。
教育实验学院本博翱翔总师班高悦芸：这堂课最珍贵的是帮我树立了系统整机观念，明晰了整机宏观认知与各学科的支撑关联，与学校培养‘总师型’人才的理念高度契合。教室里陈列的运-20、ARJ21等机型的精致模型；头顶的蓝天白云布景，仿佛让我们置身云端，与国之重器一同翱翔天际。
数学与统计学院数学强基班李炅昊：课程从民机发展历程，到C919的研发、构造与技术突破层层递进讲解，助力我形成对航空工程的全局认知。未来我会秉持探究思维，锤炼跨学科能力，立足数学专业所长，努力为我国航空航天事业贡献力量。
作为被社会誉为“总师摇篮”的西北工业大学，始终锚定国家“三航”领域战略需求，深耕“总师型”人才培养，着力培育具备系统思维、家国情怀与工程素养的国之栋梁。《三航整机工程实训》将“整机观念”与系统工程思维深植课堂，为西工大学子打造从知识认知到工程实践的总师素养培育新课堂，帮助学生建立可迁移的工程思维，破解“见木不见林”的认知局限。
未来，该课程将持续优化升级，着力打造总师育人金课，成为学校培养“专业精、系统强、重实践、能担当”的“总师型”人才的核心载体，助力更多西工大学子锤炼统筹全局的系统思维，成长为堪当民族复兴大任的国之栋梁。
