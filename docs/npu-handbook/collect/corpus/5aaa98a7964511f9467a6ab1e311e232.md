# 以手护安，以细护航-西北工业大学医院

10月15日是全球洗手日，手卫生是预防和控制医院感染最简单、最经济、最有效的手段，也是守护医患生命健康的第一道重要防线。为压紧压实院感防控责任，以督查促规范，以榜样促提升，持续夯实院内感染防控基础，进一步提升全院各岗位手卫生依从性和正确率。10月以来长安校区医院组织开展手卫生专项督查工作，把院感管控落到实操现场。
为树立先进典型，发挥示范引领作用，本次专项督查工作采取不提前通知、直接现场实地查看的方式，对临床医生、护理、医技、保洁等全部一线岗位进行督查，重点对诊疗操作前后、接触污染物后、处置标本等关键时机的手卫生落实情况进行检查，现场核对七步洗手法操作流程是否完整、指征判断是否准确。
督查过程中，在岗人员能够树立较强的院感防控意识，自觉落实手卫生各项规范。同时，也涌现出一批执行标准严谨、操作完整规范的优秀代表，由感控办组织为他们颁发了证书。
细微之处显责任，点滴之处守安全。医院将持续强化手卫生常态化管理，把手卫生转化为全体医务人员的职业自觉，从指尖守护医患安全，筑牢医院感染防控坚固屏障。
