# 多措并举锤炼青年教师队伍——马克思主义学院开展思政课教学质量提升系列活动-西北工业大学

为进一步落实教育部《关于加强新时代高校青年教师队伍建设的指导意见》，提高青年教师思政课教学能力，提升思政课堂教学质量，推动思政课教学实现高质量发展，马克思主义学院近期围绕课堂教学改革与队伍建设，统筹组织开展了青年教师思政课教学质量提升系列活动。
一是开展思政课教学观摩。学院秉持以老带新、携手共进的培养理念，统筹安排近三年入职青年教师深入课堂，切实做到“真听课、真观摩、真体悟”，近距离领略资深教师在教学设计、案例选择、课堂互动以及板书与课件呈现等方面的宝贵经验与做法，引导青年教师在比较中查找差距，在学习中吸收借鉴，在反思中不断优化教学思路与教学设计，切实提升课堂教学能力。
二是推进教师听课全覆盖。结合教育部高校思政课课堂教学提升行动，学校领导、校院督导组对本学期开设思政课程进行教师全覆盖听课，按要求认真组织开展集体备课专题教学，确保将党和国家的重大战略和方针政策全员全程全方位贯彻融入到思政课教学中。
三是组织思政课教学展示。近三年入职的青年教师围绕思政课的重点与难点开展教学展示，学院邀请校内外专家进行点评、精准把脉，从教学目标设计、重难点把握、案例运用、课堂组织与互动等方面展开精准“会诊”，并提出具有针对性的改进意见。同时，结合思政课教学“大练兵”活动，推动青年教师在实践中磨炼基本功，提升专业化教学水平。
四是召开教学质量提升研讨会。研讨会聚焦于教学能力的提升路径，校级督导、示范专家、各系（教研室）主任与近五年入职的二十余位青年教师展开深入交流。通过课程示范、经验分享以及问题研讨等方式，实现以研促教、以研提质、以研助力教师成长的目标。
通过此次系列教学质量提升活动，学院青年教师教学能力与课堂驾驭能力都有不同程度的增强。未来，学院继续锚定思政课立德树人根本目标和学校“天下工大、世界三航”远景目标，持续丰富提升形式，拓展观摩范围，创新交流方式，不断探索提升思政课教师教学质量的新途径、新机制，力求让青年教师在观摩中成长、在实践中成熟，促使青年教师成为政治素质过硬、专业功底扎实、教学能力卓越的新时代思政课教师。
