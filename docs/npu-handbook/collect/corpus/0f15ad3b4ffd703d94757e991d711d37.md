# 李玉龙教授来力学与土木建筑学院青年教师发展中心交流指导

3月24日下午，青年教师发展中心邀请民航学院院长李玉龙教授为我院青年教师开展座谈会。学院共有12位青年教师参加本次座谈会，青年教师发展中心主任路宽主持本次会议。
李教授以自身为例，结合当时学术研究背景，详细介绍了自己选择冲击动力学研究方向的初衷，以及自己的学习和科研历程。建议青年教师要两条腿走路，第一要做好基础研究，积累高水平论文；第二要与大院大所加强沟通联系，积极解决研究所的实际工程需求，做到以国家需求为牵引。同时也要做好个人的有组织科研，主动做到“走出去”，积极参加国内外学术会议，与国内外知名学者加强联络，拓展自己的学术视野和声望。
最后与会青年教师结合切身问题与李玉龙教授进行了进一步沟通，李教授细致耐心地给出了建议。
学院青年教师发展中心致力于通过定期的学术交流研讨活动为学院青年学者搭建科研学术交流平台，积极营造交叉、创新、融合、互鉴的学术氛围，为学院高层次人才培养和高水平科研成果产出提供有力支撑。
