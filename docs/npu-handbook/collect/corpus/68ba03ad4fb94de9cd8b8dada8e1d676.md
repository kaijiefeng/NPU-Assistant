# 第四届“礼敬中华”优秀传统文化季之重阳篇系列活动圆满举办-青春驿站-共青团西北工业大学委员会

为弘扬中华民族尊老、敬老、爱老、助老的传统美德，庆祝重阳佳节，10月中下旬，学校团委举办了第四届“礼敬中华”优秀传统文化季之重阳篇系列活动。本次系列活动“以传统为核、以互动为桥”，让敬老思亲的美德与欢声笑语一同镌刻在秋日的校园里。
10月29日下午，重阳节主题活动在翱翔学生中心广场举办，现场有500余名师生参加。本次活动精心设置九大特色体验环节，多方位展现了重阳节“敬老、思亲、祈福”的文化内涵。在“重阳绘鸢·风筝创作”区，大家绘菊花、仙鹤于素白风筝，寄长者安康之愿；“重阳答典·知识问答”区，围绕重阳习俗与典故竞答，解锁文化密码；“九九艾香·手作香囊”处，巧手制艾草锤、香囊，学习中医养生知识；“秋日捏柿·扭扭棒DIY”处，五彩扭扭棒变“柿子”，藏“事事如意”美意；“笔墨传情·书写祝福”区，写下“重阳安康”“敬老情长”载心意；“古韵投壶·传统趣味”处，依古礼投羽箭，品传统礼仪雅韵；“登高诵诗·诗句对答”环节，对经典诗句，扬文化韵味；“尺素敬老·书信邮寄”区，让牵挂跨越山海。参与者集齐印章参与抽奖，为这场体验中华优秀传统文化之旅画上圆满句号。
此外，学校团委联合离退休工作处，于10月16日在友谊校区共同组织开展了“陕西社会保险”APP养老待遇资格认证协助活动。志愿者“小航宝”们现场为退休教职工提供了操作指导与答疑服务，通过面对面交流、手把手指导，让退休教职工顺利完成了资格认证，避免待遇延误，以实际行动传递温暖与关怀。
此次重阳篇系列活动，通过沉浸式互动体验，让青年学子以实际行动体悟了“老吾老，以及人之老”的中华美德。下一步，学校团委将着力发挥思想引领与文化浸润作用，持续弘扬“奉献、友爱、互助、进步”的志愿服务精神，以“总师育人文化”为引领，打造更多有温度、有深度的品牌活动，让中华优秀传统文化在校园里绽放更加绚丽的光彩。
