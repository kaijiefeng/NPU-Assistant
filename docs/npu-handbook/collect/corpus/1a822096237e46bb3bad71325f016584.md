# 关于开展2026年度分析测试中心基础研究开放测试基金 申请工作的通知

各位老师：
为贯彻落实学校基础研究工作部署，锚定“天下工大、世界三航”远景目标，进一步激发师生科研活力，提高大型高端仪器共享使用效益，助力学校“双一流”建设，分析测试中心设立基础研究开放测试基金（以下简称开放测试基金），现就基金申报有关事项通知如下：
一、申报要求及资助范围
1、申请人为我校在岗教师，应具有博士学位，中级及以上专业技术职称。。
2、申请人须已获得国家自然科学基金项目资助。
二、资助额度及形式
1、资助额度：依照申请人测试需求及拟产出成果水平，设置以下三种基金额度：
·5万元，拟资助10项。
·10万元，拟资助10项。
·15万元，拟资助5项。
针对测试需求较大以及拟产出成果水平高的课题最高可资助30万元（一事一议）。
2、资助形式：在该国家自然科学基金项目执行期内，按测试费同等比例予以核减结算的方式实施，直至资助额度用尽。
三、申报程序
集中受理申报时间为11月15日之前，逾期不予受理。
申请人按要求填写《开放测试基金申请书》（附件1），分析测试中心组织专家采取集中评审的方式，对申请项目进行评审，确定受资助的项目和资助金额，并在中心网站上予以公布。
四、资料提交
1、纸质版《开放测试基金申请书》一式三份和所获《国家自然科学基金资助项目批准通知》复印件一份，请于11月15日前报送分析测试中心办公室（勇字楼406-1室）。
2、电子版《开放测试基金申请书》和所获《国家自然科学基金资助项目批准通知》电子版发至邮箱lijia126@nwpu.edu.cn。
