# 通信感知一体化：理论极限、信号处理及决策优化——西安交通大学魏志强教授来院作专题学术报告

2025年12月5日，“航海大讲堂”学术报告第74讲在航海学院海天苑大楼A326会议室顺利举行。本次讲座由航海学院研会承办，特邀国家级高层次青年人才计划入选者、德国洪堡学者、西安交通大学数学与统计学院魏志强教授担任主讲嘉宾，以《通信感知一体化：理论极限、信号处理及决策优化》为题，系统地介绍了通信感知一体化(ISAC)信息理论极限、信号处理算法和决策优化方法，为相关领域研究提供了重要参考。
魏老师首先指出，在通信与感知技术融合、频谱共享需求迫切、网络功能多元化演进及新兴应用强力驱动的背景下，通信感知一体化（ISAC）已成为 6G 的核心技术与关键应用场景。
针对感知与通信性能指标各异的核心挑战，魏老师基于容量-失真理论深入分析了双基地ISAC系统中感知与通信功能的最优折衷关系。为实现感知与通信的功能互助，报告聚焦于统一的系统建模与信号处理框架，他重点介绍了基于WiFi信号的鲁棒协同跟踪算法及目标-信道双域协同跟踪算法，有效验证了感通互助机制的可行性与性能优势。
针对高移动性场景中感知与通信过程动态耦合、难以建模与优化的难题，魏老师提出了一种双层优化问题建模方法，并在此基础上设计了一种模型与数据双驱动的混合深度强化学习-凸优化算法，显著提升了感知与通信决策的综合性能与泛化能力。
通过此次报告，魏老师系统梳理了通信感知一体化技术的发展脉络与核心突破，深入解读了理论极限与工程实践的关键问题，让同学们深刻认识到6G核心技术的创新潜力与应用价值，为相关学科交叉融合及人才培养注入了新的思路与活力。
（审核：刘朝亚，王银涛）
