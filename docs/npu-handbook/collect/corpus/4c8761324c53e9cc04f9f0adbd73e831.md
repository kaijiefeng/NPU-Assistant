# 人工智能学院/无人系统技术研究院10人次入选全球前2%顶尖科学家榜单

近日，美国斯坦福大学联合爱思唯尔数据库（Elsevier Data Repository）发布了2026年度第九版《全球前2%顶尖科学家榜单》（World's Top 2% Scientists），根据“终身科学影响力”和“年度科学影响力”两个维度遴选出世界排名前2%的科学家。
我院白俊强教授、毛昭勇教授、陈景东教授、夏勇教授、陈捷教授、石栋元教授、袁上钦副教授7人入选“年度科学影响力”（Single-year Impact）榜单。
同时，陈景东教授、夏勇教授、陈捷教授3人入选“终身科学影响力”（Career-long Impact）榜单。
《全球前2%顶尖科学家榜单》由美国斯坦福大学John P.A. Ioannidis教授团队编制，自2019年首次发布以来，已成为全球最具影响力的科学家学术成就评价体系之一。2026年度为该榜单的第九版，数据更新至2025年8月，基于Scopus数据库，通过论文引用数、h因子、合著者修正的hm因子、单独或第一作者文章引用数等多项综合指标，从全球近一千万名科学家中遴选出世界排名前2%的科学家，涵盖20个领域和174个子领域。榜单分为两大子榜单，其中：
“终身科学影响力”排行榜（Career-long Impact）：综合统计科学家职业生涯期间（1960年至2025年）的论文发表与引用情况，反映科研人员职业生涯的综合学术贡献与长期影响力；“年度科学影响力”排行榜（Single-year Impact）：聚焦科学家在2025年度的学术表现，反映其近期的科研活跃度与学术产出质量。
据本次2026年度榜单统计数据，中国内地共有14582位学者进入“终身科学影响力”榜单，37201位学者进入“年度科学影响力”榜单，我国科研队伍的国际学术影响力持续稳步提升。
