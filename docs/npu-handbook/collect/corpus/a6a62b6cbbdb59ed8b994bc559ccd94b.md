# 携手共育，筑梦工大——数学与统计学院重庆招生组赴重庆开展2024年本科招生宣传工作

为构建大学与中学之间的教育合作，打造教育合作共同体，充分发挥优质生源基地作用，持续提升我校声誉，2024年2月29日至3月5日，由数学与统计学院党委书记王莉、院长助理刘晓刚、重庆招生组组长林伟及西北工业大学伦敦玛丽女王大学工程学院王永欣教授、航空学院李华星教授、航空学院杨华保教授等组成的联合招生宣传组先后赴重庆市巴川国际高级中学校、铜梁中学校、凤鸣山中学、首佳教育、蕴华教育、重庆外国语学校等6所中学与教育机构举行招生宣传活动计11场，包括4场科普报告、6场招生宣讲、1场“优质生源基地”授牌活动。
2月29日、3月1日，招生宣传组分别赴巴川国际高级中学校、铜梁中学校和凤鸣山中学开展科普讲座3场、招生宣传活动3场。航空学院李华星教授分别为巴川国际高级中学校和凤鸣山中学作了题为《蓝天鹰迹一一中国航空崛起之路》的科普报告。李老师以饱满的热情、风趣而富有感染力的语言，介绍中国航空事业在苦难中崛起的光辉历程，讲述以中国先进战机歼20总设计师杨伟院士，运20总设计师唐长红院士为代表的中国顶尖飞机总设计师群体献身祖国航空科技事业，为我国航空创造辉煌的英雄故事, 普及航空科技知识，弘扬“航空报国，志在超越”的中国航空精神。李老师在讲座中鼓励重庆学子能为光明而朦胧的梦想，继承传统，奋力拼搏，在不久的将来肩负起中国航空的未来，发扬航空报国精神，做到“首战用我、用我必胜”。航空学院杨华保教授为铜梁中学校作了题为《蓝天逐梦》的科普报告，介绍了我国航空发展简况，从中国的航空强国梦引入西北工业大学的航空梦，讲述了飞机设计师的摇篮---西北工业大学在中国航空史上的重要地位。杨华保老师的报告幽默风趣，通俗易懂。在报告中杨老师鼓励同学们树立航空报国的远大志向，振翅翱翔、圆梦蓝天。林伟老师和刘晓刚老师分别为3所中学的同学们做了招生宣讲，详细介绍了我校的基本情况、办学特点、人才培养优势等，并鼓励同学们积极报考我校，报效祖国的航空、航天、航海事业。
3月2日-3日，招生宣传组分别前往首佳教育和蕴华教育开展2场招生宣传。林伟老师和刘晓刚老师分别向与会的学生家长和同学们详细介绍了我校的基本情况，并对在场家长提出的报考疑问进行了有针对性的解答。宣讲现场座无虚席，与会家长、师生反响热烈。
3月5日，数学与统计学院党委书记王莉和重庆招生组组长林伟来到重庆外国语学校进行“优质生源基地”授牌活动，并赠送J-20模型。重庆外国语学校副校长王俊、教务主任、高三年级组长、团委书记等参加了授牌仪式。副校长王俊围绕学校育人理念、特色育人举措及成效等，介绍了重庆外国语学校的办学情况。王莉书记简要介绍了我校人才培养的优势和为国防事业做出的重大贡献，希望更多重庆外国语学校学生报考西工大，树立为国铸剑的远大理想。
王永欣教授为重庆外国语学校学生做了《发展的基石，安全的基础——材料科学与工程》科普讲座，从材料科学与工程作为经济发展和人民美好生活的物质基础以及国家安全的基础出发，介绍了材料学科的内涵，研究内容，以及西工大材料学科聚焦国家重大战略开展的特色科研方向，以能力培养为核心的领军人才培养特色等。报告受到学生喜欢，现场气氛热烈。
林伟老师为高三学生详细介绍了西工大的历史文化底蕴、学科优势、师资力量、一流专业、多元化人才培养模式和招生政策等内容，耐心回答了学生们提出的问题，鼓励更多优秀学子报考我校。
本次活动作为2024年学院招生工作的第一站，强化了西北工业大学与重庆地区重要生源中学的沟通与联系，为进一步提升我校声誉，扩大我校在重庆地区的影响力奠定了良好基础。
