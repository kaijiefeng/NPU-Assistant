# 西北工业大学哈萨克斯坦分校2026届毕业典礼圆满举办

7月2日下午，恰逢习近平总书记“共同办好西北工业大学哈萨克斯坦分校，培养更多中哈友好事业接班人”重要指示发表两周年之际，西北工业大学哈萨克斯坦分校2026届硕士研究生毕业典礼在长安校区图书馆隆重举行。“阿里·法拉比”哈萨克国立大学副校长马尔古兰·伊布拉伊莫夫、我校副校长孔杰，材料学院、电子信息学院、计算机学院、研究生院等部门负责人及研究生导师代表齐聚现场，共同见证中哈教育合作的荣耀时刻。典礼由国际合作处副处长、国际教育学院副院长兼哈萨克斯坦分校副校长李自伟主持。
毕业生代表伊萨迪尔·纳尔库兹上台发言，深情回忆了穿梭于中哈两地的成长历程，并向两国元首的远见关怀、所有导师的悉心教导和同窗伙伴的温暖陪伴致以诚挚谢意。她表示，作为西北工业大学哈萨克斯坦分校培育出的青年学子，将努力成为中哈友好合作事业的参与者和建设者，为续写两国友谊贡献自己的力量。
导师代表、计算机学院张羽教授以“勤学、破题、融通”三点嘱托全体学子：常怀谦逊之心持续学习，怀揣果敢勇气解决实际难题，秉持包容尊重搭建友好桥梁，以青春之力助力中哈双边合作行稳致远。
马尔古兰·伊布拉伊莫夫充分肯定西北工业大学哈萨克斯坦分校作为两校高层次人才联合培养的重大项目，正逐步成为中哈教育合作的标杆范例。他勉励毕业生们打磨过硬专业能力，深耕行业前沿、勇攀技术高峰，成长为国家紧缺高端技术人才，以专业赋能全球科技创新发展。
孔杰讲话时指出两年来分校始终牢记习近平总书记重要指示精神，在两国元首持续关怀下，稳步推进分校“从有到优”高质量发展，在人才培养、联合科研与人文交流领域不断取得丰硕成果。临别之际，他向毕业生提出三点殷切期许：立足专业所学，成为行业专家，在国家发展中成就自我；传承两校友谊，积极服务两校交流，当好民心相通使者；胸怀时代格局，争做中哈友好事业接班人，助力中国—中亚命运共同体建设。
典礼现场有序开展优秀毕业生表彰、拨穗正冠、学位证书授予仪式。本次共有5名学子凭借优异学业成绩与突出综合表现获评优秀毕业生，36名硕士毕业生依次登台接过学位证书。拨穗礼成之际，两载跨山海求学的寒窗耕耘、千里逐梦的奋斗时光尽数化作荣光，为毕业生奔赴人生新征程筑牢底气、积蓄力量。
两载耕耘，初心如磐；从有到优，再启新程，这场毕业典礼是分校迈向更高质量、更高水平发展的崭新起点。
站在新的历史节点上，西北工业大学哈萨克斯坦分校将始终坚守“培养更多中哈友好事业接班人”使命，继续以更高标准、更实举措深耕中哈教育合作沃土，把“共同办好西北工业大学哈萨克斯坦分校”的殷切期望转化为一项项扎实成果，为赓续中哈世代友好、服务共建中国—中亚命运共同体贡献更多智慧与力量。
