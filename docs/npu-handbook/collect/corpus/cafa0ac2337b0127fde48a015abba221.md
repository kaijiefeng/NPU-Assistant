# 我校召开2025年本科招生政策培训会暨动员会-

报考指南
首页-报考指南>宣传动态>
我校召开2025年本科招生政策培训会暨动员会
发布日期：2025-06-12
点击数：4392
6月10日下午，西北工业大学2025年本科招生政策培训会暨动员会在友谊校区国五会议室召开。各学院院长或党委书记、对外联络办公室等相关职能部门负责人，以及各学院分管招生工作的负责人、招生组长和骨干教师，机关各部门招生工作联系人，教务部（招生办公室）全体工作人员共计近300人参加。会议由招生办公室副主任马婷婷主持。
首先，招生办公室主任王克勤对2025年学校招生政策、志愿指导、宣传方案、相关注意事项等方面作出详细解读。他表示，2025年招生工作面临新的困难和挑战，招办将充分协同各学院、各职能部门，在招生宣传和政策方面深入研讨，努力为“总师型”人才培养把好“进口关”，在接下来的集中宣传期，稳扎稳打，做好招生策略制定和志愿填报指导工作，千方百计吸纳优秀生源。
随后，招生办公室副主任马婷婷介绍了招生宣传管理信息化系统使用说明，该系统实现了招生宣传工作的智能化、精细化和数字化，将大力提升招生宣传的规范性和报考咨询服务的便捷性，为精准对接考生需求、提升宣传效能提供了有力的技术支持。
最后，教务部部长王海鹏对全体招生工作人员表示诚挚谢意。他指出，学校党委高度重视学校本科招生工作，面对新形势，请大家要认真学习新政策、新变化，将信息准确传递给考生和家长。针对接下来的招生工作攻坚期，他提出了三点工作建议：一是做好顶层设计，招办要会同各招生组提前做好集中招生宣传期间的统筹规划。二是做好服务保障，教务部要为全体招生宣传老师做好全方位的后勤保障工作，让老师们在一线工作无后顾之忧。三是做好培训动员，各学院要高度重视，会后要针对负责省份的情况再召开分省的政策培训会，确保每一位派出老师做到态度好、政策清、水平高。本次招生政策培训会暨动员会的召开，标志着学校2025年高考招生宣传集中咨询和志愿指导阶段正式拉开序幕，也为全校各招生队伍全面准确深入了解并掌握学校招生政策、指导考生填报志愿等提供了重要参考。全体招生人员将全力以赴，为选拔“总师型”人才，实现生源质量的全面提升贡献力量。
