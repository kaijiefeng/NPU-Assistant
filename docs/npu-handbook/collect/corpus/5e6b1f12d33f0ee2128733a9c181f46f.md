# 以赛促学，智创未来——第十一届华为ICT大赛宣讲会走进人工智能学院

10月16日中午，第十一届华为ICT大赛校园宣讲会在长安校区举行。华为公司专家团队走进我院，为师生介绍本届大赛的赛制安排与参赛权益。华为中国区人才生态业务总监褚力行、ICT人才伙伴发展部校企合作经理李博、ICT大赛中国区项目组专家刘闯、陕西人才发展经理陈佳俊，人工智能学院/无人系统技术研究院党委副书记徐晓峰出席活动，本科生辅导员李莹玥主持宣讲会，学院全体学生参加。
宣讲会现场
徐晓峰在致辞中代表学院党委和全体师生，对华为公司各位领导老师的到来表示热烈欢迎和衷心感谢。他表示，我院是我校主动服务国家人工智能发展战略成立的新学院，今年迎来了首届本科生，人才培养工作得到学校党委的高度重视。人工智能是实践性极强的学科，“人才培养不能只停留在课本上”，他勉励同学们多关注产业一线，在解决实际问题中练就真本领。
褚力行在致辞中回顾了华为与我校的合作渊源。他介绍，华为ICT大赛已成功举办十届，本届为第十一届，是华为与联合国教科文组织合作的竞赛项目，我校师生在上一届赛事中斩获佳绩。他谈到，参赛的意义远不止一纸证书，备赛、参赛的全过程能够锤炼同学们的技术能力与工程实践能力。他寄语青年学子：“不为胜负所限，只为突破而来。”
褚力行致辞
宣讲环节，刘闯介绍了本届大赛的赛道设置与报名安排。大赛设实践赛、编程赛、创新赛、挑战赛、商业精英赛、教学赛六大赛道并新增算子赛，覆盖网络、云、基础软件、仓颉语言、AI应用开发等方向，为不同基础、不同发展方向的同学提供了多元选择。
主讲人介绍本届大赛情况
宣讲结束后，同学们围绕赛道选择、备赛路径与赛题方向踊跃提问，华为专家逐一解答，并建立了线上交流群，将持续为同学们提供真题资料与备赛指导。
现场同学提问
此次宣讲会是我院深化产教融合、推进协同育人的一次具体实践。作为我校“人工智能+无人系统”特色发展方向的建设主体，我院始终注重把行业领军企业的优质资源引入人才培养全过程，为学子搭建接触前沿技术、参与工程实践的平台。下一步，我院将继续加强与华为等企业的对接合作，助力学生在真实场景中成长为堪当重任的人工智能领域人才。
