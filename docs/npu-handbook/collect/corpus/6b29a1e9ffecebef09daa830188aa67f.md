# 力学与土木建筑学院8位学者入选2024年度全球前2%顶尖科学家榜单

2024年9月，美国斯坦福大学和爱思唯尔(Elsevier)发布第七版《年度全球前2％顶尖科学家榜单》（World’s Top 2% Scientists）。
力学与土木建筑学院岳珠峰、乔吉超、温志勋、 解忠良、龙旭、张凯、路宽、邓子辰（按全球排名顺序）8位学者入选“年度科学影响力排行榜”榜单。
其中岳珠峰、乔吉超（按全球排名顺序）2名学者入选“生涯科学影响力排行榜”榜单。
该榜单是由斯坦福大学John P.A. Ioannidis教授团队联合国际权威学术出版社爱思唯尔数据库（Elsevier Data Repository）发布，基于Scopus数据库的引用数据系统分析,以被引数、H指数、HM因子等6种综合指标，根据“生涯科学影响力”和“年度科学影响力”从全球约700万名科学家中遴选出世界Top 2%的科学家，包括了22个学科领域和174个子学科领域，为科学家长期科研表现提供了综合性的衡量指标，能够更客观、更真实地反映科学家的影响力。
入选全球前2%顶尖科学家榜单，意味着该学者在该领域的研究已处于顶尖水平，具有较高的全球影响力。
