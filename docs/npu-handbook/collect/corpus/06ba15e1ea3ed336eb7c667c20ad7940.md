# 学院举办大学生急救知识科普专题讲座

为进一步提升学生应急自救互救能力，筑牢校园安全防线，强化学生安全责任意识，教育实验学院/未来技术学院/学科交叉中心于2026年10月22日，邀请西北工业大学校医院开展大学生急救知识科普专题讲座，各年级学生代表220余人参加。
校医院王莉医生结合日常典型突发意外案例，点明意外事故突发性、不确定性的特征，阐述了掌握急救技能对校园应急处置的重要意义。围绕心肺复苏、海姆立克急救法等急救技能开展理论讲解，梳理规范施救的原理与完整流程，纠正常见急救误区，帮助同学们树立科学严谨的急救观念。
期间，校医院医生开展现场实操示范，借助模拟人模型，直观演示心肺复苏操作与 AED 设备使用，细致讲解按压部位、标准手部姿势、按压频率及按压深度等关键操作要点。示范动作规范、讲解详实，帮助同学们对标准化急救流程建立直观清晰的认知。
本次急救知识讲座内容充实、实用性突出，有效普及了基础应急救护知识，助力平安校园建设。未来，学院将持续开展安全教育相关活动，为学生身心健康成长保驾护航。
