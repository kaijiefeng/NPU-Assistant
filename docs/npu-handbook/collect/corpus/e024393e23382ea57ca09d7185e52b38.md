# 【求职故事】和老板谈薪水要把握三大要点

如何获得一份满意的薪水，是每个求职者关心的问题，如果不会谈薪，可以求助于“谈薪师”。
邱先生是找“谈薪师”代为“谈薪”的一位机械行业的高管，有20多年的工作经验，十多年的管理经验。猎头向他推荐一个到宁波工作的机会，一开始邱先生开口只要30万元年薪，但猎头觉得开价少了点，向企业提出35万~50万元的年薪要求，企业接受不了，机会告吹。
“谈薪师”卢嫣波女士表示，一般总经理的薪水占企业利润的5%~8%比较合理，猎头推荐的这家企业年产值3000万，纯利300万，邱先生要10%的回报，已经过高，猎头的报价更高，这是谈不拢的原因。
那么，到底如何谈薪？“谈薪师”卢女士认为，要注意三个注意事项：
一是谈薪时间 最佳的谈薪时间是在面试最后，在双方都适合的时候才抛出薪水话题。
二是怎么谈 要先跟老板谈岗位贡献值，再提薪水要求，这样老板更容易接受。要明白，薪水不是谈出来的，其实是做出来的。
三是和什么人谈 一般和高级岗位和负责人谈，比如HR总监和总经理等，不和部门经理和招聘专员谈。
