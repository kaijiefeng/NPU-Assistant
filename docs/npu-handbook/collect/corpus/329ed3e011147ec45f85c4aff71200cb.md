# 寒假企业实习在华留学生招募通知

中国国际青年交流中心拟于今年寒假继续开展“在华留学生企业实习” 活动。现面向全国高校招募在华留学生，具体通知如下：
一、实习时间
2022年1月至2月，原则上不少于2个月（时间可商议）。
二、招募对象
来华攻读本科及以上学位的留学生
三、实习地点
全国各地
四、招募条件
1. 中文熟练，其他语言以企业岗位要求为准。
2. 具有胜任应聘实习岗位需要的相关专业知识和工作能力。
3. 工作认真细致，责任心强，有较强的执行力及部门间的协作配合力。
4. 实习完成后需提交实习报告。
五、实习待遇
1. 企业承担一定的实习补助，城际差旅费自理。
2. 实习结束后企业为实习合格人员出具实习证明。
3. 中国国际交流中心优先推荐实习期间表现优异的实习生参加国际交流活动。
六、相关事项
1. 实习生与企业匹配后签署实习协议，并向出入境管理局申请实习加注签证（12 月31 日前完成）。
2. 实习生应遵守实习企业的管理规定。
3. 请留学生仔细填写在华留学生寒假企业实习电子报名表，并提交相关材料。
七、报名方式及时间
请于2021年11月28日（日）前通过扫描下方二维码报名。
八、资格审核
资格初审：留学生自行填写实习报名表，交流中心联合高校共同进行资格初审，适当统筹调剂。
专业审核：12月10日前安排符合岗位需求的实习生与匹配的企业进行电话或视频面试。
审核结果：12月15日前向高校及留学生反馈配对结果。
