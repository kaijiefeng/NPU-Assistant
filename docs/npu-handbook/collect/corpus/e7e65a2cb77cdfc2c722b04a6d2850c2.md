# 回望辛亥怀先驱，感悟长征砺初心——西北工业大学、西安交通大学两校学生党支部联合开展主题党日活动

为传承红色基因，坚定理想信念，持续推动校际基层党组织交流共建，2026年10月16日，西北工业大学力学与交通运载工程学院研究生第三党支部与西安交通大学新闻与新媒体学院硕5228班党支部联合开展了“回望辛亥怀先驱，感悟长征砺初心”主题党日活动。
活动中，我院研究生第三党支部书记杨欣宇以“赓续红色血脉，弘扬伟大长征精神”为主题，结合中国工农红军长征胜利90周年，围绕长征的历史背景、主要历程及重要意义展开讲述，带领党员重温革命历史，感悟伟大长征精神，引导青年党员坚定理想信念、勇担时代使命。
随后，西安交通大学新闻与新媒体学院硕5228班党支部书记陶瑞雯结合辛亥革命115周年、孙中山先生诞辰160周年，回顾辛亥革命的历史进程，介绍孙中山先生的革命事迹与历史贡献，引导党员感悟革命先驱的爱国情怀与奋斗精神。
在交流研讨环节，两校党员积极发言，分享学习心得与感悟，进一步深化了对革命精神的理解，大家均希望双方以此次活动为契机，进一步加强两校两院党支部交流，在理论联学、活动联办等方面深化合作，共同推动学生党建共建工作走深走实。
（文：杨欣宇、景杨、王涵晶 图：杨欣宇、张琰浦 审核：路宽）
