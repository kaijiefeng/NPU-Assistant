# 【通知公告】西北工业大学长安校区暑期校园参观预约通知

为提升来校参观人员体验，进一步规范校园秩序，维护校园稳定安全，结合校园实际承载能力，经研究，对入校参观实行预约制度。现将有关事项通知如下：
（一）西北工业大学为教学科研单位，非旅游景点，入校参观仅面向个人，不收取费用。校外团体入校须与校内有关单位提前对接，审批同意后方可入校。
（二）参观时间。自7月28日起至8月23日，每日9:00-12:00和14:00-17:00，17:00后停止入校。如遇极端天气等特殊情况将进行调整或暂停开放。
（三）预约流程。实施身份证实名预约，流程如下：
1.网上预约。访客请提前1天点击西北工业大学微信公众号“服务”通道——“参观预约”进行次日预约登记。
选择参观日期、时段、参观人数（每部手机每时段最多可预约登记4个身份证号）后点击“确认选择”。
录入预约人员身份信息后，点击“提交预约”并“确认”，完成预约。
2.进校参观。预约成功后，访客需持本人有效二代身份证按预约时段由长安校区东门（东祥路）或军工素质教育实践中心南侧临时出入口（环山路）经身份核验后进入参观，并于当日19:00前从东大门或南侧临时出入口离校。
3.预约逾期。视为自动放弃参观资格。预约成功后不可自动取消，本人及同行人员不得以任何方式转让入校参观名额，并请拒绝以任何名义提供参观服务的有偿预约行为。
4.儿童。未满8周岁儿童无需预约，但须有预约成功的监护人陪同方可进校参观。
（四）开放区域。学校分为开放区域和非开放区域，请按指定路线参观。教学、科研、办公、宿舍、图书馆、体育馆等场所为非开放区域，谢绝参观。
（五）文明参观。
注意仪态仪表，爱护校园环境设施，不得干扰学校正常教学、科研和生活秩序;
禁止乱丢垃圾、不得随意涂抹、刻画、损毁公共设施；
禁止放飞“低慢小”航空器及空飘物；
禁止攀爬飞机、模型及建筑雕塑;
未经学校批准不得在校内开展集会、演讲、直播、快闪等非参观游览活动或任何形式的经营活动;
请访客做好个人安全防护，避免发生中暑、溺水等安全事件。
