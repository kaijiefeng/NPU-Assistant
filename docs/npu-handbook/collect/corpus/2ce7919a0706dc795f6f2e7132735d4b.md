# 为师生办实事 | 后勤部办公室完成两校区新增充电桩建设

为更好满足师生电动自行车及新能源汽车充电需求，根据学校2025年为师生办实事工作有关要求，后勤部办公室高度重视、积极行动，结合师生车辆多样化充电需求及既有充电桩分布情况，在两校区各增加投用了一批新能源汽车充电桩及电动自行车充电桩。
2025年5月，后勤部办公室与党委保卫部沟通，结合现有充电桩使用情况及后续安装计划，综合考量电力运行、安装场地等因素，在两校区分批次安装新能源汽车充电桩及电动自行车充电桩。
为保障正常教学及师生停车不受影响，后勤部办公室利用暑假及周末组织施工单位完成安装工作。2025年6月-11月在友谊校区公字楼北侧、航空楼A座北侧、西苑超市东侧新建新能源汽车充电桩26套，东村15号楼北侧、东村17号楼北侧、健翔楼东侧新建电动自行车充电桩10套；在长安校区海天苑大楼周边、航宇支撑学科创新中心周边新建电动自行车充电桩57套。
截至目前，友谊校区新能源汽车充电桩共有91套，电动自行车充电桩共有49套588个充电口；长安校区新能源汽车充电桩共有122套，电动自行车充电桩共有147套1764个充电口。师生可通过微信或专用APP扫码充电，具体数量及位置见下表。
