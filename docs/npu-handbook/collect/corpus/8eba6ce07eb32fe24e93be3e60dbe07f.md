# 西北工业大学第三届“华秦杯”全球校友创新创业大赛总决赛日程安排-西北工业大学资产经营管理有限公司

为进一步贯彻落实国家创新驱动发展战略，汇聚学校校友和社会创新创业资源，搭建科技成果和金融资本深度融合双向流动的互动平台，服务校友和在校师生创新创业，增强学校在创新创业领域的社会影响力，提升办学声誉，助力国家和地方经济社会发展，由西北工业大学主办，华秦科技冠名赞助，以“微光成炬 翱翔未来”为主题的，第三届“华秦杯”全球校友创新创业大赛总决赛定于2026年10月16日（星期五）在长安校区南山苑国际学术交流中心举办。
具体安排如下：
一、时间
开幕式及主旨报告：
10月16日（周五）09:00-10:30
路演答辩：
10月16日（周五）10:30-17:00
二、地点
长安校区南山苑国际学术交流中心多功能厅
三、主旨报告
施安平
国中资本首席合伙人、董事长
报告题目：新技术·新形势·新打法—当前创业投资的挑战与机遇
施安平，西北工业大学知名校友，金融学教授，博士后指导教师。中央电视台特聘创业导师，深圳市人民政府金融创新特聘专家、吉林省人民政府投资决策特聘顾问、西安市人民政府金融顾问。
2001年加入深圳市创新投资集团，曾任深圳市创新投资集团基金管理总部总经理兼投资决策委员会秘书长，深圳市创新投资集团副总裁。先后参与各类投资项目决策1000余项，参与主持决策的项目中超300多个在全球17个主流资本市场成功上市。
被评为:福布斯中国2023年度创投人TOP 5，2024年度创投人TOP4,2025年度创投人TOP9，36氪2024-2026年最受创业者欢迎投资人，2024-2026年度中国集成电路与半导体领域最佳投资人物等50余项投资领域荣誉。
田耀四
蓝箭航天空间科技股份有限公司党委书记、副总裁
报告题目：重复使用运载火箭的发展现状与工程实践
田耀四，曾任职于国家国防科工局探月与航天工程中心，全程参与我国探月工程“绕、落、回”三期任务的组织、协调与管理工作。加入蓝箭航天后，全面融入民营商业航天的创新创业实践，重点负责统筹重大项目、重要型号的目标管理与资源配置，推动管理流程优化与运营效率提升，同时全面负责公司党建工作。
蓝箭航天成立于2015年，聚焦液氧甲烷火箭发动机和大型复用运载火箭研制，已建成“设计、制造、测试、发射”全链条能力。2025年，朱雀二号火箭进入批量生产与商业运营阶段；2026年8月19日，朱雀三号可复用火箭成功实现我国首次以着陆支腿方式陆地回收，火箭复用进入工程化验证阶段。
朱健楠
陕西欧卡电子智能科技有限公司CEO
报告题目：海面具身之路的研发及产业化之路
朱健楠，欧卡智舶CEO，正高级工程师，新时代先锋奖获得者，2025福布斯科创年度人物，以色列理工访问学者，德国Falling Walls全球100名青年科学家，曾任荷兰Microflown公司高级工程师。2017年创办欧卡智舶并担任CEO，入选工信部创业特等奖，入选联合国亚太区地球青年卫士、《财富》中国40岁以下最具潜力的商界精英、胡润under35精英、36X36人才、亚洲/中国福布斯U30、胡润U30、创业邦30岁以下创业新贵，陕西省5211市级引进人才、陕西省青年科技新星、陕西省特支计划和西安市英才计划领军创业人才、陕西省五四青年标兵、西安市五四青年标兵、省市级创业明星等诸多荣誉。
