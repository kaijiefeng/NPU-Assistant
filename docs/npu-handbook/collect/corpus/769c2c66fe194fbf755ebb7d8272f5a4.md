# 公共政策与管理学院召开2026年度新认定研究生导师岗前谈话会

为进一步加强研究生导师队伍建设，强化导师立德树人职责，增强导师岗位责任意识，提升研究生培养质量，公共政策与管理学院于2026年10月13日组织召开了2026年度新认定研究生导师岗前谈话会。学院院长刘晨光、党委书记管兴华、副院长李娜及2026年度新认定研究生导师参加了本次会议。
李娜首先传达了《西北工业大学研究生导师岗前谈话工作办法》等相关文件精神，详细解读了导师岗位要求、岗位职责、导师权利、导师“十不得”等内容。
管兴华指出导师要严守学术规范和师德师风底线，牢固树立导师是研究生培养第一责任人意识，与学生建立亦师亦友的关系，既要为学生提供学术指导，更要关注学生的思想成长和品德塑造。他强调在目前学生生源多样化带来的管理挑战下，导师还需重点关注意识形态问题，防止发生负面舆情。
谈话结束后，刘晨光与新认定导师签订了《西北工业大学研究生导师岗位责任书》。谈话小组向新认定导师颁发聘书并合影留念。
此次岗前谈话进一步强化了新认定研究生导师的岗位意识和责任担当，为学院研究生培养奠定了坚实基础。新导师们一致表示将认真履行岗位职责，恪守师德师风，持续精进业务，不断提升研究生育人指导水平。
