# 高质量推进新时代立德树人工程

“十五五”规划纲要指出，“实施新时代立德树人工程”。立德树人有机融合了马克思主义教育理论精髓、中华优秀传统教育思想底蕴与新时代教育实践经验，是党的育人理念在教育领域的集中体现与生动展开，直接关系党的事业后继有人，关系中国式现代化伟大事业的前途命运。学校作为人才培养的主阵地，要以新时代立德树人工程为牵引，全面深化人才培养体制机制改革，扎实推进新时代立德树人工程落地见效，不断塑造铸魂育人新格局。
坚持党的全面领导
坚持党的全面领导，是落实立德树人根本任务的根本保证。学校要始终把党的领导贯穿人才培养全过程、各环节，通过强化政治引领、健全制度体系、夯实基层基础，确保育人工作始终沿着正确方向前进，着力培养社会主义合格建设者和可靠接班人。
突出政治引领，坚定办学方向。社会主义办学方向是中国特色社会主义教育的本质特征，也是落实立德树人根本任务的必然要求。学校要把用习近平新时代中国特色社会主义思想武装头脑作为第一要务，严格执行“第一议题”制度，常态化推进党的创新理论进教材、进课堂、进头脑，引导广大师生深刻领悟党的创新理论的真理力量与实践力量。深入开展中华优秀传统文化教育、社会主义核心价值观教育、时代使命和责任意识教育，引导青年学生增强家国情怀，自觉听党话、跟党走。严格落实意识形态工作责任制，加强校园网络、讲座论坛、社团活动等各类阵地管理，坚决反对和抵制各种错误思潮，牢牢掌握意识形态工作领导权、管理权、话语权，确保育人各项工作沿着中国特色社会主义道路前进。
健全制度体系，规范育人工作。通过不断完善党委领导下的校长负责制，健全议事决策规则，确保党委切实履行“把方向、管大局、作决策、抓班子、带队伍、保落实”的职责。将立德树人根本任务全面融入学校发展规划、学科建设、师资队伍建设、校园管理等各项工作，明确各部门、各环节的育人职责，构建“党委统一领导、党政齐抓共管、有关部门各负其责、全社会协同配合”的全方位育人工作格局，确保育人工作层层落实、落地见效。
夯实基层基础，强化组织保障。要以党支部标准化规范化建设为抓手，加强学校基层党组织建设，将党支部建在学科团队、班级、宿舍园区，充分发挥基层党组织的战斗堡垒作用。选拔政治素质高、业务能力强、育人情怀深的教师担任党支部书记，推动基层党组织成为立德树人的重要阵地。加强党员教育管理，引导党员教师立足岗位践行立德树人使命，发挥先锋模范作用，带动广大师生共同参与育人工作，形成育人合力。
构建完善的工作体系
构建科学完善、运行高效的落实机制，是推动立德树人工作常态化、长效化的关键所在。学校要立足青年学生成长成才规律与教育教学规律，从目标体系、实施体系、评价体系三个层面协同发力，构建新时代立德树人工程落实机制，确保立德树人各项任务落地落细、取得实效。
构建精准化的目标体系。学校应结合办学特色、学科优势与学生群体特点，将立德树人总体目标细化分解为思想道德目标、能力素质目标、全面发展目标等，明确不同专业、不同年级学生的育人重点与实施路径。针对不同群体的成长需求，制定差异化、个性化的育人方案，突出分类指导、精准育人，切实满足学生成长成才需求。同时，紧密对接国家战略需求与产业发展方向，动态调整优化育人目标，着力培养具有创新精神、实践能力和责任担当的高素质人才，实现育人目标与国家需求、学生发展的有机统一。
构建一体化的实施体系。深化教育教学改革，将立德树人根本任务全面融入课堂教学、实践教学、管理服务全过程。强化思想政治理论课主渠道作用，创新教学内容与教学方法，运用案例教学以及情景式、体验式、沉浸式教学等方式，增强思政课的吸引力与感染力；深入推进课程思政建设，系统挖掘各类专业课程、通识课程蕴含的育人元素，将价值引领有机融入专业知识传授，实现思政课程与课程思政同向同行、协同育人。完善实践育人体系，构建校内外联动的实践育人平台，组织学生积极参与志愿服务、社会调研、创新创业、乡村振兴等实践活动，引导学生在实践中锤炼品格、提升能力。拓展网络育人阵地，充分利用新媒体平台，传播正能量、弘扬主旋律，引导学生树立正确的网络观，营造健康向上、和睦友善的校园网络文化环境。
构建多元化的评价体系。坚决打破“唯成绩论”等片面评价导向，建立以立德树人为核心的综合育人评价体系，将思想道德素质、实践能力、创新精神、社会责任感等纳入评价范围，实现评价维度多元化、评价方式科学化。完善学生评价机制，采用过程性评价与终结性评价相结合、定量评价与定性评价相结合的方式，全面、客观评价学生的综合素质；健全教师评价机制，将师德师风、育人成效作为教师评价的首要标准，加大育人实绩在职称评审、评优评先、绩效考核中的权重，引导教师将主要精力投入教书育人工作中。建立健全育人工作督查考核机制，定期对各部门、各单位的育人工作开展督查考核，将考核结果与评优评先、资源配置挂钩，倒逼育人工作落实落细、取得实效。
涵养积极向上的校园文化生态
良好的校园文化生态能够潜移默化地影响学生思想观念、行为习惯和价值取向，增强育人工作的感染力与实效性。学校需要立足自身办学传统，发展社会主义先进文化，弘扬革命文化，传承中华优秀传统文化，建设、涵养具有时代特征以及学校自身特色的校园文化生态，充分发挥文化育人功能。
传承弘扬优秀文化，厚植育人底蕴。深入挖掘中华优秀传统文化中的育人元素，弘扬仁爱、诚信、敬业、奉献、笃行等传统美德，将其有机融入校园文化建设，引导学生传承中华文脉、增强文化自信。弘扬革命文化，充分利用红色教育资源，开展红色研学、革命故事宣讲等活动，引导学生铭记历史、缅怀先烈，厚植爱国情怀，赓续革命精神。发展社会主义先进文化，深入宣传新时代的伟大成就与先进典型，引导师生坚定“四个自信”，自觉践行社会主义核心价值观。
打造特色校园文化，营造育人氛围。结合学校办学特色与学科优势，打造具有学校辨识度的校园文化品牌，通过校园文化节、学术论坛、文艺汇演、特色文化周（节）等活动，丰富师生精神文化生活，营造崇尚学术、追求卓越、关爱学生、潜心育人的校园氛围。加强校园环境建设，优化校园景观设计，打造文化长廊、主题园区等文化载体，让校园的一草一木、一砖一瓦都发挥育人作用，实现环境育人、润物无声。培育优良校风、学风、教风，引导教师严谨治学、潜心育人，引导学生勤奋学习、立志成才，形成积极向上、团结奋进的校园风气。
激发师生主体作用，增强育人合力。教师是立德树人的实施主体，是学生成长成才的引路人。要坚持把师德师风建设摆在重要位置，实施教育家精神铸魂强师行动，培养造就新时代高水平教师队伍。教育引导广大教师自觉践行社会主义核心价值观，以德立身、以德立学、以德立教，以高尚的道德情操、扎实的学识素养、深厚的育人情怀影响和带动学生，切实成为先进文化的传播者、知识传承的实践者、道德品行的示范者，切实履行“四个引路人”职责。尊重学生主体地位，鼓励学生积极参与校园文化建设，支持学生社团、志愿者服务队等组织开展丰富多彩的文化活动，引导学生自我教育、自我管理、自我提升，增强学生主体意识与责任担当。搭建师生互动交流平台，促进师生之间、学生之间的思想碰撞与情感交流，形成师生共同参与、共同建设、共同受益的文化生态，让文化滋养成为立德树人的重要力量。
