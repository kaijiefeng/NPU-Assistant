# 学生考试规范

1．学生考试时必须携带学生证、一卡通或身份证。
2．班主任要按照教学办下发的监考通知单提前15分钟到考场监考，不得随意换人，否则按教学事故处理。
3．各年级学生辅导员在考试时要去考场巡考，特别是补考生所在考场要加强巡视检查。
4．学院教学副院长、副书记、教学秘书及教务员须到考场巡视检查。
5．学生考试时不得自行携带草稿纸，如发现视夹带处理。
6．学生必须注意考场纪律，不得有任何违纪行为。
机电学院 2004年
