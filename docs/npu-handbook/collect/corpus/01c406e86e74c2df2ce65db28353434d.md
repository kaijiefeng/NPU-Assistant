# 我校赴江苏省重点生源中学开展招生宣传活动-

报考指南
首页-报考指南>宣传动态>
我校赴江苏省重点生源中学开展招生宣传活动
发布日期：2025-04-25
点击数：2351
4月17-18日，西北工业大学党委副书记、副校长詹浩带队赴江苏省昆山中学和苏州中学开展招生宣传活动。招生办公室副主任马婷婷、自动化学院党委副书记易正阳、自动化学院江苏招生组组长马戎等参加有关活动。江苏省昆山中学党委书记、校长陈纪华、副校长陈忠平、苏州中学校长周祖华等分别陪同交流。
在昆山中学，詹浩为高一年级学生作题为《逐梦蓝天——中国航空事业发展与未来发展趋势》专题讲座。他通过回顾我国由依靠维修外国飞机摸索学习，到设立专业院系、研究所，构建完整航天人才培养体系的历史，讲述了从依靠前苏联技术，到独立自主研发，并构建具备完整体系的艰苦卓绝历程，介绍了中国航空事业由追赶世界到领跑世界的格局。他鼓励同学们树立远大志向，以报国为己任，努力奋斗，积极投身国家的航空事业。马婷婷为高三学生家长作招生宣讲，就我校招生政策和录取情况向大家作深入介绍，助力学生精准规划，圆梦高考。
在苏州中学，詹浩一行与中学校领导、高三班主任座谈，双方就大学育人目标、办学理念、大学-中学教育衔接培养、今年高考情况等事宜进行深入交流与探讨。
据悉，此次招生宣传活动推动了西工大-江苏重点生源中学友好合作，创新协同育人路径，促进双方全面建立合作共赢长效机制，助力为选拔、输送、共同培养“五育融合”的未来创新人才搭建更好的平台。
