# 德法与形势政策系召开《中国共产党思想政治工作条例》集体备课会-西北工业大学

11月30日晚，在本学期《形势与政策》课程开课前夕，马克思主义学院德法与形势政策系开展了集体备课活动。主要围绕《中国共产党思想政治工作条例》（以下简称《条例》）、《马克思主义学院考试管理流程》、《形势与政策》课程教学说明等三个方面展开学习与交流。本次活动由系主任胡建发主持，承担《形势与政策》课程的三十余名教师全程参与。
全体教师深入、全面地学习了《条例》的主要内容，涵盖思想政治工作的指导思想、遵循原则、主要内容、基本方式、队伍建设、保障与监督，以及思想政治工作的任务要求。其中特别强调，推动用习近平新时代中国特色社会主义思想凝心铸魂，是思想政治工作的首要任务。《条例》明确指出，在学校思想政治工作中，要坚持思政课建设与党的创新理论武装同步推进，构建以习近平新时代中国特色社会主义思想为核心内容的课程教材体系。
随后，大家认真学习了《马克思主义学院考试管理流程》。这一文件是学院考试工作制度化的重要体现，通过学习该文件，能够有效保障学院各门课程，尤其是公共课考试的顺利开展。胡建发作了《形势与政策》课程教学要求及其他事项的说明。
通过本次备课会，大家对《条例》有了更深刻的理解，进一步激发了各位老师开展学校思想政治教育工作的信心、积极性和主动性。学院教师将严格遵循《中国共产党思想政治工作条例》的要求和指引，持续提升高校思想政治工作的水平，进一步增强高校思政课的思想性、理论性、针对性和吸引力。
