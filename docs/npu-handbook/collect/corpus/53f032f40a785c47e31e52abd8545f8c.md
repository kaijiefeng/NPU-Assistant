# 关于自动化学院2023年研究生创新基金立项名单公示

学院全体师生：
为公平、公开地开展学院2023年研究生创新基金评选工作，依据《西北工业大学博士论文创新基金管理办法》和《西北工业大学硕士研究生实践创新能力培育基金管理办法》，经本人申报、专家现场评审，最终经研究生院审核通过，拟批准郎春博负责的“面向少样本的图像语义分割方法研究”等8个博士论文创新基金项目，及李明帅负责的“基于OCT图像处理的眼底病变诊断技术研究”等14硕士研究生实践创新能力培育基金项目予以立项（名单见附件），现予以公示。
公示期限为3个工作日，即2023年5月6日至5月9日，公示期间如有异议，请以实名书面或电话方式进行反映，所提意见要求真实客观，并提供必要的证明材料。公示期间设立下列举报联系方式：
