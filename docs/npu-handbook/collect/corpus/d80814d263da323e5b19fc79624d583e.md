# 校医院召开庆“七一”党员座谈会暨党内表彰会-西北工业大学医院

6月27日下午，校医院召开“典范领航强党性，实干赋能建新功”庆“七一”党员座谈会暨党内表彰会。党总支书记乔辉、党总支委员、党支部书记及支部委员、党员代表、发展对象代表等40余人参会，会议由党总支委员田博主持。
首先，田博宣读党总支“七一”表彰决定。希望受表彰的优秀个人和先进集体要珍惜荣誉、戒骄戒躁，以更加昂扬的斗志、更加务实的作风，走在前列、争当表率、争做示范，不断开创医院发展建设新局面。
乔辉及党总支委员何凯亮、孙伟光、石丛艳为获得“先进党支部”“优秀共产党员”“优秀党务工作者”荣誉称号的先进集体和先进个人颁发奖牌和证书。
（党总支书记乔辉颁发“先进党支部”奖牌）
（党总支委员何凯亮、孙伟光颁发“优秀共产党员”证书）
（党总支委员石丛艳颁发“优秀党务工作者”证书）
会上，先进党支部代表、长安校区党支部书记赵强，优秀共产党员代表袁华，优秀党务工作者代表贺文娟，预备党员代表折胜利，发展对象代表石凯歌依次作交流发言。
随后的座谈会中，党员们结合自身工作经历，就如何用党的创新理论武装头脑、指导实践、推动工作进行了交流。
最后，乔辉总结强调：一要“以典范为镜”，在对标看齐中淬炼党性。让患者切实感受到医者仁心和作风建设成效。二要“以实干为要”，在攻坚克难中彰显作为。倡议全体党员争当改革攻坚“排头兵”、创新突破“主力军”、服务师生“贴心人”，始终牢记“患者和师生的笑脸就是党员最好的勋章”。三要“以创新为翼”，在党建引领中再建新功。通过抓“规范”让组织生活“严起来”、抓“融合”让党建业务“活起来”、抓“队伍”让先锋作用“强起来”。最后号召全体党员以冲锋姿态实干担当，为医院和学校高质量发展贡献力量。
