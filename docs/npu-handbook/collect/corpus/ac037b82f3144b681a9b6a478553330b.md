# 西北工业大学公共政策与管理学院校友会筹建公告

亲爱的校友们：
大家好！
因学校整体规划的需要，人文与经法学院于2021年1月正式更名为公共政策与管理学院。虽然名称有所变化，但学院精神与传统是一脉相承的。无论时光如何变迁，这里永远是校友们温暖的港湾、精神的家园。
为进一步汇聚校友力量，构筑校友与母校、校友与校友之间多维互动的纽带，推动学院事业迈向更高质量发展阶段，依据《西北工业大学校友会章程》相关规定，学院于2025年12月正式启动西北工业大学公共政策与管理学院校友会筹建工作。
西北工业大学公共政策与管理学院校友会是校友自愿发起的联合性、非营利性社团机构，业务开展接受西北工业大学校友会的专业指导与行政监管。公共政策与管理学院校友会将以“服务校友终身发展，助力学院学科建设与人才培养，传承西工大精神文化”为核心使命，致力于打造资源共享、协同创新的校友发展平台，通过构建校友互助网络、产学研合作机制、文化传承体系，实现校友成长与学院的共同发展。
为更好地筹备成立公共政策与管理学院校友会，现将相关事项公告如下：
一、校友范围
西北工业大学公共政策与管理学院校友会包括下列人士：
（一）曾在西北工业大学公共政策与管理学院（或原人文与经法学院）及相关专业学习和工作过的学生、教职工；
（二）西北工业大学公共政策与管理学院（或原人文与经法学院）授予和聘请的荣誉学衔以及其他享有学校荣誉证书及荣誉称号的人员。
二、会员加入
方式一：请各位校友填写附件《西北工业大学公共政策与管理学院学院校友会（筹）校友信息登记表》并将表格电子版发送至校友会筹备组的邮箱bailifei@nwpu.edu.cn，文件命名方式为“姓名+校友信息登记表”。
