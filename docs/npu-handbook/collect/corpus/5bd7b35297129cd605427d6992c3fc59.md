# 【学籍管理中心】补拍毕业照须知-西北工业大学研究生院

各位研究生：
如您因故不能参加学校组织的毕业照统一拍摄，请按照下列途径完成毕业照补拍：
（1）登录学信网（学信网：https://www.chsi.com.cn/）确认是否无“学历照片”，不能重复拍摄！
（2）登录学信网（学信网：https://www.chsi.com.cn/）获取本人的“图像采集码”后，前往陕西大学生图像信息采集点进行学历照片采集。地址：西安市新城区皇城西路20号新华社陕西分社第二工作区（新城餐厅院内）；时间：周一到周六，上午9：00-11：30 ；下午14：00-17：00，联系电话：029-87370330 高老师。
特别注意：学历照片补拍需要45天完成图片上传学信网以及纸质照片制作，请各位同学在学位论文送审前完成学历照片采集，否则可能会影响正常毕业。
（3）补拍后请及时核对学信网中的“学历照片”，并上传至本校的“研究生教育综合系统”，具体方法：翱翔门户-研究生教育-学位管理-上报信息核实，上传后点暂存即可。并将纸质照片交给所在培养单位研究生秘书。
请各位研究生同学高度重视学历照片的重要性，学信网中无学历照片将无法注册学历，造成不能毕业的严重后果！
学籍管理中心
