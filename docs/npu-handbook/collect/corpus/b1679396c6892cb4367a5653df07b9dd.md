# 电子信息学院召开树立和践行正确政绩观学习教育总结会

9月17日上午，电子信息学院召开党委会（扩大）会议暨树立和践行正确政绩观学习教育总结会，深入学习贯彻习近平党建思想和习近平总书记重要指示精神，认真贯彻落实中央党的建设工作领导小组会议、工业和信息化部党的建设工作领导小组（扩大）会议以及学校党建工作领导小组（扩大）会议精神，总结学院树立和践行正确政绩观学习教育开展情况，研究部署巩固拓展学习教育成果、建立树立和践行正确政绩观长效机制工作。会议由学院党委书记侯俊主持。
会议指出，学院党委坚持把开展树立和践行正确政绩观学习教育作为重要政治任务，深入学习贯彻习近平总书记关于树立和践行正确政绩观的重要论述，认真学习习近平党建思想，牢牢把握“立党为公、为民造福、科学决策、真抓实干”总要求，全面贯彻落实习近平总书记“三个认认真真、扎扎实实”重要要求，一体推进学查改，推动学习教育走深走实、落地见效。通过学习教育，全院各党支部和党员、干部切实加强了党性锻炼，深化了对正确政绩观的认识和理解，形成了行之有效的制度规范，为“十五五”开局起步提供了有力保障，为学院高质量发展增添了新动能。
会议强调，树立和践行正确政绩观是久久为功的长期任务，要认真学习领会、全面贯彻落实习近平总书记的重要指示精神，巩固拓展学习教育成果，建立常态化长效化机制。要在加强新时代党的创新理论武装上持续深化，深学细悟习近平总书记关于树立和践行正确政绩观的重要论述，把正确政绩观落实到立德树人根本任务中。要在长效化整改整治上持续用力，健全有效防范和纠治政绩观偏差工作机制，经常性查改政绩观偏差问题。要在真抓实干推动发展上持续见效，以功成不必在我的精神境界和功成必定有我的历史担当，努力创造经得起实践、人民、历史检验的实绩，为建设中国特色世界一流大学贡献电子信息学院力量。
学院领导班子、党委委员，各教师党支部书记，科研团队负责人，教师代表参加会议。
