# 我校主办首届陕西高校网络安全实战攻防竞赛

9月24日上午，我校网络空间安全学院、陕西教育网络安全研究中心联合陕西省总工会网络中心及兄弟高校举办的首届陕西省高校网络空间安全实战攻防竞赛在西安唐城宾馆正式开赛。
本次大赛以实际运行系统为靶标，各参赛队通过采取网络渗透手段进行攻击获取资源，旨在增强高校学生网络空间安全素养，提升实战环境下网络安全攻防能力，共同营造安全、稳定、和谐的网络空间环境。我校及西安交通大学、西安电子科技大学、西安邮电大学等高校共选派八支队伍参加本次比赛。陕西省公安厅网安总队、陕西省总工会网络中心、我校信息化建设与管理处、图书馆、网络空间安全学院及各兄弟高校网络空间安全学院院领导出席本次大赛。
上午9:00，比赛开幕式正式开始。开幕式上，张盛兵致欢迎辞。在致辞中，张盛兵院长首先感谢了对本次比赛大力支持的上级领导、高校、公司等，并介绍了参会人员与各支参赛队伍。他指出，此次比赛的目的在于促进交流和提升能力，实现以赛促学、以赛促教，提升陕西高校学子在实战环境下的网络攻防能力，以共同守护安全、稳定、和谐的网络空间环境，迎接党的二十大胜利召开。最后，他真诚地祝愿各支参赛队伍取得好成绩，在实战中不断提升攻防能力。
随后，陕西省公安厅领导吕西平、总工会领导解欢庆、陕西网络安全研究应用中心领导宋强分别致辞。三位领导表达了对各位高校老师以及各支参赛队伍的欢迎，强调了在党的二十大召开前夕举办此次比赛的重大意义，希望各支队伍恪守程序、展现风采，不断提升实战能力，守卫网络安全阵地，为党的二十大献礼。
经过两天的激烈角逐，比赛取得重大战果并顺利结束。西安电子科技大学的“虚怀战队”以总分第一成绩斩获一等奖，西北工业大学我校Jk代表队获得二等奖，E0A战队、Hk战队获得三等奖。西北工业大学网络空间安全学院常务副院长张盛兵、陕西省总工会网络中心副主任解欢庆、西安交通大学王平辉副院长分别为获奖的各支代表队颁奖。
