# 祝贺！力学与土木建筑学院路宽副教授获批2023年度陕西省杰青项目

12月27日，陕西省科技厅公布了2023年科技计划项目立项通知，我院副教授路宽《航空发动机转子结构非线性振动》项目，获批2023年陕西省杰出青年基金项目，是我院第5位获批省杰青项目的青年教师。
路宽，2022年获批陕西省特支计划-青年拔尖人才，发表SCI论文52篇，第一及通讯作者35篇，主要发表在J.SoundVib.、NonlinearDyn.、Mech.Syst.SignalPr.等本领域权威学术期刊上。ESI高被引论文2篇，SCI引用800余次(单篇最高引用82次)；申报发明专利7件，获批软著1件，参与编写专著3部。主持及参研国家自然科学基金重点、面上、青年、KGJ国防技术基础科研项目、国家重点研发计划、JKW某领域项目等9项国家级项目及陕西省自然科学基金、中国航空发动机集团科技创新平台项目等省部级项目6项，同时参与国家973项目及两机重大专项等项目。目前担任J.NonlinearMath.Phy.客座编辑，《应用力学学报》青年编委 ，科技部国家重点研发计划“制造基础技术与关键部件”、“智能机器人”等重点专项评审专家及项目跟踪专家 ，陕西省振动工程学会常务理事，中国振动工程学会转子动力学分会委员等职务。
(文：余滨杉，审核：温世峰)
