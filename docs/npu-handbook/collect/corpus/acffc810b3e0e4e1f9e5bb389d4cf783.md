# 阳春四月 赛事连连——档案馆工会小组活动报道

盛春时节，绿荫花海。为丰富全体馆员的文化生活，全面推进全民健身，档案馆工会小组积极组织广大馆员参加由校工会主办的庆祝中国共产党成立100周年“喜迎全运快乐骑行”教职工骑自行车郊游活动。
第十九届体育文化节暨第56届田径运动会赛场上也有馆员们的矫健身影。大家秉承“共同运动、强身健体”的理念积极参加比赛，充分展示自身优势，发挥潜能。
2021年教职工趣味运动会的活动也异彩纷呈。本届趣味运动会项目设置了5个集体项目，“旱地龙舟”、“车轮滚滚”、“指压板跳绳”、“接力夹乒乓球”、“欢乐贪吃蛇”。馆员们互相帮助，互相鼓励，体现了档案馆人员的精神风采和互助精神，增强了广大馆员的凝聚力和归属感，活动在欢声笑语中圆满结束。
