# 西北工业大学第十二届翱翔青年学者论坛诚邀您参会！

为统筹推进教育、科技、人才协调融合发展，深入实施新时代人才强校战略，持续汇聚全球优秀青年人才加入到学校中国特色世界一流大学的建设事业中来，学校拟于6月14-20日通过线上方式举办第十二届翱翔青年学者论坛。
诚邀全球英才参会，共谋未来发展。
一、论坛安排
主论坛
北京时间：2024年6月15日上午9:00（美、亚太场次）
2024年6月15日下午15:00（欧洲场次）
活动内容：论坛开幕式、学校发展及人才引育政策报告
分论坛
北京时间：2024年6月14-20日陆续开展
活动内容：云参观、学术报告、面试、试讲等（各分论坛详细活动持续更新）
二、邀请对象
1.拥护中国共产党的领导，遵守中华人民共和国法律法规，热爱高等教育事业，具有良好的科学道德，自觉践行新时代科学家精神。
2.年龄一般不超过40岁；全球知名大学、科研机构已经或即将毕业（出站）的博士生、博士后，以及在境外高校、科研机构、企业研发机构获得正式教学或科研职位的优秀学者。
3.取得同行专家公认的重要研究成果，且具有较大的发展潜力。
三、报名方式
请扫描下方二维码填写个人信息报名参会，报名截至2024年6月14日。报名后请与各分论坛举办单位保持线下联系，各分论坛将通过邮件等形式向符合条件的优秀学者发送参会邀请函。
