# 人事处党支部开展“感受总师文化，熔铸爱国精神”主题党日活动

为深入调研教职工实践教育培训资源，进一步提高教职工培训的实效性，促进党建活动与业务工作融合，4月13日下午，人事处党支部赴学校部分国家重点实验室和科技创新馆调研学习，开展“感受总师文化，熔铸爱国精神”主题党日活动。
党员们现场参观了凝固技术国家重点实验室、辐射探测材料与器件工信部重点实验室和学校科技创新馆，听取了相关实验室老师的详细介绍，并就未来开展新进教职工培训实践环节的参观组织、流程设计、讲解需求等和各实验室进行了深入沟通和交流。
此次主题党日活动不仅加深了支部党员对学校国家重点实验室的了解，同时也进一步深化了对教职工教育培训资源的调研。下一步，人事处将持续完善与优化教职工培训课程体系，以高质量党建引领业务高质量发展。
（文/张慧杰 图/孙梦桐 审核/唐玉生）
