# 凝心聚力谋发展 互学互鉴促提升——计划财务部召开财务工作线上调研交流会

为进一步推动高校财务治理体系与治理能力现代化，4月17日下午，西北工业大学计划财务部与哈尔滨工程大学财务处通过线上会议形式，围绕财务工作高质量发展开展专题调研交流。两校财务部门主要负责人及业务骨干共20余人参会。会议由计划财务部部长李春林主持。
会上，双方聚焦预算管理、增收节支、风险防控、数智化转型等财务管理核心议题，展开了深入而务实的讨论，现场交流气氛热烈。双方一致认为，当前高校财务工作正处于深化改革、提质增效的关键时期，肩负着优化资源配置、保障战略实施、防范运行风险、提升服务效能的重要使命。面对高等教育内涵式发展与科技革命加速演进的宏观背景，财务管理工作必须打破思维定式，主动求变、科学应变。跨校深度交流是破解管理难题、激发创新思路、互鉴先进经验的重要路径，有助于加快构建适应新时代要求的高校财务管理新范式。
此次线上调研交流，突破地域限制，搭建了高效务实的校际沟通平台，是深化财务管理经验互鉴、推动财务治理提质增效的重要契机，也是西北工业大学财务部门主动对标先进、拓展视野、服务学校高质量发展的重要举措。通过交流，既学习借鉴了兄弟高校的先进做法，也为进一步破解财务工作难点堵点、优化管理模式提供了有益启发。计划财务部将立足学校发展全局，持续提升财务治理能力和服务水平，助力学校“双一流”建设和各项事业高质量发展，以实干实绩为学校实现“一十百千”发展目标和“天下工大、世界三航”远景目标贡献财务力量。
