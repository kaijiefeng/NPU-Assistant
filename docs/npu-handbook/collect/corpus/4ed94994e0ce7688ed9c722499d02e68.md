# 2022年苏州数字发展“校园日”—走进西北工业大学（太仓智汇港）系列活动在太仓智汇港成功举办

为贯彻落实习近平总书记关于数字强国的重要思想，紧抓长三角一体化重要战略机遇，加快推进苏州市数字强市建设，全面助力数字经济和数字化高质量发展，充分借助高校学科资源和人才优势，加强网络安全领域的产学研合作，2022年9月4日，由苏州市委网信办、太仓市委网信办主办，西北工业大学太仓智汇港、网络空间安全学院承办的2022年苏州数字发展“校园日”——走进西北工业大学（太仓智汇港）系列活动在太仓智汇港成功举办。苏州市委网信办副主任李天德、苏州市委网信办网络安全和信息化协调处副处长谭亦文、嘉昆太三地宣传部副部长，西北工业大学太仓智汇港管委会常务副主任、太仓长三角研究院常务副院长郑曦、太仓智汇港党工委副书记陈洪亮、网络空间安全学院常务副院长张盛兵出席了本次活动。
9月4日上午，以“校政企、产学研、数字发展融合”为主题的交流会正式拉开了2022年苏州数字发展“校园日”系列活动的序幕。交流会上，网络空间安全学院、软件学院的专家展示分享最新科研成果，探讨合作愿景。网络空间安全学院院长助理金增旺副教授介绍学院发展历程及相关研究方向。孙文教授就“群智空间增效理论、群智体高效可控协同、网络群智演进与对抗”三方面开展的研究做了精彩分享；李晓宇副研究员详细分析了迫在眉睫的“社交网络主动认知安全”研究现状；胡伟副教授针对芯片设计安全的研究及自主工具研发成果做了介绍；毛伯敏教授介绍了车联网智能通信与安全方面的研究成果；杨黎斌副教授以“高机动性浮空器”的核心技术、硬件指标、拓展应用以及未来的发展规划为主题进行了分享。软件学院贺亮教授就“智能无人系统与大数据应用”做主题分享；吴逾强助理教授介绍了智能装备与工业软件方面所取得的成果。太仓市资产经营集团、天创安全运营中心、山石网科等5家参会代表介绍了企业发展现状及未来发展方向，并发布了目前相关需求。交流会现场互动氛围热烈，碰撞出产学研融合发展的诸多可能。
9月4日下午，“嘉昆太”2022年网络安全宣传周启动仪式将苏州数字发展“校园日”活动推向高潮。太仓智汇港党工委副书记陈洪亮代表西北工业大学致辞，三六零安全科技有限公司、中国电信苏州分公司分享了网络安全前沿技术及企业文化理念。
获得江苏省工信厅2021年度“数动未来”融合创新平台称号的“智联城市治理及其数字安全融合创新中心”正式揭牌。该融创中心由网络空间安全学院等七家单位联合申报，是网络空间安全学院获得的首个江苏省省级科研创新平台。依托“融创中心”为载体，以学院新一代信息技术实验室和主要教师团队为核心的苏州创融数字科技发展有限公司正式揭牌。随后，网络空间安全学院与苏州安软信息科技有限公司等5家知名网络安全企业签订校企合作协议，推动校企产学研深度融合，加快推进网络空间安全相关前沿技术的成果转化，实现资源共享、优势互补，共同发展。
网络空间安全学院联手苏州市委网信办与太仓市网络综合治理中心，在太仓智汇港建设网络空间安全实习实训基地并揭牌，力求做到安全和发展协调一致、齐头并进，以安全保发展、以发展促安全，努力建久安之势、成长治之业。随着太仓智汇港领导、苏州市和嘉昆太网信办领导共同按下“嘉昆太”高校网络空间安全创新创业大赛暨“嘉昆太”2022年网络安全宣传周启动仪式的按钮，宣传周正式拉开帷幕。
启动仪式结束后，网络安全企业专场招聘会同步开启，苏州和太仓的网络安全企业与学生面对面交流，让学生近距离感受长三角企业对网络空间安全人才的渴求。苏州、太仓将与网络空间安全学院携手同行，紧密合作，发挥太仓智汇港的地区优势，进一步加强专业建设和实习实训，不断探索新的人才培养模式，为行业输送更多创新型高质量人才。
