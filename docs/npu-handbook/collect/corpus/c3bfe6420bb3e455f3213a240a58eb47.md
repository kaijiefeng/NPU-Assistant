# 工会党支部书记陈建军讲授专题党课-校工会（帮扶办）/ 妇女联合会

3月20日，工会党支部在友谊校区健翔楼301会议室召开党小组会，根据机关党委下发的理论学习指导意见开展学习，支部书记陈建军讲授“领会党中央决策部署 推动新阶段高质量发展”专题党课，工会党支部全体党员参加学习。
首先，陈建军传达了基层党委（党总支）书记会议精神和学校党委理论学习中心组（扩大）会关于全国两会精神，强调支部党员要切实把思想和行动统一到习近平总书记重要讲话和全国两会精神中来，切实重视安全生产工作，全力营造安全和谐稳定的校园环境，进一步增强工会组织的吸引力、凝聚力，增强广大教职工群众的获得感、幸福感，更好地团结引导广大教职工群众坚定不移听党话、凝心铸魂跟党走。
随后，8位党员根据前期支委会布置的学习任务，分别领学了中共中央办公厅关于巩固拓展学习贯彻习近平新时代中国特色社会主义思想主题教育成果的意见、中组部印发的《关于在防范应对低温雨雪冰冻灾害和抗震救灾中充分发挥基层党组织战斗堡垒作用和广大党员先锋模范作用的通知》、习近平总书记在2024年春季学期中央党校（国家行政学院）中青年干部培训班开班之际作出的重要指示、《习近平总书记关于制造强国的重要论述学习读本》等内容，并就学习任务进行了重点发言。
当日下午，陈建军以“领会党中央决策部署 推动新阶段高质量发展”为主题讲授了专题党课，从我国经济工作取得的进展成效，我国经济发展面临的形势和机遇，协同配合、真抓实干，有力有效推动党中央决策部署落实落地等方面展开，强调要深刻领悟习近平总书记关于经济工作的重要思想，全面领会经济工作的总体要求、政策取向，胸怀“国之大者”，增强信心和底气，认真履职尽责，围绕重点任务，找准工会贯彻落实的切入点着力点，团结动员广大教职工为推动学校各项工作高质量发展建功立业，深入开展劳动竞赛和技能竞赛、“中国梦·劳动美”等系列活动，紧紧围绕学校“127”发展目标和“天下工大、世界三航”远景目标，以服务化、品牌化、创新化、智能化为重点，推动工会工作迈上新台阶。（文、图/钱娅群 审核/陈建军）
