# 俄罗斯

俄罗斯联邦·莫斯科·外交部统办30天内D、S免签需开具出境证明
使馆签证处地址：东直门北中街4号 开馆时间：0900-1200 约7-10个工作日
使馆网址https://beijing.mid.ru/zh/
俄罗斯签证：16天（包含16天）以内办理电子签证+出境证明；16天以上办理纸质版签证
因公短期纸质版签证要求：
照片：3.5*4.5白底彩照1张，尺寸与表格照片框大小一致
表格：1份，在线填写表格 visa.kdmid.ru
0.寒暑假带队任务需提供近三个月内的艾滋病检疫报告
1. 中文照会
2. 专用名单表（中文机打）中俄峰会、上合团组应填写具体会议名称
3. 护照
4. 签证表
①第7、8项必须与邀请信（黄卡）目的一致，
表格第一页最下方前往城市与邀请信一致
②表格第14项个人住址（不能填单位）、手机号（必须手机号）和邮箱必填，第15项单位地址、座机、邮件、传真必填
③在线填表时，“申请地点”请选择俄罗斯联邦大使馆而不是北京签证中心或其他地点，打印表格后会显示在表格右上方。
5. 邀请信 请见附注（如果是黄卡或电传号请放在名单表后面）
6. 护照复印件（首页）
7. 其他材料（如有）
【特别通知】据俄罗斯驻华使馆告，自即日起(2025.5.26)，若持公务普通护照团组内有2人及以上，名单表和邀请函需要每人一套，不可共用一份名单表和邀请函，其中团长的申请材料的名单表和邀请函需要盖章原件，其他成员可以使用复印件。此外，照会中的出行目的需要与邀请函中的出行目的保持一致，若不一致则按退件处理。
此国家为外交部统办，还需按顺序准备好以下材料：
1照会复印件（由外事中心提供并复印）
2“二维码”信息表
3任务批件（确认件和通知书）复印件、外专局批件等内部备案材料
