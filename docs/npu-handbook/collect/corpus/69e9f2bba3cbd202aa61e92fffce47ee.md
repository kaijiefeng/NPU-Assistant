# 【π·归来】海外访学报告第13期——蒲哲：在德国弗莱堡大学探索泛函不等式及相关问题

报告时间：2026年9月24日 (周四) 下午 14:00
报告地点：长安校区海天苑大楼D537
报告人简介：
蒲哲，数学与统计学院2020级博士研究生，师从郭千桥教授，主要从事最佳积分型不等式的研究。
项目概况及报告内容：
受国家留学基金管理委员会（CSC）资助，蒲哲同学于2024年7月至2026年6月赴德国弗莱堡大学数学系开展为期两年的联合培养，外方合作导师为 Guofang Wang 教授。联合培养期间，主要围绕泛函不等式及相关问题开展研究。本次报告将介绍该生在德国弗莱堡大学联合培养期间的科研进展与学习体会，并重点汇报在反向 Hardy-Littlewood-Sobolev（HLS）型不等式方面取得的研究成果。主要内容包括经典反向 HLS 不等式的插值改进，以及利用相关泛函不等式获得对数 Sobolev 型不等式的新证明等。
