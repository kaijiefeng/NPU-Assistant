# 【机关风采】呼瑞雪：算好学校发展“大账”，守好师生利益“小账”-机关党委

呼瑞雪同志扎根财务关键岗位，扛责任、打硬仗、出实绩，以实际行动彰显职能部门党员在学校发展中的支撑保障作用。
2026年度机关优秀共产党员
计划财务部 呼瑞雪
敢闯敢试，勇当改革攻坚排头兵
坚持以改革破题、以制度立规，将上级和学校党委的决策部署转化为扎实有效的具体举措。推动零基预算改革，落实经费分类保障体系，抓实项目论证评审，资源配置效益不断提高；落实国家财税体制改革，牵头政府会计制度转换和电子凭证会计数据标准试点，会计信息质量显著提高；主持建成部属高校首个财务共享中心，将6个异地机构、2个二级独立核算单位纳入集中统一管理，打通财会监督的“最后一公里”；起草修订校级财经制度10余项、内部管理制度8项，重构预算编制、收支管理、绩效评价全流程，财务治理体系更加完善。
精打细算，善当资金保障好参谋
坚持多渠道开源、全方位统筹，以机制规范管理、以数据支撑决策。全面梳理创收渠道，牵头制定增收节支工作方案，实行清单化管理，辅以政策解读和数据分析，支撑各单位创收举措逐项落地；建立经费统筹管理机制，优化立项审批、台账管理、使用监管流程，资源配置更加科学精细；深入对接归口管理部门，高效推进国债项目实施和财政资金预算执行，重点任务落地见效；促成银校合作项目50余项，筹集信息化建设和智慧教室建设经费，办学条件持续改善；规范附属单位收益上缴和成本核算管理，推进学校财务管理体系建设，为学校“双一流”建设提供坚实财力支撑。
数智赋能，甘当师生服务贴心人
坚持以信息化建设为抓手，推动财务管理从“传统核算”向“数智治理”转型。搭建财务在线审批与电子票据无纸化报销系统，重构预算编报、资金收付、差旅报销等7项核心业务流程；完善财务报销系统，打通电子票据无纸化入账通道；持续优化20余项财务业务线上办理，实现“数据多跑路、师生少跑腿”；全面升级预算管理系统，实现项目申报、立项、调整、调剂全流程线上办理；打通财务与资产、人事、大型仪器共享等业务系统，构建业财融合、数据互通的管理新格局。
学以致用，争当干事创业实干家
坚持理论和实际相结合，以持续学习提升履职能力。入选陕西省高层次财会人才工程、陕西省中央财会监督人才库，参与管理理论研究课题5项，获会计论文、管理案例奖2项，提出多项财务管理建设性意见，助力学校财务治理现代化建设；主动走进学院、服务大团队，开展财经制度宣讲10余次，解决财务政策吃不准、业务办理不畅通等急难愁盼问题，以时时放心不下的责任感对待每一个预算项目、每一笔资金，在平凡的财务岗位上践行共产党员的初心使命。
