# 春晖步履·日纪韶光”春日步数打卡活动正式启动！

当海棠的花影轻轻铺满跑道，当梧桐的新叶在风中开始私语，当日历翻到四月，西工大的春天，已经为你备好了一份独特的礼物。这一次，我们不以笔墨，而以脚步为度量。
“春晖步履·日纪韶光”春日步数打卡活动正式启动！
这不是竞赛，而是一场与自己的30天春日约定，去遇见更轻盈、更健康的自己，让坚持闪闪发光！
活动信息：
•活动时间：4月24日-5月23日（共30天）
•打卡目标：30天内累计完成20天有效打卡
•有效打卡：当日步数≥7000 步
参与方式：
扫码入群：加入活动专用QQ群：476852802（所有通知、规则、收集表均在群内发布）。
修改昵称：入群后请将群名片改为：姓名-学院-学号，便于信息核对。
启用工具：“小步运动”微信小程序（需要启用“微信运动”，否则小步运动无法同步数据。此外，由于部分手机小程序只能记录当月每日步数，所以每月最后一天一定要及时截图保存当月记录页，避免步数记录丢失），请及时启用避免丢失打卡数据。
打卡规则：
•记录工具：仅认可“小步运动”小程序提供的数据。
•结果提交：5月24日00:00-24:00，通过群公告内「打卡收集表」链接，上传4 月、5月两张步数记录截图。
•逾期未提交、截图不符合要求将视为自动放弃奖励。
完成奖励：
你的坚持，值得奖励！成功完成挑战，你将获得：
•活动证明（电子版），
•国家卓越工程师学院定制纪念品一份。
春光不等人，步履正当时。现在就扫码，我们一起出发！
