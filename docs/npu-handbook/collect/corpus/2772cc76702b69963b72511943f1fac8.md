# 西北工业大学网络空间安全学院开题答辩（韩鹏飞）

一、开题答辩题目：高信容卫星遥感影像压缩关键技术研究
二、开题答辩人：韩鹏飞
三、开题答辩时间：2023年10月26日9:30-12：00
四、开题答辩地点：友谊校区毅字楼6楼606会议室
五、开题内容简介
随着科学技术的不断进步，卫星遥感、探测、侦察等技术的精度越来越高，产生的数据量也越来越大。高分辨率卫星成像系统产生的影像数据量往往达到数百Gb/s量级，再加之有限的传输带宽和存储空间限制，给数据传输带来了极大的压力。传统的卫星影像传输方式所提供的传输速率上限已经难以满足星间、星地的高速通信需求。本研究依据“星间传输速率高，星地传输速率低”的特性，开展高信容卫星遥感影像压缩关键技术研究，重点解决星间影像数据冗余、星地数据重复传输和现有星上编码方式低效问题，实现有限带宽和存储空间下卫星影像数据高信容压缩与高效传输。
六、开题答辩人简介
韩鹏飞，男，学号2021100805，网络空间安全学院，导师李学龙教授，主要研究方向为卫星影像压缩与分析。
