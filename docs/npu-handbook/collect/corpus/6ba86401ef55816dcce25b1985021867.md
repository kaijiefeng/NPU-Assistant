# 春风作伴绽芳华 活力飞扬聚同心——档案馆工会小组积极参与校工会及机关分工会系列活动

为丰富教职工文化生活，增强团队凝聚力，档案馆工会小组响应校工会、机关分工会号召，积极组织馆员参与2025年春季系列文体活动，在扎染体验、油画插花、春日骑行、趣味运动等特色活动中展现档案人蓬勃向上的精神风貌，为校园文化建设注入新活力。
3月7日，在第115个国际妇女节即将来临之际，档案馆工会小组组织女教职工参与“邂逅中国千年扎染之美”与“法式油画插花”主题文化活动。在非遗扎染体验区，馆员们通过“绞扎-浸染-氧化”等传统工艺，将素色方巾变幻出蝴蝶、星辰等美丽的纹样；油画插花课堂上，大家巧手修剪花枝、搭配色彩，用油画与花朵编织出春日祝福。
4月13日，在“春满校园 骑迹工大”教职工自行车踏青游园活动中，馆员们积极参与，沿着翱翔重点实验室、航天飞行动力学重点实验室、军工素质教育实践中心、启翔湖、何尊广场……开启春日骑行。骑行队伍中既有自在追风的潇洒身影，也有同事间此起彼伏的加油声与帮扶瞬间。车轮碾过林荫道时，细碎的阳光透过新叶在骑行服上织就的流动光斑与清脆的车铃声相映成趣，谱写出流动的工大春韵图。
4月25日，在学校第59届运动会暨第二十二届体育文化节中，档案馆工会小组组队参与趣味运动会“旱地龙舟”项目。比赛中，馆员们拼劲十足，手握充气龙舟扶手，脚踏整齐划一的步伐，在“左右左”的口号声中协力向前，拉拉队的助威声响彻赛场。最终，队伍以“零失误”完成比赛，队员们笑称：“‘档案龙舟’划出了团结协作的精气神！”
春风作伴绽芳华，活力飞扬聚同心。档案馆工会小组通过精心组织各项活动，有效提升了教职工的幸福感、归属感和凝聚力。未来，档案馆工会小组将继续创新活动形式，引领馆员以更饱满的热情投身学校“双一流”建设，为传承工大精神、服务师生校友贡献档案力量。
