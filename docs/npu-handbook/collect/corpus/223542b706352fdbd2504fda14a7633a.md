# 关于我们

## 1）西北工业大学计算机学院地址

西安市长安区东祥路1号。

## 2）乘车方案

①从西安咸阳国际机场：

- 方案一：乘坐出租车60公里，约1小时15分钟；
- 方案二：机场大巴长安区希尔顿花园酒店线 → 734路、333路，约2小时。

②从西安北客站：

- 方案一：乘坐出租车55公里，约1小时20分钟；
- 方案二：地铁2号线至国展中心站 → 环山旅游1号线，约2小时；
- 方案三：地铁2号线至小寨站 → 地铁3号线太白南路站 → 333路，约2小时30分。
