# 赓续红色血脉，激扬航天精神|航天学院举办红色事迹分享会

为弘扬红色文化，传承革命精神，3月12日下午，航天学院在学院楼C346报告厅举办了一场以“传承红色基因、赓续精神血脉”为主题的红色事迹分享会。本次活动由航天学院团委及学生会组织，吸引了众多学生积极参与。
活动伊始，郝文轩同学以饱满的热情拉开了分享会的序幕。她围绕红色主题，带领师生回顾了中国共产党百年奋斗历程中涌现出的感人事迹，深刻阐释了红色精神在新时代的延续与发扬。
首先，郝文轩同学讲述了开国将军甘祖昌的故事。他主动放弃优厚待遇回乡务农，带领群众修水库、建电站、开荒山，用一生践行共产党人艰苦奋斗、一心为民的初心使命；其夫人龚全珍亦以他为榜样，教书育人、扶危济困，成为全国道德模范。随后，郝文轩同学讲述了航天员邓清明的坚守故事。他作为中国首批航天员，曾三次入选任务乘组却均担任“备份”，二十四年始终以“主份”标准要求自己，最终于2022年圆梦太空，用行动诠释了“宁可备而不用，不可用而无备”的航天信念。
作为航天学院推进红色思想教育的分享会，本次活动通过郝文轩同学的分享，增强了学生的历史使命感，营造了浓厚的红色文化氛围。同学们认真聆听、积极互动，在思想洗礼中深化了对红色精神的理解。作为新时代航天学子，更应传承红色基因，将个人理想融入国家发展大局中，在航天事业的道路上奋勇前行。
红色基因，代代相传；奋斗之路，永无止境。航天学院将继续以“公诚勇毅”校训为指引，引领广大学子在红色精神的滋养中立志成才、砥砺前行，为实现中华民族伟大复兴的中国梦贡献青春力量。
