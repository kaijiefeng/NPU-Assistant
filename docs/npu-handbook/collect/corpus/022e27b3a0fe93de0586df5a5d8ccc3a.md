# 学校召开2025年度文明宿舍暨党员示范宿舍表彰大会

3月26日下午，学校在长安校区教西A100报告厅召开2025年度文明宿舍暨党员示范宿舍表彰大会。党委学生工作部部长于辉，后勤部后勤集团副总经理陈琛，党委学生工作部五级职员张翠仙，公寓物业人员代表，各培养单位党委副书记、辅导员、学工主管以及获奖宿舍学生代表参会。会议由学生处副处长、学生公寓管理中心主任彭亮主持。
2025年度学校共评选出500间文明宿舍、32间党员示范宿舍。这些优秀集体，秉持“内务整洁、学风浓厚、氛围和谐、先锋引领”的理念，用自律践行初心，用团结凝聚力量，用担当彰显风采，生动诠释了西工大学子脚踏实地、奋勇争先的优良风貌，为全校所有宿舍树立了可学可鉴的标杆，作出了示范引领。
本次表彰大会坚持典礼育人理念，将颁奖环节作为一堂生动的思政大课。伴随着激昂的旋律，与会嘉宾先后为获奖代表颁发荣誉证书。一份份荣誉证书，既是对获奖集体的充分肯定，更是对全校宿舍践行文明公约、涵养优良舍风的激励与号召。典礼通过庄重的仪式感、鲜明的价值导向，引导同学们在荣誉激励中厚植集体意识与责任担当。
交流发言环节，多位师生代表从不同角度分享了宿舍建设的经验与感悟。文明宿舍舍长代表、教育实验学院鲍鸣涵同学分享宿舍互帮互助、共同进步的温馨故事；党员示范宿舍舍长代表、航空学院钟登波同学生动诠释党员示范宿舍以“小我”融入“大我”、以“小阵地”引领“大风尚”的先锋风采；辅导员代表张玉台坚持育人力量下沉、做好学生引路人，为宿舍建设提供可学可鉴的范本。学生公寓管理中心副主任吴杨围绕文明新风培育、宜居品质提升、成长社区建设作专题工作汇报，回应了同学们最关注的事项。随后，党员示范宿舍舍长代表、电子信息学院佘阳同学宣读了《共建文明公寓，争做优良舍风践行者》倡议书，号召全体同学做优良舍风的坚守者、和谐公寓的维护者、优良学风的引领者、宿舍安全的守护者。
于辉向受表彰的先进集体表示热烈祝贺，向长期深耕宿舍育人一线的全体工作人员致以诚挚感谢。他以“为什么、是什么、干什么”三个问题为切入点，深刻阐释了宿舍的核心育人价值。他指出，宿舍是大学生在校期间学习生活的核心空间，是落实立德树人根本任务、推进“四全育人”的重要阵地，更是学校深化“一站式”学生社区建设的关键载体。于辉对同学们提出期望，建设一间整洁规范的宿舍，涵养严谨自律、精益求精的工匠精神；建设一个和谐奋进的宿舍，凝聚团结协作、携手攻坚的集体品格；建设一个标杆引领的党员示范宿舍，筑牢党建引领、先锋带头的基层堡垒。
此次表彰大会，既是一次成果总结会、先进表彰会，更是一次深化典礼育人、推进公寓育人工作的全面动员会。与会师生纷纷表示，将以此次大会为新起点，以先进为榜样、以文明为追求，将自律作风、勤学态度、担当精神融入日常学习生活，以优良舍风涵养优良学风，以青春担当践行初心使命，在强国建设、民族复兴的伟大征程中，奋力书写属于西工大学子的青春华章！
