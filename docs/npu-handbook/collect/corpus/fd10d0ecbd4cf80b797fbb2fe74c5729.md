# 活动室使用须知

（一）教工活动中心活动须知
1、教工活动中心是全校教职工业余学习、锻炼和娱乐的活动场所，是学校精神文明建设的重要阵地；
2、请您自觉遵守各活动室的制度，听从管理人员安排，礼貌、文明活动；
3、请您在乘坐电梯时，让老、弱、病残教职工先行。在活动时，关心、照顾老、弱、病残教职工，杜绝任何长时间占用行为；
4、严禁在教工活动中心进行任何形式的赌博、违法活动及商业经济营活动；
5、教工活动中心仅供本校教职工活动，外单位人员、大、中小学生及儿童谢绝入内；
6、为了维护教职工的利益， 保证教职工和教工活动中心的财产安全及正常的活动秩序，进入时请您出示本校证件；
7、禁止携带宠物、易燃、易爆等危险品进入教工活动中心；
8、根据校长办公会确定的原则，健身房、台球室、沙壶球厅暂实行面向全校教职工象征性有偿收费开放。请您购买《活动卡》后，按相关要求进入活动室活动；
9、请您在活动时注意安全，如有疑问，请向管理人员咨询，以免使用不当造成意外伤害；
10、请您自觉维护公共场所的卫生整洁，保持大楼内安静秩序，不得大声喧哗；
11、请您爱护教工活动中心的活动器材、设备，如有意人为损坏器材，需照价赔偿；
12、请勿在非吸烟活动室吸烟，请勿随地吐痰、乱丢杂物；
13、请勿随意私自开启教工活动中心楼内的电源开关、空调、排气扇、灯光等电器设备；
14、携带教工活动中心的器材、物品出门，需持有校工会或离退休处证明；
15、在教工活动中心发生火警等紧急情况时，请您不要拥挤，听从工作人员和管理人员的指挥，有序地安全撤离。
16、教工活动中心开放时间： （每周一为管理员休息日）
夏季（ 5月1日—9月30日）：下午2:30—6:00晚上7:30—10:30
冬季（10月1日—4月30日）：下午2:00—5:30晚上7:00—10:00
（二）多功能厅使用须知
1、多功能活动厅面向全校各单位集体开放；
2、单位、团体如在该厅内举办活动，需提前活动中心管理办公室联系，便于协调；
3、请使用者维护室内卫生，勿随地吐痰、乱丢杂物，禁止在室内吸烟；
4、请使用者爱护公物，严禁私自使用、挪动厅内各种设施设备，如人为损坏物品，需照价赔偿；
5、非工作人员不得进入控制室；
6、学校工会系统、离退休处、教职工社团组织集体活动有使用优先权；
7、请勿随意私自开关多功能活动厅内的空调、引风机、灯光等电器设备
（三）书画室使用须知
1、书画室主要面向教职工社团、协会组织开放；
2、如需使用，必须提前预约；
3、请使用者维护室内卫生，勿随地吐痰、乱丢杂物，禁止在室内吸烟；
4、请使用者爱护公物，如人为损坏东西，需照价赔偿；
5、学校工会系统和离退休处组织集体活动优先；
6、请勿随意私自开关室内的空调、排气扇、灯光等电器设备。
（四）阅览室使用须知
1、阅览室面向全校教职工开放；
2、开放时间与教工活动中心开放时间同步；
3、请您保持室内安静，勿大声喧哗和交谈；
4、请您维护室内卫生，勿随地吐痰、乱丢杂物，禁止在室内吸烟；
5、阅览室的书籍、期刊、报纸仅限在本室内阅读，一律不外借，请勿带出；
6、请您爱护阅览室的公物、书籍、期刊、报纸，请勿随处涂写、刻画；
7、凡损坏阅览室内公物，期刊、报纸者，视其损坏程度，给予相应赔偿； 8.请勿随意私自开关阅览室内的空调、换气扇等电器。

1、职工培训教室面向老年大学、社团组织开放；

3、请使用者维护室内卫生，勿随地吐痰、乱丢杂物，禁止在室内吸烟；
4、请使用者爱护公物，如人为损坏东西，需照价赔偿；

6、请勿随意私自开关室内的空调、排气扇、灯光等电器设备。

2、单位、团体如需使用，必须提前登记、预约；

5、请使用者爱护室内公物，不得随意移动或带出，如人为损坏东西，需照价赔偿；
6、请勿随意私自开关室内的空调、排气扇、照明灯等电器设备。
（七）舞蹈排练室使用须知
1、舞蹈排练室面向全校单位、社团集体开放；
2、单位、团体如需使用，必须提前登记、预约；

（八）健身房使用须知
1、根据校长办公会确定的原则，健身房暂实行面向教职工象征性有偿收费开放；
2、健身活动者须购买教工活动中心《活动卡》，并持卡由管理员注销后方可进行活动；
3、非本校职工、大中小学生及儿童一律谢绝入内；
4、开放时间与教工活动中心开放时间同步；
5、请勿穿硬底鞋、高跟鞋、带钉鞋进入健身房；
6、请您保持室内安静，不得大声喧哗；
7、请您维护室内卫生，勿随地吐痰、乱丢杂物，禁止在室内吸烟；
8、请您听从管理人员安排，文明健身，不得私自移动健身器材；
9、使用健身器材前务必先熟悉使用规程，如有疑问，请向工作人员咨询，以免使用不当造成意外伤害，凡未按操作规程，造成人身伤害者，责任自负；
10、请您爱护健身器材，如有人为损坏器材，需照价赔偿；
11、请您健身活动时，将私人贵重物品自行妥善保管；
12、请勿随意私自开关室内的空调、排气扇、灯光等电器设备。
