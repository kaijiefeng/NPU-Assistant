# 牢记嘱托，青声琅琅！“十五五”规划主题青年宣讲课单上线啦！-青春驿站-共青团西北工业大学委员会

习近平总书记指出：“新时代中国青年要继续发扬五四精神，以实现中华民族伟大复兴为己任，不辜负党的期望、人民期待、民族重托，不辜负我们这个伟大时代。”今天，强国建设、民族复兴的接力棒已经交到当代青年手中。唯有把个人奋斗融入党和人民事业，把人生理想融入民族复兴伟业，始终保持昂扬向上的精神状态和永久奋斗的青春姿态，才能在时代大潮中书写出无愧于时代、无愧于人民的青春华章。
2026年是“十五五”开局之年，“十五五”规划许多内容涉及青年，首次设立“支持青年发展”的独立专节，为支持青年成长成才和高质量发展提供了重要政策保障，充分体现了习近平总书记和党中央对青年一代和共青团工作的重视关怀。值此五四青年节即将到来之际，工大青年宣讲团用28门精品课程，把“大道理”变成“身边事”，将创新理论转化为“青言青语”，朋辈引领工大青年在“十五五”规划学习中找准奋进坐标，以青春行动践行“请党放心，强国有我”的铮铮誓言。
六大板块，提取“十五五”规划中的“青”元素
奋楫绘蓝图——“十五五”规划是什么？五年规划如何改变你我生活？
创新铸利剑——科技自立自强中的青年担当？“总师育人文化”与我校学生创新创业浪潮里藏着哪些精神密码？
数智助腾飞——人工智能、数字经济浪潮下，青年如何乘势而上？

文脉续薪火——从非遗到国潮，文化自信如何“活”起来？
青春勇担当——青年一代如何在社会实践、志愿服务、科技创新中贡献力量？
即日起，全校各党团支部、学生组织等集体可通过“西北工业大学青年宣讲团”预约小程序在线点单，宣讲团将按需送讲上门。
关于工大青年宣讲团
工大青年宣讲团是在学校党委的直接关怀下，在团委和党委宣传部的共同指导下成立的学生组织，经过六年发展，探索出具有工大特色的“信而学、学中讲、讲中行、行中创”的青年宣讲路径。
