# 校领导会见沙特水务总署代表团

6月11日，沙特水务总署副署长塔里克·加法里率团来校访问，副校长孔杰会见了加法里副署长一行。
孔杰代表学校对加法里一行来访表示热烈欢迎。他回顾了西北工业大学与沙特水务总署在工程领域联合培养人才的进展，并表示西北工业大学学科体系完备，在工程技术领域具有扎实的科研积累与支撑能力，期待双方在现有合作基础上持续深化、拓展合作，共同推动合作取得新的实质性进展。
加法里对西北工业大学的热情接待表示诚挚感谢。他表示，此行实地访问学校，对西工大在工程领域的研究深度与创新实力印象深刻。他介绍，沙特水务总署正大力推进水资源管理的智能化与工程化转型，双方在技术需求与研究方向上高度契合，期待在现有基础上进一步深化技术攻关与人才培育合作。
航海学院、宁波研究院、国际合作处相关负责同志参加了会见。
（文字：刘倩；图片：周军平；审核：陈俊）
