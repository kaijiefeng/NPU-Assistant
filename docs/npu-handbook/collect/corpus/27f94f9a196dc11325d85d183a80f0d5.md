# 关于申报“2020年度西北工业大学在华举办国际会议计划（包括在线举办国际会议）”的补充通知

各单位：
根据工业和信息化部文件《关于编制2020年度在华涉外活动计划的通知》（工外函﹝2019﹞1943号）要求，在华申办国际会议（包括在线举办国际会议）实施预报制度。对于没有按时预报计划的，工信部将不再受理申报和审批手续。请校内各单位按照工作需求，务必于2020年6月25日前将《2020年度西北工业大学在华举办国际（含双边、涉港澳台）会议计划表》电子及纸质版（附件1）、举办国际会议立项审批材料电子版（附件2）由各单位外事秘书汇总上报至国际合作处。
