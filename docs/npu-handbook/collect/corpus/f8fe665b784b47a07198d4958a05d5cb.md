# 校园交通安全倡议书

全校师生：
2024年12月2日是第十三个“全国交通安全日”，主题为“文明交通、携手共创”。在此，党委保卫部向全校师生发出倡议：
一、认真学习并严格遵守《中华人民共和国道路交通安全法》，切实增强交通安全意识，树立文明交通理念。
二、文明驾驶，礼貌行车。自觉遵守交通信号、交通标志、标线的指示，不超速行驶，不强行超车，不逆行，不抢道，不插队，不乱鸣笛，不开赌气车、英雄车。
三、服从交通管理、杜绝乱停乱放。停放车辆时，不堵占消防通道，不逆向、双排停车，不占用多个停车位；非机动车有序停放在划定的非机动车车位内，不占用机动车道及机动车停车位。
四、遵守交通规则，注意文明礼让。雨雪天气，机动车减速慢行，注意礼让行人；骑行尽量靠右靠边，不并排或成群骑行。
五、倡导校园内少开车，多步行，“低碳环保从我做起，绿色出行快乐启航”。
文明校园有你我，和谐交通伴我行。让我们共同维护校园交通环境！
党委保卫部
2024年11月29日
