# 专业概况

运动训练专业是面向“体育强国”、“健康中国”、“全民健身”发展的迫切需求，致力于培养运动训练领域具备“通人体、强专项、擅训练、能贯通”能力的体育“总师型”领军人才。
西北工业大学运动训练专业依托体育部开展学生培养工作，体育部起源于1938年国立西北工学院体育组，1957年创建西北工业大学体育教研室，1990年改名体育部。目前拥有体育学一级硕士学位授权点。本专业专任教师62人，其中教授4人，副教授29人，讲师22人，助教7人；硕士研究生导师13人，国际级裁判1人，国家级裁判16人，陕西省教指委委员1人。
本专业学生将学习体育概论、运动解剖学、运动生理学、体育心理学、体育科学研究方法等体育类基础课程，同时也接受运动训练学、运动技能学习与控制、体育竞赛学等专业核心课程，还会接受专项技能训练，如田径、篮球、羽毛球等。此外，学生还将学习体育与人工智能概论、运动训练监控与技战术分析等特色课程，并参与到各类体育赛事的组织和管理工作中，以增强实际操作能力和团队协作精神。毕业生可以在专业运动队、学校体育部门、体育俱乐部、体育科研机构等领域从事运动训练、体育教学、运动科学研究、竞赛管理等工作。
