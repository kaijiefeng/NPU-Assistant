# 国际合作处党支部开展支部书记讲党课

10月27日下午，国际合作处党支部书记张富利围绕“调查研究”讲授主题党课，国际合作处（国际教育学院）全体人员参会，会议由党支部副书记李自伟主持。
张富利从调查研究的重要性、调查研究的历史演进和如何做调查研究三方面讲述。他指出，重视调查研究是我们党的优良传统，是中国革命、建设、改革取得胜利的重要法宝。调查研究不仅是一种工作方法，更是关乎党和人民事业成败的大问题。他从百年党史中分析了调查研究的历史演进，解析了“调查”、“调查研究”、“调研”三个词语的共性与特殊性。着重介绍了开展调查研究的方法，要细化调查纲目、突出交流实效、明晰相关问题人员，要在基层交知心友、要亲力亲为、力求实效、建立长效联系机制。
此次党课使全体工作人员对于调查研究有了系统的了解和认识，对于开展调查研究有了科学的方法论指导。国际合作处（国际教育学院）也将学史力行，深入师生广泛开展调研，准确掌握师生所需所盼，主动为师生排忧解难。（文/图：张桑桑核：李自伟）
