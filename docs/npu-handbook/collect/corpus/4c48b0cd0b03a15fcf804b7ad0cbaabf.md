# 人工智能学院/无人系统技术研究院召开科研项目经费管理培训会

4月17日，院邀请计划财务部张卉主任围绕科研经费使用规范、政策解读等内容开展专题培训。20余名教师参与，本次培训由副院长符文星主持。
符文星对张卉的莅临指导表示欢迎。他强调，规范科研经费管理是保障学院科研工作有序开展的重要基础，希望参训教师珍惜本次学习机会，认真学习、积极交流，切实提升经费使用与管理能力。
张卉结合科研经费管理新政策与案例，围绕科研项目从立项到结题全流程，对经费预算编制、支出范围与标准、报销流程与注意事项、预算调整、结题审计及常见问题解析等核心内容进行讲解。她强调经费使用要遵循“合规性、真实性、相关性”原则，详细说明常见支出要求及报销凭证规范，解答教师在经费管理中的问题。培训中，参训教师聆听、记录，并结合自身问题与她深入交流。
此次培训紧密结合学院科研经费管理实际需求，内容务实、指导性强，有效解决了教师在经费管理中的困惑，为学院进一步规范科研经费使用、提升科研管理水平奠定了坚实基础。
