# 弘扬长征精神 凝聚奋进力量——学院开展“奋进正当时”青年理论学习

为弘扬伟大长征精神，走好新的长征路，持续推进自我净化、自我完善、自我革新、自我提高，10月21日，教育实验学院/未来技术学院/学科交叉中心组织开展“奋进正当时”青年理论学习。学院领导班子和全体教职工参加学习。
会上，董晨、王斯妍、玛哈分别领学习近平总书记关于意识形态工作的重要论述、习近平文化思想、习近平总书记关于加强党的作风建设的重要论述、习近平总书记关于总体国家安全观的重要论述、习近平总书记关于加强和改进民族工作的重要思想、习近平总书记关于安全生产的重要论述和重要指示精神等内容。
与会人员结合岗位职责交流学习体会、研讨落实举措。
院长林鑫指出，全体教职工要牢记为党育人、为国育才、为军铸才使命，以长征精神砥砺担当，坚持理论联系实际，统筹好“守底线”与“谋发展”，紧盯年度重点任务，补齐短板弱项，守牢各类风险底线，以实干实绩推动学院内涵式高质量发展。
党委书记牟蕾在总结讲话中强调，全体领导干部、党员、群众要弘扬伟大长征精神，在理想信念中立志，在崇高品格中立德，在过硬本领中立行，传递好历史的接力棒，团结凝聚全院力量，牢固树立底线思维，营造风清气正、干事创业的育人环境。
奋进正当时，行稳方致远。与会人员纷纷表示，将持续深学细悟、对标落实，把本次学习成果转化为履职行动，立足岗位深耕育人、潜心治学，严守纪律规矩，主动担当作为，为“两院一中心”事业高质量发展贡献力量。
