# 卓越大讲堂——“筑牢反诈防线，守护校园 安全”校园反诈专题讲座

为深入推进平安校园建设，增强广大学生防范电信网络诈骗的意识和能力，有效遏制校园涉诈案件发生，11月5日，国家卓越工程师学院联合民航学院举办反诈宣传教育专题讲座。本次讲座采用“线下主会场＋线上分会场”相结合的形式开展，长安校区学生于教西D106教室线下参会，友谊校区学生通过线上直播同步参与学习，特邀西安市公安局东大派出所一级警长贾育松担任讲师。
贾育松结合多年一线办案经验与典型案例，全面分析了当前电信网络诈骗犯罪的产业链运作模式与跨域作案特点，针对冒充公检法、机票退改签、冒充电商客服、网恋诱导投资、刷单返利、虚假网络贷款等校园高发骗术，逐一拆解作案流程与话术陷阱，深入阐释“未知链接不点击、陌生来电不轻信、个人信息不透露、转账汇款多核实”的“三不一多”反诈核心原则。他着重提醒全体学生，要妥善保管个人身份信息、银行账户及支付验证码，切勿向陌生人开启屏幕共享，警惕电话卡、银行卡出借与买卖风险；遇到可疑来电与信息务必通过官方渠道核实，一旦遭遇诈骗第一时间拨打110报警止损。讲座同时推介了国家反诈中心APP、运营商骚扰电话防护等实用反诈工具，引导学生主动筑牢自身防护防线。
本次专题讲座内容详实、案例鲜活，兼具警示性与实用性，让在场学生对电信网络诈骗的手段与危害有了更直观、更深刻的认识，有效提升了同学们的识骗、防骗、拒骗能力。未来，学院将坚持把反诈宣传教育作为学生安全教育的重点工作，通过多形式、多渠道的宣传活动常态化开展反诈教育，切实守护好学生安全，为平安校园建设筑牢坚实防线。
