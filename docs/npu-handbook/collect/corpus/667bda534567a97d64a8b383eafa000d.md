# 西北工业大学后勤办公室维修项目资料管理规定

西北工业大学后勤办公室维修项目资料管理规定
后勤办字〔2019〕4号
第一条为进一步规范维修项目资料管理，提高维修项目管理水平，特制定本规定。
第二条本规定所指的维修项目资料是指由后勤办公室组织实施的维修项目的相关资料。
第三条维修项目资料应真实、准确、完备。
第四条国拨维修项目资料应包括项目申报书、资金计划函、招标委托、招标答疑、中标通知书、中标单位的投标文件、施工合同、开工报告、材料进场检验报告、工程量签证、认质认价申报单、认质认价确认单、竣工报告、竣工验收记录表、工程结算资料、审计报告、付款审批表等。
第五条自筹维修项目资料应包括立项文件（批示的报告或纪要等）、采购资料、施工合同、工程量签证、认质认价申报单、认质认价确认单、验收报告、工程结算资料、审计报告、付款审批表等。
第六条维修项目完工验收后，相关资料应由甲方代表移交至资料管理人员，甲方代表对所移交资料的真实性、准确性、完备性负责。
第七条维修项目资料管理人员在收发项目资料时，应做好交接登记，并对收到的资料分类建档，妥善保管。其他人员因工作需要借阅已归档资料，应在资料管理人员处办理登记手续，用完及时归还。
第八条维修项目资料管理人员应定期对所保管的资料进行核查，对破损资料及资料盒及时维护，对已借出逾期未归还的资料及时催还。
第九条维修项目资料管理人员应严格遵守后勤办公室保密制度，确保所保管资料的安全，不得擅自扩大利用范围。
第十条本规定适用于后勤办公室维修项目资料管理，自发布之日起实施。
