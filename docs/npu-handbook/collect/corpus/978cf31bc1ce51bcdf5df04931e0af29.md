# 情暖中秋 健康同行-西北工业大学医院

中秋佳节圆满落幕。为进一步关爱教职工身心健康，普及科学饮食理念，9月24日中秋前夕，学校机关工会举办中秋系列主题活动，特邀校医院梁乐乐医生开展题为《别让“幸福肥”毁了你的健康》的健康饮食科普讲座。
讲座内容贴近教职工日常膳食习惯，通俗易懂、实用性强。现场学习氛围浓厚，大家积极提问、互动交流，收获满满。
活动现场，校医院护士袁华、邵婷为参与教职工提供便民健康检测服务，细致完成胸腹围测量、体脂检测等基础健康评估，帮助教职工直观了解自身身体指标，树立合理膳食、科学养生健康生活理念。
本次活动将节日温情与健康服务相结合，切实把暖心、便民的健康服务送到教职工身边，进一步营造了关注健康、热爱生活的良好校园氛围。
责编 石丛艳
审核 乔辉
