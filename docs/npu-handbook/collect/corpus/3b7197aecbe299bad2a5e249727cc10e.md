# 关于西北工业大学2023年第二学士学位招生面试安排的通知-

特殊类型招生
首页-特殊类型招生>第二学士学位>
关于西北工业大学2023年第二学士学位招生面试安排的通知
发布日期：2023-06-08
点击数：13597
各位考生：
根据《教育部高等教育司关于做好2023年度第二学士学位教育工作的通知》和《西北工业大学2023年第二学士学位招生简章》要求，学校已对报名考生的申请材料进行初审并已将结果上传至报名系统，请及时登录查看。现将面试工作相关安排通知如下：
一、面试时间
2023年6月12日（周一），具体时间考场安排（见附件1）。
二、面试地点
长安校区、友谊校区
三、面试内容
1.自我介绍环节，时间约1分钟；
2.评委提问环节，时间约9分钟。重点考核考生思想认识、专业基础（包括第二学士学位学习规划）、英语水平、语言表达和心理素质等综合能力。
四、考生注意事项
参加面试考生须携带以下材料：
1.第二代身份证原件；
2.往届毕业生须携带毕业证书、学位证书原件，应届毕业生须携带从学信网上下载的有效期内的《教育部学籍在线验证报告》；
3.须携带本人所获的本科学习阶段成绩单、院级及以上荣誉和奖励，等级证书、资格证书等相关材料；
4.由本人签字确认的《西北工业大学2023年第二学士学位考生面试诚信承诺书》（见附件2）；
5.由本人签字确认的《西北工业大学2023年第二学士学位报名表》。
五、其他事宜
1.面试全程录音录像；
2.考生须及时查看面试具体安排，未按时参加的考生视为自动放弃面试资格。
