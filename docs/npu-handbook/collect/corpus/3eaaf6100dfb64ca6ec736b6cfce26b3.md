# 停摆的八音钟——一只时钟里的纪律与初心-青春驿站-共青团西北工业大学委员会

尊敬的各位老师、亲爱的同学们：
大家好！
今年是红军长征胜利90周年。90年前，一支衣衫褴褛却目光如炬的队伍，用双脚丈量信仰，用纪律赢得民心。
在云南寻甸柯渡镇丹桂村的一座白墙青瓦院落里，陈列着一只手掌大小的古铜色八音钟。钟体锈痕浮现，指针早已停摆。它被称作红军长征柯渡纪念馆的“镇馆之宝”，并不是因为他精巧漂亮，而是因为它见证了一段关于纪律与初心的往事。
一只停摆的钟，首先是一道纪律的考题。
1935年4月底，中央红军途经柯渡，总部驻扎丹桂村，正在为抢渡金沙江作最后部署。离开时，一名年仅十几岁的警卫员陈昌奉，看到毛泽东同志日夜操劳，想到行军途中需要钟表报时，便把乡绅杨家的一只八音钟悄悄装进了挎包。部队行至金沙江皎平渡，毛泽东同志发现了这只钟，当即严肃批评，责令立即送还。毛主席讲得很重：一旦开始拿人民群众的东西，不管价值多少，都会损害我党我军的形象。当时部队距柯渡已有140多公里，渡江在即，折返已不现实。警卫员深刻检讨后，钟被暂存于江边一户农家，留下银元，托请日后归还原主。
一只八音钟，值不了几个钱，在生死攸关的渡江时刻，似乎“算不上大事”。但恰恰是在这些“算不上大事”的地方，我党我军的纪律底线才显露出真正的分量。危急关头，党和红军领导人并没有因为战事紧迫就把一只八音钟当小事。这是纪律底线，事关民心向背。“不拿群众一针一线”，不是一句写在标语上的口号，而是在枪林弹雨、生死存亡之间依然不可移易的行为边界。
从一只被归还的钟，我们看见的是一条纪律的底线；从一次严厉的批评，我们读懂的是一个更深的理论命题，即纪律怎么能够锻造政治主体。
在马克思主义经典作家那里，纪律从来不是外在于无产阶级政党的权宜之计。马克思在写给恩格斯的信中就明确表明了：“我们现在必须绝对保持党的纪律，否则将一事无成。”列宁则在其无产阶级政党理论中，进一步把无产阶级政党的纪律界定为“铁的纪律”，同时又强调，这种纪律区别于剥削阶级靠饥饿和棍棒维持的“棍棒纪律”，它是建立在共同理想和自觉认同基础上的纪律。也就是说，纪律之所以能够“锻造政治主体”，恰恰因为它不是把人变成被动服从的工具，而是通过共同的规则和约束，把分散的个体凝聚为一个有统一意志、统一行动的政治集体，使一个阶级从“自在”走向“自为”。
毛泽东同志把这一逻辑讲得更为透彻。“路线是‘王道’，纪律是‘霸道’，这两者都不可少。”路线回答往哪里走，纪律回答怎样一起走。没有纪律，再正确的路线也会在各自为政中落空；没有纪律，再宏大的理想也会在松松散散中消解。那只被责令归还的八音钟，正是在“霸道”的意义上守护了“王道”：它守护的不仅是一户群众的财产，更是一支队伍作为政治主体的纯洁性和统一性。纪律的严厉，不是对个体的否定，而是对集体政治品格的塑造。
最后，从一段渡江前的插曲，我们还要追问一个更具历史纵深的问题：民心向背的密码究竟藏在哪里。
长征途中，红军渡过的不只是金沙江、大渡河，还有一道更深的水，即民心。旧军队过境，兵过村败物亡；红军过境，打土豪、分田地，不拿群众一针一线。一只八音钟被带走，看起来是小事，但把它送回去，送回去的是群众对这支队伍的信任。人心是最大的政治。纪律的每一次严格执行，都是在为政治主体积累道义合法性；纪律的每一次松动，都是在消解这种合法性于无形。90年后回望，八音钟的故事之所以仍然动人，不是因为它讲述了一个好人好事，而是因为它揭示了一个政党何以赢得历史主动的深层机理，即纪律不是外在于初心的约束，纪律本身就是初心最可检验的存在方式。
今天，我们站在“十五五”开局之年。与1935年相比，新时代青年面对的已不是枪林弹雨和物资匮乏，而是另一种更隐蔽、更日常的考验。诱惑增多、边界模糊、小节无害的侥幸心理潜滋暗长。习近平总书记反复告诫年轻干部，要“扣好廉洁从政的‘第一粒扣子’”，要“在遵规守纪中干事创业”。这提醒我们纪律的考验从未消失，它只是换了形态。当年是一只八音钟该不该拿，今天可能是一次变通、一张卡、一个下不为例的方便。尺度变小了，但性质没有变；场景日常了，但逻辑没有变。
那只八音钟的指针停摆了，但它所丈量的纪律尺度从未停摆。作为接过共产主义接力棒的青年学生，我们研究理论，更要在理论中看清自己的位置，我们不是纪律的旁观者，而是被纪律所锻造的政治主体的一分子。把遵规守纪内化为行动自觉，不是对青春的束缚，而是一个政治主体真正走向成熟的标志。在强国复兴的新长征路上，愿我们心中都有一只不走的钟，在每一个算不上大事的选择面前，提醒自己纪律无小事，初心在分寸之间。
谢谢大家！
