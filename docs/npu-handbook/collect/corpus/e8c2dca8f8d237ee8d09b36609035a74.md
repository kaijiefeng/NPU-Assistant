# 关于开展“第七届中国大学生5分钟科研英语演讲” 西北工业大学校内选拔赛的通知-西北工业大学研究生院

各培养单位及各位同学：
根据“第七届中国大学生5分钟科研英语演讲”工作安排，现将“第七届中国大学生5分钟科研英语演讲”西北工业大学校内选拔赛相关事宜通知如下：
赛事简介：为积极响应国家培养“具有国际竞争力的新工科、新医科、新农科、新文科的创新人才”号召，提高我校本科生、研究生使用英语从事专业学习、科研创新和学术交流的能力，帮助我国未来的科研工作者有效地向国际同行介绍自己学术思想和科研成果，特举办5分钟学术英语演讲大赛暨“用英语讲科研”活动。
一、参赛要求
1.参赛选手为我校在读的大三、大四本科生及研究生。报名时分研究生组、本科生组。
2.参赛选手需用易于理解的英语在5分钟时间内向没有专业背景的听众介绍一项与自己专业相关（包括专业科普类）的研究。
3.研究形式可以介绍已发表或撰写中的科研论文，也可以介绍尚处于想法阶段的科研计划。
4.演讲的具体内容包括：（1）论文标题和研究领域；（2）研究现状；（3）研究目的（问题或假设）；（4）研究方法；（5）研究结果（或预期结果）；（6）结果讨论和研究意义；（7）参考文献。
5.作品形式为5分钟的现场演讲，PPT展示和一个250词左右的英文摘要。
6.参赛选手需遵守学术道德，不得出现以下学术不端行为：
（1）抄袭、剽窃、侵吞他人学术成果；
（2）篡改他人学术成果；
（3）伪造或者篡改数据、文献，捏造事实；
（4）未参加创作，在他人学术成果上署名。
如发现选手有上述行为，组委会将取消选手的参赛资格，并通报选手所在学院进行严肃处理。
二、报名
1.报名时间：
2023年9月3日——2023年9月30日
2.报名联系人：
西北工业大学外国语学院
崔老师：029-88430907
3.报名形式：
以个人为单位报名参加，并请扫描下方二维码进行报名信息填报。研究生报名参赛的同学可在研究生教育系统中选修研究生课程《科技英语学术报告》（M16L22089）并获得课程学分。
4.参赛选手需在2023年11月10日前提供5分钟长的视频参赛作品，并以附件形式发入邮箱：englishwrite@163. com，同时加入赛事QQ群707017201，相关赛事安排将在群中通知。
5.组委会组织专家对视频作品进行评比，入围选手受邀参加西北赛区落地赛，现场决出各奖项名次，最后推荐参加全国决赛。
6.所有参赛选手请自行留存一份参赛作品。
