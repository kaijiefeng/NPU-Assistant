# 我院教师代表参加学校航天科工人才输送座谈会

11月5日，学工部负责同志，相关学院负责同志和教师代表，我院党委副书记徐晓峰，教师代表杨尧、沈钧戈、乔磊参加了学校召开的航天科工领域人才输送专题交流座谈会。党委常委、副校长张富利主持会议。
会上，党委学生工作部通报了“十四五”以来学校航天科工领域人才输送总体情况。我院教师代表在会上做了积极发言，立足学院学科特色和人才培养优势，提出要以“总师育人文化”引领学生赴航天科工系统主机院所建功立业，主动适应国防科技事业发展新形势。在人才培养中提升人工智能专业素养，以科研项目为牵引，同步规划学生就业，关注就业学生未来发展，为学校高质量就业做出贡献。
张富利对我院近年来面向国防军工的人才输送成效给予肯定。同时指出，要准确把握国防领域人才竞争新态势，破除惯性思维，以更高站位重塑就业工作格局，推动人才培养链与国防军工人才需求链精准对接；要发挥我院的独特优势，做实联合培养和实践锻炼，健全优秀本科生向目标院所输送机制，压实导师第一责任，推动科研合作优势转化为人才培养和输送优势；要前移就业引导，持续开展校友典型案例宣传，引导学生树立正确职业观、地域观，投身国防科技事业主战场。
作为培养国防军工领域人才的排头兵，我院将认真贯彻落实学校会议精神，以高水平科研项目带动学生实践创新和职业发展，持续深化与航天科工系统重点院所的协同合作，为服务国家重大战略、促进毕业生更高质量就业作出新贡献。
（文：王坤朋 审核：徐晓峰）
