# 软件学院举办“启翔师道”高质量教育教学专题系列讲座（第十四讲） ——探讨AI时代软件工程人才培养新路径

为应对人工智能时代对软件工程人才培养带来的冲击与挑战，深入践行学院“软件*AI+X”人才培养理念，探索AI赋能下的“总师型”软件人才培养模式，2026年4月22日上午，由软件学院西安教师党支部承办的“启翔师道”高质量教育教学专题讲座（第十四讲）在启翔楼303举行。本次讲座以“人工智能时代软件工程专业人才培养的挑战与对策”为主题，特邀同济大学特聘教授朱少民主讲，采用线上线下相结合的形式开展，学院全体教师参会。讲座由软件学院西安教师党支部书记武君胜主持。
武君胜首先对朱少民的到来表示热烈欢迎，并介绍了其学术成就与行业影响力。朱少民作为CCF杰出会员，深耕软件测试、质量管理与软件工程领域近三十年，获多项省、部级科技进步奖，出版20多部著作及4本译作，代表作有《软件工程3.0》《智能软件工程》等。他曾担任思科（中国）QA高级总监等重要职务，长期以咨询、顾问等方式帮助国内近百家企业提升软件研发工程能力。
讲座中，朱少民围绕AI大模型对软件工程领域的颠覆性影响展开深度分享，内容涵盖四个方面：大模型对软件工程带来的变化、AI对软件工程教育的影响、如何借助PBL打造创造性复合型人才以及未来人才培养路径。他深入分析了当前AI技术在软件工程领域的应用现状及发展趋势，提出软件工程3.0时代“人机结对”新范式，这与学院人才培养的核心导向高度契合，为软件与AI、多领域融合的培养方向提供了有力支撑。
针对AI带来的冲击，朱少民明确了软件工程专业人才培养的转型方向，提出核心能力重构与教学改革并行的应对策略。他指出，新时代软件人才需重点提升系统性思维、批判性思维等高阶能力，强化对AI智能体的驾驭能力和问题定义能力；教学中应推行PBL教学法，将问题抛给学生，培养其分析问题与解决问题的能力；同时改革课程评估体系，强化过程性考核，鼓励学生利用AI工具辅助学习，实现个性化教学辅导。他还强调，学生应保持终身学习的好奇心，以适应快速变化的技术环境。
朱少民进一步探讨了AI时代教师角色的转型方向，认为“教师应从知识讲授者转变为学习引导者。AI时代，教师不再是知识的唯一权威，而应转变为学习环境的设计者、问题的提出者及学生思维的引导者。教师需在特定专业领域保持比通用大模型更深的专业深度，同时主动适应数字化教学生态的发展，以体现不可替代性。
讲座最后，与会教师围绕课程考核优化、教学方法创新等核心问题展开热烈研讨，结合学院人才培养实际，深入探讨软件、AI与行业需求深度融合的具体路径，为复合型人才培养目标落地建言献策。本次讲座立足AI时代产业需求，为学院培养高素质软件工程人才提供了新思路、新路径，对提升教师教学能力、优化人才培养模式具有重要指导意义，也为学院持续深化人才培养改革、打造特色鲜明的“软件*AI+X”复合型软件人才培养高地筑牢了基础。
