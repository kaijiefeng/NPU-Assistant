# 意大利

意大利共和国·罗马·外交部统办180天内不超过90天D免签 需开具出境证明
使馆签证处地址：三里屯东二街2号，只能从三环辅路过去（东三环北路），三里屯路上的三里屯东二街是死胡同！ 约7-10个工作日
签证中心地址：光华路SOHO二期C座B1层东101室，全团都持用公务普通护照的（棕皮护照）赴签证中心留取指纹
使馆网址http://www.ambpechino.esteri.it/Ambasciata_Pechino
护照翻到照片页按名单表人名先后顺序依次捆绑在一起，每个人的申请材料按照名单表人名先后顺序依次叠放在一起。
因公短期签证要求：
照片：3.5*4.5白底2张，半年内近照
表格：在线填写，打印二维码 https://e-applicationvisa.esteri.it/
1.机打预约名单表
2.机打免预约申请表（仅团组中留过指纹的申请人填写）
3.留指纹那次的签证页复印件（指纹有效期59个月，超出则无需提供，需再次前往使馆留取指纹）
4.中文照会
5.机打专用名单表（国际司盖章，1人也要）
6.签证表，填写在申根境内停留的日期，不包含路途和时差。
7.邀请信原件+复印件（国际会议、学术、文化活动邀请信必须由主办方，如学术或文化机构出具，不可由会议组织方出具）
8.邀请人护照或身份证复印件
9.意大利公司注册证明CCIAA
10.在职费用证明（英文、签字盖章）
11.保险原件+复印件（无彩打原件可提供2份复印件）
12.护照复印件
13.酒店订单
14.机票订单
15.Consent Form同意函，第一处方框内签名，不填写日期和申请编号
此国家为外交部统办，还需按顺序准备好以下材料：
1照会复印件（由外事中心提供并复印）
2“二维码”信息表
3任务批件（确认件和通知书）复印件、外专局批件等内部备案材料
