# 我校举行2026年学生军训动员大会

8月25日上午，学校在长安校区翱翔体育馆召开2026年学生军训动员大会。校党委常委、副校长、军训师第一政委张富利，武警工程大学信息工程学院大校副院长石方进，学员七大队上校大队长、军训师师长马涛出席会议，军训师全体官兵参加会议。

军训师政委于辉主持会议并表示，西工大是国家着眼国防军工事业发展专门设立的国防军工高校，自诞生之日起就与强国强军事业同频共振，承担着为党育人、为国育才、为军铸才的特殊使命，既是国防科技攻关的重要力量，更是军工拔尖人才自主培养的主阵地。新生军训既是强化国防观念、树牢国家安全意识的现实课堂，更是淬炼军工青年忠诚底色，涵养隐姓埋名、为国铸剑使命担当的实践载体，目的就是引导同学们把爱国情、强国志、报国行融入国防科技事业追求之中。

会议开始，现场全体起立，奏唱中华人民共和国国歌。张富利宣读了《2026年学生军训师团以上干部名单》，并向军训师授军旗，马涛接旗。

马涛在讲话中强调，全体参训学生要以训铸魂，厚植家国情怀；以训笃行，勇担时代之责；以训健体，锤炼坚毅品格。要全身心投身军训，持续增强国防观念，锤炼吃苦耐劳的意志品质，涵养团结互助的作风。希望全体教官立足岗位、恪尽职守，当好国防精神的传播者、军人作风的示范者、军事技能的指导者、蜕变成长的引路者。

一团五连连长陆帅宇代表全体参训教官发言，承诺全体教官必将以身作则、树立榜样，依法组训、科学施教，文明带训、筑牢安全。二团二十三连指导员陈松玲代表参训政工干部发言，送给新生集体、坚韧、使命三个关键词，并表示将认真做好训练组织、思想引领和服务保障工作。二团九连学员才雪建代表2026级参训学生发言，表示将恪守服从命令、令行禁止的准则，秉持刻苦训练、磨砺意志的信念，发扬团结协作、荣辱与共的精神。

全体齐唱《中国人民解放军军歌》，大会在激昂的歌声中结束。
