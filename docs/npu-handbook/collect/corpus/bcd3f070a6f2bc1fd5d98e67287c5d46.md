# 网络空间安全学院组织研究生导师观看 “立德树人 德法兼修”专题报告

为加强研究生导师队伍建设，进一步明确研究生导师岗位职责，网络空间安全学院于11月15日下午14：00，组织学院新导师观看2022年翱翔导师学苑专题报告（第一期）。
报告由中国政法大学张永然教授主讲，以“立德树人 德法兼修——新时代研究生导师的任务与责任”为主题，从新时代导师职责的要求、导师权责的法制分析、构建和谐导学关系的建议三个方面为研究生导师做了全面而深入的讲解。报告中张永然教授讲到导师应以人为本认真履职，营造和谐导学氛围，不断学习提高学术素质以保持对研究领域重要问题的把握能力，恪守导师职责和职业道德，以严谨治学、诲人不倦的人格魅力给予学生勇气、信心和力量，师生共同营造和谐互动、教学相长的导学关系。
观看报告的导师纷纷表示，张永然教授的报告信息全面、内容丰富，通过报告，让导师们对自己的岗位职责有了更深入和清晰的认识，也从中学习了构建和谐导学关系的优秀做法，对他们今后更好地成为一名“四有”好导师给予了很大的指导和帮助。
