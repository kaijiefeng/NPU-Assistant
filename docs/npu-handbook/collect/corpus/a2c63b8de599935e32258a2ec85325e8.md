# 党委保卫部对学校重点部位开展消防安全专项检查

为严格落实陕西省教育厅《校园安全稳定风险预警》和学校《关于开展2026年第二季度全校安全生产检查的通知》相关文件要求，切实做好消防安全防控工作。5月28日至6月3日，党委保卫部对两校区餐厅和教学区开展了消防安全专项检查。
为深刻汲取油烟管道火灾事故教训，在两校区餐厅，检查人员重点检查油烟管道和集烟罩的油污清理状况、防火止回阀和排油烟风机的运行状态、油烟管道材料是否达标，认真翻阅排烟设备清洗记录表、油烟净化设施清洗质量报告、油烟检测报告等资料。同时，对消防设施完好有效性、疏散通道畅通情况、电气线路敷设情况、消防安全管理制度落实情况进行检查，做到全方位排查、无死角整治。此外，检查人员还就厨房油锅起火应急处置常识向餐厅员工进行了普及宣传。
在两校区教学区，检查人员重点围绕以下内容开展检查：一是消防设施设备的完好性与有效性，逐一检查了教学区域的灭火器是否在有效期内、压力是否正常，消火栓是否配备齐全、水压是否达标，应急照明灯和疏散指示标志是否完好且能正常点亮，烟感和手报是否正常工作。二是消防疏散通道与安全出口的通行保障情况，对教学区楼道杂物堆放、安全出口封堵等问题开展细致排查。三是用电管理是否规范，对电气线路老化、私拉乱接电线、违规使用大功率电器等风险隐患进行排查。检查人员同时还测试了火灾自动报警系统和防火卷帘的运行情况，并向相关人员普及初期火灾扑救、疏散逃生知识。
针对本次检查中发现的隐患问题，检查人员已指导相关单位安全责任人现场整改。后续，党委保卫部将继续加强对重点部位的日常巡查工作，常态化做好隐患排查整治，确保隐患问题整改到位、动态清零，提升消防安全管理精细化水平，为高质量平安校园建设提供坚实的消防安全保障。
