# 关于2023年“五一”期间加强廉洁自律有关要求的提醒-机关党委

“五一”劳动节将至，按照学校《关于强化重要节点持续深入贯彻落实中央八项规定精神有关工作的通知》要求，持续深入贯彻落实中央八项规定精神，持之以恒纠正“四风”，推进机关党风廉政建设，现将“五一”期间加强廉洁自律有关要求提醒如下：
各党支部：坚持纠“四风”树新风并举，在五一节前面向全体干部职工做好教育提醒工作，以学习贯彻习近平新时代中国特色社会主义思想主题教育为契机，教育引导广大党员干部特别是领导干部牢记“三个务必”、践行“三严三实”，弘扬党的光荣传统和优良作风，严格家教家风，以节日为契机，将弘扬新风正气同传承节日文化结合起来，推动移风易俗、纠治歪风陋习、倡树文明风尚。
机关党员处级干部：要发挥示范表率作用，严格遵守中央八项规定精神，带头清廉过节、节俭过节，带头厉行节约、反对奢侈浪费，严禁违规吃喝、违规收送礼品礼金、违规发放津补贴或者福利等。
希望机关干部职工过一个廉洁文明、欢乐祥和、风清气正的节日。
机关党委
2023年4月28日
