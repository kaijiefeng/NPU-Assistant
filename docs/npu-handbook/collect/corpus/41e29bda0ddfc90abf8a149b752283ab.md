# 学院与西安紫光国芯开展支部共建与访企拓岗交流活动

为深化党建引领拔尖人才培养，健全校企协同育人机制，扎实推进访企拓岗，9月29日，教育实验学院/未来技术学院师生代表赴西安紫光国芯半导体股份有限公司，与企业党支部开展支部共建交流活动。学院支部书记、辅导员玛尔哈巴，组织员王斯妍参加活动。
通过前沿成果展示与专业讲解，师生们直观了解高端芯片产业发展态势，深切感受国产集成电路产业的创新活力与攻坚担当。双方支部围绕党建工作特色、党员教育管理、党建与业务融合等内容深入交流、相互借鉴，同时就企业人才能力要求、实习实践资源与就业岗位供给开展务实对接。
西安紫光国芯的系统化人才培养体系、青年员工成长路径及岗位能力标准，为学生职业发展提供了有力参考。
本次活动也邀请到西安紫光国芯优秀校友代表分享成长经历，各位校友结合自身从业经验，从专业深耕、科研积累、职场适应等方面分享心得，引导同学们立足专业、坚定方向、锤炼本领，主动投身关键领域产业建设。
本次支部共建活动，主动对接国家重大发展战略，打通校企协同育人通道，是学院以党建赋能拔尖人才培养、服务国家关键领域发展的重要举措，也是以党建联建带动访企拓岗，助力学生高质量实习就业的一次有益实践。下一步，学院将持续强化党建引领，不断完善校企协同育人机制，依托校企支部联建平台，把组织优势转化为育人优势，着力培养家国情怀深厚、追求卓越、引领未来的“总师型”科技创新领军人才。
