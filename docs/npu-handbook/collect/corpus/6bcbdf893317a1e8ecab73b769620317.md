# 人员费网报业务常见八大问题

人员费网报业务经过一段时间的运行，现就一些常见问题做一下提示和说明。
1.请各位老师填写网报单上的“发放事由”，对发放事项进行说明。图示如下:
2.在校内人员其他工薪收入申报录入模块，如果您输入的是非事业编制人员工号，银行卡号一栏会显示“Nodata”，请将鼠标放到“Nodata”一栏中点击一下，然后按“Enter”键，就会显示出一个银行卡号选取的对话框，选中卡号，点“选取”即可；若对话框中没有显示出银行卡号，则需要该人员登录个人信息平台，在平台上维护一个银行卡号，之后系统才能调取到。
3.校外人员信息采集时，是否跨行由系统自动生成，请不要人为做修改。关于开户行查询方法在下图中举例说明：
4.如果您申报的人员费类型为评审费、咨询费、论文评阅答辩费，请您将“发放项目”选择为“评审费”(图示如下），不要选“其他收入”，选择的项目是否恰当，对发放结果有影响。如您选择的不合适，财务人员无法做调整，此单会做退单处置，您需要重新提交。
5.如您选择的发放项目为“评审费”，请沿用以往的财务报账要求，继续提供相关附件材料。评审费、咨询费请提供评审会或咨询会会议通知、信息采集表（或会议签到表）、现场勘察咨询工作照等附件材料；论文评阅答辩费请提供学院开具的“学位研究生论文评阅、答辩酬金支付凭证”、“学位论文答辩计划审批表”、“学位论文答辩委员会专家备案表”、“学位论文预评审审批表”、“学位论文预答辩审批表”、“信息采集表”（或答辩会签到表）等附件材料。
6.对同一个业务事项，发放对象既有校内人员又有校外人员的，请将附件材料原件附在校内人员网报单后，校外人员网报单请附复印件。
7.每月最后两个工作日至次月8日前，受个人所得税结税和工资计税工作影响，暂停校内人员网报单的账务处理。学生酬金网报单和校外人员网报单不受影响。
8.请各项目负责人、经办人提供有效的联系方式。如果出现发放失败的情况，财务人员会短信或电话进行通知。
如您还有其他疑问，请联系财务处工资奖助科，电话：88460647、88460648、88460617。
