# 党委保卫部举办学校义务（志愿）消防队成立仪式

11月是消防宣传月，本年度消防宣传月的活动主题是“全民消防、生命至上”。为进一步提高广大师生的消防安全意识，提升消防安全管理实效，党委保卫部联合校内外组建了学校义务（志愿）消防队。11月5日下午，义务（志愿）消防队成立仪式在长安校区启真楼104会议室举行。党委保卫部部长朱建军、副部长王坤庆、方原，党委学生工作部副部长曹子尧以及西安市消防救援支队草堂消防救援站的领导及首批师生志愿者参加了成立仪式。
朱建军在致辞中指出，义务消防队的成立，是新形势下践行群众路线的根本要求，是推动平安校园建设的重要举措，并对首批志愿者提出三点希望：一是充分认识校园安全和志愿服务重要性，积极参与党委保卫部组织的业务培训；二是立足自身岗位，积极发挥专业优势、集聚社会资源、拓展工作平台，在消防安全宣传教育吸引性、有效性提升，在义务（志愿）消防队建设等方面思索创新；三是充分发挥“领头雁”示范力量，坚定群众路线，在做好消防志愿服务工作同时，以自身实际行动引领带动更多师生了解并积极加入消防志愿者队伍，共同营造校园安全环境。随后，与会领导为义务消防队员代表颁发了证书。
西安市消防救援支队草堂消防救援站站长王鑫为志愿消防员开展了消防安全培训。他从火灾的危害及校园火灾事故的主要原因、校园防火知识、火灾疏散逃生要领、消防设施介绍等四个方面进行讲解，全面提升义务消防员的消防安全意识和专业水平。
经过前期招募选拔，98名师生加入志愿者队伍，成为学校义务消防队的首批队员。后续党委保卫部将全面加强义务消防队规范化、标准化建设，强化管理培训服务，巩固群防群治力量，进一步为学校“天下工大、世界三航”远景目标实现筑牢校园坚实安全防线。
