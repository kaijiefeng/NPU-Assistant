# 就业新闻-管理学院成功举办第四届全国大学生职业规划大赛院赛

首页>就业新闻>文章
管理学院成功举办第四届全国大学生职业规划大赛院赛
日期：2026-11-05 11:44 浏览次数：24
11月5日下午，第四届全国大学生职业规划大赛管理学院院赛在学院214报告厅举行。本次大赛以“筑梦青春志在四方，规划启航职引未来”为主题，旨在引导同学们树立正确的成才观、就业观和择业观，科学规划学业与职业发展路径。大赛由管理学院就业部唐思迪同学主持，学而思西安副校长、2011级西工大校友马聪，博士生辅导员白洁，本科生辅导员那依力、管琳菲、张智如，学工主管张梦予共同担任比赛评委。
本次大赛坚持“以赛促学、以赛促教、以赛促就”，为同学们搭建了展示自我、交流成长的平台，帮助大家在梳理自我认知、明确职业方向的过程中提升就业竞争力，推动就业育人走深走实，促进毕业生高质量充分就业。大赛设成长赛道与就业赛道两个组别，经过前期报名与筛选，共有21名优秀选手入围院赛，其中就业赛道6人、成长赛道15人。
选手们结合自身经历与专业背景，从自我认知、职业定位、发展路径、行动计划等方面展开系统阐述，呈现出清晰的职业目标与扎实的规划思考。选手以生产系统建模与仿真优化工程师、质量管理工程师、茶文旅品牌运营官、乡村CEO、AI产品经理、财务BP等岗位为目标，有的结合实习经历分享对目标行业的深刻理解，有的围绕自身优势设计分阶段成长路线，有的在西工大的学习与实践中逐步锚定就业目标，充分展现了西工大学子“基础扎实、工作踏实、作风朴实、开拓创新”的精神风貌。
展示结束后，评委老师从职业规划的专业性、可行性及与个人特质的匹配度等方面，对选手们的表现给予充分肯定，并围绕目标定位的准确性、路径设计的合理性等逐一提问、细致点评。各位评委建议同学们在实践中不断调整规划，把短期目标与长远方向相结合，主动对接国家发展战略，在持续学习中拥抱未来的无限可能。
职业规划是一个持续发展、动态调整的过程。本次大赛的成功举办，不仅为同学们提供了展示规划成果的舞台，更激发了大家对职业生涯的深入思考。管理学院将选拔优秀选手参加校赛，并继续坚持以学生发展为中心，深化就业育人工作，引导同学们把个人理想融入国家发展大局，更早明确方向、更好规划未来，为同学们高质量充分就业保驾护航，培养更多堪当民族复兴大任的时代新人。
