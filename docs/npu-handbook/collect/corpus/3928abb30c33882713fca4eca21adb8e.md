# 全校唯一！自动化学院博士徐婧林荣获2022年度中国图象图形学学会优秀博士学位论文奖！

近日，中国图象图形学学会公布了2022年度中国图象图形学学会科学技术奖评选结果，自动化学院博士毕业生徐婧林（导师：韩军伟教授）荣获优秀博士学位论文奖，是西北工业大学本年度该奖项唯一获奖者。
该奖项由中国图象图形学学会组织评选，根据《中国图象图形学学会科学技术奖章程》和《中国图象图形学学会优秀博士学位论文奖评选条例》相关要求，经过形式审查、初评、公示和终评，最终决定授予2022年度中国图象图形学学会优秀博士学位论文奖10篇，优秀博士学位论文提名奖7篇。
徐婧林的博士学位论文《多视图数据机器学习算法研究》立足跨媒体智能领域国际科技前沿，围绕多视图数据面临的异构鸿沟问题，提出多视图协同感知框架，基于数据驱动的有效挖掘和知识驱动的协同推理，建立全维度智能感知推理引擎，解决图像分析与识别中感知碎片化、信息孤岛化等问题，也为跨媒体智能协同感知技术在更多视觉任务中的应用与推广奠定了基础。
据了解，徐婧林曾获评西北工业大学2022年优秀博士学位论文、2020年优秀博士毕业生、博士研究生国家奖学金等荣誉奖励。基于其博士论文研究工作，目前已发表CCF A类期刊和会议论文14篇，Google学术引用共895次；相关研究获批国家自然科学基金青年基金项目、博士后科学基金面上项目各1项。
