# 西工大获批第四批高校国家知识产权信息服务中心

12月21日，国家知识产权局办公室、教育部办公厅联合发布了第四批高校国家知识产权信息服务中心名单，西北工业大学成功入选。

我校高度重视知识产权工作，2020年成立校知识产权信息服务中心并挂靠图书馆，科研院和资产公司共同保障运行。此次高校国家知识产权信息服务中心遴选工作得到学校高度重视，副校长张卫红亲自安排部署并出席申报答辩会，经过自主申报、形式审查、专家初评和复评答辩等激烈竞争，最终我校成功获批第四批高校国家知识产权信息服务中心。

西北工业大学知识产权信息服务中心积极开展知识产权信息素养培训、知识产权信息咨询、专利检索与分析、专利申请前预评估、专利导航分析等工作，为学校科技成果申报、立项、鉴定、高价值专利培育等提供信息情报支撑，促进学校专利质量提升与成果转化；同时立足学校，面向社会，与校外各企事业单位进行交流互动并提供知识产权信息服务，助力地方产业经济发展与技术研发创新。

中心将以此次入选作为新起点，立足学校“三航”学科特色，进一步发挥信息资源和人才资源优势，为知识产权的创造、运用、保护、管理和服务提供全流程信息服务，促进高校协同创新和科技成果转移转化，服务区域经济社会发展，支撑国家创新驱动发展战略和高质量发展。
