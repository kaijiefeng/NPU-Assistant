# 党委保卫部党支部赴延安开展“传承红色基因、提高党性修养”专题培训

11月2日-3日，党委保卫部党支部赴延安革命圣地开展“传承红色基因、提高党性修养”专题培训，引导支部党员学习延安精神，汲取精神力量。
延安是中国革命的摇篮，孕育着党的伟大精神和光荣传统。党支部追寻革命先烈的足迹，在枣园、王家坪、杨家岭等革命旧址开展现场教学，简陋的窑洞见证了中国革命从弱小走向强大，走向胜利的光辉历程。党的第一代领导人在艰苦的环境下运筹帷幄，指挥革命、带领生产，将毕生精力奉献给国家和人民，彰显了我党坚定的人民立场和必胜的革命信念。在延安革命纪念馆，讲解员带领学员们追忆了党中央在延安的十三年革命历程，一件件历史文物，一张张珍贵照片，带着厚重的历史感扑面而来，仿佛再现了烽火连天的峥嵘岁月。学员们认真聆听讲解，深刻感悟革命先辈的崇高精神境界和不屈的斗争精神。
在宝塔山上，保卫部党支部副书记皮德福同志带领同志们重温入党誓词，党员们热血沸腾，以铿锵有力的誓言宣告跟党走、听党话的坚定信念和决心。 在张思德同志的追悼会旧址，同志们重温了“老三篇”之一《为人民服务》。同志们表示，作为新时代高校保卫工作者，要向警卫员张思德同志学习，将党的二十届三中全会精神融入日常工作，立足本职为师生员工做好服务保障，在平凡的岗位上践行党的根本宗旨。
两天时间里，党支部党员们通过瞻仰革命旧址，聆听革命事迹，滋养初心使命，提升党性修养。同志们纷纷表示，要将延安精神带到工作岗位上，进一步坚定干事业的决心和毅力，脚踏实地、顽强拼搏，为实现学校“127”近期目标和“世界工大、天下三航”的远景目标贡献保卫力量。
