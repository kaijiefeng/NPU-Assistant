# 后勤办公室召开学习贯彻习近平新时代中国特色社会主义思想主题教育专题民主生活会

8月28日上午，后勤办公室召开学习贯彻习近平新时代中国特色社会主义思想主题教育专题民主生活会。学校主题教育督促指导组王强参会指导，后勤办公室领导班子成员参会，科级干部与支部委员列席。会议由后勤办公室主任张文刚主持。
按照会议要求，首先，张文刚通报领导班子2022年度民主生活会整改措施落实情况和本次民主生活会的会前准备情况，并代表领导班子进行了对照检查发言。随后，围绕以学铸魂、以学增智、以学正风、以学促干的内涵和实践要求，结合个人思想和工作实际，班子成员依次进行自我检查和党性分析，严肃开展批评和自我批评，并在表态发言中诚恳接受班子其他成员的批评意见，表示在今后工作中加强改进。
接着，王强对本次民主生活会进行了点评。他认为，此次民主生活会准备充分、查找问题精准、整改措施方向明确，成员之间批评开门见山、诚恳深入，达到了坚持真理、修正错误、统一意志、增进团结的目的。他强调，后勤办公室要结合查摆出的问题和批评意见，务必坚持“当下改”与“长久立”相结合，完善体制机制，抓好整改落实工作，切实把民主生活会的成效体现在后勤管理工作的实效上。
最后，张文刚代表后勤办公室领导班子作表态发言。他表示，领导班子在今后的工作中将持续用力抓好问题整改，继续增强政治站位和班子整体合力，进一步坚定理想信念，强化责任担当，提升后勤管理能力，持续助推学校“双一流”建设和高质量发展。（撰稿人：毛淑兰；审稿人：韩争胜）
