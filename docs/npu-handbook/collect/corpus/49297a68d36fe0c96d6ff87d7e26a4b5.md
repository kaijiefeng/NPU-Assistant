# 西北工业大学网络空间安全学院开题答辩（王省欣）

一、开题答辩题目：密码核设计安全属性自动提取与形式化验证方法研究
二、开题答辩人：王省欣
三、开题答辩时间：2024年6月7日下午14：30
四、开题答辩地点：友谊校区爱生楼401
五、开题内容简介：
密码关键芯片运行过程中会存在诸多因设计实现方式导致的侧效应，造成敏感信息泄露，严重威胁了密码实现安全性。针对密码核设计实现安全性的分析与验证需求，本研究以密码核设计侧信道安全属性验证为切入点，通过构建密码核设计形式化侧信道安全模型、研究侧信道安全属性自动化提取的方法、建立形式化侧信道分析框架，从而实现密码核设计时间侧信道和能量侧信道检测及故障注入风险评估，为在密码核设计早期对设计的侧信道安全分析提供有效的理论、方法与工具支撑。
六、开题答辩人简介
王省欣，学号2023100433，1998年10月生，网络空间安全专业，师从胡伟教授，主要从事于密码侧信道分析和形式化验证方面研究。
