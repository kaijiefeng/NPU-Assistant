# 【学术报告】生态环境学院学术报告通知——雷富民研究员

报告人：雷富民 研究员
时间：2021年3月15日（星期一）9:30
地点：长安校区数字化大楼A座303会议室
题目：中国鸟类区系与生物地理学研究
报告人简介：
中国科学院动物研究所研究员，国家杰出青年科学基金获得者，国家高层次人才计划重点领域创新团队负责人。现任国际鸟类学家联合会副主席，中国鸟类学会理事长。Avian Research, Journal of Biogeography, Current Zoology等8个国际SCI期刊主编、副主编或编委。主要从事鸟类系统演化、适应进化、物种多样性及生物地理学等方面研究，已在国家SCI源刊发表论文176篇。
欢迎广大师生积极参加。报告会期间请关闭手机或将手机调至静音模式。
生态环境学院
2021年3月9日
