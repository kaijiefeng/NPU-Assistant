# 西北工业大学举办“青春之歌”2026年五四青年节舞台思政课-青春驿站-共青团西北工业大学委员会

在五四运动107周年到来之际，为弘扬五四精神，加强新时代青年理想信念教育，4月29日晚，“青春之歌”西北工业大学2026年五四青年节舞台思政课在翱翔学生中心举办。本次活动由团委、艺术教育中心联合主办，共青团陕西省委副书记刘洋、副校长张富利，相关职能部门负责同志，各学院、研究院党委书记、党委副书记、团委书记，以及千余名师生代表参加本次活动。
活动现场，校团委副书记刘星宣读《共青团西北工业大学委员会关于2026年“五四”表彰的决定》。与会领导依次为五四红旗标兵、青年岗位能手、五四红旗团支部、五四红旗团委获奖代表颁奖。张富利为五四红旗团委获奖代表颁奖，刘洋为西北工业大学团委颁发全国五四红旗团委奖牌，校团委书记佘磊磊上台领奖。
2026年五四红旗标兵、材料学院本科生陈俊以“追光而行，筑梦传光”为题，讲述自己如何从大山深处走向材料科学前沿，设立“筑云梯”基金反哺家乡、点亮乡村儿童求学希望的故事，生动展现了新时代西工大青年饮水思源、自强不息的青春风貌。青年岗位能手、航空学院教授寇家庆以归国青年学者的身份，分享了他在空气动力学领域瞄准“卡脖子”问题，真抓实干、奋勇创新，让更多青年学子笃定“国之所需，吾之所向”的信念。
2026年五四红旗团支部代表、集成电路学院ME012402班团支部周墨涵通过讲述支部成员参与红色研学、文体活动、志愿服务、科技创新等方面的点滴，展现了团队成员全面发展、为国铸“芯”的硬核担当。五四红旗团委代表、航天学院团委书记高戈通过讲述学院团委在聚焦思想铸魂、聚力固本强基、聚能成长成才三方面的先进经验，号召大家坚定信心、乘势而上，为推进学校事业高质量发展贡献力量。
接下来，五四青年节舞台思政课精彩上演。思政课分为“青年何谓”“青年何为”“青年何往”三个篇章，以多元舞台艺术为载体回望百年青年运动征程，展现我校青年学子矢志报国、勇毅前行的精神风貌。
交响曲《太阳照常升起》为本场演出拉开壮阔序幕。短剧《觉醒》、舞蹈《信仰之路》以极具张力的演绎重现先驱探寻真理的热血征程；短剧《向苍穹》、配乐合唱《保卫黄河》饱含着青年誓死捍卫家国的铮铮铁骨；短剧《烽火一课》、合唱《国际歌》，回望古路坝灯火里文脉赓续的坚守，以高歌承载民族危亡下的气节坚守。短剧《此去长征》、情景唱《映山红》重温革命先辈百折不挠的长征精神，倾诉着军民同心奔赴光明的深切期盼；短剧《远洋来信》、合唱《理想》再现先辈跨越重洋归国奉献的无悔抉择；短剧《等待》、舞蹈《晨光曲》以细腻演绎诠释科研工作者舍家为国的大爱；短剧《归来》、歌舞《铭记》诉说海外学子归国筑梦的赤诚初心，彰显了新时代青年不忘来路、勇担使命的坚定信念；歌曲《有我》、情景讲述《青年的选择》、舞蹈《乘风时刻》无一不展现出西工大学子敢想敢为又善作善成的青春品质。情景唱《错位时空》重现跨越百年的青春对话，歌曲《国旗之下》诠释着青年学子对祖国最深沉的热爱。
本次活动是学校持续弘扬“总师育人文化”，用“青言青语”让红色基因可感可触、报国信念入脑入心的生动实践，也是全国第八届大学生艺术展演活动之西北工业大学校级展演的重要内容。下一步，学校共青团将持续加强青年榜样的培育选树和宣传推广，不断探索“思政+艺术”育人模式，创新思想政治工作方式方法，团结引领我校团员青年以昂扬向上的精神风貌和强国有我的责任担当，奋力书写为中国式现代化挺膺担当的青春篇章！
