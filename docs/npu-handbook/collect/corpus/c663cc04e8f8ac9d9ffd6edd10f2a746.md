# 后勤部办公室党支部开展党纪学习教育专题党课

为推动党纪学习教育走实走深，进一步加强党员干部的纪律意识和规矩意识，7月4日上午，后勤部办公室党支部副书记韩争胜为全体党员讲授党纪学习教育专题党课。主要以《解读<中国共产党纪律处分条例>》为主题展开，支部全体党员参加了此次学习。
韩争胜从《条例》的修订背景、重要意义、修订亮点解读等方面进行了详细讲解。他结合后勤工作实际，通过生动的案例和深入浅出的解读，使全体党员干部对《条例》的各项规定有了更加全面和深入的理解。韩争胜指出，党纪学习教育的最终落脚点在遵规守纪，做到实干笃行、知行合一，才能把开展党纪学习教育的作用真正发挥到实处。
党课最后，大家纷纷表示受益匪浅，一致认为《条例》的修订完善体现了党中央对全面从严治党的坚定决心和鲜明态度。同时，大家也表示将以此次党课为契机，进一步加强自我约束和自我管理，严格遵守党的纪律和规矩，时刻对标对表后勤工作相关管理制度以及廉政风险的薄弱环节，努力养成纪律自觉，把他律要求转化为内在追求，让党规党纪真正成为日常工作的行动指南和自觉遵循。（撰稿人：毛淑兰；审稿人：韩争胜）
