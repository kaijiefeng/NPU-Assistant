# 深圳三航科技有限责任公司-西北工业大学资产经营管理有限公司

深圳三航科技有限责任公司成立于2017年1月，位于深圳市宝安区西乡街道共乐社区铁仔路60号奋成智谷大厦B座513，公司注册资本500万元，是西北工业大学深圳研究院平台公司、西北工业大学资产经营管理有限公司的独资公司，是学校立足粤港澳大湾区开展成果转化产业化、落实国家双创政策、助力地方实体产业升级、践行国家战略、推动民营企业参军的重要科技服务平台。
公司自成立以来，致力于技术成果转移转化工作，推动学校优秀科研成果的产业化及合作。目前，公司已构建概念验证、成果转化、技术交易、投融资等服务平台，开展技术开发和市场需求对接、科技成果和风险投资对接，初步形成市场化的科技成果转移转化运营体系，重点围绕“科技+金融”平台建设及相关科技服务、产学研对接及投融资开展业务。
