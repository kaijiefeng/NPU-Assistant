# 江苏无锡经济开发区政协委员考察团调研西北工业大学重庆科创中心

11月23日下午，江苏无锡经济开发区政协委员联席会议办公室主任潘秀娟带队政协委员考察团一行莅临西北工业大学重庆科创中心调研指导，中心副主任张铁邦接待。
张铁邦对潘秀娟一行的到来表示热烈欢迎，就中心的发展定位及建设运营情况进行了介绍，带领参观了中心展厅、航空航天关重件残余应力检测实验室、航空航天难变形材料特种连接技术中心等，双方重点就科技成果转化情况进行了交流。
潘秀娟表示，无锡经开区致力于推动“政策创新”真正服务“科技创新”，通过支持新型研发机构高质量发展、创新型企业培育等全方位政策体系建设，强化科技创新制度支撑，加快高质量发展。潘秀娟对中心在新型研发机构运营和科技成果转化方面取得的先进经验表示赞赏，希望双方未来能够有更多交流。
