# 西北工业大学2027年全国硕士研究生招生考试网报公告

## 一、西北工业大学（代码10699）招生单位说明

1. 考生通过中国研究生招生信息网报名系统进行报考。网上报名时间为2026年10月15日至10月24日，每天9:00—22:00；网上预报名时间为2026年10月9日至10月12日，每天9:00—22:00。考生报考前应登录西北工业大学研究生招生信息网查阅2027年硕士研究生招生简章、专业目录，了解相关报考要求。
2. 2027年学校招生计划尚未下达，中国研招网硕士专业目录中的拟考试招生人数和拟接收推免人数为我校根据2026年招生人数拟定，仅供参考，实际招生人数以2027年国家下达的招生计划为准。
3. 考生在填写个人信息和报考志愿后，应根据系统提示及报考点网上报名公告要求，规范采集本人图像，据实上传核验材料；部分须补充材料的，应按报考点要求积极配合完成报名。
4. 在校研究生报考须在报名前征得所在培养单位同意。现役军人报考按部队相关规定办理。凡报考我校非全日制研究生的考生，请在报考前查询硕士招生目录并与报考学院联系，了解报考资格、修业年限、收费标准等内容。
5. **强军计划、单独考试、同等学力（不含本科结业生）考生**必须在我校考点报名、考试，若在其他报名点报名一概无效。同等学力考生（不含本科结业生）、单独考试考生网报前需经我校研究生招生办公室审核报考条件，并于10月20日前将相关材料（EMS邮寄）寄送至西北工业大学研究生招生办公室（陕西省西安市友谊西路127号；收件人：朱老师；电话：029-88493042）。
6. 符合享受初试加分、少数民族照顾政策、免初试或报考专项计划有关条件的考生，须在网上报名时按要求填报申请信息，未按规定申报或审核（含复审）未通过的，不享受相应政策。
7. 关于招生目录中标注“宁波基地”的招生专业方向：研究生专业实践环节在宁波研究院人才培养基地开展。
8. 第二学士学位在读考生，以及在读研究生考生须在录取当年入学前取消原培养单位的学籍，否则无法注册研究生学籍。

## 二、西北工业大学（代码6112）考点说明

（一）考点情况：西北工业大学考点分两个校区考试，即友谊校区和长安校区。友谊校区：本校友谊校区应届毕业生、报考我校的社会考生；长安校区：本校长安校区应届毕业生、其他社会考生。请考生务必提前了解考场所在校区位置。

（二）考点接收考生范围：1. 西北工业大学本校应届本科毕业生；2. 报考西北工业大学且户口或工作单位在陕西省的所有往届考生；3. 报考西北工业大学的非报考点院校应届本科毕业生；4. 接收少量未报考我校的社会考生（不接收有超过3小时考试科目的考生，不接收四单元绘图或设计类的考生），考试地点在我校长安校区（西安市长安区东祥路1号）。

（三）考点审核时间：报考点审核、考生上传补充材料开始时间为2026年10月26日9:00；首次审核结论截止时间为2026年10月30日12:00；考生上传补充材料截止时间为2026年10月31日12:00；报考点审核截止时间为2026年10月31日17:00。

（四）考生根据实际情况提交核验材料及标准：

1. 往届毕业生：“户籍在陕”考生须上传本人有效居民户口簿（户口簿首页和“常住人口登记卡”页），集体户口仅提供个人单页；“户籍不在陕”但“在陕工作”考生须上传最近3个月的社保或公积金缴费证明。
2. 学籍学历校验未通过考生：应届毕业生须上传有效期内的《教育部学籍在线验证报告》，自学考试或网络教育届时可毕业本科生还须上传承办机构出具的届时毕业证明、成绩证明；往届毕业生须上传《教育部学历证书电子注册备案表》或《中国高等教育学历认证报告》；国（境）外毕业生须上传国（境）外学历学位认证书；在读研究生须上传所在培养单位校级研究生学籍管理部门盖章的“同意报考”证明。
3. 身份证件系统比对不通过的考生：须提供身份证原件照片（国徽面和人像面），要求边框完整、字迹清晰且在有效期内。
4. 报考我校单独考试的考生：须上传所在工作单位同意报考的介绍信、两名高级专业技术职称专家推荐信、《西北工业大学单独考试硕士研究生报名审批表》，经审核通过后确定考试资格。
5. 在陕就读的第二学士学位考生须上传加盖培养单位公章的在读证明。

（五）审核结果反馈：材料不符合要求的考生应根据提示补充材料，未按时补充的不予审核通过；考生提交材料务必真实有效，如发现伪造、变造证件将向公安机关报案；不符合我校报考点条件的考生请尽快联系符合条件的报考点。

## 三、注意事项

1. 考生须在网上报名期间完成报名费支付，未交费考生信息为无效报名信息。
2. 报名信息经考生确认后一律不作修改，因填写错误引起的一切后果由考生自行承担。
3. 以同等学力身份（不含本科结业生）报考者，必须获得国家承认的高职高专学历后满2年（毕业时间应为2025年9月1日之前）。
4. 报考点为我校的残疾考生，如需在考试期间提供合理考试便利服务，应于10月20日前向我校提交申请材料，并提供本人第二代及以上《中华人民共和国残疾人证》及身份证件复印件（扫描件），逾期不予补申请。
5. 学校通过信息平台、网站、电话、电子邮件、短信等方式之一公开或发送给考生的相关信息、文件和消息，均视为送达。
6. 考生参加考试须持有本人第二代居民身份证，有效期至少截至2026年12月21日。
