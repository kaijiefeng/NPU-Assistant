# 师生同心，共筑未来——航天学院权益收集反馈培训会顺利召开！

为强化权益服务收集反馈机制，3月23日，航天学院研究生会于学院345学生活动中心举办了2025年主题为“师生同心，共筑未来”的权益收集反馈培训会。本次活动由研究生会主席团成员耿浩华同学主持，学院团委书记高戈、研究生辅导员崔美琪出席，学院研究生会、各年级研究生代表参加会议。
在会议交流环节，研究生会围绕前期通过问卷调研、座谈访谈等多渠道收集的学生关切问题进行了系统梳理，内容涵盖科研支持、培养方案、生活保障及管理服务等多个方面。针对同学们普遍关注的共性问题，研究生会进行了分类汇总，并在会上提交学院进行集中反馈，确保问题表达的完整性与针对性。
针对收集到的各类问题，学院团委书记高戈老师与研究生辅导员崔美琪老师逐一进行回应与说明，从政策依据、执行流程及实际情况等多个维度进行了系统解读。对于能够现场明确答复的问题，给予了详细解释；对于需进一步协调落实的问题，也明确了后续推进路径与责任机制，体现了学院对研究生合理诉求的高度重视。
在此基础上，高戈老师从制度建设与沟通机制角度，对当前师生关系与权益反馈体系进行了系统梳理。他指出，良好的师生关系是研究生培养质量的重要保障，应在规范化制度框架下，通过多层级沟通机制实现信息的高效传递与问题的及时反馈。同时强调，研究生会作为师生沟通的重要桥梁，应进一步提升问题收集的规范性与反馈的有效性，推动形成“收集—整理—反馈—改进”的闭环机制。
会议还就后续工作进行了部署与动员。学院鼓励研究生会及各年级学生代表持续开展常态化权益调研，完善多渠道信息反馈路径，进一步拓宽问题收集覆盖面。在此基础上，将逐步开展专题化、系统化培训，提升学生骨干在权益服务中的组织能力与沟通能力，推动权益服务工作向精细化、长效化方向发展。
最后，崔美琪老师在总结发言中指出，权益服务工作是研究生教育管理体系中的重要组成部分，需要学院与学生协同推进、共同完善。她鼓励同学们以理性、客观的态度表达诉求，积极参与学院治理与建设，在互动交流中不断提升自我认知与责任意识。学院也将持续优化反馈渠道与响应机制，为研究生成长发展提供更加有力的支持与保障。
本次权益收集反馈培训会有效搭建了师生沟通的交流平台，增强了信息传递的透明度与针对性，为后续权益服务工作的规范化开展奠定了基础。未来，航天学院研究生会将持续聚焦研究生成长需求，不断完善权益反馈体系，推动形成良性互动的师生关系，共同营造务实高效、协同共进的育人环境。
