# 2025年西安市第二届大学生消防运动会在我校顺利举行

为进一步提升大学生群体消防安全意识和技能，筑牢校园消防安全防线，11月15日上午，2025年西安市第二届大学生消防运动会在我校长安校区顺利举行。此次运动会由西安市消防救援支队主办，学校与西安市高新区消防救援大队承办。西安市消防救援支队赵璐支队长、王展鹏副支队长，学校党委副书记、副校长詹浩，党委保卫部、党委学生工作部、体育部负责人以及来自西安交通大学、陕西师范大学、西北大学等39所高校的带队领导和900余名参赛大学生及志愿者参加了此次运动会。
运动会在庄严肃穆的中华人民共和国国歌声中拉开帷幕。随后詹浩、王展鹏分别致辞。学校无人系统技术研究院学生阳天瑞和西安市消防救援支队消防员张钊代表运动员、裁判员宣誓发言。
运动会设置有理论测试、原地着装、水带接力、穿越火场烟雾、火场救援、灭火打靶6个项目，通过多元化、多感官体验感知将防火、灭火、逃生自救等消防安全知识与技能实践相结合。充满速度与激情的竞赛体验让消防安全知识“活”了起来，竞技中展现的专业素养、在协作中传递的安全理念成为运动会上最亮丽的风景线。参赛选手们以赛促学，以学促防，让大学生的青春力量融入了平安西安建设之中。
西安市高校数量众多，校园消防安全是消防工作的重要组成部分，大学生消防运动会的成功举办，既是强化西安市“火焰蓝+志愿蓝”大学生消防志愿服务者热情，营造“全民消防、生命至上”浓厚氛围的重要途径，也是增强师生消防安全意识，有效预防和减少火灾事故发生，构建平安校园的重要基石。运动会期间，学校组织近300名志愿者观摩比赛、参与互动体验，进一步提升了学生的消防安全意识和自防自救能力，为构建平安校园夯实基础。
