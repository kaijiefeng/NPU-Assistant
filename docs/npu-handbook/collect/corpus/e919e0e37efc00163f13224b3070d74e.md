# 校领导率团访问摩洛哥、法国

6月26日至7月1日，受摩洛哥拉巴特国际大学和法国前沿科学理工学院邀请，我校党委常委、校务委员会秘书长王宇波率团访问摩洛哥、法国，就进一步深化校际合作、拓展人才培养渠道、推动科研协同创新、提升国际化办学水平等议题开展深入交流。
6月26日至27日，代表团访问摩洛哥拉巴特国际大学。王宇波与拉巴特国际大学工学院负责人伍德·穆萨举行工作会谈。双方围绕学生来华交流学习、学生短期访学项目、暑期课程参与、专业实习实践、科研团队对接等议题进行了深入交流。王宇波表示，西北工业大学始终高度重视与“一带一路”沿线国家高校的交流合作，积极推动优质教育资源开放共享，不断拓展中外学生交流互鉴的平台。摩洛哥区位优势明显，高等教育发展潜力突出，拉巴特国际大学办学特色鲜明、国际化程度较高，与西工大在工程教育、科技创新和青年人才培养等方面具有良好的合作基础和广阔的合作空间。
伍德·穆萨表示，拉巴特国际大学高度重视与中国高校的合作，期待以此次访问为契机，进一步加强与西工大的联系，推动学生交流、教师互访和科研合作取得实质性进展。双方一致同意并通过了签署框架合作协议的意向，为两校后续建立长期稳定合作关系提供了基础。
6月29日至30日，代表团访问了法国前沿科学理工学院，并与该校执行校长安娜·塞戈莱娜·阿布沙伊特、国际处相关负责人及教师代表举行座谈交流。双方围绕优化人才培养体系、创新师生互访机制、共建联合实验室、拓展科研合作领域、提升学生国际实践能力等议题进行了深入探讨。王宇波表示，法国前沿科学理工学院作为以航空航天工程为特色的法国工程师学校，在工程教育、实践教学和产教融合等方面具有鲜明优势，与西工大的优势学科和专业方向高度契合。希望双方在已有合作基础上，进一步挖掘合作潜力，丰富合作内涵，为两校青年学生和教师搭建更加稳定、更加高水平的国际合作平台。
安娜·塞戈莱娜·阿布沙伊特对代表团到访表示欢迎，并介绍了学校在工程师教育、国际合作、科研平台建设和企业实践资源等方面的情况。安娜认为，西北工业大学在航空航天等领域具有突出优势，双方专业契合度高、合作基础好，未来合作前景广阔。希望双方进一步完善合作机制，推动学生互派、教师交流、科研合作和平台共建等工作取得新的突破。
此次出访是我校持续深化国际交流合作、拓展全球合作伙伴的重要举措。通过访问摩洛哥和法国高校，代表团进一步加强了我校与非洲、欧洲高校之间的联系，推动了学校优势学科与国际合作资源的有效对接，为学校推进高水平国际化办学提供了有力支撑。
访问法国期间，王宇波还出席了中国国际大学生创新大赛（2026）法国区域赛决赛，进一步拓展了学校在法国青年创新创业交流领域的合作渠道。
