# 西北工业大学第十四届学生社团博览会成功举办-青春驿站-共青团西北工业大学委员会

为持续引导学生社团健康有序发展，繁荣校园文化，9月19日至20日，“社彩纷呈，青春启航”西北工业大学第十四届学生社团博览会在长安校区翱翔学生中心广场成功举办。本届博览会汇聚了98家学生社团、22个创新创业实践基地和学生组织现场展示，现场共有千余名师生参加。
开幕式上，学生龙狮运动协会、学生九弦音艺术团、学生吉他协会、学生Highcold音乐爱好者协会、广播站、礼仪队和学生书画协会带来了精彩纷呈的表演，引得现场观众爆发出阵阵掌声。招新现场人潮涌动、热闹非凡，各类学生社团亮出“绝活”，展示品牌活动和看家本领。有的学生社团注重青年宣讲，持续推进党的创新理论青春化传播；有的学生社团致力于科创探索，将自身创意转化成可亲手触碰的实践成果；有的学生社团通过运动竞技，用汗水生动诠释团队拼搏的力量；有的学生社团积极开展志愿服务，用实际行动传递温暖与爱心……同学们穿梭于各社团展位间，驻足观看、踊跃报名，青春的朝气在互动交流中绽放，积极向上的能量在校园中传递。
学生社团是学校落实立德树人根本任务、推进素质教育的重要载体。此次学生社团博览会不仅为各社团搭建了集中展示风采、高效吸纳新成员的优质平台，为社团发展注入新鲜活力，更帮助新生快速融入校园文化、找到志同道合的伙伴，进一步营造了积极向上、活力满满的校园氛围。下一步，校团委将持续加强学生社团建设管理，通过组织健康向上、富有格调、形式多样的校园文化活动，将学生社团打造为服务青年学子成长成才的坚实阵地，持续搭建广大同学德智体美劳全面发展的实践平台。
