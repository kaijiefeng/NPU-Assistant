# 比利时

比利时王国·布鲁塞尔·自送使馆180天内不超过90天D免签需开具出境证明
使馆签证处地址：三里屯路6号
开馆时间：每周一、二、四0900-1200（外交部仅二、四送取）
使馆网址：http://china.diplomatie.belgium.be/language_selection 至少10个个工作日
照片：3.5*4.5白底2张，半年内近照
表格：登陆签证中心网站在线填写
https://visa.vfsglobal.com/one-pager/belgium/china/chinese/index.html
所有材料每人一套，单面打印
1.机打预约（免预约）名单表
2.留指纹那次的签证页复印件（指纹有效期59个月，超出则无需提供，需再次前往使馆留取指纹）
3.签证表（在线填写）
4.护照复印件（照片页）
5.身份证复印件（照片页）
6.申根签证页复印件（如有）
7.确认函译文（领服抬头的照会译文单次入境single entry visa）
8.中文照会
9.照会译文（单次入境“single entry visa”）
10.欧洲名单表（三人及以上）
11.邀请信
12.在职费用证明（英文、签字盖章）
13.旅行医疗保险
此国家为外交部统办，还需按顺序准备好以下材料：
1照会复印件（由外事中心提供并复印）
2“二维码”信息表
3任务批件（确认件和通知书）复印件、外专局批件等内部备案材料
