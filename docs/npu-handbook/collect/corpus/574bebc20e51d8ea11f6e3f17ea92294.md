# 中国共产党西北工业大学教育实验学院党员大会胜利召开

2026年5月10日下午，中国共产党西北工业大学教育实验学院党员大会胜利召开。本次大会是在全面学习贯彻党的二十大和二十届历次全会精神，深入开展树立和践行正确政绩观学习教育，推动落实学校第十四次党代会部署，奋进“十五五”新征程的关键时期，召开的一次重要会议。学校党委常委、副校长王伶，党委组织部副部长宣建林出席会议,教育实验学院/未来技术学院全体师生党员参会，大会由学院院长林鑫主持。
牟蕾代表学院党委向大会作题为“笃行实干、追求卓越，奋力谱写教育实验学院/未来技术学院/学科交叉中心建设新篇章”的工作报告。报告全面回顾了学院过去五年来各项工作取得的丰硕成绩，深刻剖析了制约学院高质量发展的瓶颈与短板，系统擘画了学院2030年、2035年阶段性发展目标，并结合发展实际明确了专项落实举措。报告聚焦拔尖创新人才培养、教育教学改革创新、高水平学科交叉、国际合作交流等部署重点工作，为学院高质量、高水平、高标准建设发展指明了前进方向、凝聚了奋进力量。
范翔作教育实验学院学院党委党费收缴、使用和管理情况报告。大会审议并通过了上述两个报告和大会选举办法，通过监票人，宣读计票人。
宣建林宣读学校党委《关于同意中共西北工业大学教育实验学院委员会组成人员候选人预备人选的批复》。
在总监票人和监票人的监督下，与会党员以无记名投票方式，最终选举产生了中国共产党西北工业大教育实验学院委员会委员。
王伶代表学校向大会的胜利召开表示热烈祝贺，并对未来工作提出三点要求：一要充分发挥学院党委的政治核心作用，履行管党治党政治责任，为“两院一中心”发展提供坚强思想保证。二要靠前主动承担起拔尖创新人才培养的时代重任，努力建设具有全球影响力的、支撑引领“智慧三航”未来科技和产业发展的教学科研高地。三要紧跟学校高质量高水平高标准发展态势，解放思想、抢抓机遇，以实干实绩服务学校拔尖人才培养和一流大学建设。
在《国际歌》中，大会圆满完成了各项议程，胜利闭幕。
会后，新当选委员召开了中国共产党西北工业大学教育实验学院委员会第一次全体会议。会议选举产生了党委书记、副书记，并明确了委员们的工作分工，为学院党委的后续工作奠定了坚实基础。
风起扬帆正当时，凝心聚力启新章。全院师生将更加紧密地团结在以习近平同志为核心的党中央周围，凝心聚力勇担当，实干创新开新局，为教育实验学院/未来技术学院/学科交叉中心高质量、高水平、高标准建设而团结奋斗，为实现学校“一十百千”发展目标和“天下工大、世界三航”远景目标作出新的更大贡献！
