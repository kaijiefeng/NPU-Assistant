# 致敬西迁精神，赓续育人初心——西北工业大学医院医师教学团队赴交大西迁博物馆参观学习-西北工业大学医院

在第42个教师节来临之际，为弘扬教育家精神，进一步加强师德师风建设，厚植爱国情怀，9月9日，西北工业大学医院组织医师教学团队前往西安交通大学西迁博物馆开展了一次深刻的主题参观学习活动。
在讲解员的引导下，医师们依次参观了溯源、西迁和致远三大主题展厅。大家通过丰富的图文实物和多媒体展示形式，回溯了交通大学从南洋公学创立到响应国家号召整体西迁的壮阔历程。
在西迁展厅，一张张泛黄的老照片、一件件珍贵的实物史料，生动再现了1956年6000余名交大师生义无反顾从黄浦江畔奔赴渭河之滨的感人场景。大家驻足于西迁专列乘车证、彭康校长的日记本以及老教授们手写的教案前，深刻感受到了老一辈知识分子“党让我们去哪里，我们背上行囊就去哪里”的忠诚与担当。在致远展厅，大家看到了西迁之后交大人在人才培养、科学研究、服务国家战略方面取得的辉煌成就，特别是在医学财经展区，专题呈现了医学教育扎根西北、铸就教学科研高地的光辉历史。
此次参观不仅是一次历史的回溯，更是一次精神的洗礼。参与活动的医生们一致认为，要传承和发扬西迁精神，将爱国奋斗的信念融入到日常的医疗实践与科普教学工作中，以教育家精神潜心立德树人，助力医院多维发展。
