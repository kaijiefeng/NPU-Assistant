# 党委保卫部开展意识形态安全教育讲座

为维护校园安全稳定，进一步提升学生的安全意识，12月2日，党委保卫部与伦敦玛丽女王大学工程学院联合举办意识形态安全教育讲座。
党委保卫部特邀西安市公安局碑林分局聘任警官吕欣，为学生们开展题为《崇尚科学反对邪教，坚持总体国家安全观》的安全教育讲座。玛丽女王工程学院近百名学生参加。吕欣重点围绕反对邪教、反对恐怖主义和总体国家安全观等三部分内容详细介绍了邪教、恐怖主义对广大人民群众的危害，以及维护国家安全的至关重要性。
本次讲座采用线上与线下相结合的方式开展，扩大了学生覆盖面，让更多的学生受益，真正让意识形态安全深入人心。吕欣在讲座中，积极与同学们交流互动，现场气氛热烈，学生们纷纷表示受益匪浅。
通过本次意识形态安全教育，同学们更深层次地认识到了邪教、恐怖主义的严重危害性和国家安全的重要性。让我们携手守护国家和人民的安全防线，共同维护稳定和谐的校园环境。
