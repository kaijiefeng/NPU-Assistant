# 党委学生工作部党支部传达学习2026年暑假务虚会、秋季新学期中层干部会和学生工作会议精神

8月31日上午，党委学生工作部党支部召开支部（扩大）会议，传达学习2026年暑假务虚会、秋季新学期中层干部会以及全校学生工作会议精神。党委学生工作部全体同志参加会议。
会上，于辉领学了张云明书记、宋保维校长在暑假务虚会、秋季新学期中层干部会和全校学生工作会议上的讲话，并就扎实推进贯彻落实工作进行了安排部署。
参会人员一致认为，书记校长讲话站位高、格局大，系统分析了学校现阶段工作面临的突出问题，深刻阐释了新时代学生工作作为政治工作、战略工作、基础工作的特殊定位，为学工部全力推进“十五五”各项工作、高质量落实立德树人根本任务指明了方向，厘清了思路，明晰了路径。
会议要求，党委学生工作部全体同志要深刻领会系列会议精神，持续筑牢思想根基、扛起使命职责、锤炼履职本领、压实工作责任，切实增强政治判断力、政治领悟力、政治执行力，努力推动学生思想引领、育人阵地建设、学工队伍建设、安全底线防控、学生服务保障各项工作提质增效。一是要树牢铸魂育人导向，抓实思想引领工作。立足国防军工高校“为党育人、为国育才、为军铸才”特殊使命，深刻把握新时代学生工作的重要意义与时代特点，正确认识把握青年学生思想特点，统筹显性教育与隐性教育、线下育人与网络育人，深度挖掘军工特色育人资源，做强思政育人品牌，牢牢守住意识形态阵地，引导青年学生厚植军工报国情怀，自觉投身强国强军伟大实践。二是要树立大局意识，建强用好各类育人阵地。坚持学生工作“一盘棋”理念，深化“一站式”学生社区建设，健全校院协同、跨部门会商联动机制，推动育人力量、育人资源下沉一线，构建全员全程全方位全领域育人格局，切实当好学校立德树人决策部署落地的关键枢纽。三是要坚持问题导向，建强辅导员骨干队伍。吃透上级政策要求、摸清学工队伍现状、对接学生现实需求，聚焦辅导员职业化专业化专家化建设目标，完善选拔、培养、考核、激励全链条机制，畅通职业发展通道，补齐队伍能力短板，推动辅导员由“事务骨干” 向 “育人专家”转变，为高质量学生工作提供坚实人才支撑。四是要狠抓风险防控落实，强化底线思维。牢固树立总体国家安全观，压实安全工作责任，健全风险预警、排查研判、干预处置闭环机制，聚焦意识形态、保密安全、心理健康、网络舆情等重点领域，常态化开展隐患排查整治，抓早抓小化解苗头性倾向性问题，坚决守牢校园安全稳定底线。五是要以学生为本，提升服务保障质效。持续改进学工工作作风，聚焦学生成长堵点、发展难点、服务痛点，优化学生教育管理服务流程机制，做实学业帮扶、资助育人、心理支持、生涯就业引导等工作，切实为学生办实事、办好实事，不断提升学生归属感、认同感、成就感。
