# 航海学院召开研究生导师培训交流会

为进一步加强研究生指导教师队伍建设，提升研究生导师指导能力和业务水平，2023年6月20日，航海学院举办线上研究生导师培训交流会。副院长曾向阳主持会议。
首先，曾向阳副院长为研究生导师解读了《西北工业大学学术型博士研究生培养过程管理实施细则》，并对近年来学院研究生招生类别和招生情况进行了总结。他强调，提升质量是学院研究生培养的核心任务，要抓牢抓实选拔、培养、提升、毕业四道关口，希望导师们共同努力，发扬航海学院研究生人才培养的优势和特色，为国家培养更多更优秀的人才。曾向阳副院长还介绍了研究生论文抽检、招生宣传、优博优硕培养等方面的情况，并提出了具体要求。
陈克安教授、申晓红教授、刘静教授、高剑教授、何正耀教授、黄桥高教授、姜喆副教授、赵瑞琴副教授等研究生导师们就相关主题积极发言讨论，对研究生开题、中期检查等过程培养、论文质量保证等方面提出了意见和建议。
潘光院长在发言中指出，各位导师是研究生培养的第一责任人，应当有更高的占位，及时跟进国家重大需求和国际前沿学术问题，为研究生选题把好方向，在过程管理中应当严格要求，尤其是工程博士、同等学力研究生培养方面应与企业保持紧密协作，保证培养质量。潘光院长还就研究生招生宣传、优博优硕培养等工作提出了指导意见。
本次培训交流旨在帮助导师熟悉研究生培养过程的各个环节，明晰研究生培养的相关规定、要求和流程，同时严把质量关，为航海学院一流研究生培养工作保驾护航。学院后续还将定期举行类似的活动，为研究生导师进行经验交流和分享提供平台。
