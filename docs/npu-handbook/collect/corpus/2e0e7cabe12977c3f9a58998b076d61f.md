# 西工大在2025年度省级教改项目立项中取得优异成绩

近日，陕西省教育厅正式发布《关于公布2025年度陕西本科和高等继续教育教学改革研究项目立项结果的通知》。西工大共有54个项目获批立项，其中重点攻关项目14项、重点项目14项、一般项目26项，彰显了学校在教育教学改革领域的深厚积淀与持续领先优势。
学校获批2025年度陕西本科和高等继续教育教学改革研究项目名单
（重点攻关、重点项目）
获批项目紧扣近年来高等教育综合改革任务，选题指南聚焦高校思想政治工作路径研究、人工智能赋能高等教育改革发展研究、创新创业教育研究、发展战略研究、人才培养模式改革与创新研究、教学资源共建共享机制研究等多个关键方向，创新解决教育教学中的热点、难点、重点问题，探索人才培养新机制、新模式、新举措。
近年来，学校不断推进“总师育人文化”走深走实，围绕立德树人根本任务，高度重视教育教学研究对人才培养质量的支撑和引领作用。学校通过加强顶层设计、完善激励机制、搭建交流平台等，充分调动广大教师投身教育教学改革的积极性与创造性，在全校范围内营造出潜心教学的浓厚氛围。下一步，学校将锚定“一十百千”中期目标和“天下工大、世界三航”远景目标，持续深化教育教学综合改革，推进“总师育人文化”引领本科人才培养！
（文字：薛小婷、刘昕；审核：张学良）
