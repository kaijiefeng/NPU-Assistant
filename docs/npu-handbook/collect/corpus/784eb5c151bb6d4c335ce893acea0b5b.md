# 西北工业大学网络空间安全学院开题答辩（马中天）

西北工业大学网络空间安全学院开题答辩（马中天）
一、开题答辩题目：信息论启发的随机图模型与图学习理论与应用研究
二、开题答辩人：马中天
三、开题答辩时间：2025.1.20上午十点
四、开题答辩地点：毅字楼606
五、开题内容简介：在大数据时代，图结构数据在社交网络、生物信息学、知识图谱等领域的迅猛增长，给传统数据分析方法带来了巨大挑战。作为新兴研究方向，图学习在处理图结构数据方面展现了巨大潜力，但其理论基础和实际应用仍存在诸多难题。
本课题聚焦于“信息论启发的随机图模型与图学习理论与应用研究”，结合信息论和随机图模型两大工具，旨在为图学习方法的理论发展和实际应用提供坚实基础。信息论作为研究信息传输与处理的核心理论，为量化和理解图数据中的信息提供了有效手段；随机图模型则能够生成具有特定统计特性的图结构数据，为图学习算法设计和理论分析提供丰富的实验基础和模拟环境。
通过信息论与随机图模型的结合，本研究将深入探索图学习的鲁棒性与隐私安全等关键问题，进一步推动图学习技术在更广泛实际场景中的应用。
六、开题答辩人简介：
马中天，学号2022160916，1998年生人，西北工业大学网络空间安全学院三年级博士生，导师为王震教授，研究方向包含图神经网络，机器学习理论，信息论，社交网络等。
