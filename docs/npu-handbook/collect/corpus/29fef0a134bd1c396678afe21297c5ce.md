# 生命科学与技术学院举办“活力金秋・快乐健步”教职工健步走活动

为丰富教职工业余文化生活，引导教职工舒缓压力，领略长安校区秋日风光，凝聚学院向心力，生命科学与技术学院工会于11月5日中午，举办 “活力金秋・快乐健步”教职工健步走活动。
全院80余名老师报名参与。活动开始前，学院党委书记段利兵作简短致辞。他对各位教职工的积极参与表示欢迎，指出环湖健步走是学院打造的特色品牌活动，希望大家依托本次活动放松身心、凝聚情谊。
秋日的长安校区湖光澄澈、景色宜人。老师们精神饱满、兴致盎然。健步途中，大家沿着环湖步道有序前行，步伐轻快，边走边欣赏秋日美景，互相交流教学心得、科研进展与生活趣事，欢声笑语回荡在步道之间。大家结伴而行、相互鼓励，在轻松愉快的氛围里，卸下疲惫，感受运动带来的舒畅与活力。
下一步，学院工会将持续发挥桥梁纽带作用，立足教职工需求，丰富文体活动，做实暖心关爱，引导大家以健康体魄、饱满热情投身教学科研工作，助力学院高质量发展。
