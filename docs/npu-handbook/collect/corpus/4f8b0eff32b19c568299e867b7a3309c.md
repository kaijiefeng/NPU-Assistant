# 赓续中华文脉 厚植报国初心——电子信息学院硕士生第十党支部与自动化学院研究生第二十三党支部联合开展主题党日活动

为深入学习贯彻习近平新时代中国特色社会主义思想特别是习近平文化思想，教育引导党员同志铭记历史、赓续文脉、勇担使命，在九一八事变爆发95周年之际，电子信息学院硕士生第十党支部与自动化学院研究生第二十三党支部联合开展“赓续中华文脉，厚植报国初心”主题党日活动。本次活动采用“线上理论学习＋线下实践研学”相结合的方式，两个支部党员共同参加。
活动前期，两支部开展了线上理论学习。与会党员共同回顾九一八事变的历史经过，缅怀革命先烈和遇难同胞，从中华民族浴血奋战、不屈不挠的抗争历程中，深刻汲取落后就要挨打、强国才能安邦的历史教训。随后，党员们围绕习近平文化思想、赓续中华文脉、坚定文化自信开展专题学习和交流研讨，一致表示要自觉做中华优秀传统文化的忠实传承者和弘扬者。
理论学习结束后，党员们前往西安国家版本馆开展线下实践研学。党员们先后参观《赓续文脉踔厉前行——中华文化经典版本展（西部篇）》《楮墨遗珍万里同风——丝绸之路版本展》，驻足端详珍贵典籍、雕版拓片和丝路版本；走进文济厅，近1800平方米的巨型书墙集中陈列5万余册精品版本，大家深切感受到中华文明的源远流长、博大精深。
参加活动的党员同志在西安国家版本馆前合影
党员同志们纷纷表示，此次主题党日活动既是一次深刻的历史教育，也是一次生动的文化洗礼。作为新时代研究生党员，将铭记九一八、勿忘国耻，坚定文化自信，赓续中华文脉，把爱国之情、报国之志转化为潜心科研、勇攀高峰的实际行动，以真才实学服务国家和人民，在推进中国式现代化建设中贡献力量。
