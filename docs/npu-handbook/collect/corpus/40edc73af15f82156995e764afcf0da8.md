# 理院新闻|传劳模精神，育时代新人——学院组织师生赴西安市劳模精神展示馆开展 “我们的节日·劳动节”劳育实践

为深入贯彻新时代劳动教育理念，弘扬劳模精神与工匠精神，深化劳动教育内涵，引导师生在实践中共同学、在体验中同成长，4月30日下午，学院组织师生代表赴西安市劳模精神展示馆开展“我们的节日·劳动节”主题劳育实践活动。本次活动由学院组织员杨文琪带队，部分师生党员及团员代表共同参与，在“行走的课堂”中接受劳动精神熏陶，凝聚奋进力量。
师生同温誓词，共铸信念之魂
抵达展示馆后，杨文琪带领全体师生党员面向党旗，庄严重温入党誓词。铿锵有力的誓言回荡在展馆上空，不仅表达了党员师生对党的无限忠诚，更彰显了大家不忘初心、牢记使命的坚定信念。
沉浸式参观学习，感悟劳模风采
在讲解员的引导下，师生们有序入馆参观。馆内珍贵的实物展品与生动的图文展板，全景式展现了不同时期劳动模范拼搏奋进、无私奉献的光辉事迹。从老一辈的“铁人精神”到新时代的大国工匠，从科研攻关到基层坚守，一个个感人至深的故事让在场的师生深受触动。大家认真聆听、驻足观看，在跨越时空的对话中，抽象的劳模精神变得具体可感。老师们从劳模身上汲取了教书育人的榜样力量，学生们则更加深刻地理解了“劳动创造幸福”的时代内涵。
师生同践使命，激扬奋进力量
此次劳育实践活动，不仅是一次精神的洗礼，更是一次行动的动员。通过师生共同参与、共同学习、共同感悟，有效拉近了师生距离，构建了生动的思政育人共同体。师生们纷纷表示，要将劳模精神内化于心、外化于行，在教书育人与成长成才的道路上锤炼过硬本领，在服务社会与报效国家中践行责任担当。
未来，学院将继续深化“师生同行”的劳育实践模式，将劳模精神的传承与学科教育、专业实践深度融合，引导全体师生以劳模为榜样，在各自的“讲台”与“课堂”上发光发热，共同为培养德智体美劳全面发展的时代新人贡献力量。
