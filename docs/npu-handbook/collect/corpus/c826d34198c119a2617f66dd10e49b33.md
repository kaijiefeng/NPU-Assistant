# 物理科学与技术学院-西北工业大学医院

责任医师：王儒（主治医师）
简介：
中医儿科主治医师，硕士研究生，毕业于宁夏医科大学，擅长中西医结合治疗儿科常见疾病及小儿神经系统、内分泌系统及发育性疾病。西安市中西医结合学会经方专业委员会委员，陕西省中药协会儿科专业委员会理事。
（备注：学院责任医师是医院与学院之间的桥梁，可为我校师生提供健康咨询、健康宣教、体检结果释疑、急救知识技能培训等服务。有需求者，可通过扫描学院责任医师二维码联系。）
