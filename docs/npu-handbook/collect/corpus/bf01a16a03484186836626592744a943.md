# 动力保障中心喜获陕西省高校水电技能竞赛二等奖

2025年6月10日，由陕西省教育后勤协会能源管理专业委员会主办的“陕西省高校水电技能竞赛”在西安建筑科技大学草堂校区举行。后勤部办公室动力保障中心组建的代表队经过激烈角逐，凭借扎实的实操技能和默契的团队协作，荣获二等奖。
后勤部办公室高度重视此次赛事，动力保障中心精选技术精湛、经验丰富的选手组成参赛队伍。赛前通过多轮实操演练和模拟测试，不断突破技术难点，全面提升操作水平，为比赛奠定坚实基础。
比赛现场，队员们精神饱满，分工明确，严格按照流程完成各项安装任务。成品经评审专家现场复检，试运行一次成功，充分彰显了动力保障中心的专业素养和团队协作力。
动力保障中心将以此次荣誉为新起点，立足本职岗位，继续发扬工匠精神，勇于创新，把竞赛收获转化为做好学校服务保障工作的强劲动力，助力学校高质量发展。（撰稿人：陈晓莉；审稿人：韩争胜）
