# 追寻红色足迹 强化使命担当—树立和践行正确政绩观学习教育专题党建活动

为深入学习贯彻习近平新时代中国特色社会主义思想，引导党员教师坚定理想信念、强化使命担当，2026年5月30日，大学外语教学部党支部与研究生公共外语教学部党支部共赴蓝田县灞源镇联合开展了“追寻红色足迹 强化使命担当-树立和践行正确政绩观学习教育”党建活动。两支部党员教师通过参观学习、党课研讨、实地研学等形式，接受了一次深刻的党性教育。
重温革命历史 赓续红色血脉
上午10时30分，党员们来到灞源镇青坪村灞源革命纪念馆。灞源地区是蓝田县早期革命活动的重要区域，记录了从土地革命到解放战争时期蓝洛地区波澜壮阔的革命斗争历程，这里也曾留下李先念、汪锋等老一辈革命家战斗的足迹。纪念馆内，一幅幅珍贵的历史图片、一件件斑驳的革命文物，生动再现了当年革命先辈在极端艰苦条件下开展武装斗争、建立蓝洛地区第一个红色革命政权-蓝洛县人民民主政府的光辉历程。党员们驻足凝视，认真聆听讲解，深刻感悟革命先辈“革命理想高于天”的坚定信念和不怕牺牲、英勇奋斗的革命精神。借此反思作为新时代的外语教育工作者，如何从红色历史中汲取精神力量，时刻牢记“为党育人、为国育才”的初心使命，将正确政绩观体现于立德树人的全过程，努力培养堪当民族复兴大任的时代新人。
体验民俗文化 增强文化自信
随后，党员们走进灞源民俗展示馆。从古朴的农耕器具到精巧的民间刺绣，从传统节庆礼仪到乡约家训传承，一件件实物、一幕幕复原场景，系统诉说着关中大地的生活智慧与文化根脉。驻足于一幅幅承载着厚重历史的展板前，大家深受触动：这些鲜活的民俗记忆正是我们讲好中国故事最宝贵的素材。党员们纷纷表示，作为外语教育工作者，既是语言文化的摆渡人，也是中华文明的守望者。在未来的教学中，要将这份文化自信有机融入课程思政，引导学生在跨文化交际中精准地讲好中国故事、传播中国声音。
现场党课学习校准政绩坐标
在清坪村六亩田，大学外语教学部党支部书记杨惠英以《培根铸魂，融通中外-外语教育工作者的政绩观与时代担当》为题，为全体党员讲授专题党课。党课紧扣“核心思路”“坐标校准”“偏差反思”“实践路径”“业绩清单”五个维度，深刻阐释了外语教育工作者应树立“真业绩”“实业绩”“大业绩”的政绩观。此次党课有效促进了党建活动与外语教育教学的深度融合，进一步激励了党员同志在深化课程思政、提升育人本领、拓展文化传播、坚守意识形态阵地等方面持续发力，切实将学习成果转化为“功成不必在我”的精神境界和“功成必定有我”的担当。（文/肖勇 杨惠英；图/曹杨 黄河；审稿/王高祖）
