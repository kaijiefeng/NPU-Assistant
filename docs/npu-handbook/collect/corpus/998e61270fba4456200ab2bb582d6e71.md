# 关于开展“请听档案说——情系兰台档案学术沙龙”活动的通知

各位馆员：
在“6·9”国际档案日即将到来之际，为营造浓厚学术氛围，加强档案学术知识的交流与共享，进一步提升大家的专业素养，档案馆精心筹备了“请听档案说——情系兰台档案学术沙龙”活动。现将活动相关事项通知如下：
一、活动主题
请听档案说——情系兰台档案学术沙龙
二、活动目的
通过本次沙龙，促进馆员之间的深度交流，分享档案工作中的经验与感悟，加深对档案学术知识的理解，激发工作热情与责任感，共同推动档案事业的发展。
三、活动时间
2025年6月4日下午3:00
四、活动地点
档案馆会议室
五、参与人员
全体馆员
六、活动安排
开场致辞：由馆长戚红梅介绍本次沙龙的主题和目的。
主题分享：邀请各位馆员围绕主题进行分享，分享内容丰富多元，既涵盖档案管理的创新方法，也涉及档案文化的深度挖掘与有效传播。同时，还可分享在档案收集、整理、保管、利用等环节积累的宝贵经验与实用做法。
交流讨论：参会人员围绕主题分享内容和档案工作中的实际问题进行交流讨论，各抒己见，分享工作感悟和经验。
总结发言：由馆长对本次沙龙进行总结发言，对活动成果进行肯定，并对未来档案工作提出期望和要求。
七、活动要求
1. 请各位馆员提前做好准备，结合自身工作实际，准备与档案学术知识相关的问题或经验分享。
2. 请各位馆员积极参与交流讨论，共同营造活跃的学术氛围。
3. 希望各位馆员积极参与本次沙龙活动，共同在交流中提升，在分享中进步。
档案馆
2025年5月31日
