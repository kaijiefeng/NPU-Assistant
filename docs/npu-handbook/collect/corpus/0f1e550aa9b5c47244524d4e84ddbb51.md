# 感悟百年辉煌，启航全新征程

10月14日至17日，西北工业大学和西安工业大学共同策划组织中外学生开展以“感悟百年辉煌，启航全新征程”为主题的社会实践。
此次社会实践由西北工业大学国际教育学院、西北工业大学伦敦玛丽女王大学工程学院和西安工业大学国际教育学院的36位师生组成，在西北工业大学国际教育学院副院长兼国际合作处副处长李自伟的带领下，先后赴延安、榆林（绥德、米脂）重走总书记考察路线，重温中国共产党在陕北的革命岁月，感受能源化工重镇的快速发展，体验中国共产党领导下的乡村振兴和民风民俗。
杨家岭到杨家沟，革命圣地学党史
实践队先后在杨家岭参观了毛泽东等中央领导旧居，回顾中国共产党第七次全国代表大会和延安文艺座谈会的会议精神，在杨家沟见证中国革命的重大转折，共同感受中国共产党不断开拓进取，勇于自我革命的独特品格。
“一个党史陈列，就是一部党史教科书”，在延安革命纪念馆，队员们认真聆听讲解，浏览图文实物，重温延安革命和建设历史，了解了中共中央在延安和陕北领导中国革命的丰功伟绩，学习了红军革命的坚强意志和强大精神力量。
在中共绥德地委旧址，队员们认识到中国共产党始终坚持把人民利益放在最高位置，始终同人民站在一起、想在一起、干在一起，“人民至上是作出正确抉择的根本前提”。
工业创新促发展，能源科技开新局
在近几年的快速发展中,陕西榆林立足新发展阶段，贯彻新发展理念，服务和融入新发展格局。推动高质量发展，按照绿色低碳的发展方向，对标实现碳达峰，碳中和目标任务。榆林高新区引进多项绿色技术服务平台，促进中小企业的成长，实现了优势互补、资源共享，形成了具有榆林特色的清洁能源产业链条。
在参观高新区科创产业园时，高清洁品和特色化工品的制作过程，深深地吸引着中外实践队员的目光。为进一步了解能源行业现状，实践队员来到中煤陕西榆林能源化工有限公司和华泰氢能产业园参观学习。从公司总体情况的介绍到打造清洁能源供应商，大家对绿能产业有了充分的了解。
随后，工作人员带领队员们参观了中石油兰石化榆林乙烯项目办公场所，接线员有条不紊的接收信息，大屏幕上实时呈现出车间运行情况，整个生产过程的高效运转。
在讲解员们的中英文介绍下，队员们来到了榆树湾煤矿。“原来煤的采集过程是这样的！”来自塞内尔的GUEYE THIERNO看着屏幕上的采集车间，对3.6万吨的日产煤量发出感叹。实践队员们探讨了煤矿行业发展前景、相关产业链应用实际的情况，以及绿能科技的意义。
乡村振兴树楷模，民风质朴暖人心
队员们在张家砭镇郝家桥村回顾了村民群众通过精耕细作、改善耕种条件、选择优良品种提高单产等农业经验，推出了劳动英雄、共产党人刘玉厚的先进典型，掀起了大生产热潮，使村里各项事业都走在绥德分区的最前列，成为远近闻名的“农村楷模”。中外学生纷纷对郝家桥村在脱贫攻坚方面取得的成绩表示赞叹。
热情好客的郝家桥村民还邀请实践队员走进家中参观交流，将新鲜采摘的红枣发给大家品尝，使学生们感受到了这里淳朴的民风。
来到绥德非物质文化遗产陈列馆，中外学生近距离体验了绥德石雕、唢呐、剪纸、根雕、泥塑、说书、陕北秧歌等民俗文化，感受到了陕北人民的热情、质朴、豪迈。游览最后，文化馆馆长还为大家即兴表演了陕北民歌信天游，悠扬高亢的演唱赢得了中外学生的满堂喝彩。
近年来，西北工业大学着力开展以“中外学子多源融合，同向同行共同进步”为目的的社会实践活动，拓展中国学生国际视野，加深国际学生对中国的认识和理解，探索国际化人才的培养新模式，提升国际学生培养质量。截至目前，在校师生先后开展以“先进制造，引领未来”、“大飞机 大梦想”、“感知脱贫攻坚”和“感知西安硬科技”等主题的社会实践活动，取得显著成效。
