# 巧手匠心展风采 光影铸魂绽芳华 ——机电学院工会举办庆"三八"妇女节主题活动

3月7日，机电学院工会精心策划"以手传心，邂逅千年贝影流光"主题庆祝活动，为女教职工送上别样节日祝福。在B410教室内，30余名女教师化身"非遗传承人"，认真制作螺钿胸针手链。
指尖流转间，贝母碎片在光影中熠熠生辉，化作翩跹蝶翼，传统工艺的厚重底蕴与现代设计的灵动创意交织融合，碰撞出独特的美学韵味。参与者们沉浸其中，不仅深刻体会到千年非遗技艺的精妙绝伦，更在协作交流中拉近了彼此距离，情谊在指尖的温度中悄然升华。
从设计构图的巧思到镶嵌打磨的细致，大家互帮互助，默契配合，一枚枚蝶舞花绽的胸针、一串串流光溢彩的手链逐渐成型，每一件作品都凝聚着匠心与巧思。老师们捧着精心制作的作品，难掩喜悦之情。活动现场特别设置了成果展台，精巧别致的物件引得众人驻足欣赏、拍照留念，非遗文化在指尖焕发出新的生机与活力，成为节日里一道亮丽的风景线。
随后，工会组织教职工集体观看悬疑喜剧《唐探1900》。影片中环环相扣的推理与幽默桥段引发阵阵欢笑，大唐西市影城的沉浸式观影体验，让教职工在紧张工作之余享受文化盛宴。
参与教师纷纷表示，此次活动既有传统手作的匠心传承，又有现代光影的艺术享受，充分感受到学院对女性群体的关怀与尊重，将以更饱满的热情投身教育事业，展现新时代女性教育工作者的风采。
