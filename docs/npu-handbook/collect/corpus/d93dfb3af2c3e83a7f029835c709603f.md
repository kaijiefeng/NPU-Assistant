# 西北工业大学召开航海科技工作大会

11月16日，西北工业大学航海科技工作大会顺利召开。西北工业大学校长、中国工程院院士宋保维，副校长杨益新、张开富，海军潜艇学院陆铭华少将，中船集团第705研究所所长王中，第710研究所所长王晓林，第726研究所所长马晓民，第716研究所高级专务万勤，第719研究所副所长林原胜，第715研究所副所长洪常委，第760研究所副所长夏春艳，航天科工第三研究院水下装备总体部副主任李长文，中船集团系统工程研究院院长助理梁立全，汉江国家实验室领域科学家张必银、王华奎，中船集团第702研究所石亚军研究员等来自国内多家行业院所的主要领导、专家学者及学校科学技术研究院领导，航海学院领导班子成员、院长助理、各科研团队负责人、团队首席科学家和教师代表等参加会议。
张开富代表学校致欢迎词，对各位嘉宾长期以来对西工大、对航海学院的关心、帮助和大力支持表示最衷心的感谢。他指出，长期以来，学校始终牢记总书记嘱托，坚持不懈服务于国家海洋战略需求，在科学研究、人才培养等诸多方面实现跨越式发展，展现出昂扬向上的办学新成效。他希望，航海学院要进一步弘扬“总师育人文化”，加强系统集成创新，促进科技成果转化，为学校“127”近期发展目标和“天下工大、世界三航”远景目标贡献力量。他强调，学院要经常性开展有组织的与科研院所交流对接活动，尤其是青年教师要增进与兄弟单位院所的交流合作，以国家战略需求为导向，充分展现我校青年科研工作者在实现国家海洋强国战略中的个人使命与卓越价值。
航海学院院长潘光作《航海学院“十四五”科研发展分析与总结报告》，系统总结学院“十四五”以来科研工作取得的成绩和经验，剖析学院各项工作面临的新形势和存在的问题，提出了下一步合作方向和工作举措，以期推动学院高质量、内涵式发展。
上级部门及兄弟单位代表陆铭华、王中、王晓林、马晓民、万勤、林原胜、洪常委、夏春艳、李长文、梁立全、张必银、王华奎、石亚军等立足工作实际，结合科技发展，从“实施有组织科研、开展‘1→0’研究、重点项目进展、深化交流合作”等不同角度展开研讨，为学校航海科技工作建言献策。
西北工业大学科学技术研究院院长王伶指出，长期以来，航海学院心怀“国之大者”，主动担负科技强国使命，在若干重要科技领域形成竞争优势，为打造国家战略科技力量，加快实现高水平科技自立自强提供了有力支撑。
杨益新指出，长期以来，各个上级单位和兄弟院所与西工大同频共振、同向同行、携手共进，共同推动航海科技事业不断发展。他表示，一要坚持“总师育人文化”引领，源源不断培养造就拔尖人才。二要紧密关注并聚焦于未来智能化科技工作的发展趋势。三要统筹强化关键核心技术攻关，促进科研团队良性布局，为航海科技发展贡献新的更大力量。
宋保维在总结讲话中充分肯定了学校航海科技工作取得的丰硕成果，分析了存在的问题和面临的机遇与挑战，他强调，在下一步工作中，一要深化科技改革，打造关键力量。瞄准国家重大战略需求，优化学科布局，拓展学科内涵，致力于打造高水平国家战略科技力量。二要聚焦新兴领域，引育青年人才。在新时代背景下，新兴产业领域的崛起，为各类人才成长提供了更加广阔的平台，要将科技人才的培养与使用置于事业的发展大局之中，弘扬科学家精神，担当作为、创新求实、专心研究，为实现高水平科技自立自强贡献力量和智慧。三要军民深入协同，不断提升创新能力。希望相关行业院所和学校、学院凝心聚力，不断加强顶层设计和统筹谋划，提升科技创新能力，破解“卡脖子”问题。四要打造校企共同体，牵引领域发展。深化校企合作，进一步整合优势资源，创新合作模式，拓展合作空间，深化合作内涵，更好地推动学科和产业的共同发展与进步。
