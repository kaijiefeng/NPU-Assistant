# 推动“总师育人文化”走深走实：航海学院举行2024年黄震中海洋班专项奖学金颁发仪式

为深入贯彻落实学校第十四次党代会精神，推动“总师育人文化”走深走实，航海学院于12月8日在长安校区教西A205召开黄震中海洋班专项奖学金颁发仪式。航海学院院长潘光、副书记王银涛、副院长雷波、院长助理杨长生，以及黄震中海洋班班主任、辅导员、学工主管、教学秘书和全体同学参加了本次活动。会议由王银涛主持。
“黄震中海洋班”以我国水中兵器教育事业奠基人之一，西北工业大学水中兵器系（航海学院前身）首任系主任，著名水中兵器专家、力学家、教育家“黄震中”教授之名命名。该班自2022年起设立，设置个性化培养方案，本研贯通培养，实行动态管理机制。为了激励黄震中班同学勤奋学习，潜心科研，学院设立黄震中海洋班专项奖学金，每年度5000元/人，覆盖班里所有学生。
潘光介绍了学校本科人才培养概况和“总师育人文化”的内涵。他表示，工科生在学习专业知识的同时，也要关注人文精神和文化素养的提升，这些素质都是成为“总师型”人才所不可或缺的。他指出，学院应探索符合自身特色的路径，打造具有航海特色的人才培养体系。在激动人心的颁奖环节中，潘光依次为学生代表颁发了获奖证书，获奖学生们脸上洋溢着自豪的笑容，手中的证书既是他们努力的成果，也是未来前进的动力。
获奖代表曾昊、陈卓表示，作为黄震中海洋班的一员深感自豪，学院丰富的理论与实践学习平台筑成了同学们不断进步的坚实基础，将以这份荣誉为动力，继续培养自身能力与责任感。学校浓厚的“总师育人文化”深深地感染着大家，今后将刻苦学习专业知识，奋发图强。
班主任杨占龙、谢磊老师表示，黄震中海洋班专项奖学金的设立给予了学生们极大的激励，航海学子要努力奋斗、再接再厉，把奖学金作为鞭策自己前进的动力。今后要更加注重专业基础知识学习，以总师校友为榜样，以更加优异的成绩回报学校，回报社会。
雷波对黄震中海洋班管理办法、动态调整细则进行了解读，希望同学们能够更严格的要求自己，他鼓励学生要将“总师育人文化”内化于心、外化于行，深入理解“总师育人文化”的内涵、打牢专业基础、树立远大目标，成为未来社会的领导者和贡献者。
最后学生和与会教师进行了亲切的沟通交流，纷纷表示受益匪浅。
