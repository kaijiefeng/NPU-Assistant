# 力学与交通运载工程学院党委组织召开11月党支部书记（扩大）工作例会

为深入学习贯彻党的二十届五中全会精神，持续夯实基层党建根基，推进党支部标准化规范化建设，压紧压实新时代党建工作责任，11月3日上午，力学与交通运载工程学院党委在206会议室召开11月党支部书记（扩大）工作例会，全院师生党支部书记、支部委员参加会议，会议由学院党委书记巨维博主持。
会上，巨维博书记带领与会人员学习《中国共产党第二十届中央委员会第五次全体会议公报》《中共中央关于持之以恒推进全面从严治党若干重大问题的决定》以及习近平总书记关于《中共中央关于持之以恒推进全面从严治党若干重大问题的决定》的说明等文件精神，传达校党委理论学习中心组扩大会议关于学习贯彻党的二十届五中全会精神部署要求。提出各支部要将学习贯彻党的二十届五中全会精神作为当前和今后一个时期的重大政治任务，认真组织集中学习，切实将党的二十届五中全会精神和党的创新理论学习成果，转化为增强基层党建、锤炼干事创业本领的实际成效。
会议指出，一是要充分认识持之以恒推进全面从严治党的极端重要性和现实紧迫性，切实把严的基调、严的措施、严的氛围长期坚持下去。二是要充分激发基层党支部战斗堡垒作用。各党支部要抓实党员教育管理，强化党建业务融合发展，扎实推进基层组织建设。要建强支委骨干队伍，常态化开展党务能力提升和业务培训，持续提升党支部规范化建设水平，激发组织效能。三是要发挥党员先锋模范带头作用，引导广大师生党员勇于担当作为，持续提振干事创业精气神。四是要抓实安全稳定工作，各党支部要切实履职尽责，常态化做好师生联系工作，下沉师生一线，主动排查化解矛盾风险，营造积极向上、和谐稳定的良好氛围。
本次会议还对学院党代会筹备、巡视迎检、“三会一课”制度落实和组织生活规范化建设等工作进行安排部署，组织与会人员学习新修订《中国共产党发展党员工作细则》，要求各支部扛牢主体责任，以高质量基层党建赋能学院事业高质量发展。
