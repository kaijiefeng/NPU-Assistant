# 深学细悟树正确政绩观 数智赋能促财务新发展——计划财务部党支部召开专题党课暨理论学习会

为深入学习贯彻关于树立和践行正确政绩观的重要论述，积极应对数字化变革对高校财务管理提出的新要求，3月18日下午，计划财务部党支部召开专题党课暨3月理论学习会。部门全体人员参加会议，会议由支部副书记张鹏主持。
聚焦智慧财务，探索数智赋能新路径
会议特邀计算机学院李青副教授作专题讲座。李青以“大模型赋能高校财务智慧化建设与实践路径”为题，为与会人员带来了一场内容丰富、见解深刻的学术盛宴。讲座聚焦大模型技术如何驱动财务职能从传统核算向智慧管理、决策支持转型，系统阐释了其基本原理、高效应用方法与核心价值，并对财务领域的技术融合前景进行了前瞻展望，为思考财务工作数字化、智能化提供了重要启发。
筑牢思想根基，树立服务发展新标杆
在理论学习环节，支部书记李春林领学了《习近平关于树立和践行正确政绩观论述摘编》、习近平总书记在二十届中央纪委五次全会上的重要讲话精神、中央党的建设工作领导小组召开会议研究部署树立和践行正确政绩观学习教育工作等内容。大家纷纷表示，要将学习成果切实转化为做好财务工作的实际行动，把正确政绩观贯穿于财务工作的全过程、各方面，确保财务工作始终沿着正确方向，为学校事业发展提供坚实保障。
李春林在总结发言中强调，面对新形势、新任务，全体财务人员必须主动识变、应变、求变。一是要坚持问题导向，紧密围绕师生关切和业务痛点，善于运用新技术、新思维发现并破解工作中的深层次问题。二是要深化对人工智能等新兴技术的理解与应用思考，积极探索其在预算管理、绩效评价、风险预警等具体场景中的应用，让技术真正为管理增效、为师生减负。三是要树立终身学习理念，不断拓展认知边界与专业视野，不仅要精通财务政策业务，也要了解技术发展趋势和高等教育发展规律。四是要将财务工作置于学校发展大局中谋划推进，深入研究宏观政策与学校发展战略，使财务管理更好服务于学校学科建设、人才培养、科学研究等中心工作，推动财务工作从“核算型”向“战略型”转变。
计划财务部将以此次学习为新的起点，立足学校发展大局，提升财务工作站位，持续强化理论武装与业务钻研，积极探索新一代信息技术在财务管理中的创新应用，以智慧财务建设为抓手，不断提升财务治理能力，高质量高水平高标准推动各项工作落地见效，为实现学校“一十百千”发展目标和“天下工大、世界三航”远景目标贡献坚实财务力量。
