# 自动化学院召开本科教学成果奖申报辅导会

为深入推进学院本科教学改革，切实做好教学成果奖申报工作，3月23日下午，自动化学院召开本科教学成果奖申报辅导会，学院党委书记孙华强、教学副院长程塨、各系教学主任、拟申报教学成果奖的教师代表参加会议。
会上，程塨强调，教学成果奖是衡量学院教学水平和人才培养质量的重要标志，全体教师要深刻认识到教学成果奖对于学院人才培养工作的重要性，要克服困难，精心打磨，力争在本届教学成果奖申报中取得新突破。
本次辅导会邀请具有丰富申报经验的吴小华教授作专题报告。吴教授围绕教学成果奖介绍、前期准备、撰写逻辑、核心模块撰写指南等四个方面进行了深度讲解。吴老师以个人获奖申报书为例，逐项拆解，详细阐述了如何精准提炼成果简介、清晰梳理解决教学问题的方法、有力佐证成果的创新点，以及规范整理支撑材料。与会教师纷纷表示深受启发、受益匪浅。
孙华强在总结讲话中谈到，全体教师务必以教学成果奖申报为抓手，深度思考“如何培养好人才”这一核心任务。他强调，好的教学成果不光是“写出来”的，更是“做出来”的，要确保每一项教学成果都经得起实践和时间的检验，真正做到为党育人、为国育才。
后续，学院将针对拟申报的项目，邀请校内外专家打磨辅导，依托教学成果奖申报，鼓励教师潜心教书育人，持续深化教育教学改革，提升人才培养质量。
