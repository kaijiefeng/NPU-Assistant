# 一站式”学生社区｜学院举办“书记下午茶”活动

9月29日下午，教育实验学院/未来技术学院/学科交叉中心在“智慧三航”学研空间报告厅顺利举办“书记下午茶”活动。学院党委书记、本博翱翔总师班执行班主任牟蕾与2025级本博翱翔总师班（HC002515班）同学齐聚一堂，围绕学业发展与生涯规划展开深入交流。
活动伊始，牟蕾梳理总结了班级建设、学业成绩与综合表现，也充分肯定了同学们在本博贯通培养模式下取得的优异成绩，同时结合课堂学习、科研参与、团队协作等实际，客观指出了存在的不足与改进方向，对新学期提出明确要求。随后，她与同学们深入交流暑期科研实践情况，鼓励大家勤进实验室、早进课题组，在真实科研场景中打基础、长见识，把科研报国的种子扎进本博成长全过程。
牟蕾说，“总师型”人才的成长不仅在于专业能力，更在于品格修养与综合素养。她与同学们亲切交流，勉励大家在日常点滴中修炼品行、拓宽格局。她希望同学们传承西工大“公诚勇毅”校训，践行“三实一新”校风，在本博贯通、学科交叉的平台上，涵养家国情怀，练就过硬本领，做到德智体美劳全面发展，真正成为可堪大任的时代新人。
本次活动既是对同学们学习科研工作的全面指导，更是一场有温度的人生成长对话。HC002515班全体同学将以更加昂扬的姿态投身学习与科研，交出属于西工大本博翱翔总师班学子的时代答卷。
