# 纸翼筑梦，快乐启航”——机电学院庆“六一”亲子活动欢乐举行

为落实学校工会、校妇联关于青年教师人文关怀的工作要求，丰富教职工亲子文化生活，5月30日上午，机电学院工会在航空楼B座会议室及大草坪成功举办“纸翼筑梦，快乐启航”庆“六一”亲子活动，全院教职工携子女踊跃参与。
活动伊始，孩子们便收到了学院工会精心准备的盲盒和彩笔套装，现场还摆放了琳琅满目的零食，小朋友们惊喜连连，迫不及待地拆开盲盒互相分享，欢声笑语瞬间充满了整个会议室。
随后，活动按年龄分组在三个会议室同步展开趣味折纸环节。每位小选手领取了4张折纸材料，既包括对照30余种机型图纸折叠的限定挑战，也包括利用空白彩色卡纸和彩笔自由创作的DIY环节。孩子们认真研究图纸、尝试不同折法，家长们则在一旁耐心指导，有的手把手教孩子对齐折痕，有的和孩子一起讨论设计造型，还有的负责剪裁、孩子负责涂色，分工合作其乐融融。爸爸妈妈和孩子围坐在一起，你一言我一语，一架架独一无二的纸飞机在亲子携手合作中诞生，每一架都凝聚着家长与孩子共同的巧思与欢笑。
折纸绘制完成后，活动移至航空楼大草坪进行飞行比赛。蓝天白云下，绿草如茵，孩子们手持自己亲手制作的纸飞机，按年龄分组依次登场。每位小选手有5次投掷机会，取最远一次成绩。随着裁判一声令下，一架架纸飞机划出优美的弧线，有的盘旋升空，有的直冲远方。家长们在场边加油助威，孩子们则认真调整投掷角度和力度，屡屡刷新最好成绩。草坪上欢呼声、掌声此起彼伏，亲子同乐的温馨画面成为这个“六一”最美好的回忆。
活动最后颁发了飞行距离奖——每组前10%获得一等奖、前10%-40%获得二等奖，以及由全体参赛选手及工作人员现场投票产生的“最美DIY”创意奖。获奖孩子们手捧奖品，脸上洋溢着自豪的笑容。本次活动不仅让孩子们在动手与运动中收获了快乐与成长，也为教职工家庭创造了珍贵的亲子互动时光，进一步增强了学院的凝聚力与归属感。
