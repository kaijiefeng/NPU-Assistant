# 清风扬正气，廉洁铸忠诚”——硕士生第六党支部举办廉洁主题教育分享会

近日，西北工业大学硕士生第六党支部于学院119会议室举办了“清风扬正气，廉洁铸忠诚”主题教育分享会。本次活动旨在深入贯彻落实全面从严治党要求，强化青年党员纪律规矩意识。
活动伊始，支部书记邹松名阐述了廉洁教育的重要性。他说到，我们青年党员正处于价值观成型和学术科研的关键时期，必须明辨是非、恪守底线，将清正廉洁内化于心、外化于行。
分享环节中，四名预备党员依次发言。吴迪讲述了焦裕禄同志“心中装着全体人民，唯独没有他自己”的公仆情怀，彰显了老一辈共产党人克己奉公、清廉自守的崇高风范；王路铭同志分享了“全国优秀县委书记”廖俊波同志在工程招标等关键岗位上坚决拒绝吃请礼品、始终秉公办事的真实事迹，诠释了其“肝胆干事、干净做人”的优秀品格；李宏宇同志讲述了中国工程院院士马远良同志毕生致力于国家水声工程与国防科技事业，淡泊名利、治学严谨的事迹，展现了科技工作者胸怀祖国、无私奉献的责任担当；王宏霞同志分享了杨善洲老书记退休后扎根荒山植树造林22年，将价值数亿元的林场无偿交给国家，自己仅带走三根锄把留念的无私境界。四位同志的分享引发全场共鸣，充分展现了大家对廉洁自律理念的深刻理解与坚定信仰。
活动最后，邹松名结合近期通报的违纪违法典型案例提醒大家，支部全体党员要以案为鉴、警钟长鸣，从反面教材中受警醒、明底线、知敬畏。同时，号召大家在科研生活中不断加强党性修养，遵守学术规范，共同营造风清气正的校园氛围。
本次分享会是支部“党建领航，研精笃志”品牌建设的重要实践。与会党员表示此次活动进一步夯实了理想信念之基。下一步，支部将持续推进清廉文化建设，培育品行端正、堪当民族复兴重任的时代新人。
