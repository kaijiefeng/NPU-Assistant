# 生命科学与技术学院组织师生观看庆祝中国共产党成立105周年大会

为庆祝中国共产党成立105周年，深入学习贯彻习近平新时代中国特色社会主义思想，大力弘扬伟大建党精神，进一步激发全院师生党员的爱党爱国热情，7月1日上午，生命科学与技术学院组织师生集中收看庆祝中国共产党成立105周年大会直播。
大会直播过程庄严肃穆、振奋人心。全体师生党员凝神端坐、认真观看，集中学习领会习近平总书记重要讲话精神，深入了解“七一勋章”获得者、“两优一先”代表的感人事迹。大家被先进榜样忠诚于党、矢志报国、无私奉献、攻坚克难的崇高精神深深打动，接受了深刻的思想洗礼和党性教育，现场学习氛围浓厚。
此次集中收看活动极大提振了全院师生的精气神，充分激发了大家干事创业、奋勇争先的饱满热情。师生党员纷纷表示，要以先进典型为镜、向榜样标杆看齐，努力汲取奋进力量，切实把此次学习成果转化为学习和工作的不竭动力。
初心如磐笃行致远，凝心聚力再启新篇。今后，学院将持续深入学习贯彻习近平党建思想，深化党建引领作用，立足学院学科特色，聚焦国家重大战略需求，以实干担当推动学院各项工作提质增效，为学校高质量发展和民族复兴伟业贡献力量。
