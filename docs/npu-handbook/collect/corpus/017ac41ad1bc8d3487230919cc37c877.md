# 陕桂区域研究生教育改革经验互鉴与协同发展学术研讨会在广西桂林召开-西北工业大学研究生院

10月27—29日，陕桂区域研究生教育改革经验互鉴与协同发展学术研讨会在广西师范大学召开。本次论坛由陕西省学位与研究生教育研究中心主办，广西师范大学党委研究生工作部/研究生院、广西高等教育发展研究中心承办。来自陕西、广西以及全国各有关高校的专家学者及研究生教育工作者以“区域联动、产教融合：新时代研究生教育质量提升与创新体系构建”为主题展开研讨，为我国研究生教育改革及高质量发展建言献策。广西师范大学党委副书记、校长孙杰远，西北工业大学党委常委副校长、陕西省学位与研究生教育研究中心学术委员会副主任委员王伶，广西壮族自治区教育厅副厅长张勤芳出席开幕式并致辞。研讨会分为开幕式、主旨报告、主题报告和闭幕式等环节。论坛开幕式由广西师范大学党委常委、副校长林国庆主持。
孙杰远指出，陕西、广西两省区虽相隔千里，但在服务国家战略、推动区域高质量发展上有着共同的使命担当。研究生教育作为国民教育体系的顶端，是科技创新的生力军，也是人才自主培养的主阵地，其质量直接关系国家竞争力的高低。广西师范大学作为综合性大学，研究生人数规模较大，期待加强与兄弟院校交流改革实践，学习借鉴陕西高校研究生教育改革发展的有益经验。他表示，陕桂两地研究生教育资源禀赋互补、合作潜力巨大，希望以本次研讨会为纽带，搭建跨区域交流协作桥梁，推动建立常态化交流机制，推进联合培养、导师互聘、学分互认等务实合作，深化互学互鉴，共建陕桂研究生教育协同育人生态，携手助力区域研究生教育事业协同进步。
广西师范大学党委副书记、校长孙杰远致辞
王伶指出，研究生教育是教育、科技、人才一体化推进的关键结合点，当前正处于落实“十五五”规划的关键阶段，国家对区域教育协同、产教融合提出更高要求。陕西科教资源雄厚，拔尖人才培养积累丰厚，广西拥有面向东盟的开放优势，两地研究生教育课题相近、互补性强，具备良好的交流合作基础。陕西省学位与研究生教育研究中心依托西北工业大学建设，学校立足国防特色办学定位，传承总师育人文化，在高层次工程科技人才培养方面积淀深厚，形成特色研究生培养模式，推动人才培养与产业重大需求紧密对接。他表示，西北工业大学与陕西省学位与研究生教育研究中心将发挥平台纽带作用，做好研究交流与咨询服务，助力两地研究生教育协同发展。
西北工业大学党委常委、副校长，陕西省学位与研究生教育研究中心学术委员会副主任委员王伶出席研讨会开幕式并致辞
张勤芳在研讨会上致辞，他代表自治区教育厅对陕桂两地及其他各地的参会同仁表示热烈欢迎。陕西高等教育基础雄厚，广西研究生教育正处于扩容提质、加速追赶的阶段，两地在服务国家战略、助推区域高质量发展使命一致，本次研讨会交流互鉴意义重大。他指出，现阶段广西研究生教育亟须借鉴陕西在工程硕博士改革、产教融合方面的成熟经验，推动研究生教育转向内涵式发展。他表示，区域协同重在优势互补、双向赋能，希望陕、桂两地立足各自产业与区位特色，在学科共建、联合培养、导师互聘、学分互认等方面建立常态化交流，探索跨区域育人新模式。
广西壮族自治区教育厅党组成员、副厅长张勤芳出席研讨会开幕式并致辞
广西师范大学党委常委、副校长林国庆主持开幕式
在主旨报告环节，中国高等教育学会第六届理事会会长瞿振元、中国学位与研究生教育学会副会长兼学术委员会副主任王战军、西北工业大学党委常委、副校长王伶分别以《提质扩容调结构：“十五五”时期研究生教育的发展趋势和政策导向》《迈向强国的中国研究生教育：规模·质量·创新》《聚焦“从1到0”重大工程问题逆向突破，军工领军人才培养体系的构建与实践》为题进行主旨报告。本环节由广西师范大学教育学部党委书记蓝廖国主持。

陕西省学位与研究生教育研究中心将持续发挥智库平台作用，不断深化和广西及全国兄弟单位的学术交流，探索区域研究生教育协同创新路径，助力研究生教育高质量发展。
