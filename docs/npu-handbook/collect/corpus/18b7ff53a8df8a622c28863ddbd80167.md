# 力学与土木建筑学院-西北工业大学医院

责任医师：牛仙玲（副主任医师）
简介：
牛仙玲，副主任医师，毕业于西安医科大学临床专业，在第四军医大学完成硕士研究生课程班学习。在陕西省第二人民医院儿科工作近20年。先后在西北妇幼保健院、西安市儿童医院、西京医院进修学习。擅长儿科呼吸系统、消化系统疾病及新生儿常见疾病的诊治，对儿童生长发育中的身心问题有一定的研究，发表专业论文数篇。
（备注：学院责任医师是医院与学院之间的桥梁，可为我校师生提供健康咨询、健康宣教、体检结果释疑、急救知识技能培训等服务。有需求者，可通过扫描学院责任医师二维码联系。）
