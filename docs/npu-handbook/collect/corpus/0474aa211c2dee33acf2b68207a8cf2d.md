# 电子信息学院举行庆祝中国共产党成立105周年暨“两优一先”表彰大会

7月2日上午，电子信息学院举行庆祝中国共产党成立105周年暨“两优一先”表彰大会。学院领导班子成员、党委委员、受表彰的优秀个人和先进集体负责同志，以及各党支部书记、支委和党员代表参加会议。会议由学院党委副书记高敏主持。
大会在庄严的国歌中拉开帷幕。
在辅导员代表史越的带领下，全体党员面向党旗肃立，高举右拳庄严宣誓，一同重温入党誓词，铿锵有力的誓言响彻会场。党委书记侯俊宣读《电子信息学院党委关于表彰2026年度优秀共产党员、优秀党务工作者和先进党支部的决定》。学院领导及党委委员为31名优秀共产党员、8名优秀党务工作者、6个先进党支部颁发荣誉证书。
会上，获奖代表依次作交流发言。优秀共产党员代表、2025级硕士研究生汪逸凡结合自身社会实践、支教服务、支部履职与专业成长经历，分享了在基层一线叩问初心、在专业淬炼中厚植信仰、在服务师生中践行使命的成长历程，生动诠释了新时代青年党员听党话、跟党走的坚定信念，号召全体青年党员把个人理想融入党和国家事业发展大局，在科研攻关与服务人民的最前沿挺膺担当、砥砺奋进。优秀党务工作者代表、空天电磁感知师生融合党支部书记粟嘉分享了党务工作经验，支部积极探索党建与业务深度融合、思政与科研双向赋能的创新路径，构建了“学—讲—践—行”四维一体工作体系，以务实举措推动党建工作提质增效，努力为建设教育强国科技强国人才强国作出新贡献。先进党支部代表、博士生第二党支部书记赵畅菲介绍了支部紧扣科研育人主线、打造“高质量党建引领高质量科研”支部品牌的建设成果，展现了支部党员深耕电子信息前沿领域、聚力国防科研攻关的扎实实绩与报国担当。支部将持续深化党建引领，带动全体党员在国防科研赛道上勇毅前行，争做堪当民族复兴重任的时代新人。
侯俊代表学院党委向受到表彰的先进集体和优秀个人表示热烈的祝贺，向辛勤工作在教学、科研、管理一线的全体党员同志致以崇高敬意和节日问候。站在新的历史起点上，侯俊向全院各党支部和广大党员提出三点希望与要求。一是要突出政治建设，筑牢政治忠诚、严肃政治生活、守牢政治底线，在锻造忠诚本色上展现新担当。二是要夯实党建基础，强化基层组织建设、提升业务本领，在建强战斗堡垒上彰显新作为。三是要抓实全面从严治党，严明纪律规矩、持续改进作风，在涵养清风正气上展现新风貌。侯俊强调，全院上下要更加紧密地团结在以习近平同志为核心的党中央周围，以受表彰的先进集体和优秀个人为榜样，树立和践行正确政绩观，脚踏实地、久久为功，奋力在“十五五”新征程中开创电子信息学院高质量发展的精彩篇章。
大会在雄壮激昂的《国际歌》中圆满落幕。
