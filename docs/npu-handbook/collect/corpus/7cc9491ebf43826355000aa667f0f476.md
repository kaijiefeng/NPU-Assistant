# 赓续红色血脉，传承延安精神——生命科学与技术学院开展延安红色实践活动

为贯彻落实学校实践育人“三个一”工程要求，充分利用红色资源启智润心、培根铸魂功能，引导青年学子传承红色基因，厚植家国情怀，9月19日至20日，生命科学与技术学院组织50名2025级及2026级本科生赴延安开展“赓续红色血脉，传承延安精神”红色实践活动。活动由学院辅导员乔雪琪带队。
9月17日晚，学院召开行前动员大会，会议由乔雪琪主持，实践学生全员参会。会议围绕行程安排、历史认知、安全保障、行前准备展开培训，明确了实践日程安排及分组任务；重点讲解党中央在延安十三年的革命历程、延安精神的核心内涵与时代价值，引导同学们提前了解延安、带着问题出发，做到“行走有思考、参观有感悟”。
9月19日下午，队伍抵达王家坪革命旧址。同学们聆听专题讲座《毛泽东与毛岸英特殊父子情》。王家坪革命旧址主任、研究员冉春嫚以时间线为脉络，从毛岸英幼年艰苦流离的成长经历讲起，重点阐释毛泽东在毛岸英人生关键阶段的悉心引导与严格教诲。一堂家风党课，让同学们真切读懂伟大领袖毛泽东同志大公无私、严于教子、家风清正的崇高品格，深刻理解特殊父子情背后的家国大义。随后，同学们有序参观旧址，驻足于历史遗迹和珍贵文物前，回望革命先辈在艰苦环境中坚守信仰、奋勇拼搏的峥嵘岁月，真切体会延安精神中自力更生、艰苦奋斗的创业精神。
9月19日下午，研学队伍前往延安革命纪念馆开展集中学习。馆内丰富的史料、详实的图文影像、珍贵的革命实物，系统展现了党中央在延安十三年的光辉奋斗历程。同学们认真聆听讲解，细致浏览展品，全面回顾中国革命从艰难求索到走向胜利的壮阔征程。从红军长征落脚陕北，到抗日民族统一战线建立，从大生产运动到整风运动，从党的七大召开到夺取全国胜利，一件件文物、一幅幅照片，无声讲述着那段波澜壮阔的岁月。同学们深刻感悟红色政权来之不易、今日盛世来之不易，进一步坚定了听党话、跟党走的理想信念。
9月19日晚，实践队走进延安红街，观看大型沉浸式红色演艺《再回延安》。该演出采用独特的行走式沉浸观演模式，聚焦长征路上的青春信仰，以一支五人护旗班的长征征程为主线，生动讲述了一名年轻战士跟随队伍跨越千山万水、奔赴延安的热血故事。真实悲壮的革命故事、身临其境的沉浸场景、直击人心的情感演绎，让同学们真切感受到长征精神的磅礴力量与革命先辈的赤胆忠心。
9月20日上午，实践队首先到达延安博物馆。入馆前，大家学习了安塞腰鼓。在老师指导下，同学们手持红绸，击鼓踏步，饱满的热情展现了生科院学子积极向上的精神风貌。实践队随后走进延安博物馆。一件件文物静静陈列，串联起延安从远古到近代的完整脉络，勾勒出黄土高原的文明标识。同学们不仅了解了延安的地理自然、物产资源与民俗文化，更深刻认识到：延安既是革命圣地，也是中华文明的重要发祥地之一。在历史与文明的交汇中，同学们的文化自信与民族自豪感油然而生。”
在张思德纪念广场，枣园革命旧址管理处副主任、文博副研究员曹峰为同学们讲解了共产主义战士张思德的动人事迹。张思德平凡而伟大的一生，生动诠释了全心全意为人民服务的根本宗旨，他的奉献精神深深根植在同学们心中。随后，大家共同朗诵毛泽东同志的名篇《为人民服务》，洪亮的声音响彻天际。通过现场教学与诵读，同学们更加深刻地理解了“为人民服务”五个字的重量与温度。大家纷纷表示，要以张思德同志为榜样，把服务人民、奉献社会作为人生追求，在专业学习和社会实践中践行初心使命，做有理想、敢担当、能吃苦、肯奋斗的新时代好青年。
最后一站，实践队来到枣园旧址。在五大书记铜像前，同学们肃立瞻仰，表达对老一辈革命家的崇高敬意。随后依次走进毛泽东、周恩来、刘少奇、朱德等老一辈革命家旧居。窑洞内油灯、纺车、补丁军装静静陈列，为同学们上了一堂生动的“思政课”。同学们盯着桌角磨损的漆面和低矮的土炕，深刻体会到，正是在这样艰苦环境中，革命先辈以坚定正确的政治方向、解放思想实事求是的思想路线、全心全意为人民服务的根本宗旨、自力更生艰苦奋斗的创业精神为指引，领导中国革命走向胜利。
9月20日下午，中共延安市委党校体验教学基地党支部书记尚延以一节沙盘体验课，带领同学们回顾了长征历史。通过“重走长征路”活动，同学们深刻感受到长征的艰难。各小组通力合作，完成四支红军队伍的长征路线，并自主学习长征路上的重要历史事件与人物，最终以板报形式展示交流。
本次延安红色实践，将行前动员与实地研学紧密结合，让青年学子在圣地寻初心、学史悟使命、践志担未来。后续，学院将持续深化思政育人成效，引导生科学子赓续红色血脉、传承奋斗精神，为强国建设、民族复兴贡献青春力量。
【实践感悟】
2026级本科生 张国峰
此次延安研学，是一堂行走的思政大课，更是一次深刻的精神洗礼。作为新时代青年学子，我们生逢盛世、肩负重任，延安精神从来不是尘封的历史，而是砥砺前行的精神动力、终身践行的人生准则。立足当下学习生活，我深刻认识到，传承延安精神重在践行、贵在坚持。今后，我将以革命先辈为榜样，坚定理想信念，筑牢思想根基，树立正确的世界观、人生观、价值观，坚定不移听党话、跟党走；秉持实事求是，勤学笃行实干，脚踏实地钻研知识、锤炼本领，求真务实、戒骄戒躁；传承艰苦奋斗作风，克服学习生活中的困难挫折，拒绝安逸享乐，主动磨砺自我；厚植家国情怀，勇担青年使命，将个人理想融入国家发展、民族复兴伟业。
2025级本科生 倪楚扬
此次全方位、沉浸式的延安研学，让我跳出碎片化认知，对延安精神的丰富内涵与时代价值形成了系统、立体、深刻的认知。回望峥嵘岁月，重温革命历史，从来不是为了沉湎过往、追忆苦难，而是为了从百年党史、延安岁月中汲取精神养分、凝聚奋进力量，以革命精神指引当下、赋能未来。对比革命先辈们食不果腹、居无定所、浴血奋战的艰难处境，我们新时代青年生长在山河无恙、国泰民安、物质富足的新时代，更应当知来之不易、懂感恩奋进，坚决摒弃安逸享乐、懈怠躺平的消极心态，始终传承坚守艰苦奋斗的优良底色。
