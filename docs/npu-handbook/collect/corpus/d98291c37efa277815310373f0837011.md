# 后勤部办公室党支部开展“光影铸魂强党性 以史为鉴启新程”主题观影活动

为深化爱国主义教育，弘扬伟大民族精神，引导广大党员铭记历史、缅怀先烈、珍爱和平，10月11日下午，后勤部办公室党支部组织全体党员开展“光影铸魂强党性 以史为鉴启新程”主题观影活动，集中观看爱国主义教育影片《志愿军：浴血和平》。
影片《志愿军：浴血和平》作为系列终章，聚焦抗美援朝战争第五次战役后至停战协定签署的“边打边谈”阶段展开。通过上甘岭战役的炮火硝烟与板门店谈判桌的智慧博弈双线叙事，生动还原了志愿军战士以血肉之躯筑牢钢铁防线、以坚定信念捍卫国家尊严的壮烈场景。银幕上，志愿军将士为守护和平浴血奋战的身影，使党员们深刻体会到和平年代美好生活的来之不易，被影片传递的信仰力量与牺牲精神深深触动。
观影结束后，大家一致认为，此次活动既是一次深刻的爱国主义教育，更是对抗美援朝战争中英勇牺牲的志愿军将士们的深切缅怀。党员们表示，将把影片传递的精神力量融入工作日常，用扎实作风践行后勤人的初心使命，坚定地将革命先辈精神转化为为师生办实事的工作动力，努力为实现学校“一十百千”发展目标贡献后勤力量。（撰稿人：毛淑兰；审稿人：韩争胜）
