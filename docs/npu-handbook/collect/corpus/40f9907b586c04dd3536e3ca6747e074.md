# 2025年清明节假期安全温馨提示

清明节即将来临，祭扫、焚香、踏青等活动频繁，为了您和家人度过一个平安祥和的假期，在此特别提醒您注意以下安全事项：
1.树立文明祭扫观念，倡导用植树、献花等方式祭奠。严禁在教学区内进行祭祀活动。祭祀焚香烧纸时请远离住宅、燃气管道等区域，不得占用、堵塞安全出口及消防通道。
2.居民居家期间注意用火、用电、用气安全。明火必须远离可燃物，开火做饭时切勿离开；养成“三清三关”的良好习惯，即清走道、清阳台、清厨房、关火源、关电源、关气源。需特别注意对家中老人、孩子关于用火、用电、用气的安全引导，教育孩子不玩火。
3.假期留校学生要严格遵守学校安全管理制度，严禁在学生宿舍等场所使用电磁炉、电熨斗、电饭锅等违禁电器，严禁私拉乱接电线；做实验时严格遵守相关管理规定和操作流程。
4.定期检查电器设备、线路及燃气设备、管道，如老化、破损需及时维修或更换。严禁在宿舍、教学楼、图书馆等人员密集场所内吸烟，室外吸烟后要及时熄灭烟头。
5.校园内外均请注意遵守交通规则，文明安全出行。外出时留意天气变化，不到危险区域游玩逗留，注意避免溺水。提高自我防范意识，防范各类诈骗，确保人身及财产安全。
