# 西北工业大学2025级会计学（ACCA方向）专业拟录取名单公示

经过认真筛选和严格面试，管理学院确定了2025级会计学（ACCA方向）专业拟录取学生名单(具体名单见附件)，现予以公示，公示期为2025 年8月20日至8月22日。
公示期间，学生如有疑问可向学院反映。公示结束后涉及转学院的同学需向所在学院提出申请并获批准。所有拟录取同学在开学报到期间携带本人校园卡、身份证，前往管理学院217报到办理相关手续。
特此公示。
联系方式：管理学院本科生教学办公室029-88431783
西北工业大学管理学院
2025年8月20日
