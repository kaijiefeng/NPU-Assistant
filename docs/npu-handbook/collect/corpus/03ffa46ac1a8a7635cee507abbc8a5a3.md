# 2025-2026学年夏季学期选课通知

各教学单位，各位同学：
现将2025-2026学年夏季学期选课安排通知如下：
一、选课安排
1.7月1日（14:00）至7月4日（10:00）在“翱翔教务”通过直选方式选课。
2.2023-2025级及2022级建筑学在校本科生可选暑期国际学堂课程、专业选修课程、素养类及学科拓展类课程、实践实训课程等。
3.在校研究生可选暑期国际学堂课程。
二、注意事项
1.选课前请登录翱翔教务，通过“公共服务—全校开课查询”查看课程安排，合理规划个人修读计划。
2.夏季学期课程仅受理一般退课。
3.课表中未显示时间、地点的课程（如生产实习、科研训练等），须联系开课单位或任课教师了解课程安排。
4.暑期国际学堂课程的课程代码最后一位为“S”。
5.选课操作指南详见附件。
三、联系方式
联系电话：029-88430931、88430930。
咨询地点：教学东楼C座203、204室。
（文字：姚鹏、郑波；审核：王劲）
