# 公务卡业务办理指南

一、公务卡办理范围
公务卡是指中央预算单位工作人员持有的，主要用于日常公务支出和财务报销业务的信用卡。
办理范围：学校在编在岗的正式教职工、博士后、非编在岗员工因公办理（非编人员需提供办理公务卡申请）。
二、公务卡强制结算目录
包括办公费、印刷费、咨询费、手续费、水电费、邮电费、物业管理费、差旅费、维修（护）费、租赁费、会议费、培训费、公务接待费、专用材料费、公务用车运行维护费、其他交通费用等16项。
三、公务卡办理流程
1.本人申请：本人携带身份证原件及身份证复印件（正反面复印在一页上，边框底纹清晰），在财务处现场填制“公务卡申请表”、工商银行告知书，并现场拍照。
2.财务处审核:申请表填写是否规范、材料是否齐全。
3.工商银行审核：财务处将申请材料送至工商银行审核，审核通过后交银行制卡中心制卡。
4.领取公务卡：公务卡办理完毕后，由工商银行通知申请人领取。
5.绑定信息：申请人领取公务卡后，致电财务处88460321，登记公务卡信息并绑定。
四、公务卡额度调整
副高级职称及以上职工信用额度为5万元，其他员工信用额度为3万元。因职称或职务变动需调整额度的，在财务处网站下载并填写《预算单位公务卡调整信用额度申请表》，携带收入证明（人事处开具）及身份证复印件（正反面复印在一页上，边框底纹清晰），由财务处统一提交银行办理。

六、公务卡丢失及销户
1.公务卡丢失：由本人到工商银行申请补办公务卡或拨打工行服务热线95588，根据语音提示进行挂失、补卡，并及时将新公务卡相关信息通知财务处银行联络员岗，电话：88460321。
2.公务卡销户：教职工离职或退休，由本人到工商银行办理公务卡销户手续，并将银行销卡回执交学校勇字楼114室，电话：88460243。
七、公务卡到期换卡
公务卡到有效期限银行会自动更换新卡，本人持旧卡及身份证原件到工商银行领取新卡。
