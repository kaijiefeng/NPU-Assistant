# 力学与土木建筑学院举办青年教师发展论坛—学术研讨第二期

2022年12月7日上午，力学与土木建筑学院青年教师发展论坛——学术研讨第二期，在学院206会议室召开。本次青年教师发展中心邀请学院李明教授，针对自身近期学术研究进展进行分享交流。近10名青年教师参加了此次学术研讨活动。
李明教授做了“下一代超临界电厂焊接部件多尺度强度寿命评估”的报告，细致介绍了大型汽轮机组管路焊接部件的热机械疲劳、焊接接头力学性能测试及焊接试验件疲劳强度测试等相关研究，最终对此研究领域进行展望。参会的每个人员围绕此报告相关领域进行了观点分享和热烈讨论，整个讲座时长近2个小时。
学院青年教师发展中心致力于通过定期的学术研讨活动为广大研究学者搭建科研学术交流平台，积极营造交叉、创新、融合、互鉴的学术氛围，为高层次人才培养和高水平科研成果产出提供有力支撑。
