# 关于张贴博士研究生学位论文答辩公告的通知-西北工业大学研究生院

为提高博士答辩的公开透明度，加强学术交流，接受公众监督，我校博士研究生学位论文答辩公告一直采用研究生院官网专栏公布和线下张贴答辩公告的方式进行。近日，研究生院重新对博士研究生学位论文答辩公告进行了设计，现将公告制作、领取和张贴的相关事宜通知如下：
1.公告的制作
公告由研究生院统一制作，彩色喷印。答辩秘书应在答辩前7日，将答辩信息（见附件）发送至指定邮箱15353582065@qq.com。
2.公告的领取
（1）时间：答辩前5日。
（2）地点：
友谊校区爱生楼西北角翱翔印务打印店，联系电话13060425201。
长安校区大学生超市旁翱翔印务强文店，联系电话13572231576。
（3）领取人：答辩人或答辩秘书，凭本人身份证或一卡通领取。
（4）张数：1张。
3.公告的张贴
公告应于答辩前3日张贴完毕，地点为培养单位信息公告栏。
博士研究生可根据情况，自愿进行公告张贴。
研究生院学位办
2023年5月29日
