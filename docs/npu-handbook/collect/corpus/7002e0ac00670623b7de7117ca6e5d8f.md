# 西北工业大学-重庆市中学教育论坛成功举办

为加强西北工业大学与重庆市各中学的交流与合作，探讨中学-大学贯通培养模式与思路，提升人才培养质量，2024年5月11日“西北工业大学-重庆市中学教育论坛”在重庆市成功举办。本次论坛邀请重庆市40所中学领导参会，重庆市教育考试院副院长边勃、高考处处长陈伟、副处长王青霞，西北工业大学党委副书记、副校长詹浩，招生办公室主任王克勤，对外联络办公室主任、校友会秘书长杨铭，航空学院党委书记于辉，伦敦玛丽女王大学工程学院院长范晓丽，数学与统计学院党委书记王莉，西北工业大学附属中学年级组长王兴卫，西北工业大学澳洲校友会会长陈代勇，招生办公室副主任马婷婷，对外联络办公室副主任苟兴旺，招生办公室、重庆市校友会、数学与统计学院、重庆招生组相关负责成员等80余人共同参会，论坛由王莉主持。
詹浩代表学校对参加论坛的老师们表示热烈欢迎。他表示，希望借助此次论坛，进一步交流和探讨大学教育与中学教育紧密衔接的有效机制，共同推动拔尖创新人才培养，更好地实现为党育人，为国育才的神圣使命。
王克勤汇报了西北工业大学概况和在渝招生政策，边勃介绍了重庆市高考综合改革情况，王兴卫分享了西工大附中尖子生培养方案与具体做法。
随后，主题为“中学-大学贯通培养模式与思路”、“拔尖人才培养的思考与实践”的交流研讨在两个分会场分别举行。中学领导分享了各自学校的宝贵经验和有效做法，就当前存在的问题进行积极探讨，现场气氛活跃，研讨热烈。中学领导纷纷表示，希望西北工业大学通过研学、科普报告等活动，进一步加强与重庆市中学的交流合作，激发学生为国铸剑的爱国情怀。
在分享环节，重庆市荣昌中学校校友、航空学院党委书记于辉分享了重庆人在西工大的成长发展之路。
5月12日上午，还举办了“2024年西北工业大学重庆市高中家长见面会”。招生办公室副主任马婷婷、教育实验学院副院长蔡力、航海学院教授闫永胜、西北工业大学伦敦玛丽女王大学工程学院院长范晓丽分别进行学校、学院情况介绍和招生政策解读，随后进行交流咨询，吸引了线下200余位、线上6000余位家长参与。
本次论坛有效加强了我校与重庆市生源中学、重庆市家长的交流与联系，招生办公室和数学与统计学院将以此为契机，锚定“127”目标，发扬招生工作“四千精神”，讲好西工大故事，做好顶层设计，落细具体举措，为支撑学校“总师”型人才培养和“天下工大、世界三航”的远景目标而努力奋斗！（文：南剑波/图：南剑波、周成松/审核人：郭千桥）
