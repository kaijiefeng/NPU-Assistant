# 西安科技大学人工智能与计算机学院来院调研本科人才培养方案

5月11日，西安科技大学人工智能与计算机学院副院长马天率各系主任、副主任一行到访西北工业大学人工智能学院，围绕本科人才培养方案开展专题调研交流。人工智能学院副院长夏勇及学院本科教学办公室相关工作人员参加座谈。
座谈会上，夏勇代表学院对马天副院长一行的到来表示热烈欢迎，并简要介绍了西工大人工智能学院的发展历程、专业设置、师资队伍及学校人工智能专业本科生的培养情况。马天也分享了西安科技大学人工智能与计算机学院的基本情况、办学特色及专业建设现状。
双方聚焦本科人才培养方案的核心要素展开深入讨论。在课程设置方面，两院就如何构建通识教育、学科基础、专业核心与实践创新相结合的课程体系交换了意见，探讨了前沿技术课程与传统课程的比例分配问题。在学分设置环节，双方围绕总学分控制、必修与选修学分比重、实践教学学分要求等具体指标进行了细致交流。
双方一致认为，人工智能领域发展迅猛，本科人才培养方案需紧跟技术前沿和产业需求，不断优化课程结构与学分配置，强化学生实践能力和创新思维训练。通过此次调研，两院进一步加深了了解，为今后在课程共建、教学资源共享及培养方案协同修订等方面开展更广泛的合作奠定了良好基础。
