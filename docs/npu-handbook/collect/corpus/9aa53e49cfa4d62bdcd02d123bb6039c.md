# 莫航学院开展新生交通安全必修课

为扎实做好新生日常交通安全专题教育，9月17日下午，莫航学院联动西安公安交管支队法宣大队，邀请交管碑林大队、交管高新大队面向学院2026级298名新生进行日常交通安全专题授课。学院党委书记向丹主持活动。
首先，交管碑林大队、拥有18年以上公安交管岗位工作经验的刘潇泽民警以“法润平安 文明相伴”为题，重点围绕电动自行车骑行安全开展介绍宣讲，系统讲解了电动自行车新标准、骑行佩戴头盔的必要性以及醉酒驾驶电动车的安全隐患，并结合交通事故真实案例以案说法，普及道路交通安全法律法规，引导同学们在日常行车中知敬畏、守交规，切实守护自身生命安全和身体健康。
授课中，刘潇泽民警邀请同学们开展酒驾眼镜体验，直观感受酒驾状态下视线模糊、判断失准的危险场景。同学们踊跃参与、积极互动问题，在亲身感受与思考交流中深刻认识酒后驾车等交通违法行为的严重危害，进一步筑牢交通安全思想防线。
随后，交管高新大队、长期从事一线交通管理工作岗位民警聂勇以“文明交通，礼行天下”为主题开展宣讲。他结合自身在城郊农村地区和企业园区的一线交管经历，详细介绍了西北工业大学长安校区周边道路交通环境和特点。聂勇细致讲解了常见的交通风险，重点剖析了大货车视野盲区以及乘坐无运营资质车辆的安全隐患。通过发人深省的真实交通安全事故案例，让同学们切身感受到交通违法行为带来的巨大危害，警示效果强烈。聂勇民警勉励同学们在勤学奋进的同时，争做文明交通的参与者、城市平安的守护者。
本次交通安全授课进一步夯实了校园安全教育工作基础。下一步，学院将常态化开展安全教育系列活动，引导全体学生时刻绷紧安全之弦，真正将交通安全意识内化于心、外化于行，切实筑牢个人学习生活的平安健康防线，着力营造安全、有序、和谐的校园学习生活环境。
