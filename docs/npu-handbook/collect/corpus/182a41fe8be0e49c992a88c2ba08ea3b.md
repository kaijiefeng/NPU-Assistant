# 学校召开2027年全国硕士研究生招生考试自命题工作布置会-西北工业大学研究生院

10月22日下午，学校召开2027年全国硕士研究生招生考试自命题工作布置会。党委常委、副校长王伶参加，会议由研究生院院长朱继宏主持。
会议围绕2027年研究生招生考试和自命题工作进行全面部署和详细安排，进一步统一思想、凝心聚力。
会议要求，各招生单位要深刻认识研究生招生考试工作的重要性、复杂性和敏感性，筑牢命题防线，严格安全管理，强化红线意识，压实主体责任，全力以赴做好各项工作。
会议强调，各招生单位要提高政治站位，把牢正确方向，严守招生考试纪律，用追求极致、追求卓越的工作作风，扎实做好2027年研招考试工作；要强化底线思维，严格落实国家教育考试安全保密规定和考务管理要求，确保安全保密工作规范有序，万无一失；要压紧压实全链条责任，扛牢使命担当，把控好命题用人关、过程关、质量关，严格落实政策要求，确保自命题工作安全平稳。
各招生单位主要负责同志、分管研究生教育工作的负责同志，纪检监察机构有关负责同志，全体教学秘书及研究生院相关人员参加会议。
（文/梁维琦 张扬 审核/王会）
