# 机电学院关于学生实习期间请假的说明

近年来，部分学生因参加各种活动或学科竞赛，无法参加本专业组织的实习实践环节，为对实习实践教学环节规范管理，特向机电学院本科生作如下说明：
1.参加学校统一组织活动的学生，需持相关部门出具的活动安排证明，向学生所在专业负责人和实习队长办理请假手续，审批后报送学生所在学院本科教学管理办公室留存。这部分学生的实习成绩由活动组织方给出，经学生所在专业的专业负责人和实习带队教师认定后录入教务系统。
2.参加各类学科竞赛的学生，需持各竞赛基地或竞赛参赛队指导教师出具的参赛/备赛证明（证明需由基地或竞赛指导教师签字）向所在专业实习带队老师办理请假手续。这部分学生的实习成绩由竞赛基地或竞赛参赛队指导教师依照《西北工业大学大学生学科竞赛管理办法》给出，通过如下途径进行成绩转换：竞赛结束两周内，由竞赛基地或竞赛参赛队指导教师下载填写“西北工业大学本科生课程成绩变更申请表”，上交至机电学院本科教学管理办公室，由教务部统一处理或者交由学生所选课的实习队带队老师进行录入。
3.生产实习队伍要提前与实习单位确定具体实习人数以及购买保险等准备事宜，符合以上两种情况的学生需提前至少15个工作日办理相关请假手续；若学生所在专业有其他实习顶相关要求，例如包括但不限于：提交活动总结、竞赛训练或参赛总结等等，学生需提前与实习带队老师沟通并遵守执行。
4.未尽事宜，咨询机电学院本科教学管理办公室（航空楼B425）029-88491445，王老师。
