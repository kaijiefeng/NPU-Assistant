# 东北大学软件学院与我校软件学院交流研讨会顺利召开

2025年1月16日，东北大学软件学院副院长郭军一行7人到访软件学院。此次访问旨在围绕特色化示范性软件学院建设，就人才培养、校企合作等核心议题展开深入交流与探讨。软件学院副院长马春燕、3位课程组组长以及本、研教学秘书参加了此次会议，会议由马春燕主持。
马春燕首先对东北大学软件学院代表团的到来表示热烈欢迎，并全面、系统地介绍了学院在人才培养、课程资源建设及校企合作等方面的最新进展与显著成效。她强调，学院近年来基于“厚基础、高认知、国际化、复合型、创新型”培养理念，立足“专业精、系统强、重实践”，建设“软中有工、‘软’‘工’融合”的双融合课程体系，构建“院院协同、校企联合”的双协同的人才培养模式，建立“复合交叉、自主创新”双特征的大型工业软件人才评价机制。
郭军分享了东北大学软件学院在教育教学、技术融合及课程实践平台建设等方面的创新举措与成功经验。他特别提到，学院正积极运用数字人技术辅助教学，为师生提供多元化、沉浸式的学习体验。郭军表示，东北大学软件学院同样致力于探索高校人才培养的新模式，并期待两个学院在多方面加强交流与合作，共同推动新工科交叉复合型高质量人才培养。
随后，双方分别介绍了各自学院的软件工程专业培养方案，并就课程设置、实践教学、学生创新能力培养及校企合作模式等关键议题展开了热烈而深入的讨论。
在进一步的深入交流中，双方一致表示，将充分利用此次交流的机会，进一步加强沟通与协作，携手并进，共同推动软件工程教育的创新与发展，为培养更多高素质的软件工程人才贡献力量。
会议最后，马春燕再次对郭军一行的到来表示感谢。她表示，愿以此次会议为契机，在课程资源建设、教学研究项目、人才培养等方面探索共建、共用、共享的新模式，共同推动特色化示范性软件学院的建设与发展。
（撰稿：张桐 蔡康英 审核：马春燕）
