# 祝贺！10位博士生导师、18位硕士生导师上岗——航海学院召开2023年新认定研究生导师岗前谈话会

为进一步加强学院师德学风建设，提高研究生导师的责任意识，按照研究生院的总体工作安排，航海学院于2023年10月11日召开新认定研究生导师岗前谈话会。航海学院院长潘光、党委书记孙华强、副院长曾向阳以及2023年新认定的10位博士生导师、18位硕士生导师参加了会议。会议由曾向阳主持。
会议伊始，曾向阳领学了《西北工业大学研究生导师岗前谈话工作办法》等研究生导师相关文件精神。他强调，导师要切实增强岗位意识，遵循研究生教育规律，做好研究生成长成才的知心人、热心人、引路人。
接着，孙华强就导师在政治素质、师德师风、业务素质等方面提出要求：导师不仅要提高研究生科研水平，更重要的是要培养学生的社会责任、科学道德和社会良知。“关爱学生是师德的灵魂。”他强调应加强学生心理疏导、提供个性化指导，让思想的力量静水流深，让爱与责任孕育芬芳。
育栋梁之才，铸国之重器。随后，潘光就“如何做一名好导师”发言交流。他说，导师要增强研究生教育的荣誉感和使命感，严格要求自我，树立大局观念，“个人的师德师风、治学态度、言传身教都会潜移默化地影响学生做人、做事、做学问的方式，影响学生的人生观、价值观、世界观。”他表示，作为导师理应助力学生树立远大目标，志存高远方能登高望远。潘光还强调，导师要不断增强自身学术水平和育人能力，瞄准国际科技前沿和国家重大需求；结合团队特点，将研究生导师第一责任人制和团队集中培养有机融合。
教师涵养育人智慧，学生才能开启智慧大门、精神丰满富足、个性才华充分彰显。与会新认定研究生导师纷纷表示，当牢记习近平总书记的嘱托，牢记立德树人根本任务，躬身践行教育家精神，学习优秀教育家的育人智慧，与日俱进增强自身的本领，用自己的智慧培育出一代又一代担当民族复兴大任的时代新人。
会议最后，潘光、孙华强与新认定研究生导师签署岗位责任书，并向所有新认定研究生导师颁发聘书。
学院全体研究生导师将始终牢记习近平总书记的殷殷嘱托，牢记为党育人、为国育才使命，积极探索新时代教育教学方法，不断提升教书育人本领，为培养更多“总师型”人才作出新的贡献，为学校、学院的“双一流”建设贡献智慧和力量。
