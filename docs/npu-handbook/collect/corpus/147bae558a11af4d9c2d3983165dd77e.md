# 重庆科创中心党支部组织开展《夺冠》、《金刚川》观影活动

为贯彻落实学校新时代爱国主义教育方案和四史教育方案，不断深入推进“不忘初心、牢记使命”主题教育，丰富学习教育形式，加强党员党性锻炼和爱国主义教育，深化其责任感和使命感。自11月以来，重庆科创中心党支部组织全体党员、员工和入驻团队教师集中观看了《夺冠》和《金刚川》两部影片。
《夺冠》影片讲述了几代中国女排人的奋斗历程以及她们顽强拼搏、为国争光的感人故事。影片从上个世纪八十年代的中日女排对决讲起，自女排在日本夺得了第一个世界杯冠军，此后一发不可收拾，不断在国际赛场上取得好成绩，开创了女排十连冠的伟业。影片充分体现了中国女排“祖国至上、团结协作、顽强拼搏、永不言败”精神的延续和传承。
《金刚川》影片故事背景发生在1953年7月的“金城战役”，是抗美援朝的最后一战。讲述志愿军战士们在敌我力量悬殊的情况下，以血肉之躯顽强拼搏的英勇事迹。这种奋不顾身、不惧牺牲的大无畏精神，也从侧面展现出我志愿军将士坚韧顽强、机智勇猛的战斗作风和中华民族不畏强暴、维护和平的责任担当。回望历史正是中国人民志愿军不畏强敌、不怕牺牲的英勇斗争，为新中国的和平与发展奠定了坚实的历史基础。
两部爱国主义题材的影视，让大家不但深刻的感受到了“女排精神新的时代内涵是她们在赛场上展现了祖国至上、团结协作、顽强拼搏、永不言败的精神面貌”，也深刻的感受到了习近平总书记在纪念抗美援朝70周年讲话中提到的伟大的抗美援朝精神的内涵“不畏艰难困苦、始终保持高昂士气的革命乐观主义精神，英勇顽强、舍生忘死的革命英雄主义精神，为完成祖国和人民赋予的使命、慷慨奉献自己一切的革命忠诚精神”。此次观影党员和职工们坚定了理想信念，纷纷表示在今后的工作中将不畏艰难勇往直前，用实际行动践行党员的初心和使命，为实现校地产学研深度融合和学校“双一流”建设贡献力量。
