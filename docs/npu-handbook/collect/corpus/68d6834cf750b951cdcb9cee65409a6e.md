# 关于第十五届中国创新创业大赛—重型装备智能制造专业赛参赛项目征集的通知-西北工业大学资产经营管理有限公司

各科研团队，成果转化企业：
为推动科技创新和产业创新深度融合发展，强化企业科技创新主体地位，推动创新资源向企业集聚，支持高新技术企业和科技型中小企业发展，“第十五届中国创新创业大赛—重型装备智能制造专业赛”（以下简称“大赛”）将于11月25日至27日在齐齐哈尔市举办，现将有关要求通知如下：
一、参赛范围及对象条件
（一）参赛范围
面向冶金、能源、轨道交通、工业母机、矿山、工程机械等各类重型装备产业，涵盖研发设计、先进工艺研发、铸锻成型、材料应用、热处理工艺、生产制造、运维服务、改造升级、技术攻关等环节，覆盖重型装备智能化升级、核心功能部件国产化、工业软件、工业互联网与人工智能应用、数字孪生、生产制造数字化、智能检测、智能运维服务、绿色低碳制造等全链条方向。
（二）参赛对象主要条件
参赛对象分团队组和企业组：
1.团队组参赛条件
（1）团队组应具有较强的创新能力和转化潜力，拥有科技创新成果和创业计划的团队。包括但不限于：高校及科研院所师生团队、海外归国项目、企业内部孵化项目、产学研联合创新项目、独立创业团队等。
（2）参赛项目中的产品、技术及相关知识产权归属团队核心成员，与其他单位或个人无知识产权纠纷。
（3）鼓励携带已授权专利、软件著作权、成果鉴定证书等创新成果参赛。
2.企业组参赛条件
高校师生以技术入股或全职创业方式已注册成立企业的，可报名企业组参赛。企业应为在中国境内依法注册的非上市企业，具有独立法人资格，经营规范、社会信誉良好。
二、报名须知
（一）团队组报名
1.报名资料
（1）《第十五届中国创新创业大赛重型装备智能制造专业赛（团队组）报名表》（附件1）。
（2）其他相关资料，包括但不限于路演PPT、图片、视频、音频等（禁止使用AI）。
2.报名邮箱及截止日期
（1）报名邮箱：qqhrcxcyds@163.com
（2）报名时间：即日—10月30日
3.提交方式
将报名资料打包成压缩文件并以“团队名称+项目名称”命名发送至报名邮箱。
（二）企业组报名
1.报名通道：登录“中国创新创业大赛官网”—重型装备智能制造专业赛报名端口—点击“我要报名”，按要求填写和提交相关资料。
2.官网链接：http://www.cxcyds.com
参赛团队及企业在报名成功后将《第十五届中国创新创业大赛—重型装备智能制造专业赛信息统计表》（附件2）发送至yin_li2025@163.com，以便学校后期统一组织安排。
三、赛事安排
（一）资格审核：11月上旬
（二）初赛安排
初赛时间：11月中旬（拟定）
初赛方式：线上路演答辩
（三）决赛安排
决赛时间：11月25日—27日
决赛地点：齐齐哈尔高新智谷
决赛方式：线下路演答辩
赛事详细信息，可登录“中国创新创业大赛官网”—重型装 备智能制造专业赛页面全面了解。
四、奖项设置
赛事设企业组和团队组两个组别，分别评选一等奖各1名、二等奖各2名、三等奖各3名、优秀奖若干。获奖团队将获得大赛统一颁发的国家级赛事证书和奖金。
