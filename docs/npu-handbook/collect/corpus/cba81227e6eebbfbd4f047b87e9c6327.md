# 生命科学与技术学院开展“深入践行习近平生态文明思想”主题党日活动

10月21日，西北工业大学生命科学与技术学院组织师生党员走进陕西省航天育种工程技术研究中心地面选育基地和长安区五台街道西尧村，开展“深入践行习近平生态文明思想”系列主题党日活动。此次活动将理论学习与田间实践相结合，把专题党课搬到乡村一线，引导师生党员在科技创新中感悟绿色发展理念，在基层实践中深化生态文明认识，在学思践悟中凝聚科技报国力量。
航天育种“科技田”里探寻绿色发展新路径
科技创新是推动生态文明建设和乡村振兴的重要力量。活动首站，师生党员来到陕西省航天育种工程技术研究中心地面选育基地，近距离感受现代农业科技创新成果。在基地袁中权老师的带领下，师生们走进田间地头，实地参观基地种植的各类作物，了解航天育种科研成果及地面选育实践。从航天科技的创新探索到田间作物的生长实践，一株株作物成为生动的教学素材，让师生们更加直观地认识到科技创新对现代农业的重要支撑。
新时代“美丽乡村”里感悟党建引领乡村建设新成效
从航天育种的科技田走向乡村治理的实践场，师生党员随后与西安文理学院生物与环境工程学院的党员师生一起来到秦岭脚下的五台街道西尧村，在长安区五台街道相关领导和工作人员的带领下了解当地新农村建设成效。
五台街道党工委书记康鑫向师生们介绍了辖区生态资源、基层党建和乡村发展情况，重点讲解了当地依托秦岭生态资源发展绿色产业、推进人居环境整治等工作举措。师生们实地察看村庄生态治理点位与产业阵地，围绕生态保护、产业升级和校地合作等内容深入交流，切身感受党建引领下乡村生态振兴与绿色发展的实践成效。康鑫表示欢迎学院师生经常来此开展成果转化和交流实践活动。
秦岭脚下“生态文明思政课”里凝聚科技报国奋进力量
实地观摩交流之后，学院党委书记段利兵在西尧村村委会的活动室以《深入践行习近平生态文明思想》为题，现场为师生党员讲授了一堂内容生动的生态文明思政课。
段利兵紧密结合秦岭生态环境保护实际，通过深入解读习近平生态文明思想的理论内涵与实践要求，引导师生党员深刻认识生态文明建设的重要意义，并能从身边的小事做起，进一步思考如何将专业学习、科研创新与国家生态文明建设需求相结合，进一步强化立足生态修复与生命科学专业优势、服务绿色发展的责任感和使命感。
