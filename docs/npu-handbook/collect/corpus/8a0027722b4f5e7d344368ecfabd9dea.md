# 西北工业大学网络空间安全学院开题答辩（武伟）

西北工业大学网络空间安全学院开题答辩（武伟）
一、开题答辩题目：面向智能计算网络的资源优化和安全机制研究
二、开题答辩人：武伟
三、开题答辩时间：2025年1月23日上午10:00
四、开题答辩地点：爱生楼401(友谊校区)
五、开题内容简介：全息通信和智能交互等无线服务的数据和计算密集度越来越高，对全深度感知和实时动态智能决策提出了挑战。要在大规模复杂网络中实现动态快速响应，需要通信资源和算力高效深度的协同。基于此，本课题提出一种新颖的智能计算网络。智能计算网络依托高速、移动、安全、泛在的网络连接，整合网络多层次算力资源，提供数据感知、传输、存储、运算等一体化服务。通过边缘到边缘的交互来感知分布式计算能力和资源位置，然后通过敏捷的无线通信将请求调度到适当的节点进行服务。从用户的角度来看，他们不需要知道确切的服务部署，只需要给出自己的服务需求。智能计算网络根据需求自动找到最优资源，并将服务调度到几个协作边缘节点，这对于负载不平衡和通信拥塞情况尤其有益。而计算节点之间的协作提高了资源利用率和用户体验，进而为用户提供按需、全面的智能化计算服务。本课题拟在智能计算网络架构下统筹边缘节点、云和终端节点之间的通信、计算和网络资源，围绕智能计算网络的高效数字孪生部署、大规模网络下基于数字孪生的最优部署机制、计算需求和算力资源感知的联邦学习、基于区块链的安全联邦学习等开展研究，通过数字孪生、区块链和联邦学习等技术的深度融合，解决算力服务的响应慢、服务方式单一、功耗高、安全隐患等问题，从而为用户提供快速、智能化、低功耗、安全可靠的算力服务。
六、开题答辩人简介
武伟，学号2022100769，1984年12月06日生，网络空间安全学院网络空间安全专业，导师慕德俊教授。
