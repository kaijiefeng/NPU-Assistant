# 架起信息桥梁 铸就科技辉煌 | 通信发展历程及演进讲座顺利举办-集成电路学院（微电子学院）

11月1日下午，由校科协主办，集成电路学院芯未来集成电路科学技术协会承办的“通信发展历程及演进”主题讲座在长安校区教东D1-204开讲。中兴通讯射频资深专家董晶受邀主讲，为在场师生带来一场横跨古今的技术分享，生动展现了中国通信从追赶到引领的奋斗征程。
从烽火狼烟、驿站传书，到莫尔斯电报、贝尔电话，再到香农信息论奠定数字通信基石，讲座开篇梳理了人类通信文明的演进脉络。董晶老师指出，对“连接”的渴望，始终是通信技术迭代的底层动力，而每一次技术突破，都在重塑文明的边界。
最令人动容的是中国通信的破局之路。面对“七国八制”的被动局面，一代代通信人埋头攻坚，在3G时代迎来突围——自主标准TD-SCDMA跻身国际标准。如今，中国4G基站占全球70%，5G九大国际标准中8项由中国牵头，全球设备四强中中国企业占据两席，实现了从跟跑到领跑的跨越。
董晶老师结合科研经历，拆解基站技术的代际演进：从2G机柜式基站，到4G的BBU+RRU分离架构，再到5G的AAU有源天线一体化方案，其背后是射频芯片、GaN器件等核心技术的持续突破，体现了集成电路对通信产业的底层支撑作用。讲座最后，他介绍了5G在智慧城市、远程医疗、智能制造等领域的应用，展望了6G向通感一体化、空天地一体化演进的趋势，并勉励学子勇做科技自立自强的中坚力量。
本次讲座拓展了同学们的行业视野，让大家深刻体会到“科技自立，通信自信”的分量。学院学子将以专业为根基，在科技强国赛道上接续奋进。
