# 卓越巅峰，“羽”你共赴，国家卓越工程师学院首届羽毛球大赛火热来袭！

亲爱的国卓院同学们：
在实验室里，我们是精益求精的未来工程师；在运动场上，我们亦是挥洒汗水的拼搏健儿！为丰富我院学生的课余文化生活，培养团队协作与永不言弃的精神，国家卓越工程师学院首届羽毛球大赛即将拉开帷幕！
这不仅是一场速度与力量的较量，更是一次智慧与技巧的碰撞，期待各位同学们在球场上展现出别样的风采！
活动基本信息：
1.比赛项目
男子单打、女子单打、混合双打，选手可以兼报单双打项目。
2.比赛时间：
海选赛：11月16日13:30；晋级8强
半决赛&决赛：11月23日13:30
3.比赛地点：
东篱菊苑羽毛球场
4.比赛规则：
海选赛：单局决胜，21分制
半决赛&决赛：三局两胜，21分制
注意事项：
1.比赛原则与纪律
坚持“友谊第一，比赛第二”的原则，所有参赛人员须爱护场地设施与比赛器材。裁判应严格履行执裁职责，确保公正；参赛选手须尊重并服从裁判判罚，严禁以任何形式攻击、干扰裁判或对方队员。如有违反，将视情节轻重予以警告、取消比赛资格等处理。
2.时间与签到要求
裁判及参赛选手须提前20分钟到达比赛场地进行签到与热身。比赛正式开始后，迟到超过5分钟者视为自动弃权。
3.装备须知
请参赛选手自备球拍，比赛用球由学院统一提供。为保障安全，请勿携带钥匙、小刀等坚硬锋利物品入场，避免佩戴金属或玻璃饰物。建议佩戴眼镜的选手做好固定防护或使用运动眼镜。请穿着运动服、羽毛球鞋或胶底运动鞋，禁止穿拖鞋、皮鞋等不符合要求的鞋履入场。
4.安全与秩序
参赛队员须为我院学生，且身体健康，无严重病史及不适宜参加体育运动的疾病。赛事期间，因个人隐瞒实际情况（如病史、身体状况等）而造成的一切后果由本人自负。
参赛选手应自觉做好热身运动，量力而行，防止意外受伤。比赛期间请听从工作人员指挥，在指定区域候场或观赛，不得随意进入其他比赛区域，共同维护赛场秩序。
5.特殊情况说明
如遇学校重大安排、场地故障或极端天气等不可抗力因素，学院会对赛程进行调整或推迟，相关通知将通过官方渠道及时发布，请全体参与者保持关注。
奖项设置：
共设男子单打、女子单打、双打三个项目，每项目前三名即为冠军、亚军、季军。
冠军：国卓院定制充电宝一个
亚军：国卓院定制天堂雨伞一把
季军：运动护膝一个
参与奖：凡参与同学均可获得精美手胶一个
报名渠道：
扫码进群并填写报名表
报名截至时间：2025年11月15日18：00。赶快运动起来吧~
