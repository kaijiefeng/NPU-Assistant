# 关于开展西北工业大学2025-2026学年春季学期校园文化活动立项申报工作的通知-青春驿站-共青团西北工业大学委员会

各学院、研究院团委：
为全面落实立德树人根本任务，充分发挥共青团在高校学生思想政治工作中的主力军作用，锚定学校“十五五”发展目标，弘扬“总师育人文化”，持续开展形式多样、健康向上、贴近学生需求的校园文化活动，加快推进“五育融合”体系建设，现就2025-2026学年春季学期校园文化活动立项申报工作通知如下。
一、申报时间
即日起至3月13日
二、申报类型
（一）重点选题
纪念中国工农红军长征胜利90周年。2026年是中国工农红军长征胜利90周年，为深入学习贯彻习近平总书记关于用好红色资源、赓续红色血脉的重要指示精神，弘扬伟大长征精神，策划开展主题宣讲、知识竞赛、征文、红色歌曲咏唱等活动；开展线上主题教育，利用校园媒体矩阵举办主题音视频、微电影大赛等活动。
（二）定向选题
1.思政实践类。以习近平新时代中国特色社会主义思想为指导，聚焦社会实践与基层服务，把握重要时间节点，组织开展理论学习、影像观摩、青年理论宣讲等活动，强化责任担当，厚植家国情怀。
2.学术科技类。以“总师育人文化”为引领，聚焦弘扬科学家精神，打造学术年会、学术沙龙、科创工作坊、学科竞赛等活动，搭建师生互动、朋辈互促的平台，鼓励学生突破思维边界，在学术钻研与科创实践中提升创新能力。
3.体育运动类。聚焦集体荣誉与团队协作，开展体育文化节、趣味运动会、团体挑战赛等兼具竞技性与趣味性的活动，培养学生团队意识、协作能力、拼搏精神和规则意识，在竞技中磨砺意志品质，激发集体荣誉感。
4.文化艺术类。充分发挥美育在育人过程中的重要作用，聚焦以美育人、以文化人，打造非遗工坊、经典诵读、戏剧鉴赏会、摄影比赛等品牌活动，培养学生发现美、感受美、鉴赏美、表现美、创造美的能力，厚植文化自信。
5.知识技能类。聚焦学习能力与个人素养提升，开展知识技能竞赛、辩论与演讲训练营等多样化实训活动，构建“学—练—赛—促”一体化成长体系，帮助学生拓展知识储备，着力培育具有全球视野和深厚家国情怀的新时代青年。
6.志愿环保类。聚焦志愿服务与生态文明建设，开展生态保护文化节、绿植养护创意赛、垃圾分类志愿行、绿色手工展等主题活动，培养环保意识和绿色生活习惯，推动绿色低碳发展，建设美丽中国。
（三）“一院一品”活动 鼓励各学院、研究院团委发挥共青团文化育人优势，以精品活动为载体、品牌化建设为抓手，结合各学院学科特色打造品牌活动。 三、项目安排
（一）申报阶段
1.活动申报
各学院、研究院团委填写《西北工业大学2025-2026学年春季学期校园文化活动立项申报表》（附件1）和《西北工业大学2025-2026学年春季学期校园文化活动意识形态审核意见表》（附件2），有前期成果的活动可随申报表提交往期活动支撑材料。
2.活动评审
学校团委对各学院、研究院团委提交的材料进行初审，对申报项目组织评审，结合现场答辩、推送投票、校园文化活动督察员反馈等情况进行打分，评选出立项活动。
（二）实施阶段
1.规范经费管理。各学院、研究院团委要规范活动预算规划，据实填写经费预算，活动过程中需按照核定报销额度合理分配资金，避免浪费。
2.规范过程记录。各学院、研究院团委要规范活动过程的记录工作，包含留存活动宣传素材、活动现场照片、活动改进措施等。
3.规范组织实施。各学院、研究院团委要规范活动的组织实施，在“团团小文体”小程序按时提交宣传物料，及时更新活动信息，组织活动参与成员签到签退。
（三）结项阶段
1.做好信息录入。活动结束后的三个工作日内，各学院、研究院团委须确定并公布参与人员名单与获奖名单，获奖人数不得超过参与人数的15%，并将相关信息录入“团团小文体”小程序。
2.提交活动材料。活动结束后的三个工作日内，各学院、研究院团委需配合活动督察员完成材料撰写，提供活动目标达成情况、宣传素材、现场照片等，并整理活动宣传品相关报销材料。
3.开展考核评优。学校团委将统一对各类型活动进行考核，通过考核的活动将在共青团年度工作考核中酌情加分及进行报销；未通过考核的活动则在下一年度重新申报，审核通过后方可开展；同一活动连续两年未通过考核，则取消该活动申请认定资格。
四、工作要求
（一）做好顶层设计。各学院、研究院团委要高度重视校园文化活动开展，活动实施要重质量轻数量，鼓励跨院（至多四个）整合特色资源，办出影响面广、教育性强的校园文化活动。
（二）做好活动宣传。各学院、研究院团委要充分利用线上、线下等多种方式做好宣传工作，提高活动有效覆盖面。要持续完善校园文化活动宣传矩阵，注重过程和成果的宣传展示，及时向相关媒体平台投稿。
（三）做好项目管理。各学院、研究院团委在活动开始前一周向主办单位进行活动报备。要提前做好活动应急预案，注重加强过程性指导。活动结束后及时做好成果总结，活动中的评奖评优应秉持公正、公平、公开原则，接受师生监督。
五、提交要求
请各学院、研究院团委于3月13日17:00前将由单位主管领导签字、单位盖章的纸质版申报表报送至长安校区星天苑综合服务大楼“青春驿站”202室校园文化活动中心，[已脱敏:邮箱]，邮箱主题及压缩包命名为“学院/研究院团委名称—校园文化活动申报”。
