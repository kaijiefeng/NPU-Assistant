# 软件学院-西北工业大学医院

责任医师：牛爽（副主任医师）
简介：
神经内科副主任医师，硕士研究生，从事临床工作十余年。曾多次陕西省人民医院进修学习，擅长脑血管病、头晕、偏头痛、认知障碍、高血压、糖尿病、冠心病、心力衰竭等老年病管理及预防具有丰富的临床经验。发表专业论文数篇。
（备注：学院责任医师是医院与学院之间的桥梁，可为我校师生提供健康咨询、健康宣教、体检结果释疑、急救知识技能培训等服务。有需求者，可通过扫描学院责任医师二维码联系。）
