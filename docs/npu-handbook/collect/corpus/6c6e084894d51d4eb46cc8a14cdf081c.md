# 网络空间安全学院开展2023年招生宣传工作

根据学校“双一流”建设总体要求，以提高本科生源质量为核心任务，切实提高招生工作成效，网络空间安全学院组织骨干教师队伍于6月23日至25日分为7组，分别在友谊校区和渭南地区进行高考招生集中咨询工作，并奔赴其他县区重点高中进行招生宣传，为广大考生及家长提供高考招生咨询服务，激励高分生源报考我校。
为保障招生宣传工作成效，学院领导全员参与此项工作，通过广泛动员形成了以学院领导班子、各专业骨干教师、学院办公室人员、热心校友和学生积极参与的良好局面。由学院党总支书记王震负责的第一小组在友谊校区进行集中宣传活动，由常务副院长张盛兵带队的第二小组在渭南市进行集中宣传和走访，骨干教师和学生组队的招生小组则分别于23日至25日在韩城市、富平市、蒲城县、大荔县和合阳县进行集中宣传，重点布局了渭南市高级中学、瑞泉中学、韩城市象山中学、富平县迤山中学、尧山中学、大荔县大荔中学、合阳县合阳中学等，与学校与班主任面对面，与学生及家长面对面。
招生宣传时间正值高考出分期间，已知分数的同学和家长们带着热切的期盼前来咨询。在校园开放日集中宣传和渭南市集中宣传时，宣讲老师们通过电话沟通、现场一对一咨询、高招会、集中宣讲、添加QQ、微信等方式针对高考学生和家长关心问题进行了细致和耐心的讲解，各小组指导考生现场填写高考志愿意向登记表，及时收集学生意愿报考专业信息，在交流过程中综合考虑学生兴趣和高考排名后个性化的推荐报考专业，同时广泛宣传学院学科专业特色。
在各区县重点中学宣讲时，招生团队与学生们亲切交流，耐心解答疑惑，详细介绍了我校、我院的招生计划情况，同时介绍了专业优势、师资力量以及科研成果，让学生们深入了解学院的教学环境和发展前景，引导他们认识到学校的卓越优势和学术潜力。此外，招生团队还积极组织宣讲会，为学生和家长们提对学校更加全面的了解。
学院各招生宣传组顶烈日、战酷暑，圆满完成了2023年招生宣传工作，并与重点高中在未来合作方面达成了共识，为提升我校在渭南地区及周边地区的高考生源数量及质量提供了有力保障。
