# 公共政策与管理学院2026级行政管理专业拔尖班顺利举行开班仪式

为扎实推进拔尖创新人才培养工作，公共政策与管理学院于2026年10月22日在学院楼104报告厅举办2026级行政管理专业拔尖班开班仪式。学院院长刘晨光、副院长原嫄、党委副书记谢丹，公共管理系的专任教师、本科教务和学生工作负责老师以及高年级本科生代表与拔尖班全体同学共同参加。
首先，刘晨光院长向开班仪式致辞。致辞中，刘院长向入选拔尖班的15名同学表示祝贺，并勉励同学们珍惜拔尖班的优质培养平台，厚植公共情怀、夯实专业根基、树立远大理想，找准个人发展方向，努力成长为新时代公共治理领域的优秀后备人才。
随后，参会师生依次进行自我介绍，进一步加强了师生之间的相互了解。2026级行政管理专业拔尖班的15位同学逐一介绍了个人基本情况、兴趣特长与大学阶段的学业规划等；参会老师们详细介绍了自己的授课课程、研究方向等。
在师生自我介绍之后，公共管理系本科专业负责人张琳围绕课程设置、导师制、科研训练、实践项目等内容，解读拔尖班教学培养方案，帮助新生清晰把握本科四年成长体系。执行班主任张晓敏围绕学风建设、集体活动、协同发展等方面，对班级建设思路进行介绍，鼓励同学们勤耕不辍、勇于探索、互助共进，共建优良班风和学风。同时，本次活动邀请2023级行政管理专业学生代表张博苒结合自身经历，从专业学习、科研竞赛、科研入门、社会实践、竞赛参与、时间管理等方面，为新生分享经验，为同学们更好地适应大学生活提供参考。
最后，副院长原嫄作总结讲话，勉励同学们珍惜拔尖班宝贵的培养机会，脚踏实地、勇于担当，在行政管理专业道路上持续求索。
此次开班仪式的圆满举行，标志着2026级行政管理拔尖班人才培养工作正式开启。学院将持续落地拔尖人才培养方案，迭代完善育人体系，为拔尖学子成长成才筑牢保障。
