# 航天学院召开新学期工作布置会传达学校寒假务虚会、新学期干部会精神

3月1日下午，学院召开新学期工作布置会，传达学习学校2026年寒假务虚会、新学期干部会会议精神，研究部署学院有关工作。学院领导班子成员、党委委员、院长助理、各研究所所长和党支部书记，学校翱翔团队和学院创新团队负责人，国家级人才、青年教师代表及学院办公室人员参会。会议由党委书记黄越主持。
会上，黄攀峰院长传达了学校2026年寒假务虚会和新学期中层干部会上李言荣书记、宋保维校长的重要讲话精神以及五位校领导报告的主要内容，结合学校目标任务要求，深入分析了学院当前形势、挑战和不足，对2026年及今后一个阶段的重点工作进行了部署。他指出，2026年是学校“十五五”规划的开局之年，学院要在学校“十五五”规划和“一十百千”指标体系引领下，狠抓落实学院各项指标任务，加强高水平师资队伍建设，有组织推进人才引育特别是海优引进；推进“总师型人才培养”走深走实，推动人工智能赋能人才培养；优化学科布局和科研方向，强化科技创新能力，持续巩固传统科研特色，不断提升基础研究能力水平，强化科技成果转化，推动学校内涵式高质量发展。
参加学校寒假务虚会和新学期中层干部会的部分教师代表分享了学习心得体会。各副职院领导围绕学院各项重点工作进行了细化部署。
黄越传达了中央和学校开展树立和践行正确政绩观学习教育的有关要求精神，并围绕高层次人才引育和提升基础研究能力等重点工作，以及本学期校内巡视整改、筹备学院党代会、安全稳定等方面工作做了部署。她强调，要充分认识做好人才工作和加强基础研究对学院可持续发展的重要意义，学院领导干部、各研究所和团队的负责人要以高标准、严要求，以“时时放心不下”的责任心和“事事心中有底”的行动力狠抓工作落实，确保学院年度目标任务和“十五五”规划指标高质量完成，为学校“双一流”建设和“一十百千”核心发展指标体系的完成贡献力量。
