# 西北工业大学网络空间安全学院开题答辩（夏明赟）

一、开题答辩题目：无人机集群通信网络安全关键技术研究
二、开题答辩人：夏明赟
三、开题答辩时间：2024年1月18日10：00
四、开题答辩地点：中国电子科技集团公司第三十研究所3号楼5楼会议室
五、开题内容简介：
当前，网络空间安全已经上升到国家安全战略，而无人机集群是国家、军事战略的重要技术设施，应用前景广泛，应当高度重视保护其安全。无人机集群通信网络是无人机集群的重要组成部分，实时共享有效准确的飞行数据以及作战指令等信息，如果该网络遭遇网络攻击或者干扰，将导致无人机集群组网通信失败，指令无法准确传输，严重影响安全态势，所以对无人机集群通信网络的安全研究具有重要意义。本研究通过对集群通信通信网络结构分析，从物理、链路、网络等层次开展对其安全脆弱性分析，在此基础上分析灵巧攻击、欺骗攻击、篡改攻击等攻击方法对无人机集群通信网络安全的影响，从而针对性提出对无人机集群通信网络的安全防护手段。
六、开题答辩人简介
夏明赟，学号2021161085，出生于1982年10月，网络空间安全学院电子信息专业，导师：谢瑞云，研究方向：无线网络安全
