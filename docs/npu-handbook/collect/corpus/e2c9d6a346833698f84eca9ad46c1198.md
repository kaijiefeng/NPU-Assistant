# 关于做好2024年度文件归档工作的通知

各单位：
依据《西北工业大学档案管理办法》（办转档案字〔2021〕27号）《西北工业大学归档文件整理规则》文件规定，为确保学校2024年度文件归档工作顺利完成，现将相关要求通知如下：
一、归档范围
1.2024年1月至12月期间，学校党群、行政、教学、科研、基本建设、国有资产、产品生产、出版、外事、财会等各项工作中形成的具有保存价值的文件材料，详细内容参见各单位归档范围。
2.其他往年应归档但尚未归档的文件材料。
二、归档要求
1.各单位兼职档案员要切实履行工作职责，负责本单位文件材料的收集、整理、归档工作，于5月30日前移交学校档案馆。
2.各单位负责本单位拟稿发文的涉密文件归档工作，文件需签章、附件齐全，并按照保密要求进行归档。
3.各单位负责本单位非密自制文和签发单的打印及归档工作。签发单上勾选“依申请公开”和“不予公开”的文件，按照线下文件移交，不提交电子版。其他文件按照公开文件归档，需提交电子版，电子文件以“文件编号”命名，没有“文件编号”以“题名”命名。
4.各单位形成的工作计划、总结、统计报表、规章制度、出版刊物、签订的合作协议、备忘录、重大活动中产生的文件材料（应成套整理）等，须加盖单位公章归档，不提交电子版。
5.各单位负责归档的议事机构会议纪要、议题材料，按照线下文件移交，不提交电子版。
6.各单位作为主责部门负责诉讼与仲裁的案件资料（包括起诉状或答辩状、案件处理方案、证据鉴定、司法文书、总结报告等全部案件资料），按照线下文件移交，不提交电子版。
7.党政办公室负责归档的党委全委会、党委常委会、校长办公会会议记录、纪要、议题材料，按照线下文件移交，不提交电子版。
8.党政办机要室负责2024年度学校外来公文归档工作，并向档案馆提供涉密、非密校发文件清单。
9.各单位归档材料应填写“文件材料移交清单”（附件1），线下文件填写“线下文件材料移交清单”（附件2），涉密文件填写“移交涉密载体受控单”（附件3），声像材料填写“声像档案移交清单”（附件4），证书、奖牌、奖杯等填写“实物档案移交清单”（附件5），并提供附件1、附件2、附件4、附件5电子版，电子版通过E-Mobile发送档案馆相关联系人。
10.请各单位重新填报“档案工作分管领导及兼职档案员情况登记表”（附件6），与归档材料一起归档。
三、联系方式
为做好2024年度文件归档工作，档案馆将提供业务指导服务。请各单位兼职档案员及时与相关工作人员联系归档事宜，确保文件材料“应归尽归、应管尽管”。
档案馆
2025年4月2日
