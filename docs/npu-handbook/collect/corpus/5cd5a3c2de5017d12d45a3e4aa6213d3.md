# 后勤部办公室完成友谊校区北院10kV中心开闭所升级改造

友谊校区北院10kV中心开闭所自2000年投运以来，承担着北院大部分楼宇和南院全部楼宇的供电任务，属于友谊校区配电网络的核心枢纽。经过25年的连续运行，逐步出现了配电柜柜体变形、绝缘件老化、部分功能失效等问题，严重影响友谊校区配电系统的安全可靠运行。为消除老旧设施运行安全隐患，保障供电安全可靠，后勤部办公室组织完成了北院10kV中心开闭所整体升级改造。
为确保改造方案科学合理完善，在项目设计阶段，后勤部办公室在前期考察的基础上，会同设计单位对改造方案进行了多轮研讨，结合现场实际及后续扩容需求确定更换高压柜40面，选用具备状态实时感知、可视化管理、远程智能控制等功能的智能开关柜，并将电缆夹层的梳理整治一并列入改造范围。施工招标完成后，后勤部办公室第一时间组织召开项目启动会，结合学校整体教学工作安排制定项目工期计划。设备生产过程中，安排专人赴生产现场监督检查设备组装流程，确保符合功能需求，同步组织施工单位完成开闭所电缆夹层梳理改造。设备进场前，后勤部办公室提前制定了严密紧凑的设备更新施工计划，为尽量减小临时停电对正常教学科研工作和师生生活的影响，设备更新施工全部安排在夜间进行，同时对部分区域采用应急电源车保障正常供电，并通过在网上发布和楼下张贴的方式将临时停电时间及范围提前告知广大师生住户。自10月27日至11月8日，后勤部办公室动力保障中心与施工单位协作配合，连续奋战13天（期间有5天通宵作业），克服了改造施工与供电保障并行带来的诸多挑战，确保了改造期间校园电网的整体安全稳定运行，按计划顺利完成了开闭所全部设备更新改造。
目前，全新升级的友谊校区北院10kV中心开闭所已投入运行，实现了“标准化无人值守开闭所”的改造目标，有效消除了设备运行安全隐患，极大提升了友谊校区配电网络的安全运行水平，后续将为友谊校区教学科研及师生工作、学习、生活提供更加安全可靠的供电保障。
