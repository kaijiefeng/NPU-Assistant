# 中国科学院院士黄维走进河北衡水中学开展招生宣传-

报考指南
首页-报考指南>宣传动态>
中国科学院院士黄维走进河北衡水中学开展招生宣传
发布日期：2025-04-27
点击数：2720
4月23日，招生办公室、软件学院河北招生组邀请中国科学院院士，西北工业大学学术委员会主任黄维，走进衡水中学开展招生宣传工作。黄院士为上千名衡中师生带来一场题为《在科技强国的道路上砥砺前行“柔性电子”科学之路》的前沿科技盛宴，活动由衡水中学校长郭春雨主持。西北工业大学招生办公室主任王克勤、河北招生组负责人李晗、河北招生组组长陈博陪同参加活动。
讲座中，黄院士以科学家的前瞻性视野，结合自身丰富的科研经历与深厚学识，将技术演进逻辑与国家发展需求紧密结合，从历史纵深追溯柔性电子技术的迭代轨迹，从现实维度展现其在提升生活品质、赋能产业变革中的多元应用。他以翔实的科研案例与数据支撑，从战略高度深度诠释核心技术自主创新对突破“卡脖子”瓶颈的战略意义，特别强调科技创新与文化自信的深层关联，指出科技自立自强不仅是产业升级的动力源，更是筑牢文化根基、增强民族复兴底气的核心支撑。
在互动交流环节，现场气氛热烈非凡。衡水中学的同学们围绕柔性电子领域，踊跃提出极具思考性的问题，提问视角覆盖研究难点、应用前景等多个维度。黄维院士耐心解答，鼓励大家保持对科学的好奇心和探索精神，为科技进步贡献力量。期间，全场多次响起经久不息的掌声。讲座结束后，同学们层层包围院士，追“星”索要签名。
此次讲座不仅拓宽了衡水中学师生们的科学视野，更埋下了无数报考西工大的萌芽种子，激发了同学们投身科研、报效祖国的热情。许多同学表示，黄维院士的讲座点燃了他们心中的科技梦想，今后将努力学习，为我国科技强国建设添砖加瓦。
同日，学校招生办公室主任王克勤赴衡水市第二中学开展招生宣讲活动，并与中学校长进行深度交流。在衡水二中报告厅，王克勤主任面向200余名学生，全面介绍了我校的“总师育人文化”和卓著的人才培养成果以及特色优势学科专业设置和毕业生高质量就业深造等情况，详细解读了近年来在河北省的招生政策与录取情况，互动气氛十分活跃，有效提升了我校在河北优质生源中学的影响力和吸引力。
