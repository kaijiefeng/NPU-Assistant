# 学院举办“我们的节日·元宵节”主题党日活动

时值元宵佳节，为弘扬中华优秀传统文化，3月3日，物理科学与技术学院在星天苑C座“一站式”学生社区组织开展“我们的节日·元宵节”主题党日活动。通过手工体验、党史竞猜、红色观影等形式，将传统文化体验与党史学习教育深度融合。学院师生党员、入党积极分子参加此次活动。
巧手做汤圆·窗花映团圆
在传统手工体验环节，师生们挽起袖子，揉面团、包馅料、剪窗花，一双双巧手捏出圆润饱满的汤圆，剪出寓意吉祥的窗花图案，糯米粉的清香与红纸的艳丽交相辉映。大家在协作中感受传统手艺的温度，体悟团圆祥和的文化内涵，在动手实践中加深了对中华优秀传统文化的理解与认同，进一步增强了文化自信与民族自豪感。
猜谜悟党史·聚力新征程
党史知识竞猜将活动推向高潮。灯谜巧妙融入党史知识、党的二十大精神和校史校情，既有“党的一大召开时间”等基础知识，也有“物理学家励志故事”等学科特色题目，兼具思想性与趣味性。师生们在解谜过程中重温峥嵘岁月，汲取精神滋养。竞猜现场气氛热烈，大家在轻松愉悦的氛围中接受党性教育，实现了知识性与趣味性的有机统一。
光影映理苑·团圆暖元宵
红色观影环节温情开启。师生共同观看经典红色题材影片，在光影交错中感受革命先辈的家国情怀与理想信念。观影结束后，大家围绕影片内容畅谈感悟，结合自身学习科研实际交流心得，纷纷表示要将爱国之情转化为报国之行，以更加饱满的热情投身学习和工作，在新时代新征程中贡献青春力量，书写无愧于时代的青春华章。
此次活动把传统文化与党性教育紧密融合，让师生在沉浸式体验中增强文化自信，凝聚奋进共识。今后，学院将持续深化“三全育人”实践，把传统文化教育融入人才培养全过程，引导青年学子厚植家国情怀、涵养进取品格，在奋进新征程中展现担当作为，为培养堪当民族复兴重任的时代新人贡献力量。
