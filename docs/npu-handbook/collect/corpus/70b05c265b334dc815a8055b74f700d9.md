# 西北工业大学生命科学与技术学院科研成果：鱼肉里的细刺为何有多有少——王堃教授团队合作揭示真骨鱼类肌间刺的形成与演化机制

同样是鱼，为什么有的鱼肉里细刺密布，有的却很少见？这些细刺被称为“肌间刺”。它们给食用和加工带来不便，背后也藏着一个科学问题：一种骨骼结构如何形成，又为何在不同鱼类的演化过程中多次消失？
近日，华中农业大学水产学院、湖北洪山实验室高泽霞教授团队联合西北工业大学生命科学与技术学院王堃教授团队，在《美国国家科学院院刊》（PNAS）发表研究论文，为回答这一问题提供了新证据。
研究团队比较了360种真骨鱼类的肌间刺形态，发现早期分化的鱼类通常拥有更多、更复杂的肌间刺，而多个后起源的类群分别经历了肌间刺简化或消失。肌间刺的保留还与部分鱼类的生境和游泳表现有关，提示这种结构的演化与不同的生态需求相联系。
一根细刺究竟怎样在鱼肉中长出来？团队结合跨物种单细胞分析、组织学观察和功能实验发现，肌间刺形成于肌隔的肌腱区域，需要两类条件共同作用：以runx2b为代表的基因启动成骨程序，mkxa、mkxb等基因则帮助维持肌腱微环境，让前成骨细胞继续成熟。功能实验显示，当这一微环境受损时，成熟成骨细胞明显减少。团队据此提出“成骨启动—肌腱微环境许可”的机制模型，并发现相关基因网络的变化可能参与了不同鱼类肌间刺的独立丢失。
这项研究将肌间刺“从哪里来、为什么会消失”的问题推进到了细胞和基因层面，也为今后研究少刺性状提供了可检验的线索。它同时提示，探索肌间刺性状改良时，还需要关注肌腱的正常发育及其功能。

今年以来，学院“生物多样性基因组学及生物性状仿生利用”翱翔战略团队联合国内外合作者，在生命适应与性状演化研究中取得了一系列进展：深海大王具足虫耐饥饿机制研究发表于《Cell》，瘤胃纤毛虫调控反刍动物甲烷排放的研究发表于《Science》，黑金鲍（彩虹鲍）不对称发育及外套膜功能研究发表于《Science Advances》，深海海葵演化与适应研究发表于《Current Biology》。团队还在今年年初刊载于《The Innovation》的真骨鱼类基因组研究中，与合作者建立了覆盖464种真骨鱼类的全基因组比较资源。从鱼类演化的整体图景，到一根肌间刺的形成机制，这些工作体现了团队将大规模比较基因组资源与细胞、分子功能研究相结合，持续解析生物适应和性状演化机制的研究特色。
