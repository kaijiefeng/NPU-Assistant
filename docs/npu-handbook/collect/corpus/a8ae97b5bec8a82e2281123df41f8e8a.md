# 后勤办公室党支部召开理论学习会

按照机关党委理论学习指导意见要求，9月27日上午，后勤办公室党支部组织全体党员召开理论学习会。会议由党支部书记张文刚主持。
会上，全体党员集中学习了《中办国办印发<关于进一步加强青年科技人才培养和使用的若干措施>》《在文化传承发展座谈会上的讲话》《关于开展2023年“师德师风建设月”活动的通知》等内容，重点学习了李言荣书记在学校学习贯彻习近平新时代中国特色社会主义思想主题教育总结大会上的讲话、宋保维校长在2023年暑期工作研讨会暨新学期干部大会上的讲话精神。
接着，与会党员围绕学习内容，对标学校“127”目标举措的内涵与要求，结合个人工作职责，进行了深入研讨交流。大家一致认为，将持续强化理论学习，深入领会李言荣书记和宋保维校长的讲话精神，在新学期、新征程上，勇于担当作为，将后勤管理与服务师生工作落实落地、见行见效。
最后，张文刚对党员干部提出三点要求：一是持续强化理论学习，在不断对理论知识温故知新的过程中，获取工作新思路、实践新方法；二是继续深化主题教育成果，狠抓工作落实，将主题教育的成果体现在为师生办实事的具体实践中；三是深入理解学校“127”目标举措的内涵与要求，对后勤管理工作下一步“怎么干”进行深入思考，群策群力共同推动后勤管理工作再上新台阶。（撰稿人：毛淑兰，审稿人：韩争胜）
