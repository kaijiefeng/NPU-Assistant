# 姜晓萍教授做客我校翱翔灵犀学术殿堂

11月2日上午，四川大学城市治理研究院院长姜晓萍教应邀做客我校翱翔灵犀学术殿堂，为我校师生做题为《迈进公共管理学科共同体》的学术报告。来自公共政策与管理学院师生八十余人参加报告会，公共政策与管理学院院长刘晨光教授主持报告会。
姜晓萍教授围绕公共管理学科共同体的缘起、概念、内涵、特征、功能和因素等方面进行了深入的分析和讲解，主要回答了“公共管理学科共同体是何？”“公共管理学科共同体如何”“加入公共管理学科共同体何为？”三大问题。她提出公共管理应以行为先、以思为要，既要扎根实践、服务社会，也要胸怀远方、引领时代，以知行合一的实干与担当，书写公管人的使命和责任。
整场报告内容充实、层次分明，既有前沿进展，也有深度思考。在场师生在轻松而富有启发性的讲解中拓宽了学术视野，对公共管理学科共同体的重要性有了更加深刻的认识。
报告结束后，在场师生围绕论文研究选题、如何拓展新领域研究、提升学术标识度等问题踊跃提问。姜晓萍教授逐一细致解答，同时分享了自己的科研心得、从业感悟，鼓励师生扎根中国实践，增强构建中国公共管理学自主知识体系的学术自信，互动环节在师生们的意犹未尽中圆满落幕。
最后，刘晨光作总结发言。他感谢姜晓萍教授为师生带来精彩的学术盛宴，希望师生将学术研究融入国家发展大局，为服务国家重大战略和区域经济社会发展做出自己的贡献。
