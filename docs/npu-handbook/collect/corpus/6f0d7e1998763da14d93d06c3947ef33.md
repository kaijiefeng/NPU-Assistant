# 网络空间安全学院举办“解码AI新未来，守护数字新安全”网安实战化技能培训

当前，Frontier AI技术正以前所未有的速度重塑网络空间安全格局，为行业发展带来新机遇与新挑战。为深入贯彻实战化网络安全人才培养理念，切实提升广大学生的网络安全实战能力与行业视野，把握这一浪潮下的技术趋势与发展机遇，2026年9月6日，网络空间安全学院在长安校区教西D-103成功举办“解码AI新未来，守护数字新安全”实战化培训。本次活动面向全校学生开放，吸引了来自多个学院、不同专业背景的学生积极参与，网络安全拔尖班全体成员、学生信息安全协会全体成员到场聆听学习。
本次讲座特邀绿盟科技能力中心技术总监、智能化攻防与M01NTeam负责人高东，我校2023届校友、M01NTeam核心成员李晓辉作专题分享。讲座由网络空间安全学院院长助理张慧翔主持，学院副院长刘志强出席并致辞。
刘志强在致辞中表示，当前人工智能技术正深刻重构网络安全攻防体系，行业对兼具技术功底与AI应用能力的实战型人才需求日益迫切。学院将企业一线实战资源引入校园，面向全体学生开展实战化培训，旨在帮助不同专业学生了解AI驱动下的网络安全攻防要求，提升实战能力。他希望同学们珍惜机会，在知识学习和实操训练中主动对标行业需求，夯实综合素养。
高东以《Frontier AI时代的网络安全趋势和机遇》为题，结合十余年国家级攻防演练一线实战经验，系统阐释了前沿人工智能对网络安全攻防格局的重塑作用。他指出，Frontier AI的快速发展一方面将漏洞挖掘、攻击编排与社会工程攻击推入“机器速度”时代，大幅降低了攻击门槛；另一方面也驱动检测响应与防御体系向自动化、智能化加速演进。针对模型生态开放性与安全护栏不对称、对齐机制滞后等固有缺陷催生的提示注入、供应链污染、自主智能体逃逸等新型风险，他结合国内外AI安全前沿观察与技术演进脉络进行了深入解读，帮助同学们理解人工智能驱动下的攻防实战新范式，明确AI时代对安全从业者能力提出的全新要求。
李晓辉以《直面网络威胁：构建专属安全分析Copilot》为题，结合自身AI安全研究与多项国家顶尖网安赛事的实战经历，聚焦应急响应一线痛点展开实战化知识培训。针对传统应急响应与木马分析依赖人工逆向、新手学习曲线陡峭等问题，他详细讲解了依托大模型自主构建专属安全分析Copilot的技术路径，让AI化身为安全专家，辅助完成木马分析、行为链梳理、入侵路径溯源等关键环节，并结合实践案例剖析了AI Agent落地过程中的常见陷阱，用生动的实战案例帮助同学们理解如何让人工智能真正赋能网络安全一线攻防，成为主机安全的“副驾驶”。
培训现场交流氛围浓厚，同学们结合培训内容与日常学习中的问题积极提问，两位专家围绕AI安全技术学习路径、攻防能力提升、行业职业发展等问题逐一解答，互动持续热烈。
本次实战化培训是学院深化校企合作、推进人工智能与网络安全深度融合的重要实践，也是面向全体学生开展网络安全实战化培养的重要举措。学院始终以培养卓越“总师型”人才为目标，着力构建“基础、对抗、创新”分层递进实践课程体系，强化“厚基础、强系统、重实战、勇担当”的网络空间安全人才培养体系。下一步，学院将持续深化政校企协同育人模式，扩大实战化培训覆盖面，构建多方深度参与、互利共赢的协同培养长效机制，全面提升网络安全人才培养质量，助力学生成长为网络强国建设的中坚力量。
