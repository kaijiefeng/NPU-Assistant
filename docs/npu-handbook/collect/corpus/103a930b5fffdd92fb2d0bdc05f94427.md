# 网络空间安全学院召开本科教育教学审核评估工作推进会

7月5日，我院本科教育教学审核评估工作推进会在友谊校区爱生楼405召开，党总支书记王震、常务副院长张盛兵、教学副院长刘志强、副院长慕德俊、副书记禹亮，全院教职工线上线下参会。会议由教学副院长刘志强主持。
党总支书记王震强调，全院上下要切实提高政治站位，充分认识审核评估迎评工作的重要性和紧迫性，从落实立德树人这个根本任务出发，切实增强迎评工作的思想自觉和行动自觉，要深刻领会新一轮审核评估的要义，根据审核评估指标内涵确定工作目标，积极思考，真正做到“以评促建、以评促改、以评促管、以评促强”。
教学副院长刘志强围绕学院审核评估工作整体进展、自评报告撰写情况、学院自评自建工作情况以及专家对自评工作意见反馈进行了详细介绍。他提出四点要求，一是要高度重视，提高站位，充分认识审核评估工作的重大意义。此次评估事关学校和学院未来发展，时间紧、任务重，全院上下要将审核评估作为重点工作抓紧抓好，切实增强责任感和使命感，主动作为，变被动迎评为主动作为，全力以赴做好评建工作；二是要认真学习，深入理解审核评估的精神内涵。所有教师要对照指标体系，进一步梳理、强化亮点优势，紧扣评估指标内涵，对各项工作、各类材料进行凝练和打磨，按照工作推进任务清单，从每项工作、每个环节抓起，将工作做细做实；三是要明确工作任务，围绕工作清单、坚持问题导向，扎实推进工作；四是要加强督导检查，对审核评估自评自建过程中发现的问题要及时通报、限期整改、持续改进。
随后全院教师对照审核评估指标体系，围绕本单位自评自建工作开展情况、自评自建反馈以及下一步工作计划等方面进行了交流研讨。
常务副院长张盛兵作部署讲话，新一轮审核评估从教学评估转向教育教学评估，从聚焦教学工作转变为全方位育人的工作。学院高度重视，将以此次审核评估作为促进教育教学改革、推动内涵发展、提升办学水平的重要机遇。学院将持续以审核评估为契机，围绕“质量共同体”，全面落实立德树人根本任务、深化本科教育改革创新，为实现内涵发展、特色发展、创新发展持续发力，为全面提高人才自主培养质量贡献西工大力量。
