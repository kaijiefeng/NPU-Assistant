# 【求职故事】如何与不喜欢的工作牵手

1、交几个职场好友：虽然职场中的朋友无法与闺蜜相提并论，不可能做到掏心掏肺，但不可否认的是，如果你与同事的关系比较和谐，并且能在空闲时间聊天，开玩笑，不自觉中会增加你对工作的喜爱度。这是因为我们每个人都有归属的需要，好的人际关系氛围让我们感到轻松愉快，进而增进对工作的满意度。
2、将好心情与完成工作任务建立联系：工作不要拖延，要先集中时间和精力把工作完成，把休闲放松作为自己完成工作的犒赏，在完成任务之后，就可以尽情地享受放松的心情，渐渐地，对工作的喜爱之情也就油然而生了。
3、为工作注入新鲜刺激：一成不变是很多人对工作生厌的理由，因此，有意识地为工作注入些新鲜刺激，是体验快乐的好方法，只要留心，这些新鲜刺激可以随时创造，比如说，改变办公桌的摆设，更换桌面设置，甚至更换个可爱的笔记本……当然，也可以从工作本身发挥创意，有效避免心理疲劳。
4、写成长日记：最永恒的奖赏不是金钱，也不是权力，而是来自内心的成长。每天将工作中的成长和感悟写下来，并不断发掘自己的优势和特长，渐渐地，你对工作的兴趣将和自己的信心一同增长。
