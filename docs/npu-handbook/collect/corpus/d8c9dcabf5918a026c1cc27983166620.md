# 全团最高荣誉！西工大团委荣获“全国五四红旗团委”！-青春驿站-共青团西北工业大学委员会

近日，共青团中央印发《共青团中央关于表彰全国五四红旗团委（团支部）、全国优秀共青团员、全国优秀共青团干部的决定》，学校团委荣获“全国五四红旗团委”称号。这一荣誉是共青团中央授予基层团组织的最高荣誉，也是学校继2016年获“全国五四红旗团委”称号后，时隔10年再次获此殊荣，充分彰显了上级团组织对学校共青团工作的高度认可，更是全校团员、团干部及各级团组织共同奋斗的成果。
长期以来，学校团委在学校党委和上级团组织的坚强领导下，深入学习贯彻习近平总书记关于青年工作的重要思想和对国防军工高校的重要指示批示精神，积极践行“四个始终成为”重要要求，以学校“总师育人文化”为引领，构建“三位一体”团建育人格局，打造五大“青”字工程，形成“1235”团学工作体系，牢记“为党育人、为国育才”，着力为学校“总师型”人才培养铸魂、强基、赋能，先后获中国青年五四奖章、中国青年五四奖章集体、“挑战杯”全国竞赛“优胜杯”、全国社会实践活动优秀单位、陕西省五四红旗团委等荣誉，相关工作获央视《新闻联播》、《人民日报》、共青团中央官微等媒体报道400余次。
深化“总师育人文化”浸润
建设引领青年思想进步的政治学校
始终把思想政治引领放在首位，第一时间组织团学骨干学习贯彻习近平总书记重要讲话与重要回信精神，并依托“总师育人文化”打造特色宣讲课单，举办全国高校联学联讲，承办中央军委政治工作部军地青年典型分享交流等，常态化开展青年理论宣讲，让军工报国情怀浸润青年心灵。
积极整合优化团属新媒体矩阵，累计策划推送1600余篇青年喜闻乐见的内容，制作原创视频120余个，其中“青春为中国式现代化挺膺担当”主题视频获团中央宣传部专函感谢，获教育部全国大学生网络文化节优秀原创作品等荣誉7项。同时，加强青年工作理论研究，相关先进经验刊发于《中国共青团》杂志、《中国青年报》，出版相关学术论文集和省级一流课程教材，形成“理论+实践+传播”的思想引领闭环。
厚植“总师育人文化”情怀
凝聚组织青年永久奋斗的先锋力量
学校团委提前谋划，积极申请获赠习近平总书记发表署名文章强调“共同办好西北工业大学哈萨克斯坦分校，培养更多中哈友好事业接班人”当日天安门广场升挂国旗，为校园文化活动增添内涵。
优化“第二课堂”供给，推出“团团小文体”小程序，总访问量超500万次；举办“五四”青年节舞台思政课等爱国主义教育活动，29家社团入选“全国优秀大学生社团”，18个学生社团、学生组织实践案例获评全国“榜样100”优秀案例，入选数量位居全国高校前列。出版《大学生社会实践》系列配套教材，课程入选省级一流课程。广泛开展志愿服务活动，“进乡村、进社区、进基层”的志愿服务品牌深入人心，全校3.46万名注册志愿者累计服务近240万小时，获评陕西省青少年公益项目大赛金奖；研究生支教团事迹先后受央视等媒体报道50余次，成为青年服务国家的生动缩影。
强化“总师育人文化”认同
当好党联系青年最为牢固的桥梁纽带
着力打造思政实践育人新范式，累计超5万名学生参与各项专题实践活动，连续多年社会实践评奖评优全覆盖，多次获团中央、教育部等表扬信。团委书记受邀在团中央基层建设沙龙等分享思政实践经验；“三航科普润心田，各族少年共扬帆”项目获批国家民委2025年度各族青少年交流计划全国试点项目，CGTN纪录片《澎湃中国》全程跟拍“追火箭的年轻人”社会实践队，“Z世代的中国课”在2024年中外大学生社会实践周活动上展示成果，《铸剑格桑花》实践案例在陕西省实践成果展上交流分享。
深入推进创新创业教育，完善全要素、全链条双创教育体系，建强指导教师队伍和竞赛基地。在“挑战杯”系列竞赛中，2024年获金奖7项，金奖总数位居全国高校第3，2025年总积分并列全国第9、特一等奖并列全国第3，蝉联“优胜杯”。在中国国际大学生创新大赛中，2024年获金奖13项，位居全国第2，2025年获金奖16项，位居全国第1，连续获评中国国际大学生创新大赛高校集体奖。
把握“总师育人文化”脉搏
塑造紧跟党走在时代前列的先进组织
坚持组织建设全覆盖，严格落实党建带团建制度，规范团组织运行机制，压实学院团委责任，2024年高标准举办学校第十七次团代会。推行基层支部“分层分类、阶梯晋级”管理模式，常态化展示支部团日活动风采，成功创建省级团建标杆院系4个、样板支部7个。
强化团干部能力培养，开设团委书记培训班，举办团干部素质能力大赛，累计获陕西省团干部素质能力大赛一等奖5项，连续三年获评优秀组织单位。年均开展新任团支书、新发展团员培训20余次，实施“三维度、六模块”青马工程培养方案，承办全国“青马工程”相关教育活动。选树青年先锋典型，累计获评中国青年五四奖章、中国青年五四奖章集体等各级荣誉20余项。深化学生会组织改革，校学生会、研究生会连年获评陕西省标兵学联学生会组织，“学霸直播间”“星火骨干营”项目均入选全国精品项目（全国仅100项）。
此次荣获“全国五四红旗团委”称号，既是对学校共青团工作的肯定，更是新的起点。下一步，学校团委将在学校党委和上级团组织的坚强领导下，继续团结带领各级团组织和广大团员、团干部深入学习贯彻习近平新时代中国特色社会主义思想，持续深化“总师育人文化”浸润，为学校实现“天下工大、世界三航”远景目标贡献力量，引领广大团员青年把青春奋斗融入党和人民的事业，在国家重大战略需求中挺膺担当。
