# 芬兰

使馆签证处地址：启皓大厦西塔19层
使馆网址：http://www.finland.cn/
所有申请材料按序号顺序每人一套（预约名单表除外），按名单表顺序依次排列。
照片：3.5*4.5白底1张，半年内近照 照片要求极为严格，挨个查看
表格：1份
若还前往第三国（非申根），需先办理第三国签证
1.指纹预约/免预约名单表
2.留指纹那次的签证页复印件
3.申请表（个人联系方式填写手机号码）
4.打印Checklist并签名https://finlandvisa.fi/checklist/CHN/27
5.旅行医疗保险
6.确认函译文（外交领事服务中心抬头的照会译文）
7.中文照会
8.照会译文
9.欧洲名单表（三人及以上）
10.邀请信
11.机票订单
12.酒店订单
13.在职费用证明（英文、签字盖章）
14.护照复印件（照片页）
15.签证中心同意函（打钩、签名，见下页图示）
【领事服务中心关于近期申请芬兰签证注意事项的通知】
各办证单位：
根据芬兰驻华使馆要求，现将部分近期申签注意事项通知如下：
一、自即日起，申请材料中须附材料清单（checklist)，此材料可通过在线填写申请表（finlandvisa.fi)后自动生成，或通过finlandvisa.fi/checklist选择打印。请注意，所有因公护照申请人均选择“MFA/FAO-外交部/外事办”，请勿选择商务等其他选项。
二、申请人提供的保险保单，须明确显示覆盖地区为申根地区/全球，不可只覆盖芬兰。且保单信息均需为双语（中英文）显示。
此国家为外交部统办，还需按顺序准备好以下材料：
1照会复印件（由外事中心提供并复印）
2“二维码”信息表
3任务批件（确认件和通知书）复印件、外专局批件等内部备案材料
