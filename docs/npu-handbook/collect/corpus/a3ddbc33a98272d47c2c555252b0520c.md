# 2027年公共管理硕士（MPA）专业学位研究生招生宣讲会

2027年公共管理硕士（MPA）专业学位研究生招生工作已经开始。为帮助考生全面了解西北工业大学MPA招生政策和MPA教育特色优势，西北工业大学特举办2027年公共管理硕士（MPA）专业学位研究生招生宣讲会。欢迎广大考生积极报名参加！
一、项目介绍
● 院校介绍
西北工业大学（简称西工大或西北工大）坐落于陕西西安，是一所以航空、航天、航海等领域人才培养和科学研究为发展特色的国家“双一流”建设高校，隶属于工业和信息化部。学校脉源三支、强强融合（国立西北工学院、华东航空学院、哈尔滨军事工程学院空军工程系），1960年被中共中央确定为全国重点大学，“七五”“八五”均被国务院列为国家重点建设高校之一，1995年首批进入“211工程”，2001年进入“985工程”，2017年进入“一流大学”建设高校（A类）行列，是“卓越大学联盟”成员高校，是“一带一路”航天创新联盟发起高校。
公共政策与管理学院具有较长的办学历史，其渊源可追溯至1983年设立的社会科学部(1985年改为社会科学系)。2003年，在原社会科学系、外语系基础上组建人文与经法学院。2013年和2015年，以外语系和思想政治理论教学科研部为基础，先后分别成立外国语学院和马克思主义学院。2021年，人文与经法学院更名为公共政策与管理学院。学院下设有公共管理系、经济学系、法学系和MPA教育中心4个教育教学单位。
● MPA教育中心介绍
西北工业大学2005年获批试办MPA教育，是全国第三批获得办学资格的院校之一。学院为适应不断发展的公共管理现代化、科学化、专业化的迫切需求，在充分发挥学校优势和学院学科特色的基础上，组织优秀的师资团队，确立了社会治理、公共项目管理、数字治理、政府管理创新与改革等方向。
经过20多年的发展，我校MPA教育已培养优秀MPA毕业生2000余人，其中40%以上就职于党政机关，约35%就职于国防科技工业相关企事业单位。MPA毕业生具有深厚家国情怀，综合素质全面，知识扎实、能力突出，在各自岗位上发挥着关键、重要作用。

● 实践教学活动
MPA教育中心持续深化实践教学改革，着力拓展MPA研究生专业视野,精心打造"三位一体"实践教学体系：定期开展政企单位现场教学，组织社会治理专题考察，实施新闻热点实地调研，形成了课堂学习与实践教学的良性互动机制。
● 案例教学
西工大 MPA 持续深化案例教学改革，鼓励研究生组队深入基层调研，围绕政务治理难题开发原创案例，积极参与中国研究生公共管理案例大赛。参赛学员完成案例撰写、评审、现场展示与答辩，多支团队斩获国家级、省级重要奖项。学院构建起 “以赛促学、以案促教” 特色培养模式，依托竞赛推进实践育人，打通理论学习与政务实务的衔接通道。
