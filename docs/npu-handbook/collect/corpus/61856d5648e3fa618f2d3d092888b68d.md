# 长安校区启翔湖亲水平台木栈道旧貌焕新颜

坐落于长安校区启翔湖畔的亲水平台，是生活在长安校区的广大师生休闲漫步、观赏湖景的好去处。但由于靠近湖边湿气较大，木栈道的地板及龙骨长期被湖水浸泡，已出现大面积腐烂、翘起变形，不仅影响环境美观，且无法正常使用，存在较大的安全隐患。
为恢复该亲水平台的使用功能并排除安全隐患，后勤部办公室积极担起维修主责，经多次现场踏勘、市场调研、方案研讨，决定对亲水平台木栈道进行整体更换，将原有的木地板更换为更加耐湿气、耐暴晒的塑木，不仅保持了木栈道原本的美观，也大大降低了木地板浸泡腐烂的隐患。在维修工作实施过程中，重点对塑木地板的面层厚度、材质、平整度及龙骨规格、间距等进行了仔细检查，确保所用材料符合相关标准和规范。
经过三周的施工，目前木栈道更换维修工作已全部完成。经过维修后的亲水平台旧貌焕新颜，为启翔湖畔增添了一抹亮色，为本校师生和校外人员提供了更加安全、美好、舒适的校园环境。（撰稿人：张帆；审稿人：郝东兴）
