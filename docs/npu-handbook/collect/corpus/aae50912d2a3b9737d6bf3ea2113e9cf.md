# 不忘初心、牢记使命——航海学院杰出校友史小锋总师讲授“感悟深蓝”课程

近日，航海学院校企协同课程“感悟深蓝”学期第四讲在长安校区教学西楼D105顺利举行，航海学院杰出校友、中国船舶第七〇五研究所科学技术委员会主任委员、中国船舶集团有限公司首席专家史小锋总师来校授课。全校400余名本科生聆听了主题为《不忘初心、牢记使命，为全面建成世界一流海军奉献青春和力量》的课程。
问渠那得清如许？为有源头活水来。史小锋总师从我国船舶集团建设、国际水下科技发展和自身科研之路三个方面向同学们介绍了深蓝事业的开拓、学习和发展之路。从红色基因的传承讲起，他讲述了中国船舶七〇五所等院所是如何从新中国成立初期几乎一无所有的海防技术，发展到如今全国各地各司其职、技术先进的海防科研机构，秉持着“团结奋斗、精益求精、开拓进取、现身国防”的七〇五所取得了一系列丰硕的成果，为人民海军提供多种装备。
新时代赋予船舶集团新的使命，在“努力把人民海军全面建成世界一流海军”的伟大号召下，史小锋总师向同学们讲述了中国船舶集团有限公司的未来发展展望。他说到，中国船舶集团将会为我国海洋国防建设、能源开采、科研考察、货运养殖等多个领域提供新型智能装备，助力我国深蓝事业不断向前发展。
会当凌绝顶，一览众山小。他带领同学们对标国际海洋兵器强国，介绍了国际上核动力鱼雷、超大型水下无人航行器和超轻型鱼雷等前沿技术的发展，并讲述了自己的求学奋斗历程，回顾了从基础做起的工作，虽艰辛但值得。“不登高山，不知天之高也；不临深渊，不知地之厚也”，史总师引用荀子的话，勉励同学们积极投身国防现代化的事业，身体力行，脚踏实地，续写国防科技领域的“西工大现象”，为中华民族伟大复兴奉献青春力量！
授课专家简介：
史小锋，1965年10月出生，1987年7月西北工业大学航海工程系热能动力机械与装置专业本科毕业并参加工作，2004年12月获西北工业大学电子与通信工程专业硕士学位。
长期任职于中国船舶第七〇五研究所，致力于水下航行器动力及总体技术研究工作。现任七〇五所科学技术委员会主任委员，中国船舶集团有限公司首席专家、标准化委员会副主任委员、科技委某专业委员、某科技创新专家组组长，硕士研究生导师，中文核心期刊《水下无人系统学报》编委会副主任委员。为享受国务院政府特殊津贴专家，获国家科学技术进步二等奖1项，国防科学技术进步一等奖1项、中国船舶科学技术进步特等奖2项等多项省部级奖。
