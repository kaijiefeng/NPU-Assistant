# 青岛蓝谷管理局杜乐江一行莅临中心调研

12月4日下午，青岛蓝谷管理局党委副书记、常务副局长杜乐江一行莅临西北工业大学重庆科创中心调研，中心副主任张铁邦接待。
张铁邦对杜乐江一行的到来表示热烈欢迎，带领参观了中心展厅、航空航天关重件残余应力检测实验室、航空航天难变形材料特种连接技术中心等。
在随后的座谈会上，张铁邦就中心建设运营、人才引进、平台建设、成果转化等主要工作进行了介绍。杜乐江介绍了青岛蓝谷青岛蓝谷的发展历程、重点产业以及发展模式。杜乐江对中心取得的工作成果表示赞赏，并重点就博士后科研工作站建设以及人才引进工作进行了深入交流。
杜乐江表示，青岛蓝谷致力于助推海洋强国战略，打造高科技研发及高技术产业集聚区域，西北工业大学重庆科创中心在人才引进、平台建设方面取得了优秀经验，希望未来能够加强交流与合作。
