# 校招生办公室来院研讨招生工作

为进一步总结招生工作经验，提升生源质量，优化招生策略，2025年10月23日，校招生办公室副主任马婷婷和王思羽老师一行赴数学与统计学院研讨招生工作。数学与统计学院副院长郭千桥、西安招生组组长王振海、招生秘书李彦吉参加座谈。
马婷婷首先对数学与统计学院在2025年招生工作中取得的优异成绩表示祝贺。她指出，重庆市招生工作连续三年取得很大进步，充分体现了学院对招生工作的高度重视，她代表招生办公室感谢学院全体教职工的辛勤付出。马婷婷深入解读了当前重庆招生工作面临的新形势，对学院下一阶段招生宣传工作提出指导意见，希望学院在巩固现有成果的基础上，进一步挖掘潜力，争取更大突破。随后，王思羽结合详实数据，对学校整体生源情况、重庆市招生情况、数学专业招生情况进行了系统梳理与精准分析。
郭千桥副院长对校招办一行来院指导表示衷心感谢。他表示，校招办的精准反馈和深入指导为学院未来招生工作指明了方向、注入了动力。学院将认真吸纳宝贵建议，持续深化“全年、全员、全力、全方位”的招生宣传理念，进一步发挥全院教职工、重庆籍教师和优秀学子在招生宣传中的积极作用，不断优化工作方法与工作策略。
此次会议为学院招生工作指明了进一步努力方向。数学与统计学院将在招生办公室的指导下，凝聚全院智慧与力量，持续提升招生工作水平，为选拔培养更多“总师型”拔尖创新人才贡献力量。
