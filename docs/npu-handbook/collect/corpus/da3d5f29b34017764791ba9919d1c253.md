# 工业和信息化部印发《中共工业和信息化部党组关于加强新时代离退休干部党的建设工作的实施意见》

工业和信息化部党组深入贯彻党的二十大精神，落实中办《关于加强新时代离退休干部党的建设工作的意见》（以下简称《意见》），高度重视、高位推动《意见》的落实，先后召开2次部党组会议，研究审议《中共工业和信息化部党组关于加强新时代离退休干部党的建设工作的实施意见》（以下简称《实施意见》）。《实施意见》结合学习贯彻党的二十大精神和工业和信息化部离退休干部党建工作实际提出了5个方面32条具体措施。
在强化政治引领方面，《实施意见》开宗明义把深入学习贯彻党的二十大精神作为离退休干部党建工作的首要政治任务加以部署，强调要持续抓好党的创新理论武装，引导离退休干部党员始终做习近平新时代中国特色社会主义思想的坚定信仰者和忠实实践者。用好支部工作微信群、“工信银龄之声”微信公众号等信息化平台，着力提升学习效果。部党组和部属各单位党组织或有关方面负责同志要每年为离退休干部党员讲一次党课。落实离退休干部政治待遇保障措施，鼓励各单位举办离退休干部党员骨干培训班。严明党的政治纪律和政治规矩，教育引导离退休干部党员不越底线红线。
在强化组织功能方面，《实施意见》明确要坚持大抓基层的鲜明导向，进一步优化离退休干部党组织设置，确保党组织有形有效覆盖。建强离退休干部党支部班子，梯次培养班子后备力量。规范党组织换届工作，党员年龄普遍较大的党支部可由在职党员兼任副书记或委员。认真落实组织生活制度，支部书记每年讲1次党课。严格执行组织生活纪律，规范党费收缴使用和管理。持续提升党支部建设标准化规范化水平，开展“六好”示范党支部创建活动。
在强化管理监督方面，《实施意见》明确要加强理想信念教育和党规党纪教育，做到离岗不离党、退休不褪色。发挥好党组织管理监督作用，教育引导离退休干部严格遵守党的各项纪律规定。有序有效组织退休领导干部在企业、社团兼职（任职），定期开展教育，加强提醒监督，兼职（任职）的退休领导干部每年以书面形式向组织报告情况。加强党员出国（境）和流动党员管理。严格微信群等互联网群组管理。
在强化激励关怀方面，《实施意见》明确要发挥离退休干部党员政治优势、经验优势、威望优势，持续深化“增添正能量、共筑中国梦”活动，组织离退休干部党员围绕党和国家事业发展、工业和信息化发展、社会和谐稳定献智出力。加大表彰和宣传力度，注重发现离退休干部党员先进典型。激发离退休干部党员政治荣誉感，落实干部荣誉退休制度，做好“光荣在党50年”纪念章颁发工作。落实走访慰问、谈心谈话等关怀帮扶制度。贯彻精准服务理念，建立健全“为老办实事”工作机制，服务离休干部实行“一人一策”，服务退休干部注重分类管理、精准施策、重点关注。对接社会养老资源，丰富养老服务方式。
在强化组织领导方面，《实施意见》提出党组织要切实履行离退休干部党建工作主体责任，党组织书记每年至少听取1次离退休干部党建工作汇报。健全离退休干部党建工作运行机制，加强离退休干部党建工作队伍建设，建立健全离退休干部党支部在职联络员制度。强调要发挥各单位党建工作部门和离退休干部工作部门对离退休干部党建工作的支持保障作用。加强干部培养和实践锻炼，将离退休干部党建工作经费列入单位年度预算，纳入管理费用予以保障。根据实际为离退休干部党支部书记、副书记、委员发放工作补贴。加强党建阵地建设，完善学习活动场所功能。发挥工业和信息化部工作优势，探索信息化条件下党建工作新模式，打造离退休干部线上服务管理新机制，以信息化带动精准化、规范化建设，大力开展“智慧助老”教育培训，以扎实党建工作引领推动部系统离退休干部工作高质量发展。
