# 教育实验学院-西北工业大学医院

责任医师：韩涛（医师）
简介：
毕业于西安医科大学临床医学系，从事内科临床工作20余年，曾在交大医学院第二附属医院肾病内科进修1年，擅长内科常见病、多发病的诊治。现为中华医学会内科会员。在糖尿病、高血压、老年综合征、代谢综合征、慢性肾病等疾病的诊治方面，具有丰富的临床经验。
（备注：学院责任医师是医院与学院之间的桥梁，可为我校师生提供健康咨询、健康宣教、体检结果释疑、急救知识技能培训等服务。有需求者，可通过扫描学院责任医师二维码联系。）
