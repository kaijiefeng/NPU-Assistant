# 我校举办2026年西北工业大学“翱翔四海”暑期项目出征仪式暨带队老师行前培训会

7月3日，2026年西北工业大学“翱翔四海”暑期项目出征仪式暨带队老师行前培训在友谊校区国际会议中心第一会议室举办。副校长孔杰出席会议并讲话。校党委学生工作部、艺术教育中心、航空学院、航天学院等30家单位负责人、外事秘书、带队老师参会。
会上，国际合作处副处长陈俊首先对2026年“翱翔四海”项目实施情况进行了专题汇报。他表示，2026年寒假期间，学校已派出1000余名本科生赴国（境）外开展交流学习，项目整体运行平稳有序；目前暑期项目计划派出2500人，预计将顺利完成年度目标任务。
会议对2025年度“翱翔四海”出国（境）项目组织派出工作表现突出的单位进行表彰。其中，集成电路学院（微电子学院）等6家单位荣获卓越奖，航空学院等16家单位荣获优秀奖。
孔杰向2026年“翱翔四海”暑期项目全球治理勇担当、“一带一路”绘未来、科技创新攀高峰、强基拔尖创卓越、学术前沿拓视野、国际竞赛展风采、人文交流促相通七大主题代表单位逐一授旗，勉励各位老师肩负育人使命，做好学子海外求学引路者。
孔杰在总结讲话中指出，“翱翔四海”项目是我校国际化人才培养体系中的重要品牌，更是学校面向全球治理格局、主动融入世界高等教育版图的生动实践。它既承载着“总师型”人才走向国际舞台的育人使命，也体现着学校深化教育对外开放、拓展全球合作网络的坚定决心。孔杰对即将出征的各位带队老师提出四点希望：一是扛牢安全责任，抓实全程管理，守稳风险底线；二是深耕过程育人，立足专业研学，务求实学实效；三是严守纪律规范，规范言行举止，维护学校形象；四是厚植家国情怀，做好思想引领，拓展全球视野。
随后，国际合作处陈思危围绕案例警示、安全管理、外事纪律及突发事件应对等内容进行带队老师培训。培训通过典型案例分析，强化风险防范意识，进一步明确带队教师职责边界与管理要求，切实提升带队老师安全管理与应急处置能力，确保暑期海外交流项目安全有序实施。
学校将持续完善“翱翔四海”平台建设，优化国际化人才培养路径，统筹推进联合培养、海外交换、国际竞赛、访学研修等多元育人载体，全方位打通西工大学子走向世界、认识世界、贡献世界的重要通道，引导青年学子在国际舞台开阔视野、锤炼本领、勇担使命，成长为具有家国情怀，追求卓越、引领未来的领军人才。
