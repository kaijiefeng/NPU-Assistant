# 离退休党委/离退休工作处召开全体教职工大会

3月5日下午，离退休党委/离退休工作处召开全体教职工大会，传达学习在全党开展树立和践行正确政绩观学习教育有关精神、学校2026年寒假务虚会和春季新学期中层干部会精神，研究部署贯彻落实举措。会议由赵洪章书记/处长主持。
会上，赵洪章带领与会人员深入学习了中央办公厅《关于在全党开展树立和践行正确政绩观学习教育的通知》精神、中央党的建设工作领导小组会议精神以及学校党委树立和践行正确政绩观学习教育启动部署会精神；传达学习了李言荣书记、宋保维校长在寒假务虚会和春季新学期中层干部会上的讲话精神。马俊、陈仲昌副书记/副处长围绕2026年学校工作重点，对新学期离退休工作进行了具体安排。
会议指出，此次学习教育以“立党为公、为民造福、科学决策、真抓实干”为总要求，以“学思想、守初心、强担当、创实绩”为主要任务。一要深学细悟，通过理论学习中心组、“三会一课”、专题研讨等形式，组织党员干部及离退休党支部书记先学深学，领会正确政绩观核心要义，筑牢思想根基。二要对标行动，围绕离退休教职工思想政治引领、服务管理、文化养老、作用发挥等方面，查摆服务保障、阵地建设等短板，梳理突出问题，清单化精准整改。三要建章立制，以学习教育为契机，完善离退休工作规章制度，固化好经验好做法，形成保障正确政绩观落地的长效机制。四要实干出绩，推动学习教育与离退休工作深度融合，把树立和践行正确政绩观融入日常、抓在经常，以工作实效检验学习成果，凝聚老同志力量助力学校发展。
会议强调，2026年是学校“十五五”开局之年，全体教职工要提高政治站位，深入领会“一十百千”核心发展指标的战略内涵，深刻把握学校“高质量、高水平、高标准”工作基调。要紧扣学校决策部署，以问题和实绩为导向，精准对接老同志需求，提升服务保障质效；要严守稳定安全底线，优化资源使用，不断提升干部能力水平和工作标准;要始终保持“要上进、要努力、要奋斗”的精神风貌，精准精细、用心用情做好离退休工作，团结带领广大离退休教职工为实现“一十百千”发展目标和“天下工大、世界三航”远景目标贡献银发力量。
