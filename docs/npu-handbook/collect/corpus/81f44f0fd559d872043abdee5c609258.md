# 力学与土木建筑学院举办青年教师发展论坛—学术研讨第一期

2022年12月1日上午，力学与土木建筑学院青年教师发展论坛——学术研讨第一期，在学院206会议室召开。本次青年教师发展中心邀请学院乔吉超教授和巫荣海副教授，针对自身近期学术研究进展进行分享交流。20余名青年教师参加了此次学术研讨活动。
乔吉超教授首先做了“非晶固体粘弹性力学行为”的报告，介绍了基于分级关联原子运动的非晶态物质变形理论框架相关的研究概况，为理解非晶态物质的弛豫现象和非弹性变形行为的微观机制提供新的视角。
巫荣海副教授做了“材料变形损伤的多尺度建模与数值模拟”的报告，介绍了变形损伤的分子动力学、位错动力学和相场法研究，以及相关领域的应用和进展。参会人员围绕两个报告相关领域进行了观点分享和热烈讨论。
学院青年教师发展中心致力于通过定期的学术研讨活动为广大研究学者搭建科研学术交流平台，积极营造交叉、创新、融合、互鉴的学术氛围，为高层次人才培养和高水平科研成果产出提供有力支撑。
