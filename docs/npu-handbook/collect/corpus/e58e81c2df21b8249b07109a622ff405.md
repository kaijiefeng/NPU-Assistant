# 我校荣获“陕西省绿色学校”称号

近日，陕西省教育厅公布了“2024年陕西省绿色学校”名单，我校成功入选。这是我校继获得“2021年省级节水型高校”称号后在绿色节能工作方面获得的又一个省级荣誉。
近年来，我校始终贯彻落实习近平生态文明思想，深入践行绿色发展理念，将生态文明建设融入学校发展规划、学科建设、科学研究和管理服务等各项工作，全面提升广大师生的生态文明意识。学校积极采用节能、节水、环保、可再生等绿色设施设备，促进资源循环利用；鼓励教职工绿色办公、绿色出行、绿色生活，以实际行动践行绿色低碳生活；积极开设生态文明教育课程，在课堂中渗透生态文明教育；积极组织师生参与节能环保等绿色实践活动，在“全国节能宣传周”“世界水日中国水周”等时间节点开展绿色节能主题宣传活动。
自陕西省教育厅、陕西省发展和改革委员会发布《陕西省绿色学校创建行动方案》的通知以来，学校积极组织相关部门召开工作推进会，多措并举扎实开展绿色学校创建工作，顺利通过自评、申报、评估、验收等环节，达到认定标准。
下一步，我校将以此次荣誉为契机，持续深化绿色学校创建工作，引导师生践行简约适度、绿色低碳、文明健康的生活理念和生活方式，不断巩固提升我校绿色学校创建成果，有效助推学校高质量发展。（撰稿人：张偲偲；审稿人：韩争胜）
