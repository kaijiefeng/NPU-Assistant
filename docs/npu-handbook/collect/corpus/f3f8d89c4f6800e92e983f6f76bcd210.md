# AI赋能高校治理模式 聚力服务保障提质增效——“机关学习大讲堂”第六讲-机关党委

10月14日下午，机关党委举办2026年“机关学习大讲堂”第六讲，特邀请软件学院副院长马春燕教授作专题报告，机关部门、学院（研究院）70余名相关业务负责人参加。
马春燕以《AI赋能高校治理探索与实践》为题，从识变、应变、求变、实践四个维度，围绕智能决策、人才培养、科研管理、师生服务等业务场景，深入讲解了AI赋能高校治理的运行模式、实践路径和人机协同模式，提出了一批可落地、可复制的实践案例，内容详实、重点突出，为AI赋能机关智能化管理提供了重要指引。
人工智能作为新一轮科技革命和产业变革的关键变量，正全方位重塑生产方式、生活方式和治理方式。机关部门和二级单位办公室作为学校的主要管理服务机构，要主动把握人工智能发展大势，立足业务场景找准切入点，积极探索AI赋能破解管理痛点堵点的新模式，不断提升服务保障能力，以管理提质增效助力学校高质量发展。
