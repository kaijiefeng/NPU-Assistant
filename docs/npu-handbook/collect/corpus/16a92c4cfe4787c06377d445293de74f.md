# 力学与交通运载工程学院党委召开9月党支部书记工作例会

为扎实推进学院基层党建规范化建设，统筹落实学院党代会筹备及新学期各项工作要求，9月4日下午，力学与交通运载工程学院党委在延安精神党员活动室召开9月党支部书记工作例会。学院各党支部书记、支委参加会议，会议由学院党委书记巨维博主持。
会议集中开展树立和践行正确政绩观专题学习。巨维博领学相关篇目，要求各党支部要深刻领悟正确政绩观的核心要义、实践要求和时代内涵，筑牢思想根基，坚守“为党育人、为国育才”初心使命，坚持以高质量党建引领学院事业高质量发展，推动政绩观教育走深走实、落地见效。
随后，会议对学院党代会筹备工作进行专项部署安排，会议详细解读党代会相关工作流程、推荐标准、时间节点与工作要求，要求严守选举工作纪律，确保党代会筹备工作严谨规范、平稳有序推进。
会议对本学期各党支部重点工作任务作出全面系统部署，提出一是深化政治理论学习，持续推进理论学习常态化、制度化，巩固学习成效，推进学用结合，切实把学习成效转化为履职尽责、担当作为的实际行动。二是抓实党建业务融合，以学院党代会召开为重要抓手，凝聚全院发展共识，助力学院“十五五”规划落地落实。教工党支部要发挥党员先锋模范作用，推进AI赋能人才培养、科研攻坚、人才队伍建设等中心工作。学生党支部要发挥基层战斗堡垒作用，强化党员在学风建设、班风培育、创新实践能力提升等方面的引领作用发挥。三是严守安全发展底线，聚焦基层党建规范化建设，高标准规范“三会一课”、智慧党建系统维护、党员发展等基础党务工作，常态化抓好师德师风、学术道德、意识形态、保密安全等底线工作，筑牢全面从严治党基层防线，切实以高质量党建为学院各项事业高质量发展保驾护航。
