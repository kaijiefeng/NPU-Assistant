# 展现巾帼风采 绽放最美芳华” ——“三八”节踏春赏花活动

为庆祝第113个“三八”国际劳动妇女节，3月8日下午，档案馆工会小组积极参加了机关部门工会组织的“展现巾帼风采 绽放最美芳华”踏春赏花活动，地点是长安唐村-南堡古寨。
刚一下车，秦岭衬托下的梅园就吸引了大家的目光。穿梭在梅林中，忽然听见“风雨送春归，飞雪迎春到。已是悬崖百丈冰，犹有花枝俏。”不知是谁吟诵起了《卜算子·咏梅》。大家听到后不约而同笑着背诵道：“俏也不争春，只把春来报。待到山花烂漫时，她在丛中笑。”再往前走，映入眼帘的是书屋茶馆、古朴建筑。
游览完毕，大家集结在一起玩起了丢手绢游戏。“丢、丢、丢手绢，轻轻地放在小朋友的后面，大家不要告诉她，快点快点抓住她，快点快点抓住她……”在“你追我赶”的欢声笑语中，大家暂时卸下紧张的工作情绪，仿佛回到了童年时光。此次踏春活动，使大家感受到了初春希望的气息，增进了彼此之间的了解，提升了团队的凝聚力，展现了女教职工积极向上的精神面貌。
