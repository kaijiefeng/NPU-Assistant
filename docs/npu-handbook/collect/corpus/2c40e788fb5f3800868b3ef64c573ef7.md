# 口腔科-西北工业大学医院

西北工业大学医院口腔科是集牙体牙髓、牙槽外科、口腔修复、口腔正畸及口腔预防为一体的综合性科室，承担西北工业大学教职工、学生、以及周边社区居民口腔健康保障及治疗工作。以治疗效果好、服务态度好、价格信得过等，赢得了良好的声誉。目前的技术规模在全市高校医院中名列前茅，科室有技术过硬的从事口腔内科、口腔修复、口腔正畸和口腔种植的专业人才。现有副主任医师和主治医师共6名，口腔修复学博士1名，口腔正畸学硕士1名，与空军军医大学口腔医院和西安交通大学口腔医院专家长期合作会诊。
口腔科拥有11台牙科综合治疗椅，除开展洗牙、补牙、拔牙、牙齿矫正、镶牙等常规治疗外，还开展牙种植、隐形矫正、瓷贴面修复等先进治疗项目。我科配备高温高压预真空消毒机，芬兰普兰梅卡数字化全景x光机、快速灭菌器封口机手机清洗注油及超声波清洗机，根管定位仪、Protaper机用镍钛根管预备系统、热牙胶充填系统、隐形矫治器、自锁托槽、微型钛钉正畸骨支抗和牙种植微动力系统、诺贝尔种植机等先进设备。拥有精湛的医疗技术，分工细致，多专业合作，实现科内会诊和转诊，优良的就诊环境，为患者提供舒适、人性化的优质医疗服务。 为杜绝医源性感染我科对使用过的手机头洁治机头及手术器械均集中管理消毒灭菌对进入病人口腔内的所有诊疗器械做到了“一人一用一消毒或者灭菌”从而有效的预防了交叉感染
主要诊治项目：口腔内科开展龋齿填充、根管治疗、牙周炎治疗等各种常规疾病。牙槽外科，开展拔牙以及各种复杂阻生齿的拔除术。口腔修复科开展精密附着体义齿、全口吸附性义齿、固定义齿、贴面修复、隐形义齿修复等。口腔正畸科开展常规直丝弓矫治技术、自锁托槽矫正，隐适美隐形矫正等。口腔种植科开展瑞典诺贝尔种植牙系统和韩国DIO种植牙系统。除此之外，我科还开展适龄儿童窝沟封闭术、牙齿美白术、口腔粘液腺切除术等各种口腔常见疾病的诊治。
随着社会的进步和保健意识的提高，人们对口腔健康的需求与日俱增。我科全体医护人员，将以优良的技术和质量、合理的收费，为患者提供放心的医疗服务。
