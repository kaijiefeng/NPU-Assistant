# 西北工业大学社区《预防接种证》办理须知-西北工业大学医院

1.预防接种证是儿童接种疫苗的凭证，也是儿童入托、入学和成年后就业、出国的健康身份证。根据《中华人民共和国疫苗管理法》第四十七条规定，国家对儿童实行预防接种证制度。在儿童出生后一个月内，其监护人应当到儿童居住地承担预防接种工作的接种单位或者出生医院为其办理预防接种证。监护人应当妥善保管预防接种证。预防接种实行居住地管理，儿童离开原居住地期间，由现居住地承担预防接种工作的接种单位负责对其实施接种。接种单位对儿童实施接种时，应当查验预防接种证，并作好记录。
2.本辖区指西北工业大学友谊校区（含南苑、西苑）。本辖区内居住的常住儿童办理预防接种证,家长需要在宝宝出生一个月内带着宝宝的户口簿、出生证以及出生医院出具的《新生儿首针乙肝疫苗和卡介苗接种登记单》(红、黄二联单),到西北工业大学医院预防科办理《预防接种证》,医院会给家长一个小绿本儿,上面有接种计划和医生预约的疫苗接种时间,家长按照预约时间按时带孩子到接种门诊进行接种。
3.在外地出生但在本辖区居住的孩子,也应尽快到预防科办理预防接种证,让孩子尽快地补种各种疫苗。若在原地区已接种过疫苗,应带上原来的预防接种证和接种卡办理迁入手续,根据已接种过的疫苗记录,安排未种和补种的疫苗。
4.境外（含港、澳、台地区）出生但在本辖区居住的孩子，家长应携带孩子的户口簿（或护照）、境外出生证明和疫苗接种记录证明办理迁入手续,根据已接种过的疫苗记录,安排未种和补种的疫苗。一岁以下年龄段孩子家长需要完成“新手爸妈疫苗接种课堂”线上学习与考核（详见第6条）。
5.本辖区内居住的流动儿童办理预防接种证,家长需带孩子的户口簿、出生证、出生医院出具的《新生儿首针乙肝疫苗和卡介苗接种登记单》(红、黄二联单)以及房屋租赁合同和房主有效证件来办理。房屋租赁合同地址与房主有效证件地址不相符时需带近3个月内水电费缴费单1张。
6.初次办理预防接种证的孩子家长在办理预防接种证前请扫描二维码，接种点选择西安市碑林区西北工业大学医院，进入课程完成西安市疾病预防控制中心的“新手爸妈疫苗接种课堂”学习，考试领取结业证书并截屏，办证时把截屏信息交给办证医生。（二维码见文末）
7.家长在办理预防接种手续时,必须把真实可靠的通讯住址和联系电话告诉医务人员,以便于联系。
8.接种证办理时间:每周一、三下午(节假日及特殊情况除外，寒暑假另行通知）。
