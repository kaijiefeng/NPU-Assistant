# 精准把脉学情 赋能课堂提质——马克思主义学院开展思政课学情调研-西北工业大学

为持续深化思政课教学改革，精准把握新时代青年学生思想动态与学习需求，切实提升思政育人针对性、实效性，近期，西北工业大学马克思主义学院组织教师开展思政课学情调查。
本次调查坚持问题导向、育人导向，各位教师根据课程专题特点和年级属性不同，分别采用线上问卷、线下问题清单收集、督导课堂走访相结合的方式，覆盖本研多个年级、各专业学生。调研聚焦课程内容供给、课堂教学模式、实践教学开展、师生互动成效、数智思政体验等核心维度，收集学生真实学习感受、意见建议与思想困惑。
调研过程中，学院立足学校育人特色，重点梳理青年学生对国防思政、红色育人、理论结合实践的学习诉求，系统梳理当前课堂教学优势与短板，本学期授课教师均形成授课专题问题清单。
下一步，学院将以调研结果为参考，靶向优化教学设计、创新授课形式、丰富育人载体，持续推动思政课从“入耳入眼”向“入脑入心”转变，打造贴合西工大学子特质、彰显军工底色的高质量思政课堂。
