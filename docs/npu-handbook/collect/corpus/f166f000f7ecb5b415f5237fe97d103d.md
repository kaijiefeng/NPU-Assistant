# 后勤部办公室党支部召开理论学习会

为进一步落实深入贯彻中央八项规定精神学习教育工作要求，强化支部党员作风建设，5月28日，后勤部办公室党支部组织两个党小组分别召开了理论学习会议。
会上，党支部书记张文刚、副书记韩争胜分别带领党员们学习了《党的十八大以来深入贯彻中央八项规定精神的成效和经验》和《党政机关厉行节约反对浪费条例》。随后，大家集体学习了《八项规定改变中国》《习近平总书记在中共中央政治局第二十次集体学习时的重要讲话精神》等内容，并观看了《八项规定改变中国——以作风建设新成效赢得人民群众衷心拥护》视频短片。党员们围绕理论学习内容，结合工作实际展开了交流研讨。
最后，张文刚强调，全体党员要以高度的政治自觉抓好学习教育，时刻紧绷党纪党规这根弦，自觉自为、驰而不息加强作风建设，以党风政风的持续改进带动后勤工作作风向上向好，扎实助推学校高速度高质量高水平发展。（撰稿人：毛淑兰；审稿人：韩争胜）
