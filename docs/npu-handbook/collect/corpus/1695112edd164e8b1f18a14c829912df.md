# 西北工业大学医院召开新学期中层干部会-西北工业大学医院

9月10日，西北工业大学医院召开中层干部会，会议由院长郑莉莉主持，党总支书记乔辉，副院长何凯亮、孙伟光及全体中层干部参加会议。
党总支书记乔辉和院长郑莉莉分别领学了学校张云明书记和宋保维校长在2026年暑假务虚会和秋季学期中层干部会上的讲话精神。会议要求全院上下深入思考"我们是干什么的、我们的处境是什么、我们应该怎么干"这一核心问题，聚焦学校"十五五"规划落地实施要求，进一步强化责任担当，切实将会议精神转化为履职尽责的实际行动，并融入日常工作全过程。
副院长何凯亮和孙伟光分别就主管工作进行了上半年工作总结和新学期工作部署，希望大家认清形势、明确方向。
郑莉莉要求新学期各科室要注重医疗安全，坚守"安全是底线"，自上而下落实医疗质量安全培训；紧盯秋冬季流感高发形势，强化业务培训；吃透医保政策新变化，严守风险防控关口；加强青年医师技能培训，不断提升医疗服务质效。她希望全体职工牢固树立"铆足干劲是根本"的意识，真抓实干履职尽责。
乔辉表示，新学期全体职工要提高政治站位，统一思想认识，深入贯彻落实学校会议精神，厚植师生情怀，搞清楚"为谁服务"这一根本问题；紧扣医院"十五五"规划部署，聚力提升医疗服务水平；坚持问题导向、目标导向和结果导向；树牢底线思维，严把医疗质量，恪守廉洁行医准则。此次会议进一步统一了思想，凝聚了共识，西北工业大学医院将以此次会议为新的起点，着力推进各项工作落地见效，为学校加快建设中国特色世界一流大学贡献健康力量。
