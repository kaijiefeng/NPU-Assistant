# 第二课堂丨学生科协举办“青年前沿科学讲堂”活动

10月29日，学校学生科协举办“青年前沿科学讲堂”活动。国家级领军人才，中国空气动力学副理事长张伟伟教授应邀开讲，以“多智能体协同的飞行器智能化设计平台研究”为题，带领在场学子探讨人工智能在现代飞机与武器设计领域的深度应用，以及该技术对行业发展的深远影响。学生科协指导教师王杰及百余名学生参加活动。
张伟伟教授首先介绍了AI如何赋能设计流程。他指出，AI大模型作为一种新型设计工具，能够有效融合空气动力学、结构力学等多学科知识，优化设计过程，显著缩短飞机的整体设计周期。随后，他分析了AI技术在降低传统物理实验误差、减少高昂试飞成本方面的作用，指出设计验证环节正从传统的实物测试，逐步向高精度模拟与数据驱动转变。最后，张伟伟教授探讨了AI大模型在武器设计中的推动作用，并结合技术发展对传统设计师就业可能带来的“挤压”效应，与同学们交流了对人机协作模式及未来工程师角色定位的思考。
在交流研讨环节，现场气氛热烈。张伟伟教授就同学们提出的AI技术创新应用、航空飞行器设计及未来就业市场等问题逐一作出分析与解答，进一步拓宽了同学们的学术视野与专业发展思路。
讲座结束后，张伟伟教授做客“科学沙龙”，与学院铸剑班学生代表进行更为深入的交流。他细致分析了AI技术在航空飞行器智能化设计中的具体应用，分享了航空领域的前沿研究方向与能力成长路径，并鼓励同学们在学习与科研中注重培养人机协同的工程思维。
本次活动立足学科前沿，聚焦人工智能与航空领域的交叉融合，为同学们搭建了与专家学者面对面交流的平台，有助于进一步激发专业兴趣、拓宽学术视野。今后，学生科协将持续营造浓厚的校园学术氛围，助力同学们成长成才。
