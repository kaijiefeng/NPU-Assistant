# 党建领航强堡垒 感控6S管理提质效 —长安校区党支部引领门急诊服务升级-西北工业大学医院

在长安校区党支部引领下，门急诊开展感控 6S 管理实践，数月来，医疗服务质量与管理效能双提升，为师生健康构筑起坚实屏障。
前期筹备：系统规划，制定方案 。前期在感控办张毅主任的带领下，长安校区党支部组建专项组深入一线调研，精准定位问题。组织骨干学习先进经验，何凯亮副院长及科主任组织科室成员召开“感控6S管理启动及动员会”，结合实际制定科学方案，凝聚共识。
实施过程：党员带头，扎实推进。在感控6S管理推进过程中，金铧护士长、郑浩等党员充分发挥先锋模范作用，主动担当“排头兵”。带领全体医护人员，对长安校区医院门诊部空间彻底整理、物品全面整顿。通过党建与管理深度融合，优化诊疗环境，筑牢医院感染防控的坚固防线。
成果成效：焕然一新，持续提升。如今，长安校区医院焕然一新，环境整洁、就诊体验感提升，疾病风险防控能力得到了强化，受到了师生、患者的好评。
长安校区党支部赵强书记表示，将以此次实践为起点，巩固成果，完善机制，创新管理，助力医院发展，为师生健康贡献力量。
