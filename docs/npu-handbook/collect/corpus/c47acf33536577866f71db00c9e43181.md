# 党委保卫部党支部传达学习学校2026年寒假务虚会和春季新学期中层干部会会议精神

3月6日，党委保卫部党支部召开全体党员大会，传达学校2026年寒假务虚会和春季新学期中层干部会精神，研究部署2026年度重点工作。会议由党支部书记朱建军主持。
会上，朱建军带领与会人员深入学习李言荣书记、宋保维校长在寒假务虚会和春季新学期中层干部会上的讲话，重点围绕学校“十五五”规划的发展目标和重点工作任务进行学习研讨，并结合部门实际，对新学期重点任务作出部署：一是强化党建引领，对照“四强”党支部标准推进支部建设，不断提升组织力和战斗力；二是健全联动机制，构建“公安+保卫+社区”研判体系；三是推动科技赋能，提高主动预警能力，推进视频监控、门禁、报警等安防系统一体化建设；四是聚焦主责主业，加大安全隐患排查整治力度，持续优化校园交通环境，提升社区服务保障水平；五是加强队伍建设，锤炼过硬政治素养、业务能力和服务意识，为学校高质量发展提供坚实保障。
会议强调，全体党员干部要提高政治站位，深刻学习领悟寒假务虚会和春季新学期中层干部会精神，牢牢锚定学校“一十百千”发展目标和“天下工大、世界三航”远景目标，以“时时放心不下”的责任感和“事事心中有底”的执行力，推动保卫工作高质量、高水平、高标准持续发展，为“十五五”开局起步奠定坚实基础。
