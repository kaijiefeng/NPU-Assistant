# 西北工业大学宁波研究院（浙江省三航科技概念验证中心） 概念验证专项资金项目征集通知

为深入贯彻创新驱动发展战略，服务浙江“全国研发、浙江验证、浙江转化”科技成果转化新格局，依托西北工业大学宁波研究院建设的浙江省三航科技概念验证中心（全省首批省级概念验证中心、“概念验证+技术经理人”机制试点单位），现面向研究院内外科研人员及全国合作单位，征集具备前瞻性、原创性的概念验证项目。
本中心立足宁波、服务浙江、链接全国，主动发现和承接全国范围内航空、航天、航海、新材料及相关硬科技领域尚处于实验室阶段或产业早期的原创成果和产业技术需求，在浙江完成技术可行性与商业可行性的双重验证，推动更多“技术样品”“产业需求”在宁波、在浙江加快转化为“市场产品”和“产业方案”。
一、项目要求（应同时满足）：
1. 技术先进性：项目核心技术具备显著的前瞻性、原创性和技术领先性，符合国家、浙江省及宁波市战略性新兴产业和先导产业发展方向
2. 市场潜力：项目提出的创新概念具备转化为有明确商业前景的产品或服务的潜力，目标市场清晰
3. 团队能力：项目负责人（申请人）在该领域具有较高学术水平；项目团队具备较高的商业化能力和创新实力
4. 可行性：项目实施方案合理，技术路线可行，验证目标明确，预期通过概念验证后的成果具有良好的产业化应用前景
5. 知识产权：项目核心知识产权归属清晰、无争议，申请人/团队拥有或可依法取得相关知识产权
二、申报流程
1. 申报
申报时间：本项目实行常态化申报。
申报材料：《概念验证项目申报书》、商业计划书。
2. 初评
浙江省三航科技概念验证中心对申请材料进行形式审查和初步筛选，主要考察项目与专项资金定位的契合度、基础条件等。
3. 专家评审
浙江省三航科技概念验证中心将组织技术专家、产业专家及投资专家组成评审委员会，依据以下核心维度对通过初评的项目进行量化与质性相结合的综合评估：
1）技术维度：创新性、成熟度、可验证性、知识产权。
2）市场维度：需求匹配、商业模式、团队能力。
4. 立项签约
对通过评审的项目予以立项，项目团队与浙江省三航科技概念验证中心正式签署《概念验证项目协议书》，明确双方权利义务、经费额度、考核指标等。
三、项目支持
通过评估获批立项的概念验证项目根据项目实际情况给予启动资金，最高可获得100万元的概念验证经费支持，资金使用应符合国家相关规定。
四、提交方式：
1. 填写概念验证项目申报书（附件1）（扫描下方二维码获取）
2. 将概念验证项目申报书和商业计划书发至邮箱：nanette@mail.nwpu.edu.cn
