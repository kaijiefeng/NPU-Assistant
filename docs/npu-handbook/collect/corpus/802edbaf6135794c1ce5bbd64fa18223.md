# 青春讲党课，奋进新征程｜电子信息学院初心党支部开展主题党日活动

为深入学习贯彻习近平新时代中国特色社会主义思想，推动理论学习与专业学习、科研实践相结合，11月4日，电子信息学院初心党支部在学院楼159会议室开展“青春讲党课，奋进新征程”主题党日活动。活动由党支部书记陈沛权主持，支部全体党员及发展对象参加。活动以微党课展示、交流研讨、互评提升为主要形式，结合红色历史、校友事迹和专业特色讲述初心故事，在交流学习中凝聚青春奋进力量。
青春开讲，以微党课诠释初心使命
活动中，六名学生党员依次登台，围绕伟大长征精神、科技报国使命、红色通信历史等主题，从总师校友扎根大飞机研制一线的坚守，讲到革命年代“半部电台”里的初心；从跨越时空的两代青年对话，讲到北斗导航、卫星通信背后的自主可控。他们结合电子信息专业特色与青年成长实际，把宏大的理论命题讲述成可感可信的青春表达。
交流互鉴，在研讨打磨中共同提升
微党课展示结束后，支部组织开展集中交流研讨。围绕如何突出长征精神的时代内涵、如何增强历史故事与现实实践的联系、如何体现电子信息专业特色，大家逐一对照作品找亮点、提建议，在相互切磋中打磨课程。大家一致认为，讲好一堂微党课，既要有扎实的理论支撑，也要善于从具体人物、真实故事和自身经历中寻找切入点，以小见大、以情动人，让理论宣讲更贴近青年学生的学习生活。
以讲促学，在知行合一中践行担当
此次主题党日活动将理论学习与微党课比赛相结合，让学生党员从理论学习的参与者，转变为主动思考、积极表达的宣讲者。自主选题、查阅资料、登台讲授、交流互评，每一个环节都是一次再学习：对伟大长征精神的理解更深了一层，对新时代青年使命的认识也更实了一分，表达能力在相互切磋中得到锻炼。
下一步，电子信息学院初心党支部将持续创新党员教育形式，丰富微党课宣讲、理论研讨、读书分享等学习载体，引导青年党员在学思践悟中坚定理想信念，在专业学习和科研实践中锤炼过硬本领，主动发挥先锋模范作用，以实际行动践行初心使命，让青春在科技报国的奋斗实践中绽放光彩。
