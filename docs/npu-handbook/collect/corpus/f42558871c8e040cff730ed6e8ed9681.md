# 自主水下航行器团队2022级硕士研究生学位论文集体开题答辩会圆满举行

2024年1月8日至9日，航海学院自主水下航行器团队2022级硕士研究生学位论文集体开题答辩会在航海学院东配楼顺利召开。航海学院院长潘光、党委书记刘朝亚、副院长曾向阳、学校研究生院杨珍老师、督导王育才教授、党建军教授以及自主水下航行器团队老师出席此次开题答辩会。会议由闫争超老师主持。
开题伊始，潘光院长、曾向阳副院长、杨珍老师依次上台致辞。潘光强调，根据学校的总师育人文化要求，学院和团队在研究生培养上应上下对齐、共同发力。研究生培养面临研究方向的选择问题，而研究方向对未来的工作规划和发展前景具有重要指导作用，研究方向应紧贴国际学术前沿，聚焦国家重大战略需求和学校重要科研方向。另外，开题报告的内容选择在很大程度上决定了学生的学术和职业方向，是提高学生科研能力的重要环节。他希望，学生和导师们结合团队承担的大型UUV、仿生柔体潜水器、新型水下航行器等科研任务，在有组织科研基础上，凝练出高质量的论文题目，更好地服务国家战略需求。这次集中开题作为一种新的尝试，打破传统单一方向分组答辩的模式，有助于拓展导师和学生的学术视野，希望这次尝试对学生成长、学院乃至学校的研究生培养工作提供有益的经验和做法。
曾向阳谈到，航海学院在研究生培养方面有着良好的传统、特色及优势，学校“127”目标对学院的研究生培养工作提出了相当高的要求，也希望学院能有创新的思维和做法。自主水下航行器团队在团队联合培养研究生方面一直有新的尝试，本次集中开题专家、老师和学生们一起观摩、探讨，是一次非常好的实践，对同学们硕士论文选题的新颖性、开题的可行性，乃至将来论文质量都有非常好的帮助。这次开题既是一次很好的学术交流机会，也是一次科研工作的研讨会，希望学生和老师们都能在这次开题中有所获益。
杨珍老师对本次开题工作表示高度认可，强调学院在硕士培养方面拥有较大的自主权，并表示研究生院将全力服务大家，助力研究生培养工作。
随后，团队62名学生针对大型UUV、仿生水下航行器、集群编队、传统AUV等应用对象等主题进行开题答辩，涉及总体设计技术、能源动力技术、导航控制技术、探测通信技术等方面。各位专家及老师仔细聆听，并给出详细的指导和建议。
学生开题答辩结束后，潘光院长进行了总结。本次集体开题基本达到预期，但也存在一些不足。主题聚焦需更清晰，团队现在的诸多项目为研究生开题提供了良好支撑，而指导老师要找准真问题，尤其是应用场景下的真问题。此次团队集体开题交叉融合了总体、动力、控制、探通等主体方向，是难得的学术研讨机会。
最后，刘朝亚进行了总结，他借用李言荣书记提出的评价一个干部水平高低就是看他的“长宽高”的标准，对同学们的学习和生活提出了期许：在“高”的层面，希望大家要树立远大理想，追求更高、更好、更远，要结合国家重大战略需求，努力朝“优秀硕士论文”目标迈进。在“宽”的层面，希望大家要有宽的胸怀和宽的知识面，要注重团结和包容，学会合作和欣赏别人。在“长”的层面，希望大家要谋划长远、高点定位、锐意进取，对自身提出更高的要求，为加快建设海洋强国做出贡献。他还对遵守保密规定提出了要求。最后，他希望同学们在专注科研的同时，要培养体育爱好，强健体魄，一起向未来。
