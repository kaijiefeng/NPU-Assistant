# 北京研究院组织全体教职工线上参加学习党的二十大精神全校干部师生大会-西北工业大学

11月9日下午西工大召开传达学习党的二十大精神全校干部师生大会。
校党委书记张炜从党的二十大精神的丰富内涵和重大意义、我国高等教育十年成就与变革、学校工作十年发展变化、认真学习宣传贯彻党的二十大精神等四个方面，作了题为《认真学习宣传贯彻党的二十大精神扎实推进学校事业高质量发展》的主题报告，向全校干部师生传达党的二十大精神，并对下一步工作作出安排部署。北京研究院组织全体教职工进行了线上学习。
