# 南京大学刘怀玉教授做客我校翱翔灵犀学术殿堂-西北工业大学

2026年5月23日，南京大学刘怀玉教授做客西北工业大学翱翔灵犀学术殿堂第963期，为师生带来题为《从抽象的一般性走向具体的普遍性的历史空间辩证法》的报告，马克思主义学院张云龙教授主持报告会。
报告伊始，刘怀玉教授从历史唯物主义的本体论、认识论双重视角切入，以“不平衡”为关键词，强调中国革命与中国式现代化道路的哲学理论基础之一是唯物辩证法的矛盾普遍性与特殊性相互关系思想，但其渊源却是德国辩证法传统中的抽象与具体的关系理论以及中国传统哲学上的共相与殊相的关系思想。进一步，刘怀玉教授分别从历史哲学、社会哲学、认识论、文明形态历史观四个维度，系统分析中国式现代化的哲学逻辑，介绍了马克思关于现代社会的有机体系理论、城乡协调发展、立足整体视角的国家工程建设问题等，强调要以空间辩证法的视野，从整体上把握中国式现代化的矛盾与张力。
报告交流环节中，在场学生积极提问，分别围绕阿尔都塞结构主义、跨越卡夫丁峡谷与社会空间转移等前沿学术问题与刘教授展开交流。
报告尾声，曹瑜教授表示，刘怀玉教授从中国式现代化发展的特殊性与不平衡性切入，为解读马克思主义辩证法、黑格尔辩证法以及当代国外马克思主义理论提供了全新研究视角。张云龙教授作总结发言。他指出，刘怀玉教授从基础理论出发，层层深入，为中国式现代化研究提供了极具深度的学理范式。
本次讲座在浓厚的学术氛围中圆满结束。
