# 2026年实践育人“三个一”工程——红色实践教育推进会暨“红色基因 蓝色情怀”主题实践团出征仪式顺利举行

7月6日，党委学生工作部在友谊校区组织开展2026年实践育人“三个一”工程——红色实践教育推进会暨“红色基因 蓝色情怀”主题实践团出征仪式。党委学生工作部相关负责同志、各学院（研究院）对口党建的学工干部及“红色基因 蓝色情怀”主题实践带队老师参加会议。会议由党委学生工作部学生党建思政教育办公室主任张文静主持。
会议深入阐述了学校党委实施实践育人“三个一”工程的现实背景、重要意义及工作要点，聚焦“传承红色基因”模块，详细解读了红色实践教育的总体思路及实施方案，围绕实践统筹推进、特色建设、闭环提效进行了系统部署，实践行前准备、过程管理、复盘提升进行了细致辅导，强调各学院（研究院）要着力在深度、广度、亮度上靶向发力，做实和拓展实践平台，革新和催生实践动能。
在实践育人“三个一”工程暑期专项——“红色基因 蓝色情怀”主题实践团出征仪式上，张文静为实践队授旗，实践队带队老师代表材料学院刘昕浩接受授旗。
会议围绕“红色基因 蓝色情怀”主题实践的实践内容进行了系统讲解，聚焦加强组织领导、加强宣传引导、加强安全保障三方面明确了工作流程及规范化要求，强调要坚持以习近平新时代中国特色社会主义思想为指导，紧紧围绕唱响爱党爱国爱社会主义主旋律，深入拓展实践育人空间和阵地，教育引导广大学生扎身实践课堂、躬身实践建功，传承红色基因，厚植蓝色情怀，把青春奋斗融入中国式现代化建设大局。
最后，会议就“到延安去”西工大学子圣地行、“红色基因 蓝色情怀”主题实践等工作的具体开展相关问题进行了细致解答。
