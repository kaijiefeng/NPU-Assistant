# 新认定研究生导师岗前谈话会议召开

9月28日下午，我院召开了2026年度新认定研究生导师岗前谈话会议。
会议伊始，徐伟侠副院长就导师岗位设置要求、基本素质标准、立德树人职责、权利与行为准则、激励与退出机制等方面作了系统解读，指出导师在研究生培养中承担的第一责任人角色，帮助新认定导师准确把握岗位职责与规范要求。
随后，盛其杰院长向两位新认定的研究生导师严宇超、赵建村表示祝贺，同时希望两位导师对照“四有”好老师标准，牢记育人初心，在学术指导和思想引领两方面同步发力，把育人要求落实到日常指导的具体行动中。
王涛副院长聚焦导学关系调适、研究生思想政治教育和心理健康等重点工作，结合实际案例提醒导师切实履行“第一责任人”职责，筑牢研究生思想防线，关心学生身心发展，营造融洽和谐的导学氛围。
交流发言环节，新认定导师严宇超、赵建村依次表态。他们表示始终以立德树人为根本遵循，坚持严谨治学，严守导师指导行为底线，以更高标准要求自己，努力成为学生学术路上的引路人和成长途中的陪伴者，为研究生培养和研究院发展添砖加瓦。
最后，新认定导师与谈话小组签署了《研究生导师岗位责任书》，谈话小组向新认定导师颁发聘书并合影留念。
