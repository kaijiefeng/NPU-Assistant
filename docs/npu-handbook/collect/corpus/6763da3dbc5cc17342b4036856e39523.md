# 保卫处开展安保人员暑期业务技能培训

为提升安保人员的综合业务技能水平，增强安保人员的纪律意识和团队协作能力，6月30日-8月25日，保卫处集中开展暑期业务技能专项培训系列课程，训练主题包括队列军姿训练、反恐处突培训和消防安全培训。
队列军姿培训课上，来自西安市公安局高新分局的田海卫警官和李朋刚警官详细讲授了队列军姿基本动作要领，对安保人员进行分组指导，耐心示范各个动作，手把手纠正，队员们认真学习，直至熟练掌握。
反恐处突培训的教官是西安市公安局高新分局东大派出所的李帅警官，他深入讲解了《恐怖暴力事件的危害与处置》的理论基础知识，开展反恐防暴器材的实操演练，逐一介绍防暴盾牌、钢叉、警棍、抓捕器等防暴器材的基本操作方法。反复强调动作要领，分组进行模拟场景式训练。
消防安全培训课上，西安市消防救援支队重点保卫处的王巍警官讲解了消防法律法规、消防工作方针和原则、火灾的概念、相关重点场所要求和常用的消防设施器材等五个方面的内容，引导学员们夯实理论知识基础，进一步加强理论对实践的指导作用，学员们纷纷表示，讲授课程内容非常实用，补足了自身理论知识短板。
通过暑期集中业务培训，引导校卫队员进一步掌握了队列、反恐、消防等业务理论知识，提升了综合素质，以更加饱满的精神面貌迎接新学期。
