# 学校召开2026年本科教学获奖教师代表座谈会-西北工业大学教务部

9月7日下午，学校组织召开2026年本科教学获奖教师代表座谈会，表彰2026年本科教学获奖教师代表，共同学习暑假务虚会、秋季学期中层干部会精神，研究落实举措，畅谈育人经验。副校长岳晓奎，2026年本科教学卓越名师和新秀、本科最满意教师代表、职能部门代表参加了会议。会议由教务部部长王海鹏主持。
会上，教务部副部长王劲传达了2026年暑假务虚会、秋季学期中层干部会精神。获奖教师代表紧扣科技产业变革新挑战、人工智能新机遇、教育强国新要求，结合专业优化、课堂教学、教学研究、课程建设、教材建设、科教协同育人、教学竞赛、教学能力提升等维度，分享了各自的育人实践与思考，并对学校更好更快发展，提高育人水平积极建言献策。老师们由衷感慨，感谢学校对一线教师的关心与支持，作为一线教师，要牢记为党育人、为国育才初心使命，以人民教育家为榜样，以德立身、以德立学、以德施教，做好学生为学、为事、为人的引路人。职能部门代表，组织部副部长王玉玲、宣传部副部长付怡、人力资源部副部长宗凡、计划财务部副部长张鹏对投身课堂、坚守教学一线的老师们表达了由衷的敬意，并表示，将高度重视老师们提出的意见和建议，认真研究，为一线教师做好服务保障工作。
随后，宗凡、张鹏为本科最满意教师代表颁奖，王玉玲、付怡为卓越新秀代表颁奖，岳晓奎为卓越名师代表颁奖。
王海鹏对受到表彰的教师表示祝贺，感谢教师们对学校本科人才培养作出的贡献，感谢各职能部门对教务部工作的大力支持。他表示，教务部将继续协同相关部门和各教学单位，面向国家重大战略需求，聚焦“总师型”人才培养体系完善，以专业调整为抓手，以AI赋能为主线，以机制创新为牵引，扎实工作、锐意进取，不断优化“招生—培养—深造”联动机制，以更大决心、更实举措全力推动本科人才培养“十五五”规划任务落地。
岳晓奎向获奖教师表示祝贺，对一直以来为学校人才培养事业发展辛勤耕耘的教师们表示感谢，并致以节日的祝福。岳晓奎表示，今年是学校“十五五”开局之年，正处在加快建设中国特色世界一流大学的关键时期。各位获奖教师要认真学习领会暑假务虚会、秋季学期中层干部会精神，牢记为党育人、为国育才初心使命，以严实作风立标打样，恪尽名师之责、勇担新秀之任，带动全体一线教师在教学研究、教材建设、课堂教学、实践教学、招生宣传等方面继续坚守，以“排头兵”的担当推动学校“总师型”人才培养体系不断完善，为国防现代化和新型工业化源源不断培养造就卓越“总师型”人才。岳晓奎强调，教务部要持续发挥人才培养“链主”作用，链接职能部门与教学单位，调动校内外资源，不断完善“协同—联动—闭环”机制；要始终把服务做在前面、把细节落到实处，让老师们少一分后顾之忧，多一份从容笃定，心无旁骛地深耕课堂、潜心育人。
