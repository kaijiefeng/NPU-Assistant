# 书香润初心 共读砺信仰——电子信息学院硕士生第十二党支部举办红色经典读书分享会

思想之光，照亮成长之路；书香之气，砥砺入党初心。5月18日，硕士生第十二党支部以“读红色经典、悟思想伟力、筑信仰根基”为主题，举办了一场别开生面的红色经典读书分享会。活动以“读原著、学原文、悟原理、强信念”为主线，引导青年同志从经典中汲取精神力量，在书香中感悟思想伟力、传承红色精神、坚定入党初心。
读经典 悟真理：青年之声激荡信仰力量
活动现场氛围庄重而热烈，多位同志依次分享红色经典著作，结合自身成长经历，畅谈学习收获与思想感悟。
朱泽昊同志率先分享《毛泽东选集》，并诵读了关于实事求是、群众路线的经典论述。他表示：“这部著作是中国革命与建设的思想宝库，作为新时代青年，我们要从中学习科学的立场观点方法，做到学思用贯通、知信行统一。”
李京华同志聚焦《邓小平时代》，围绕改革开放的历史进程与时代精神，节选了解放思想、开拓创新的篇章。他谈到：“要从波澜壮阔的改革开放历程中汲取奋进力量，坚定走中国特色社会主义道路的信念。”
杨晶同志深情分享了《习近平的七年知青岁月》，诵读了习近平总书记与群众同甘共苦、扎根基层的动人片段。他说：“七年知青岁月彰显了习近平总书记的人民情怀与实干品格，青年一代要以习近平总书记为榜样，扎根基层、脚踏实地、心系群众，在磨砺中成长成才。”
忆峥嵘 铸忠诚：红色基因代代相传
陈钰彬同志带来《地球的红飘带》，节选了红军长征艰苦卓绝、信念如磐的经典段落。她感慨到：“长征精神是永不褪色的红色基因。作为入党积极分子，要传承不怕牺牲、百折不挠的意志，在学习生活中迎难而上、勇毅前行。”
石馨瑜同志动情讲述了《红岩》中革命先烈坚守信仰、宁死不屈的故事。她说道：“江姐等先烈用生命诠释忠诚与担当，我们要铭记历史、坚守底线，以坚定的理想信念砥砺品格，扣好人生‘第一粒扣子’。”
杨秉玺同志分享《朝花夕拾》，结合鲁迅笔下的家国情怀与青年担当，节选了体现爱国奋进、追求真理的篇章。他表示：“要以先辈为镜，厚植爱国情怀、锤炼过硬本领，以实际行动向党组织靠拢。”
深交流 再出发：坚定信念勇担使命
分享环节结束后，全体同志围绕理论学习、思想提升、入党动机、实践行动等话题展开热烈讨论。大家一致认为，此次读书分享会既是一次红色精神的洗礼，更是一场思想的“加油充电”，进一步加深了对党的历史、理论与初心使命的理解，更加坚定了入党积极分子以党员标准严格要求自己、积极向党组织靠拢的决心。
支部书记康泽博对支部全体成员提出两点希望：一是以书为媒强理论，持续深学红色经典与党的创新理论，筑牢思想根基；二是以学促行担使命，把学习成果转化为学习科研、服务集体、奉献社会的实际行动。
结语
书香润心，信仰铸魂。本次读书分享会主题鲜明、内容扎实、成效显著，有效提升了支部党员的理论水平与思想觉悟，丰富了支部思想教育形式。康泽博表示未来将持续开展形式多样的理论学习与红色教育活动，引导党员在学思践悟中坚定信仰、在奋发有为中践行初心，为支部建设注入强劲红色动力。
