# 软件学院受邀参加“第十二届全国软件工程研究生教育研讨会”

2026年4月24日至26日，由示范性软件学院联盟主办的“第十二届全国软件工程研究生教育研讨会”在江西南昌顺利召开。本次会议以“AI时代软件工程研究生教育高质量发展”为主题，聚焦人工智能背景下软件工程学科的创新发展、学位点建设与评估、卓越工程师培养路径、课程体系重构、科研与教学深度融合等关键议题展开深入研讨。
4月25日，西工大软件学院院长郑江滨受邀作大会主题报告。他以《科研优势厚植研究生培养资源建设》为题，系统阐述了研究生教育中将科研优势转化为育人资源方面的理念、方法与学院的实践探索。郑江滨指出，应系统提取优质科研成果中的育人要素，并将其有效映射至研究生核心能力培养全过程。提出四类优质科研成果有效转化为育人资源的12种方法。一是将理论型成果（论文、专著等）转化为课程内容、教材等培养资源，实现“课程即科研入口，科研即课程延伸”的良性互动机制；二是将技术型成果（核心算法、专利技术）转化为实验教学案例、竞赛课题等资源，推动课赛研贯通，提升学生实践创新与攻关能力；三是将系统型成果（集成平台、复杂系统及国际合作成果）转化为课程资源、实践载体与联合培养平台等资源，提升研究生系统攻关能力与国际化视野；四是将技术转化型成果(企业生产工艺、生产产品)，转化为校企联合实践平台及共建课程等培养资源，提升研究生工程实践与协同攻关能力。郑江滨强调，推动科研团队内部成果向学院层面共享育人资源的转化，是实现科研成果育人价值的关键落脚点。
本次大会报告系统呈现了学院在“以科研优势厚植研究生培养资源”方面的扎实探索与阶段性成果，总结提炼出具有可复制、可推广价值的育人资源转化路径与实践模式，为各高校在人工智能时代推动软件工程研究生教育提质增效、创新资源建设机制，提供了参考。
