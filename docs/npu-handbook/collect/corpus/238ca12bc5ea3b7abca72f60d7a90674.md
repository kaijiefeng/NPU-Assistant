# 化学与化工学院-西北工业大学医院

责任医师：王莉（主治医师）
简介：
硕士研究生，曾就职于西安交通大学第一附属医院东院。业务范围：心内科常见病、多发病的诊治，特别对顽固性高血压，心律失常等的药物治疗积累了丰富的临床经验，工作至今于核心期刊发表论文五篇。
（备注：学院责任医师是医院与学院之间的桥梁，可为我校师生提供健康咨询、健康宣教、体检结果释疑、急救知识技能培训等服务。有需求者，可通过扫描学院责任医师二维码联系。）
