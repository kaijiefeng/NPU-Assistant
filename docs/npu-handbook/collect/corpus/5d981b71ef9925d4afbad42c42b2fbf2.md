# 外国语学院召开树立和践行正确政绩观学习教育工作推进会

3月23日，外国语学院召开了树立和践行正确政绩观学习教育推进会。学院党政领导班子、师生党支部书记、办公室主任等参加了会议。会议由学院党委书记王高祖主持。
王高祖带领与会人员学习了习近平总书记在全国两会期间的重要讲话和全国两会精神，传达了学校关于学习贯彻全国两会精神的具体要求。随后，他带领大家学习了学校党委关于树立和践行正确政绩观学习教育的实施方案和工作要求，通报了学院开展学习教育的具体安排，要求党政领导班子和各党支部要准确把握工作重点，扎实开展学习教育。
按照学习教育查摆问题和整治整改要求，会议通报了2025年度年终考核、绩效核算有关事宜。王高祖强调，学院严格按照学校部署要求，规范开展有关工作，确保考核结果和绩效分配公平公正，下一步将持续加强对学校“十五五”规划和学校年度重点工作、学院重大决策等的宣贯解读，充分调动全体教职工干事创业的积极性。
会议要求，学院党员领导干部和各党支部要把思想和行动统一到习近平总书记重要讲话和全国两会精神上来，将树立正确政绩观融入师风学风建设；要深学《习近平关于树立和践行正确政绩观论述摘编》，用好正反典型，树牢正确政绩观；要从严对照查摆，发扬民主、听取意见，强化党性锤炼和作风改进；要一体贯通整改，聚焦重点整治，压实责任推动，加强“当下改”和“长久立”，健全长效机制，主动接受师生监督，以实干实绩推进学院各项工作高水平高质量高标准发展，为学校“一十百千”核心指标达成贡献力量。（文/王开薇；审稿/王高祖）
