# 马克思主义学院党委召开党委扩大会议-西北工业大学

3月5日下午，马克思主义学院召开党委扩大会议，集中传达学习学校2026年寒假务虚会及春季新学期中层干部会议精神，专题部署学院树立和践行正确政绩观学习教育工作。学院领导班子成员、党委委员、各教工党支部书记、系主任、教学主任等参加会议，会议由学院党委书记王彦革主持。
会议首先由学院党委书记王彦革传达学校2026年寒假务虚会、春季新学期中层干部会精神，带领与会人员全面学习会议部署要求，结合学院工作实际，对2026年学院党建重点任务进行系统安排，明确工作方向、细化落实举措，推动学校会议精神在学院落地生根。
随后，王彦革领学习近平总书记关于树立和践行正确政绩观的重要论述，传达学习中共中央办公厅《关于在全党开展树立和践行正确政绩观学习教育的通知》、中央党的建设工作领导小组会议及学校党委树立和践行正确政绩观学习教育启动部署会精神。会议还研究部署了学院树立和践行正确政绩观学习教育相关工作，要求学院党委、各党支部、各系提高政治站位，深学细悟，切实把正确政绩观融入办学治院、育人育才全过程，转化为履职尽责、真抓实干的思想自觉和行动自觉。
最后，学院院长杨云霞解读了学院“十五五”规划核心内容及新学期重点工作安排，并作总结讲话。她强调，各党支部、各系要以此次学习教育为契机，紧扣学校和学院工作部署，切实把学习成果转化为推动工作的强大动力，迅速调整状态、凝心聚力，扎实推进新学期各项工作有序开展，确保全年目标任务高质量完成。
