# 铸剑班的夏天：跨越两万公里，在知行合一中淬炼锋芒！

今年暑期，在班主任、党委学生工作部副部长、学生处副处长管峻，党委学生工作部副部长、学生处副处长彭蓉，班级指导教师、学生党建思政教育办公室主任张文静以及班级指导教师王紫东的带领下，铸剑班学员以多元主题为导向，奔赴海内外开展2025年度暑期“大实践”。学员们远赴肯尼亚内罗毕，深度参与联合国学术理事会（ACUNS）2025年会；走进上海交通大学参加“全球视野 中国情怀”全球胜任力青年训练营；应联合国训练研究所邀请，前往瑞士和意大利参加联合国青年领导力发展项目；赴北京开展“继往开来，京华砺刃”专题国内实践；并深入多家重点领域单位开展实习锻炼。总行程跨越两万余公里，学员们以脚步丈量世界，以实践淬炼真知，在知行融合中凝聚奋进力量。
联合国学术理事会（ACUNS）2025年会
6月22日至27日，铸剑班16名学员全程深度参与联合国学术理事会（ACUNS）2025年会，在这场汇聚全球顶尖学者的盛会上，学员们不仅见证了国际治理前沿讨论，更以自身专业素养和展现出来的责任担当获得了与会人员的认可。会议结束后，实践队开展内罗毕市内研学活动，溯源非洲文明，拓宽人文视野，并深度聚焦当代中国企业的海外实践与担当，在杰出校友马骋远的带领和讲解下，参观中航国际环球贸易中心（GTC）、中航国际肯尼亚代表处展馆以及中航科创有限公司，深刻认识新时代青年科技人才在全球舞台上的责任与机遇。
“全球视野 中国情怀”上海交大全球胜任力青年训练营
6月27日至29日，铸剑班5位学员代表应邀参加上海交通大学全球胜任力青年训练营，与来自35所国内外院校的400余名师生共同参训交流，学习国际规则，培养全球视野与跨文化交流交际能力。在训练营中，铸剑班学员以墙报展示和PPT汇报的形式，围绕联合国可持续发展目标进行了专题分享，展现出过硬的专业素养和开阔的视野，并以优异表现取得了5人全部获奖、共获奖9人次的好成绩。
2025年联合国青年领导力发展项目
7月5日—7月16日，在学校“翱翔四海”项目的支持下，在学校国际合作处的统筹安排下，受联合国训练研究所邀请，学校铸剑班31名成员、大学生艺术团13名成员，在党委学生工作部和艺术教育中心相关负责教师的带领下，赴瑞士和意大利，开展为期12天的联合国青年领导力发展项目深度学习调研，聚焦全球治理、AI向善、文化艺术，深度解码联合国运作、碰撞前沿科技思想、共探欧洲文明精髓，有力提升同学们的全球胜任力与青年领导力，在世界舞台展现新时代中国青年构建人类命运共同体的博大胸怀与卓越行动力。
“继往开来 京华砺刃”暑期国内实践
8月17日至21日，铸剑班24名学员赴北京开展专题实践。适逢抗战胜利80周年，学员在抗日战争纪念馆、中国人民革命军事博物馆体悟抗战精神、革命精神在新时代的延续与升华，在保利艺术博物馆和北大红楼，体会历史纵深与文化底蕴对人才成长的重要性。在中国航空工业历史博物馆感受“航空报国”的精神传承；于航天科工二院，深入了解“空天神盾”研制历程和“软件定义装备”等前沿理念，体会军民融合的深度与广度；与中国航空工业发展中心领导和校友座谈，理解其“竞争、创新、唯实、合作”理念……本次跨越“5馆2所1校”的专题实践，通过历史与未来对话、技术与艺术融合，让学员们在多重维度中深化了对“总师型”人才内涵的认知，为今后的“铸剑征程”注入新动力。
重点领域单位实习锻炼
7月3日至8月20日，党委学生工作部联合多家重点单位共同组织开展了2025年度铸剑班暑期实习活动，选派13名铸剑班学员分别赴中国航空工业集团公司西安航空计算技术研究所、中国空气动力研究与发展中心、之江实验室、中兴通讯股份有限公司、西安精雕软件科技有限公司开展实习锻炼，在实践中拓宽视野、增长才干，进一步坚定“立大志向、上大舞台、入主战场、干大事业”的信念。
万里路遥不忘初心，山海无阻淬炼锋芒。这个夏天，铸剑班学员以脚步丈量山河，以实践印证真知，在跨越四万里的壮阔旅程中，将“心怀家国、堪当大任”的信念熔铸进炽热的理想。征程未竟，步履不停。全体成员必将以更加坚定的信念、更加澎湃的激情，矢志追随“天下工大、世界三航”的宏伟蓝图，在成为新时代“总师型”人才的道路上砥砺前行、再续华章！
