# 学院召开2025年度党支部书记抓党建述职评议考核大会

3月10日上午，教育实验学院召开2025年度党支部书记抓党建述职评议考核大会。学院党委筹备工作组成员、党支部书记、教职工党员代表及学生代表参会，会议由牟蕾主持。
会前，牟蕾简要介绍了2025年度党支部书记抓党建述职评议考核的主要内容及评议方法。会上，四名党支部书记紧扣党建工作职责，围绕突出深入学习贯彻习近平新时代中国特色社会主义思想、突出强化党支部政治功能和组织功能、突出落实基层党建工作重点任务、突出做好师生思想政治教育、突出落实全面从严治党要求以及上年度述职评议点评查摆问题整改情况、存在的问题和下一步工作计划等6个方面进行现场述职。学院党委筹备工作组成员对支部书记一年来的工作进行了点评，与会师生党员代表对述职人员进行了评议。
会议充分肯定了各党支部2025年度党建工作取得的成效。牟蕾表示，2026年是“十五五”规划开局之年，希望各支部书记要切实担起管党治党政治责任，对标学校“一十百千”发展目标和“天下工大、世界三航”远景目标，创新思路、精准发力，推动党建与未来技术学院和学科交叉中心实体化建设、成建制“总师型”拔尖创新人才培养等工作同谋划、同部署、同落实，同时要建强支部堡垒，创新党建工作载体，打造具有学院特色的党建品牌，切实提升学院党建工作质量，以更加饱满的精神和热情，为学校“双一流”建设和学院高质量发展贡献力量。
