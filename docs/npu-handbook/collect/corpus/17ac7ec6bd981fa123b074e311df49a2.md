# 后勤集团赴陕西交控集团党风廉政教育基地开展实践研学-后勤集团

为扎实推进树立和践行正确政绩观学习教育、落实集团全面从严治党工作部署，4月2日，后勤集团党委组织党员干部赴陕西交控集团党风廉政教育基地，开展沉浸式、体验式实践研学活动。
在教育基地讲解员引导下，党员干部先后参观“纪律立党历久弥坚”“从严治党一以贯之”“依规治党守正创新”“殷鉴不远警钟长鸣”“德润三秦廉洁齐家”等八个主题展厅和廉洁文化长廊。通过互动体验、多媒体展示和运用身边“真案例”“活教材”情景再现等方式，带领大家回顾了中国共产党反腐倡廉的历史进程和取得的显著成效。大家纷纷表示，此次研学跳出“课堂式”学习模式，以“看得见、触得到”的方式敲响警钟，将以典型案例为镜鉴，始终牢记初心使命，把正确政绩观融入后勤服务保障各环节，以“时时放心不下”的责任感做好各项工作。
后续集团将持续创新学习形式，把廉政教育与后勤工作实际紧密结合，引导党员干部以廉洁作风、务实行动践行“服务保障为根本、提质增效为关键、师生满意为标尺”的服务宗旨，为学校高质量发展提供清廉高效的后勤保障。
