# 健步凝心强体魄 砥砺奋进勇担当—化工系党支部健步走挑战活动圆满落幕

为丰富支部党建文体生活，缓解党员教师教学科研压力，培养健康运动习惯，化工系党支部组织开展了为期一个月的健步走挑战活动，引导全体党员以强健体魄和饱满状态，更好投身立德树人与科研攻关工作。
本次活动贴合教师工作实际，采用轻量化、常态化的参与模式，不限场地、不设门槛，鼓励党员教师利用通勤、课余等碎片化时间自主锻炼、每日打卡。灵活便捷的活动形式得到了支部党员的积极响应。大家相互鼓励、坚持参与，营造出积极向上、崇尚健康的良好氛围。
为期一个月的挑战中，全体党员持之以恒、积极比拼，赛出风采、赛出佳绩。单日步数榜单中，凌博凯以32956步位列第一，王欣、张宝亮分别以28032步、22974步紧随其后。月度总步数比拼中，张和鹏、张爱波、谢君健三位老师凭借稳定的表现位居前三。在步数提升榜单中，禚司飞、张蕾、黄珊三位老师进步显著，展现出突破自我、积极进取的良好精神面貌。
本次健步走活动是支部推进“暖心党建”的生动实践，有效帮助教师舒缓身心、改善作息，进一步增强了支部的凝聚力和向心力，也丰富了支部文体活动形式。下一步，化工系党支部将常态化开展健康文体活动，引导党员把持之以恒、拼搏进取的运动精神转化为履职担当的工作动力，立足岗位、实干笃行，为学院高质量发展贡献力量。
