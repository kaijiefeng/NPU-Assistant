# 初探图书馆，笃行新起点—数学与统计学院新生图书馆入学教育活动

为帮助新生熟悉图书馆的资源与服务、筑牢信息素养根基，图书馆为数学与统计学院2025级新生组织了一场图书馆新生入学教育活动——从校史脉络到航空记忆，从院士风采到三航特色。

**方寸藏章，见证校史**：新生们在历史发展区域通过不同年代的馆藏章，了解学校从西北工学院至今的发展历程，馆藏章成为了读懂校史的一把“钥匙”。

**航空史料，触摸初心**：沿着楼梯向上，大家来到六楼姜长英航空史料馆。泛黄的航空图纸、珍贵的文献及老式飞机模型，记录了中国航空事业的起步与飞跃。不少新生驻足细观，感受“航空报国”的初心。

**院士风采，启迪未来**：在八楼院士简介区和四楼三航特色展区，同学们进一步触摸专业未来：院士科研事迹激励人心，航天器零部件模型、无人机设计等展示，也让新生对所学专业有了更具体的想象。

**资源指南，赋能启航**：最后，图书馆为新生带来“基础服务与资源使用指引”讲座，涵盖借还书、电子资源检索、论文引用规范等内容，这场讲座消除了新生对“图书馆使用”的陌生感，帮助同学们未来更充分地利用馆内资源。

此次活动不仅帮助新生们直观地了解了图书馆的空间布局与资源服务，更引导大家掌握利用学术资源的核心技能。图书馆丰富的馆藏、便捷的设施与专业的支持，将转化为同学们未来四年专业学习与学术探索中的坚实助力。
