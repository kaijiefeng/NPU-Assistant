# 党委保卫部开展网络安全宣传活动暨防范电信网络诈骗专题讲座

为切实提升辖区居民的网络安全意识与防范电信网络诈骗能力，筑牢社区反诈安全防线，值此网络安全宣传周之际，党委保卫部于9月15日下午在友谊校区西馆组织开展网络安全宣传活动——防范电信网络诈骗专题讲座。
本次活动特邀西安市公安局碑林分局一级警长田江龙担任主讲，社区居民代表、社区工作人员及党委保卫部安保人员参加了相关培训讲座。
讲座中，田江龙以通俗易懂的语言，讲解了实用的识诈技巧，并深入剖析了当前高发的电信网络诈骗手段和类型。他结合工作中的真实案例和办案纪实，揭示了诈骗分子的常用话术与作案套路，直观展现了电信网络诈骗的危害。同时，重点讲解了“六不三问”的防诈准则，即不轻信、不汇款、不透漏、不扫码、不点击链接、不接转接电话，遇可疑情况问警察、问银行、问亲友。
此次专题讲座有效扩大了反诈宣传的覆盖面，进一步提升了辖区居民的防诈意识和识诈能力，为守护群众“钱袋子”安全助力。
