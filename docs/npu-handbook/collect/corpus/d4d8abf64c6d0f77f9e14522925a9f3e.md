# 党委保卫部为2024级新生开展系列安全教育讲座

为进一步筑牢校园安全防线，有效提升了在新生的安全防范意识，9月2日至9月6日，党委保卫部为各学院开展新生安全宣传讲座，取得了较好宣传教育实效。
党委保卫部筑牢“宣传也是战斗力”的理念，提前谋划，精心准备，选拔经验丰富的骨干力量参与宣传，设计印刷校园安全宣传页，根据大学生的心理特征与行为特点设计讲座内容和宣传方式，提高讲座的趣味性和参与性，充分做好前期准备工作。
新生安全教育开展期间，党委保卫部四天内连续举办20场讲座，从六个方面全景展示校园保卫工作概况，通过制度讲解、案例解析、现场答疑等形式，全面系统的讲解校园安全事项。通俗易懂的讲解，诙谐幽默的语言风格，将一条条抽象的保卫工作制度演变为贴近校园生活的事例，朗朗上口的安全教育“七字歌”更是激发了学生的学习兴趣，现场互动气氛轻松热烈。
通过宣传讲座，一方面有效提升了学生的安全意识和法治观念，另一方面帮助学生掌握甄别危险，提升自我保护技能。此外，党委保卫部还协调属地公安机关开展了“反诈骗宣传进校园”活动，多名警官为新生开展了防范电信诈骗专题讲座。
2024年新生安全讲座覆盖20个学院的3000余名新生，既注重了内容的专业性和全面性，又充分考虑形式的趣味性和通俗性，学生们表现出了浓厚的兴趣，取得了良好效果。
