# 管理学院在第四届CMAU大赛中斩获多项荣誉

近日，第四届CMAU全国大学生市场研究与商业策划大赛全国总决赛在西安交通大学落下帷幕。经过专业知识认证考试、校内选拔赛、分赛区竞赛、全国总决赛的激烈角逐，西工大学子们凭借扎实的专业知识、出色的团队协作和创新的商业思维，在本次大赛中取得了卓越的成绩，荣获两项国家级一等奖、一项国家级二等奖以及最佳组织奖。
CMAU全国大学生市场研究与商业策划大赛由中国高等院校市场学研究会CMAU与Credamo见数联合主办，致力于通过大赛培养学生的市场研究与商业策划的专业技术与实践能力，为将来个人就业与发展打下良好基础。作为聚焦市场研究与商业实践的权威赛事，该赛事已入选中国高等教育学会竞赛目录，吸引全国超600所高校、数万学生同场竞技。本届赛事共2881支团队参加，经层层选拔，最终推送108支团队晋级全国总决赛，展开巅峰对决。
来自管理学院的三支团队历经多轮比拼，在总决赛取得较好成绩。其中由常玉老师和卢亭宇老师指导的“你管我对不队”，以及谢言老师指导的“美貌侦查队”两支队伍凭借扎实的市场调研、创新的商业策划，成功突围斩获全国一等奖；卢亭宇老师和常玉老师指导的“疯狂星期四”队伍聚焦企业真实痛点，以精准洞察与可行方案拿下全国二等奖。赛场上，各队伍均展现出超强专业能力与综合学科素养，展现了西工大学子的良好精神风貌。
学院全链营销与人智协同管理实践基地和企业经营与创业模拟创新实践基地高度重视赛事筹备，从赛事动员激活学生参与热情，到组队构建多元化知识储备，再到专业教师全程护航、打磨方案细节，凭借在本次大赛中的精心组织和出色表现，代表学校荣获最佳组织奖，成为赛事中亮眼的“西工大名片”。
这份成绩，是学院“以赛促学、以赛促教”模式的具体现。近年来，管理学院深耕实践育人，依托企业案例库、创新实践平台，推动专业知识与商业场景深度融合，让学生在“解决真问题”中练就硬本领。参赛学生代表队队长王越坦言，备赛不仅是专业能力的试炼场，更是团队协作、市场洞察的成长课，让他们清晰触摸到行业脉搏。
未来，管理学院将持续以高水平学科竞赛为抓手，深化实践育人路径，为学校“总师型”人才培养注入商科活力，在培育适应市场需求的拔尖创新人才道路上，续写西工大人的奋进故事，让更多学子在商业实践的浪潮中乘风破浪，绽放光彩！
