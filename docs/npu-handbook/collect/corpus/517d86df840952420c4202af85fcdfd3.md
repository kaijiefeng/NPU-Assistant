# 后勤办公室党支部参加党员专题党课学习会

为了深入学习贯彻落实党的十九大精神，深刻领会党的十九大报告主要内容和精神实质，用党的先进理论统一党员干部思想，促进学校后勤管理工作的开展。根据学校党委总体部署和机关党委11月份理论学习计划安排，11月29日下午2:30，在党政办公楼A座327会议室后勤办公室党支部与纪委监察处党支部联合举办专题党课学习会。参加专题党课学习会的校领导有：校纪委书记张海兰同志；全体党员参加了本次专题学习会。
学习会由后勤办公室党支部书记、主任赵刚主持。邀请校纪委副书记、监察处处长高广元作题为“全面从严治党，推进党的建设新的伟大工程”专题辅导讲座。高书记从“党的十八大以来，全面从严治党取得显著成就；成就是如何取得的；全面从严治党新成就助推党的建设新工程；党的十九大报告为今后从严治党指明了方向等四个方面进行了专题辅导，用大量详细的数字讲述了我们党坚持全面从严治党方针，推进党的建设、反腐倡廉取得显著成就；从“两个坚持”、“两个以”和“5+2”总体布局等方面分析解读了党的十九大报告中，全面从严治党理论创新和奋斗方向。
后勤办公室全体党员通过专题辅导讲座，系统学习了党的十九大报告中全面从严治党主要内容，思想认识得到了提高，受益匪浅。
