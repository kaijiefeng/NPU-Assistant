# 深耕亚太航天合作 赋能青年科创成长——2026年亚太空间合作组织（APSCO)立方星竞赛（ACC）项目夏令营培训在西工大圆满落幕

8月13-21日，亚太空间合作组织（APSCO）立方星竞赛项目夏令营培训在我校成功举办并圆满收官。本次活动由航天学院、国际合作处和空天地海一体化大数据应用技术国家工程实验室联合承办。来自APSCO 8个成员国的40名青年师生参与培训，顺利完成本次立方星理论研习与工程实操训练。
APSCO立方星竞赛（ACC）是该组织重点打造的国际航天人才培养与科创交流品牌项目，赛事面向成员国高校青年学子，聚焦3U立方星设计、研制、测试及在轨应用，旨在为亚太航天产业储备人才。本次项目夏令营培训采用理论授课、实物演示、现场实操相结合模式，开设结构、热控、电源、整星测试、星载软件、姿控、地面测控通信等全流程实训课程，让成员国学员完整接触微小卫星研制测控流程，切实强化工程实践与问题处置能力。
8月23日，闭幕式在我校圆满举行。APSCO秘书长江辉对本次培训在西工大的成功举办与圆满收官给予高度评价，充分肯定其在亚太航天青年人才培养方面发挥的积极作用，并对各成员国后续深化航天创新合作寄予美好展望。航天学院党委副书记韩冬全面回顾了此次培训的组织、实施与学员收获，肯定活动的圆满成功。APSCO战略规划与项目管理部部长Atiq Ur Rehman对本次培训作总结，充分肯定并感谢各位指导老师的课程付出。各成员国领队依次汇报培训成果，认可培训实效，期盼后续深化交流合作。各参训国团队顾问也相继发言，对培训的周密组织致以感谢，并分享亚太航天青年交流的合作愿景。
APSCO秘书长江辉为本次立方星竞赛的全体参训学员、领队老师以及志愿者颁发证书。
本次夏令营培训圆满完成APSCO实训教学任务，既是APSCO推进多边航天合作、联合培养区域航天人才的生动实践，也是西工大发挥航天学科优势、服务国家航天国际化战略的重要举措。后续实验室将充分发挥平台作用，深化与各成员国科教协同，推进人才共育与技术共享，助力区域微小卫星技术创新，为亚太航天高质量发展注入青春力量。
