# 学院召开树立和践行正确政绩观学习教育启动部署会

3月10日，教育实验学院召开树立和践行正确政绩观学习教育启动部署会，学习贯彻习近平总书记关于树立和践行正确政绩观学习教育的重要讲话和重要指示精神，研究部署全院开展学习教育工作。学院领导班子、党支部书记、教职工党员等参加会议。会议由牟蕾主持。
会议指出，在“十五五”开局起步的关键节点，党中央决定在全党开展树立和践行正确政绩观学习教育，是贯彻落实党的二十届四中全会战略部署、确保基本实现社会主义现代化取得决定性进展的必然要求，是践行党的根本宗旨、夯实党的执政根基的重要举措，是巩固拓展党内集中学习教育成果、持之以恒推进全面从严治党的有效途径，具有很强的针对性和现实意义。
会议强调，与会人员要深刻认识树立和践行正确政绩观学习教育的重大意义，坚持以习近平新时代中国特色社会主义思想为指导，深入贯彻党的二十大和二十届历次全会精神，全面贯彻习近平总书记关于树立和践行正确政绩观的重要论述，切实把思想和行动统一到党中央决策部署和学校党委的工作要求上来，推动正确政绩观内化于心、外化于行。
会议要求，全体党员特别是处级以上领导干部要按照“立党为公、为民造福、科学决策、真抓实干”的学习教育总要求，将学习教育与国家级未来技术学院申报和学科交叉中心实体化建设紧密结合，与“博士+硕士”双学位项目紧密结合，与成建制“总师型”拔尖人才培养改革紧密结合，严格按照学校党委学习教育工作安排，围绕岗位职责认真开展学习研讨、查摆问题、整改整治、建章立制、开门教育等重点工作，抓好统筹协调，切实履行责任，力戒形式主义，扎实开展好学习教育，为“两院一中心”高质量发展提供坚强政治保障。
