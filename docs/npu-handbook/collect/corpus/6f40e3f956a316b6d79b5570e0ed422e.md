# 联学联建共奋进 互学互通促提升——西北工业大学北京研究院党支部与中国航发航材院高温材料研究所党总支共同开展主题党日活动-西北工业大学

4月27日西北工业大学北京研究院（下称“北研院”）党支部赴中国航发航材院高温材料研究所（下称“高温所”）开展了一场以“联学联建共奋进 互学互通促提升”为主旨的主题党日活动。本次活动紧扣“学思想 强党性 重实践 建新功”总要求，旨在深入开展党建学习教育，教育引导党员、围绕党建业务沟通和党建文化建设，积极探索推进党建与业务深度融合。
活动期间，北研院与高温所一同开展了爬山活动，大家边爬山边交流，爬山期间分别介绍了部门基本情况、科技成果转化与应用情况。同时双方就做实党建业务、党建文化建设、党纪学习教育等方面进行了深入沟通。探索党建交流新模式，共谋校企合作新实践；把党建学习成果转化为“牢记使命责任、坚定航空报国志向”的强大力量，为航空发动机事业和航空材料事业的贡献更大力量。
此次党建活动是北研院落实开展党纪学习教育的系列安排之一，旨在通过校企面对面交流，精准剖析各自优势，为后续深化战略合作、共同谋划科研平台建设、科技成果转化奠定基础，为学校建设中国特色世界一流大学和“127”发展目标贡献北研院力量。
