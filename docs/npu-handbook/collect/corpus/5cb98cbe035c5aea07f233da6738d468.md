# 【创新创业】西北工业大学第三届“华秦杯”全球校友创新创业大赛（深圳赛区）决赛成功举办

2026年9月12日，由西北工业大学深圳研究院（以下简称"深研院"）承办、西北工业大学粤港澳大湾区校友企业家联谊会（以下简称"联谊会"）协办的第三届西北工业大学"华秦杯"全球校友创新创业大赛（深圳赛区）决赛在深圳市南山区三航科技大厦圆满举办。
本次大赛以"微光成炬，翱翔未来"为主题，吸引了来自粤港澳大湾区等地区的23支校友队伍参赛，分为成长组9个项目、种子组14个项目。参赛项目集中在具身智能机器人、低空经济、新材料与半导体、AI算力四大硬科技赛道，同时覆盖生命健康、平台服务等领域，高度契合西工大"三航+信息+材料"的学科优势，选手们展开了一场技术与创新的激烈角逐。
比赛开幕前，嘉宾观看了大赛宣传片《铸国之重器，兴民生百业》。本次视频首次尝试AI制作，以温暖生活化的叙事视角，展现西工大校友如何用科技点亮生活。随后，深研院院长查钢强致辞。他表示，华秦杯既是科技成果转化的重要赛事，也是校友交流聚合的优质平台。西工大率先实施"三项改革"推动科技成果转化，获国务院高度认可与表彰，学校正持续推进教育、科技、人才一体化发展，而本次大赛正是这一成果转化体系在校友群体中的延伸与落地。最后他预祝大赛圆满成功，祝愿各位参赛者和嘉宾都能有所收获。
西北工业大学粤港澳大湾区校友企业家联谊会会长、广东四方威凯科技（集团）有限公司董事长方芳也到场致辞，他寄语参赛校友用前沿技术作答"铸国之重器，兴民生百业"的时代命题。恰逢联谊会成立一周年，方芳会长回顾了一年来通过企业走访、产业沙龙、资源对接等务实举措，践行"三航报国，湾区共赢"宗旨的点滴足迹。他表示，联谊会不仅是比赛的平台，更是校友企业长期成长的生态，路演之后对接与合作仍将持续，陪伴校友企业在湾区走得更稳、更远。
西安生产力促进中心刘壮子现场向大家介绍了2026西安国际创业大赛赛事情况；深圳市科技创新战略研究中心黄榆茗对深圳市鲲鹏创新创业政策进行了解读；深圳西工大科技园公司招商运营部部长张兰介绍了三航招商相关政策。
路演现场，选手们充分展示了创新才华和创业热情，从技术壁垒、商业模式、市场前景等维度全面展示项目，评委嘉宾从创新性、可行性、成长性等多维度犀利提问、精准点评。台上亮点纷呈，台下校友企业家、投资人、产业专家面对面深度交流，资源在对接，合作在萌芽——这不仅是一次比赛，更是一场西工大硬科技力量的集中检阅与生态共振。
最终，经过评委严格评审与综合打分，本次大赛共有成长组3支团队、种子组3支团队成功晋级。他们将带着湾区的创新锐气，走向十月校庆周的总决赛舞台，与全球西工大校友创业者同台竞技、共赴荣耀。让我们共同期待十月，见证总冠军的诞生！
种子组：深圳赛博格机器人有限公司
成长组：运得动力(深圳)有限公司
种子组：灵络(深圳)智能科技有限公司
成长组：广东四方威凯科技(集团)有限公司
种子组：硅基记忆(深圳)科技有限公司
成长组：深圳翱翔蔚蓝科技有限责任公司
西北工业大学资产经营管理有限公司、国家大学科技园副总经理顾振芳在闭幕式上作总结发言及致谢。他回顾了华秦杯大赛创立背景与生态价值，介绍了西工大"三项改革"成果及科技园成果转化实践经验。他表示，校友文化是大学文化的重要组成部分，母校与校友之间应当形成"校荣我荣、双向赋能"的生动局面——学校为校友持续成长提供坚实支撑，校友也为母校建设添砖加瓦。最后，他向所有获奖团队表示祝贺，并相约西安总决赛再聚。
本次大赛得到了西北工业大学的指导，由西北工业大学深圳研究院承办，西北工业大学粤港澳大湾区校友企业家联谊会、深圳三航科技有限责任公司协办，西北工业大学深圳校友会、香港校友会、广州校友会、湖南校友会、珠中江校友会、柳州校友会、佛山校友会等多地校友会的大力推广，比赛还获得了中国工商银行股份有限公司深圳高新园南区支行的赞助支持。
