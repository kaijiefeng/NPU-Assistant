# 妇科-西北工业大学医院

西北工业大医院妇科现有副主任医师1名，主治医师2名，均毕业于西安交通大学医学部，从事妇科专业数十年，具有丰富的临床经验及诊治水平。
科室配有德国ERBE宫颈LEEP刀机、EDAN C6 HD高清阴道镜、麦澜德盆底功能筛查及康复治疗仪、妇科臭氧治疗仪、宫颈微波治疗仪等设备，对妇科常见病如阴道炎、宫颈疾病、前庭大腺囊肿、盆腔炎性疾病，妇科内分泌疾病、盆底功能障碍性疾病等进行全面、规范诊治。开展卵巢储备功能检测、宫颈癌筛查、阴道镜检查、宫颈活检、宫颈LEEP治疗术、臭氧治疗、理疗、盆底功能及产后康复治疗以及早期终止妊娠等计划生育手术。开展儿童期、青春期、育龄期、围产期、更年期及老年期各阶段妇女保健及相关疾病预防的技术指导工作。
科室专科特色：
1.女性生殖道炎症诊治：遵循相关疾病指南，科学合理用药，结合臭氧治疗仪、远红外线理疗仪，采用中西医结合方式，形成西工大医院妇科独有的诊疗方案。
2.宫颈疾病诊治：结合德国ERBE宫颈LEEP刀机、EDAN C6 HD高清阴道镜，可完成宫颈癌筛查、阴道镜检查、宫颈活检、宫颈LEEP刀治疗等宫颈疾病阶梯诊疗。
3.妇科内分泌疾病诊治：开展卵巢储备功能检测，绝经激素治疗，规范诊治多囊卵巢综合征、异常子宫出血、卵巢早衰、闭经等妇科内分泌疾病，并进行长期综合管理。
4.盆底功能障碍性疾病及产后康复：科室引进麦澜德盆底功能筛查及产后康复治疗仪器。对盆底障碍性疾病及产后康复治疗效果良好，具有安全、无创、无痛、趣味化等特点。
5、早期终止妊娠手术：可在 B超监测下，精准定位的无痛人工流产手术。手术方式具有出血量少、安全性高、损伤小等特点。
妇科医务人员将竭诚为广大师生、患者服务，为您的健康保驾护航。
