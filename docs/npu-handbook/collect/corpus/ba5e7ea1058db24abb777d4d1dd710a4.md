# 党建引领聚合力，校企共建赢未来——力学与交通运载工程学院建筑系教工党支部联合建筑系学生党支部与基准方中（成都）建筑科技有限公司党支部开展结对共建活动

为深入学习贯彻习近平新时代中国特色社会主义思想，深入贯彻中央八项规定精神学习教育，巩固党的二十大和二十届三中全会精神学习成果，提升学院人才培养质量，促进学院高层次人才队伍建设，2025年6月17日，力学与交通运载工程学院党委副书记路宽带队，组织建筑系教工党支部书记黄姗、建筑系副主任王晋、建筑系学生党支部书记张吉森、建筑系教师代表及学生代表一行9人赴四川成都基准方中开展党支部共建活动。
在基准方中集团董事秦正军、党委副书记张菁、副总建筑师钟波、党支部书记张晶等人的陪同下，学院一行人首先参观了天府匠芯园区。大家先后走进南区运动中心、北区办公区，实地了解企业员工的工作环境。接下来，一行人来到企业文化展厅，通过展厅内的图文展示和讲解，系统了解了基准方中的发展历程、业务板块分布及企业文化。
随后，双方围绕学院建筑学科发展方向凝练、在党建引领下的校企联合人才培养模式创新、企业用人需求、推进产学研结合和有组织科研活动开展了深入的交流座谈。
在现场所有人员的共同见证下，西北工业大学力学与交通运载工程学院建筑系教工党支部与基准方中（成都）建筑科技有限公司党支部正式签署了结对共建协议，此次签约标志着双方在党建引领下的校企合作又迈出了坚实的一步。
未来，双方将秉持党建引领、优势互补、协同共进原则，在党建交流、科研攻关、人才培养等多方面持续发力，以高质量党建引领高质量发展，推动校企合作向更深层次、更广领域拓展，推动学校“总师育人文化”走深走实。
