# 学院开展消防安全演练

为落实学校关于加强学生安全教育、筑牢校园安全防线的部署要求，进一步提升学生消防安全意识和自防自救能力，10月28日下午，教育实验学院/未来技术学院组织开展消防安全演练，学院党委副书记、副院长范翔，学校党委保卫部消防科相关老师，学院学工秘书杨莉、辅导员刘更亮及90余名学生代表参加演练。
范翔讲到，消防演练不是走形式、走过场，希望同学们提高思想认识，掌握实用技能，严格演练纪律，知风险、会逃生、懂处置，带动身边更多同学提高安全防范意识和应急处置能力。
学校党委保卫部消防科许磊老师结合秋冬季节火灾易发多发的特点，讲解宿舍防火要点、初期火灾处置方法和火场逃生注意事项，并演示灭火器、消火栓等消防器材的正确使用方法。随后，学生们按照疏散预案，用湿毛巾捂住口鼻、弯腰低姿前行，快速、有序地撤离至室外安全区域；撤离后，同学们分组进行了灭火实操训练，逐一掌握灭火器操作技能。
此次演练将知识讲解与实景实操相结合，帮助同学们熟悉疏散流程，掌握基础消防技能。下一步，学院将常态化开展安全教育和隐患排查，共同营造安全稳定的学习生活环境。
