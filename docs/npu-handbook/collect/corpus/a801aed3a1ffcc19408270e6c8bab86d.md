# 关于开展2024年机关健步走活动的通知-机关党委

机关各工会小组：
为丰富机关教职工文体生活,推动机关全民健身活动开展，引导广大机关教职工把勇于争先、奋进拼搏的体育精神，转化为爱岗敬业的强大动力和干事创业的强大合力，锚定“127”目标，以不变的初心、扎实的脚步为学校高质量发展贡献力量，特面向机关组织2024年健步走活动。现将具体内容通知如下：
一、活动时间
自4月8日至6月7日，共61天。
二、参与方式
本次活动面向机关所有教职工，由机关各工会小组组织大家报名参赛。健步走活动主要分为基础赛道、单项赛道和全能赛道，参评单项赛道奖项和全能赛道奖项的选手需首先满足基础赛道相关要求。本次健步走活动采取积分赛制，通过健步走、五公里健步走线上打卡两种形式获取积分。
（一）活动规则
自4月8日至6月7日，日步数达到8000步以上，天数达到45天者即满足基础赛道条件。
满足基础赛道条件的选手，可通过积分方式积极参与健步走和五公里健步走线上打卡，具体积分方式为：
1.健步走线上打卡积分：日步数达到8000步积10分，达到10000步积12分，达到15000步积13分，达到20000步积15分，未达到8000步不积分，依次累积。
2.五公里健步走打卡积分：每完成一次五公里健步走打卡另加8分积分，要求五公里健步走时长在1小时以内，每完成一次请将截图、配速表等信息留存。
（二）奖项设置：
凡满足45天日步数达到8000步以上的选手，可参评全能赛道和单项赛道奖项，具体奖项设置如下：
全能赛道：累积积分前60名给予奖励，其中1-20名为一等奖，21-40名为二等奖，41-60名为三等奖。
单项赛道：
五公里健步走（1小时内）打卡次数最多的30名选手，评选为单项赛道“运动健将”；
日步数15000步以上天数最多的20名选手，评选为单项赛道“健步走达人”。
基础赛道：
如选手在上述全能赛道、单项赛道中均未获奖，将为选手颁发优秀奖。
注:获得“运动健将”的选手不再参评“健步走达人”，单项赛道获奖选手不再参评全能赛道奖项，等同于全能赛道-等奖。
三、相关要求
1.请各工会小组认真组织，动员更多教职工参与本次健步走活动。请参与教职工4月8日前，搜索打开微信小程序“蓝江运动步数”并登录，每日自动记录步数；五公里健步走使用APP记录活动轨迹及时间（APP包括但不局限于悦跑圈、华为运动、Keep等）。
2.积分计算：请健步走达标者将个人运动统计步数报表、五公里健步走截图及时发送给工会小组长计算步数积分，最终由工会小组长计算总积分情况并填写附件积分表。（步数截图方法：搜索微信小程序“蓝江运动步数”—微信账号登陆—我的—我的统计—按时间节点截图保存）。
3.各小组如有报名单项赛道五公里“运动健将”或15000步以上“健步走达人”的选手，请将个人轨迹、步数截图附上。
4.请各工会小组长每轮活动结束后上报一次积分情况。4月8日至5月8日为第一轮活动，于5月15日之前填写附件“2024年健步走积分表（第一轮）”发至机关党委邮箱；5月9日至6月7日为第二轮活动，于6月20日前填写附件“2024年健步走积分表（第二轮）”并上报。
附件：2024年机关健步走活动积分表
特此通知。
机关部门工会
