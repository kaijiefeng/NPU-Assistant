# 教务部党支部开展专题党课

3月19日上午，教务部党支部在诚字楼218会议室组织开展专题党课活动。招生办公室主任兼教务部副部长王克勤同志以《增强政治三力，狠抓工作落实，提升生源质量》为题，为支部全体党员讲授了一堂生动的专题党课。
王克勤同志结合自己在工信部党校第25期处级干部进修班的学习经历，分享了学习收获与思考。他详细介绍了进修班的教学模式与学习内容，并围绕“政治三力”的核心内涵与实践要求进行了深入阐释。围绕如何提升工作效能，王克勤同志谈到，要着力强化“狠抓工作落实、学会换位思考、做好时间管理、合理评估自己的能力”等，做到凡事有交代、件件有着落、事事有回音。结合招生具体工作，王克勤同志从精准把握国家招生政策导向、推动招生政策全面升级、加大招生宣传力度等方面，提出了提升生源质量的具体举措。
通过此次专题党课，全体党员对“政治三力”有了更加深刻的理解。大家一致表示，将以此次党课为契机，进一步增强政治意识和责任担当，凝聚思想共识，切实将学习成果转化为推动工作的强大动力，为学校教育事业发展贡献力量。
（文字：王青青；审核：马婷婷）
