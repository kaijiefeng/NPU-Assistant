# 西北工业大学网络空间安全学院开题答辩（贾琳）

一、开题答辩题目：社交网络平台虚假信息分析关键技术研究
二、开题答辩人：贾琳
三、开题答辩时间：2024年7月24日晚上19:00
四、开题答辩地点：毅字楼801室（友谊校区）
五、开题内容简介：随着网络信息技术的飞速发展，特别是短视频平台的兴起，现代传播体系在传播场域、逻辑、媒介、功效等方面发生了重大变革，形成了全程、全息、全员、全效的媒体形态，信息无处不在、无所不及、无人不用，导致舆论生态、媒体格局、传播方式发生了深刻变化，短视频时代由此应运而生。这种信息传播方式的变革为巩固和壮大主流舆论提供了重要机遇，但同时也给网络空间内容安全带来了新的风险和挑战。社交网络平台传播的新闻由多种不同模态的信息组成，如图片、文本、视频、音频等。相较于传统的纯文本新闻，由多模态信息组成的新闻可以给读者带来更好的故事体验，更能引起读者的注意。虚假新闻制造者借助这一优势，通过伪造图片、视频和篡改文本内容等方式发布虚假新闻，使其在在线社交网络平台中迅速传播。部分虚假新闻制造者通过曲解社会热点信息，达到虚假新闻制造的效果。除此之外，社交网络上的新闻还拥有社交上下文内容、外部知识、传播结构，其对虚假新闻的检测具有一定的价值与作用。相较于只利用文本、图片等单模态信息来判断新闻或帖子等信息的真实性，综合传播结构、外部知识等信息更能有效识别出虚假信息。本课题面向社交媒体的虚假信息检测，以真实世界的数据集为研究对象，融合文本信息、图像信息、社交上下文内容、外部知识等，开展社交网络平台虚假信息分析关键技术研究，从数据感知、数据分析与传播溯源三个角度展开研究，最终提升社交网络平台虚假信息分析能力。
六、开题答辩人简介
贾琳，学号2022100773，1980年8月12日生，网络空间安全学院网络空间安全专业，导师王震教授。
