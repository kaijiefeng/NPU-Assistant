# 关于2027届本科毕业生图像采集的通知

各学院、各毕业班：
根据教育部关于学历信息电子注册的相关要求，现将2027届本科毕业生图像采集的有关事项通知如下：
一、采集时间
2026年11月5-6日，具体时间地点安排详见附件1。
请各学院负责老师按照“2027届本科毕业生图像采集时间安排表”组织好本学院毕业生拍照事宜，以班级为单位（学号由小到大顺序）按照附表中规定时间到指定地点拍照，错过学院排定时间者将安排在当天所有学生拍完后补拍。请各学院务必通知到每位毕业生。延长学制的学生，在学信网确认个人信息无误，已有学历照片的，可不再参加拍摄。
二、收费标准
本届本科毕业生的毕业证和学位证照片均采用新华社统一采集的数码相片，每位学生收取照相费20元/人，请各学院负责老师按参加拍照的毕业生人数以班级为单位统一收取（留学生由国际教育学院组织收取），并在拍照现场扫描二维码通过微信或支付宝转至新华社账户。
三、拍摄流程
按照中国高等教育学生信息网（以下简称学信网）的相关要求，采集照片前两至三天请各学院务必通知每位学生登录学信网获取本人采集码（具体流程见附件2），避免在采集现场临时操作影响整体进度，届时新华社工作人员现场扫码拍摄。
四、注意事项
（一）拍摄要求
根据教育部就业指导中心、学信网相关要求，请就以下注意事项认真贯彻执行：
1. 图像采集时请勿穿与蓝色背景同一颜色的衣服。
2. 图像采集时严禁穿吊带、背心、无袖上衣以及带有毛领的衣服；拍照时整理衣领、着装整齐。
3. 请勿佩戴眼镜、美瞳及项链、耳环、耳钉等饰品。
4. 严禁化浓妆，需露眉露耳，耳朵边的头发请别在耳后。
5. 嘴巴需自然闭合，不可佩带唇钉。
如未按以上规定给图像上传造成影响的后果自负。
（二）信息确认
学生图像信息将于40天后在学信网公布，每位毕业生必须登录学信网：http://www.chsi.com.cn，核对本人图像信息。核对后，信息无误，必须点击确认；如确已参加拍摄，但没有信息或照片有质量问题，由学院汇总后报教务部学籍学位办公室。没有图像信息的毕业生，其毕业数据将无法上传至学信网。
（三）图像补采
1. 如有特殊原因未能参加拍照的学生，请在每周一至周六8：30-11：30；14：00-17：00（2027年4月1日前）自行前往西安市新城区皇城西路20号新华社第二工作区补拍，联系电话：029-87370330。个人拍照时请携带身份证及学信网图像采集码。
2. 因在外不能回校参加拍照的学生，请至新华社中国图片社采集中心开通的“大学生图像信息采集网”（网址为：http://www.xinhuacu.com）了解新华社国内各分社补拍地点，办理图像采集事宜，学校代码为10699。学信网照片核对时间及领取照片时间请咨询当地补拍点，补拍学生需在2027年5月1日前领取实物照片，并提交至学院本科教务老师处，否则，将造成毕业证、学位证上无照片，不能按时领取证书。
此次本科毕业生图像采集关系到2027届毕业生毕业证书、学位证书能否准确、按时发放，是关系到2027届毕业生切身利益的大事，请各学院务必认真对待，切实做好动员和组织工作，确保此次毕业生图像采集工作顺利完成。
