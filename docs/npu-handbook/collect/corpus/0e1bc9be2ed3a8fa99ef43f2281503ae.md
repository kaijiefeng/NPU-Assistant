# 【学术报告】翱翔灵犀学术殿堂——Jean-Yves Tourneret教授报告会

全校师生：
我校定于2026年6月12日举办翱翔灵犀学术殿堂——Jean-Yves Tourneret教授报告会，现将有关事项通知如下：
1.报告会简介
主讲人：Jean-Yves Tourneret
时 间：2026年6月12日（星期五）10:00
地 点：航天学院346报告厅
主 办：党委学生工作部
承 办：航天学院
主 题：遥感与稀疏逆问题驱动的二氧化碳精准反演
2.主讲人简介
Jean-Yves Tourneret，IEEE Fellow，法国图卢兹大学教授，法国国家科学研究中心（CNRS）图卢兹信息研究所成员。1989年获得法国图卢兹国立电子、电工、计算机、水力与电信高等工程师学院（ENSEEIHT）电气工程工程师学位，1992年获得法国图卢兹国立综合理工学院博士学位。长期从事统计信号与图像处理方法研究，重点关注贝叶斯方法、马尔可夫链蒙特卡洛方法及其在信号处理、图像处理和多传感器信息处理中的应用，在Nature Communications，IEEE TSP、TGRS、TIP等重要期刊上发表论文多篇。曾任IEEE信号处理学会Signal Processing Theory and Methods技术委员会委员、欧洲信号处理协会Theoretical and Methodological Trends in Signal Processing技术委员会委员；2019年任法国信号与图像处理协会（GRETSI）主席，2019年至2021年任欧洲信号处理协会（EURASIP）理事会成员，2022年至2024年任欧洲信号处理协会主席。曾担任IEEE Transactions on Signal Processing 和 EURASIP Journal on Advances in Signal Processing 等国际期刊副主编。
欢迎广大师生前来聆听。报告会期间请关闭手机或将手机调至静音模式。
党委学生工作部
2026年6月11日
