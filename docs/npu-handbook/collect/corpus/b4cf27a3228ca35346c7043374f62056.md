# 无犯罪记录证明、政审证明办理流程

一、办事流程
二、所需材料
请登录翱翔门户的网上办事大厅，填写“在校期间政审和无犯罪记录证明申请”并提交。
三、注意事项
1.申请提交后，学生由学院辅导员审核，教职工由单位处级领导审核。
2.网上流程结束后到保卫处领取证明。如需在制式表格上盖章，请带上制式表格。
3.如遇网络问题，也可先到本人所在单位开具纸质证明，再到保卫处办理（如需代办请携带委托函以及代办人有效证件）。
4.办公地点：友谊校区综合楼400室，电话88494447；长安校区启真楼一楼学生一站式服务大厅，电话88430735。
