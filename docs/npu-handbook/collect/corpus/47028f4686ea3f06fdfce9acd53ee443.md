# 学校开展校级示范性党员活动室创建调研和验收工作

10月22日，学校开展校级示范性党员活动室创建调研和验收工作。为促进互学互鉴，验收评委团由学校首批校级示范性党员活动室创建单位相关负责同志担任。学校党委常委、党委组织部部长詹浩，副总会计师张建新以及党委组织部负责党建工作相关同志参加此次活动。
为进一步准确把握验收标准，提升创建质量，当日上午，评委团一行赴碑林区党群服务中心进行学习调研。碑林区委组织部副部长冯冰对评委团一行的到来表示热烈欢迎。评委团先后调研参观了党史教育馆、政治生活馆和“三会一课”室，详细了解了场馆建设的设计、布局、功能以及后期规划。评委团成员还通过体验人脸识别借阅党建书籍、VR技术、电子板书写互动等现代科技手段的运用，进一步提升了推进党建工作信息化、智慧化的意识。随后，双方进行了座谈交流，冯冰详细介绍了碑林区党建工作基本情况并表达了进一步加强与西工大联合开展党建活动、加强理论研究合作的意愿。张建新代表评委团对碑林区党群服务中心的热情接待和周密安排表示感谢，并表示双方要继续坚持党建引领，加强交流协同，使校地合作能够落地落实。
下午，评委团先后对长安校区和友谊校区首批校级示范性党员活动室创建单位进行验收。评委团对照创建申请书，通过听取创建单位介绍和参观交流，现场进行打分并对各单位的建设情况提出了中肯的建议和意见。
示范性党员活动室创建工作是认真落实学校第十三次党代会精神，推进党建“双创”工作开展的重要组成部分。下一步，各基层党委、党总支将结合前期建设成效，不断拓展和优化党员活动室的功能，将党员活动室建设成为集教育、培训、服务、管理于一体的活动阵地，继续以高质量党建推动学校高质量发展。（拟稿：石戈；图片：王一宁；审核：段利兵）
