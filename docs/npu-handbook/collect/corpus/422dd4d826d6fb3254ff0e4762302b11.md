# 厚植军工报国情怀 绷紧纪律规矩之弦——外国语学院开展校纪校规专题宣讲

为引导研究生扣好人生“第一粒扣子”，筑牢纪律规矩意识，9月22日中午，院党委副书记张桑桑在学院楼210报告厅面向全体2026级硕博研究生新生开展“厚植军工报国情怀，绷紧纪律规矩之弦”校规校纪专题宣讲。宣讲会由研究生辅导员赵青主持。
宣讲中，张桑桑结合学校“为党育人、为国育才、为军铸才”的育人定位与三航国防特色，向同学们介绍毕业生重点就业领域，鼓励研究生将个人理想融入国家战略，重点关注国防军工、公共服务等方向。她指出，学院在情报研究、战略规划、军队文职翻译等领域具备独特平台优势，希望同学们厚植军工报国情怀，涵养忠诚品格，争做担当有为的新时代外语人。
围绕校规校纪，张桑桑依据学校学生违纪处分管理办法，从政治法律、学术学业、网络保密、秩序规范、公共道德、公寓生活六个维度，解读各类违纪情形，阐释不同层级处分类型及其入档带来的长远影响，提醒同学们认真研读《西北工业大学研究生手册》，时刻敬畏纪律红线。
本次宣讲融入多起真实警示案例，对网络言行规范、意识形态安全、保密纪律、人身安全等重点内容作出提醒，针对学术不端、考试作弊、宿舍违规电器、电信诈骗等校园高频风险问题开展警示教育，引导同学们以案为鉴、警钟长鸣。张桑桑强调，同学们在学习科研与日常生活中如遇到困难和诉求，可及时与辅导员、导师等沟通反馈，学院将积极倾听同学们的心声，尽力为大家疏解困难，携手共建平安和谐的校园环境。她寄语全体新生，自觉恪守校规校纪，养成良好习惯，以饱满状态投入科研学习，在成长道路上行稳致远。（图文：仝乐；一审：孙温炎；二审：赵青；三审：张桑桑）
