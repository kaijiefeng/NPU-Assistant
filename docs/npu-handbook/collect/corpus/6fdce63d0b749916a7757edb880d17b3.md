# 民航学院成功举办动力提升航空器适航（符合性）验证技术研讨会

为促进动力提升航空器适航领域的技术交流与创新发展，凝聚行业共识，推动相关标准落地与产业协同，2026年 1月27日，动力提升航空器适航（符合性）验证技术研讨会在江苏省太仓市智汇谷成功召开。本次会议由西北工业大学民航学院主办，来自民航管理部门、科研院校、地方政府、航空企业等多个领域的50余名代表齐聚一堂，共话行业发展新机遇、共商技术创新新路径。
本次研讨会得到了行业内外的广泛关注与大力支持。中国民航华北、华东、中南、西南、西北等地区管理局与中国民航科学技术研究院相关领导，北京适航审定中心、沈阳适航审定中心、广州适航审定中心、江西适航审定中心、西安适航审定分中心的专家通过线上或线下形式参会指导；太仓市、陕西礼泉县相关政府部门领导，陕西空天动力研究院、西安西测测试技术股份有限公司、上海峰飞航空科技有限公司、上海时的科技有限公司、四川沃飞长空科技发展有限公司、上海艾思唯尔检测科技有限公司等10余家企业代表，中国民航大学、西北工业大学等高校的专家学者共同出席会议。
中国民航大学石霄鹏副教授和冯振宇教授围绕标准制定背景和相关条款符合性要求进行深入解读，结合行业发展实际，对标准实施中的重点难点问题进行剖析，为企业开展适航验证工作提供了专业指导。在研讨交流环节，与会代表围绕标准应用、技术创新等议题展开热烈讨论，分享实践经验、碰撞思想火花，形成了一系列建设性意见。
西北工业大学民航学院院长李玉龙教授作eVTOL结构与强度适航分析与试验验证实验室建设方案介绍，依托现有科研团队的研究成果，从适航性和符合性验证、动力升空航空器适航标准、结构与强度实验室建设建议等方面进行系统阐述，为行业技术升级提供了重要参考。随后的研讨交流环节，代表们聚焦结构强度验证、适航技术创新、产业协同发展等核心议题，展开深度交流，进一步凝聚了发展共识。
会上，太仓市和礼泉县进行了政府推介，详细介绍了区位优势、产业政策、营商环境等方面的突出优势。
会议开始前，参会代表前往西测翱翔（太仓）航空科技有限公司及太仓市航空航天展示馆参观。在西测翱翔（太仓）航空科技有限公司，代表们详细了解了冲击动力学方面的先进设备与技术应用，其中，多台设备均为国内首台套；在太仓市航空航天展示馆，通过实物陈列、多媒体演示、互动体验等丰富形式，直观感受太仓市在航空航天产业领域的扎实基础、发展成果与宏伟蓝图，为理论研讨与产业实践搭建了坚实桥梁。
本次研讨会的成功举办，不仅搭建了民航管理部门、科研院校、企业及地方政府之间的高效沟通桥梁，促进了动力提升航空器适航（符合性）验证技术的深度交流与推广应用，助力行业标准不断完善与技术创新突破，更推动了产学研用深度融合与区域产业协同发展，为校企合作、政企联动注入了新活力。民航学院将针对此次研讨会的核心成果与关键结论，开展系统性研究并建设各类结构强度适航性符合验证实验室，持续发挥学科、人才、科研优势，深化与行业各界的合作交流，积极推动科研成果转化应用，为我国低空经济高质量发展作出更大贡献。
