# 学院召开2025级莫航联培项目学生行前教育培训暨2024级莫航联培项目学生返校座谈交流会

9月4日下午，电子信息学院在学院楼159会议室召开2025级莫航联培项目学生行前教育培训暨2024级莫航联培项目学生返校座谈交流会。学院党委书记侯俊、副院长姚如贵、保密处副处长王革明、项目负责人高晓光教授、李波教授，以及国际化、学生工作、科研工作等相关老师出席会议。2023级莫航联培项目学生代表、2024级和2025级全体莫航联培项目学生参加会议。
会议由姚如贵主持。会上，2025级学生代表汇报了未来一年的学习规划；2024级学生代表汇报了在俄学习一年的经历和收获，也为即将出发的学弟学妹提供了宝贵建议；2023级学生代表重点介绍了自己在莫航期间的学习体会和收获，以及这段学习经历对提高自己学术科研能力的积极作用，以此鼓励大家珍惜海外优质资源，潜心研学，学有所获。随后，国际化秘书郭媛就爱国守法、注重人身财产安全、努力完成学业等事项作了行前指导；学生事务办公室负责人程姣姣从坚守家国初心、发挥组织作用、恪守外事纪律三个方面对同学们进行了思政教育。
作为本次会议的重要环节，王革明为同学们做了一场深刻的出国保密安全教育。他结合当前国家安全形势，提醒同学们要始终保持高度警惕，在日常学习生活中要严格管理个人手机、电脑等电子设备，保护好个人信息。他要求同学们在外学习过程中严格要求自身，严守纪律规矩和道德底线，自觉净化社交圈、生活圈。
高晓光和李波为同学们作临行寄语：一是始终将国家利益放在首位，时刻注意人身安全和财产安全；二是要珍惜来之不易的留学机会，树立系统思维、创新思维和工程思维，潜心治学；三是时刻铭记自身身份，在虚心学习国外优秀文化的同时，坚定作为中国青年、西工大学子的骨气与底色，自信从容地展示国家形象，维护学校声誉。
侯俊在讲话中首先代表学院向圆满完成海外学业、平安返校的2024级同学表示热烈祝贺，并向即将启程的2025级同学致以美好祝愿。他特别强调，无论身在何处，都要始终把保密和安全放在心上、落实到行动中。
会议最后，学院向2025级莫航学生赠送了临行礼物，全体与会人员合影留念。本次会议既是对新一批学子出征前的全面动员和保障，也是对过往培养成效的总结与传承，充分体现了学院对莫航联培项目的高度重视和对学生成长成才的深切关怀。期待2025级同学一路平安、前程似锦，也祝愿所有莫航联培项目学子早日成才、为国争光！
