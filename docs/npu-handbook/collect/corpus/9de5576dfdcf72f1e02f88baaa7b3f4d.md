# 航海学院召开2021-2022学年学业分析暨班主任考核交流研讨会

为进一步加强学生工作队伍建设，提升班主任的职业素养和业务能力，加强经验交流，进一步规范班主任管理、考核工作，根据学校《关于开展2021—2022学年班主任考核工作的通知》工作要求，7月14日至15日，航海学院采取线上、线下相结合的方式，以年级为单位召开2021-2022学年学业分析暨班主任考核交流研讨会。
航海学院院长潘光，党委书记孙华强，副院长曾向阳、崔荣鑫，副书记王银涛，院长助理耿云辉出席并参与打分，学院学生工作办公室、全体本科生辅导员、四个年级共42名班主任老师参加了此次考核交流研讨会。交流研讨会由班主任所在年级辅导员主持。
会上，各位班主任梳理了过去一年的工作经历，对班级学业情况分析、班风学风建设、创新创业实践、班团组织建设、引导升学就业、疏导心理困惑、存在问题及下一年工作措施等进行总结，分享了心得感受，总结了存在不足，并对班级管理中存在的典型问题进行交流研讨。
潘光做总结发言。他首先对班主任交流研讨会表示肯定，对班主任老师的辛勤付出表示感谢，强调加强经验交流、总结工作成果对开展下一步工作指明了努力方向。随后，潘光就如何使学生“成长，成才”提出三点建议，一是要注重学生专业遴选改革；二是要注重专业优良传统和基因的继承和发扬；三是要进一步发挥本科生导师制作用。潘光强调，班主任是学生学习的组织者、服务者，要主动了解学生、贴近学生，加强与学生之间的沟通，深入班级与宿舍，做学生的良师益友。最后，希望各位班主任一起努力，共同培养高素质航海学子。
孙华强首先对班主任的辛苦工作和精心准备表示肯定和感谢。孙华强说，要主动关心关注“四难”学生，本着“不放弃，不抛弃”的原则，帮助每一位同学顺利完成学业。同时要提高站位，紧抓“立德树人”根本任务，注重学生考研等重要学业时间节点，做好学生学业帮扶工作和整体学业规划。孙华强强调，班主任是人才培养的重要力量，也是建设高素质教师队伍的重要力量，作为联结学院与学生的重要桥梁和纽带，要将爱生融入血液，将为生刻入骨髓，将思政教育有机融入各项工作中，充分运用专业教育资源和优势，引导学生早立大志，助力学生成长成才。
曾向阳、崔荣鑫、王银涛分别从考研就业、日常管理、学业帮扶等方面提出意见和建议。
本次班主任交流研讨会是2021-2022学年班主任考核工作的重要内容，总结了2021-2022学年班主任工作中的经验与成绩，为下一阶段学生工作提供有益建议，为班主任老师们提供了交流学习平台，对加强学院班主任队伍建设起到了良好的促进作用。
会后，党委副书记王银涛组织所有本科辅导员、学生工作办公室秘书召开专题会议研讨下一步围绕学风常态化建设及学业帮扶、学业辅导站建设的工作思路与具体安排。
航海学院以立德树人为根本任务，着力建立一支信得过、靠的住、做得好的班主任队伍，不断增强学院学生工作队伍的向心力、凝聚力和战斗力，努力为学校一流人才培养和“双一流”建设贡献力量。
