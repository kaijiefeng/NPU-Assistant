# 关于2023年寒假放假安排的通知-西北工业大学

各单位：
现将我校2023年寒假放假事宜通知如下：
一、寒假放假时间
1.学生：2023年1月7日～2月19日。2月20日正式上课。
2.教职工：2023年1月8日～2月18日。1月7日和2月19日正常上班。
二、相关事项及要求
1.学校总值班室设在友谊校区学校办公楼A121室，值班电话：88493361，值班传真：88492261。学校两校区24小时值班电话：88494110（友谊校区）、88430110（长安校区）。
2.各单位要做好寒假期间的稳定安全、安全生产、保密及应急管理等工作，请党委学生工作部、后勤产业集团等相关单位，做好寒假在校学生的关心管理和服务保障工作。
3.各单位要严格落实寒假期间值班值守要求，主要负责同志手机要保持24小时畅通；要明确在校带班领导、工作日在岗值班人员（至少1人，并明确值班地点）；加强值班工作培训，做好值班工作交接；春节及周末需安排带班领导，可不安排在岗值班人员。
友谊校区：上午8:30～11:30，下午15:00～17:00
长安校区：上午9:30～11:30，下午14:00～16:00
4.根据市机要局统一安排，学校机要室寒假值班时间为每周四上午，值班地点为友谊校区学校办公楼A226室；寒假期间学校翱翔办公系统（OA）正常运行，请各单位做好线上公文流转。
5.下学期开学第一天，各单位要严格考勤，及时将教职工签到情况报人事处，学生返校情况报党委学生工作部、教务处和研究生院。
6.请各单位于2023年1月7日12:00前，将本单位寒假值班安排表（附件1）及假期机要值班人员审批表（附件2），加盖电子公章或主要负责人签字（任意签）后，以电子版形式报学校办公室（邮箱：xly@nwpu.edu.cn）。
特此通知。
学校办公室
2023年01月05日
