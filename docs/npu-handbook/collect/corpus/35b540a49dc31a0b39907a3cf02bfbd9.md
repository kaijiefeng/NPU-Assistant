# 关于开展2024年度西北工业大学教育教学改革研究项目（哈萨克斯坦分校专项）申报工作的通知

各单位：
为深入贯彻习近平总书记对办好西北工业大学哈萨克斯坦分校的重要指示精神，落实学校党委关于《认真学习贯彻落实习近平总书记重要指示精神，加快建设西北工业大学哈萨克斯坦分校的实施意见》文件精神，学校决定开展2024年度西北工业大学教育教学改革研究项目（哈萨克斯坦分校专项）申报工作。现将有关事项通知如下：
一、选题指南
本次申报分委托项目、重点项目两种类别，选题指南详见附件1。
二、申报要求
（一）项目前期论证充分、目标明确、思路清晰、重点突出，研究计划可行。
（二）项目主持人须为学校在岗教职工（承担教改项目还未结题的，也可申报此次专项）。
（三）项目参与人原则上不超过4人（不包含主持人）。鼓励校内跨单位组建研究团队。
三、项目管理
（一）项目建设周期为立项日期起（预计9月初）至2024年12月31日。确有特殊原因需要延长研究时间，须由项目主持人以书面形式向学校申请，待审批同意后方可延期。
（二）各单位应加强研究过程的管理与督促，项目所在单位应创造条件，为研究项目提供便利与支持，保证项目研究工作的顺利进行。
（三）项目按研究计划完成研究任务后，学校组织专家组对项目进行结题验收，项目组需提供项目研究总结报告和相关研究建议等成果材料，结题验收结果分为优秀、良好、合格、不合格四个等级。
四、经费支持
（一）委托项目经费资助额度拟为每个项目3万，重点项目经费资助额度拟为每个项目1.5万。
（二）项目主持人应根据实际需要编制科学合理的经费预算，项目经费使用需严格遵守国家和学校的相关财务制度，不得用于与项目研究无关的开支。
五、材料提交
（一）在线申请。各项目主持人通过教学研究项目管理评审服务平台提交立项申报书（附件2，签字完整版PDF文件），登录路径为：翱翔门户－翱翔教务－快速通道－教学研究项目管理评审服务平台－进入工作台－在线申报－2024年度西北工业大学教改项目（哈分校专项）申报。
在线申请截止时间：2024年8月28日（星期三）
（二）单位审核。各项目主持人在线提交后，由项目所依托单位按要求和工作流程进行线上审核，单位审核完成后需将申报汇总表纸质版（附件3，一式1份，签字盖章完整版）和电子版WORD文件报送至教务部，汇总表信息与系统填报信息须保持一致。
单位审核和材料报送截止时间：2024年8月31日（星期六）
（三）请各单位高度重视，提前自行组织遴选推荐工作，确保成果质量。
