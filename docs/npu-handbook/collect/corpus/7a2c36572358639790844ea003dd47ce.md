# 弦歌载史 档忆芳华——档案馆“寻校史、唱校歌、做手作”沉浸式体验活动圆满完成

为拉近学生与档案和校史的距离，让静态的馆藏资源走进日常校园生活，2026年10月29日，档案馆面向学生开展以“寻校史、唱校歌、做手作”为主题的沉浸式体验活动。来自各学院共计30余名同学参加，现场气氛活跃，活动取得圆满成功。
此次活动以档案为媒介、以体验为路径，是档案馆深化档案育人、进一步打造学生实践基地的一次生动实践。活动通过“档案溯源”“问答传唱”“文创手作”三个环节，把静态的馆藏资源转化为可看、可听、可参与的校园文化场景，让同学们在歌声中感悟校史温度，在趣味互动中亲近档案文化，在沉浸式体验中厚植爱国爱校情怀，充分发挥档案馆“存史·资政·育人”功能。
档案溯源：在珍贵馆藏里“看见”学校的来时路
档案溯源环节，馆员冯瑶以馆藏档案为线索，为大家系统梳理了学校校史。讲解从“脉源三支”展开，详细讲述了三支源流如何汇聚成今日之西工大，再到校训校风校歌的诞生、演变及深刻内涵。一张张馆藏老档案，把大家带回那些滚烫的峥嵘岁月。
同学们从“古路坝灯火”中感受到艰苦条件下的“爱国心、救国心、报国心 ”；从华东航空学院的整建制搬迁中体悟到“热爱祖国、顾全大局、艰苦创业、献身航空”的华航西迁精神；从“公诚勇毅，三实一新”的校训校风中学习钱学森先生“严肃认真、丝毫不苟”的优良学风和勇于创新的精神，在传承中坚定科技报国志向。
问答传唱：在校史闯关中“唱”出认同
问答传唱环节把校史知识串联成了一场闯关游戏。
快问快答的题目主要围绕学校建校历史、发展历程、校训校风等内容，既有对“华航西迁精神”内涵的理解阐释，也有对“坝上长夜，七星灯火”美谈的溯源探究。现场同学们踊跃举手抢答，气氛紧张而热烈，掌声和欢笑声此起彼伏，答对的同学通过现场抽奖获得了档案馆精心准备的丰富多彩的文创礼品。
接下来在馆员李丹祺的领唱下，同学们齐声唱响校歌，这首诞生于1939年古路坝的旋律，昂扬奋发，雄浑厚重，历经岁月打磨，“公诚勇毅，永矢毋忘”的词句穿越八十余年，焕发出新时代的风采，直抵人心。
文创手作：把校史记忆带走，把感悟祝福留下
文创手作环节，档案馆为同学们现场提供了多种精美书签、异形卡片、书写及绘画工具，大家围坐一堂，以校风校训、学校办学特色、校园建筑等为灵感展开创作。活动尾声，每位同学都带着亲手制作的“校史纪念品”满载而归。大家还将参加活动的感悟与对学校的美好祝福等，以文字和绘画的形式记录成册，留存于档案馆，成为一份承载校园风貌和青春记忆的独特档案。
让档案“活起来”，让校史“会说话”
本次活动充分发挥档案馆作为学生思政教育实践基地和校史育人基地的作用，以寓教于乐的形式普及了校史知识，激发了同学们学习校史、传承精神的热情。参与学生纷纷表示，通过看档案、听校史、唱校歌、做手作，对学校的办学历史与精神传统有了更直观、更真切的理解，他们将传承先辈治学报国初心，深耕学业、潜心科研，为学校高质量发展贡献青春力量。
近年来，档案馆坚持把校史育人融入立德树人全过程，以馆藏档案资源为依托，积极打造学生实践基地，为学生参与档案整理、校史讲解、文创设计等实践活动搭建平台，推动党史、校史教育从参观式向参与式转变。下一步，档案馆将持续丰富实践载体、拓展育人场景，引导学生在实践活动中传承精神薪火，勇担时代使命。
