# 主动作为、用心服务，保障师生出行安全

受新一轮冷空气影响，自1月15日开始，西安大范围持续降雪，校内外道路及西门、南门外天桥上积雪严重，路面湿滑，影响师生家属的出行安全。
保卫处领导高度重视在校师生的出行安全，为消除交通安全隐患，1月16日晚上，保卫处组织校卫队员清扫积雪，大家分工协作，加班加点毫无怨言，在积雪路段撒融雪剂，尽快清理积雪，经过数小时的齐心努力，成功将各大门内外道路上及西门、南门外天桥上的积雪全部铲除清理完毕，全力保障我校师生家属的出行交通安全，真正做到用情用心服务，受到了广大师生家属一致好评与点赞。
