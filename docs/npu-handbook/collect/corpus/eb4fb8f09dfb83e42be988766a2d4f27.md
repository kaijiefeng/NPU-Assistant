# 党委保卫部开展反恐防暴技能培训以练促防筑牢校园安全屏障

为进一步提升校园安保队伍的安全防范意识与反恐防暴实战能力，增强应对突发事件的协同处置水平，切实保障师生人身安全，11月12日与14日，党委保卫部特邀西安市公安局碑林分局巡特警大队宣博文和卢昆仑两位教官，分别在两校区组织开展了反恐防暴技能专项培训。
本次培训重点围绕反恐防暴器材的规范使用与战术配合展开。教官系统讲解了盾牌、钢叉、短棍等常用装备的操作要领及使用注意事项，帮助参训人员精准掌握器材使用的核心要点。
在强化基础技能的同时，此次培训着重训练不同场景下的阵型布置与协同配合。参训人员分为若干小组，重点模拟演练了利用盾牌、钢叉等器材进行协同控制、推进与防护的战术阵型。教官采取“边讲解、边示范、边纠正”的教学方法，确保每位队员熟练掌握团队配合作战的流程与技巧，真正将“协同”意识内化于心、外化于行。
培训过程中，全体参训人员态度认真、精神饱满、全力投入，将演练场视为真实战场，做到动作规范、配合默契，有效检验并提升了团队在模拟实战条件下的应急处突能力。
通过“以学促练、以练促防”的常态化培训，不仅进一步增强了校园安保队伍的反恐防暴意识，更通过针对性的阵型训练，切实提高了队伍在应对突发事件时的快速反应、协同作战和有效处置能力，为筑牢校园安全第一道防线、维护和谐稳定的校园环境奠定了坚实基础。党委保卫部将持续推进此类培训演练的常态化开展，确保校园安保队伍始终保持良好的战备状态和专业的处置能力。
