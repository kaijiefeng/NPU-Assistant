# 【暑期项目】关于“2024年莫斯科航空学院航电系统设计与综合暑期项目”的报名通知

一、项目名称
2024年莫斯科航空学院“航电系统设计与综合”暑期项目
二、项目外方高校
莫斯科航空学院
三、外方高校简介
莫斯科航空学院成立于1930年，苏联时期获得列宁勋章，十月革命勋章，2009年获俄罗斯国立研究型大学称号。为中俄工科大学联盟俄方成员。莫航目前仍是世界上最大的一所航空学院,历史上培养了16万名航空航天领域专家、250名首席设计师、100名试飞员和21名宇航员。学校拥有诸多推进试验设备、风洞和飞行模拟器等航空试验设备，在拜科努尔航天发射场、朱可夫斯基、希姆基和阿赫图宾斯克建有航空基地或分院，在全球航空航天类高等院校中首屈一指。
四、项目合作背景
电子信息学院与莫斯科航空学院合作历史悠久、交流紧密。“西北工业大学-莫斯科航空学院”硕士联合培养项目已顺利执行五年，累计选拔培养学生50余人，成果丰硕。
五、项目时间及内容
项目时间：2024年7月15日-2024年7月28日
项目内容：
-飞机导航技术
-航电系统确认与验证
-航电设计自动化
-航电测试技术
-参观莫航电设计实验室
-参观Irkut公司的MC21和SSJ100飞机的航电测试系统
六、项目费用
1500美元-1600美元（根据实际报名人数确定最终的费用，包含学费、住宿费和餐费，不包含签证费、国际旅费、保险费等）
七、学校资助政策
参加本项目的同学一次性获得学校资助8000元/生；
注：每位同学一个自然年内仅可获得一次寒暑假项目资助。
八、学院配套资助政策
电子信息学院的本科生，可申请学院配套资助。其他学院学生请咨询各自学院外事秘书。
九、项目报名方式
1、报名截至时间：2024年4月30日
2、报名对象：面向我校在读本科生、研究生
3、填写附件《西北工业大学2024年出国（境）短期交流项目学生信息统计表》发送至邮箱：wangqiuxia@nwpu.edu.cn，同时加入QQ群：796155195。
