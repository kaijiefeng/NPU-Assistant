# 物理科学与技术学院党委组织各党支部专题学习党的二十届四中全会精神

为深入学习贯彻党的二十届四中全会精神，切实把全院师生的思想和行动统一到党中央决策部署上来，根据学院党委统一安排，近日，学院各师生党支部通过集中观看、在线学习、专题研讨等多种形式，认真组织学习党的二十届四中全会精神。
各支部组织党员集中观看了《中国共产党第二十届中央委员会第四次全体会议公报》及相关新闻报道视频，认真学习全会提出的统筹教育强国、科技强国、人才强国建设等重要部署。学习过程中，党员同志们全神贯注，认真记录全会精神的核心要义。
观看结束后，各支部分别组织开展交流研讨。与会党员紧扣“学习收获感想”与“如何贡献青年力量”两大议题，结合物理学科特点和个人成长实际踊跃发言。大家一致认为，党的二十届四中全会为新征程上推进中国式现代化建设指明了前进方向，全会提出的“十五五”规划建议描绘了未来发展蓝图，为青年成长成才提供了广阔舞台。
学生党员表示，作为新时代青年，要将个人理想融入强国建设大局，练就过硬本领，主动到祖国最需要的地方建功立业。研究生党支部党员结合自身科研工作谈到，要深刻领会全会关于“科技自立自强”的战略部署，在基础研究领域勇于探索、敢于创新，把论文写在祖国大地上。教师党员表示，要将全会精神融入教学科研全过程，坚守立德树人初心，为党和国家培养更多高素质人才。
大家一致表示，要以此次学习为契机，进一步深刻领悟“两个确立”的决定性意义，增强“四个意识”、坚定“四个自信”、做到“两个维护”。同时，将全会精神与物理学科特色相结合，在量子科技、新材料、空间材料等前沿领域主动布局，勇攀科学高峰，以实际行动肩负起新时代科技报国的使命担当。
下一步，学院党委将持续深化党的二十届四中全会精神学习宣传贯彻工作，通过“三会一课”、主题党日、微党课宣讲等丰富形式，推动学习往深里走、往实里走，引导全院师生将学习成果转化为推动学院高质量发展的强大动力。
（文：杨文琪；审核：晁小荣）
