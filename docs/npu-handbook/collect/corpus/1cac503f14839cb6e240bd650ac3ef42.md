# 秦岭卫星成功发射，凝聚西工大宁波力量！

北京时间2026年9月20日12时03分，西北工业大学抓总研制的秦岭卫星（01、02星）搭载“力箭一号”遥十八运载火箭在酒泉卫星发射中心发射升空，火箭飞行728秒后01星分离、752秒后02星分离，两颗卫星准确进入预定轨道，卫星各项状态良好，发射任务取得圆满成功。
秦岭卫星（01、02星）单颗卫星质量150公斤，设计寿命5年，载荷为亚米级高分辨率“全色+多光谱”相机，运行于500km太阳同步轨道。西北工业大学宁波研究院卫星与大数据技术研究中心（以下简称“西工大宁波卫星与大数据中心”）主任周军教授担任卫星总设计师。
秦岭卫星（01、02星）装箭实景图
西工大宁波卫星与大数据中心承担了秦岭卫星结构星的总装集成和鉴定级力学试验工作，有效地保障和验证了卫星总体结构的力学特性。同时，自主建设的宁波测运控中心和12米卫星测控数传地面站承担秦岭卫星01、02星在轨测试，以及全寿命周期内的在轨长期管理，包括卫星测控、状态监测、遥感数据接收、存储、分发等。在秦岭卫星工程中发挥了重要作用。
秦岭卫星结构星鉴定级力学试验
宁波卫星测运控中心
西工大宁波卫星与大数据中心作为卫星与大数据应用浙江省工程研究中心，开展卫星网络与规划、卫星设计与制造、卫星测控与服务、大数据技术与应用等创新研究。承担包括国家型号卫星“澳门科学一号”卫星A星、B星，秦岭卫星01、02星，八一03星等在内的多个卫星型号的数传、测控和在轨长期管理。
