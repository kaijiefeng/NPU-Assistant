# 魏炳波院士受邀在第十二届环太平洋先进材料与工艺国际会议（PRICM12）做大会报告

2026年8月9-13日，第十二届环太平洋先进材料与工艺国际会议（PRICM12）在澳大利亚黄金海岸召开，我院中国科学院院士、中国材料研究学会理事长魏炳波教授受邀做大会报告。空间材料科学与技术团队一行七人参加此次国际会议并做学术报告。
环太平洋先进材料与工艺国际会议（PRICM）由中国金属学会（CSM）、日本金属材料学会(JIM)、韩国金属材料学会（KIM）、澳大利亚材料学会（MA）和美国矿物金属材料学会（TMS）共同发起主办，五家学会轮流承办，每三年举办一次。经过30余年的不断努力，PRICM会议已发展为全世界材料及工艺领域规模最大、影响力最高的综合性学术会议之一，近年来规模一直保持在千人以上的较高水平。
