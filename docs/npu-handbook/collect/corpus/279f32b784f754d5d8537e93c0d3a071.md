# 西北工业大学与德国品牌应用科学大学合作举办工业设计专业硕士研究生教育项目2024年中外合作办学评估工作公示

根据《教育部办公厅关于印发2024年高等学校评估项目安排的通知》（教督厅函〔2024〕13号）和《教育部学位中心关于开展2024年度中外合作办学评估工作的通知》（学位中心函〔2024〕54号）等文件要求，我校与德国品牌应用科学大学合作举办工业设计专业硕士研究生教育项目进行了2024年度中外合作办学评估工作。
现根据教育部要求对评估中的“办学情况简介”“基本信息”“招生简章”等内容面向社会进行公示。公示期为2024年10月10日至2024年10月23日。公示期间若有异议，请与西北工业大学与德国品牌应用科学大学合作举办工业设计专业硕士研究生教育项目联系。
