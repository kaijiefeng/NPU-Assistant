# 重庆科创中心党支部开展主题党日活动

为深入贯彻落实习近平新时代中国特色社会主义思想和党的十九届五中全会精神,认真贯彻落实新时代党的建设总要求和新时代党的组织路线。不忘初心、牢记使命，弘扬爱国奋斗精神，建功立业新时代。11月13日，重庆科创中心党支部组织支部全体党员和部分员工赴重庆中国三峡博物馆、重庆人民大礼堂、周公馆、桂园等红色革命教育基地开展主题党日活动，接受爱国主义教育。
上午，大家来到了全国爱国主义教育示范基地—重庆中国三峡博物馆参观学习。重庆中国三峡博物馆（重庆博物馆）是一座集“巴渝文化、三峡文化、大后方抗战文化、统战文化、移民文化”等为一体的综合性省级博物馆。众人先后参观了壮丽三峡、远古巴渝和抗战岁月等场馆，前两个场馆分别展示了长江三峡地区奇特地貌景观、山川形胜和重庆古老文明可追溯3000年的文化根源。
抗战岁月场馆集中展示了中国在抗日战争和世界反法西斯的战争中，重庆这座城市和重庆人民为人类和平进步事业所作出的贡献与牺牲。大家怀着对革命先烈无比崇敬的心情，认真观看馆内丰富的抗战文物、抗日民族统一战线、红军转战重庆北上抗日、重庆大轰炸介绍，大家站在历史场景的面前，仿佛身临其境的感受到抗战时期重庆这座英雄之城厚重的历史。
众人纷纷表示，今天来到博物馆，见证了中国军民抵御日本侵略者抛头颅洒热血，不畏牺牲的爱国主义精神，才知道美好的生活来之不易，在今后的工作中将不畏艰难迎难而上，用实际行动践行党员的初心和使命，为中华民族的伟大复兴贡献力量。
随后，大家步行参观了重庆市人民大礼堂。重庆市人民大礼堂是邓小平，刘伯承、贺龙等老一辈无产阶级革命家主持修建的世界知名建筑，是重庆的象征和最具影响力的标志性建筑之一。
下午，大家参观了周公馆、桂园等红色革命教育基地。周公馆是中共中央南方局设在城区的办公地点，因周恩来为首的中国共产党人在这里战斗和生活得名，是老一辈共产党人为抗日民族统一战线的发展、壮大和巩固不懈努力的历史见证。
桂园，因1945年10月10日，国共两党在桂园签署了著名的《双十协定》，使其成为国共谈判的重要见证地。大家在周公馆和桂园瞻仰陈列着毛泽东、周恩来同志在重庆谈判期间的活动照片，以及《新华日报》、《解放日报》在当时的有关报道，无不感叹到老一辈无产阶级革命家崇高的革命追求与伟大的革命情操。
通过此次主题党日学习，大家不仅加深了对重庆市地理渊源、文化背景的认识，同时对习近平总书记讲到 “伟大抗战精神，是中国人民弥足珍贵的精神财富，将永远激励中国人民克服一切艰难险阻、为实现中华民族伟大复兴而奋斗” 的深刻内涵有了新的认识。
在返程路上，大家纷纷表示在以后的工作和学习中将继承和发扬革命先烈的光荣传统，坚定理想信念，积极投入到科创中心的发展建设中，为中心的持续发展添砖加瓦，为学校“双一流”建设和重庆的高质量发展贡献力量。
