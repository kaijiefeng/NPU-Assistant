# 党委保卫部传达学习学校寒假务虚会、新学期中层干部会会议精神

2月26日，党委保卫部召开全体党员及骨干队员大会，传达学习学校寒假务虚会、新学期中层干部会会议精神。会议由党支部书记朱建军主持。
朱建军介绍了学校寒假务虚会、新学期中层干部会的整体情况，传达了李言荣书记《以高水平党建引领学校高质量发展》、宋保维校长《坚持教育科技人才一体推进 谋篇布局“十五五”发展》两个专题报告精神，结合部门工作领学了《西北工业大学2025年工作要点》，并结合近期工作传达了上级关于稳定安全工作的会议精神。
他指出，两个报告总结过往成绩全面客观，分析当下形势科学精准，提振了学校干事创业的精气神，为下一步工作指明了方向。党委保卫部将严格遵循“三高”发展基调，对标“三要”工作要求，以高质量实施学校“人防、物防、技防”能力一体化提升的规划为主线，全面推动保卫工作高质量发展。在新的一年，党委保卫部要聚焦政治建设、聚焦机制牵引、聚焦主责主业、聚焦巩固提升，持续加强科技赋能和群防群治，深入开展安全教育培训和实战演练，为学校实现“127”近期发展目标和“天下工大、世界三航”远景目标贡献力量。
