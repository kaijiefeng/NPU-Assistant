# 领航新程，开启招生新序章——数学与统计学院重庆招生组2025年工作启幕

为深化大学与中学之间的教育协作，打造“总师型”人才教育合作共同体，充分发挥中学作为重要生源基地的关键作用，持续提升我校声誉，2025年1月20日至25日，由数学与统计学院党委书记王莉、副院长郭千桥、重庆招生组组长林伟、招生秘书李彦吉及生命科学与医学学部党委书记段利兵、教育实验学院党委书记牟蕾、航空学院钟诚文教授等组成的联合招生宣传组先后赴重庆市璧山中学校、重庆巴蜀科学城中学校、重庆市育才中学校、重庆实验外国语学校、重庆市江津中学校、重庆第二外国语学校、西南大学附属中学校等7所中学及蕴华教育等教育机构举行招生宣传活动计13场，包括3场科普报告、7场招生宣讲、3场“优质生源基地”授牌活动。
1月20日上午，党委书记王莉带领招生组赴重庆市璧山中学校与党委书记廖万华、校长成林、副校长梁多俊等5人开展了座谈交流。会上，双方签订了合作协议，西北工业大学向重庆市璧山中学校授予了“优质生源基地”牌匾，并赠送歼-20飞机模型，双方深入交流了未来中学与西工大合作具体举措。下午，王莉书记带队转战重庆巴蜀科学城中学校开展招生工作，校长江文、副书记赵文平出席活动。面向高三学生进行招生宣讲及科普讲座，钟诚文教授以“战斗机的前世今生”为题介绍了历史上的著名战斗机，科普了战斗机的发展历程及技术发展趋势。重庆招生组组长林伟老师从“好听、好看、好学、好胜、好前程”五个方面全方位解析了西工大在人才培养、科学研究、师资队伍、就业前景、校园文化的优势和特色，鼓励学生们要好好学习，希望同学们能够矢志报国，献身国防，未来能够成为西工大的一份子。
1月21日上午，王莉书记与招生组受邀到重庆市育才中学校开展招生宣传活动，教务主任俞建操出席活动。面向高三学生进行招生宣讲，钟诚文教授做客《行知讲坛》第1期进行科普讲座，现场气氛热烈火爆。下午，王莉书记带领招生组来到重庆实验外国语学校进行“优质生源基地”授牌活动，并赠送J-20模型。重庆实验外国语学校党委书记肖艳、校长钟艳等领导参加了授牌仪式。双方围绕学生研学、中外合作等议题深入探讨。会后，钟诚文教授做科普报告，受到学生喜欢，现场气氛热烈。王莉书记、林伟老师分别进行招生宣讲。
1月23日上午，副院长郭千桥、招生组组长林伟、招生秘书李彦吉一行到重庆市江津中学校举行了签约授牌仪式，并向学校赠送了歼-20飞机模型。江津中学党委书记张跃国、校长羊自力、副校长杨万机等13人出席了签约仪式。会上，双方围绕中学-大学贯通培养、学生研学等议题，共同探讨人才培养与教育合作的新路径。会后，林伟老师面向高三学生作招生宣讲。下午，招生组一行转战重庆第二外国语学校，继续开展招生宣讲活动，外联主任周盛平出席活动。宣讲现场气氛热烈，学生们热情高涨，积极与招生组老师互动交流。
1月25日上午，教育实验学院党委书记牟蕾、秘书王斯妍、学生大使王绎哲和招生组一行到蕴华教育面向百余位高三家长做招生宣讲，并对在场家长提出的报考疑问进行了有针对性的解答。宣讲现场座无虚席，与会家长、师生反响热烈。下午，生命科学与医学学部党委书记段利兵、招生大使李培鑫与招生组赴西南大学附属中学校面向高三学生开展招生宣讲，鼓励优秀学子报考我校。高三年级主任颜冬生和支部书记范志峰出席活动。
本次系列招生宣传活动拉来了2025年学院招生宣传工作序幕，系列活动有效强化了我校与重庆地区重要生源中学的沟通与联系，为进一步提升我校声誉，扩大我校在重庆地区的影响力奠定了良好基础。
