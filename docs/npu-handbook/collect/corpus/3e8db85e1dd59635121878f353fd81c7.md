# 1000余家单位！西工大秋季招聘会等你来~

“金九银十”秋招旺季，三航聚势机遇满怀，千企万岗校园揽才，虚位以待“职”等你来。

秋招启动以来，已有超1000家用人单位，携四万余个就业岗位来到我校。优质岗位+广阔平台双向发力，行业机遇+多元通道同步释放。现场还设置有简历门诊、政策咨询等服务专区，助力同学们实现高质量就业。

学校党委高度重视毕业生就业工作，充分落实就业“一把手”工程，校党委书记李言荣多次参加校园招聘活动，与用人单位和同学们充分交流，关心了解同学们的就业意愿和企业需求，听取用人单位对学校“总师型”人才培养的意见建议。

9月1日，中航工业自控所来校开展专场宣讲，秋季校园招聘正式启幕。

9月4日，我校承办2025年陕西省“组团式”招才引智军工人才专场招聘首场活动，这也是我校2026届秋季校园招聘首场大型双选会。

9月5日，中国航天科工集团2026届首场校园招聘活动在我校举办，集团党组书记、董事长陈锡明在宣讲会现场做主题推介。

此外，中国电子、中电科、中国兵器、中国商飞、国家管网、中广核等重点单位也组团召开宣讲会及双选活动，多场双选会为全国首场。还有陆军、空军、火箭军、军事航天部队、网络空间部队等部队单位，中科院院属研究所、乾元实验室、汉江实验室、怀柔实验室等重点科研单位，华为、中兴、中建八局、铂力特、美的、迈瑞医疗等行业知名企业陆续来校，持续搭建校企招聘平台，助力同学们好就业、就好业。

更多领军单位持续上新，欢迎同学们关注学校就业信息网和“西工大就业”微信公众平台。还有“职面星期三”、每周四线下“简历门诊”、AI模拟面试平台，助你锁定每一次机会。

提前准备、主动了解，积极投递、把握机遇，祝愿每位同学都能斩获心仪offer，立大志向、上大舞台、入主战场、干大事业。
