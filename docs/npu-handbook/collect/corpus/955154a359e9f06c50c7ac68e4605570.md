# 体检中心-西北工业大学医院

体检中心位于友谊校区医院门诊四楼，成立于2010年，占地面积400余平方，依托医院人才、技术、设备之优势，聚集了一批专业技术过硬的医护人员，组成了一支强大的健检队伍，为学校广大师生及社区居民提供健康体检、健康管理、健康教育的“一站式”服务。
体检项目丰富，套餐多样化。中心设有内科、外科、眼科、耳鼻喉科、妇科、口腔科、心理测评室、心电图室、彩超、放射、病理、医学检验等20多个检查科室，环境温馨、布局合理。体检仪器设备先进，拥有12导联心电图工作站、 In body770人体成分分析仪、动脉硬化检测仪、经颅多普勒检测仪、骨密度测定仪、碳13幽门螺旋杆菌测定仪、眼底照相机、电测听、耳内窥镜、佳能64排螺旋CT、国际知名品牌（西门子、东芝、三星等）彩色超声设备。此外，体检中心还开展了无创基因检测早癌筛查项目。
体检中心有医生6名，其中主任医师2名，副主任医师2名；护士5名，其中主管护师3名；健康管理师5名。此外，每日参与各项体检工作的高级职称医师占比超过了50%，保证了体检结果的严谨性和权威性。
体检中心除开展健康咨询、健康体检、报告解读、重大阳性结果追踪随访外，还定期深入团检单位，举办健康科普讲座，解惑体检报告，提高群众健康意识，促进大家“未病先防、既病防变”健康理念的形成。
体检中心团队坚守“以受检者为中心，以质量为根本，优化提升永不停”的宗旨，在工作中不断探索，提供全心全意服务。
