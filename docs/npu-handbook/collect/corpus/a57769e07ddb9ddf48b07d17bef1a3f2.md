# 就业新闻-筑梦青春志在四方，规划启航职引未来——电子信息学院举办第四届全国大学生职业规划大赛学院选拔赛

首页>就业新闻>文章
筑梦青春志在四方，规划启航职引未来——电子信息学院举办第四届全国大学生职业规划大赛学院选拔赛
日期：2026-11-05 13:30 浏览次数：20
11月5日下午，第四届全国大学生职业规划大赛电子信息学院选拔赛在启真楼共享会议室102举行。比赛分设成长赛道和就业赛道，来自本硕博阶段的9名同学同台展示。学院党委副书记高敏、学工主管程姣姣、辅导员朱新生、雷思远参与活动。
以赛促学，在规划中锚定方向
赛场上，选手们围绕成长经历、职业目标和发展路径依次展开陈述。有同学立志“扎根西工大、投身航空报国”，将个人成长融入国家航空事业；有同学瞄准通信导航系统总体设计岗位，梳理出从本科到博士的专业成长阶梯；有同学聚焦低空智能网联、AI算力基础设施等前沿方向，展现出对行业趋势的观察与思考；也有同学以“为国铸剑，从‘芯’立起”为题，勾勒出本科四年乃至本硕博贯通的成长蓝图；还有同学计划把科普教育带进乡野课堂，将个人理想写进乡村振兴的热土。选手们或结合专业特色畅谈职业追求，或围绕目标岗位拆解能力要求，充分展现了新时代工大学子的青春担当与职业思考。
精准点评，在指导中补齐短板
汇报结束后，老师们逐一点评，并与选手面对面交流，指出一份有说服力的职业规划，首先要“清晰目标岗位”，明确目标单位与岗位所需能力，避免方向宽泛、内容堆砌。
针对就业赛道选手，老师们建议进一步锚定个人能力与行业需求的结合点，将个人经历与岗位所需精准对应，同时加强职业使命感、认同感与责任情怀的表达，让专业技能、实践成果与岗位胜任力形成闭环。针对成长赛道选手，老师们建议立足年级特点细化阶梯式规划：低年级同学可适当展望本科、硕士乃至博士的长远发展路径；有从教意向的同学应深入了解具体岗位要求，多参与支教实践和研究生支教团项目，让规划更有支撑。此外老师们还就讲解节奏、表达自信、PPT凝练等方面提出了细致建议。
以赛促就，在接力中奔赴下一程
经过集中评审，比赛评出一等奖、二等奖、三等奖，并现场颁发荣誉证书。根据评审结果，学院将择优推荐选手代表学院参加校级选拔赛，并围绕目标岗位拆解、陈述打磨、模拟答辩等环节，对晋级选手开展针对性辅导。
本次院级选拔赛为同学们提供了系统梳理职业方向、直面专家点评的宝贵机会。希望同学们以大赛为契机，把赛场收获转化为日常学习的动力，进一步明确职业发展目标，提升就业竞争能力，将个人理想追求融入国家发展需要，在青春奋斗中实现人生价值。
