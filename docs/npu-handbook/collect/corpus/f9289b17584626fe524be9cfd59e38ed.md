# 网络空间安全学院“备战秋招”专题辅导报告成功举办

为帮助同学们更好地应对秋季招聘，提升求职竞争力，9月26日，由西北工业大学网络空间安全学院主办的“备战秋招——简历和面试必须知道的那些事”专题辅导讲座在启真楼211报告厅成功举办。讲座特邀数学与统计学院党委书记、我校资深就业导师王莉老师担任主讲。网络空间安全学院党委副书记杜瑶、学工部主管方雪、专职辅导员王昌昌与全体2026届毕业生一同参加。

报告前，杜瑶介绍了邀请王莉老师的初衷，强调了在当前就业形势下掌握科学求职方法的重要性。

在随后的分享环节，王莉结合自身多年招聘经验，围绕“就业分享”“简历制作”与“面试技巧”三大核心模块，为同学们带来了干货满满的分享。

在就业形势分析部分，王莉首先梳理了网络空间安全领域的行业发展趋势与人才需求特点，帮助同学们建立对就业市场的宏观认知，引导大家结合自身优势进行职业定位。她通过具体案例讲解了就业选择的多种考量因素，并以“你有什么”“你要什么”“你需要放弃什么”精炼总结就业思考维度。并提醒同学们理性看待求职挫折，保持积极心态，同时增强防范意识，警惕高薪陷阱。

在简历制作环节，王莉指出，简历是求职的“敲门砖”。她结合典型案例重点强调简历内容需与目标岗位高度匹配，善用关键词提升通过率；描述实习与实践经历时，推荐使用STAR法则（情境-任务-行动-结果），并尽量量化成果；简历框架要清晰、排版美观，避免拼写与语法错误。

在面试技巧部分，王莉深入剖析了面试逻辑，通过实际案例讲解如何准备“黄金一分钟自我介绍”，并针对行为面试、技术面试、群面等不同形式提供应对策略与思维框架。最后她还指出了面试中常见的扣分项，指导大家如何展现自信、真诚且专业的沟通姿态。

本次专题讲座在应届毕业生对招聘有了基本概念的背景下，讲座前在应届毕业生中做了系统的问卷调查，报告紧扣学生求职实际需求，内容扎实，针对性强，有效助力网安学子提升求职技能与竞争力。

**主讲嘉宾简介**：王莉，数学与统计学院党委书记，原学校学生职业发展指导服务中心主任，副教授、国家高级职业指导师，国家二级心理咨询师，全球职业规划师（GCDF），国际生涯教练（BCC），国际注册就业胜任力教练（ICECC），中级生涯规划师、互联网+创业指导中级教师，《大学生职业生涯规划实训手册》主编。擅长领域为生涯规划、生涯转换和适应问题、生涯决策问题、就业指导、求职技能训练等。
