# 集成电路学院举办“翱翔青春榜样”成长故事分享会-集成电路学院（微电子学院）

为发挥优秀学子的榜样示范作用，搭建朋辈经验交流学习平台，帮助学生做好学业规划、提升科研能力，10月29日晚，集成电路学院（微电子学院）关工委和学院分团委在长安校区教西B3-201举办“翱翔青春榜样”朋辈成长故事分享会。学院围绕学生在学业规划、科研探索、职业发展等方面的需求，邀请来自清华大学的我院2025届本科毕业生孙鹏程、管帅轶和入职中兴通讯“蓝剑计划”的2026届硕士毕业生李昊东，分享各自的成长经历与实践经验。
孙鹏程围绕大学四年的成长经历以及研究生阶段所需的各项能力，分享了自己如何在不同学习阶段探索并找到适合自己的学习方法。他结合课程学习与科研训练中的鲜活案例，鼓励同学们脚踏实地、勇攀高峰。
管帅轶结合高算力芯片电源管理研究方向，讲述了自己从科研入门到深入探索的历程。他坦诚分享了自己在科研瓶颈期如何调整心态、将精力聚焦于问题本身的经验，传递了持之以恒、坚定信念的科研态度。
李昊东结合自身求职经历，分析了将专业知识与产业前沿相结合的职业发展路径。他建议同学们保持自信、主动求知，在夯实专业基础的同时关注行业趋势，提前做好职业规划。
交流环节中，同学们围绕学业规划、科研方法、职业选择等问题踊跃提问，三位主讲人结合各自经历逐一耐心解答。现场气氛热烈，同学们纷纷表示受益匪浅。
本次分享会促进了学习交流，帮助同学们解答学业发展、科研探索中的困惑，发挥了青年榜样的示范引领作用。学院将持续打造系列成长交流平台，助力学生全面发展、逐梦远航。
