# 关于2026年博士研究生招生拟录取名单的公示及修改通讯地址的通知

各位考生：
2026年博士研究生招生录取工作已经结束，现将拟录取名单公示如下,具体名单见附件。
公示期为7日，如有问题请在公示期内通过邮件或书面形式向西北工业大学研究生招生办公室反映。
联系电话：029-88493042
电子邮箱：yzb@nwpu.edu.cn
拟录取名单公示结束后，我校将进行2026年博士研究生定向培养协议书的签订和录取通知书的发放，现将考生相关材料邮寄通讯地址修改要求如下：
一、邮寄时间
定向培养协议书6月下旬，录取通知书7月上旬，具体时间以学校工作安排为准。
二、适用对象
定向培养协议书：针对录取类别为定向就业的考生；
录取通知书：针对所有拟录取考生（含本科直博、秋季入学硕博连读生和“申请-考核”制考生）。
如无修改，将按照博士报名期间预留通信地址信息邮寄。
三、修改时间
2026年6月23日上午8：00-26日中午12：00，过期不能修改。
四、修改方式
请需要修改通信地址的考生在6月26日中午12：00前登录“西北工业大学研究生招生信息网”（https://yzb.nwpu.edu.cn/），进入博士网上报名系统，选择相应报名批次进行修改，逾期不再受理。
五、注意事项
（一）建议本校直博生、硕博连读生将通讯地址修改为家庭住址，以免毕业离校后，录取通知书无法投递。
（二）请使用Chrome浏览器登录博士网上报名系统。
（三）修改通讯地址仅一次机会，请慎重填写。
