# 北研院党支部召开“严守纪律规矩 加强作风建设”专题组织生活会-西北工业大学

9月23日下午，北京研究院党支部召开“严守纪律规矩 加强作风建设”专题组织生活会。资产公司党委委员杨安庆同志参会指导，研究院党支部全体党员参加，会议由党支部书记方文杰主持。
方文杰代表北京研究院党支部委员会向全体党员报告了北京研究院开展“廉洁文化宣传教育月”和纪律教育的有关情况，并通报了此次民主生活会会前学习和党员谈心谈话的情况以及党支部检视存在的问题。随后，支部党员逐一发言，讲收获提高，讲差距不足，结合自身工作实际，认真开展自我批评和批评。
杨安庆对本次专题组织生活会给予了充分肯定。方文杰在总结发言时表示，党的纪律建设和作风建设没有终点，支部党员要通过此次专题民主生活会，更加深入地学习贯彻习近平总书记关于全面从严治党、党风廉政建设、纪律建设、廉洁文化建设的重要论述，严守政治纪律和政治规矩，增强意识形态风险防控意识，以更加昂扬的精神状态和奋斗姿态迎接党的二十大胜利召开。
