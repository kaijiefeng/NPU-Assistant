# 学院举办2026年陕西省中外合作办学学生外语演讲比赛院内选拔赛

为扎实落实陕西省教育厅《关于举办2026年陕西省中外合作办学学生外语演讲比赛的通知》相关工作部署，深入践行“以赛促学、以赛促教、以赛促践”育人理念，近日，莫航学院组织开展2026年陕西省中外合作办学学生外语演讲比赛院内选拔赛。学院党委副书记程茵、团委副书记邢文思、俄语教师、外事秘书等担任评委。学院共计40余名学生踊跃报名参与本次选拔赛。
本次大赛以“以声赓续文脉，以语联通世界”为主题，设置英语、俄语两个赛道。比赛现场，参赛学子依次登台，围绕文化自信、青年使命、文明互鉴等主题，以流利的英语及俄语传递青年心声，讲述中华文脉故事，彰显新时代青年深厚的家国情怀与广阔的国际视野。评委老师结合选手的语言表达、内容立意、现场发挥等方面进行专业点评，并有针对性地提出后续改进建议。
此次赛事以语言为桥、以声音为媒，既为同学们搭建了外语实践和展示交流的平台，也为选手备战省级演讲比赛夯实基础。学院将持续建强语言实践育人阵地，引导青年学子厚植家国情怀，锤炼专业素养，在国际化学习交流中讲好中国故事，践行青年担当。
