# 保卫处开展“12.4”国家宪法日系列宣传教育活动

在“12.4”国家宪法日到来之际，为弘扬宪法精神，深入贯彻落实习近平法治思想，做好法治宣传教育工作，保卫处结合实际工作开展系列法制宣传教育活动。
12月2日和12月4日，保卫处分别对友谊校区校卫队员和全体干部、长安校区校卫队员开展普法宣传教育活动。期间，由保卫处友谊校区安保办孙燕萍同志作题为《保卫与法》的主题宣讲。通过宣讲，让同志们了解如何运用法律知识开展工作，提升保卫处校园综合治理的法治化、规范化水平。
宣讲内容分为六个章节，分别为：“盗窃与遗失的法律界定”、“校园内机动车剐蹭与交通事故的法律认定”、“流浪狗治理的法律溯源”、“聚众闹事行为的法律定性”、“火灾预防与发生的法律问题”、“宪法修正案”、“民法典中的婚姻法“。宣讲会内容充实，重点突出，对全处职工深入领会习近平法治思想，学习宪法要义，推进保卫处校园综合治理工作起到了积极的促进作用。
会后，同志们就相关法律问题开展了热烈的讨论。朱建军处长指出，孙燕萍同志给我们开启了一个良好的开端，今后我们应多多组织这样的活动，让其他有专业特长的同志也来给大家做宣讲，将保卫处的培训教育常态化、多样化。
