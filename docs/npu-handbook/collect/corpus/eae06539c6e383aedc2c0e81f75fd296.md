# 西北工业大学数字艺术未来设计师学科竞赛基地在2026年第十四届未来设计师全国高校数字艺术设计大赛（NCDA）中再创佳绩-西北工业大学教务部

近日，2026年第十四届未来设计师全国高校数字艺术设计大赛（NCDA）全国总决赛评审结果揭晓。我校共荣获国家级奖项13项，其中一等奖3项；省级以上奖项51项，其中一等奖9项。同时，我校获得全国总决赛集体荣誉“优秀组织奖”，多名教师获评“优秀组织教师”“优秀指导教师”。
本次获奖作品紧密结合国家战略与社会需求，深度彰显我校“三航”与硬核科技特色，广泛覆盖智慧医疗与特殊人群康养、生态可持续与绿色低碳等领域，并深度融合非遗文化传承与乡村振兴等社会议题，充分体现了工大学子“专业精、系统强、重实践、能担当”的综合素养与以设计服务国家、回馈社会的家国情怀。
第十四届未来设计师全国高校数字艺术设计大赛（NCDA）全国总决赛一等奖作品封面
未来设计师全国高校数字艺术设计大赛（NCDA）始于2012年，每年举办一届，已连续举办13届，是入选《全国普通高校学科竞赛排行榜》，由工业和信息化部人才交流中心、未来设计师 全国高校数字艺术设计大赛组委会主办，获近20个省（区、市）教育厅认定，“学习强国”学习平台支持，对接联合国国际赛的国家级大学生竞赛。本届大赛共有1916所高校参与，征集作品32万余件，设有29个省级赛区；985、“双一流”高校及国内顶尖美术学院参赛率高达95%，设计学学科评估C级以上的高校全部参赛。
我校“数字艺术未来设计师学科竞赛基地”成立于2024年，由力学与交通运载工程学院建筑学系杨晨副教授牵头负责，是对标NCDA，培养我校学生人文艺术素养、设计创新精神、工程实践能力等系统性素养的重要基地之一。基地依托高水平的学科竞赛，全面提升学生的专业知识、创新思维、实践技能和团队协作能力等综合素养。基地面向学生成长需求，服务第二课堂建设，拓展学生在理工科背景之外的人文艺术与知识探索，以实现人才培养的多样化和专业化。
在教务部和力学与交通运载工程学院的持续支持下，基地将继续紧扣国家重大战略需求，以学科竞赛为牵引，深化教育教学与人工智能等前沿技术的交叉融合；持续赋能课程改革，全面提升学生的系统整机观念、创新思维与工程实现能力，致力于培养具备“专业精、系统强、重实践、能担当”特质的新时代“总师型”拔尖创新人才，助力学校高质量发展。
