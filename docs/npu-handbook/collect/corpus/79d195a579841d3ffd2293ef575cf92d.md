# 学校开展2026年消防宣传月应急疏散逃生大演练

2026年11月9日是第35个全国消防日，11月消防宣传月的主题是“全民消防、生命至上—提高自防自救能力”。为进一步提升全校师生的消防安全意识和自救互救能力，完善校内各部门联合应急处置火情等突发事件的联动机制，按照上级要求和学校工作安排，11月5日下午，学校在长安校区海天苑4号学生公寓组织开展了2026年消防宣传月应急疏散逃生大演练。党委保卫部部长朱建军担任演练总指挥，党委学生工作部、党委保卫部、后勤部、校医院以及西安市高新区消防救援局秦岭三路消防救援站、高新分局东大派出所等相关单位参加了演练。
11月5日14时30分，海天苑4号学生公寓436室突发火情，楼内报警声音响起，循环播报安全疏散提示。物业管理人员确认火情后立即拨打党委保卫部报警电话、119火警电话和校医院急救电话，按下安全出口一键开启按钮，迅速组织学生进行紧急疏散，有序撤离至楼外安全区域。
接警后，灭火战斗组、交通警戒组、引导疏散组、医疗救护组及后勤保障组快速集结赶赴现场，有序开展灭火救援工作。交通警戒组在道路两侧设置警戒线，进行交通疏导，保障消防及医疗救援通道畅通。灭火战斗组驾驶微型消防车，到达现场后分为搜救组、内攻组开展灭火救援。搜救组进入公寓楼展开全范围搜索，引导被困学生保持低姿、捂好口鼻，有序撤离至楼外安全区域；内攻组进入火场后，对起火点进行勘查，就近利用楼内消火栓铺设水带，建立灭火阵地，待后勤保障组切断电源后立即实施初期火灾灭火。引导疏散组在一楼楼梯口引导参演学生迅速疏散到室外开阔地带。秦岭三路消防救援站接警后立刻出动2辆灭火救援车到达火情现场，与校内搜救组密切配合，发现受伤人员后用担架救出，转移至医疗救援组进行专业救治；同时在楼外驾驶举高喷射消防车从外部向起火点方向实施灭火。经过紧急、高效的灭火救援，在各单位通力协作下，14时38分，海天苑4号学生公寓火情扑灭完毕，被困人员安全救出，疏散逃生大演练顺利完成。随后，秦岭三路消防救援站丁老师对演练流程、疏散规范进行细致点评，并就冬季消防安全注意事项进行提醒。朱建军对演练活动进行总结，强调希望参演师生积极参与学校消防安全教育活动，提升个人自救能力。
演练活动结束后，秦岭三路消防救援站和学校微型消防站采用双场地同步授课模式，对在场师生开展了消防技能实操培训。秦岭三路消防救援站现场展示了灭火救援各类器材装备，向在场师生讲解了常用救援装备的功能、使用场景和操作要点，并邀请学生上手操作和试穿灭火战斗服。学校微型消防站为师生讲解并演示了干粉灭火器的使用方法，重点强调了“提、拔、握、压”的操作要领，在场师生轮流操作体验使用灭火器灭火，进一步提升了扑救初期火灾能力。
此次演练是学校2026年消防宣传月系列活动之一。后续，党委保卫部将继续坚持消防工作“预防为主、防消结合”的方针，加强与校内各部门、属地消防救援机构等联动配合，持续常态化开展消防安全教育、应急演练、隐患排查整治工作，让消防安全理念融入日常。
