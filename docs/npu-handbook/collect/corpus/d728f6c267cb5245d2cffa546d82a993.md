# 2026年陕西省智慧校园示范活动暨高校网络安全培训会议在我校举办

9月16日上午，2026年陕西省智慧校园示范活动暨高校网络安全培训会议在西北工业大学学术交流中心顺利召开。陕西省教育厅教育信息化处领导出席会议并致辞，会议由我校信息化管理处处长薛静主持。来自全省高校信息化部门的负责同志、业务骨干及合作厂商代表共130余人参加。
会议围绕“智慧校园示范”与“网络安全宣传”两大主题展开，旨在通过专题报告、经验分享和案例展示，为全省高校智慧校园建设提供“西工大经验”。
在专题报告环节，我校信息化管理处三位同志围绕高校信创体系建设、网络安全纵深防御体系建设、信息设备保密与运维管理等主题，系统介绍了学校在网络安全责任制落实、数据治理、智能防护、保密管理等方面的探索实践。此外，紧贴网络安全工作痛点，集中展示了AI驱动的校园网络安全运营门户、钓鱼邮件治理的智能体方案及校园网络安全协同运营平台三项实践应用，体现了“以AI对抗AI”的网络安全防护理念，为高校网络安全智能防御提供了可借鉴的实践路径。报告内容兼具体系框架与实操演示，引发了与会代表热烈讨论。
本次会议不仅展示了我校在智慧校园建设与网络安全领域的积极探索与阶段性成果，也为陕西省高校信息化发展搭建了高质量的交流合作平台，在促进经验互鉴、凝聚行业共识方面取得了良好成效，为推动全省教育数字化、智能化转型提供了有益借鉴和有力支撑。
