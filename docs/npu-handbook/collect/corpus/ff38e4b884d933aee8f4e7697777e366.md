# 南京航空航天大学保卫处来我校调研

2021年3月31日，南京航空航天大学保卫处徐曙峰副处长一行来我校保卫处调研，保卫处朱建军处长、皮德福副处长出席了座谈会。
朱建军处长向徐曙峰副处长一行介绍了我校保卫处的基本情况，以及人员编制管理、制度建设、信息化建设、多校区保卫管理模式等方面的工作开展情况。他谈到，去年我校保卫处在各方面工作中取得了一定进步，但与东部地区高校安全保卫工作相比还存在差距，希望借此机会与南京航空航天大学保卫处领导多交流，学习先进工作经验。徐曙峰副处长对朱建军处长的介绍表示感谢，希望双方单位今后进一步加强交流，促进共同发展。
随后,双方就校园安全保卫工作中的重点难点问题进行了深入探讨。
会后，徐曙峰副处长一行参观了监控中心。
