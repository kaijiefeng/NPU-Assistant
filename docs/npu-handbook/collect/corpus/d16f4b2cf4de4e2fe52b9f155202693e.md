# 【暑期项目】关于2026年俄罗斯莫斯科航空学院暑期学校项目报名的通知

一、项目名称
2026年俄罗斯莫斯科航空学院暑期学校项目
二、项目外方高校
莫斯科航空学院
三、外方高校简介
莫斯科航空学院（Moscow Aviation Institute）成立于1930年，是俄罗斯国立研究型大学，隶属于中俄工科大学联盟成员。该校总部位于莫斯科，拥有拜科努尔航天发射场等航空基地及分院，设有航空宇宙系、飞机机械系、飞行器发动机系等11个教学单位，涵盖60余个专业方向。
莫斯科航空学院是俄罗斯历史最悠久的航空航天专业院校之一，校园环境优越，现有在校生近2万人。其学科体系涵盖9个系与6个研究院，包括飞机机械系、航空宇宙系、应用数学与物理系等核心院系，开设60多个专业，研究方向从飞行器设计延伸至电子信息、经济管理等交叉领域。
四、项目合作背景
两校已正式签订人才培养合作协议，为项目开展奠定坚实基础。项目依托双方在航空航天教育领域的办学优势，打造 “通用俄语 + 航空/电子专业俄语 + 专业场景研学” 的特色暑期交流模式，是学院推进国际化人才培养的重要实践。
