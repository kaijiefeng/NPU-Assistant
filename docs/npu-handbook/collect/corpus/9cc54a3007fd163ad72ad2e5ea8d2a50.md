# 以赛促教强本领，名师助力促提升——自动化学院成功举办2026年青年教师教学竞赛

为进一步夯实青年教师教学基本功，搭建教学交流与风采展示平台，推动本科教学质量持续提升，10月22日下午，自动化学院青年教师教学竞赛决赛在学院341会议室成功举办。竞赛特邀国家级教学名师史仪凯、段哲民、孙浩、赵美英及陕西省教学名师李玉忍担任评审专家。自动化学院院长李伟林，副院长程塨、王小旭出席活动，西藏民族大学工学院冉照海书记一行应邀莅临观摩、指导交流，竞赛由程塨主持。
竞赛伊始，程塨介绍了出席决赛的领导和评审专家，并简要介绍赛事组织安排。本次竞赛历经初赛决赛两个阶段，自启动以来，得到全院青年教师积极响应，共有29名教师报名参赛，经激烈角逐，9名教师进入决赛。他提出，各位名师专家深耕教学一线，具有丰富的教学经验和深厚的学术造诣。希望青年教师珍惜机会、展示自我，认真听取专家宝贵意见。
李伟林在致辞中代表学院向担任本次竞赛评委的各位名师专家致以热烈欢迎和诚挚感谢，向莅临指导交流的西藏民族大学工学院冉照海书记、乔丽萍副院长及各位青年教师表示特别感谢，希望以此次竞赛为契机，进一步加强两院交流合作，相互学习、共同进步。随后，他介绍了近年来学院在学科建设、科学研究、教育教学、人才培养等方面取得的成效。他强调，学院始终牢记为党育人、为国育才的初心使命，坚持以人才培养为中心，持续深化教育教学改革。青年教师作为学院师资队伍的生力军，要锤炼教学功力，守好人才培养主阵地。同时也向参赛教师提出三点要求：一是赛出水平、展示风采，充分展示专业功底和精神风貌；二是以赛促教、以赛促改，把竞赛中的收获转化为课堂教学的实际改进；三是坚持初心、潜心育人，真正做到立德树人。
课堂教学展示环节中，9位参赛教师依次登台，围绕参赛课程进行精心设计的教学呈现，充分展现了我院青年教师扎实的专业功底与各具特色的教学风格。随后名师专家围绕教学内容设计、AI时代教学组织创新、板书规范与设计等方面对每位选手给予了细致到位的点评指导。专家既肯定了亮点，也指明了改进方向，为青年教师教学能力提升精准把脉，现场研讨氛围浓厚。
教师展示教学风采
经过激烈角逐与公正评审，竞赛最终评选出特等奖2人、一等奖3人、二等奖4人，国家教学名师史仪凯教授宣读获奖名单。名师专家代表及西藏民族大学乔丽萍副院长共同为获奖教师颁发荣誉证书。
国家教学名师史仪凯为特等奖教师颁奖
国家教学名师段哲民为一等奖教师颁奖
西藏民族大学工学院副院长乔丽萍为二等奖教师颁奖
王小旭做总结讲话。他表示，各位评审专家给出的宝贵指导意见，不仅对参赛教师个人成长具有重要意义，也为学院改进教学提供了有益借鉴。希望教师们珍惜荣誉、再接再厉，认真吸收专家点评中的意见建议，对照自身教学找差距、明方向，在日常教学中精耕细作，持续打磨教学基本功。同时也感谢西藏民族大学工学院冉照海书记带队莅临指导交流，希望后续两院以本次竞赛为契机，在教学研讨、人才培养、科学研究等方面开展更多合作，共同推动合作走深走实。
本次竞赛坚持以赛促学、以赛促改、以赛促创，为学院教师搭建了教学展示、交流互鉴的良好平台。学院后续将一如既往地重视和支持青年教师成长，搭建竞赛、培训、研讨等平台，持续推动教育教学改革，引导教师深耕教学，推动学院人才培养质量不断提升。
