# 铸魂励志强根基，科技报国担使命——电子信息学院2026年第1期入党积极分子集中培训顺利开展

4月下旬，电子信息学院党委组织开展了2026年第1期入党积极分子集中培训。本次培训以“金色课堂”“红色课堂”“蓝色课堂”为载体，引导学员筑牢信仰之基、锤炼过硬本领、勇担时代使命。
金色课堂：理论铸魂，把稳思想之舵
金色课堂聚焦党的创新理论与国家发展战略，为学员思想“补钙”、精神“铸魂”。
4月21日，高旭红教授围绕《深入学习领会“十五五”规划》专题授课，从规划纲要的主要内容切入，讲解国家未来五年发展的战略任务和重大举措，帮助学员把握“十五五”时期的阶段性特征与奋斗目标。高旭红谈到，青年学生要主动关心国家大事，把个人学业规划同国家发展需要联系起来，在服务大局中找准自身定位。
4月23日，代家玮副教授以《教育、科技、人才一体化发展的历史镜鉴与时代回应》为题授课，介绍了近年来国家在教育、科技领域推出的一系列改革举措，分析了人才培养面临的新形势新要求，鼓励学员打牢专业基础，关注行业发展前沿，把学习成果转化为报效国家的实际能力。
4月29日，陈诚平副教授主讲《坚定不移全面从严治党，深入推进新时代党的建设新的伟大工程》。课程系统回顾了党的十八大以来全面从严治党取得的重要成果，阐释了持续深化自我革命的现实意义，提醒学员从申请入党开始就要树立规矩意识，在日常学习生活中严格要求自己，逐步养成过硬作风。
红色课堂：初心砺志，赓续红色血脉
红色课堂突出理想信念教育与党性锤炼，让初心使命入脑入心。
4月9日，全体学员共同观看晋剧《一门忠廉·折家军》。这场沉浸式红色教育将传统戏曲与党性教育有机融合，引导学员在艺术共鸣中感悟许党报国的赤诚初心。
4月22日，赵海霞教授讲授《坚定理想信念，争做合格党员》专题党课。她从“什么是理想信念”“为什么要坚定理想信念”“怎样做合格党员”三个问题入手，阐释党员的基本标准和应有的责任担当。课堂上，赵海霞还就学员们关心的问题进行了回应，鼓励大家以实际行动向党组织靠拢。
4月23日，党务秘书王心怡就《中国共产党发展党员工作流程》作专题讲解，逐一梳理了申请入党、入党积极分子的确定和培养教育、发展对象的确定和考察、预备党员的接收、预备党员的教育考察和转正五个阶段的工作要求，并对常见问题进行了说明，帮助学员熟悉发展流程和规范。
蓝色课堂：科创赋能，深耕专业报国
蓝色课堂立足专业特色与科技前沿，助力学员提升素养、厚植家国情怀。
4月10日，电子科技大学王勇教授带来《城市极化SAR分解：面向下一代SAR技术的挑战与应对》讲座，围绕合成孔径雷达技术的前沿动态与关键挑战进行深度讲解，引导学员以专业能力服务国家科技自立自强，将“总师育人文化”内化于心、外化于行。
研讨交流：学思互鉴，凝聚奋进共识
培训期间，全体学员围绕党的二十大和二十届历次全会精神、“总师育人文化”开展专题研讨。学员们结合理论学习、专业实践与成长规划分享心得，不少学员表示，要把学习成果落实到日常行动中，努力向“总师型”人才靠拢，持续提升综合素质。深入的交流进一步加深了学员对党的创新理论和学校育人理念的理解，进一步坚定了“强国有我、科技报国”的理想信念。
此次培训通过“金色课堂”“红色课堂”“蓝色课堂”的有机衔接，将理论教学、红色教育与专业拓展融为一体，有效提升了入党积极分子的政治素养与使命意识。未来，电子信息学院党委将持续优化入党积极分子培养模式，不断深化“金色、红色、蓝色”三大课堂建设，引导更多青年学生成长为信念坚定、能力过硬、作风踏实的合格党员后备力量，为学院高质量发展、学校“十五五”发展规划和国家现代化事业发展添砖加瓦。
