# 西工大学子在全国高校商业精英挑战赛会计与商业管理案例竞赛中取得佳绩

近日，全国高校商业精英挑战赛会计与商业管理案例竞赛全国总决赛圆满落幕。本次大赛由中国国际贸易促进委员会商业行业委员会、中国国际商会商业行业商会和中国商业经济学会联合主办，影响力广泛，吸引了来自全国30个省、自治区、直辖市的近600所高校积极参与。在未来财智领航者创新实践基地的精心筹备下，西北工业大学的学子们在此次竞赛中表现卓越，成功斩获国家级一等奖1项、国家级二等奖5项与国家级三等奖1项。该项赛事设置了知识赛、校赛、全国（区/市）预选赛以及全国总决赛等多个环节，着重考查选手运用会计信息开展自主商业研究的能力。从策划案撰写时对市场的深入调研，到结合专业知识精心构思每一处细节；从PPT制作中力求以清晰逻辑和精美设计展现方案亮点，到参赛视频排练与录制时的反复打磨；再到全国赛路演视频录制及决赛答辩环节，同学们始终沉着自信，兼收并蓄、厚积薄发。
一直以来，管理学院高度重视学科竞赛，积极为学生搭建广阔的实践平台，大力鼓励学生参与各类高水平赛事，助力学生在实践中锻炼能力、提升素养。此次在全国高校商业精英挑战赛中取得的优异成绩，不仅为学校的学科竞赛成果增添了浓墨重彩的一笔，也将激励更多西工大学子在未来的学术与实践道路上奋勇前行，不断创造新的辉煌！
（撰稿/杨萍 审核/陈琳）
