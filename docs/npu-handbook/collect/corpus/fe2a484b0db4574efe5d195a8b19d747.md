# 2027年硕士研究生招考报名信息拟存在问题考生名单

各位考生：
在2027年硕士研究生招生考试报名中，部分考生报名信息存在问题或疑问。主要涉及学历（学籍）校验未通过、有研究生学籍的考生。为确保后续报考流程顺利进行，请相关考生按要求修正报考信息。
一、网报提示学历（学籍）校验未通过的考生
根据相关规定，凡网报提示学历（学籍）校验未通过的考生，尽快查明原因，按提示要求修改。网上确认时需提交相关说明，以免耽误报考。
造成学历（学籍）校验未通过可能的原因和要求提供的材料有：
1. 身份证号变更。（须提供公安部门身份证号码更正证明及原学信网学历和学籍认证报告、学历证书复印件）
2. 姓名变更。（须提供公安部门身份证号码更正证明，户口本更名页复印件及原学信网学历和学籍认证报告、学历证书复印件）
3. 从未做学历（学籍）认证。（须提交学信网学历认证报告和学籍认证报告、身份证复印件、学历证书复印件）
4. 国外学历。（须提交教育部留学服务中心认证报告、学历证书复印件）
5. 毕业学校更名。（须提交学信网学历认证报告和学籍认证报告、身份证复印件、原学校学历证书复印件）
6. 毕业时间填写错误。（要求与毕业证书时间一致。务必准确填写年、月、日）
二、网报提示有研究生学籍的考生
在校研究生报考须在报名前征得所在学校同意，需提供相关证明。证明没有统一模板，但请务必注明“同意报考”字样，同时需校级单位（研究生院）盖章。
