# 2022第三届先进控制与智能系统前沿论坛成功举办

11月1日-4日，第三届先进控制与智能系统前沿论坛以线上形式成功举办。本次论坛由西北工业大学学科建设办公室主办，自动化学院和信息融合技术教育部重点实验室承办。
论坛邀请到了控制、智能、导航系统领域的13位知名专家就自身当前领域的研究作主题报告。大会由黄攀峰教授、王小旭教授、刘准钆教授担任主席，200余名相关领域专家、学者及师生线上参加。
论坛开幕式由国务院控制科学与工程学科评议组成员、国家级高层次人才、自动化学院院长黄攀峰教授主持。西北工业大学校长助理、学科建设办公室主任张艳宁教授致开幕辞。
11月1日上午的学术报告环节，中国科学技术大学李智军教授作了题为“面向感觉与运动功能重建的穿戴机器人与生机电系统”开场报告，对可穿戴机器人的现有的科学问题进行了深入分析与研究，并演示了可穿戴机器人在肢体损伤患者康复训练和机器人辅助运动等方面的应用。
北京大学喻俊志教授作“水下仿生跨介质机器人”报告，主要从海洋生物的游泳姿态出发，以斑原海豚为仿生对象，探索海豚跨介质运动的机理。国防科技大学罗晖教授作“光电惯性技术前沿”报告，介绍了激光陀螺的基本原理与特点、主要误差因素和涉及的技术领域，总结了国外激光陀螺的发展历程与应用情况，并与会学者还就惯性导航发展开热烈讨论。浙江大学胡慧珠教授作“基于悬浮光力学的光动量传感研究进展”报告，介绍了其团队在基于光动量效应的悬浮光镊系统的研究进展，并对相关应用进行了展望。
下午场的学术报告环节，浙江工业大学张文安教授作“网络化多传感器信息融合估计”报告，介绍了多传感器信息融合技术取得的最新研究成果，并探讨该方向有待解决的问题。北京航空航天大学李文玲教授作“多目标跟踪的复杂运动建模与估计”报告，介绍了多目标跟踪算法设计面临的目标运动不确定、传感器测量不确定和目标数目不确定等不确定性难题。航空工业自控所得王祎敏研究员作“机载PNT技术发展和思考”，介绍了机载PNT技术的发展和演进趋势，并给出了未来发展的展望和思考。北京理工大学郑乐教授作“自动驾驶中的高分辨毫米波雷达系统”报告，介绍了分布式毫米波雷达技术在自动驾驶的应用并介绍了课题组在该方面的研究成果和未来发展方向。
11月2日上午的学术报告环节，东北大学付俊教授作“Deterministic dynamic optimization and control of nonlinear systems”报告，介绍了一种基于右手边限制技术的新型动态优化算法，和开关动态系统的开关方法。北京工业大学乔俊飞教授作“城市固废焚烧过程智能优化控制”报告，针对城市固废焚烧过程动态调控的共性问题，重点介绍课题组近年来在其检测、建模和智能优化控制方面取得的研究进展。天津大学李醒飞教授作“宽频微角振动传感器及在空间载荷中的应用”报告，介绍了基于基于流、电、磁、力多物理场耦合仿真的MHD微角振动传感器分析与设计方法，展示了MHD微角振动传感器在惯性参考单元中的具体应用。中南大学谢永芳教授作“基于分布机器视觉的矿物浮选过程智能化”报告，介绍了将分布机器视觉引入浮选过程后助力智能化生产的整个流程，展现了机器视觉在工业中的应用。浙江大学贺诗波教授作“现场级工业物联网架构与互联互通技术”报告，对现场级工业物联网的架构进行了探讨和相关关键技术进行了剖析。
论坛报告主题丰富、内容详实，与会师生就报告中的学术问题进行了多次深入交流探讨，会场氛围热烈融洽。论坛为控制、导航、智能系统领域专家学者探索学科前沿、增进学术交流、加强科研合作搭建了良好平台，有助于广大师生进一步了解前沿动态、拓宽科研思路，也为促进本校基础学科、新兴学科、交叉学科发展建设起到了积极作用。
