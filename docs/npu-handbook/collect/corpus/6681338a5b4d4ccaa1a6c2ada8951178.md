# 中国近现代史基本问题研究系召开集体备课会学习《中国共产党思想政治工作条例》-西北工业大学

为帮助师生掌握《中国共产党思想政治工作条例》（以下简称《条例》）所提出的新要求与新举措，更有效地落实习近平总书记针对高校思政课的一系列重要指示精神，11月27日，中国近现代史基本问题研究系召开集体备课会，对《条例》展开学习。
通过学习，老师们进一步深刻认识到思想政治工作是党的优良传统、鲜明特色和突出政治优势。同时也认识到，《条例》作为我们党历史上第一部关于思想政治工作的统领性、综合性基础主干法规，是做好新时代思想政治工作的根本遵循，对于坚持和加强党对思想政治工作的全面领导，提升思想政治工作科学化、制度化、规范化水平，具有重大意义。围绕实际工作需求，老师们探讨了如何将《条例》中党的思想政治工作新要求，落实到教学科研工作以及教研队伍建设当中。并就如何依托思政课程和课程思政助力西北工业大学“总师育人文化”建设展开讨论。
此次学习活动助力教师们更深入地领会思想政治工作“生命线”地位，提升了对思政课教师以习近平新时代中国特色社会主义思想铸魂育人这一光荣使命的认知，有助于在后续课程中持续推动党的创新理论进教材、进课堂、进头脑。
