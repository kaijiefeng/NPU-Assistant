# 公共政策与管理学院学生赴成都银行西安分行暑期专业实习圆满收官

近日，公共政策与管理学院国际经济与贸易专业学生圆满完成成都银行西安分行暑期专业实习活动。为展现实习实践成果、交流成长收获，7月30日，成都银行西安分行举办实习生结业交流会，分行行长谭志慧、行长助理李军、人力资源部负责人李婉璐、个人金融部负责人王旭、公司业务管理部负责人徐腾、带教老师及全体实习学生共同参加会议。
本次专业实习依托实习实践基地，学院与银行前期协同制定专业实习方案，精准匹配实习岗位，严格组织面试遴选，最终选派9名优秀学子赴成都银行西安分行开展为期一月的专业实习。同学们分组入驻个人金融、公司金融两大核心业务条线开展沉浸式跟岗实训，在一线金融岗位勤学实干、积累经验，圆满完成实习实践任务。
实习总结交流会上，我院实习生代表王舒冉、魏子童结合自身岗位经历依次分享实践心得，系统复盘一月以来的岗位实操收获与成长感悟，真诚致谢带教老师的悉心指导。
成都银行西安分行行长谭志慧为实习生颁发实习证书并作总结发言。谭行长对我院学子在实习期间的综合表现给予高度肯定与赞扬，她指出，本次校企实习合作成效显著，是高校优质人才资源与银行行业实践平台的深度融合。金融行业兼具专业性与实践性，希望同学们珍惜此次实习收获，巩固合规思维、服务意识与风控理念，将一线实务经验转化为专业学习动力。
此次实习实践，是我院落实立德树人根本任务、深化校企协同育人、落实“总师育人文化”的重要举措，也是提升学生就业核心竞争力的有效途径。下一步，我院将持续深耕校企合作，不断拓展优质实践育人平台，持续推动以学促练、以练促长的人才培养模式落地，引导学生在行业一线锤炼本领、增长才干，以过硬的专业能力和职业素养奔赴未来职场新征程。
