# 外国语学院召开2026年教师表彰暨教师节座谈会

金秋九月，桃李芬芳。外国语学院2026年教师表彰暨教师节座谈会于9月10日下午在友谊校区翱翔体育馆201会议室顺利举行。学院党政领导班子成员、教职工代表参加本次会议，座谈会由学院党委书记王高祖主持。
会议伊始，王高祖书记带领大家共同学习了习近平总书记关于师德师风的重要论述，引领全体教师筑牢思想根基、恪守育人初心。他代表学院党政班子向全院教职工致以节日问候，向本次受到表彰的先进个人和集体表示热烈祝贺，向长期扎根教学科研一线、默默耕耘奉献的全体教师致以崇高敬意。他强调，学院2026年在人才培养、学科建设、国际交流、教学科研等方面取得的各项成果离不开每一位教师的坚守与付出。
随后进入表彰环节。伴随着热烈的掌声，获奖教师依次上台，工作人员为获奖教师献上鲜花，致敬榜样力量。
座谈交流环节。与会教职工代表踊跃发言，气氛热烈。大家结合自身课堂教学、思政引领、科研课题、国际合作等工作实际，分享育人感悟，畅谈工作思考，交流工作中的经验与困惑。王高祖认真倾听各位老师发言，并结合老师们提出的意见作出回应。他指出，学院正处在快速发展的转型期，机遇与挑战并存，全院教师要牢牢把握立德树人根本任务，牢记为党育人、为国育才使命，坚守师德师风底线，把价值引领贯穿外语教学全过程。外语学科是文明交流互鉴的窗口，广大教师要发挥专业优势，既要深耕课堂、打磨教学本领，持续提升人才培养质量，服务学校人才培养；也要顺应人工智能时代，善用AI赋能课堂教学，创新科研范式，以新技术助力外语教学改革提质增效、科研工作转型升级。学院将全力支持教师发展，营造尊师重教、干事创业的良好氛围，共同推动学院事业高质量发展。（文/王开薇；图/田研；审稿/王高祖）
