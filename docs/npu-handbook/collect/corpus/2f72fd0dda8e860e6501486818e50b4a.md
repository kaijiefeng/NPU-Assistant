# 网络空间安全学院召开“深化本科人才培养改革”专题研讨会暨教师集体备课活动

为扎实推进培养方案修订工作，进一步深挖“总师型”人才从“1”到“0”的内涵，2026年4月12日9:00，学院在友谊校区爱生楼召开了“深化本科人才培养改革”专题研讨会暨教师集体备课活动。活动由学院院长助理张慧翔主持。学院教学副院长刘志强、学院督导、各系（部）主任及相关骨干教师参加了会议。
会议伊始，刘志强首先强调了本次研讨会的背景和重要意义。他指出，当前知识迭代速度加快、学生信息获取能力显著增强，传统的知识传授模式面临深层挑战。2026级本科培养方案的修订必须牢牢把握立德树人根本任务，紧密对接国家网络安全战略需求和科技前沿趋势，将学院的办学特色与学校深厚的“总师育人文化”深度融合，着力培养具有家国情怀、系统思维与创新能力的网安领军人才。
与会教师重点围绕“2026级本科培养方案优化”与“新开课程设置”展开了深入研讨。各系主任及骨干教师结合专业特点，就课程体系的逻辑衔接、知识点重叠的梳理压缩、专业基础课的夯实等问题进行了热烈交流。会议明确提出，应改变过去教师“单兵作战”的模式，通过组建教学团队与“课程群”，统筹协调相关课程的教学内容与资源建设，形成育人合力。与会专家一致认为，在新一轮培养方案中，必须进一步突出学院“厚基础、强系统、重实战、拓交叉”的人才培养模式，在整合优化课程内容的同时，严控新开课程方向，避免资源碎片化，切实解决课程间内容重复、知识结构递进关系模糊等痛点。会议还提出，实践教学应紧扣毕业能力要求进行系统设计，明确各学期实训课程的具体目标与进阶路径，确保实践环节与培养标准的精准对应。
在会议核心环节，与会人员聚焦“总师型”人才从“1”到“0”的深挖议题进行了专题研讨。与会教师认为，网安人才的培养必须彰显鲜明的行业背景与系统工程思维，将“总师”应具备的全局视野、架构设计能力与攻坚克难的意志品质，具体落实到培养方案与课程内核之中。会议提出，应以“总师育人文化”为引领，围绕厚基础、强系统、重实战、拓交叉四个维度构建全链条课程体系，着力夯实数理根基、贯穿信创系统安全能力培养、强化攻防实战训练、拓展学科交叉视野。与会教师一致认为，应以“五个一”举措为抓手，集中力量打造一批有深度、有特色、有引领性的“金课群”，推动学生在本科阶段建立起从底层原理到系统整机的完整认知闭环。
面对生成式人工智能对教育形态的深刻影响，会议专门就“AI赋能教学”与教学模式创新进行了专题研讨。与会教师指出，必须正视学生通过多渠道自主学习能力提升的现实，主动将AI技术融入教学各环节。会议探讨了利用AI构建课程知识图谱、实现个性化学习路径规划及智能辅导的可行性。学院督导强调，在引入新技术手段的同时，务必守住教学质量底线，对教学大纲、讲义及考核材料提出更严格的规范化要求。
在随后开展的集体备课环节中，学科基础课与专业核心课的课程负责人分别分享了建设思路，并围绕教学大纲的落地衔接、课程思政元素的有机融入等议题进行了深入的经验交流。会议还对鼓励经验丰富的老教师牵头编写国家级规划教材、推动优质教学资源建设等事宜进行了初步部署。
最后，刘志强进行会议总结。他表示，本次研讨会既是2026级本科培养方案的顶层设计预备会，也是一次直面问题、凝聚共识的思想碰撞会。希望全院教师以此为契机，将会议成果转化为推动改革的切实行动，一体化推进课程、教材、实践与评价体系建设，构筑具有鲜明西工大特色的网络空间安全拔尖创新人才培养体系，为服务国家战略需求续写新的“西工大现象”。
