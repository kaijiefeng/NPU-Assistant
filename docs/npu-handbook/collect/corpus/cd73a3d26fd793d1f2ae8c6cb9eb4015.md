# 赓续长征精神，勇担强国使命”五校荣誉学院、未来技术学院赴延安开展党建联学活动

为纪念中国工农红军长征胜利90周年，10月10-11日，西北工业大学、哈尔滨工业大学、武汉大学、电子科技大学、兰州大学五校荣誉学院、未来技术学院齐聚延安，联合开展“赓续长征精神，勇担强国使命”主题党建联学活动，以红色实践教育铸魂砺志，激励青年学子奋楫笃行。
巍巍宝塔山下，五校学子集体诵读红色经典，厚植家国情怀，汲取奋进力量。活动现场，西北工业大学“我要当总师”学生宣讲团聚焦长征精神、延安精神与军工报国使命，发起“一代人有一代人的长征路”主题倡议，启动纪念中国工农红军长征胜利90周年线上宣讲活动。
循着革命足迹，五校师生先后前往杨家岭革命旧址、延安革命纪念馆、中国人民抗日军政大学纪念馆、凤凰山革命旧址，聆听思政大课《延安革命旧址是一本永远读不完的书》《再回延安》，沉浸式感悟老一辈革命家救国图强的担当坚守与矢志不渝的理想信念。
本次党建联学活动组织五所高校拔尖学子齐聚革命圣地，赓续红色血脉、淬炼初心使命，是国内一流高校互学互鉴、协同聚力，共建拔尖学生成长共同体的生动实践。未来，学院党委将持续引导青年学子立足学科专业锤炼过硬本领、锚定国家需求勇毅前行，把青春理想融入强国复兴伟大事业，以实干实绩彰显新时代青年的责任与担当。
