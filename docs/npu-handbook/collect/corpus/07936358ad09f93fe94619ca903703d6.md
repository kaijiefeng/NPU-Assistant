# 【勤工助学】国家大学科技园勤工助学岗位招聘启事（报名截止2022年6月10日）

国家大学科技园(以下简称:科技园)负责我校国家大众创新万众创业示范基地建设、企业孵化服务和成果转化等工作，是学校开展创新创业教育和人才培养的重要阵地。
根据“十四五”规划，科技园 2022年的工作任务重、时间紧。现在友谊校区招聘学校勤工助学岗3个，负责协助开展科技园有关工作，具体要求如下。
一、岗位设置
文秘写作助理岗1名
活动组织助理岗1名
场地管理助理岗1名
二、岗位要求
1.具有良好的沟通、合作精神，服务意识强，工作认真、负责、严谨、细致。
2.能够熟练使用WORD、EXCEL、PPT等办公软件，掌握打印复印、扫描等办公室基本技能，有相关实习或工作经历者优先。
3.积极主动配合并且保质保量完成老师布置的工作和任务，有服务师生的热情，工作责任心强，具有良好的沟通、协调能力。
