# 就业面对面之就业形势政策及求职技巧提升分享会”圆满结束

3月15日晚，机电学院“就业面对面之就业形势政策及求职技巧提升分享会”在国五会议厅举办。西北工业大学学生就业指导服务中心的樊文迪老师和李慧老师参加了此次会议，并针对学生关心的就业政策及就业流程、求职中的注意事项等做了详细的讲解。
会上，樊文迪老师以毕业生的毕业去向为契机，以毕业生数字化签约平台的使用为主线，详细讲述了毕业生的签约流程，以及在签约过程中需要注意的事项，最后强调同学们务必以认真慎重的态度在平台上进行相关操作。
李慧老师从专业的角度对求职过程中的简历制作和面试展示等进行了讲解，将简历和面试的目的概括为说明经历、展示能力、证明岗位胜任力三大部分，同时对求职简历的逻辑架构、招聘简章的解读、面试问题的回答等一一进行了解答。
最后，辅导员冯永涛老师对同学们面提耳命，表示一定要重视就业，现在开始准备、提升自我能力、清晰自我认识，以往届师兄师姐的例子督促大家规划好自己，最后表达了对同学们的殷切期望。
分享会气氛热烈，此次分享会的成功举办为推进学院就业工作提供了有力保障。
