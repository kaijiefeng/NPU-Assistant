# 航天学院研究生会述职评议会暨团支部换届大会顺利召开

2026年3月26日16时，西北工业大学航天学院研究生会述职评议会暨团支部换届大会在长安校区370会议室召开。航天学院团委书记高戈和院研究生会全体成员参加，会议由航天学院研究生会主席团成员刘苏毅主持。
会议通过了西北工业大学航天学院研究生会团支部换届的请示，任命乔巍同志为党支部书记，吕行同志为支部副书记，吕春臻同志为组织委员，林天宇同志为宣传委员，王富杰同志为纪律委员。
图团委书记高戈发言
接着，航天学院研究生会团支部副书记、办公室负责人吕行做述职汇报，将学校“天下工大、世界三航”远景目标和“一十百千”近期目标融入到研究生会工作的各个方面，分别从组织建设、思想学习、文体活动、学术活动、院校交流、特色活动等几个方面进行汇报，并对下一阶段的工作安排做了规划。
图研会办公室负责人吕行述职
最后，学院团委书记高戈老师作总结讲话，对研究生会前期在组织建设与服务保障等方面取得的进展给予充分认可，同时指出当前工作中仍需进一步强化系统性与前瞻性。研会应持续聚焦研究生成长发展需求，在学术交流平台建设、就业指导服务优化以及心理关怀机制完善等方面精准发力，不断提升服务质量与覆盖深度，切实发挥桥梁纽带作用，推动学院研究生工作实现高质量发展。
图航天学院团委书记高戈总结讲话
航天学院研究生会将以此次述职评议会暨团支部换届大会为重要契机，持续推进组织体系规范化与运行机制优化，不断增强组织凝聚力与内生动力，着力打造结构完善、协同高效、富有创新活力的学生组织。未来，研会将更加聚焦研究生成长发展的实际需求，提升服务的针对性与专业化水平，切实发挥联系师生、服务同学的桥梁作用，稳步提升工作质效与组织影响力，为学院研究生群体提供更加优质、多元的发展支持平台。
