# 后勤部办公室召开“双节”期间安全生产工作部署会

为切实做好2025年国庆、中秋“双节”期间校园安全生产工作，9月25日至29日，后勤部办公室组织开展两校区动力运行及施工项目安全生产自查，针对检查发现的问题形成整改台账，督促按时整改。
9月29日下午，后勤部办公室召开安全生产工作会议，针对国庆、中秋“双节”期间动力运行值班安排及施工安全工作进行专项部署。会议由后勤部办公室副主任韩争胜主持。
会上，韩争胜传达了上级主管部门关于安全生产的文件精神，对“双节”期间动力运行和施工项目安全生产工作进行了详细部署。动力保障中心、各施工单位、监理单位相关负责人就近期安全生产情况及节日期间安全生产工作安排进行了汇报。
最后，韩争胜要求，一是绷紧思想之弦，压实安全责任。要深刻认识节假日期间安全生产工作的特殊性和重要性，牢固树立红线意识和底线思维，以高度责任感抓实抓细安全生产各项工作。二是严格落实风险管控措施，切实消除各类安全隐患。三是强化应急值守，提升处置能力。落实关键岗位24小时值班制度，完善应急预案，畅通信息渠道，确保及时高效稳妥处置突发事件。
“双节”期间，后勤部办公室将持续强化安全巡查与应急值守，以扎实举措守护校园平安，为师生安全过节保驾护航。（撰稿人：张偲偲；审稿人：韩争胜）
