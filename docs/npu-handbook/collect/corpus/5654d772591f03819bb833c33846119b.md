# 西北工业大学自动化学院2026年暑期校园开放日活动方案

一、学院概况
西北工业大学自动化学院脉源中国人民解放军军事工程学院（哈军工）和华东航空学院西迁，坚持传承和弘扬“哈军工”优良传统，围绕国家重大战略需求和社会需求，立足航空、航天国防特色，深耕飞行控制、智能信息处理、电气工程以及机器人工程等领域人才培养与科学研究，教学科研和人才培养成绩显著。
学院设有自动化、电气工程及其自动化、机器人工程3个本科专业；拥有控制科学与工程、电气工程2个一级学科。在第五轮学科评估中，控制科学与工程学科取得突破，进入优势学科序列。
自动化学院形成了一支结构合理、水平高超的师资队伍。现有教职工180人，其中专任教师150人，教师博士化率97%，在站统分及企业博士后30人。俄罗斯宇航科学院外籍院士1人，中国工程院院士（双聘）3人，国家级领军人才10人，国家级青年人才25人，科睿唯安“全球高被引科学家”7人，陕西省教学名师3人，省部级科技创新团队4个，科技部、教育部、中国科协等省部级及以上优秀人才近50人次，国际顶级期刊编委20余人，中国政府友谊奖1人。
学院教学科研和人才培养效果显著。自动化学院现有国家一流课程4门、国家精品课程1门、国家双语教学示范课程1门、省级一流课程6门、省级精品课程3门；近年来获国家教学成果奖2项、陕西省教学成果奖15项，省级及国家一级学会优秀博士论文17篇。学院目前在读本科生1200余人、硕士研究生1100余人、博士研究生500余人。经过六十余年的耕耘与发展，学院累计向国家输送近万名本科生、5000余名硕士生、千余名博士生，涌现出一大批杰出院友，为祖国的各行各业做出了重要贡献。
自动化学院师生在科学研究中秉承着“顶天（面向脑与人工智能、多源信息融合技术、飞行安全及综合监控等方向）、立地（面向航空航天器供电系统、稀土永磁电机与机电伺服控制等方向）”的科研理念。“十四五”以来，学院承担国家大型运输机、C919、AG600、空间站等国家重要科技攻关项目200余项；获得国家及省部级奖励50项；现有省部级及以上科研平台14个、国际科技合作基地2个。学院深度参与载人航天与探月、大飞机等国家重大专项，在稀土永磁电机、航空航天器供电系统、无人系统、多目标跟踪、智能科学与技术等领域为我国航空航天做出了卓越贡献； 2025年九三阅兵中学院参与了近10款国之重器研制工作。
二、时间安排与人数规模
1.报名时间：2026年6月25日至7月7日
2.活动时间：7月11日至13日
3.预期人数：100人左右
三、学生申请条件
1.遵纪守法，品行优良，无任何违法违纪受处分记录。
2.身心健康，学风端正，具有较强的科研创新能力和学术实践能力，并且有意于到我院继续深造。
3.全国双一流大学高校应届本科生（2027年毕业）。
4.学习成绩优秀，综合表现优异（如在校期间获得科技活动、学科竞赛相关奖项或在重要期刊发表学术论文等）。
四、申请与审核流程
1.网上报名：申请人登录西北工业大学研究生招生信息网（http://yzb.nwpu.edu.cn/），填写报名信息并按照要求上传附件材料。
申请人须提供以下材料：
（1）本科前三年（或前五学期）成绩单、综合测评成绩单（加盖学校或院系教务部门公章）
（2）其他证明材料（已发表论文、获奖证书或其它考试证书的复印件）
2.学院审核：
学院根据学生综合情况，择优确定参加暑期夏令营学生名单，于2026年7月7日中午12：00前完成系统审核，请申请者在报名系统中查询审核结果。
3.学生确认：
请申请者于规定时间确认是否参加，逾期视为放弃。
