# 新时代人文经济学自主知识体系构建学术论坛征文启事-西北工业大学

构建中国人文经济学的自主知识体系，是不断开拓当代中国马克思主义政治经济学新境界的重大命题，也是深入践行习近平经济思想和习近平文化思想的现实要求。习近平总书记指出：“文化很发达的地方，经济照样走在前面。可以研究一下这里面的人文经济学。”“十五五”规划纲要明确提出“实施积极的文化经济政策”。推动人文经济学的理论创新，激发人文经济发展的新动能，对于我国经济高质量发展有着深刻的现实意义。为推动构建人文经济学自主知识体系，加快建设现代化经济体系，将于2026年9月11-12日（双休日）在陕西西安（西北工业大学）举办“新时代人文经济学自主知识体系构建学术论坛”。诚邀学界同仁参会交流。
一、论坛主题
新时代人文经济学自主知识体系构建
二、具体议题
（一）马克思主义关于文化与经济的基本思想
（二）人文经济学的理论建构与科学内涵
（三）人文经济学的实践探索与价值贡献
（四）人文经济学与中国式现代化建设
（五）人文经济学与多学科交叉融合
三、投稿要求
