# 我校召开2026年本科招生政策培训会暨动员会

6月10日上午，西北工业大学2026年本科招生政策培训会暨动员会在友谊校区国五会议室召开。副校长岳晓奎，各学院院长或党委书记，教务部、对外联络办公室等相关职能部门负责人，以及各学院分管招生工作的负责人、招生组长和骨干教师，机关各部门招生工作联系人，招生办公室全体工作人员共计三百余人参加。会议由教务部部长王海鹏主持。
首先，招生办公室主任王克勤详细解读了2026年本科招生政策，并对招生季宣传工作做了总体部署。他表示，2026年招生工作形势更为复杂、任务更为艰巨，招办将主动联动各学院、各职能部门，在招生政策解读、宣传方案策划上精耕细作，全力为“总师型”人才培养守好“生源关”。后续集中宣传阶段，将稳慎推进、精准施策，细化分省招生策略、做好填报咨询服务，全力以赴吸引优质生源，为学校人才培养高质量发展夯实根基。
随后，招生办公室副主任马婷婷就招生宣传管理信息化系统作专项培训，讲解系统功能、操作流程及使用规范，助力各招生组工作通过数字化、信息化提升工作效率与服务质量。
最后，岳晓奎作总结动员讲话。他肯定了招生工作取得的成效，向全体招生队伍的辛勤付出表示了诚挚谢意。他指出，学校党委高度重视本科招生工作，面对新形势、新任务，请大家认真学习新政策、新变化，将信息准确传递给考生和家长。针对接下来的集中志愿填报咨询的攻坚期，他提出了三点工作建议：一是从严抓牢政策培训，实现全体外出人员培训全覆盖，确保政策说得清、疑问答得准、咨询讲得透，全方位展现西工大招生队伍的专业素养。二是从实抓好行程安排，学院领导要带头驻扎一线，要把每一场咨询会、每一所生源中学、每一名宣传人员都做到全方位考量、高规格安排、精细化落实。三是从紧守牢纪律红线，严格遵守各项规章制度与廉洁纪律，牢固树立过紧日子思想，厉行节约、务实高效。
本次招生政策培训会暨动员会的召开，标志着学校2026年高考招生宣传集中咨询和志愿填报指导阶段正式启动，为全体招生队伍精准掌握招生政策、高效开展咨询服务夯实了基础。下一步，全体招生工作人员将继续发扬“四千精神”，弘扬“六皮作风”，全力吸引优质生源报考，为学校“总师型”人才培养提供坚实保障。
