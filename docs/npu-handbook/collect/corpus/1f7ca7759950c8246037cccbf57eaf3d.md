# 全球南方卓越科学家交流大会在西安开幕

10月27日，全球南方卓越科学家交流大会在西安开幕。中国工程院院士、西北工业大学校长宋保维出席开幕式并致辞。白俄罗斯国家科学技术委员会主席科尔日茨基，白俄罗斯国家科学院主席团主席卡拉尼克，白俄罗斯驻华大使切尔维亚科夫，白俄罗斯国家科学院副主席特鲁哈诺夫，俄罗斯科学院副院长切霍宁，俄罗斯库尔恰托夫国家研究中心副院长布拉戈夫，土库曼斯坦科学院院长阿希罗夫，乌兹别克斯坦共和国科学院副院长米尔扎耶夫，阿塞拜疆国家科学院副院长塔吉耶夫；人力资源社会保障部外国专家服务司副司长史麦男，工业和信息化部国际合作司副司长张晓雷，陕西省人民政府外事办公室主任姚红娟，陕西省科技厅副厅长马云；中国科学院院士、西北工业大学学术委员会主任黄维等出席开幕式。开幕式由西北工业大学副校长岳晓奎主持。
宋保维代表学校向各位领导、院士专家和嘉宾表示欢迎。他指出，西北工业大学是一所以航空、航天、航海为特色的世界一流工科大学，学校始终聚焦国家战略需求和世界科技前沿，坚持高水平对外开放，高位推进国际合作与交流工作。当前，人工智能与数字技术迭代演进，许多复杂前沿课题需要各国科研工作者相互交流、协同攻关。希望以此次大会为新起点，持续发挥大会的平台纽带作用，深化全球南方科学家的常态化交流互鉴，依托白俄罗斯国家科学院中国分院，打造辐射全球南方的国际科技合作枢纽，聚焦重点领域深化联合研究，加强青年科技人才共育与成果普惠共享，携手构建更加开放包容的国际科研生态，让科技创新成果更多惠及全球南方人民，为构建人类命运共同体贡献科技智慧。
史麦男表示，大会为全球南方科学家搭建了人工智能领域交流对话、协同创新的高水平平台，人力资源社会保障部外国专家服务司将坚定不移扩大人才对外开放，优化引进人才支持保障机制，搭建更多国际交流平台，努力为外国专家在华发展提供更好服务、更优环境，共同谱写中外合作新篇章。
马云表示，陕西科创资源富集，是全国重要科研、高等教育和高新技术产业基地，愿与全球南方国家深化科技合作，持续加强创新平台共建、科研联合攻关、科技人才交流、成果转化合作，以科技创新助力全球南方国家实现自主可持续发展。
姚红娟表示，科技交流合作是深化南南合作的重要组成部分。陕西省外办将持续发挥桥梁纽带作用，做好外事服务保障，畅通国际交流渠道，助力全球南方在高层次人才联合培养、前沿科学研究及科技成果转化等领域深化务实合作。
卡拉尼克指出，全球南方已成为推动世界经济增长和科技发展的重要力量，科学事业的发展离不开科研人才的创造与努力。此次大会汇聚各国优秀科学家，有助于凝聚科研力量、促进科技进步。期待各方深化国际科研合作，孕育更多创新理念和合作项目，让成果惠及各国人民。
科尔日茨基在致辞中表达了对中白科技合作的积极期待，希望双方在人工智能时代进一步深化交流合作。
宋保维为卡拉尼克、切霍宁两位专家颁发西北工业大学名誉学衔聘书并佩戴校徽。
黄维与白俄罗斯国家科学院信息学联合研究所所长萨哈鲁克签署《西北工业大学柔性电子学院与白俄罗斯国家科学院信息学联合研究所协议》。
岳晓奎代表学校与亚美尼亚共和国国家科学院、乌兹别克斯坦共和国科学院、阿塞拜疆国家科学院签署合作备忘录。
大会发布了122项白俄罗斯国家科学院可在华转化科技成果，其中，2项合作成果已率先落地——西北工业大学机电学院与明斯克无线电材料研究所、陕西西科智安信息科技有限公司签署成果转化协议，西北工业大学材料学院与白俄罗斯国家科学院、钠美新能源科技（洛阳）有限公司签署成果转化协议。
宋保维、卡拉尼克、黄维、切霍宁、史麦男、张晓雷、米尔扎耶夫、姚红娟、塔吉耶夫、马云共同启动全球南方卓越科学家交流大会常设会址。
来自24个国家的高校、科研院所及企业科学家代表出席活动并围绕“ 未来构型—航空前沿技术 ”“空天先进材料与成型技术”“智能制造技术与自动控制”“电子信息交叉前沿与能源动力创新”“人工智能与计算系统”等领域开展深入交流，达成合作意向。
