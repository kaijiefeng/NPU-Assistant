# 【勤工助学】学生资助服务中心两校区研究生助管招聘启事（报名截止：2023年3月3日）

学工部学生资助服务中心现因工作需要在校内招聘研究生助管，以协助开展日常工作，岗位将按照“按需设岗、按劳取酬、公平竞争、严格考核”的原则进行选拔聘用，欢迎各位学有余力的同学加入。具体安排如下：
一、招聘要求
1.西北工业大学在读研究生；
2.原则上任期一年；
3.熟练掌握基础办公软件，具备良好的沟通、协调能力；
4.对部门工作有较强的责任心，工作中细致严谨且富有耐心，能够自主完成工作；
5.积极主动协助老师工作，并保质保量完成工作内容；
6.应聘前应征得导师同意；
7.长安校区应聘需要有一定文字撰写基础，有推送或新闻稿撰写经验者优先。
二、岗位待遇
研究生600元/月。
三、报名方式
[已脱敏:邮箱]，邮件名称和简历附件名称均为“助管申请+校区+姓名”。
