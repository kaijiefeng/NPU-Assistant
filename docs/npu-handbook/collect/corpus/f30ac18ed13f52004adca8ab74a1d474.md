# 风险隐患排查整治 高温天气 防范热隐患“生产篇”

高温天气 防范热隐患
生产篇
电网运行
高温天气，空调等使用较多，电网负荷加大，加之电网设施长期处在高温环境下，特别是直接暴露在阳光下容易发生火灾。
安全生产提示
1. 加强监测重要输电通道、枢纽变电站、低洼变电站和地下配电室的运行情况，加强应急抢险准备工作；
2. 加强设备维护，发现老化严重的电线及时更换，避免因设备故障或线路老化引发的火灾；
3. 相关生产单位根据天气情况，强化设备异常、故障上报工作；
4. 建立健全应急预案，提高应对突发事件能力。
易燃易爆场所
一些易燃易爆危险品受热后易分解，如果通风不良，热量积聚不散，致使温度升高，容易引发爆炸。
主要涉及场所：加油站、加气站、油库、油漆库房、烟花车间和库房、炸药仓库、煤炭堆放区域、有易燃粉尘的区域、化学品仓库、燃料仓库。
安全生产提示
1. 加强安全维护、巡查和管理，严防因长期高温、压力升高导致储罐、管道等破裂泄漏引发的爆炸着火等事故；
2. 严格火源管控，严禁违章动火，安排专业人员进行现场监护；
3. 减少和避免静电产生火花；
4. 必须使用防爆型电器设备，并做好保养维护。
特种设备场所
高压气体在阳光照射下温度上升，体积膨胀，严重的会发生气瓶爆炸造成人员伤亡和财产损失。
主要涉及场所：有气焊、气割作业等压力容器的工作场所。
安全生产提示
1. 进行定期检验，未经定期检验或检验不合格的特种设备，责令停止使用；
2. 设备对环境温度有要求的，必须严格按照要求进行降温，加装散热系统或冷却系统，确保系统工作正常；
3. 氧气瓶一定要和其他物品分开存放，不得倒置，不得在阳光下暴晒。
有毒有害作业场所
和有限空间场所
高温会加快有毒气体的挥发、扩散，接触有毒气体岗位的操作人员很容易发生有毒气体中毒、窒息等事故。
主要涉及场所：接触有毒有害物质作业的场所；转炉、电炉、混铁炉、电缆沟、泵房集水池、污水处理厂。
安全生产提示
1. 为工作人员配备相应的防护服和检测仪器；
2. 必须对有限空间的氧气浓度、有毒有害气体浓度进行检测，检测结果合格后，才能开展作业；
3. 作业现场必须配备呼吸器、通讯器材、安全绳索等防护设施和应急装备；
4. 改善作业场所的隔热、降温条件；
5. 合理安排作业人员工作时间，确保人身安全和身心健康。
