# 守护生命安全・共筑平安校园——人工智能学院开展防灾逃生安全教育活动

11月5日，人工智能学院组织开展防灾逃生安全教育活动，牢固树立安全发展理念，进一步增强同学们的防灾避险意识，提升火灾、地震等突发事件下的自救互救能力，筑牢校园安全防护屏障。本次活动全体同学参会，辅导员李莹玥主持。
开展防灾安全宣讲
李莹玥结合高校宿舍安全典型案例开展安全宣讲，着重强调宿舍消防安全红线，明确宿舍内严禁使用大功率电器、杜绝各类违规用电行为，引导同学们从源头排查隐患，防范火灾事故。宣讲过后，全体同学共同观看宿舍防火逃生、地震避险警示教育片。影片借助真实事故场景与规范处置示范，直观展现灾害的巨大危害。观影结束，李莹玥围绕不同险情，细致讲解逃生避险要点、自救方法以及日常安全注意事项，帮助同学们理清避险思路，夯实安全理论基础。
集中观看避险警示教育片
专题学习完成后，现场组织应急疏散演练。同学们严格遵照要求、听从指挥，保持镇定，沿预定疏散路线迅速有序撤离。整场演练紧张有序、规范顺畅，大家在实操过程中熟悉疏散流程，熟练掌握弯腰捂鼻、快速撤离等应急动作要领，切实锻炼应急处置和逃生实操能力。
有序开展应急疏散演练
本次安全教育活动将理论宣教与实操演练有机结合，以案为鉴、以练促学，补齐同学们安全应急能力短板，推动安全知识入脑入心。下一步，学院将持续常态化开展校园安全教育与应急演练，把安全理念融入日常教育管理，引导全体同学时刻绷紧安全这根弦，共同守护师生生命安全，共建平安和谐校园。
