# 一站式”学生社区｜学姐有“料”，等你来“聊”——优秀校友屈小红专访活动成功举办

4月15日上午，化学与化工学院在学院楼举办“四个一”访谈活动。本期活动聚焦“材化筑梦·实业报国”主题，特邀请学院优秀校友、浙江艾合新材料股份有限公司董事长屈小红重返母校，与学弟学妹们共话专业成长、行业前沿与青年担当。学院党委副书记姚东东、辅导员胡云杰以及学生代表30余人参加本次活动，活动由学院兼职辅导员焦梦薇主持。
本次访谈围绕“青春回溯”“职业历程”“行业前沿”“专属寄语”四个篇章展开。多名学子围绕专业学习、职业规划、行业发展等方面积极提问请教，屈小红结合自身求学及工作经历，用生动的案例和深刻的感悟逐一解答。
在“青春回溯”篇章，她分享了大学时期的学习方法与科研探索故事，鼓励同学们珍惜校园时光，夯实专业基础，提升综合能力；在“职业历程”环节中，她详细介绍了从校园到职场的转型心得，强调了坚持与创新在职业发展中的重要性；谈及“行业前沿”，她深入分析了航空航天特种高分子材料领域的技术突破与未来趋势，激发了同学们对专业领域的探索热情；最后在“专属寄语”部分，她寄语全体化院学子：牢记“公诚勇毅”校训，弘扬“三实一新”校风，立大志、做实学、勇担当，将个人发展融入国家需要，在化学化工与高分子材料领域书写属于自己的报国篇章。访谈过程中，现场互动频繁，气氛热烈，同学们纷纷表示深受启发，对今后的学业规划和职业发展有了更清晰的目标。
此次访谈不仅是优秀校友经验的分享，更是一堂生动的专业信念教育课。屈小红用二十年的坚守与求索，激励着每一位在场学子：在“材化筑梦、实业报国”的道路上，唯有以匠心坚守、用创新突破，方能在国家最需要的地方绽放青春光彩。
访谈嘉宾简介
屈小红，化学与化工学院2007届物理化学专业硕士毕业生，现任浙江艾合新材料股份有限公司董事长，获评航天科技集团学术带头人称号，担任西北工业大学工程硕士校外导师。二十年来，她深耕航空航天特种高分子材料领域，胸怀家国、潜心科研，以技术创新助力航空强国建设。先后入选2025年度浙江省级人才、2019年度常州市“龙城英才”、2022年度嘉兴“潮城精英”引领计划，荣获陕西省科学技术进步一等奖。
