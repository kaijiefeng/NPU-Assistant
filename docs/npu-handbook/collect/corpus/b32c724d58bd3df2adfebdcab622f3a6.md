# 为大国重器“强骨”！|创新争先奖“花落”西工大重庆科创中心

5月29日，以“矢志创新发展 建设科技强国”为主题的2025年重庆市全国科技工作者日主场活动在重庆科技馆举行。现场，创新争先奖正式揭晓。西北工业大学重庆科创中心副主任、重庆三航新材料技术研究院有限公司总经理唐斌荣获创新争先奖先进个人。
重庆创新争先奖由重庆市科学技术协会、人力资源和社会保障局、国有资产监督管理委员会等单位联合设立，是重庆市推动科技创新、培育高层次人才的重要举措。该奖项旨在表彰在基础研究、技术研发、成果转化等领域取得突破性成果的个人和团队。
唐斌，共产党员，西北工业大学材料学院教授、博士生导师，国家级青年人才，西北工业大学重庆科创中心副主任，重庆三航新材料技术研究院有限公司总经理。
国家重器不仅代表了国家的科技实力和工业水平，更是国家综合实力和国际竞争力的重要体现。如今在明月湖，唐斌带领着团队为大国重器关键部件、关键材料的研发和迭代正做着默默贡献。
航空发动机和航天器部件的关键材料，往往要求能够在高达800℃的极端温度下保持强度、抗氧化和抗腐蚀性，同时兼顾装备的轻量化要求，这对材料与工艺提出了极高的要求。
用唐斌的话讲，“我和团队目前及以后要做的事情，就是持续地为国家重器‘强骨’，使其的变得抗造耐热。”
近5年来，唐斌带领团队围绕航空航天飞行器对高性能轻质合金的重大需求深入开展基础研究和应用基础研究，已突破系列关键核心技术，研制出系列轻质高强钛合金与轻质高温钛铝合金材料及其关键部件，解决了国家重大装备研制的“卡脖子”难题，支撑了新型航空发动机与航天飞行器关键耐热部件的研制。
同时，唐斌坚定科技创新“四个面向”，坚持把论文写在祖国大地上，融通高水平研究型大学主力军作用和科技领军企业“出题人”、“答题人”、“阅卷人”作用。
唐斌始终聚焦科技成果落地的关键链条，积极推动成果转化，以市场化思维解构技术痛点与产业需求，实现了多项 “卡脖子” 技术的产业化突破。他主持重庆三航新材料技术研究院有限公司在渝孵化工作，公司在特种合金熔铸技术与智能装备、塑性成形技术与装备、粉末成形技术与工艺装备、热加工构建寿命评价技术与装备等领域持续进行关键技术攻关和产业孵化，公司已获得国军标、质量体系认证、重庆市科技型企业、重庆市创新型中小企业、国家高新技术企业、重庆市专精特新企业认定，获批了重庆市制造业创新中心，目前正在申报国家级制造业创新中心。
