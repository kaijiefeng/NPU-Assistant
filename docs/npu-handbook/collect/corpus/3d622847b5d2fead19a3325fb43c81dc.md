# 我院开展扎牢抵御防范校园传教渗透防线主题班会

10月15日下午，我院党委副书记徐晓峰面向全院研究生党员开展“扎牢抵御防范校园传教渗透防线”主题班会，结合高校案例，讲解相关政策要求与校园安全知识，引导同学们增强法治观念和抵御防范能力，辅导员韩凯参加。
班会上，徐晓峰从尊重宗教信仰自由、遵守校园管理规定和防范非法校园传教活动等方面展开讲解，提醒同学们警惕以社交活动、网络群聊和学习交流等名义开展的违规传教行为。面对来源不明的信息和活动邀约，要保持理性判断，不轻信、不盲从；发现疑似违法违规情况，应立即向学院或学校有关部门反映。他强调，学生党员更要严守思想底线，坚守共产党人的精神家园，绝不能在宗教中寻找自己的价值和信念。
此次主题班会进一步加深了同学们对校园传教渗透风险的认识，增强了辨别和抵御非法传教活动的意识与能力，引导同学们自觉遵守校园管理规定，坚决抵制校园传教渗透行为，切实筑牢抵御和防范校园传教渗透的思想防线，共同维护校园的安全稳定和良好的育人环境。
