# 航海学院与航天科工二院206所签订战略合作协议

2月20日，西北工业大学航海学院与航天科工二院206所战略合作协议签约仪式在航海学院201会议室顺利举行。航天科工二院206所所长白鹏英、副所长王锐、技术发展处副处长杜晓东、办公室副主任尹传豪、彭雪明总师，以及航海学院领导班子成员、院长助理、团队负责人、教师代表出席仪式。会议由航海学院副院长崔荣鑫主持。
航海学院院长潘光对白鹏英一行的到访表示热烈欢迎，并从学院发展定位、科研平台情况、科学研究情况等方面介绍了航海学院的整体情况。他表示，期待双方能够展开深入而富有成效的合作，共同绘制未来发展的美好蓝图。
白鹏英介绍了206所的基本情况和发展定位，同样表达了对未来合作的深切期盼，期望双方能够共谋发展，携手开创合作共赢的新篇章。
会上，双方开展座谈交流，就科学研究、技术方向、平台合作、人才培养等内容展开研讨，交换意见，为实现资源共享、优势互补奠定基础。
潘光和白鹏英代表双方签署了战略合作协议书，双方有关人员共同见签，标志着双方将本着“优势互补、平等互利、协同发展、合作共赢”的原则，在已有合作基础上，进一步探索合作机制，共同推进产学研协同创新，为推动海洋强国和国防现代化建设贡献力量！
