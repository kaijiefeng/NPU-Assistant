# 化学与化工学院开展2026年《实验室安全基础理论》专题准入培训及考试

为切实增强师生安全责任意识，确保进入实验室前掌握必要的安全知识与操作规范，学院于9月2日下午邀请西安安备思软件有限公司总经理刘涛，举办实验室安全准入培训专题讲座。学院共240余名师生参加培训，院长助理郭威参会，培训讲座由学院安全员郭思敏主持。
本次培训主要面向各实验室2026年秋季学期新入学的硕士、博士研究生、做毕设或大创的各年级本科生、新进青年教师、科研助理及实验人员。培训开始前，郭威结合近年高校发生的典型事故案例，强调了安全生产工作的重要性。他勉励参训人员珍惜学习机会，不断提高安全防范意识，做好实验风险评估与过程监督，以严谨规范的态度对待每一个实验环节，切实保障自身与他人的生命财产安全。随后郭思敏向参训人员就培训考核要求作了说明。
培训过程中，刘涛围绕人的不安全行为、物的不安全状态、管理漏洞和环境因素，剖析了实验室常见风险隐患的成因与表现。并通过对危险化学品法规的解读和实验室常见隐患案例的分析，帮助参训师生建立从隐患发现、风险辨识到应急处置的认知，切实提升了安全隐患排查与应对能力。
学院为通过考试的师生配发了危险化学品实验室准入证、实验服等安全物资，并组织签署实验人员安全生产责任书。
此次培训及考核有效增强了师生的实验安全责任意识，巩固了安全理论知识，增强了识别实验风险与隐患的能力，为营造浓厚的实验室安全文化氛围奠定了良好基础。今后，学院将持续加强实验室安全管理，常态化开展安全生产检查，不断提升安全保障水平，为学院科研教学工作的高质量发展提供坚实支撑。
