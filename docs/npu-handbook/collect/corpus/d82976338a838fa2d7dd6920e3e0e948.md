# 2025年保密宣传月┃关于开展保密教育线上培训活动安排的通知

各相关单位：
为提升人员保密知识技能，中央保密办（国家保密局）依托“保密观”APP和中国保密在线网站(www.baomi.org.cn)，组织开展保密教育线上培训。现将培训有关事宜安排如下：
一、培训对象
请各相关单位及时组织本单位涉密人员及项目组非密人员参加培训并完成考试，其他非密人员自愿参加，切实增强师生法治意识，提升师生保密技能水平。
二、培训时间
即日起至10月15日。
三、参加方式
（一）注册登录
注册成为“保密观”APP或中国保密在线网站会员后，即可登录系统参加培训。（“保密观”APP、中国保密在线网站账号通用，培训前请将“保密观”APP升级到最新版本）参加人员注册时只填写手机号和昵称，可不填写真实姓名。
1.中国保密在线网站进入培训系统方式：
可从网站首页(www.baomi.org.cn)“培训入口”点击进入。
图1 中国保密在线网站进入培训系统方式
2.“保密观”APP进入培训系统方式有两种：
第一种：点击首页标题图。
图2 “保密观”APP进入培训系统方式一
第二种：点击页面底部“学”—“培训”。
图3 “保密观”APP进入培训系统方式二
（二）学习
进入系统，点击“课程”开始学习。课程内容包含保密优良传统、保密法律法规、保密技术防范和保密警示教育4部分，以视频、音频为主。可在学习页面随时查看已获得的学时。
图4 点击“课程”开始学习
（三）考试
当学完4学时后，点击“考试”—“开始考试”。考试共25道题，成绩满分100分，90分以上为优秀， 60-89分为合格。
图5 满足4学时可参加考试
（四）证书下载
考试成绩合格，系统将自动生成证书，可填写真实姓名并将其下载保存至手机，自行打印。
图6 打印证书
四、有关说明
1.本次活动可作为涉密人员年度保密教育的一部分，计入保密教育5.0学时。
2.参加培训人员完成培训取得证书后，将证书交所在单位保密员处归档。
3.请各单位保密员统计本单位培训情况，于10月17日17时前通过E-mobile将汇总表报保密处（见附件）。
