# 副校长王伶带队赴航发贵阳所、航天科工十院调研-西北工业大学研究生院

8月24日，副校长王伶带队赴中国航发贵阳发动机研究所（以下简称“航发贵阳所”）、中国航天科工集团第十研究院（以下简称“航天科工十院”）调研，分别与航发贵阳所党委书记、副所长张金峰，航天科工十院党委副书记、副院长濮秀君等开展座谈。国家卓越工程师学院常务副院长蒋建军，研究生院副院长王会、副院长刘准钆，科学技术研究院高新技术与平台处副处长李鹏等参加调研活动。
王伶对航发贵阳所和航天科工十院长期以来给予学校的支持表示感谢。他指出，双方前期紧扣国家航空航天重大战略开展务实合作，取得扎实成效。未来，希望双方锚定国家战略需求，深化人才共育、平台共建、项目共研，优化工程硕博士联合培养机制，培育军工领域总师型人才与行业领军人才，共建校企协同育人基地，瞄准重点领域关键核心技术瓶颈开展联合攻关，为实现高水平科技自立自强凝聚合力。
航发贵阳所、航天科工十院负责同志表示，西工大办学特色鲜明、科研底蕴深厚、人才储备扎实，与本单位发展定位、科研攻坚方向高度契合。期待双方立足现有良好合作基础，进一步加强交流互鉴，积极探索人才培养、科研项目合作新模式，以高质量人才供给和高水平科技攻关赋能产业升级，为服务国家战略、助力民族复兴贡献坚实的科创力量与人才支撑。
航天学院、动力与能源学院、电子信息学院负责同志参加有关活动。
