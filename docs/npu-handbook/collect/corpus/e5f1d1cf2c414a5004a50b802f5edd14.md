# 互学互鉴促提升 交流赋能谋发展——中国人民大学档案馆莅临学校档案馆调研交流

9月24日，中国人民大学档案馆馆长钟兰芳一行3人莅临档案馆，围绕电子文件归档、学生档案管理等重点工作开展专题调研交流。
馆长戚红梅对来访同仁表示热烈欢迎，就我馆业务发展整体情况和信息化建设进行了介绍，并围绕档案系统信创国产化升级改造、电子档案长期保存系统建设、“AI+档案”数智化体系构建三大领域进行了详细交流。随后，档案同仁现场查看了电子档案全流程监控管理系统、档案安全管控体系，观摩了线上归档流转等实操环节。
座谈交流中，双方业务骨干结合岗位实际交换思路举措，深入研讨档案系统与OA系统对接、学生档案全周期管理、数字化成果应用、档案资源挖掘与宣传等核心工作；围绕电子文件归档标准、线上全流程流转，以及学生档案接收、在校管理、毕业转递、信息安全保密等关键业务，分享实践经验、剖析堵点难点，氛围务实高效。钟兰芳馆长表示，两馆档案管理模式相近、业务共通性强，希望双方持续深化经验共享、共同提升。
此次调研交流搭建起双方沟通协作的桥梁，深化了发展范式，拓宽了工作思路。下一步，双方将持续深化对接交流，互学互鉴、取长补短，把学习成果转化为务实举措，共同推动档案工作提质增效。
