# 【文书档案】归档范围及要求

一、归档范围
文书档案是党政机关、教学科研机构、支撑和服务保障机构、科研平台等单位在学校党群、行政、教学、科研、基本建设、国有资产、产品生产、出版、外事、财会等各项管理工作中形成的具有保存价值的文件材料，归档范围各异，各单位请遵照本单位归档范围开展文书档案归档工作。
二、归档要求
1.各单位兼职档案员要切实履行自己的工作职责，负责本部门文件材料的收集、整理、归档工作。
2.各单位负责本部门非密校发文件、签发单的打印及归档工作，同时负责本部门拟稿发文的涉密文件的归档工作，在检查文件材料的签章、附件齐全后进行归档。
3.党政办信息机要科负责学校外来公文归档工作，并向档案馆提供涉密、非密校发文件清单。
4.归档文件材料必须是原件，声像材料归档时应附文字说明，注明责任者、形成时间、内容等信息。
5.电子文件归档参照纸质文件归档范围，归档的电子文件以“文件编号”命名，没有“文件编号”的电子文件以“题名”命名。
6.个人获省部级以上奖励证书的复印件，需在复印件上手写“与原件一致”和鉴定的时间，并在手写字上加盖单位公章。
7.各单位归档材料应填写移交清单，相关格式以每年下发的“年度文件归档通知”要求为准。
8.档案工作分管领导及兼职档案员发生调整的单位，需填写“档案工作分管领导及兼职档案员情况登记表”（下载)与归档材料一起归档。
