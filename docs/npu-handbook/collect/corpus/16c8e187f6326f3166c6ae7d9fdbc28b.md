# 国际合作处党支部召开2021年度组织生活会暨民主评议党员大会

3月29日下午，国际合作处党支部在友谊校区毅字楼732会议室召开2021年度组织生活会暨民主评议党员大会。会议由国际合作处党支部书记张富利主持，机关党委副书记邱若娟参加，支部全体党员出席会议。
首先，张富利代表党支部委员会向党员大会作支部工作报告，回顾2021年支部建设情况，全面查摆支部存在的问题与不足，并提出今后工作思路及整改措施。随后，全体党员对照检查的具体要求，逐一开展自我批评与相互批评，深入查找自身存在的不足，接受其他党员同志的批评意见。之后，全体党员认真填写《民主评议党员测评表》，对支部班子和党员进行评价。
邱若娟肯定了此次党支部召开的组织生活会，她提出以下几点希望：第一，通过“五个对照”查摆出的问题，做好整改清单；第二，持续加强党史学习教育；第三，进一步加强国际合作处的支部建设；第四，做好党建促业务发展，发挥支部战斗堡垒作用与党员先锋模范作用。
张富利代表支部进行表态发言。他希望广大党员同志立足自身工作岗位与业务发展，以党建促业务发展，充分发挥支部特色，为学校“双一流”建设作出贡献。
（国际合作处撰稿人：张曦审核人：李自伟）
