# 莫航学院学子在2025年陕西省中外合作办学学生外语演讲比赛中取得佳绩

11月25日，由中共陕西省委教育工委、陕西省教育厅主办，陕西省高等教育学会中外合作办学分会、西安工业大学共同承办的2025年陕西省中外合作办学学生外语演讲比赛决赛暨颁奖仪式在西安工业大学（未央校区）隆重举行。本次比赛共吸引来自全省23所院校的63名学生参赛。莫航学院2025级本科生李储麟表现突出，在比赛中荣获三等奖。2025级本科生李宇腾、徐小雅获得优秀奖。
本次大赛以“展现青春使命担当，共筑时代文化强音“为主题，旨在引导广大青年学生厚植家国情怀，拓展国际视野，用外语讲述中国故事，推动中华优秀传统文化创造性转化与创新性发展，展现中外合作办学学子良好的精神风貌。
围绕大赛主题，李储麟以中华民族代表性元素“织机” 为主线，结合自身在手机刷到传统水墨美学与AI生成技术相融合的动画短片时所产生的深刻文化共鸣，将个人成长体验与文化思考深度联结。他在演讲中系统呈现孔子哲学的智慧精髓、李白诗歌的浪漫意境、二十四节气的农耕密码等中国优秀传统文化瑰宝，同时聚焦AI翻译、VR技术、“国潮” 文化等科技创新成果，生动描绘出 “织机” 作为文化传承与创新象征的深远影响与重要地位，展现了中华文化的博大精深、鲜活生命力与时代适应性，传递出时代青年在中外文明交流互鉴中的文化使命与担当。
中共陕西省委教育工委副书记、一级巡视员王海波、陕西省高等教育学会中外合作办学分会秘书长孔杰出席本次比赛。
中共陕西省委教育工委副书记、一级巡视员王海波在致辞中表示，本次大赛是陕西教育系统贯彻党的二十届四中全会精神、服务“双强国”建设的重要举措，为中外合作办学学生搭建展示交流平台。他希望同学们拓展全球视野，开放包容促交流，文明互鉴筑互信；坚定文化自信，创新讲好中国故事，彰显中华文化魅力；胸怀国之大者，以学识服务社会、以开拓担重任，努力成长为国之栋梁，为民族复兴贡献青春力量。
此次赛事中，莫航学院学子尽显精湛外语功底与文化底蕴，更彰显了新时代青年的使命担当。初次参赛即取得亮眼成绩，展现了同学们着力锤炼外语能力、提升全球胜任力的明确方向。展望未来，莫航学子必将深植家国情怀，广拓国际视野，传承中华文脉，笃行文化自信。学院也将持续精进国际化人才培养体系，助力青年学子成长为兼具家国情怀与全球视野的国际化拔尖创新人才，在青春赛道上书写更多精彩。
