# 深化育人实效 共筑航海英才——航海学院本科班主任工作交流会圆满召开

为全面总结2024-2025学年本科学生工作成效，提升班主任队伍育人能力，航海学院于6月5日至6日召开本科班主任工作交流会。会议以线上线下结合的形式举行。学院党委副书记王银涛、副院长雷波、院学生工作办公室、全体辅导员及班主任出席会议。
王银涛系统介绍了班主任工作考核流程及评价体系，他说到，本次交流会以“数据驱动、问题导向、协同育人”为原则，围绕学风建设成效、班团凝聚力、竞赛参与度、国际交流四大核心指标展开研讨，要求重视工作经验交流，切实解决重点学生问题。
各年级班主任就2024-2025学年考核工作进行汇报，围绕学风建设、班团活动、竞赛获奖、国际交流与社会实践等方面反馈本班级的基本情况，对学生学业、心理、就业等问题展开经验交流。
在交流环节中，与会班主任们围绕主题班会创新、深度学生沟通、困难学生精准帮扶、宿舍走访实效、家校协同育人等核心工作内容，分享了各自在班主任工作中的实践经验和典型案例，重点交流了“学困生一对一导师制”“班委轮值负责制”“班务公开透明化”等创新性工作方法，并就如何提升班级自主管理水平进行了深入探讨。与会教师一致表示，要切实履行“以本为本”的教育使命，既要做好学生专业学习的指导者，更要当好学生人生发展的引路人，为培养德才兼备的航海人才提供全方位保障。
各年级辅导员进行各年级情况整体汇报，围绕学业支持、心理关怀、就业服务等方面汇报学生发展动态，通过定期更新台账，构建全员全过程支持体系，协同学院精准帮扶。
雷波总结并肯定了上一学年的学生工作成果，强调学院对三大赛事、深造率、毕业率、出国及保研情况的重视，并对未来学院学生工作规划提出三项建议：一是优化培养模式，保障每位学生的培养方案完成度；二是重视工作方式方法，动员学生自主学习；三是保障学院托底工作，鼓励学生追求更高的目标的同时，为学生的生涯规划保驾护航。
王银涛系统回顾了本学年学生工作成效，充分肯定了在学风建设、学科竞赛组织、升学就业指导等方面取得的阶段性成果，并对下阶段学生工作提出以下要求：一是优化个性化培养方案，建立“一生一档”跟踪机制；二是创新学业指导方式，完善学习帮扶体系；三是在确保基本培养质量的基础上，重点支持学生参与国际交流和科研实践，构建“全面发展、特色成长”的培养体系。
（审核：刘朝亚，王银涛)
