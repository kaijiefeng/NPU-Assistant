# 【勤工助学】 学工部资助服务中心研究生助管招聘启事（报名截止2022年6月20日）

学工部资助服务中心现因工作需要在校内招聘研究生助管，以协助开展日常工作，岗位将按照“按需设岗、按劳取酬、公平竞争、严格考核”的原则进行选拔聘用，欢迎各位学有余力的同学加入。具体安排如下：
一、招聘要求
1.西北工业大学在读研究生；
2.原则上任期一年；
3.熟练掌握基础办公软件，具备良好的沟通、协调能力；
4.对部门工作有较强的责任心，工作中细致严谨且富有耐心，能够自主完成工作；
5.积极主动协助老师工作，并保质保量完成工作内容；
6.应聘前应征得导师同意。
二、工作内容
1.协助完成日常工作；
2.评奖评优评助月协助完成相关工作。
三、岗位待遇:
研究生600元/月。
五、报名方式
[已脱敏:邮箱]，邮件名称和简历附件名称均为“助管申请+校区+姓名”。
