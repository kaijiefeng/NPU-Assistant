# 以讲促教，精进育人——人工智能学院/无人系统技术研究院开展本科主讲教师院级试讲评审工作

6月24日，人工智能学院/无人系统技术研究院开展2025-2026学年春季学期本科主讲教师院级试讲评审会。本次会议邀请机电学院葛文杰、电子信息学院段哲民、计算机学院李伟华三位教授担任评审专家。人工智能学院副院长夏勇主持会议。
首先，夏勇作开场致辞，阐明试讲评审是夯实本科教学、培育优质师资队伍的关键环节，坚持以评促建、以评促改，助力新晋教师精进教学能力、提升育人质量，并对到场专家的莅临指导表示诚挚感谢。
随后，李宁飞教授开展15分钟《人脑智能与人工智能》“智能基础”章节理论课程试讲。其授课逻辑清晰、节奏得当，配合板书完整讲授知识点，专业功底与教学素养突出。
试讲结束后，评审专家从课件、板书、语速、课堂互动等基础教学环节提出优化意见，并针对课堂设问、启发式教学、知识延伸及课程思政融合开展专业指导，推动教书与育人深度融合。综合授课表现与各项考核指标，专家组一致认定李宁飞老师授课内容掌握熟练、教学设计科学、教态大方、教学功底扎实，符合主讲教师任职要求，准予通过试讲。
本次评审搭建教学交流提升平台，助推教师精进授课能力。学院将常态化开展教研与师资培养，严控课堂教学质量，锤炼高素质专业教师队伍，依托优质教学赋能本科人才高质量培养。
