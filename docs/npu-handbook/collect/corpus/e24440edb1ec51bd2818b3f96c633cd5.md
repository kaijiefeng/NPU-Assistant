# 深耕网络思政沃土，培根铸魂时代新人——西北工业大学“思享+”网络文化工作室工作案例

一、主题和建设思路
党的二十大报告指出：“教育是国之大计、党之大计。培养什么人、怎样培养人、为谁培养人是教育的根本问题。育人的根本在于立德。”高校作为人才培养的主阵地，承担着为党育人、为国育才、培养社会主义建设者和接班人的重要使命。中国式现代化建设对高等教育的需要比以往任何时候都更加迫切，对优秀人才的需求比以往任何时候都更加强烈，这就对高等教育特别是贯穿高校人才培养体系全过程的思想政治教育提出了更高的要求。
近年来，信息技术的高速发展深刻地影响着高等教育的发展，大学生作为各类网络平台和新媒体平台中最活跃的一个群体，网络空间成为其进行信息获取、思想交流和人际交往的重要场所。信息体量巨大、质量参差的网络空间对大学生的思想观念、思维方式和价值取向的影响越来越大。这表明高校牢牢把握网络思想政治教育主动权已然成为新时期高校人才培养的必然要求。
西北工业大学坚持立德树人根本任务，高度重视学校思想政治工作体系建设，党委学生工作部学生党建思政教育办公室于2019年11月开始，筹备建立创立“思享+”网络文化工作室，立足工大特色和青年特点，以提升理论学习引力、增添疫情防控韧力、弘扬中华文化魅力、彰显校园文化活力等为主要内容，充分发挥即时性、移动性、互动性等网络特点深耕网络思政沃土。工作室自2020年2月正式运行以来，依托“西北工业大学”“西北工大学生之家”微信公众号等平台，创作短视频、原创歌曲、H5、网文、小程序等精品思政教育作品300余项，树牢网络思想引领“风向标”，透过“眼球”直达“心灵”，培根铸魂时代新人。
二、主要做法和成效
（一）着力提升理论学习引力，点亮信仰之灯。工作室坚持守正创新、与时俱进，结合党史学习教育、学习贯彻党的二十大精神、学习贯彻习近平新时代中国特色社会主义思想主题教育等主题主线，不断探索信息化、多元化的理论传播形式，扩大更具黏性的理论学习内容供给，更好引导青年学生赓续红色基因、感悟思想伟力，扣好人生“第一粒扣子”。立足专业化解读，精选《习近平讲故事》《习近平与大学生朋友们》等书籍内容，带领青年学生感受人民领袖对青年一代的亲切关怀和殷切期望，精心制作18期“百年伟业党史微享”系列作品，带领青年学生回顾党的一大到十九大……推动以学铸魂、以学增智、以学正风、以学促干。立足青年阐释，先后录制推出“百年党史我来讲红色基因代代传”党史微课、“人人讲党史”优秀宣讲作品、“我学我讲二十大”等系列微视频50余个，组织青年学生以文字、视频等形式热议习近平总书记重要讲话精神……以青年讲带领青年听、青年悟。立足趣味学习，党史学习教育期间，制作“党史知识竞赛”小程序，吸引3500余名学生竞争西工大“党史学习百强”，党的二十大召开前夕，制作《@西工大学子，走进党代会，喜迎二十大》H5，吸引7800余名西工大学子在学习党代会知识的同时，生成西工大专属祝福海报，营造喜迎党的二十大的浓厚氛围……切实提高思政教育的吸引力和实效性，助力理论学习走“新”更走“心”。工作室制作的微视频在全国大学生网络文化节、网络教育优秀作品评比中荣获优秀奖1项、在陕西省评比中荣获三等奖1项、优秀奖3项。
（二）着力增添疫情防控韧力，激发攻坚之志。工作室积极适应疫情防控新形势，创新开展“云思政”，把“键对键”作为“面对面”的有效替代，有力推动疫情防控工作的开展。疫情防控期间，第一时间发布《致全校同学的疫情防控倡议书》《“共战疫情党员在前我承诺我行动”倡议》《疫情防控期间学生在线学习行为规范》等，努力汇聚“同心抗疫共克时艰”的强大凝聚力和向心力，创作并发布了《武汉，我依然爱你》原创歌曲、《西工大学子抗疫日记》vlog、《你品，你细品，这场战疫里有我们最熟悉的东西》原创社会主义核心价值观宣传漫画等一系列网络正能量作品，积极主动宣传师生在抗疫中的典型人物和感人事迹，营造浓厚氛围，加强浸润教育，在学生中引起了较好反响，相关作品获得了人民网、学习强国等主流媒体广泛转载。同时设计打造了12节“信仰的力量”系列微党课，千余名学生在线学习，让价值引领入脑入心，该项工作获陕西教育系统新型冠状病毒肺炎疫情防控工作领导小组简报[2020]106期专题报道。
（三）着力弘扬中华文化魅力，汲取奋进之力。工作室注重以传统节日、节庆日、纪念日等为契机，引导学生赓续文化基因、激扬中国力量。一方面，紧密结合“网路中国节”主题活动，在元宵节组织开展线上猜灯谜、赏花灯活动，在清明节开展“网络祭英烈”活动，在端午节带领同学们了解全国各地丰富的端午习俗，在中秋节组织同学们线上学习中秋传统文化习俗、线下体验工大月饼制作，在重阳节和同学们分享古诗词中的重阳……在这些重要的传统节日让浓郁的中国味充盈网络，丰富学生的历史文化滋养。另一方面，在每年的劳动节、教师节、国庆节、全民国家安全教育日等重要节庆日，在建党节、“九一八”纪念日、辛亥革命纪念日等重要纪念日，通过知识普及、有奖问答、热议感言等形式，有效激励学生在“生动的网络课堂”中补足精神之钙、筑牢信仰之基、凝聚奋进力量。
（四）着力彰显校园文化活力，渲染青春之色。工作室立足校园，植根生活，以品牌栏目为依托，创作了一系列贴近大学生日常学习生活的网络思政文化作品，展现工大学子青春风采，传播校园正能量。《工大声音》栏目为工大学子提供讲好工大故事，传递青年思想、传播工大声音的平台。《工大月记》栏目在每月1日带领同学们回顾上一个月校内的新闻热点，引导同学们主动关注学校发展动态，积极参与各项校园活动。《工大悦读》栏目每一期邀请一名优秀学生作为推荐人以文字采访的形式向同学们推荐好书，引导同学们培养多读书、读好书的习惯。《小飞飞教你》系列栏目则是图文并茂地向同学们详细讲解PPT、LaTeX、Pr等实用软件工具的操作方法，帮助同学们掌握更多技能。此外，还有《毕业MV》《NPU奇妙夜》《发现工大美食》等一系列深受同学们喜欢栏目，成为了同学们解锁不一样的工大、展现不一样的自我的重要载体，既丰富了同学们的校园文化生活，也让工作室更加贴近学生、走进学生，更具感染力和亲和力！
三、经验启示
（一）抓实理论，筑牢思想根基。网络思政作为思政教育的重要组成部分，如何有效发挥网络思政“立德树人”作用，教育引导广大青年成长为“时代新人”，关键在于以习近平新时代中国特色社会主义思想铸魂育人。习近平新时代中国特色社会主义思想是系统全面、内涵丰富的科学的理论体系，工作室立足专业化解读、青年阐释、趣味学习，通过系列视频宣讲、知识竞答、原著领读等广受青年学生欢迎的方式，润物无声地带领广大青年学子实现了读原著、学原文、悟原理，让青年学生全面系统、及时跟进、深入思考、联系实际地学习理论知识，筑牢思想根基。
（二）把握规律，科学开展工作。一是要把握网络平台的特点，网络空间作为高校思想政治教育的重要阵地，交互性极强的同时内容供给鱼龙混杂，这就要求高校网络思政工作的开展要高度重视对主流思想的传播，要善于找准网络思政工作的切入点，也要敢于发声。二是要把握学生的成长规律，从学生的群体特点和实际需求出发，创造学生喜闻乐见的网络思政教育作品，不断提升网络思政教育的吸引力。
（三）保持开放，提升育人实效。坚持与时俱进、守正创新，根据不断变化的形势和学生的实际需求，主动适应新变化、创新应用新载体、灵活使用新表达，不断优化内容供给、强化学生互动，从而实现内容不断深化、形式不断拓展，打造更多年轻人愿听愿看、爱刷爱赞、共情共鸣的精品作品，不断提升网络思政育人亲和力和实效性。
四、下一步加强和改进的计划
（一）整合资源，汇聚育人力量。工作室目前由党委学生工作部学生党建思政教育办公室负责组织和运营，制定具体的工作计划、把关网络思政作品质量，招募和培训在校生加入工作室共同完成网络思政作品的制作。今后可加强与思政课教师、辅导员工作室、其他网络思政工作室等的交流与合作，整合各方资源，制作出更多维度、更高质量的作品。
（二）加强总结，长效推进工作。一方面是加强调查研究，及时了解学生对工作室网络思政作品的评价和认可程度，总结学生喜爱的网络思政内容和形式，以此作为今后作品创作的重要依据之一。另一方面，及时发掘、凝练工作开展过程中的好经验、好做法，强化品牌塑造，不断扩大工作室的覆盖面和影响力，从而不断提升网络思政育人实效。
