# 航海学院组织开展2025年国家自然科学基金申报专题辅导会

为了进一步帮助青年教师提高申请书撰写质量、提升国家自然科学基金项目中标率、提升学院科学研究水准，11月15日，我院邀请自动化学院国家杰出青年科学基金获得者刘准钆教授在学院201会议室做题为“基金申报体会”专题辅导。辅导会由航海学院崔荣鑫副院长主持，学院二十余位青年教师、高年级博士生参加了辅导会。
刘准钆教授以自身的申请经历为例，从项目摘要、学术贡献、未来工作、评审要求四个方面详细讲述了申请书的撰写流程和细节。他强调项目的研究意义要紧密结合国家重大需求，创新贡献论述要具体明确，学术成果要列举典型代表。他建议大家多站在评审人的角度去撰写，杜绝出现小错误、避免长篇大论。
报告结束后，参会师生围绕国家自然科学基金申请书题目的应用性和科学性如何权衡，内容要求、科研问题的选择，研究方案的设计，撰写前的准备工作以及申请书的整体把握等方面与刘教授进行了深入探讨和交流。
最后，崔荣鑫作总结讲话，对刘准钆教授的倾囊相授表示感谢。他希望，参会教师能够将刘教授的经验吸收消化并应用到申报书撰写中去，期待航海学院在2025年基金申报中取得更好的成绩！
