# 我校举行新党员入党宣誓活动

7月1日，学校在长安校区举行新党员入党宣誓活动，800余名新发展的教职工党员和学生党员参加活动，副校长张富利领誓并讲话。活动由党委学生工作部部长、学生处处长于辉主持。
活动在庄严的国歌中拉开帷幕。
在领誓人的带领下，全体党员面向党旗肃立，高举右拳庄严宣誓。铿锵有力的誓言响彻会场，表达了对党的绝对忠诚和为共产主义事业奋斗终身的坚定决心。
新党员代表、自动化学院2023级本科生路一鸣在发言中代表全体新党员承诺，将始终牢记入党誓词，坚定理想信念，锤炼过硬本领，把青春奋斗融入强国建设、民族复兴的伟大事业，努力成长为让党放心、爱国奉献、担当民族复兴重任的时代新人！
张富利代表学校党委对新入党的党员表示祝贺，并聚焦“感悟思想伟力，凝聚奋进力量”“锤炼坚强党性，涵养正确政绩观”“砥砺责任担当，争当实干先锋”三个方面向广大新党员提出了殷切期望，希望大家坚持以习近平新时代中国特色社会主义思想为指导，大力弘扬伟大建党精神，不忘初心、牢记使命、接续奋斗，用忠诚擦亮“党员名片”，用行动诠释责任担当，为加快建设中国特色世界一流大学，为以中国式现代化全面推进强国建设、民族复兴伟业作出新的更大贡献！
宣誓活动在雄壮的《国际歌》中结束。
（图文：张文静海那尔；审核：管峻）
