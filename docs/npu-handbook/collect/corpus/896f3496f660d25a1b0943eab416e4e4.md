# 预防保健科-西北工业大学医院

预防保健科是医院的重要组成部份，在医院的领导下，疾控、监督部门的指导下，肩负着医院、社区及中小幼的预防保健工作重任，积极开展健康教育、传染病与公共卫生事件报告与处理、结核病管理、计划免疫、慢病管理、中医药服务、精神卫生服务、孕产妇保健、儿童保健、老年人保健、居民健康档案、卫生协管及大学生保健等工作，坚持以人为本，用心服务；坚持主动服务，上门服务；坚持预防为主，防治结合；坚持优惠服务，个性化服务。遵循“情系百姓健康，共筑和谐社区”的理念，竭尽所能为辖区居民提供优质、安全、快捷、高效、廉价、方便、连续的医疗和公共卫生服务。科室现有11名工作人员，其中：副主任医师1人，主治医师3人，医师2人，主管护师1人，护师4人。为辖区4万多人口提供公共卫生服务。
