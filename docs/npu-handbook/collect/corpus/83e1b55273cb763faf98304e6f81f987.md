# 学校第十八期“青马工程”培训班特邀原校党委副书记陈建有开展专题讲座-青春驿站-共青团西北工业大学委员会

3月13日下午，学校团委邀请校务委员会副主任、校关工委主任、原校党委副书记陈建有为第十八期“青马工程”培训班开展专题讲座。讲座由校团委书记佘磊磊主持，离退休工作处、学校团委相关负责同志参加，第十八期“青马工程”培训班学员到场学习。
陈建有以“为国西迁、为国育才、为国铸剑”为主题，系统梳理了“总师育人文化”的历史逻辑与时代意义。他从“西工大现象”切入，结合生动案例和详实资料，带领师生回顾学校作为“总师摇篮”的奋斗历程与卓越成效，深刻展现了西工大鲜明的办学特色和西工大人深厚的家国情怀。在此基础上，他进一步梳理了总师育人文化的历史脉络与现实意义，介绍了学校在推进“总师型”人才培养方面的制度设计与实践载体。最后，陈建有从校园文化维度解析了总师育人文化的建设路径，使报国初心与总师精神成为浸润校园、滋养学子的核心文化力量。
讲授结束后，第十八期“青马工程”培训班班长万卓祺代表全体学员向陈建有敬献鲜花。随后，学员们踊跃发言交流，围绕青年马克思主义者成长成才、第二课堂对总师育人文化的涵育作用等内容，与陈建有书记展开了深入探讨交流。
最后，佘磊磊在总结中强调，本次授课集中展现了学校对总师育人文化这一核心课题的深入探索与深刻思考，使学员们对学校的发展历程与精神文脉有了更加系统、清晰的认识。同时，他勉励全体青马学员将所学所悟内化于心、外化于行，从校史中汲取力量、在传承中砥砺初心，努力成长为信仰坚定、本领过硬的青年马克思主义者。
本次专题课程是“青马工程”深化校史校情教育的一项重要内容，有效推动了总师育人文化入脑入心。下一步，学校团委将持续深耕“青马工程”这一育人阵地，不断完善培养体系、创新育人模式，团结带领广大青年为学校“一十百千”发展目标和“天下工大、世界三航”远景目标贡献青春力量。
