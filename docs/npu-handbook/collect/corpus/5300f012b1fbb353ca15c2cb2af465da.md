# 资助护航成长 安全筑牢底线——生命科学与技术学院开展2026级本科生奖助学金政策解读暨实验室安全教育主题班会

为落实立德树人根本任务，扎实做好新生资助育人与实验室安全准入教育工作，10月22日下午，生命科学与技术学院面向2026级本科生开展奖助学金政策解读及实验室安全教育主题班会。会议由26级本科生辅导员贾苏元主持。
学院学工主管景丽老师围绕学院综合测评文件、奖助学金体系展开细致宣讲，系统讲解国家奖学金、国家励志奖学金、校设奖学金、各类助学金及助学贷款的申请条件、评选流程和奖励标准，解读综合测评各维度计分规则、荣誉称号评定要求以及各类奖助项目的限项规定等，引导同学们树立诚信参评、励志向上的观念，鼓励同学们勤学奋进，合理利用各项资助政策助力学业成长。
学院本科教学实验中心杨小超老师结合生命科学实验室特点，着重强调实验室操作规范、风险防范和应急处置等，警示同学们牢固树立“安全第一”意识，严守实验室管理规定，规范各项实验行为，把安全意识融入日常科研学习全过程，守牢安全底线。
本次会议将资助育人与安全教育相结合，一方面帮助新生全面熟悉奖助政策，明晰努力方向；另一方面夯实新生实验室安全思想根基。学院后续将持续推进资助育人、安全教育常态化，全方位护航新生成长成才。
