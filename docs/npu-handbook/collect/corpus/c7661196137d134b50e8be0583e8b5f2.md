# 软件学院召开2026年度新认定研究生导师岗前谈话会

为进一步加强研究生导师队伍建设，落实导师立德树人职责，增强导师岗位责任意识，软件学院于10月15日在长安校区启翔楼303室召开2026年度新认定研究生导师岗前谈话会。学院院长郑江滨、党委书记李晗以及学院 2026年全体新认定研究生导师参加本次会议。
会上，郑江滨向新认定研究生导师表示祝贺，带领参会导师学习国家及学校研究生教育政策文件与导师管理相关规定。他强调，导师是研究生培养的第一责任人，要做到“经师”与“人师”相统一，勉励新认定导师恪守师德为先、守正创新的育人导向，落实好“三个立足”：立足立德树人筑牢思想根基，立足学科前沿赋能创新培养，立足产教融合拓宽育人格局，主动对接国家软件领域重大需求，着力培育高素质软件创新人才。
李晗结合近年高校师德师风、科研经费管理、导学关系建设等方面典型案例开展警示教育，为新认定导师划清行为红线、筑牢思想防线。他结合学院人才培养实际，着重强调新时代研究生导师行为准则，要求各位导师在学术科研上坚守科研诚信、严守学术规范；在经费使用上做到依规管理、公开透明；在师生交往中注重人文关怀，做好思想引导与心理关注，构建平等和谐的导学关系，切实当好研究生成长成才的引路人和守护者。
随后，全体新认定导师依次作表态发言。大家纷纷表示，将牢记为党育人、为国育才的初心使命，严守师德规范，立足岗位履职尽责，不断精进科研能力与育人水平，既当好研究生科研创新的学术领路人，也做好学生成长成才的思想引航者，为学院研究生人才培养和学科高质量发展贡献力量。
会议最后，新认定导师与谈话小组签署《研究生导师岗位责任书》，谈话小组向新认定研究生导师颁发聘书，全体人员合影留念。
本次岗前谈话深化了新认定导师对岗位权责、政策规范的理解把握，强化师德师风与履职尽责意识，为学院导师队伍规范化建设，推动研究生教育高质量发展积蓄新力量。
审核：郑江滨
