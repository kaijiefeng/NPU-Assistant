# 西北工业大学校园环境综合治理管理办法（试行）

西北工业大学校园环境综合治理管理办法（试行）
第一章 总则
第一条为维护良好的校园秩序，加强校园环境综合治理，创建文明、和谐的校园环境，根据国家有关法律法规，结合学校实际，制定本办法。
第二条本办法适用于在校园内工作、学习、生活、承揽工程、从事商业经营、举办公益活动等的一切社会团体、法人单位和自然人。
第三条校园环境综合治理的内容包括：
1.校园环境保护；
2.文明施工管理；
3.商业经营和临时摊点管理；
4.宣传媒介的布置与摆放管理；
5.学校及后勤工作领导小组交办的事项。
第二章 管理体系和部门职责
第四条后勤工作领导小组是校园环境综合治理工作的领导机构，负责校园环境综合治理事项的顶层规划设计。
第五条后勤办公室是校园环境综合治理工作的总牵头部门，负责牵头组织实施后勤工作领导小组的各项决策部署、制定工作计划，代表后勤工作领导小组对校园环境综合治理工作督查督办。
第六条各职能部门按照“谁主管，谁负责”的原则，履行校园环境综合治理工作职责。
（一）党委宣传部
1.负责校园室外公共区域及楼宇外立面固定电子屏、展板、标识等宣传媒介建设方案的审批；
2.负责教学区及校园主干道沿线公共区域内宣传条幅、海报、展板等临时宣传媒介的审批。
（二）离退休工作处（社区居民委员会）
1.组织开展家属区范围内校园环境综合治理宣传教育活动，动员家属区广大住户自觉遵守校园环境综合治理有关规章制度；
2.负责组织相关部门与家属区住户沟通协调校园环境综合治理相关事务。
（三）国有资产管理处负责国有资产管理处组织施工的公用房、住房维修项目管理及文明施工监督。
（四）基建处
1.负责学校各种临建、搭建、管线敷设、开挖等施工的管理和审批（应急抢修除外）；
2.负责维修改造或装修中涉及建筑结构安全及外立面改造的设计方案的审批；
3.负责基建处所管建设项目的安全文明施工管理。
（五）保卫处
1.负责校外单位在校园内开展商业经营活动、举办社会公益活动、承接工程项目等所需的特种作业车辆以及其它用途车辆的通行管理；
2.负责校园内车位的统筹规划和划线（含共享单车）；
3.负责校园内废旧机动车辆的清理；
4.负责校园内犬类及其它危害师生安全的动物的清理；
5.负责校园内临时摊点的审批和对无证摊点的清理。
（六）长安校区管理办公室
1.负责配合后勤工作领导小组统筹协调长安校区校园环境综合治理工作；
2.负责与长安校区驻地政府沟通协调校园环境综合治理相关事务。
（七）后勤产业集团
1.负责校园环境保护，对校园内乱贴乱挂的各类小广告进行清理；
2.制定校园垃圾清运管理办法及作业规范，并组织实施；
3.负责校园“除四害”工作，配合相关部门做好卫生防疫工作；
4.负责校园内公共区域乱堆乱放杂物（含共享单车）的清理, 协助后勤办公室及校内其它部门对家属区违章建筑进行整顿清理；
5.负责校园内建设项目竣工后原有地下管网及绿化带的恢复确认；
6.负责与商业服务用房租借商户沟通协调校园环境综合治理相关事务。
第七条校外单位及团体组织的夏令营、游学、校园参观等活动，必须经校内对接部门审批；长安校区内的活动需报长安校区管理办公室备案，友谊校区内的活动需报学校办公室备案；活动车辆进入校园，需向保卫处提前申请。
第八条校园内各种临建、搭建、管线敷设、房屋及道路维修改造等施工需在现场醒目位置张贴《工程公示牌》。
第三章保障措施
第九条将校园环境综合治理工作纳入校园建设规划，建立和完善校园环境综合治理责任制，召开校园环境综合治理工作会议，分析、布置、督促和检查相关工作。
第十条各责任单位应根据本单位校园环境综合治理工作职责明确相关负责人。
第十一条各责任单位根据自身特点和实际情况，制定相应的管理办法和实施细则，并做好本单位校园环境综合治理相关工作的日常监督检查。
第十二条对治理过程中严重破坏校园环境、扰乱教学秩序或其它拒不履行整改要求的行为，由保卫处协调校外执法机构依法处理。
第四章考核和奖惩
第十三条组建校园环境秩序巡查队伍，负责全校范围内校园环境综合治理工作的专项检查和日常监督抽查；及时向各责任单位通报检查情况，并下发限时整改通知单，责任单位应及时落实整改。
第十四条学校每年通过校园环境综合治理相关制度的落实、检查及整改落实等情况对各相关职能部门进行考核。并根据考核和检查情况对有关单位及个人进行通报表扬或批评。
第十五条学校将校园环境综合治理工作纳入文明校园建设体系。对违反校园环境综合治理规定导致安全事故或重大财产损失的，视情节和后果追究相关单位和有关人员责任；触犯法律的，移交司法部门依法处理。
第五章附则
第十六条本办法由后勤办公室负责解释。
第十七条本办法自颁布之日起执行。如法律、法规中另有规定的，按其规定执行。
