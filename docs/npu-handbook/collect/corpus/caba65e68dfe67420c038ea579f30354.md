# 校企联动 共促科创——江西国科军工集团股份有限公司到访航天学院深化科研合作

为聚焦高端装备与空天动力领域国家重大战略需求，深化产学研协同创新，加快关键技术突破与成果落地，4月23日上午，江西国科军工集团股份有限公司党委书记、董事长余永安率核心团队莅临西北工业大学航天学院开展专题调研交流。航天学院党委书记黄越、党委副书记韩冬及相关领域科研骨干参加会议，会议由韩冬主持。
黄越书记对余永安董事长一行表示热烈欢迎。她指出，服务国家空天领域技术创新、成果转化、产业融合发展是航天学院的重要使命，学院将以此次交流为契机，整合优势科研力量，聚焦企业核心需求，在联合技术攻关、高端人才协同培育、科技成果转化等方面精准发力构建校企合作体系。
余永安董事长详细介绍了江西国科军工集团的发展布局、核心业务与技术攻关方向，重点围绕飞行器总体设计、固体发动机及推进剂、无人协同系统、智能飞行器等领域阐明工程需求与合作愿景。他高度认可航天学院在航天技术、智能装备、动力系统等领域的科研实力与人才积淀，认为双方发展方向高度契合，期待建立长效合作机制，携手服务国防科技高质量发展。
交流环节，双方围绕相关领域关键技术展开深入研讨，精准对接技术需求与科研优势，明确合作切入点与实施路径，就协同创新、资源共享、人才共育等达成高度共识，为后续合作落地奠定坚实基础。
此次交流洽谈，进一步畅通了校企协同创新通道，明晰了空天领域合作方向与重点任务。未来，双方将立足国家战略需求，以技术协同、项目共研、产业共育为纽带，充分发挥高校基础研究优势与企业工程实践优势，以高水平产学研合作，共筑空天领域创新发展新生态。
