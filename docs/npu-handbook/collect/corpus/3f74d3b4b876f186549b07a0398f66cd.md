# 我校召开2017年度校园物业服务契约化考核大会

为了进一步促进我校后勤物业服务工作平稳有序开展，提高物业服务整体水平，更好地为教学、科研和师生员工学习、生活提供优质的服务保障。根据《校园物业管理服务协议》的有关规定和《2017年度校园物业服务契约化考核工作实施方案》，后勤办公室于2017年12月4日下午，在友谊校区正禾宾馆西四楼会议室；12月5日上午，在长安校区数字化大楼第五会议室，分别召开了2017年度校园物业服务契约化考核大会。参加考核大会的职能部处领导有后勤办公室主任赵刚、副主任霍国元、后勤产业集团总经理杨永祥、后勤产业集团党委书记杨军、副总经理田建昌；以及两校区各业主单位党政办公室主任、工会主席、教工监督员、学生物业监督委员会监督员、后勤产业集团各部门负责人、相关物业中心主任、副主任、部门经理等管理人员97人参加了考核大会。考核大会由后勤办公室副主任霍国元主持。首先，各物业中心进行了一年来物业管理服务工作的汇报，由后勤产业集团友谊物业管理服务中心、长安物业管理服务中心分别向大会汇报了年度物业服务保障工作整体情况；各业主单位代表进行了交流座谈和评价打分。参会的各业主单位领导、代表、学生、教工监督员结合物业服务工作汇报，进行了综合测评打分，对物业中心服务工作提出了意见和建议。
后勤产业集团总经理杨永祥代表领导班子进行了发言，首先感谢全校业主单位对后勤服务工作的关心支持；并对后勤服务工作的开展提出具体要求:一是各物业管理服务中心要以本次物业考核为契机，针对各业主单位代表提出的建设性意见和具体性意见，要本着立行立改的原则，加强研究和信息反馈，制定措施，加大整改落实力度；二是学校后勤服务质量、服务水平的整体提升是一个永恒的主题，要求后勤各物业管理服务中心把两个整体提升时刻摆在重要位置，以师生美好生活需求为己任，进一步强化内部管理和控制，为全校师生员工提供好精细化服务；三是校园环境的维护是全校师生员工的共同事情，各物业管理服务中心要加强与全校师生员工相互沟通，自觉维护校园环境，共同推进我校后勤服务保障的开展。
其次，后勤办公室主任赵刚作总结讲话。赵主任首先对两校区物业契约化考核大会的圆满召开表示祝贺，对全校各业主单位的大力支持、积极参与表示感谢，对各物业中心一年来开展的服务保障工作取得的成绩给予了充分的肯定。强调了以下几个方面：一是后勤物业服务契约化考核制度是校园物业绩效评价考核体系一项重要内容，通过建立平台，师生广泛参与，形成校园物业服务工作有效监督保障机制，以此推动后勤物业服务工作的有效开展。二是各物业管理服务中心一年来，以服务提升为总目标，以校园环境改善、动力保障和重大活动保障为突破口，通过对职能部门和学院的走访，了解师生员工需求，认真总结经验，不断查找问题，及时制定措施，狠抓落实整改，圆满完成了契约化服务协议的工作任务。三是结合学校后勤综合改革，要不断创新校园物业服务监督考核机制，利用校园物业监督平台，加大物业服务监督考核频次，促进学校后勤管理服务保障工作的开展。
最后，后勤办公室副主任霍国元向大会宣布了考核随机问卷、考核大会等两项单项分值。
