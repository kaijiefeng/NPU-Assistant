# 【转发】Nature + 1！

近日，西北工业大学航海学院声场感知与隐身技术团队（负责人：曾向阳教授）成员张秀海与合作者在临界拓扑相变研究方面取得重要进展，相关成果以“Observation of critical topological phase transition”为题在《自然》（Nature）发表。新加坡南洋理工大学博士后程哲宇、西北工业大学博士后张秀海为共同第一作者；宁波东方理工大学助理教授余雪佳、中国海洋大学教授周龙文、新加坡国立大学教授Jiangbin Gong和新加坡南洋理工大学教授Baile Zhang为共同通讯作者。这也是航海学院首次作为主要完成单位之一在《自然》（Nature）正刊发表研究成果。
相变是非常重要的物理现象之一，传统观点认为，相变体系中的临界行为与拓扑性质难以共存。近年来，随着临界拓扑理论的发展，拓扑不变量的概念可以拓展至临界相边界。本研究借助声学超材料平台，在实验中实现了临界拓扑相变，统一了临界行为和拓扑性质；并在多临界点上观察到纠缠熵满足可加性，为拓扑强制多临界点的存在提供了直接证据。

作者简介：
张秀海，2020年博士毕业于西安交通大学，2020-2022年在西北工业大学材料学院从事博士后研究（合作导师王宏强教授），2023-2026年在西北工业大学航海学院从事博士后研究（合作导师曾向阳教授），现受聘于声场感知与隐身技术团队。已发表SCI论文30余篇，其中以第一/通讯作者（含共同）身份在Nature及其子刊等刊物发表论文15篇；主持国家自然科学基金、陕西省自然科学基础研究计划等项目3项，近三年参与水下减振降噪相关项目3项（经费1400余万元）。担任多个SCI期刊同行评审人，IOP Trusted Reviewer，Crystals客座编辑；担任第30届全国振动与噪声高技术应用学术会议分会场主持人。曾获美国声学学会ASA International StudentGrant；曾在中央电视台财经频道（CCTV-2）《创业英雄汇》节目展示研究成果。
