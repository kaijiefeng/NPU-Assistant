# 数学与统计学院召开2026年度本科招生工作研讨会

为扎实推进2026年本科招生工作，精准谋划招生宣传策略，学院于1月29日在友谊校区诚字楼202教室召开专题研讨会，重点研究部署2026年重庆地区本科招生宣传的时间安排与活动策划。学院副院长郭千桥、院长助理刘晓刚以及林伟、王振海、李彦吉参加会议。
会议围绕“如何进一步提升重庆地区本科生生源质量与报考热度”这一核心目标展开。与会人员结合往年招生数据、重庆地区教育特点及考生需求，对2026年招生宣传的关键时间节点、行程安排、宣传形式与内容进行了深入分析和细致讨论。会议重点探讨了如何结合学科优势、专业特色、人才培养成果及就业前景，设计更具吸引力和针对性的宣讲材料与互动活动，以有效吸引优质生源。经过充分研讨，会议初步拟定了重庆地区招生宣传工作的初步时间框架与活动方案。
本次研讨会的召开，标志着数学与统计学院2026年度本科招生宣传工作已正式启动。学院将系统整合资源，创新宣传方式，持续吸引心怀报国理想的优秀学子汇聚西工大，为学校高质量生源的规模性突破贡献力量。
