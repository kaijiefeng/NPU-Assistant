# 葛会宾副教授在Angew发文揭示Cu单原子对Pt3团簇催化能力的促进机制

近日，我校生命科学与技术学院葛会宾副教授联合青岛科技大学覃勇教授、西安交通大学姜召教授，在双金属催化剂催化富乙烯条件下乙炔选择性加氢领域取得重要研究进展。相关成果以“Atomic Contact With Cu Single Atom Promoting Pt₃ Clusters for High-Performance Acetylene Semihydrogenation”为题，于2026年9月28日发表在化学领域顶级期刊Angew. Chem. Int. Ed.上。
富乙烯条件下的乙炔选择性半加氢是聚合级乙烯纯化的关键工艺，催化剂需要同时兼顾高加氢活性、高乙烯选择性以及长周期稳定性。由于贵金属Pt基团簇具有较强的氢气活化能力，可以提高贫氢条件下的氢气利用效率。但是Pt团簇对不饱和烃吸附过强，容易发生过度加氢，或通过碳氢键断裂导致积碳生成。而通过引入助金属形成双金属催化剂则是改善催化剂催化性能的常用手段。但是，传统合成方法很难精准控制双金属的空间排布，在引入助金属后，助金属和主金属之间的分布呈随机性，这往往又导致对助金属和主金属在催化过程中的各自用途以及两者之间的协同作用出现认知偏差。而解决这一问题的关键则是在保证其它因素不变的情况下，如何精准控制主金属和助金属之间的空间分布，进而揭示各自的作用机制。
本工作利用γ-Al2O3表面羟基锚定位点可调的特点，通过空气或H2预处理，控制Cu前驱体沉积位置，分别制备了Pt、Cu含量几乎相同的两个催化剂：Cu与Pt直接成键的Pt3Cu1/Al2O3催化剂和Pt3团簇与Cu单原子空间分离的Pt3-Cu1/Al2O3催化剂。该设计首次在保持负载量、载体和团簇暴露度基本一致的前提下，把“Pt-Cu是否原子接触”作为唯一核心变量，直接回答了双金属协同是否必须依赖金属–金属成键这一问题。在富乙烯条件下的乙炔加氢反应中，通过原位表征实验和理论计算证明了氢气的活化解离位点和乙炔的活化加氢位点均是在Pt3团簇上，而Cu单原子的作用则是通过电子转移进一步提高了Pt3团簇的氢气活化能力以及乙烯中间体的脱附能力，而Cu单原子本身并未直接参与到反应进程中。即Cu单原子对Pt3团簇的促进，必须依托形成的Pt‑Cu键；而仅空间靠近无法实现本征协同。本工作为原子精确双金属/团簇催化剂的理性设计提供了实验范式，强调了化学成键是双金属协同的关键判据。
西北工业大学高楚晗（已毕业硕士）、西安交通大学李林森（博士研究生）和太原理工大学曾戬（硕士研究生）为论文共同第一作者。西北工业大学葛会宾副教授、西安交通大学姜召教授和青岛科技大学覃勇教授为论文共同通讯作者。本研究得到了国家重点研发计划、国家自然科学基金面上项目、中央引导地方科技资金项目等基金的支持。
