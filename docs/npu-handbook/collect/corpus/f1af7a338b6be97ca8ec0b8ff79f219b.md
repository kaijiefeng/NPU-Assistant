# 党委保卫部开展交通安全专项培训

今年6月是第24个全国“安全生产月”，为切实提升校卫队员的交通安全意识与业务能力，营造安全有序的校园交通环境，党委保卫部于6月19日、20日邀请西安市公安局交通警察支队碑林大队刘潇泽警长，分别在友谊校区和长安校区组织开展交通安全知识专项培训活动。
本次培训涵盖理论学习与实践操作两部分，围绕校园交通事故预防、电动车安全管理、交通指挥手势实训等内容展开，两校区共计80余名校卫队员参与培训。
培训中，刘潇泽警长结合自身丰富的工作经验，通过案例分析和情景模拟等形式，详细讲解了电动车新规、电动车骑行规范、车辆动态盲区识别及“一盔一带”安全要求等专业知识。实训环节，现场示范了标准交通指挥手势，并指导校卫队员逐一联系，确保动作规范。
此次培训旨在通过专业化培训筑牢校园交通安全防线，为师生打造更安全、有序的交通环境。今后，党委保卫部将持续开展此类专项活动，不断提升校卫队伍的综合素质与服务水平。
