# 关于开展10月份教职工法律咨询服务的通知-校工会（帮扶办）/ 妇女联合会

各位教职工：
为深入推进工会 “暖心惠服行动”，持续优化教职工服务保障体系，做实做细公益法律保障，按照年度工作安排，校工会继续联合泰和泰（西安）律师事务所，依托校工会教职工法律咨询服务中心将于10月15日（星期四）14:30—17:30开展10月份线下专场法律咨询活动。现将有关事项通知如下：
一、服务地点
友谊校区健翔楼320室。
二、服务范围
婚姻家事、房产交易、合同纠纷、劳动人事、债权债务等常见民商事法律问题，律师提供专业咨询与风险提示。本次咨询采取一对一私密面谈的方式，单次咨询时长30分钟，本期设置6个预约名额。
