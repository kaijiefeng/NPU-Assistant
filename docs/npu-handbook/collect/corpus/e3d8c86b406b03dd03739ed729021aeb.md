# 后勤办公室党支部召开理论学习会

按照机关党委理论学习指导意见要求，11月24日上午，后勤办公室党支部召开理论学习会，全体党员和预备党员参加会议。会议由党支部书记张文刚主持。
会上，全体党员集中学习了《习近平对宣传思想文化工作作出重要指示强调坚定文化自信秉持开放包容坚持守正创新为全面建设社会主义现代化国家全面推进中华民族伟大复兴提供坚强思想保证强大精神力量有利文化条件》《党章党规》《二十届中央第二轮巡视相关宣传报道》等内容。
接着，与会人员围绕学习内容，结合工作实际，进行了交流研讨。大家一致认为,要坚持用党纪党规约束自己，不断强化规矩意识，持续在履行好岗位职责、办好师生实事上发力。
最后，张文刚强调，党员干部要将党章党规反复学、对照学、比较学，将党章党规的学习与党的二十大精神结合起来，与为师生解难题、办实事的后勤保障工作结合起来，真正将党纪法规内化于心、外化于行，不踩“红线”，不越“雷池”，以踔厉奋发的姿态、实干担当的精神为学校高质量发展贡献力量。（撰稿人：毛淑兰；审稿人：韩争胜）
