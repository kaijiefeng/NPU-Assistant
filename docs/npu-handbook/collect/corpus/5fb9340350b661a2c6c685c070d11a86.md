# 后勤部办公室召开2025年度领导干部述职测评大会

1月7日上午，后勤部办公室召开2025年度处科级领导干部述职测评大会，单位全体人员参加会议。会议由后勤部办公室主任张文刚主持。
张文刚首先向全体人员传达了学校《关于开展2025年度领导干部考核工作的通知》精神，并向与会人员介绍了考核内容、本次述职测评大会议程及测评规则。接着，后勤部办公室张文刚、韩争胜、郝东兴三位主任和李保康、孟琳、蔺阳三位科长依次进行述职。他们围绕学习贯彻落实习近平新时代中国特色社会主义思想的情况，政治素质和提高政治判断力、政治领悟力、政治执行力的情况，以及担当作为、作风建设情况等，结合各自岗位职责，从德、能、勤、绩、廉以及存在的问题和下一步工作思路等方面进行了全面述职汇报。全体与会人员分别对处级和科级领导干部进行了现场民主测评。
会议最后，张文刚对此次大会进行了总结。他表示，此次述职大会是对过去工作的全面回顾和总结，也是对下一步工作的规划和展望。新的一年，希望大家继续团结一心、砥砺奋进，用心用情用力做好后勤管理和服务保障各项工作，努力开创后勤工作新局面，为学校“一十百千”中期目标和“天下工大、世界三航”远景目标的实现贡献后勤力量。（撰稿人：毛淑兰；审稿人：韩争胜）
