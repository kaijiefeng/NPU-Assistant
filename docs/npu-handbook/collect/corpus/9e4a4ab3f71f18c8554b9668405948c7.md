# 精细修改，细致打磨——航海学院举办2025年国家自然科学基金申报假期集中辅导会

为确保国家自然科学基金申报工作落实见效，有效抓住寒假的“黄金时间段”，进一步推进基金申报进度和提高申报书质量，学院于寒假伊始就先后组织开展了新一轮基金申报专家辅导工作。1月下旬，学院组织了假期第一次辅导会，邀请了校内外八位专家对老师们的申报书撰写工作进行了线下一对一辅导，效果显著，收获颇丰。在此基础上，2月13日上午，学院再次组织假期线上集中辅导会，辅导的重点是申报书精细修改。本次辅导再次邀请了校内外十位专家参会，会议由崔荣鑫副院长主持，学院十余名教师参与。
按照教师申报领域的不同，本次辅导分成三个小组同时进行。在每组辅导中，参会教师分别从项目主题、研究内容、技术思路、研究目标、关键科学问题、项目特色和创新、研究基础等方面向专家们进行了汇报。每位专家则围绕上述内容从准确性、科学性、创新性等方面进行了深入剖析点评，重点在申报书逻辑思路和文字凝练等方面提出了大量的建设性意见，同时也对于一些申报撰写过程中的共性问题及注意事项进行了详细讲解。
本次辅导会不仅为教师们搭建了一个良好的学术交流平台，也为申报书的撰写提供了明确的方向和有力的支持。参会教师们纷纷表示，将抓住假期最后的“尾巴”，认真吸收专家的意见和建议，好好打磨申报书，争取在2025年国家自然科学基金申报中取得优异成绩。
学院将继续关注申报工作的进展，持续为教师们提供更多的支持和指导，助力学院科研工作再上新台阶。
