# 关于第八届西北工业大学结构设计竞赛获奖名单的公示

各学院：
第八届西北工业大学结构设计竞赛已于2026年11月8日结束。本次共有120支队伍报名参赛。经评审委员会评审，最终评选出60支获奖队伍，其中特等奖1队，一等奖6队，二等奖18队，三等奖35队。最佳设计奖、最佳制作奖各1队（均在二等奖队伍中产生，该奖项视同为一等奖）。
现将获奖名单（见附件）予以公示。如有异议，请于公示发布之日起3日内以书面形式反映至联系邮箱。
