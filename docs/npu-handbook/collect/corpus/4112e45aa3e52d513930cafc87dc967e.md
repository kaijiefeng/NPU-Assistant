# 体育部开展教师育人能力提升专题培训

为进一步夯实教师育人素养、锤炼师德师风、提升课堂教学与育人综合能力，依托学校教师发展支持计划，2026年9月24日下午，体育部在友谊校区翱翔训练馆201会议室举办教师培训讲座。本次讲座特邀徐国富教授作题为“走向讲台的梦想—如何做一名好老师”的专题报告，讲座由教学副主任聂东风主持，专任教师参加培训学习。
讲座伊始，聂东风对徐国富教授的到来表示热烈欢迎，并简要介绍了其学术积淀与从教经历。随后，徐国富教授以“努力是人生永恒的主题”为核心主线，结合自身丰富的从教经验与体育教学实际，深入解读新时代体育教师的育人使命与成长路径。他强调，教师要摒弃任务式教学思维，潜心深耕课堂、抓实教学细节，用心做好教学本职工作。围绕“争做新时代优秀体育教师”这一主题，徐国富教授倡导全体教师将“工匠精神”融入日常教学，立足专项领域精研深耕、精益求精；并提出核心成长要求：坚守育人初心与责任，精细落实各教学环节；秉持正向育人理念，多鼓励引导学生，激活学生运动热情；坚持终身学习，主动更新知识体系与教学理念，持续精进专业能力。
本次培训主题鲜明、内容务实、启发深刻，以“四有好老师”标准为导向，进一步筑牢全体教师的育人初心。参会教师纷纷表示，将以本次培训为契机，对标先进、补齐短板，切实把学习所得转化为教学实践与育人成效，持续精进教学本领、创新教学方式、厚植师德情怀，助力学校体育教学工作和人才培养质量实现进一步提升。
