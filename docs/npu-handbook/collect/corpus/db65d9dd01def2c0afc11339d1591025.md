# 校领导率团访问意大利

6月14日至17日，学校副校长孔杰率团赴意大利访问。代表团出席2026中欧卓越大学校长对话会，并与都灵理工大学、国际劳工组织国际培训中心达成系列合作，推动学校全球合作迈向更高水平。
出席中欧卓越大学校长对话会 引领工程教育国际合作
6月15日，中欧卓越大学校长对话会在都灵理工大学开幕。教育部部长怀进鹏、意大利环境和能源安全部部长吉尔贝托·皮凯托·弗拉廷发表视频致辞。德国卡尔斯鲁厄理工学院、西班牙马德里理工大学、意大利都灵大学、葡萄牙里斯本高等理工学院，哈尔滨工业大学、同济大学、西安交通大学、华中科技大学等近30所中欧高水平大学出席对话会。
怀进鹏指出，习近平主席高度重视工程教育，中国政府始终支持工程科技创新与工程教育协同发展，以产教融合为路径构建人才培养机制，以产业需求为牵引优化工程教育生态，以价值贡献为导向推进评价机制改革。他希望中欧高校携手深化创新发展，共同促进世界工程教育质量提升；携手拥抱智能时代，共同推动数字赋能工程教育变革与发展；携手夯实合作网络，共同打造开放协作共赢的工程教育创新生态。
孔杰介绍了西工大办学特色及标志性成果，重点阐释了人才流动与联合培养的创新机制，展示了“走出去、引进来、送出去”的国际合作理念。他以玛丽女王工程学院为典范，展现了中外合作办学的扎实成效；通过“翱翔四海”计划，实现本科生国际交流规模和质量跨越式提升。中欧春校以科技人文课程促进青年创新互鉴，中欧青年文明对话大会汇聚三十余所高校数百名青年围绕多个主题深度对话。孔杰指出，这些实践有效促进了国际人才的流动互通，更打造了具有西工大特色的跨境联合培养新路径，显著提升了学校在中欧工程教育合作中的议程塑造力，为全球工程教育改革贡献了西工大力量。
签署国际劳工组织培训中心备忘录 共筑全球治理人才高地
在都灵期间，孔杰访问了国际劳工组织国际培训中心，与主任克里斯托弗·佩兰举行会谈。双方就青年领导力培养、国际组织实习及人才推送达成战略共识，并正式签署合作谅解备忘录。孔杰表示，西工大愿将合作纳入“一带一路”人才交流框架，服务人类命运共同体建设。佩兰高度评价双方合作基础，期待打造中国高校与联合国专门机构合作的示范标杆。
深度对接中欧大学 拓展中欧教育合作内涵
代表团与都灵理工大学、葡萄牙里斯本高等理工学院围绕中外合作办学、双学位项目及国际引智等议题举行多轮会谈。双方一致同意在学科交叉、学分互认、教师互访等领域深化合作并续签两校协议。
此次访问是学校深度推进全球战略的关键举措。访问期间，学校持续深化与欧洲顶尖理工高校的战略对话，紧密夯实双方学术合作纽带，在中外合作办学、联合实验室共建、学分互认拓展等领域达成多项实质性合作共识，推动学校对欧合作不断走深走实，为中欧工程教育合作持续注入新动能。
国际合作处、集成电路学院（微电子学院）等单位代表随团出访。
