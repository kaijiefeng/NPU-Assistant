# 总师摇篮，为国铸剑——数学与统计学院多措并举扎实推进2026年本科招生宣传工作

为进一步增强考生、家长及社会对我校的了解，持续提升学校生源质量，数学与统计学院院长聂玉峰、党委书记王莉统筹部署、亲临一线，副院长郭千桥、院长助理刘晓刚、林伟老师、王振海老师分工组织，副院长徐根玖、都琳，副书记张莹，院长助理王晓龙和全院40余位教师积极参与，紧扣“总师摇篮，为国铸剑”育人使命，通过开展系列培训、举办高水平学术报告、组织系列家长见面会、深入重点中学开展座谈与科普宣讲等举措，全方位、多层次推进2026年本科招生宣传工作，为吸引优质生源、提升学校影响力奠定坚实基础。
大中衔接座谈会，共话拔尖创新人才培养
5月29日，校党委副书记杨晓、学院党委书记王莉、招生办公室副主任李佩、学院副院长郭千桥、院长助理刘晓刚一行先后赴重庆市南开中学校与重庆市第一中学校，举办大中衔接座谈会。在南开中学，杨晓分别结合国家在航空、航天、航海等领域的重大战略部署，重点解读了西工大王牌专业的学科优势与人才培养特色；在重庆一中，杨晓围绕高质量就业问题，深入剖析了低空经济、航天、海洋、智能等领域的广阔发展前景。两场座谈会均表达了深化大中衔接合作、共育拔尖创新人才的共同愿景。杨晓副书记代表学校向两校赠送“直20”飞机模型，期待未来在人才共育、学术交流等方面进一步深化合作。
硬核科普进中学，共探深海蓝天
为充分展示学校的学术实力与育人优势，学院特别邀请杨坤德院士、苏继东副总师、钟诚文教授等专家，深入重庆多所重点中学举办七场高水平科普讲座，将“大师总师进校园”的浓厚学术氛围延伸到中学课堂。4月19日至20日，杨坤德院士、招办副主任龚思怡、学院副院长郭千桥、院长助理刘晓刚一行先后走进重庆八中、重庆一中、巴蜀中学、南开中学，为每校中学带来《守护蓝色国土：海洋强国与水下硬核科技》主题报告，深入浅出地展示了西工大在海洋探测、水下通信、无人航行器等领域的创新成果，现场互动问答气氛活跃。各校对此次活动高度重视，重庆一中校长毛明山、副校长卫晋丽和何文吉，巴蜀中学党委书记舒义海、党委副书记兼校长李潇珂、副校长金凤、蒋莉、罗本华、党委委员兼纪委书记杨海燕、黄花园校区校长会成员王旭、张家花园校区校长会成员白羽，重庆南开中学党委书记冉孟凯、党委副书记吕珍律，重庆八中纪委书记朱艳等校领导亲自接待并组织师生参与。
苏继东副总师、钟诚文教授则围绕航空航天前沿科技，为学子们带来同样精彩的分享。外国语学校官兵副校长、江津中学杨万机副校长和我院副院长都琳、招生秘书李彦吉等出席活动。七场报告不仅让广大考生直观感受到学校深厚的学术积淀，更激发了同学们对海洋科技、航空航天的浓厚兴趣与报国热情，有效提升了学校的社会影响力和招生吸引力。
系统培训强内功，打造专业化招生宣传队伍
为全面提升招生宣传队伍的专业素养，学院于2026年精心策划并组织了三场集中培训活动，系统强化教师对招生政策的理解与宣讲实务能力。4月1日，首场本科招生宣讲教师资格认证培训会在友谊校区西馆XA101举行。学院党委书记王莉、院长助理刘晓刚、招生工作负责人林伟、王振海及五十余位教师参会。会上播放了校招办主任王克勤关于学校整体情况的宣讲视频，帮助教师系统把握学校办学特色。刘晓刚就特色班设置、强基班招生及重庆市招生政策进行详细解读。王莉在总结讲话中强调，本科招生是人才培养的“入口关”，必须提高站位、规范流程，严格实行“培训—考核—认证”准入机制。5月14日与22日，学院接续在友谊校区勇字楼会议室组织两场专题培训，持续深化教师对招生政策的理解，进一步夯实宣传队伍的专业基础。三场培训内容扎实、节奏紧凑，为2026年本科招生工作的有序推进提供了有力支撑。
政策发布会暨家长会覆盖城区、深入区县，反响热烈
为深入解读招生政策、精准对接重庆考生需求，全面展示学校办学特色与育人优势，数学与统计学院联合招办及各院系，于5月30日、6月中下旬在重庆市连续举办多场家长见面会与招生政策发布会，累计吸引逾千名考生及家长参与，现场气氛热烈，互动积极。
5月30日，数学与统计学院在重庆召开西北工业大学重庆市家长见面会。西北工业大学党委副书记杨晓致辞，数学与统计学院党委书记王莉主持活动，招生办公室副主任李佩介绍学校整体情况及报考指南。同时，邀请航空学院副院长万方义、航天学院院长助理郭宁、航海学院教授杜鹏、教育实验学院副院长蔡力、计算机学院教授黄兴、西北工业大学伦敦玛丽女王大学工程学院/莫航学院院长范晓丽，分别针对航空学院（黄玉珊航空班）、航天学院（陈士橹飞天班）、航海学院（黄震中海洋班）、教育实验学院（智慧三航拔尖班）、计算机类专业以及中外合作办学项目的专业特色与培养优势进行了详细介绍。最后进行了家长现场提问与咨询交流环节。到场家长270余人，活动持续3小时，现场互动热烈。
三区联动，江北、开州、万州家长见面会。6月13日至14日，数学与统计学院王振海老师带队，在重庆江北区、开州区、万州区连续组织三场家长见面会。现场累计参会家长及考生超过500人。学校组织部张婷钰老师，数学与统计学院张莹副书记、郭千桥副院长、林伟老师、刘哲老师、温金环老师、柯乔老师全程参与。我校85级管理学院校友林更力学长到场支持，热心学生家长也主动帮忙协调组织工作。
重庆两地招生政策发布会，国家级教学名师领衔。6月20日至21日，数学与统计学院分别于重庆市沙坪坝区、渝中区举办两场重庆市招生政策发布会。本次宣讲特邀国家级教学名师孙浩领衔主讲，孙老师从学校办学历史、学科顶尖实力、育人平台、升学就业前景等方面全方位系统介绍学校整体情况，内容详实有深度，直击考生和家长核心关切，整场分享干货满满，感染力极强，收获在场家长与考生一致好评。学院郭千桥副院长对重庆招生最新招生政策进行了详细解读，徐根玖副院长、刘晓刚院长助理分别讲解黄玉珊航空班、陈士橹飞天班培养模式；航海学院闫永胜教授介绍海洋工程类（黄震中海洋班）；教育实验学院蔡力副院长解读智慧三航拔尖班特色培养体系；计算机学院周果清副教授全面介绍计算机专业情况。航海学院何轲，数学与统计学院林伟、杨宗泽、张硕、李彦吉全程参与两场宣讲保障工作。沙坪坝区到场260余人、渝中区到场100余人，氛围热烈，互动积极，实现了精准触达与深度交流。
院长书记赴一线，宣讲咨询进校园
为精准服务考生志愿填报、深入宣传学校办学优势，数学与统计学院于志愿填报关键期全面铺开中学宣讲与招生咨询工作。学院组织骨干教师分赴巴蜀中学校、第八中学校、重庆市第一中学校、南开中学校等40余所重点中学，开展线下招生咨询活动50余场，累计服务考生及家长万余人次。此外，学院亦选派教师参加西安铁一中滨河学校及西工大校园开放日招生咨询活动。咨询现场，老师们围绕学校办学历史、学科实力、育人环境、近年录取情况及特色专业进行系统介绍，并针对考生个性化的志愿填报困惑与专业选择方向，提供了一对一精准指导，切实打通招生服务“最后一公里”。学院院长聂玉峰、党委书记王莉在志愿填报关键期亲临一线，为家长、考生答疑解惑。
数学与统计学院通过系统化、立体化的招生宣传矩阵，成功将西工大的总师育人文化、学科实力与育人环境全方位呈现。未来，学院将继续整合资源、创新方式，以更加饱满的热情和扎实的作风投入到招生宣传工作中，为学校高质量生源的规模性突破贡献力量。
