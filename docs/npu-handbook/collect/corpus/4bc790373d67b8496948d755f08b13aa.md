# 生命学院-西北工业大学医院

责任医师：沙娟娟（副主任医师）
简介：
神经内科副主任医师，硕士研究生，毕业于西安交通大学临床医学七年制（本硕连读）。陕西省医学会神经病学分会青年医师委员会委员、中国医药教育协会眩晕专业委员会西安学组委员。主持完成省级科研课题一项，并于核心期刊发表科研论文十余篇。曾获陕西省医学会科普能力竞赛三等奖、陕西省神经内科青年医师演讲比赛特等奖、西北工业大学“思政教学大练兵”一等奖。
（备注：学院责任医师是医院与学院之间的桥梁，可为我校师生提供健康咨询、健康宣教、体检结果释疑、急救知识技能培训等服务。有需求者，可通过扫描学院责任医师二维码联系。）
