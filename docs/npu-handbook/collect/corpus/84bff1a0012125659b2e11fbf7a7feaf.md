# 工信部表彰！西工大“银发力量”再获殊荣

12月17日，工业和信息化部召开离退休干部工作会议，深入学习贯彻习近平总书记关于老干部工作的重要论述和重要指示批示精神，全面总结“十四五”期间部系统离退休干部工作情况，对下一阶段工作作出安排。部党组成员、副部长、离退休干部工作领导小组组长辛国斌出席会议并讲话。会上通报表扬了近五年来表现突出的离退休干部集体和个人。西北工业大学“五老”宣讲团获“工业和信息化部表现突出离退休干部集体”荣誉称号；李华星、席守谋、王秀青三位同志获“工业和信息化部表现突出离退休干部”荣誉称号。
长期以来，学校党委始终高度重视离退休工作，坚持党建引领，用心用情做好离退休教职工的服务保障，为离退休教职工发挥余热搭建广阔平台。“五老”宣讲团作为学校离退休工作的一张亮丽名片，汇聚了一批政治坚定、经验丰富、德高望重的老教师、老专家，他们走进校园课堂、奔赴中小学课堂，以亲身经历讲述西工大与国防事业同频共振的奋斗故事，持续为总师育人文化传承贡献“银发”力量。李华星、席守谋、王秀青三位老同志，是全校离退休教职工的优秀代表，他们发挥各自特长，在各自领域持续发光发热，以实际行动诠释了“离岗不离党、退休不褪色”的赤诚担当。
下一步，离退休党委将在学校党委坚强领导下，加强与校内各部门协同联动，主动担当作为，用心用情做好精准服务工作，奋力推动学校离退休工作再上新台阶、再谱新篇章。
（撰稿：李晓珊；摄影：赵盛楠；审核：陈仲昌）
