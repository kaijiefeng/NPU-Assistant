# 生命科学与技术学院成功举办2026年校友返校座谈会暨选调生、公务员经验分享会

2026年10月17日下午，生命科学与技术学院2026年校友返校座谈会暨选调生、公务员经验分享会在学院顺利举行。学院校友刘婧仪、张虓应邀返校分享。
活动伊始，学院党委副书记张敏乔和对外联络秘书薛璇在学院B206会议室与两位返校校友进行了亲切座谈。她代表学院对两位校友的归来表示热烈欢迎，并与校友们共同回忆了在校期间的学习生活经历。座谈中，张敏乔向校友们详细介绍了学院近年来在学科建设、人才培养、科学研究和师资队伍等方面取得的发展成就，以及学院未来的发展规划和目标。两位校友认真聆听，对学院日新月异的发展变化感到由衷地高兴和自豪。
随后，选调生、公务员经验分享会在学院B107会议室正式开始，学院24级、25级研究生代表40余人参加。分享会由学院2024级硕士生辅导员贾苏元主持。张敏乔首先对两位优秀校友在百忙之中抽出时间返校分享表示衷心感谢，并指出校友是学院最宝贵的财富，校友返校交流活动为在校生搭建了与优秀前辈面对面学习的平台。她勉励在场的硕士生们以优秀校友为榜样，提前规划职业发展道路，并寄语校友常回学校看看。
分享环节中，学院2019届本科、2022届研究生优秀校友刘婧仪首先作公务员考试与职业发展经验分享。她结合自身备考经历和工作实际，从公务员考试的岗位选择、备考策略、面试技巧等方面进行了详细介绍。她建议同学们在备考过程中要把握好“应届生”身份，明确目标、踏实准备，同时注重综合能力的提升，为未来的职业发展打下坚实基础。
接着，学院2020届本科、2023届研究生优秀校友张虓作选调生经验分享。他围绕选调生的选拔流程、基层工作经历、职业发展路径等内容，结合自身在广东肇庆基层一线的工作实践，生动讲述了自己的转变与成长。他介绍了在乡村振兴、纪委监委、应急管理等多岗位轮岗锻炼的经历，表示基层磨砺让自己快速成长。同时，他结合个人经历，对同学们的报考选考提出了建议。
在交流讨论环节，在场的同学们踊跃提问，就职业规划、备考方法、基层工作适应、公务员与选调生的区别等关心的问题与两位校友进行了深入交流。两位校友耐心细致地逐一解答，现场气氛热烈而融洽。分享会结束后，两位校友与在场硕士生代表合影留念。
此次校友返校活动暨经验分享会的成功举办，为校友与母校、校友与在校生之间搭建了宝贵的交流桥梁。未来学院将继续依托各类校友资源，进一步加强与广大校友的常态化联系与深度合作，持续为同学们提供更多元的就业信息渠道和更丰富的职业技能培训，助力同学们更好地规划职业发展、提升就业竞争力。
