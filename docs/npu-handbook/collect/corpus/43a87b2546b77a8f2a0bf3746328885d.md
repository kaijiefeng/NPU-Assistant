# 【培养办】关于2019年研究生思政专项及人文素养类课程建设项目评审结果的公示-西北工业大学研究生院

根据《关于优化我校学术型研究生课程体系的通知》及《关于申报我校研究生课程建设项目的通知》，经各单位组织申报，研究生院组织课程负责人PPT汇报，专家评审商议，最终评选出10门课程作为2019年研究生思政专项及人文素养类课程建设项目的立项课程，现将结果予以公示（见附件），公示期限为5天，公示时间为5月23日至5月27日。
公示期间，如有异议，请联系研究生院培养办反映情况。
