# 关于2025-2026学年春、夏季学期课程 补（缓）考的通知

各教学单位，各位同学：
现将2025-2026学年春、夏季学期课程补（缓）考有关事项通知如下：
一、考试报名
在校生（本科生、研究生）请于2026年8月31日至9月1日登录“翱翔教务”，进入“考试管理”，在“补缓考查询”中核对系统生成的考试科目清单，以免遗漏。如无法登录“翱翔教务”或登录后未查到考试科目信息，请于9月1日16:00前反馈至所在学院或培养单位。
2026届本科结业生请于8月26日前通过“翱翔教务”自行报名，各单位请于8月30日前完成审核工作，报名及审核流程详见附件1。
2025-2026学年春、夏季学期办理了休学的本科生，若有已缓考或需补考的课程，请于8月30日前联系所在学院报名，学院审核并填写附件2《休学学生考试报名表》于8月31日前发送至教学运行与服务中心邮箱（[已脱敏:邮箱]）。
二、考试安排
（一）本科生考试安排
本科生课程补（缓）考将于9月14日至24日进行。由教务部统一排考的课程补（缓）考安排将于9月7日发布，请同学们务必登录“翱翔教务”，进入“考试管理”查看，考试安排以“考试信息”发布内容为准。
由开课单位自行安排的课程补（缓）考请于9月11日前将具体时间地点等考试安排通知到参加考试的学生，考试信息以开课单位通知为准。
（二）研究生考试安排
1.补考
随机过程（M11G11005）、数学物理方程（M11G11008）和偏微分方程数值解法（M11G11003）的补考安排将于9月7日发布，请同学们务必登录“翱翔教务”，进入“考试管理”查看，考试安排以“考试信息”发布内容为准。
其余课程补考由各开课单位自行安排，请同学们及时联系任课教师或开课单位确认考核安排。
2.缓考
2025-2026学年春季学期缓考通过的学生参加下一次课程的结课考试，请同学们注意课程开课时间，及时联系开课单位，确认考核安排。
三、成绩录入
各教学单位须于10月14日24:00前完成补（缓）考成绩录入，并按照要求及时完成考试材料的归档工作。
四、其他
近期2025-2026学年春、夏季学期课程考核成绩会陆续发布，各位同学请及时查看。若对成绩有异议，请及时联系开课单位。
（文字：刘晗、郑波；审核：王劲）
