# 中心残余应力精确测量关键技术与装备制造取得系列重要进展

近日，西北工业大学重庆科创中心残余应力精确测量关键技术与装备创新成果转化应用项目启动会在中心顺利召开。该项目将首次实现残余应力精确测量关键技术与装备成果在我国航空发动机粉末盘/环的残余应力测试及评价中的应用，为提高我国航空发动机关键构件残余应力控制水平，解决加工和服役变形问题奠定基础。
该项目技术由西工大科研团队历经近十年潜心研究，涉及6项关键技术，2项装备和1项实物成果均为国内首创，且已完成样机制造，知识产权自主可控。2021年9月，项目团队联合中国航发北京航空材料研究院共同申报并获批国家级项目。2021年12月，项目团队与重庆理工大学、贵州航宇科技发展股份有限公司联合申报并获批重庆市科技局技术创新与应用发展项目1项；依托该项目，为中心与在渝高校院所在平台建设、科学研究、人才培养等方面深化合作奠定了坚实基础。
新年伊始，中心主任潘宏谱带领项目团队分别与航空工业贵州安大航空锻造有限责任公司、贵州航宇科技发展股份有限公司就联合创新平台建设展开交流，并达成合作意向。与会各方均表示，将以此次交流为契机，加强战略对接，深化务实合作，共襄互利共赢，实现共同发展。
