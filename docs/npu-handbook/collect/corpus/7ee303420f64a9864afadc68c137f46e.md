# 大型仪器共享平台（课题组负责人）

文案：陈建源 编辑：王嘉玮 审核：刘平
大型仪器共享平台（课题组负责人）
1. 激活课题组内用户
1. 1 登录大型仪器共享平台：https://fcdy.nwpu.edu.cn/cf/main/
1.2 点击红框选中的地方
1.3 找到所要激活的成员---点击修改
1.4 是否激活勾选 ”是“---点击保存修改（课题组未激活人员激活成功）
2. 设置 PI 助理
2.1 找到相应的人员---点击修改
2.2 点击角色
2.3 勾选 PI 助理---点击保存修改
3. 查看经费卡号---生成结算单
注：课题组负责人与设置的 PI 助理均可生成结算单
3.1 点击财务管理中的报销管理
3.2 点击更新然后刷新页面
3.3 勾选一条或多条结算项目---点击批量修改经费卡号
3.4 下拉选择所要使用的经费卡号---点击保存
3.5 点击生成结算单
3.6 点击结算单---待经费负责人审批结算单---（找到上一步生成的结算单）点击初审
注：结算单审批只能由经费负责人进行初审
3.7 选择通过或驳回然后提交
3.8 结算单已提交至中新管理员审核---此处可查看结算单审核状态
