# 保卫处联合交警开展“12.2”全国交通安全日 暨安全文明进校园活动

为提高全校师生的交通安全防范意识，12月1日，保卫处联合交警碑林大队、交警高新大队、党委学生工作部，在长安校区开展“12.2”全国交通安全日暨安全文明进校园宣传体验活动，活动主题是：文明交通，你我同行。
本次活动，学校与西安市交警支队碑林大队、高新大队紧密协作，采取“教学体验+现场检查”双项并举的思路开展。在教学体验现场，师生通过智慧交通体验项目，身临其境的感受到了车祸发生瞬间的破坏力，以第一视角体验到酒后驾车的危险状态，更直观的了解到司机的视线盲区，沉浸式体验让参与者深感震撼，更深刻的认识到了车祸的危害性，进一步理解了遵守交通规则的重要意义。在知识科普环节中，工作人员以交通知识讲解，趣味问答，通过VR体验驾照考试等多种形式，引导师生重视交通安全，进一步学习掌握交通法规和正确的驾驶方法，以寓教于乐的形式提高了师生的交通安全意识。为了增进活动的趣味性，活动还组织了抽奖，师生参与四项以上的体验活动，即可参与抽奖领取纪念品。同学们对本次活动表现出浓厚的兴趣，纷纷排队参与学习互动。
在长安校区东北门银河路，交警高新大队与保卫处联合开展“一盔一带”现场检查，对有违规行为的车主进行批评教育，并邀请其观看安全知识展板，学习交通安全知识。活动现场，工作人员向师生讲解骑电动车、摩托车不戴头盔、不系安全带、超员等违规行为的严重危害性，发放宣传彩页，引导师生文明出行，遵守交规。计算机学院的张同学表示：通过学习才知道自己有很多交通知识盲区，今后一定会更加注重学习交通规则，为维护校园交通秩序尽一份力。
今年，保卫处充分发挥警务室的桥梁作用，一方面加强联合检查，纠正校内违规行为，营造安全和谐的校园环境，另一方面转变传统的单一宣教形式，开展具有数字化、可视化的体验式教育，增进安全教育的趣味性和实操性，提升安全教育的质量效果，多措并举，提升师生的交通安全意识，共创良好的校园交通环境。
