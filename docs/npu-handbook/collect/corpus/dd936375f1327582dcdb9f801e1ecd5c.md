# 翱翔四海|西北工业大学电子信息学院2026年香港大学暑期交流项目圆满结束

为深入推进国际化人才培养战略，拓展学生全球视野与学术交流能力，2026年7月13日至18日，电子信息学院组织18名学生赴香港大学，开展了为期六天的“6G与人工智能”前沿技术研学项目。本次活动围绕6G通信与AI融合技术，涵盖专题讲座、实验室参访及文化交流等环节，帮助学生在国际化学术环境中拓宽专业边界，提升综合素养。
课程学习
研学期间，香港大学Kaibin HUANG教授等四位老师为同学们带来了全英文授课的核心课程，内容覆盖6G边缘智能、大模型与生成式AI、分布式机器学习等新兴技术专题，系统展示了通信与人工智能交叉领域的最新进展。
Kaibin HUANG教授以《Edge Intelligence in 6G》为题，深入讲解边缘智能架构与算力下沉路径，并结合车联网、工业物联网等场景，剖析6G落地应用中的关键技术难点。课后，同学们走进6G通信实验室，近距离观摩实验设备，直观理解课堂理论如何转化为实际系统。
Hongyang DU教授围绕《Large Language Model and Generative AI in 6G》，聚焦大模型优化网络调度、信道预测及故障自主排查，展示生成式AI在通信仿真中的实操方案，启发同学们对AI赋能网络自主运维的深度思考。
Xianhao CHEN教授主讲的《Distributed Machine Learning in 6G》则从分布式协同训练、数据隐私保护、多节点算力均衡等维度，系统比较集中式与分布式学习在无线网络中的优劣，帮助同学们理解6G海量终端场景下的智能计算逻辑。
Shaodan MA教授以《Emerging Technologies in 6G》为题，全面梳理通感一体化、超大规模MIMO、空天地一体化网络等前沿方向，结合智慧城市、远程医疗、低空经济等应用场景，客观分析技术商业化面临的频谱、硬件与协议挑战。
通过系列课程的系统学习，同学们初步认识了6G网络下各类智能技术的体系架构与研究价值，明晰了通信与人工智能交叉领域的发展方向，建立起对多条6G前沿技术路线的系统认知。这不仅完善了同学们对6G新技术体系的整体理解，拓宽了电子信息领域的专业视野，也进一步激发了大家深入探索通信前沿技术的兴趣。
实验室参访
交流期间，同学们全程跟随教授走进香港大学6G通信与人工智能专业实验室，近距离观摩整套前沿通信、AI一体化实验平台，完整见证理论知识转化为实体技术系统的研发流程，弥补了校内课堂仅接触抽象公式、概念的学习局限。
实验室陈列多款商用、自研通信测试设备，其中中国移动研发的大规模有源天线阵列给同学们留下深刻印象。教授讲解了阵列内置数百根微型天线的排布逻辑，结合课堂讲授的Massive MIMO理论，演示多天线协同收发信号、提升通信容量与覆盖稳定性的实测过程。
同学们还参观了6G通感一体化测试平台、分布式AI算力仿真机房，观看科研人员调试终端协同训练实验，直观了解了无线通信与人工智能结合的真实科研流程，清晰地认识到现阶段6G落地需要攻克的硬件损耗、同步时延等实际难题，对无线通信底层技术、交叉学科科研实践产生了更为立体、深刻的理解。
文化交流
在香港大学学生大使的带领下，同学们还参观了校园标志性建筑、图书馆及红墙打卡点，深入了解港大“格物明德”的校训精神，切身感受其开放包容的学术氛围。课余时间，团队还前往维多利亚港、坚尼地城、太平山顶等地标，领略香港兼具潮流活力与深厚底蕴的城市风貌。从课堂到街头，从学术研讨到文化体验，同学们在多元场景中收获了丰富的研学体验。
