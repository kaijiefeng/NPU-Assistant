# 离退休党委举办党支部书记专题培训班

7月6日至9日，离退休党委组织离退休党支部书记赴延安大学泽东青年干部学校开展党支部书记专题培训。
本次培训充分用好延安红色资源，采用专题授课、现场教学、情景教学相结合的教学模式，围绕延安精神、党中央在延安十三年、梁家河实干担当、白求恩精神等内容开设专题辅导。参训学员先后走进杨家岭、王家坪、枣园、梁家河等革命旧址，实地参观延安革命纪念馆、延安文艺纪念馆、北京知青博物馆，在红色实景课堂中追忆革命岁月、感悟初心使命，深刻领会延安精神时代内涵，接受了一次全面深刻的党性淬炼与精神洗礼。
参训学员纷纷表示，本次培训紧扣树立和践行正确政绩观学习教育要求，课程内容充实、教育感染力强。下一步，大家将把此次培训所学所思转化为履职尽责的实际行动，传承弘扬延安精神，充分发挥先锋模范作用，持续提升离退休党建工作质效，为学校事业高质量发展贡献银发智慧与力量。
（撰稿：李晓珊；摄影：延安大学泽东青年干部学校；审核：马俊）
