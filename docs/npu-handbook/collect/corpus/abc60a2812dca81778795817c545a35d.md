# 马克思主义学院开展新学期本科教学工作检查-西北工业大学

新学期第一天，马克思主义学院思政课全面开讲。校长宋保维一行来到长安校区检查。第一节课前，宋校长走进《中国近现代史纲要》课堂，与师生交流，了解课前准备情况，强调要不断深化课程教学改革，提升思政课和公共基础课教学质量，为学生价值塑造和高质量深造奠定更加扎实的基础。
学院院长杨云霞、党委书记王彦革、副院长贺苗与学院教学督导开展督导听课。教学督导深入课堂，对教师课前准备、课堂组织和教学秩序等情况进行全面巡查，与任课教师和学生交流教学安排与学习状态，及时掌握开学伊始思政课教学运行情况，确保新学期教学平稳有序开展。
新学期，新气象，学院将持续全面落实督导听课制度，学习领会“新时代高校思政课建设工作推进会”精神，不断提升思政课质量和水平，为培养“总师型”拔尖创新人才夯实思想基础。
