# 西北工业大学网络空间安全学院开题答辩（陈捷）

一、开题答辩题目：一种面向攻防不确定性的网络动态安全体系构建及基于推理决策的安全资源调配关键技术研究
二、开题答辩人：陈捷
三、开题答辩时间：2024年1月18日 上午10：00-12：00
四、开题答辩地点：中国电子科技集团公司第三十研究所3号楼5楼会议室
五、开题内容简介：
网络安全易攻难守，传统防护模式以静态为主，通过应急处置措施缓解网络安全事件带来的网络资产损失，难以应对当前网络安全风险的不确定性。动态防护思想旨在提升网络安全主动性，通过增强自我变化的动态性，以体系化网络安全防御调节机制为核心，改变网络攻防中安全防护方的被动局面。本论文在本体思想下建立多源攻防对抗的网络安全动态防护模型与方法，以可高效调配的安全资源为基础，对动态化的网络安全防护体系架构相关概念和关系进行建模，基于推理方法实现安全防御方案的快速主动决策，从而实现系统防御架构动态可变，达成网络安全主动持续优化能力。
六、开题答辩人简介
陈捷，女，学号2021161083，1977年4月出生，网络空间安全学院电子信息专业，导师谢瑞云，主要研究方向为网络安全体系、主动防御等。
