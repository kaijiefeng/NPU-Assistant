# 新生入学教育｜集成电路学院组织2026级新生走进校史馆开展校史校情教育-集成电路学院（微电子学院）

为引导2026级新生坚定报国志向、厚植爱校荣校情怀，聚焦集成电路国家战略人才需求，2026年10月9日下午，集成电路学院组织2026级本科生、硕士研究生、博士研究生新生走进校史馆，开展沉浸式校史主题入学教育。
在讲解员引导下，新生依次参观序厅、追根溯源、雄鹰展翅、翱翔腾飞、奔向一流、春华秋实六大展区。从国立西北工学院、华东航空学院、哈军工空军工程系三脉汇聚，到古路坝灯火、华航西迁、哈军工严谨治学；从抗战烽火中科技报国，到“三航”领域为国铸剑，一幅幅照片、一件件实物、一段段影像，将学校八十余载办学历程娓娓道来。展馆以“时间毯”、褐色至科技蓝的色调过渡、雕塑模型、场景还原、投影触摸、红外感应、机器人讲解等形式，让历史可感可触。同学们驻足于全国第一架小型无人机、第一台地效飞行器、第一型50公斤级水下无人智能航行器等成果前，更对学校研制出我国第一块航空专用大规模集成电路芯片深感振奋。师昌绪、高景德、陈士橹、黄玉珊、张立同、徐德民等科学家和教育家，以及唐长红、邓景辉等总师校友的故事，生动诠释了“国之所需，吾之所向”的使命担当。
校史馆参观完毕，同学们意犹未尽、百感交集，纷纷提笔抒怀、以文寄情：
“走进校史馆，仿佛与前辈展开一场跨越时空的对话。从古路坝到启真楼，我更加懂得’公诚勇毅’的重量。作为集成电路学院的本科生，我需要夯实数理与电路基础，在科创实践中练就真本领，让青春与祖国需要同频共振。”
“看到学校研制出我国第一块航空专用大规模集成电路芯片，我深受触动。芯片虽小，牵动国运。我将立足专业方向，踏实做实验、认真跑仿真、严谨对流片，在’卡脖子’处发力，把论文写在强国征程上。”
“校史中一代代西工大人’国之所需，吾之所向’的选择，让我更加明晰博士阶段的责任。我将面向国家战略需求做有组织科研，在芯片设计、EDA、先进封装等方向勇闯无人区，传承总师精神，努力把创新成果转化为大国重器的’芯’支撑。”
本次校史馆参观是集成电路学院（微电子学院）新生入学教育和“芯”文化育人的重要一环，也是一堂理想信念与专业认同深度融合的校史思政课。通过校史校情学习，新生进一步理解了“为党育英才、为国铸重剑”的使命，坚定报国志向。
