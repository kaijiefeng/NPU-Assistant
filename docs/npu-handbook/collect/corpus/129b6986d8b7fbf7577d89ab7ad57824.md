# 红色基因 蓝色情怀”力学与交通运载学院学生党员暑期社会实践纪实（三）

为高质量实施新时代立德树人工程，深入开展西北工业大学实践育人“三个一”暑期专项工作，引导青年学子立大志向、上大舞台、入主战场、干大事业，力学与交通运载工程学院在学工主管王涵晶老师、辅导员高晨光老师的带领下，组建“红色基因 蓝色情怀”主题实践队，开启了一场“触摸红色根脉、追寻领袖足迹、传承军工薪火”大学生暑期社会实践，教育引导青年学生党员在实践育人大课堂中，争做又红又专的“总师型”人才。
为深入贯彻落实习近平总书记关于资源型地区转型发展系列重要指示批示精神，系统学习借鉴资源地市推进资源型城市高质量全面转型发展的先进经验、创新路径与典型举措，同步引导青年学子实地体察国情社情、锤炼专业本领、积累实践调研素材，实践队7月8日这一站奔赴铜川市开展专题学习交流研讨。
首先前往药王故里艾叶有限公司，实地考察中医药特色产业发展模式，学习当地依托本土资源，以特色农业带动群众增收致富、助力乡村振兴的实践做法。
随后，队员们走进当地低空经济领域代表企业，陕西苍穹领航科技有限责任公司开展实地交流，该公司是陕西西部华安实业集团旗下专注于科技领域发展的全资子公司，同时也是无人机技术应用的综合服务商。通过参观与现场实操直观了解了不同型号无人机的前沿技术与应用场景。现场实践队员还与企业负责人王战名围绕产学研协同、人才交流、科创成果转化等方面深入探讨，学习科技驱动多行业数字化升级，无人机低空经济积极服务乡村振兴与产业智能化战略。
同时，现场举行了社会实践基地揭牌和授牌仪式，为企业挂牌“西北工业大学实践育人‘三个一’工程实践基地”，进一步加深了校企合作，为后续学生专业实习实践、科研合作搭建了长期稳定的平台。
下午，实践队一行到达铜川市人民政府，与铜川市科学技术局政务领导进行座谈，详细了解了铜川市在传统产业改造升级、战略性新兴产业培育、科技创新赋能产业发展、绿色低碳转型等方面的实践做法、政策举措与成效案例，为本次社会实践调查研究提供了现实参考。
调研产业振兴新路径，探索科技赋能高质量发展。此次与铜川市政府、企业的调研拓宽了队员们的社会视野，进一步感悟到城市发展转型的复杂性与系统性，也深刻认识到自身专业在其中的广阔应用空间。大家纷纷表示，今后将立足专业所长，主动对接地方发展需求，努力把论文写在祖国大地上，以青年力量与担当助力区域经济与科技产业发展。
