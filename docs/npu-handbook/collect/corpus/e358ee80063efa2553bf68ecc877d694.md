# 凝心铸魂强堡垒 实干担当促发展——教育实验学院召开新学期党支部书记例会

为深入贯彻落实学校党建（全面从严治党）工作领导小组（扩大）会议部署要求，扎实推进新学期基层党组织建设，我院召开新学期党支部书记工作例会。学院党委书记牟蕾、各党支部书记、组织员参加会议。
会议聚焦传达学习学校近期重要会议精神，党的创新理论学习研讨，党务工作规范化水平提升等，进一步统一思想、凝聚共识，压紧压实党建工作责任，部署新学期党建重点工作。
会上，各党支部书记逐一对照学校、学院年度工作部署，客观梳理工作短板与发展堵点，结合支部育人特色，务实交流整改思路与新学期工作计划。
结合学校会议精神，牟蕾对学院党建工作作出部署。一是以理论铸魂把方向，持续深化常态化理论学习，用好《习近平党建文选》《习近平关于基层工作方法论述摘编》等教材，抓实正确政绩观践行落地，切实把学习成效转化为履职实效。二是以标准提质固根基，持续推进党支部标准化规范化建设，严格规范党内政治生活，做实党员全周期教育管理，严把党员发展质量关口，夯实基层战斗堡垒。三是以守正笃实防风险，常态化开展意识形态、校园安全、学生管理风险排查，筑牢校园思想安全与政治安全防线。四是以融合赋能促发展，紧扣学校教育科技人才一体化发展部署，坚守“为党育人、为国育才、为军铸才”初心使命，立足学院拔尖创新人才成建制培养核心任务，推动党建工作深度融入学科建设、教育教学、学生工作全过程，助力学校“十五五”高质量发展。
下一步，学院将锚定发展目标、夯实党建根基、深耕融合赋能，以更加务实的作风、更加有力的举措推动基层党建工作提质增效，为学校建设特色鲜明、世界一流大学贡献力量。
