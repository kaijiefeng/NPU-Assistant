# 守护校园供水安全，筑牢师生健康防线

习近平总书记强调，饮水安全是人民生活的一条底线。校园供水安全是保障师生身体健康、维护校园稳定的关键环节。为切实筑牢校园供水安全屏障，给广大师生营造安全、健康的用水环境，后勤部办公室多措并举，扎实推进各项供水安全保障工作。
定期清洗二次供水水池，筑牢健康防护墙
二次供水设施是校园供水系统中的重要组成部分，其清洁程度直接影响二次供水水质。后勤部办公室严格按照《二次供水设施卫生规范》等相关规定，每半年组织专业公司对校内二次供水蓄水池进行一次彻底清洗消毒，清除水箱内的污垢、杂质和细菌。同时，委托第三方检测机构对二次供水水质进行检测，检测项目涵盖色度、浑浊度、pH值、总大肠菌群等多项指标，确保符合国家生活饮用水卫生标准，为广大师生员工的身体健康筑牢坚实的“防护墙”。
安装维修水泵房监控设施，织密安全防护网
为进一步强化两校区饮用水安全管理，实时掌握水泵房运行状况，及时发现问题并处理潜在安全隐患，后勤部办公室对两校区水泵房监控设施进行了全面维修及补装，实现了水泵房24小时监控全覆盖。工作人员可通过远程监控系统随时查看水泵房运行情况，一旦发现异常，可第一时间赶赴现场处理，有效提升了水泵房安全管理的效率和精准度，为校园饮用水安全增添了一道坚实的“防护网”。
实施供水设施更新改造，提升运行可靠性
为彻底消除部分老旧水泵房运行安全隐患，提升各楼宇供水稳定性，后勤部办公室持续推进老旧供水设施更新改造，完成了友谊校区西苑15号楼水泵房、毅字楼水泵房等老旧水泵房改造，对老旧水泵、控制柜、稳压管等设施进行更换；同时，安排专业人员对正常使用的设施进行定期维保检修，确保设施平稳可靠运行。
定期维护更换饮水设备，保障便捷饮水安全
为进一步做好师生饮用水服务保障工作，近几年后勤部办公室在梳理盘点学生公寓开水器使用年限及运行状态的基础上，更换老旧开水器近300台。同时，安排专业维保人员定期对校园内公共区域直饮水机进行滤芯更换、水箱清洗等维保工作，确保直饮水机出水安全卫生，让师生能够放心、便捷地饮用直饮水。
加强与自来水公司沟通，畅通信息联动渠道
校园供水安全离不开市政供水公司的支持与配合。为及时掌握市政自来水有限公司的供水情况，确保校园供水稳定、安全，后勤部办公室与两校区自来水公司建立了常态化沟通机制，定期了解自来水公司的供水计划、管网维修改造等信息，及时面向师生发布有关通知并制定应对预案，最大限度减小因外部供水问题对校园二次供水的影响。
下一步，后勤部办公室将持续高度重视校园供水安全，不断完善供水安全保障体系，细致查找二次供水工作中的薄弱环节，持续推进设施更新及管理机制健全，让广大师生和教职员工喝放心水、用安心水。（撰稿人：张偲偲；审稿人：韩争胜）
