# 集成电路学院举办“从麦克斯韦方程到 偏振感知芯片”专题讲座-集成电路学院（微电子学院）

11月5日上午，西北工业大学集成电路学院（微电子学院）在长安校区教东D1-202举办集成电路技术研讨专题讲座。本次讲座邀请西安电子科技大学先进材料与纳米科技学院副教授李晓波作题为《从麦克斯韦方程到偏振感知芯片》的学术报告。报告围绕基于低维各向异性材料的偏振感知芯片展开，介绍了相关理论基础与技术实现。讲座由集成电路学院院长助理刘炜老师主持。
报告从光学发展历程与麦克斯韦方程组出发，介绍了光的电磁特性及偏振感知的相关理论，梳理了从基础物理规律到光电器件设计的研究思路。针对传统硅基器件对光偏振状态不敏感的瓶颈，李晓波老师介绍了利用低维材料各向异性构建偏振探测器的技术路线，阐述了材料物理特性与器件功能之间的联系。
在研究进展介绍中，李晓波老师以(NbSe₄)₃I、紫磷等低维材料为例，介绍了研究团队利用晶体各向异性特征构建偏振探测器的相关工作，展示了低维各向异性材料在光电感知领域的应用潜力。
围绕器件微型化与功能集成，李晓波老师进一步介绍了如何利用各向异性材料的本征物理特性进行器件设计，阐述了相关研究为下一代光电芯片设计提供的新物理机制与技术路径，并简要介绍了相关研究工作。报告将电磁理论、材料特性与器件应用相结合，呈现了从基础研究走向光电感知系统的探索过程。
本次讲座聚焦低维功能材料与光电芯片的交叉研究前沿，为师生了解偏振感知技术的发展与应用，以及认识材料创新和器件设计之间的联系提供了有益参考，也为相关领域的学习与科研拓宽了思路。
