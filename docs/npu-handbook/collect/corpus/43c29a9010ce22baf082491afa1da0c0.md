# 西北工业大学国际学生校友联络和管理办法

西北工业大学国际学生校友联络和管理办法
第一条国际学生校友（即“外籍校友”）是西北工业大学的宝贵资源，是学校校友的重要组成部分。开发外籍校友资源，做好外籍学生校友联络与管理工作，对学校的建设和发展有着积极的影响。为推动外籍校友工作，规范外籍校友的管理，结合《西北工业大学校友会章程》中的相关内容，制定本办法。
第二条西北工业大学外籍校友指曾在学校接受一年及一年以上教学、培训的外籍毕业生、肄业生或结业生，包括各类国际学生中的研究生、本科生及进修生。
第三条国际教育学院负责外籍校友的联络和管理工作。留学生管理办公室负责保持与外籍校友的联系，外籍校友工作的开展需要学校各单位的支持和协助。
第四条国际教育学院整合外籍校友资源，建立外籍校友信息沟通机制，负责建立并维护外籍校友信息库，及时更新校友档案，收集并维护包括住址、电话、电子邮件、在校期间的情况、毕业后去向、事业发展情况等信息。
第五条国际教育学院积极为在华工作或旅华的外籍校友提供信息与咨询服务，定期为外籍校友组织开展座谈会、团拜会、互访活动等，增进外籍校友与学校的感情。
第六条国际教育学院指导外籍校友建立联谊组织，积极在外籍校友数量相对集中的国家建立外籍学生校友会，并将其纳入学校校友工作进行统一指导。
