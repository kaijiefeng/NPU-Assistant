# 航空学院关于做好2025级研究生新生（含推免生）调档转党团组织关系的通知

各2025级研究生（含推免生）：
根据学校有关规定，需要对所有拟录取非定向硕士、博士新生进行调取档案，请所有拟录取新生联系所在单位协助做好以下工作：
1.应届毕业生的档案材料（含中学、高考、大学本科及党团员材料等），由考生所在单位于2025年7月10日前将考生的全部档案以顺丰或邮政EMS方式寄到我院（定向生、强军计划不寄）。录取通知书由校研招办统一寄送，请同学们提醒自己档案所在单位的相关负责老师，尽早将档案寄达我院，以免造成档案缺失。
2.党员组织关系转入：研究生新生党员应将党员组织关系于今年9月报到入学后转入我院（具体时间待学院通知），原则上所有新生党员转入均通过“党建信息化平台”转入，转入的目标党支部名称：中共西北工业大学航空学院硕士研究生第七支部委员会（硕士）或中共西北工业大学航空学院博士研究生第三支部委员会（博士）。如果本单位确实未开通线上通道（一般仅部队或涉密单位），请携带原单位党组织纸质介绍信转入。介绍信抬头为“中共西北工业大学委员会”，所去党组织为“中共西北工业大学航空学院硕士研究生第七支部委员会（硕士）或中共西北工业大学航空学院博士研究生第三支部委员会（博士）”，入学时将纸质关系介绍信交到航空楼A座321。联系人及电话：李老师029-88494301。
3. 团员组织关系转入：新生团员（含仍在团党员）应将团组织关系转入我院，转入采取“网上系统转入”或“携带组织关系纸质介绍信转入”。新生团员即日起在“智慧团建系统”完成组织关系转接，转入的目标支部名称：陕西省教育团工委-西北工业大学团委-航空学院团委-2025级研究生临时团支部。具体操作（含北京、广东、福建系统操作办法）见“智慧团建”系统首页。其他有关问题请参考微信公众平台@共青团中央《2022年毕业学生团员组织关系转接指引和问答，请查收！》一文。
4.档案邮寄地址：详见调档函。
5.以上请相互转告，如有问题请及时和学院联系。
