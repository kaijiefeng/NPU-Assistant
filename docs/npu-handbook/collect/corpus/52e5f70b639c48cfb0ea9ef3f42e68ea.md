# 工会党支部书记陈建军讲授专题党课 传达学习寒假务虚会、新学期中层干部会会议精神-校工会（帮扶办）/ 妇女联合会

2月27日下午，工会党支部书记陈建军讲授主题为《学习贯彻学校寒假务虚会、干部会会议精神 创新工会工作 助力学校高质量发展》的专题党课，支部全体党员参加学习。
陈建军带领全体党员认真学习了李言荣书记、宋保维校长在学校寒假务虚会、新学期中层干部会上的讲话精神，梳理了学校第十四次党代会各项任务中工会可为能为的工作，解读了刚刚闭幕的“双代会”上学校党委对工会和教代会工作的最新要求，并结合学校2025年工作要点，从强化党建引领、创新工会工作、健全教代会工作机制、围绕中心如何发力、丰富文体活动、优化福利发放、加强调查研究、凝练工作思路方法、强化工作作风、坚守廉洁底线等方面与大家交流了思考和想法，强调工会要深入学习贯彻学校第十四次党代会精神，学习习近平总书记关于工人阶级和工会工作的重要论述，找准与学校中心工作的结合点、切入点、发力点，努力提升教职工的归属感、幸福感、获得感。
随后，支部13位党员根据前期支委会布置的2月学习清单进行领学，并结合工作实际开展交流研讨活动。
新的一年，工会全体党员要不断提高政治站位，将思想统一到中央和学校党委决策部署上来，强化思想引领和支部建设，抓好主责主业，深化服务师生，为建设中国特色世界一流大学做出更大的贡献！
