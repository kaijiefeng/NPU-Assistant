# 关于组织开展2025年度西北工业大学本科专业设置工作的通知

各学院：
为深入贯彻全国教育大会精神，落实《教育强国建设规划纲要（2024－2035年）》重要部署，做好学校本科专业设置及申报工作，进一步优化专业结构，不断提高专业建设水平，按照《西北工业大学本科专业建设管理办法》（校教字〔2022〕23号）、《西北工业大学本科专业动态管理实施细则》（教字〔2022〕33号）文件要求，现提前部署2025年度本科专业设置工作，有关事项通知如下：
一、申请新增本科专业（2025年度专业预申报）
按照教育部办公厅《关于进一步做好普通高等学校本科专业设置工作的通知》（教高厅〔2024〕1号）相关规定，自2024年度起，申报新增本科专业均须提前一年进行预申报。
（一）预申报专业的范围：申报新增的备案专业、国控专业以及目录外新专业。
（二）预申报专业的应用：在2026年度新增本科专业工作中，申报备案专业须与预申报的专业相同或相近；申报国控专业和目录外新专业，预申报情况将作为审批时的重要参考。
2024年已通过“普通高等学校本科专业设置与服务平台”预申报的专业，学校将另行组织材料填报工作。
二、申请新增第二学士学位专业
申请增设第二学士学位专业可依托现具有学士学位授予资格的本科专业，无需预申报。
三、本科专业设置基本要求
（一）将服务国家重大战略需求、服务国防科技工业、服务国家现代化建设作为专业发展的基本定位。
（二）充分发挥学院学科优势，进一步建立西工大特色“总师型”人才培养体系，主动布局国家战略、国防工业和未来产业急需紧缺专业，拓展战略新兴专业，鼓励设置“航空航天+”等具有西工大特色及相关领域急需紧缺专业。对社会需求不高、同一区域（领域）重复设置的、与国家战略不符的专业教育部将继续严格控制。
（三）积极应对人工智能对人才培养带来的机遇和挑战，主动开展相关行业态势研判调研，及时布局战略新兴领域专业，深化工工、理工交叉融合，强化人工智能赋能传统工科专业的改造升级，推动现有专业与智能技术交叉融合，培育建设“人工智能+”新兴专业。
（四）设置目录外新专业要充分论证，专业名称应科学规范，与目录内已有专业有明显区分，具有一定的发展性，避免简单叠加或口径过窄。
（五）有明确的专业建设方向，有相关学科为依托，有必需的专职教师队伍、教学辅助人员以及教学资源，具备开办专业所必需的办学条件；社会需对所增专业有稳定的人才需求，校内、外实践条件能够满足专业办学需求。
（六）在满足《普通高等学校本科专业类教学质量国家标准》的基础上，各申报专业要对标一流本科专业建设“双万计划”，科学论证专业发展规划，提供充足资源投入，持续推动专业建设可持续发展，着力提高人才自主培养质量。
四、其他要求
请各学院高度重视，积极探索建立面向“总师型”人才培养的需求研判和响应机制，对拟新增和撤销专业开展充分调研和论证。学校将在总量控制、结构优化的前提下开展专业动态管理，统筹规划每一年度申报新增和撤销专业。
五、材料报送
请有意向申请增设新专业（包含第二学士学位专业）的学院认真填写《西北工业大学拟申报新增专业基本情况采集表》（附件1），申请撤销专业的学院填写《西北工业大学拟申报撤销专业基本情况表》（附件2），并于4月10日（星期四）前将电子材料（盖章版PDF文件）提交至教务部规划办公室。
