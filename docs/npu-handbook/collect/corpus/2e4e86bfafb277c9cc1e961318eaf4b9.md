# 航海学院召开研究生导师培训会

研究生导师培训是加强师德师风建设、提升导师育人能力的重要举措。为加强学院研究生导师伍建设，提升研究生导师的指导能力和业务水平，2025年9月26日，航海学院举办了研究生导师培训会，学院全体研究生导师参加了培训。
会上，曾向阳副院长强调，导师是研究生培养的第一责任人，其学术水平、创新意识和指导能力直接关系到研究生的培养质量。他指出，由于招生政策、学生情况、管理规定和学业要求等都在不断发生变化，研究生导师也应与时俱进，不断学习和成长。他希望全院导师能够与研究生建立互信和谐的师生关系，有效激发出研究生科研创新潜能，实现高质量、可持续研究生培养的实践路径。
随后，研究生秘书李淼、罗钰、赖慧详细从招生、课程学习、培养环节要求、学位申请、国际化等的一些关键事项展开培训。
本次培训旨在帮助研究生导师进一步明确导师第一责任人制度，熟悉研究生培养过程的各个环节，明晰研究生培养的相关规定、要求和流程，促进研究生导师指导能力和育人成效的持续提升，为进一步提高学院研究生培养质量奠定坚实基础。
（审核：刘朝亚，王银涛)
