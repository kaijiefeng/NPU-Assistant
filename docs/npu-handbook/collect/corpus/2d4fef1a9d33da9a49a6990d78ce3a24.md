# 支付结算方式

学校对外资金结算主要采用银行转账和公务卡结算，控制现金结算。支付结算规定如下表：
一、公务卡结算
公务卡是财务报销业务的信用卡，持卡人在消费限额内按规定用于日常零星公务支出，并在发卡行规定的免息还款期内完成财务报销。因个人报销不及时造成的罚息、滞纳金等相关费用，由持卡人承担。
二、银行转账
通过学校银行账户将款项划转到收款方账户的支付结算方式。报销时需准确提供对方单位名称、开户行及银行账号信息。
三、现金结算
结算方式为纸质现金、个人银行卡、微信/支付宝等，统称现金结算。可使用现金结算的情形如下：
1.慰问金、抚恤金、丧葬补助及遗属补助等补助支出。
2.签证费、版面费等无法使用公务卡结算的支出。
3.快递费、过桥过路费、出租车费等只能使用现金结算的支出。
4.未办理公务卡人员单独出差的相关支出。
四、校内转账
学校内部单位之间利用学校资源提供有偿服务所发生的内部结算业务，如资源占用费、测试化验费、网络服务费、场地使用费等，均需通过财务处进行内部转账结算，严禁使用现金结算。
五、报销要求
1.按规定使用公务卡结算的，需在网上报销“公务卡”模块编制公务卡消费信息，若未编制，报销时提供公务卡消费记录。
2.应使用公务卡或对公转账方式结算而未使用的，报销时需备注说明未使用公务卡原因。
