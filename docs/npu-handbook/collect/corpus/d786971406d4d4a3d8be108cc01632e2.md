# 工会党支部与航空学院办公室党支部联合开展主题党日活动-校工会（帮扶办）/ 妇女联合会

为深入学习贯彻习近平生态文明思想，深入贯彻中央八项规定精神学习教育，4月29日上午，工会党支部与航空学院办公室党支部作为结对共建支部，联合开展了主题党日活动。
活动首站来到西安国家版本馆，这座被誉为“中华文化种子基因库”的国家级文化殿堂，以典藏展示中华文明发展脉络为核心。在讲解员引导下，党员们依次参观《赓续文脉 踔厉前行——中华文化经典版本展》等主题展，通过古籍文献、碑帖拓印、红色档案等珍贵版本，深切感受中华文明的博大精深。
在“大教训”警示教育基地，党员们通过图文影像、实景复原和典型案例，系统了解秦岭北麓违建问题整治历程。触目惊心的生态破坏案例与重焕生机的修复成效形成鲜明对比，生动诠释“绿水青山就是金山银山”理念。
两支部党员还走进长安校区南山青禾农场，实地了解学校劳动教育基地建设成果，切身感受劳动教育的育人价值。
此次主题党日活动，通过“文化+生态”“党建+工建”双主题融合，推动党员从历史文脉中汲取精神力量，在劳动实践中锤炼党性修养。两支部将以此次活动为契机，持续深化共建机制，在党风廉政建设、师德师风工作、分工会作用发挥、文化传承、乡村振兴等领域开展深度合作，共同打造“资源共享、优势互补、协同发展”的党建新格局，为学校高质量发展贡献力量。
