# 化学与化工学院开展2026届本科毕业生“工大最后一课”毕业教育

为持续深化毕业生思想引领，厚植青年学子家国情怀与爱校荣校底色，引导毕业生锚定人生航向、扛起时代重任，以昂扬奋进姿态奔赴人生新征程，6月22日上午，化学与化工学院党委书记傅茂森在学院报告厅为2026届本科毕业生讲授了“工大最后一课”。学院党委副书记姚东东、辅导员刘程飞及2026届本科生参加。
傅茂森以“深耕实学砺本领 为国铸剑启新程”为主题授课，紧扣时代发展机遇与基础学科使命担当，从牢记强国嘱托、潜心基础笃行致远，启航新业征程、精进综合核心素养，传承总师基因、逐梦星海建功立业三个维度展开系统讲授。他勉励毕业生坚守科研初心，深耕基础研究，用扎实学识服务国家战略需求；对标拔尖创新人才培养要求，打磨多元发展所需综合能力，不断完善自身素养；弘扬总师育人文脉，接续先辈报国志向，胸怀家国奔赴各行各业，立足岗位担当作为、建功新时代。
本次课程为即将奔赴山海的全体本科毕业生送上深刻思想启迪与暖心临别关怀。整场授课既有站位高远的价值领航，亦有细腻走心的温情叮嘱，为学子们在西工大的青春求学时光，烙下厚重温暖的专属印记。愿全体毕业生前路浩荡、踏浪逐光，以青春担当扛起家国使命，凭实干笃行书写新时代青年的奋进答卷。
