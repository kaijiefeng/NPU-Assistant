# 航天学院黄攀峰教授团队国家重点研发计划国际合作项目启动

5月7日，由航天学院智能机器人研究中心张帆教授担任负责人、国网四川省电力公司为牵头单位的国家重点研发计划2025年度“战略性科技创新合作”重点专项“基于空地机器人群体智能协同的输电铁塔组塔关键技术联合研发”项目在四川成都正式启动。四川省科技厅副厅长刘菊蓉、国网四川省电力公司副总经理明自强、国家电网公司基建部技术处处长龙磊、西北工业大学航天学院院长黄攀峰、四川省能源局综合处副处长王映雪等主管领导参加会议。航天学院张帆教授作为项目负责人汇报项目开题报告、王通副教授作为任务（课题）负责人汇报具体实施方案。中国工程院张建伟院士、原电力科学院副院长李正、华南理工大学自动化学院院长丛杨教授、浙江大学刘勇教授、成都飞机设计研究所（611所）副部长李军等担任评审专家，哈萨克国立大学祖玛迪尔院士、香港大学助理教授陈楠、巴基斯坦巴尔卡布公司代表均发表讲话。
本项目是黄攀峰教授团队围绕所深耕的“空间绳系机器人”这一重大国防技术领域，整合全球优势资源，向国家重大民生工程领域延伸的一次战略尝试。项目组汇聚了国家电网、中科院、中电建、中能建、北航、西交大、香港大学、哈萨克国立大学等13家全球优势团队，整合9个全国重点实验室，构建产学研用深度融合、国内外协同攻关的创新体系。项目聚焦川藏高海拔、地形复杂、生态敏感区等施工痛点，破解传统组塔周期长、风险高、生态扰动大等难题，服务雅下水电送出、西电东送等国家重大能源工程。项目预期建立全球首套无人组塔技术体系，并完成全球首次无人化组塔示范与首个跨国应用，推动我国占领高海拔、山区等复杂环境输电工程无人化施工技术世界制高点，为国家能源安全与新型电力系统构建提供坚实支撑。
航天学院智能机器人研究中心作为项目负责人团队，始终以我国国防和国家重大需求为牵引、以智能机器人技术为核心，解决国家重大工程任务中的核心关键技术。中心将以本项目为契机，深化落实《关于我校“十五五”规划中的几个问题》提出的“强特色、筑高峰”要求，助力“总师型”人才特色培养模式走深走实，坚持做具有价值的高水平科研，取得更多丰硕成果。
