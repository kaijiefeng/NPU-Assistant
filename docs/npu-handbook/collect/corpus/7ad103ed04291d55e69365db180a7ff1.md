# 我校召开 2025年学生创新创业竞赛总结暨第24届“三航杯”创新大赛启动会-青春驿站-共青团西北工业大学委员会

12月9日，西北工业大学2025年学生创新创业竞赛总结暨第24届“三航杯”创新大赛启动会在友谊校区召开。校长宋保维出席大会并讲话。党委常务副书记吕卫东，副校长岳晓奎、王伶，校长助理王宇波及创新创业教育工作领导小组成员单位负责人，各培养单位负责人，项目指导教师、学生代表等参加大会。大会由副校长詹浩主持。
校团委书记佘磊磊汇报了中国国际大学生创新大赛(2025)和第十九届“挑战杯”全国大学生课外学术科技作品竞赛的整体情况、备赛经验和后续规划。在今年10月举办的中国国际大学生创新大赛 (2025)全国总决赛中，学校获金奖16项，金奖总数位居全国第一；在11月举办的第十九届“挑战杯”全国大学生课外学术科技作品竞赛中，主体赛特/一等奖总数并列全国第三，蝉联“优胜杯”。
王伶、王宇波为金奖团队获奖代表颁奖。
岳晓奎为优秀指导教师获得者颁奖。
詹浩为双创工作先进个人获得者颁奖。
吕卫东为双创卓越工作者获得者颁奖。
宋保维为优秀组织奖获奖单位颁奖。
本年度金奖团队学生代表、机电学院燕则翔同学讲述了自己通过大赛锻炼了从“会做”到“既会做又会讲”的心路历程。指导教师代表、教育实验学院/未来技术学院院长林鑫以“双创赋能拔尖人才培养”为题，分享了学院以双创工作为牵引培养拔尖创新人才的相关情况。优秀组织单位代表、航天学院党委书记黄越以“凝心聚力 勇于开拓 推动学院创新创业教育工作迈上新台阶”为题，从强化系统谋划、深化协同聚力、聚焦过程培育等方面分享了学院将创新创业教育融入人才培养全过程的具体举措。
宋保维代表学校、代表李言荣书记，向同学们在大赛中取得的优异成绩表示热烈祝贺
向各位辛勤付出的指导教师表示衷心感谢，并宣布第24届“三航杯”创新大赛启动。他指出，习近平总书记两次给中国国际大学生创新大赛参赛学生代表回信，接续勉励、意义重大。党的二十届四中全会提出，要扎实推动科技创新和产业创新深度融合，作为培养学生创新创业综合能力的重要载体，创新创业教育是贯彻落实党中央这一决策部署的生动实践。近年来，国家正持续推进卓越工程师教育培养改革，进一步拉近高校和企业的紧密关系，同学们要走进企业、走到一线，看到真问题、解决真问题、真解决问题。希望广大学子积极投身创新创业，成长为胜任时代发展需求的拔尖创新人才。希望各部门协同联动，完善制度保障体系，传承发扬科研精神，充分利用良好的校企合作基础，众筹各方资源全力支持学生创新创业工作。
关于进一步开展好学生创新创业竞赛工作，他提出三点要求：一是要继续保持高位求进的工作态势。作为“一十百千”中期目标的关键指标，创新创业竞赛竞争激烈，要面向世界科技前沿、面向国家重大需求，与兄弟高校互学互鉴，挖掘彰显学校特色优势的项目。二是要以人才培养为第一要务，为学生引路搭桥。要选优配强指导老师队伍，通过自身的工作经历，引导学生将课堂和实验室所学应用到工程实践当中，多为学生提供了解项目需求、了解社会的机会。三是要充分发挥传帮带和榜样引领作用。要发挥优秀团队、优秀学生的示范引领、辐射带动作用，帮助学弟学妹们提高创新创业素养和能力，力争双创能力走在前列、学生水平走在前列，为推进中国式现代化作出新的贡献。
