# 分析测试中心开展暑期前实验室安全专项检查

7月17日上午，为严格落实学校暑期安全管理要求，中心组织开展假期前实验室安全专项检查，并对暑期安全工作的重点内容进行了强调和提示。
本次检查坚持“查隐患、固成效、强意识”原则。检查小组首先重点核查了前期问题整改落实情况，确保重大风险隐患点管控措施有效，对实验室整体运行状态给予肯定。此外，针对个别气瓶标识不全、惰性气体监测报警装置待完善等问题，已现场要求立行立改，加快气体检测装置部署。
结合现场检查情况，中心领导在下午的全体会议中进行了暑期安全综合提示：一是守牢消防底线；二是严管施工安全，三是强化值班巡查，重点检查设备运行、电路负荷及消防设施，确保响应及时；四是规范水电使用。五是严格履行备案手续，落实双人值守（其中一人为教职工）。
中心将以“时时放心不下”的责任感，进一步压实三级安全责任体系，扎实做好假期值班值守与应急准备，确保暑期实验室安全稳定运行。
