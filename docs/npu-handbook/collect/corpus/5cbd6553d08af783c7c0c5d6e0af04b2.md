# 数学与统计学院举行2026年本科招生宣传资格认证培训会

为进一步提升教师队伍的招生宣讲专业能力与水平，扎实推进2026年本科招生工作，4月1日晚，数学与统计学院在友谊校区西馆XA101教室举行本科招生宣讲教师资格认证培训会。学院党委书记王莉、院长助理刘晓刚、招生工作负责人林伟、王振海及五十余位教师参加会议，会议由刘晓刚主持。
会上，首先播放了招办王克勤主任关于学校整体情况的宣讲视频，帮助教师系统了解学校整体情况与办学特色。随后，刘晓刚围绕特色班专业设置、强基班招生、重庆市招生指南及注意事项进行了详细介绍，帮助教师准确把握相关招生政策与培养亮点。在现场问答环节，与会教师就招生宣讲中的重点难点问题进行了交流探讨。
最后，王莉书记在总结讲话中强调，本科招生是人才培养的“入口关”，必须提高站位、严谨规范，严格落实“培训—考核—认证”准入机制，希望全体教师进一步提高站位、强化责任，以专业、热情、细致的宣讲讲好西工大故事，为吸引优质生源贡献力量。
本次培训会内容务实、安排紧凑，进一步夯实了学院招生宣传队伍的专业基础，为2026年本科招生工作的顺利开展提供了有力保障。
