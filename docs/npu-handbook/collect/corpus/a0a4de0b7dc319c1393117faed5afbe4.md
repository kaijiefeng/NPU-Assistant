# 科技强盾铸防线 智慧赋能护未来”主题科普活动顺利举办

为深入学习贯彻习近平总书记关于科技创新和网络强国的重要论述，加快提升网络安全高素质人才培养，在第二十五个全国科技活动周的浓厚氛围中，西北工业大学网络空间安全学院在校科协、中国系统工程学会网络空间安全与治理专委会的指导下联合西安青年科学技术协会、中国青年科技工作者协会人工智能专委会，于2025年5月25日成功举办了“科技强盾铸防线，智慧赋能护未来”主题科普活动。活动邀请到西安四叶草信息技术有限公司创始人兼董事长马坤、奇安信技术总体部技术首代张富洋等网络安全领域专家为全场师生带来主题报告，现场指导学生实际攻防演示，活动由网络空间安全学院院长王震教授主持。
智能时代的网络安全攻防体系与威胁应对策略
首先，马坤为在场师生带来第一场题为《智能时代的网络安全攻防体系与威胁应对策略》的精彩报告。马坤以近年来备受关注的Facebook数据泄露事件和智能手表窃听案等典型案例为切入点，深刻揭示了在数字化转型浪潮中网络安全所扮演的关键角色，并旗帜鲜明地提出“网络安全是信息化时代底座” 的重要论断。此外，马坤还从攻击者的视角出发，深入浅出地向同学们阐述了企业内网等系统的攻击原理，介绍了构建安全体系的基本步骤，进一步强调了网络安全的重要地位。
在可信不可信网络中构筑网络安全防线
接着，张富洋以《在可信不可信网络中构筑网络安全防线》为题做第二场报告。他从日常工作生活、国际形势变化等多个角度层层剖析了网络空间的信任危机，并为同学们展示了诸多国家级网络对抗的重大事件（例如，震网病毒）。就电信诈骗话题，他通过分享典型诈骗案例、分析电诈信息来源，呼吁同学们要提高反诈意识。报告尾声，张富洋列举了日常生活中存在安全隐患的各种行为，并阐释了各领域构筑网络安全防线的方法。
网络安全攻防演示
最后，由西北工业大学学生信息安全协会会长周子博为同学们进行了生动刺激的路由器攻防演示，形象地展示了网络漏洞的隐秘性、危险性以及网络安全的重要作用。
王震总结说，在数字化浪潮奔涌向前的今天，网络安全已成为国家安全的重要组成部分，本次讲座不仅是一次知识的传递，更是一场关于责任与使命的对话。作为网络空间安全学院的学生，需以创新为驱动，以技术为利剑，为打造坚不可摧的网络空间防线贡献力量！
