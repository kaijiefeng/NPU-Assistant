# 航海学院2025级本科新生入学教育系列活动顺利开展

为帮助新生尽快适应大学生活、明确成长方向、筑牢发展根基，自2025级本科生入校以来，航海学院组织了理想信念教育、校史校情教育、校规校纪教育、安全法制教育等系列教育活动，通过专题讲座、现场教学、互动实践等丰富形式，引导新生厚植爱国荣校情怀，强化规则意识与安全观念，为开启充实而有意义的大学生活奠定坚实基础。
【理想信念教育】
“纪念中国人民抗日战争暨世界反法西斯战争胜利80周年”大思政课
9月18日，西北工业大学航海学院组织2025级本科新生代表赴启真楼，参观“烽火记忆——西北工业大学抗战历史主题展”与“哈军工精神展览”。新生们驻足珍贵史料前，聆听校史中的抗战故事，深刻感悟先辈“以智御敌”的报国情怀。当晚，学院组织全体2025级本科新生同上“弘扬伟大抗战精神 做光荣自豪中国人”思政大课。课上回顾抗战历程，结合航海学院“向海图强”的使命，激励新生将抗战精神转化为科研报国动力。此次活动，为新生上好入学思政第一课，筑牢其胸怀“国之大者”的信念。
延安实践育人“三个一”活动
9月27日至28日，西北工业大学航海学院组织2025级本科新生赴延安开展实践育人“三个一”活动，以红色教育筑牢理想信念，以实践行动传承延安精神。同学们走进延安革命纪念馆、杨家岭革命旧址等地，通过实物展览、现场讲解，重温党中央在延安的奋斗历程，深刻感悟“自力更生、艰苦奋斗”的延安精神。此次活动将红色教育与实践育人深度融合，为航海学院学子上好“行走的思政课”，进一步坚定了青年学子扎根国防、科研报国的理想信念。
【校史校情教育】
图书馆新生入馆教育活动
为帮助2025级本科新生快速熟悉图书馆资源与服务，增强信息素养与学术规范意识，传承发扬“总师育人文化”，9月25日及10月9日，航海学院2025级本科新生分两批前往图书馆参与新生入馆教育活动。此次针对本科生的入馆教育，重点围绕高效利用图书馆资源与服务展开。活动中，工作人员详细讲解并指导新生熟悉图书馆空间布局，掌握图书借阅流程，了解电子资源访问方式，同时介绍了阅读推广等基础服务内容，旨在通过系统化的指导，为新生筑牢信息素养基础能力，助力其更快适应大学学术生活，为后续的学习与科研活动打下坚实基础。
校史馆新生入馆教育活动
10月16日下午，西北工业大学航海学院2025级本科生前往校史馆参观，沉浸式感受学校发展历程与精神底蕴。此次活动是学校党委宣传部、党委学生工作部联合举办的“校史教育月”重要环节，旨在培养新生爱国爱校荣校意识，激励学子奋发作为。校史馆荣誉满载，是展示学校办学历史、传承优良家风、增强师生文化认同、弘扬爱国主义精神和科学家精神的关键平台。参观过程中，新生们跟随讲解深入了解学校在不同时期的办学成就、科研突破与育人成果，深刻感悟学校蕴含的家国情怀与科学家精神。此次校史馆之行，不仅让新生们增进了对学校的认知与认同，更激发了他们以校为荣、奋发图强的青春动力，为未来在学业与科研道路上砥砺前行奠定思想基础。
【校规校纪教育】
组织新生学习《西北工业大学学生手册》
学生手册涵盖学籍管理、奖惩制度、学术规范、校园安全等核心内容，是新生快速适应大学管理模式、明确自身权利与义务的重要指南。9月下旬，航海学院组织2025级全体本科新生开展《西北工业大学学生手册》专题学习活动，并同步完成学生手册签领承诺环节，为新生筑牢校园行为规范根基，引导其树立正确的求学态度与纪律意识。学习结束后，全体新生逐一签署学生手册签领承诺书，以书面形式承诺将严格遵守校规校纪，自觉维护校园秩序。此次活动不仅让新生清晰了解学校管理要求，更强化了其规则意识与责任担当，为营造优良学风、助力新生健康成长提供了有力保障。
学校奖助政策及航海学院综测文件解读
为帮助同学们明晰奖助政策与综测规则，9月18日航海学院开展了专题解读会。25级本科生辅导员首先详细了介绍学校奖助体系，涵盖国家奖助学金、专项奖学金及专项补助等项目。重点说明各奖项申请条件、评定标准、申报流程与时间节点，明确成绩、综合素质等核心评审要素，同时解答家庭经济困难认定、资金发放等疑问，助力同学们精准申报。其次，结合专业特色，辅导员拆解综测细则，明确思想道德、学业成绩、科研实践、志愿服务等考核维度的计分标准与材料要求。解读会设置互动答疑环节，及时回应疑问，确保同学们吃透政策要点，保障奖助评定与综测工作公平公正，充分发挥政策激励作用。
【安全法治教育】
安全教育体验馆参观
为切实增强学生安全防范意识，提升自我保护能力，9月份航海学院组织25级本科生分四批前往西北工业大学安全教育体验馆，开展沉浸式、互动式安全知识学习活动。通过丰富的知识讲授与互动体验相结合的方式，全方位、多角度开展自然灾害、国家安全、校园安全、消防安全、卫生健康、交通安全等实践体验教育培训。此次参观活动，将抽象的安全知识转化为生动直观的体验，有效弥补了课堂教学的不足。学生们纷纷表示，通过这次活动不仅学到了丰富的安全知识，更提高了自我保护的警惕性，未来将把所学知识运用到生活和学习中，时刻绷紧安全之弦，为自身健康成长保驾护航。
（审核：刘朝亚 王银涛）
