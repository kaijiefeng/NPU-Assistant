# 关于2023年图书馆志愿者招募的通知

全体在校同学：
西北工业大学图书馆志愿者团队成立于2013年9月。十一年来，我们秉承“奉献、友爱、互助、进步”的宗旨，打造出一支以“学生为核心”的师生共建服务团队。该团队集学习、交流、体验为一体，鼓励学生深度参与图书馆各项服务工作，最大限度调动和激发学生的积极性，提升学生团队合作能力，助力其在工作实践中不断成长与发展。
为进一步加强图书馆学生队伍建设，弘扬志愿服务精神，组织动员广大青年学生在工作中磨砺才干本领，在实践中培养青年学生的能力和水平，增强学生组织的生机与活力，现面向全体在校同学招募图书馆志愿者，招募信息如下：
一、志愿者服务内容
在图书馆老师的带领下，参与图书馆的空间管理、书库管理及宣传推广、资源维护等工作。
二、志愿者招募要求
1、西北工业大学在读本硕博学生；
2、热爱志愿服务、有奉献精神、服务意识、责任心、有一定的组织协调能力、服从安排；
3、能按时参加志愿服务，不无故缺勤。
三、志愿者保障
1、提供“志愿汇”平台志愿时长认定；
2、定期提供志愿者服务时长证明；
3、对优秀志愿者进行表彰并奖励；
4、为符合条件的优秀志愿者推荐勤工助学岗位工作机会。
四、报名方式
关注西北工业大学图书馆微信公众号内相关推文或QQ搜索群（群号111439459）加入群聊后报名，报名截止时间2023年10月30日22：00。
