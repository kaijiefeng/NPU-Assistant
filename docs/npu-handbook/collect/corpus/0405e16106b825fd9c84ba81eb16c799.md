# 第五届全国“红色工业文化研究”学术会议通知-西北工业大学

百年风云，工业报国。从党领导的安源路矿工人大罢工，到官田兵工厂的炉火初燃；从“一五”计划的宏图铺展，到三线深山的艰苦创业；从改革开放的敢闯敢试，到新时代大国重器的接连问世——中国红色工业走过了气壮山河的百年历程，铸就了大庆精神、“两弹一星”精神、西迁精神、载人航天精神等融入民族血脉的精神谱系。
百年回望，尤见其重：亲历者们正渐渐老去，抢救性记录已到最后窗口；精神谱系如何续写、社会记忆如何守护、个人叙事如何留存，正待学界同仁携手作答。
为深入挖掘红色工业文化资源，研讨中国红色工业的精神谱系、社会记忆与个人叙事，推动红色工业文化研究走深走实，西北工业大学及“红色工业文化研究联盟”单位拟于2026年10月16日至18日在四川成都召开第五届全国“红色工业文化研究”学术论坛。本论坛与第一届“红色工业文化育人理论与实践”学术研讨会（2026年10月16日～18日，成都）同期同城举办，两会有分有合、联动而独立。现将有关事项通知如下。
01 会议主题
红色工业文化百年史：精神谱系•社会记忆•个人叙事
02 主要议题
1.红色工业文化百年史的分期与整体书写研究。涵盖革命根据地时期、社会主义革命和建设时期、改革开放和社会主义现代化建设新时期、中国特色社会主义新时代等阶段的红色工业文化史脉络。
2.红色工业精神谱系的生成逻辑与建构机制研究。包括大庆精神（铁人精神）、“两弹一星”精神、西迁精神、三线建设精神、载人航天精神、劳模精神、劳动精神、工匠精神等的学理阐释。
3.红色工业文化的社会记忆研究。包括工业城市、单位制、工人村、“记忆之场”、三线乡愁与工业共同体的集体记忆、文化记忆研究。
4.个人叙事与红色工业口述史研究。包括生命史方法、“一五”时期与三线建设亲历者抢救性口述访谈、口述史料与档案文献互证、访谈伦理等。
5.红色工业记忆的载体与媒介研究。包括档案、厂志厂报、照片影像、工业遗产本体、博物馆与数字平台的保存、传播与再生产。
6.其他与红色工业文化相关的选题。

2.鼓励立足红色工业文化百年历程，结合新型工业化、工业文化建设和中国式现代化等问题深入研究；欢迎基于口述史访谈、档案文献与田野调查的一手研究成果。
（二）格式规范
1.论文篇幅宜在0.8万—1.5万字，中文摘要200—300字，中文关键词3—5个；
