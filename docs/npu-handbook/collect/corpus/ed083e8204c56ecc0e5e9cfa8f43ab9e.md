# 2023-2024学年春季学期体育康复保健类课程选课说明

一、课程介绍与目标人群
西北工业大学体育康复保健类课程是针对伤残病学生开设的体育与健康公共课程。包括《运动与康复保健》、《运动与养生》、《运动与慢病防治》、《运动与关节健康》等四门课程（见附件2）。
本课程仅针对以下人群（未列入人群不予受理）：
1. 残疾学生；2. 慢性疾病学生；3. 突发疾病学生；4. 病后初愈康复学生。
二、选课流程
体育康复保健类课程选课形式为预置名单课程（不在教务系统开放选课）。选课的同学需提交申请及证明材料，具体流程为：
1.学生提交申请（详细内容见附件申请表），证明材料附在申请表后页，申请表命名为课程名称+姓名+学号，发送至邮箱[已脱敏:手机号]@163.com；同时添加体育健康班学生QQ群：1012952836，如有疑问可在QQ群内联系管理员。
2.体育部教学办审核。审核未通过，体育部将联系学生本人进行核实；审核通过的学生体育部不再单独通知。
3.学生资格通过审核后，由体育部将名单报送教务处分批录入教务系统对应课程，选课完成。
4.申请时间同步选课时间（三轮选课和补选），其余时间不予受理。
5.申请者按时提交附件1。
