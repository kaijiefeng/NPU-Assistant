# 西北工业大学音像电子出版社-西北工业大学资产经营管理有限公司

西北工业大学音像电子出版社有限公司（以下简称“西工大音像社”）成立于2000年12月，2004年5月新增电子出版物出版权，注册资本200万元，是西北工业大学出版社有限公司的独资子公司，是工业和信息化部主管、西北工业大学主办的中央级出版社。
西工大音像社一贯坚持为高等教育的教学科研服务，为学科建设和人才培养服务，为国防科技工业科研生产服务的办社宗旨，配合本版图书发行有关航空、航天、航海科学技术和本校所设其他理、工、文、管等专业（学科）范围内的音像制品，出版社会科学、科学技术、教育类电子出版物，提供计算机、通信网络信息技术服务。建社以来，已出版电子图书2500余种，音像制品700余种。在数字化发展趋势下，西工大音像社承接慕课、微课、数智课程、各类短视频、宣传视频的拍摄与制作，出版发行音像电子出版物及数字教材。
“十五五”期间，西工大音像社将努力加强特色品牌选题体系的构建和人才队伍的建设，实现创新发展，逐步成为能够提供优质内容的知识服务型企业。
