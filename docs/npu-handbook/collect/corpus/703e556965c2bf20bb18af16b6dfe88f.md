# 探寻考古印记，感悟文明薪火 ——集成电路学院师生赴陕西考古博物馆 开展主题党日活动-集成电路学院（微电子学院）

10月29日，学院机关党支部与本科生第二党支部近30名党员前往陕西考古博物馆参观学习，开展主题党日活动。
陕西考古博物馆是全国首座考古学科专题博物馆，围绕考古历程、文化谱系、考古发现、文保科技等内容展示陕西考古成果。在讲解员的带领下，师生们依次参观展厅，近距离观摩各类文物与标本。
参观过程中，讲解员结合展品，为大家讲解地层学、类型学等基础考古知识，介绍考古工作者如何依靠土层特征、器物形制梳理历史线索。从秦汉、唐代遗存到宋代出土器物，师生们透过丰富的展品，了解不同时期古人的物质生活与文化风貌。同时，大家也了解到现代科技在文物病害检测、修复保护中的重要作用，感受到文物保护工作的严谨与不易。师生们结合自身兴趣，就展品相关问题与讲解员交流探讨，在实物观摩中收获新知。
此次主题党日活动将文化体验与科学教育相结合，引导师生在参观学习中感受中华优秀传统文化的深厚底蕴，厚植文化自信。全体师生将把此次研学的感悟内化于心、外化于行，传承求真务实、精益求精的治学精神，在科研求索、勤学笃行中践行使命担当。
