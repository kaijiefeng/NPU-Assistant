# 给2022届毕业研究生的一封信

给2022届毕业研究生的一封信
日期：2022-03-10 11:23   浏览次数：2672

亲爱的2022届研究生同学们：

大家好！陌上花渐开，希望次第来。伴着希望与感动，我们一起克服困难、携手同行，为研究生阶段画上了圆满句号。祝贺同学们即将迎来新的人生旅程，祝大家在新的旅程中创造新的精彩！

毕业离校之际，学生职业发展指导服务中心特别提醒同学们，务必关注以下几点关键信息，这对大家非常重要：

1．毕业离校前请一定与辅导员联系，领取《报到证》（升学学生无《报到证》）、《户口迁移证》或《户口卡》（户口在校学生），这些对大家真的很重要，很重要，很重要！

2．请大家及时与《报到证》上的指定单位取得联系，在规定时间内前往《报到证》上的指定单位办理报到手续（升学的学生凭录取通知书报到）；派遣回原籍的毕业生请联系档案接收单位，在规定时间内到《报到证》上的单位去报到。《报到证》是你在规定时间内办理工作报到、个人户口迁移、人事部门转接档案等手续的重要凭证。如无《报到证》，则会出现以下情况：(1)异地或原籍无法办理你的落户；(2)人事局或人才中心将不予接收你的档案；(3)国有企事业单位无法将你录用为正式工作人员等。

3．户口请同学们自己持《户口迁移证》或《户口卡》及时至落户地办理相关手续（含升学学生）。

4．毕业后学校将依据就业协议书上档案转递信息或《报到证》上的单位将同学们的档案通过EMS邮寄，请大家及时落实档案是否寄到。如一个月后仍未收到档案，请及时致电学校档案馆（029-88492473）或关注“西工大档案馆”微信公众号，查询本人档案去向。

5．根据我省教育厅就业相关文件，非定向学生毕业后改派办理规定如下：毕业时已签约工作两年内（毕业后第二年的6月30日前），待就业三年内（毕业后第三年的6月30日前）可向学校就业部门提出改派申请。每人仅可改派一次。如果同学们在改派期限内找到了新的工作，请按照相关规定及时回母校办理。

6．学校学生职业发展指导服务中心电话：029-88494728，邮箱：[已脱敏:邮箱],咨询QQ：2873502225，QQ群：674810287，请同学们保存，有就业相关问题请联系我们。

亲爱的同学们，鹏程万里今日起，载誉归来意拳拳。希望我们的努力能使你感受到来自母校的关怀，让我们共同期待美好的重逢！

西北工业大学学生职业发展指导服务中心

二〇二二年三月十日
