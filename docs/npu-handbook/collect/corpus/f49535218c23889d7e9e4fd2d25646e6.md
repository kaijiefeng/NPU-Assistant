# 西北工业大学2026年研究生招生校园开放日期待你的加入！

为持续拓展优秀研究生生源，提升我校拔尖创新型人才培养质量，为“总师”型人才培养打好优秀生源基础，我校2026年研究生招生校园开放日（以下简称开放日）即将拉开帷幕。欢迎有意报考我校的同学们申请参加，让我们一起为国铸剑，逐梦苍穹！

## 一、报名条件

1. 主要面向综合表现优异的2027届本科生。
2. 遵纪守法，品行优良，无任何违法违纪受处分记录。
3. 身心健康，学风端正，具有较强的科研创新能力和学术实践能力，具有继续深造攻读研究生的愿望与潜质，对所报专业有浓厚的兴趣。
4. 学院要求的其他条件。

## 二、时间安排

- 报名时间：2026年6月25日——7月8日
- 活动时间：2026年7月10日——7月12日

具体时间由各招生单位自行确定。

## 三、报名链接

https://yjszs.nwpu.edu.cn/pp/#/summer-camp/master/declare/200875/index

## 四、活动形式

活动主要采取线下的方式开展，内容包括前沿学术论坛讲座、各学院招生宣介、导师面对面交流、重点实验室参观等。旨在引导学生全方位了解我校学科特色、科研平台、师资力量、就业趋势和校园文化氛围等。

## 五、其他事项

1. 开放日不收取任何费用，入选后须全程参与各项活动。开放日活动食宿由学校统一安排。
2. 营员申请材料务必真实有效，如有不实、弄虚作假，学校将取消其营员资格。

## 六、联系方式

咨询电话：029-88493042；官方微信：NWPU_YZB。

## 七、各招生单位活动安排（持续更新中）

各学院（航空学院、航天学院、航海学院、材料学院、机电学院、力学与交通运载工程学院、动力与能源学院、电子信息学院、自动化学院、计算机学院、数学与统计学院、物理科学与技术学院、化学与化工学院、管理学院、公共政策与管理学院、软件学院、生命科学与技术学院、外国语学院、马克思主义学院、集成电路学院（微电子学院）、网络空间安全学院、民航学院、无人系统技术研究院、柔性电子研究院、光电与智能研究院）分别公布了申请日期与具体信息网址，申请日期集中在2026年6月25日至7月8日之间，详情见各学院页面。
