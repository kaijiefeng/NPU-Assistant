# 管理学院2026年本科生转专业录取结果公示

根据《西北工业大学本科生转专业（大类）实施办法》（办转教字〔2022〕24号）《西北工业大学本科生转专业实施办法》（校教字〔2025〕180号）《关于2026年本科生转专业工作安排》的通知要求，学院组织开展了2026年本科生转专业工作。
按照《西北工业大学2026年本科生各专业转专业接收人数和考核办法一览表》接收条件和考核办法，学院组织开展面试工作并择优确定了拟录取名单。现将结果予以公示（见附件），公示期为即日起三个工作日。公示期间，若有异议，请以书面形式向转专业工作小组反映。
