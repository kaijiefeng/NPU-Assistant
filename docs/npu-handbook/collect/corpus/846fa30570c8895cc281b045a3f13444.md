# 【学术报告】研究生出国（境）交流项目系列报告——魏楷宗：在德国马普所探索野生小家鼠性别差异的分子机制

报告时间：2025年12月1日（周一）下午19点
报告地点：长安校区生态环境学院B109
报告人简介：
魏楷宗，生态环境学院2023级硕士生，师从张文宇教授，研究方向为进化基因组学，主要进行野生小家鼠群体的基因表达进化研究，迄今为止共发表学术论文2篇，其中以第一作者发表1篇。
项目概况及报告内容：
受西北工业大学国际化领军人才培养项目资助，魏楷宗同学于2025年5月至2025年10月期间，在德国马克斯普朗克进化生物学研究所进行了为期6个月的访问学习，外方导师为Diethard Tautz教授。Tautz教授是一位享有国际声誉的进化生物学家，也是欧洲分子生物学组织（EMBO）院士和德国科学院院士，多年来一直致力于动物进化遗传学的研究，并在分子演化和群体遗传学等领域做出了多项重要贡献。截至目前，Tautz教授已在Nature、Science、Cell、PNAS等知名学术期刊上发表了300多篇论文，总引用次数超过43000次，其h-index高达96。
访学期间，该生在Diethard Tautz教授的指导下进行了野生小家鼠群体不同性别的基因表达分化以及性别偏向机制的研究。本次报告将从研究所概况、科学研究与日常生活等方面，介绍该生在德国马克思普朗克进化生物学研究所访学交流期间的收获和体会。
