# 管理学院在第三届中国研究生企业管理创新大赛中再创佳绩

11月7日-9日，2025年第三届中国研究生企业管理创新大赛总决赛在贵阳圆满落幕。作为由教育部学位管理与研究生教育司指导，中国学位与研究生教育学会、中国科协青少年科技中心主办，全国工商管理专业学位研究生教育指导委员会联合主办的国家级赛事，本届大赛竞争强度与参赛规模再创新高——共有全国150所高校的411支研究生团队参加总决赛。管理学院学子凭借扎实的专业素养与高效团队协作，最终获奖26项，更将赛道二的最高荣誉“见数实践奖”（全国仅设11项，获奖率低至1%）收入囊中，学校亦连续三届荣获“优秀组织单位”称号，彰显硬核育人实力。
本届大赛聚焦数智时代企业管理核心挑战，设企业决策赛道，商业分析与实践赛道，工商管理案例赛道和AI与数字技术应用专项赛道，对参赛团队的理论应用、数据洞察与解决方案落地能力提出了更高要求。我院在各赛道均展现强劲竞争力，实现“多点开花”。商业分析与实践赛道不仅斩获全国一等奖1项、二等奖5项、三等奖4项，更凭借“偶得三贤”团队的出色实践应用成果，赢得命题企业高度评价，成功拿下该赛道最高荣誉“见数实践奖”，团队指导老师卢亭宇亦获评“优秀指导老师奖”。企业决策赛道收获二等奖1项、三等奖5项；工商管理案例与数字技术赛道获二等奖和三等奖各1项；AI与数字技术应用专项赛道获二等奖2项、三等奖5项。
取得如此佳绩，离不开学校对此次赛事的高度重视，赛前筹备到赛中支持全链条保障。学校研究生院、管理学院精心部署，组建由资深教授、行业专家组成的指导教师团队，从选题论证、方案打磨到模拟答辩，为参赛学子提供全程专业化指导，学校专门成立了研究生企业管理创新大赛工作室，从动员宣传、指导培训、模拟赛事、专家评审、沟通协调等方面，积极组织对接，服务参赛师生，保障参赛师生以最佳状态迎战总决赛。
中国研究生企业管理创新大赛是全国研究生教育领域的重要赛事之一，旨在激发研究生的创新思维和实践能力，促进高校研究生教育与企业管理实践的深度融合。通过参与面向企业实际问题的大赛，让学生将理论知识与实践创新相结合，是管理学院培养学生成长为创新人才的重要途径。
