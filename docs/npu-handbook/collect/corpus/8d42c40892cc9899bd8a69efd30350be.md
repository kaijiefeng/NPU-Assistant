# 红色基因 蓝色情怀”力学与交通运载学院学生党员暑期社会实践纪实（六）

为高质量实施新时代立德树人工程，深入开展西北工业大学实践育人“三个一”暑期专项工作，引导青年学子立大志向、上大舞台、入主战场、干大事业，力学与交通运载工程学院在学工主管王涵晶老师、辅导员高晨光老师的带领下，组建“红色基因 蓝色情怀”主题实践队，开启了一场“触摸红色根脉、追寻领袖足迹、传承军工薪火”大学生暑期社会实践，教育引导青年学生党员在实践育人大课堂中，争做又红又专的“总师型”人才。
7月11日，实践队继续在延安开展“到延安去”西工大学子圣地行活动，走访多处红色地标，追忆革命岁月，传承红色精神。
上午，首先抵达杨家岭革命旧址开展参观学习，研学途中与航空学院实践队顺利汇合，两队学子相聚交流，共学红色历史、共悟革命初心。随后，队员们认真参观旧址场馆，了解老一辈无产阶级革命家在此办公生活、运筹帷幄的峥嵘过往，深切感受革命先辈艰苦朴素、坚守初心的崇高品格。
之后，队伍前往枣园革命旧址，实地聆听红色故事，探寻革命奋斗轨迹，大家围坐一起，开启了一场研讨会，积极探讨深入学习延安时期优良作风与奋斗精神的所思所想。
最后一站，队员们登临延安标志性地标宝塔山，俯瞰延安全貌，回望延安十三年革命光辉历程，也为本次实践画上了圆满的句号。
这个夏天，学院学生党员实践队用脚步丈量祖国大地，用内心感应时代脉搏。在革命旧址中追寻初心，在政企军营中积蓄担当。传承红色基因，不仅在理论学习中入脑入心，更在蓝色实践中见行见效。
此次暑期实践，是一堂生动的“大思政课”，也是一次深刻的“国情调研”。实践虽已落幕，但青春启航正当时。未来，学院青年学子将带着这份沉甸甸的收获，继续以红色精神为灯塔，以蓝色情怀为动力，筑牢信仰之基，练就过硬本领，让青春在全面建设社会主义现代化国家的火热实践中绽放绚丽之花。
