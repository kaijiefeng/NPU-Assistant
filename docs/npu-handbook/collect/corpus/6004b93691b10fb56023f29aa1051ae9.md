# 化学与化工学院召开2026届研究生毕业生代表座谈会

3月30日下午，化学与化工学院2026届研究生毕业生代表座谈会在学院楼258会议室召开，学院党委书记傅茂森、党委副书记姚东东、研究生辅导员马忠雷、潘富平以及15位优秀研究生毕业生代表参加。座谈会由姚东东主持。
毕业生们依次分享了在校期间的学习经历与收获感悟，对母校的悉心培养和老师的谆谆教导表示由衷感谢，并围绕仪器测试、就业实践、校企合作等方面提出了宝贵意见与建议。姚东东、马忠雷、潘富平分别结合自身经历分享了工作感悟，并对毕业生送上了诚挚寄语与美好期盼。三位老师叮嘱同学们在未来的人生道路上，始终保持求学时的严谨与热爱，心怀理想，脚踏实地，在各自的领域里发光发热。
傅茂森代表学院向顺利完成学业的毕业生表示祝贺，对同学们提出的意见建议逐一做出积极回应。他向毕业生提出三点殷切期望：一是心怀家国，做科技强国的先锋。希望大家把个人理想融入国家发展大局，把论文写在祖国大地上。无论继续深造还是走向岗位，都要以化学人的担当，为科技自立自强贡献力量。二是勇于创新，做破壁攻坚的勇者。希望大家永葆敢为人先的锐气，保持求真务实的作风，坚守学术诚信，在挑战中突破自我，让“总师育人文化”焕发新的光芒。三是脚踏实地，做行稳致远的行者。希望大家牢记“公诚勇毅”校训和“三实一新”校风，保持务实作风，苦练过硬本领，不驰于空想、不骛于虚声，在实干中成就事业、实现更好发展。
