# 校长宋保维到重庆科创中心调研

11月5日下午，校长宋保维到重庆科创中心调研指导工作，副校长张开富、两江新区管委会副主任皮涛等陪同。
中心执行理事、首席科学家李金山教授陪同参观了中心展厅与实验室及孵化企业重庆两航金属，重点就中心建设发展整体情况、产业化工作及下一步工作方向做了汇报。
宋保维对中心取得的成绩表示肯定。他指出，中心立足重庆，积极开展人才引进、科研平台建设和科技成果孵化，起到了较好的示范带头作用。
宋保维要求，中心下一步要加强整体谋划和提前布局，落实校地协议，厚植优势功能，实现高质量发展，更加积极主动融入成渝双城经济圈建设，以中心高质量发展助力地方经济社会发展和学校“双一流”建设。
学校办公室、资产公司和重庆科创中心相关部门负责人参加活动。
