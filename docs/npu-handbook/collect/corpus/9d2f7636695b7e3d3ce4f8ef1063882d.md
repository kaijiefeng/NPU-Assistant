# 校工会学习贯彻习近平总书记在庆祝中华全国总工会成立100周年暨全国劳动模范和先进工作者表彰大会上的重要讲话精神-校工会（帮扶办）/ 妇女联合会

4月30日，校工会组织学习贯彻习近平总书记在庆祝中华全国总工会成立100周年暨全国劳动模范和先进工作者表彰大会上的重要讲话精神，会议由工会常务副主席陈建军主持。
习近平总书记的重要讲话，高度评价了100年来党领导的中国工人运动的光辉历程和伟大成就，充分肯定中国工人阶级和中国工会在党和国家事业发展全局中的地位和作用，深刻总结工运事业和工会工作的宝贵经验，对我国工人阶级和广大劳动群众奋进新征程、建功新时代寄予殷切期望，对做好新时代新征程工会工作提出明确要求。
全体工会干部要认真学习习近平总书记重要讲话精神，深刻认识新征程上工会工作面临的新要求、新使命、新担当，要坚持正确的政治方向，把广大教职工紧紧团结在党的周围，坚决扛起引领教职工听党话、跟党走的政治责任，要坚持以教职工为中心的工作导向，竭诚服务广大教职工，要深化工会改革和建设，不断增强引领力、组织力、服务力，脚踏实地、奋发进取、拼搏奉献，用创造拥抱新时代，以奋斗铸就新辉煌，奋力谱写中国特色世界一流大学建设新篇章。
