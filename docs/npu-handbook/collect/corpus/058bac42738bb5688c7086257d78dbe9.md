# 对症对标巧应聘，我材必用有秘诀——段纪军研究员为青年学子讲授就业成才安全发展实务

近日，中国船舶集团资深管理专家，七六〇所原党委书记兼副所长，中国船舶集团天津公司（“华北局”）原董事、总经理、党委副书记段纪军研究员受邀做客翱翔名家讲堂，为师生作《对症对标巧应聘，我材必用有秘诀——大学生就业成才安全发展实务》专题报告。报告会由航海学院党委副书记王银涛主持。
段纪军从当前大学生就业形势切入，指出求职不能“一份简历走天下”，而要对标岗位能力素质要求，找到自身专业、经历、特长与岗位的契合点。他结合中船集团等大型国企、科研院所的选人用人实践，讲解简历撰写、面试表达、职业选择中的常见问题，强调“我材必用”的秘诀不在空想，而在主动对标、持续积累，在实干中形成不可替代的竞争力。
段纪军围绕“就业成才安全发展”，从求职安全、职业发展安全、廉洁从业安全、保密安全等维度，用真实案例提醒同学们警惕虚假招聘陷阱。他勉励青年学子，成才不是一蹴而就的，要在耐得住寂寞、经得起锻炼，到国家重点行业、关键领域建功立业。
交流互动环节，段纪军就国企应聘、职业发展、专业对口与跨界成长等问题为同学们答疑解惑。他谈到，就业是人生新起点，既要脚踏实地、守住底线，也要服务国家战略，以“对症对标”智慧求职、以“我材必用”自信成才、以“安全发展”理念走稳人生路。
此次报告会不仅是一堂就业指导课，更是一次面向国家重大需求的职业引领。希望青年学子以段老师为榜样，把个人成长融入国家发展，在强国建设、民族复兴新征程中贡献青春力量。
