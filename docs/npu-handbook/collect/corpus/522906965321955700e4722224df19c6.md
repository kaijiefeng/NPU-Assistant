# 电子信息学院赴西北工业大学哈萨克斯坦分校开展招生宣传工作

为深入贯彻落实习近平总书记重要指示精神，加快建设西北工业大学哈萨克斯坦分校（以下简称哈分校），2024年8月，电子信息学院高度重视，在学校国际合作处、国际教育学院、西北工业大学哈萨克斯坦分校的统筹安排和指导下，学院于八月上旬和下旬，由电子信息学院姚如贵副院长带队、院长助理秦雨潇、学院教师刘自成教授、范西昆副教授组成招生团队，分两批次赴哈分校开展2024 级信息与通信工程硕士研究生招生宣传工作，同时赴华为、中兴等在哈中资企业走访调研，深化开展校企合作。
积极开展哈分校招生工作
八月正值哈分校招生的关键时期，学院教师招生团队全力以赴，以高度的责任感、使命感投入哈分校的招生工作，在哈分校进行了细致的面对面宣讲咨询活动，为意向学生全面介绍了哈分校项目特色、招生政策以及电子信息学院的学科特色、人才培养、学生就业及未来发展等内容，吸引了众多学生及家长前来咨询，耐心细致地解答了学生及家长关注的问题，提供了一线指导和服务。
与在哈中资企业开展哈分校校企共建
在哈期间，团队拜访了新落成的中兴哈萨克斯坦分公司，结合分校人才培养目标，与分公司负责人进行了座谈交流。针对分校的建设目标，充分了解了企业人才诉求，深入探讨合作机制，双方达成了企业实习实践、共同开展科研交流的意向。
随后，团队还拜访了华为阿拉木图分公司，与分公司负责人、人力资源负责人进行了深入的交流。分校建设之初，就与在哈华为公司积极对接，前期在华为的大力支持下，已落成5G/5.5G通讯实验室等校企合作平台，接收了一批华为捐赠的用于科研教学的设备。此次拜访华为，双方就新入学哈分校学生的共同培养、实习实践、5G 实验室的建设工作等方面进行了深入细致的交流，为哈分校信息与通信工程硕士研究生培养做好资源保障工作。
与哈国大筹划开展学科论坛
在哈期间，学院还与哈萨克国立大学科学研究院、哈萨克国立大学物理与技术学院积极对接，双方就深入开展科研合作达成了重要共识，并计划于9月在哈国大共同举办信息与通信工程领域学科论坛。目前，双方已就论坛的具体时间、地点以及参与学者等关键细节交流了初步意见，将于近期继续推进论坛筹备工作。
电子信息学院作为哈分校的重要培养单位之一，高度重视哈分校建设工作，未来将继续以习近平总书记重要指示精神为指引，紧密跟随学校战略部署，以高度的责任感和使命感，聚焦哈分校招生宣传、人才培养、科研合作等各项工作，全力以赴执行好培养单位的各项职责，为培养中哈友好事业接班人贡献力量。
