# 【关工委工作】我校召开关工委成员单位工作会议

4月2日上午，我校在友谊校区健翔楼会议室召开关工委成员单位工作会议。副校长、校关工委主任孔杰，校关工委主任陈建有，委员黄迪民、王友明，校关工委秘书长赵洪章以及关工委成员单位负责人参加会议。
校关工委副秘书长马俊围绕党建带关建、“五老”作用发挥、思政引领、红色基因传承、教育帮扶、心育美育、家校社共育等方面介绍了关工委2025年重点工作以及2026年工作要点。
各成员单位负责人对工作要点进行研讨交流，并提出修订意见。会议审议通过《西北工业大学关工委2026年工作要点》。
与会人员结合分管工作，围绕思政教育延伸、心理健康帮扶、招生宣传融入、校史挖掘编撰等联动切入点进行了深入交流研讨。
陈建有谈到，过去的一年，各成员单位充分发挥职能作用，积极为“五老”作用发挥创造条件，在助力青少年成长成才、弘扬“总师育人文化”、营造良好校园氛围等方面发挥重要作用。希望各成员单位主动谋划、发挥优势，形成特色经验做法，为学校育人工作和总师育人文化建设贡献更大力量。
孔杰充分肯定了“五老”在关心下一代事业中的无私奉献和责任担当。要求校关工委一是提高政治站位，充分认识关心下一代工作的重要意义，服务好学校“十五五”发展大局。二是抓住工作重点，充分发挥“五老”独特优势，传承弘扬“总师育人文化”；三是建好工作平台和阵地，持续深化“五老助五育”实践探索，筑牢青少年信仰根基；四是进一步推进工作协同机制，加强沟通协调，密切配合，凝聚关心下一代工作合力，推动工作高质量发展。
