# 【求职故事】服务员月薪万五？当心上当

网上看到“高薪”招聘要小心了！
“高薪招聘模特，日薪600元起；优秀促销员，收入400元/天；服务员，月薪15000元……”这类招聘广告在网站上和各中介广告上异常活跃。然而，据记者调查发现，这些所谓的“高薪”招聘背后却暗藏着陷阱，求职者打醒十二分精神，提防上当受骗。
骗术一：职位和待遇前后大相径庭 某公司招聘兼职店员，打出“日薪300元/天”的广告。小张前去报名，对方却告知此职位已经招满，继而推荐他到其他公司工作，但待遇却与广告上的宣传相差很多，而且，还得收取“会员费”。
骗术二：先培训后上岗 王小姐看到一份招聘兼职模特的信息，承诺薪金600元/天，可是当王小姐赶到中介公司后，对方却硬性要求她先拍摄一组照片，并收取几百元的费用。
骗术三：变相推销公司产品 阿文本来应聘的是推销员岗位，一天的报酬是400元。但他到了公司以后，对方却以公司员工必须熟悉本公司产品为由，硬性要求阿文购买数百元公司产品。
骗术四：利用虚假公司招聘 小峰在网上看到某“大型连锁”餐饮公司发布的服务员招聘信息，月薪15000元，让他填写完整的个人应聘资料，并要交报名费500元。
薪酬高得离谱要小心
专家提醒，求职者在应聘时，首先要仔细掂量一下薪酬标准是否合理，如果过于偏离实际水平，就要提高警惕了。
切莫轻信街头小广告和网上一些所谓的招工信息。正规公司一般会在一些权威报纸发布招聘信息，求职者需多加辨别。还可以通过政府开办的职业介绍机构或者知名的营利性中介机构求职。
应聘时，一定要去公司实地看看，要直接找到招聘方的办公室和具体负责人，问明情况、探明虚实后再作决定。
一般情况下公司不会用电话面试，一般是面对面进行面试，也不会在公司所在地之外的地点进行面试。求职者不要轻易汇钱，尤其是遇到只闻其声不见其人的情况，务必格外小心，以免上当受骗。对于交纳保证金、入会费的要求，切不可盲目缴费，一定要查清楚招聘单位主体的合法性和经营范围，审核他们的资格，为自己维权提供有力证据。
