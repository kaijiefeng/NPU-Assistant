# 党委保卫部在我校第二十一届体育文化节暨“颜贻梯杯”第58届运动会中取得佳绩

10月25日-26日，西北工业大学第二十一届体育文化节暨“颜贻梯杯”第58届运动会在两校区举行。党委保卫部职工们热情高昂，参与积极性高，取得了较好的比赛成绩。
运动会期间，虽然天气忽晴忽雨，但丝毫不影响选手的现场发挥，由于日常体能训练扎实，党委保卫部的选手们在比赛中充分体现出了体能素质上的优势，他们身姿矫健，反应敏捷，为了集体的荣誉努力奋斗。经过一番角逐较量，孙立宾同志荣获教工男子1500米甲组第一名，弓雪雪同志获得教工女子铅球甲组第一名，蒋媛同志获得教工组女子50米自由泳(45岁以下组) 第一名，王敏同志获得教工组女子50米蛙泳(45岁以上组) 第二名，刘志浩同志获得教工男子铅球甲组第二名，葛天赐同志获得教工男子甲组100米第二名。
为了做好运动会期间的安全保障工作，党委保卫部不设运动员代表队，职工通过轮岗的形式自主参与比赛，部分选手在参赛项目结束后立即归岗执行保障任务。选手们在赛场上奋力角逐，归岗后执勤一丝不苟，齐心协力维护好运动会期间校园秩序，体现了团结协作、爱岗敬业的精神风貌。
运动会不仅丰富了教职工的业余生活，也培养了职工顽强拼搏、积极向上的体育精神，激励着教职工从中华体育精神中汲取精神力量，将赛场上的顽强斗志转化为工作动力，更好的投入日常工作。
