# 机电学院关于临时监考人员的要求

1.临时监考人员基本条件：工作认真负责，本校正式在职教职工，主要以教师和实验技术人员为主，有监考经验者优先。
2. 临时监考工作主要为重修和补考，监考教师接受监考任务后，按照学院教学办下发的监考通知提前15分钟到达考场并整顿考场秩序，履行监考职责；中途不得随意换人。
3. 考试结束后三天内，监考教师需将监考通知书和考场记录单返回学院教学办。
4. 原则上不允许监考老师私自调换监考，因故无法监考的，须提前两天到学院教学办办理调换手续。
