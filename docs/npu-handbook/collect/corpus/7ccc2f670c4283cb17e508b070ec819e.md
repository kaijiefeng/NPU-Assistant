# 第五届中国创新挑战赛（宁波）暨2020年宁波企业技术创新需求对接活动企业技术需求公告

为深入实施创新驱动发展战略，加快科技成果转化落地，贯彻落实《国家技术转移体系建设方案》（国发〔2017〕44号）精神，根据《科技部火炬中心关于开展第五届中国创新挑战赛申办工作的通知》（国科火字〔2020〕77号）的有关部署，2020年科技部火炬中心会同宁波市科技局共同承办第五届中国创新挑战赛（宁波）暨2020年宁波企业技术创新需求对接活动，挑战赛以解决企业技术需求为目标，面向社会公开征集解决方案，通过“挑战”、“比拼”等方式，择优确定技术需求解决方案。
经征集、诊断，宁波市已遴选了100项本地企业急需解决的技术需求面向全国公告，寻求挑战者。其中，重点需求10项，设置了“关键共性技术需求”和“新兴产业技术场景应用需求”两类重点需求（两类合并称为重点需求）；个性化企业技术需求90项。
校内有意向的科研团队可根据通知要求参加挑战赛，宁波研究院负责做好服务工作，联系人：程翔，电话：0574-27965050，手机：18667896663
