# 航空学院2026年暑期校园开放日暨研究生招生宣传活动成功举行

为深入贯彻落实“总师育人文化”内涵，夯实航空领域创新人才培养根基，西北工业大学航空学院于7月10日-11日举办了2026年暑期校园开放日暨研究生招生专项宣传活动。本次活动吸引了全国各地多所高校的60余名优秀本科生齐聚校园，搭建起青年学生与学院科研团队面对面深度沟通交流的桥梁，打通了优质生源与学院人才培养体系精准对接的渠道。
7月10日上午，航空学院副院长韩忠华作专题宣讲，围绕学院历史传承、人才培养、师资队伍、平台建设、科学研究等方面的优势和特色，对学院研究生的培养状况和未来成长发展做了深入解读。航空器设计工程系李冰教授、综合技术与控制工程系喻天翔教授、飞行器空气动力学系许和勇教授、航空结构工程系杨扬副教授以及极端力学研究院秦飞飞副教授分别介绍了各系团队情况。学院硕士生时睿婕、梁颢天作为优秀学生代表进行了分享。
随后，参会学生依据自身科研兴趣自主分组，走进全国重点实验室和各科研团队，与导师面对面深度交流。各位导师现场细致答疑、分享一线科研经历，同学们围绕专业难点、读研规划、课题选择等问题积极提问。全方位的双向交流让学生们近距离感受到了学院的学科实力与育人文化，对相关学科的发展前景有了更直观的认识。
本次暑期开放日暨研招宣传活动圆满开展，不仅让全国各地优秀学子沉浸式感受到学院严谨浓厚的治学科研氛围，也搭建起学院与青年学子双向了解、双向选择、共筑航空理想的沟通平台。立足航空报国使命、厚植航空报国情怀，学院将持续健全招生服务保障体系，不断完善高层次创新人才培养机制，为青年学子攀登科研高峰提供全方位支撑。
