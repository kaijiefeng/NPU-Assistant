# 西北工业大学医院就诊须知

一、就诊时间

（一）友谊校区医院：

1. 冬令时（10月1日至次年5月1日）：周一至周五上午8：00-12：00，下午14：00-17：30；
2. 夏令时（5月1日至次年10月1日）：周一至周五上午8：00-12：00，下午14：30-18：00；
3. 急诊全年无休，急诊科电话：029-88491120。

（二）长安校区医院：

1. 周一至周五上午9:00-12：00，下午13：30-16:50；
2. 急诊全年无休，急诊科电话：029-88430120。

二、挂号及缴费

1. 手机智慧医院和自助机：所有患者均为挂号平诊2元，急诊3元；可在智慧医院或院内自助机缴费，暂无法在线使用医保结算。
2. 人工窗口：
（1）大学生：挂号平诊2元，急诊3元，参加大学生医保的同学可在窗口直接报销结算，或先行全额缴费后，到医保窗口进行报销。
（2）教职工：不使用医保卡挂号为平诊2元，急诊3元，使用医保卡挂号为友谊校区医院平诊6.5元（统筹支付3.5元），急诊9.5元（统筹支付4.5元）；长安校区医院平诊5元（统筹支付3元），急诊7.5元（统筹支付4元）。可在人工窗口进行医保结算。推荐使用智慧医院挂号，就诊结束后在人工窗口进行医保结算。

三、大学生医保

根据市医保发[2023]24号文件规定，2023年9月入学的新生及未缴纳上一年度大学生医保的在校学生，在学校规定的统一缴费期内缴纳2023年（2024年度）大学生医保费用，经税务和市医保中心两部门审核通过后，待遇享受期自2023年9月1日起至2024年12月31日。上一年度正常参保的老生，医保待遇享受期自2024年1月1日至2024年12月31日。

门诊医保待遇享受期内所产生的费用（在医保范围内）医保报销70%，个人支付30%。一个年度最高限额为500元。

校医院已实施门诊直报系统，正常参保学生凭身份证原件在我院（长安及友谊校区医院）门诊就医，在两校区校区医院人工收费窗口进行交费，可直接享受医保相关待遇，无需二次报销。因各种原因未能直报的，可凭身份证原件、发票联到两校区医院医保办进行报销。

需要到西安市校外医院门诊就诊的同学，须经校医院医生根据病情研判后开具转诊申请单，到定点医疗机构就诊，持身份证原件、转诊单、发票联、门诊病历、门诊费用清单及各项检查报告单复印件，回我院审核报销。

在西安市定点医疗机构住院就医的同学，持身份证原件至医保窗口办理住院手续，出院时直接办理医保结算手续，无需回学校报销。

友谊校区医保办联系电话：029-88492549；正常工作日：8：00至12：00，下午14：30—18：00（夏令时），14：00—17：30（冬令时）。

长安校区医保办联系电话：029-88431194；正常工作日：上午9：30至15：30（中午不休息）。
