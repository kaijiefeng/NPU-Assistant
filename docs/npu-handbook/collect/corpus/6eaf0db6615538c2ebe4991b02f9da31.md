# 弘扬教育家精神 勇担强国使命 —学校第六期高层次人才国情教育研修班在汉中顺利举办-人力资源部

为进一步弘扬教育家精神，深度拓展校企全方位协同合作，4月28日至29日，学校党委教师工作部、党委统战部、工会组织我校30余名教师赴汉中开展第六期高层次人才国情教育研修。本次研修以校史铸魂、红色引领、产学研融合为主要内容，在实地研学中引导高层次人才厚植家国情怀、扛起强国使命、勇担时代重任。
在开班仪式上，党委教师工作部副部长林楠介绍了本次国情研修的目的和意义，希望全体参训教师潜心研学、深入思考、积极交流研讨，真正将研修所学、所思、所悟转化为深耕立德树人主业、服务国家重大战略需求的实际行动。
4月28日下午，参训教师首先前往城固县博物馆，系统了解汉中深厚历史文化底蕴，以及西北联大在抗战期间扎根秦巴、赓续民族文脉、艰苦办学的教育史诗，从中深刻感悟教育救国、兴学强国精神；随后走进西北工学院旧址，实地踏访先辈办学足迹，重温烽火岁月中“坝上长夜、七星灯火”的学习景象，深刻感悟“公诚勇毅”校训的时代内涵。当晚，全体人员集体观看影片《古路坝灯火》，在光影中回望办学艰辛，汲取精神力量。
4月29日上午，研修班走进中航工业陕西飞机工业（集团）有限公司，深入生产一线参观调研，与企业技术骨干、相关负责人座谈交流，对接产业发展需求，深挖校企协同潜力，共谋学术研究与国家重大工程、航空强国建设深度融合。下午，全体人员前往川陕革命根据地纪念馆，通过馆藏文物与珍贵史料，重温川陕苏区军民攻坚克难的奋斗历程，传承革命精神，接受革命传统教育，持续厚植矢志报国、担当奉献的深厚爱国情怀。
此次国情研修进一步加深了参训教师对校史传承、国家使命与行业需求的深刻理解，参训教师纷纷表示，本次研修内容丰富、意义深刻，未来将把研修所学所悟融入教学科研工作，立足岗位、瞄准国家战略急需，在教育强国、科技强国、人才强国建设中展现西工大高层次人才的担当与作为，为实现学校“一十百千”发展目标和“天下工大、世界三航”远景目标贡献更大力量。
