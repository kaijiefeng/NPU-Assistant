# 西北工业大学哈萨克斯坦分校正式启用

西工大新闻网10月13日电（文字 潘子祺 摄影 周军平)在“一带一路”国际合作高峰论坛即将举行之际，为积极落实中国-中亚峰会成果，扎实践行“一带一路”倡议。10月12日，西北工业大学哈萨克斯坦分校在阿拉木图市正式启用，标志着中国第一所高水平大学在“一带一路”首倡之地正式开始办学。
启用大会在“阿里·法拉比”哈萨克斯坦国立大学（以下简称“哈国大”）图书馆大厅举行。哈萨克斯坦总统顾问奥塔尔巴耶夫，哈萨克斯坦科学和高等教育部副部长塔尔格特，中国驻阿拉木图总领事蒋薇，我校党委书记、中国工程院院士李言荣，“阿里·法拉比”哈萨克斯坦国立大学图伊梅巴耶夫·詹森特·坎森图雷，哈萨克斯坦萨达巴耶夫大学、哈萨克国立农业研究大学、纳克索兹大学等单位校领导，中石油、中国有色、华为等中资企业代表，中哈双方相关学院、职能部门负责人及分校首批新生等出席分校启用大会。
启用大会上，李言荣代表西北工业大学向关心支持分校发展的中国驻阿拉木图总领馆、哈萨克斯坦科学与高等教育部、中资企业等表示衷心感谢。他指出，哈萨克斯坦是“一带一路”的首倡之地，分校启用是落实中哈两国元首会晤成果的具体行动和有益实践，意义重大。
李言荣对分校发展提出了三点设想，一是以人才培养为抓手，推动两国教育模式深度融合；二是以硕士培养为切口，推动高水平办学；三是以人才培养为桥梁，推进科研合作协同创新。在发言中，他寄语新同学，希望同学们成为融通中哈教育精髓、掌握新技术的好青年；希望同学们积极互学互鉴，成为中哈交流的友好使者；希望同学们增强学习本领，努力成为未来的栋梁人才。最后，他说，期待双方携手努力，为分校发展开辟更广阔的前景。
图伊梅巴耶夫对李言荣一行表示热烈欢迎。他指出，作为中国在哈萨克斯坦成立的第一所分校，哈方高度重视，希望持续完善分校教学体系，促进两国青年人才交流共进，推动中哈教育合作交流迈向新高度。
奥塔尔巴耶夫致辞表示，哈国大在哈萨克斯坦高校中具有重要的地位，西工大是中国工科实力强劲的高水平研究型大学。分校合作得到双方的大力支持，希望分校建设进一步促进各领域的合作，推动中哈友谊再上新台阶。
蒋薇代表中国驻阿拉木图总领馆对分校成功落地表示热烈祝贺，她指出，为响应两国元首在中国-中亚峰会上的重要提案，在两国主管部门的大力支持下、两校领导周密部署，仅用5个月时间将分校由蓝图变为现实，为即将举行的第三届“一带一路”国际合作高峰论坛献上了一份特殊的“礼物”，切实助力中哈务实合作高质量发展。
随后，入学新生受颁录取通知书，标志着分校第一批新生正式入学。
录取通知书颁发后，李言荣、蒋薇、塔尔格特、图伊梅巴耶夫和奥塔尔巴耶夫共同为分校揭幕。
启用会前，两校签署了全面合作办学备忘录，明确培养方案、教学安排、管理机制等方面系统合作，全力保障分校高水平办学。
启用会后，李言荣、蒋薇、塔尔格特、图伊梅巴耶夫、奥塔尔巴耶夫为分校剪彩，并参观了分校。
据悉，首届中国-中亚峰会期间，在中哈两国元首见证下，西北工业大学哈萨克斯坦分校合作框架协议正式签署。分校建设自签约伊始就按下“快进键”，跑出“加速度”，5个月内双方校领导会晤4次，西工大50余人次出访哈国大，高效完成培养方案、校舍选址、教学计划等准备工作，并在“一带一路”国际合作高峰论坛举办前夕，迎来首批新生入学，这将促进中哈两国教育合作，推动构建更加紧密的中国—中亚命运共同体，助力高质量共建“一带一路”。
（审核：张富利 马西平）
