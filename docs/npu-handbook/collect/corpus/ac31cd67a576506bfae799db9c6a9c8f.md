# 关于开展2025年度西北工业大学教育教学改革研究项目申报工作的通知

各单位：
为贯彻落实党的二十届三中全会、全国教育大会和学校第十四次党代会精神，进一步落实立德树人根本任务，全面深化教育教学改革，提高教师教学水平，提升“总师型”人才培养质量，根据《西北工业大学教育教学改革研究项目管理办法》（校教字〔2022〕32号），学校决定开展2025年度西北工业大学教育教学改革研究项目（以下简称“教改项目”）申报工作，请各单位认真组织申报。现将有关事项通知如下：
一、立项范围
（一）立项范围。教改项目聚焦“总师型”人才培养，立项主要范围：人才培养模式、课程体系、教学内容、教学方法与教学手段，创新教育，实验、实习、实训和社会实践，教学资源共享、教学管理信息化、教学质量保障、国际化人才培养等方面的改革研究与实践。
（二）项目选题需参照《2025年度西北工业大学教育教学改革研究项目选题指南》（附件1）。
二、申报类别
教改项目申报类别分为重点攻关、重点、一般三种。
（一）重点攻关项目指由学校主导的，以解决近期或当前人才培养过程中具有全局性、综合性的重点、难点或热点问题为目标，对推进教育教学改革有重大影响，有较好的研究基础，可望取得重大成果，并有较高推广、应用价值的研究项目。
（二）重点项目指以解决当前学校人才培养过程中的重点、难点或热点问题为目标，对推进学校教育教学改革有较大影响，能取得实质性成果，并有较高应用价值的研究项目。
（三）一般项目指以解决具体问题为目标，根据教学单位（部门）教育教学改革需要而进行的实践周期短、受益面聚焦的研究项目。
三、指标分配
教改项目实施限额申报。项目申报限额由基础指标和导向指标综合测算后确定，各单位申报限额见附件2。其中基础指标依据学院在岗教职工人数测算，导向指标按照坚持向本科教学一线教师倾斜的原则，依据学院为本科生课程授课情况、人才培养质量、已立项教改项目建设情况等测算。
四、申报要求
（一）项目选题应紧跟国家教育教学改革发展趋势，重点围绕学校教育教学发展，尤其是教学工作中亟待解决的重点、难点和热点问题，或重大、迫切、实际问题，对学校教育教学改革与发展具有理论指导意义和应用推广价值。
（二）项目要有一定的理论基础与实践性，在提高教学质量、加强教学管理和人才培养工作改革等方面有较高的应用价值。
（三）项目前期论证充分、目标明确、思路清晰、重点突出，研究计划可行，且已具备按计划开展研究的各项基本条件。
五、申请资格与限项规定
（一）项目主持人须为学校在岗教职工。
（二）项目主持人限1人，项目参与人原则上不超过4人（不包含主持人）。鼓励校内跨单位组建研究团队。
（三）项目主持人同年度限申报1项，且作为其他项目组成员限参与不超过1项；项目组成员同年度限参与不超过2项。
（四）项目主持人限主持在研项目为1项。结题当年，可以申请下一年度项目，如果后续结题通过，新申请项目与同批项目进入立项与否的审批程序。
六、项目管理
（一）项目建设周期原则上不超过两年，确有特殊原因需要延长研究时间，须由项目负责人以书面形式向学校申请，待审批同意后方可延期。
（二）学校对获准立项的项目实行中期检查制度，各单位应加强研究过程的管理与督促，项目所在单位应创造条件，为研究项目提供便利与支持，保证项目研究工作的顺利进行。
（三）项目按研究计划完成研究任务后，学校组织专家组对项目进行结题验收，项目组需提供项目研究总结报告和相关研究成果等材料，结题验收结果分为优秀、良好、合格、不合格四个等级。
七、经费支持
（一）学校对立项的教改项目进行专项经费资助，其中重点攻关项目6万元/项、重点项目3万元/项、一般项目1.5万元/项，分两年期进行支持。
（二）项目主持人应根据实际需要编制科学合理的经费预算，项目经费使用需严格遵守国家和学校的相关财务制度，不得用于与项目研究无关的开支。
（三）项目经费分为教务部“全额资助”及项目“经费自筹”两种方式，其中申请“经费自筹”的项目，将增设评审指标，设置专门赛道。
八、其他要求
（一）申报材料不能涉及保密内容。
（二）申报书填报内容真实，不存在任何知识产权问题。
（三）项目需要根据定位准确选择申报类别（重点攻关、重点或一般）。
（四）获准立项的校级教改项目将作为推荐参与省部级及以上教改项目的候选项目。
九、材料提交
（一）在线申请。各项目主持人通过教学研究项目管理评审服务平台提交立项申报书（附件3，签字完整版PDF文件），登录路径为：翱翔门户-翱翔教务-快速通道-教学研究项目管理评审服务平台-进入工作台-在线申报-2025年度西北工业大学教改项目申报。
（二）单位审核。各项目主持人在线提交后，由项目所依托单位按要求和工作流程进行线上审核，单位审核完成后需将申报汇总表纸质版（附件4，一式1份，签字盖章完整版）和电子版word文件报送至教务部，汇总表信息与系统填报信息须保持一致。
（三）申报时间。在线申请、单位审核、材料报送截止时间均为2025年1月3日（星期五），逾期不予受理。
（四）请各单位高度重视，提前自行组织遴选推荐工作，确保申报项目质量。
