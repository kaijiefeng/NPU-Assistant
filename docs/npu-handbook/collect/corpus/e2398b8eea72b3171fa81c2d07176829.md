# 电子信息学院师生赴中国电子科技集团第二十九研究所开展实践研学

近日，西北工业大学电子信息学院近20名师生赴中国电子科技集团第二十九研究所（简称“29所”），开展“红色基因，蓝色情怀”专项实践活动。此次实践旨在引领青年学子走进国防军工单位，感悟“国家利益高于一切”的军工信仰，将专业认知与使命担当深度融合，引导青年一代在强国强军征程中找准坐标、砥砺前行。活动由学工主管程姣姣、辅导员解宇带队。
座谈交流会上，29所专家与校友代表出席本次座谈会，通过介绍师生们全面了解了29所发展概况、人才招聘政策及职业发展通道等内容。在自由交流环节，多位在29所工作的西工大校友结合自身成长经历，从工作内容、工作氛围、行业发展等方面与学弟学妹们展开了深入交流。校友们谈到，在29所从事相关工作，需要将理论知识与工程实践紧密结合，更需要奉献和担当精神。他们勉励同学们将专业能力与军工情怀相结合，为国防事业发展贡献力量，并详细解答了学弟学妹们在就业选择、职业规划、学业发展等方面的困惑。
会前师生们参观了29所展厅，了解到29所为国防建设作出的卓越贡献，师生们深受震撼，对“国家利益高于一切”的军工精神有了更加直观而深刻的理解。
走进29所，让我真切感受到了“团结、献身、求实、创新”的军工精神。29所的前辈们数十年如一日深耕军工领域，为国家筑起了一道无形的电磁长城。作为西工大学子，我们更应赓续红色血脉，将个人理想融入国家需求，在电子信息领域深耕笃行，为强国强军伟业贡献青春力量。
—2024级博士生奚贵鹏
此次赴29所的实践研学，是一堂“行走的专业认知课”，更是一次“触及灵魂的思政教育”。通过走进国防军工一线，不仅深化了我们对电子信息学科前沿的认知，更在亲身感受中厚植了家国情怀，引导我们青年学子在建设世界科技强国的征程中书写无愧于时代的青春华章。
—2025级硕士生王彩丽
