# 四川大学党委常委、副校长韩芳一行来校调研

11月21日上午，四川大学党委常委、副校长韩芳一行来校调研，我校党委常务副书记吕卫东参加座谈交流。校长助理兼后勤部党工委书记、后勤部部长王宇波主持座谈会。
吕卫东代表学校对韩芳一行表示欢迎，并介绍了我校办学特色、发展目标，以及后勤工作的基本情况。他表示，四川大学与我校具有独特的渊源与深厚的感情，在后勤综合改革方面有着值得我校借鉴的丰富经验和成功做法，希望两校能够以此次交流为契机，在后勤管理体制、服务模式等方面开展深入交流与合作，为学校发展和师生生活提供更加优质、高效的后勤保障。
韩芳表示，西工大近年来办学水平与社会影响力不断提升，尤其在“三航”特色和“总师育人文化”方面形成了独有的“西工大现象”，在国防科技领域做出重要贡献，相关经验做法值得学习和借鉴。她强调，此次调研交流，主要针对后勤领域，希望为“十五五”规划的科学编制提供重要参考，也为进一步深化后勤综合改革夯实基础。
座谈会前，韩芳一行参观了学校科技馆。
座谈会上，四川大学及我校后勤部、基建处等相关单位负责人进行了深入交流。会后一同参观了7号学生公寓和学生一食堂。（文字：蔺阳；图片：卢迪；审核：张文刚）
