# 红色基因 蓝色情怀”力学与交通运载学院学生党员暑期社会实践纪实（五）

为高质量实施新时代立德树人工程，深入开展西北工业大学实践育人“三个一”暑期专项工作，引导青年学子立大志向、上大舞台、入主战场、干大事业，力学与交通运载工程学院在学工主管王涵晶老师、辅导员高晨光老师的带领下，组建“红色基因 蓝色情怀”主题实践队，开启了一场“触摸红色根脉、追寻领袖足迹、传承军工薪火”大学生暑期社会实践，教育引导青年学生党员在实践育人大课堂中，争做又红又专的“总师型”人才。
7月10日实践队赴延安大学马克思主义学院、中国人民抗日军事政治大学旧址、延安革命纪念馆、梁家河等地深入学习红色历史，感悟革命精神，汲取奋进力量。
上午，一行人走进延安大学马克思主义学院，与团委书记闫莉莉、党委组织员苗玉园等30余名师生开展座谈交流。双方围绕学生党建工作建设、红色文化育人等内容进行深入探讨。“延安精神”贯通于学生培养的课程、实践、数字、文化等多个维度，特别就延安大学依托其作为延安精神发源地见证者与参与者的独特地位，形成的一套系统化红色文化教育特色情况开展了面对面交流学习，互相借鉴先进经验，拓宽工作与学习思路。热情的两校学子互赠“续红色血脉 育时代新人”书法作品与《延安故事》书籍。
随后，在扎根延安军营的红色讲解员郑班长的带领下，队员们走进中国人民抗日军事政治大学旧址参观学习，回顾抗大光辉办学历史，深切体悟艰苦奋斗、矢志报国的革命精神。
下午，队伍依次参观延安革命纪念馆与梁家河。在延安革命纪念馆中，延安驻军红色宣讲志愿者韩班长通过丰富的史料、图片与实物，让实践队员全面了解党中央在延安十三年的峥嵘岁月，深刻领会延安精神的时代内涵。
实践队员不少人也读过《习近平的七年知青岁月》、《梁家河》一书，如今身处在梁家河，大家追寻习近平总书记奋斗足迹，更深刻感受到书记扎根基层、脚踏实地、攻坚克难的实干精神。在知青旧居，土窑洞、煤油灯、老式农具静静陈列，这里是习近平总书记度过七年知青岁月的地方，现场实践队员系统了解了习近平总书记带领村民打坝淤地、修建沼气池、创办铁业社和缝纫社等改变梁家河面貌的务实举措。从梁家河的窑洞灯火到新时代的思想伟力，总书记七年知青岁月所彰显的理想信念、家国情怀、进取精神、吃苦耐劳的优秀品格，深深感染着每一位参观的学子。
本次“行走的大思政课”研学实践让队员们在体验式、场景化中感悟习近平新时代中国特色社会主义思想的真理伟力，接受了深刻的红色教育，进一步坚定了理想信念、锤炼优良作风，不断增强书写好中国式现代化青春答卷的使命与担当。
