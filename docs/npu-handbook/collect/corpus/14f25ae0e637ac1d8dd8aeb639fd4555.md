# 后勤部办公室党支部召开理论学习会暨深入贯彻中央八项规定精神学习教育总结会

9月26日上午，后勤部办公室党支部组织全体党员召开理论学习会暨深入贯彻中央八项规定精神学习教育总结会，会议由党支部书记张文刚主持。
会上，大家集体学习了《习近平总书记在纪念中国人民抗日战争暨世界反法西斯战争胜利80周年大会上的讲话》《习近平总书记关于锲而不舍落实中央八项规定精神，推进作风建设常态化长效化的重要指示精神》《弘扬伟大抗战精神，向着中华民族伟大复兴的光辉彼岸奋勇前进》等习近平总书记重要讲话精神以及《工业和信息化部召开的深入贯彻中央八项规定精神学习教育总结会精神》等内容。
接着，结合学习教育评估总结工作要求，党支部副书记韩争胜带领全体人员，再次学习了《党政机关厉行节约反对浪费条例》（以下简称《条例》）的主要内容，让党员们进一步深刻领会《条例》精神，准确把握规定要求。
最后，党支部书记张文刚对学习教育工作进行总结。他通报了学习教育开展以来的主要工作、对照查摆的突出问题及整改落实情况。他指出，支部全体党员要把学习贯彻中央八项规定及其实施细则精神，作为一项长期政治任务，推动作风建设常态化长效化。要将学习教育成效运用到后勤工作的方方面面，不断增强贯彻落实的政治自觉、思想自觉和行动自觉，持续营造风清气正的政治生态。（撰稿人：毛淑兰；审稿人：韩争胜）
