# 重庆科创中心关于申报2021年度川渝联合实施重点研发项目的通知

各有关单位：
重庆科创中心现转发重庆市科学技术局《关于申报2021年度川渝联合实施重点研发项目的通知》如下，请研阅，有意向申报的老师于6月10日前与重庆科创中心联系。
一、内涵定位
川渝联合实施重点研发项目旨在集聚川渝优势科技资源，共同推进区域协同创新，深入推进成渝地区科技创新合作计划。2021年度重点聚焦人工智能、大健康、生态环保、现代农业4个领域联合开展技术攻关。
二、申报要求
详见重庆市科技局官网通知：http://kjj.cq.gov.cn/zwxx_176/tzgg/202105/t20210525_9325884.html。
三、申报时间
申报时间为：2021年5月26日9：00—2021年6月15日18：00，重庆科创中心项目审核截止时间：2021年6月14日18时。
重庆科创中心
2021年5月26日
