# 离退休党委组织离退休党员干部观看电影《731》

9月18日上午9点18分，离退休党委组织离退休党员干部骨干开展“观影鉴史铭初心，离岗笃行葆本色”主题党日活动，集体观看电影《731》。离退休党委机关党支部全体党员一同观看。
离退休党员观影后深受触动，一致认为这不仅是历史的回顾，更是初心的再唤醒、使命的再接力。大家表示，将始终做到“离岗不离党、退休不褪色”，把对历史的深刻铭记，转化为优势作用的发挥，用银发担当践行党员使命。
（撰稿：李晓珊；摄影：穆扬；审核：马俊）
