# 对话总师（二）| 韩云：积跬步，守初心，志在长空万里

河洛大地，伊水之滨。为引领青年学子以榜样为镜、奋勇前行，5月20日，西北工业大学电子信息学院师生走进中国航空工业集团公司洛阳电光设备研究所（简称航空工业光电所），开展“总师专题访谈”活动。本次访谈嘉宾为我校1998届校友、光电所型号副总师韩云。二十七载深耕国防一线，从青涩学子成长为火控领域型号副总师，韩云结合自身经历，与在场师生畅谈成长历程、分享职业感悟。
一、目标是一步步走出来的
访谈从职业生涯起点展开，当被问及“成为总师的目标是何时建立的”，韩云坦言，学生时代的想法很朴素：把专业学扎实、把基础打牢固。目标并非一蹴而就，而是在工作中一步步明确的。
她回忆，刚入职时，单位每年都会评选劳动模范。那些劳模身上有一种特别踏实、较真的劲头，她便把他们当作榜样，仔细观察他们如何工作、如何解决问题，自己也照着去做。“有一天我突然想：我能不能也评上一次劳模呢？”于是，评上劳模成了她职业生涯的第一个小目标。在朝着这个目标努力的过程中，她不断积累经验、锻炼能力，后来又有了更大的目标——就这样一个台阶一个台阶地往前走，慢慢走到了副总师的位置。
她借此对青年学子提出建议：“不用一开始就想着做大事，先给自己定一个够得着的小目标，把眼前的每件事做好。榜样的力量会推着你往前走，目标也会在行动中越来越清晰。”
二、守住初心，放开手脚，一直学下去
面对电子信息、控制、光电等领域技术加速迭代，队员们纷纷请教：新时代青年应坚守哪些本心、锤炼哪些新本领。
对此，韩云给出了清晰解答。她认为，技术更新步伐越快，越要坚守从业初心与优良作风：踏实肯干、严谨尽责的态度不能丢，航空人“一次做对、一次做好”的职业准则更要始终传承。同时她建议青年主动锤炼三项能力：一是主动沟通，入职后切忌被动等待指导，多交流探讨才能厘清工程难题；二是大胆发问，不必顾虑问题浅显，多元思考与观点碰撞，正是技术突破的关键；三是坚持终身学习。她结合自身求学经历分享，工作后先后完成在职硕士、在职博士深造，坦言学习并非只为获取学历，而是紧跟技术迭代、适配型号研发的必然要求。
最后，她以十三字寄语勉励青年学子：守住初心，放开手脚，一直学下去。“航空报国的理想，正始于日复一日的点滴坚守与不懈奋进。”
三、系统思维是在实践中磨练出来的
“在校学习以理论知识为主，步入工程实践后，常会陷入单一技术问题的局限，难以站在系统全局层面思考问题，如何培养系统思维与全局意识呢？”
韩云解答道，培养系统思维的核心在于敢问、敢为、敢担当。开展工作时切勿局限于自身负责的模块，在完成本职任务之余，主动了解上下游环节与相关业务，探索工作延伸方向。系统思维并非与生俱来，而是在参与项目、解决实际难题的过程中逐步积淀形成。她还分享了自身经验，平日坚持阅读学习，攻读博士期间研读的系统建模相关书籍，极大助力自己理解复杂系统逻辑。课堂之外的知识积累与实践历练，是构建全局视野的有效途径。
访谈尾声，韩云回顾了二十七载从业之路。自 1998 年毕业入职航空工业光电所，她一路深耕火控领域，亲历行业技术飞跃，见证我国航空光电事业蓬勃发展。她心怀感恩，感念国家培养与母校栽培，并寄语青年学子珍惜校园时光，夯实专业根基，不断拓宽知识眼界。
整场访谈让成员们深受启发：总师之路并非遥不可及的传奇，而是一条由一个个“小目标”铺就的实干之途。从劳模梦到副总师，航空报国从来都不是豪言壮语，而是在每一次主动沟通、每一次敢于提问、每一次终身学习中积淀的扎实功底。
步履不停，方能致远；初心如磐，不负长空。新时代的西工大学子，必将带着这份“积跬步、守初心”的精神密码，脚踏实地、逐梦前行，让“公诚勇毅”的校训精神在一代代工大人手中接力传递，让青春在守护祖国蓝天的奋斗中熠熠生辉。
