# 关于举办全校教职工歌手大赛的通知-校工会（帮扶办）/ 妇女联合会

各基层工会、全体教职工：
为深入贯彻习近平文化思想，践行以文化人、以文育人工作要求，落实中华全国总工会、陕西省总工会关于新时代职工文体工作高质量发展相关部署，立足我校 "三航" 特色办学传统，充分挖掘我校尊师重教、立德树人深厚文化底蕴，传承弘扬总师育人文化，强化思想文化引领，厚植爱党、爱国、爱校、爱生教育情怀，着力营造昂扬向上、团结奋进、温馨和谐的校园文化氛围，校工会、校妇联将举办全校教职工歌手大赛。现将有关事项通知如下：
一、活动主题
颂歌礼赞新时代 师声润心育新人
二、参赛对象
全校在职教职工
三、赛程安排
报名阶段：即日起至9月9日
比赛时间：2026年9月29日（周二）
比赛地点：友谊校区健翔楼教工活动中心5楼多功能厅
四、参赛要求
1.曲目要求：参赛曲目需为传唱歌颂党、歌颂祖国、歌颂人民、歌颂英雄、歌颂中华民族、歌颂民族团结的优秀歌曲，内容健康向上、思想性强，弘扬主旋律、传递正能量，充分展现新时代教职工爱党爱国爱校的赤诚情怀、立德树人的育人初心和尊师重教的校园风尚；可涵盖美声、民族、通俗、原生态、戏曲等各类唱法，鼓励原创贴合校园育人主题、歌颂党和国家发展成就的作品。
2.演唱形式：可采用独唱、对唱、小组唱（不超过4人）形式参赛，支持跨单位、跨基层工会组队。
3.时长要求：演唱曲目1首，时长控制在4分钟以内。
4.伴奏要求：选手需自备高品质伴奏音频（MP3 格式），于报名时一并提交，现场不提供伴奏乐器。
5.舞台要求：参赛选手着装得体、台风端正，可搭配贴合曲目主题的肢体动作，鼓励展现教职工的职业特色与舞台感染力。
五、评分规则
本次比赛采用100分制，评委现场打分。

六、奖项设置
本次比赛根据报名人数设一二三等奖、优秀奖若干名，另设最佳表现奖1名。
七、报名方式
本次比赛以基层工会为单位统一报名，各基层工会需择优推荐参赛选手，报名截止日期前将参赛报名表（附件1）报送校工会，同时提交伴奏音频。
联系人：李老师，联系电话：88492466，邮箱：gonghui@nwpu.edu.cn
八、注意事项
1.各基层工会要积极组织教职工报名参赛，做好参赛选手的选拔与推荐工作，确保活动顺利开展。
2.参赛选手需遵守比赛纪律，按时到场抽签、候场、参赛，逾期未到场视为自动放弃参赛资格。
