# 大型仪器共享平台（仪器负责人）

文案：陈建源 编辑：王嘉玮 审核：刘平
大型仪器共享平台（仪器负责人）
1. 仪器设置
1.1 登录大型仪器管理平台---点击资源管理---仪器管理
1.2 选择自己负责所要设置的仪器---点击修改
1.3 基本信息设置---（可填写仪器基本信息以及添加或删除负责人及联系人）
1.4. 仪器使用设置
1.4.1 是否需要培训授权---勾选后学生需要通过培训授权后预约仪器
1.4.2 是否开启值班老师---勾选后客户端使用完成后会下拉选择相应的值班老师
1.4.3 预热/冷却时间设置---若仪器有预热时间或冷却时间设置相应时间后在使用记录中勾选， 则该时间段不收费
1.4.4 使用表单设置---可以设置预约或送样表单中需要填写的实验信息
1.4.5 使用预警---可以设置预警规则，预警消息可以在消息中心中查看
1.5 送样设置
1.5.1 接受送样预约---勾选后使用该仪器需要提交送样申请
1.5.2 送样表单---可设置在送样预约中要求填写相关测试信息
1.5.3 默认批准送样申请---勾选后学生送样申请无需仪器负责人再次审批
1.5.4 送样规则---可设置送样预约时间以及修改送样记录时间
1.6 预约设置
1.6.1 使用要求---勾选后该仪器使用需要预约
1.6.2 预约规则---勾选合并同一用户连续续约，在设置的时间段内同一用户的预约记录会被合 并；勾选允许用户在他人预约时段使用仪器，可以在他人预约时间段内登录自己的帐号使用 设备
1.6.3 设置预约最早以及最晚时间
1.6.4 工作时间设置---可设置工作时间段以及时间段预约的人员
1.6.5 预约表单---设置表单，在预约过程中学生可填写实验需求
1.6.6 提前上机设置---可设置用户提前上级
1.6.7 时间对齐设置---勾选后可设置为已一个时间段为基础预约设备
（注：勾选后学生预约无法添加自定义时间预约只能下拉日期框进行预约）
1.6.8 其他预约设置---如有特殊预约设置请联系工程师处理
1.7 计费设置---可根据不同类型设置不同收费标准（注：如有特殊计费请联系工程师处理）
1.8 用户标签设置---可将用户或课题组设置成不同的标签类
2.预约/送样审批
1. 点击个人主页---待审批---可查看所负责仪器的预约审批记录---点击审批
3.确认收费
3.1 仪器负责人点击财务管理---收费确认（可对已完成的测试记录收费进行编辑或确认）
3.2 仪器负责人收费确认编辑---可在此处编辑送样或预约使用信息以及上传测试记录
