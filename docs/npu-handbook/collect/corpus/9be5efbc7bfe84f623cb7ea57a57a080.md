# 【学术报告】关于2021年国际公务员职业生涯规划系列讲座的通知

根据国际组织人才培养创新实践基地工作安排，现将2021年第一、二、三场国际公务员职业生涯规划系列讲座事宜通知如下：
讲座一：
一、讲座主题：参与全球治理，筑梦国际组织
二、内容简介：40年的外事工作生涯，宋允孚先生的人生经历紧随国家的发展，见证了我国外交事业的蓬勃发展。在讲座中，他将与我们分享新的时代背景下，对国际组织工作的新认识、新思考。
三、主讲人：宋允孚，世界卫生组织前高级官员，原卫生部外事司司长。
四、讲座时间：3月12日（周五）19:30
讲座二：
一、讲座主题：看见世界，也看见自己的未来
二、内容简介：2017年，赵天一从上海纽约大学毕业，前往纽约大学进行深造。同年她进入联合国训练研究所实习，毕业后她成功转正，开启了自己向往的国际组织职业生涯。她用亲身经历告诉我们：探索和热情，是面对未知的最好本领，也是自我成长的最佳推动力。
三、主讲人：赵天一，联合国训练研究所纽约联络处正式雇员
四、讲座时间：3月13日（周六）19:30
讲座三：
讲座主题：联合国总部（纽约）实习初体验
二、内容简介：2019年底，胡启元来到联合国纽约总部副秘书长办公室实习。她的主要工作是信息传播，包括官方网站的更新、社交媒体的运营、一些会议纪要的撰写等。她将讲述自己的亲身经历以及由此而生的国际使命感。
三、主讲人：胡启元，曾在联合国总部（纽约）副秘书长办公室实习，目前供职于某央媒
四、讲座时间：3月14日（周日）19:30
