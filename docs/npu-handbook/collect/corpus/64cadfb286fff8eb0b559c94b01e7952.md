# 网络空间安全学院召开实战化教学与数智化课程建设研讨会

2025年12月31日，网络空间安全学院在爱生楼5楼会议室召开全院教学工作会暨实战化教学与数智化课程建设研讨布置会。学院党委书记张文涛、院长王震、副院长刘志强、院长助理张慧翔及全体教师参会，会议由刘志强副院长主持。
党委书记张文涛在讲话中充分肯定了全院教师在2025年度教育教学工作中的突出贡献，特别是在教育教学、学科竞赛、课程建设等方面取得的扎实成绩。他强调，面对新时代国家对网络安全人才的迫切需求，全体教师应进一步提高政治站位，始终以“为党育人、为国育才”为根本目标，将网络安全领域的国家战略需求融入人才培养全过程，以更加饱满的热情和务实的作风，投入到下一阶段的各项教学工作中，持续提升人才培养质量。
会上，院长助理张慧翔就信息安全专业认证中期审查工作做了专题汇报与详细部署。他系统介绍了认证中期审查的具体要求、时间节点与关键指标，对照认证标准，对当前教学文档规范、持续改进机制、学生成果评价、支撑材料整理等各项任务进行了精细化梳理与分解，明确了责任分工与完成时限。他要求相关教师应高度重视此项工作，以评促建、以评促改，确保高质量通过中期审查，推动专业建设内涵式发展。
副院长刘志强围绕学院教学数智化升级与实战化教学能力提升作了重点报告。他详细介绍了学院正在推进的“数智化课程改造计划”“面向教学靶场的课程改造计划”以及“校园网教学靶场建设”进展情况，同时指出，为适应网络安全技术快速演进和产业对实战型人才的强烈需求，学院将依托校园网教学靶场平台，全面推进现有课程的数字化、智能化升级，打造一批对接国家网络空间安全战略、契合新工科建设要求的一流课程。他要求全体教师以此为契机，全面梳理所授课程，主动对接前沿技术与实战需求，积极参与课程资源升级与教学模式创新，共同打造一批具有高阶性、创新性和挑战度的优质课程。
会议最后，院长王震作总结发言，进一步强调了三点意见：一是要统一思想，凝聚共识，深刻认识当前网络安全人才培养面临的新形势、新任务，将教学改革与专业认证工作作为提升学院核心竞争力的关键抓手；二是要聚焦重点，狠抓落实，特别是要紧盯专业认证中期审查的各项要求，以及数智化课程与教学靶场建设的既定目标，确保各项任务落地见效；三是要协同联动，形成合力，全体教师要主动担当，积极作为，共同推动学院教学工作再上新台阶，开创高质量人才培养的新局面。
本次会议总结了全年的人才培养工作，明确了学院下一阶段教学工作的方向与路径，为持续推进教学改革、强化专业内涵建设、提升人才培养质量奠定了坚实基础。
