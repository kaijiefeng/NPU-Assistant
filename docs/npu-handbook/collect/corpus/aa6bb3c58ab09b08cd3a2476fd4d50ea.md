# 赓续长征精神，汲取奋进力量——西北工业大学力学与交通运载工程学院与太原理工大学航空航天学院航空研究生党支部联合开展主题党日活动

为纪念中国工农红军长征胜利90周年，同时进一步加强校际研究生党支部之间的交流合作，创新基层党组织联学共建形式，2026年9月18日下午，我院研究生第二党支部与太原理工大学航空航天学院航空研究生党支部联合开展了“赓续长征精神，汲取奋进力量”主题党日活动。同时，当天也是九一八事变爆发95周年的特殊日子，两校学子共同缅怀先烈，勿忘国耻，吾辈自强。
活动伊始，两校师生党员共同来到长安校区“为国铸剑”雕塑与何尊组雕前。研究生第二党支部书记关博元结合雕塑的文化寓意和学校发展历程，深情讲述了何尊铭文中“宅兹中国”所承载的深厚家国意蕴，以及“铸剑勇士”所象征的“隐姓埋名、为国铸剑”精神。
随后，党员们走进校史馆，了解西工大扎根西部、服务国家的发展历程，回顾学校在航空、航天、航海等领域取得的重要成果，学习优秀校友和老一辈科研工作者矢志报国、攻坚克难的奋斗故事。
在军工素质教育实践中心航空馆，大家近距离了解航空装备的发展脉络与重大科研成果，聆听一代代航空科技工作者攻坚克难、矢志报国的奋斗故事，在沉浸式参观中进一步感悟航空报国精神，深化了对科技强国、航空强国使命担当的认识。
最后，双方支部成员齐聚学院“一站式”学生社区开展座谈交流。学院学工主管王涵晶老师代表学院对太原理工大学航空航天学院师生一行的到来表示欢迎，并介绍学校、学院基本情况以及学生党建工作开展情况。研究生第二党支部书记关博元以“赓续长征精神，汲取奋进力量”为题讲授了一堂专题党课，回顾长征重要历史节点，带领大家重温红军在艰难险阻中坚定信念、攻坚克难的伟大征程。
太原理工大学航空航天学院辅导员刘鹏老师、贾佳老师分享支部工作和经验做法。双方围绕研究生基层党组织建设、主题党日活动形式创新以及党建工作与学生学习科研相融合等方面开展了深入交流。
座谈会结束后，太原理工大学航空航天学院航空研究生党支部向学院赠送了“山西精神”主题文化纪念框。这份具有鲜明地域文化特色的纪念礼物，不仅为此次校际交流留下了珍贵印记，也承载着双方支部互学互鉴、深化友谊的美好期许。
此次联合主题党日活动将校园文化教育、国防特色实践、红色历史学习与校际支部交流有机结合，不仅进一步增进了两校研究生党支部之间的了解，也为双方互学互鉴基层党建工作经验搭建了良好平台。
未来，学院党委将继续深化党建交流共建，积极探索更加丰富、更具实效的联合活动形式，引导学生党员坚定理想信念、锤炼过硬本领、强化责任担当，以实际行动走好属于新时代青年的“长征路”。
