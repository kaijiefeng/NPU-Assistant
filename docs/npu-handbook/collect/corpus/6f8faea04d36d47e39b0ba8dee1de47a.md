# 党委保卫部开展第二季度管制类危化品专项检查

为切实加强学校管制类危化品安全管理，落实学校相关文件要求，7月4日至7月9日，党委保卫部组织对涉及管制类危化品的16家二级单位开展了专项检查。
此次检查，重点关注各二级单位相关实验室管制类危化品安全管理制度落实情况、2025年管制类危化品责任书签署情况、管制类危化品出入库使用登记台账填写情况、管制类危化品分类存放落实情况、管制类危化品存量是否超标，是否存在超量购买，长久未使用等情况、存放各类管制类危化品的危化品柜是否达标（包含通风、隔热、防腐蚀）等，检查人员通过对照台账，现场核实管制类危化品的种类和数量，确保账物相符，无差错、无遗漏。针对检查中发现的隐患问题，检查人员现场指导并提出整改意见，针对无法立行立改的隐患问题下发整改通知书，要求各二级单位采取有效措施限期整改、并形成整改报告。
此次专项检查行动为我校持续抓好管制类危化品安全管理工作打下坚实基础。后续，学校将继续加大监督管理力度，举一反三，进一步健全完善易制毒、易制爆化学品等管制类危化品的全流程监管，切实做到来源可查、去向可追、流向可控，切实抓好各项安全防范措施的落实，保障校内安全形势持续稳定。
