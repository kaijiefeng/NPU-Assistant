# 材料学院-西北工业大学医院

责任医师：张萌（主治医师）
简介：
张萌，中共党员，内科主治医师，河北医科大学硕士毕业。从事急诊和内科工作十余年，擅长急危重患者的抢救、内科常见病和多发病的诊治、个性化健康管理方案制定、生活方式指导、科学减重及营养膳食指导。发表专业论文数篇。曾在陕西省人民医院和西安交通大学第二附属医院进修学习。持有健康管理师和公共营养师资格证书。
（备注：学院责任医师是医院与学院之间的桥梁，可为我校师生提供健康咨询、健康宣教、体检结果释疑、急救知识技能培训等服务。有需求者，可通过扫描学院责任医师二维码联系。）
