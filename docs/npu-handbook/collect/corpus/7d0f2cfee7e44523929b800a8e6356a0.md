# 学校开展2025年“安全生产月”消防应急疏散逃生大演练

今年6月是第24个全国“安全生产月”,为进一步提升全校师生的消防安全意识和自救互救能力，完善校内各部门联合应急处置火情等突发事件的联动机制，按照上级要求和学校工作安排，6月11日下午，党委保卫部在友谊校区北村3号楼学生公寓组织开展了2025年“安全生产月”消防应急疏散逃生大演练。党委保卫部副部长方原担任总指挥，党委保卫部、党委学生工作部、后勤部、校医院以及枫林路消防救援站等相关单位参加了演练。
6月11日16时08分，北村3号楼学生公寓810室突发火情，楼内消防广播自动开启，循环播报安全疏散提示。物业管理人员确认火情后立即拨打党委保卫部报警电话、119火警电话和校医院急救电话。
接警后，灭火战斗组、交通警戒组、引导疏散组、医疗救护组及后勤保障组快速集结赶赴现场，有序开展灭火救援工作。交通警戒组在道路两侧设置警戒线，进行交通疏导，保障消防及医疗救援通道畅通。灭火战斗组驾驶微型消防车，到达现场后迅速穿戴好防护救援装备，分为搜救组、内攻组开展灭火救援。搜救组进入公寓楼展开全范围搜索，引导被困学生保持低姿、用湿毛巾捂好口鼻，有序撤离至楼外安全区域；内攻组进入火场后，对起火点进行勘查，就近利用楼内消火栓铺设水带，建立灭火阵地，待后勤保障组切断电源后立即实施初期火灾灭火。引导疏散组在一楼楼梯口引导参演学生迅速疏散到室外开阔地带。枫林路消防救援站接警后立刻出动2辆灭火救援车到达火情现场，与校内搜救组密切配合，发现受伤人员后用担架救出，转移至医疗救援组进行专业救治；同时在楼外利用高喷消防车出水，从外部向起火点方向实施灭火。经过紧急、高效的灭火救援，在各单位通力协作下，16时14分，北村3号学生公寓火情扑灭完毕，被困人员安全救出，疏散逃生大演练顺利完成。随后，党委保卫部消防科杨鹏程对本次活动做了点评和总结，再次提醒参演师生提高消防安全意识，关注消防安全宣传教育。
此次演练坚持“以演筑防、以练为战”理念，前期党委保卫部精心策划，认真制定了演练方案和预案，保证了活动顺利开展。此外，6月以来，党委保卫部还面对计划财务部、生命学院、生态环境学院、软件学院、柔电学院、化学与化工学院等单位开展消防安全教育及培训。后续，党委保卫部将继续坚持消防工作“预防为主、防消结合”的方针，加强与校内各部门、属地消防救援机构等联动配合，积极组织消防宣传教育培训、加强消防巡查检查，努力争取“防患于未然”，确保师生安全与校园和谐稳定。
