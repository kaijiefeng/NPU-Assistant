# 外国语学院启动部署树立和践行正确政绩观学习教育工作

3月5日下午，外国语学院树立和践行正确政绩观学习教育动员部署会在学院楼204会议召开，院党委书记王高祖主持会议，学院党政领导班子、党支部书记、师生党员代表参加了会议。
会议指出，在全党开展树立和践行正确政绩观学习教育，是以习近平同志为核心的党中央做出的重大决策部署，是今年党的建设的重要任务。会议传达学习了中央党的建设工作领导小组会议部署和中共中央办公厅《关于在全党开展树立和践行正确政绩观学习教育的通知》精神，传达学习了学校党委的工作要求，启动部署学习教育工作。
会议要求，要立足教育强国建设，牢牢把握“立党为公、为民造福、科学决策、真抓实干”总要求，以“学思想、守初心、强担当、创实绩”为主要任务，坚持学查改一体推进，在深学、真查、实改上下功夫，通过学习研讨、查摆问题、整改整治、建章立制、开门教育高标准高质量落实好学习教育各项任务，切实把学习成果转化为建设高水平育人文科的强大动力，转化为落实学校“十五五”规划和“一十百千”核心指标的具体举措。
会议强调，要把开展学习教育作为一项重要政治任务，各党支部和领导干部要坚决有力贯彻落实党中央决策部署，以及学校党委的工作要求，加强学习研讨、深入查摆问题、抓好整改整治、完善制度机制，使学习教育成果让师生可感可及，确保学习教育取得扎实成效，为“十五五”开好局、起好步提供强大动力。（文/王开薇；审稿/王高祖）
