# 机电学院-西北工业大学医院

责任医师：梁乐乐（主治医师）
简介：
毕业于西安交通大学临床医学专业，在内科、急诊科工作18年，擅长高血压、冠心病、糖尿病等常见病的诊治，以及急危重症患者的诊断、抢救及治疗。在陕西省人民医院急诊科进修学习2次。2023年取得应急救护培训师资格。
（备注：学院责任医师是医院与学院之间的桥梁，可为我校师生提供健康咨询、健康宣教、体检结果释疑、急救知识技能培训等服务。有需求者，可通过扫描学院责任医师二维码联系。）
