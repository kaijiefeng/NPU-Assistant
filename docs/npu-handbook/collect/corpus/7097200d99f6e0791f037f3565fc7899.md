# 莫航学院师生赴延安开展“纪念中国工农红军长征胜利90周年”主题实践研学

为纪念中国工农红军长征胜利90周年，传承弘扬伟大长征精神，10月17日至18日，莫航学院百余名师生赴延安开展“纪念中国工农红军长征胜利90周年”主题实践研学活动。师生们寻访红色旧址、聆听现场思政课，在思想淬炼与精神洗礼中激励青年学子传承红色基因，赓续红色血脉。
踏红色热土，寻信仰之光
师生们走进梁家河，走进村史馆与知青旧居，透过老照片、旧农具等旧物，体悟主动攻坚克难、躬身实干的为民初心。巍巍宝塔山下，师生在斑驳塔影之中重温那段伟大远征落足陕北的峥嵘岁月，先辈们历经长征淬炼奔赴延安、矢志报国的坚定信仰，深深触动在场每一位青年学子。走进延安革命纪念馆，在一幅幅珍贵历史影像、一件件革命文物前，同学们直观感受了革命年代朴素而坚定的信仰力量。一路寻访，一路感悟，红色地标串联起鲜活党史长卷，引领青年学子传承红色薪火，奋楫时代新程。
实景专题授课，感悟初心力量
研学期间，亢婉红老师作专题思政课，结合现场实景带领大家回望知青扎根基层、心系群众的峥嵘岁月，从鲜活的奋斗事迹中阐释实干担当的公仆精神与矢志不渝的为民初心，引导青年学子涵养躬身实干的价值追求。党婕睿讲师作题为《革命旧址是一本永远读不完的书》的现场讲述，依托杨家岭的一屋一址、一砖一瓦，深情回溯了党中央在延安十三年的奋斗历程，师生们深刻感悟到延安精神与长征精神一脉相承的时代价值。
品读红色史诗，厚植信仰根基
当光影流转，一场跨越时空的精神对话在剧场内徐徐启幕。研学期间，师生们沉浸式观看大型红色情景体验剧《再回延安》。剧目以行进式演绎再现长征风雪征途与延安峥嵘岁月，现代科技营造的沉浸式场景带来直击人心的心灵震撼，让师生们直观感悟到红色精神的磅礴力量。
延安，是中国革命的圣地、新中国的摇篮。站在中国工农红军长征胜利90周年的历史坐标上回望来时路，同学们“到延安去”不仅是一次跨越时空的精神洗礼，更是一堂浸润人心的生动思政课。同学们于革命圣地汲取精神力量，走的是初心之路，传承的是红色基因，淬炼的是时代之责，将以更加坚定的理想信念和更加昂扬的奋斗姿态，在强国建设、民族复兴的新征程中贡献青春力量。
研学感悟
莫航学院2026级本科生 林佳
梁家河的窑洞、巍然矗立的宝塔山、延安革命纪念馆里一件件珍贵文物，静静诉说着厚重的红色往事。烽火艰难岁月里，革命先辈们扎根黄土高原，在困苦中坚守理想，于求索中开辟前路。作为西工大青年，我会珍藏研学所得，将延安精神、长征精神内涵融入学习实践中，勇担使命，矢志笃行，用青春担当回应时代召唤。
莫航学院2026级本科生 徐铭基
踏上延安这片热土，最触动我的是生生不息、薪火相传的信仰力量。在杨家岭革命旧址、枣园旧址、延安革命纪念馆等地，重温那段峥嵘岁月，老一辈革命家们自力更生、艰苦奋斗的精神令我深受震撼。历史是最好的教科书。作为新时代青年，我们应从延安精神中汲取前行力量，将个人理想融入国家发展大局，在专业学习中精益求精，在时代浪潮中挺膺担当，用奋斗书写无悔青春。
莫航学院2026级本科生 王泳锦
巍巍宝塔山，滚滚延河水。研学期间，厚重的历史变得生动而具体。延安精神中自力更生、艰苦奋斗的内核，犹如明灯，指引吾辈青年不惧风雨、奋勇向前。我会把此次研学的感悟转化为前行的动力，在今后的学习与实践中迎难而上，脚踏实地，走好我们这一代青年的奋进之路。
