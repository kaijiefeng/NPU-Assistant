# 西北工业大学网络空间安全学院开题答辩（周小艺）

一、开题答辩题目：面向边缘AIGC虚拟服务的空中通算网络资源优化调度
二、开题答辩人：周小艺
三、开题答辩时间：2025年3月8日 上午10：00
四、开题答辩地点：网络空间安全学院245会议室
五、开题内容简介：
近些年，AIGC（生成式人工智能）技术的出现为虚拟世界提供了内容生成、交互设计、个性化体验等强大支持，推动元宇宙等虚拟服务向更加真实、动态和多样化的方向发展。空中通算网络作为未来B5G和6G愿景中的核心组成部分，通过与AIGC技术的深度融合，结合边缘计算和语义级数据处理能力，可显著降低对中心服务器的依赖，降低网络延迟，并为用户提供沉浸式、实时更新的虚拟服务体验。本研究以多类型AIGC模型性能分析，协作隐蔽通信及通算、存储资源优化为切入点，研究空中通算网络资源优化调度策略，力求在保障运营商数据安全及用户隐私安全的同时，降低运营商虚拟服务开销，并提升用户体验。
六、开题答辩人简介
周小艺，2022100766，1997年2月生，网络空间安全专业，导师郭鸿志副教授。
