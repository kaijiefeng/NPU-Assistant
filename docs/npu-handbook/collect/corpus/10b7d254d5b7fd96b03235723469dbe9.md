# 航海学院举办2024届硕士毕业生就业情况分析座谈会

为了进一步推动我院2024届硕士毕业生就业工作，了解毕业生就业需求，将就业帮扶工作做实做细，帮助毕业生充分有效就业，11月7日下午，航海学院在204会议室召开了2024届硕士毕业生就业情况分析座谈会。学院党委书记孙华强、副书记王银涛、院长助理耿云辉、辅导员李乐、学生事务主管赖慧以及2024届硕士毕业生代表参加座谈，本次座谈会由李乐主持。
会议伊始，李乐向在场师生介绍了学院就业工作开展情况，并结合当前2024届硕士毕业生就业情况分析就业形势。随后，老师们与毕业生代表围绕自身当前就业状态、职业规划、就业难点以及毕业论文等方面开展深入交流。
最后，孙华强指出学院将认真贯彻落实习近平总书记关于高校毕业生就业工作的系列重要批示精神，全力以赴推动就业工作。他提醒同学们要立足学院学科特色和自身特点，以“立大志向、上大舞台、入主战场、干大事业”为己任；要打开视野，充分从发展的角度进行职业选择，有定位准确、目标清晰的职业规划；要勇于尝试、大胆沟通、相互鼓励、信息共享，兼顾求职与学业，保证科研任务和毕业论文的进度。同时，他强调学院将继续抓紧抓细、落地落实就业工作，精准开展就业帮扶，暖心联系毕业生，对慢就业、懒就业、就业困难毕业生强化就业帮扶。
航海学院一直以来高度重视学生就业工作，9月以来，配合学校完成船舶集团大型招聘，邀请多家用人单位来院开展小型专场招聘会，以“小而精、专而优”的原则为用人单位专项招聘提供便利，累计组织专场招聘超30场次，努力为毕业生提供数量更多、频次更高、质量更优的优质就业机会和资源。本次座谈会的开展，有助于毕业生进一步明晰就业形势和政策，调整就业心态，也有助于学院把握当前就业重点难点，根据学生实际情况，强化就业指导与服务，引导学生继续抢抓就业关键期，多举措助力毕业生更高质量、更充分就业。
