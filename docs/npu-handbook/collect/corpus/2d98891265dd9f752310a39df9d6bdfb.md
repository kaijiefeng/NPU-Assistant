# 学院承办中国自然辩证法研究会工程与社会发展专业委员会2026年学术年会-西北工业大学

2026年6月13日至14日，中国自然辩证法研究会工程与社会发展专业委员会2026年学术年会在贵州大学成功举办。会议由中国自然辩证法研究会主办，中国自然辩证法研究会工程与社会发展专业委员会（以下简称“专委会”）、贵州大学马克思主义学院、贵州大学哲学学院和西北工业大学马克思主义学院共同承办。贵州大学党委书记杨未教授、马克思主义学院院长李传兵教授、中国自然辩证法研究会副秘书长崔伟奇教授、专委会主任胡大平教授出席开幕式并致辞。本次会议以“新兴科技·工程创新·人的全面发展”为主题，来自南京大学、中山大学、北京化工大学、北京航空航天大学、上海交通大学、大连理工大学、华南理工大学、西北工业大学等全国数十所高校和科研院所的50余位专家学者与会，围绕工程哲学、新兴科技伦理与技术现象学等开展跨学科研讨。
本次年会设置四场大会报告与两个分会场，搭建了贯通工程哲学基础理论与人工智能前沿实践的学术交流平台。会议认为，人工智能技术的迭代突破正在深刻重塑工程实践与社会发展的基本范式，工程哲学研究须扎根中国实践，从技术前沿与工程现场提炼理论问题。未来技术专家须兼具人文自觉，人工智能应被置于控制论批判、存在论反思与社会试验的多元框架中审视，推动从设计伦理走向存在论伦理。会议指出，工程师精神具有独立于科学家精神的价值结构、实践逻辑与伦理半径，是支撑新质生产力发展的精神底盘；大语言模型的文化对齐、内在意义与可解释性构成智能时代工程哲学的核心议题；具身智能的共情边界、上下文工程中的知情同意框架、机器人技术下的劳动异化新形态等问题同样亟待哲学回应。会议还围绕马克思主义劳动幸福观、重大工程实践的哲学逻辑、人机共生的辩证进路以及无人驾驶伦理等方向展开深入对话。
西北工业大学马克思主义学院作为本次会议的承办方及专委会挂靠单位，扎实做好会议统筹协调、专家联络对接、议程组织落地等各项工作，有力保障本次会议圆满顺利举办。学院兼职博导胡大平教授围绕《控制论与资本主义生产关系再生产》阐释前沿学术观点；副院长、专委会副主任兼秘书长张云龙教授作《工程结构的生成机制与关系重构》学术报告；吴小安教授、吕天择副教授依次登台，分别分享《论人类智能与机器智能》《批判与实践之间：技术哲学反思性视角的限度与工程乐观主义的边界》研究成果。《西北工业大学学报（社会科学版）》编辑部主任陆风副研究员主持学术报告环节。学院博士研究生宋知寰、曹奥琪、龚彦铭、韦龙阳向会议投稿，并在分会场进行了学术报告与交流。
闭幕式由张云龙教授作学术总结，认为会议报告面向事实本身，兼顾基础理论的扎实探讨与技术前沿的敏锐回应。贵州大学马克思主义学院院长李传兵教授致感谢辞。下一届年会将在中山大学（珠海）举办，潘恩荣教授代表承办方向学界同仁发出邀约。会议的成功举办，对于推动构建中国工程哲学自主知识体系、促进智能时代工程与社会的协调发展具有重要意义。
