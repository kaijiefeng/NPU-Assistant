# 北京研究院开展“传承红色基因 弘扬革命精神 提升教职工思想政治素养” 主题教育活动-西北工业大学

正值中国人民抗日战争暨世界反法西斯战争胜利80周年的重要历史节点，为持续巩固和深化深入贯彻中央八项规定精神学习教育成果，进一步加强师德师风建设，北京研究院党支部于2025年9月20日，携手北京市海淀区西三旗街道，共同前往门头沟区平西情报联络站纪念馆，开展了主题为“传承红色基因，弘扬革命精神，提升教职工思想政治素养”的红色教育活动。
活动当天，参与人员井然有序地进入纪念馆，认真参观了馆内陈列的珍贵历史文物、图片及详尽的文字资料。在讲解员饱含深情且细致入微的解说下，大家不仅深入了解了平西地区在抗日战争和解放战争时期所发生的重大历史事件，还详细知晓了众多英雄人物的感人事迹，深切体会到了革命先辈们在艰苦卓绝的环境中，如何以百折不挠的革命精神，为国家复兴和民族解放事业所做出的巨大牺牲和卓越贡献。在沉浸式体验馆中，参与者们通过亲身体验收发电报的操作，深刻感受到了革命先辈在恶劣环境下坚守初心、捍卫国家安全的艰辛，从而更加深刻地认识到革命胜利的宝贵和来之不易。
此次红色主题教育活动，不仅有效增强了北京研究院教职工的凝聚力和向心力，还极大地激发了大家的爱国情怀和奋斗精神，引导教职工以更加团结、奋发有为的精神状态，积极投身于教育强国建设的事业中，为学校实现“天下工大、世界三航”的宏伟远景目标注入了强劲的动力和坚实的思想基础。
下一步，北京研究院将继续秉承红色教育的理念，开展形式多样、内容丰富的主题活动，进一步引导教职工传承红色基因，打好政治基础，勇担时代使命，推动学校教育事业迈向新的更高台阶。
