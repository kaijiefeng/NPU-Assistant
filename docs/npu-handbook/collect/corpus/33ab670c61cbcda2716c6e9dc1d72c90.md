# 集团饮食服务中心党支部赴八路军西安办事处纪念馆开展实践研学活动-后勤集团

为深入推进树立和践行正确政绩观学习教育，引导党员干部坚持实事求是、求真务实作风，强化廉洁自律与服务担当，4月14日下午，后勤集团饮食服务中心党支部组织党员干部前往八路军西安办事处纪念馆，开展实践研学活动。
在讲解员的带领下，全体党员走进七贤庄革命旧址。系统回顾八路军西安办事处从秘密交通站到完成历史使命撤离的十年光辉历程，认真学习其在“西安事变”和平解决、开展抗日统战工作、输送革命人员、转运物资情报等方面发挥的“革命桥梁”重要作用。通过“老山遇险”革命故事和“采办委员会”复原场景，大家深切感悟革命先辈在极端艰苦条件下忠诚履职、保障前线、严守纪律、服务大局的崇高精神。
参观过程中，党员干部认真聆听、深入交流。大家一致认为，“八办”历史是一部艰苦奋斗、无私奉献的革命史，更是一部心系群众、服务大局的实践史，其精神内核与后勤“服务保障为根本”的工作宗旨高度契合。
此次研学是一次深刻的红色教育和思想淬炼。党员们纷纷表示，将把学习领悟转化为履职尽责的强大动力，把正确政绩观融入后勤饮食服务全过程，以更实作风、更高标准做好师生餐饮保障，为学校“一十百千”发展目标和“十五五”良好开局贡献后勤服务力量。（图：李昶龙 文：王瑾瑶，审核：杜俊业 邱若娟）
