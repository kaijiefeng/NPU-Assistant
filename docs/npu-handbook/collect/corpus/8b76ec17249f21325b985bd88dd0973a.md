# 后勤部办公室党支部召开理论学习会

6月12日上午，后勤部办公室党支部组织全体党员召开理论学习会。会议由党支部书记张文刚主持。
会上，全体党员集中学习了《习近平总书记在重庆、山东考察时关于党纪学习教育的重要讲话精神》《发展新质生产力是推动高质量发展的内在要求和重要着力点》《习近平对学校思政课建设作出重要指示强调不断开创新时代思政教育新局面努力培养更多让党放心爱国奉献担当民族复兴重任的时代新人》等习近平总书记重要讲话精神以及《中国共产党纪律处分条例（节选）》的部分内容。
围绕以上学习内容，党员们结合个人工作实际分享了自己的学习心得。大家纷纷表示，要时刻将党纪党规内化于心、外化于行，将规矩纪律意识贯穿于工作的始终，强化政治理论武装，为新时代学校发展贡献后勤力量。
最后，张文刚对学习会进行了总结，并对党员们提出了具体要求。他强调，一是要继续加强理论学习，不断提高政治素养和业务能力；二是要紧密结合工作实际，将所学所获转化为推动工作的具体行动；三是要绷紧纪律之弦，时刻坚守清正廉洁底线，自觉把铁的纪律刻印在脑海中、体现在助推学校高质量发展的行动上。（撰稿人：毛淑兰；审稿人：韩争胜）
