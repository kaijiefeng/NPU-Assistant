# 关于2025年度西北工业大学“TCL青年学者”奖教金申报工作的通知

各相关单位：
为进一步激励教师潜心从事教育教学工作，不断提升人才培养质量，教育实验学院/未来技术学院/学科交叉中心拟启动2025年度西北工业大学“TCL青年学者”奖教金申报工作，现将具体事宜通知如下：
一、申报范围
“TCL青年学者”奖教金申报对象为西北工业大学所有在册，年龄不超过40岁（含）的教职工。
二、申报要求
1.遵守国家的法规和学校的规章制度。
2.忠诚教育事业，诚实守信，思想品德高尚，在教学、科研第一线的工作，具有良好的团队精神。
3.是所在学科领域中具有突出竞争力的青年人才，具有独立的研究方向；活跃在学术前沿，在同年龄段学术人才中具有突出的学术发展潜力。
4.对学科发展具有战略性和创造性构想，具备服务国家重大战略需求、带领科研团队开展高水平学术研究的潜力。
5.能够系统讲授反映本学科领域最新研究成果的相关课程。
6.承担学校本科教育教学工作，优先支持深度参与教育实验学院/未来技术学院/学科交叉中心（以下简称“学院”）教育教学改革并取得突出成效的青年教师。如作为指导教师带领学院队伍（项目所属单位为学院或项目第一负责人为学院学生）参加“三大赛”及其他科技竞赛并获得省部级及以上奖励；依托学院在思政建设方面取得省部级及以上奖励；依托学院获得省部级及以上教育教学成果奖励；担任学院荣誉导师、班主任、辅导员指导学生发展做出突出贡献等，将优先考虑。
三、评选安排
1.2025年度“TCL青年学者”奖教金评选名额：1-4名。
2.“TCL青年学者”奖教金的评审工作，由西北工业大学教育实验学院/未来技术学院/学科交叉中心负责。
四、申报材料
1.填写附件：西北工业大学“TCL青年学者”奖教金申请表，并按照上述要求准备相关支撑材料。申请表电子版需要word和签字盖章pdf扫描件。申报材料电子版文件名格式为：学院+申报人姓名，所有材料的电子版发送至wangrong1107@nwpu.edu.cn，纸质版报送至教育实验学院学院楼101办公室王蓉老师。
2.通知发布之日起接受申报，截止时间为2025年12月4日（星期四）17:00前。
3.联系人：教育实验学院/未来技术学院/学科交叉中心，王蓉老师029-88430277。
