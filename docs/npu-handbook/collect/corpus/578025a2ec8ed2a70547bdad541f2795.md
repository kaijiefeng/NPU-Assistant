# 黄迪民教授主讲校史校情专题讲座

回望建校峥嵘岁月，传承前辈革命精神。西工大校史是一代代建设者铸就的报国丰碑。教育实验学院/未来技术学院/学科交叉中心于10月15日下午，特邀校关工委委员、学校 “五老” 宣讲团团长黄迪民教授，作题为“传承西工大红色基因，弘扬老前辈革命精神”的专题讲座。2026级本科生及辅导员代表到场聆听。
黄迪民教授从西工大 “一脉源三支” 的建校源流讲起，回望了学校八十余载扎根国防、深耕三航的办学征程。他指出，西工大的精神血脉深深根植于老一辈建设者的创业历程，“公诚勇毅” 校训、“三实一新” 校风的传承演进，集中体现了西工大人服务国家战略的办学底色。在讲述建校老一辈事迹时，他依次介绍了刘海滨、寿松涛、刘咸一、刘刚、唐铎五位老领导的生平贡献，从革命履历、办学功绩、品格风范三个维度，系统展现了西工大校史的精神内核。
面向在场的2026级新生，黄迪民教授寄予了殷切期望。他表示，西工大校史不只是办学发展的历程记录，更蕴藏着穿越岁月的精神力量。同学们既要从建校前辈的奋斗事迹中汲取信念养分、读懂报国初心，更要把这份精神传承融入日常学业，深耕专业知识、直面困难挑战，以实实在在的成长践行西工大人的使命担当。
学院举办校史校情专题讲座，引导新生在回望办学历程中深化校史认知、领悟办学传统，从中汲取精神力量，自觉践行“公诚勇毅”校训、弘扬“三实一新”校风。通过将校史学习与精神传承相贯通，学院进一步把校史中的精神养分融入立德树人全过程，推动“总师育人文化”走深走实，激励青年学子在成长征程中砥砺奋进。
