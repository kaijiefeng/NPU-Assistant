# 档案馆关于2025年寒假工作安排的通知

全校师生：
为做好2025年寒假档案管理服务工作，根据学校《关于2025年寒假放假安排的通知》要求，结合档案馆工作实际，现将有关安排通知如下：
一、办理档案查（借）阅业务
二、集中办理档案归档业务
注：①其他类档案寒假期间暂停办理归档；②设备仪器（合同金额2万（含）～10万）归档，请在网上办事大厅办理。办理步骤为“翱翔门户—办事大厅—设备仪器（合同金额2万（含）～10万）”。
三、办理中文成绩单及出国材料
1.办理中文成绩单：在校本科生及2023届、2024届本科毕业生请在“翱翔教务系统”自助打印；2022届（含）以前的本科毕业生请在档案馆“学生自助打印区域”自助打印；其余毕业生请在档案馆官网“出国材料预约办理平台”进行预约办理。
2.办理出国材料：在校本科生及2023届、2024届本科毕业生办理英文成绩单请在“翱翔教务系统”自助打印；其余毕业生办理出国材料请在档案馆官网“出国材料预约办理平台”进行预约办理。
以上业务也可以在每周一、周三值班时间到档案馆107室现场办理，咨询电话88493280；出国材料预约办理步骤为“西北工业大学档案馆官网（http://dag.nwpu.edu.cn/）—档案办事大厅—学生窗口—出国材料预约办理”。
特此通知。
档案馆
2025年1月15日
