# 国际教育学院-西北工业大学医院

责任医师：刘燕（医师）
简介：
刘燕，医师，毕业于华北理工大学，擅长疫苗接种预检相关问题，高血压，糖尿病等慢性病相关问题，曾在美国宾夕法尼亚州立大学，陕西省人民医院进行学习。陕西省健康体检服务协会秘书。
（备注：学院责任医师是医院与学院之间的桥梁，可为我校师生提供健康咨询、健康宣教、体检结果释疑、急救知识技能培训等服务。有需求者，可通过扫描学院责任医师二维码联系。）
