# 绿茵逐梦 拼搏无悔—我院足球队结束“三航杯”征程

近日，西北工业大学“三航杯”足球比赛相关赛程正在推进，我院足球队在本届赛事中奋勇拼搏，以小组赛一胜一平一负的战绩结束征程。尽管遗憾止步小组赛，但全体队员在赛场上展现出的竞技热情与拼搏精神，成为绿茵场上一道亮眼的风景，生动诠释了我院学子追求卓越、永不言弃的青春风采。
小组赛阶段，我院足球队先后与网络空间安全学院、化学与化工学院、管理学院三支劲旅展开激烈角逐。面对实力不俗的对手，队员们始终秉持“团结协作、每球必争”的信念，全程斗志昂扬、全力以赴。首战对阵网安学院，球队凭借默契配合与精准战术执行成功取胜；次战迎战化工学院，队员们顶住压力、稳扎稳打，最终以平局收获积分；收官之战对阵管理学院，尽管队员们拼尽全力展现出顽强的抗争意志，但终因稍逊一筹憾负对手，无缘淘汰赛。赛场上，我院队员攻防有序、配合默契，展现出的战术素养与团队凝聚力，不仅赢得了现场观众的阵阵掌声，更收获了对手的认可与尊重。
征程虽止，热爱不息。对于我院足球队而言，“三航杯”不仅是竞技水平的比拼舞台，更是锤炼意志、凝聚集体力量的生动课堂。此次比赛虽留有遗憾，但也为球队积累了宝贵的实战经验，让队员们在磨合中深化了默契、在对抗中看清了不足。
赛后，队员们纷纷表示，将认真总结此次比赛的经验教训，在后续训练中刻苦打磨技术、强化战术配合，不断提升球队整体实力。未来，我院足球队将带着这份对足球的热爱与拼搏的初心继续前行，力争在后续赛事中突破自我、锤炼本领，持续传承和发扬我院学子顽强拼搏、追求卓越的优良作风。
