# 文明交通·绿色出行·共建文明校园”倡议书-机关党委

学校机关全体教职工：
校园是我们共同工作、学习和生活的家园，文明交通是平安校园建设的重要基石，更是机关工作人员作风素养的直观体现。为进一步规范校园交通秩序，消除安全隐患，营造畅通有序、和谐文明的校园环境，充分发挥机关工作人员的示范引领作用，机关党委发出如下倡议：
一、遵守交通规则，文明安全出行
1.遵守交通规则。不逆行、不抢道，转弯时注意观察后方来车与行人。
2.安全出行。驾驶和骑行时请勿佩戴耳机、勿接打电话、勿单手操作方向盘或车把，骑行请按照要求佩戴头盔。
3.文明礼让。控制车速，礼让行人，坚决杜绝“鸣笛”“飞车”“飙车”“漂移”等不文明和危险行为。
二、践行绿色理念，规范停放车辆
1.更新理念。倡导“步行优先、绿色出行”理念；树立“有序停放是责任，文明校园靠大家”的意识；使用共享单车等非机动车辆时，严禁“只顾方便，随意停放”的现象发生。
2.规范停车。机动车停放做到“按位停放、朝向一致、整齐有序、不超时限”；非机动车停放做到“不压线、不跨线，不占用消防通道、应急出口、人行道、教学楼/办公楼/宿舍楼门口等公共区域，不堵塞交通要道”，严禁停放在规定区域以外；大排量摩托车原则上严禁进入教学科研区；长期不用的“僵尸车”（如破旧自行车、电动车）请及时清理，避免挤占公共停车资源。
3.让渡资源。友谊校区教学科研区物理空间有限，倡议在党政办公楼及附近办公的机关教职工自觉将非机动车停至图书馆地下停车场，将有限的地面非机动车停车资源让渡给学生，做到“多花一分钟，文明当先锋”。
三、强化表率引领，凝聚文明合力
1.带头示范树标杆。让我们自觉践行“平常时候看得出来、关键时刻站得出来”的要求，主动带头步行通勤、规范停车，做好文明示范。
2.党员干部作表率。机关党员干部要发挥先锋模范作用，主动友好劝导不文明行为，用微笑服务传递文明理念，带动同事、影响学生共同养成良好习惯，让“人人讲文明、处处守秩序”的氛围浸润校园。
3.共建共享聚合力。文明示范是机关作风建设的流动窗口，绿色出行是共建美好校园的生动实践。让我们从每一次出行、每一次停放做起，用实际行动诠释机关工作人员的责任与风采，带头守护校园的畅通与安全，为建设平安、和谐、美丽的西北工业大学贡献机关力量！
特此倡议。
机关党委
2025年12月2日
