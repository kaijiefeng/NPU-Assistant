# 生命科学与技术学院师生赴宝鸡开展培训活动

为深入推进“大思政课”建设，创新实践联学育人形式，厚植师生理想信念与人文素养，在学校“大思政课”建设单位项目和教职工培训与发展专项的支持下，10月10日，我院组织40余名师生赴宝鸡眉县开展“大思政课”建设实践联学活动、教师素质提升培训、导师培训，走进西部兰花生态园与张载祠（横渠书院），在自然科研之美与先贤文脉之光中感悟师者初心、淬炼育人品格。
上午，师生实践团前往西部兰花生态园。作为省级现代农业科普与生态教育基地，园区依托现代化智能温室、植物组培技术、无土栽培示范体系，集中展示了现代农业科研工作者潜心钻研、默默坚守、精益求精的科研精神。园内兰花清雅高洁、四季常青，自古象征“不因无人而不芳”的君子品格。大家实地观摩花卉育种、精密培育、科学管护全过程，深刻体会到科研工作者数十年如一日扎根一线、精耕细作、久久为功的治学态度。师生纷纷表示，兰花“低调内敛、坚韧生长、质朴向善”的特质，与科研工作者潜心治学、静心育人、甘于奉献的职业底色高度契合，为新时代师德修养提供了生动的精神范本。
下午，师生实践团走进张载祠（横渠书院），沉浸式体悟关学文化精髓与千年师道传承。张载祠作为北宋理学关学发源地、传统师德文化教育高地，承载着厚重的中华教育文脉。全体人员认真聆听讲解，细读碑刻文脉、瞻仰千年古柏、回望讲学历史，深度领会“为天地立心，为生民立命，为往圣继绝学，为万世开太平”的横渠四句宏大抱负，感悟中华优秀传统文化中胸怀家国、笃行担当的精神内核。同时，大家深入学习张载“言有教、动有法、昼有为、宵有得、息有养、瞬有存”的修身治学理念。先贤严于律己、知行合一、立德树人、心怀家国的治学精神，生动诠释了学高为师、身正为范的师者准则，为全体教职工筑牢师德根基、明晰育人使命提供了深厚的文化滋养，也为青年学子树立了修身治学、立志担当的精神标杆，让同学们在传统文化浸润中坚定理想信念、厚植家国情怀、砥砺奋进品格，切实打造了一堂行走的“大思政课”。
此次实践联学，将科研实践体验与中华优秀传统文化浸润有机融合，既是学院持续深化师德师风教育的重要载体，也是推进“大思政课”建设的生动实践。师生们纷纷表示，将汲取先贤精神养分，教师坚守育人初心、涵养高尚师德；学生立志勤学笃行、勇担时代使命，把本次研学收获转化为教学科研、求学奋进的实际行动。
