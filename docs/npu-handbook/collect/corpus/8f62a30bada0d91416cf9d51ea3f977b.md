# 西北工业大学专利中心运营公告-西北工业大学资产经营管理有限公司

全校师生，各有关单位：
西北工业大学专利中心成立于1987年，隶属于西北工业大学，是国家知识产权局批准设立的专利代理机构（机构代码61204），也是国防知识产权局批准的全国34家国防专利代理机构之一（编号024）。
根据学校机构改革总体方案，2024年1月1日起学校独家授权西北工业大学国家大学科技园运营“西北工业大学专利中心”，开展专利代理、著作权代理、专利检索导航等相关服务工作。校内师生办理专利代理业务可通过翱翔门户知识产权系统办理，在“提交方式”中选择“西北工业大学专利中心”。校外申请人办理专利代理业务，请直接联系西北工业大学专利中心。
西北工业大学专利中心将一如既往地为广大客户提供优质服务，为科技创新与成果转化提供有力支撑！
