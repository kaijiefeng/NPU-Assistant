# 航海学院-西北工业大学医院

责任医师：亢秀丽（主治医师）
简介：
亢秀丽，主治医师，从事内科急诊科临床工作20余年，擅长内科高血压、冠心病等常见病、多发病的诊治，以指导健康生活、心理疏导和药物治疗相结合。急危重症高热、急性荨麻疹、胸痛等的抢救。曾在陕西省人民医院急诊科和心血管科进修学习。
（备注：学院责任医师是医院与学院之间的桥梁，可为我校师生提供健康咨询、健康宣教、体检结果释疑、急救知识技能培训等服务。有需求者，可通过扫描学院责任医师二维码联系。）
