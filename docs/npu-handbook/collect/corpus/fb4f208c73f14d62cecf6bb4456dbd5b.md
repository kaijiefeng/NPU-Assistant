# 会议费（国内）报销凭据及指南

一、会议形式
会议形式包括线下会议和线上会议。
二、开支范围
1.线下费用：住宿费、伙食费、其他费用（会议场地及设备租金、市内交通费、文件印刷费、办公文具、医药费等）；
2.线上费用：能够明确对应具体会议的设备租赁费、线路费、电视电话会议通话费、技术服务费、软件应用费、音视频制作费等。
三、会议组织相关规定

地点选择
1. 优先安排校内场所
2. 超过50%本地人员参会的会议原则上在本地召开
3. 不得到国家命令禁止的风景名胜区召开会议
会期确定
根据业务活动实际情况确定
1. 会期原则上不超过1天半，传达布置类不得超过1天
2. 报到和离开时间合计不得超过1天半，不超过20人的小型研讨会、座谈会、评审会等会议报到和离开时间合计不得超过1天。
原则上不超过3天
人数控制
根据业务活动实际情况确定
原则上控制在150人以内（面向学生的管理会议除外）
根据实际需要合理确定
住宿安排
1. 本地召开的会议本地人员原则上不安排住宿
2. 确实需要安排工作人员住宿，人数控制在会议工作人员50%以内
工作人员数量
1. 工作人员数量控制在代表人数10%以内
2. 国际会议可招募一定数量志愿者

综合定额以实际发生的费用项目分项定额标准总额为上限，结合线下实际参会人数、时间进行核算，超支部分不予报销。
国内会议工作人员食宿费用定额标准与会议代表一致；国际会议工作人员食宿费用定额标准为450元/人/天，志愿者用餐或者发放误餐补贴定额标准为100元/人/天。
2.线上费用
线上费用不纳入综合定额标准内核算，凭合法票据原则上在会议预算内据实列支。
五、会议相关费用参考标准
1.参会人员国际旅费、城市间交通费标准参照学校外国文教专家旅费或国内差旅费标准执行。
2.校外专家发放的咨询费、讲课费、评审费、劳务费、同声传译人员翻译费等人员费用，参照《西北工业大学评审费等劳务支出管理办法》（办转财字〔2020〕94号）执行。
六、报销凭据
1.会议通知（加盖举办单位公章的正式文件）；
2.西北工业大学会议费预算表（科研经费开支的不安排住宿的国内学术会议，可不提供；在“计划财务部官网-常用下载-会计核算”下载)；
3.西北工业大学会议费报销单（财务系统填写网报后生成）；
4.参会人员签到表或加盖举办单位公章的参会人员名单；
5.住宿、用餐、会议场地租金、设备租赁、软件应用、音视频制作等费用票据及明细清单（金额达到学校合同签订起点的需提供合同）；
6.其他资料（如国际会议需提供上级主管部门批准办会的文件；涉密会议按照保密规定提供报销资料；委托办会的需提供合同）。
七、禁止事项
1.严禁各单位借会议名义组织会餐或安排宴请；
2.严禁套取会议费设立“小金库”；
3.严禁在会议费中列支公务接待费；
4.严禁扩大会议费开支范围，擅自提高会议费开支标准；
5.会议住宿不得安排高档套房，用餐安排自助餐或者工作餐；
6.不得使用会议费购置电脑、复印机、打印机、传真机等固定资产；
7.会议期间不得组织会议代表旅游及与会议无关的参观；
8.严禁组织高消费娱乐、健身活动；
9.严禁以任何名义发放纪念品。
