# 后勤部办公室党支部开展植树主题党日活动

春回大地，万物复苏。为共建美好校园，增强大家爱校护绿意识，在植树节来临之际，3月11日下午，后勤部办公室党支部联合后勤集团物业服务中心党支部，在友谊校区健翔楼南侧，开展“播种绿色希望 共建美好校园”植树主题活动。
下午，大家兴致满满来到活动现场，戴上白手套、拿起大铁铲，已经迫不及待地想投入到“干活”的实践中去了。活动开始前，绿化师傅们首先向大家介绍基本的种植方法，怎样挖坑植树、怎样封土浇水等。大家听得认真、干得起劲儿。活动现场，5人一组，有的挖坑、有的扶苗、有的浇水……在大家团结协作下，不一会儿，一棵棵月季树已“亭亭玉立”在沃土之上。虽然人人满头是汗、脚下沾泥，但是看着自己劳动的成果，脸上洋溢着收获的喜悦。
这次植树活动，不仅为校园环境提升增添了一抹绿色，激发了大家植绿护绿、爱校护校的热情，同时也进一步增强了全体党员干部崇尚劳动、团结协作的精神，以自己的实际行动践行劳动育人宗旨，建设美丽校园。（撰稿人：毛淑兰，审稿人：韩争胜）
