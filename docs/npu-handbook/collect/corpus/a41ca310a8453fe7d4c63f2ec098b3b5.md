# 爱尔兰

爱尔兰·都柏林·外交部统办D免签90天内需开具出境证明
使馆签证处地址：塔园办公楼2号楼11层请到英国使馆签证处留取指纹：朝阳区丰联大厦B座11层，外交领事服务中心，约一个半月
使馆网址：https://www.ireland.ie/zh-hans/china/beijing/
查询签证状态网址：https://www.ireland.ie/zh-hans/china/beijing/fuwu/qianzheng/qianzhengjieguo/
TEL：65326945 FAX：65326857
共用一份的申请材料按照本手册序号顺序依次夹在团长护照内，个人单独的申请材料按本手册序号顺序夹在个人护照内。
因公短期签证要求:
照片：3.5*4.5白底2张，半年内近照
表格：1份 在线填写并打印 http://www.inis.gov.ie/
正部长及正部级以上官员因公访爱，随行团组成员（不包括记者和商人）可免留指纹，可申请免签贴纸。需在照会中注明带队人为正部级或以上。
提前准备预约信息 例：工信部+二级单位名简称+姓名+手机号
所有材料装在透明文件袋内
1.爱尔兰预约名单表（机打）
2.签证表（使馆根据在线表格内容颁发签证，表格填错了签证也是错的）
3.护照首页复印件 2份
4.本土邀请信（复印件即可）参加会议需提供缴纳注册费的证明
5.户口本复印件及翻译件（整本）
6.在职费用证明（英文、签字盖章）
7.照会译文
8.中文照会
9.欧洲名单表（三人及以上）
10.确认函译文（外交领事服务中心抬头的照会译文）
11.英文申请信(每人一份，申请人签字，说明赴爱性质以及停留时间，申请人的联系信息)
12.营业执照复印件/组织机构代码证复印件及翻译件
13.移民局网站上出具的5年内出入境记录查询报告（http://s.nia.gov.cn）
也可通过微信小程序“移民局”查询获得
此国家为外交部统办，还需按顺序准备好以下材料：
1照会复印件（由外事中心提供并复印）
2“二维码”信息表
3任务批件（确认件和通知书）复印件、外专局批件等内部备案材料
