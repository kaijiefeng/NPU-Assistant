# 国际教育学院开展安全教育主题班会

为帮助国际学生增强安全防范意识，提高安全防范能力，国际教育学院于12月1日晚在海天苑会议室开展了以安全教育为主题的班会活动。本次班会分为三个部分：法律法规、日常管理和学术学风建设，由留学生辅导员雷宇晨子主持，线上线下共80余名留学生参与了本次班会。
雷宇晨子首先对与国际学生密切相关的法律法规条款进行了阐释，并强调了来华留学生签证、保险、外国人临时住宿登记的重要性，以及学校对学生涉毒、非法打工等违法行为的零容忍。此外，雷宇晨子通过案例强调了校园安全、消防安全、宿舍安全注意事项，以及遇到危险时的应对措施。最后，针对近期的考试周，老师们为大家介绍了考前复习准备方法，并强调了考风考纪问题。
国际教育学院高度重视国际学生安全问题，本次安全教育主题班会进一步加强了国际学生对安全的重视，提高了同学们的自救自护防范能力，为学院持续推进安全稳定工作奠定了基础。
（审稿：李自伟）
