# 校长宋保维院士寄语2026届本科生：赓续精神血脉 奔赴时代山海

6月25日上午，西北工业大学2026年本科生毕业典礼暨学位授予仪式在长安校区翱翔体育馆举行。
典礼上，西北工业大学校长、中国工程院院士宋保维以《赓续精神血脉 奔赴时代山海》为题致辞，向全体毕业生致以热烈的祝贺，并送上诚挚的祝福与殷切的嘱托。
以下为致辞全文——
赓续精神血脉 奔赴时代山海
——在2026年本科生毕业典礼暨学位授予仪式上的讲话
西北工业大学校长 宋保维
亲爱的同学们、老师们，各位来宾、家长朋友们：
大家上午好！盛夏终南，风光正好；骊歌悠扬，逐梦远航。今天，我们隆重举行2026届本科生毕业典礼暨学位授予仪式，共同见证大家圆满完成四年学业，即将奔赴人生新的征程。首先，我谨代表全校师生员工、代表张云明书记，向同学们致以最热烈的祝贺！向辛勤耕耘的教职工、辛勤付出的各位家长，致以最衷心的感谢和最诚挚的敬意！
同学们，四载工大岁月，是你们潜心求学、拔节生长的时光。校园各处留下了你们勤学奋进的身影，你们在运-20物理样机前、在为国铸剑雕塑旁，聆听百名“总师思政课”；竞赛赛场记录了你们敢闯敢创的担当，无数个深夜鏖战，你们在科创赛场夺金争先；实践路上印下了你们逐梦前行的脚步，你们在革命圣地延安传承红色基因，在国防军工院所厚植蓝色情怀，在30余个国家和地区翱翔多彩世界。从初入校园懵懂憧憬，到学有所成志存远方，大家在一次次探索与实践中锤炼过硬本领。“公诚勇毅”的校训、“三实一新”的校风，已然成为刻在你们身上的鲜明印记。
同学们，2026年，是意义重大的一年；在“十五五”规划开局之年，我们同时迎来中国共产党成立105周年和红军长征胜利90周年。三大重要节点交汇相伴，为你们的毕业征程赋予了厚重底色，也为前行之路标注了精神航向。中国共产党从南湖启航，带领中华民族实现从站起来、富起来到强起来的伟大飞跃；二万五千里伟大长征淬炼出不畏艰险、矢志奋斗的精神品格，成为我们攻坚克难、砥砺前行的精神源泉。一直以来，西工大深耕“三航”国防科技领域，为党育英才、为国铸重剑，培养了大批服务大国重器研制、支撑国防现代化建设、保障国家安全的战略后备力量。近九十载办学积淀，学校形成了西部国防军工高校特有的总师育人文化，这既是对历代校友成长轨迹的总结，更是西工大人独有的精神底色。
同学们，你们即将告别校园，有的选择继续深造潜心学习，有的奔赴国防一线建功立业，有的扎根基层服务社会，还有的投身浪潮创新创业。在此，我向大家提三点期许，愿你们赓续精神血脉，汲取奋进力量，勇敢奔赴属于自己的星辰大海。
一、以信仰为舵，心怀家国，做矢志不渝的追梦者
习近平总书记强调：“青年的理想信念关乎国家未来。青年理想远大、信念坚定，是一个国家、一个民族无坚不摧的前进动力。”西工大，因国防而生、因强军而兴、随科技而强，一大批优秀校友怀揣理想奔赴四方，成长为型号总师、技术领军人才，以过硬本领担当强国使命，诠释着矢志报国的赤子情怀。我校1996级本科校友、系列固体火箭发动机总师王健儒，毕业后义无反顾选择了航天动力技术研究院，扎根航天动力研制一线二十余载，带领团队攻坚克难、久久为功，冲破多项国外技术壁垒，接连突破40余项核心技术，成功研制大推力固体发动机，支撑了多款运载火箭成功飞天，夯实了我国自主航天动力的根基，展现了新时代航天科技战线以终生奋斗追梦航天强国的动人风采。希望大家传承西工大军工报国薪火，校准人生航向、锚定强国复兴使命，坚守理想、心怀赤诚，让青春在为国奉献中绽放最美光彩。
二、以实干为帆，勤学笃行，做精益求精的奋斗者
习近平总书记强调：“要脚踏实地,埋头苦干,不驰于空想,不骛于虚声。”长征的胜利、大国重器的诞生，均源于脚踏实地的坚守与持之以恒的钻研。毕业从来不是学习的终点，而是终身求索、躬身实践的全新开端。人工智能飞速发展，知识迭代不断加快，唯有坚持学习、锤炼本领，才能紧跟时代步伐。我校1999级本科校友、歼-10CE总设计师李俊，在校深耕飞行器设计专业，厚植航空报国初心。走上科研岗位后带队自主突破多项战机核心技术，研制全天候多用途外贸主战机型歼-10CE。该机型海外服役表现广受赞誉，已成为彰显大国航空实力的硬核名片。希望大家秉持西工大人低调务实、严谨笃行的优良作风，沉下心、扑下身，以“十年磨一剑”的匠心钻研业务，以认真负责的态度提升本领，努力成长为行业骨干、领域先锋。
三、以担当为桨，勇立潮头，做敢为人先的开拓者
习近平总书记强调：“青年要保持初生牛犊不怕虎、越是艰险越向前的刚健勇毅，勇立时代潮头，争做时代先锋。”敢闯敢试、勇于创新，是西工大人才辈出、勇攀高峰的精神密码。从翼身融合民机技术领跑全球，到“飞天一号”直冲云霄，再到仿生蝠鲼潜水器探秘深海，学校一次次突破技术壁垒，靠的是敢为人先、探索不止的创新精神。我校2000级本科校友、中国航空工业集团“翼龙”系列总设计师唐勇，便是学校优秀毕业青年学生的优秀代表。他怀揣航空报国梦想，带领团队迎难而上、大胆创新，接连攻克多项核心技术，打造出享誉海内外的多款新型察打一体无人机，亮相九三阅兵，成为守护国家安全的硬核力量。希望大家永葆青年的锐气和闯劲，弘扬总师育人文化，主动拥抱变革，矢志创新求索，用智慧与担当书写新一代西工大人为国铸剑的青春华章。
亲爱的同学们！秦岭铭记你们日夜勤学的铿锵书声，沣河镌刻你们朝气蓬勃的青春荣光！纵使前路风雨兼程，母校永远是你们温暖的港湾、无畏向前的强大支撑！欢迎大家常回母校看看，共忆青春、共话未来。愿全体2026届毕业生，赓续精神血脉，奔赴时代山海，在中国式现代化的伟大征程中乘风破浪、绽放光彩！
最后，祝愿同学们前程似锦、一帆风顺！祝愿各位老师、家长身体健康、万事顺遂！谢谢大家！
