# 西北工业大学电子信息学院第九次学生代表大会暨第六次研究生代表大会圆满举行

2026年5月24日，西北工业大学电子信息学院第九次学生代表大会暨第六次研究生代表大会在长安校区八九院报告厅举行，电子信息学院团委书记史越、校学生会主席团成员杨浩楠、校研究生会主席团成员孙抒祺、力学与土木建筑学院学生会主席团成员张元帅出席会议，电子信息学院全体学生代表参加会议。
全体代表通过预备会议听取《西北工业大学电子信息学院第九次学生代表大会暨第六次研究生代表大会筹备工作报告》，大会筹备工作准备完善，随后表决通过《西北工业大学电子信息学院第九次学生代表大会暨第六次研究生代表大会代表资格审查报告（草案）》《西北工业大学电子信息学院第九次学生代表大会暨第六次研究生代表大会会议议程（草案）》《西北工业大学电子信息学院第九次学生代表大会暨第六次研究生代表大会主席团、秘书长建议名单（草案）》。
下午14时，电子信息学院第八次学生代表大会暨第五次研究生代表大会正式开始，大会由杨家源主持。会议第一项，核查学生代表参会人数，全体起立唱国歌。
随后，杨浩楠、孙抒祺分别发言，他们结合在校学生会、研究生会参与工作的经历，分享了服务同学、组织活动和团队协作中的心得体会，也围绕学生组织如何更好发挥桥梁纽带作用、提升服务实效交流了自己的思考。
接着，史越对大会到场的学生代表表示欢迎，并对学生会和研究生会上一年的工作做出了简要的回顾，鼓励大家在新一届的工作中继续稳扎稳打、主动作为，不断提升学生组织的引领力、组织力和服务力。
大会听取并审议《西北工业大学电子信息学院第八届学生会工作报告》《西北工业大学电子信息学院第五届研究生会工作报告》和《西北工业大学电子信息学院第九次学生代表大会暨第六次研究生代表大会提案工作报告》，表决并通过《西北工业大学电子信息学院第九届学生会、第六届研究生会主席团选举办法（草案）》《西北工业大学电子信息学院第九届学生会、第六届研究生会主席团候选人名单（草案）》和《西北工业大学电子信息学院第九届学生会和第六届研究生会主席团选举总监票人、监票人、总计票人、计票人名单（草案）》。
下午15时30分，大会进行主席团候选人答辩环节，选举西北工业大学电子信息学院第九届学生会主席团和第六届研究生会主席团，七名候选人分别从工作经历，职务认知，未来展望等不同方面做以介绍，参会学生代表对新一届主席团候选人有了更为深入的了解。答辩环节结束后，学生代表现场填写选票并投票。
下午16时30分，针对《西北工业大学电子信息学院第八届学生会工作报告》《西北工业大学电子信息学院第五届研究生会工作报告》《西北工业大学电子信息学院第九次学生代表大会暨第六次研究生代表大会提案工作报告》《关于修改〈西北工业大学电子信息学院学生会章程〉的说明》和《西北工业大学电子信息学院学生会章程（修订草案）》进行讨论。
统票和监票环节结束后，大会公布了答辩人员所得票数，并宣布王文钰、胡琬悦、周弋滋为电子信息学院第八届学生会主席团成员。闫李林、陈忍为第五届研究生会主席团成员。
第三阶段，大会表决通过《西北工业大学电子信息学院第九届本科生常任代表选举办法（草案）》《西北工业大学电子信息学院第九届本科生常任代表候选人名单（草案）》和《西北工业大学电子信息学院第九届本科生常任代表选举总监票人、监票人、总计票人、计票人名单（草案）》，随后选举出第八届电子信息学院本科生常任代表，史越宣布了选举结果。
最后，史越进行闭幕讲话，大会圆满结束。
会后，两届学生会及研究生会主席团成员及第九届本科生常任代表在学院楼119会议室召开了西北工业大学电子信息学院第九届常任代表会议第一次全体大会，讨论了新一届委员的工作分工。
西北工业大学电子信息学院第九次学生代表大会暨第六次研究生代表大会圆满完成各项议程，胜利闭幕。站在新的起点上，电子信息学院全体学生骨干将始终牢记“全心全意服务同学”宗旨，持续锤炼务实作风、强化责任担当，与全院青年学子一道踔厉奋发、勇毅前行，以更加昂扬的姿态为学院高质量发展贡献青春力量。
