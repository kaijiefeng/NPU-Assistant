# 教务部党支部开展树立和践行正确政绩观学习教育专题党课

2026年6月30日上午，教务部党支部组织开展树立和践行正确政绩观学习教育专题党课。党支部书记王海鹏以《树立和践行正确政绩观 奋力书写“十五五”高质量发展新篇章》为题讲授党课。
王海鹏围绕深刻认识学习教育的重大意义、准确理解正确政绩观的丰富内涵、对照反思警惕政绩观偏差、以实干实绩推动事业发展四个方面进行了详细阐释。他结合教务部工作实际强调，全体党员要牢牢把握正确政绩观核心要义，持续强化担当作为，锚定立德树人根本任务，不断优化学科专业结构，深化教育教学改革，完善“招生—培养—深造”联动机制，全力推动人才培养“十五五”规划任务落地。
与会党员纷纷表示，将持续加强学习，自觉践行正确政绩观，立足岗位履职尽责，切实把学习成效转化为推动人才培养工作提质增效的实际行动，为学校“十五五”高质量发展贡献力量。
（文字：王青青；图片：王青青；审核：马婷婷）
