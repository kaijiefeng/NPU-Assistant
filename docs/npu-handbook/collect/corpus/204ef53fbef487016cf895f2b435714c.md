# 喜报！西北工业大学翱翔队再捧沙赛团队最高荣誉——"金沙鸥"奖

5月1日至4日，红牛第十四届商学院沙漠挑战赛（“沙14”）在内蒙古阿拉善腾格里沙漠成功举行，全球110多所商学院的4000多名勇士在此集结。西北工业大学翱翔队30名师生以超强意志力和团队协作精神，超A组勇夺第6名，继沙11后团队再次荣获赛事最高荣誉"金沙鸥"奖，C队全员获"金沙漏"奖，展现了西工大人团结协作、坚韧不拔的精神风貌。
“沙14”翱翔队由西北工业大学MBA教育中心主任杨宏玲带队，包括1位超A队员、12位A队队员、6位B队队员、10位C队队员、1位团队经验丰富的顾问组成。
本届沙赛期间，首日沙尘暴若海浪奔腾，次日艳阳似火烧，决战日风雨交加如怪兽发狂，被称为“史上最虐沙赛”，考验着组委会的应急能力，也考验着每一位队员的意志，每一所院校的团队组织能力。
赛场内外，闪耀着一个个动人的故事。超A队员王宁勇猛直前被称为“宁神”；A队队长、曾登顶珠峰的余国明稳如全队定心丸；领队徐祥海细致入微、排兵布阵被称为“团队粘合剂”；C队仅有的两位男生——王通和张达在完赛之后带领其他几位女生队友，迅速完成帐篷搭建、物资领取、场地清理等工作，被称为“环保大使”。那些奋斗的身姿、感人的瞬间，早已镌刻在大家心中。
翱翔队用行动诠释了“特别能吃苦、特别能战斗、特别能攻关、特别能奉献”的精神。沙赛虽已落幕，但精神永不退场。这场跨越沙海的心灵接力，在广袤大地上播撒下团结拼搏的火种，必将在新时代的征程上赓续传承。
