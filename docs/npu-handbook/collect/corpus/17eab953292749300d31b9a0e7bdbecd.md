# 重庆科创中心党支部参观明月坊抗战大后方高校内迁主题展馆

6月10日，重庆科创中心党支部组织党员及职工代表前往明月坊抗战大后方高校内迁主题馆，开展主题党日活动。
明月坊展馆作为重庆市爱国主义教育基地，通过“烽火内迁”“弦歌不辍”“教育救亡”“薪火相传”四大展区，全景呈现了抗战时期高校内迁的壮阔历程。在讲解员的引导下，党员们驻足观看泛黄的历史照片、珍贵的书信手稿及复原的校园场景，深入了解国立西北工学院、西南联大、中央大学、交通大学等高校在战火中辗转办学、科研报国的感人事迹。一张国立西北工学院校歌的照片、一张交大师生在竹篾黄泥房中坚持教学的照片，一段复旦大学在北碚创办“中国第一所核农学专业”的记录，让党员们深切感受到先辈“教育不辍、科技强国”的坚定信念。
此次活动不仅是一次历史回顾，更是一场精神洗礼。科创中心党支部将带领广大员工一起铭记先辈们“在炮火中传薪，于困境中育人”的担当，立足岗位践行初心，以实际行动传承红色基因，勇担时代使命。
