# 高校-高中”联动，强化交流沟通——重庆招生组赴重庆参加中学校庆等系列活动

2023年11月17日-18日，重庆招生组组长林伟老师应邀参加重庆外国语学校校庆和重庆巴蜀科学城中学交流活动。
11月17日晚，林伟老师应邀参加重庆外国语学校建校六十周年校庆活动，与该校唐刚校长、张季菁书记、唐东副校长、王俊副校长等认真交流，并受邀参加18日上午的“弦歌六秩，行健未来”主题校庆成果汇报活动。重庆外国语学校全名为四川外国语大学附属外国语学校，是我校的重要生源中学，2022年、2023年共有8位同学进入我校继续学习。
18日下午，林伟老师和来自上海交通大学等兄弟高校的招生老师与重庆巴蜀科学城中学赵文平校长、江文副校长、何南方副校长等座谈交流，就中学发展、学科建设需求、学生生涯规划等进行了认真探讨沟通，会后还参加了教职工活动。重庆巴蜀科学城中学是重庆巴蜀中学在科学城建立的分校，引进了巴蜀中学的师资资源、教研资源、管理经验等优势，招聘了一批对教育教学充满了热爱的骨干教师，是一所未来值得期待的学校。
本次系列活动我校重庆招生组与重庆中学有个更深入地沟通与交流，进一步加强了与重要生源中学的沟通和联系，为招生工作的顺利开展奠定了良好基础。
