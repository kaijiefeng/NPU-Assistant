# 西北工业大学网络空间安全学院开题答辩（张叶欣）

西北工业大学网络空间安全学院开题答辩（张叶欣）
一、开题答辩题目：复杂场景社团发现理论与算法研究
二、开题答辩人：张叶欣
三、开题答辩时间：2025年1月20号上午10:00
四、开题答辩地点：毅字楼606
五、开题内容简介：社团发现通过对观测到的网络进行节点的社团归属标签预测来揭示潜在的社团结构，其在推荐系统、自然语言处理、蛋白质功能预测社会学行为分析和舆情监测等多个领域有着广泛的应用。然而，在理论层面上，尤其是在信息论方面对于社团发现的研究尚显不足，进而严重制约了技术的进步以及新应用场景的开拓。因此，本研究致力于社团发现的信息论基本极限推导以及算法性能的理论分析，期望通过理论研究指导算法的改进和设计，使算法具备更优的性能、更高的效率、更强的鲁棒性，从而更好地服务于实际应用。
六、开题答辩人简介
个人简介：张叶欣，2022100377,1995年9月生，网络空间安全专业，导师孙文教授。
