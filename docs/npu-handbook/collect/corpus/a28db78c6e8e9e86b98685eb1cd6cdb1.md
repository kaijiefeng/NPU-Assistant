# 外国语学院召开2025年度党支部书记抓党建述职评议考核大会

3月5日下午，外国语学院2025年度党支部书记抓党建述职评议考核大会在学院楼204会议室召开。学院党委领导班子、辅导员代表、师生党员代表等参加了本次会议。会议由学院党委书记王高祖主持。
会上，学院4位教职工党支部书记、6位学生党支部书记依次进行述职。各支部书记围绕年度党建工作重点任务，认真总结了支部在深入学习贯彻习近平新时代中国特色社会主义思想，强化党支部政治功能和组织功能，落实基层党建工作重点任务，做好师生思想政治教育，落实全面从严治党要求等方面的工作成效，深入分析了存在问题并结合学院发展和支部工作实际，明确了下一步的整改方向和工作思路。
党委书记、党委副书记、党委委员等分别对教职工、学生党支部的年度工作进行点评，既肯定了各支部在强化政治功能、夯实组织基础、推动党建与业务融合等方面的积极探索和显著成效，也指出了工作中存在的不足，提出了针对性的改进建议，为后续工作开展指明了方向。
王高祖对各党支部所做出的努力和取得的成绩给予了高度评价与充分肯定，并提出三点期望：一是持续强化政治建设，坚持深入学习贯彻习近平新时代中国特色社会主义思想，立足教育强国建设，从严从实抓好党内政治生活，切实把学习成效转化为推动改革发展的强大动力；二是着力推动问题整改。坚持问题导向，针对查摆发现问题，明确整改方向，认真落实整改，切实把整改成效转化为提升支部建设质量、改进工作作风的实际成效；三是深化党建业务融合，聚焦落实立德树人根本任务和学校“十五五”规划目标，持之以恒将党旗插在人才培养和科学研究最前沿最基层，要把党建优势转化为发展优势，以成果为牵引凝聚发展合力，以“要上进、要努力、要奋斗”的干事创业精神推动党建与业务深度融合，引领学院事业高质量高水平高标准发展。（文/王开薇；审稿/王高祖）
