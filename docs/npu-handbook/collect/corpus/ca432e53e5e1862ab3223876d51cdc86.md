# 后勤部办公室党支部召开专题党课暨理论学习会

为扎实推进深入贯彻中央八项规定精神学习教育，7月10日下午，后勤部办公室党支部组织召开专题党课暨理论学习会。会议由党支部书记张文刚主持，全体党员参加学习。
首先，由党支部副书记韩争胜为全体党员讲授“把握精神核心要义 筑牢拒腐防变思想”的专题党课。他从习近平总书记关于加强党的作风建设的重要论述、八项规定何以深刻改变中国、关于中央八项规定精神的重要论述、深入贯彻中央八项规定精神学习教育、违反中央八项规定精神典型问题等五个方面展开详细讲解。通过精准解读与深刻剖析，全体党员对“规定”的边界红线有了更深刻的认知，对“精神”所蕴含的清廉本质有了更进一步的领悟。最后，韩争胜指出，贯彻中央八项规定精神绝不能停留在口头表态和文件学习上，在实际工作中，必须时刻以中央八项规定精神为镜鉴，切实把中央八项规定精神内化于心、外化于行。
接着，全体党员集体学习了《关于认真学习贯彻习近平总书记重要讲话精神推动深入贯彻中央八项规定精神学习教育取得实效的通知》《习近平总书记在中共中央政治局第二十一次集体学习时强调坚持从抓作风入手推进全面从严治党把新时代党的自我革命要求进一步落实到位》等7月份的理论学习内容，并结合所学内容进行了交流研讨。
会议最后，与会党员纷纷表示，将会把学习贯彻中央八项规定精神作为一项长期的政治任务贯穿工作的方方面面，切实把作风建设成果转化为服务师生的实际行动，以作风建设新成效为学校事业高质量发展贡献后勤力量。（撰稿人：毛淑兰；审稿人：韩争胜）
