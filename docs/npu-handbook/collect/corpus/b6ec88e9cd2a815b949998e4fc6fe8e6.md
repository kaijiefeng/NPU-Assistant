# 后勤办公室党支部组织党员群众观看党史教育影片活动

根据学校党委组织部关于组织观看党史教育电影《大会师》、《风云1927之八七会议》的通知要求和机关党委的具体安排。9月12日（星期三）下午2:30，后勤办公室党支部全体党员、群众前往西安市西稍门十字开元商城万达国际影城集中观看了《风云1927之八七会议》和《大会师》这两部党史教育电影。
期间，全体党员、群众认真观看，重温了我们党领导中国工农红军进行“八一”南昌起义、秋收起义、万里长征、四渡赤水、飞夺泸定桥和延安会宁大会师的艰苦奋斗岁月和光辉历程。党员和群众们通过观看党史教育电影，进一步增强了爱党、爱国情怀，思想上进一步得到了提升，受益匪浅、深受教育。
