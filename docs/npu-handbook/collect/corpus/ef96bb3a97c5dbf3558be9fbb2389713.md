# 微世界，塑未来” 机电学院庆“六一”亲子活动

2023年5月28日，由机电学院支持，学院工会在健翔楼多功能活动中心举办了庆祝“六一”国际儿童节的活动。学院工会主席卜昆教授参加了本次活动，并祝孩子们儿童节快乐！
图1卜昆教授致词
活动以“微世界，塑未来”为主题，进行了绿色微景观亲子DIY制作。邀请非遗继承人任老师讲授了微景观的制作过程和技巧，并进行了现场指导。孩子们眼里的小世界通过小小的植物和美丽的装饰逐步呈现出来。
图2互动制作
平时忙于科研教学工作的老师因为本次活动陪伴了孩子，增加了亲子互动。同事之间也增加了聊天互动，孩子们也结交了自己的好朋友，增加了小友谊。活动现场欢声笑语，现场洋溢着欢乐的气氛。
图3看我们的“微世界”
家长和孩子一起动手，共同努力建设除了自己的美丽小世界。本次亲子活动让孩子们体会到美好要靠自己亲手创造。愿每个孩子都拥有美丽的微世界，塑造自己美好的未来！
