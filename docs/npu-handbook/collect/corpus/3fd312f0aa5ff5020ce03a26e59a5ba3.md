# 关于西北工业大学莫航学院开展2026年本科生学业指导教师配备工作的通知

为加快建设一流本科教育，助力学生做好学业发展规划，全面提升本科人才培养质量，根据《西北工业大学莫航学院本科生学业指导教师管理实施细则》相关规定，学院启动本科生学业指导教师配备工作，现将有关事项通知如下：
一、指导周期
学院为全体2025级本科生配备学业指导教师，指导周期不少于三年，原则上导师一经选定不得随意变更。学生进入毕业设计阶段，经学生本人申请或导师提出要求，学业指导教师可继续负责该生毕业设计指导工作。
互选成功后，学生应主动对接导师建立常态化联系，导师每学期内每月与每名学生开展面对面交流至少1次，并将指导情况记入《西北工业大学莫航学院本科生学业指导教师学生成长记录档案》（附件1）；学生须珍惜指导机会，落实个人学业规划。
二、导师范围与指导名额
学业指导教师为航空、航天、电子信息等相关学院，与飞行器设计与工程、航空航天工程、探测制导与控制技术、电子科学与技术相近专业的副高级及以上职称教师。
导师指导名额实行限额管理，一名学业指导教师每年级指导学生不超过2名，指导学生总数不超过4名。同学们选择导师时，可结合教师研究方向与自身学业发展需求合理选报。
三、开展方式
本科生学业指导教师配备采用“师生双向选择与学院统筹协调相结合”的方式，分以下四个步骤开展。
（一）查询导师信息。学院在网站公布《本科生学业指导教师信息一览表》（附件2），同学们可在学校网站教师主页查阅教师基本情况，并通过办公邮箱等渠道与导师沟通咨询。沟通交流请文明得体、简明扼要，邮件标题建议规范命名为：“本科生导师咨询-莫航学院-姓名-学号”，并附上简短自我介绍或个人简历。
（二）填报志愿。同学们填写《西北工业大学莫航学院本科生学业指导教师配备申请表》（附件3），在“个人情况说明”栏如实填写课程成绩、实践成绩、英语水平及感兴趣的研究方向等信息，经本人签字承诺内容真实、准确后生效。
（三）导师确认。学生与意向导师充分沟通、达成一致后，由导师在《本科生学业指导教师配备申请表》（附件3）“接收导师意愿”栏签字确认（可电子签），视为双选成功。双选确定后，请同学们于11月20日前将申请表纸质版提交至莫航学院教育教学中心409办公室（马老师处）备案留存。逾期未提交材料的，视作放弃本轮自主选报资格，学院将按照专业相近原则予以统筹调配。
（四）公示与备案。双选名单经学院汇总后进行公示，公示无异议后确认互选结果，最终名单由学院上报教务部备案。指导周期内原则上不得变更导师，确因转专业、保留学籍、休学复学、专业学习、毕业设计或其他特殊情况需要变更的，须经原导师、新导师、学生三方协商一致，于每年10月份向学院教育教学中心提交《西北工业大学莫航学院本科生学业指导教师变更申请表》（附件4），经学院教学主管部门审核批准后方可变更。
四、其他说明
学业指导教师将围绕培养方案解读、选课规划、学业方法指导、创新创业与学科竞赛、考研留学、就业发展、本研衔接等方面开展全流程学业指引，同学们应当尊重导师，主动汇报个人学业情况，认真听取指导建议，根据导师意见动态调整个人学业规划。
请各位同学高度重视，按要求按时完成各环节工作。如有政策、流程相关疑问，可咨询学院教育教学中心。
