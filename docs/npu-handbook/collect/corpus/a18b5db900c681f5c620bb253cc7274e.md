# 定期存款银行竞争性选择项目评审结果公告

根据《中央预算单位资金存放管理实施办法》（财库〔2017〕176号）相关规定，西北工业大学于2023年8月1日召开“西北工业大学定期存款银行竞争性选择项目”评审会，经评审委员会综合评分，现将评审结果予以公告。
一、项目名称
西北工业大学定期存款银行竞争性选择项目
二、项目编号
西北工业大学定存-2023-001号
三、定期存款金额
1.5亿元，一年期定期存款
四、入选银行信息
长安银行股份有限公司西安丝绸之路支行
五、公告期限
2023年8月2日至4日（3个工作日）
