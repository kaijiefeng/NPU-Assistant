# 工会党支部与计划财务部党支部联合开展“迎七一·守党纪”主题党日活动-校工会（帮扶办）/ 妇女联合会

为深入学习贯彻习近平总书记关于党纪学习教育的重要讲话和重要指示精神，扎实推进党纪学习教育走深走实，牢固树立廉政思想，涵养廉洁文化，6月26日下午，工会党支部与计划财务部党支部赴汉景帝阳陵博物院，联合开展廉洁文化主题党日活动。
“俭，德之共也；侈，恶之大也。”党员们在专业讲解的带领下，参观了汉风廉韵——汉代廉政文化特展，汉代注重培育整个社会的崇俭尚廉之风，大家认真聆听汉代廉洁文化思想，观赏清白镜、昭明镜等代表汉代廉政制度的文物，了解汉代廉政文化的历史风貌，感悟“以廉立身，以廉立业，以廉立世”的优秀传统文化。此外，大家还共同参观了考古陈列馆及帝陵外藏坑遗址保护展示厅。
此次廉洁文化主题党日活动，进一步强化了两支部党员廉洁自律意识和拒腐防变能力,大家一致表示，要传承践行中华优秀传统文化，强化纪律意识，守牢行为底线，从廉洁文化中汲取营养，把廉洁文化活动转化为知敬畏、存戒惧、守底线的行动实践。（文/钱娅群 张卉 图/韩关亮 审核/陈建军 罗玲）
