# 自动化学院召开“总师育人文化”引领人才培养研讨会暨名师论坛

为深入贯彻落实学校第十四次党代会精神，推动“总师育人文化”走深走实，11月5日下午，自动化学院在友谊校区1901会议室组织召开“总师育人文化”引领人才培养研讨会暨名师论坛。会议邀请了机电学院葛文杰教授、史仪凯教授，数学与统计学院孙浩教授、航空学院赵美英教授、化学与化工学院颜红侠教授等多位国家级、省级教学名师及艺教中心主任张清江参会指导，自动化学院副院长刘准钆、党委副书记易正阳、课程建设负责人、专业建设负责人及教师代表参会。会议由刘准钆主持。
会上，刘准钆首先传达了学校“总师育人文化”引领人才培养的顶层设计及推进情况，然后以《强化自动化类一流专业建设 推进总师育人文化走深走实》为题，介绍了学院坚持以一流专业建设为牵引，持续推进“总师育人文化”引领人才培养的思路和举措。易正阳阐述了学校“总师育人文化”的特质内涵及培养路径，然后从“育红心”“强特色”“重引领”三个维度展开，重点围绕学风建设、创新创业、社会实践、思政育人四个方面内容，系统讲述了学院以高质量学生工作推进“总师型”人才培养的系列举措。
交流研讨环节，与会教师结合自身教学科研等经历和对“总师型”人才培养的思考，围绕深化自动化类特色“总师型”人才自主培养模式积极建言献策。
在“总师育人文化”建设名师论坛环节，机电学院葛文杰教授、史仪凯教授，数学与统计学院孙浩教授、航空学院赵美英教授、化学与化工学院颜红侠教授、艺教中心主任张清江，自动化学院李玉忍教授、刘慧英教授、吴小华教授、樊泽明教授、李广文副教授等课程专家畅所欲言，围绕“总师育人文化”引领一流专业建设开展研讨，并以李俨教授等主讲的《自动控制原理》国家一流课程作为主要案例，对我院课程建设、教材建设以及教学团队建设等提出了宝贵意见。
与会人员一致认为，统筹推进一流专业建设，要强化顶层设计，坚持以总师育人文化为引领，以人才培养为主体，以质量提升为目标，以理念创新为先导，以资源建设为基础，以人工智能等先进技术手段为辅助，做到强理论、显特色、重实践，持续探索多元化教学方法，着力提升课程建设内涵，并积极发挥教学名师等引领作用，打造特色鲜明的一流专业。
刘准钆在总结发言中表示，学院将统筹规划、协同推进，通过持续深化教学改革、优化课程体系、加强校企合作等一系列措施，推进“总师育人文化”走深走实，着力培养“总师型”拔尖创新人才。
（撰稿：杜彤彤；审核：刘准钆）
