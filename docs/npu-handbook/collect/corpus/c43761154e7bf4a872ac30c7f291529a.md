# 西北工业大学莫航学院关于选聘2026级本科生班主任的通知

为适应新时代高等教育发展要求，进一步落实立德树人根本任务，深入开展莫航学院2026级本科生思想引领、学业指导、生涯规划指导与班级日常管理等工作，按照学校《西北工业大学班主任管理办法》(党政办发字〔2025〕20号)工作要求，现面向相关培养单位公开选聘2026级本科生班主任12人。有关事项通知如下：
一、选聘范围
在莫航学院开展教学工作的基础课程授课教师，以及航空学院、航天学院、电子信息学院等培养单位青年教师。
二、选聘条件
（一）具有较高的政治素质和坚定的理想信念，坚决贯彻执行党的教育方针政策，有较强的政治敏锐性和政治辨别力；
（二）师德高尚、作风正派，具有较强的纪律观念和规矩意识，忠诚党的教育事业，热爱学生思想政治教育工作，有高度的事业心、责任感和奉献精神；
（三）具备较强的组织管理能力和语言、文字表达能力，以及教育引导能力、调查研究能力，具备开展思想教育工作和价值引领工作的能力，具备较强的工作协调能力，能够较好地处理班主任工作与自身承担教学科研工作的关系；
（四）具备履行班主任岗位职责的身体条件。
三、主要职责
（一）思想政治教育。坚持以习近平新时代中国特色社会主义思想为指导，加强学生理想信念教育，引导学生树立正确的世界观、人生观、价值观，把培育和践行社会主义核心价值观融入班级管理全过程；
（二）党团和班级建设。定期召开责任班级的主题班会，举办党团活动、班级集体活动。会同辅导员组织开展班级学生骨干的遴选和评优推荐、学生思想动态调查和有关问题排查，做好特殊群体学生帮扶工作；
（三）班风、学风建设。充分发挥教学与科研经历优势，开展学科专业教育、学习方法教育、学风与学术道德教育，引导学生树立正确的学业态度和专业认知。掌握学生学习状态，指导学生开展课外学术实践活动，营造积极向上的学习氛围和创新创业氛围；
（四）学业、就业指导。及时跟踪掌握学生成长发展状态，积极参与教育教学活动，每学期至少开展2次主题班会，在专业方向选择、学业课程配置、科研创新实践、学术素质养成、职业生涯规划、就业创业发展等方面对学生进行指导，着力培养学生的学习实践能力、学术专业素养和国际视野，帮助学生丰富完善成长发展路径，提升成长发展质量；
（五）日常教育管理。经常性走进学生教室、宿舍、“一站式”学生社区，指导建设健康向上、互助和谐的班级和宿舍文化。了解学校各类危机事件应急处置预案和工作流程，协助做好危机事件处置工作。配合辅导员共同做好家庭经济困难、学业发展困难、心理问题等学生的帮扶指导工作；
（六）认真贯彻落实学校、培养单位的各项工作部署，积极参加相关工作培训和有关会议。主动学习研究思想政治教育理论与方法，积极开展相关调查研究。
四、选聘程序
（一）报名申请
申请人于2026年7月12日17:00前填写附件《西北工业大学莫航学院2026级学生班主任申请表》，发送至邮箱masstudent@nwpu.edu.cn。
（二）资格审核：学院对申请人进行资格审查与综合评议。
（三）审定公示：学院党委研究确定拟聘名单，公示无异议后正式聘任。
（四）岗前培训：学院统一组织岗前培训，强化班主任育人工作能力提升。

六、保障与激励
学院按校院规定落实工作量认定、考核与激励保障，表现优秀者优先推荐参评校级优秀班主任、青年岗位能手等个人荣誉。诚邀各位老师踊跃报名，投身育人一线，护航2026级本科生逐梦成长，共同助力学院人才培养高质量发展。
