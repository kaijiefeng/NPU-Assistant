# 莫斯科航空学院一行来院交流

10月29日，莫斯科航空学院航空技术学院院长德米特里・斯特烈列茨教授一行到访莫航学院，与学院师生代表开展座谈交流。学院院长范晓丽主持会议。
范晓丽对德米特里・斯特烈列茨院长一行表示诚挚欢迎，简要介绍了学院的整体办学情况，期待双方持续深化合作交流，完善育人体系，共同推进人才培养工作高质量发展。
德米特里・斯特烈列茨教授在发言中分享了莫斯科航空学院在航空专业教学理念与办学经验。他鼓励同学们用好中俄联合培养平台，把握宝贵学习机遇，努力夯实专业基础、拓宽国际视野。
座谈中，同学们结合自身学习与实践经历，围绕俄语课程学习、学业发展规划等内容积极提问、建言献策。与会教师认真听取了同学们的发言，表示将系统梳理收集到的意见建议，持续完善人才培养机制，不断助力青年学子成长成才。
此次座谈交流为师生搭建了沟通桥梁，有效助力同学们拓宽国际视野、深化专业认知。学院将以本次交流为契机，扎实推进协同育人，不断夯实“总师型”人才培养根基。
