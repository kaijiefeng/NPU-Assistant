# 西安翱翔工大正禾宾馆有限责任公司-西北工业大学资产经营管理有限公司

西安翱翔工大正禾宾馆有限责任公司成立于2018年7月19日，注册资本200万元，是西安翱翔工大后勤产业集团有限公司的独资子公司。
正禾宾馆1985年建成并投入使用，位于西北工业大学友谊校区校园内，使用面积约8000㎡，由东楼、西楼及附属配套设施组成，含独立停车场。作为集住宿、餐饮、会议、商务于一体的综合性服务实体，宾馆承接校内外各类型会议、用餐、住宿接待。宾馆现有客房137间，4个大、中、小型会议室。宾馆餐厅共有两层，290个餐位，设有散席大厅、宴会厅、豪华包间、普通包间等装修风格迥异的大中小型包间14间。大堂还设有休息区、商务中心、商品部等功能区域。
同时，学校委托正禾宾馆代管了友谊校区国际会议中心及东、西会议室，其中国际会议中心包含“国一”“国二”“国三”“国四”“国五”5个会议室。
此外，宾馆在友谊校区运营“云上南山”迎宾店（校内大超南侧）及“云上南山”正禾店（正禾宾馆门口南侧）。
