# 【机关风采】机关先进党支部篇：科学技术研究院党支部-机关党委

党建引领有组织科研 矢志为国铸重剑
2026年度机关先进党支部
科学技术研究院党支部
科学技术研究院党支部坚持以习近平新时代中国特色社会主义思想为指导，深入学习贯彻党的二十大和二十届历次全会精神，认真学习践行习近平党建思想和习近平总书记关于教育、科技、人才的重要论述，牢记“为党育英才、为国铸重剑”使命担当，锚定“天下工大、世界三航”远景目标，紧扣学校“十五五”规划部署，强化基层党组织政治功能和组织功能，充分发挥战斗堡垒作用，在国家奖申报、国家级平台建设、重大科研项目攻关中引领党员干部攻坚克难，推动学校科技创新核心任务实现历史性突破，为学校科研事业高质量发展提供坚强政治保障和组织保障。
强化政治引领，厚植科技报国理想信念。支部始终把党的政治建设摆在首位，大力弘扬科学家精神，厚植“总师育人文化”，围绕“全国科技工作者日”主题开展系列活动200余场，引导全校师生心怀“国之大者”，想国家之所想、急国家之所急、应国家之所需。严格落实“三会一课”、主题党日等组织生活制度，坚持把党旗插在科学研究最前沿，推动支部建在科研攻坚一线，设立“党员先锋岗”“科研联系人”，推动党建工作与有组织科研深度融合互促，切实把党组织政治优势、组织优势转化为科技创新治理效能。
聚焦国家战略需求，党员骨干冲锋攻坚担当作为。支部党员立足科研管理岗位履职尽责，围绕国家战略需求和世界科技前沿，贯通“方向-队伍-平台-项目-成果”创新链条，全力保障关键核心任务落地见效。“十四五”期间，学校牵头获得国家科技奖11项，居全国高校前列，其中牵头国家技术发明一等奖1项；获第四届全国创新争先奖5项，全国第五；获批国家级平台17个，科技活动经费突破70亿元。“十四五”牵头亿元级项目10项，较“十三五”增长400%；国家自然科学基金年度立项数突破400项。近年来，不断强化服务国家战略能力，翼身融合大型客机缩比试验机、“飞天系列”火箭冲压组合动力、“澳门科学一号”卫星B星、某水下无人系统等大国重器相继取得重大突破。
深化作风建设，营造优良科研创新生态。支部持续推进科研治理体系建设，修订完善15项科研管理制度，健全内控管理体系。坚持严的基调不动摇，常态化开展科研领域廉洁警示教育；做实做深跨支部联学共建，主动对接上级机关、全国学会办事机构、各学院科研一线党支部开展联学宣讲，搭建职能部门与科研团队高效沟通交流平台。坚持原始创新“0到1”突破与工程技术“1到0”攻关双向发力，强化有组织科研，统筹集聚优势资源开展前瞻性、系统性、原创性研究。落实树立和践行正确政绩观相关要求，不断优化科研服务保障链条，为广大科研人员潜心攻关营造风清气正的良好环境，为加快建设中国特色世界一流大学、服务高水平科技自立自强贡献支部力量。
