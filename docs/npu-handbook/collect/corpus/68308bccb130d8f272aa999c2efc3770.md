# 校领导现场调度长安校区电力保障工作

近期，西安市持续出现高温天气，加之恰逢考试周，长安校区空调用电量明显增大，导致校区高压进线负载率明显增高。在用电高峰时段，部分楼宇出现短时限电、多次停电现象，广大师生意见较大。
学校党委高度重视师生关于用电问题的反馈意见，6月16日上午的校领导会商会上，在听取专题汇报后，李言荣书记明确要求在前期工作的基础上，多措并举，尽全力保障师生学习、科研、工作、生活等的正常用电。
为贯彻落实学校党委决策部署，6月17日上午，校长助理兼后勤部党工委书记、后勤部部长王宇波在长安校区现场组织调度电力保障工作。调度组深入教学东楼、教学西楼、图书馆、学生食堂等楼宇，详细了解电力供应情况及保障措施，现场查看楼宇内考场及教室空调运行情况。调度组明确要求，后勤部办公室要坚决按照学校党委要求，与教务部、学工部、图书馆、长安校区各学院等单位密切沟通，在充分掌握长安校区近期整体用电需求的基础上，制定稳定可靠、切实可行、应急可调的供电保障方案，全力保障师生正常用电需求，同时加快推动两校区电力增容工作。
6月13日，后勤部办公室已经紧急租赁安装了5台1000kW应急电源车投入使用，大大缩小了限电区域和时长。6月14日后，长安校区整体电力运行平稳，没有再出现区域限电和楼宇停电现象。16日起，长安校区总计租赁安装了10台应急电源车。后续，将根据整体用电需求全力保障正常供电，确保长安校区广大师生学习、科研、工作、生活的顺利开展。
