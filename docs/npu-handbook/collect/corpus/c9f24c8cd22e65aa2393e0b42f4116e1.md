# 情暖六一，“饺”融童心——动物生态学师生融合党支部赴天爱特殊儿童关爱中心开展志愿服务活动

在“六一”国际儿童节即将来临之际，为弘扬“奉献、友爱、互助、进步”的志愿服务精神，引导支部党员在社会服务中践行初心使命，5月29日上午8时30分，动物生态学师生融合党支部前往西安天爱特殊儿童关爱中心，开展关爱特殊儿童志愿服务活动，为孩子们提前送去节日的祝福与温暖的陪伴。
抵达中心后，支部成员在中心老师的引导下迅速投入活动准备。大家分工协作，清洗水果、整理餐具、布置活动区域，并为孩子们准备了香蕉、葡萄等新鲜水果，细致周到的准备工作为当天的陪伴活动拉开了温馨的序幕。
图为支部为孩子们准备的水果
随后，支部成员一起为孩子们包制饺子。擀皮、放馅、捏合、摆盘、下锅，大家默契配合，将一份份爱心包进热气腾腾的饺子中。中午时分，饺子煮熟出锅，弥漫的饭香为即将到来的儿童节增添了浓浓的人情味。
图为支部成员为孩子们包制饺子
在等待和用餐过程中，支部成员主动走到孩子们身边，与他们聊天交流，耐心倾听，用温和的语言和真诚的笑容陪伴孩子们度过这段美好时光。轻松亲切的互动逐渐拉近了彼此的距离，也让孩子们真切感受到来自支部集体的关怀与节日祝福。
图为支部成员与孩子们交流互动
在烘焙体验环节，支部成员与孩子们一同参与糕点制作。从准备原料、整理工具，到协助操作、共同等待成品出炉，大家在细小而具体的劳动中传递着陪伴与鼓励，让孩子们在亲身体验中收获快乐与成就感。活动最后，支部成员与中心师生合影留念。
图为支部志愿者参与烘焙糕点准备
此次活动不仅为特殊儿童送去了儿童节前夕的陪伴与关怀，也进一步增强了支部成员的责任意识、服务意识和社会实践能力。动物生态学师生融合党支部将继续发挥基层党组织的战斗堡垒作用，将专业学习、社会服务与志愿实践有机结合，在持续行动中传递温暖、凝聚力量。
