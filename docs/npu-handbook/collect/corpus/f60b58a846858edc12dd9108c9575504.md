# 后勤部党工委召开工作交流暨《领导力》专题培训会-后勤集团

10月10日下午，后勤部党工委召开“翱翔学习讲堂”第二期活动，三位副处级干部围绕工作开展交流，校党委副书记杨晓做《领导力理论与实践》专题讲座，后勤部办公室和后勤集团全体处、科级干部参加会议，会议由后勤部党工委副书记、后勤集团党委书记侯亚涛主持。
会上，三位副处级干部紧扣后勤工作新形势、新要求，立足岗位实际，聚焦工作中存在的主要问题，结合党建、宣传文化建设、廉洁文化建设、动力能源保障等重点工作，分享岗位经验、查摆工作短板、交流改进思路。大家相互借鉴、互通有无，在研讨中拓宽工作思路、凝聚发展共识，有效实现了以学促思、以学促干的工作目标。
杨晓副书记围绕领导力定义与要素分析，典型领导力理论和中华优秀传统文化中的领导力思想，结合后勤服务保障工作和大家进行了讲解交流，希望后勤部党员干部加强党的创新理论武装，结合师生需求提升工作能力、改进工作作风，不断推进后勤工作高质量发展，建设一流大学服务保障体系。
最后，侯亚涛要求全体人员以此次培训为契机，学以致用、知行合一，切实把培训成果转化为工作实效；持续强化责任担当、精进业务能力、细化服务举措，深化协同配合，全力补齐工作短板，不断提升后勤服务保障质效。（图/文：综合事务部，审核：侯亚涛）
