# 希腊

希腊共和国·雅典·自送使馆180天内不超过90天D免签 需开具出境证明
使馆签证处地址：光华路19号 开馆时间：0930-1130 约5-7个工作日
使馆网址 https://www.mfa.gr/china/zh-CN/ TEL：65321317/1588
因公短期签证要求：
照片：3.5*4.5白底2张，半年内近照
表格：1份
如更换护照，需重新到大使馆录指纹。
1.申请表（请下载附件）最后一页签名左边一栏中日期“date”空着不填
2.邀请信（本土）
3.中文照会
4.照会译文
5.欧洲名单表（三人及以上）
6.在职费用证明（英文、签字盖章）
7.中方营业执照（组织机构代码）复印件
8.护照复印件（照片页+所有签证和盖章页）
9.留指纹那次的签证页复印件（指纹有效期59个月，超出则无需提供，需再次前往使馆留取指纹）
10.机票订单
11.酒店订单
12.保险
13.专办员证复印件（外事中心提供）
