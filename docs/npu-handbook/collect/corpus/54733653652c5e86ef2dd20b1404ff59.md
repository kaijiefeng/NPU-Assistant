# 西工大体育代表队赴法国开展中法大学生交流活动

9月21日至30日，由中国学生体育联合会组织，西北工业大学、吉林大学、上海交通大学体育代表队等组成体育交流团赴法国开展交流活动，本次活动以匹克球、羽毛球、乒乓球为媒介，推动中法高校青年学子、在法华人青年面对面互动交流。
在法期间，交流团一行走进巴黎访多所高校，通过友谊赛事、现场体验、座谈研讨等多元形式式开展深度交流，拓宽了视野、增进了友谊，加深了对法国高校体育发展模式的认知理解。在巴黎高等商学院（HEC），中法青年学子同台开展球类互动切磋，实地亲身感受法国商学院校园体育的运动氛围。在索邦大学（SU），双方围绕高校体育社团建设、大学生课外体育活动策划组织、中外青年文体互访等话题交换意见，分享各自校园体育发展经验，探讨高校体育育人的创新路径。在让·萨莱尔大学体育中心，中法青年运动员齐聚场馆，开展匹克球、乒乓球、羽毛球对抗切磋，重点聚焦新兴运动项目匹克球，交流技战术打法，双方队员自由结对、分组比赛，在回合对弈中感受这项新兴运动的独特魅力与竞技乐趣。在巴黎大学城，中外学生同台竞技、相互切磋，在比赛交流中互相学习打法技巧、适配赛场节奏，通过多个运动项目体验当地大学生的训练模式，近距离观察法国校园球类运动的组织形式，实现双向学习、共同提升。与全法博联开展座谈与比赛交流，围绕中法高校体育文化差异、青年体育活动推广、匹克球等新兴运动在海外华人青年群体中的普及开展等议题展开了探讨，举行了友谊比赛。
在法期间，中国学体联、陕西省学生体育协会有关领导、各参团高校体育代表队负责人等一行还与法国大学生体育联合会负责人进行了工作交流，双方充分肯定本次交流成果，就常态化开展中法高校体育互访、深化青年体育合作达成初步共识，为后续长效交流奠定基础。
此次出访，我校体育代表队师生在竞技赛场上奋勇进取顽强拼搏、锐意进取，在交流互动中积极主动、真诚自信，充分展现了西工大学子昂扬向上的精神风貌，有力传播了当代中国大学生的青春力量。交流活动进一步拓展了中外青年通过体育交流增强了解、增进情谊的渠道与途径，为后续深化校际体育交流做出了有益探索、打下了良好基础。
我校体育代表队队员杨淑雅说：“能够有机会走出国门来到巴黎参与中法大学生体育交流，是一次十分难得的成长历练。通过与法国青年交流切磋匹克球项目，既体会到不一样的运动理念，也看到我们自身可以学习提升的地方。今后会把本次出访的见闻带回校园，积极推广匹克球等体育项目，带动身边更多同学了解新兴体育项目”。队员朱斌豪表示：“赛场没有国界，一颗小球就是沟通的桥梁。在和法国大学生对打的过程当中，我们不仅切磋运动技艺，也互相分享校园学习生活。我将牢记‘三实一新’的校风，把此次海外交流的收获转化为动力，立足校园做好体育文化传播”。教练王轲老师表示，本次实地走访直观了解到了法国高校校园体育的开展现状，见证了新兴运动在海外青年中的普及热度，为我校校园体育创新发展提供了全新思路。领队傅莉老师表示，体育是沟通世界最好的语言，各国青年以体育为媒平等对话、真诚互动，为我校持续深化国际体育合作、拓宽青年对外交流渠道，带来了新的启发与思路。
本次交流活动，由中国学体联副主席兼秘书长陈东升为团长，中国学体联副主席华爱军，陕西省学生体育协会副主席兼秘书长张原耕等随团参加有关活动。我校代表队一行6人由体育部傅莉书记任领队，王轲老师任教练，匹克球队陈畅、朱斌豪、杨淑雅、王梦瑶同学为队员，全程参与了在巴黎的各项交流活动，本次出访得到学校“翱翔四海”国际交流项目的大力支持。
（文稿：王梦瑶，图：朱斌豪，审核：王轲 傅莉）
