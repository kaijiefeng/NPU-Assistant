# 关于开展“以赛促教—教学能力提升示范展示”系列活动的通知

各教学单位：
为充分发挥教学竞赛标杆示范引领作用，坚持“以赛促教、以赛促学、以赛促创、赛教融合”，加强西北工业大学第六届教师教学创新竞赛赛前专题辅导培训，以参赛备赛推进课程教学创新改革，特组织开展“以赛促教－教学能力提升示范展示”系列活动。现将有关事项通知如下。

二、培训形式
请各教学单位认真组织校赛参赛教师参加现场培训，我校第六届教师教学创新竞赛（含院赛和校赛）全体参赛主讲教师（或教学团队成员）须签到参会，培训期间可携带纸质版参赛材料请主讲专家进行针对性指导。如有特殊情况不能现场参加，请联系工作人员申请线上参加。
同时，参赛教师可通过在线学习观摩提升教学能力。为进一步促进数字化教学资源共享，教务部在AI驱动的“翱翔学堂”平台建设了“教学竞赛优秀教师示范课”，我校教师可在线观摩。登录路径为“翱翔门户-翱翔学堂-优质示范课-教学竞赛优秀教师示范课”。
三、主讲专家简介
