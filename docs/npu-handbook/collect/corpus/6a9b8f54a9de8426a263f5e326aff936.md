# 关于调整教职工车辆便捷通道开放时间的通知

全体教职工：
自友谊校区西门科创大楼教职工车辆便捷通道开通以来，极大地缓解了西门外的交通压力。通过最近两周的实践检验，结合教职工诉求，现对教职工车辆便捷通道开放时间进行调整，将下午开放时间提前至17:00，其他不变。
调整后的开放时间为：周一至周五7:20-8:20、17:00-19:00（节假日除外）。
特此通知。
保卫处资产经营管理有限公司
2020年9月22日
（文/夏勇；审稿/皮德福）
