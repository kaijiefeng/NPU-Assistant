# 化学与化工学院开展2026年度《实验室事故预防与应急》专题准入培训及考试

为进一步强化实验室安全管理，提高师生安全意识和应急能力，确保科研实验活动安全有序开展，3月5日晚上，学院邀请西安安备思软件有限公司总经理刘涛开展了实验室安全准入培训专题讲座。学院共220余师生参加培训，院长助理郭威参会，培训讲座由学院安全员郭思敏主持。
本次培训主要面向各实验室2025级硕士、博士研究生、做毕设或大创项目的本科生，以及新进青年教师、科研助理和实验人员。
培训开始前，郭威结合近年高校发生的典型事故案例，阐述了安全生产工作的极端重要性。他强调，参训人员要珍惜这次学习机会，认真听讲，不断提高安全防范意识，规范实验操作行为，切勿盲目开展风险实验，要加强实验风险评估和过程监督，多与导师沟通实验方案，及时反馈实验进展与风险点，切实保障生命财产安全。随后郭思敏向参训人员就培训考试要求作了说明。
随后，刘涛围绕实际操作、危险化学品、安全用电、安全用气、消防安全五个篇章，结合国内典型事故案例情况，剖析了隐患事故发生的成因，讲解了不同场景下的防护物资配备要求及事故预防措施，提供了各类隐患引发事故时的紧急处置方法和自救互救技能。讲座过程中，刘涛与在场人员进行了积极互动，分享了自己的经验和见解。
培训结束后，学院为参加培训并通过考试的师生人员配发了危险化学品实验室准入证、防毒面罩、护目镜等个体防护物资。
本次专题准入培训及考试进一步巩固了师生的理论知识储备，提升了实验风险防范与应急处置的能力，有力推动了实验室安全文化建设。今后，学院将进一步加强实验室安全管理，常态化开展安全生产检查，不断提升安全保障水平，为科研工作的高质量开展营造安全稳定的环境。
