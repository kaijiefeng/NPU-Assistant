# 关于第三届“京东物流杯”智能供应链大学生竞赛 校内选拔赛结果的公示

各学院：
2026年6月14日（周日）晚19:30，数研智创大学生创新实践基地组织举办了第三届“京东物流杯”智能供应链大学生竞赛校内选拔赛。本次选拔赛共有来自管理学院、计算机学院、航空学院、航天学院、航海学院、软件学院、教育实验学院、伦敦玛丽女王大学工程学院学生组成的6支队伍参加。经评委会评审，最终推选出三支队伍代表学校参加第三届“京东物流杯”智能供应链大学生竞赛。
现将推选名单（见附件）予以公示。公示期为2026年6月15日-6月16日。如对公示结果有异议，请在公示期内以书面形式向数研智创大学生创新实践基地反映，并提供真实姓名、联系方式及必要证明材料。逾期不予受理。
