# 化学与化工学院开展实验室安全生产检查

为持续筑牢安全防线，9月16日下午，学院副院长陈凯杰带队，对学院新楼、老楼各实验室开展安全生产全面检查暨前期隐患“回头看”复查。院长助理郭威、安全员郭思敏及实验室督查组全体成员参加检查。
本次检查重点对前期各级检查中发现隐患的整改落实情况进行“回头看”复查，针对检查中发现的标签不完善、有机溶剂超规格存放、报警装置不完善等问题，检查组与现场师生进行了充分沟通，逐一提出明确整改意见，要求相关实验室限期整改到位。
安全是一切工作的底线，学院将继续依托“四级检查”体系，常态化开展安全检查和“回头看”，持续巩固整改成效，坚决防止隐患反弹，为学院教学科研工作提供坚实安全保障。
