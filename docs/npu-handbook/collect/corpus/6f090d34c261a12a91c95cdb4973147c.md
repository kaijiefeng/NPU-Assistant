# 我校在第十七届全国大学生数学竞赛决赛中喜获佳绩

近日，第十七届全国大学生数学竞赛决赛在四川大学和成都理工大学落下帷幕。我校学子表现优异，共斩获全国一等奖2项、二等奖9项、三等奖2项，同时，我校荣获优秀高校组织奖一等奖。
全体参赛学生和带队老师合影
本届竞赛由中国数学会主办，吸引了来自北京大学、清华大学、中国科学技术大学、复旦大学、浙江大学等全国1332所高校的35.2万余名学生参赛。经过层层选拔，最终1342名学生晋级决赛。我校来自数学与统计学院、电子信息学院、网络空间安全学院、自动化学院、航天学院、计算机学院的13名学生入围决赛，入围规模为历史之最。
中国科学院院士、中国数学会理事长席南华教授，中国科学院院士田野教授分别为同学们作了《黎曼猜想》和《整数与矩阵的对话：当线性代数遇见基础数论》的科普报告。另外，数学界顶级专家出席颁奖大会，为获奖学子颁奖。
本次比赛得到学校教务部和数学与统计学院的高度重视与大力支持，由大学生数学能力创新实践基地负责人聂玉峰教授指导，数学与统计学院郭千桥副院长统筹，全国大学生数学竞赛负责人马荣教授具体负责实施。备赛历时8个月，从校赛到初赛、再到决赛，师生利用周末和假期集中攻关，有效拓展了学生的知识面，提升了解决复杂问题的能力。
全国大学生数学竞赛自2009年创办以来，已成为国内参赛规模最大、影响力最高的本科生数学学科竞赛之一，旨在为青年学子搭建展示数学基本功与数学思维的舞台，推动高校数学课程改革与创新人才培养。
