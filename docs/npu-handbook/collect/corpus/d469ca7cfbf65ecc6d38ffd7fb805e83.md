# 行走课堂悟初心，实践育人长才干——生命科学与技术学院赴汉中开展培训活动

为进一步推进“大思政课”建设，引导师生在实践中受教育、长才干，10月24日至25日，生命科学与技术学院组织学院铸剑班第二期学员、师生党员代表共30余人，赴汉中市开展为期两天的培训，此次活动由学院党委副书记张敏乔带队。师生先后走进朱鹮国家级自然保护区、古路坝西北工学院旧址、川陕革命根据地纪念馆和汉中博物馆，在生态观察、校史寻根与红色教育中接受了一次沉浸式的精神洗礼与实践锻炼。
10月24日上午，师生走进汉中朱鹮国家级自然保护区，深刻体会习近平生态文明思想。汉中朱鹮国家级自然保护区是我国首个开展朱鹮抢救性保护的地方，朱鹮为国家一级保护动物，是秦岭生态保护标志性物种。通过学习，大家系统了解了朱鹮从濒临灭绝到种群复壮的艰辛保护历程，对其栖息地环境、生活习性和保育措施等有了更为直观的认识，从生物学科、生态文明建设等维度审视物种保育与生态平衡的关系，进一步体会到学科知识在生态保护中的现实价值。
随后，城固县博物馆马茹讲解员以“西北联大变迁史与西工大的前身”为题为大家专题授课。授课围绕西北联大变迁历程展开，系统梳理了西北联大在抗战烽火中辗转办学的历史脉络。大家在听讲中进一步厘清了学校办学的历史源流，对“公诚勇毅”校训的历史内涵有了更系统的认识，也为随后前往古路坝村溯源奠定了基础。
下午，师生前往城固县古路坝村寻访校史根脉、重温西迁办学岁月。古路坝是抗战时期国立西北联合大学工学院办学地，也是西北工业大学前身——国立西北工学院的诞生旧址，是承载学校初心文脉的重要校史地标。师生沿着先辈足迹实地寻访，深入学习这段属于西工大的办学历史，了解前辈学人在烽火乱世之中扎根古路坝、组建国立西北工学院，于艰苦条件下坚守工科教育、赓续强国文脉的动人往事，深切感悟先辈们弦歌不辍、兴工报国的精神底色，在行走的校史课堂中接受了一场沉浸式校史校情教育与精神洗礼。
10月25日，师生先后参观川陕革命根据地纪念馆与汉中博物馆。在川陕革命根据地纪念馆中，大家通过一件件展陈史料、一幅幅历史图片，深入了解川陕革命根据地的建设和斗争历史，在追寻红色足迹中感悟初心使命，在回望革命历程中坚定理想信念。参观结束后，张敏乔带领党员师生重温入党誓词，铿锵誓言回荡展厅，进一步坚定了每一位党员不忘初心、牢记使命的信念与决心。
随后，师生走进汉中博物馆，参观学习古汉台的历史遗存。古汉台作为汉中历史文化的重要载体，留存着丰富的文物与史料，大家在参观中感受汉中深厚的人文底蕴，对这座历史文化名城的沿革与传承有了更为深入的认识，在历史与现实的对照中厚植家国情怀，坚定文化自信。
此次活动将生态观察、校史寻根、红色教育与历史文化学习融为一体，大家在行走的课堂中不仅近距离感受了生态文明建设的重要成果，同时在学校烽火办学的古路坝旧址和红色展馆中接受了精神洗礼，进一步加深了对生态保护、校史校情、红色文化与历史传承的理解，实现了实践学习与思想淬炼的有机统一。未来，学院将进一步拓展实践育人路径，推动行走的课堂与课堂教学同向同行、协同育人，引导师生在实地走访中坚定理想信念、锤炼精神品格。
