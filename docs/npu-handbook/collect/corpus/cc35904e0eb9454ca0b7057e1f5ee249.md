# 后勤部办公室学生助管招聘启事

为进一步加强后勤管理与服务工作，为学生提供实践锻炼的机会和平台，更好地发挥管理育人、服务育人功能，后勤部办公室结合工作实际，现需面向校内招聘学生助管人员2名，有关情况具体如下：
一、岗位设置
后勤部办公室维修管理综合岗
二、招聘人数
2人（仅限本校在读研究生）
三、工作地点
长安校区
四、工作内容
1.协助开展维修工单电话回访；
2.完成科室安排的其他工作任务。
五、工作要求
1.工作认真负责，细致耐心，遵守工作纪律；
2.服务意识强，工作积极主动，有较强的语言表达能力；
3.工作时长须符合学校相关规定与要求。
六、报名时间及报名方式
2026年10月8日-10月12日
请有意向报名的同学将个人简历发送至邮箱：[已脱敏:邮箱]
后勤部办公室
