# 电子信息学院2024年暑期国际学堂课程选课通知

电子信息学院2024年暑期国际学堂课程选课通知
为扎实推进学校“双一流”建设，响应学校国际化人才培养举措，促进学生本土国际化发展，电子信息学院将于今年暑期继续开展暑期国际学堂课程活动，邀请来自莫斯科航空学院、英国伯恩茅斯大学、纽卡斯尔大学、意大利热那亚大学、韩国仁川大学等海外知名院校的8位专家进行授课。课程面向全校本科生和研究生开放，所有课程均采用英文授课。
一、选课方式：
本科生选课方式：登录“翱翔教务”—“课程管理”—“选/退课”界面选课。
研究生选课方式：登录“翱翔门户”--“研究生教育”--“暑期学堂”--“选课”界面选课。
分为正选和补选两个阶段。正选时间为2024年6月11日9:00—— 6月14日14:00，补选时间为2024年6月17日9:00—— 6月19日17:00。
二、课程介绍
1、课程名称：航电系统设计与仿真/Design and Simulation of Avionics System
主讲教师： Evgeny Neretin/Nikita Sharovatov莫斯科航空学院
课程简介：介绍航空电子系统的相关基本知识及主要设计原则。学生可以学习到关于航空电子系统基本概念、系统功能、航电系统架构，发展进程，设计工具和测试平台的基本知识。学生还可以通过仿真软件工具应用于实践当中。
课程群：
2、课程名称：航空机载传感器/Sensor Technologies in Aviation
主讲教师：Evgeny Neretin/Artem Savelev莫斯科航空学院
课程简介：介绍有关航空传感器的基本知识及主要设计主要原理。学生能够掌握有关传感器分类、类型、功能、性能、计量特性和应用的基本知识。此外，学生还可以通过软件工具进行航空传感器的仿真与开发
课程群：
3、课程名称：Adversarial Machine Learning/对抗机器学习
主讲教师：Fabio Roli意大利热那亚大学
课程简介：本课程提供统计机器学习的基本概念及其对精心设计的攻击的安全性，包括测试时规避和训练时中毒攻击（也称为对抗性示例）。主要介绍统计机器学习和对抗性机器学习的基础知识以及一些评估机器学习算法对对抗性攻击的脆弱性的技术。该课程使用的应用示例包括图像中的物体识别，生物识别身份识别，垃圾邮件和恶意软件检测。
课程群：
4、课程名称：图像处理/Image Processing
主讲教师：Gwanggil Jeon仁川大学
课程简介：向学生介绍目前用于数字图像处理的分析工具和方法，并将其应用于实际图像信息处理问题。在实际应用中介绍图像增强，图像恢复和图像压缩等技术。
课程群：
5、课程名称：视频处理/video Processing
主讲教师：Gwanggil Jeon仁川大学
课程简介：本课程重点讨论视频理解的艺术视频分析并研究其在不同领域的应用，包括视频监控和视频引导手术等。
课程群：
6、课程名称：5G-6G通信信号设计，应用与硬件实现/5G-6G Communication signal design, applications and implementation
主讲教师：许同阳 英国纽卡斯尔大学
课程简介：本课程重点介绍无线通信系统的前沿技术、仿真验证与硬件实现，通过本课程学习，可以实现搭建现有通信系统。
课程群：
7、课程名称：探索搜寻与优化算法/Search and Optimisation
主讲教师：张建康 英国伯恩茅斯大学
课程简介：本课程旨在为学生提供一个全面的视角，深入理解并掌握各种优化算法的原理与应用。通过本课程的学习，学生将能够熟悉优化和搜索的基本概念，并能够运用一系列先进的优化算法解决实际问题。
课程群：
撰稿：王秋霞
审核：姚如贵
