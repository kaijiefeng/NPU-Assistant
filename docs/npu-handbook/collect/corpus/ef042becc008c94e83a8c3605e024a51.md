# 就业新闻-浙江大学就业指导与服务中心来校调研

首页>就业新闻>文章
浙江大学就业指导与服务中心来校调研
日期：2026-11-11 09:34 浏览次数：19
11月9日上午，浙江大学就业指导与服务中心副主任杨倩一行来校调研交流。党委学生工作部副部长刘伟，学生职业发展指导服务中心朱莉、动力与能源学院邢译水、马克思主义学院董润等参加座谈交流。座谈会由刘伟主持。
刘伟对杨倩一行表示热烈欢迎，并围绕学校历史沿革与办学特色，介绍了学校在引导毕业生服务国防军工重点领域、职业生涯规划课程体系建设、全国大学生职业规划大赛组织等方面的做法与体会。
杨倩对学校表示感谢，并介绍了浙江大学就业指导与服务中心在就业引导体系建设、选调生引导等方面的探索。
双方围绕生涯课程建设、职规赛选手选拔与培训机制、校院两级就业工作考核等具体问题进行了深入研讨，双方希望以此次调研为契机，进一步加强交流互鉴。
