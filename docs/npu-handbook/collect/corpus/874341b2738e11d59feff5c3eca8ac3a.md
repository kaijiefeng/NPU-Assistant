# 西北工业大学计算机学院2026年工程博士专项班复试工作方案

## 一、复试方式

我院博士专项班招生复试采用现场复试的方式。

## 二、复试工作时间安排

6月3日14点开始，半天复试。学生先到西工大长安校区计算机学院楼119报到，没有提交纸质材料的请提交纸质材料，然后等待电话通知面试地点。

## 四、复试相关要求

（一）复试条件、复试纪律要求

1.严禁考生出现弄虚作假及替考作弊等行为，一经查实将按照《国家教育考试违规处理办法》《普通高等学校招生违规行为处理暂行办法》，视情节轻重予以处理。

2.复试过程中严禁考生对复试过程进行录音录像，在学校复试工作全部结束前严禁将复试相关资料上传网络或提供给相关培训机构，一经查实将取消其拟录取资格并追究相关责任。

（二）复试流程：包括学生报到、综合面试环节。

（三）复试内容及要求：复试内容包括思想政治考核和专业综合能力考核两部分，每部分100分。复试采用综合面试，包括考生汇报和专家考核两个环节，考生使用PPT汇报个人学习及工作经历、科研计划、论文发表、专利申请和荣誉获奖等情况，汇报环节为8分钟；每位考生复试时间不少于20分钟。

## 五、录取工作

（一）录取总成绩计算：录取总成绩 = 思想政治考核成绩*15% + 专业综合能力考核成绩*85%。

（二）录取原则：按录取总成绩从高分到低分排序依次录取。

## 六、信息公开

相关信息在学院网站进行公开公示，内容包括复试工作方案、复试名单、拟录取考生名单等；学院将对拟录取名单公示，公示时间为7个工作日。

## 七、监督与复议

学院研究生复试录取督导组负责对研究生复试录取工作进行监督，监督检查须覆盖复试录取全流程、各环节。咨询电话：029-88431522；邮箱：majz@nwpu.edu.cn；通讯地址：陕西省西安市西北工业大学长安校区计算机学院886信箱，邮编710129。
