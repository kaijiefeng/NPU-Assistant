# 关于开展2026年西北工业大学“119”消防安全宣传知识竞赛的通知

全体师生：
2026年11月9日是第35个全国消防日，国务院安委会办公室、国家消防救援局定于11月份在全国开展消防宣传月活动，主题是“全民消防、生命至上——提高自防自救能力”。为进一步提升广大师生消防安全意识，提高应急处置能力，特开展2026年西北工业大学“119”消防安全宣传知识竞赛，现将相关事项通知如下:
一、参赛对象
西北工业大学全体师生。
二、竞赛方式
微信扫描下方小程序二维码即可参与：
三、答题时间
11月5日8时至11月20日20时。
四、注意事项与奖项设置
1.答题时务必填写姓名，工号或学号，二级单位名称及联系方式。
2.答题时从题库中随机抽取20道题目，每题5分，满分100分，每人有2次答题机会。
3.答题设置个人奖项，按照得分及答题时长排序，活动结束后予以奖励。
五、活动联系人
党委保卫部：潘丁，联系电话：88492280。
党委保卫部
2026年11月4日
