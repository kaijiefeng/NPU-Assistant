# 西北工业大学长安校区人工湖管护服务竞选公告

一、竞选条件
西北工业大学长安校区人工湖管护服务项目，采购人为西北工业大学后勤部办公室，项目资金来源为自筹经费。本项目已具备采购条件，现进行竞选。
二、项目概况
对西北工业大学长安校区人工湖全域进行管护服务，负责启翔湖湖泊生态补水，确保水域来水充足；清理启翔湖、启真湖水面漂浮垃圾、杂物、水生藻类等。服务期限一年。
三、供应商资格要求
1.供应商具有独立法人资格，具备有效的企业法人营业执照（具有统一社会信用代码）。
2.法定代表人身份证明书或法人授权委托书、法定代表人身份证和被授权人身份证正反面复印件（留法人或法人授权委托人联系方式及有效电子邮箱）。
3.供应商具有自2023年1月1日（以合同签订时间为准）以来承担的合同额不低于20万元的同类业绩合同一份。
4.供应商在信用中国、中国政府采购网及国家企业信用信息公示系统等未被列入失信被执行人名单、重大税收违法失信主体及政府采购严重违法失信行为记录名单等查询证明。
5.提供本项目不允许联合体响应，不接受分包的供应商承诺书。
四、报名资料提交
1.报名要求：本次报名采取线下报名，不接受任何线上报名、不接受联合体投标、不接受关联单位同时投标。未按要求报名或提供资料，或在截止时间后收到的报名资料，一律视为无效。
2.资料要求：响应单位报名时需提供本竞选公告第三条“供应商资格要求”中1-5项全部资料的复印件（按顺序装订，复印件加盖公章，承诺书需原件，报名资料不返还），并携带企业营业执照、业绩合同的原件（以备报名现场查验，原件查验后及时返还）。
3.提交时间：2026年9月10日至9月14日（工作日：上午9:00-12:00，下午15:00-17:00，周六周日不接受报名）。
五、其他要求及注意事项
1.本项目竞选公告在“西北工业大学后勤部办公室官网（网址https://houqinbu.nwpu.edu.cn/index.htm ）”发布。
2.供应商不得被列入失信被执行人、重大税收违法失信主体、政府采购严重违法失信行为记录名单及其他不符合《中华人民共和国政府采购法》第二十二条规定条件，不得被取消或暂停投标资格，上述信息查询以政府诚信平台和学校不良行为记录为准，其中政府诚信平台是指信用中国、国家企业信用信息公示系统、中国政府采购网。
3.竞选小组根据响应单位提交的报名资料进行资格预审，采购人向资格预审合格的单位发送竞选文件。
4.本次竞选以各响应单位报名资料中的邮箱为准发送竞选文件等相关资料，各响应单位务必保持邮箱可正常接收邮件，凡因响应单位对公告阅读不深、疏漏、或因邮箱问题造成的后果和风险，均由响应单位自负。
