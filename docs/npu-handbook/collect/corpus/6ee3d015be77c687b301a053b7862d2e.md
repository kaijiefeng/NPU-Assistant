# 基础科研能力培训｜“卓越表达力”（第二期）预告

活动简介
“卓越表达力”是国家卓越工程师学院重点打造的学术赋能品牌活动之一。该活动聚焦科研绘图、PPT演示、学术写作等核心学术表达能力，通过系统化、模块化的专题课程体系，致力于帮助学生将复杂的研究成果转化为逻辑严谨、表达专业的学术内容。活动旨在全面提升学生在论文发表、项目申报、学术交流等场景中的表达效果，为其科研创新成果的传播与认可提供有力支撑。
首期“卓越表达力”活动照片
首期“卓越表达力”活动带领同学们掌握了英文论文写作与投稿的全流程。为助力大家实现从“会写”到“写好”的转变，国家卓越工程师学院“卓越表达力”活动第二期——“论文深度精讲与新手误区规避”即将启幕。
本期活动将邀请拥有丰富学术评审与写作经验的专家，从审稿人和作者的双重视角，深度剖析高水平论文的写作逻辑与常见误区。无论您是科研新手，还是希望进一步提升论文质量的高年级同学，这都将是一场不容错过的进阶指南。
本期讲座主题
本期活动依托西北工业大学科学技术协会和中国通信学会联合承担的“大学生科技社团支持计划”，由多部门联合举办，汇聚优质资源，旨在通过专业训练全面提升学生的核心竞争力。
