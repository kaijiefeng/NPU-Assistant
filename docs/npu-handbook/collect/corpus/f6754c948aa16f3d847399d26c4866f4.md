# 两校区灭火器检修、充装、更换及增配”项目采购公告

一、采购单位：西北工业大学
二、项目名称：两校区灭火器检修、充装、更换及增配
三、采购方式：公开采购
四、项目概况：
两校区干粉灭火器及二氧化碳灭火器的购置、检修及充装，包含灭火器收取、取旧放新、放置指定位置以及放置后的周围环境清理等。
五、报名方式及资质要求：
报名方式为线下报名，按照以下要求提供报名资料。报名时提交的原件及复印件资料须加盖公司红章，所有资料按照以下顺序整理、装订（不要胶装）。
1.报名单位应具有国内独立法人资格，符合《中华人民共和国政府采购法》第二十二条相关规定。提供独立法定代表人证明书或法定代表人授权委托书（留原件），提供法定代表人身份证（留复印件）及被授权人身份证原件（留复印件）。
2.提供合法、有效期内的标注统一社会信用代码的营业执照原件（留复印件）。
3.提供有效期内的中国国家强制性产品认证证书（3C认证证书）（留复印件）、国家消防装备质量监督检验中心出具的检验报告（留复印件）、厂家提供的产品销售授权书（留复印件）。
4.灭火器检修、充装供应商应具备并提供陕西消防协会——消防产品质量监督检验检测站出具的维修能力检测报告（留复印件）。
5.提供自2023年9月28日以来同类项目合同额不低于40万元的合同一份，以合同签订日期为准（留复印件，合同复印件应与合同原件一致，不允许缺页、少页，并附相关发票等）。
6.提供售后服务承诺书，能够响应采购方供货期要求（自合同签订完成之日起30天内完成供货等）以及质保期要求（自项目验收合格之日起3年），同时配有较强的专业技术队伍，能提供快速、有效的售后服务（留原件）。
7.报名单位不得是“信用中国”网站所列的失信被执行人，提供“信用中国”网站相关报告（留原件）。
8.本项目不允许联合体报名，提供非联合体报名承诺书（留原件）。
六、采购小组对报名单位进行资格预审，只有资格预审合格的报名单位才能参加后续采购。
七、报名时间：
各单位应按照以上要求提交相关资料。报名期限共3个工作日，自2026年9月28日上午9：00至2026年9月30日下午17:30止，材料提交时间为工作日上午9:00-11:30、下午15:00-17:30。
八、报名地点：
西北工业大学友谊校区综合楼4楼407办公室。联系人：杨老师、王老师，电话：029-88492280。
九、如发现有围标、串标、借取他人资质或以其他方式弄虚作假等违法违规行为，一经查实，列入我校不良行为名单且取消其本次报名及报价资格，不允许参与本次项目的后续采购。
