# 自动化学院顺利召开2024级专业确认宣讲会

为扎实做好本年度专业确认工作，帮助学生深入了解学院专业特色、培养方向及专业确认政策，7月4日下午，自动化学院在学院楼报告厅举办2024级专业确认宣讲会，同步开启线上直播会议，学院院长李伟林、副院长刘准钆、党委副书记易正阳、辅导员、本科教学办负责人员及2024级全体学生参会。会议由易正阳主持。
易正阳首先强调了专业选择在同学们大学学习生涯以及未来职业发展中的重要意义，鼓励同学们认真对待专业确认，做出适合自己的选择，为未来的学习和发展奠定基础。
随后，刘准钆围绕专业确认、国际班选拔等政策进行了深刻解读。他详细介绍了专业确认流程、时间节点及考核标准，强调“遵循志愿、成绩优先、计划控制”的原则，提醒学生根据个人兴趣与职业愿景选择专业。针对国际班选拔，他围绕课程体系、海外交流机会、研究生推免等方面展开说明，鼓励学生根据兴趣积极申报，为个人国际化视野培养和未来深造就业拓宽路径。
李伟林围绕培养目标、课程体系、专业特色、多元就业方向以及广阔发展前景等多个维度系统介绍了学院自动化、电气工程及其自动化、机器人工程专业建设情况。通过列举历届毕业生的高质量就业案例和考研深造情况，生动直观地呈现了各专业优势与发展潜力。他说，同学们要立足个人兴趣与未来发展，理性自主选择专业，避免盲目跟风。希望通过本次宣讲能够帮助大家充分了解各专业特色，为后续的专业选择提供有价值的参考依据。
在提问解答环节，现场气氛热烈，同学们积极发言，老师们围绕专业确认的具体细节、国际班学习强度、专业课程难度差异等问题做了详细解答，进一步加深了同学们对专业的了解。
本次专业确认宣讲会为同学们深入解读了学院专业特色与优势、专业确认政策及国际班选拔，有效增进了同学们对专业的了解，为后续专业分流选择提供了明确的指引，为顺利开展专业确认工作奠定了坚实基础。
