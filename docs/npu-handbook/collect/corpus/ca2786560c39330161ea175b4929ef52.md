# 总分第1！西工大蝉联“挑战杯”！-青春驿站-共青团西北工业大学委员会

6月7日，第十三届“挑战杯”陕汽集团陕西省大学生创业计划竞赛闭幕式暨颁奖仪式举行。我校副校长岳晓奎参加闭幕式，高性能热场材料革新者团队作为优秀参赛作品进行了汇报展示。学校推报的17件参赛作品，经过激烈角逐，获特等奖11项、一等奖5项、三等奖1项。
特等奖数量与总积分均位列全省第一！
蝉联省赛最高荣誉“挑战杯”！
第十三届“挑战杯”陕汽集团陕西省大学生创业计划竞赛由共青团陕西省委、中共陕西省委教育工委、陕西省科学技术协会、陕西省学生联合会、陕西省西咸新区开发建设管理委员会联合主办，西安财经大学承办，陕汽集团协办支持。据悉，本届竞赛自启动以来，共收到全省90所高校推报的参赛作品1170件，经资格审核、网络评审层层遴选等环节，共有86所高校的419件作品入围终审决赛。
