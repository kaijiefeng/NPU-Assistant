# 个人所得税知识问答

根据全国人民代表大会常务委员会关于修改《中华人民共和国个人所得税法》的决定及国务院关于修改《中华人民共和国个人所得税法实施条例》的决定，从2011年9月1日起我校将执行新的个人所得税法并实行个人所得税全员全额申报。
一、新税法的主要变化
工薪收入所得税起征点由2000元提高到3500元，税率由9级减少为7级。

三、什么是个人所得税全员全额申报
学校向个人支付人员费用时，不论其是否属于本单位人员、是否达到纳税标准，学校在代扣税款的次月,向税务机关报送个人的基本信息，包括发放内容和数额、扣缴税款数额以及其他相关涉税信息。
四、实施全员全额申报，要报送那些相关涉税信息
报送的涉税信息包括：工号、姓名、性别、出生年月、国家或地区、证件类型、证件号码、是否有住所、是否股东、个人股本额、学历、职业、职务、联系电话、工作单位、邮政编码、通信地址、户籍所在地、医疗保险金、住房公积金、养老保险金、失业保险金等。
五、实行个人所得税全员全额扣缴申报的应税所得包括哪些内容
1）工资、薪金所得；
2）劳务报酬所得；
3）稿酬所得；
4）特许权使用费所得；
5）利息、股息、红利所得；
6）财产租赁所得；
7）财产转让所得；
8）偶然所得；
9）经国务院财政部门确定征税的其他所得。
六、实行新税法及纳税全员全额申报后的计税方法
1)在职人员工资收入
按照新工薪税税率和减除标准计税。
2)在职人员其它工薪收入
把每次发放金额与当月已经发放的工资、薪金收入金额累加，然后按照新工薪税税率和减除标准重新计算应扣税金，减去本月已扣税金。
个人收入应缴所得税金额的计算公式为：
当月应纳所得税额 = 当月应纳税所得额 × 适用税率-速算扣除数
当月应纳税所得额 =当月各类工资、津贴、补贴-住房公积金扣款+ 当月取得课时费 + 当月从项目中取得的人工费收入 + …… - 3500
本次应纳所得税额 = 当月累计应纳所得税额 — 当月已纳税额合计
本次实发金额 = 本次应发金额 - 本次应纳所得税额
3)聘用制人员工资收入
按照新工薪税税率和减除标准计税，3500元以下不扣税。。
4)聘用制人员其它工薪收入
与当月已经发放的工资、工薪收入等累加，然后对本次发放金额按照新工薪税税率计税。
5)校外人员劳务收入
每次发放时，按照劳务报酬所得税率及减除标准（即不超过4000元减除800元费用，4000元以上减除20%费用，减除后按20%税率计税；减除费用后余额超过20000-50000元的部分，按30%税率计税；超过50000元的部分按40%税率计税）计税，单次计税不累加。
6)学生助研费收入
按新工薪税税率计税，3500元以下不扣税。
七、哪些收入免征个人所得税
1）省级人民政府、国务院部委和中国人民解放军以上单位，以及外国组织颁发的科学、教育、技术、文化、卫生、体育、环境保护等方面的奖金。
2）国债和国家发行的金融债券利息。其中，国债利息，是指个人持有中华人民共和国财政部发行的债券而取得的利息，国家发行的金融债券利息，是指个人持有经国务院批准发行的金融债券而取得的利息所得。
3）按照国家统一规定发给的补贴、津贴。指按照国务院规定发给的政府特殊津贴、院士津贴、资深院士津贴和国务院规定免纳个人所得税的补贴、津贴。
4）福利费、抚恤金、救济金。其中，福利费是指根据国家有关规定，从企业、事业单位、国家机关、社会团体提留的福利费或者从工会经费中支付给个人的生活补助费，救济金是指国家民政部门支付给个人的生活困难补助费。
5）保险赔款。
6）军人的转业费、复员费。
7）按照国家统一规定发给干部、职工的安家费、退职费、退休工资、离休工资、离休生活补助费。离退休人员按规定领取离退休工资或养老金外，另从原任职单位取得的各类补贴、奖金、实物，不属于免税范围，应按"工资、薪金所得"应税项目的规定缴纳个人所得税.
8）中国政府参加的国际公约以及签订的协议中规定免税的所得。
根据两国政府签订文化交流项目来华工作两年以内的文教专家，或根据我国大专院校国际交流项目来华工作两年以内的文教专家，其工资、薪金所得由该国负担的，免予征收个人所得税。
9）企业和个人按照省级以上人民政府规定的比例提取并缴付的住房公积金、医疗保险金、基本养老保险金、失业保险金，不计入个人当期的工资、薪金收入，免征个人所得税。超过规定的比例缴付的部分计征个人所得税。个人领取原提存的住房公积金、医疗保险金、基本养老保险金时，免予征收个人所得税。
10）经国务院财政部门批准免税的所得。
①曾宪梓教育基金会教师奖。
②光华科技基金会奖励科技人员奖。
③个人领取原提存的住房公积金、医疗保险金、基本养老保险金。
④独生子女补贴、差旅费补贴、误餐补助。
⑤外籍个人所得的探亲费。
⑥外籍个人以实报实销形式取得的住房补贴、伙食补贴、搬迁费、洗衣费。
八、全员全额申报后可以开具个人完税证明
以往纳税申报没有个人明细，税务部门无法向个人开具完税证明，实行全员申报后个人信息完备，具备向个人开具完税证明的条件。
