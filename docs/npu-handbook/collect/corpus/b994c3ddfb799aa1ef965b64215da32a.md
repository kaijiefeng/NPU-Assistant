# 我校学生在2026年全国大学生英语竞赛总决赛中喜获佳绩

8月2日至8月7日，2026年全国大学生英语竞赛全国总决赛（NECCSF）在安徽省合肥市圆满落幕。本届赛事规模宏大、含金量高，汇聚全国31个省（自治区、直辖市）200余所高校的300余名顶尖选手，参赛者均为各赛区特等奖获得者或校级第一名，集中展现了全国高校大学生顶尖的英语综合应用能力。
本次全国总决赛设置英语演讲、英语辩论、英语风采三大竞赛板块，赛事覆盖面广、综合考察维度全面。我校选派6名优秀学子代表学校参赛，全体选手沉着应战、稳定发挥、勇于争先，在全国激烈角逐中斩获特等奖2项、一等奖6项、二等奖1项、三等奖1项，获评“最佳辩手”1项、优秀参赛选手2项，学校整体成绩在全国参赛高校中表现亮眼、位居前列。
从左至右：指导教师卜雅婷，选手韩鑫厚、丁子亦、李昊葭、杨歌飒、王婧伊、商政
今年4月至5月，2026年全国大学生英语竞赛校级初赛、省级决赛陆续开展。我校赛事工作由教务部、外国语学院大学生英语实践创新基地联合统筹承办，全校共计2800余名学生踊跃报名参赛，覆盖竞赛全部类别，参与面广、学生参赛热情高涨。经过校级层层选拔、省级多轮严格考核，我校丁子亦、韩鑫厚、杨歌飒、王婧伊、商政、李昊葭六位同学凭借扎实的语言功底与优异的综合表现，成功晋级全国总决赛。
赛事期间，组委会同步开设英语学习经验交流会、英语文化沙龙等特色配套活动，搭建全英文沉浸式交流平台，为全国参赛学子创造了语言互通、文化互鉴、经验互学的优质场景。系列活动寓教于乐、以赛促育，有效提升了学生的英语听说交流能力，锤炼了自主学习、创新思维与团队协作素养，进一步夯实了终身学习的基础。
我校学生韩鑫厚（左一），丁子亦（左二）参加辩论赛
为全力备战省赛、国赛，自今年4月起，在学校教务部、外国语学院的统筹指导下，大学生英语实践创新基地组建专项指导教师团队，为参赛选手开展了为期三个月的系统化集训与全真模拟训练。培训内容精准对标竞赛考点，覆盖笔试阅读、翻译、写作及口语演讲、专业辩论等核心模块，采用理论精讲、实战演练、复盘答疑相结合的培养模式，并结合每位学生的优势与短板制定个性化培优提升方案，精准助力选手能力提质增效。
本届总决赛赛题紧扣时代主题，演讲、辩论议题聚焦中国文化国际传播、社会主义核心价值观、社会热点思辨等前沿内容，英语风采大赛融合歌曲、舞蹈、话剧、创意展演等多元文艺形式，兼具语言专业性与思想时代性。我校参赛学子从容自信、发挥稳定，以扎实的专业积累、流畅的双语表达、敏捷的临场应变展现了优良的综合素养，赢得大赛评委的高度认可与一致好评，生动诠释了我校“三实一新”的优良校风。
通过长期系统集训与国家级大赛淬炼，参赛学生不仅实现了英语听说读写综合能力的跨越式提升，更在工程思维、人文素养、国际视野上实现了全方位成长，进一步彰显了学校复合型、创新型、领军型人才的培养成效，深度践行了我校“总师型”人才的育人理念。
我校学生杨歌飒（左），王婧伊（右）参加风采大赛
长期以来，我校高度重视学生外语综合能力与国际化素养培育，持续依托各类高水平学科竞赛搭建育人平台。全国大学生英语竞赛在校内参与热度持续攀升、参赛规模逐年扩大、覆盖院系不断拓宽，逐步形成“以赛促学、以学促练、以练促优”的优良学风氛围。多年来，我校学子在该项赛事中屡创佳绩，累计斩获国家级、省级奖项数百项，竞赛成绩稳步攀升、屡创新高。
一系列优异成绩，充分展现了我校学子扎实的外语功底、开阔的国际视野、严谨的思辨能力与勇于争先的进取精神。未来，学校将持续深耕外语教育教学改革，完善学科竞赛育人体系，以高水平赛事赋能高质量人才培养，持续书写我校国际化人才培育的崭新篇章。
