# 关于举办2026年陕西省高校企业竞争模拟大赛西北工业大学校内选拔赛的通知

各学院：
为深化创新创业教育改革，提升学生企业运营、企业决策和供应链管理能力，做好2026年陕西省高校企业竞争模拟大赛选拔工作，学校决定举办2026年陕西省高校企业竞争模拟大赛校内选拔赛，现将有关事宜通知如下。
一、竞赛简介
“企业竞争模拟”是运用计算机技术模拟企业的竞争环境，供模拟参加者进行企业运营和企业决策的练习。企业竞争模拟能训练学员在变化多端的经营环境里，面对多个竞争对手，发扬团队合作精神，全面、灵活地运用如生产管理、市场营销、财务会计、战略管理等管理学知识，和统计学、运筹学、决策论课程中的预测、优化、数据分析与挖掘等数量分析方法，正确制定企业的决策，达到企业的战略目标。全国企业竞争模拟大赛是利用基于互联网的企业竞争模拟系统面向高校大学生的重要商业模拟竞赛。截至2026年9月，全国企业竞争模拟大赛（本科组）已成功举办了17届，陕西省高校企业竞争模拟大赛已成功举办了6届。
全国企业竞争模拟大赛被列入《西北工业大学认定的本科生学科竞赛项目名录》（2026年版），为A1级别竞赛，是面向高校大学生的具有中国特色的重要商业模拟赛事，是中国高等教育学会发布的《全国普通高校大学生竞赛分析报告》重要的竞赛项目之一。
二、关联基地
校内关联基地：企业经营与创业模拟创新实践基地
三、参赛对象
本校在籍注册的本科生。
四、竞赛形式
（一）竞赛包括企业运营、企业决策、企业供应链决策三个赛道：
1.企业运营赛道采用BizWar企业经营竞争模拟软件，系统综合评价指标包括：上期分数、普通股股东权益、本期销售收入、本期净利润、本期人均净利润、本期投资回报率、累积纳税、累积普通股股利等十多项指标。
2.企业决策赛道采用iBizSim企业竞争模拟系统，系统综合评价指标包括：利润、市场占有率、累计纳税、累计分红、净资产、人均利润率、资本利润率等。
3.企业供应链决策赛道采用iBizSand企业竞争模拟系统，系统综合评价指标包括：企业投资回报率（ROI）、利润总额。
（二）本届大赛分为初赛（校内网络赛）、复赛（网络赛）和决赛（网络赛）三个阶段。
1.校内赛时间为12月5日，复赛竞赛时间为12月13日，决赛时间为12月27日。
2.校内赛以团队形式参赛。每支参赛队由3名参赛选手组成，每名学生只能报名一支队伍，参加一个赛道。
3.参赛同学可以跨年级、跨专业、跨学院组队。
4.报名后，企业经营与创业模拟创新实践基地将为参赛队伍提供统一培训与指导，并配备指导教师。
5.校内赛推选优秀队伍报名复赛。
五、校赛报名安排
报名方式：加入竞赛QQ群根据通知报名，后续咨询、辅导、比赛的具体时间地点安排等信息，将通过竞赛QQ群的方式通知。
报名截止日期：即日起至 2026年11月15日（周日）
