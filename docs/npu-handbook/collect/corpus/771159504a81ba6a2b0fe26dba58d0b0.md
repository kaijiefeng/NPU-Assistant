# 支部共建守初心 校史育人担使命-后勤集团

为传承红色基因，厚植爱校荣校情怀，11月3日，后勤集团工程服务中心党支部联合档案馆党支部、材料学院碳材料博士生党支部、碳材料师生融合党支部，共同开展校史教育主题党日暨支部共建活动，组织教工党员、学生党员追寻校史足迹，缅怀先贤。
活动首站，全体党员走进学校档案馆，参观档案文化长廊。档案馆刘老师以学校“脉源三支、强强融合”办学脉络为线索，讲述了古路坝“七星灯火”的烽火办学史、华航西迁的峥嵘历程、“哈军工”风洞群建设攻坚史，以及钱学森和西工大的深厚情缘，介绍了宋文骢、唐长红等校友总师的报国事迹，以史料实物和一个个“工大掌故”，生动阐释学校“总师育人文化”精神内核。
随后，全体党员前往友谊校区桃李园，在寿松涛、刘海滨、季文美三位先生的铜像前驻足瞻仰，聆听档案馆李老师声情并茂的讲述，回顾三位先生的人生历程。三座铜像静静伫立，诉说着先贤们将人生最宝贵的年华留在西北热土的动人故事。
雕像无言，精神有声。蒙蒙细雨中，教工党员和学生党员们有序开展擦拭先贤铜像志愿服务。大家手持抹布，轻轻拭去雕塑表面的浮尘，以简朴庄重的方式追思先贤、致敬前辈。一次擦拭，一份敬意，这既是饱含深情的缅怀，更是一堂浸润人心的现场思政课。
此次支部共建活动，将校史教育、先贤事迹学习与劳动教育有机结合，为各支部互学共进搭建了交流平台。大家表示，将铭记先辈奋斗历程，传承弘扬总师育人文化，把学习所得转化为干事创业的动力，立足本职岗位，勤学实干、笃行不怠，以实际行动践行共产党人的初心使命，为学校高质量发展贡献力量。（文/图：后勤集团、档案馆；审核：张卫红、邱若娟）
