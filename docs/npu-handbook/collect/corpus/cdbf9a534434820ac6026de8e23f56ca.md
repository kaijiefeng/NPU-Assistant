# 生命科学与技术学院组织“用青春铺路，让理想闪光——走好新时代的长征路”微党课院赛

为深入学习贯彻党的创新理论，弘扬伟大长征精神，引导青年学生坚定理想信念、勇担时代使命，11月5日下午，生命科学与技术学院在学院报告厅举办“用青春铺路，让理想闪光——走好新时代的长征路”微党课院赛。学院党委副书记张敏乔、教育实验学院／未来技术学院辅导员王杰老师、生科院辅导员乔雪琪老师、学工主管景丽和马倩老师担任评委。各支部党员代表、入党积极分子代表近百人到场观摩学习。比赛由兼职辅导员王春霖主持。
比赛中，参赛选手紧扣主题，立足专业特色与时代背景，以鲜活的事例、真挚的情感和生动的语言讲述红色故事、传承革命精神、诉说报国之志。研究生第一党支部闫琦雨以通过一封跨越时空的书信，展现长征精神在新时代的赓续传承；动物生态学师生融合党支部高天池以“民勤治沙七十载”为切入点，讲述几代治沙人扎根荒漠、接续奋斗的感人事迹，结合专业特色诠释新时代青年的责任与担当；秦岭生态监测与保护师生融合党支部路源阐释雷锋精神的深刻内涵与时代价值。研究生第四党支部吴敏、研究生第五党支部孙雯君、研究生第六党支部彭瑞宁、高年级本科生党支部段苏扬及低年级本科党支部姜仲桓围绕“当代青年如何走好新时代长征路”“青春铸剑”等主题展开宣讲，回顾革命先辈艰苦奋斗、无私奉献的光辉历程，讲述一代代西工大人胸怀家国、潜心科研、为国铸剑的感人故事，激励青年学子将个人理想融入国家发展大局。整场比赛主题鲜明、内容丰富，选手们的精彩宣讲赢得现场师生阵阵掌声。
比赛结束后，张敏乔作总结讲话。她对本次大赛的举办及参赛选手的表现给予肯定，并提出三点期望：一是赓续长征精神，坚定理想信念。希望青年学子从党的光辉历史中汲取精神力量，传承红色基因，始终保持奋发向上的精神状态。二是树立远大理想，肩负时代使命。勉励同学们将个人成长与国家发展、民族复兴紧密结合，把青春理想融入党和人民的事业，在新时代新征程中勇担责任、主动作为。三是练就过硬本领，贡献青春力量。鼓励同学们珍惜青春时光，立足专业、勤学笃行，在专业学习、科研创新与实践锻炼中提升综合素质，以扎实的专业能力和实际行动服务国家发展需要，在奋斗中书写青春答卷。
此次微党课大赛以赛促学、以讲促思，为学院学生党员搭建了交流学习、展示风采的平台，进一步激发了青年学子的爱国热情与使命担当。学院将持续创新党员教育形式，引导广大青年学生赓续红色血脉、汲取奋进力量，以实际行动走好新时代的长征路。
