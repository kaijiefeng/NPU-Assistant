# 西工大社区卫生服务站开具《居民死亡推断书》办事指南-西北工业大学医院

社区居民居家或公共场所死亡者需到社区卫生服务中心或服务站开具《居民死亡推断书》。死者家属持《居民死亡推断书》二、三、四联办理相关后续手续。注：若未持《居民死亡医学推断书》，殡仪馆不予接收死者及办理尸体火化手续。为避免家属产生不必要的麻烦，请在死者被送至殡仪馆之前，携带好完整资料前往校医院急诊科开具《居民死亡医学推断书》。
（一）西工大社区内（户籍和非户籍）居民在家正常死亡者开具《居民死亡推断书》的办理流程如下：
1.确认医学死亡。（请拨打120急救电话或校医院急诊科电话）
2.家属持死者身份证原件及复印件1份、户口本原件及120出具的确认死亡证明或者西工大校医院出具的死因初步推断证明到居委会开具《社区居民死亡证明》。
3.家属持《社区居民死亡证明》和相关材料（详见流程图）到校医院急诊科开具《居民死亡推断书》。
（二）西工大社区内（户籍和非户籍）居民在家非正常死亡者及在本社区公共场所死亡者开具《居民死亡推断书》的办理流程如下：
1.确认医学死亡。（请拨打120急救电话）
2.拨打110，公安机关现场勘察出具死者身份证明及现场死亡事实证明。
3.家属持死者身份证原件及复印件1份、户口本原件及120出具的确认死亡证明到所居住社区居委会开具《社区居民死亡证明》。
4.家属持《社区居民死亡证明》和公安机关出具的死者身份证明及现场死亡事实证明以及相关材料（详见流程图）到校医院急诊科开具《居民死亡推断书》。
