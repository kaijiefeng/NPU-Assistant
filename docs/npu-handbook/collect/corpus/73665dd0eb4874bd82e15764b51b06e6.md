# 2025年第三批国际化领军人才培养项目申报通知

为深入贯彻习近平新时代中国特色社会主义思想，培养更多创新型、紧缺型、复合型国际化人才，学校决定继续实施国际化领军人才培养项目，资助优秀硕博士研究生赴国（境）外一流大学和机构进行联合培养。
一、主要选派类别及留学期限
联合培养硕士研究生：3-12个月；
联合培养博士研究生：6-24个月
二、资助内容为一次往返国际旅费和资助期限内的奖学金。

项目实际资助期限及资助标准以最终录取结果为准，留学资格有效期保留一年。资助期限不应超过拟留学单位邀请信中规定的留学期限和项目规定的最长资助期限。申请人可根据联合培养需求办理项目改派，变更留学单位、外方导师、留学期限等，但获批的资助期限不得延长。
三、重点支持留学人员前往教育、科技发达国家和地区的世界一流大学和科研院所。优先支持留学人员赴QS世界大学排名、泰晤士高等教育世界大学排名（THE）、U.S.News世界大学排名或世界大学学术排名（ARWU）四大排行榜认定的全球排名前200名的高校或所申请学科前100的高校。
四、暂不受理以下任一人员的申请
1. 已获得国（境）外全额奖学金资助。
2. 已获得国家公派留学资格且尚在有效期内。
3. 已申报国家公派出国留学各类项目，尚未获得录取结果。
4. 已获得/在校期间已享受过校内外其他三个月及以上出国（境）项目资助。
五、申请材料
1. 《国际化领军人才培养项目申请表》（见附件1）
2. 拟留学单位邀请信/入学通知（如非英文，需提供中文翻译件）
六、申请流程
1.学生申请：请将申请材料一同交至学院外事秘书；
2.学院审核：学院审核后提交至国际合作处（毅字楼721办公室），具体提交方式见文末；
4.确定结果：根据学院推荐意见及学生申请材料确认录取结果并公示。
请各单位于2025年11月14日（周五）前将申请材料扫描件以及附件2电子版及扫描件以压缩包形式发送至wangruojia@nwpu.edu.cn。总文件夹命名为：XXX学院2025年第三批领军申请材料，其中包含单独以学生姓名命名的个人申请材料文件夹。
