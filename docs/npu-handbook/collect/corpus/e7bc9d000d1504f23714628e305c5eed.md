# 陕西省关工委来校考察调研“五老”关爱工作室

9月10日下午，陕西省关工委常务副主任应宏锋、陕西省教育系统关工委副主任张海明等一行，来校考察调研航天学院“育心护航·关爱工作室”建设相关工作。学校关工委主任陈建有，离退休工作处处长、关工委秘书长赵洪章，航天学院党委书记、关工委主任黄越，离退休工作处副处长、关工委副秘书长马俊，离退休工作处五级职员王静，“银发育心员”高宝营、李进贤、谷良贤、王焘参加会议。
调研组现场观摩工作室品牌活动——《生活中的情绪心理学》心理读书会。活动由黄越主持，高宝营主讲，银发育心员与30余名学生代表共同参与。高宝营围绕嫉妒情绪这一常见心理现象，析成因、讲表现、谈影响，引导学生科学正视情绪变化，理性看待成长差距与良性竞争，将负面情绪转化为进取动力。学生结合自身经历与理解积极踊跃发言。
座谈会上，赵洪章介绍了学校“五老”关爱工作室的整体建设情况、工作成效及下一步的打算。黄越介绍了学院关工委在银发队伍建设、活动组织开展的具体做法，以及“育心护航·关爱工作室”的实践探索。与会人员围绕“五老”赋能心理健康教育、学业帮扶、生涯规划等深入交流。
张海明指出，学校“五老”关爱工作室站位高、思路新、举措实，将心理健康教育与思想政治引领有机融合，体现了西工大特色。他强调，要关注学生心理健康新情况，推动关爱工作下沉学院、班级、宿舍，做到早发现、早关怀、早帮扶；要总结可复制可推广的经验，打造教育系统关工委工作品牌。
应宏锋充分肯定学校关工委工作和“五老”关爱工作室的建设成效。他指出，当前学生心理健康问题日益受到关注，心理读书会等活动精准贴合大学生成长需求，学校高度重视工作室建设，平台扎实、特色鲜明、成效显著。希望学校持续深耕“五老”关爱品牌，盘活优质资源，丰富育人载体，创新育人模式，常态化开展暖心育心活动，全方位助力青年学生身心健康、全面发展，打造高校关工委育人特色标杆。
陈建有感谢省关工委、省教育系统关工委长期关心支持。他表示，学校将认真落实调研指导意见，以“十五五”开局为契机，聚焦铸魂育人，传承红色基因，深化“五老助五育”；加强自身建设，壮大“五老”队伍，健全长效机制；持续建好省儿童青少年心理健康研究中心，推动“五老”关爱工作室提质增效，为培养堪当民族复兴重任的时代新人贡献西工大力量。
会后，关工委和航天学院共同向老教授、老领导敬献鲜花，致以教师节问候。
