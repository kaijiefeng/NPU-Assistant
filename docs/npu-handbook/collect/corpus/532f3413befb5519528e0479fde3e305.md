# 江西飞行学院来院调研交流座谈

11月9日下午，江西飞行学院原党委委员、副校长肖鸿晶教授、江西飞行学院航空信息工程学院党总支副书记李晓华一行来民航学院开展专题调研交流。民航学院党委书记闫伟、教学副院长张晓化、院长助理陈杰、专业负责人刘贞报出席座谈会。
闫伟代表学院，对江西飞行学院一行的到访表示热烈欢迎，并简要介绍了学院历史沿革、师资队伍、学科建设等情况。肖鸿晶也重点介绍了航空信息工程学院在学科建设、人才培养等方面的特色和成果。张晓化重点围绕人才培养，介绍了学院专业建设情况、专业建设的基本思路与经验等。
研讨交流环节，双方围绕西安低空经济产业人才需求、传统航空专业改造、课程体系重构、实践教学建设、校企协同育人等重点内容深入交流。来访人员结合江西航空产业发展实际，就优化人才培养体系、更好地服务地方低空经济发展等问题开展探讨。
此次座谈搭建起良好的校际沟通平台，进一步拓宽了双方办学思路。下一步，两院将保持常态化沟通，持续深化交流协作，共同培育低空经济复合型人才，助力低空经济产业高质量发展。
