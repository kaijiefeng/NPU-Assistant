# 建设最美书香校园，浸润总师育人文化——2024年校园阅读文化节开幕

4月23日下午，2024年校园阅读文化节开幕式暨优秀读者颁奖典礼在长安校区图书馆报告厅举行。今年的主题是“建设最美书香校园，浸润总师育人文化”。中国科学院院士、我校副校长张卫红，中国工程院院士马远良莅临开幕式现场，校内多个部门及学院负责人、图书馆领导班子成员及各部室负责人、优秀读者、师生代表等150余人参加开幕式。

张卫红致开幕词。他指出，举办校园阅读文化节是学校深入推进全民阅读、弘扬“总师育人文化”、建设书香校园、促进学校高质量发展的重要举措，希望大家坚持学思用贯通、知信行统一，锤炼本领、增长才干。

马远良院士向图书馆赠送了“工大学者文库”题词。开幕式举行了“工大学者文库”揭牌仪式、“三航”特藏馆揭牌仪式、精品学术著作入藏仪式，并现场用视频回顾了“书香进秦巴”的捐书活动。随后进行优秀读者颁奖典礼，与会领导为第九届“万方杯”信息检索大赛获奖者、2023年度优秀读者及优秀学生服务标兵逐一颁发了证书。

图书馆馆长张盛兵在总结发言中表示，今后图书馆将继续坚守职责，齐心协力，共同推动学校“127”发展目标的落实，为工大人才培养和科学研究贡献力量。

开幕式启动后，图书馆集中展示了近期建设的新资源、新空间以及各类特色展：与航海学院合办“大国之蓝”海洋科技文化主题巡展，与航天学院合办“极目楚天 共襄星汉”中国航天大事记和西工大成就展，遴选并举办西北工业大学CNS正刊成果展、西工大出版社“总师育人文化”及“三航”优秀图书入藏展。

“工大学者文库”整理我校学者学术研究成果，保留学校的学术历史和文化传统，是图书馆特藏文化建设的重要项目之一；“三航”特藏馆收集整理我校图书馆航空、航天、航海及相关专业图书文献；精品学术著作由科学技术研究院将我校多位教师撰写的精品学术著作移交入藏图书馆。

活动期间还举办了图书馆老物件展（西文打字机、俄文打字机、单双卡录音机、缩微平片阅读机、电影放映机等）、图书创意工作坊（美育课堂）、图书馆读者满意度调查、图书修补活动、文创产品展示、纸飞机大赛、亲子读书月、“总师之路”影视播放等。
