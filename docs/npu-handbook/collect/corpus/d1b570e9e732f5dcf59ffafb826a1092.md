# 集成电路学院举办2026级新生生涯规划班会-集成电路学院（微电子学院）

为帮助2026级新生树立远大理想、明确发展方向，增强生涯规划意识，10月22日，集成电路学院举办新生生涯规划班会。2026级辅导员王淼主持，2023级辅导员贺睿杰作专题宣讲，2026级全体新生参加。
班会开始，王淼结合大学学习特点，围绕学业发展、实践锻炼和综合素质培养等方面进行交流，引导同学们认识大学阶段的责任与使命，增强自主规划意识，将个人理想追求与国家发展需要相结合。
随后，贺睿杰从认识大学、认识自己、规划未来三个方面展开宣讲。引导同学们主动适应大学生活，认识自身兴趣、性格与能力优势，思考个人成长方向。结合集成电路学科特点与行业需求，引导同学们关注国家战略需求，树立远大志向，增强专业认同感与使命担当，将个人发展融入国家科技创新与集成电路产业发展大局。
交流环节中，同学们围绕学业发展、未来规划等问题积极提问，贺睿杰逐一解答，引导大家正确认识阶段性目标与长远发展的关系。
此次班会增强了新生的生涯规划意识和专业使命感。下一步，学院将持续深化理想信念教育、生涯规划教育与专业教育，引导学生将个人成长融入国家发展大局，为国家科技进步和集成电路事业发展贡献力量。
