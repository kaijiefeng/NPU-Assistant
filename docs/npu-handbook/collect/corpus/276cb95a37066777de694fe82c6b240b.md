# 后勤办公室党支部组织党员理论学习会议

根据学校机关党委5月党支部理论学习指导意见，5月13日下午，后勤办公室党支部在会议室召开了全体党员理论学习会，会议由党支部书记张文刚同志主持。
会上，党支部副书记韩争胜同志组织党员集中学习了习近平总书记在陕西考察、西迁精神、给参与“东方红一号”任务的老科学家重要回信、寄语新时代青年等全部内容；学习了中共中央办公厅印发《关于持续解决困扰基层的形式主义问题为决胜全面建成小康社会提供坚强作风保证的通知》、中共工业和信息化部党组《关于进一步贯彻落实中央八项规定精神和解决形式主义突出问题为基层减负的意见》等文件主要内容。党员们结合本职工作实际，就如何发扬西迁精神、加强作风建设开展了专题讨论。
党支部书记张文刚同志结合理论学习，对党员提出了具体要求。一是按照学校和上级部门文件要求，认真落实后勤办公室首问责任制，进一步加强作风建设，在制度建设方面，梳理修订完善内部管理制度，规范业务管理工作流程，为后勤管理提供制度保障。二是要进一步增强责任意识、敢于担当意识，在各自工作岗位上认真履行职责，发挥党员模范带头作用，努力完成本职工作，把后勤办公室建设成团结战斗的坚强集体。
