# 聚成长｜学院开展沟通与联结专题讲座

为引导学生掌握有效沟通方法，提升人际联结与表达能力，教育实验学院/未来技术学院/学科交叉中心于11月5日下午举办“沟通与联结：把话说到人心里”专题讲座。本次讲座特邀管理学院张亚莉教授担任主讲，2026级本科生及辅导员刘更亮到场聆听。
讲座伊始，张亚莉教授从沟通的长期现实价值切入，结合AI时代下大学生日常沟通的现实现象，阐释沟通双向传递的本质内涵，厘清有效沟通的核心构成要素。现场设置室友交流分享、传话游戏等趣味互动体验，引导同学们直观感受信息传递过程中的损耗与偏差，跳出“话术至上”的认知误区，帮助大家建立起对有效沟通更加完整客观的认知。
围绕校园真实生活场景，张亚莉教授讲解了可落地的沟通实践原则，同时聚焦人际心态建设开展正向引导，帮助同学们理性看待他人评价、接纳真实自我。她指出，沟通能力的提升不在于熟记技巧，而贵在持续的行为改变，为同学们的人际成长指明实践方向。
本次讲座为同学们适应校园生活、构建良好人际关系提供务实指引。学院将持续聚焦拔尖创新人才培养目标，统筹抓好专业培养与素养培育，促进学生学业发展与身心成长同频共进，助力学生成长为综合素质过硬的拔尖创新人才。
