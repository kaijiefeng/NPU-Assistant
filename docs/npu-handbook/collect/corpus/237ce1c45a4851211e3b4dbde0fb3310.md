# 公共政策与管理学院成功举办2026年暑期校园开放日暨研究生招生宣传日活动

7月10日至12日，公共政策与管理学院2026年暑期校园开放日暨研究生招生宣传日活动顺利举办，来自全国50余所高校的90余名优秀本科生齐聚一堂，开启学术探索与校园体验之旅。
7月11日上午，开营仪式在友谊校区西馆举行，学院分管研究生工作的副院长李娜主持，学院领导、各系主任与导师代表到场参加。
仪式上，学院党委书记管兴华讲话，他介绍了西北工业大学发展成果、“一十百千”建设目标与优质的就业出路，鼓励大家坚定文科学习信念；学院院长刘晨光详细讲解了学院学科、师资情况和研究生培养规则，倡导学子树立家国情怀、踏实科研，期待优秀学子加入学院深造。
仪式结束后，公共管理学、应用经济学、法学、教育学、文物五个专业分场同步开展学术讲座和师生座谈。各专业导师们围绕学科前沿动态、研究方向与招生培养要求耐心细致进行讲解，同学们结合自身学业规划踊跃提问，在双向互动中深化了对学科特色与科研路径的认知，现场交流氛围融洽热烈。
当日下午，参营同学们统一乘车前往长安校区。在校史馆中，大家沉浸式感悟西工大“隐姓埋名、为国铸剑”的精神传承；漫步校园间，山水校园的雅致风貌与水上图书馆等特色建筑给同学们留下深刻印象。
在随后的学生交流会上，学院邀请在读研究生为大家分享在校学习感受与学习生活经验，帮助同学们更直观地了解研究生阶段的成长路径。
7月12日上午，同学们参加学校校园开放日开幕式。西北工业大学副校长王伶出席并讲话，他介绍了学校办学特色与发展成就，勉励同学们锚定理想、勇担使命。研究生院院长朱继宏解读了学校研究生招生政策与培养体系。学校还特邀总师嘉宾作专题讲座，结合一线科研实践分享心得体会，传递家国情怀，同学们深受启发。
此次开放日搭建起学院与全国优秀学子的对接桥梁，全方位展现了公共政策与管理学院的办学实力与育人温度。未来，学院将持续优化招生宣传形式，广纳优质生源，携手青年学子共赴学术新程。
