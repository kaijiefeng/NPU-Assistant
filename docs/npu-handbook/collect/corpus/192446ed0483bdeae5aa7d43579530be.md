# 享受免征增值税政策解读

我校目前是增值税一般纳税人，增值税款征收率为3%（不包括其他附加税种），开具增值税普通发票。可以按国家有关规定享受“提供技术转让、技术开发和与之相关的技术咨询、技术服务”的增值税直接减免税收优惠。提供免税应税服务合同不得开具增值税专用发票。为了能顺利享受国家税收优惠政策，需注意以下几点：
一、纳税义务发生时间的确定：
【(财税[2013]37号)第四十一条】中规定，增值税纳税义务发生时间为：
1.纳税人提供应税服务并收讫销售款项或者取得索取销售款项凭据的当天；先开具发票的，为开具发票的当天。
收讫销售款项，是指纳税人提供应税服务过程中或者完成后收到款项。
取得索取销售款项凭据的当天，是指书面合同确定的付款日期；未签订书面合同或者书面合同未确定付款日期的，为应税服务完成的当天。
2. 纳税人提供有形动产租赁服务采取预收款方式的，其纳税义务发生时间为收到预收款的当天。
3. 纳税人发生视同提供应税服务的，其纳税义务发生时间为应税服务完成的当天。
4. 增值税扣缴义务发生时间为纳税人增值税纳税义务发生的当天。
即1.纳税人提供应税服务并收讫销售款项的日期 2.开具发票的日期3.书面合同确定的付款日期4.应税服务完成的当天。四者中最早的一个日期为纳税义务的发生时间。
二、可享受免税的合同：
提供技术转让、技术开发和与之相关的技术咨询、技术服务。
（1）技术转让，是指转让者将其拥有的专利和非专利技术的所有权或者使用权有偿转让他人的行为；技术开发，是指开发者接受他人委托，就新技术、新产品、新工艺或者新材料及其系统进行研究开发的行为；技术咨询，是指就特定技术项目提供可行性论证、技术预测、专题技术调查、分析评价报告等。
（2）与技术转让、技术开发相关的技术咨询、技术服务，是指转让方（或受托方）根据技术转让或开发合同的规定，为帮助受让方（或委托方）掌握所转让（或委托开发）的技术，而提供的技术咨询、技术服务业务，且这部分技术咨询、服务的价款与技术转让（或开发）的价款应当开在同一张发票上。
注：单独签订的技术咨询和技术服务合同不能享受免税。
三、免税审批的程序。
试点纳税人申请免征增值税时，须持技术转让、开发的书面合同，到试点纳税人所在地省级科技主管部门进行认定，并持有关的书面合同和科技主管部门审核意见证明文件报主管国家税务局备查。
需要特别注意的事项：
1.目前相关备案的时间大约需要4个月，分别是省科技厅认定部门一个月、省科技厅出文件一个月、主管税务所审核合同一个月、主管税务局免税备案一个月。望各位老师在签订合同时将第一次付款的时间留够办理备案所需的时间，（即提交备案合同给科技管理部的时间到纳税义务的发生时间[上面一点所述]至少留够4个月，否则仍享受不到免税优惠政策）
2.享受免税备案的合同不能开具增值税专用发票,只能开具增值税普通发票。如果开具专用发票，则全校36个月内不得再申请免税、减税。望各位老师在提交备案合同时，问清对方单位后再提交需要免税的备案合同，以免造成全校36个月享受不到免税优惠政策。
