# 关于开展2024年度第二期教育教学改革研究交流活动的通知

各位教师：
为进一步落实立德树人根本任务，全面深化教育教学改革，提高教师教育教学水平，提升“总师”型人才培养质量，鼓励教师产出高水平教育教学改革研究成果，并将成果应用人才培养全过程。教务部特邀请国家级教学成果一等奖第一完成人赵美英老师作教育教学改革交流报告。
一、报告题目
以能力产出为导向的专业课项目式教学改革与教学成果凝练
二、报告时间
5月17日（星期五）16:00-17:30
三、报告地点
友谊校区国五会议室
四、报告人简介
赵美英，陕西省教学名师，“飞机设计专业课程”国家级教学团队负责人，“飞行器结构设计”国家级精品课程负责人，“轻质多功能超材料设计创新”陕西省科技创新团队负责人，2023年获国家级教学成果一等奖。
从教三十余年来，坚决贯彻落实立德树人的根本任务，践行为党育人、为国育才的初心使命，致力于高等工程教育人才培养模式改革与创新、专业、课程与教材建设等教学研究和成果应用推广。在总师育人文化的引领下，不断深化本科生专业课程教学改革和研究生导学团队建设，努力开拓“总师”型人才培养的新途径，广泛开展课程思政和“以创新设计能力产出为导向”的教学改革，提出了“基于飞机结构实物的案例式教学法”和“现场课-理论课协同教学法”，曾完成省级教改项目3项，获陕西省教学成果奖4项。
