# 莫航学院团委传达学习贯彻党的二十届五中全会精神

11月2日下午，莫航学院团委召开专题会议，集中传达学习党的二十届五中全会精神。学院团委书记杨粉萍、副书记邢文思、学院团学骨干、青年学生代表参会。
会上，参会人员集体学习了《关于〈中共中央关于持之以恒推进全面从严治党若干重大问题的决定〉的说明》《中国共产党第二十届中央委员会第五次全体会议公报》以及《中共中央关于持之以恒推进全面从严治党若干重大问题的决定》，同步传达了学校党委理论学习中心组扩大会议精神。与会人员深刻领会全会的重大意义、核心要义和实践要求，准确把握持之以恒推进全面从严治党各项部署安排。
会议指出，持之以恒推进全面从严治党，是新时代党的自我革命的伟大实践；全面从严管团治团，是全面从严治党在青年群团领域的延伸和落实。学院团委将认真学习贯彻落实全会精神，把严的基调、严的举措、严的氛围贯穿团学育人全过程。
会议强调，各团支部要把学习宣传贯彻党的二十届五中全会精神作为当前和今后一个时期的重大政治任务，面向青年学生扎实开展宣讲阐释，坚持学用结合、知行合一，推动全会精神入脑入心。全体团学骨干要深刻把握新时代青年工作的政治使命，切实将学习成效转化为服务青年、实干建功的强大动力。全体青年学子要在日常学习与实践中，牢记青年使命、主动担当作为、锤炼务实作风，以笃行实干的行动自觉投身“十五五”建设发展新征程。
下一步，学院团委将在学院党委指导下，依托各团支部主题团日活动、小组研讨、主题宣讲等形式持续深化学习宣传，切实引领学院广大青年学子把个人成长融入国家发展战略大局，奋力书写新时代青年学子的青春答卷。
