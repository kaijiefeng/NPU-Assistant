# 山河万里·卓越同行——国家卓越工程师学院访企问学上海站顺利开展

为持续深化产教融合，扎实推进卓越工程师人才培养改革，精准对接航空航天领域重大工程需求，夯实工程硕博士联合培养工作基础，10月22日—24日，西北工业大学国家卓越工程师学院赴上海开展“山河万里·卓越同行”访企问学调研走访系列活动。本次活动依托大学生科技社团支持计划，遴选学生代表随队同行，搭建起校园科创实践与产业一线对接的平台，帮助青年学子近距离感受一线科研实景，在实地走访研学中涵养科创素养、厚植报国情怀。
学院党委副书记、副院长王谦,团委书记、辅导员孙康瑶带队，先后走访上海空间推进研究所、中国商飞上海飞机设计研究院、中国商飞上海航空工业（集团）有限公司，看望在岗专业实践的研究生，实地了解学生的课题进展、岗位安排和日常生活，并就联合培养工作、就业对接等共商校企协同育人路径；同步开展红色思政研学，引导工程学子扎根一线、为国铸剑。
走访期间，各单位详细介绍了核心科研领域布局、前沿技术发展方向和人才引进政策。双方重点梳理了工程硕博士联合培养、校企双导师协同指导、产学研项目联动攻关等工作的推进成效，为持续深化合作夯实根基。座谈交流会上，校企双方围绕工程硕博士入企实践管理、实践保障服务体系、实践过程考核评价、科研创新能力培育、协同育人机制优化及毕业生留企就业情况等内容充分交流研讨。双方一致表示，将建立常态化沟通机制，持续打通人才培养供需链路，依托企业真实工程场景与科研平台，引导学生扎根产业一线深耕关键技术。学院团队走进企业展厅、测试场地与生产现场，通过一线实地走访，精准了解产业技术需求以及工程人才的核心能力要求，为学院动态优化人才培养方案、创新实践育人模式获取了一线产业数据。
走访各单位期间，学院与在岗实践学子、即将入企实践学生代表开展座谈交流。同学们结合参与型号攻坚、科研攻关的亲身经历，分享了一线学习的收获感悟、科研探索的成长思考以及职业发展的规划方向，同时也如实反馈实践过程中遇到的困难与诉求。学院调研团队认真倾听、逐一回应，勉励全体学子牢记科技报国初心使命，沉心扎根工程实践一线，敢于直面技术瓶颈与科研难题，充分依托优质产业平台锤炼专业技能、积累工程经验，努力成长为可堪大任的卓越工程人才。
为赓续红色血脉、筑牢报国初心，本次走访期间，学院组织师生前往中共一大纪念馆开展沉浸式红色研学活动。师生驻足研读史料、观摩珍贵文物，重温建党峥嵘岁月，深刻体悟伟大建党精神的内涵与时代价值。同学们纷纷表示，将传承红色基因、坚定报国志向，把个人成长主动融入国家重大战略，以实干担当深耕工程领域，以过硬本领践行报国初心。
此次上海站访企问学活动，是学院做实做细卓越工程师培育工作的关键举措。活动串联整合了空间动力、民用大飞机、航空制造等多领域优质产业育人资源，进一步深化了校企协同育人合作关系，掌握了一线培养实况与产业用人需求，为健全工程硕博士全周期培育管理体系、构建精准化产教融合育人格局提供了有力支撑。
下一步，学院将持续立足国家战略与产业发展导向，常态化推进访企问学调研活动，不断深化产教、科教、研教深度融合，持续优化完善卓越工程师培育体系与校企协同共育机制，推动人才培养、科研创新、产业服务深度同频共振，持续培育一批信念坚定、技术精湛、敢于创新、勇于担当的卓越工程人才，为我国国防科技事业高质量发展、国家高水平科技自立自强持续注入西工大青春动能。
