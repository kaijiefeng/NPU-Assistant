# 承前启后，继往开来——后勤办公室党支部成功召开换届选举大会

7月1日下午3点，后勤办公室在友谊校区会议室召开了党支部换届选举大会。
会议由张文刚同志主持并报告了机关党委关于后勤办公室党支部委员会组成人员候选人预备人选的批复情况，同时代表支委向支部全体党员做了上一届支委会工作汇报。
随后，张文刚同志宣读了选举办法和候选人名单，推选了监票人、计票人名单。在投票环节中，支部严格按照公平、公正、公开的原则，由专门监票人和计票人唱票并宣读结果。经党员大会无记名、差额投票，张文刚、韩争胜、李保康、常跃跃、毛淑兰五名同志当选为后勤办公室党支部新一届委员会委员。
会议最后，张文刚同志做了会议总结。他对上一届支委会的工作予以肯定，希望新一届支委会带领党支部继续发挥战斗堡垒和党员模范带头作用，增强管理服务意识，推动后勤各项管理服务工作稳步开展。
会后，新一届支部委员会举行第一次支委会，选举产生了党支部书记和副书记，并对支委进行了分工。
