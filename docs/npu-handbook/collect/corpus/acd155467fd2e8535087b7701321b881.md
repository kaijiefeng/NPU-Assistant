# 喜报！自动化学院樊泽明教授荣获双项机械行业教育奖

喜报！自动化学院樊泽明教授荣获双项机械行业教育奖
近日，中国机械工业教育协会公布“中国机械行业教育教学名师”等资质评价工作评审结果，自动化学院樊泽明教授凭借在机器人工程教育教学与教材建设方面的突出成果，一举摘得两项行业大奖——“中国机械行业教育教学名师”和“中国机械行业教育优秀成果（教材）一等奖”。
揽获行业双项荣誉，彰显教学硬实力
此次奖项由中国机械工业教育协会（国家一级协会）组织评定，是面向全国机械类高校及企业教育工作者的最高荣誉之一。“教育教学名师”和“优秀成果（教材）一等奖”两项荣誉的斩获，既是对樊教授在机器人工程教学领域贡献的肯定，也是学院深化教育教学改革、创新人才培养的重要标志性成果。
图1 樊泽明教授荣获的“中国机械行业教育教学名师”和“机械行业教育优秀成果（教材）一等奖”证书
立德树人，潜心深耕机器人学科
荣获“中国机械行业教育教学名师”称号（全国普通本科院校共115名获此殊荣），是樊泽明教授长期致力于机器人工程教学改革、课程体系建设与创新方面的集中体现，也是对其在行业领域获得成果的充分肯定。
他成功将串联型、并联型与移动机器人技术融合，研发了56款多功能、自主智能机器人研究平台，发布行业标准3项，平台中的轮式人形机器人实践系统已入选工业和信息化部首批国家级“先进适用技术”榜单，为陕西省唯一上榜技术，获省自然科学奖1项、省高校科学技术奖2项。
图2 樊泽明教授在宣传和科普机器人学科
在教学方面，樊教授开发了基于“互联网+数字孪生+AI技术”的线上线下混合式教学平台，以此为支撑，课程负责人建设：国家级一流课程1门、省级各类一流课程3门、校级各类一流课程6门；第一主编：教材6部和教改专著3部，其中，中国机械行业优秀教材一等奖（最高奖）、国家重点出版物出版项目2部、国家战略新兴领域“十四五”规划教材1部（直接参评国家“十四五”规划教材）、已推荐参评国家“十四五”规划教材1部、国际著名出版社出版英文教材1部、工业和信息化部精品教材1部、工业和信息化部“十四五”规划教材1部，国家出版基金项目专著1部；专业负责人主持：《机器人工程》专业建设与改革，获国家级一流专业，2023年软科评级“A+”和软科排名全国“第六”；分别以第一、第三完成人获得：省级教学成果奖3项、校级教学成果奖8项；第一完成人获得：省级以上教学竞赛奖20余项，其中全国高校教师教学创新大赛荣获一等奖（本次大赛，全国高校一等奖只有12项、二等奖40项、三等奖197项，该奖项为陕西省唯一一等奖）；第一完成人获得：中国机械行业教育教学名师、校级卓越名师奖等教学荣誉奖10余项；负责人获得：优秀教学研究一等奖2项、西部联盟竞赛奖1项、优秀基层教学组织奖和示范课程团队2项。
图3樊泽明教授主持的《计算机控制系统》课程获评国家级一流课程
樊教授主持和参与了10余项国家级与省部级教改项目，取得了20余篇教改论文、10余项教改专利。相关教学成果不仅推动了机器人学科的前沿发展，也为国内外高校与企业提供了宝贵的技术支持。
厚植育人初心，一流教材赋能高水平人才培养
樊教授主编的《机器人学基础》教材获中国机械行业优秀教材一等奖（全国一等奖23部、二等奖48部、三等奖38部）。该教材首次将串联型、并联型和移动型三类机器人技术有机融合，实现了机器人本体、环境构建与交互技术的系统集成。为配套教学，樊教授开发了高智能立体化数字平台，结合数字孪生、人工智能和课程思政等先进方案，打造了“纸质教材+数字平台”融合式教学新模式。目前，该教材已获评工业和信息化部精品教材，已推荐国家级“十四五”规划教材，并在全国28个省、百余所高校推广使用，出版两年时间，已销售13000余册。
图4 樊泽明教授编写的部分教材
此次樊则明教师获奖，是对学院在机器人工程领域教育教学、科学研究等方面工作的高度肯定，也彰显了我院在机器人行业人才培养的卓越成效。下一步，学院将持续深化教育教学改革，加强师资队伍建设，推动产学研深度融合，持续推动行业领域更多高水平创新人才培养和科研成果涌现。
