# 学院举办2025年第二期发展对象和入党积极分子培训班

为进一步加强党员教育管理，切实增强党的理论教育和党性教育，提高学院党员发展质量，9月至11月，教育实验学院/未来技术学院2025年第二期发展对象培训班和入党积极分子培训班顺利举行，学院本期发展对象、入党积极分子100余人参与。
本次培训仍以“金色课堂、红色课堂、蓝色课堂”为三大模块，采用“专题授课+视频党课+实践教育+交流研讨+结业考核”的模式，让理论学习有深度、实践感悟有温度、考核检验有力度。
专题授课环节，牟蕾书记讲述和介绍了学校“总师育人文化”的特质内涵和拔尖人才培养路径，希望同学们在日常学习生活中发挥先锋模范带头作用，将学校“总师育人文化”内化于心、外化于行；蒲瑶教授立足中华文明历史根基，阐述了文化自信的当代价值与实践路径，并寄语同学们勇担时代使命，将中华民族共同体意识融入到专业学习与社会实践中；郝保权教授通过大量例证与史料，生动形象地讲述了建国初期参与“两弹一星”的人员不讲条件、不计个人得失，不计名利、不畏艰辛、艰苦奋斗的感人故事，勉励同学们赓续和弘扬“两弹一星”精神；贺苗副教授从意识形态工作的要求着眼，简要概括了新时代网络舆情的特点，进一步阐释了舆情治理思路，引导同学们应提高积极主动参与网络生态治理的意识与能力，自觉培育和践行社会主义核心价值观；赵海霞教授深情讲述了延安时期中国共产党由小到大、由弱到强的奋斗历程，阐释了延安精神的丰富内涵，引导同学们从党的非凡历史中汲取智慧和力量。视频党课环节，精选“纪念中国人民抗日战争暨世界反法西斯战争胜利80周年”思政大课和人民网《大国故事》系列，增强党课的亲和力与渗透力，推动党的理论入脑入心。实践教育环节，组织同学们赴延安、关中革命纪念馆等红色基地，在回望革命历史中厚植爱国情怀，强化同学们的理想信念与使命担当。交流研讨环节，聚焦“当代青年如何增强做中国人的志气、骨气、底气”“如何争做新时代好青年”主题，组织同学们结合学习体会与实际开展深入研讨，在交流中凝聚思想共识、激发前进动力。培训最后设置结业考试，全面检验学习成效，颁发结业证书。
