# 分析测试中心2026年暑假正常运行通知

各位师生用户：
根据学校《2026年暑假相关工作的通知》，2026年暑假时间为7月20日至8月27日。
为全力保障广大师生用户暑假期间正常有序的开展科研工作，分析测试中心坚持暑假期间正常开放运行,全心全意为师生用户提供周到的优质测试，竭尽所能满足师生测试服务需求。
在此期间，如有紧急测试及特殊测试需求，可提前与设备负责人联系（负责人联系方式，详见附表1）。
感谢各位师生用户对分析测试中心的支持与信任，欢迎广大师生用户通过中心预约平台（https://fcdy.nwpu.edu.cn/cf/main/）预约测试。
