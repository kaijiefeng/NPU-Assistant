# 后勤部办公室扎实开展两校区中央空调维保工作

随着夏季高温天气的来临，为确保两校区中央空调系统安全稳定运行，5月初起，后勤部办公室组织专业空调维保公司对两校区公共区域大型中央空调系统开展全面细致的维护保养工作，此次维保工作旨在提升空调运行效率，减少空调停机故障，为师生营造舒适的教学科研环境，同时有效延长大型中央空调设备使用寿命，节约设备更新投资。
一、科学部署，全面体检
后勤部办公室动力保障中心和专业空调维保公司组成维保团队，对友谊校区创新大厦、勇字楼，长安校区图书馆、体育馆、学生活动中心中央空调进行全面“体检”和深度清洗，清洗水系统中央空调主机11台、冷却塔11台、冷却水系统过滤器17个；清洗多联机中央空调室外机8台、室内机191台。维保后设备运行效率显著提升，能耗明显降低。
二、精准维修，消除隐患
在维保过程中，团队人员对发现的一些空调故障和隐患进行了及时维修和处理，截止目前，共更换老化零部件6个，维修制冷系统故障17处，更换压缩机1台，修补制冷剂泄露2处，确保空调设备始终处于最佳运行状态。
三、快速响应，服务师生
各楼宇中央空调系统启动运行后，维保团队及时处理师生报修问题。累计受理并解决全校中央空调报修问题125单。同时对启真楼、启翔楼、实验大楼等楼宇师生反映的中央空调故障进行专项维修。
目前，两校区中央空调维保工作仍在稳步有序开展，后勤部办公室将持续关注设备运行状况，加强日常巡检维护，畅通报修渠道，确保整个夏季中央空调系统安全稳定运行，为师生提供清凉舒适的学习工作环境。（撰稿人：王家元；审稿人：韩争胜）
