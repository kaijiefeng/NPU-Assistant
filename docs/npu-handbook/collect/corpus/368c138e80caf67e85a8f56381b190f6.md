# 党委保卫部开展防范电信网络诈骗专题讲座

为持续深化校园防范电信网络诈骗宣传教育，切实提升师生安全防范意识与识诈防诈能力，有效保障师生人身财产安全，5月14日至15日，党委保卫部分别邀请西安市公安局碑林分局杨文渊警官、高新分局杨皓宇警官，在长安校区和友谊校区为航空学院、材料学院、自动化学院学生开展“防范电信网络诈骗”专题讲座。
讲座中，两位警官凭借丰富的工作经验，针对刷单返利、冒充客服、交友网恋、虚假贷款、买卖游戏账号等校园高发诈骗类型，通过真实案例剖析，细致分析了诈骗分子的作案手法和话术特点，并着重提醒同学们在日常生活中严格遵循“三不一多”安全准则：未知链接不点击、陌生来电不轻信、个人信息不透露、转账汇款多核实，以此筑牢个人财产安全防线。同时，警官们特别强调妥善保管个人“两卡”的重要性，警示同学们切勿因贪图小利随意出租、出借，避免沦为诈骗活动的“帮凶”。
活动现场，党委保卫部向同学们发放了反诈宣传手册，进一步普及实用反诈知识。
此次活动不仅营造了浓厚的校园反诈氛围，还有效提升了同学们的反诈意识和防范能力，强化了大家的法治观念。
下一步，党委保卫部将持续开展反诈宣传，不断筑牢防范电信网络诈骗的“防火墙”，全力守护师生财产安全与校园和谐稳定。
