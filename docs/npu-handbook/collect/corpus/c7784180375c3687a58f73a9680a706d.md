# 喜报！西北工业大学软件学院荣获两项荣誉

11月6日至8日，以“落实行动计划，重塑AI育人新生态”为主题的2026全国高校人工智能教育大会在西安举行。本次大会聚焦《“人工智能＋教育”行动计划》落地实施路径、人工智能学科专业体系升级、AI原生课程与教材建设、智能时代教师数字素养提升、产教融合协同育人机制创新等核心议题，邀请全国高校人工智能、计算机、自动化、电子信息等相关院系负责人、专业教师、研究人员及企业代表共商人工智能教育高质量发展大计，共筑支撑中国式现代化的AI人才自主培养体系。
在本次大会上，西北工业大学软件学院（以下简称“西工大软件学院”）荣获全国高校人工智能教育大会专家委员会委员单位；学院王兵书副教授团队的“数筑Structify：AI赋能‘数据结构’教学智能体”案例荣获2026年全国高校人工智能教育大会优秀案例一等奖。
本次获聘专家委员会委员单位，体现了大会及全国高校同行对西工大软件学院在人工智能与软件工程交叉学科建设、AI赋能教育教学改革方面工作的高度认可。作为首批国家示范性软件学院，西工大软件学院近年来主动对接国家人工智能战略需求，将AI技术深度融入专业建设与人才培养全过程，在智能软件工程、AI原生课程设计、智能教学辅助平台研发等方向持续布局，逐步形成了“学科交叉、产教协同、数智赋能”的育人新生态。
王兵书团队申报的“数筑Structify：AI赋能‘数据结构’教学智能体”案例，旨在形成AI大模型和知识图谱支撑的人机协同教学评一体化模式。教师引导学生在可视化、可交互、可实践的环境中理解算法、完成编程验证，并根据学习情况提供个性化支持，培养学生的计算思维、工程实践、自主学习与反思能力。该案例自主研发基于AI大模型的“数据结构”教学智能体，将教材、课件、知识图谱、算法动画与编程实践用于课前、课中、课后的教学活动。项目组以“AI大模型+知识图谱”支撑人机协同教学评一体化模式，并明确模型与程序的分工：AI大模型负责理解与表达，确定性程序负责规则与执行。AI结合知识图谱反馈学情画像、动态匹配资源，教师据此调整教学安排。软件学院本科生赵容德、郑又祥、许子轩、范世轩、马梓洋参与创作教学智能体，做出积极贡献。目前，Structify教学智能体功能已实现并上线，正面向全国院校教师推广应用。
本次大会期间，西工大软件学院教师与来自全国高校的专家学者围绕AI课程体系建设、智能教材开发、教师数字素养提升、产教融合育人等议题展开深入交流。学院将以此次获奖为契机，进一步落实《“人工智能＋教育”行动计划》，持续探索AI与软件工程教育的深度融合路径，强化智能体、大模型等前沿技术在课程教学、实践教学、科创竞赛中的创新应用，着力培养具备扎实软件功底与智能素养的复合型拔尖创新人才。
面向未来，西工大软件学院将继续发挥特色化示范性软件学院的示范引领作用，以AI重塑育人生态，以创新驱动教学改革，持续提升学院人才培养质量。
审核：李晗
