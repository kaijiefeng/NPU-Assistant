# 翱翔四海 | 2026年数学与统计学院剑桥大学“数理维度推导与人工智能实践“项目圆满收官

为深化国际化人才培养，拓宽青年学子国际视野，提升学生全球胜任力与跨学科科研思维，2026年8月9日至8月22日，西北工业大学数学与统计学院13名学生在李文成老师的带队下，赴英国剑桥大学开展为期14天的“数理维度推导与人工智能实践”暑期研学项目。本次研学依托剑桥大学顶尖师资与科研平台，打造“理论授课+科研实践+文化参访+学术交流”四维培养模式，让同学们沉浸式接轨国际前沿科学研究，在康河畔续写工大青年探索世界、对话前沿的成长篇章。
【深耕学术前沿，探秘AI潜力与边界】
项目核心课程由剑桥大学应用数学与分析方向资深学者Anders C. Hansen教授主讲，围绕压缩感知理论与人工智能稳定性两大前沿主题展开，系统讲授了从数学基础到工程应用的完整知识体系。
在压缩感知理论部分，Hansen教授依托其专著《压缩成像：结构、采样与学习》，以三维核磁共振扫描为例，直观展示了压缩感知在医学成像中的实用价值——在相同扫描时长下，通过合理的采样策略可显著提升图像分辨率。课程系统剖析了压缩感知的三大核心支柱：稀疏性、不相干性与均匀随机子采样，并深入讲解了受限等距性质——即测量矩阵在特定条件下能够保持稀疏信号的能量结构，为信号稳定恢复提供严格的数学保证。教授还梳理了傅里叶变换、拉东变换、沃尔什-哈达玛变换三类主流积分变换测量模型，串联起从物理建模、离散化、图像先验、采样设计到重建算法的六阶段压缩成像完整流水线。
在人工智能稳定性部分，Hansen教授聚焦深度学习方法的潜在风险。他以某国际顶级期刊发表的深度学习图像重建网络为例，通过一系列实验揭示了该网络的脆弱性：在输入信号中加入肉眼几乎无法察觉的微小扰动后，重建图像竟会出现严重失真乃至完全错误的解剖结构。教授进一步展示了令人警醒的米老鼠实验——研究团队在训练数据中放入一张带有米老鼠图案的脑部图像，神经网络学会了画出米老鼠；当输入没有米老鼠的正常图像时，网络仍然凭空画出米老鼠。Hansen教授从矩阵零空间的角度解释了这一现象：欠定方程组的解空间恰好包含米老鼠特征，测量过程没有捕捉到相关信息，但网络基于训练经验强行补上。这种幻觉在临床场景中尤其危险——如果幻觉出的不是卡通图案而是类似真实病变的结构，放射科医生可能无法分辨。
Hansen教授进一步讲解了一致推理悖论，指出任何试图在所有问题上保持一致推理的人工智能都必然会产生幻觉。他论证，任何值得信赖的人工智能都必须能够说“我不知道”——这一机制不仅是防止幻觉的必要条件，也是实现更高层次智能的关键前提。课程还对比了深度学习与传统压缩感知方法的本质差异：前者速度快但天然存在不可控的幻觉风险，后者依赖稀疏性假设，有严格的数学条件保证稳定性。这些深刻的数学洞察让同学们对人工智能的潜力与根本局限有了全新的认识。
课程采用“理论讲授+辅导研讨”的教学模式。每日上午由Hansen教授主讲核心内容，下午则由助教主持习题研讨课，围绕上午所学开展严格的训练。同学们从稀疏度定义、支撑集概念出发，计算具体向量的稀疏程度，研究最佳逼近误差，并将受限等距性质与零空间性质、对偶证书等概念串联，在动手推导中使理论从听懂走向会用。此外，同学们还使用专业优化算法进行编程实践，构建高斯随机测量矩阵，完成稀疏信号重建实验，并通过蒙特卡洛模拟验证压缩感知的相变现象，亲身体验了“理论—实验—解释”的完整科研闭环。
【追寻诺奖足迹，感悟科学传承】
8月10日下午，研学团参访了享誉世界的卡文迪许实验室。该实验室自1874年成立以来，共走出了29位诺贝尔奖得主，是电子、原子核结构与DNA双螺旋结构的发现地。同学们参观了实验室旧址与博物馆，近距离观摩了从基础物理到工程应用的多项突破性成果，深刻感受了科学探索的传承与创新。
【漫步千年殿堂，领略英伦文化】
研学之余，团队走进剑桥大学最著名的学院之一——国王学院。该学院由英国国王亨利六世于1441年创立，其哥特式教堂拥有世界上最大的扇形拱顶和精美的彩色玻璃窗，是剑桥建筑的一大代表。
8月16日，研学团前往牛津大学进行为期一天的文化参访。牛津大学是英语世界中最古老的大学，拥有逾900年的办学历史。同学们漫步于古老的校园，参观了博德利图书馆——欧洲最古老的图书馆之一，欣赏了拉德克利夫圆楼、谢尔登剧院等标志性建筑，感受了与剑桥截然不同的学院氛围和学术传统。
8月20日下午，研学团前往位于剑桥的计算历史中心进行参访。该中心拥有一个国际知名的、超过40,000件的藏品，致力于通过互动展览讲述信息时代的故事。同学们在这里亲身体验了从20世纪50年代的大型计算机，到80年代风靡全球的家用电脑，再到现代系统的完整演进历程。与许多传统博物馆不同，这里的大部分机器都是可以触摸和操作的，让抽象的数学与计算理论变得触手可及。
【学以致用，思辨未来】
在助教的引导下，同学们围绕Hansen教授讲授的AI稳定性、幻觉机理及一致推理悖论等核心课题，分组开展了深入研究与讨论。8月20日下午，研学团举行了小组作业答辩会。各小组从不同角度选题，运用课程所学的数学工具，逻辑清晰地展示了问题分析、建模推导和实验验证，并就评委老师提出的关于假设合理性和推广边界的追问进行了深入回应。Hansen教授和助教对同学们的数学功底和批判性思维给予了高度评价，认为大家在短时间内对如此前沿而深刻的课题形成了有深度的独立见解。
通过这次小组作业，同学们不仅巩固了课堂知识，更锻炼了团队协作和学术表达的能力。大家深刻体会到，数学不仅在理论上支撑着人工智能的发展，更在检验其可靠性与安全性中发挥着不可替代的作用。
【研学感悟】
2024级本科生杨沅锡：两周的剑桥数学项目让我第一次体会到，原来数学并不是一个人在纸上推导就够了。上午听教授讲压缩感知和AI稳定性的理论，下午就得坐在电脑前试着把那些公式变成能跑的程序。很多地方卡住，线搜索失败、伴随关系对不上，Fabian助教教我们用线性算子替代显式矩阵构造，我试了一整个下午，最终还是没有跑通。但汇报那天Hansen教授说了一句话让我印象很深，他说做研究就是要学会面对失败，诚实承认自己没做成，比假装成功更重要。这大概是此行最值得记住的一句话。
2023级本科生徐恺阳：在剑桥的十四天，我第一次真正感受到英国的生活节奏。早上在霍默顿学院吃英式早餐，培根、煎蛋和烤豆子，和在国内吃的完全不一样，康河撑船的经历令我印象深刻，两岸是国王学院和三一学院的古老建筑，划船的英国小哥随口讲着牛顿和达尔文的故事。周末去伦敦，参观了大本钟、伦敦眼和白金汉宫的换岗仪式，感受了英伦风情和本土文化。比起伦敦的繁华，剑桥要安静得多，街上随处可见几百年的老建筑，傍晚草坪上有人坐着聊天，图书馆门口的长椅上总有人在看书。临走前我们去了牛津，比剑桥更热闹，但具有相同的历史文化和学术氛围。这些天让我印象最深的，是这里的人对传统的尊重和对生活的从容，是一种很不一样的节奏。
本次研学是学院推进国际化育人、提升拔尖人才自主培养质量的重要实践。通过沉浸式境外课堂研学、名师学术引领、多维跨域交流，有效帮助学子接轨国际数理前沿、拓宽全球学术视野、锤炼国际交流能力。未来，数学与统计学院将持续深耕国际化育人体系，常态化搭建境外研学、学术交流、校际互通平台，引导学子立足前沿、放眼全球，深耕基础学科、勇攀科技高峰，努力成长为具备国际视野、创新能力与家国担当的新时代拔尖数理人才。
