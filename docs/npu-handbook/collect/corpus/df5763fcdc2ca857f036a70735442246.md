# 关于2025-2026学年秋季学期课程 补（缓）考的通知

各教学单位，各位同学：
现将2025-2026学年秋季学期课程补（缓）考有关事项通知如下：
一、考试报名
在校生（本科生、研究生）请于2026年3月2日至3日登录“翱翔教务”，进入“考试管理”，在“补缓考查询”中核对系统生成的考试科目清单，以免遗漏。如无法登录“翱翔教务”或登录后未查到考试科目信息，请于3月3日16:00前反馈至所在学院或培养单位。
2025届本科结业生请于2月25日前通过“翱翔教务”自行报名，各单位请于3月1日前完成审核工作，报名及审核流程见附件1。
2025-2026学年秋季学期办理了休学的本科生，若有办理了缓考或需补考的课程，请于3月1日前联系所在学院报名，学院于3月2日前将休学学生考试报名表（附件2）发送至教学运行与服务中心（邮箱：[已脱敏:邮箱]）。
二、考试安排
1.本科生考试安排
本科生课程补（缓）考将于3月16日至29日进行。由教务部统一排考的课程补（缓）考安排将于3月9日发布，请同学们务必登录“翱翔教务”，进入“考试管理”查看，考试安排以“考试信息”发布内容为准。
由开课单位自行安排的课程补（缓）考请于3月13日前将具体时间地点等考试安排通知到参加考试的学生，考试信息以开课单位通知为准。
2.研究生考试安排
（1）补考
数理统计(M11G11004)、矩阵论(M11G11001)和数值分析(M11G11002)的补考安排将于3月9日发布，请同学们务必登录“翱翔教务”，进入“考试管理”查看，考试安排以“考试信息”发布内容为准。
其余课程补考由各开课单位自行安排，请同学们及时联系任课教师或开课单位确认考核安排。
（2）缓考
2025-2026学年秋季学期缓考通过的学生参加下一次课程的结课考试，请同学们注意课程开课时间，及时联系开课单位，确认考核安排。
三、成绩录入
各教学单位须于4月15日24:00前完成补（缓）考成绩录入，并按照要求及时完成考试材料的归档工作。
四、其他
近期2025-2026学年秋季课程考核成绩会陆续发布，各位同学请及时查看。若对成绩有异议，请及时联系开课单位。
（文字：马洋洋；审核：王劲）
