# 我校举办2026年度辅导员能力提升研修班

为全面贯彻教育强国建设部署要求，扎实推进新时代立德树人根本任务落实落地，推进辅导员队伍专业化、职业化、专家化发展，5月22日至23日，由党委组织部、党委学生工作部联合主办的西北工业大学2026年度辅导员能力提升研修班在友谊校区顺利举办。学校党委常委、副校长张富利，校长助理王宇波出席开班仪式及相关培训活动。相关职能部门负责人、各培养单位党委副书记、全体辅导员、学工主管及党委学生工作部处科级干部参加培训。开班仪式由党委学生工作部部长、学生处处长于辉主持。
开班仪式上，于辉作题为《强化多元供给，聚力精准赋能，推动辅导员队伍高质量发展》的报告。系统阐述学校辅导员队伍建设总体思路、培养体系架构以及核心落实举措，全面介绍学校在辅导员培育赋能、职业发展支撑等方面的系统化规划与实操部署。
仪式现场，学校为2026年度辅导员工作室集中授牌，为新任辅导员生涯导师颁发聘书。
辅导员生涯导师代表、参训辅导员代表先后发言，分享育人初心与履职展望。
张富利在开班仪式上作总结讲话。他表示，本次研修班是学校构建辅导员系统化培养体系的重要载体，更是落实立德树人根本任务、夯实学校“总师型”人才培养根基的关键举措，对锻造高素质学生工作队伍具有重要意义。围绕新时代辅导员履职尽责，他对全体参训辅导员提出三点要求。一是提高政治站位，牢记为党育人、为国育才初心使命，精准把握新时代高校思政育人工作的核心内涵。二是聚焦能力锤炼，对标新时代育人工作新要求，补齐能力短板、精进业务技能，练就过硬本领。三是坚守育人初心使命，深耕学生思想政治教育一线，用心用情履职尽责，奋力书写新时代高校立德树人答卷。
本次研修班精心设计专题讲座、辅导报告、分组研讨等模块，聚焦政治理论提升、履职能力锻造、实务技能夯实，全方位赋能辅导员成长。5月22日上午，王宇波为全体参训辅导员讲授专题思政报告《从三代校友的救国报国强国之路看我校为党育人、为国育才的人才培养历程》。报告紧扣“为谁培养人、培养什么人、怎样培养人”根本教育命题，回望师昌绪、陈士橹等老一辈院士科技救国的奋斗征程，展现唐长红、黄维娜等新时代院士校友攻坚克难、铸就国之重器的责任担当，讲述尹东、唐勇等优秀校友矢志报国的青春事迹，以鲜活案例系统梳理学校各阶段办学积淀与人才培养脉络，生动诠释西工大扎根教育报国、深耕立德树人的办学初心。
5月22日下午，研修班聚焦网络思政、校园安全两大重点领域开展专项授课。原西安市公安局警察训练支队二级调研员、高振国警官作校园安全专题报告，结合典型案例深度剖析宗教向校园渗透的特征与本质，普及政治安全防范知识，传授风险识别、防范处置实操方法，有效强化辅导员校园安全防控意识与履职能力。全国三八红旗手、全国最美高校辅导员莫伶受邀作《打通网络思政的最后一公里》专题报告。她立足数字化育人新形势，围绕高校思政工作现存困惑，聚焦“学生在哪里、思想在哪里、思政在哪里”核心问题，深入剖析网络思政工作现状，明确新时代辅导员网络思政工作研究方向与自我提升路径。
针对新任辅导员岗位适配需求，5月23日，学校专设新任辅导员专项培训环节。党委组织部、党委宣传部、党委学生工作部、团委等职能部门负责人结合分管工作，围绕党支部建设与党员发展、校园网络舆情风险研判与应急处置、共青团育人作用发挥与创新创业教育、学生思政教育及事务管理等核心工作，开展系统化、精细化实务培训，逐条拆解学生工作流程规范、核心要点与工作方法，精准助力新任辅导员吃透工作要求、掌握业务技能、快速胜任岗位。
分组交流研讨环节，参训新任辅导员分六组开展集中研讨交流。大家结合培训所学、岗位实际与工作认知，围绕学生思想引领、事务管理服务、成长帮辅、学风建设等重点工作，分享学习感悟、交流工作思路、谋划落实举措，为后续高质量开展学生工作筑牢基础。
研修班尾声，于辉对本次研修班作总结点评。他充分肯定全体参训辅导员认真钻研、积极交流、主动思考的优良学风。他强调，辅导员是高校落实立德树人根本任务、开展学生思想政治教育的一线骨干力量，大家要坚守育人初心、贴近学生成长、深耕一线工作，用心用情做好思想引领、日常管理、成长服务等各项工作，主动创新育人模式与工作方法，持续提升专业化育人能力，以高度的责任感和使命感扛起新时代高校思政育人重任。
下一步，学校将持续优化精准培养培训体系，推进辅导员队伍专业化、职业化、专家化建设。依托集中实训与常态化分散学习实践相结合的培育模式，搭建分类分层辅导员成长平台。聚焦学生工作热点难点、履职技能提升、育人模式创新开展定制化培训，全方位提升辅导员队伍综合素养与履职能力，推动学校学生思想政治教育工作提质增效，为学校“总师型”拔尖创新人才培养提供坚实的队伍保障。
（文字：张静、王永康；审核：于辉）
