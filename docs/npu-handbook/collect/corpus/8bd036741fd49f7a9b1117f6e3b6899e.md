# 西北工业大学公共政策与管理学院2026年公共管理硕士（MPA）非全日制调剂复试通知

一、复试时间安排如下表：
时间
工作内容
相关说明
4月8日
9:00-21:00
调剂报名
考生登录全国硕士研究生招生调剂服务系统填报调剂志愿。
23:00
复试名单公示
根据择优遴选原则，确定进入复试考生名单。

6:00-12:00
学院发放复试通知，复试确认
考生在规定时间内，登录全国硕士研究生招生调剂服务系统，进行复试确认，逾期未确认者，视为自动放弃本次复试资格。
网络设备测试
复试采用腾讯会议，要求双机位，测试会议号另行通知，考生提前准备好设备进行测试，具体操作流程详见附件。
12:00-13:00
面试顺序确定
学院根据确认名单，安排复试顺序
14:00-17:30
面试
复试采用腾讯会议,要求双机位，会议号另行通知，笔试答案按照要求准时提交。
18:00-19:00
笔试：思想政治理论
二、复试平台
采用腾讯视频会议平台，考生提前下载安装该软件并完成版本升级，熟练掌握软件操作方法，避免因操作不熟练影响复试进行。
三、面试要求
按照面试顺序安排，依次进行面试，考生须准时参加面试，未能按时参加的视为考生自动放弃复试资格，后果由考生自行承担。
请各位考生高度重视，严格遵守上述要求，提前做好准备，确保复试顺利进行。
