# 在实践中不断推进新时代党的政治建设

唐静 李鹏
来源：光明日报
党的十九大明确提出新时代党的建设总要求，强调党的政治建设是党的根本性建设。习近平总书记强调，党的政治建设是一个永恒课题。要把准政治方向，坚持党的政治领导，夯实政治根基，涵养政治生态，防范政治风险，永葆政治本色，提高政治能力，为我们党不断发展壮大、从胜利走向胜利提供重要保证。
加强党的政治建设是各个时期始终不变的主题
加强党的政治建设是马克思主义政党的性质决定的，也是其区别于其他政党的显著标志。马克思主义政党从不讳言自己的政治属性和政治使命。在《共产党宣言》中，马克思和恩格斯系统阐述了无产阶级政党政治建设的价值取向、目标任务、实现途径和领导力量等要素。
中国共产党人作为马克思主义的忠诚信奉者、坚定实践者，自创立之日起，就在指导思想、奋斗目标等方面旗帜鲜明地宣誓自己的政治属性和政治使命。在革命战争年代，中国共产党就高度关注党的政治建设问题。毛泽东同志明确指出：“我们的将来纲领或最高纲领，是要将中国推进到社会主义和共产主义社会去的，这是确定的和毫无疑义的。”改革开放以来，党中央立足具体的历史和社会实践，从整体和大局上考虑党的政治建设问题，强调加强党中央权威和集中统一领导的必要性。习近平总书记强调，历史经验表明，我们党作为马克思主义政党，必须旗帜鲜明讲政治。以习近平同志为核心的党中央，旗帜鲜明地提出把党的政治建设摆在新时代党的建设的首位。由此可见，在革命、建设和改革的不同历史时期，加强党的政治建设是始终不变的主题。
新时代党的政治建设体现党的价值引领
新时代党的政治建设体现了党的价值引领。从中国共产党建党之初，就明确把实现共产主义作为自己的最高理想。党的十八大以来，党中央多次强调要坚定马克思主义信仰和共产主义信念。中国共产党人必须要坚定共产主义远大理想和中国特色社会主义共同理想，矢志不移贯彻执行党的基本路线和基本纲领，做好当前每一项工作，不断推进为崇高理想而奋斗的伟大实践。
新时代党的政治建设体现了党领导各项事业的根本要求。党政军民学、东西南北中，党是领导一切的。中国共产党领导是中国特色社会主义最本质的特征，是中国特色社会主义制度的最大优势。党的十九大报告首次把党的政治建设纳入党的建设总体布局，并强调“以党的政治建设为统领”“把党的政治建设摆在首位”，指出“党的政治建设是党的根本性建设，决定党的建设方向和效果。保证全党服从中央，坚持党中央权威和集中统一领导，是党的政治建设的首要任务。”党的其他建设都要围绕党的政治建设来进行，都要体现党的政治建设的要求。
新时代党的政治建设体现了党的人民立场。全心全意为人民服务是我们党一切工作的出发点和落脚点，坚持以人民为中心，必须坚持人民主体地位。要秉承人民是历史创造者的马克思主义唯物史观，立足于人民是决定党和国家前途命运根本力量的科学判断为依据，更好地坚持党的领导、人民当家作主、依法治国的有机统一。
党的政治建设要在实践中贯彻落实
一分部署，九分落实。党的政治建设不只需要理论建构，更需要在实践中得到真正的贯彻落实。全党必须树牢政治意识、大局意识、核心意识、看齐意识，坚定道路自信、理论自信、制度自信、文化自信，坚决维护习近平总书记党中央的核心、全党的核心地位，坚决维护党中央权威和集中统一领导。全党必须坚定执行党的政治路线，严格遵守政治纪律和政治规矩，在政治立场、政治方向、政治原则、政治道路上同党中央保持高度一致。
营造良好政治生态，突出政治标准，把树立正确选人用人导向作为构建良好政治生态的重要着力点。习近平总书记强调，用一贤人则群贤毕至，见贤思齐就蔚然成风。认真落实《关于进一步激励广大干部新时代新担当新作为的意见》，把正向激励和纠错容错机制有机结合起来，让干事创业有担当的干部脱颖而出。要尊崇党章，严格执行《关于新形势下党内政治生活的若干准则》，增强党内政治生活的政治性、时代性、原则性、战斗性，自觉抵制商品交换原则对党内生活的侵蚀。弘扬忠诚老实、公道正派、实事求是、清正廉洁等价值观，坚决防止和反对个人主义、分散主义、自由主义、本位主义、好人主义，坚决防止和反对宗派主义、圈子文化、码头文化，坚决反对搞两面派、做两面人。
党员干部要提高政治能力，防范政治风险，永葆政治本色。要加强政治理论学习，提高把握方向、把握大势、把握全局的能力，辨别政治是非、保持政治定力、驾驭政治局面、防范政治风险的能力。与此同时，党员干部要始终保持强烈的忧患意识、风险意识，要教育引导各级领导干部增强政治敏锐性和政治鉴别力，必须以永远在路上的坚定和执着，坚决把反腐败斗争进行到底，永葆党员的政治本色。
