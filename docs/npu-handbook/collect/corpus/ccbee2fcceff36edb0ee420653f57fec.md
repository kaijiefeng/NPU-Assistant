# 关于开展教职工家庭系列科普体验活动的通知-校工会（帮扶办）/ 妇女联合会

各基层工会、全体教职工：
为进一步丰富教职工精神文化生活，用心用情做好教职工关心关爱工作，落实妇联、女工委暖心服务举措，校工会、校妇联组织开展以家庭为单位的走进实验室科普体验活动。本次活动旨在帮助教职工舒缓工作压力，不断增强归属感、获得感、幸福感，营造和谐温馨、积极向上的家庭氛围与校园文化氛围。现将有关事项通知如下：
一、活动对象
本校在职教职工以家庭为单位报名参加
二、活动内容
1.实验室参观：组织教职工家庭走进实验室，近距离观摩科研设备，由专人讲解科普知识，直观感受科学魅力。
2.科普活动：围绕趣味科学主题开展科普分享，内容通俗易懂，设置互动答疑环节，激发科学兴趣。
3.手工制作：设置科普主题手工环节，家庭协同动手创作，增进交流，留存温馨成果。
三、活动安排
体验活动于周末进行，11月份安排具体如下：

第一期
科普活动：搭建近距离接触科学、动手探索实践的平台，通过趣味满满的物理小实验体验，让孩子们跳出书本，在真实的实验场景中感知物理现象、培养科学思维，把课本里的科学变成看得见、摸得着的奇妙现象，一同感受物理科学独有的趣味与魅力。

②非牛顿流体制备与研究：亲手调配神奇流体，见识它“遇强则强、遇弱则柔”的反差特性；
③伯努利原理模拟小实验：解密气流背后的奥秘，看懂飞机升空、流体吸力背后的科学道理。

第二期
实验室参观：全国科普教育基地——西北工业大学飞行器基础布局全国重点实验室。
①参观科普知识长廊：认识科普IP形象“航小翼”“航小栅”，了解翼型和叶栅的概念以及发展演化。
②参观飞机模型：走进模型展示区，观摩实验室自研、用于风洞试验的各类飞机模型、叶片模型。
③走进风洞：进入核心试验区域，实地参观全亚洲最大的低速翼型风洞。了解风洞整体结构、驱动系统、风洞试验的基本原理等。
④拼装飞机模型：前往三航科学实验室动手拼装飞机模型。

四、报名须知
请有意向参加的教职工填写报名表（附件1），以基层工会为单位发送至工会邮箱gonghui@nwpu.edu.cn。11月份活动报名截止时间11月13日10:00，名额有限，报满即止。
五、有关要求
参加本次活动的教职工务必注意安全，遵守实验室有关制度和保密要求，服从现场管理，有序文明参观，未经允许不得拍照录像。
