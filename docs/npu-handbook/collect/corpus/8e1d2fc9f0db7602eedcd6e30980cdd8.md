# 学校召开2025年本科招生工作总结暨表彰大会-

10月10日，我校召开2025年本科招生工作总结暨表彰大会。校党委书记李言荣出席并讲话。校党委副书记、纪委书记徐永兵，招生工作领导小组成员单位和相关职能部门负责人，各学院领导及分管招生工作的负责人、招生组长、骨干教师，2025年度招生工作先进集体和先进个人代表等共计200余人参加会议。大会由副校长岳晓奎主持。
招生办公室主任王克勤作2025年本科招生工作总结汇报。教务部部长王海鹏宣读了2025年本科招生工作先进集体和先进个人获奖名单。
“招生领航人”获奖代表——材料学院院长付前刚、动力与能源学院党委副书记徐永超、软件学院党委副书记陈博分别结合本单位工作实际，分享了招生工作体会和经验。大家一致表示，招生工作取得成绩的背后，是“天下工大、世界三航”的西工大力量，反映了学校的“总师育人文化”深入人心，体现出学校办学实力和社会口碑的持续提升。各学院将坚持“三个永远”，不断提升招生工作质效，为学校招收高质量生源贡献力量。
岳晓奎为获得“优秀招生大使”“招生先锋”奖和“先进集体优秀奖”的获奖代表颁奖。
徐永兵为获得“招生领航人”奖和“先进集体二等奖”的获奖代表颁奖。
李言荣为获得“先进集体一等奖”的获奖集体代表颁奖。
李言荣代表学校和宋保维校长，对参加今年本科招生工作的同志们表示衷心感谢，对本科招生工作取得的优异成绩和获得2025年本科招生工作先进荣誉的集体及个人表示祝贺。他说，今年本科招生取得了前所未有的好成绩，进步很大，这是全校师生全员动员、全体参与的结果，本科招生相关单位精细谋划，各个学院精准对接，师生、校友大力支持，全校上下结合、点线结合,方方面面都为招生工作做出了贡献。今年的招生工作为我们树立了“只有做好了才算是做了”和“三个永远”的典型样式。好的学生招进来，一定要培养好，既要“聚天下英才而育之”，更要“育天下英才而成之”，学校人才培养、后勤保障、大学治理等方方面面都要为人才培养出力，举全校之力把优秀的学生培养成才。
李言荣说，面对2026年的本科招生，总体形势是好的，有利的形势和机遇没有改变，但面临的困难、问题、压力也很大，我们要保持追求卓越、追求一流的精神，持续做好招生工作。他对本科招生工作提出了四点要求。一是以“全链条贯通”，应对挑战。要打破“招生只管入口”的思维，全校上下一盘棋，将招生工作嵌入“培养-深造”环节，动态调整招生专业结构，适时调整招生策略。二是以“招生为入口”，锚定国防特色需求。要强化国防特色资源与招生工作的深度融合，发扬军工特色和“总师育人文化”，在招生环节确保生源与“总师型”人才培养目标契合度，为后续培养打下坚实基础。三是以“立体化传播”，提升品牌影响力。要进一步讲好“三航”故事、总师故事，用师生校友的真实案例打造好学校“为国铸重剑”的品牌形象，发挥校友、家长的“口碑效应”，进一步做好招生宣传。四是以“系统化保障”，夯实工作基础。持续完善招生工作制度体系，加强招生队伍建设，强化纪律保障，维护好学校品牌声誉。
2025年学校本科招生工作取得新突破、好成绩，下一轮招生中，全校上下将继续弘扬“四千精神”，咬定青山不放松，为学校实现“一十百千”近中期目标和“天下工大、世界三航”远景目标贡献智慧和力量！
