# 关于做好2025年度文件归档工作的通知

各单位：
依据《归档文件整理规则》（DA/T22-2015）《西北工业大学档案管理办法》（办转档案字〔2021〕27号）等文件规定，为确保学校2025年度文件归档工作顺利完成，现将相关要求通知如下：
一、归档范围
（一）2025年1月至12月期间，学校党群、行政、教学、科研、基本建设、国有资产、产品生产、出版、外事、财会、后勤管理等各项工作中形成的具有保存价值的文件材料，详细内容参见各单位归档范围。
（二）其他往年应归档但尚未归档的文件材料。
二、归档要求
（一）各单位兼职档案员要切实履行工作职责，负责本单位文件材料的收集、归档工作，于5月30日前统一移交学校档案馆。
（二）归档文件材料需签章、附件齐全，红头文件的签发单/阅办单须一并归档。
（三）公开文件材料归档
1.红头文件签发单上勾选“主动公开”的文件，按照公开文件移交，需提交电子版，电子文件以“文件编号”命名，没有“文件编号”以“题名”命名。
2.年度工作总结和计划、统计报表、规章制度、出版刊物、签订的合作协议、备忘录、重大活动中产生的文件材料（应成套整理）等，各单位视材料敏感程度确定按公开或线下文件移交，不提交电子版。
3.党政办负责外来公文编号为“SW……”的公开文件移交。
4.公开文件材料填写“公开文件材料移交清单”（附件1）。
（四）线下文件材料归档
1.红头文件签发单上勾选“依申请公开”和“不予公开”的文件，按照线下文件移交，不提交电子版。
2.各单位负责归档的议事机构会议记录、纪要、议题材料，按照线下文件移交，不提交电子版。
3.各单位作为主责部门负责诉讼与仲裁的案件资料（包括起诉状或答辩状、案件处理方案、证据鉴定、司法文书、总结报告等全部案件资料），按照线下文件移交，不提交电子版。
4.党政办负责归档的党委全委会、党委常委会、校长办公会会议记录、纪要、议题材料，按照线下文件移交，不提交电子版，并负责外来公文编号为“XX……”的线下文件移交。
5.线下文件材料填写“线下文件材料移交清单”（附件2）。
（五）涉密文件材料归档
1.党政办负责学校涉密外来公文归档工作。
2.各单位负责本单位拟稿发文的涉密文件归档工作。
3.涉密文件材料填写“移交涉密载体受控单”（附件3）。
（六）各单位重要工作、重要活动、重要会议等形成的声像材料，填写“声像档案移交清单”（附件4）。
（七）各单位荣获的省部级以上集体获奖证书、奖牌、奖杯、锦旗等，以及校际交流中具有保存价值的实物，填写“实物档案移交清单”（附件5）。
（八）档案工作分管领导及兼职档案员有变动的单位，重新填报“档案工作分管领导及兼职档案员情况登记表”（附件6），与归档材料一起归档。
（九）附件1、附件2、附件4、附件5电子版需通过E-Mobile发送档案馆相关联系人。
三、联系方式
为做好2025年度文件归档工作，档案馆将提供业务指导服务。请各单位兼职档案员及时与相关工作人员联系归档事宜，确保文件材料“应归尽归、应管尽管”。
档案馆
