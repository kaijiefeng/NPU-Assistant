# 向阳而立、向下扎根、向上生长，志做新时代好青年——写给西北工业大学2023级本科新生的一封信

亲爱的2023级本科生同学们：
你们好！欢迎你们从五湖四海相聚启真湖畔，加入这所有胸怀、有精神、有担当的大学！一直以来，西工大坚持以深厚文化底蕴涵养家国情怀，以创新创造活力驱动高质量发展，以初心使命引领培育时代新人，是广大具有“爱国之心、报国之情、强国之志”的青年学子的理想选择。西工大将不仅是你们放飞青春梦想的起点，更是你们成就精彩人生的沃土！
站在新的人生起点，如何心怀家国情、走好奋斗路、练好基本功，志做新时代好青年，追求有高度的人生是你们面临的共同课题。今天以信为载，谈谈我的想法，与君共勉。
新时代好青年要向阳而立，以远大理想涵养浩然正气。“红日初升，其道大光；河出伏流，一泻汪洋。”当前，我国已全面开启以中国式现代化全面推进中华民族伟大复兴的新征程。在这段充满光荣与梦想中的远征中，担任“闯将”“干将”“先锋”的无疑是新时代中国青年。同学们要想有所作为，必须坚持以信仰为指引，找准奋斗坐标，才能充分发挥青春的力量、青春的涌动、青春的创造在时代潮流中矗立潮头。我校优秀校友、中国大飞机三剑客之一的“鲲龙”AG600水陆两栖飞机总设计师黄领才，在谈到自己的航空梦时曾感慨到：“一个人应该有梦想，因为梦想将是你终生为之奋斗的动力。”早在孩童时期他就通过家乡的一场火灾了解到了飞机在灭火中能起到重大作用，自此航空梦逐渐在他的心中生根发芽，即使改革开放初期大部分年轻人投身经济热潮寻找机遇，军工项目发展遭遇重重困难，也并没有动摇对航空事业的热爱，他在职业生涯中始终秉持着航空报国的信念感和使命感，始终坚守在岗位上，终生为之奋斗，终得“鲲龙”翱翔海天，理想照进现实。胸怀梦想的远征，从来不惧风雨兼程。同学们，希望你们把个人奋斗同民族复兴的伟大目标紧密结合起来，坚定不移听党话、跟党走，以远大理想抱负、深厚家国情怀，扬起青春远航的风帆，让爱国成为人生的鲜明底色，让强国成为心中的星辰大海，彰显新时代好青年浩然正气！
新时代好青年要向下扎根，以厚积薄发充盈厚实底气。“合抱之木，生于毫末，九层之台，起于累土。”伟大的事业都始于梦想、基于创新、成于实干。同学们成长成才、实现梦想，就是一个不断积累知识、积累能力的过程，以严实的工作作风练好基本功、坚实学识基础显得至关重要的作用。“学所以益才也，砺所以致刃也。”唯有脚踏实地、稳扎稳打，一步一个脚印地努力奋斗，厚积而薄发，才能练就干事创业的真才实学、搏击长空的过硬本领。积累不够，甚至眼高手低、光想不干，都会阻碍未来的发展。我国国防科技工业领域唯一的女院士、我校张立同教授，在上世纪70年代，以崇高的责任感，勇敢承担了“高温合金无余量熔模精密铸造叶片新工艺研究”课题，由于当时国外技术封锁、研究条件艰苦，而且要研究的材料，超出了她所学专业的范畴，涉及其他几个学科，她为了掌握需要的专业知识，她无数次地出入图书馆，在实验室做了上千次的实验，测试了上万个数据，整理了100多万字的实验资料，经过半年不分昼夜的工作，从获得的数万个数据的分析中，探索出了航空发动机涡轮叶片在熔模铸造过程中的变形规律和本质，为无余量精铸工艺研究提供了重要理论依据。在之后的进一步研究中，她又刻苦攻读陶瓷专业的理论知识、四处调研，做了大量的研究工作、付出了巨大的劳动，一天深夜，她独自在实验室，由于劳累过度，一不小心被喷出的高温蜡糊住了双眼，第三天，眼伤未愈，她又进了实验室……正是凭着这股几十年如一日的砥砺深耕，张院士带领团队一次又一次突破了发达国家对我国的技术和设备封锁，解决了国家急需的一系列重大关键技术，取得多项开创性成果，为我国大飞机的发展奠定了坚实基础。同学们，希望你们紧抓大学这一沉潜蓄势、增长才干的黄金时期，发扬西工大人严实的工作作风，脚踏实地，在勤学苦练中求得真学问、练就真本领，厚积薄发，不断提高与时代发展和视野要求相适应的素质和能力，彰显新时代好青年厚实底气。
新时代好青年要向上生长，以担当作为锤炼昂扬锐气。同学们，你们正值最富活力、最具创造性的青年一代，不仅要满足于做一个“会读书的人”，更要励志成长为一个“会创造的人”，一个勇立时代潮头的时代先锋。这就需要你们拿出敢为人先、革故鼎新的锐气，面对机遇挑战时不犹豫、不观望，面对困难时不畏惧、不逃避，积极探索新发现、开辟新路径、创造新价值。我校航海学院博士研究生朱健楠，因在一次旅行中看到清洁工人撑着木船捡拾河面垃圾，引发对国内湖泊水垃圾问题的思考与调研，从此结合专业所学，开启了无人驾驶技术应用于环境治理的科技创新与创业之旅。他带领团队从大学生创业项目做起，克服了重重困难，研发了国内首个通过欧盟CE认证的无人驾驶环保船，推出了三大系列无人驾驶清洁船，为水环境综合治理提供一体化解决方案，同时创办了国家级高新技术企业“欧卡智舶”，以科技创新守护“绿水青山”。西工大学生中这样的“创客”还有很多，他们在不断精进学业的同时，还奋力奔跑在创新创业、竞技体育、艺术展演、志愿服务、社会实践等众多赛道上，不断拓宽人生奋斗场域、出彩舞台，实现人生价值、升华人生境界。同学们，希望你们传承好西工大人“勇猛精进，敢为人先”的品格，用锐意进取、追求卓越的态度，去干、去闯、去创造，努力站到更高、更大的舞台，努力突破科技创新瓶颈，彰显新时代好青年昂扬锐气！
同学们，新时代好青年是殷殷嘱托、是时代呼唤，更是广大中国青年矢志不渝坚守的精神追求。希望你们在最美好的西工大求学时光里，向阳而立、向下扎根、向上生长，为成长为新时代好青年奠定坚实的基础！
