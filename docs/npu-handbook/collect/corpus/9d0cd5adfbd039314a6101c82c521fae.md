# 重庆大学党委保卫部来校调研

10月14日上午，重庆大学党委保卫部（保卫处）部长（处长）崔晓奎一行莅临我校，就“大安全”工作格局构建等主题开展调研交流。我校党委保卫部部长朱建军，副部长皮德福、方原及相关科室工作人员参加座谈会。
座谈会上，朱建军对崔晓奎一行的到来表示欢迎。双方依次介绍参会人员，并观看学校宣传片。皮德福聚焦“大安全”工作格局建设，全面介绍了我校校园安全保卫工作开展情况；崔晓奎介绍了重庆大学近年保卫工作建设成效。随后，根据调研重点，双方围绕保卫队伍建设、安防力量配置、智慧消防建设、校园交通管理、群防群治组织建设等议题开展深入交流。
双方一致认为，校园保卫工作是高校事业高质量发展的重要前提与坚实保障。要持续健全“大安全”工作格局，深化党建引领作用，完善校内外协同联动机制，优化多校区安全治理模式，夯实政保、治安、消防、交通等基础安全工作，充分调动师生参与校园安全建设的积极性与主动性，全方位筑牢校园安全防线。
双方表示，希望今后持续深化沟通协作，互学互鉴，共同推动校园安全保卫工作提质增效。
