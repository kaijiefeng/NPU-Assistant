# 关于开展教育实验学院/未来技术学院/学科交叉中心2025级本科生荣誉导师双选确认工作的通知

为落实立德树人根本任务，强化人才培养核心地位，汇聚校内优质教育教学资源，发挥本科生荣誉导师科研育人作用，提高拔尖创新人才培养质量，根据《教育实验学院/未来技术学院/学科交叉中心荣誉导师管理办法》（教实字〔2025〕8号），现开展教育实验学院/未来技术学院/学科交叉中心2025级本科生荣誉导师双选确认工作。
一、工作流程
（一）学生意向征集。学院面向学生公布荣誉导师相关信息后，学生通过学校教师主页（网址：https://teacher.nwpu
.edu.cn/）查询教师教学、科研等方面信息，并结合自身专业兴趣和学术发展规划，于11月21日前完成意向荣誉导师信息登记。
（二）师生双选确认。荣誉导师根据学生申报意愿、学业规划、综合评价等情况，确定指导学生，于11月30日前完成《教育实验学院/未来技术学院/学科交叉中心荣誉导师确认志愿申请表》签字确认工作。
（三）学院审核公示。学院对师生双向选择结果进行审核，公示荣誉导师及其指导学生名单。
二、相关要求
（一）每位荣誉导师指导同年级的学生原则上不超过2人，学校翱翔（战略、领军）团队、省部级及以上创新团队协同指导同年级的学生不超过4人。
（二）学生应积极参与荣誉导师指定、建议的各类学习与实践活动，及时完成《荣誉导师指导记录手册》填写。
