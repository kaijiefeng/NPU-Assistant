# 统一思想 凝聚共识 全力应对AI时代的挑战 软件学院召开“软件*AI+X”本科培养方案修订和课程重塑启动会

软件学院积极响应学校教务部关于培养方案修订的工作部署，坚持以“总师育人文化”为引领，主动应对人工智能时代对软件工程人才培养带来的冲击与挑战，不断推进AI赋能下的“总师型”人才培养模式探索。2026年4月3日上午，软件学院线上召开全体教师大会，正式启动“软件*AI+X”本科专业培养方案修订和课程重塑工作。院长郑江滨、党委书记李晗、副院长马春燕等出席会议，全体教师参加。会议由马春燕主持。
会议伊始，郑江滨在动员讲话中深刻阐述了AI时代软件工程专业转型的紧迫性与核心理念。他指出，AI时代软件生产模式正从“手工劳动”转向“人机协作”，软件的重要性大幅提升，行业将迎来空前繁荣，但人才培养内涵必须进行根本性调整，若不主动改革，将直接影响专业生存与发展。为此，他提出要从课程内容重塑和课程体系重建两方面入手，所有课程都要融入AI知识与设计，并面向大型工业、嵌入式系统、计算机视觉、智慧医疗、智能优化控制等特色领域，推动软件与垂直行业深度融合，以此带动课程体系的整体重构。
随后，马春燕基于前期的调研与学习，详细介绍了“软件*AI+X”转型的主要思路，从“培养什么样的人”“现有培养方案的不足”“AI范式下如何进行课程改革”三方面展开系统讲解。她强调，全体教师必须主动学习，否则将面临职业能力退化、人才培养质量下降的严峻现实。她提出，围绕软件工程主线、AI工程主线、行业领域主线、工程实践主线、专业方向主线等五条主线，构建“少而精”的课程体系。在教学内容上，大幅删减AI可替代的机械性操作与低阶记忆内容，增加AI难以替代的抽象建模、系统设计、逻辑思维及批判性思维训练；重点强化需求分析、问题建模、架构设计及质量保障标准，并针对上述特色领域的关键场景开展案例教学与项目实践；实践环节全面转向综合性大项目训练，突出人机协作完成复杂系统级项目的能力培养。
会议最后，马春燕对后续培养方案修订、课程内容重构等重点工作进行了明确分工，进一步细化了时间节点和具体产出要求。并号召全体教师勠力同心，以主动求变的勇气和立德树人的担当，将“软件*AI+X”的理念落到实处，真正培养出能驾驭AI、运用专业知识解决行业领域复杂软件问题的复合型软件人才，为学生的未来发展和国家软件事业保驾护航。
本次会议凝聚了共识，明确了方向，全体教师将以此次启动会为新起点，统一思想、凝心聚力，着力打造“软件*AI+X”“总师型”软件人才培养的新高地。
审核：马春燕
