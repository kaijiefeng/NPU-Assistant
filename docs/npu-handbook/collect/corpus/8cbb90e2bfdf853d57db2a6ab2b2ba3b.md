# 校工会党支部与试飞院工会党支部开展联学共建主题党日活动-校工会（帮扶办）/ 妇女联合会

为深入学习贯彻习近平新时代中国特色社会主义思想和党的二十届三中全会精神，推动党的创新理论在工会工作中的落地落实，深化党建引领、赋能工会工作提质增效，9月26日上午，校工会党支部与中国飞行试验研究院工会办公室党支部携手开展了联学共建主题党日活动。
活动伊始，两支部围绕“共学党的二十届三中全会精神，书写新时代高校与科研院所工会合作新篇章”主题，开展了深度的学习共建交流。会议由中国飞行试验研究院工会党支部副书记刘纳和我校工会党支部书记陈建军共同主持。双方党员结合各自工作实际，深入探讨了如何贯彻落实党的二十届三中全会精神，推动教育、科技、人才一体化高质量发展。重点交流了在深化高校和科研院所工会改革中，如何更好地加强职工思想政治引领，服务于新质生产力的提升，以及充分发挥工会“大舞台、大学校、大家庭”三大作用的思路和举措。
在随后的参观环节，党员们在刘纳副主席的带领下，观摩了试飞院第四届职工“五小”创新成果展。展览生动展示了职工在“小发明、小创造、小革新、小设计、小建议”等创新工作中的亮点，彰显了职工参与的广泛性和创新的实践性。
同时，大家还参观了范小东劳模创新工作室，了解劳模创新工作室运行机制等方面的情况。该工作室聚焦试验机外勤维修保障领域，解决了维修过程中的重大技术难题，充分发挥了劳模的引领和示范作用，推动了技术改革的新动能。
此次联学共建活动形式多样、内容丰富，充分体现了高校与科研院所工会在信息互通、资源共享、优势互补方面的务实合作。活动不仅深化了党建引领下的业务融合，也为今后双方在协同育人、产学研融合等领域的深入合作奠定了坚实基础。双方表示，未来将进一步加强交流与合作，共同推进学校与研究院在新时代背景下的高质量发展。
