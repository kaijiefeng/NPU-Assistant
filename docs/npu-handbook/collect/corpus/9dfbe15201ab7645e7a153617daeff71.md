# 金秋燃情，“芯”动赛场｜集成电路学院十月系列体育活动-集成电路学院（微电子学院）

金秋十月，赛场争锋。为丰富师生课余文体生活，西北工业大学集成电路学院先后举办小班足球赛、校友交流羽毛球赛与篮球小班赛。学子们以球会友、以赛聚力，尽展青春风采。
绿茵逐梦，少年意气贯长虹
10月15日下午，小班足球赛在星天苑小足球场打响。比赛以大一、大二学生为主体，特邀大四及研究生学长同场竞技。大一学生组成两支队伍，其余参赛年级组成两支联队，切磋球技。
比赛中，高年级联队率先掌握节奏，新生联队积极应对、寻找机会。双方队员在攻防中你来我往，对抗有度，碰撞后主动伸手相扶，尽显学院优良作风。
下半场，新生联队率先破门，在绿茵场上尽情驰骋；高年级联队凭借经验稳扎稳打。两场比赛分别以6:2与8:4结束。赛事圆满收官，同学们在拼搏中磨炼意志，在协作中增进默契。
银羽飞扬，以球会友叙情谊
10月17日下午，由学院学生会体育部主办的“以球会友，羽你同行”校友交流羽毛球赛在东篱菊园体育馆举行。数名校友齐聚赛场，久别重逢的同窗握手寒暄，随后挥拍上阵，切磋球技。
赛事设男单项目，采用抽签淘汰制。快速攻防、凌厉扣杀轮番上演，看点十足。参赛者秉持“友谊第一、比赛第二”的精神，奋勇拼搏、每球必争，展现出西工大人朝气蓬勃的风采。赛事还设双打趣味环节，让久未执拍的校友尽兴而归。赛后，全体参与人员合影留念。
赛事为校友搭建了交流互动的平台，让大家在运动中强健体魄、重温情谊。
篮下争锋，同心聚力展风采
10月29日下午，篮球小班赛在星天苑篮球场举行。大二39班、40班、41班代表队，以及大三联队、大四联队、研究生联队，共六支队伍参加比赛。赛事采用3V3赛制，进行五轮积分循环赛。未上场的队伍轮流承担执裁和计分工作，共同维护比赛秩序。
各队从开局试探到渐入佳境，在攻防转换中调整节奏，比分交替上升。面对连续五轮比赛的体能考验，队员们通过配合寻找得分机会，也在胶着时刻努力稳住心态。
五轮战罢，大四联队以全胜战绩排名第一，大二39班以四胜一负的成绩排名第二，大二41班位列第三，研究生联队、大二40班与大三联队分列其后。
赛场上，同学们将情谊置于胜负之上，在切磋中打破隔阂、增进相知，展现出同心聚力的昂扬风采。
“芯”动赛场系列体育活动，让同学们与校友们因运动相聚，留下了难忘的回忆。今后，学院将继续开展形式多样的文体活动，让同学们在运动中锻炼体魄、增进交流。
