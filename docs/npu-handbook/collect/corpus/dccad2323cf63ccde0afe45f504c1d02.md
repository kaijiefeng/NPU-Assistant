# 首届红色工业文化育人理论与实践学术研讨会在蓉举行-西北工业大学

金秋十月，蓉城叠翠，锦水含章。10月17日，第一届红色工业文化育人理论与实践暨第五届红色工业文化研究学术研讨会在成都工业职业技术学院举行。会议由西北工业大学、成都工业职业技术学院联合主办，工业和信息化部工业文化发展中心、四川省教育厅指导。来自全国高校、职业院校、文博场馆和行业企业的代表200余人齐聚一堂，共赴一场“以文化人、以史育人”的思想之约。
合影。成都工业职业技术学院供图
开幕式由成都工业职业技术学院党委专职副书记苏文胜主持。成都工业职业技术学院党委书记唐崇敏、西北工业大学马克思主义学院党委书记王彦革、中共成都市委教育工委专职副书记沈鹏、工信部工业文化发展中心副主任孙星先后致辞：唐崇敏以“精神密码”为喻，承诺与各发起单位共建课程资源、共育实践阵地；王彦革强调，红色基因始终是中国工业最深沉的底色，要把它化为青年学子可感、可知、可践行的育人力量；沈鹏细数成都从三线重镇迈向制造强市的工业文脉，愿与各方把工业资源用起来、育人平台搭起来、协同机制建起来；孙星指出，联盟打通了资源与需求之间的通道，工业文化发展中心将在理论研究、资源对接、平台建设等方面持续支持。4位致辞者视角各异，却指向同一命题——让红色工业文化从历史深处走进育人现场。
随后，“红色工业文化育人联盟”揭牌，42家发起单位代表分3组上台受牌。汪永平教授宣读《红色工业文化育人联盟倡议》，共担使命、共享资源、共推实践、共研学理、共守规范，五项倡议掷地有声。“脚绘四川工业地图”实践品牌同步发布，一幅师生用脚步丈量工业现场、用专业记录工业记忆的画卷正徐徐铺展。
活动现场。成都工业职业技术学院供图
主旨论坛新论迭出。孙星介绍工业文化教育实践的进展情况；西北工业大学贺苗教授以“问天、探海、铸魂”为题，讲述行走在大国重器间的“大国三航”思政课；上海电机学院党委副书记李晓军阐释工业文化育人“从融入到同向同行”的学理与机制；汪永平教授以文化记忆理论为钥，揭示红色工业文化实践课程地图的构建逻辑；铁人学院首席专家傅殿戈以大庆油田教培基地盘活利用为例，解析现场教学基地从“点”到“体”的效能建构；咸阳纺织工业博物馆馆长呼俊琪从西北一棉的档案与党报文本中，打捞国营企业红色文化的历史逻辑；南京理工大学范彬副教授以书院制为切入点，勾勒工业文化实践育人体系的构建路径。7场报告或立论高远、或案例鲜活，从不同侧面回答了“红色工业文化何以育人”的时代之问。
午后，与会代表先后走进“天府工业记忆——正兴军氮厂工业文化展”和“中国工业精神”红色文化馆，在泛黄的厂志与斑驳的机床间触摸工业脉搏。随后，3个平行分论坛同步开讲，分别聚焦“思政课与课堂教学融入”“育人机制与精神谱系价值阐释”“工业遗产与三线历史资源的育人转化”。30余位发言人围绕三线精神赋能“大思政课”、工业遗产空间叙事、精神谱系学理化阐释、数智技术赋能育人等议题各抒己见，思想在交锋中互鉴，共识在研讨中凝聚。
参观。成都工业职业技术学院供图
闭幕式由成都工业技术学院马克思主义学院院长刘勇主持，大会首先为优秀论文作者颁奖，汪永平作会议总结并宣布第二届会议的承办单位。次日，与会代表赴四川齿轮厂“川齿记忆馆”参加工业遗产现场教学，在轰鸣犹存的机床旁聆听历史回响，为大会写下“行走”的注脚。
本次会议是首届以“红色工业文化育人”为主题的全国性学术研讨会，与连续举办五届的红色工业文化研究研讨会同场举行——“研究”把学问做深，“育人”把成果用活，双翼并举、互证互进。“红色工业文化育人联盟”的成立，打通了高校、职业院校、文化场馆、行业企业与政府部门之间的资源壁垒，搭建起理论研究、课程开发、实践教学、师资共享、资源共建的协同平台，标志着红色工业文化由学术研究走向育人实践。以此为新起点，各方将携手把工业遗产转化为育人课堂、把工业精神转化为育人力量，让红色基因在新时代产业报国的接力中薪火相传，为培养堪当民族复兴重任的时代新人、服务教育强国和制造强国建设注入澎湃的文化动能。
