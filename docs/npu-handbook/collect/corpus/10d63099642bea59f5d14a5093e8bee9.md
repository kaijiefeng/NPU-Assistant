# 2024年“三航杯”羽毛球小班赛圆满落幕

本次“三航杯”羽毛球挑战赛精彩纷呈，特别设置了男单、混双和女单三个项目，一共167个队，吸引了900余名学生积极参与。比赛不仅考验了选手们的技术，更是对他们竞技精神和团队合作的一次全面检验。
在男单项目中，选手们充分展现了他们的速度和力量，每一次跃起扣杀都让人热血沸腾。混双赛场上，男女选手的默契配合成为一大看点，他们精准的配合和快速的反应赢得了观众的阵阵掌声。而在女单对决中，女选手们展现了细腻的技巧和坚韧的拼搏精神，巾帼不让须眉。
本次比赛中的裁判经过了严格的培训，以公正、公平的态度为每一场比赛做出准确的判决，确保了比赛的顺利进行。
通过本次“三航杯”羽毛球挑战赛，不仅锻炼了学生们的身体，更培养了他们的竞技精神和团队合作意识。这场赛事为校园羽毛球运动注入了新的活力，也让学生们更加深入地感受到了羽毛球的魅力。
（图文：体育部 审核：郭光 赵春娜）
