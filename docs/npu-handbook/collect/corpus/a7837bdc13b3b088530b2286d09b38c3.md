# 【学籍管理中心】研究生退学办理说明-西北工业大学研究生院

各位研究生同学：
如需办理退学手续，请按照附件1“研究生退学审批表”要求填写，经导师、学院、研究生院审批。
退学审批手续完成后，按照附件2“研究生退学通知单”办理离校手续，办理完成后原件交研究生院学籍管理中心，可视为完成退学手续。
注：退学手续要求研究生本人办理，因故不能本人办理的情况，须出具本人签字的委托书（委托书中要明确注明本人及委托人信息，须附本人及委托人身份证复印件）。
