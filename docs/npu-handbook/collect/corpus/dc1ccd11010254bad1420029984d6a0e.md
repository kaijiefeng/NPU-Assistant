# 巧手缝囊桂香传情 中秋聚力共筑同心——我院分工会开展“指尖藏雅趣、卓工话月圆”手工香囊制作活动

金风送爽，丹桂飘香。在中秋佳节来临之际，为弘扬中华优秀传统文化，传递工会组织温暖，丰富师生精神文化生活，9月24日上午，我院分工会举办“指尖藏雅趣、卓工话月圆”主题手工香囊制作活动。学院师生欢聚一堂，在穿针引线间感受传统民俗魅力，共迎中秋佳节。
活动现场布置温馨雅致，长桌上整齐摆放着色彩缤纷的绸缎布料、清香怡人的艾草香料、五彩丝线、精美流苏及挂绳等丰富材料。活动中，大家穿针引线、填充香料、绑系收口、搭配挂饰，悉心缝制属于自己的中秋香囊。制作间隙，师生一起品尝中秋月饼，甜香与囊香相映，让大家在巧手缝制之外，也尝到了节日的甜蜜滋味。
轻松温馨的制作过程中，大家围坐畅谈，分享生活学习中的收获感悟与美好瞬间，在欢声笑语中增进彼此情谊、凝聚团队力量。师生们围绕工程创新、职业发展等话题深入交流，纷纷表示将以更饱满的热情、更昂扬的姿态投入工作和学习，以匠心守初心、以实干担使命，为学院卓越工程师培养体系建设和高质量发展贡献更多力量。
活动结束后，学院进一步传递这份佳节温情，面向新老校区全体在校生派发中秋月饼，作为中秋佳节的特殊慰问关怀，把学院的牵挂送到每一位同学手中，让大家品尝到佳节的甜蜜、感受到集体的温暖。
此次主题活动将传统民俗文化与工会关怀深度融合，既为广大师生送上了暖心的节日祝福，也搭建起交流思想、凝聚共识、增进情谊的温馨平台。大家在活动中感受传统文化魅力，传递学院关怀，进一步凝聚起同心同行、筑梦卓越的奋进力量。
