# 航海学院召开师生座谈交流会

航海学院召开师生座谈交流会
为深入落实立德树人根本任务，搭建导师与研究生沟通桥梁，解答研究生在学业规划、生活适应、职业发展等方面的困惑，强化个性化指导，构建“导学相融、互助共进”的育人氛围，航海学院于10月16日和10月21日分别组织导师和研究生座谈交流会。
10月16日，水下仿生与流动控制科技创新团队杜鹏老师以《事业目标驱动下的研究生生涯规划》为题，分别从出国、从教、研究所和企业就业等多方面目标，帮助研究生规划未来事业，并希望同学们在达到毕业标准的基础上，掌握并精通一门技能，发表高水平文章，成为行业专家。
10月21日，导师陈连平、诸国磊、秦登辉、崔晓东、张秀海围绕导学沟通机制优化、如何保证有效的学术的主题，通过跨学科、多维度对话，系统梳理当前导学关系建设中的热点问题，具体就“课程学习”“博士申请审核”“课题研究”以及“未来发展个性化路线”等方面与研究生进行探讨和交流，为研究生成长提供明确方向。
在师生互动交流环节，以成致远为代表的研究生则主动交流入学以来的感受，坦诚提及在课程学习节奏、校园生活适应等方面的典型困惑。导师们则针对学生提出的疑问逐一耐心解答，沟通氛围轻松热烈。
本次座谈交流会实现了教学相长的理念，学生视角的实证分析为导学关系建设提供了鲜活样本。航海学院将建立常态化导学对话机制，推动“亦师亦友”导学文化培育，为打造具有航海学院特色的高水平研究生育人生态注入新动力。
（审核：刘朝亚，王银涛)
