# 物理科学与技术学院党委召开党支部书记例会暨2025年度党支部书记抓党建工作述职评议考核会议

3月13日上午，物理科学与技术学院党委在学院楼353会议室召开党支部书记例会暨2025年度党支部书记抓党建述职评议考核会议。物理科学与技术学院党委书记晁小荣、化学与化工学院党委副书记姚东东，物理科学与技术学院党委委员、党支部书记、辅导员及师生党员代表参会，会议由学院党委副书记樊文迪主持。
会上，樊文迪就学院党支部书记述职评议考核工作、考核程序内容做了具体说明。随后，各党支部书记依次述职，重点汇报了支部年度亮点工作以及深化品牌建设、推动党建与业务深度融合的措施和成效。述职结束后，参会评委进行了现场评议打分。最后，晁小荣进行总结点评。他充分肯定了各支部一年来的工作成绩，并强调要持续推进基层党建规范化建设，深化“一支部一品牌”创建，提升“三会一课”质量和党员发展质效，将党建工作成效转化为学院实实在在的核心竞争力。
在随后召开的党支部书记例会上，晁小荣带领大家深入学习了中央关于开展树立和践行正确政绩观学习教育的有关精神，传达了《中共西北工业大学委员会关于开展树立和践行正确政绩观学习教育实施方案》。他指出，2026年是“十五五”规划开局之年，是锚定“一十百千”发展目标、保持“高位运行”的关键之年，各党支部要准确把握“高质量、高水平、高标准”的发展要求，提高政治站位，把树立和践行正确政绩观的要求融入支部工作全过程；要聚焦人才队伍建设、有组织科研等重点任务，推动“十五五”规划核心指标落地见效；要拓展共建渠道，加强与兄弟学院、科研院所、头部企业的交流合作。会上同步安排了2025年度组织生活会及民主评议党员工作，并针对党的二十届四中全会精神学习走深走实、党徽党旗及党员徽章规范使用、党员组织关系转接中存在的薄弱环节，逐一提出了具体要求，纳入到了重点任务清单当中。
本次述职评议通过“述、评、议”相结合的方式，既晒成绩、找差距，也明方向、定举措，达到了红脸出汗、加压鼓劲的效果。下步，学院党委将建立整改台账，实行销号管理，推动各支部在政治建设上再聚焦、在组织功能上再强化、在作用发挥上再提升，以党建联建促进理工融合、科教协同、产教融合，全面推进学院各项事业更高质量发展。
