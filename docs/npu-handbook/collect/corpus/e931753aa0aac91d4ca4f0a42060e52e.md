# 延安研学话长征，青春逐梦向未来——人工智能学院开展主题团课

10月24日，人工智能学院组织开展了“延安研学话长征，青春逐梦向未来”主题团课。本次活动邀请学校宣讲团成员郑钧同学主讲，其以我校学生赴延安研学旅行为切入点，带领学院团员青年重温长征历史、感悟长征精神。
郑钧宣讲现场
团课中，他结合研学途中的所见所闻与切身体悟，将长征这一波澜壮阔的伟大远征徐徐展开。从中央红军瑞金出发到三大主力会宁会师，从翻越皑皑雪山到穿越茫茫草地，他以翔实的史实与生动的讲述，结合延安红色革命底蕴，引导同学们在历史与现实的映照中，深刻体悟革命先辈坚定信念、百折不挠、浴血奋战的长征精神。
同学们认真听团课
团课现场，同学们神情专注、反响热烈。大家纷纷表示，要将长征精神内化于心、外化于行，在人工智能专业学习中不畏艰难、勇攀高峰，以实干担当赓续红色血脉。此次团课是一堂深刻的理想信念教育课，人工智能学院将持续创新主题团日形式，引导青年学子在学思践悟中坚定理想信念，立志做有理想、敢担当、能吃苦、肯奋斗的新时代好青年。
