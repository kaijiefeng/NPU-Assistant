# 公共政策与管理学院传达学习学校2026年暑假务虚会和秋季学期中层干部会等会议精神

9月2日上午，公共政策与管理学院召开党委（扩大）会议，传达学习学校2026年暑假务虚会和秋季学期中层干部会等会议精神，研究部署学院新学期重点工作。学院党委委员参加会议，教工党支部书记、系主任和学院办公室工作人员列席会议。会议由学院党委书记管兴华主持。
管兴华传达了张云明书记、宋保维校长在暑假务虚会、秋季学期中层干部会、基础研究工作会、学生工作会上的讲话精神，强调全院上下必须深刻领会、坚决贯彻。要牢牢把握“站位再提高、思想再解放、落实再加力”的工作要求，对标对表，以更严尺度和更高标杆履职尽责。同时，要持续巩固树立和践行正确政绩观学习教育成效，坚持以党建为引领，推动党建与业务同向发力、深度融合，切实把学习成果转化为推动学院“十五五”开好局、起好步的实际行动。
刘晨光对本学期学院学科专业调整、高水平师资队伍建设、有组织科学研究等重点工作进行了系统部署。他强调，要深入思考人工智能赋能学院发展的落脚点和切入点。同时提出要以机关工作人员业务能力提升为抓手，完善学院治理体系，提升治理能力。强化协同联动，以高效能治理支撑高质量内涵式发展，确保本学期各项重点任务落地见效。
与会人员围绕会议精神开展了讨论，一致表示要深学细悟、对标看齐，把学校各项部署要求内化于心、外化于行，切实以“思想破冰”推动学院高质量发展，以更坚定的担当、更务实的作风，狠抓落实、协同攻坚，合力促进学院事业持续向上向好发展。
