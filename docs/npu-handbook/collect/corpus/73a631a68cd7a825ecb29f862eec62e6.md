# 体育部开展教师综合素质提升专题培训

10月10日，依托学校教师发展支持计划，体育部组织教师43人赴商洛市干部教育培训基地牛背梁开展教师综合素质提升培训，进一步提升教师的政治素养和师德修养。
老师们一行首先来到海拔1700米的月亮垭现场教学点，这里是2020年4月20日习近平总书记来陕考察时发表重要讲话的地方。站在习近平总书记曾经站立过的地方，老师们认真学习“自觉讲政治，对‘国之大者’要心中有数”的重要论述，深刻领悟秦岭违建“大教训”的警示意义，在绿水青山间接受沉浸式生态文明教育，在实地感悟中牢记育人使命、强化责任担当。
随后，老师们沿着习近平总书记当年的考察足迹步入羚牛谷现场教学点。详细了解当地如何将生态保护与旅游发展有机结合的实践探索与成功经验，让大家切身感受到“绿水青山就是金山银山”不是口号，而是实实在在的发展路径。老师们边走边议，联系体育工作实际思考如何把生态文明理念融入体育教学、群体活动和育人实践，引导学生在体育锻炼中强健体魄、锤炼意志。
此次培训，使参加活动的教师在思想上受到了一次深刻洗礼，进一步增强了立德树人的责任感和使命感。老师们纷纷表示，要切实把增强“四个意识”、坚定“四个自信”、做到“两个维护”落到日常工作中，把学习收获转化为做好体育教学、训练竞赛和体质健康工作的实际行动，立足岗位、积极作为，努力为培养德智体美劳全面发展的社会主义建设者和接班人贡献体育力量。
（文：杨梦晨，图：杨梦晨，审核：傅莉）
