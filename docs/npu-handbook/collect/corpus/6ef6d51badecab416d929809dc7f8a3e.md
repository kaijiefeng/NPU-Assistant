# 后勤办公室党支部组织党员理论学习会议

根据学校机关党委7月党支部理论学习指导意见，7月8日下午，后勤办公室党支部在会议室召开了全体党员理论学习会，会议由党支部书记张文刚同志主持。
首先，由张文刚同志带领全体党员集中学习了《习近平致哈尔滨工业大学建校100周年的贺信》《习近平给复旦大学青年师生党员回信勉励广大党员在学思践悟中坚定理想信念在奋发有为中践行初心使命》《习近平在宁夏考察时强调决胜全面建成小康社会决战脱贫攻坚继续建设经济繁荣民族团结环境优美人民富裕的美丽宁夏》《习近平在中央政治局第二十一次集体学习时强调：贯彻落实好新时代的组织路线不断把党建设得更加坚强有力》《充分认识颁布实施民法典重大意义，依法更好保障人民合法权益》等文件。
接着，对《习近平来陕考察重要讲话重要指示》开展了专题学习，围绕习近平来陕考察重要讲话重要指示，后勤办公室结合近期工作进展和工作实际情况，在集体学习的基础上各党员结合本职工作，展开了专题研讨交流。
最后，张文刚同志做大会总结。他指出全体党员要深刻领会精神实质，并贯彻落实到实际工作当中，不断提高政治理论水平，提升工作业务能力，增强服务意识，发挥党员的先锋模范作用，努力做好本职工作，为学校“双一流”建设贡献力量。
