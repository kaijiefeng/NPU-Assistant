# 西安翱翔工大后勤产业集团-西北工业大学资产经营管理有限公司

西安翱翔工大后勤产业集团有限公司成立于2017年6月22日，注册资本1200万元，是西北工业大学资产经营管理有限公司独资公司，作为西北工业大学后勤集团的运营机构，为学校教学科研、人才培养、师生员工正常生活提供有力的后勤保障服务。
公司经营范围涵盖企业管理、物业管理、酒店管理、餐饮管理、工程管理、小微型客车租赁经营管理、人力资源服务、会议及展览服务、家政服务、公共事务管理服务、各类销售服务等，是一家综合性现代化专业后勤服务企业。公司现有人员近1600人。2025年，集团年产值为1.17亿元，现已逐步发展成为多点支撑、多业并举、多元发展的后勤服务实体。
公司下设两个子公司（西安南山苑宾馆有限责任公司、西安翱翔工大正禾宾馆有限责任公司）和七个分公司（物业分公司、运输服务分公司、饮食服务分公司、工程建设分公司、友谊商贸分公司、长安商贸分公司、太仓分公司）。
公司始终坚持“三服务、三育人”服务宗旨，秉承“乐在人后、勤在人先”服务理念，聚焦“职责、标准、流程、质量、能力”五要素建设，坚持育人有为、服务有心、保障有力、发展有方，努力做立德树人的忠实践行者、师生服务的优质提供者、学校发展的坚强保障者、一流后勤的矢志追求者。
