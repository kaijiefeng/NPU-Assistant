# 关于举办2025年“6·9”国际档案日“请听档案说”主题征文活动的通知

档案馆全体职工、各单位兼职档案员：
档案是历史的见证，是文化传承的重要载体。为深入挖掘档案背后的故事与价值，传承和弘扬西工大的优良传统，进一步激发广大师生和校友的爱校荣校情怀，根据2025年全国档案宣传工作要点以及国际档案日系列宣传活动安排，现面向全馆同志及学校各部门兼职档案员，举办2025年国际档案日“请听档案说”主题征文活动。
一、征文主题
“请听档案说”
二、征文内容
围绕“请听档案说”主题，用档案讲好新时代西工大故事。可以从西工大档案中探寻党和国家各项事业在学校发展中的历史性巨变；可以展现西工大档案工作在学校全面深化改革中的生动实践；可以聚焦“十四五”以来西工大档案事业发展新成就，凸显档案工作在信息化建设、档案文化传播、档案资源保护等方面的价值；还可以讲述新时代西工大兰台人坚守初心使命、忠诚履职的职业风采，展现档案人的责任与担当。
三、征文要求
1.主题鲜明，观点正确，积极向上。
2.题目自拟，体裁不限，表述清晰，篇幅3000字以内。
3.语言生动，事例鲜活，有感染力，不空谈道理。
4.来稿须为原创作品，此前未公开发表。
5.来稿须在文章标题上方注明作者姓名、单位、手机号码（如信息缺失，则无法参与评奖），请以word文档格式发送至征文活动电子邮箱：dag@nwpu.edu.cn，邮件主题注明“国际档案日征文”，投稿截止日期为2025年6月15日。
四、奖项设置
此次征文活动设一等奖1名、二等奖3名、三等奖5名，获奖者将获得荣誉证书和精美奖品。所有参与征文活动的人员都可获得一份参与奖品。此外，活动中的优秀作品将被推荐至国家档案局，参加由其主办的同主题征文评选活动。
