# 学习贯彻全会精神，凝心聚力奋进新程”党的二十届四中全会精神专题党课

为持续深入学习贯彻党的二十届四中全会精神，推动全会精神在基层一线走深走实、落地见效，近日，物理科学与技术学院院长翟薇面向材料物理系第一、第二党支部，应用物理系第一、第二、第三党支部全体党员讲授专题党课。
授课中，翟薇院长紧扣党的二十届四中全会核心要义，围绕全会审议通过的《中共中央关于进一步全面深化改革、推进中国式现代化的决定》，解读了全会提出的教育、科技、人才“三位一体”统筹推进的核心内涵，强调高校是培育人才、深耕科研、赋能教育的重要阵地，必须牢牢锚定国家重大战略需求，主动扛起新时代高等教育使命担当。
翟薇全面梳理学院近年发展成效，学院深耕超常条件材料物理与化学、光信息技术、超声科学与技术等优势研究方向，办学科研成果硕果累累。她表示，各项事业稳步向好发展，离不开各基层党支部凝心聚力建强战斗堡垒，更离不开全体党员教师冲锋在前、履职尽责发挥先锋模范作用。结合学院学科建设、人才培养、科研创新实际，翟薇对下一步工作提出明确要求。一是筑牢思想根基，抓实理论学习，牢牢把握办学育人正确方向，不折不扣落实立德树人根本任务；二是聚力科研攻坚，深耕有组织科研模式，主动对接人工智能、航空航天航海等重点领域发展需求，推动多学科交叉融合创新；三是科学统筹长远布局，精准谋划“十五五”时期发展蓝图，聚力打造高端科研平台，聚力攻关重点科研项目，全力争取发展新突破；四是严守思想阵地，抓实意识形态工作，筑牢校园安全稳定防线，倾力打造彰显物理学科特色、贴合院系发展实际的党建工作品牌。
今后，将立足教学科研本职岗位，深学细悟全会精神，把学习成果转化为干事创业实际行动，在材料物理、应用物理等优势学科领域勇毅攻坚、潜心钻研，以过硬专业能力产出高水平科研成果，推进学院各项事业实现更高质量发展。
（文：杨文琪；审核：晁小荣）
