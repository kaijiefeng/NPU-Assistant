# 关于组织参加第十八届蓝桥杯全国大学生软件和信息技术专业人才大赛的通知

各学院：
为落实国家人工智能人才培养与高校创新体系建设要求，进一步提高学生工程实践和就业能力，推动产教融合，为制造强国和网络强国建设提供人才服务支撑，学校决定组织参加第十八届蓝桥杯全国软件和信息技术专业人才大赛,现将报名有关事项通知如下。
一、参赛对象与竞赛类别
我校本科生、研究生均可报名参赛。
大赛分为省赛/全国选拔赛、全国总决赛。
省赛/全国选拔赛、全国总决赛由大赛组委会统一安排，并为获奖选手及指导教师颁发证书。
二、竞赛类别与安排
1.软件赛、电子赛、人工智能赛、专项赛（鸿蒙应用开发）
赛项范围：软件赛（C/C++程序设计、Java软件开发、Python程序设计、Web应用开发、软件测试和网络安全）、电子赛（单片机设计与开发、嵌入式设计与开发、EDA设计与开发、物联网设计与开发、FPGA设计与开发、5G全网规划与建设）、人工智能赛（AI模型应用开发、智能体开发、数据分析与可视化）、专项赛（鸿蒙应用开发、蓝桥杯大赛主视觉与赛事IP文创设计）；
报名时间：即日起至2026年12月18日14:00。
2.视觉艺术设计赛、数字科技创新赛
赛项范围：视觉艺术设计赛（海报设计、文创设计、交互设计(UI)、插画设计、信息可视化设计、视频设计、动画设计、AIGC微短剧创意设计、环境艺术设计、工业产品设计、包装设计）、数字科技创新赛（数字科技应用创新、智能装备数字化建模）
报名及提交作品时间：即日起至2027年4月26日14:00。
3.专项赛（产教融合赛道）
赛项范围：蓝桥杯大赛主视觉与赛事IP文创设计
报名及提交作品时间：即日起至2026年11月30日14:00。
注：各项竞赛规则及说明等相关要求详见大赛官网（网址：dasai.lanqiao.cn）
三、竞赛时间
省赛/全国选拔赛：2027年4月。
全国总决赛：2027年6月中上旬。
四、报名方式
请参赛学生登录大赛官网在线报名，大赛官方网站：dasai.lanqiao.cn
五、注意事项
1.大赛章程、各科目竞赛规则及说明、后续通知等相关信息将由大赛组委会进行发布，请参赛学生及时关注大赛官网。
