# 档案馆工会小组组织部分职工参加“当好主人翁，建功新时代”第十一届教职工登山比赛

又是一年秋天至，11月2日，我校第十一届教职工登山比赛在翠华山如期举行，档案馆工会小组组织部分职工参加活动。登山过程中，大家相互搀扶、相互帮助、相互鼓励，充分发扬了团结拼搏、不畏艰险的优良作风，共同完成了登山比赛，比赛中没有一名选手掉队。通过本次比赛，让教职工在繁忙而紧张的工作之余，提高身体素质，增进感情，共同享受着运动的快乐，也充分展现了档案馆教职工团结向上、顽强拚博的精神风貌和自强不息、勇攀高峰的工大风采。
