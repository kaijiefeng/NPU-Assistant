# 外币境外汇款业务办理指南

一、线上申请
翱翔门户-办事大厅-境外汇款申请，上传以下材料并提交后委托财务处办理汇款手续：
（一）汇款类型为会议注册费、版面费等，需提供：情况说明（“境外汇款申请”界面下载模板）、发票及录用通知、协议等。
（二）汇款类型为外籍人员劳务费，需提供：情况说明（“境外汇款申请”界面下载模板）、薪酬收据（“境外汇款申请”界面下载模板）、外专护照复印件、劳务协议、邀请函等。
二、预约网报
线上审核通过后，线上预约境外汇款网报单，网报单金额按照网报当日汇率换算为人民币；若由汇款人承担手续费，网报单金额需再加上相应手续费（一般为400元人民币，如果汇款金额较大，适当增加手续费）。
网报单银行信息应填写：名称：西北工业大学（资金性质：济困助学专户），开户行：中行西工大支行，账号：102010169938。
