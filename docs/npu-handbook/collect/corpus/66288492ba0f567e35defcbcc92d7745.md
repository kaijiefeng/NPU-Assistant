# 筑牢理想信念、强化使命担当 ——校医院多党支部组织爱国主义教育主题观影活动-西北工业大学医院

为深入开展党史学习教育，弘扬爱国主义精神，引导党员铭记历史、勿忘国耻，厚植家国情怀与职业担当，9月23日，西北工业大学医院门诊党支部联合住院党支部、行政党支部全体党员集中观看历史战争影片《731》。
影片以详实的史料和震撼的影像，揭露了日军的滔天罪行，真实再现了那段充满苦难与抗争的历史，为全体党员上了一堂生动而深刻的爱国主义教育课和党史国史教育课。
观影过程中，看到侵华日军那些惨无人道的细菌实验、毫无人性的活体解剖，一桩桩、一件件，无不在挑战着人类道德和伦理的底线。这些画面让党员同志们深感愤怒和悲痛，更被中华民族在危难时刻所展现出的不屈不挠、英勇抗争的伟大精神所深深触动。大家深刻认识到，历史的悲剧绝不能重演，和平来之不易，必须倍加珍惜。
此次观影活动是校医院各党支部加强党员思想教育、凝聚奋进力量的一项重要举措。通过观影，全体党员接受了一次深刻的精神洗礼。大家纷纷表示，要时刻铭记历史，缅怀先烈，从历史的苦难中汲取教训，从民族的抗争中汲取力量；要坚定理想信念，筑牢信仰之基，补足精神之钙，把对祖国的热爱、对历史的敬畏转化为立足本职岗位、奋发有为的强大动力；要自觉践行以患者为中心的服务理念，不断提升医疗技术水平和服务质量，以更加饱满的热情、更加昂扬的斗志、更加务实的作风，积极投身到守护师生健康、建设健康校园的各项工作中，为学校高质量发展贡献校医院人的智慧和力量，以实际行动告慰历史、开创未来。
门诊党支部将以此次活动为契机，继续创新学习形式，丰富教育载体，引导全体党员不忘初心、牢记使命，将爱国情怀、历史感悟内化于心、外化于行，切实发挥党支部的战斗堡垒作用和党员的先锋模范作用。
