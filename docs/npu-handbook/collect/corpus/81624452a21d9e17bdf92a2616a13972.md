# 关于2023年西北工业大学优秀博士学位论文评选结果的公示-西北工业大学研究生院

各学院、各学位评定分委员会：
按照《关于2023年西北工业大学优秀博士学位论文评选工作的通知》的要求，经个人申报、学院推荐、分会评选、专家组评审，2023年我校优秀博士学位论文评选工作已经全部结束。《静电驱动微机电系统的随机动力学研究》等40篇博士学位论文被评为2023年西北工业大学优秀博士学位论文，同时推选28篇博士学位论文参加2023年陕西省优秀博士学位论文评选，现将名单公示（见附件）。公示时间为2023年4月14日至2023年4月20日，若对评选结果有异议者，请将有关书面材料扫描后发至西北工业大学研究生院学位办公室邮箱（xwb@nwpu.edu.cn）。
