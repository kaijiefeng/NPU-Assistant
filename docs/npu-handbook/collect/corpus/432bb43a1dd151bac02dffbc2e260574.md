# 我校举行2023年度新入选国家级人才代表座谈会

10月10日上午，学校举行2023年度新入选国家级人才代表座谈会。校党委书记李言荣与大家畅谈交流、共谋发展，了解人才所需，听取意见建议。
航天学院魏祥庚、宁昕、张庆华、石磊，航海学院王鹏、施瑶、闫永胜，材料学院李恒、苏海军、徐飞、张燮，机电学院骆彬，力学与土木建筑学院龙旭，动力与能源学院周莉，电子信息学院蒋雯、崔万照、张洵颖、梅少辉，自动化学院宋受俊、张鼎文，计算机学院尤著宏，数学与统计学院孙浩，物理科学与技术学院王建元，管理学院车阿大，生态环境学院李永鑫等25位老师参加座谈会。
座谈中，各位老师对学校在教学、科研、工作、生活等各方面的支持与保障表示衷心感谢。大家围绕学校“127”目标，结合自身发展和成长经历，畅谈感悟、展望未来，并对学校平台建设、人才引育、科研保障、校企合作、学科交叉等方面提出了诚恳的建议。
李言荣认真听取了大家的发言，并与每一位人才代表都做了交流互动。他说，很高兴看到各位老师在各自领域取得成绩、有所建树，我们各部门各学院就是要千方百计帮助老师成功、少走弯路。他说，人才是学校发展的第一资源，人才的数量和质量与学生培养、科学研究的水平和质量是强相关的。“三学”（学生、学者、学术）的核心是“学者”，一个学校只有拥有好学者、高水平学者，才能培养出好学生、发展出好学术。今年是学校人才工作大发展的一年，虽然我们取得了很大进步，但离我们的目标还相差甚远，接下来，学校各单位要认真把握人才工作的规律和方法，花更大力气有组织地抓好人才队伍建设。
李言荣向今年获得国家级人才称号的老师们表示祝贺，并对大家提出三点希望：第一，在大学工作，一定要做一名好老师，既要“教书”又要“育人”，既要“言传”又要“身教”，要主动到学生中去，不仅要传授学生知识，更要影响学生的视野和学生的思维方式；第二，当上了人才后，要戒骄戒躁，要低调务实、淡泊名利，要尽快安静下来，做更加有意义的事，要聚焦最尖端、最前沿、最急需的方向，要做更有想象力、穿透力和影响力的事，要坚持做真科研、做真学问、做真贡献；第三，要敢于谋划更大的事，树立更大的目标，要善于组织团队，带领更多人一起干，特别是在“国际化”和“行业化”两方面做更有价值的事，要敢于在国际学术舞台上和国内行业领域的高峰上插上几面西工大的旗帜。
最后，他说，获得国家级人才称号，就像在人生中打出了第一口井一样，大家在接下来5-10年的时间里至关重要，要么将井中的水一桶一桶地打上来，要么带领人再打一口更大的井。他说，大家已从山脚下走到了各自领域的半山腰，但是还未登顶，只有到了山巅，才会登高望远、一览众山小。
学校办公室、人事处等职能部门负责人参加座谈会。
