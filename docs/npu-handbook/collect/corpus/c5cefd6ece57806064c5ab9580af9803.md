# 西北工业大学后勤办公室印章使用管理规定

西北工业大学后勤办公室印章使用管理规定
后勤办字〔2020〕4号
为进一步加强后勤办公室行政印章管理，维护行政印章的权威性、严肃性，杜绝漏洞发生，确保印章使用和管理的规范化、制度化，制定本规定。
第一条印章保管
（一）印章由专人负责保管，防止丢失和盗用。印章不使用时，必须锁于保险柜内。
（二）保管人员不得擅自将印章带出存放地点使用。因特殊原因需在存放地点以外使用本印章的，应经主任同意，并派遣专人携带前往。
第二条印章使用范围
（一）以后勤办名义签发、签订、上报的文件、协议、报表等材料；
（二）与校内外相关单位进行工作联系的通知、公函等资料；
（三）工程签证单、工程结算书、材料认质认价单等零星维修相关资料；
（四）其他需要加盖印章的资料。
第三条印章使用程序
印章使用要坚持安全、规范的原则，用印人需要使用后勤办印章时，必须履行相关审批程序，详细填写《后勤办印章使用登记表》，注明用印事项、数量、用印经办人、批准人、用印日期后，方可用印。在用印审批权限范围内，用印审批人对用印负责。凡不符合用印规定的，均应拒绝盖印。职工因私用印，必须经主任审批后方可用印。
第四条印章一般用于工作联系，不得用于对外签署合同或协议等超出适用范围的事项。
第五条印章由后勤办工作人员使用，外单位人员、各施工单位及其他人员不得使用。
第六条印章限于当面使用，在非特殊、非特批情况下不外借、不留用。
第七条严禁在空白介绍信、单据或空白纸上加盖印章。
第八条未按本规定使用印章的，依情节轻重追究相关责任人的责任。
第九条本规定由后勤办公室负责解释。
第十条本规定自2020年11月6日起施行。
