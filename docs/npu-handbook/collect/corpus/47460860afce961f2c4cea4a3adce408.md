# 网络空间安全学院举办实战能力培养与拔尖班选拔政策宣讲会

2025年12月27日，网络空间安全学院面向全体大一学生举办实战能力培养与拔尖班选拔政策宣讲会。学院副院长刘志强出席会议并作系统介绍，现场反响热烈。
会议宣讲了学院实战化人才培养体系的总体设计和实施路径，重点说明了校园网实战教学靶场的建设情况，以及学院在课程实验、实习实训等环节中如何开展实战化教学的情况。学院鼓励所有同学参加学科竞赛、护网行动、实网演练等多种形式的实战化实践活动。
会上宣讲了网安拔尖班的选拔办法、考核机制、动态管理模式等。拔尖班实施动态管理制度，每年进行人员调整，实行优胜劣汰，以保持拔尖班的活力与培养质量。在培养方案方面，拔尖班突出“实战导向、创新驱动、高阶要求”的特色，不仅课程设置兼顾前沿性与高阶性，还注重实战创新能力培育，并将引入企业师资、搭建校际交流平台，全力拓展学生学术视野与综合素养。学院致力于培养具备卓越实战对抗能力和系统创新能力的“总师型”网安高素质专业人才。拔尖班是一块实验田，帮助学院探索与培养目标相匹配的培养体系。
宣讲会现场气氛活跃，学生们围绕个人发展、能力提升等方面积极提问，刘志强副院长一一耐心解答，同时鼓励同学们主动把握成长机遇，潜心学习、勇于探索，努力成长为适应国家战略需要的网安高素质专业人才。
本次宣讲会系统阐述了学院实战育人与拔尖培养的整体理念，增强了学生对学科价值的认同，也为后续人才培养工作的开展营造了良好氛围。
