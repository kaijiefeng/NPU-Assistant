# 关于2026年“五一”劳动节放假期间教学安排的通知

各教学单位：
根据学校《关于2026年“五一”劳动节放假安排的通知》，2026年“五一”劳动节放假时间为5月1日（周五）至5月5日（周二）。
放假期间，原则上本科生及研究生所有课程停课，5月9日（周六）按当日课表上课。需要补课的教师请根据课程实际情况合理安排补课，及时通知学生，并报所在教学单位、教务部教学运行与服务中心备案。
特此通知。
（文字：姚鹏，郑波；审核：王劲）
