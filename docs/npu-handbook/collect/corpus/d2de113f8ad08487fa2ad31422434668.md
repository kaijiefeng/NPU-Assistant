# 因公长期出国（境）办理流程

## 因公长期出国（境）类型

分为三类：

1. 国家公派：接到国家留学基金委录取函、外方邀请函后开始办理因公长期出国（境）手续。
2. 单位公派：接到学校或学院经费资助、外方邀请函后开始办理。
3. 自费公派：接到外方邀请信后开始办理。

## 办理流程

校内审批流程：翱翔门户—外事系统—我的外事—教职工因公长期出国（境）填写审批表—短信通知批件办理完成—前往人事处、财务处及所在单位办理后续手续。

注意事项：

1. 邀请函：需明确出访人姓名、出访时间、出访地点、出访事由、工作内容和目的、费用来源（由邀请方资助的需明确资助范围和内容；邀请方全额资助境外费用的，须落实邀请方是否承担境外意外、医疗保险费用）；邀请函必须从访问目的国或地区本土发出，驻华办事处或驻华分支机构发出的无效。
2. 详细的研修计划。
3. 国家留学基金委录取函复印件（仅限国家公派），其他公派项目需提供人事处签批的报告。
4. 申请人持任务批件到人事处办理因私护照申请或因私护照领取、签订出国协议、交纳出国保证金等手续，具体所需材料请咨询人事处综合办：88494328。
5. 按照本人的研修计划和人事处相关规定出国（境）执行任务。
6. 线下办理步骤：填写《出国（境）安全保密承诺书》（在保密处网站下载），本人签字并提交所在单位；填写《西北工业大学教职工因公长期出国（境）审批表》，本人签字后由所在单位主要负责人审批并加盖公章；填写《长期公派出国（境）任务书》；准聘教师与博士后人员还需提供《长期公派出国（境）协议》《聘期任务书》和《聘期成果完成情况对照表》。上述材料交国际合作处审核，审批完成后办理任务批件，接到电话通知领取批件后至人事处、财务处及所在单位办理后续手续。
