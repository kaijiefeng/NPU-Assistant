# 青春启航“羽”你共攀 —— 莫航学院班级羽毛球赛圆满落幕

春意盎然，活力无限。为丰富同学们的课余生活、增强班级凝聚力，营造积极向上、乐于运动的校园氛围，实现以体育人、锤炼意志、健全人格的育人目标，3月26日至4月2日，西北工业大学莫航学院在东篱菊苑体育馆顺利举办“青春启航 ‘羽’你共攀”班级羽毛球赛。
预赛比赛场景
本次比赛以班级为单位参赛，通过抽签确定预赛、半决赛对阵对手，赛事流程规范、组织有序。赛场上，气氛热烈而紧张，扣人心弦的对决轮番上演：选手们步伐灵活矫健，发力精准娴熟，大力扣杀气势如虹，巧妙吊球智慧尽显，队友间默契配合、同心协作，白色羽球在空中飞舞，拼搏身影成为赛场最美风景。赛场下，观众呐喊助威、掌声不断，充分展现了莫航学院学子团结奋进、昂扬向上的精神风貌。
半决赛比赛场景
经过多轮激烈角逐，比赛圆满落下帷幕，学院老师为获奖班级颁奖。此次羽毛球赛的成功举办，不仅提升了同学们的运动积极性，缓解了学习生活压力，丰富了校园文体生活，更增进了班级情谊、凝聚了集体力量，推动了学院体育文化工作深入开展。
生命不息，运动不止。莫航学院将以此次活动为契机，持续开展丰富多彩的体育文化活动，激励全体学子发扬拼搏争先、奋发有为的精神，以强健的体魄、饱满的热情、昂扬的斗志投入到学习与生活中，续写莫航学院体育文化发展的精彩篇章。
