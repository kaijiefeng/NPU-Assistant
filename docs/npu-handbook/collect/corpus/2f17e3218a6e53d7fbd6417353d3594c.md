# 治安联动，快速处置，成功破获盗窃手机案

近日，党委保卫部联合辖区派出所成功破获一起手机系列盗窃案，成功抓获三名嫌疑人，有力维护了广大师生的人身和财产安全。
9月15日、16日，我校大操场、篮球场接连发生两起手机失窃事件。案发后，党委保卫部高度重视，紧急调拨骨干力量组成“手机系列盗窃案”专案小组展开侦查工作。侦查人员通过监控视频收集掌握了犯罪嫌疑人的体貌特征、行动轨迹等重要信息。9月24日19时许，东门队员发现三名嫌疑人再次进校，指挥中心接到东门报告后，立即通过监控视频锁定目标嫌疑人，同时安排便衣人员，对其进行实时监控，经周密部署，19时15分许，应急分队队员联合辖区派出所民警当场将三名嫌疑人抓获，当场追回手机两部。在侦破过程中，嫌疑人对另外两起盗窃行为供认不讳。目前该案已移交太白路派出所做进一步处理。
为进一步筑牢校园安全防线，2023年党委保卫部升级完善安全服务保障工作，建成三级联防联控处置体系，巩固加强校园应急处突机制，加大警校合作力度。同时，党委保卫部温馨提示全校师生员工，切实提高安全防范意识，妥善保管好个人物品。
