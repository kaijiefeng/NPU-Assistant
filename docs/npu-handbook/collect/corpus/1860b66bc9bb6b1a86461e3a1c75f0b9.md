# 【暑假项目】2026年教育实验学院/未来技术学院/学科交叉中心慕尼黑工业大学未来航空技术eVTOL飞行器暑期项目报名通知

为培养具有家国情怀，追求卓越、堪当大任、引领未来的“总师型”科技创新领军人才，强化学院的国际化氛围，丰富全球胜任力教育教学资源，全方位提升学生的全球胜任力，教育实验学院/未来技术学院/学科交叉中心将于2026年暑假组织开展慕尼黑工业大学未来航空技术eVTOL飞行器暑期项目。
一、学校简介
慕尼黑工业大学是德国顶尖大学，2026年QS世界大学排名全球22位。慕尼黑工业大学的优势学科包括航天航空、机械、电子信息、物理、数学、医学等。
二、项目时间
2026年7月20日至2026年8月2日
三、项目内容及亮点
项目课程设置涵盖学术前沿、科研实践和企业参访三大模块。其中，学术前沿模块聚焦于eVTOL无人飞行控制系统、分布式电推进系统以及城市空中交通的核心理论及最新研究动态；科研实践模块通过实验验证和数字化模拟，使学生掌握关键技术的实际应用；企业参访模块则依托慕尼黑地区的先进企业资源，提供行业案例分析和实地交流机会。
除课堂学习外，学生还将参访空中客车Airbus、eVTOL矢量发动机推进代表企业Lilium、宝马智能工厂等代表德国先进制造水平的知名企业。
项目手册请见附件。
四、项目费用
4400欧元/人
费用包含：课程、活动、住宿、接送机、签证服务及保险等费用。
费用不包含：国际机票、签证申请、餐食等其他个人消费。
五、项目资助标准
学校国际合作处将对顺利参加项目并按学校要求顺利完成访学的同学进行资助，具体资助管理办法请见：https://guoji.nwpu.edu.cn/info/1025/5073.htm。
注：每位同学一个自然年内仅可获得一次寒暑假项目资助（一个自然年一次，如超出资助名额限制，优先第一次参加翱翔四海的低年级本科生）。各学院资助配套政策可咨询所在学院外事秘书。
