# 网络空间安全举办青年教师教学能力提升计划系列活动——李晖教授专题报告会

以提升青年教师教学能力为目标，在教务部指导下，网络空间安全学院启动了“网络安全青年教师教学能力提升计划”系列活动。
2026年1月21日，特邀国家级教学名师、中央网信办网络安全优秀教师西安电子科技大学李晖教授作专题报告。教务部部副部长、研究生院副院长王劲、学院领导及全体教师参加报告会，副院长刘志强教授主持了报告会。
报告会上，李晖教授以“网络安全实战能力培养模式与平台建设——网络空间安全实验班的建设实践”为主题，系统分享了西安电子科技大学在网络安全人才培养方面的理念、模式与实践经验。他指出，作为国家一流网络安全学院建设示范项目高校，西工大与西电均高度重视学生实战能力的塑造，并将其视为网络安全人才培养的核心环节。
详细介绍了西电网安学院实验班的建设经验，包括通过笔试与面试选拔具有潜质和兴趣的学生，实施本硕贯通培养模式，并构建涵盖专业基础、骨干与核心课程的课程体系。在实战能力培养方面，西电形成了系统化路径：建立“实验夯实基础—竞赛提升创新—实践接触前沿—实战锤炼本领”的四层渐进培养体系，涵盖达标性实验、作品赛与攻防赛、国创与企业实习、护网演习与网信先锋实战等环节，全面增强学生解决真实安全问题的能力。
李晖还重点介绍了评价改革与教学靶场实验平台建设。学院通过多元评价机制，综合考量绩点、竞赛成果、开源贡献等维度，激发学生积极性；同时建设了功能先进的实验教学中心，依托虚拟仿真平台与覆盖网络、密码、硬件的多层次靶场环境，支持大规模并发实验与贴近实战的训练，为人才培养提供有力支撑。
学院青年教师与李晖教授开展了互动交流。与会教师围绕实战能力培养、课程体系建设、实验平台资源共享等话题踊跃提问，李晖教授结合西电的实践经验和具体案例，逐一进行了细致深入的解答，现场交流气氛热烈。
刘志强教授作报告总结发言。他指出，本次报告会是一个非常好的互相学习交流的机会。李晖教授的报告系统展示了西电在实战型网安人才培养方面的创新成果，尤其在实验班建设、阶梯化培养和评价改革等方面的经验，对我院教育教学改革具有重要借鉴意义。他结合报告内容交流了西工大网安学院在校园网实战教学靶场建设、拔尖班设置和实战化教学方面的特色做法。鼓励与会教师积极学习西电在人才培养方面的先进经验，不断提升自身的教学能力，打造优质教学资源，产出优秀教学成果。
接下来，院长王震代表学院向李晖教授表示感谢。他强调，西电的成功实践为我院人才培养提供了宝贵参考，全院教师应主动学习、结合实际，在培养方案、实践教学和平台建设等方面持续探索，共同推动学院人才培养质量不断提升。
本次活动为我院青年教师提供了宝贵的学习交流机会，对推动教学改革、创新实战型人才培养模式具有积极意义。学院将持续开展系列教研活动，助力青年教师成长，不断提升网络安全人才培养质量。
