# 重庆科创中心党支部开展廉洁文化宣传教育月活动

按照学校纪委《关于组织开展2020年廉洁文化宣传教育月活动的通知》要求，为进一步深化重庆科创中心党风廉政建设，加强全体党员思想道德和党纪国法教育，持续推进廉洁文化建设，5月28日，科创中心组织全体党员开展了党内法规学习暨党课活动。
活动伊始，支部书记齐天同志带领全体党员学习了《党委（党组）落实全面从严治党主体责任规定》、《中共中央关于加强党的政治建设的意见》等党内法规，随后以党课形式分享了他学习《中国共产党党内监督条例》的一些心得，就党内监督条例的背景、全文解读、强化科创中心党支部监督、遵照条例做好廉洁自律几方面进行了讲述。他指出，党支部是确保党的路线方针政策及其决策部署落实到位的基础组织，是教育党员、团结群众、攻坚克难的坚强战斗堡垒，我们全体党员应该不断加强党性修养，增强对党支部监督作用重要性和必要性的认识，筑牢信念之基，增强“四个意识”、坚定“四个自信”、做到“两个维护”。
然后，大家围绕强化纪律规矩意识，巩固拓展作风建设成效，增强制度建设规范性和执行力等方面进行了专题学习研讨，大家表示，要持续加强理论学习的广度深度，廉洁自律，确保科创中心各项工作任务落实到位。
最后，全体党员一致认为，党内法规是党员的行为规范和指引，大家应敬畏法规、遵守法规，廉洁诚信，真正做到学规懂规、入脑入心、见行见效。要强化责任担当，健全监督机制，落实主体责任，严格制度执行，增强廉洁从业意识，推动科创中心工作迈上新台阶。
