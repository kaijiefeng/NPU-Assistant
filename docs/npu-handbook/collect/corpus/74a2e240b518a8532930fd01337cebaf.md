# 融域”讲堂系列活动——“融教”讲坛暨柔性生物电子技术名师讲坛 第31-35期

无人系统技术研究院为进一步推进一流本科人才培养，深入贯彻落实学校2026-2027学年秋季学期本科教学工作会议精神，抓牢“十五五”开局之年加快建设中国特色世界一流大学关键时期，持续深化总师型人才培养，基于研究院“融域”讲堂，精心打造了特色品牌活动——“融教”讲坛。此次讲坛同时也是柔性生物电子技术名师系列讲座第31至35期。该系列活动定于2026年9月12日至10月24日，周六下午14:00-15:00，以线上形式开展（具体安排详见下方海报），邀请国内知名青年专家学者，围绕柔性生物电子技术领域的最新科研成果进行分享。通过本学期系列讲坛的举办，坚持以学科特色和最新科研成果转化为引领，激发我校学生对柔性生物电子技术的兴趣和关注，支撑拔尖创新人才培养和“四新”建设，弘扬总师育人文化。
本次融域讲堂系列活动邀请了柔性生物电子技术相关领域的5位杰出青年学者，分别是：西安交通大学叶芝露助理教授、海南大学王东教授、华中科技大学张帆副研究员、上海科技大学于游研究员、哈尔滨工业大学齐殿鹏教授。
讲座内容包括：柔性无线供能与生物应用、软生物电子界面的微纳构筑与智能诊疗、柔性智能传感蒙皮测量技术及应用、多模态感知柔性电子与主动柔性界面、柔软神经电极的制备及应用探索。
讲坛面向我校全体师生开放，无需报名，扫描海报二维码，进入腾讯会议即可，欢迎踊跃参加！
