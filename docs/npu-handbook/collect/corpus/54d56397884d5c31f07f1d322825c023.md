# 关于组织申报2021年重庆市自然科学基金项目的通知

各相关教师：
重庆科创中心现转发《重庆市科学技术局关于申报2021年重庆市自然科学基金项目的通知》如下, 请研阅，有意向申报的老师请及时与重庆科创中心联系，完成线上提报。
一、项目类型
2021年重庆市自然科学基金项目受理申报自然科学基金面上项目、博士后科学基金项目、市杰出青年科学基金项目、创新研究群体项目等4类项目。
二、申报要求
（一）个人信息注册。项目负责人和项目组成员应当事先在“重庆市科技管理信息系统”中注册备案，且达到社会信用等级和科研信用等级的相关要求。
（二）项目负责人及参与人要求。项目负责人申请主持项目和主持在研项目的总数不超过1项；项目参与人参与申请项目和在研项目不超过2项。项目负责人需为重庆科创中心引进人才，如申请面上项目，需签署配套资金承诺书（详情请见附件）。
三、申报方式
2021年度申报项目均通过“重庆市科技管理信息系统--科研项目子系统”实行网上在线申报。
（一）项目申报书实行网上在线提交，相关附件材料签字签章后以PDF格式上传，并按“项目负责人提交--项目申报单位审核--项目申报单位提交”的流程操作。
（二）实行“无纸化”项目申报。项目申请时，只需要在线确认提交电子申请书及相关申报材料，无需报送纸质申请材料。
四、申报时间
重庆科创中心项目审核截止时间：2021年4月26日16时，系统申报截止时间：2020年4月30日16时。具体通知网址及申报附件详见http://kjj.cq.gov.cn/zwxx_176/tzgg/202104/t20210401_9059426.html。
请有意向申报的老师于2021年4月15日18:00前与重庆科创中心联系。
