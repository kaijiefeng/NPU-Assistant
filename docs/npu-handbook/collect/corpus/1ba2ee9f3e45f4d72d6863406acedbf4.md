# 关于组织参加“2027铸造工艺设计赛”的通知

各位老师、同学：
中国大学生机械工程创新创意大赛已纳入《全国普通高校大学生竞赛分析报告》竞赛目录。铸造工艺设计赛是中国大学生机械工程创新创意大赛的赛项之一，由中国机械工程学会主办、中国机械工程学会铸造分会承办，旨在为材料成型相关专业在校学生提供社会实践平台，鼓励学生主动跟踪铸造科技发展，学习铸造专业知识，提高铸造工艺设计和操作技能，提升科技创新与工程实践能力，为铸造行业培养优秀专业人才。
2027年中国大学生机械工程创新创意大赛：铸造工艺设计赛分为校内选拔赛、区域赛、全国总决赛三个阶段。为更好地组织我校参赛工作，现将相关事项通知如下：
一、组织单位
材料学院科教实践与材料分析创新中心
二、参赛范围
相关专业在校本科生、硕士研究生
三、比赛题目
1. 采取统一命题方式；
2. 比赛题目分为本科生组题目（A件、B件、C件、D件、E件、F件、G件、H件、J件、K件）和硕士研究生组题目（L件、M件）；
3. 参赛者在所属组别的命题题目中只能选择一个铸件作为参赛题目；
4. 本届赛事命题题目分砂型铸造工艺（A件、B件、C件、D件、E件、F件、G件、H件、L件、M件）和高压压力铸造工艺（J件、K件），设计时须选用相应的铸造工艺，不允许采用以其他工艺方法参赛；
本届赛事的区域赛、全国总决赛全部使用同一套赛题进行比赛。区域竞赛由赛项评审委员会专家对参赛作品工艺方案进行评审（作品盲审），不进行现场答辩。
5. 命题题目已上传中心官方网站主页（http://smarc.nwpu.edu.cn/vue/xgd/），供参赛者下载。
四、参赛要求
1. 校内参赛由材料学院科教实践与材料分析创新中心统一组织，不接受个人名义参赛。
2. 参赛的本科生只能选择本科生组题目；硕士研究生只能选择硕士研究生组题目。每名参赛者只能参加一个小组比赛，不可跨组参赛。
3. 参赛者以小组形式报名。每个本科生组参赛学生不超过5人、指导老师1–2名；每个硕士研究生组参赛学生不超过3人、指导老师1–2名。
赛事实行限额申报：每校报名作品不超过25个；经校内选拔赛，择优向赛项执委会推送不超过12个作品参加区域赛，且每个命题题目最多推送1个作品。
参赛以我校为单位，不可与其他院校合作参赛。
五、赛事安排及校内组织流程
1. 校内报名
截止日期：2026年11月15日
报名方式：填写报名表格，发送至邮箱smarc@nwpu.edu.cn
联系人：钟老师
2. 校内选拔赛：2027年1月中旬
3. 提交区域赛作品：2027年3月8日
六、其他说明
1. 比赛通知、参赛规则及赛事资料均统一于赛项官网www.chinafoundry.org公布，请密切关注。
2. 如证实参赛团队存在作假或违规行为，赛项执委会有权取消其参赛资格，取消并追回所获奖项。
请有意参赛的师生认真阅读赛事规则，密切关注官网信息，提前准备，积极组队，争取优异成绩。
