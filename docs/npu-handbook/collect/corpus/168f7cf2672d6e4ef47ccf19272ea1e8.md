# 北京研究院党支部召开深入贯彻中央八项规定精神学习教育工作学习会-西北工业大学

2025年3月24日下午，北京研究院党支部召开党员大会，专题学习深入贯彻中央八项规定精神学习教育工作。资产公司党委副书记田建昌同志到会指导工作。北研院全体党员和干部职工参会，会议由党支部书记方文杰主持。
会议集体学习了关于印发《中共西北工业大学委员会关于开展深入贯彻中央八项规定精神学习教育的实施方案》的通知和《深入贯彻中央八项规定精神学习教育工作提醒（一）》，传达学习了学校党建工作领导小组暨基层党委（党总支）书记扩大会议精神及学校关于开展深入贯彻中央八项规定精神学习教育的相关要求。会议要求全院党员干部和职工以高质量、高标准、严要求做好深入贯彻中央八项规定精神学习教育相关工作。
田建昌在总结时指出，一是要牢固树立纪律和规矩意识，严守中央八项规定精神，在守纪律、讲规矩上作表率；二是做到知行合一，严格按照中央八项规定要求执行，在各环节、各方面对标查摆反思，做到有则改之无则加勉；三是树牢“改进工作作风 密切联系群众”的根本理念，统筹推进深入贯彻中央八项规定精神学习教育，学深学透、落实落细。
