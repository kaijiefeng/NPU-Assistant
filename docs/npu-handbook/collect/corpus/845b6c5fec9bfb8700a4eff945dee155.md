# 中国人民大学王向明教授作客学院“讲道理：以研促教Seminar”-西北工业大学

6月30日上午，中国人民大学王向明教授受邀作客学院第49期“讲道理：以研促教Seminar”，带来《以真心真情真意讲好思政“金课”》的专题讲座，校内外近40名思政课教师到场参加。讲座由马克思主义学院副院长贺苗主持。
讲座伊始，王向明教授围绕“真心、真情、真意”三个维度，运用丰富生动的案例，一是强调思政课教师必须筑牢信仰根基，二是强调要用鲜活情感赋予思政课堂温度，三是围绕教学创新分享实操方法，深入浅出阐释如何打造有力量、有温度、有实效的思政课堂实践路径，让思政教学直抵人心，灵活落地。王向明教授以深厚学识、真挚情怀，紧紧围绕真心、真情、真意，以精彩的教学示范使老师们感受到思政课从不是冰冷理论的灌输，而是以赤诚之心传递真理、以滚烫真情打动青年、以纯粹真意立德树人。
交流环节，现场教师踊跃提问，围绕思政金课选题、职业院校思政课建设、长短课时专题教学设计等实际教学难题展开请教。王向明教授结合多年授课、评审、金课指导经验逐一细致解答，针对性给出实操建议，为一线教师破解教学痛点提供清晰思路。
讲座最后，贺苗代表参会老师对王向明教授的倾囊相授表示感谢，此次讲座兼具情感温度与实践力度，既系统梳理了新时代思政课的育人逻辑，又提供了可直接落地的教学方法，为思政课教师打磨精品课堂、提升育人实效指明方向。
与会教师表示，此次学习深受启发，今后将持续以习近平新时代中国特色社会主义思想为指引，以“真心、真情、真意”为抓手，深耕思政课堂、深挖故事、创新教法，持续打造让学生入耳入脑入心的优质思政课程，坚守为党育人、为国育才初心使命，以高质量思政教育助力学校立德树人事业迈上新台阶。
“讲道理：以研促教Seminar”是在深入学习贯彻习近平新时代中国特色社会主义思想背景下，为切实提升思政课以研促教、教研相长的实效，由我校马克思主义学院发起并创设的系列教研活动。未来学院将持续用好这一平台，不断丰富教研形式，以系统化教研助推思政课内涵式提质增效。
