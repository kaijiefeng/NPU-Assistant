# 学院举办大学生职业规划大赛经验分享会

为帮助学生明晰职业方向、增强生涯规划意识，10月22日，教育实验学院/未来技术学院/学科交叉中心举办“规划启航，职引未来”职规赛经验分享会，邀请第三届全国大学生职业规划大赛“成长赛道”金奖获得者、物理科学与技术学院2023级本科生张益沐作经验分享，各年级学生代表220余人参加。
会上，张益沐结合国赛答辩PPT，围绕职业目标确立、成长路径梳理、参赛复盘展开分享。他结合专业学习、科研竞赛与社会实践经历，讲解如何立足自身优势对接行业需求，在实践中迭代调整职业方向，并就备赛分享心得，要讲清职业选择逻辑，用真实经历证明岗位匹配，材料重成长实绩而非荣誉堆砌，打磨文稿的同时通过模拟答辩锻炼临场能力。互动交流环节，同学们围绕职业规划、赛事备赛等方面踊跃发问，张益沐结合自身经历一一解答。
学院学工主管王蓉现场动员同学们积极参与职业规划大赛，鼓励大家以赛事为契机，认真思索个人发展，梳理学业与实践经历，科学做好职业生涯规划，在备赛过程中深化自我认知、锤炼综合能力。
本次分享会内容充实，帮助同学们厘清职规赛备赛思路，打通专业学习、科研实践与职业目标的衔接。未来，学院将持续搭建朋辈分享交流平台，切实提升学生职业规划素养，护航学生成长成才。
