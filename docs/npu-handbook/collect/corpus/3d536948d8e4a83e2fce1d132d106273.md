# 西北工业大学网络空间安全学院开题答辩（蒲石）

一、开题答辩题目：面向攻击面分析的网络威胁狩猎方法研究
二、开题答辩人：蒲石
三、开题答辩时间：2024年1月18日10：00 - 12：00
四、开题答辩地点：中国电子科技集团公司第三十研究所3号楼5楼会议室
五、开题内容简介：
网络空间已成为继陆、海、空、天外的第五主权空间，成为国家主权延伸的新疆域, 在全球信息技术不断推陈出新、数字化转型不断加速的大背景下，信息化、数字化、智能化等方面正在发生不同程度的变革，网络空间问题日益凸显，网络威胁层出不穷，网络安全逐步引起各行各业的高度重视。本研究通过对数字攻击面的深入分析，以网络攻防对抗视角，及时发现资产暴露情况，研究利用ATT&CK模型分析、机器学习与自动化分析技术，实现对攻击过程的精准定位以及对潜在威胁和攻击路径的研判，进而高效完成相关网络威胁狩猎活动。
六、开题答辩人简介
蒲石，男，学号2021161084，1982年9月出生，网络空间安全学院电子信息专业，导师谢瑞云，主要研究方向为网络安全、红蓝对抗等。
