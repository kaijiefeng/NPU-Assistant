# 深耕理论，聚焦前沿——第十届全国航天动力学与控制青年学者论坛会议在西安召开

2026年4月17日至19日，第十届全国航天动力学与控制青年学者论坛会议在陕西省西安市召开。本届论坛由西北工业大学和中国力学学会动力学与控制专业委员会主办，西北工业大学航天学院承办，航天飞行动力学技术国家级重点实验室协办，内蒙古工业大学校长宝音贺西教授和西北工业大学副校长岳晓奎教授担任论坛主席。本届论坛瞄准航天重大工程中的科学问题，促进我国航天领域的前沿技术创新与成果转化。共有来自清华大学、上海交通大学、南京大学、中山大学、哈尔滨工业大学、国防科技大学、北京航空航天大学、西北工业大学、北京理工大学等全国航空航天领域高校和科研院所的200余名代表汇聚一堂，共同探讨航天动力学前沿进展。
论坛开幕式
开幕式上，宝音贺西教授作为大会主席致辞，回顾了全国航天动力学与控制青年学者论坛会议的发展历程，强调随着航天动力学与控制领域研究队伍的不断成长壮大，论坛在促进前沿技术攻关、推动青年人才建设方面发挥了日益重要的纽带作用，并对未来大会的发展寄予深切期望。随后，岳晓奎教授通过视频致辞，向与会学者致以热烈欢迎和诚挚问候，表达了主办单位西北工业大学对大会的高度重视，充分肯定大会对我国航天事业高质量发展与青年人才成长的积极作用，并介绍了西北工业大学以三航为特色的深厚底蕴、使命担当与未来发展战略构想。航天学院秦飞副院长代表承办单位致辞，强调了学院在“总师型”拔尖人才培养与尖端科研平台建设方面取得的丰硕成果，表达了对青年人才投身我国航天事业发展、助力航天强国建设的殷切期许。大会开幕式由航天学院代洪华教授主持。

开幕式后，中国科学院空间应用工程与技术中心高扬研究员、北京航天飞行控制中心曹建峰副研究员、哈尔滨工业大学王小刚教授、北京航空航天大学于洋教授、西北工业大学杜崇瑞教授作为特邀嘉宾，分别进行了《DRO-A/B卫星地月大救援：轨道弹性与系统韧性的创新设计及在轨极限验证》、《地月时空基准维持技术》、《跨介质飞行器发展与关键技术》、《碎石堆小行星的撞击响应与溅射物演化分析》、《郁金香轨道构造方法郁金香轨道构造方法及其在地月空间任务中的应用特性分析》的大会特邀报告，分享了各自团队取得的最新成果。大会特邀报告分别由高长生教授、龚胜平教授、邬树楠教授、曾祥远教授和叶东教授主持。五场报告内容翔实、视角新颖，现场互动踊跃，掌声不断。报告后，刘闯教授主持了下一届青年学者论坛承办单位竞选。

本届论坛共设置5场特邀报告和4个分论坛，200余名航天动力学与控制领域青年学者在40个分会场报告中聚焦航天动力学基础理论、复杂空间任务规划、多源感知与自主控制、空间机器人操控等前沿热点，全方位展示了最新科研成果。现场既有关于前沿理论的激烈碰撞，亦有结合工程应用的务实探讨，有效促进了航天动力学与控制领域青年学者的学术交流与合作。大会特邀报告结束后，中国力学学会动力学与控制专业委员会航天动力学与控制专业组组长乔栋教授主持召开了专业组会议。中国力学学会副理事长田强教授、动力学与控制专业委员会主任王青云教授出席会议并参与交流讨论。

精彩瞬间
本次论坛的成功举办，有力促进了青年学者间的学术互通与深度合作，为深化相关领域的学术合作与研究发展奠定了坚实基础。在热烈的学术氛围中，论坛圆满落幕。我们深信，未来全国航天动力学与控制青年学者论坛会议将继续推动我国航天动力学与控制事业迈向新的高度，为青年学者施展才华、贡献智慧提供更广阔的舞台。
