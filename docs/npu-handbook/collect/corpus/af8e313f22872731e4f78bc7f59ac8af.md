# 国产仪器示范中心西工大中心”正式揭牌成立

2026年1月16日下午，陕西省分析测试协会与陕西省科技资源统筹中心共同举行了“国产仪器示范中心西工大中心”揭牌仪式。陕西省科技资源统筹中心党委委员、副主任杜学军，我校国有资产与实验设备管理处处长刘延安共同为中心揭牌；陕西省分析测试协会理事长陈忠伟教授，我校分析测试中心副主任刘平教授代表双方接受授牌。
国产仪器示范中心的设立，是陕西省深入贯彻落实国家“高水平科技自立自强”战略部署的重要行动，也是推动国产科学仪器设备自主创新与推广应用的关键举措。
作为国产仪器示范中心的重要布局，西工大中心将依托学校雄厚的科研基础和分析测试中心的平台优势，致力打造国产仪器展示、验证、推广、应用及技术交流的示范高地。通过推动国产仪器在科研实践中的示范应用，系统开展国产仪器的性能评估与验证，加速技术迭代与产品成熟，为我省乃至全国高端分析仪器的自主创新与产业化应用提供有力支撑。
国产仪器示范中心西工大中心将以国产仪器自主创新为纽带，推动教育、科技、人才资源高效联动，为服务学校“一十百千”中期目标与“天下工大、世界三航”远景目标贡献力量！（文：陈敏 审：刘平）
