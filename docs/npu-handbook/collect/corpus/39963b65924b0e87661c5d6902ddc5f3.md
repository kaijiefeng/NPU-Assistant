# 筑牢反诈安全防线 守护青春财产安全——人工智能学院开展反诈安全教育专题宣讲会

10月29日，我院联合数学与统计学院、化学与化工学院、体育部开展大学生反诈安全专题宣讲教育活动。本次活动由学校党委保卫部联动西安市公安局高新分局，邀请杨皓宇警官作宣讲，面向全院学生普及反诈知识、强化风险防范能力，切实增强学生安全防范意识，有效防范校园电信网络诈骗案件发生，筑牢平安校园安全屏障。
宣讲中，杨皓宇立足当前高校反诈工作形势，聚焦大学生群体高发诈骗类型开展专题讲解，深入剖析刷单返利、虚假退款、车票改签等校园高频诈骗套路。结合多起真实涉校诈骗案例，杨警官梳理总结了不法分子利用大学生社会经验欠缺、求职兼职、网购出行等心理实施诈骗的共性手段，点明此类诈骗普遍存在诱惑性强、伪装程度高、传播速度快、隐蔽性突出等特征，提醒同学们警惕“高薪轻松兼职”“异常退款理赔”“低价票务改签” 等信息，不断提升风险辨别能力。
围绕校园日常反诈防范要点，杨警官重点宣讲“三不一多”安全准则：未知链接不点击、陌生来电不轻信、个人信息不透露、转账汇款多核实。他强调，同学们在日常学习生活中要时刻绷紧安全防范之弦，接到陌生消息、遇到转账要求务必冷静核实，摒弃侥幸心理，严守个人信息与财产安全底线，从源头防范电信网络诈骗风险。
同时，杨警官积极推广国家反诈中心APP，详细介绍软件的风险预警、来电识别、骗局拦截、安全科普等核心功能，号召全体同学及时下载注册、开启预警防护，充分借助官方反诈工具构建个人安全屏障，常态化做好自我防护。
本次宣讲内容精练、针对性强，紧贴大学生生活实际，有效补齐了学生反诈认知短板，进一步夯实了我院平安校园建设基础。下一步，我院将持续推进反诈安全教育常态化、制度化，持续营造全员识骗、防骗、拒骗的良好氛围，全力守护广大学生人身与财产安全。
