# 西北工业大学马克思主义学院举行《工程伦理学》课程集体备课会-西北工业大学

为深入贯彻落实立德树人根本任务，扎实推进课程教学改革，提升《工程伦理学》课程教学质量与育人实效。2025年12月21日，西北工业大学马克思主义学院《工程伦理学》课程组进行了集体备课会。工程伦理学课程负责人宫淑燕副教授主持会议并作经验分享，学院副院长张云龙教授、课程组全体教师参加了本次集体备课。
备课会上，课程负责人宫淑燕首先介绍了本学期《工程伦理学》课程的整体教学安排、重点难点以及教学方法的创新思考。与会教师围绕课程大纲设计、教学内容优化、案例库更新、教学环节设置、考核评价方式改革等议题展开了热烈而深入的研讨，并分享了各自的教学心得与资源。
张云龙在听取汇报和讨论后，首先肯定了课程组前期的工作成效和本次集体备课的必要性。张云龙强调，《工程伦理学》课程是学校工程教育与思想政治教育、价值引领紧密结合的关键课程，对于培养新时代具有高度社会责任感、良好职业道德和卓越工程素养的领军人才具有重要意义。同时，张云龙还分享了自己关于《工程伦理学》课程的授课经验，一是要坚持“内容为王”， 持续深化理论研究，及时将科技前沿、国家战略与工程实践中的伦理新议题、新挑战融入教学，确保教学内容的先进性与时代性；二是要探索“方法创新”， 积极运用案例教学、情境模拟、项目研讨等多元化教学方式，激发学生主动思考与价值辨析的能力，增强课程的吸引力与感染力；三是要强化“价值引领”， 牢牢把握课程的价值属性，在知识传授中突出家国情怀、工匠精神、科技向善等核心价值观的引导，实现知识传授、能力培养与价值塑造的有机统一。
随后蒲瑶、吕天泽、齐承水、聂阳等同志也结合自身的教学与课程建设进行了经验分享。最后宫淑燕指出，《工程伦理学》课程是西北工业大学的特色课程之一，不仅应充分发挥集体智慧，打造教学共同体，还需要课程组进一步凝练教学特色，形成具有西工大辨识度的教学范式，并加强教学资源的系统性建设，特别是具有行业特色和学校特色的案例开发等。
本次集体备课会气氛热烈，成效显著。通过《工程伦理学》课程组老师的深入交流与思想碰撞，课程组进一步统一了教学理念，明确了建设方向，细化了教学方案。与会教师纷纷表示，将认真吸收《工程伦理学》课程集体备课会内容，精心打磨每一堂课，努力将《工程伦理学》课程建设成为学生真心喜爱、终身受益的“金课”，为培养担当民族复兴大任的时代新人贡献智慧和力量。
