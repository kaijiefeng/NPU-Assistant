# 化学与化工学院赴党风廉政教育基地实践研学

为推动树立和践行正确政绩观学习教育走深走实，引导党员领导干部进一步筑牢廉洁自律思想防线。6月18日，化学与化工学院组织党委理论学习中心组成员、教工党支部书记赴陕西交通控股集团有限公司党风廉政教育基地，开展沉浸式廉政警示教育实践研学活动。
在讲解员的引导下，全体人员依次参观了“纪律立党 历久弥坚”“从严治党 一以贯之”“依规治党 守正创新”“殷鉴不远 警钟长鸣”“德润三秦 廉洁齐家”“清风交控 行稳致远”等主题展区及廉洁文化长廊。展馆通过图文展板、视频音效、情景演绎等多元载体，系统回顾了党的百年纪律建设历程，集中展示了全面从严治党取得的显著成效，并深度剖析了高校、国资、工程等领域违纪违规典型案例，以案释纪、以案明责。参观结束后，大家面向党旗重温入党誓词，铿锵誓言响彻展厅，既是对初心使命的重温与叩问，更是对廉洁从政、廉洁从教的郑重承诺。
此次参观学习进一步强化了全体人员的纪律意识和规矩意识，大家一致表示，将以优良作风汇聚奋进力量，将正确的政绩观转化为攻坚克难、干事创业的强大动力和实际成效，为推动学校和学院事业高质量发展提供坚强作风保障。
