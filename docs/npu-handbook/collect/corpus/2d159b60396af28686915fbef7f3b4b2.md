# 孔杰

孔杰
职务：JAC委员/西北工业大学党委常委、副校长
邮箱：kongjie@nwpu.edu.cn
个人简介链接：https://teacher.nwpu.edu.cn/kongjie.html
孔杰，男，教授、博士生导师，国家杰出青年科学基金获得者，洪堡学者，教育部新世纪优秀人才，陕西省“三秦学者”特聘教授及创新团队带头人，英国材料矿物与矿业学会会士，2021-2023“科睿唯安”全球高被引科学家。主要从事超支化高分子设计合成及在高温吸波材料、透波介电材料、陶瓷前驱体、能源材料中应用的研究工作；主持国家重点研发计划课题、国家重大科技专项专题、国家自然科学基金（6项）等国家级项目10项；以第一或通讯作者在Nat. Commun.、Adv. Funct. Mater.、Macromolecules等期刊发表论文150余篇，引用18000余次，H-Index为70+；已获授权发明专利30余件；获教育部技术发明奖二等奖（排名第1）、陕西省教学成果奖二等奖（排名第1）等省部级奖5项。
