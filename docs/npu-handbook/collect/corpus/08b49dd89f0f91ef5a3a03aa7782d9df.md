# 党委保卫部全力做好暑期校园安全保障工作

党委保卫部认真贯彻落实学校关于暑期安全工作的部署要求，紧密围绕平安校园建设重点任务，周密安排，狠抓落实。工作人员坚守岗位、履职尽责，全力维护暑期校园安全稳定，为新学期开学营造了良好的校园环境。
聚焦“有序”，全力应对暑期校园开放新考验
成立暑期安保工作专班，提前谋划、科学布控。校园开放期间，每天安排30名校卫队员在岗执勤，开展秩序维护、应急处突、咨询引导等工作；12名应急分队队员全天候待命，灵活响应，确保各项工作落实到位。针对排队拥堵、老幼帮扶等重点环节，推出三项保障措施：一是增派安保人员和志愿者，加强排队区域秩序维护，及时制止插队等不文明行为；二是在确保安全的前提下优化核验流程，增加核验通道，加快人员入校速度；三是加强对老人、儿童等群体的引导和帮助，做好现场安全提示，及时处置拥挤等安全隐患，确保校园整体运行平稳有序。
值得一提的是，今年首次允许访客车辆入校，这既是服务群众的新举措，也给停车管理和交通疏导带来新的挑战。党委保卫部反复研究，科学规划校内参观路线，划定专用停车区域，实行人车分流、进出分离的引导模式，并重点加强车辆分流引导，有效缓解了交通压力，让便民政策真正落到实处。
暑期长安校区累计接待访客超过25万人次、外来车辆4万余辆。面对访客量大、首次开放车辆入校等考验，校园开放运行平稳有序，服务群众工作扎实细致，圆满完成暑期校园开放保障任务。
聚焦“畅通”，动态优化施工区域交通管控
统筹做好暑期施工区域安全管控与交通保障。针对在建施工及应急抢修项目，主动对接施工单位，逐点位踏勘周边通行条件，按照“一项目一方案”原则制定专项交通疏解预案。根据施工时序实施临时封路管控，并提前通过校内各类渠道发布通行提示；对影响施工推进的占道车辆逐一通知车主并及时挪移，动态优化周边通行路线，在关键路口和施工区段设置临时引导标识，最大限度减少施工对日常通行的影响。
同时，全程跟进多个施工点位的交通保障，做好大型材料运输车辆的路线引导与错峰管控，确保物料安全有序进场。紧急抢修因暑期施工导致的安防监控离线线路230余路，确保重点区域监控全覆盖。
聚焦“安全”，切实提升隐患治理与应急水平
持续织密校园安全防护网，多措并举提升管理服务效能。严把出入关口，累计劝离非必要入校人员878人次、校外车辆607辆次，有效净化校园周边环境。大力整治交通乱象，开展专项治理行动，清理违停非机动车2546辆，纠正机动车违规停放875起，查处超速、鸣笛等不文明驾驶行为88起，校园通行秩序明显改善。倾力回应师生求助，高效处置师生及家属日常求助300余起，找回遗失物品46件，挽回经济损失5.68万余元；主动排查清除校园马蜂窝隐患9处，先后4次协助学生取回高空悬挂的飞机模型，以细致服务传递校园温度。积极应对极端天气，针对暑期强对流、短时暴雨频发的特点，迅速启动防汛应急响应机制，及时通报并协助后勤等相关部门处置内涝积水、树木倒伏等险情，同步做好危树清理、燃气及水暖管网抢修等施工区域的交通疏导与通行保障，全力守护师生生命财产安全。
聚焦“长效”，抓紧抓实安防基础设施更新
暑假前已完成长安校区访客预约系统与车辆道闸系统的升级改造，假期持续加强运行监管，确保两系统在校园开放高峰期间平稳高效运行，有力支撑了人员与车辆的有序通行。同时，充分利用假期施工黄金期，集中推进图书馆、光德苑、档案馆等消防系统建设改造项目，目前均已完工，进入收尾验收阶段。
在抓好基础建设的同时，日常安全管理不松懈。针对消防“双随机、一公开”检查发现的24项隐患，逐项落实整改；开展日常消防安全巡查检查142次，新发现并整改隐患17处。办理动火作业备案6份，作业期间均安排专人现场监护，确保施工安全万无一失。
开学前，党委保卫部坚守岗位不放松，开展校园安全隐患排查，完成新生报到保障任务，并持续为学生军训做好服务保障，以扎实的工作成效回应师生期待，为新学期开学营造安全、稳定、和谐的校园环境。
