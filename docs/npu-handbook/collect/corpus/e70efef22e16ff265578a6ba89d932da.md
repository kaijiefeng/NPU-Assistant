# 西北工业大学建校八十六周年暨第十二届校友周校友资料征集启事

亲爱的校友：
时光荏苒，岁月如歌，在时间的长河中，每一份回忆都闪耀着不朽的光芒！我们深知每位校友的足迹与成就都是母校宝贵的精神财富和历史见证。为了更加全面地记录学校的发展历程，传承那份深厚的文化底蕴与不朽精神，激励后来者，现面向广大校友征集各类珍贵资料。我们诚挚邀请您积极参与，与我们携手，共赴一场寻找记忆宝藏的奇幻之旅，共同为母校的记忆库添砖加瓦！
一、征集内容（包括但不限于）
【照片与影像资料】
1.在校期间学习、科研、实习、生活等各种场景照片、视频等；
2.在校期间参加联欢会、运动会、辩论赛等形成的照片、视频等；
3.在校期间参加国内外重大活动，包括社会活动、学术活动、重要比赛或评比等形成的照片、视频等；
4.反映学校不同时期风貌的校园建筑、校园风光的照片、视频等。
【实物与文献资料】
1.在校期间形成的有纪念意义的各种资料、实物、学习用品等，包括媒体报道、笔记、校徽、学生证、借书证、纪念章、毕业纪念册、师生间赠言题签等，或教材、论文手稿、论文集等；
2.集体或个人获得国家、省部级的各类表彰、奖励的资料、实物（获奖证书可提供电子版）等。
【口述资料】
通过录音或视频形式，记录校友对母校历史事件的回忆、对师长同窗的怀念以及对未来学弟学妹的寄语。
【其他资料】
能够反映学校发展历史的、有价值的其他资料。
二、参与方式
1.线上提交：欢迎您使用云盘、电子邮件等方式提交资料，云盘链接、文献资料、照片、视频等可发送至quyan211@nwpu.edu.cn，并请附上您的姓名、毕业年份及联系方式，以便我们更好地与您沟通。
2.邮寄实物：欢迎您使用EMS到付方式邮寄实物资料，并附上简要说明。邮寄地址：陕西省西安市碑林区张家村街道友谊西路127号西北工业大学档案馆，收件人：屈老师 029-88491657。
3.现场捐赠：欢迎您直接与我们面对面交流，分享您的故事与资料。

时间：10月19日上午9:00-16:00

三、温馨提示
1.您的慷慨捐赠是对母校深厚情感的体现，我们深感荣幸并备受鼓舞，为了向您表达最诚挚的谢意，请您扫码填写相关信息，方便我们发放文创产品并寄送捐赠证书以资纪念。
2.捐赠资料请注明时间、地点、事由、人物等，以便后期整理。如有任何问题，请及时与我们取得联系，联系人：屈老师 029-88491657。
亲爱的校友，您的每一份资料都如同珍贵的宝石，镶嵌在母校记忆的宝库中，熠熠生辉。您的每一份贡献都是对母校最深情的告白。让我们携手合作，共同守护这份美好的记忆，愿母校的明天更加辉煌灿烂！
