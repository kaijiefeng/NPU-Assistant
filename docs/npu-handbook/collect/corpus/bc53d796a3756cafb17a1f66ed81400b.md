# 以赛促学，以赛育人|国卓院“三航杯”创新大赛启动会顺利召开

为深入学习贯彻党的二十届四中全会精神，落实教育科技人才一体发展要求，扎实推进学校创新创业竞赛工作，国家卓越工程师学院于2026年1月13日14:30，在长安校区海天苑1号楼A座“一站式”学生社区举行“三航杯”创新大赛启动会。会议采用线上线下相结合的方式，学院师生齐聚一堂，共同拉开本届赛事的序幕，现场氛围热烈，秩序井然。
锚定目标，全力支持
学院党委副书记、副院长王谦作动员讲话。他紧密结合学校“一十百千”中期目标以及“天下工大、世界三航”远景目标，对学院创新创业工作提出明确方向与要求。他强调，要依托学院特色与优势，积极开展重点赛道项目申报，勇于“揭榜挂帅”，鼓励同学们聚焦国家战略需求，积极投身赛事实践。同时，他表示学院将充分发挥政策引导与资源保障作用，持续加大支持力度，为参赛团队提供全方位、全过程支撑。他寄语同学们把握机遇、敢于突破，在赛事中锻炼能力、成长成才，力争取得优异成绩。
系统解读，精准指导
学院团委书记、辅导员孙康瑶系统解读了本届“三航杯”的赛道设置、参赛条件、评审标准与赛程安排，通过分类阐释与要点梳理，帮助学生迅速把握各赛道内涵与侧重，为项目遴选与团队组建提供清晰指引。在备受关注的政策解读环节，立足学院特色围绕同学们普遍关注的赛事扶持政策、专项资金保障及奖项激励措施等核心内容，进行全面细致的解读，阐释了学院推进创新创业教育、支持学生参与赛事的系列保障措施，系统介绍了学院“制度保障、资源倾斜、全程服务”赛事支撑体系，让同学们充分感知学院对双创工作的重视。
榜样引领，经验传承
2025年“挑战杯”获奖学生代表于镇源结合自身备赛实践经验，从项目选题方向、团队组建策略、方案打磨技巧、答辩流程准备等关键维度，分享实操经验与心得感悟，重点阐述备赛过程中的难点突破路径。同时，在分享过程中，他特别感谢学院在备赛过程中给予的全方位支持。详实的案例分享与务实的经验总结引发与会学生强烈共鸣，现场记录认真、互动交流有序。
本次会议不仅系统解读赛事体系、深入阐释支持政策、生动分享实践经验，更在全院营造起崇尚创新、勇于实践、团结协作的浓厚氛围，为后续赛事有序开展筑牢坚实根基。学院将以此次会议为起点，持续优化资源配置，健全服务体系，强化对参赛团队的指导与支持。期待全体同学以此为契机，积极投身创新实践，在竞赛中锻炼成长，在挑战中追求卓越。
