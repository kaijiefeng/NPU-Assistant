# 我运动 我健康"——档案馆工会小组活动报道

为了调节身心健康，提高工作效率，增强全体馆员的健身意识和身体素质，营造“运动、健康、快乐、高效”的工作氛围，档案馆工会小组积极组织广大馆员参加由机关部门工会开展的健步走、工间操活动。
馆员们积极响应，每天主动打卡、晒步数，利用工作间歇开展健身活动，舒展身体，不亦乐乎。一个月来，大家的运动热情明显提高，运动已成为习惯，运动陶冶着身心。
通过健身活动，既丰富了馆员们的文化生活，又展示了当代档案馆工作者的精神风采。大家纷纷表示，一定要将健身活动坚持下去，凝心聚力，奋力谱写档案馆追赶超越新篇章。
（文/图 王晨冰 审核/戚红梅）
