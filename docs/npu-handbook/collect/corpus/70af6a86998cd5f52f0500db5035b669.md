# 后勤服务向导

## 一、餐饮服务指南

长安校区餐厅包括海天苑餐厅（一楼学生餐厅、每一天鲜食店，二楼自选餐厅、风味餐厅，三楼教工餐厅、民族餐厅）、云天苑餐厅（一楼学生五餐厅，二楼学生六餐厅）、星天苑南餐厅（一楼学府快餐、学子快餐，二楼正禾星苑美食一餐厅，三楼正禾星苑美食二餐厅）、星天苑北餐厅（一楼学生二餐厅，二楼学生三餐厅、民族餐厅，三楼西餐厅）。

友谊校区餐厅位于爱生楼：东南角一楼学生一餐厅（平价餐厅）、东南角二楼学生二餐厅（风味小吃、延时餐厅）、东北角一楼风味小吃城、西面一楼加工组（西工大包子、馒头花卷）、民族餐厅、幸福小厨；健翔楼南面一楼教工餐厅（可微信订餐、定点送餐，设自助区、智能结算）；西门口设西工大包子师生供应点。

备注：

1. 餐厅供应时间：早餐6:30—9:00，午餐11:00—13:00，晚餐17:00—19:00。
2. 后勤产业集团饮食服务中心电话：88492420（友谊校区）、88430306（长安校区）。
3. 部分餐厅设1元菜、0.6元鸡蛋、0.25元馒头、免费汤、平价快餐；云天苑学生六餐厅、星天苑南餐厅正禾星苑美食一、二餐厅设夜市（17:00—22:30）。

## 二、物业服务

物业服务中心隶属后勤产业集团，服务范围覆盖两校区校园环境卫生保洁、楼宇保洁、绿化养护、场馆及会务服务。学生公寓（长安校区）提供一站式服务：免费项目包括针线盒、蒸汽熨斗、微波炉热饭、报修、应急药品、打气筒、爱心雨伞、小五金工具出借；收费项目包括洗衣卡、自助售货机、洗衣洗鞋等。

办公地址：友谊校区（爱生楼）、长安校区（云天苑E座）；电话：（友谊）88493834、（长安）88430317。

## 三、动力服务

动力服务中心负责水、电、暖、土木及浴室地热系统的运行维护、维修与抢修。

水、电、暖报修及突发事件应急处置电话：友谊校区88491244，长安校区88430914。

水、电购买：友谊校区角楼一站式服务大厅（88494868），周一至周五8:00—19:00、周六日9:00—12:00；长安校区启真楼一站式事务大厅（88430297），周一至周五9:00—12:00、13:30—17:00。

## 四、一卡通服务

校园一卡通支持餐厅消费、超市消费、洗浴消费、图书借阅、医院门诊、体育场馆消费、校车乘坐、机房上机、公寓门禁、自助缴费（公寓电费、网费）、自助充值、自助挂失、自助查询等功能。

五种充值方式：

1. 支付宝自助充值：支付宝首页搜索校园一卡通，选择小程序，点击新卡充值，选择西安与西北工业大学，输入姓名学号和金额，同意协议并付款。
2. 翼支付自助充值：翼支付全部应用—校园卡—添加新卡充值，输入城市、学校、学号、姓名后充值。
3. 圈存机自助转账：校园卡绑定本人名下西安地区工商银行借记卡后，在圈存机自助转账。圈存机分布：友谊校区一站式服务大厅5台、研究生西馆一楼电梯南侧2台；长安校区一站式事务服务大厅1台、星天苑北餐厅一楼东侧2台、星天苑南餐厅大学生超市门口4台、校医院1台。
4. 自助现金存款机充值（限100元纸币）：友谊校区一站式服务大厅1台，长安校区一站式事务服务大厅1台。
5. 柜台现金充值：长安校区启真楼一楼一站式事务服务大厅（88430300），周一至周五9:00—12:00、13:30—17:00；友谊校区角楼一站式服务大厅（88495600），周一至周五8:00—19:00、周六日9:00—12:00。

目前一卡通POS机可直接刷微信和支付宝付款码消费。
