# 后勤集团召开全面从严治党工作会议暨警示教育会-后勤集团

为深入学习贯彻习近平总书记关于党的自我革命的重要思想，全面落实二十届中央纪委五次全会精神和学校全面从严治党工作部署，3月23日上午，后勤集团召开全面从严治党工作会议暨警示教育会。集团党政领导班子成员、各二级单位副主任（副部长）及以上人员、各党支部书记、职工代表参加会议。会议由集团总经理郑曦主持。
会上，集团党委副书记邱若娟传达学校2026年全面从严治党工作会议精神，对集团2026年党的建设重点工作进行全面部署。集团纪检员张永鑫通报了高校后勤领域违纪违法典型案例，开展警示教育。
集团党委书记侯亚涛在讲话中全面回顾集团2025年全面从严治党工作总体情况，深刻剖析当前集团全面从严治党工作形势与关键所在，指出干部员工教育引导、日常工作管理监督、廉政风险防控体系建设等方面的问题与不足，要求全体干部职工清醒认识反腐败斗争严峻形势，切实增强全面从严治党的政治自觉、思想自觉和行动自觉。
侯亚涛对2026年集团全面从严治党工作提出五点要求：一是深刻领悟习近平总书记重要讲话和中央纪委五次全会精神，准确把握“三个更加”重要要求，把思想和行动统一到党中央决策部署和学校党委工作要求上来。二是扛牢政治责任，强化以案促改抓治理，分层分类开展警示教育，压实全链条责任，狠抓整改闭环落实。三是健全防控体系，规范权力运行防风险，严格执行“三重一大”决策制度，规范选人用人全流程管理，健全利益冲突防范机制，从严规范合同与项目管理，常态化开展廉政风险排查。四是加强教育管理，筑牢思想防线促提升，强化廉洁从业教育，做实做细日常管理监督，厚植廉洁文化生态。五是强化标本兼治，深化系统施治提效能，提高政治站位压实责任，刀刃向内狠抓问题整改，健全长效机制实现标本兼治，强化督导问责确保整改实效。
郑曦就贯彻落实本次会议精神强调三点意见。一要提高认识、强化学习，各党支部要迅速传达学习会议精神，引导广大党员干部深刻领会新时代全面从严治党战略部署，切实把思想和行动统一到集团党委工作要求上来。二要压实责任、细化举措，各二级单位要落实“管业务必须强监管”要求，主要负责人履行第一责任人职责，班子成员落实“一岗双责”，结合实际制定整改方案，确保各项任务落地见效。三要保持定力、纵深推进，将全面从严治党与集团2026年重点工作深度融合，聚焦学校“一十百千”发展目标，把从严治党成效转化为推动集团高质量内涵式发展的强大动力，营造务实担当、清正廉洁的良好发展环境。（文/图：王景景；审核人：张永鑫、邱若娟）
