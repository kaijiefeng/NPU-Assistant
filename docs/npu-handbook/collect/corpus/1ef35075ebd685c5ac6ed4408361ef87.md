# 西北工业大学医院2026年度自聘非事业编制人员公开招聘结果公示-西北工业大学医院

结合我院业务发展需求，经公布招聘岗位、个人报名、资格审核、笔试、面试、用人单位考察、政审和体检等环节，确定郑书娟为拟聘用人选，现将结果予以公示（名单附后）。
公示时间：2026年10月29日至2026年11月6日。若对拟聘用人选有异议，可在公示期内通过口头或书面形式实名向医院办公室反映。反映情况要实事求是，以便调查核实。
联系电话：029-88493471
联系地址：医院办公室（西北工业大学友谊校区医院三楼北318室）
