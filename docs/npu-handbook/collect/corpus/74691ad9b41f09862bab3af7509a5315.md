# 【重要通知】西北工业大学全球人才招聘宣讲洽谈会即将启动（新加坡和香港站）

2023年4月14-21日，学校将由校领导带队，多学院、多学科组团，赴新加坡、香港开展专场人才招聘宣讲洽谈会。
春光正好，邀您共赴！诚邀优秀学者积极报名参会！

新加坡南洋理工大学专场

招聘领域
招聘学科领域包含工学（工程、材料、信息）、理学（数学、物理、化学、生物学、生态学）、医学、管理、人文社科，以及柔性电子、人工智能等新兴交叉学科。
招聘岗位
招聘岗位包含讲席教授、领军人才、优秀青年人才、准聘师资、博士后、专职科研人员等。详细岗位信息和薪酬待遇请点击原文查看（https://renshi.nwpu.edu.cn/zpgg202303.pdf）。
