# 我校图书馆赴哈尔滨和北京兄弟院校图书馆开展调研

3月12日至3月13日，图书馆馆长张盛兵、党总支书记孙华强、办公室主任郝天侠一行赴哈尔滨工业大学图书馆、哈尔滨工程大学图书馆、北京理工大学图书馆、北京航空航天大学图书馆专题调研了机构改革及馆员队伍建设、宣传文化工作、特色馆藏建设、研究型图书馆建设等工作。
3月12日上午，我校图书馆一行来到哈尔滨工业大学图书馆调研交流。哈尔滨工业大学图书馆党总支书记李景凯及相关部门负责同志参加了座谈交流。李景凯介绍了哈尔滨工业大学图书馆机构改革、三定一聘工作、文化建设、馆员队伍建设等相关情况。随后双方围绕调研主题开展了深入的探讨和交流。最后，图书馆一行参观了虚拟现实体验空间、全息激光影院、微课录播室等特色空间。
3月12日下午，图书馆一行赴哈尔滨工程大学图书馆调研交流。哈尔滨工程大学图书馆馆长许兆新、党总支书记刘文、副馆长姜述强及相关部室负责人参加了调研活动。许兆新全面介绍了哈尔滨工程大学图书馆各项工作的特色做法，双方就机构设置、队伍建设、党建业务融合发展、知识产权服务、特色馆藏资源建设、研究型图书馆建设等工作开展了深入全面交流。座谈会后，一行人员参观了哈尔滨工程大学图书馆主题阅读空间、特色研讨空间、中华传统文化教育教室等特色空间。
3月13日上午，我校图书馆调研组赴北京理工大学图书馆调研交流。调研组在北京理工大学图书馆馆长杨静馆长、党总支书记金军带领下参观了中关村图书馆红色传奇“创校元勋” 李强老院长革命历程展、科学家精神教育基地的“党的事业就是我的奋斗方向”科学家入党故事选粹主题展览。随后调研组与北京理工大学图书馆杨静、金军、副馆长崔宇红、副馆长姚文莉及相关部门负责同志围绕图书馆的机构设置、馆员队伍建设、知识产权服务、特色馆藏资源建设、研究型图书馆建设等工作开展了深入全面的座谈交流。
3月13日下午，图书馆一行赴北京航空航天大学图书馆调研交流。北京航空航天大学图书馆馆长杨超、党总支书记于金龙、副馆长秦小燕、副馆长侯毅及相关部门负责同志参加了座谈交流。杨超以发展中的北航图书馆为题介绍了北京航空航天大学图书馆人员编制、机构设置、文献资源建设、知识产权服务、特色资源建设的相关情况；于金龙介绍了图书馆党建融合业务、文献资源审核专项工作情况，随后双方围绕调研主题开展了热烈的讨论和交流。座谈会后，一行人参观了图书馆航空航天文献史料展、赵沁平院士书屋等特色阅览空间。
通过对哈尔滨工业大学图书馆、哈尔滨工程大学图书馆、北京理工大学图书馆、北京航空航天大学图书馆的调研，为建设世界一流大学研究型图书馆提供了宝贵经验，图书馆将认真学习借鉴工信部兄弟高校图书馆的先进经验和特色做法，充分利用图情优势服务学校重大科研项目和国家级科技成果培育，提供精细化个性化的学科服务，为学校人才培养和科技创新提供三航特色的文献信息资源支撑，“强特色、筑高峰”，不断提高图书馆服务能力和管理水平，为学校“127”发展目标贡献图书馆力量。
