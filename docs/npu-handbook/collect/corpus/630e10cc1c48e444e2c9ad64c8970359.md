# 【关工委工作】西工大关工委联合幼儿园开展校园科普实践活动

5月20日，正值幼儿园大班小朋友毕业在即，校关工委、联合幼儿园、军工素质教育实践中心、化学与化工学院等单位，举办校园科普实践活动。在老青师生志愿者的带领下，幼儿园小朋友走进西工大长安校区，先后参观了何尊广场、航空馆、停机坪、化学实验室及安全教育体验馆，开展了寓教于乐、触摸科技的生动实践活动。
“银发宣讲员”黄迪民老师为小朋友们讲述了何尊广场、铸剑勇士的故事。有孩子好奇地问：“为什么他把头埋在草地里？”“隐姓埋名、为国铸剑！”黄老师铿锵有力地回答，让孩子们懂得了西工大人默默奉献、扎根奋斗的精神力量。
在军工素质教育实践中心，学生志愿者为小朋友们讲解了运20“胖妞”的故事，这只“大胖鸟”会带着军用物资飞得更远更快，让中国空军首次拥有自主战略投送能力。停机坪承载着深厚的教育使命，这里不仅是教学实践基地，更是弘扬“总师育人文化”的重要平台。
航空博物馆馆内，丰富的展陈让小朋友们目不暇接。飞机结构、发动机、机载设备等珍贵实物以横截面、侧剖面的形式一一展出，精密的管线、复杂的齿轮、蜂巢状的复合材料层清晰地呈现在眼前，让孩子们第一次看清了“铁鸟”内部的奥秘，满足了好奇心，也激发了对科学和“三航”的热爱。
在化学实验室，“银发宣讲员”岳红老师和分子创客科普社团的学生带来了一场奇妙的溶解和变色实验：水从透明渐变为粉色、紫色、蓝色，孩子们目不转睛，见证了溶解、变色、沉淀如魔法般的变化。大型仪器设备共享平台的常宁辉老师演示了液氮实验，生动展示了液氮的超低温特性——荷叶浸入液氮几秒后脆化，孩子们恍然大悟，明亮的眼睛里写满了“原来这就是科学”。
在安全教育体验馆，小朋友们亲身感受八级地震的震感，学习了灾后环境中安全通行的方法；在消防火灾区，掌握了用湿毛巾捂住口鼻、弯腰低姿逃生的正确要领。在玩中学、在体验中记，孩子们不仅玩得开心，也把安全知识牢牢记在了心里。
通过此次科普体验活动，孩子们在参观与互动中开阔了视野、增长了见识，让科学的种子在孩子们心中生根发芽。今后，校关工委将继续发挥“五老”优势作用，依托学校特色阵地和平台，助力学生健康成长成才。
