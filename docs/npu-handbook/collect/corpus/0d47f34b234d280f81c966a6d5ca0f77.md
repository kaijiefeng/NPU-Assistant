# 计划财务部召开2027年校内预算编制工作布置会

为深入贯彻落实党中央、国务院关于深化零基预算改革的决策部署，全面落实“过紧日子”要求，进一步提升学校预算管理的科学化、精细化、规范化水平，10月9日下午，计划财务部组织召开2027年校内预算编制工作布置会。各单位分管预算工作的领导、办公室负责人及具体负责预算编报的工作人员共150余人参加会议。会议由计划财务部计划管理科科长呼瑞雪主持。
计划财务部部长李春林指出，预算编制是学校治理体系和治理能力现代化的基础环节，关乎学校财力资源统筹和事业发展规划落地，各单位须压实主体责任、树牢系统观念，重点抓好三方面工作：一是提高政治站位，把准财经工作方向。深入学习领会习近平总书记关于财经工作和教育工作的重要论述精神，推进零基预算改革，严格落实“过紧日子”要求，确保学校财经工作始终沿着正确的政治方向推进。二是强化责任落实，提升预算编报质量。各单位要将预算编制置于教育事业发展全局中统筹谋划，坚持“先谋事、后排钱”，扎实做好项目论证，加强支出标准建设和应用，将绩效管理深度嵌入预算编制、执行、监督的全流程，切实提高资金使用效益。三是坚持多措并举，强化资源统筹能力。各单位要主动作为，拓展多元增收渠道，同时厉行节约、精打细算，构建增收节支并举、绩效评价贯穿全过程的闭环管理机制，以高质量预算管理支撑学校高质量发展，更好地服务国家教育事业发展大局。
计划财务部副部长张鹏对《2027年校内预算编制工作方案》作专题辅导报告。他围绕国家零基预算改革的政策导向，介绍破除“基数依赖”、践行“先谋事、后排钱”理念对学校事业发展的核心价值；结合2027年校内预算编报全流程，详细解读关键节点、申报内容、申报方式、申报要求，强调要牢牢把握绩效导向，把有限资金用在刀刃上，全面提升预算编制的科学性、精准性。最后，他重点提示了预算编报中的常见问题、支出标准和绩效目标设置要求，为各单位高质量完成预算编报提供了清晰的操作指引。
此次预算编制工作布置会统一了全校预算工作思想、细化了编制标准、明确了工作时限，为2027年全校预算编制工作有序、规范、高效开展筑牢了基础。下一步，计划财务部将持续深化细化财务管理，常态开展政策宣讲和业务指导，稳步推动零基预算改革落实落地，不断优化校内资源配置，以高质量财务工作支撑学校各项事业高质量发展。
