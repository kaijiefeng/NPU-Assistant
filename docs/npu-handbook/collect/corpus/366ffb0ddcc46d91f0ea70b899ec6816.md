# 分析测试中心顺利通过ISO9001质量认证监督评审

5月23日，中国质量认证中心专家组对西北工业大学分析测试中心开展ISO9001质量管理体系监督评审。本次评审会议在学校友谊校区诚字楼104会议室召开，由评审专家李淑玉主持，中心副主任刘平及相关工作人员参会，并完成管理层专项会谈。
评审期间，专家组严格依据体系标准，通过查阅管理体系文件、核查台账资料、开展现场试验演示等方式，对中心人员监督、能力监控、方法验证、计量溯源、结果报告等关键工作进行全面细致核查。
末次评审会上，专家组充分肯定中心质量管理成效，认定各项工作持续契合实验室认证规范标准，本次监督评审圆满结束。中心将以此次评审为契机，不断优化完善质量管理体系，切实赋能学校双一流建设，依托专业技术与优良服务，提供科学、准确、高效、创新的测试保障。(文：陈建源 审：刘平)
