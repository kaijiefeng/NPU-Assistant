# 关于推荐北京市自然科学基金评审专家的通知-西北工业大学

各学院、科研团队：
为深入贯彻习近平总书记关于基础研究的重要讲话精神，完善基础研究项目的组织、申报、评审和决策机制，实施差异化管理和国内外同行评议，加快建设具有中国特色、世界一流的优势学科，北京市自然科学基金委员会办公室面向学校邀请符合条件的教师加入北京市自然科学基金评审专家库，参与北京市自然科学基金项目评审工作。具体条件要求如下：
（一）具有良好的科学道德和职业道德，科技工作中无不良记录，能够认真、公正地履行职责。
（二）熟悉相关领域的研究发展状况及有关法律、法规及政策，了解科技活动的特点与规律。
（三）具有高级专业技术职务（职称）。
（四）身体健康，具备时间和精力完成评审等工作，年龄原则上不超过60周岁（中国科学院院士、中国工程院院士可放宽到70周岁），鼓励优秀青年积极参与。
（五）作为项目（课题）负责人承担过国家或省部级科技项目/课题，或是国家或省部级科技奖获奖人，或是国家或省部级科技人才称号获得者，或是在主要国际学术组织中担任职务，或是国际标准起草人。
（六）无不良科技信用记录，无学术不端行为，无不良社会信用记录，无违法犯罪记录。
特别注意：
1.征集信息采用电子文档形式（Excel），由专家本人填写《北京市自然科学基金评审专家信息表》（附件 1），并发送至邮箱fuxu@nwpu.edu.cn，填报时间截止2025年6月10日。
2.填写的熟悉学科代码采用北京市自然科学基金2025年第一版学科代码（附件2），如研究领域包含完整一级学科代码领域可填写至一级学科代码，除此以外请填写至二级学科代码。
3.新专家待正式入库后会分配对应账号，后续专家信息更新和 项目评审将采取邮件短信通知方式进行，请务必填写准确的手机 和邮箱信息。
