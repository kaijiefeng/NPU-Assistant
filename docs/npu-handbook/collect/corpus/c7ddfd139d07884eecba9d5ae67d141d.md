# 莫航学子在“新生杯”足球赛、篮球赛中荣获佳绩

近日，西北工业大学“新生杯”足球赛与篮球赛相继圆满落幕。莫航学院运动健儿双线出击、连战连捷，在两项赛事中均斩获亚军佳绩。赛场上，莫航学子与兄弟学院代表队同场竞技、以赛会友，用汗水与拼搏书写了亮丽的青春答卷。
足球篇：绿茵会友，同心同行
“新生杯”足球赛小组赛阶段，队员们迅速进入状态，敢打敢拼、配合流畅，小组赛三场全胜，累计打入12粒进球、仅失3球，以小组第一的优异成绩强势出线。进入淘汰赛，球员们持续稳定发挥，以5:2战胜对手；半决赛中，队员们攻防均衡、团结协作，以5:0大胜对手，晋级决赛。
决赛中，莫航学院与玛丽女王工程学院绿茵会师。比赛开始后，双方迅速进入竞技节奏，攻防转换节奏明快，场上对抗紧张激烈，场边助威声此起彼伏。莫航队员全力以赴、每球必争，在落后时奋力追赶，在拼抢中毫不退缩。球队一路稳扎稳打、团结拼搏，最终斩获亚军，创下学院足球队组建以来的最佳战绩。
篮球篇：六战淬火，战至终章
第八届“新生杯”篮球赛中，莫航学院队与对手精彩对垒。从小组赛到决赛，六场较量，一场未弃、每球必争。小组赛中，球队先后以52:32、51:27、69:23的比分取胜，顺利挺进淘汰赛。淘汰赛中，球队稳守优势，以47:27晋级；半决赛中，全体队员凝心聚力、顶住压力，以36:21成功挺进决赛。
决赛对阵玛丽女王工程学院，双方开局即陷入激烈拉锯战，首节比赛分数交替领先，下半场对手接连命中三分、打出快攻，令比赛悬念迭起。终场哨响，莫航学院获得本届“新生杯”篮球赛事亚军。赛后，两队队员在中圈握手致意、相拥合影，将竞技的汗水化为兄弟学院之间深厚的情谊。
绿茵逐梦，青春当燃；以球会友，携手同行。在本次“新生杯”足球、篮球系列赛事中，莫航学院新生尽显昂扬风采、赛出实力水平，与兄弟学院的青年学子以运动激扬青春，以友谊联结你我，继续怀揣热爱、奋勇前行！
