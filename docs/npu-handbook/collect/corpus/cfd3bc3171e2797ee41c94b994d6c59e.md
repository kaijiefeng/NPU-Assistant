# 外国语学院“语说中国”第二季——“语说大国重器”活动启动仪式暨专题报告会成功举办

9月25日，外国语学院在学院楼204会议室举办了“语说大国重器”启动仪式暨专题报告会，特邀我校航天学院马志强教授做专题报告。院党委领导班子、教工党支部书记、指导教师、学工主管、学生预备党员参加了会议。会议由院党委书记王高祖主持。
王高祖指出，“语说中国”每期选题都会紧跟时代步伐，与国家、与学校的建设发展同频共振，与师生的需求合拍共鸣。为纪念中国人民抗日战争暨世界反法西斯战争胜利80周年，弘扬伟大抗战精神，以九三阅兵为新的历史起点，不断从党的光辉历史和科技强军的伟大成就中汲取智慧力量，按照学校党委关于“总师型”人才培养的要求，结合我们的学科专业特色，精心策划本次“语说大国重器”活动。
随后，马志强教授以“在轨服务遥操作技术进展及展望”为题，从大国重器入手，引导师生了解了我国在轨服务技术的战略定位和发展背景，通过动画演示与数据，直观呈现了遥操作技术在针对复杂、动态场景帮助人类实现感知和行为向远端的精准延伸和高效交互,清晰展现了我国在轨服务遥操作技术“从无到有、从有到优”的跨越式发展历程。讲座中，他还结合国内外前沿案例介绍了遥操作技术的研究现状、研究进展及未来展望。
王高祖对马志强教授表示衷心感谢，他指出，报告深入浅出,空间在轨遥操作技术体现了我国在航天领域的硬实力，也是我校航天人赓续创新基因、勇攀科技高峰的生动写照，对师生精准把握“大国重器”之“重”，用外语讲好大国重器背后的创新故事、科技精神提供了精彩的专业指引与思路启发。他强调，我们外语专业的学生一定要打上“三航”烙印，既要扎实筑牢语言功底，更要主动学习了解“三航”领域的知识和前沿动态，努力成长为精语言、懂科技、有情怀、矢志报国的复合型外语人才！（文/王开薇；审稿/王高祖）
