# 山西大学尤洋教授来学院作学术报告-西北工业大学

11月9日上午，山西大学尤洋教授应邀来到西北工业大学马克思主义学院，为学院师生带来主题为《人工智能与语言意义理解》的学术报告。报告会由马克思主义学院副院长张云龙主持，吴小安教授、吕天择副教授与会进行交流。
尤洋教授本次报告的内容分为三部分，分别是人类“心灵奠基”与语言意义的生成建构、AI的“符号接地”困境及其功能性理解的根本局限、人工智能走向意义理解的具身与关联路径。尤洋教授以梅洛-庞蒂具身认知理论与哈纳德“符号接地问题”为理论线索，一方面阐释了人类语言意义根植于身体经验、主动探索与社会互动相统一的“心灵奠基”机制，另一方面提出突破符号接地困境的关键在于以具身与关联的方式复刻人类心灵奠基的实践路径，在具身经验的网络中理解意义的本质。
尤洋教授与学院师生继续就人工智能能否真正理解语言意义、具身智能的技术可行性与哲学边界、马克思主义理论学科如何回应人工智能带来的认知变革等问题进行了深入交流，鼓励在座学生加强哲学与认知科学、神经科学等前沿科学的交叉学习，持续推动人工智能哲学与马克思主义理论学科的创新发展。
主讲人简介：尤洋，二级教授、博士生导师。国务院学位委员会哲学学科评议组成员，教育部高等院校哲学类专业教指委委员，国家高层次人才特殊支持计划哲学社会科学领军人才，教育部马工程教材及中国原创性哲学社会科学教材审核专家，国家级一流本科课程负责人。国家社科基金规划办、国家留学基金委评审专家，《自然辩证法研究》《人大复印报刊资料·科学技术哲学》编委会委员。获第十届教育部科学研究优秀成果奖（人文社会科学）二等奖，在《中国社会科学》（中英文版）《学术月刊》等期刊发表学术论文50余篇。兼任中国自然辩证法研究会生物哲学专委会、科学技术与公共政策专委会、教育与普及工作专委会副主任委员。
