# 经信委科技处带队调研国家超高清视频创新中心

11月13日，重庆市经济和信息化委员会科技处处长黄剑伟率重庆三航研究院、重庆机电集团、西工大重庆科创中心一行赴国家超高清视频创新中心（以下简称“国创中心”）参观考察，重点交流国家制造业创新中心在平台建设、技术攻关、成果转化及运营模式等方面的经验做法。四川省经济和信息化厅技术创新处处长高薇陪同调研，国创中心副主任宋小民、副主任杨俊及相关部门人员进行了热情接待。
调研组首先参观了国创中心成果展示及培训基地，详细了解了国创中心总体建设情况，包括共性技术研发、测试验证、中试孵化及行业支撑服务四大能力平台的建设成效，听取了国创中心在超高清视频产业链关键技术创新、成果转化、行业应用及产业赋能方面的成果和经验介绍。
随后，调研组考察了国创中心两大公共服务平台。在全国首个超高清视频领域具备 “双C” 检测认证资质的检验检测平台，调研组参观了光学性能检测、图像主/客观性能检测、应用场景仿真等专业实验室，并了解了测试验证服务体系建设情况。之后，调研组又实地考察了可实现超高清技术产品生产工艺验证、小批量试制、工艺熟化的中试产线，并就其工艺创新、运行机制等进行了交流。
参观结束后，调研组与国创中心管理团队召开座谈会，围绕创新中心申报、体系建设及市场化运营等实践经验展开了深入沟通和交流。调研组高度肯定了国创中心的创新实践和建设成效，认为中心在平台组建、能力平台建设、运营发展等方面的经验，对重庆建设高能级平台具有重要借鉴意义。
双方表示，未来将在创新资源整合、产业链协同、区域合作等方面建立常态化沟通机制，携手推动成渝两地制造业高质量发展。
