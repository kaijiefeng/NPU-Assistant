# 健康护航 急救同行-西北工业大学医院

10月24日晚，校医院门诊部党支部与无人系统技术研究院在友谊校区西馆开展“过敏性鼻炎科普及急救技能培训”活动，无人系统技术研究院约140名师生参加此次活动。
无人系统技术研究院责任医师王晓燕，向师生们系统讲解了过敏性鼻炎这一秋冬季常见疾病。重点强调疾病发生的原因和防护措施，并特别提醒，校园草木多，换季时需格外注意防范过敏原。急诊科医师梁乐乐以“关爱生命 守护健康”为题，围绕心肺复苏术、自动体外除颤仪（AED）的使用方法进行了理论讲解，还结合真实案例，深刻阐述了第一时间实施有效急救的重要性。此外，医务人员在现场同步演示了心肺复苏标准流程与AED使用方法，从动作规范到原理剖析，层层递进，帮助师生扫清认知盲区。
实践环节，在医务人员的指导下，同学们纷纷上前，认真练习心肺复苏的操作手法与节奏，学习使用AED。培训现场气氛热烈，师生们体验着急救操作的每一步细节，深刻认识到“黄金4分钟”的重要性。大家表示，实操练习不仅让自己能更准确把握急救动作细节，也进一步增强了学习急救技能的信心。
活动最后，无人系统技术研究院党委副书记徐晓峰在总结讲话中，首先对校医院门诊党支部送医到学院的贴心服务表示感谢。他指出，此次培训让师生通过讲座深入了解过敏性鼻炎疾病特点及处置，初步掌握AED等急救设备使用技能，有效提升了师生对校园常见突发病症的急救能力；同时强调，普及社会急救技能具有紧迫性与重大意义。他提到，无人系统技术研究院的同学作为西工大优秀学子，不仅要在课堂上学好理论知识，更要在实践中锤炼为人民服务的本领。只有在实践中不断巩固，才能真正将急救技能内化于心、外化于行。
门诊党支部将继续充分发挥所辖科室专科优势，精准对接师生健康需求，提供定制化健康科普与服务，为师生健康筑牢坚实屏障。
