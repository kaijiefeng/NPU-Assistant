# 自动化学院召开2023年新认定研究生导师岗前谈话会

为全面落实研究生导师立德树人职责，打造一支有理想信念、有道德情操、有扎实学识、有仁爱之心的导师队伍，按照学校研究生院的总体工作安排，自动化学院于10月19日上午召开了2023年新认定研究生导师岗前谈话会。院长韩军伟、党委副书记（主持工作）李伟林、副院长许斌以及2023年新认定的6位博士生导师、3位硕士生导师参加了会议。会议由许斌主持。
会上，许斌带领各位新导师认真学习了《西北工业大学研究生导师岗前谈话工作办法》，并对研究生学籍规定、招生指标分配、培养过程管理、学位成果要求等文件内容进行了简要介绍。他要求各位导师严格遵守学校和学院有关研究生教育的政策和规章制度，强化业务能力，持续构建良好的导学关系。
李伟林强调，导师是研究生培养的第一责任人，担负着教书和育人两大基本职责，对研究生的思想政治教育负有首要责任。各位导师在培养过程中，要心怀责任心和使命感，以德施教，全面关心学生的成长成才，对研究生日常学习、生活、就业等方面遇到的困难和问题，要及时给予关心和帮助。
韩军伟为新任导师讲授《坚持立德树人，严格落实导师责任制》主题党课并提出三点要求。一是要履职尽责，坚守责任担当，确保足够的时间和精力及时给予研究生启发和指导，以德育人、以文化人；二是要培养研究生严谨认真的治学态度和求真务实的科学精神，强化学术规范训练，提升学术道德涵养，杜绝学术不端行为；三是要助力学生树立远大目标，志存高远方能登高望远，以促进学生成长成才为出发点，因材施教，探索特色的培养模式。
后续，学院将进一步加强导师管理，积极听取导师意见，搭建畅通的学习交流平台和经验分享平台，为培养“总师型”人才贡献积极力量。
会议最后，新认定导师签署了岗位责任书并合影留念。
