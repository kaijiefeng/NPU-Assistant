# 分析测试在“1→0”重大工程科学问题研究中的推动作用研讨会 成功举办

为贯彻落实“十五五”规划，服务“一十百千”目标，扎实推进“0→1”和“1→0”双向发力，分析测试中心积极思考分析测试在“1→0”工程问题溯源中的重要作用。10月24日，分析测试中心在友谊校区国际会议中心第一会议室，召开分析测试在“1→0”重大工程科学问题研究中的推动作用研讨会。中国航发西安动力控制科技有限公司总冶金师尚高峰一行、西安航天复合材料研究所研究员翟虹、陕西省分析测试协会失效分析专业委员会秘书长杨健、西安交通大学教授孟令杰、西北大学化学与材料科学学院教授崔斌、中航西安飞机工业集团股份有限公司主管师张锰、北京优材百慕航空器材有限公司西安分公司副总经理郭凌云一行，以及校内外专家学者、师生等70余名参加了此次研讨会。
分析测试中心主任刘峰对参会的专家学者表示热烈欢迎，并做开幕致辞。他介绍了西北工业大学“1→0”重大工程科学问题的背景、内涵和意义，并指出，分析测试在“1→0”回溯性基础研究中起着不可或缺的作用，希望以此次研讨会为契机，共同聚焦分析测试技术开发与创新应用，加强西工大与同行、研究院所的合作，让分析测试成为解决重大工程科学问题的“新引擎”，为服务国家重大战略需求贡献分析测试力量！最后，他对本次研讨会的举办再次表示祝贺。
中国航发西安动力控制科技有限公司总冶金师尚高峰、西安航天复合材料研究所研究员翟虹、陕西省分析测试协会失效分析专业委员会秘书长杨健、西安交通大学孟令杰在研讨会上进行了精彩的学术报告交流。
报告会场，众多师生慕名而来，与各位专家现场进行深入交流沟通，参会的各位学者及师生均收获颇丰。
学术报告交流之后，与会的总师、专家、教授学者等开展了进一步深入座谈。大家积极发言，畅谈了自己对“1→0”研究的认识、思考，在重大工程实践中遇到的基础科学问题，以及对分析测试技术的需求和发展期待，并提出了诸多宝贵的意见和建议。与会人员展开了热烈的讨论与对接。
此次大会的顺利召开，搭建了分析测试中心与企业、科研院所以及学院教师间高水平交流合作的桥梁，促进了分析测试和工程实践的紧密结合。分析测试中心将以此次研讨会为契机，持续推动“0→1”和“1→0”双向发力，为服务学校“一十百千”目标和“天下工大，世界三航”远景目标贡献力量。（文：陈敏 编辑：王嘉玮 审核：刘平）
