# 力学与土木建筑学院青年教师发展论坛—学术沙龙第一讲暨国家自然科学基金动员讲座&第二讲暨国家重点研发计划申报动员会

2022年11月23日上午，力学与土木建筑学院青年教师发展论坛——学术沙龙第一讲暨国家自然科学基金动员辅导会，在学院206会议室召开。本次青年教师发展中心邀请邓子辰教授，针对国家自然科学基金申报，结合自身体会和多年思考，从学科申请现状、人才项目要点、申请书撰写技巧等方面分享了申报经验，学院近30位青年教师参加了讲座。会上，青年教师积极发言，提出了各自在国家自然科学基金申报中的问题，与邓子辰教授进行了充分交流。
接下来，路宽副教授结合自身经验，针对国家重点研发计划项目申报，从项目背景、组织实施、重点专项、申报流程等方面进行了分享交流。
学院青年教师发展中心致力于青年教师综合能力提升，将积极组织开展各项学术交流与培训活动，为培养学院持续发展的后备力量打下基础。
