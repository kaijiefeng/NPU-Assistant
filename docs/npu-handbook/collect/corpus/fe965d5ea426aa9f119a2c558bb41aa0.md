# 袁家军：唱好新时代西部“双城记” 引领“十五五”现代化新重庆建设迈出新步伐

1月4日上午，重庆市召开提升成渝地区双城经济圈发展能级推进大会。记者 苏思 摄/视觉重庆
袁家军在重庆市提升成渝地区双城经济圈发展能级推进大会上强调
唱好新时代西部“双城记”
引领“十五五”现代化新重庆建设迈出新步伐
1月4日是新年首个工作日，重庆市召开提升成渝地区双城经济圈发展能级推进大会。市委书记袁家军出席会议并讲话。他强调，要深入贯彻党的二十大和二十届历次全会精神，深化落实习近平总书记视察重庆重要讲话重要指示精神，主动适应国家优化区域经济布局新形势新要求，构建提升双城经济圈发展能级的“四梁八柱”，迭代升级“十项行动”，扎实推动“两中心两地”战略定位和“三中心一走廊”部署要求落地见效，唱好新时代西部“双城记”，引领“十五五”现代化新重庆建设迈出新步伐。
市人大常委会主任王炯，市政协主席程丽华，市委副书记、常务副市长陈新武，市委常委，市级领导同志出席。
会议听取成渝地区双城经济圈建设进展及发展能级提升“十项行动”工作汇报，市经济信息委、市科技局、市委金融办、市文化旅游委、市商务委、市大数据发展局、两江新区、永川区负责人作了发言。
袁家军在讲话中指出，党的二十大以来，全市上下牢固树立“一盘棋”思想和一体化发展理念，紧扣“两中心两地”战略定位和“三中心一走廊”部署要求，谋划实施成渝地区双城经济圈建设“十项行动”，扎实推动重庆都市圈发展能级和竞争力显著提升，现代化产业体系向新攀高，现代化基础设施体系加快构建，“416”科技创新布局牵引市域创新体系效能整体提升，西部金融中心建设全面赋能区域高质量发展，巴蜀文化旅游走廊建设加快成势见效，改革开放新高地建设综合集成效应持续彰显，高品质生活宜居地建设质效更加可感可及，双城经济圈引领西部、服务全国的能力和贡献度明显增强。今年是“十五五”开局之年，也是提升成渝地区双城经济圈发展能级起步之年，要深入学习贯彻党的二十届四中全会精神，全面落实中央经济工作会议部署，坚持全市域融入、全方位推进，充分释放发展潜力，迭代升级“十项行动”，乘势而上开创提升双城经济圈发展能级新局面。
袁家军强调——
●要加快构建极核引领、全域融入成渝地区双城经济
●要推动现代化产业体系跨越提升，聚力打造智能网联新能源汽车、软件信息服务、食品及农产品加工万亿级产业集群，加快建设承接东部沿海地区产业转移示范区，推动新兴产业和未来产业规模发展，深化共建生产性服务业集聚区。圈建设新格局，建强现代化主城都市区，深化渝西地区一体化高质量发展，激发各区县优势潜能，更好促进资源共享、优势互补。
●要增强创新策源和集聚转化功能，优化科技创新走廊体系，强化产学研用协同攻关，打造全国重要产业创新策源地，加快建设全球科技创新网络重要节点。
●要深入实施重点领域和关键环节集成式改革，加快推进区域市场一体化，持续提升市场主体竞争力，进一步深化经济区与行政区适度分离改革。
●要提升链接欧亚大陆经济走廊的战略枢纽服务效能，提质构建现代化集疏运体系和综合服务体系，聚力打造枢纽经济区，高水平建设中西部国际交往中心。
●要推进AI赋能超大城市发展服务安全治理现代化，构建高能级城市数字底座，实施城市智能中枢能力提升行动，推进“数字重庆”“智慧蓉城”贯通联动，加快打造人工智能应用高地。
●要放大西部金融中心集聚辐射效应，做强现代金融业集群，迭代升级“智融惠畅”工程，大力推进金融改革创新，持续提升立足西部、面向东南亚的内陆金融服务效能。
●要推动巴蜀文化旅游走廊建设取得更大成果，打造长江文明巴蜀文化金名片，做靓“雄奇山水 新韵重庆”文旅品牌，构建国际化旅游旗舰产品集群，打造富有巴蜀特色的国际消费目的地。
●要提升基础设施互联互通水平，拓展完善现代综合立体交通网络，构建高效协同的水网和新型能源体系，加快布局高能融合的新型基础设施。
●要高标准打造高品质生活服务圈，推动区域教育、医疗、养老等优质资源均衡共享，联合打造“川渝通办”集成服务矩阵，持续提升市域生态环境保护质量，放大美丽中国先行区建设示范效应。
袁家军强调，要强化川渝统筹协调，健全双核联动联建机制，突出多点发力、全域协同，加强向上沟通对接，进一步凝聚工作合力，全力推动成渝地区双城经济圈建设取得更大突破。
会议以视频方式召开。市委各部委、市级国家机关各部门，有关人民团体、市属事业单位、部分中央在渝单位、市属重点国有企业、中央和外地在渝大型企业、有关科研机构负责人，民营企业代表等在主会场参会。各区县，重庆高新区、万盛经开区设分会场。
（来源：重庆日报）
