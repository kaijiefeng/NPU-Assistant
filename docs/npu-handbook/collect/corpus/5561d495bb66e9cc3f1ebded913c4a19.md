# 航海学院召开“总师育人文化” 走深走实专题研讨会

为深入贯彻落实学校第十四次党代会精神，推动“总师育人文化”走深走实，11月6日上午，航海学院召开推动“总师育人文化”走深走实专题研讨会。705研究所某系统总师樊书宏，陕西千山航空电子有限公司某系统总师贾宁，航海学院院长潘光、党委书记刘朝亚、副书记王银涛、副院长雷波、教学部主任、教学秘书、学工主管和师生代表参加了会议。会议由王银涛主持。
潘光对樊书宏和贾宁的到来表示热烈欢迎，并希望他们能够以院友和企业代表的身份，协助学院深入推动“总师育人文化”走深走实。
雷波传达了学校第十四次党代会精神，以及“总师育人文化”引领人才培养的相关情况，并作《校-企-军协同育人，推动“总师育人文化”走深走实》主题报告，从“学院基本情况、本科专业介绍、特色做法成效、下一步举措”四个部分介绍了学院“总师育人文化”引领人才培养的思路。
樊书宏深情回顾了自己在航海学院本科阶段的求学经历，他表示，这段宝贵的时光不仅为他奠定了坚实的学术基础，更为日后的职业生涯提供了巨大的帮助。提及在青岛的实习经历，樊书宏深刻体会到了实践对于理论知识的重要性。他谈到，学生们应当充分利用业余时间，广泛学习并掌握多种技能。学校所培养的具备“专业精、系统强、重实践、能担当”的“总师”雏形特质，不仅使他在机械领域有所建树，还让他对信息、动力等相关领域有了全面的了解。
贾宁表示，学会“如何思考问题、如何解决问题”是学生时期需要培养的重要能力。她鼓励大家秉持“干一行、爱一行”的态度，全心全意地投入并热爱自己的工作。在工程实践中，她深切体会到理论与实践相结合的重要性，主动钻研知识、积极寻求解决方案，才能在实践中快速成长。此外，她还着重提到了创新意识的重要性，鼓励同学们保持低调务实、兼收并蓄的态度，从而厚积薄发，为国铸剑。
与会教师围绕“总师育人文化”这一主题展开了热烈的讨论，结合自身教学、科研工作以及在人才培养方面的思考，提出了宝贵的意见和建议。刘朝亚在发言时谈到，时代的变化与学生多元化需求为人才培养带来新挑战，要求教师不断创新教学内容和方法。学校第十四次党代会明确了培养“家国情怀、追求卓越、引领未来的领军人才”的方向和目标，航海学院应探索符合自身特色的路径，打造具有航海特色的人才培养体系。潘光指出，实践实训在人才培养中至关重要，能增强专业情感，明确职业方向。因此，培养方案改革需注重实践实训的深度与实效，确保学生获得真正的成长和提升。研究生阶段应参与到重要的科研项目当中，不断提高实践能力和科研素养。学生代表就学习、科研、就业等问题与老师们进行了深入的交流与探讨，纷纷表示受益匪浅。
