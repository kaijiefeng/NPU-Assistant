# 西北工业大学关于招生咨询和考生申诉渠道的说明（2025版）

报考西北工业大学的考生可通过下列渠道咨询我校本科招生相关信息：
方法一：拨打招生咨询热线。考生可通过拨打029-88460206电话咨询，我校开通15部云呼平台，可同时接听考生和家长的咨询。
方法二：电子邮箱咨询。[已脱敏:邮箱]。
方法三：微信公众号咨询。考生可关注“西工大招办”微信公众号，在对话框中进行咨询。
2025年新生复查工作严格按照教育部要求进行，复查期间未收到举报投诉。
考生如对招生过程中任何环节有异议，可通过拨打029-88460206进行查询和申诉。
