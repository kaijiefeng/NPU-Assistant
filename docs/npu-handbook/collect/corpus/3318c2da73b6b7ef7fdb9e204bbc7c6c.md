# 电子信息学院选调生校友返校宣介交流会成功举办

11月14日下午，电子信息学院“基层选调生校友”返校交流活动于学院楼159会议室成功举办。本次活动由学院团委书记、2025级本科辅导员史越主持，特别邀请了何明遥、何飞龙两位校友为全院学生传授宝贵上岸经验，介绍所在地市选调生政策、咨询答疑、职业发展等焦点问题。

活动伊始，史越介绍参会人员，代表学校聘任何明遥、何飞龙为西北工业大学校外职场导师，并赠送纪念品。在随后的校友发言中，何明遥以“扎根北疆沃土，践行工大精神”为题从三个方面与大家进行交流分享，从母校理论课程的系统学习、工程实践的深入参与，到科技一线，掌握各级科技政策，持续提升创新意识和业务工作能力，再到扎根基层乡镇，走向广袤田野，和村干部一同入户，讲政策、听意见、找办法、解难题。她始终铭记母校“公诚勇毅，三实一新”的校训，勇担责任、砥砺前行，向下扎根、向上生长，用奋斗诠释初心，努力交出一份属于西工大人的时代答卷。何飞龙则从具体选调生问题出发，以自身见闻出发，更加具体地回答同学们所遇到的问题。

在互动交流环节中，何明遥、何飞龙两位校友对现场到达的同学们在报考选调生过程中遇到的疑惑进行了回答，何飞龙校友着重介绍了贵州省选调的各种优势，鼓励同学们报考。史越强调电子信息学院研究生三月毕业，时间紧张，如选择选调生考试需要提前准备，关注学校就业信息网。

会后，全体与会人员进行合影留念。本次交流会积极响应国家号召，引导学院青年学子将个人理想融入国家发展大局，着力提升学院学子基层就业的意识与实践能力，鼓励广大有志青年奔赴祖国最需要的地方建功立业。

**校友简介**：何明遥，电子信息学院2021届电子信息工程专业本科毕业生，于2021年考录内蒙古自治区定向选调生，现就职于包头市科学技术局，现任规划与重大任务科副科长，负责牵头拟订全市创新驱动发展战略、编制全市科技计划并建立统一的科技项目管理平台。何飞龙，电子信息学院2020级通信工程专业本科毕业生，2024年通过贵州省定向选调到贵州现代物流集团，目前在总部负责数据分析相关工作。
