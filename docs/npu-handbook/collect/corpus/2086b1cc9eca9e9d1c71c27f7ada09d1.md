# 西北工业大学关于考生个人录取信息查询渠道和办法

西北工业大学关于考生个人录取信息查询
渠道和办法的说明
西北工业大学本科招生录取信息根据各省级招委会投档时
间安排并结合我校工作实际，及时向考生公布。凡报考我校的考
生可通过下列两种方法查询个人录取信息。
方法一：通过西北工业大学本科招生信息网查询。考生登录
我校本科招生信息网（http://zsb.nwpu.edu.cn/），点击首页的
录取查询进入查询系统，通过考生本人的考生号和身份证号进行
查询。
方法二：通过西工大招办微信公众号查询。考生关注“西工
大招办”微信公众号，在对话菜单中选择录取查询，通过考生本
人的考生号和身份证号查询个人录取信息。
