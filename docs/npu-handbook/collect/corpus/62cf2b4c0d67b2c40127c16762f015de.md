# 【成果转化】专利权转让现金收益分配公示

各部门：
为落实科技部、财政部、税务总局《关于科技人员取得职务科技成果转化现金奖励有关个人所得税政策的通知》(财税(2018)58号)及《关于科技人员取得职务科技成果转化现金奖励信息公示办法的通知》(国科发政(2018)103号)，现将西北工业大学研究院ZL 201820376376.6等4项专利转让权现金收益分配情况公示如下：
一、转让专利信息
●专利号：ZL 201820376376.6；
专利名称：医用永磁体治疗装置；
●专利号：ZL 201920978862.X
专利名称：一种磁疗装置
●专利号：ZL 202030008120.2
专利名称：按摩垫（磁疗保健A款）
●专利号：ZL201920981381.4
专利名称：一种培养装置
二、技术合同登记信息
该合同已在深圳市科技创新局完成技术合同认定登记备案。登记号为4403012025003630。
三、收益及分配信息
1.上述4项专利收益为人民币400000元，于2025年04月10日收到合同款400000元，其中现金奖励金额总计320000元；
2.奖励成果完成人魏云鹏32000元，商澎88000元，团队200000元。
以上情况在西北工业大学深圳研究院网页中予以公示，如有意见，请在公示之日起十五日内以书面形式反映至深圳研究院综合保障部(电话：0755-26551545)。
