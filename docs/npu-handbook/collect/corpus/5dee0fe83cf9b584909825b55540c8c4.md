# 青春逐梦，榜样同行 | “翱翔青春榜样”成长故事分享会第二场顺利举行

5月28日下午，由电子信息学院与网络空间安全学院联合举办的“翱翔青春榜样”成长故事分享会本学期第二场在线上举行。本次分享会特别邀请到北京大学电子学院2025级博士生时嘉乐以及英国格拉斯哥大学计算机科学专业2025级博士生李骏乐，围绕个人成长、能力提升、海外升学等内容，为学弟学妹们带来了一场干货满满、真挚动人的经验分享。
时嘉乐：聚焦核心目标，在笃行中明晰成长坐标
时嘉乐，本科毕业于西北工业大学电子信息学院通信工程专业，在校期间成绩优异，连续三次斩获国家奖学金，绩点与综合测评均位列专业第一，保送北京大学攻读博士学位。
分享会上，时嘉乐结合自身保研深造经历，系统分享了本科阶段学业、实践与规划的心得体会。她表示，绩点是学习的阶段性结果，但持续学习的能力与独立思考的意识，才是支撑长远发展、深耕科研的核心底气。时嘉乐有着丰富的学生工作经历，在她看来，学生工作不是负担，而是锻炼统筹、沟通与问题解决能力的重要平台。如何平衡学业与科研压力，她建议同学们大学期间要学会取舍、聚焦重点，结合自身兴趣、能力与抗压水平，理性规划保研、出国等发展方向，拒绝盲目跟风。身处AI快速发展的环境，她肯定了AI工具在效率提升等方面的优势，但也提醒同学们切勿依赖工具捷径，要夯实专业基础，培养独立思考与批判性思维能力，提高核心竞争力。
李骏乐：突破信息藩篱，在变局中开辟海外升学之路
李骏乐本科就读于西北工业大学网络空间安全学院，在校期间综合表现突出。曾任校辩论队队长，获校级一等奖学金等多项荣誉，先后在香港科技大学（广州）、清华大学深圳国际研究生院担任科研助理，目前以全额奖学金赴英国格拉斯哥大学攻读计算机科学专业博士学位。
针对当前复杂的海外升学形势，李骏乐结合工科学生特点，为同学们分享了实用的升学规划策略。她结合各地政策差异，梳理了多个国家（如英国、加拿大等）及中国港澳地区的升学路径，建议大家规避风险区域，理性选择升学地区。她详细对比了硕士与博士的升学差异与适配场景，指出硕士更适合快速就业、职业转型，直博更适合立志科研的同学，且多数地区的直博奖学金政策优厚、对本科生友好。她建议，GPA和语言成绩是升学申请的基础门槛，同学们要尽早筹备，同时要善于整合自身的竞赛、科研、实践经历，梳理出逻辑清晰、亮点突出的个人履历，提升竞争力。
与优秀者为伍，与奋斗者同行。本次分享会有效帮助同学们厘清了学业困惑、明晰了未来方向。愿每一位西工大学子都能以榜样为标杆，汲取奋进力量，找准成长坐标、勇敢突破自我，在逐梦路上笃行不怠、展翅翱翔。
