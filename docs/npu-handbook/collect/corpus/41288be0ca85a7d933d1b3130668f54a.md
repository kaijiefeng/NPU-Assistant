# 2026年第二批国际化领军人才（含本硕博）培养项目申报通知

各教学单位、广大师生：
为深入贯彻国家人才强国战略，培养更多创新型、紧缺型、复合型国际化人才，国际化领军人才培养项目将按照“聚焦重点、精准选派”的思路进行优化，重点支持博士研究生赴英国、德国、意大利、澳大利亚、法国、西班牙、瑞典等高等教育发达国家的一流高校和科研机构开展联合培养。
现将2026年第二批项目申报有关事项通知如下：
一、选派类别及留学期限
本项目重点支持理工农医、新兴学科以及交叉学科等国家重点急需人才培养学科领域的博士研究生赴外交流学习。

二、申请条件
申请人须为我校全日制在读学生，拥护中国共产党的领导，品德良好，具有扎实的专业基础和发展潜力。
三、项目申请流程
（一）联合培养博士/硕士研究生
1. 学生申请：填写附件1《国际化领军人才培养项目申请表》，连同拟留学单位邀请信/入学通知交至学院外事秘书；
2. 学院审核：学院审核后将学院拟推荐人申请材料及附件2《国际化领军人才培养项目拟选派学生汇总表》提交至国际合作处；
3. 组织评审：国际合作处遵循“公开、公平、公正”的原则进行材料评审并公示结果。
（二）本科插班生
项目类型包括本科生赴国（境）外毕业设计项目及学分学位交换项目等，各类项目“随时发布、随时申请、集中资助”，项目信息及申请材料请关注国际合作处和各培养单位微信公众号报名通知。
四、资助申请及发放流程
（一）联合培养博士/硕士研究生
已录取同学按要求完成线上出国（境）审批手续即可向国际合作处申请首次资助，剩余资助分批次发放，最后一个月资助将于完成线上返校申请后发放。
（二）本科插班生
获得学校各类长期出国（境）项目录取的本科生需在派出前完成资助申请，具体流程如下：
1. 学生申请：填写附件3《西北工业大学本科生长期（三个月及以上）出国（境）交流项目资助申请表》，提交至学院外事秘书；
2. 学院审核：学院审核后连同附件4《西北工业大学本科生长期（三个月及以上）出国（境）交流项目资助汇总表》提交至国际合作处；
3. 组织评审：国际合作处遵循“公开、公平、公正”的原则进行评审并公示结果；
4.按要求完成线上出国（境）审批手续，国际合作处将分批次进行资助发放。
五、资助内容及资助标准

六、重要说明
1. 重点支持博士研究生依托国内外导师间已有的科研合作项目/协议赴国外学习；
2. 优先支持赴QS、THE、U.S.News、ARWU四大排行榜认定的全球前100名高校或所申请学科前50名高校进行交流学习；
3. 学生须在派出前完成项目申请流程并获得资助资格。实际资助期限及资助标准以录取结果为准，且资助期限不得延长；
4. 本批次录取的博/硕研究生须在2026年12月30日前派出，特殊情况可申请延期派出，但最晚应于2027年6月30日前派出，此后资助资格作废；本批次录取的本科插班生资助资格一经批准，仅对所申请项目当次有效，不可转用于其他项目或延至其他时间使用；
5. 学生返校后严格按照出入境记录核实在外留学时间，在外时间低于最低留学期限的，资助不予发放，已发放部分须全额退回学校相应账户。
