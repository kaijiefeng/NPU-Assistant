# 后勤部办公室组织职工参加学校骑行踏青活动

春风送暖，万物复苏，正是踏青赏春的好时节。为丰富职工精神文化生活，进一步凝心聚力，4月11日上午，后勤部办公室积极响应学校工会号召，组织60余名职工参加了校园骑行踏青活动。
上午10点，大家精神饱满、兴致盎然，身着休闲运动装准时在长安校区家属区内集合。在简单的活动动员后，大家骑着自行车有序出发，一边悠闲骑行，一边欣赏校园春日盛景，粉嫩的花朵、抽芽的绿树尽收眼底，处处洋溢着盎然春意。一路上，大家畅谈生活趣事、交流工作心得，一阵阵欢声笑语，在校园道路上回荡。骑行过程中，大家相互照应，充分展现了后勤职工团结友爱、积极向上的良好精神风貌。
活动结束后，每个人还沉浸在轻松愉悦的氛围中意犹未尽。大家纷纷表示，此次活动十分有意义，在放松心情、缓解压力后，将以更加饱满的热情和昂扬的斗志投入到工作岗位中去，继续为学校高质量发展贡献后勤力量。（撰写人：毛淑兰；审稿人：韩争胜）
