# 国际合作处学习传达学校暑假务虚会、秋季学期中层干部会会议精神

8月31日上午，国际合作处（港澳台办公室）、国际教育学院、哈萨克斯坦分校召开全处干部职工大会，专题传达学习学校2026年暑假务虚会、秋季学期中层干部会及学生工作会会议精神，安排部署新学期国际合作重点工作。
与会人员一致认为，学校暑假务虚会和秋季学期中层干部会立足“十五五”开局之年发展方位，系统研判了发展形势，深刻阐释了“我们是干什么的、我们的处境是什么、我们应该怎么干”的发展命题，谋划了以高质量发展推进中国特色世界一流大学建设的总体路径，对新学期重点工作作出全面系统的动员部署。
会议明确，新学期国际合作工作聚焦三大重点精准发力：一是攻坚海外办学提质，推动哈萨克斯坦分校“从有到优”，健全办学质量体系，推进重点专业与标志性科研项目落地，打造高校海外办学标杆；二是升级育人双品牌，深化“翱翔四海”工程拓面增效，优化“留学工大”培养质效，提升师生全球胜任力；三是深化“三圈联动”，统筹科技合作、高端引智、中外合作办学协同发展，构建高水平开放创新生态，赋能学科科研创新。
全体人员纷纷表示，要持续深入学习书记校长讲话精神，以更高站位、更严标准、更实举措推进各项工作，为奋力谱写中国特色世界一流大学建设新篇章注入强劲国际化动能！
（文：张芑卉；图：刘颖；审核：李自伟）
