# 党建引领聚合力 筑牢安全护平安-化学与化工实验中心党支部开展安全教育体验活动

为为深入贯彻国家安全观，切实增强教师的国家安全意识和应对突发安全事故的处置能力，10月23日，化学与化工实验中心党支部在长安校区安全教育体验馆组织开展安全教育体验主题党建活动。学院党委副书记姚东东参加活动。
安全教育体验馆设置自然灾害区、校园安全区、消防安全区、卫生健康区、交通安全区五大模块，采用环境模拟、情景沉浸式体验、安全知识讲授、安全知识竞答等多种形式，使参与者在互动中感受、体会和学习。活动中，教师们在讲解员引导下参观了消防、交通、网络、应急救护等多个安全主题展区，重点沉浸式学习校园安全生产、消防安全、应急处置、日常防护等多维度安全知识，系统学习危化品分类、实验室安全规范与突发情况处置等知识。大家立足岗位实际，踊跃互动，积极提问，在实践操作中深化了对安全知识的理解。
此次参观学习活动，是化学与化工学院落实校园安全工作部署、深化安全教育育人的重要举措。本次活动将理论知识与实景体验相结合，以实景体验赋能安全教育，有效提升了党员的安全意识与应急处置能力，达到了以学促知、以知促行的良好效果。实验中心党支部将以此次活动为契机，持续推进安全教育常态化、长效化，切实筑牢实验教学及实验室管理的安全防线。
