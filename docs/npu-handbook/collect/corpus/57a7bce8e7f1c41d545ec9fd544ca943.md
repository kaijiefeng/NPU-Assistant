# 我校开展2026年全国节能宣传周和低碳日活动

为践行绿色低碳理念，响应2026年全国节能宣传周“节能新起点 低碳向未来”和全国低碳日“绿色转型 全民同行”主题号召，6月18日，后勤部办公室组织开展全国节能宣传周和低碳日特色主题活动，以“废旧物品换绿植 旧衣捐赠暖山区”的新颖形式，将低碳环保与公益爱心传递深度融合，在校园内营造出人人节能、人人低碳、人人向善的浓厚氛围。
本次活动以校园资源循环利用为核心，面向全体师生开展废旧物资回收兑换活动。活动现场氛围热烈、秩序井然，师生们纷纷携带废旧纸箱、塑料瓶及闲置旧衣物参与活动。师生可凭可回收物资兑换多肉、芦荟、仙人球等绿植，以实物兑换的直观形式，让师生们真切感受资源循环利用的价值，打破低碳节能的抽象概念，让绿色低碳理念沉浸式走入师生心中。
本次活动增设公益捐赠特色环节，师生捐赠的干净完好、八成新以上的闲置衣物，统一打包整理，对接中华慈善总会专业回收。衣物经消毒分拣后，将定向捐助山区困难儿童，实现了低碳节能、资源再生与爱心公益的深度融合，让环保行动更具温度。参与学生表示，废品换绿植、旧衣助山区的活动形式新颖且意义十足，让大家以实际行动践行垃圾分类与资源回收理念，真切认识到低碳生活的实用性。
下一步，学校将常态化开展绿色公益实践活动，持续推动节约型校园建设，引导师生自觉践行低碳生活、传递公益正能量，让勤俭节约、绿色向善的文明氛围在校园里蔚然成风。（撰稿人：张偲偲；审稿人：韩争胜）
