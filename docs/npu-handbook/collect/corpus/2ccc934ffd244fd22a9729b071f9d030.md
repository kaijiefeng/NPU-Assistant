# 擦亮“以体育人”鲜明底色

近日，如果您有机会走进学校的中华武学传承中心、翱翔体育馆、体育专业教学实验中心、国防体育教育基地等长安校区的体育场馆场地，您会惊喜地发现：这些场馆的标志更加规范醒目，环境更加温馨舒适，文化气息更加浓郁。这些悄然发生的变化，得益于体育部系统推进体育场馆文化建设，得益于体育文化综合展示建设项目的如期落地。
以文铸魂，寓教于体，让传统文化“可感可知”
体育场馆既是育人的空间，更是文化的载体。近年来，体育部认真学习贯彻习近平总书记关于体育的重要论述，紧密结合高校体育育人实际，坚持把文化建设作为深化体育育人改革的目标追求和重要抓手，系统推进两校区场馆场地的体育文化综合展示建设，取得初步成效。走进陕西省普通高校中华优秀传统文化传承中心（中华武学），入口立体字庄重大气，武术文化形象墙围绕武术的源流、内容、文化、价值与精神依次铺展，系统呈现中华武术的历史脉络与精神内核；武学室内屏风、古筝、展柜错落有致，文武相济、古朴雅致。摔跤室及楼梯通道以“锤炼体魄、坚守本心”“借力翻千斤、立身守寸心”等内容营造中国式摔跤文化墙，并展示“中华优秀传统文化是中华文明的智慧结晶和精华所在”等重要论述。师生在一招一式间体悟崇德尚武、修身立德的武学精神，在耳濡目染中增进对中华优秀传统文化的认同与自信，传统文化由此真正“活”在了校园里。
以体育德，体教融合，让体育精神“入脑入心”
在系统推进体育场馆场地文化建设过程中，体育部努力打破体育“重技能、轻文化”的传统局限，将中华优秀传统文化、校训校风与“三航”特色融入场馆空间，着力构建“运动强基、文化铸魂、素质赋能”三位一体的体育场馆文化育人体系，让师生在运动中潜移默化地接受优秀传统文化的熏陶与精神洗礼。翱翔体育馆等师生运动场所，“享受乐趣、增强体质、健全人格、锤炼意志”“文明其精神，野蛮其体魄”等标语抬眼可见，力量区、有氧区结合运动项目特点打造墙面文化，时刻传递学校体育“四位一体”的目标要求。体育专业教学实验中心入口形象墙以运动人体科学线条图案为底，配以“厚基础、强专项、擅训练、能担当”育人理念，让科学健身与专业精神浸润日常；国防体育教育基地迷彩大门庄严醒目，训练场上“为党育人、为国育才”红色大字与障碍训练设施相互映衬，将航空报国、科技强军的家国情怀种进青年心中。一面面墙壁、一处处走廊，正成为没有铃声的“思政课堂”。
以建促改，优化氛围，让工大理念“沁人心脾”。
从“强身健体”到“修心明德”，从“功能场馆”到“文化地标”，体育文化综合展示建设不仅是场馆空间的更新，更是体育育人功能的拓展与升华。体育场馆文化建设是体育强国建设的必然要求，是科技强校战略的重要组成部分，是一项需要长期坚持、持续更新的任务。本次体育文化综合展示建设项目得到学校大力支持，体育部项目组老师们利用暑假坚守施工现场，及时协调解决施工中的问题与困难。在多方的共同努力下，体育场地以崭新面貌呈现在师生们面前，文化氛围更加浓厚。
下一步，体育部继续传承弘扬好“总师育人文化”，用好、管好体育场馆文化新阵地，推动学生体质提升与精神成长同频共振，以体育德、以体启智、以体强志、以体润美，引导广大青年学子在体育锻炼中享受乐趣、增强体质、健全人格、锤炼意志，为培养德智体美劳全面发展、堪当民族复兴重任的时代新人，为学校“总师型”拔尖创新人才培养持续注入体育动能。
