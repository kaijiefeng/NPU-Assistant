# 2026年实践育人“三个一”工程暑期专项——“红色基因 蓝色情怀”主题实践总结表彰大会顺利举行

为深入学习贯彻习近平新时代中国特色社会主义思想，贯彻党的二十大及二十届历次全会精神，高质量实施新时代立德树人工程，深入拓展实践育人空间和阵地，学校于今年暑期组织开展实践育人“三个一”工程暑期专项——“红色基因 蓝色情怀”主题实践，围绕“触摸红色根脉 赓续红色血脉”“追寻领袖足迹 体悟伟大变革”“传承军工薪火 厚植蓝色情怀”三大专题，组成42支实践队分赴祖国各地开展实践，教育引导广大学生扎身实践课堂、躬身实践建功，传承红色基因，厚植蓝色情怀，把青春奋斗融入中国式现代化建设大局。
9月17日，西北工业大学2026年实践育人“三个一”工程暑期专项——“红色基因 蓝色情怀”主题实践总结表彰大会在长安校区马克思主义学院207报告厅举行。党委组织部、党委宣传部、党委学生工作部、校团委相关负责同志以及各实践队指导老师、队员代表100余人参加了会议。
经各学院遴选推荐的29支实践队按照抽签顺序依次进行答辩汇报。各实践队结合PPT演示、微视频等形式，以详实的实践内容、鲜活的实践故事、丰富的实践成果，生动展现了实践过程中的收获与感悟，既有踏访红色热土、追寻领袖足迹、走访国防军工院所的深刻感悟，也有立足学科专业、青年视角，开展红色基因宣讲、航空科普活动、专题调研，把所学知识转化为实干力量的鲜活实践。
评委通过答辩评审和材料评审进行了综合评分，评选出一二三等级及优秀奖。
后续，学校将紧密结合庆祝新中国成立77周年、纪念中国工农红军长征胜利90周年等重要历史节点，策划组织特色实践项目，多措并举做好总结提升、成果展示，持续提升实践影响力、育人力。
