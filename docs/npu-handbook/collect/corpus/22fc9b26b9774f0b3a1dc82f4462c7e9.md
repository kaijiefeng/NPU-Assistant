# 我校召开2026年网络安全工作培训会

10月12日上午，2026年西北工业大学网络安全工作培训会在友谊校区东馆C205报告厅召开。学校党委常委、副校长王伶出席会议，各二级单位分管网络安全（或信息化）工作的领导、网络安全与信息化相关工作人员、2026年度网络安全工作先进集体代表和先进工作者等150余人参加。会议由信息化管理处处长薛静主持。
会议对2026年度“网络安全工作先进集体”和“网络安全先进工作者”进行了表彰，王伶副校长为获奖集体代表和获奖个人颁发了荣誉证书。他指出，今年是“十五五”开局之年，必须坚持系统观念，统筹好学校发展与安全。要层层压实网络安全责任，持续完善长效工作机制，全面提升师生网络安全素养与防护技能，以更加坚实的网络安全防线，为学校高质量发展保驾护航。
信息化管理处宋强聚焦个人终端防护、数据安全与师生个人信息保护等重点内容，结合身边典型案例做专题培训，进一步夯实全员风险防范意识。马克思主义学院张敏教授紧扣人工智能发展新形势，深入阐释个人信息保护核心问题。保密处王革明通过培训进一步明确保密工作要求。
此次会议进一步压实了各单位网络安全主体责任，明确了教学、科研、管理等重点领域防护要求，为学校网络安全工作走深走实、规范有序推进筑牢了基础。下一步，信息化管理处将常态化开展政策宣讲和业务指导，协同各单位持续完善网络安全工作体系，严格落实数据安全和个人信息保护要求，严守保密工作纪律，以高水平网络安全护航学校事业高质量发展。
