# 科研概况

专任教师62人，其中教授4人，副教授29人，讲师22人，助教7人，硕士生导师11人。体育部科研工作以面向国家重大需求、瞄准国际前沿、突出自主创新、加速成果转化为发展战略为着眼点，在基地建设、科研成果和产学研合作等方面取得了重要进展，科技创新能力不断增强，科技竞争力显著提升。
体育部科学研究、学术交流、科技成果、科研队伍、科技信息等方面工作由体育部负责。
我部进一步把握新时代体育工程发展的前沿动态，为不断提高我国的体育工程研究水平做出新的贡献——作为西北地区首所加入“冰雪体育科技联盟”的高校，我校被纳入理事单位，参与了“十三五”国家重点研发计划“科技冬奥”重点专项。借助特有的风洞教学与科研平台，开展了速度滑冰高端冰刀的制备过程应用评价和竞速类高性能服装制备的研究，创造了2022年北京冬奥会速滑冠军高亭宇夺金和男子钢架雪车闫文港摘铜的历史佳绩。
同时，体育部领导和教师十分注重体育科学研究，召开多次在全国有影响力的体育科研情况交流会，以体育科研带动促进体育教学。如 “第十届全国体育工程技术大会”和“第四届全国体育工程科技创新设计展”，吸引了来自全国兄弟院校老师和学生参与，取得了良好交流效果。去年举办的“运动•行为•健康：2021体育参与行为与健康促进高峰论坛”也吸引了众多行业翘楚参加。
新时期，体育部将结合自身在长期科研实践中形成的特色研究与优势方向，进一步发挥学科和人才潜能，立足学科技术前沿，加强基础性、前沿性、交叉性研究，推进内涵式发展，积极承担战略性、前瞻性的重大项目，为国家建设和科技进步贡献力量。
