# 后勤部办公室党支部赴鄠邑区水生态保护警示教育中心开展警示教育活动

根据学校深入贯彻中央八项规定精神学习教育工作要求，为进一步强化党员廉洁自律意识，7月4日下午，后勤部办公室党支部组织全体党员赴西安市鄠邑区黄河流域水生态保护警示教育中心开展警示教育活动。
该中心依托秦岭北麓与渭河交汇的独特地理优势，以“水”为主线，打造了“水出秦岭”“水润鄠邑”“水映史澜”“水鉴清风”“水淀清浊”“水碧城兴”六大主题展厅。活动中，党员们跟随讲解员的引导，详细了解了鄠邑区水系演变、治水历史及生态保护成果。通过详实的文字、图片、视频及互动装置，大家深刻认识到“绿水青山就是金山银山”理念的实践意义，以及水资源保护对区域可持续发展的重要性。
接着，党员们还学习了鄠邑区纪委监委制定的《涉水领域负面言行清单》，该清单以条目式列举了基层干部在生态保护中易发的“推诿扯皮”“吃拿卡要”“隐瞒不报”等20类问题，并配以漫画、案例解析，直观呈现违纪行为的边界与代价，让大家切身感受到水环境保护工作的现状和挑战，为全体党员上了一堂深刻的政治纪律和政治规矩警示教育课。
活动结束后，党员们纷纷表示，在今后的工作中，将以问题为导向，以案例为镜鉴，淬炼优良作风，自觉接受监督，切实拧紧思想“总开关”，以清正廉洁的作风护航学校高质量发展，为建设“绿色低碳校园”贡献后勤力量。（撰稿人：毛淑兰；审稿人：韩争胜）
