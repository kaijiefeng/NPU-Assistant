# 踏访英雄重庆 传承红岩精神——马克思主义中国化研究系教学团队赴重庆开展研学备课-西北工业大学

为提升增强思政课教师对中国共产党人精神谱系融入思政课的能力，近日，马克思主义中国化研究系教学团队奔赴重庆开展了为期三天的研学备课，通过深入学习红岩精神及其当代价值，以期将之运用到思政课教学实际中，引导学生从历史中汲取奋进力量，更好地传承红色基因、担当时代使命。
马克思主义中国化研究系教学团队先后走进渣滓洞集中营旧址、白公馆监狱旧址、红岩革命纪念馆、曾家岩等红色教育基地，感悟红岩精神。在渣滓洞真切触摸到革命先辈在绝境中坚守信仰的不屈灵魂；在白公馆内深刻感悟到红岩儿女为民族解放事业献出一切的赤诚初心。红岩革命纪念馆内，通过详实的文献资料，学习以周恩来同志为代表的中共中央南方局在重庆的斗争历程。曾家岩周公馆感悟当年中共中央南方局在重庆开展隐蔽战线斗争的峥嵘岁月。老师们听取讲解，对于“红岩精神是共产主义精神、民族精神、时代精神的结合”有了更具象的认知，
研学中教学团队开展集体备课研讨。高旭红表示：“作为思政教师，我们有责任让红岩精神代代相传，引导学生在新时代的征程中，以红岩精神为指引，勇担时代使命，让青春在为国家和人民的奉献中绽放光彩。”华艳君表示：“这次研学让我对红岩精神的内涵有了更鲜活地理解，深刻意识到红岩精神不仅是历史的记忆，更是当代青年成长的精神养分。回到课堂后，我会把这些亲身感悟转化为生动的教学案例。”陈诚平表示：“作为思政课教师，我们不仅要讲好红岩故事，更要引导学生从历史中找答案、从精神中汲力量，让红岩精神成为他们面对挑战时的精神灯塔，在新时代的奋斗中书写属于自己的‘红岩篇章’。老师们一致认为将在以后的思政课教学中，要将红色基因的弘扬传承与“总师育人文化”相结合，为培育服务强国建设、民族复兴的时代新人而努力。
