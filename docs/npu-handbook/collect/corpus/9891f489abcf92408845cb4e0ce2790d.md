# 喜报！重庆科创中心首席科学家李金山教授牵头获国家科学技术进步奖二等奖

7月8日上午，国家科学技术奖励大会、两院院士大会、中国科协第十一次全国代表大会在人民大会堂隆重召开。中共中央总书记、国家主席、中央军委主席习近平出席大会，为国家最高科学技术奖获得者等颁奖并发表重要讲话。
西北工业大学6项成果获2025年度国家科学技术奖励。
重庆科创中心负责人、首席科学家、凝固技术全国重点实验室主任李金山教授主持完成的成果“高性能钛合金累积变形均质化制造关键技术及应用”荣获国家科学技术进步奖二等奖。中心副主任唐斌教授是项目完成人之一。
该成果围绕大飞机等重大装备研制对宽幅钛合金板材和紧固件用高强钛合金棒丝材的亟需，攻克了合金多尺度异构组织构建、累积变形晶体取向调控、跨相区工艺路径优化与加工等关键技术，研制了数智化制造装备与产线，解决了均质化制造难题，实现了产品批次稳定性大幅度提高，构建了“成分设计－工艺调控－装备研制－标准制定”全链条技术体系，批量应用于多型飞机、舰船等重大型号及装备，大幅提升了我国钛合金加工制造的国际竞争力。中心将继续心怀“国之大者”、坚持“四个面向”，为建设耐高温金属材料及精密成形领域的国家战略科技力量勇毅前行，为学校“双一流”建设和重庆“416”科技创新布局及“33618”现代产业集群体系建设贡献力量。
