# 关于缴纳2027年度大学生基本医疗保险费的通知-西北工业大学医院

依据陕西省医保局、教育厅、人社厅、税务局联合印发的陕医保函〔2026〕142号文件，结合学校实际，对我校全日制本科生、研究生参加西安市大学生基本医疗保险参保缴费相关事项通知如下：
一、缴费标准
在校学生2027年度参加居民医保个人缴费标准暂定为400元/人预收。陕西省外的低保学生不予认定，按照400元缴纳。
二、待遇享受期
1.符合连续参保学生：2027年1月1日—2027年12月31日。
2.符合连续参保新入学学生，并且集中缴费期参保：待遇享受期为2026年9月1日—2027年12月31日。
3.断保学生（上年度未参保）：执行医保参保长效机制，设置不少于3个月待遇等待期。
三、缴费时间
我校集中缴费期：即日起—2026年11月30日
四、缴费方式
1.手机端
扫描二维码登录校园统一支付平台→其他缴费→点击“缴”完成缴费。
2.PC端
方式①：翱翔门户—财务系统—校园统一支付平台
方式②：直接访问网址：https://wszf.nwpu.edu.cn
操作路径：点击“其他费用”→选择大学生基本医疗保险费项目→进入缴费→下一步→选择支付宝/微信→确认支付、扫码付款。
无法自助缴费的学生，联系校医院医保办处理。
五、重要参保、停保事项
1.参保地原则：大学生优先在学籍地参保；在校参保后，不要在户籍地重复参保缴费。
2.省外生源在校参保：务必将原参保地居民/职工医保办理停保。
操作路径：国家医保服务平台APP→左下角地方专区→选择原参保省份→业务办理→城乡居民暂停参保。
3.陕西省内生源：省内医保系统自动停保，学生无需手动办理停保。
