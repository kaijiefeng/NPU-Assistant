# 我校在第十五届全国大学生信息安全竞赛中取得佳绩

2022年8月20日-24日，第十五届全国大学生信息安全竞赛决赛落下帷幕，全国大学生信息安全竞赛是由教育部高等学校网络空间安全专业教学指导委员会发起并主办、中央网信办支持、教育部认可的56项“全国大学生学科竞赛”之一，分为作品赛和创新实践能力赛两种竞赛方式。我校获得作品赛全国二等奖3项，创新实践能力赛全国二等奖1项，三等奖1项。
第十五届全国大学生信息安全竞赛—作品赛由湖南大学承办，全国191个学校，840支队伍，2692名师生，840份参赛作品参赛。经过初赛线上会评，共310支队伍进入总决赛，我校3支队伍入围。总决赛于8月20日至21日经过在线答辩、作品演示、评委质询、专家现场评分，刘航老师指导，杨轶帆、杨之铭、孔令怡、彭乐赟完成的作品“Guard dog：无人系统轻量化位置欺骗检测系统”，曹国彦老师指导，于锦阳、郑贺源、周奇完成的作品“工业传感网络的强实时异常检测与高精度定位系统”，杨黎斌老师指导，韩骥远、刘展、魏凯航、李勇邦完成的作品“‘秦岭道士’物联网僵尸网络主动探测系统”，均获得全国二等奖。
第十五届全国大学生信息安全竞赛—创新实践能力赛由南开大学承办。全国495所高校的2219支队伍，共7178人注册报名参赛，参赛的战队、人员数量创历届之最。经过线上初赛和分区赛层层选拔，最后遴选出82支优秀队伍入围全国总决赛（每个高校至多两支队伍晋级），我校2支队伍均进入总决赛。总决赛于8月23日至24日在线举行，经激烈角逐，张慧翔老师指导，周诚远、洪汇智、马镜博、张傲锐组成的Kaleido76战队，获得全国二等奖，并获网络安全挑战创新单项奖；邰瑜老师指导，李浩宇、梁高玮、崔智尧、祖锦源组成的JK战队，获得全国三等奖。
网络空间安全学院建院以来坚持“厚基础、强系统、重实战、拓交叉”的人才培养体系，大力支持学生参加具有影响力的学科竞赛，以赛促学、以赛促练，培养实战型网安专业人才。2022年，在教务处的大力支持下，网络空间安全学院竞赛负责教师张慧翔与邰瑜，通过线上宣讲、经验交流、参赛辅导等多项举措，组织多支队伍参加竞赛，最终在本年度信息安全竞赛中取得良好成绩，提升了学生的网络安全技术水平和创新实践能力。
