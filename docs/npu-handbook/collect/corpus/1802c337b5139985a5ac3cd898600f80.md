# 重庆科创中心开展安全隐患排查

按照工信部和学校安全生产相关通知要求，11月22日下午，中心副主任张铁邦带队开展安全隐患排查工作，中心各部门负责人及各实验室负责人组成检查组对中试及科研场地进行了全面安全隐患排查。
检查组根据前期梳理的实验室危险源清单逐一进行排查，针对高温、高压、高能辐射、特种设备及危化品场所，详细检查了设备状况和相关记录。检查过程中，张铁邦强调要对照检查项目表逐条进行自查，对进入实验室的人员必须做好培训工作，并配备必要的防护用品，确保操作人员的安全，坚决杜绝安全生产事故发生。
