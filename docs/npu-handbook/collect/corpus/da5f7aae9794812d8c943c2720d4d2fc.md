# 档案人指尖上的非遗瑰宝——掐丝珐琅

弘扬传统文化，传承非遗经典。在第114个“三八国际妇女节”来临之际，档案馆工会小组积极组织广大馆员参加掐丝珐琅手工活动。
活动上，特邀老师深入浅出地向大家介绍了掐丝珐琅的历史及制作流程。在老师的指导下，大家一步一步绘图、缕丝、掐丝、点蓝。这些制作过程看似简单，实则环环相扣，每位成员都用心地制作着自己手中的掐丝珐琅画，一朵朵栩栩如生的“花儿”跃然而出。
掐丝珐琅是我国非物质文化遗产之一。其精巧细致的手工制作过程和色彩斑斓的艺术效果，不仅使大家在繁忙之余享受到手工制作的安静美好，也让大家在实操中领略到了中国传统工艺与非遗文化的独特魅力。
（文/冯瑶 审核/戚红梅）
