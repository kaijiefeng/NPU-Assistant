# 民航学院圆满完成2023级本科生暑期生产实习工作

为深入贯彻落实总师育人理念，深化产教融合人才培养模式，全面提升学生工程实践能力与专业素养，民航学院于7月至8月组织2023级本科生分批次赴海航西安分公司、国营四达机械制造公司开展暑期生产实习，引导学生深入航空一线、扎根生产现场，在真实工程环境中夯实专业基础、提升实践能力。
实习前期，学院召开暑期生产实习动员大会。教学院长就实习纪律、生产安全和学习态度提出明确要求，强调全体学生须严格遵守校企规章制度，服从岗位安排、恪守考勤规范，展现民航学子严谨自律的良好风貌；切实保障人身安全，规范实操流程；珍惜实践机会，主动钻研学习、认真总结反思，促进专业理论与工程实践深度融合，确保实习取得实效。
在海航西安分公司实习期间，飞行器设计与工程、飞行器控制与信息工程专业学生分三批次赴该单位开展实践，由韩栋、陈杰、马宗耀三位老师带队。企业依托真实运维场地开展沉浸式教学，组织学生参观航空器运维基地，系统讲解飞机运维周期、机身与航电系统相关专业知识。资深工程师围绕民航运维体系、复合材料应用、机载设备检修标准开设专题课程，通过案例剖析、故障模拟推演等实训方式，引导学生独立思考。同学们结合课堂所学，在复合材料损伤检测、结构优化方向提出创新性建议，获得企业技术人员高度认可。此次实习有效打通理论与实践壁垒，增强了学生专业认同感与创新意识，进一步巩固了校企协同育人合作基础。
在国营四达机械制造公司实习阶段，飞行器设计与工程、飞行器控制与信息工程、低空技术与工程专业学生于马宗耀老师带领下赴企业参加实践学习。该单位对本次实习给予充分重视，培训部工作人员履职尽责，实行标准化、严格化管理，有序组织学生开展保密知识技能、生产安全管理相关学习。保密科、安全生产处高级工程师结合典型案例开展讲解分析，采用互动教学模式，帮助学生充分理解保密及生产安全工作的重大意义，树立 “保密安全责任在我” 的思想观念，为学生在后续实践过程中落实保密与安全生产相关要求打下良好基础。
本次生产实习是学院深化总师育人理念、推进产教融合的重要举措，有效提升了学生的工程实践能力与职业素养，夯实了专业发展根基。
