# 数学与统计学院开展AI辅助教学研讨

2026年10月30日晚，数学与统计学院组织召开AI辅助教学线上研讨会，重点探讨AI技术在作业批改与智慧教学中的应用。会议由学院副院长郭千桥主持，教务部课程办主任韩寅奔到会指导，学院公共课与专业课负责人、骨干教师共同参会。江苏金智教育（知途）受邀参会，并围绕“AI如何辅助数学作业批改与教育教学”进行系统演示与深入交流。
数学课程作业逻辑性强、公式繁多、手写量大，传统批改方式耗时费力且实时性较差。金智教育结合上海交通大学、同济大学等高校的实践案例，详细展示了“学生拍照上传—系统自动切题—AI智能体批阅—助教核验—错题本与薄弱点分析”的全流程能力。与会教师紧密结合数学教学实际，针对乱涂乱写识别、多种证明方法打分、统计口径界定、跨页答题切分、学生自适应学习实际效果以及AI代写作业等痛点问题进行了热烈讨论，并就“AI直接在原图上精准批注”“AI判断代做比例”等功能完善提出建议。
教务部课程办主任韩寅奔表示，AI辅助作业批改和智慧教学势在必行，建议学院选取部分课程尽快开展试点。副院长郭千桥在总结中指出，AI辅助教学并非替代教师，而是将教师从重复性劳动中解放出来，提升教学效果与学生学习效率。他希望各位老师积极推进AI辅助教学相关工作。
