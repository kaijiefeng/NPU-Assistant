# 档案馆关于2026年寒假工作安排的通知

全校师生：
为做好2026年寒假档案服务利用工作，根据学校《关于2026年寒假安排的通知》要求，结合档案馆工作实际，现将有关安排通知如下：
一、办理档案查（借）阅业务
二、办理档案归档业务
三、办理中文成绩单及出国材料
1.办理中文成绩单：在校本科生及2023届（含）以后本科毕业生请在“翱翔教务系统 ”自助下载打印；2022届（含）以前的本科毕业生、硕博毕业生请在档案馆“学生自助打印区域”自助打印或通过“档案远程服务利用平台”预约办理；继续（网络）教育毕业生请在“档案远程服务利用平台”进行预约办理。
2.办理出国材料：在校本科生及2023届（含）以后本科毕业生办理英文成绩单请在“翱翔教务系统”自助下载打印；其余本科毕业生办理英文成绩单及办理其他出国材料业务，请通过“档案远程服务利用平台”预约办理，也可在每周一、周三值班时间前往档案馆107室现场办理，咨询电话88493280。
特此通知。
档案馆
2026年1月22日
