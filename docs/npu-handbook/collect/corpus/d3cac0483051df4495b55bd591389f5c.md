# 后勤部党工委召开树立和践行正确政绩观长效机制推进会-后勤集团

9月10日下午，后勤部党工委召开专题会议，认真学习贯彻习近平总书记关于树立和践行正确政绩观重要讲话精神，进一步深入落实学校2026年暑期务虚会、新学期中层干部会精神，就树立和践行正确政绩观长效机制进行研讨布置。校党委副书记杨晓、后勤部办公室和后勤集团全体处、科级干部参加会议。会议由后勤部党工委副书记、后勤集团党委书记侯亚涛主持。
会上，四位处级干部结合学习领会暑期务虚会、新学期中层干部会精神情况和分管工作推进情况，全面梳理现阶段后勤服务、项目建设、日常管理等工作，剖析现存问题与短板，明确后续工作推进思路与重点方向，进行了深入交流和研讨。
杨晓对各位干部的汇报逐一进行点评，对后勤部阶段性工作成效予以肯定，并对下一步重点工作作出专项部署。杨晓重点解读了《后勤部党工委关于建立树立和践行正确政绩观长效机制的工作方案》，清晰界定后勤工作发展目标与实施路径，明确后勤工作将以建设一流大学后勤服务保障体系为总体目标，通过十大关键领域细化工作举措，构建全方位、常态化、长效化的后勤管理服务体系。
最后，侯亚涛就本次会议精神落地落实作出三点工作要求：一是全员深入贯彻落实学校系列工作会议精神，建立常态化学习、调研、复盘工作机制，夯实工作开展基础；二是紧扣四项提升核心任务，深耕服务育人特色，打造后勤服务专属品牌，全方位提升校园后勤保障质量与服务效能；三是各单位、各党支部对照十项重点举措细化工作计划、建立工作台账、实行挂单推进，确保工作机制落地生根、常态长效。（图/文：综合事务部，审核：邱若娟、侯亚涛）
