# 党委保卫部党支部赴红旗渠干部学院开展党员培训

6月28日-29日，党委保卫部党支部赴红旗渠干部学院开展“学红旗渠精神、筑忠诚担当”主题培训班，通过理论讲解与实地参观相结合的教学方式，引导学员们深刻感悟红旗渠精神的丰富内涵，更深刻、更全面的把握中国共产党人的精神谱系。培训活动由党支部书记朱建军同志、支委委员王坤庆同志带队。
历史是最好的营养剂。在红旗渠纪念馆，老师带领学员们全面回顾了红旗渠的建设背景、艰辛历程和深远影响。同志们认真聆听记录，更系统、全面的了解了红旗渠对于林县发展的历史意义，也更深刻的领悟了“自力更生、艰苦创业、团结协作、无私奉献”的红旗渠精神伟力。纪录片《红旗渠》记录了60多年前林县人民热火朝天的工作场景，再现了修渠人员穿梭于悬崖峭壁间的惊心动魄，不认命、不服输、敢于战天斗地的英雄气概穿透荧屏，感染和鼓舞着新时代的党员干部。
在参观见学环节，学员们重走了“水长城”，参观了红旗渠标志性工程青年洞。沿着前辈们凿石修渠的路线一路前行，太行山崖壁陡峭，山路蜿蜒，渠内水量充沛，滔滔不绝，学员们更直观的感受到当年“逢山凿洞、遇壑架桥、逼水上山”的艰难，体会到百年中国发生的巨大变迁，也更深刻的领悟到我们党为人民谋幸福、为民族谋复兴的初心使命。
在红旗渠总干渠通水60周年之际，党委保卫部党支部组织党员干部重温红旗渠精神，不仅是重温这段辉煌历史，更是引导党员们深入思考红旗渠精神的时代价值，将所学所悟融入日常，转化为工作动力。学习结束后，学员们纷纷表示，在红旗渠精神的感召下，将进一步筑牢理想信念，提升业务水平，在工作中不断拼搏进取，创新开拓，为学校稳定安全工作贡献更大力量。
