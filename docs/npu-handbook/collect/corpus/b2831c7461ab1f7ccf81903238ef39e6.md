# 后勤部党工委传达学习暑期务虚会、新学期中层干部会会议精神

8月31日下午，后勤部党工委召开专题会议，传达学习学校2025年暑期务虚会、新学期中层干部会会议精神。后勤部办公室和后勤集团全体处级干部参加会议。会议由校长助理兼后勤部党工委书记、后勤部部长王宇波主持。
会上，王宇波首先带领与会人员集体学习了李言荣书记、宋保维校长在暑期务虚会、新学期中层干部会上的讲话，并结合后勤工作实际，就如何深入贯彻落实书记校长讲话精神做了安排部署。
随后，与会人员进行了热烈地交流研讨，既谈学习体会，也谈工作思路。大家一致认为，暑期务虚会和新学期中层干部会的召开，为下半年工作的开展打下了坚实基础；书记校长的讲话，内容丰富、催人奋进，像一剂强心针，为后勤工作注入了新的动力。
王宇波表示，当前正处于学校“十五五”规划的重要时期，作为支撑与服务保障部门，后勤工作务必要保障到位。一是要提升“软”服务、补齐“硬”短板。通过夯实基础、苦练内功，不断提高后勤服务保障水平，从而弥补设施设备陈旧等硬件方面存在的问题和不足。二是要发挥主动性、勇于解难题。持续聚焦师生急难愁盼，主动破解制约学校发展的困难和问题，为师生办好实事，为学校发展助力。三是要加强协作配合、凝聚工作合力。后勤部各单位在管理和服务中既要充分发挥好各自优势和作用，更要同频共振、同向发力，要进一步完善工作机制，强化工作作风，以“只有做好了才算做了”的标准，将“三个永远”“三个千方百计”“四个凡事”变成为日用而不觉的工作习惯，为学校早日实现“一十百千”发展目标贡献后勤力量。（撰稿人：蔺阳；审稿人：王宇波）
