# 启智润心 明志笃行——力学与交通运载工程学院举办学科认知与生涯指导讲座

为引导学院本科生深入了解学科专业方向，强化专业认同感，树立科学的学业与职业规划意识，2025年10月16日下午，西北工业大学力学与交通运载工程学院在学院楼报告厅举办了“第二课堂”思政教育活动——学科认知与生涯指导讲座。本次讲座特邀教育部国家工科力学教学基地负责人，教育部力学教学示范中心负责人岳珠峰教授主讲，学院大一、大二本科生代表参加了此次活动。
讲座中，岳珠峰教授首先以自身海外求学经历为切入点，分享了留学与科研道路上的收获与感悟，鼓励同学们拓宽国际视野，坚定科研志向。随后，他回顾了2000年以来学校和学院的发展历程，结合自身读研、读博的成长经历，深入讲解了飞机与航空器的发展过程、航空器力学的演变以及航空飞行器的基本概念，帮助同学们系统了解力学学科在航空航天领域中的重要地位与作用。
在讲座的最后，岳教授以丰富的实践经验分析了力学专业学生的就业前景与发展方向，指出力学学科作为工程科学的重要基础，在航空航天、交通运输、能源装备、智能制造等国家重点领域中都具有广泛的应用，拥有广阔的发展前景和丰富的科研空间。
整场讲座内容充实、启发深刻，同学们受益匪浅。通过此次活动进一步加深了对力学学科的理解，明确了科研学习目标，对未来的学业与职业规划有了更加清晰的认识。
此次“第二课堂”思政教育活动，不仅帮助本科生深化了学科认知、增强了专业自信，也在思想上引导学生树立远大理想、勇担时代使命。学院将持续推动“第二课堂”思政教育常态化、体系化发展，助力青年学子成长为德智体美劳全面发展的新时代领军人才。
