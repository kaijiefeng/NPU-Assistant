# 西北工业大学材料学院陕西省摩擦焊接工程技术研究中心招聘启事

西北工业大学材料学院陕西省摩擦焊接工程技术研究中心因工作需要，现面向社会公开招聘非事业编制人员15名，具体要求如下：
一、岗位名称
AI算法工程师（5名）
自动控制工程师（机器人方向）（5名）
焊接工程师（5名）
二、岗位要求
AI算法工程师（5名）
（1）负责大语言模型（LLM）或多模态模型在工业中的应用与优化，主导从数据处理、模型微调（SFT/RLHF）到推理部署的完整链路。
（2）针对业务中的复杂问题设计创新的算法方案。持续跟踪前沿技术，探索Agent、RAG、模型压缩等方向在业务中的落地可能。
（3）精通Python，熟练使用PyTorch或TensorFlow等主流深度学习框架。深入理解Transformer架构，熟悉GPT、DeepSeek、LLaMA等主流大模型原理，具备模型微调（SFT/RLHF/DPO）、RAG或Agent开发的实际经验。了解模型推理优化技术
自动控制工程师（机器人方向）（5名）
（1）负责机器人的运动学与动力学建模，设计并实现高精度运动控制算法，包括轨迹规划、力/位混合控制、阻抗/导纳控制等，优化机器人在抓取、交互等场景下的精度与稳定性。
（2）研究并应用MPC（模型预测控制）、WBC（全身控制）、LQR等优化控制方法，提升机器人动态性能与抗干扰能力。参与强化学习（RL）控制策略的真机部署与适配，打通仿真到现实的迁移链路。
（3）系统集成与真机调试：负责控制系统与机器人本体、伺服关节模组、多传感器（IMU、扭矩/力传感器、编码器等）的软硬件联调。熟悉EtherCAT、CANopen等工业总线协议，保障力控闭环的实时性与高精度。
（4）搭建仿真测试环境（如Mujoco、Isaac Sim、Gazebo），完成算法验证、参数标定与性能评测，编写技术文档，沉淀可复用的控制组件与适配方案。
焊接工程师（5名）
（1）根据产品材料特性、产品要求和行业标准，设计合理的焊接工艺方案，选择合适的焊接方法（如电弧焊、MIG/MAG、TIG、埋弧焊、激光焊等），制定焊接参数及工艺流程，输出焊接工艺规程等工艺文件，并组织试焊验证。
（2）参与焊接设备的选型、调试与维护，根据工艺升级需求提出设备改造方案，确保设备运行参数与焊接工艺要求匹配。支持焊接工装夹具的设计与优化
（3）跟踪焊接前沿工艺、新技术及新装备（如激光焊接、搅拌摩擦焊、焊接机器人及智能化焊接设备），开展技术创新与工艺改进，从工艺优化角度提出降本解决方案，优化产线节拍，提升生产效率与良率
（4）熟悉主流焊接工艺原理（电弧焊、气体保护焊、埋弧焊、激光焊等），深入理解金属材料焊接性、焊接冶金原理、焊接应力与变形控制，掌握常用材料（碳钢、不锈钢、合金钢、铝合金等）的焊接特性
（5）能独立设计焊接工艺试验方案，编制、审核焊接工艺规程、焊接工艺评定报告等工艺文件，为生产现场提供专业技术指导。
三、应聘条件
1.遵纪守法，热爱本职工作，身体健康；
2.责任心、服务意识强，有较强的团队协作精神和组织协调能力；
3.本科及以上学历，具有与以上岗位相匹配的相关专业背景，有工作经验优先，应届毕业生均可。
四、招聘程序
1.符合条件者请将个人简历、学历、学位证明及其他证明材料电子版于2026年12月31日24:[已脱敏:邮箱]（邮件主题：岗位名称+姓名+学校+专业，不接受压缩文件）；
2.团队对符合条件的应聘者进行初筛，入围者通知面试，择优录用。
五、考核及待遇
1.考核及待遇参照西北工业大学非事业编制人员有关规定执行；
2.工作地点为西北工业大学友谊校区；
3.试用期3个月，首次聘期3年。
