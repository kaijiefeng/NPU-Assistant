# 以“芯”迎新 以心连心丨集成电路学院2026级本科生迎新工作圆满收官-集成电路学院（微电子学院）

暮夏渐隐，新秋初临。2026年8月21日至22日，西北工业大学集成电路学院（微电子学院）2026级本科生迎新工作在学院党委统一部署下，由院学生会与全体志愿者通力配合，圆满完成。
长安校区翱翔体育馆外，志愿者各司其职，为新生及家长提供路线指引、报到协助与现场答疑等帮助；馆内工作人员严谨核验新生信息，确保流程规范顺畅，并将迎新礼包逐一发放到位。新生们在学院特别设计制作的学科特色展板等合影打卡装置前拍照留念，在光影记录中完成与学院的首次“同框”，切实感受到学院对每一位新生的诚挚欢迎。
迎新期间，集成电路学院学院党委书记杨妮花来到迎新工作现场，详细了解迎新工作开展情况，关切询问新生报到感受，向新同学送上暖心问候与美好期盼。
整个迎新过程高效有序，处处洋溢着青春朝气与学院温度，新生们在温暖包容的氛围中迈入大学生活的全新阶段。
韶华正好，征途初启。愿全体2026级新生以热爱为引，在方寸芯片间潜心求索，于微观世界中勇毅攻坚，以青春之力锻造“中国芯”的硬核未来！
