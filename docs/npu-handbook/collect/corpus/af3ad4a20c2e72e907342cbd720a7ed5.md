# 西北工业大学网络空间安全学院开题答辩（黄星杰）

一、开题答辩题目：异构云环境下的安全智能检测和自动化编排关键技术研究
二、开题答辩人：黄星杰
三、开题答辩时间：2024年7月24日晚上18:00
四、开题答辩地点：毅字楼801室（友谊校区）
五、开题内容简介：随着信息化程度不断加深，异构云环境与传统环境并存，网络安全防护边界不断扩大，网络安全暴露面越来越广，同时，内外网环境的安全威胁也在不断增加，各种攻击手段日益丰富、技术日趋成熟、攻击速度日渐升级，面临着严峻的网络安全挑战，主要体现在数字化云安全防护需求迫切、互联网大区安全防护难度加大与异构安全设备广泛使用，攻防转换速度加快，安全智能检测和自动化编排和自动化手段有待提升。因此，亟需开展面向异构云环境下的安全智能检测和自动化编排关键技术研究，构建基于网络代理技术的管理平台，打通异构云环境下日志、告警、事件与安全处置设备已有的防护壁垒，消除异构云环境下异构设备无法协同、联动的问题，从防护、监测、响应、处置等多维度，形成立体的防护效果，提升公司网络安全智能运维、监控分析与自动化应急响应能力。
六、开题答辩人简介
黄星杰，学号2022161133，1989年12月3日生，网络空间安全学院电子信息专业，导师王震教授。
