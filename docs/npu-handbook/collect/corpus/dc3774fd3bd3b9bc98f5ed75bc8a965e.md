# 盛夏骊歌 化育芳华—化学与化工学院举行2026届本科生毕业典礼暨学位授予仪式

6月22日下午，化学与化工学院2026届本科生毕业典礼暨学位授予仪式在学院楼报告厅顺利举行。学院院长顾军渭、党委书记傅茂森，校友代表、西安航天远征流体控制有限公司总经理李洪春，学院班子全体副职、院长助理、系主任、教师代表、毕业年级辅导员、班主任、学院办公室人员以及2026届全体本科毕业生齐聚一堂，共同见证这场青春与梦想的盛大启航。毕业典礼由学院党委副书记姚东东主持。
典礼在庄严雄壮的国歌声中正式拉开帷幕。全体师生肃立，目光坚定，激昂的旋律不仅是对祖国的深情告白，更是化院学子即将奔赴四方、报效家国的铮铮誓言。
副院长田威宣读了2026届全体本科毕业生名单。每一个名字的背后，都是四年寒窗的勤勉与汗水，汇聚成今日的累累硕果。
副院长张宝亮宣读了2026届优秀毕业生名单。14名在学业科创、社会实践等方面表现突出的学子，充分展现了化院青年的风采与担当。副院长张宝亮、陈凯杰共同为获奖学生颁发荣誉证书及纪念礼物，勉励大家珍惜荣誉、接续奋斗，在新的征程上再创佳绩。
毕业生代表、2022级化学类（强基计划）专业王晨昱同学深情回溯了在化院求知探索的青葱岁月，从实验室里的专注钻研到图书馆里的挑灯夜读。他代表全体毕业生向悉心栽培的师长、朝夕相处的同窗表达了最诚挚的感谢，并许下了“以所学回报社会，以实干书写青春”的庄严承诺。
在校生代表、2023级化学类（强基计划）专业吴黄艺舒同学向即将踏上新征程的学长学姐们送上了最美好的祝福。她表示，未来将以优秀毕业生为榜样，传承化院优良学风，在学习科研中脚踏实地、追求卓越。
教师代表闫毅教授寄语毕业生。他结合自身科研经历，鼓励同学们在未来的人生道路上，既要仰望星空，心怀远大理想，也要脚踏实地，锤炼过硬本领，始终保持对科学的好奇与热爱，在各自的领域发光发热。
学院2008届校友李洪春分享了自己从高分子专业走向航天一线的奋斗历程，以“除夕夜攻关技术难题”的切身感悟勉励学子：心怀家国、踏实做事，将个人发展融入国家战略，在服务社会中实现人生价值。
在校友班级联络员聘任环节中，傅茂森为五位2026届新任校友班级联络员颁发了聘书，顾军渭为他们佩戴上校徽。这枚闪耀的校徽，既是西工大人的身份印记，更寄托着母校对学子“饮水思源、情系工大”的深情厚望，成为连接校友与母校、校友与校友之间的情感桥梁。
毕业生代表心怀感恩，为学院精心准备了亲手书写的书法画轴，内容是以“化院学子，永念师恩”为句首的藏头诗。八句诗句，句句藏情，既寄托着化院学子对母校的深深眷恋，也承载着对恩师的崇高敬意。
顾军渭以“初心、匠心、平心”为主题寄语全体毕业生。一要守“初心”，永葆报国情怀，将个人理想融入国家发展，主动奔赴祖国最需要的地方；二要铸“匠心”，坚持实干创新，沉下心深耕专业，以实干攻克难题，以创新成就价值；三要秉“平心”，恪守修身律己，在顺境中清醒、在逆境中坚守，终身学习，成长为有担当的时代新人。祝愿同学们以微观之力成就宏观之功，前程似锦。
顾军渭、傅茂森为优秀毕业生和优秀毕业论文获得者逐一拨穗、颁证。方寸证书，镌刻着无数日夜的求索与坚守；流苏轻扬，见证着从青衿学子到国家栋梁的蜕变。
教授代表田威、陈凯杰、闫毅、史学涛为毕业生拨穗、颁证。每一次拨穗，都是对青春奋斗的最高礼赞；每一次握手，都饱含着师长的深深祝福与殷切期盼。
聚散终有时，未来皆可期。衷心祝愿化学与化工学院2026届全体本科生毕业快乐！始终牢记“公诚勇毅”校训，弘扬“三实一新”校风，在新的人生征程中乘风破浪，前程似锦，用奋斗谱写无愧于时代的青春华章！
