# 心理科-西北工业大学医院

西北工业大学心理科成立于2020年1月，在两校区医院均设门诊。科室配备主治医师3名、心理测评师及物理治疗师2名。配备全套心理测评系统、近红外脑功能成像系统、重复经颅磁刺激治疗仪、机器人导航的精准经颅磁刺激仪、经皮微电刺激仪、多通道生物反馈治疗仪等各类先进的评估及治疗仪器，可进行评估、诊断，以及药物治疗，物理治疗，正念、催眠、认知行为、团体心理治疗等综合治疗。科室作为陕西省关心下一代儿童青少年心理健康研究中心的主要工作力量，立足高校，面向师生，学科特色突出，在儿童青少年心理诊疗方面有着较强的优势。
仪器简介：
一、测评仪器：
1、近红外脑功能成像系统：一种客观仪器检测，可快速检测抑郁症、焦虑症、双相情感障碍、精神分裂症等精神心理疾病，实现心理疾病早发现、早预防、早治疗的目标。
2、心理测评系统：通过自评或他评量表的形式将被试者的心理特征量化，根据不同需要可进行情绪、智力、个性特征、发育水平、健康水平等方面评估。
3、脑电图仪：通过获取脑部的自发性生物电位并加以放大，记录脑细胞群的自发性、节律性电活动。用于精神心理疾病、脑器质性疾病的辅助诊断及鉴别诊断。
二、治疗仪器：
1、重复经颅磁刺激仪：利用时变脉冲磁场无创透过颅骨，作用于中枢神经系统，产生感应电流，从而影响脑内代谢和神经元兴奋性，达到改善及治疗精神和神经疾病的效果。广泛应用于治疗抑郁症、焦虑症、强迫症、失眠等精神心理疾病，是心理科常用的物理治疗设备，具有无创、无痛、起效迅速、安全性高、副作用小等特点。
2、机器人导航的精准磁刺激仪：在重复经颅磁刺激基础上联合个体头颅影像结果，通过算法对患者病灶部位进行个性化精准计算，并对病灶部位进行靶向追踪，可精准刺激病灶靶点，产生比普通经颅磁刺激更快、更优的效果。
3、经皮神经低频电刺激仪（释烦离）：可通过微电流刺激三叉神经眶上神经和滑车上神经分支，调节中枢神经系统疼痛控制关键区域，抑制促觉醒系统，是FDA批准的全球第一款非药物预防治疗头痛失眠的医疗仪器。具有预防治疗头痛、改善失眠、舒缓减压、减少药物使用等功效，疗效广受师生好评。
4、多参数生物反馈仪：通过生理参数的自我反馈调节实现减压、缓解焦虑抑郁情绪的目的。分为团体生物反馈和个体生物反馈，通过渐进式肌肉放松训练、呼吸调整训练、正念训练、催眠训练、音乐疗法等专业放松训练模块，达到放松减压的目的。适合亚健康人群、高压力群体及情绪疾病人群。
