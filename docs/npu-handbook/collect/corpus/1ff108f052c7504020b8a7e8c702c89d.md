# 赴延安 悟初心｜学院赴延安开展红色实践活动

为充分发挥红色资源育人作用，扎实开展实践育人“三个一”，引导青年学生坚定理想信念、厚植家国情怀，9月19日至20日，教育实验学院/未来科技学院/学科交叉中心组织90名学生党员、入党积极分子及学生骨干赴延安，开展“弘扬延安精神 赓续红色血脉”红色实践活动。活动由学院辅导员王杰和玛哈带队。
登临宝塔山，感悟初心力量
9月19日抵达延安后，师生首登宝塔山，拾级而上俯瞰延安城，在宝塔与延河之间感受革命圣地的历史积淀。同学们共同诵读《回延安》、重温入团誓词，并聆听《中国共产党的百年历史和基本经验》专题课程。当晚，大家观看《红秀·延安延安》、体验胜利腰鼓，在鲜活情景中感受革命年代的精神力量。
走进红色旧址，追寻革命足迹
9月20日，师生先后走进延安文艺纪念馆、延安革命纪念馆和杨家岭革命旧址。在文艺纪念馆，师生重温革命文艺为人民服务的光辉历程，从《黄河大合唱》中体会其凝聚人心、鼓舞斗志的力量；在革命纪念馆，透过珍贵文物深入了解党中央在延安十三年的奋斗历程，并聆听《毛主席和小青马的故事》现场教学；在杨家岭，大家回望重要历史瞬间，聆听《爱国青年奔赴延安的信仰与抉择》专题教学，感悟先辈与进步青年的坚定信念。
感悟延安精神，凝聚青春力量
两天的实践把课堂延伸到革命旧址，让书本中的历史变得可感可知。从宝塔山到杨家岭，师生在一路寻访中深化了对延安精神内涵的理解。
李奇峰：站在宝塔山下，弹坑斑驳的塔身诉说着烽火岁月。共产党人在土窑洞里写下《矛盾论》《实践论》，也写下军民深情。真正的信仰不是悬空口号，而是苦难中选择相信与奋斗的坚定。
邵怡宁：延安革命纪念馆里，一件件实物与老照片带我重返峥嵘岁月。先辈凭信仰自力更生，铸就延安精神。作为新时代青年，我将把延安精神融入学习生活，摒弃浮躁，担当时代使命。
周黎轩：杨家岭七大礼堂前，毛泽东旧居仅一床一桌一盏煤油灯，却在此写下43篇重要著作。作为飞行器专业学生，我深知：从窑洞灯火到实验室灯光，变的是条件，不变的是矢志报国的初心。
此次实践既是一次追寻革命足迹的学习之行，也是一堂生动的实践育人课。未来，学院将继续依托红色资源深化实践育人，引导青年学子赓续红色血脉、书写奋进青春。
