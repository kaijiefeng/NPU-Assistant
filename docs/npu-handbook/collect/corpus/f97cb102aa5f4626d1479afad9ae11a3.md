# 精准学业指导 助力萌新启航——软件学院召开2026级本科生学业领航专题班会

为全面做好人才培养工作，助力2026级本科新生快速适应大学学习模式，夯实入学教育与学业规划根基，引导学生明晰专业发展与升学成长路径，9月10日下午，软件学院于教西D201召开2026级本科生学业领航专题班会。本次会议由本科生教学秘书郭艳静主持，2026级软件工程专业全体本科生参会。
本次班会是新生入学教育的关键环节，立足新生从高中到大学的学习模式转型需求，以“解政策、明规范、定目标、谋长远”为主线，系统梳理本科四年学业核心内容，切实帮助新生打破认知壁垒、理清学习脉络、树立科学的学业发展理念。
会上，郭艳静围绕本科人才培养体系，从培养方案、选课管理、学籍管理、推免深造等核心要点展开细致讲解，帮助新生建立对专业培养体系的完整认知。在选课管理板块，详细解读选课规则、学分认定流程与注意事项，结合常见选课误区逐一提醒修读要点，引导同学们科学规划学期修读计划。学籍管理板块重点宣讲学业预警、学籍异动、毕业审核标准等刚性要求，严明学业底线，倡导自律严谨的治学态度。针对新生高度关注的升学发展问题，逐条解读推免政策细则，清晰阐释学业评价标准、评优推免条件等，直观厘清本科阶段成长路径，引导新生尽早树立长远学业目标，做好阶段性学习规划。
班会尾声，郭艳静对2026级新生提出殷切期望。她勉励同学们把握大学全新起点，深耕软件工程专业，找准个人定位，夯实专业理论基础，锤炼工程实践能力，秉持软件报国使命担当，潜心向学、笃行不怠，在专业学习中锤炼本领。
本次专题班会内容详实、靶向精准、指导性强，有效回应了新生在课程学习、升学发展等方面的核心困惑，高质量完成了新生学业启蒙教育。下一步，学院将立足“软件*AI+X”人才培养特色，常态化开展学业指导、生涯规划、课堂教学反馈、学风建设系列活动，全方位助力学生夯实成长根基、明晰发展航向，厚植优良学风。
