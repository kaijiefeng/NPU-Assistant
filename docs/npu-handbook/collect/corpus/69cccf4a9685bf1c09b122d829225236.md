# 【勤工助学】文化遗产研究院勤工助学岗位招聘启事（报名截止：2023年2月27日）

岗位名称：研究生助教岗位
岗位类型：固定岗
招聘人数：研究生2人
工作地点：新校区教东/教西
联系电话：029-88491395
工作时间：
2022-2023学年春季学期，按照老师课程安排，每周4课时工作量，有工作津贴。
工作内容：
1.须在聘期内取得学校发放的研究生助教培训结业证书。
2. 全程跟随主讲教师听课，批改作业和辅导答疑。
3. 参加平时、期中、期末考核的整理归档等相关工作。
4. 与学生积极沟通，并及时向主讲教师反馈学生学习效果、 作业等信息。
5. 承担主讲教师安排的其他与教学相关的辅助工作。
6. 实验类教学助教岗位需协助承担仪器、设备管理等工作。
7. 遵守学校安全与保密管理等相关规定。
申请要求：
申请人须为我校全日制在读研究生，且须满足以下条件：
1. 遵纪守法，诚实守信。
2. 学业成绩良好，工作责任心强，学有余力，具有相应课程扎实的基础知识。
3. 没有同时担任助管工作。
4. 本人提出申请且经导师同意。
5. 申请研究生课程助教原则上要求博士研究生或二年级以上硕士研究生。
报名方式：
于2月27日前填写申请表后发送至邮箱。
邮箱地址：[已脱敏:邮箱]
邮件标注“姓名+校区+学院+学号+联系方式”。
欢迎踊跃报名！
