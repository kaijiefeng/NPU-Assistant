# 智算融合探前沿，交叉创新启未来——中山大学廖少林教授来院作《智能科学 (AI for Science)》专题学术报告

2025年5月21日，“航海大讲堂”学术报告第69讲在学院201会议室顺利举行。本次讲座特邀中组部国家海外高层次引进人才、中山大学电子与信息工程学院教授廖少林担任主讲嘉宾，以《智能科学 (AI for Science)》为题，深入探讨了人工智能在科学计算与工程应用中的前沿进展，重点展示了深度学习神经网络与大模型算法如何赋能传统领域的智能化升级。
报告首先以物理信息神经网络（PINN）为例，剖析了AI for Computational Science（AI4CS）的变革潜力。通过将物理定律嵌入深度学习模型，PINN能够高效求解复杂方程，大幅提升科学计算的精度与效率，为流体力学、材料模拟等领域提供全新研究工具。AI与科学计算的结合不仅是方法创新，更是研究范式的根本转变。
在通信领域，传统电磁计算面临复杂度高、耗时长等挑战。而智算电磁学（AI for Electromagnetics，AI4EM）结合信息压缩技术，为6G通信、智能反射面（RIS）等场景提供了颠覆性解决方案。AI算法可快速优化电磁波调控，显著提升通信系统性能，推动无线网络向自适应、智能化方向演进。
在感知与成像领域，AI大模型正展现出广阔的应用前景。例如，基于电磁信号的非接触式监测技术，可精准识别人体心跳、呼吸及手势动作，为智慧医疗、人机交互等场景提供核心支持。
随着AI与科学计算的深度融合，智能科学（A4S）将在通信、医疗、能源等领域催生更多颠覆性应用，为人类社会进步注入强劲动力。此次报告让同学们深刻认识到人工智能与科学计算融合的巨大潜力，特别是在通信、医疗等领域的创新应用令人耳目一新。
(审核：刘朝亚，王银涛）
