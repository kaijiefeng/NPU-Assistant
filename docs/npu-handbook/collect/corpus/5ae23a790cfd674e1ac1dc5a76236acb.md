# 关于本科结业生报名参加秋季学期课程考试的通知

各教学单位，各位同学：
现将2026-2027学年秋季学期本科结业生报名参加课程考试事项通知如下：
一、考试报名
2026届本科结业生请于9月25日至28日通过“翱翔教务”自行报名（仅限秋季学期开设的课程，网课除外），学生所在学院及开课单位请于9月30日前完成审核工作，报名及审核流程见附件。
二、考试安排
课程考核以任课教师或开课单位要求为准。报名的结业生需及时登录“翱翔教务”，进入“考试管理”，在“结业生报名申请”中查看考试信息。
三、成绩录入
请各单位依据课程考试安排完成结业生的成绩录入，并按照《西北工业大学本科生考试管理办法》（办转教字〔2023〕7号）要求及时完成考试材料的归档工作。
（文字：刘晗、郑波；审核：王劲）
