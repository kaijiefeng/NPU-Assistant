# 渝”你同行，数统启航——2024级重庆籍新生见面会顺利召开

2024年12月10日晚19：00，西北工业大学数学与统计学院重庆招生组在启翔楼357会议室召开了2024级重庆籍新生见面会。学校招生办公室姚远、陈雪琦、数学与统计学院副院长郭千桥、学院资深教授彭国华、重庆招生组组长林伟、招生秘书李彦吉、重庆籍学生代表谭肖遥以及三十余名重庆籍新生参加了会议，见面会由院长助理刘晓刚主持。
校招办姚远在欢迎辞中对重庆籍新生们的到来表示热烈欢迎，并简要介绍了西工大在重庆市招生情况，强调招办会持续关注大家在校期间的成长，希望大家未来四年制定明确的学业目标，积极参与社团活动，培养终身学习的好习惯。
林伟老师跟同学们强调，大学学习生活要学会自律，养成良好的生活习惯；培养自主能力，独立思考，勇于担当；善于自思，不断反思，提升自己；坚定自强信念，为实现人生目标而努力拼搏。相信同学们一定能在丰富多彩的大学生活中不断成长，书写属于自己的精彩篇章。
彭国华教授以其丰富的学术背景和深厚的教育情怀，与同学们分享了个人求学的经历，希望大家能够珍惜眼前的学习机会。他强调，大学学习与高中阶段的学习有着本质的区别，他鼓励同学们转变学习观念，注重学习方法。在大学的学习旅程中，同学们应当深入探究每个知识点的起源与演变过程，力求对知识体系有一个全面而系统的把握。他提倡立体化的学习模式，而不是离散式或平面式，要注重思维训练的深度与广度，不断培养批判性思维和创新能力。
谭肖遥同学结合个人发展经历向新生们分享了自己的大学学习生活经验。讲述了大学学业成绩的重要性、如何平衡学习与社团活动、参与竞赛项目、社会实践等实用技巧。他建议大家在大学四年中一定要找到自己喜欢的事情，留下终生难忘的回忆。他的分享贴近新生实际，赢得了在场同学的共鸣。
在座谈交流环节中，新生们积极提问，就自己关心的问题与在场的老师和学长进行了深入交流。在互动环节，招办姚远老师和陈雪琦老师还为同学们发放了颇有意义的小礼品。
最后，郭千桥副院长进行了总结讲话。他首先对与会学生和校招办老师表达了感谢。郭千桥表示，数统学院负责数学公共课的教学工作，大家在数学课程学习中遇到任何问题都可以跟任课教师和招生组交流请教；最后，希望大家大学四年树立明确的目标，也希望能够加入重庆招生团队，为我校生源质量进一步提升贡献力量。
此次重庆籍本科新生见面会的成功举办，不仅让新生们感受到了学院的温暖和关怀，也为他们的大学生活开启了一个良好的开端。后续数学与统计学院将继续关注新生的成长和发展，为同学们提供全方位的支持和帮助。
