# 网络空间安全学院召开2026年新认定研究生导师谈话会

10月10日上午，网络空间安全学院在爱生楼401会议室举行2026年新认定研究生导师谈话会。学院党委书记张文涛、副院长刘志强、党委副书记杜瑶组成谈话小组，围绕导师责任、师德师风、学生培养、安全稳定等议题与新认定导师面对面交流。
张文涛首先向新认定导师表示祝贺，指出导师既是荣誉更是责任，研究生培养导师是第一责任人，要始终牢记立德树人根本任务，全程关心学生成长成才，从招生、培养到就业、心理健康都要用心用情。要坚持师德第一标准，德高为师、身正为范，谨言慎行，守住底线。希望大家珍惜荣誉、履职尽责。
杜瑶副书记结合分管工作分享感悟，提出导师往往是学生印象最深、最感恩的人，鼓励导师落实立德树人根本任务，既做学术导师，更做人生导师。要重点抓好三件事：全过程常态化开展职业生涯规划，服务高质量就业；把心理健康教育抓在日常；守牢安全稳定底线，加强宗教、保密、意识形态、网络文明等教育提醒。
刘志强副院长强调导师是教师队伍中的核心岗位，学生的学业、生活、思想都要关心。培养入口和培养过程同样重要，要全年重视招生，严把生源质量关。同时结合学术不端和师德师风等案例提醒导师坚守学术诚信底线。他强调，讲底线不是束缚手脚，而是底线思维，最终目的是让学生健康成长、真正成才。
会议最后为新认定导师颁发了聘书，并组织签订研究生导师岗位责任书。导师们表示，将珍惜荣誉、扛起责任，严守师德底线，努力做学生为学、为事、为人的表率，为学院研究生培养和学科发展贡献力量。
