# 凝聚青年力量 共话时代发展——电子信息学院本科生第二党支部举办主题读书分享会

4月24日，电子信息学院本科生第二党支部组织开展了“凝聚青年力量 共话时代发展”主题读书分享会。活动围绕青年发展、法治建设、国家战略等主线展开，吸引了入党积极分子、发展对象、预备党员及正式党员共18人参加。支部委员韩艺林同志主持活动。
聚焦政府工作报告 彰显青年关怀导向
分享会上，姜一潢同志首先就2026年政府工作报告进行系统解读。他从青年就业创业扶持、民生福利保障、人才培育发展三个维度切入，深入分析了国家在新时代背景下对青年群体的政策支持与发展要求。他提到，青年既是国家发展的受益者，更是推动社会进步的重要力量，青年党员应强化责任担当，把学习成果转化为干事创业的实际行动。
树立正确政绩观 榜样引领知行合一
钱琪珂同志围绕“青年大学生党员如何树立和践行正确政绩观”展开分享。她以新发展理念和高质量发展为衡量标尺，结合黄文秀、张桂梅等先进典型事迹，以及“形象工程”等反面案例进行对照剖析。她号召青年党员立足学业实际，坚持实干导向，在服务社会中主动担当，用务实行动诠释正确政绩观。
深化法治实施 强化示范引领
牛宝田同志以“法治实施论”为主题，从理论与实践相结合的角度阐述了法治的生命力在于实施。他表示，党员应在学习与实践中不断强化法治意识，自觉发挥示范引领作用，将法治理念贯穿学习、工作和生活各方面，做到知行合一、以行践法。
发展海洋经济 服务国家战略
段守一同志围绕“海洋经济高质量发展”进行分享，系统阐释了海洋经济在国家发展全局中的战略意义。他强调，要坚持陆海统筹、深化对外开放与国际合作，提升我国参与全球海洋治理的能力与水平。他勉励青年党员树立全局观念，将个人发展融入国家战略，为加快构建现代海洋产业体系贡献力量。
总结提升 凝聚奋进力量
活动最后，韩艺林同志表示，本次读书分享会主题鲜明、内容充实，既深化了理论学习，又强化了实践导向。下一步，党支部将持续丰富学习载体、创新学习形式，引导广大党员在学思践悟中不断提升政治素养与履职能力，以更加昂扬的姿态投身新时代发展实践。
