# 计划财务部召开预算管理专题研讨会

3月16日上午，计划财务部组织召开了业务研讨会，围绕本年度预算执行、人工智能对财务管理的影响等核心议题展开深入研讨。计划财务部全体处科级干部及业务主管参加会议。
会议全面分析了学校当前财务运行状况，重点研究了本年预算执行和编制的难点与对策，以及当前人工智能快速发展背景下的财务转型。
会议强调，2026年预算管理要从“被动保障”向“主动治理”转变。全体人员要统一思想，深刻领会国家和学校关于厉行节约的决策部署，将“开源节流、提质增效”作为财务支持学校可持续发展的核心任务。一方面，在预算编制上“下真功”，深化零基预算改革，压减非刚性、非重点支出，把有限的资金用在刀刃上，集中资源保障学校重大战略和重点项目落地；另一方面，在预算执行上“求实效”，严格核算审核，强化绩效导向，建立各类项目经费全过程监督管理机制，确保每一笔资金都能发挥最大效益。同时，随着信息技术从辅助工具转变为重塑大学核心竞争力的关键力量，所有人员必须主动适应发展新趋势，广泛调研先进高校的有益做法，围绕“人工智能+财务”的发展进行深入研究。
会议要求，全体财务人员要提高政治站位，将财务工作自觉融入学校发展大局，建立常态化学习机制，一是精准把握财经法规与纪律要求，筑牢廉洁自律防线；二是主动拓展知识储备，克服“本领恐慌”，提升运用数智化手段解决实际问题的能力；三是转变工作思路，加强研究创新，跳出传统思维定式，推进支出标准建设与预算管理的有机融合，探索建立符合高校特点的成本分担机制。
全体财务人员要将凝聚的共识转化为实际行动，为学校“十五五”规划开好局、起好步提供坚实可靠的财务保障，以实干实绩为学校“一十百千”发展目标和“天下工大、世界三航”远景目标的实现贡献坚实财务力量。
