# 校长宋保维与学校国家级人才代表交流座谈

为深入贯彻落实主题教育总体要求，以深化调查研究推动解决发展难题，着力解决人才成长成才过程中的急难愁盼问题，6月5日下午，学校召开人才代表座谈交流会。校长宋保维同校内16位国家级人才代表深入交流、共话发展。党委常委、副校长侯成义，校长助理兼学校办公室主任王宇波参加会议。座谈会由侯成义主持。
座谈会上，每位人才都结合自身成长经历，畅谈在校生活工作的收获与感受，围绕未来五到十年的工作规划畅所欲言，并重点就学校学科建设、人才培养、人才引育、团队建设、考核评价、资源配置等方面工作提出了意见和建议。
侯成义对学校人事人才相关政策进行了详细解读，并就代表们提出的关于人才支持措施、科研团队建设、服务保障体系、校内资源供给等方面问题进行了一一回应和解答，对需要继续完善和逐步落实的事项，要求相关职能部门研究落实。
宋保维对国家级人才在学校各项事业发展中作出的重大贡献表示感谢。他指出，要聚焦学校发展过程中的问题短板，进一步发挥国家级人才的作用，并结合学校现阶段发展实际，对国家级人才提出了三点希望：一是要立大志，个人要有更高的追求，要始终将服务国家重大战略需求、培养“总师型”人才、服务学校学科建设作为事业发展的基本定位；二是要谋大局，要坚持面向世界科技前沿基础问题的研究方向、瞄准国家重大战略工程和“卡脖子”技术谋划布局，准确定位自身发展方向，努力成为所在领域的“出题人”；三是要有大气，要做到有眼界、有心胸、有站位，要重视青年、关心青年，加强团队建设助力青年人成长，要善于合作、敢于合作，并积极深化产教深度融合。
宋保维强调，学校将进一步健全人才服务保障体系，竭尽全力支持各类人才的工作，让教师乐业、学生乐学，打造和谐健康、师生至上的学校发展生态。同时，进一步深化人才发展体制机制改革，优化资源配置体系，为教师打造干事创业的平台，调动和激发高层次人才的积极性和主动性。最后，他表示，希望各位国家级人才要全面贯彻落实党的二十大关于教育、科技、人才的战略部署，为推动学校内涵式高质量发展作出新的更大贡献。
人事处处长唐玉生等相关职能部门主要负责人参加会议。
