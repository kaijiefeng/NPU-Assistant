# 劳务费报销指南

一、劳务费发放流程

1. 登陆翱翔门户，点击“财务系统—网上申报管理系统”制作劳务费薪酬发放表，提交劳务费申报信息，其中：

（1）在职职工、退休返聘人员、非事业编制人员、劳务派遣人员，通过“校内人员其他工薪收入申报”模块制单；
（2）校外人员，通过“校外人员劳务申报”模块先采集后提交；
（3）学生发放奖助学金或其他劳务费，通过“学生酬金申报”模块提交；
（4）学生发放助研费，通过“研究生助研费申报”模块提交。

2. 申报成功后，打印薪酬发放表。发放表经学院或部门主管、项目负责人和经办人签字确认，同相关附件一并提交财务处自助投单机。（备注：通过“研究生助研费申报”模块提交的网报单，由学工部集中批量打印交财务处发放）

3. 外国专家劳务费发放流程

若外国专家有我国国内银行卡，可直接发放；若外国专家无国内银行卡，可通过境外汇款支付或由校内老师代领。

直接发放或通过境外汇款支付外专劳务费，薪酬发放表上发放类别选择“外籍劳务”；由校内老师代领外专劳务费，薪酬发放表上发放类别选择“代领外籍人员劳务费”。

通过境外汇款支付外国专家劳务费，需提前通过“翱翔门户—办事大厅—境外汇款申请”，薪酬发放表上需手动注明汇款手续费由我方承担还是由对方承担。

境外汇款支付外专劳务费，校外人员银行账号、开户行及单位按以下信息进行采集：银行账号 102010169938；开户行 中国银行西安西工大支行；单位 西北工业大学（资金性质：济困助学专户）。

二、劳务费报销标准及所需资料

1. 专家咨询费/评审费

报销资料：薪酬发放表；劳务费信息采集表（原件，模板见财务处官网—常用下载）；评审费会议通知或邀请函，若无，需附情况说明（负责人签字）。

发放标准（税前）：高级专业技术职称人员1700-2800元/人天；其他专业人员1000-1700元/人天；院士、全国知名专家，可按照高级专业技术职称人员的标准上浮50%执行。横向可按上述标准上浮50%执行；校内专家科研项目发生的评审费与校外专家标准一致；学校教学、管理等其他业务咨询活动发生的评审费按照校外专家标准的60%发放。

不同形式组织的专家咨询活动适用的专家咨询、评审费发放标准：会议、现场访谈或勘察形式，会期为半天的按发放标准的60%执行，会期不超过两天（含两天）的按发放标准执行，会期超过两天的前两天按此标准执行、第三天及以后按此标准的50%执行；通讯形式按次计算，每次按此标准的20%-50%执行。

2. 论文评阅/答辩费

报销资料：薪酬发放表；劳务费信息采集表（原件）；学位论文答辩计划审批表或学位论文答辩委员会专家备案表（复印件）。

发放标准（税前）：博士论文评阅费400-600元/篇，博士论文答辩费400-500元/人，答辩秘书300-400元/人；硕士论文评阅费200-400元/篇，硕士论文答辩费200-300元/人，答辩秘书150元/人；论文“盲评”送审劳务费50元/篇。注意：导师不得从本人指导的学生论文评阅答辩活动中领取酬金；项目负责人不得领取。

3. 讲课费

报销资料：薪酬发放表；劳务费信息采集表（原件）；邀请函或讲座、讲课、报告通知，若无，需附情况说明（负责人签字）。

发放标准（税前）：副高级及以下技术职称专业人员每学时不超过600元；正高级技术职称专业人员每学时不超过1200元；院士、全国知名专家每学时一般不超过1800元。注意：讲课费按实际发生的学时计算，每半天最多按4学时计算。

4. 外籍专家劳务费

报销资料：薪酬发放表；外国专家薪酬收据（模板见财务处官网—常用下载）；专家工薪、专家讲课费需附劳动合同（劳务合同）或工作协议，专家咨询费（讲座费）、专家补贴需附邀请函或讲座通知等支撑材料（若无，附情况说明，负责人签字）；外国专家项目信息回执单（用于国际合作处审批备案）；外国专家护照复印件；由校内老师代领外专劳务费，另需附垫付声明（模板见财务处官网—常用下载，需垫付人签字）。

发放标准：专家工薪依据核算的工作量和预期成效，参考费用标准约定报酬，并签订劳动合同（劳务合同）或工作协议；专家咨询费（讲座费）不超过3000元/次；专家讲课费院士、世界知名学者不超过1800元/课时，正高级不超过1200元/课时，副高级及以下不超过800元/课时；专家补贴不超过1000元/天。注意：专家工薪、专家咨询费（讲座费）、专家讲课费、专家补贴只能选择其中一种方式给予资助；对单次来华工作90天以上或采取远程方式的专家，项目负责人须与其核算工作量，依据预期成效和费用标准约定报酬，并签订劳动合同（劳务合同）或者工作协议。

三、文件依据

《西北工业大学评审费等劳务费支出管理办法》（办转字〔2020〕94号）；《西北工业大学外国专家项目及经费管理办法》（校外字〔2023〕319号）。

四、其他注意事项

1. 我校劳务费报销实行实名发放制，即发放到领款人本人银行卡（外籍无国内银行卡的除外），由学校代扣代缴个人所得税，原则上不得发放现金。
2. 劳务费信息采集表需提供原件，采集表上需领款人实名签字，如通过线上方式提供劳务，无法取得领款人实名签字，需在附件资料中注明是通过线上方式进行的劳务。
3. 劳务费的发放标准均为税前标准，不得超标。
