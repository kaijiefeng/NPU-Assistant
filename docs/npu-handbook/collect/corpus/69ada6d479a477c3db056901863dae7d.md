# 北研院党支部召开2022年度组织生活会-西北工业大学

根据学校《关于召开2022年度组织生活会和开展民主评议党员工作的通知》（组字〔2023〕3号）和资产公司党委《做好2022年度组织生活会和开展民主评议党员工作方案》要求，3月15日上午，北京研究院党支部召开了2022年度组织生活会。
会上，党支部书记方文杰代表北京研究院党支部委员会向党员大会进行了述职。随后，支部党员逐一发言，结合会议主题讲收获提高，讲差距不足，并深入开展自我批评和批评。
资产公司党委委员杨安庆对本次组织生活会进行了细致点评。他表示，北研院党支部各位党员的发言能够密切围绕会议主题，深入挖掘自身问题和不足，在批评环节以业务提期望、提要求，会议总体达到了“照镜子、促团结”的预期。
方文杰在总结时表示，2022年迎来了党的二十大的胜利召开，今年作为全面贯彻落实党的二十大精神开局之年，北研院党支部要以习近平新时代中国特色社会主义思想为支撑，把干事创业的力量凝聚到党的二十大各项任务上来，增强“四个意识”、坚定“四个自信”、做到“两个维护”，落实立德树人根本任务，扎实推进学校“双一流”建设。
