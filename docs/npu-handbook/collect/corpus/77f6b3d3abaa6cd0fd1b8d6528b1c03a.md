# 人事处党支部传达学习校领导讲话精神

5月26日下午，人事处党支部召开支部大会，传达学习李言荣书记在学校学习贯彻习近平新时代中国特色社会主义思想主题教育读书班集中交流会暨专题党课上的讲话精神。学校党委常委、副校长侯成义和支部全体党员参加。会议由人事处处长、党支部书记唐玉生主持。
唐玉生结合自己的学习体会，带领全体党员系统全面深入学习了李言荣书记在专题党课上的讲话精神。他表示，李言荣书记的党课深刻剖析了学校当前面临的机遇和挑战，明确了未来的发展目标和思路举措，大家要结合各自岗位职责深入学习、认真领会，不断提高人事人才工作质量。
侯成义在讲话中指出，李言荣书记在党课上的讲话站位高、内容实，不仅明确了学校今后一段时期的发展目标和路径，而且对学校人事人才工作提出了明确要求，具有重要的指导意义。人事处全体人员要全面、深入、细致学习讲话精神，与自己的工作相结合，把自己摆进去、把职责摆进去，坚持大局意识、系统思维和辩证思维，做好定位，锚定目标，科学施策，不断推动学校事业高质量内涵式发展。
（人事处 文/张慧杰 图/耿婷 审核/唐玉生）
