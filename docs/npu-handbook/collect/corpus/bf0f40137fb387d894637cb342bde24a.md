# 范晓丽

范晓丽
职务：JAC委员/玛丽女王工程学院院长
电话：029--88431978
邮箱：xlfan@nwpu.edu.cn
个人简介链接：http://teacher.nwpu.edu.cn/fanxiaoli
范晓丽，教授，博导，政协陕西省第十二届委员、西安市碑林区第十九届人大代表。香港中文大学博士，加拿大西安大略大学博士后，牛津大学、杜克大学访问学者。兼任陕西省高等教育学会中外合作办学分会副会长。研究方向为材料微尺度模拟，主要从事热力学稳定结构、性质、性能，及微观反应动力学过程和机理研究。主持国家重点研发计划项目课题、国家自然科学基金、陕西省自然科学基金重点项目等研究项目10余项。研究成果在Phys. Rev. Lett.、J. Am. Chem. Soc.、Nano letters等知名期刊上发表SCI论文150余篇，成果获陕西省高等学校自然科学奖一等奖，河南省自然科学优秀论文一等奖。
