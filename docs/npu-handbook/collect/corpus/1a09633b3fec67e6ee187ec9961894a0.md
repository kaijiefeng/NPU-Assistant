# 【关工委工作】我校召开“五老”骨干工作培训会

4月30日上午，我校在友谊校区健翔楼五楼多功能厅召开“五老”骨干工作培训会。校关工委主任陈建有，委员黄迪民、王友明，教务部副部长张学良，发展规划处六级职员李苗，离退休工作处处长赵洪章，副处长马俊，以及“五老”骨干等60余人参加会议。会议由赵洪章主持。
张学良从人才培养的“西工大现象”这一鲜明标识切入，系统阐述了学校“总师育人文化”内涵、“总师型”人才培养体系构建逻辑与实践路径。他对“五老”长期以来对人才培养工作的关心与支持表示感谢，希望大家继续以丰富阅历和深厚情怀，为“总师型”人才培养贡献智慧。
李苗就学校“十五五”建设规划的编制过程、规划体系、发展基础、核心内容及关键指标等作了全面介绍。她谈到，规划是学校迈向世界一流大学前列的行动蓝图，真诚感谢老一辈对学校发展的倾情奉献与持续关注，期待大家继续发光发热，助力学校在新征程上行稳致远。
陈建有在讲话中谈到，关工委工作的根本在“人”，关键在发挥“五老”的优势作用。他就做好关心下一代工作提出三点希望，一是持续提升“五老”骨干的工作本领，强化思想引领力与感召力；二是不断擦亮品牌活动，让红色基因和育人传统薪火相传；三是充分发挥“五老”在立德树人中的独特作用，深度融入学校人才培养大局，助力“总师型”人才的精神塑造和价值引领，为学校高质量发展贡献智慧与力量。
