# 分析测试中心顺利通过CNAS检测实验室能力认可复评审

5月20日，中国合格评定国家认可委员会（CNAS）对西北工业大学分析测试中心开展检测实验室能力认可复评审。本次评审由中国兵器工业第二一三研究所朱安宁担任组长，兵器工业西北地区理化检测中心谢华担任组员，以现场评审方式，依据相关认可准则与应用说明，通过现场查看、演示试验、文件查阅、人员考核等，对中心认可检测项目及管理体系运行情况进行全面审核。
评审期间，专家组召开首次会议，明确审核安排与要求，听取中心工作汇报；详细核查实验室管理体系文件，现场逐一核验检测项目与技术能力，对发现问题予以反馈并给予专业指导。末次会议上，评审组充分肯定中心质量管理工作，一致认定其持续符合认可条件与能力要求，复评审圆满完成。
此次复评审通过，是对中心技术与管理水平的高度认可。中心将以此为契机，持续优化质量管理体系，强化对学校 “双一流”建设的支撑作用，以更专业、优质的服务，为社会提供科学、准确、高效、创新的测试服务。（文：陈建源 审：刘平）
