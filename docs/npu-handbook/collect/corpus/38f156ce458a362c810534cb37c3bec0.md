# 离退休党委机关党支部联合校工会党支部开展现场警示教育活动

6月26日上午，离退休党委机关党支部联合校工会党支部共24名党员赴秦岭违建警示教育中心开展现场警示教育活动。
在警示教育中心，全体党员通过图文影像和沉浸式展陈，系统学习习近平总书记历次来陕考察重要讲话重要指示精神和关于秦岭生态环境保护的重要指示批示，回顾秦岭北麓违建别墅整治过程，全体党员认真聆听，全方位了解了秦岭北麓违建问题专项整治的总体情况和秦岭北麓鄠邑段生态修复的成效，接受了一次深刻的党性教育与思想洗礼。
大家一致表示，将以秦岭违建典型案例为镜鉴，时刻绷紧纪律之弦，牢固树立践行正确政绩观，切实把教育成效转化为履职担当的实际行动，以清正廉洁务实的工作作风助力学校高质量发展。
（文字：王益婷；图片：王益婷；审核：马俊）
