# 青春为中国式现代化挺膺担当|青年宣讲团讲师田铭翔开展主题宣讲

3月28日下午，航天学院在学院楼C345举办《青春为中国式现代化挺膺担当》的主题宣讲活动，由西北工业大学青年宣讲团的讲师田铭翔担任主讲，宣讲从文化自信的角度讲时代变迁、谈青年作为，结合历史与现实，系统地阐述了新时代青年在文化自信中的责任与作为。
在“习语论文化”部分，田铭翔列举了近年来习近平总书记关于文化传承与人文交流的重要讲话。从考察洛阳龙门石窟时的谆谆教诲，到与外国领导人会谈时对文化等领域交流合作的重视，总书记这些重要的论述为新时代文化建设指明了方向，也让青年一代更好地理解文化自信。
通过对文化自信的解读，田铭翔自然引入了“今昔鉴文化”部分。通过对比古今展现了中华文化传播方式的历史变迁。从口口相授、碑刻书籍，到如今利用科技手段保存并传播，文化传承的形式不断丰富，其承载的民族精神与文化认同却始终如一。
随后的“实践兴文化”部分聚焦近年来我国文化事业的主要成就和发展。在完备的理论知识和思想引领作用下，我国文化事业繁荣发展，文化遗产保护工作和活化利用都取得了积极成效，充分彰显了文化繁荣与保护并重的实践路径。
宣讲最后落脚于“吾辈行文化”层面。守护文明根脉，赓续文化传承，不仅需要政策支持，更需要我们青年一代的奉献和努力。田铭翔表示，文化自信是根植于血脉的生命力，要实现文化的创造性转化和创新性发展，不断加强文化传播和交流互鉴，为文化传承注入不竭动能。
整场宣讲内容详实、脉络清晰，既体现了青年学子对中华优秀传统文化的深刻理解，也展现了新时代青年投身文化传承与创新的坚定姿态。
