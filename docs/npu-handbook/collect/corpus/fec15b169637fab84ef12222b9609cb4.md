# 【寒假项目】2026年教育实验学院/未来技术学院/学科交叉中心南洋理工大学飞行器设计寒假项目报名通知

为培养未来技术领域的“总师型”国际化人才，丰富全球胜任力教育教学资源，全方位提升学生的全球胜任力，教育实验学院/未来技术学院/学科交叉中心将于2026年寒假组织开展南洋理工大学飞行器设计项目。
一、学校简介
南洋理工大学是新加坡一所综合类研究型大学，是环太平洋大学联盟、全球大学校长论坛成员。学校在人工智能、机器人、航天飞行器、绿色能源、生命科学与医疗等前沿领域的科研实力突出，同时与全球60多所顶尖大学及多家知名企业保持紧密合作，打造了开放、国际化的科研环境。2026年QS世界大学综合排名第12位。
二、项目时间
2026年2月1日-2月8日
三、项目内容
项目包括材料力学、工程材料、空气动力学、飞行器设计等核心课程。此外，项目包括校园文化游览、实验室等机构参访活动。
四、项目费用
学费：14600元
费用包含：学费、住宿、机构参访、文化交流活动、接送机等。
费用不包含：国际机票及其他个人消费。
五、项目资助标准
亚洲地区不超过5000元/生，具体资助办法请见：https://guoji.nwpu.edu.cn/info/1025/5073.htm.
注：根据相关规定，一个自然年内，一名学生只可以享受一次短期项目资助；学院具体资助要求及标准请咨询本学院外事秘书。
