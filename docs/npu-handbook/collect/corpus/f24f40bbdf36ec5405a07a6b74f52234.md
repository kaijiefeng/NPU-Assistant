# 管理学院2025级数据科学与智能管理拔尖班选拔的通知

为贯彻落实《教育部关于在部分高校开展基础学科招生改革试点工作的意见》（教学〔2020〕1号）文件精神，提高拔尖创新人才培养质量，现开展管理学院2025级数据科学与智能管理拔尖班选拔工作。
一、面向对象
2025级管理类本科生。
二、选拔流程
（一）报名流程
1.2025年9月8日上午12：00前，将本人签字扫描版《管理学院数据科学与智能管理拔尖班申请表》（见附件）发送至联系邮箱，纸质版交至管理学院217办公室。
2.邮件与文件名称统一命名为“学号-姓名-行政班-转入申请”。
3.提交了申请表的学生，应加入QQ群，以便后续接收通知。
（二）考核方式
1.学院对申请材料进行审核后，以面试形式进行考核，具体安排另行通知。
2.重点考查学生的思想政治、学习能力、科研兴趣、创新思维、实践能力等。
