# 【关工委工作】网络空间安全学院举办“四个一”访谈暨“相约‘网小安’——银发导师面对面”活动

4月30日下午，网络空间安全学院在长安校区启真楼休闲吧举办“四个一”访谈暨“相约‘网小安’——银发导师面对面”活动。学院关工委副主任张泾周教授受邀与铸剑班学生代表畅谈科研历程与人生感悟。
四个一访谈
作为学院“读懂中国”和“四个一”访谈活动的重要组成部分，本次活动以师生访谈形式展开。陈松玲首先向同学们介绍了张泾周教授与西工大结缘四十余载的育人故事。1982年，张泾周从西北工业大学毕业并留校任教，师从学科创始人戴冠中教授，是网络空间安全学院成立时首批教师之一。随后，铸剑班学生王少君担任访谈主持人，围绕求学经历、科研故事等话题与张泾周教授展开深入对话。
访谈中，张泾周回忆起从农家子弟到考入西工大的求学之路。从飞机系到计算机系、自动化学院，直至并入网络空间安全学院，数十年的足迹恰是个人理想与国家需求同频共振的缩影。“并不需要刻意规划，国家需要、企业需要，我们就应该去做，踏踏实实把事情做好。”谈及技术报国经历，张泾周介绍，自己从早年服务医学信号检测等民生领域，到本世纪以来投身航空电源系统国防科研一线，团队成果已应用于歼-20、歼-16等先进机型。他深情回忆起戴冠中教授等老一辈师长兢兢业业、一丝不苟的治学风范，称这正是学校“三实一新”校风的真实写照，也与国防军工领域“隐姓埋名、为国铸剑”的使命紧密相连。
银发导师面对面
在“银发导师面对面”自由交流环节，同学们围绕学业规划和科技发展踊跃提问，气氛热烈。大一学生玛迪娜就如何培养跨领域能力提出困惑。张泾周以自己为做好医学项目刻苦钻研医学专著、与北京301医院专家顺畅沟通的经历为例，勉励同学们打好基础、博闻强识：“大学里设置的每一门课都有用，学好知识是为了培养能力，不要过早给自己设限。”李雨阳同学则抛出一个颇具深度的思考：人工智能高速发展如何促进社会文明进步、避免技术偏见？张泾周从AI与网络安全的伴生关系切入，强调了系统设计中去除个人偏见、引入第三方独立监督的重要性。陈松玲在交流中表示，关注技术背后的伦理命题，正是成长为“总师型”人才不可或缺的视野与自觉。当学生们开始思考科技如何更好地服务社会文明进步，也就迈出了从“学技术”到“担使命”的重要一步。
活动尾声，张泾周为青年学子送上人生赠言：不管从事什么职业，都要踏踏实实做好分内事，只要国家和社会需要，就是我们应该全力以赴去完成的本职工作。
本次活动将“四个一”访谈融入学院“相约网小安”品牌栏目，通过老一辈教授的言传身教，引导青年学生传承西工大优良传统，在强国建设新征程上自觉做有理想、敢担当、能吃苦、肯奋斗的新时代好青年。未来，学院“网小安”党建工作室将继续依托“相约网小安”系列活动，深入挖掘“五老”育人资源，为培养家国情怀深厚、追求卓越、引领未来的“总师型”网安人才持续赋能。
