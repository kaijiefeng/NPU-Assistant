# 西北工业大学网络空间安全学院开题答辩（李金梅）

一、开题答辩题目：网络情感信息空间构建关键技术研究
二、开题答辩人：李金梅
三、开题答辩时间：2023年12月24日 上午9点
四、开题答辩地点：友谊校区创新大厦A1201
五、开题内容简介：
大数据环境下网络情感信息量巨大，由此产生的信息情感数据亦磅礴复杂，针对此环境下网络情感信息空间的维度相关概念做以界定，对网络情感信息空间、情感维度空间构建和信息情感单元的特征分析和识别研究，有利于深度挖掘网络环境中的高动态、高热度、高危的网络情感信息空间数据隐含的内部规律和特征，能够较好地促进网络情感信息空间分析与监测的实时性、有效性、预测性的全面提升。对网络情感信息空间的情感倾向性和波动规律、表达和量化网络情感信息空间情感特征和规律等一系列问题的分析与研究，是网络情感信息空间的分级监测和危机预警的重要基础，对于促进社会网络空间环境的和谐稳定具有重要的现实意义。同时，网络情感信息空间背后隐藏的情感数据及各维数据指标的变化是网络情感信息空间演变和预警监测的着力点，在网络情感信息空间危机预警中不容忽视，探寻网络情感信息空间情感的变化规律和维度空间特征是网络情感信息空间大数据化进程中亟需解决的、具有重要现实意义的关键问题。
六、开题答辩人简介
李金梅，女，汉族，1986年2月出生，中共党员，学号：2022161108，网络空间安全学院电子信息专业，研究方向为网络空间数据安全，导师杜承烈教授。
