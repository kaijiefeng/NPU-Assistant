# 我要当总师”学生宣讲团第六期｜追总师蓝天足迹，做坚韧开拓先锋

为深入贯彻落实党的二十大和二十届三中、四中全会精神，认真学习贯彻习近平总书记关于教育、科技、人才的重要论述，大力弘扬总师育人文化，2025年12月14日，教育实验学院党委“我要当总师”学生宣讲团走进启真学生社区，以我国军民领域重大型号总设计师的成长故事为蓝本，引导青年学子将个人理想融入国家需求，用热血与担当书写青春答卷。学院本科生入党积极分子，学生骨干等参加活动。
宣讲团成员高悦芸、谢睿涵、张惠臻分别围绕歼-10C、C919、C929总设计师成长故事，细腻勾勒出科研工作者在困境中坚守初心、在难关前无畏攻坚、在技术封锁下自立自强的精神群像，让榜样力量跃然眼前。歼-10C总师扎根西北、矢志空天，推动中国战机跻身世界先进行列；他对设计细节的严谨苛刻，正是科研人精益求精责任意识的生动写照。C919总师从军用领域跨界民用航空，始终以沉着冷静的姿态带领团队直面危机、破解难题，彰显了科研带头人临危不乱的硬核担当。C929总师携团队与中国大飞机事业同向而行，用坚持不懈的工匠精神、矢志蓝天的坚定信念，书写着中国航空的蓝天新史诗。
“我要当总师“学生宣讲团将持续围绕弘扬总师育人文化开展系列活动，让更多青年走近总师，读懂总师成长的心路历程，感悟总师矢志报国的价值追求，引导青年学子立大志、明大德、成大才、担大任，努力成为堪当民族复兴重任的时代新人。
