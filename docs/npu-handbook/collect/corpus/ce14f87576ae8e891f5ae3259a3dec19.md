# 大国航母：深蓝力量——何佳高级专家讲授“感悟深蓝”课程

近日，航海学院校企协同“感悟深蓝”课程第六轮第六讲在长安校区顺利举行，中国船舶集团有限公司第七O一研究所高级专家何佳来校授课，全校200余名本科生聆听了主题为《大国航母：深蓝力量》的讲座。
何老师以当下美伊冲突局势作为开篇切入，先简明阐释航母的核心定义，再结合美军在军事冲突中的航母部署案例，提炼出航母的核心定位，并结合伊朗在对峙中面临的现实安全困境展开延伸评述，借此警醒所有人和平来之不易，应当倍加珍惜。
课堂上还梳理了世界航母发展简史，并聚焦中国航母的崛起之路，阐述了我国航母从无到有、从零起步的跨越式发展历程，以及现代航母的未来发展趋势与面临的全新挑战。
本次授课逻辑层层递进、内容详实深刻，紧扣国际时事，梳理航母百年发展脉络，解读前沿军工技术。课程尾声，何老师着重阐释 “国家兴亡，匹夫有责，落后就要挨打” 的道理，为讲座收尾，令在场学子深受触动、收获良多。
授课专家简介：
何佳，陕西潼关人，1998年毕业于武汉大学电气工程学院，2005年获华中科技大学能源与动力学院工学硕士，中国船舶集团有限公司第七O一研究所（中国舰船研究设计中心）高级专家。
