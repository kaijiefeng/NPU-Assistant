# 党委保卫部党支部召开深入贯彻中央八项规定精神学习教育动员部署会

3月25日，党委保卫部党支部召开了深入贯彻中央八项规定精神学习教育动员部署会。会议由党支部书记朱建军主持，全体党员及入党积极分子参加了会议。
会上，朱建军传达《中共西北工业大学委员会关于开展深入贯彻中央八项规定精神学习教育的实施方案》精神，他指出，开展深入贯彻中央八项规定精神学习教育，是巩固深化主题教育和党纪学习教育成果、推动全面从严治党向纵深发展的重要举措；广大党员要深刻认识此次学习教育的重要意义，在思想上高度重视，在行动上狠抓落实，确保学有质量、查有力度、改有成效，党支部委员要走在前，做表率，把服务质量和师生群众满意度作为检验学习教育成效的标准。
随后，朱建军做了深入贯彻中央八项规定精神学习教育专题党课，系统解读中央八项规定精神，深入剖析违反中央八项规定精神的具体表现，引导党员干部将学习教育内容转化为自觉行动。
最后，党支部开展了3月份理论学习及研讨。
