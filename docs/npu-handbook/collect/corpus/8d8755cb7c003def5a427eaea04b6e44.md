# 【学籍管理中心】休学、复学、保留学籍及提前毕业办理说明-西北工业大学研究生院

各位研究生同学：
如需办理休学、复学、保留学籍及提前毕业，请登录“研究生教育综合管理系统”，在“学籍异动”中进行相应申请，提交申请后，经导师——学院主管院长——研究生院学籍管理中心审核后方可生效。
审核完成后，可在自助打印机中打印纸质版学籍异动办理证明。
申请休学、复学、保留学籍及提前毕业的具体条件参见《西北工业大学研究生学籍、学历管理工作实施细则》。
学籍管理中心
