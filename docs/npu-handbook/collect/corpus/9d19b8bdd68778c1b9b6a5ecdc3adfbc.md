# 中共党员党组织关系转入、转出须知

各位老师、同学，现将中共党员党组织关系转入、转出须知告知如下：
由外单位转入材料学院：
1.网上转接党员组织关系，须在原单位通过党建信息化平台进行。转入党组织名称：中共西北工业大学材料学院委员会（如果无法搜索到具体学院，请转入中共西北工业大学委员会，务必备注“去向：材料学院委员会”）
2.如开具纸质版《党员组织关系介绍信》转入的党员，介绍信抬头：中共西北工业大学委员会，去向：材料学院。
由材料学院转出至其他单位：
4.需要转出党组织关系的党员，请填写《毕业生组织关系转接信息表》（附件1）发送到dangjian4@nwpu.edu.cn，1-3个工作日会进行办理，如特别着急，请电话联系。
联系电话：15102568016 张同学
5.需要开具党员材料证明的同学，请将说明公函、党员材料影印电子版发送至dangjian4@nwpu.edu.cn，1-3个工作日会进行联系。
联系电话：88460843 廖老师
6.如在国内，需要短期暂留党组织关系在学校的同学，在“翱翔门户-智慧党建-组织关系申请-毕业生保留组织关系申请”中填写相关内容，可保留组织关系1年。
7.如出国等原因，需要保留组织关系的同学，在“翱翔门户-智慧党建-组织关系申请-出国（境）党员保留申请”中填写相关内容，可保留组织关系5年。
