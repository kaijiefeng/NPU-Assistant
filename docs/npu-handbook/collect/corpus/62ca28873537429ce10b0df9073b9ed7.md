# 自动化学院召开工程博士培养专项调研交流会

为切实提高学院工程博士培养质量，全方位了解工程博士培养情况，9月22日上午，自动化学院召开工程博士培养专项调研交流会。研究生院副院长王鹏、学位办负责人毛伟云、翱翔导师服务中心负责人黄媛、学籍管理中心负责人过娟，自动化学院副院长王小旭、刘准钆，党委副书记管峻，工程博士导师代表及研究生教学秘书等参加会议。会议由王小旭主持。
王小旭从招生情况、培养过程、学术交流等方面详细介绍了学院工程博士的培养现状，结合前期对工程博士和导师的问卷调研结果，深入剖析了当前存在的问题和原因，并提出了学院下一步工作计划和举措。
与会导师代表就工程博士授课形式和考核方式、学术成果标准、分类培养管理等开展了深入交流研讨，为推进工程博士培养工作拓展了思路，凝聚了共识，统一了思想。
王鹏在总结性发言中，对学院工程博士培养工作给予了充分肯定，同时强调学院应进一步发挥学科特色优势，紧密结合国家经济社会和科技发展需求，积极探索工程博士培养新模式，培养出更多工程技术领军人才。
