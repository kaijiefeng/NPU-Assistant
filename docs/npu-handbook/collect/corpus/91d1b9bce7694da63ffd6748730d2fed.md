# 离退休党委成功举办2026年党员知识答题活动

为持续深化党的创新理论武装，扎实推进离退休党员思想政治教育，近日，离退休党委组织开展2026年党员知识答题活动，以考促学、以学促知、以知促行。
本次知识答题内容涵盖习近平新时代中国特色社会主义思想、习近平党建思想等内容。1038名党员积极参与了答题，各党支部立足自身实际，创新活动开展形式，有的党支部组织离退休党员围坐开展集中答题研讨，边答题边交流感悟；有的党支部安排支部委员上门，为行动不便的老党员读题讲解，协助完成答题；在外党员依托线上答题端口，实现理论学习“不断线”。
同时，结合党员知识答题，离退休党委同步下发了离退休工作调查问卷，广泛征集老同志对我校离退休工作的实际感受与意见建议，始终把老同志的满意度作为工作标尺，从老同志关切处发力，精准优化管理服务举措。
下一步，离退休党委将运用多种形式持续深化离退休党员教育管理，用心用情做实服务保障，扎实推动离退休工作高质量发展。
