# 档案馆举办“档案话百年”档案法知识竞赛活动

在庆祝中国共产党成立100周年之际，档案馆以“档案话百年”为主题开展系列活动。2021年6月7日—6月9日，档案馆工会小组认真组织、精心准备，举办了“档案法知识竞赛答题”活动，旨在全馆馆员中兴起“学业务、提能力、促发展”的学习高潮。
本次答题范围以新修订的《中华人民共和国档案法》、《高校档案管理办法》、《西北工业大学档案管理办法》等为内容，采用网络平台随机抽题答题的形式，自动从精选出的100道知识问题中随机生成30道题目，以得分高低、答题频次为评判标准，经过激烈角逐，最终评选出一等奖2名，二等奖4名，三等奖5名。
“档案法”的学习对于促进新时代档案事业高质量发展具有重大和深远影响，本次知识竞赛答题活动增强了全体馆员的档案意识，形成知悉档案法、遵守档案法、运用档案法的良好氛围，为造就一支政治强、业务精、作风硬的高素质档案管理队伍打下坚实基础。
