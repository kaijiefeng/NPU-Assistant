# 后勤部办公室传达学习暑期务虚会、 新学期中层干部会会议精神

9月1日上午，后勤部办公室召开专题会议，传达学习学校2025年暑期务虚会、新学期中层干部会会议精神。会议由后勤部办公室副主任韩争胜主持。后勤部办公室全体人员参加会议。
会上，韩争胜带领全体人员深入学习了李言荣书记、宋保维校长在暑期务虚会、新学期中层干部会上的讲话。接着，与会人员围绕学校会议精神，结合新学期各自工作开展情况进行了研讨交流。大家一致认为，学校暑期务虚会和新学期干部会上书记校长的讲话，高屋建瓴、主题鲜明、内容丰富、思想深刻，为新学期工作和学校发展指明了方向，令人备受鼓舞、倍增动力。
会议要求，后勤部办公室全体人员要深入学习书记校长讲话精神，贯彻落实好会议部署要求，一如既往以务实、踏实、朴实的工作作风，在新学期里加快推进各项工作稳步有序、高质高效完成。一是要打开格局，将服务于学校高质量内涵式发展、服务于学校“总师型”人才培养作为后勤工作的中心目标。二是要务实肯干，持续聚焦师生急难愁盼，尽早、尽多、尽好为师生办实事办好事。三是要勇于担当，在学校电力扩容等亟待解决的难题面前挑重担、打头阵、冲在前，以“三个永远”的精神状态和“四个凡事”的工作标准，在后勤管理工作中不断取得新成效，为学校早日实现“一十百千”发展目标贡献力量。（撰稿人：毛淑兰；审稿人：韩争胜）
