# 后勤部办公室传达学习2026年寒假务虚会和春季新学期中层干部会精神

3月2日上午，后勤部办公室召开全员会议，传达学习学校2026年寒假务虚会、春季新学期中层干部会会议精神。会议由后勤部办公室主任张文刚主持。后勤部办公室全体人员参加会议。
与会人员集体学习了李言荣书记、宋保维校长在学校寒假务虚会和春季新学期中层干部会上的讲话。随后，张文刚结合后勤部办公室工作实际，对本学期重点工作进行了安排部署。
会议要求，全体人员要认真学习并深刻领会书记校长讲话精神，切实做好新学期后勤管理与服务保障各项工作。会议提出了三点要求：一是要提高政治站位，将学校会议精神与后勤工作开展相结合，切实增强本职工作的责任感和使命感；二是要狠抓责任落实，聚焦学校中心任务，围绕主责主业，着力解决师生“急难愁盼”问题，确保把实事办实、把好事办好；三是要主动谋划担当，在学校电力增容、热力扩容等亟待解决的问题面前迎难而上、勇挑重担，为学校实现“一十百千”发展目标和“天下工大、世界三航”远景目标贡献坚实的后勤力量。（撰写人：毛淑兰；审稿人：韩争胜）
