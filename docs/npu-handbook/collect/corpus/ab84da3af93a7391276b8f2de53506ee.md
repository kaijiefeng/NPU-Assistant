# 党委保卫部暑期坚守岗位，维护校园安全稳定

2025年暑期，党委保卫部全体工作人员以高度的责任感和使命感，奋战在校园安全保卫工作第一线，圆满完成各项任务，为学校暑期工作的顺利开展提供了安全有序的校园环境。
一、安全防线筑牢固 用心服务暖人心
今年暑期工作面临着持续高温，人员流动量大等多重挑战。党委保卫部带领全体校卫队员顶烈日、战高温，严格落实门禁管理制度和24小时执勤值守制，加强巡逻频次和力度。妥善处理各类突发事件22起，解决师生家属日常求助610起，找寻遗失物71起，开展消防安全检查400余次，及时推动消防隐患整改，用实际行动诠释了“安全无小事”的责任担当。
社区管理中心用心用情做好各项服务工作，持续推动技防设施建设升级，主动上门看望独居老人17人次，及时调解处理噪音扰民、房子漏水、高空抛物等矛盾纠纷，持续开展重点人走访、帮扶、教育，维护了学校和谐稳定。
二、统筹协调齐发力 环境提升强保障
为全力保障暑期校园环境提升工程顺利实施，党委保卫部提前部署南村、西苑、航海学院等改造现场踏勘，协助规划交通方案，及时清理施工区域违规停放车辆；对校园在建改造项目全程巡查与监督，特别加强对施工车辆的管控，严格落实进出校园施工车辆的登记管理制度，协调处理交通投诉、车辆剐蹭等事件。在施工期间，组织人员加班加点，全面排查技防设施运行状态，及时维修校内因施工导致离线监控设备，确保技防设施运行正常，确保校园秩序稳定和各项工程顺利施工。
三、迎新工作准备足 热情服务获好评
全力做好迎新保障工作。前期，党委保卫部多次查看现场并召开会议制定详细的迎新安全保卫方案。迎新期间，在翱翔体育馆设立户籍服务点，耐心为新生讲解户口迁移办理流程；在报到点门口发放预防电信诈骗宣传彩页，传授防范网络诈骗知识，增强新生的安全防范意识。烈日下，工作人员耐心引导车辆和人员，用热情周到的服务温暖了来自四面八方的新生和家长，圆满完成了2025年迎新安保任务。
2025年暑假期间，党委保卫部用坚守诠释责任，用汗水书写担当，在平凡的岗位上做出了不平凡的贡献。每一次巡逻检查，每一次贴心服务，每一次交通疏导，都凝聚着他们对校园保卫工作的热爱与执着。新学期已经开始，党委保卫部将以更加饱满的热情、更加务实的作风，为学校建设发展营造更加安全、稳定、和谐的校园环境。
