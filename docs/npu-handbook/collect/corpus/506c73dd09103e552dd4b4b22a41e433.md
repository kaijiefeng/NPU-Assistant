# 航海学院召开2024年招生工作总结大会

为进一步推进“总师育人文化”走深走实，持续改进学院本科招生工作，10月30日下午，航海学院召开2024年招生工作总结大会。会议邀请了学校招生办公室主任兼教务部副部长王克勤，以及浙江、山东、上海、重庆、江苏、河南等地招生组组长。航海学院院长潘光、党委书记刘朝亚、副院长雷波、院长助理、教学秘书等参加会议，会议由雷波主持。
潘光对各位招生组组长的到来表示热烈的欢迎，随后由湖南招生组组长杨占龙、广西招生组组长杜向党对2024年度招生工作进行详细汇报。
王克勤重点解读了学校招生政策，并对航海学院的招生工作予以充分肯定。他指出，航海学院负责的湖南、广西两省在招生工作中表现突出，同时，省内的榆林地区近年来在招生位次上也不断攀升。他表示，招生工作竞争激烈，机遇与挑战并存。为此，学校将持续加大资源投入力度，进一步强化“总师育人文化”在招生工作中的引领作用。学校招生办公室将与学院及职能部门协同联动，为提升学校生源质量、推动“总师型”人才培养贡献力量。
与会人员围绕学院在两省一市及海洋工程大类的招生录取情况、现存问题等方面展开交流探讨，对下一步招生工作提出了切实可行的意见和建议。
潘光在总结发言中指出，本科生是“总师型”人才培养的“毛坯”和“原材料”，学院领导班子要亲自参与到招生宣传的第一线，确保招生工作有效进行。招生工作并非一蹴而就的任务，而是一项需要长期投入和持续关注的常态化工作，学院应发挥主体作用，不断提升航海学院“两省一市“和“海洋工程大类”招生质量，推进“总师育人文化”走深走实。
