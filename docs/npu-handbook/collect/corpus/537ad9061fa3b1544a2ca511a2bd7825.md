# 离退休党委机关党支部赴富平开展主题党日活动

11月28日，离退休党委机关党支部赴富平开展“追寻红色足迹，强化实干担当”主题党日活动。
在关中革命纪念馆，党员们跟随讲解员依次参观了各个展厅，系统了解了关中地区人民在中国共产党的领导下英勇革命的伟大历程，特别是习仲勋等老一辈革命家领导渭北人民开展游击战争、建立红色政权的光辉事迹。
在习仲勋陵园，全体党员怀着崇敬的心情，向习仲勋同志雕像敬献花篮，鞠躬致意，表达对革命先辈的深切缅怀。在习仲勋故居，大家通过实地参观等深入了解习仲勋同志波澜壮阔的革命历程和始终以党的利益为最高追求的政治品格，深刻体悟到老一辈革命家对党忠诚、心系人民、无私奉献的深厚家国情怀。
随后，党员们前往八路军120师抗日誓师纪念地学习参观，感悟革命先辈在民族危亡时刻挺身而出的崇高精神，进一步坚定爱国报国、为党奉献的理想信念。
此次主题党日活动是一次深刻的红色教育和思想洗礼,大家一致表示，今后将以革命先辈为榜样，牢记初心使命，立足工作岗位，以实干担当践行党员使命，为学校高质量发展贡献智慧和力量。
