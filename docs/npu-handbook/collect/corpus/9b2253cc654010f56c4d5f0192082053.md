# 汇聚师生共识 提升育人实效——生命科学与技术学院召开2026年师生交流座谈会

为贯彻“以学生为本”的工作理念，畅通沟通渠道，倾听研究生诉求，提升研究生培养质量，生命科学与技术学院于10月13日上午召开研究生师生交流座谈会。学院党委书记段利兵、副院长蔡晶及导师、师生代表共30余人参会，座谈会由蔡晶主持。
会上，研究生代表结合科研、学习、生活，围绕毕业政策、科研保障、课程培训、就业服务等多方面建言献策。与会导师针对科研、就业、能力提升给出指导建议，勉励学生树立长远目标，把握AI时代机遇，规划发展方向，提升求职沟通能力。
此次座谈会搭建了双向沟通平台，凝聚育人共识。后续学院将完善沟通机制，常态化开展此类活动，及时回应学生诉求，提升研究生教育管理服务水平，为培养高素质生命科学专业人才夯实基础。
