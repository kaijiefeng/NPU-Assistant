# 人事处党支部传达学习宋保维校长主题教育专题党课精神

7月17日上午，人事处党支部召开支部大会，传达学习宋保维校长主题教育专题党课讲话精神，开展师德师风专题学习。会议由党支部书记唐玉生主持。
唐玉生结合自己的学习体会，带领全体党员系统全面深入学习了宋保维校长在专题党课上的讲话精神。他表示，宋保维校长的党课内容全面、数据详实、分析深入，对人事人才工作具有深刻的现实指导意义，特别是学校机构改革、 评价改革两大改革任务和七个主要方面的很多具体举措都涉及人事人才工作，人事处全体工作人员要深入学习领会，认真贯彻落实，多思考分析、多调查研究，不断提高工作水平和工作能力，立足学校全局，扎实推进机构改革、评价改革、高水平人才引育、团队建设等重点任务，以高质量人事人才工作支撑学校中国特色世界一流大学建设。
王增磊传达了学校师德集中学习教育方案和相关通知要求，以“深入学习贯彻习近平总书记关于师德师风的重要论述”为题讲授了专题党课，带领支部党员全面系统地学习了习近平总书记关于师德师风的重要论述、新时代高校师德师风建设的工作要求和高校教师师德失范警示案例，强化了支部党员师德集中学习实效。
（文/张慧杰 图/孙梦桐 审核/唐玉生）
