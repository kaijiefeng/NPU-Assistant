# 关于举办“分析·创新‘1→0’： 2026分析测试方法研究生暑期学术论坛”的通知

各位同学：
为进一步提升研究生创新思维与科研能力，持续加强“总师型”拔尖创新人才培养，扎实推进“1→0”重大工程科学问题研究，材料学院科教实践与材料分析创新中心拟于2026年7月20日举办“分析·创新‘1→0’：2026分析测试方法研究生暑期学术论坛”。本次论坛将聚焦前沿分析测试方法的开发与跨学科创新应用，致力于打造集知识学习、技术攻关与成果交流于一体高水平学术平台，促进开放共享与交叉融合。
现诚邀全校在读硕士、博士研究生踊跃报名参加。相关事宜通知如下：
一、论坛形式
本次论坛以主题报告形式开展，由研究生自主申报，经中心遴选后确定。报告人须立足自身研究方向，聚焦前沿探索与创新实践，重点介绍如何运用先进分析表征技术解决复杂工程科学问题，并分享总结相关研究经验与心得体会。
二、报名方式
1、提交报名表：填写《2026分析测试方法研究生暑期学术论坛报名表》（见附件），发送至中心邮箱smarc@nwpu.edu.cn。
2、报名截止日期：2026年7月13日。
三、奖项发放
1、所有入选报告人均可获得由科教实践与材料分析创新中心颁发的“科研助力礼包”（含设备随心约卡+免费机时券）。
2、论坛将组织专家评选“分析·创新”奖，并颁发奖励证书及相应奖金。
四、其他事项
1、提交报名后请及时加入论坛QQ群，备注“姓名+学院”。后续日程安排、报告顺序及会议资料将通过群公告发布，请密切关注。
