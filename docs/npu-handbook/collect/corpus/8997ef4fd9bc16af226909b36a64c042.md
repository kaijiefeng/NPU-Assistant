# 校领导检查两校区供暖准备工作

在冬季供暖正式开始之前，为确保供暖工作平稳有序开展，11月5日和6日，校长助理兼后勤部党工委书记、后勤部部长王宇波分别在友谊校区和长安校区检查指导供暖准备工作。
王宇波实地查看了友谊校区角楼换热站、长安校区南区换热站等供暖设施运行情况，现场听取了后勤部办公室关于前期供暖准备工作的汇报。王宇波指出，友谊校区供暖设施运行年限长，部分设备管网存在老化漏损问题，后勤部办公室要在当前冷水循环期间加强设备故障消缺和管网漏损治理，尽力保障供暖系统正常运行。长安校区相较去年新增了海天苑大楼等采暖楼宇，后勤部办公室要加强对新增楼宇采暖需求的关注和保障，在供暖初期及时科学合理调节各区域热量分配，确保各区域供暖稳定达标。王宇波要求，后勤部办公室要增强对两校区整体供暖工作的系统分析研判，提前做好应对极端天气的准备。
最后，王宇波强调，冬季供暖是一项重要的民生工程，直接关系到师生员工的切身利益和冬季生活质量，后勤部办公室要进一步强化与热力公司的沟通联动机制，确保两校区市政热源按时充足供至校内，同时加强校内供暖设施巡查维护，利用智慧供暖平台数据科学合理调节系统运行参数，确保两校区供暖整体稳定达标，为广大师生员工提供温暖舒适的工作学习生活环境。（撰稿人：李保康；审稿人：韩争胜）
