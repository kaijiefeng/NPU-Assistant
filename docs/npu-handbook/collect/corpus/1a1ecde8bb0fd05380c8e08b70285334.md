# 西北工业大学机电学院智能工厂工业软件工程研究中心招聘启事

西北工业大学机电学院智能工厂工业软件工程研究中心因工作需要，现面向社会公开招聘非事业编制人员1-2名，具体要求如下：
一、岗位名称
专职科研岗(1-2名)
二、岗位职责
1.协助团队完成相关关键技术(智能工艺设计与优化)的研究工作;
2.协助团队完成自主工业软件的研发工作;
3.协助团队完成项目的申报与结题工作;
4.完成团队负责人交办的其他工作。
三、应聘条件
1.具有机械工程或计算机相关专业背景，具有大型工业软件研制经验者优先;
2.具备C/C++/JAVA/Python/Javascript等程序语言的编写能力;
3.遵纪守法，热爱本职工作，身体健康，年龄不超过40周岁;
4.责任心、服务意识强，有较强的团队协作精神和组织协调能力。
四、招聘程序
1.符合条件者请将个人简历、学历、学位证明及其他证明材料电子版于2026年11月13日24:00之前发送至邮箱
[已脱敏:邮箱](邮件主题:岗位名称+姓名+学校+专业，不接受压缩文件);
2.学院对符合条件的应聘者进行初筛，入围者通知笔试和面试，择优录用。
五、考核及待遇
1.考核及待遇参照西北工业大学非事业编制人员有关规定执行;
2.工作地点为西北工业大学友谊校区;
3.试用期6个月，首次聘期3年。
