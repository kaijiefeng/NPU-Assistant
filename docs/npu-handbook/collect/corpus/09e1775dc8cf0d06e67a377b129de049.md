# 西北工业大学军工素质教育实践中心（博物馆）航空馆展陈设计方案征集结果公示

根据西北工业大学军工素质教育实践中心（博物馆）航空馆展陈设计方案征集工作安排，2024年6月6日西北工业大学组织专家评审会对11家参加单位提交的设计方案进行评审并确定结果，经学校相关程序审核，现将评审结果公示如下：

单位名称
1
上海宽创国际文化科技股份有限公司
2
广东省集美设计工程有限公司
3
百达文化科技有限公司
