# 西安翱翔动力科技-西北工业大学资产经营管理有限公司

西安翱翔动力科技有限责任公司（以下简称翱翔动力）成立于2018年1月，是西北工业大学资产经营管理有限公司的独资公司、陕西空天动力研究院有限公司的创始股东。作为学校空天动力领域重要的科技成果转化平台，致力于推动空天动力产业相关技术的创新突破与产业化发展。
翱翔动力充分发挥学校在航空宇航科学与技术、材料科学与工程、机械工程等学科优势，聚焦航空宇航推进、先进材料与智能制造、空天能源等产业方向，与陕西空天动力研究院建立深度协同机制，构建“基础研究—技术开发—产品孵化—市场应用”的全链条创新体系。通过技术转移转化、共建创新平台等方式，为空天动力领域科技成果产业化提供重要支撑。
未来，翱翔动力将继续深化产学研合作，以服务国家空天动力产业发展战略为使命，努力成为国内领先的空天动力产业创新策源地和孵化高地。
