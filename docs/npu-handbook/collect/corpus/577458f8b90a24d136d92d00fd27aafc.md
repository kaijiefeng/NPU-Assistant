# 档案馆参加2026年工业和信息化部部属高校档案工作协作组工作会议

为深入学习贯彻习近平总书记关于新时代档案工作的重要指示批示精神，学习全国档案事业发展“十五五”规划，进一步提升部属高校档案工作管理水平，促进档案工作人员学习交流，9月20日至22日，2026年度工业和信息化部部属高校档案工作协作组工作会议在北京航空航天大学国际创新研究院（学院）召开。工业和信息化部办公厅、部机关相关司局、部属各高校、部直属单位及通信管理局档案工作协作组组长单位的负责人与档案同仁出席会议。
会上，七所部属高校围绕本单位2026年度档案工作重点与亮点进行了专题汇报。学校档案馆馆长戚红梅代表学校作了题为“数智赋能档案 信创筑基未来”的交流发言，围绕档案思政育人、服务保障、数智转型、资源建设、行业支撑等九大方面全面展示了2026年重点工作成效。重点分享了学校构建“1+N”电子档案全流程管理系统矩阵、档案信创国产化改造、电子档案长期保存体系建设，以及“AI+档案”数智化体系规划建设等实践探索，充分展现了学校在档案数字化向数智化转型过程中的建设思路与阶段性成果。
会议期间，开展了行业专家业务培训。浙江省档案馆原副馆长郑金月、浙江大学公共管理学院信息资源管理系副主任章燕华分别围绕“档案工作数智化转型的浙江探索与经验”以及“‘十五五’我国档案工作数智化升级的重点方向与实现路径”作了专题讲座，从地方实践与理论研究双维度为部属高校档案数智化建设提供了参考与指引。
会后，与会代表实地参观了北京航空航天大学国际创新研究院（学院）图书馆、空天馆以及杭州国家版本馆，进一步拓宽了档案工作的文化视野与工作思路。
