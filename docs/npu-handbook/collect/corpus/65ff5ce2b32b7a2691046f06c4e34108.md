# 关于发放教工和博士生集体户口登记卡的通知

为了提升办事效率和服务质量，更好的方便师生、服务师生，保卫处优化户籍管理办事流程，简化办事程序，经研究决定：从即日起，将所有教工及博士生集体户口登记卡全部发放给个人，免去师生借用户口时押证、多跑路等麻烦。
请户口在学校集体户的教工和博士生到保卫处友谊校区户籍室领取本人集体户口登记卡。需要在长安校区领取的，可提前拨打友谊校区户籍室电话88494447进行登记，保卫处会安排老师将集体户口登记卡带到长安校区户籍室发放。
集体户口登记卡领取注意事项：
1.集体户口登记卡相当于个人户口簿，请妥善保管。
2.如不慎丢失，可凭本人有效证件前往太白路派出所进行补办。
3.如需迁移户口，可直接前往太白路派出所办理。
4.如在户口使用过程中遇到问题，可拨打保卫处户籍室电话进行咨询。
保卫处户籍室地址：友谊校区综合楼四楼400，电话：88494447；
长安校区启真楼一楼学生一站式事务服务大厅19号工位，电话：88430735。
太白路派出所地址：友谊校区东门外，大学南路、边西街北口，电话：88423903
保 卫 处
