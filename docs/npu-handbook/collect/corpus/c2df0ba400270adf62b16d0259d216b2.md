# 校领导会见“阿里·法拉比”哈萨克国立大学副校长马尔古兰·伊布拉莫夫一行

7月3日，“阿里·法拉比”哈萨克国立大学副校长马尔古兰·伊布拉莫夫教授一行来访我校，副校长孔杰会见了代表团一行。
孔杰代表学校对马尔古兰·伊布拉莫夫一行的来访表示热烈欢迎。他指出，目前哈分校第二届36名硕士毕业生顺利毕业，标志着分校办学迈入新阶段，希望未来双方围绕分校“从有到优，共同办好西北工业大学哈萨克斯坦分校，培养更多中哈友好事业接班人”继续精诚合作，共同打造中哈科教合作的旗舰项目。
马尔古兰·伊布拉莫夫表示非常高兴再次来校访问。他表示，西北工业大学哈萨克斯坦分校的建设为两校战略合作走深走实筑牢了根基，成为中哈高校合作的典范。期待未来在科研领域开拓更多合作增长点，携手推动两校合作迈上新台阶。
材料学院、电子信息学院、计算机学院、数学与统计学院、国际合作处以及哈萨克斯坦分校的相关负责同志参加了本次会见。
