# 政策领航，路径指津—集成电路学院（微电子学院）举办2024、2025级保研政策宣讲会-集成电路学院（微电子学院）

2026年10月15日下午，集成电路学院（微电子学院）面向2024级、2025级全体本科生举办保研政策专题宣讲会。宣讲会由辅导员贺睿杰主讲，围绕推免政策、发展路径、能力提升开展系统辅导。
宣讲会上，贺睿杰解读推免政策，介绍绩点排名、外语成绩、科研成果、学科竞赛、社会实践等指标的核算规则与申报要求。推免准备需要长期积累，应贯穿大学全过程。结合年级特点，她提出针对性的建议：2024级学生处于专业核心课学习的关键期，需扎实学好专业课程；2025级学生要树立长远发展观念，夯实专业基础，尽早明确发展目标。
在发展路径规划环节，贺睿杰梳理了保研、考研、就业三条主要发展路径的特点与时间节点。她讲到，有推免意向的同学要密切关注夏令营、预推免的关键窗口期，主动对接，争取机会；计划考研的同学要科学安排复习，重视复试环节中与导师的沟通；选择就业的同学要注重综合素养的提升，增强个人核心竞争力。无论选择何种发展方向，提前谋划、稳步落实都是重中之重。
在综合能力提升方面，贺睿杰鼓励同学们主动查找自身短板，有针对性地补齐弱项，在理论学习和实践探索中持续提升自我，拓宽发展空间。
本次宣讲帮助同学们准确把握推免政策，理清学业规划思路。学院后续将持续开展考研、就业、科研实训等系列学业指导活动，助力学生成长发展。
