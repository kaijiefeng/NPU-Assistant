# 西工大2026年校园开放日暨一流大学高招咨询会圆满结束-

报考指南
首页-报考指南>宣传动态>
西工大2026年校园开放日暨一流大学高招咨询会圆满结束
发布日期：2026-06-27
点击数：201
为方便考生及家长更加全面了解各大高校最新招生政策、人才培养特色、本科专业设置等报考资讯，从而更科学、更合理地填报学校和专业志愿，6月26日，西北工业大学2026年校园开放日暨一流大学高招咨询会在友谊校区举办。80余所国内一流大学招生老师齐聚西工大，与学校各学院老师为考生、家长提供面对面咨询服务。党委书记张云明、校长宋保维来到活动现场检查指导，副校长岳晓奎陪同。
本次活动吸引了陕西省及周边省份的众多考生、家长。学校各学院主要领导、招生老师以及招生办公室工作人员等与考生和家长展开了深入交流，围绕学校办学实力、人才培养、专业设置、招生政策、志愿填报等相关问题，进行耐心细致解答，全方位为广大考生提供详实专业的报考指导和服务。现场气氛热烈、交流深入、咨询踊跃。
张云明、宋保维先后走访各学院招生咨询展位，详细了解现场咨询开展、考生报考意向等情况。期间，张云明、宋保维与现场考生、家长亲切交谈，细致询问考生生源属地、意向专业、学业规划及深造发展意愿等，并欢迎广大优秀学子报考西工大。
本次参会的众多双一流高校展位前同样人头攒动、咨询热烈。各高校招生老师表示，本次活动组织规范有序、服务细致周到、咨询效果良好，并对学校的统筹安排与贴心保障表示高度认可与诚挚感谢。
