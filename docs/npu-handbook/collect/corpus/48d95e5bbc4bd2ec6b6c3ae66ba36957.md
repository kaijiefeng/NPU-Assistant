# 【机关风采】马玥：坚守党员初心 深耕美育思政-机关党委

马玥同志作为一名基层共产党员，始终严守党员标准、坚定理想信念、牢记初心使命，坚持党建与美育业务深度融合，立足艺术教育岗位深耕思政育人，在各项工作中主动担当、奋勇争先，充分发挥共产党员的先锋模范作用。
2026年度机关优秀共产党员
艺术教育中心党支部 马玥
坚持理论铸魂，锤炼过硬政治素养
始终把政治理论学习摆在首要位置，常态化学习党的创新理论，持续淬炼“政治三力”。担任党支部副书记，严谨务实、恪尽职守、廉洁自律，严格落实组织部署，积极营造奋进的支部干事氛围。依托支部“七个一”特色工程，创新党建工作方式方法，持续夯实支部战斗堡垒作用，以高质量党建引领美育事业高质量发展。
深耕美育阵地，构建融合育人新格局
始终坚守以美育人、以文化人工作理念，将美育与思政教育深度融合，把党性教育贯穿人才培养、活动策划与舞台创作全过程。
从红色基因中激发爱国热情。引进 “琴音传薪火”音乐党课、电影《飞天》主创进校园等有深度、有温度的艺术党课，用鲜活的艺术形式讲好红色故事，让广大党员群众听得懂、记得牢，在热情激昂的旋律和感人肺腑的故事中接受伟大精神洗礼。
从校本文化中赋能总师型人才培养。组织排演《大国之蓝》等科学家系列作品，戏内戏外铸牢“总师”型人才使命担当之魂。组织创编七部讲述“为国铸剑者”的作品入选全国“科学家故事舞台剧推广行动”，数量位居全国第一。
从传统文化中厚植文化自信。积极推进校地美育深度合作。依托壁画、秦腔、博物馆美育等多个平台，深耕中华优秀传统文化传承创新，推动传统艺术资源转化为育人资源，持续提升学生文化认同感与民族自豪感。
从时代课题中续写青春使命。紧扣时代主题与重要节点，打造短片《理想》等正能量和大流量兼备、深度和温度并重的特色舞台思政项目，相关作品在全国 1800 余家平台展播。参与央视五四特别节目、《同心筑国防》等国家级节目录制，持续擦亮学校美育思政品牌，扩大育人影响力。
勇于担当攻坚，践行服务师生初心
始终冲锋在校园文化建设和重大文艺任务一线，高标准、高质量完成各类展演、赛事创排工作。年均统筹开展美育文艺活动近 50 场，持续丰富校园文化生态，营造浸润式美育育人氛围，持续推动学生艺术团成为我校校园文化建设的核心主力军。
牢记全心全意为人民服务宗旨，积极推动美育走出校园、服务社会。牵头开展山区美育帮扶、社区文艺服务、行走的艺术课堂等公益实践活动，带领师生扎根大地、服务群众，用接地气有温度的文艺实践，彰显高校教育工作者与青年学子的责任担当。
