# 后勤部办公室党支部召开理论学习会议

为持续强化党员干部的理论武装，4月18日上午，后勤部办公室党支部组织全体党员召开理论学习会议。会议由党支部书记张文刚同志主持。
会上，大家集中学习了《习近平在湖南考察时强调坚持改革创新求真务实奋力谱写中国式现代化湖南篇章》等习近平总书记重要讲话精神，以及《中国共产党党员网络行为规定》《党史学习教育工作条例》等相关文件、《学校召开2024年全面从严治党工作会议》等学校重要会议精神。接着，全体人员集中观看了《<焦点访谈>—国家安全 共同守护》国家安全教育宣传视频。
在学习过程中，党员干部们认真聆听、积极思考，就学习内容进行了热烈地讨论和交流。大家纷纷表示，作为一名党员干部，必须时刻以党的纪律和规矩为准绳，保持清醒的政治头脑，切实增强政治定力、纪律定力、道德定力、抵腐定力，为学校发展贡献力量。
最后，张文刚同志对全体党员提出三点要求。他强调，一是要继续加强理论学习，不断提高自身素质和能力水平；二是要学纪、知纪、明纪、守纪，时刻树立良好的党员形象；三是要紧密结合工作实际，将学习成果转化为工作成效，切实助力学校“127”发展目标的实现。
