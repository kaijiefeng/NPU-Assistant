# 关于开展2023-2024学年微专业相关工作的通知

各单位：
为深入推进我校人才培养模式改革，促进学生跨学科知识和能力的交叉融合，满足学生个性化、多元化发展需求，鼓励学有余力的学生在学习本专业的同时，根据兴趣自愿选择修读微专业，不断完善“总师”型人才培养体系，提升人才自主培养质量，现开展2023-2024学年微专业相关工作，相关事宜通知如下：
一、微专业申请与审核
学生申请修读微专业可以选取采用“集中报名+动态申请”两种方式：
（一）集中报名（推荐）：学校每年会发布微专业招生通知，学生按照各微专业招生选拔要求进行集中报名，通过招生选拔后按照所选微专业课程目录进行修读。
（二）动态申请：没有赶上微专业集中报名的学生也可以按照相关微专业课程目录自行修读，达到微专业毕业要求，向微专业所在单位提出微专业毕业申请。
（三）审核要求
1. 学生根据微专业培养方案，修读完成微专业课程目录中要求的课程并获得相应学分，可在秋季学期申请微专业证书，经微专业所在单位审核、教务处复核合格后，发放学校统一制作的微专业证书。
2. 在校期间学生原则上可修读最多1个微专业。
3. 学生修读微专业应与主修专业归属不同的本科专业类（具体回避专业见附件）。
二、微专业具体信息
2023-2024学年计划招生微专业13个，具体信息详见附件《2023-2024学年微专业信息详表》。
