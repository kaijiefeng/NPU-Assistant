# 巾帼言志、竞展芳华”——档案馆工会小组举行三八节活动

在春意盎然的季节，我们迎来了第112个“三八”国际劳动妇女节。为了进一步关心关爱全体女馆员健康，彰显女馆员的风采，档案馆工会小组举办丰富多彩的活动庆祝“三八”国际劳动妇女节。
爱美之心人皆有之。档案馆工会小组邀请中国医师协会皮肤科医师分会会员、陕西省性学会皮肤与美容专业委员会常委兼秘书霍伟红，举办“科学护肤 绽放美丽”讲座，为大家讲授实用的皮肤知识，正确的护肤方法，传递科学护肤的健康理念。
档案馆工会小组还积极组织全体女馆员参加由机关部门工会“巾帼言志——我们的新征程”的线上读书分享活动，通过职工家庭读书会志愿者推荐优秀书目并分享读书心得。
通过举办讲座和分享会活动，既丰富了馆员们的文化生活，又展示了当代档案人的精神风采。大家纷纷表示，一定要用昂扬的斗志，饱满的工作激情，立足本职，不忘初心，不负韶华，在平凡的岗位上用坚毅和真诚书写档案事业的美好未来，奋力谱写档案馆追赶超越新篇章。
