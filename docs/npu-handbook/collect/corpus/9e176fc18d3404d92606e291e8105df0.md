# 学校召开2026年度创新创业教育工作领导小组会-青春驿站-共青团西北工业大学委员会

10月22日下午，学校召开2026年度创新创业教育工作领导小组会。校长宋保维主持会议并讲话。
会议审议通过了《西北工业大学学生创新创业竞赛参赛奖励办法》，听取了团委关于学校创新创业教育工作情况的汇报。随后，与会人员结合工作实际交流研讨。
宋保维在总结讲话中指出，“三大赛”作为培养“总师型”拔尖创新人才的重要载体，已经成为人才培养质量的重要评价要素之一。要持续引导同学们积极参与创新竞赛活动，强化学生创新意识培育、创新思维塑造、创新能力培养，营造创新创业教育的良好生态。一是提高认识，强化协同配合。各单位要扛起育人责任，把创新创业教育与教学、科研、管理各项工作统筹起来，在政策支持、资源保障、条件建设等方面做好支撑，为广大师生提供更加广阔、更富活力的创新创业平台。二是优化激励，巩固良好态势。要进一步多措并举强化奖励激励，维护好广大师生创新热情，巩固学校“三大赛”育人成效，充分用好校内外各类资源，发挥校友优势，深化校企合作、产教融合，坚持真题真做，引导学生聚焦“真问题”、解决“真问题”、获得“真应用”，大力推动创新成果转化为现实生产力。三是拓宽视野，促进开放交流。持续拓展与世界一流大学交流渠道，推动学生与来自不同领域、不同文化背景的青年互学互鉴、协同攻关，在创新创业交流实践中持续提升学校国际影响力。
校领导岳晓奎、王伶、张富利、王宇波，学校创新创业教育工作领导小组成员单位负责同志参加会议。
