# Christopher Bray

Christopher Bray
职务：JAC委员
邮箱：c.bray@qmul.ac.uk
个人简介链接：
https://www.qmul.ac.uk/spcs/staff/academics/profiles/christopherbray.html
Christopher Bray，男，教授，现任科学与工程学部教学院长。主要从事有机化学的研究，专注于开发新的合成方法和全合成。其项目组还对天然产物全合成保持浓厚兴趣，特别关注具有非常规环状化合物，致力于模仿生物遗传途径，从而更便捷地合成这些化合物。Christopher Bray在有机化学领域做出了重大贡献，他的研究在材料科学等领域具有潜在的应用前景。
