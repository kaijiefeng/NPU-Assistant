# 因公短期出国办理流程

为保证申请人顺利办理手续，请至少提前1个半月提出申请（赴俄罗斯、美国请至少提前3个月申请）。请各位教师在收到外方邀请信后，尽快到国际合作处办理相关手续。

## 一、校内审批

翱翔门户—外事系统—我的外事—教职工因公临时出国（境）填写审批表—短信通知批件办理完成。

注意事项：

1. 邀请信及中文翻译件：邀请信中需明确出访人姓名、出访时间、出访地点、出访事由、工作内容和目的、费用来源（由邀请方资助的需明确资助范围和内容；邀请方全额资助境外费用的，需落实是否承担境外意外、医疗保险费用）；邀请信需有邀请单位抬头并有邀请人亲笔签名；邀请信必须从访问目的国或地区本土发出，驻华办事处或分支机构发出的无效；可先用正式邀请信扫描件办理审批手续，原件或传真件随后邮寄用于签证申请；翻译件内容需依照原件翻译，不能歪解、遗漏。

2. 严格按照已批准方案执行任务，严禁擅自延长在国外停留时间、增加出访城市或国家，严禁以各种名义前往未报批的国家。

3. 线下办理步骤（2024年起全部转为线上办理）：填写《出国（境）安全保密承诺书》（在保密处网站下载），本人签字并提交所在单位；填写《西北工业大学因公临时出国（境）公示》并发送至国际合作处 jiaoshichuguo@nwpu.edu.cn；填写《西北工业大学因公临时出国（境）任务和预算审批表》，本人签字后由所在单位主要负责人审批并加盖公章，然后与附件材料（日程表、邀请信原件、邀请信翻译件）交国际合作处审核。审批完成后办理任务批件和政审批件，接到电话通知办理护签手续。

## 二、办理因公护照（约10个工作日）

收到短信通知批件办理完成后，持数码照片回执和身份证照片页电子版或扫描件至毅字楼723办理（团组需成团办理）。因公护照签发后，工作人员邮件通知护照信息，按照使馆要求准备签证材料。护照照片要求：JPG格式，像素300pi以上，文件不大于100KB，比例为241×150px。

## 三、办理签证（注）/出境证明（约20个工作日，具体时间视国别而定）

1. 将签证所需材料提交国际合作处。
2. 签证所需材料中二维码填写请在国际合作处在线办理。
3. 签证受理完毕后，国际合作处通过邮件发送《签证领取单》，出访人员根据领取单信息赴北京领取签证。
4. 办理出境证明约4—6个工作日；港澳通行证（签注）办理约30—40个工作日。

注意事项：各国所需材料详见国际合作处网站出国出境—各国签证所需材料栏目；签证材料中出访时间、线路、内容、人数必须同任务批件内容一致；俄罗斯签证需提供邀请函原件；签证表需申请人签名处均用中文签名；赴免签、落地签及无贴纸签证国家执行任务时，必须携带工信部开具的出境证明原件；为确保出访顺利，请及时自行购买境外意外伤害险。

## 四、回国总结

1. 外事系统提交回国总结：进入出访总结待办事项，下载并填写附件1—3，其中附件1《西北工业大学出国（境）项目总结表》填写完直接上传，附件2—3《实际日程安排》《因公临时出国（境）团组执行中央八项规定及其实施细则精神报告表》填写打印并由团组所有成员签字后拍照或扫描上传，系统自动公示，纸质版提交国际合作处。

2. 持以下材料至毅字楼723交还护照：行后回访回执（所在单位办理）；任务批件原件；实际出访日程（团组为单位，全部出访人签字）；《因公临时出国（境）团组执行中央八项规定及其实施细则精神报告表》。

注意事项：如因故未能出访也应及时归还因公证照；请务必留存因公护照首页、签证页和出入境记录页复印件或扫描件，以便办理报销；持批件原件、证照交还证明、护照首页复印件、签证页复印件、出入境记录页复印件及相关票据按财务规定办理报销；出国（境）费用报销不能分次办理，请整理全部票据后一次性完成。
