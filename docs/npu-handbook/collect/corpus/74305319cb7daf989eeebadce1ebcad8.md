# 通信网络强海权，学科交融促发展——杨益新教授讲授《走向深蓝》课程

2024年12月27日，《走向深蓝》新生研讨课本年度最后一讲于长安校区教西D201和D202教室顺利举行，西北工业大学副校长、国家级人才杨益新教授走上讲台，以《空天地海一体化信息网络》为主题进行授课。航海学院2024级全体学生及部分其他学院学生共300余名本科生聆听了本次讲座。
杨益新教授从新时代中国的海洋强国战略讲起，介绍了从近岸边到深远海的发展战略、海洋资源军用民用的广阔前景，强调了海洋科技自立自强的重要性，并以蛟龙号、深海勇士号、奋斗者号的深海探测器发展轨迹为例，讲述了科技自主研发的路径。
杨益新教授还带领同学们把视野拓展到国际，回顾了近代史上各国海权意识逐渐强大的过程，以及我们在海洋战场的失败教训和当今面临的形势，他强调，中国的海洋权益仍然面临挑战，发展海洋科技刻不容缓。他指出，我国对海洋信息的感知、获取和传输应该继续向着深、远、广、多、快的方向发展，以更好地保卫我国海洋权益。
杨益新教授重点阐述了各域网络发展不均衡、海洋与空天地信息网络异构以及跨介质信息传输一体化所面临的诸多挑战。他运用专业视角，向同学们剖析了海洋一体化子网络和空天地一体化子网络中现有技术的功能与局限性。从水声通信、跨海洋界面通信，到无人机、无人船、浮标的协同辅助，再到天基、空基、地基信息网络的一体化联通，杨教授通过深入浅出的讲解，使同学们深刻认识到信息传播网络的复杂性与先进性，同时也意识到自身肩负的重大责任。
他结合自己多年研究经验，强调了学科交融的重要性，并鼓励同学们积极学习本专业以外的知识，以期在未来技术交叉与协作领域做出更大贡献。
本学期最后一次《走向深蓝》课程在杨教授精彩的讲座中落下帷幕。
航海学院开设的《走向深蓝》是深蓝系列课程之一，课程通过知名教授或团队负责人的组合式授课模式，为新生提供一个了解学院、专业、方向和大学生活各方面的平台，使学生对海洋安全、海洋权益和海洋科技前沿有了更多的认识，更加坚定了自己为祖国海洋国防事业奉献自我的决心，为续写新时代“总师”型人才培养积蓄新动能。
