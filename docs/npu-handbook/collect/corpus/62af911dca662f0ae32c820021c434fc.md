# 祝贺！民航学院2名博士生获批2025年中国科协青年人才培育工程博士生专项计划

中国科协青年科技人才培育工程博士生专项计划，旨在整合资源、赋能青年科研人才，通过系统的培养助力其深化国情认识、开阔学术格局、精准对接社会需求。在最新公布的入选名单中，民航学院两名博士生凭借其突出科研潜力，成功获选此项计划。
王鑫及导师简介
王鑫，男，四川成都人，2024级博士研究生，航空宇航科学与技术专业，师从姜洪开教授，研究方向为航空装备智能故障诊断。入选2025年度中国科协青年科技人才培育工程博士生专项计划，培育学会为中国仪器仪表学会。以唯一第一作者在Information Fusion、Reliability Engineering & System Safety、Mechanical Systems and Signal Processing等期刊发表高水平论文6篇（5篇SCI一区Top期刊，1篇SCI三区期刊），其中3篇同时入选ESI热点论文和ESI高被引论文，论文总被引次数741，单篇最高被引次数147，H-index为13。曾获博士研究生国家奖学金、硕士研究生国家奖学金、陕西省研究生创新成果展高质量成果A类、太行国家实验室第一届太行杯未来动力创新大赛优胜奖、英国皇家物理学会杰出/信赖审稿人，近5年共获校级及以上荣誉20余项。
姜洪开，民航学院教授、博士生导师，从教30年。主讲本科生课程《数字信号处理》《民机系统原理与适航审定》，研究生课程《智能诊断原理及应用》《智能运维与健康管理》《Advanced Signal Processing》等，年均教学工作量150学时。4次获西北工业大学优秀本科毕业论文指导教师，3次获西北工业大学优秀硕士论文指导教师。培养硕、博士研究生87人，其中80%进入国防科研院所或高校，10余人已成为单位带头人、型号总师、业务主管。主持国家自然科学基金等国家级科研项目5项，发表SCI论文100余篇，获省部级科技奖励3项。连续3年入选科睿唯安全球高被引科学家，连续4年入选爱思唯尔中国高被引学者。担任校学术委员会委员、民航学院学术委员会副主任、飞行器控制与信息工程专业负责人。
董志城及导师介绍
董志城，民航学院2023级博士研究生，导师为万小朋教授，研究方向为力学超材料结构设计与功能优化，在Advanced Science（封面论文）、Materials Today Bio、Nano Research等国际权威期刊以第一/共一作者发表SCI论文7篇，其中2篇入选ESI高被引论文。获得2025年度中国青年科技创新挑战杯“揭榜挂帅”擂台赛人工智能赛道擂主（特等奖第一名）及2025年陕西省第九届研究生创新成果奖特等奖，并主持西北工业大学博士论文创新基金重点项目1项，曾获研究生国家奖学金、科研创新奖学金、一等学业奖学金、优秀研究生等荣誉。
万小朋，教授，西北工业大学校务委员会副主任，太仓智汇港党工委书记、管委会主任，专注于飞行器设计专业科研、教学与高等教育管理工作。主持国家级教学改革项目20余项，负责及参与科研项目30余项，发表论文70余篇，出版教材3部，编写讲义6本。获国家教学成果一等奖、陕西省科技进步奖、陕西省教学成果一等奖、陕西高等学校科学技术研究优秀成果一等奖、中国科协期刊优秀学术论文、校优秀硕士论文指导教师奖等荣誉。现任陕西省高等教育学会副会长，中国高教学会教学研究分会常务理事。
