# 贯彻落实寒假务虚会、新学期干部会会议精神，人力资源部赴学院开展走访交流工作

为贯彻落实寒假务虚会、新学期干部会会议精神，坚持“高质量、高水平、高速度”的指导思想和发展思路，推动人事人才工作高质量发展，2月19日至26日，人力资源部部长、高层次人才办公室主任唐玉生，高层次人才办公室常务副主任张忻及相关人员赴航天、航海、材料、机电、电子信息、自动化、计算机等学院，与院长、书记、翱翔创新团队代表等开展深入交流。
会上，张忻对2025年院士增选工作、国家重大人才工程新政策进行解读，“一院一策”对“海外优青”申报进展、各学院人才后备队伍进行分析，“一队一策”对翱翔创新团队建设情况进行梳理，以及“十五五”规划、博士后队伍建设、目标责任制和基本工作量等重点工作逐项展开交流，深入剖析堵点问题，并积极听取学院意见和建议。

各学院高度重视人事人才工作，根据人力资源部前期梳理的调研提纲充分准备交流内容，聚焦学校党委部署的重点工作任务，对本学院2025年“海外优青”人选、后备人才发展布局、翱翔创新团队建设规划等重点工作进行详细介绍，提出针对性的意见建议。并表示会进一步切实抓好人事人才各项工作的落实，坚持“内培大人才，外引青字号”工作思路，狠抓高层次人才队伍建设。
唐玉生表示，人力资源部已形成学期初赴学院走访交流的常态化工作机制，通过深入基层统一思想认识，能更精准对接落实学校重点任务。并表示，学校党委高度重视人才工作，新学期部署的“五场硬仗”其中两项都与人力资源部工作紧密相关，深感责任重大、使命光荣。他指出，人力资源部系统推进人事制度创新改革的步伐永远在路上，一是全力保障顶尖人才评选、大小人才工作、海外优青等重点指标任务完成，加强翱翔创新团队建设评估与遴选，落实发挥好青年教师“百人总师培养工程”作用，更加注重人才梯队建设，为青年人才搭建成长平台；二是全面系统做好“十五五”师资队伍建设专项规划，持续优化人才引育机制，由“数量提升”向“量、质并重”转变，由“单点突破”向“系统布局”转变；三是优化目标责任制和基本工作量考核体系，不断完善人才激励和评价体系，充分激发人才的创新创造活力；四是进一步做好博士后引育工作，扩大博士后队伍规模，提升博士后质量。最后表示，会更进一步与各学院、各部门协同联动，为学校高质量发展提供坚实人才支撑。
后续，人力资源部将持续开展学院走访调研工作，坚持以“永远在一线、永远在状态、永远在前列”的奋发状态，深入基层一线，聚焦实际问题，出台针对性的支持政策，推动人事人才工作再上新台阶，助力学校“127”近期目标和“天下工大，世界三航”的远景目标的实现。
