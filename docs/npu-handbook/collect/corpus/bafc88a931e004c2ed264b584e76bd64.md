# 友谊校区图书馆开放教师专用研修室

为了提升图书馆的服务功能和服务品质，助力学校人才培养和学科建设中心工作，经前期准备，在友谊校区图书馆东馆建设了教师专用研修室，并于2019年5月20日正式向全校教职工开放，教师专用研修室位于友谊校区图书馆东馆北526室。

教师研修室使用面积约100平方米，具备自修、阅览、研讨等功能，并备有多类工具图书，方便教职工查阅。研修室入口处放置了纸笔、订书机、插线板、抽纸等用品，增添了饮水机等设施，方便教职工使用。

教师研修室开放时间：周一至周五 8:00—22:30（周五18:00关闭）；周六、周日 8:30—22:30。

欢迎广大教职工前来使用。
