# 点亮就业“引航灯”，护航职场“第一步”——自动化学院召开2027届毕业生就业动员会

9月8日，自动化学院召开2027届毕业生就业动员暨网签政策解读会。学院党委书记孙华强、2023级本科生辅导员刘文星、2026级本科生辅导员崔文瑞、2027届毕业生参加会议。会议由2024级硕士研究生辅导员邓飞主持。

孙华强结合当前毕业生就业形势和学院人才培养实际，围绕求职择业与未来发展，与同学们进行了深入交流。他说，就业是同学们从校园走向社会的关键一步，面对不断变化的外部环境，同学们既要客观审视就业形势，也要在实践和比较中逐步明晰适合自身的发展方向。同时在择业过程中要正确处理个人发展与职业选择之间的关系，既要关注岗位、地域、待遇等现实因素，更要看重发展平台、成长空间与长期价值。最后孙华强勉励同学们“立大志向、上大舞台、入主战场、干大事业”，充分发挥学校和学院的行业优势，主动对接国家重点行业和重点领域的人才需求，将个人职业发展融入国家战略需要，在国家经济社会发展需要的各行各业建功立业。

邓飞结合学院近三届硕士研究生的就业数据，从整体就业情况、就业去向结构、重点就业单位以及国防军工领域就业情况等方面展开介绍。通过对不同年度数据的横向对比，他系统分析了学院毕业生的就业特点与近年来就业趋势，引导同学们结合自身实际，合理设定求职目标，科学规划就业选择。随后，邓飞还围绕学校就业相关工作安排，对就业系统使用、相关政策和关键时间节点等内容进行了详细说明。

本次就业动员会使2027届毕业生对当前就业形势有了更清晰的认识，有助于明确就业方向、科学规划职业发展，也为学院全面推进2027届毕业生高质量就业奠定了良好基础。后续，学院将持续加强毕业生就业指导与服务工作，精准对接学生实际需求，引导毕业生树立正确的就业观与择业观。
