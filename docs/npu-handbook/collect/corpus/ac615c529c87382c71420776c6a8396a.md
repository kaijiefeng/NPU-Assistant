# 大型仪器共享平台（中心管理员）

文案：陈建源 编辑：王嘉玮 审核：刘平
大型仪器共享平台（中心管理员）
1. 报销流程
2. 仪器入账平台添加
2.1 中心管理员登陆账号---点击设置
2.2 点击仪器管理---仪器入账管理
2.3 点击添加---输入相应的信息
2.4 点击仪器管理---点击修改
2.5 仪器隶属机组选择上一步步添加的平台然后点击保存
3. 分摊账户设置
3.1分摊账户设置（可以设置仪器的分摊账户类型）
3.2 点击分摊比例设置修改不同比例（ 目前所有所有仪器比例一致）
4. 结算单审核
4.1 点击财务管理----报销管理
4.2 点击结算单---待中心审核结算单---点击复审---（选择通过或驳回）点击确认
4.3 点击所有报销单，可查看报销进度，状态会变成报销中，财务那边审核后会变成已核销
