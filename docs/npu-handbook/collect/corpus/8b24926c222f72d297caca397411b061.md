# 材料学院科教实践与材料分析创新中心2026年暑期设备开放预约安排通知

各位老师、同学：
根据学校《2026年暑假安排的通知》，结合诚字楼西侧一楼场地改造施工计划与师生暑期科研实际需求，现将2026年暑期设备开放预约工作安排如下：
（1）7月20日—7月22日、8月24日—8月30日，中心诚字楼西侧一楼仪器设备正常开放；7月23日—8月23日，因楼道施工改造工程（工期约1个月），该区域设备暂停开放，请有测试需求的师生提前做好安排。
（2）7月20日—8月30日，材料科技大楼、公字楼、东馆、西苑区域的各仪器设备均正常开放。
（3）如有紧急科研测试需求，在确保安全的前提下，可联系相关设备负责老师（联系方式见附件）协调安排。
（4）其他问题可致电中心办公室：029-88493450，或关注中心公众号、加入中心测试服务QQ群咨询。
请各位师生相互转告，合理安排实验时间。感谢大家长期以来对中心工作的支持，我们竭诚为您提供服务！
材料学院科教实践与材料分析创新中心
2026年7月7日
