# 付前刚

付前刚
职务：JAC委员/西北工业大学材料学院院长
邮箱：fuqiangang@nwpu.edu.cn
个人简介链接：https://teacher.nwpu.edu.cn/fuqiangang.html
付前刚，男，工学博士，现任西北工业大学材料学院院长。主要从事抗氧化抗烧蚀碳/碳复合材料研究，提出并开辟了纳米线增韧、多相镶嵌钉扎、自愈合协同抗烧蚀等涂层新方向，有效解决了碳/碳复合材料国防应用的高温易氧化难题。以第二完成人获国家自然科学二等奖、教育部技术发明一等奖和陕西省科学技术一等奖，获陕西省青年科技奖。发表SCI收录论文230余篇（影响因子大于5论文40余篇），授权专利39项。入选“万人计划”科技创新领军人才、科技部中青年领军人才、首批基金委优青、首批中组部万人计划-青拔、教育部新世纪优秀人才、首批陕西省青年科技新星，博士论文入选全国百篇优博。
