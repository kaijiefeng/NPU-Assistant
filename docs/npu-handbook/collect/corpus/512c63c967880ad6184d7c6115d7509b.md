# 2024全国复合材料强度理论与应用技术研讨会暨第二届复合材料与绿色航空论坛在太仓顺利召开

2024年11月8日-10日，2024全国复合材料强度理论与应用技术研讨会暨第二届复合材料与绿色航空论坛在太仓成功召开。本次会议由中国飞机强度研究所王彬文研究员、西北工业大学李玉龙教授、同济大学李岩教授担任大会主席，全国高校、科研院所以及企业的200多名代表齐聚太仓，共同探讨复合材料强度理论与应用技术领域的最新进展。
中国复合材料学会副秘书长、北京理工大学梁军教授，大会主席、西北工业大学民航学院院长李玉龙教授出席开幕式并致辞。太仓市科技局局长、招商局局长郁颖珠女士在开幕式上作太仓科创环境介绍。开幕式由西北工业大学民航研究院李晨常务副院长主持。

此次会议设置了7个分论坛，分别以渐进损伤与破坏准则、层间断裂模型、测试方法与测试标准、本构模型与多尺度理论、应变率相关模型、数据驱动与机器学习模型、复合材料与绿色航空作为论坛主题，围绕复合材料强度理论与应用技术方面，从不同维度展开深入交流、研讨，多位领域内专家学者作会议交流报告，向与会者展示了行业内最新的研究成果、突破性的创新技术以及一系列成功的应用案例，为复合材料技术的未来发展提供了宝贵的参考与启示。
本次会议的圆满召开，不仅搭建了一个供业内学者展示最新研究成果、深入交流学术见解的高端舞台，还成功融合产学研用各方力量，对促进该领域的深度合作具有深远影响。民航学院将始终站在科技发展的最前沿，紧密连接技术创新与市场需求，深刻洞察新质生产力的核心要素，通过打造具有前瞻性、引领性和指导意义的顶级学术交流平台，为推动我国民用航空复合材料产业的蓬勃发展贡献力量。
