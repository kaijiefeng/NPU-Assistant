# 化学与化工学院开展国庆假期前实验室安全检查

为落实学院安全生产部署，保障国庆假期期间实验室安全稳定运行，9月30日上午，化学与化工学院组织开展假期前实验室安全检查，并对近期学校及学院安全检查发现的隐患进行“回头看”复查。
本次检查由副院长陈凯杰带队，院长助理郭威、学院安全员郭思敏及学院实验室督查组成员参加。检查组对照实验室安全检查核心要点,结合各实验室假期危险性实验备案情况，逐项核查风险点，与实验室人员现场交流，并针对发现的问题提出具体整改意见，要求立行立改；无法当场整改的，要求明确整改方案，落实临时防护措施，确保风险可控。
此外，检查组对前期发现的隐患逐条核实整改情况，确保闭环管理，并提醒各实验室要切实增强安全责任意识，严格落实假期值班值守要求，加强水、电、气源管理，规范实验操作，做好风险防范，严防安全事故发生。
此次检查进一步压实了实验室安全管理责任，推动安全隐患排查整改落细落实。学院将持续推进实验室安全常态化管理，筑牢安全防线，为学院安全稳定和教学科研工作的有序开展提供坚实保障。
