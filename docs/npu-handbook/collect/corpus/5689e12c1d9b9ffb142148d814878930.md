# 中山大学张书维教授为我院师生作学术报告

7月8日上午，中山大学政治与公共事务管理学院教授、博士生导师张书维应邀莅临公共政策与管理学院，在长安校区102会议室作题为《选择性服务与亲社会违规：公共组织行为的两难表现及影响机制》的学术报告。学院教师代表及研究生代表参加了本次活动,报告由张悦副教授主持。
报告聚焦公共部门组织行为研究及实践中的“顾此失彼”现象，系统阐述了选择性服务(Cream-skimming)与亲社会违规(Prosocial rule breaking)两类典型行为及其影响机制。张书维教授指出，公务员在工作中常面临管理效益与社会伦理的冲突，据此提出了公共部门组织行为的类型框架。围绕选择性服务，基于街头官僚国家代理人与公民代理人双重叙事，揭示了绩效压力通过底线心态影响基层人员服务对象选择的内在逻辑，并分析了公民应得性特征作为环境因素的交互作用。围绕亲社会违规，探讨了民众行政负担反馈如何通过认知(应得性感知)与情感(公共服务动机)双重路径激发街头官僚的规则突破行为，并指出了上级问责压力的关键制约作用。结合系列情境实验与质性访谈，张书维教授深入阐释了上述行为产生的“制度-心理”机制，为改善基层治理提供了理论洞见与实践启示。
交流互动环节，张书维教授结合自身科研经验逐一细致解答师生提问，双方围绕变量的操纵、数据收集渠道等学术问题展开研讨，现场气氛热烈。
此次学术报告的成功举办，拓宽了师生在公共组织行为研究领域的学术视野，深化了对基层治理实践中复杂问题的认知，进一步加强了学院对外学术交流与合作。
