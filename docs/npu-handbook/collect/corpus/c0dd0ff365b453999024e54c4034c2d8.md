# 点燃创业梦想 激发创新活力——西北工业大学第三届“华秦杯”全球校友创新创业大赛（宁波赛区）圆满落幕

9月11日，以“微光成炬 翱翔未来”为主题的西北工业大学第三届“华秦杯”全球校友创新创业大赛（宁波赛区）在西北工业大学宁波研究院圆满落幕，来自上海、江苏、浙江、安徽、福建、江西和山东等七个省份的校友带来了一场精彩的“巅峰对决”。
本次大赛宁波赛区由西北工业大学宁波研究院主办，宁波校友会、苏州校友会、杭州校友会、上海校友会、无锡校友会、南通校友会、南京校友会、常州校友会、淮安校友会、安徽校友会、厦门校友会、福州校友会、烟台校友会、青岛校友会、济南校友会协办，中国银行宁波市科技支行赞助支持。自学校发布大赛公告后，研究院积极组织联络宁波赛区所包含的地方校友会，讨论大赛相关事项。在前期的大力宣传下，共计23个团队报名参加，包括成长组9项、种子组14项。
本次大赛评委由5位投资专家、1名高校学术专家、2名创新创业管理人员组成，大赛采用“陈述（PPT）+答辩”的方式，参赛选手各有8分钟陈述和5分钟答辩时间，最后按总得分确定排名。
选手们在现场路演、答辩等环节发挥出色，充分展示了各自的创新创业项目，展现了新颖的创业理念、扎实的创业基础和卓越的创新能力。每位选手路演完毕后，专家评委就各项目的路演情况，分别做出详细、专业的点评，指出各项目的优势与不足，并为每位参赛选手给出宝贵建议。
经过激烈对决，最终角逐出成长组一等奖1名，二等奖2名，三等奖3名；种子组一等奖1名，二等奖2名，三等奖3名（详细名单附后）。
西北工业大学资产公司总经理沙治邦作了总结发言，对主办单位、协办单位、支持单位的付出表达衷心感谢，对所有获奖团队表示祝贺。他指出，“华秦杯”全球校友创新创业大赛是学校链接全球校友、集聚创新资源的品牌活动，也是深化产学研用协同创新、推动校友资源与区域产业融合发展的重要实践。他也向校友们发出邀约，期待他们在10月份的西安总决赛中再创辉煌，展现出西工大校友无尽的创新创业活力。
