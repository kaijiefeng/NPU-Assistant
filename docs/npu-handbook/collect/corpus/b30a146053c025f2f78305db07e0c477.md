# 离退休工作处召开全体教职工大会传达学习党的二十届五中全会精神

11月2日，离退休工作处召开全体教职工大会，专题传达学习党的二十届五中全会精神，研究部署贯彻落实工作。会议由离退休党委书记、离退休工作处处长赵洪章主持。
会议传达了党的二十届五中全会精神，学习了《中共中央关于持之以恒推进全面从严治党若干重大问题的决定》，传达了学校党委理论学习中心组（扩大）会关于学习贯彻党的二十届五中全会精神的部署要求。
会议要求，全处工作人员务必将学习贯彻党的二十届五中全会精神作为当前和今后一个时期的重大政治任务。一是要提高政治站位，分层分类组织学习传达。准确把握全会核心要义和精神实质，充分考虑老同志实际，通过组织专题宣讲、党支部集中学习、个人线上自学等方式，推动全会精神入脑入心。二是要强化政治引领，持续夯实离退休党组织建设。要认真落实全面从严治党主体责任，压紧压实管党治党政治责任，严明纪律规矩，把严的基调、严的措施、严的氛围贯穿离退休党建工作全过程，不断增强离退休党组织政治功能和组织功能，引导广大离退休党员永葆政治本色。三是要理论联系实际，推动学习成果转化为工作实效。要对照全会部署和学校党委要求，对标学校“十五五”规划和本年度工作要点，结合离退休工作实际和岗位职责，扎实抓好离退休教职工教育管理、服务保障、作用发挥等重点工作，用心用情做好精准服务，全心全意解决老同志急难愁盼，为学校事业高质量发展持续贡献银发力量。
