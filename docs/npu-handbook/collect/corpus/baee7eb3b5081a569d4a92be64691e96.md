# 消防宣传进军训 -开启平安开学季

为增强在校学生消防安全意识，提升应急自救能力，8月28日，保卫处在长安校区对参加军训的2023级全体本科生开展了消防安全教育培训，累计4500名学生参与活动。
培训过程中，保卫处消防科老师结合学校实际情况和校园火灾特点，重点围绕学生公寓、教学楼、实验室等场所安全用火用电，初起火灾扑救，火场逃生方法和基本技能以及灭火器使用操作等消防安全知识进行了详细讲解，帮助学生将消防安全意识根植于心，安全知识常熟于心。
后续，保卫处将以校园开学季为有利契机，深化消防安全宣传教育的方式方法，强化宣传教育的广度深度，努力营造“学消防、懂消防、知消防”的良好氛围，为构建平安、和谐的校园环境提供坚实基础。
