# 党建带团建 | 思想政治教育系硕士生党支部、团支部开展第三期“党建引领·联学联讲”主题活动-西北工业大学

为深入学习贯彻习近平新时代中国特色社会主义思想，传承弘扬伟大长征精神，纪念中国工农红军长征胜利90周年，10月22日，思想政治教育系硕士生党支部联合思想政治教育系团支部开展第三期“党建引领·联学联讲”主题活动。西安交通大学学生微宣讲团代表、西北工业大学马克思主义学院青年学生以线下线上相结合的形式同步参与学习交流。
活动伊始，尉迟庆文领学习近平总书记在纪念中国工农红军长征胜利90周年大会上的重要讲话。
宣讲环节，两位学生宣讲员紧扣主题、结合实践，依次开展分享交流。
西安交通大学学生微宣讲团讲师张丽丹以《从历史史诗到时代答卷——长征胜利90周年视域下精神谱系的理论与实践》为题，从太奶奶亲历的红军往事切入，回顾湘江战役、遵义会议、四渡赤水等史实，阐释伟大长征精神的内涵。结合自身支教经历，她把长征灵活应变的智慧运用到教学中，针对基础薄弱班级，跳出固有框架，推行分层任务、学科积分，帮助学生从小目标逐步取得进步。她引用习近平总书记给四所交通大学全体师生重要回信内容，号召青年党员传承红色血脉，坚持实事求是，勇担使命、实干笃行。
西安交通大学学生微宣讲团讲师张晶晶以《长征中的“娃娃军”——从红二十五军看青年的力量》为题，讲述了平均年龄不足18岁、仅2980余人的红二十五军从大别山出发远征的故事：独树镇战斗里吴焕先振臂冲锋、带领队伍突围；11岁小号手熊开先父子随军行军；七名女战士组成“七仙女班”，绑腿相连走完长征。依托鲜活史实，她号召新时代青年以理想信念锚定方向，依靠党组织凝聚合力，直面变局勇于创新。
与会党员、团员青年纷纷表示，此次活动既是一次生动的党史学习教育，也是一次深刻的思想洗礼。作为马克思主义学院学生，今后将持续深学细悟伟大长征精神，扎根学习科研与社会实践，脚踏实地走好新时代长征路，奋力交出无愧于时代的青春答卷。
