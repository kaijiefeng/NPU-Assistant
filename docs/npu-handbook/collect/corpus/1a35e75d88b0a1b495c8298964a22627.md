# 海航航空技术有限公司赴民航学院开展校企合作专题调研

为深入贯彻落实校企合作战略部署，持续深化合作内涵，巩固拓展共建成果，扎实推进协同育人工作，4月16日下午，海航航空技术有限公司西北维修基地总监蒙海、培训管理部总经理张冲一行5人，赴民航学院开展专题调研与工作交流。学院教学副院长张晓化、党委副书记张龙、院长助理陈杰出席会议。
会议紧紧围绕民航事业发展大局，双方一致强调，要坚持以立德树人为根本任务，推动学生思想政治教育与行业认同教育深度融合，将民航文化、行业使命与家国情怀有机融入人才培养全过程，着力引导西工大学子坚定扎根民航、服务国家的理想信念，筑牢投身民航事业的思想根基。
针对实践教学体系创新，学院明确提出将在现有本科实践教学基础上，积极探索增设研究生实践环节，推动实践项目与学位论文选题、科研攻关紧密结合，引导研究生在真实工程场景中提升科研能力与解决实际问题的能力，以高质量实践推动高层次人才培养质量全面提升。
就实习工作提质增效问题，海航集团表示将聚焦上年度实习反馈中的问题，持续优化并扩充实习项目内容，切实提升学生实习体验。同时，企业希望学院进一步加大民航领域人才培养的宣传力度与资源投入，精准对接企业用人需求，输送更多高素质、专业化的民航后备人才，为企业高质量发展提供持续人才支撑。
此次调研交流活动进一步夯实了双方长期合作的坚实基础，标志着校企合作迈入从“搭建平台”向“提质增效”的关键转型阶段，为促进学生高质量实习就业、共同服务民航行业高质量发展注入了强劲动力。
