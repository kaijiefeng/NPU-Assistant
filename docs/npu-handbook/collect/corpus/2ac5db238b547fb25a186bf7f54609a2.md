# 党委保卫部组织开展校园交通安全主题培训

为进一步提高安保人员维护好校园交通秩序的能力，4月26日下午和5月10日上午，党委保卫部邀请聘任教官交警碑林大队小雁塔中队刘潇泽和江南两位警官分别在两校区开展题为《大学校园周边交通事故预防及简易事故处理》的交通安全主题培训。
此次培训以理论与实践相结合的方式开展。刘潇泽和江南首先结合校园交通环境状况、大学生出行特点、大学生进山安全、维护交通秩序与宣传教育、简易事故处理等五部分内容，开展理论培训。通过学习，安保人员系统了解了校园交通安全的基本知识及日常工作、生活中遇到的常见交通问题，并初步掌握了简易交通事故视频快处的流程和方法。
随后，两位教官针对新老校区不同的交通环境特点，设置不同的事故场景开展实践教学，并耐心示范讲解交通手势指挥与疏导。
通过本次交通安全培训，学校安保人员的交通安全意识得到了进一步提升，为今后做好校园交通管理服务工作奠定了良好的基础。
在此，党委保卫部再次提醒全校师生：珍爱生命，重视交通安全，自觉养成良好的交通安全习惯。
