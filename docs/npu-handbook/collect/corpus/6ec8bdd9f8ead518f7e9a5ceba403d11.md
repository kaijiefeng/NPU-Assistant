# 西北工业大学航海学院“水下机器人创新团队”团队招聘启事

西北工业大学航海学院“水下机器人创新团队”因工作需要，现面向社会公开招聘非事业编制人员1名，具体要求如下：
一、岗位名称
科研助理
二、岗位职责
1.负责实验室硬件设备测试及日常管理；
2.负责课题组采购、财务报账工作。完成课题组劳务费发放、办公用品采购、日常报销等；
3.负责课题组科研项目管理和合同档案管理工作。做好科研项目的日常管理，如申报、结题、经费变更等资料的撰写、归档等工作；
4.协助课题组负责人管理实验室安全等工作；
5.负责课题组科技交流与合作的联系与协调以及完成负责人安排的其他文书和事务性工作。
三、应聘条件
1.具有良好的思想政治素质和职业道德，遵纪守法、身心健康；
2.具有较强的语言表达、写作能力和沟通组织协调能力，能够熟练掌握运用相关计算机办公软件，服务意识强，工作认真细致、责任心强；
3.本科及以上学历，专业不限，有相关科研管理经验。
四、招聘程序
符合条件者请将个人简历、学历、[已脱敏:邮箱]（邮件主题：科研助理+姓名+学校+专业，不接受压缩文件）。
五、考核及待遇
1.考核及待遇参照西北工业大学非事业编制人员有关规定执行；
2.工作地点为：西北工业大学友谊校区；
3.试用期6个月，首次聘期3年。
