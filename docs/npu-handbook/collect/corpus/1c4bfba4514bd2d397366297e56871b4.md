# 项目管理

一、课程信息
课程名称：项目管理
获奖等级：国家级一流本科课程（线上）
二、教学团队
课程负责人兼任航空工业行业职业教育教学指导委员会委员，中国(双法)项目管理研究委员会副主任委员，陕西省项目管理协会会长，中国建筑业协会工程项目管理委员会常委，中国宇航学会系统工程与项目管理委员会副主任等职。
课程团队每年主讲本科“项目管理”课程20多门次，课程先后评为省精品课程、省精品资源共享课程、省精品视频课程、首批国家级一流本科课程（线上）、校线上线下混合式一流课程。
课程负责人主编国家十一五及十二五规划教材《项目管理案例教程》、教育部哲学社会科学原创性教材《中国特色项目管理案例》等近20本，发行量超50万册。
获得的教学奖励：项目管理专业化与系统化系列教材体系建设（教材），2019年陕西省教学成果二等奖；《项目管理》国家级一流本科课程四维一体教学模式创新与实践，2023年陕西省教学成果二等奖；《项目管理案例教程》，2020年陕西省优秀教材二等奖；企业战略导向下的项目组合管理研究，2018年陕西省科技进步三等奖；项目管理工具与方法精要，2018年陕西省哲学社会科学优秀成果三等奖。

三、课程概况
1.课程目标
“项目管理”是面向全校本科的“管理与领导力类”课程，秉承“价值引领、知识融合、实践探究、能力提升”的教学理念，课程目标是培养学生项目管理理论、方法与工具的综合应用能力。具体包括：
1)知识层面：理解和掌握现代项目管理的基础知识体系，深入了解项目管理与其他专业之间的相互联系，对项目管理应用中的关键问题形成清晰认识。
2)能力层面：认识到项目管理是系统做事的方法论，有效提升学生的系统思维能力和系统做事能力，掌握在给定时间、资源及费用等约束下，通过科学计划与管控实现任务目标的能力。
3)素质层面：从系统观出发形成看待问题的大格局、大视野，具备家国情怀和全球视野，实现“立德、树人、求知、悟真、践行”的综合目标。
2.课程建设情况
我校是中国（双法）项目管理研究委员会（PMRC）的发起单位，也是中国项目管理学科发展的主要促进者。项目管理自2000年以来一直是国家一流本科专业工程管理的核心课程，也是面向全校选修的“管理与领导力类”课程，每年面向本科的项目管理课超30门次。课程先后被评为省精品课程、省精品资源共享课程、省精品视频课程、国家一流本科课程（线上）、校研究生高水平课程，线上是中国大学慕课网同类课程选课人数最多的课程，同时也是我校学生选课意愿值全校排名第二的课程。
课程通过线上线下混合式教学改革，形成了混合式、一体化、相关联的教学创新模式。线上基于团队打造的一流线上项目管理慕课开展系统知识学习与考核，线上课程设计36讲，着重于理论知识与管理方法的系统学习，并强化理论知识学习成效的考核。线下基于团队创建的演练、竞赛与认证相结合的“三度融合”一流赋能平台提升学生项目管理创新与实践能力（见图1所示）。
3.课程教学与应用成效
线上慕课是首批国家级一流本科课程（线上），线上选课学生累计超10万人，覆盖百所院校，SPOC使用院校包括哈工大、山东大学等79所；主编教材10多本，并获陕西省优秀教材二等奖一项，教材发行量超50万册，采纳院校包括浙江大学、四川大学、武汉大学等超百所；采写的多篇案例成为中国案例共享中心入库案例和百优案例；指导学生参加“全国高校项目管理案例大赛”，连续8届获奖等级与数量居全国第一。
