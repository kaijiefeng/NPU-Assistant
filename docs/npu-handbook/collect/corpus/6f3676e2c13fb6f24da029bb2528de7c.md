# 西北工业大学社区母子健康手册领取须知-西北工业大学医院

1.《西安市母子健康手册》在西安市助产医疗保健机构代替产科病历使用。除急诊、急症等情况外，孕12周后孕妇须持《手册》在助产机构复诊，医生必须将后续复诊情况在《手册》上按要求记录。
2.西工大辖区（包括西苑、南苑）常住孕产妇可以到西工大医院预防保健科免费领取《母子健康手册》。来时请携带身份证或户口本（若户籍在西工大）或居住在西工大社区的证明。
3.《西安市母子健康手册》领取时间:周内正常上班时间(节假日及特殊情况除外，寒暑假另行通知）。
校医院预防保健科咨询电话：029-88460634。
