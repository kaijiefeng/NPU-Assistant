# 关于封闭综合训练馆东侧道路的通知

北院住宅区各住户：
为保障综合训练馆的正常使用，我办计划于9月5日8时至9月6日20时使用大型工程机械对综合训练馆东侧外墙进行防水施工，施工期间将封闭训练馆东侧与田径场之间道路，禁止车辆停放和通行。因道路封闭，过往车辆可经综合训练馆周边其他道路绕行。
施工难免会对各住户的日常出行、生活造成不便，感谢您的理解与支持。
特此通知。
后勤部办公室党委保卫部
2026年8月31日
