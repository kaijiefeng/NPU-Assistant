# 校企协同育人，实战驱动成长：西工大软件学院携手华为昇腾CANN成功举办暑期训练营

当前，人工智能产业正加速从模型架构创新迈向基础软件深度优化，懂原理、精实战的复合型人才需求日益迫切。2026年7月13日，由西北工业大学软件学院与华为昇腾CANN社区联合主办的“CANN训练营2026暑期季·西北工业大学专场”线下活动在我院成功举行。本次实践活动以“赋能学习+任务实操+现场交流”为核心，面向学生打通了“理论学习→线上集训→线下现场coding攻坚社区任务”的完整实践链路，旨在弥合高校教学与产业需求之间的能力鸿沟，切实提升学生在AI基础软件领域的动手能力与创新思维，为自主AI技术生态建设储备高素质后备力量。
围绕这一链路，训练营采用“先学后练、实战驱动”的分阶段培养模式：线下活动前期，7月6日至8日，由华为技术专家实时线上直播教授6节Ascend C核心课程；，7月13日完成线下昇腾Vibe Coding实操课，确保学生系统掌握昇腾开发全流程。此后，学生正式接取社区任务，并在7月31日前完成提交。参营学生不仅可获得官方认证机会，更能通过源自真实业务场景的任务积累宝贵项目履历，实现从课堂知识到产业实战的有效衔接。
线下活动伊始，西北工业大学软件学院教授徐韬、华为西研高校系统部部长刘晓莉出席并致开场寄语。徐韬教授指出，底层原理是上层优化的根基，吃透计算架构与编译逻辑的运行机制，才是AI时代不可替代的核心竞争力。他以自身多年基础软件研究经验勉励学子：既要善用工具，更要沉入底层，在“知其然更知其所以然”中锻造真正的技术护城河。他高度肯定同学们在暑期主动走进训练营的热情，鼓励大家珍惜与产业专家面对面交流的机会，把疑惑变为追问，把构想落地为代码。刘晓莉部长结合21年基础软件研发经历，向在场学生分享了技术迭代之快远超想象的切身体会。她表示，从“有想法”到“做出来”之间的鸿沟，恰恰是成长最宝贵的一课，而昇腾CANN社区正是同学们动手实践、验证创意的天然摇篮。她寄语学子不做被动的技术消费者，而要做开源生态的积极建设者。
寄语环节之后，活动进入表彰与交流阶段。现场对前期学习中表现突出的优秀开发者进行了表彰，以激励更多同学以先进为榜样、勇攀技术高峰。随后，昇腾CANN生态布道师李博涛带来任务开发技巧交流分享，优秀开发者杨可现场分享实战经验，布道师团队进行课程作业引导与零距离答疑。针对开发中的技术卡点、调试调优策略，同学们获得了即时、精准的指导。这种“学-练-评-奖”闭环设计，有效缩短了从课堂知识到产业应用的认知鸿沟。参营学生纷纷表示，经过连续高强度有效实践，不仅加深了对异构计算架构的理解，团队协作与问题定位能力也得到显著提升。
本次活动通过任务驱动、社区协作与激励引导的有机融合，以真实产业场景检验所学，以社区协作锤炼能力，充分彰显了学院“以练促学、以战代训”的实践育人导向。软件学院始终将工程实践能力与底层创新思维作为人才培养的核心抓手，此次与华为昇腾CANN社区的深度合作，正是学院深化产教融合、推进新工科建设的重要举措。未来，学院将持续引入产业优质资源，搭建更多高水平实践平台，为AI产业输送更多具备底层思维和工程素养的创新型人才。
