# 关于2018届毕业研究生春季派遣有关工作的通知

关于2018届毕业研究生春季派遣有关工作的通知
日期：2018-03-07 16:35   浏览次数：7840

各学院及2018届毕业研究生：

我校将于3月底到陕西省教育厅进行2018届毕业研究生春季集中派遣。派遣数据将于3月19日（星期一）16时冻结，为全面做好本次春季派遣工作，现将有关政策及近期工作通知如下，请严格按照相应时间节点遵照执行。

一、毕业生派遣工作

1.春季派遣对象

所有春季答辩的研究生都将列入春季派遣计划。

2.毕业生核对信息

毕业生应于3月19日前，登陆签约平台核对本人信息：政治面貌、联系方式、奖惩信息、单位名称、单位所在地、档案转递信息、户口迁移地址、报到证抬头、报到地址等，并预览报到证(升学学生无报到证)，如有问题请于3月19日16时前到就业创业中心(或致电)进行核对修改，逾期不予受理。

3.春季派遣数据冻结时间

3月19日16时，就业创业中心将从签约平台下载已答辩毕业生的就业数据，并以此为依据编制2018届毕业研究生春季派遣计划，未就业或签约未完成的学生将以“待就业”状态派遣回原籍，未答辩的学生将列入暑期派遣计划（6月下旬）。

4.就业材料返回时间

春季派遣毕业生必须于3月23日17时前返回就业材料（就业材料可为就业协议书、用人单位出具的接收函、劳动合同、工作证明或录取（录用）通知书等），否则离校系统中就业创业中心审核将不予通过。

5.申请户口档案暂留的毕业生

此类学生需正常参加春季派遣，由本人提出书面申请，暂留期为一年，一年内须自行办理后续转出手续。学生下载填写《西北工业大学毕业生户档暂时留校申请表》（校就业信息网下载），研究生辅导员签字并加盖公章后由学院统一收齐，于3月19日前交就业创业中心，逾期不予受理。

6.自费出国与公派出国

①自费出国：已获取国外、境外大学录取通知书（复印件）的毕业生应在签约平台内选择“出国、出境”提交，填写《西北工业大学毕业生自费出国（出境）留学派遣申请表》（校就业信息网下载），经学院审核签章后与录取通知书复印件一并于3月19日前交就业创业中心，学校将学生户档派回各省区。

②公派出国：已获取国家公派出国资格学生应在签约平台内选择“出国、出境”提交，并将国外、境外大学录取通知书（复印件）、国家留学基金委员会函（复印件）、《西北工业大学国家公派出国留学研究生派遣申请表》及《西北工业大学国家公派出国留学研究生保留户口和档案协议书》（校就业信息网下载）一式两份于3月19日前交就业创业中心办理。

7.灵活就业

灵活就业是指毕业时无法签订就业协议、单位不能开具录用证明或者签订劳动合同证明就业，此类学生需至填写《灵活就业申请表》（纸质版下发学院），由学院收齐后，于3月19日前交就业创业中心审核。

8.待就业

学院应做好待就业毕业生的数据统计，落实签约平台中待就业毕业生手机、电子邮件、QQ号码等有效联系方式的正确填写，并于3月19日前将纸质版待就业硕士毕业生名单统一交至两校区就业创业中心。待就业原因按照“求职中、签约中、拟参加公招考试、拟创业、拟应征入伍、暂不就业、拟升学、拟出国出境”八类填写。

待就业博士毕业生正常参加春季派遣，报到证派回原籍，户口档案暂时留校（不用填表），期限为两年。

二、其他注意事项

1.根据陕西省教育厅有关规定，学校对于定向、委培生原则上不再统一办理就业报到证，学生毕业后直接回本单位工作，学生在校期间的学籍档案由学校邮寄回工作单位。如本单位确需报到证方可办理相关工作手续，请学生本人提出书面申请。

2.毕业生离校工作安排及档案寄发工作见后续通知。
