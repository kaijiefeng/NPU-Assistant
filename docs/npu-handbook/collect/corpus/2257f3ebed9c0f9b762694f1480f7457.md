# 校长宋保维带队赴香港澳门开展全球引才活动

为高质量推进中国特色世界一流大学师资队伍建设，持续发现和吸引全球优秀人才，加快推动“青字号”倍增工程落地见效，3月上旬，由宋保维校长带队，人力资源部和航空学院、航天学院、航海学院、材料学院、机电学院、力学与土木建筑学院、动力与能源学院、自动化学院、计算机学院、网络空间安全学院、柔性电子研究院等11个学院（研究院）赴香港、澳门开展全球引才活动，为学校2024年度全球引才工作拉开了帷幕。
学校在香港理工大学、香港科技大学、香港城市大学、香港大学、香港中文大学、香港浸会大学及澳门科技大学等7所大学举办了专场人才交流会，共吸引了300余名青年学者参会，现场座无虚席，反响热烈。
宋保维校长作学校发展报告。他从学校发展历史、人才培养质量、科学研究水平、学科发展布局、科研平台建设、国际合作与交流等方面详细介绍了学校情况。他指出，西工大是一所有情怀、有担当、有梦想的大学，始终与国家发展同向同行，希望大家选择西工大，立大志、谋大局、有大气，一同为科技强国人才强国建设贡献力量。
为充分发挥以会引才实效，学校在认真总结2023年度全球引才工作基础上，周密部署、细致安排，制定包含所有意向学者、意向岗位、责任学院（研究院）等详细情况的任务表，临行前做到一日一更新，力求对每一位意向学者的需求都做到心中有数。交流会上，人力资源部唐玉生部长详细介绍近年来学校良好的人才发展机遇、人才发展生态以及人才引进政策；各学院（研究院）突出强调了各自学科特色及个性化支持政策等；近年来入职的国家级青年人才崔禾磊、周生喜、王震等分别和大家交流分享成长成才体会和入校发展情况，希望通过个人发展经历吸引更多学者来校工作。
学校良好的科研平台和学科发展态势以及人才引育政策等吸引了众多青年学者，他们与各学院（研究院）在宣讲后进行了面对面深入交流。同时，意向学者和责任学院在会议现场一对一改本子、提意见，务求取得扎扎实实的效果。
在此期间，学校聘任香港理工大学协理副校长、香港工程科学院院士、香港青年科学院院士、科睿唯安高被引科学家王钻开教授为我校客座教授；聘任香港青年科学院院士、香港大学陆洋教授为我校客座教授；聘任香港城市大学杨勇教授、景兴建教授为我校客座教授。四位教授表示，很荣幸成为西工大的成员，将为学校人才引育、学生培养、科学研究、国际交流等方面贡献力量。各学院（研究院）还聘任了12位教授、副教授作为引才大使，将为我校优秀人才引进发挥举荐作用。
学校高度重视人才引育工作，始终将人才、尤其是青年人才视为最宝贵的资源，此次由宋保维校长带队开展全球引才活动，进一步加强了我校与世界一流大学的交流合作，取得了良好的以会引才、以才引才效果。学校将继续由校领导带队，赴新加坡、欧洲等国家开展全球引才，为实现学校“127”发展目标和“天下工大，世界三航”的远景目标贡献人才力量。
(文字：崔晓静；审核：宗凡、唐玉生)
