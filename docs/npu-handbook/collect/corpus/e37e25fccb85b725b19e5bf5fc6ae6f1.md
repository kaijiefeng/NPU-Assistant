# 网络空间安全学院2023年本科生专业实践启训仪式成功举行

8月7日上午，网络空间安全学院2023年本科生专业实践启训仪式在太仓智汇港成功举办。启训仪式由网络空间安全院长助理张慧翔主持，启明星辰有限公司冯德胜、马晓楠、王仲文，学院教师代表和99名2020级本科生参加本次仪式。
院长助理张慧翔首先强调了实习实践的重要性，开展本次专业实践的背景与目的，随后介绍了本次实践的整体安排。本次专业实践由四周的实践课程和演练实训组成。除了系统全面、内容丰厚的实践课程，学院还将利用课余和周末时间组织学生参观企业，浏览风景名胜、人文古迹，通过这些活动，学生们可以近距离了解太仓和苏州的人文、历史和现状，增长知识和见识。
带队教师王曲北剑强调了学生管理的相关规定，对需要注意的事项提出明确的要求。首先，需严格按照寝室入住要求，遵守公寓各项规章制度，中途因故暂时离校等情况，必须与老师进行报备。其次，要保证安全，注意人身安全、出行安全等，确保身体健康。最后，保持通讯畅通，牢记重要联络电话，遇事及时汇报，确保在太专业实践期间安全稳定。希望学生共同遵守规定，营造良好的学习和生活环境，体现新时代西工大学子的风貌和素养。
启明星辰工程师冯德胜就行业发展现状、网络安全产业规模等进行了详实的分析与讲解，启明星辰工程师马晓楠对实践内容和考核要求进行了详细说明，并布置了实践任务。
最后，随着张慧翔老师宣布网络空间安全学院2023年专业实践正式启动，为期四周的专业实践正式拉开帷幕。
网络空间安全学院高度重视实践育人建设，以立德树人为根本，坚持知行合一，加强构建学院实践育人协同体系，整合实践育人资源，加强创新创业教育，搭建实践育人平台，强化实践育人保障，形成实践育人合力，让学生在实践课堂中受教育、长才干、作贡献。自2020年太仓智汇港建设以来，学院高校积极投入资金和资源，建设实验室和实践基地，提供优质的实践条件和设备；积极组织各类实践活动，如实习实训、社会实践、科研实践等，为学生提供广阔的实践舞台，同时，鼓励学生主动参与科研和创新项目，在导师的指导下进行科研实践和创新实践；学院还积极与企业、社会组织建立合作关系，为学生提供实践平台和项目。学院高度重视实践育人，不仅是为了提高学生的实际操作能力和专业素养，更是为了培养学生的创新能力、团队合作能力和解决问题的能力，以应对日益复杂和多变的社会需求。实践教育在现代高等教育中扮演着重要的角色，为学生的综合素质和职业发展奠定了坚实的基础。
