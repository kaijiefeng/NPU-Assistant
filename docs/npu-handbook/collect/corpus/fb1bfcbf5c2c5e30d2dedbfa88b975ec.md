# 【关工委工作】“网小安”问道网安学科奠基人戴冠中教授

在第十个“全国科技工作者日”来临之际，为大力弘扬科学家精神，传承西工大优良传统，5月15日下午，西北工业大学网络空间安全学院关工委组织学生代表，拜访并访谈了我国网络空间安全学科奠基人之一、西北工业大学原校长戴冠中教授。师生们围绕学科创建历程、人才培养理念与前沿技术突破展开深入交流，在对话中感悟老一辈科技工作者“科技报国、敢为人先”的崇高精神，凝聚新时代网安人接续奋斗的磅礴力量。
活动伊始，学院2024级铸剑班班长杨兴硕带着对专业的热爱与好奇率先提问。面对青年学子对学科起点的探寻，戴冠中教授回溯了那段极具远见的创业历程。他回忆道，上世纪90年代中后期互联网飞速发展，他敏锐察觉到网络空间将成为继陆、海、空、天之后的第五疆域，其安全问题隐蔽但至关重要。彼时，“网络空间安全”尚未列入学科目录。面对国家急需，戴冠中教授深知人才培养刻不容缓：“一定要成立一个专业，只有成立专业，才会有人才。”他以已有的“信息对抗”专业为依托招生，并亲自挂帅，从电子、自控、计算机等系动员转来第一批学生，将培养方向精准锁定在网络空间对抗这一全新领域。这招“借壳育才”，使西工大在国内率先迈出了网络空间安全人才培养的第一步。从2000年起步，到2024年跻身国家一流网络安全学院建设示范项目，学院这二十余年的跨越发展正是源于戴冠中教授当年的高瞻远瞩与敢闯敢试。
在技术探索的传承上，年轻一代学子已崭露头角。网络空间安全大学生创新实践基地的学生负责人薛沛元介绍了自己研究大模型智能化网络攻防技术的实战经历，并就此请教从控制论角度看攻防对抗的核心问题。戴冠中教授指出：“利用AI做攻防，最重要的就是数据。”他强调，一定要组织真正隔离、互不通气的攻防小组，进行实战对抗，以此针对性积累高价值数据，才能形成自己的核心系统。戴冠中教授的这一见解，与学院“重实战”的人才培养模式高度契合。
2025级硕士生吕佳文结合自身认知安全研究方向，请教对学生培养的指导意见。戴冠中教授提出，网络空间安全学院的学生不能只停留在应用表层，必须筑牢系统论、控制论、信息论的坚实基础。特别是在认知安全领域，他勉励学子要发挥优势，在利用大模型等技术时，融入结构化推理与正确的价值引导，使研究对国家和社会产生正面作用。
交流中，2024级本科大班团支部书记李雨阳就青年学子如何学习请教戴冠中教授。“基础最重要”戴冠中教授反复叮嘱。他建议同学们扎实学好数学、密码学及系统科学，同时要养成多看论文的习惯，密切关注最新文献和科技前沿。他语重心长地说，真正有价值的漏洞和问题，不是一眼就能看出来的，需要靠长期的脑袋思考和知识沉淀。只有多看、多学、多积累，才能在科技前沿问题出现时迅速反应，将其纳入自己的知识体系中去理解和解决。
访谈的最后，当薛沛元请戴冠中教授为正在从事攻防学习的同学们留一句寄语时，戴冠中教授欣然应允，挥笔写下遒劲有力的嘱托：“做网络空间领域的战斗员。”他深情地补充道，当前国家在硬件制造上快速追赶，但软件与网络信息安全仍需全面加强，核心技术不能靠别人。未来的战争形态将是网络战先行，同学们肩负的责任非常重大。他勉励全体网安学子，既要下大功夫钻研前沿技术，也要在紧张的攻防学习之余强健体魄，以真才实学捍卫国家第五疆域的安全。
访谈学子感悟
听戴冠中校长讲述信息对抗专业的创办初心与战略布局，我深受震撼与鼓舞，深刻理解了学科创立的时代意义与国家重托。我会谨记戴校长的指引，筑牢专业根基、紧跟前沿方向，以赤诚之心深耕网安领域，用真才实学扛起青年担当，守护国家网络安全。
——2024级本科生 杨兴硕
从戴冠中校长的讲述中，我不仅追溯了过往，也对学科的现状与未来有了更清晰的认识。谈话中，戴校长结合时代发展趋势和学科的战略意义，多次谈到实践的重要性，让我更加体会到，作为本科生，要夯实基础、敢于实践，用实际行动筑牢国家网络安全的防线。
——2024级本科生 李雨阳
与学科创始人戴冠中校长对话，我深切感受到了作为新时代网安学子的重任，也领悟到攻防对抗技术的深层价值。我将铭记戴校长的嘱托，持续精进技能，厚植学识，不负所望。
——2023级本科生 薛沛元
从戴冠中校长殷切的话语中，我深切感受到一位将一生投入到教育工作、投入到信息对抗领域当中的教育家、科学家的热忱，戴校长依旧深切关怀着国家的安全与发展，关切着后辈青年们的成长成才，我将牢记戴校长“做网络空间领域的战斗员”寄语，将个人发展与时代脉搏紧紧联系，在网络空间安全领域发光发热。
——2025级硕士生 吕佳文
