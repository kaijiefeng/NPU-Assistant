# 管理运筹学理论与实践

一、课程信息
课程名称：管理运筹学理论与实践
获奖等级：国家级一流本科课程
二、教学团队
课程负责人：车阿大教授
三、课程概况
《管理运筹学理论与实践》课程秉承“以学生发展为中心”的教学理念。近年来，课程团队重构了运筹学课程知识体系，在传统知识体系的基础上，融入智能算法、数学启发式算法、数据驱动的仿真优化等前沿理论，优化了运筹学知识结构；提出了“案例教学-上机实验-综合设计”递进式实践教学模式，通过“做中学”，培养学生运用运筹学理论与方法分析和解决实际管理问题的综合能力；强化多维度的过程性考核，通过构建集案例研讨、上机实验、综合设计汇报、期末闭卷考试于一体的多维考核模式，加强学生应用运筹学模型分析和解决问题的综合能力考核。通过课程思政教育，培养学生整体优化的思维、追求卓越的习惯，使学生树立正确的人生观、价值观和家国情怀。学生普遍反映改革后课程知识结构更加合理，教学内容丰富，教学方法多样，上机实验和综合设计环节收获很大，提高了分析和解决实际管理问题的能力。
