# 西安沃兰科技有限责任公司-西北工业大学资产经营管理有限公司

西安沃兰科技有限责任公司（以下简称沃兰科技）成立于2004年2月，是西北工业大学资产经营管理有限公司的独资公司，注册资金200万元人民币。
沃兰科技是一家集进出口代理、电子计算机软硬件、化工、机械、环保及相关技术产品的开发、销售、技术咨询和技术服务为一体的贸易公司。主要从事教学科研仪器及实验材料进出口代理和各类国际贸易相关咨询服务，服务对象为西工大各教学科研单位以及其他高校、企业、科研院所等。
自成立以来，沃兰科技一直凭借良好的商业信誉、雄厚的技术力量、专业的服务和管理能力，与多家国内外著名企业建立合作关系，为校内外多个客户提供服务，为学校教学科研、企业高质量生产等做出了贡献。
西安沃兰科技有限责任公司将继续奉行内求协作、外求联合的精神，不断开拓创新，为各类用户提供更优质的服务。
