# 人事处党支部组织召开理论学习专题会议

8月31日上午，人事处党支部在学校办公楼A319会议室组织召开理论学习专题会议，全体党员参加会议，会议由党支部书记唐玉生主持。
会上，唐玉生传达了汪校长在学校暑期干部大会上的讲话精神，强调建设好思政课程和开展课程思政工作的重要意义，结合人事工作实际，科学规划思政课程师资队伍建设，将课程思政能力培养纳入教师专题培训体系，切实提升思政教育实效。针对人事人才工作面临的新问题、新挑战，要求全体同志工作要用心，不断加强理论研究，注重开拓创新，推动人事制度改革深入开展。
根据机关党支部理论学习指导意见的要求，会议集中学习了习近平总书记系列重要讲话，重点学习习近平致哈尔滨工业大学建校100周年的贺信、给复旦大学青年师生党员回信、寄语广大高校毕业生等关于高等教育相关讲话精神。阮长江、张忻、孙怡晓结合学习内容，进行了重点交流发言。唐玉生强调，政治理论学习务求学深学透，做到系统梳理、全面消化，特别是习近平总书记关于高等教育方面的论述，大家更要深入理解、积极思考、真抓实干、贯彻落实，发挥好理论指导实践的重要作用。
最后，党支部书记唐玉生、党支部副书记阮长江分别在会上讲授专题党课，学习了习近平总书记来陕考察重要讲话精神和高校人事制度改革相关内容。
(撰稿：张皓 审核：阮长江）
