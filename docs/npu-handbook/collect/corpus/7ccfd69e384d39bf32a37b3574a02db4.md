# 喜报！我院马春燕教授团队荣获国家级一流本科课程认定

近日，教育部公示了《第三批国家级一流本科课程认定结果》，我院马春燕教授团队主讲的《面向对象编程与设计》课程成功入选国家级线上线下混合式一流课程。此次获评，不仅为学院教育教学改革树立了标杆，更为推动高质量数智课程体系建设注入了新动能。
近年来，马春燕带领张涛、王犇、石亦磊等骨干教师深耕教学一线，积极探索课程改革与实践。通过线上线下深度融合，重构教学内容、优化教学模式、创新实践体系并完善考核机制，成功打造出一门兼具理论深度与实践价值的国家级精品课程。
《面向对象编程与设计》课程秉承OBE教育理念和新工科建设要求，构建了理论课、实验课与MOOC课程相结合的混合式教学；课程以学生为中心，实施“自主学—引导学—创造学”三段式教学模式，实现了“理论与实践”相辅相成、“线上与线下”相互补充；课程以特色化大型工业软件案例为支撑，将案例体验与进阶型前沿技术融合；依托混合式教与学过程设计，研制了多元产出评价精准微课堂平台，显著提升了教学质量与学习效率。
此次《面向对象编程与设计》课程成功入选国家级一流本科课程，是学院长期以来坚持高质量课程建设与深化教育教学改革的重要成果。学院始终将人才培养作为立院之本，致力于打造优质教学资源品牌，通过系统规划与创新实践，持续推进课程建设与教育教学质量提升。未来，学院将充分发挥一流课程的示范引领作用，加快推进数智化教学资源建设，构建多类型、多样化的教学内容与课程体系，为“总师型”人才培养提供坚实的教学资源支撑。
审核人：郑江滨
