# 航空学院关于五一假期保密、安全工作的通知

各系、实验室、课题组：
为了做好五一假期学院保密、安全工作，杜绝安全和失泄密事件的发生,现将学院五一假期保密、安全工作要求通知如下：
保密工作
一、各单位要严格按照保密要求，组织开展本单位保密检查，落实假期值班制度，确保涉密设备、涉密科研资料存放安全。
二、放假离校前，涉密人员须按规定将涉密文件、资料和所有涉密介质（涉密移动硬盘、U盘等存储介质）及笔记本电脑检查后放入保密文件柜中存放，检查并锁好办公、实验场所门窗。
三、严禁在家属区、私人住宅或其他有上网条件的非涉密场所处理涉密科研业务，严禁将工作用笔记本带回家中使用。
四、严禁通过微信、腾讯QQ、钉钉等社交平台发送、转发、谈论涉密科研项目相关文件、资料等。
五、各位导师要提醒和教育参与科研项目的研究生，严禁在非密场所、上网机上处理与研究项目有关的事务，严禁将私人电脑及其他带有视频、录像功能的电子产品带入工作场所，严禁将无关人员带入涉密场所。
六、自觉遵守“涉密机不上网、上网机不涉密”的保密规定。
七、承担涉密科研项目的课题组，要重视和加强假期期间的保密工作，对假期继续开展工作的涉密人员做好保密教育，加强课题组载体、计算机及办公自动化设备的管理工作。
八、严格按照保密要求，做好假期期间涉密载体的制作、产生、移交、传递、保管等各环节的保密工作。确保涉密载体账物相符、流向可控、去向可查。
九、假期旅行、探亲的涉密人员不得将工作、科研中知悉的国家秘密泄露给无关人员；不得将无关人员带入科研工作场所及保密要害部门部位。
安全工作
一、开展安全教育，增强安防意识
各单位、实验室、教研室、机房要在放假前对相关人员进行一次安全警示教育(包括实验室的外来施工人员），特别注意假期各办公室、实验室、教研室、机房的安全，增强安全防范意识教育，提高防范能力，严防各类事故的发生。
二、加强组织领导，落实安全工作责任制
牢固树立“以人为本、安全第一、预防为主、综合治理”的理念，严格遵循“谁使用、谁负责，谁主管、谁负责”的实验室安全管理原则，层层压实安全管理责任，确保责任到位、监督到位、检查到位。切实加强对五一假期安全工作的领导，安排部署好本单位的安全工作，明确具体责任人。
三、坚持开展安全自查，严防各类事故发生
各单位、实验室、机房、学习室在放假前认真开展一次深入细致的安全自查，确保不留死角。对检查发现的问题要立即确定整改措施，对尚在整改的部分要制定切实可行的临时防范措施，并及时上报，积极推进妥善解决。
四、五一假期各系、实验室（含机房）办公室、学习室要特别注意以下几点：
（1）假期里各机房、办公室、实验室等人员离开时必须关闭水源、电源，锁好门，关好窗，空调、饮水机、计算机、充电器等长期不使用要拔掉电源插头。
（2）进入实验室人员必须遵守实验室的各项规定，严格执行相关的操作规程。
（3）保持实验室卫生，禁止堵塞实验室消防通道，保持消防通道畅通。
（4）对易燃、易爆、化学品等危险品，要严格按有关制度领用、贮存和使用，严防危险品流出实验室，同时要加强实验废弃物处置的管理。
（5）各个实验室门钥匙必须专人专管，不得擅自外借他人使用，以备应急之需。任何人不得在实验室从事烹煮食物、聚餐、吸烟、使用明火等与实验无关的事情，严禁在教研室、实验室留宿，不得从事与实验无关的事情。
（6）对于压力容器、气瓶、起重机、行吊等特种设备，假期里应妥善放置，如需使用须报系所主管领导责批准，相关实验室负责人同时做好安全提醒等工作。
（7）不合格或有裂纹的插座要及时更新，且不得放在木质桌面上，最好选用大公司名牌产品，以防不测。
（8）使用临时工和进行施工的单位要对其相关人员进行安全教育，坚决制止违规使用大功率电器，规范操作施工，防止发生电器火灾和其它安全事故，确保安全。
五、值班人员在值班期间要注意检查本单位及周边情况，发现问题及时报告值班领导，并上报学院以及学校保卫处等上级部门。
航空学院
