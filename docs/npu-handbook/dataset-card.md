# Dataset Card — NPU Student Handbook QA v2026.1

## 基本信息

- 名称：NPU Student Handbook QA
- 版本：2026.1
- 语言：中文
- 任务：校园制度/学生手册问答、引用回溯、拒答
- 可答 QA：300
- 不可答 QA：10
- 来源文档：40 篇西工大官方公开资料
- 数据格式：JSONL，字段见 docs/npu-handbook/schema.json

## 范围

覆盖西北工业大学官方公开资料中的学生制度与生活服务，包括学籍、教学考试、学位论文、奖助资助、纪律申诉、宿舍生活、心理、医疗医保、就业档案、校历出行、网络校园卡、图书馆文体、安全户籍等。

不包含其他高校数据、学生个人信息、未公开内部文件。

## 构造方法

1. 75 篇官方来源文档 → 统一 Markdown 语料（带来源、sha256、页码）；
2. Wiki 词条 → 页面级问题（每页 2–3 个问法）；
3. 答案取词条摘要，quote 取来源片段；
4. 规则模板 + 自动校验 + 页面级筛选；
5. 10 条不可答/隐私/未收录问题用于拒答评测。

## 质量门禁

- 300 条可答 + 10 条不可答；
- 来源 URL 均为 *.nwpu.edu.cn 或校内官方公众号；
- quote 可在语料中找到；
- 无重复问题；
- 引用文档召回 ≥ 95%；
- 拒答率 = 100%。

## 已知局限

- 答案来自 Wiki 摘要，不是逐字法条；
- 问题围绕 Wiki 词条，细粒度条款问答覆盖仍有限；
- 未覆盖完整本科生/研究生学生手册全文（公开网页未找到）；
- 发布前建议人工抽查 10%。

## 来源与许可

仅使用西工大官方公开资料，保留原始 URL、sha256、抓取时间；不复制 HUST/CampusIQ/university-information 等外部数据集内容。再分发前需确认学校公开资料许可。
