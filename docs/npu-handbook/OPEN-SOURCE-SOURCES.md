# NWPU 相关开源资料调研

调研日期：2026-10-27  
调研范围：GitHub、Hugging Face、ModelScope、网页搜索  
用途：只作为**覆盖清单和来源线索**，不直接导入数据集。

## 结论

没有找到公开的**西北工业大学官方学生手册全文**或官方问答数据集。  
能找到的 NWPU 相关开源项目主要是：

1. 学生自写的校园生活/学习指南；
2. 课程资料、校园地图、社区 wiki；
3. 遥感数据集（与校园问答无关）。

其中最有参考价值的是 **《瓜兵速成指南》**，但它没有开源许可证，且是个人/学生整理，不能直接作为权威内容导入。

## 二、《瓜兵速成指南》可补充的主题

从仓库目录看，和当前数据集的缺口高度重合：

- 宿舍：床铺尺寸、楼栋分布、独卫/独浴、空调暖气、断网断电；
- 生活：热水时间、洗衣房、快递点、外卖、打印、超市、校医院、眼镜店；
- 学习：选课、GPA、补考/缓考/重修、转专业、体测、奖学金、保研；
- 出行：校门、校车、去市区、去火车站、学生票；
- 竞赛：数学建模、三电、英语、普通话、创新创业。

其中不少条目我们已经有官方来源；它更适合用来**检查问题覆盖是否完整**，而不是提供答案。

### 附件中的官方制度线索

仓库 `docs/public/attachment/` 里有多份西工大制度 PDF，可作为找官方原文的线索：

- 《西北工业大学本科生考试管理办法》
- 《西北工业大学本科生转专业（大类）实施办法》
- 《西北工业大学本科生 GPA 计算办法》
- 《西北工业大学本科生选课办法》及补充规定
- 本科生在读证明流程
- 体测各项评分标准
- 深澜上网账号激活和 PPPoE 拨号设置须知
- 2024 年硕士招生专业目录
- 发展党员工作流程图/规程

**这些附件应回到 `nwpu.edu.cn` 找原始发布页后再入库，不从第三方仓库复制。**

## 三、明确不建议直接使用的资料

1. **RLE-wiki NWPU 页面**：含个人 QQ、邮箱、跨性别学生人数等敏感信息，不适合作为通用知识库内容。
2. **课程资料仓库**：作业、实验报告、教师答案涉及版权和学术诚信，不应进入学生手册问答。
3. **无许可证的学生指南**：可读、可参考结构，但不能直接复制正文；如要引用，应先联系作者取得许可。
4. **遥感/科研数据集**：与校园制度问答无关，避免误用。

## 四、建议的补充顺序

### P0：官方制度原文

优先找以下官方 PDF/页面，补进 `sources.json`：

- 本科生考试管理办法
- 本科生转专业（大类）实施办法
- 本科生 GPA 计算办法
- 本科生选课办法
- 本科生在读证明流程
- 体测评分标准
- 校园网认证/深澜账号说明

### P1：生活服务核对

用《瓜兵速成指南》的目录做 checklist，逐条核对：

- 热水时间、洗衣房、快递点、打印点、超市、食堂、校医院、校车、校门、外卖。

已有官方来源的保留官方；没有官方来源的，标记“待核实”，不直接写入答案。

### P2：地点/导航

如果后续做“校园地图/怎么走”类问答，可参考 NPUmap 的 POI，但必须：

- 保留 MIT 许可和版权声明；
- 坐标实测核对；
- 不把个人开发项目说成学校官方数据。

## 五、对当前数据集的影响

当前 v2026.1 数据集**没有导入上述任何外部内容**，来源仍全部是西工大官网/校内公众号。

这份调研的用途是：

1. 补充 `sources.json` 的 P0/P1 目标；
2. 检查生活服务类问题是否覆盖完整；
3. 为后续“校园地图/位置”类问答提供候选 POI 来源。

> 外部项目只作为线索和覆盖清单；是否入库取决于原始来源是否为西工大官方公开资料，以及许可是否允许。
