# 源文件来源审计（2026-11-15 导入后）

## 一、结论

- **获取途径**：当前 2,618 篇源文件均来自公开渠道（学校官网、信息公开、学院/部门站点、微信公众号公开文章、公开下载附件），**未发现**需要登录、内网、VPN 或本地私有路径才能获取的文件。
- **但**：部分源文件包含个人信息（录取/合格名单、联系人手机号、邮箱、报名号等），即使原始页面公开，**也不建议把原始文件直接提交到 Git 仓库**。

|---|---|
| A. 保持不提交源文件（推荐） | Git 只保留代码/文档；源文件留在 `backend/data/uploads`，避免公开仓库扩散个人信息 |
