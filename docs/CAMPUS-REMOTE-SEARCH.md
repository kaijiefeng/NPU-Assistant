## 三、实现方式

新增：

```text
backend/app/remote_sources.json        # 四个网站 + 四个公众号的检索配置
backend/app/services/remote_search.py  # 检索服务（不写数据库）
scripts/remote_search_probe.py         # 命令行探针
```

流程：

```text
query
  → 网站站内搜索 API（VSB AOP queryPage）
  → 搜狗微信搜索（非自有公众号）
  → 还原 mp.weixin 原文 URL → 抓正文
  → 结果只进内存 TTL 缓存（15 分钟）
  → 返回 {source,title,url,snippet,content,date,fetched_at}
```

关键约束：

- 网站结果按 `allowed_domains` 过滤，外站链接丢弃；
- 公众号结果按账号别名过滤；
- 不登录、不绕验证码；触发反爬直接报错；
- 不写 `documents` / Wiki，不改变本地库容量；
- 文章 URL 带时效签名，必须发现后立即抓取。

## 四、开源社区方案评估

| 项目 | 结论 |
|---|---|
| [wechat-article-exporter](https://github.com/wechat-article/wechat-article-exporter) | 2026-07-30 已停止维护，上游接口关闭，不可用 |
| [Wechat2RSS](https://github.com/ttttmr/Wechat2RSS) | 需订阅公众号/使用托管服务，非通用非自有账号方案 |
| [Mp2RSS](https://github.com/areyoubugcoder/Mp2RSS) | 商业托管/订阅制，不适合本项目 |
| [weread-mp-fetcher](https://github.com/Pengyf04/weread-mp-fetcher) | 依赖微信读书登录态，涉及个人账号，不采用 |

结论：非自有公众号没有稳定官方搜索 API；**搜狗微信搜索 + 原文抓取**是目前可试验的公开路径，但属于第三方、易触发反爬，只适合低频/演示，不适合作为唯一生产通道。

## 五、维护与降级

- 网站搜索 owner/URL 可能随站点改版变化：配置化 + 健康检查；
- 搜狗触发验证码：冷却 10–30 分钟，转人工/CUA，不重试轰炸；
- 公众号文章打不开：保留搜索标题/摘要，标记“仅摘要”，不伪造正文；
- 所有结果带 `fetched_at`，回答中标注“实时检索”；
- 管理员可随时停用某个源。

## 六、接入回答链路（下一步）

```text
本地检索（Wiki）
  + remote_search.search_all(query)
  → 合并/去重
  → LLM 回答
  → citations: origin=local/remote + url + fetched_at
```

远程结果只作为临时上下文，不编译进 Wiki。

## 八、合规说明

- 只检索公开页面/公开文章；
- 不登录、不绕过验证码、不伪造身份；
- 低频请求，遵守站点条款；
- 保留原文 URL 与抓取时间，版权归原作者；
- 如学校/公众号要求撤下，停用对应源即可。
